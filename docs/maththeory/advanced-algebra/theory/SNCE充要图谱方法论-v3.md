# SNCE充要图谱 v3 · 方法论规范

> 版本：v3.0　日期：2026-10-07　状态：✅ 生效

## 0. 一句话本质

以SNCE双路径充要拆解为核心操作，按命题类型入模板、按五层认知架构记理解深度、以版本回溯对抗过早收敛、以双反例边界探针标记概念边界、以充要关系三类边（充分→/必要←/充要↔）把卡片盒改造成逻辑化知识网络。

## 2. 五阶内核（环形，可回溯）

> 每阶标注对应的SNCE操作步骤与认知机制。五阶不是线性瀑布，而是实践→认识→再实践→再认识的辩证循环。

### 阶1 充要定位
- **操作**：本质问题 + 命题类型判定 + 几何锚定。
- **SNCE对应**：S1充分性探索的准备阶段——明确"我要理解什么概念""这个概念属于什么命题类型""它的几何载体是什么"。
- **认知机制**：这是实践的目的性环节——学习者在构造之前先明确构造的目标，对应马克思主义哲学中"实践是有目的的能动性活动"。本质问题必须能追溯到实践需要（这个概念是为了解决什么问题而产生的？）或对象化后的属性反思（这个概念形成后有什么必然性质？）。

### 阶2 基石锚定
- **操作**：严谨表述；按命题类型选方向——
  - 刻画定理：判定方向（充分）+ 性质方向（必要）；
  - 单向定理：前提 → 结论 + 不反向的证据；
  - 定义：判定条件清单；
  - 算法：输入/输出/步骤/复杂度；
  - 例族：典型例 + 边界例。
- **SNCE对应**：S1充分性探索（判定方向）+ S2必要性探索（性质方向）的初步执行。
- **认知机制**：这是充分条件与必要条件的分离环节——判定方向回答"什么条件足以推出概念"（实践的能动性：人主动构造前提），性质方向回答"概念成立必然推出什么"（认识的反思性：对象化后反思固有属性）。二者的分离是充要互通的前提——只有先分别掌握充分和必要，才能在二者之间自由往返。

### 阶3 充要双拆
- **操作**：构造法（怎么做）+ 解释法（为什么）+ 边界探针（反例）。
- **SNCE对应**：S1充分性探索（构造法）+ S2必要性探索（解释法）+ S4双反例边界探测（边界探针）的深度执行。
- **认知机制**：
  - **构造法**是实践的对象化——从条件出发构造满足概念的具体对象，在空间中"看到"构造过程（空间化构造）或用符号表达式构造（符号化构造）。构造成功则条件是充分的。
  - **解释法**是认识的反思——从概念自身出发推导其必然推论，在空间中观察对象的必然几何性质（空间化解释）或用符号推导代数性质（符号化解释）。每个推论都是必要条件。
  - **边界探针**是认识的边界标记——通过构造充分反例（满足条件但不满足概念）和必要反例（满足概念但不满足条件）来精确探测概念的适用边界。这对应真理的相对性——任何概念都有其适用范围，超出范围真理就转化为谬误。
  - **双路径协同**：构造法与解释法交替执行、最终整合，不是同时进行（认知负担大）。初学者有先后，高阶者双向贯通。

### 阶4 直观验证
- **操作**：代数结论 → 几何操作；几何约束 → 代数表达（仅 ✅/⚠️ 锚定项执行）。
- **SNCE对应**：空间直观双重定位中的表征维度——空间化与符号化的双向辅助。
- **认知机制**：这是空间化与符号化的互译环节——代数结论转化为几何操作（符号→空间），几何约束转化为代数表达（空间→符号）。空间直观启发符号推导，符号推导深化空间直观，二者形成正反馈循环。⚠️级锚定必须标注失效边界——几何类比在什么情况下不成立，这本身就是边界探针的一部分。

### 阶5 收敛沉淀
- **操作**：一句话本质（定义级 / 结构级两层）+ 高频易错 + 迁移题 + 误区归因。
- **SNCE对应**：S3充要识别（充要条件集的提炼）+ S5误区归因（错误分类与认知机制分析）。
- **认知机制**：这是认识的阶段性收敛——从丰富的充要拆解中提炼出概念的本质（充要条件集），并对学习过程中出现的错误进行系统归因。但收敛不是终点——误区归因的结果反过来修正对概念的理解，触发下一轮的边界探测。一句话本质分定义级与结构级两层，允许标注"待修订"，承认压缩的暂时性——这是对"收敛认知锁死"的制度性防御。

## 3. 六机制

| 机制 | 对应缺陷 | 操作规则 | SNCE理论构件 |
|---|---|---|---|
| ① 命题类型化 | 缺陷一、二 | 模板按类型分流；本质问题须能写出判定标准，否则不写 | SNCE命题类型化区分（定义/刻画定理/单向定理/算法/例族） |
| ② 版本与回溯 | 缺陷三 | 用新概念重读旧条目即升版，追加"本次回看新增：…"记录 | SNCE双路径交替执行 + 设计研究迭代循环 |
| ③ 收敛分级 | 缺陷四 | 本质分两层写；允许标注"待修订" | SNCE误区归因模型（S5不是终点，是下一轮边界探测的起点） |
| ④ 几何锚定分级 | 缺陷五 | 按 ✅/⚠️/⛔ 标注；⚠️ 必须写失效边界 | SNCE空间直观双重定位（可信度分级 + 失效边界=双反例探针） |
| ⑤ 充要关系边管理 | 缺陷六 | 每条目携带：充分→ / 必要← / 充要↔ 三类逻辑边 + 前驱→后继 / 类比 / 推广 / 特例 / 反例簇 五类语义边 | SNCE充要知识图谱（三类逻辑边 + 五类语义边互补） |
| ⑥ 深度分级 + 外部校验 | 缺陷七、八 | L1~L5 记深度；每模块配置证伪任务或真题锚点 | SNCE五层认知架构 + 四层测量体系（外部证据不依赖方法自身） |

## 4. 外部校验清单（每模块至少一项）

> 外部校验的认知本质：引入不依赖方法自身的证据来源，对抗自证偏误。这对应SNCE四层测量体系中的解题行为编码和误区诊断。

- [ ] 证伪任务：为模块核心命题找一个失效反例（充分反例或必要反例）；
- [ ] 真题锚点：至少 1 道与模块直接相关的真题/竞赛题；
- [ ] 例生成：自造 2~3 个例子并说明其边界（参考 Bogomolny 的例生成任务思想）；
- [ ] 充要关系图：画出本模块核心概念的充要关系图（标注充分→/必要←/充要↔），与专家图对比。

---

## 5. 复杂度分级（防一刀切）

| 级别 | 适用 | 要求 | SNCE对应 |
|---|---|---|---|
| L1 轻条目 | 定义、小性质、记号 | 条目头 + 定义级本质 + 1 条边 | L1概念记忆层 |
| L2 标准图谱 | 核心定理、算法 | 五阶完整 + 1 项外部校验 | L2-L3条件识别/双向拆解层 |
| L3 深层图谱 | 结构定理、标准形 | 五阶完整 + 多轮回溯（≥2 次升版）+ 2 项外部校验 + 充要关系图 | L4-L5边界通透/充要重构层 |
