# 充要图谱 v2 · 方法论规范

> 版本：v2.0　日期：2026-09-06　状态：✅ 生效
> 定位：新体系（三领域重构）所有模块的统一生成模板与理解协议。
> 与 v1 的关系：保留五阶内核（充要双拆、边界探针、收敛沉淀），修复八项结构性缺陷，改变方法的"形状"。
> 详细诊断见《00-几何统摄与充要图谱-学术论文.md》第 6 节。

---

## 0. 一句话本质

知识条目按命题类型入模板、按深度分级记理解、以版本回溯对抗过早收敛、以外部校验对抗自证偏误、以五类边把卡片盒改造成知识网络。

---

## 1. 条目头（每个条目必填）

| 字段 | 取值 | 说明 |
|---|---|---|
| 命题类型 | 定义 / 刻画定理 / 单向定理 / 算法 / 例族 | 决定模板形态，充要模板仅用于刻画定理 |
| 领域归属 | 领域一 矩阵×基 / 领域二 线性空间 / 领域三 线性变换 | 三领域相对独立 |
| 模块编号 | 如 F3 / S6 / T5 | 所在领域内模块 |
| 几何锚定 | 一条可核验几何命题 + 分级标签 | 分级：✅可信直觉 / ⚠️启发类比(标失效边界) / ⛔无几何不硬造 |
| 版本号 | v1 / v2 / v3 … | 每次重读修订即升版 |
| 理解深度 | L1 见过 / L2 会用 / L3 能讲 / L4 能改能证 | 取代 v1 的三元状态 |

## 2. 五阶内核（环形，可回溯）

1. 充要定位：本质问题 + 命题类型判定 + 几何锚定。
2. 基石锚定：严谨表述；按命题类型选方向——
   - 刻画定理：判定方向（充分）+ 性质方向（必要）；
   - 单向定理：前提 → 结论 + 不反向的证据；
   - 定义：判定条件清单；
   - 算法：输入/输出/步骤/复杂度；
   - 例族：典型例 + 边界例。
3. 充要双拆：构造法（怎么做）+ 解释法（为什么）+ 边界探针（反例）。
4. 直观验证：代数结论 → 几何操作；几何约束 → 代数表达（仅 ✅/⚠️ 锚定项执行）。
5. 收敛沉淀：一句话本质（定义级 / 结构级两层）+ 高频易错 + 迁移题。

## 3. 六机制

| 机制 | 对应缺陷 | 操作规则 |
|---|---|---|
| ① 命题类型化 | 缺陷一、二 | 模板按类型分流；本质问题须能写出判定标准，否则不写 |
| ② 版本与回溯 | 缺陷三 | 用新概念重读旧条目即升版，追加"本次回看新增：…"记录 |
| ③ 收敛分级 | 缺陷四 | 本质分两层写；允许标注"待修订" |
| ④ 几何锚定分级 | 缺陷五 | 按 ✅/⚠️/⛔ 标注；⚠️ 必须写失效边界 |
| ⑤ 五类边管理 | 缺陷六 | 每条目携带：前驱→后继 / 类比 / 推广 / 特例 / 反例簇 |
| ⑥ 深度分级 + 外部校验 | 缺陷七、八 | L1~L4 记深度；每模块配置证伪任务或真题锚点 |

## 4. 外部校验清单（每模块至少一项）

- [ ] 证伪任务：为模块核心命题找一个失效反例；
- [ ] 真题锚点：至少 1 道与模块直接相关的真题/竞赛题；
- [ ] 例生成：自造 2~3 个例子并说明其边界（参考 Bogomolny 的例生成任务思想）。

## 5. 复杂度分级（防一刀切）

| 级别 | 适用 | 要求 |
|---|---|---|
| L1 轻条目 | 定义、小性质、记号 | 条目头 + 定义级本质 + 1 条边 |
| L2 标准图谱 | 核心定理、算法 | 五阶完整 + 1 项外部校验 |
| L3 深层图谱 | 结构定理、标准形 | 五阶完整 + 多轮回溯（≥2 次升版）+ 2 项外部校验 |
