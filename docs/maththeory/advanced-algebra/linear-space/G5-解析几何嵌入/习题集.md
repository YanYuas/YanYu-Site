## 本模块核心考点

1. **向量与位置向量**：点 P 的位置向量，两点距离
2. **直线方程**：参数式、对称式、一般式（两平面交）
3. **平面方程**：点法式、一般式、截距式
4. **法向量**：平面 Ax+By+Cz+D=0 的法向量 n=(A,B,C)
5. **位置关系**：线线（平行/相交/异面）、线面（平行/相交/在面内）、面面（平行/相交/重合）
6. **夹角**：线线角、线面角、面面角（均用内积）
7. **距离**：点到平面、点到直线、异面直线距离（均用正交投影）
8. **投影**：点在平面/直线上的投影
9. **曲面**：球面、柱面、旋转曲面
10. **二次曲面**：椭球面、双曲面、抛物面
11. **坐标变换**：平移、旋转
12. **线性代数视角**：平面=线性方程的解，直线=两平面交，法向量=系数行向量，距离=正交投影，夹角=内积

### ★ 基础巩固

**【G5-A-★-001】** 求过点 P0(1,2,3)，方向向量 v=(2,-1,1) 的直线的参数方程和对称式方程。

- **难度**：★
- **对应知识点**：直线方程（研究模块第 1 章）
- **耦合方向**：→ G1（向量空间）/ → F2（线性方程组）
- **来源**：基础计算题
- **解答**：
  **参数方程**：r = r0 + t·v，即
  (x,y,z) = (1,2,3) + t(2,-1,1)
  分量形式：x=1+2t, y=2-t, z=3+t (t∈R)

  **对称式方程**：从参数方程解出 t：
  t = (x-1)/2 = (y-2)/(-1) = (z-3)/1
  即 (x-1)/2 = (2-y)/1 = (z-3)/1

  **验证**：t=0 时 (x,y,z)=(1,2,3)=P0 ✓；方向向量与对称式分母一致 ✓。

  几何意义：直线上的点 = 起点 P0 + 方向向量的任意倍数。参数 t 表示从 P0 出发沿 v 方向走了多远。
- **一句话点评**：直线参数式 r=r0+t·v=起点+方向×参数，对称式由参数式解出t联立。这里 (x,y,z)=(1,2,3)+t(2,-1,1)，对称式 (x-1)/2=(2-y)=(z-3)。直线的本质="一个点+一个方向"——1维仿射子空间，方向向量生成1维线性子空间，点确定位置。

**【G5-A-★-002】** 求过点 P0(1,2,3)，法向量 n=(2,-1,1) 的平面方程，并化为一般式。

- **难度**：★
- **对应知识点**：平面方程（研究模块第 2 章）
- **耦合方向**：→ F2（线性方程）/ → G3（法向量/正交）
- **来源**：基础计算题
- **解答**：
  **点法式**：n·(r-r0)=0，即
  2(x-1) - 1(y-2) + 1(z-3) = 0

  **展开为一般式**：
  2x-2-y+2+z-3 = 0 → 2x-y+z-3 = 0

  **验证**：代入 P0(1,2,3)：2(1)-2+3-3=0 ✓；法向量与一般式系数 (A,B,C)=(2,-1,1) 一致 ✓。

  **截距式**：x 截距 3/2，y 截距 -3，z 截距 3。
  x/(3/2) + y/(-3) + z/3 = 1

  几何意义：平面是所有满足"与法向量垂直"的点的集合——n·(r-r0)=0 表示平面内任意向量与法向量正交。法向量决定平面的"朝向"，点决定平面的"位置"。
- **一句话点评**：平面点法式 n·(r-r0)=0=法向量与平面内任意向量正交，一般式 Ax+By+Cz+D=0 由点法式展开。这里 2(x-1)-(y-2)+(z-3)=0 化为 2x-y+z-3=0。平面的本质="一个点+一个法向量"——2维仿射子空间，法向量的正交补是2维线性子空间（平面方向），点确定位置。一般式系数(A,B,C)就是法向量。

**【G5-A-★-003】** 求点 P(1,2,3) 到平面 2x-y+z-3=0 的距离。

- **难度**：★
- **对应知识点**：点到平面的距离（研究模块第 4 章）
- **耦合方向**：→ G3（正交投影/距离）/ → F2（线性方程）
- **来源**：基础计算题
- **解答**：
  点到平面距离公式：
  d = |Ax0+By0+Cz0+D| / sqrt(A²+B²+C²)

  这里 A=2,B=-1,C=1,D=-3，P(1,2,3)：
  d = |2(1)-2+3-3| / sqrt(4+1+1) = |0|/sqrt(6) = 0

  距离为 0，说明点 P 在平面上！验证：2(1)-2+3-3=0 ✓。

  **换一个不在平面上的点** Q(0,0,0) 验证公式：
  d = |0+0+0-3|/sqrt(6) = 3/sqrt(6) = sqrt(6)/2 ≈ 1.22

  几何意义：点到平面的距离 = 点到平面的垂线段长度 = 点与平面上任意一点连线在法向量方向上的投影长度。
  公式推导：取平面上一点 P0，向量 P0P 在法向量 n 上的投影长度 = |n·P0P|/||n|| = |Ax0+By0+Cz0+D|/||n||。
- **一句话点评**：点到平面距离 d=|Ax0+By0+Cz0+D|/sqrt(A²+B²+C²)=点与平面上点连线在法向量上的投影长度。这里P(1,2,3)代入得0——点在平面上！换Q(0,0,0)得 d=3/sqrt(6)=sqrt(6)/2。距离公式的本质是正交投影：d=||P_n(P0P)||，这是G3正交投影在解析几何中的直接应用。

**【G5-A-★-004】** 求点 P(1,2,3) 到直线 (x-1)/2=(y-2)/(-1)=(z-3)/1 的距离。

- **难度**：★
- **对应知识点**：点到直线的距离（研究模块第 4 章）
- **耦合方向**：→ G3（叉积/投影）/ → G1（向量）
- **来源**：基础计算题
- **解答**：
  直线过 P0(1,2,3)，方向向量 v=(2,-1,1)。

  注意：P(1,2,3)=P0，点在直线上，距离为 0！

  **换一个不在直线上的点** Q(0,0,0)：
  点到直线距离公式：
  d = ||P0Q × v|| / ||v||

  P0Q = Q-P0 = (-1,-2,-3)。
  P0Q × v = |i  j  k; -1 -2 -3; 2 -1 1|
  = i((-2)(1)-(-3)(-1)) - j((-1)(1)-(-3)(2)) + k((-1)(-1)-(-2)(2))
  = i(-2-3) - j(-1+6) + k(1+4) = (-5,-5,5)

  ||P0Q × v|| = sqrt(25+25+25) = sqrt(75) = 5·sqrt(3)
  ||v|| = sqrt(4+1+1) = sqrt(6)
  d = 5·sqrt(3)/sqrt(6) = 5/sqrt(2) = 5·sqrt(2)/2 ≈ 3.54

  几何意义：点到直线的距离 = 以 P0Q 和 v 为邻边的平行四边形面积 / 底边长 ||v|| = 高。叉积的模=平行四边形面积，除以底=高=点到直线距离。
- **一句话点评**：点到直线距离 d=||P0Q×v||/||v||=平行四边形面积/底=高。这里P在直线上（P=P0）距离为0；换Q(0,0,0)得 d=5sqrt(2)/2。叉积 P0Q×v 的模=以两者为邻边的平行四边形面积，除以方向向量长度=高=点到直线距离。这是向量叉积在几何中的经典应用。

**【G5-A-★-005】** 求两直线 L1: (x-1)/1=(y-2)/2=(z-3)/3 和 L2: (x-2)/2=(y-1)/1=z/(-1) 的夹角。

- **难度**：★
- **对应知识点**：两直线的夹角（研究模块第 3 章）
- **耦合方向**：→ G3（内积/夹角）/ → G1（向量）
- **来源**：基础计算题
- **解答**：
  L1 方向向量 v1=(1,2,3)，L2 方向向量 v2=(2,1,-1)。

  两直线夹角公式（取锐角，0≤θ≤π/2）：
  cosθ = |v1·v2| / (||v1||·||v2||)

  v1·v2 = 1×2+2×1+3×(-1) = 2+2-3 = 1
  ||v1|| = sqrt(1+4+9) = sqrt(14)
  ||v2|| = sqrt(4+1+1) = sqrt(6)

  cosθ = |1|/(sqrt(14)·sqrt(6)) = 1/sqrt(84) = 1/(2·sqrt(21)) ≈ 0.109
  θ = arccos(1/(2sqrt(21))) ≈ 83.7°

  验证 Cauchy-Schwarz：|v1·v2|=1 ≤ sqrt(14)·sqrt(6)=sqrt(84)≈9.17 ✓。

  几何意义：两直线的夹角=它们方向向量的夹角（取锐角）。内积给出夹角余弦，这是 G3 内积/夹角在解析几何中的直接应用。
- **一句话点评**：两直线夹角 cosθ=|v1·v2|/(||v1||||v2||)（取锐角）。这里 v1=(1,2,3),v2=(2,1,-1)，点积=1，cosθ=1/sqrt(84)≈0.109，θ≈83.7°。直线夹角=方向向量夹角，本质是G3内积定义的夹角在解析几何中的应用。取绝对值是因为直线没有方向（正反指向同一直线），所以取锐角。

**【G5-A-★-006】** 求直线 L: (x-1)/2=(y-2)/(-1)=(z-3)/1 与平面 π: 2x-y+z-3=0 的夹角。

- **难度**：★
- **对应知识点**：直线与平面的夹角（研究模块第 3 章）
- **耦合方向**：→ G3（内积/夹角）/ → F2（线性方程）
- **来源**：基础计算题
- **解答**：
  直线方向向量 v=(2,-1,1)，平面法向量 n=(2,-1,1)。

  注意：v=n！直线方向与平面法向量相同，说明直线垂直于平面，夹角=90°。

  用公式验证：直线与平面夹角 θ（0≤θ≤π/2）是直线与它在平面上投影的夹角：
  sinθ = |v·n| / (||v||·||n||)

  v·n = 4+1+1 = 6
  ||v|| = ||n|| = sqrt(6)
  sinθ = 6/6 = 1，θ=90°。✓

  **换一个不垂直的例子**：直线方向 v=(1,0,0)，平面法向量 n=(0,0,1)（xy-平面）。
  sinθ = |0|/(1×1) = 0，θ=0°——直线平行于平面（在平面内或平行）。

  几何意义：线面角=直线与平面中投影的夹角=90°-直线与法向量的夹角。所以用 sinθ 而不是 cosθ——线面角是方向向量与法向量夹角的补角。
- **一句话点评**：线面角 sinθ=|v·n|/(||v||||n||)=直线与平面中投影的夹角=90°-直线与法向量夹角。这里 v=(2,-1,1)=n，直线垂直平面，θ=90°（sinθ=1）。换 v=(1,0,0),n=(0,0,1) 得θ=0°（直线平行平面）。线面角用sin是因为它是方向向量与法向量夹角的补角——这是内积夹角在几何中的补角应用。

### ★★ 进阶应用

**【G5-A-★★-007】** 判断两直线 L1: (x,y,z)=(1,2,3)+t(1,0,-1) 和 L2: (x,y,z)=(0,1,2)+s(2,1,1) 的位置关系（平行/相交/异面），若相交求交点。

- **难度**：★★
- **对应知识点**：两直线位置关系（研究模块第 3 章）
- **耦合方向**：→ F2（线性方程组）/ → G1（向量）
- **来源**：基础计算题
- **解答**：
  L1 方向 v1=(1,0,-1)，L2 方向 v2=(2,1,1)。
  L1 过 P1=(1,2,3)，L2 过 P2=(0,1,2)。

  **第一步：判断是否平行**
  v1 与 v2 不成比例（1/2 ≠ 0/1），不平行。

  **第二步：判断是否相交**
  设交点满足：(1,2,3)+t(1,0,-1) = (0,1,2)+s(2,1,1)
  分量方程：
  1+t = 2s  ... (1)
  2 = 1+s   ... (2)
  3-t = 2+s ... (3)

  由 (2)：s=1。
  代入 (1)：1+t=2 → t=1。
  代入 (3)：3-1=2+1 → 2=3，矛盾！

  方程组无解，两直线不相交。

  **第三步：不平行且不相交 → 异面**

  验证异面的另一种方法：混合积 (P1P2, v1, v2) ≠ 0。
  P1P2 = P2-P1 = (-1,-1,-1)。
  v1×v2 = |i j k; 1 0 -1; 2 1 1| = (0×1-(-1)×1, (-1)×2-1×1, 1×1-0×2) = (1,-3,1)。
  混合积 = (-1,-1,-1)·(1,-3,1) = -1+3-1 = 1 ≠ 0。✓ 异面。

  几何意义：两直线在三维空间中可以不平行也不相交——它们不在同一个平面内，称为"异面直线"。混合积≠0是异面的代数判据（三个向量不共面）。
- **一句话点评**：两直线位置关系判据：方向向量成比例⇒平行（或重合）；否则联立参数方程，有解⇒相交，无解⇒异面。这里 v1=(1,0,-1),v2=(2,1,1) 不平行，联立得s=1,t=1但第三式2=3矛盾⇒无解⇒异面。验证：混合积(P1P2,v1,v2)=1≠0（三向量不共面）。异面直线是三维空间特有的现象——二维中两直线不平行必相交，三维中可以"擦肩而过"。

**【G5-A-★★-008】** 求两异面直线 L1: (x,y,z)=(1,2,3)+t(1,0,-1) 和 L2: (x,y,z)=(0,1,2)+s(2,1,1) 之间的距离。

- **难度**：★★
- **对应知识点**：异面直线距离（研究模块第 4 章）
- **耦合方向**：→ G3（叉积/投影）/ → G4（商空间）
- **来源**：基础计算题
- **解答**：
  异面直线距离公式：
  d = |P1P2 · (v1×v2)| / ||v1×v2||

  由上题：
  P1P2 = (-1,-1,-1)
  v1×v2 = (1,-3,1)
  ||v1×v2|| = sqrt(1+9+1) = sqrt(11)
  P1P2 · (v1×v2) = (-1)(1)+(-1)(-3)+(-1)(1) = -1+3-1 = 1

  d = |1|/sqrt(11) = 1/sqrt(11) = sqrt(11)/11 ≈ 0.30

  几何意义：异面直线距离=公垂线段长度。v1×v2 是同时垂直于两直线方向的向量（公垂线方向），P1P2 在这个方向上的投影长度就是两直线间的最短距离。
  公式本质：d = ||P_{v1×v2}(P1P2)||——正交投影的长度。

  与商空间的联系：两异面直线可以看作两个1维仿射子空间，它们的方向子空间分别是 span{v1} 和 span{v2}。距离=两个仿射子空间之间的最短距离=连接向量在公垂线方向的投影。
- **一句话点评**：异面直线距离 d=|P1P2·(v1×v2)|/||v1×v2||=连接向量在公垂线方向的投影长度。这里 d=1/sqrt(11)=sqrt(11)/11≈0.30。v1×v2=(1,-3,1) 是公垂线方向（同时垂直两直线方向），距离=正交投影长度。本质：d=||P_{v1×v2}(P1P2)||，这是G3正交投影在几何中的又一应用。异面直线距离是三维解析几何中最精妙的计算之一。

## B 层 基础理论

> 定位：方程等价形式、距离公式证明、位置关系判定、投影公式、曲面方程。从"算"过渡到"证"。

### ★ 基础巩固

**【G5-B-★-009】** 证明平面方程的三种形式等价：点法式 n·(r-r0)=0、一般式 Ax+By+Cz+D=0、截距式 x/a+y/b+z/c=1。并说明各自的适用场景。

- **难度**：★
- **对应知识点**：平面方程的等价形式（研究模块第 2 章）
- **耦合方向**：→ F2（线性方程）/ → G3（法向量）
- **来源**：基础证明题
- **解答**：
  **点法式 → 一般式**：
  点法式 n·(r-r0)=0，设 n=(A,B,C), r0=(x0,y0,z0), r=(x,y,z)：
  A(x-x0)+B(y-y0)+C(z-z0)=0
  Ax+By+Cz - (Ax0+By0+Cz0)=0
  令 D=-(Ax0+By0+Cz0)，得 Ax+By+Cz+D=0。∎

  **一般式 → 点法式**：
  一般式 Ax+By+Cz+D=0，取平面上一点 r0=(x0,y0,z0)（满足 Ax0+By0+Cz0+D=0），则
  Ax+By+Cz+D = A(x-x0)+B(y-y0)+C(z-z0) = n·(r-r0)=0，其中 n=(A,B,C)。∎

  **一般式 → 截距式**（当 A,B,C,D 均非零时）：
  Ax+By+Cz+D=0 → Ax+By+Cz=-D → x/(-D/A)+y/(-D/B)+z/(-D/C)=1。
  令 a=-D/A, b=-D/B, c=-D/C，得 x/a+y/b+z/c=1。∎
  截距 a,b,c 分别是平面与 x,y,z 轴的交点坐标。

  **适用场景**：
  - 点法式：已知平面上一点和法向量时最方便，几何意义最清晰。
  - 一般式：最通用，适合计算距离、判断位置关系、求交线。法向量直接从系数读出。
  - 截距式：已知平面与三轴交点时方便，能直接看出平面的"位置"和"大小"。但当平面过原点或平行于某轴时无法使用（截距为0或无穷）。

  几何意义：三种形式描述同一个几何对象（平面），只是参数化方式不同。一般式是"标准形式"，点法式强调"点+法向量"的构造，截距式强调"与三轴交点"。
- **一句话点评**：平面三形式等价：点法式 n·(r-r0)=0 展开得一般式 Ax+By+Cz+D=0（D=-(n·r0)）；一般式除以-D得截距式 x/a+y/b+z/c=1（a=-D/A等）。点法式适合已知点+法向量，一般式最通用（法向量=系数(A,B,C)），截距式适合已知三轴交点但过原点或平行轴时失效。三种形式描述同一平面，是"同一几何对象的不同代数表示"——解析几何的核心思想。

**【G5-B-★-010】** 证明直线方程的三种形式等价：参数式 r=r0+t·v、对称式 (x-x0)/l=(y-y0)/m=(z-z0)/n、一般式（两平面交线）。

- **难度**：★
- **对应知识点**：直线方程的等价形式（研究模块第 1 章）
- **耦合方向**：→ F2（线性方程组）/ → G1（向量）
- **来源**：基础证明题
- **解答**：
  **参数式 → 对称式**：
  参数式 r=r0+t·v，分量 x=x0+lt, y=y0+mt, z=z0+nt（v=(l,m,n)）。
  当 l,m,n 均非零时，解出 t=(x-x0)/l=(y-y0)/m=(z-z0)/n。∎
  若某个分量为零（如 l=0），则对应坐标 x=x0（常数），对称式写为 x=x0, (y-y0)/m=(z-z0)/n。

  **对称式 → 参数式**：
  令 (x-x0)/l=(y-y0)/m=(z-z0)/n=t，则 x=x0+lt, y=y0+mt, z=z0+nt，即 r=r0+t·v。∎

  **参数式 → 一般式（两平面交）**：
  参数式给出 x=x0+lt, y=y0+mt, z=z0+nt。
  消去 t：从 x=x0+lt 和 y=y0+mt 得 m(x-x0)=l(y-y0)，即 mx-ly+(ly0-mx0)=0——这是一个平面。
  从 y=y0+mt 和 z=z0+nt 得 n(y-y0)=m(z-z0)，即 ny-mz+(mz0-ny0)=0——另一个平面。
  直线就是这两个平面的交线。∎

  **一般式 → 参数式**：
  两平面 A1x+B1y+C1z+D1=0 和 A2x+B2y+C2z+D2=0 的交线。
  方向向量 v = n1×n2 = (A1,B1,C1)×(A2,B2,C2)（同时垂直于两个法向量，所以在两个平面内，即在交线上）。
  找交线上一点 r0：解联立方程组（令一个变量为0或某个值，解另两个）。
  然后参数式 r=r0+t·v。∎

  **适用场景**：
  - 参数式：最灵活，适合求交点、计算点在线上的位置、参数化曲线。
  - 对称式：最直观，直接看出直线过的点和方向。
  - 一般式（两平面交）：最通用，直线是两个线性方程的联立解——这是线性方程组的几何意义。
- **一句话点评**：直线三形式等价：参数式 r=r0+tv 解出t得对称式；消去t得两平面交（一般式）；两平面交的方向向量=n1×n2，找交点得参数式。参数式最灵活（求交点/参数化），对称式最直观（点+方向），一般式最通用（两线性方程联立解）。直线=1维仿射子空间，一般式揭示了"线性方程组的解=几何中的直线/平面"这一核心对应——这是线性代数与解析几何的桥梁。

**【G5-B-★-011】** 证明点到平面距离公式：点 P(x0,y0,z0) 到平面 Ax+By+Cz+D=0 的距离 d=|Ax0+By0+Cz0+D|/sqrt(A²+B²+C²)。

- **难度**：★
- **对应知识点**：点到平面距离公式证明（研究模块第 4 章）
- **耦合方向**：→ G3（正交投影）/ → F2（线性方程）
- **来源**：核心证明题
- **解答**：
  设平面 π: Ax+By+Cz+D=0，法向量 n=(A,B,C)。
  取平面上任意一点 Q(x1,y1,z1)，满足 Ax1+By1+Cz1+D=0。

  向量 QP = P-Q = (x0-x1, y0-y1, z0-z1)。

  点 P 到平面的距离 = QP 在法向量 n 方向上的投影长度（因为最短距离是垂线段，垂线方向就是法向量方向）：
  d = |QP · n| / ||n||

  计算 QP·n = A(x0-x1)+B(y0-y1)+C(z0-z1) = Ax0+By0+Cz0 - (Ax1+By1+Cz1)。
  因为 Q 在平面上，Ax1+By1+Cz1 = -D。
  所以 QP·n = Ax0+By0+Cz0 - (-D) = Ax0+By0+Cz0+D。

  ||n|| = sqrt(A²+B²+C²)。

  因此 d = |Ax0+By0+Cz0+D| / sqrt(A²+B²+C²)。∎

  **几何意义**：
  距离=向量在法向量上的投影长度。分子 Ax0+By0+Cz0+D 的符号表示点在平面的哪一侧（正侧/负侧），绝对值是距离。
  这是正交投影（G3）在解析几何中的直接应用——点到平面的垂足就是 P 在平面上的正交投影。

  **有向距离**：去掉绝对值得到有向距离 δ=(Ax0+By0+Cz0+D)/||n||，正号表示 P 在法向量指向的一侧，负号表示另一侧。
- **一句话点评**：点到平面距离 d=|Ax0+By0+Cz0+D|/sqrt(A²+B²+C²)。证明：取平面上点Q，距离=QP在法向量n上的投影长度=|QP·n|/||n||，而QP·n=Ax0+By0+Cz0+D（因为Q在平面上Ax1+By1+Cz1=-D）。本质是G3正交投影：距离=投影长度，垂足=P在平面上的正交投影。分子的符号表示点在平面哪一侧（有向距离），绝对值是距离。这是线性代数（投影）与解析几何（距离）的完美对应。

**【G5-B-★-012】** 证明点到直线距离公式：点 P 到过 P0、方向为 v 的直线的距离 d=||P0P × v||/||v||。

- **难度**：★
- **对应知识点**：点到直线距离公式证明（研究模块第 4 章）
- **耦合方向**：→ G3（叉积/投影）/ → G1（向量）
- **来源**：核心证明题
- **解答**：
  设直线 L 过 P0，方向向量 v。点 P 到 L 的距离=垂线段长度。

  **方法一：平行四边形面积法**
  以 P0P 和 v 为邻边作平行四边形。
  平行四边形面积 = ||P0P × v||（叉积的模=平行四边形面积）。
  底边长 = ||v||。
  高 = 面积/底 = ||P0P × v||/||v||。
  这个高就是点 P 到直线 L 的距离（因为高是从 P 到 v 所在直线的垂直距离）。∎

  **方法二：正交投影法**
  P0P 在 v 方向上的投影向量 = (P0P·v/||v||²)·v。
  P0P 垂直于 v 的分量 = P0P - 投影 = P0P - (P0P·v/||v||²)·v。
  距离 = ||垂直分量||。
  可以证明 ||P0P × v|| = ||P0P||·||v||·sinθ，而 ||垂直分量|| = ||P0P||·sinθ，所以两者相等。∎

  **几何意义**：
  叉积 P0P×v 的模=以 P0P 和 v 为邻边的平行四边形面积，除以底 ||v|| 得高=点到直线距离。
  这是向量叉积在几何中的经典应用——叉积同时编码了面积和方向。

  **与投影的关系**：
  ||P0P||² = ||投影分量||² + ||垂直分量||²（勾股定理）。
  ||P0P × v||² = ||P0P||²||v||² - (P0P·v)²（Lagrange恒等式）。
  d² = ||P0P × v||²/||v||² = ||P0P||² - (P0P·v)²/||v||² = ||P0P||² - ||投影||² = ||垂直分量||²。∎
- **一句话点评**：点到直线距离 d=||P0P×v||/||v||。证明一（面积法）：叉积模=平行四边形面积，除以底||v||=高=距离。证明二（投影法）：距离=P0P垂直于v的分量长度，由勾股定理=sqrt(||P0P||²-||投影||²)，与叉积公式等价（Lagrange恒等式）。叉积同时编码面积和方向，是三维向量代数的核心工具。点到直线距离和点到平面距离本质都是正交投影——一个投影到1维子空间（直线方向），一个投影到2维子空间（平面），残差长度=距离。

**【G5-B-★★-013】** 证明两平面位置关系的判定：平面 π1: A1x+B1y+C1z+D1=0 和 π2: A2x+B2y+C2z+D2=0。
(1) 平行 ⇔ 法向量成比例 (A1,B1,C1)=k(A2,B2,C2) 但 D1≠kD2；
(2) 重合 ⇔ 所有系数成比例 (A1,B1,C1,D1)=k(A2,B2,C2,D2)；
(3) 相交 ⇔ 法向量不成比例，交线方向 v=n1×n2。

- **难度**：★★
- **对应知识点**：两平面位置关系（研究模块第 3 章）
- **耦合方向**：→ F2（线性方程组）/ → G3（法向量）
- **来源**：性质证明题
- **解答**：
  两平面的位置关系由联立方程组的解决定：
  A1x+B1y+C1z+D1=0
  A2x+B2y+C2z+D2=0

  **(1) 平行（无交点）**：
  方程组无解。两个方程的系数行向量 (A1,B1,C1) 和 (A2,B2,C2) 成比例（否则方程组有解，因为秩=2时3变量2方程必有解），但常数项不成比例（否则重合）。
  即 (A1,B1,C1)=k(A2,B2,C2) 但 D1≠kD2。
  此时两平面法向量平行，平面平行但不重合。∎

  **(2) 重合（无穷多交点，且所有点相同）**：
  两个方程等价，即 (A1,B1,C1,D1)=k(A2,B2,C2,D2)（k≠0）。
  此时两个方程描述同一个平面。∎

  **(3) 相交（交于一条直线）**：
  法向量不成比例，即系数矩阵的秩=2。此时方程组有1个自由变量，解集是1维仿射子空间=直线。
  交线方向 v 同时在两个平面内，所以 v 与两个法向量都垂直：v·n1=0, v·n2=0。
  所以 v ∥ n1×n2（叉积同时垂直于两个因子）。
  取 v=n1×n2 作为交线方向向量。∎

  **几何意义**：
  两平面的位置关系=联立线性方程组的解的情况：无解=平行，唯一解不存在（3变量2方程不可能唯一解），无穷解=重合或相交（交于直线）。
  这是线性方程组解的理论（F2）在几何中的直接应用——方程组的秩决定了解集的维数。

  **面面角**：
  相交时，两平面的二面角=法向量的夹角（或补角）：
  cosθ = |n1·n2|/(||n1||||n2||)。
- **一句话点评**：两平面位置关系=联立方程组解的情况：法向量成比例但常数项不成比例⇒平行（无解）；所有系数成比例⇒重合（同解）；法向量不成比例⇒相交于直线（秩2，1自由变量），交线方向v=n1×n2（同时垂直两法向量）。这是线性方程组解的理论（F2）在几何中的直接应用——秩决定解集维数：秩1=平行/重合，秩2=交于直线。面面角=法向量夹角cosθ=|n1·n2|/(||n1||||n2||)。解析几何的本质="线性方程组的几何化"。

**【G5-B-★★-014】** 证明两直线位置关系的完整判定：设 L1 过 P1 方向 v1，L2 过 P2 方向 v2。
(1) 重合 ⇔ v1∥v2 且 P1P2∥v1；
(2) 平行不重合 ⇔ v1∥v2 但 P1P2 不平行 v1；
(3) 相交 ⇔ v1 不平行 v2 且混合积 (P1P2,v1,v2)=0；
(4) 异面 ⇔ v1 不平行 v2 且混合积 (P1P2,v1,v2)≠0。

- **难度**：★★
- **对应知识点**：两直线位置关系判定（研究模块第 3 章）
- **耦合方向**：→ F2（线性方程组）/ → G3（混合积）

- **解答**：
  **(1)(2) v1∥v2 的情况**：
  若 v1=k·v2（k≠0），两直线方向相同。
  - 若 P1P2 也平行于 v1（即 P2 在 L1 上或 L1 平移后与 L2 重合），则两直线重合。
  - 若 P1P2 不平行 v1，则两直线平行但不重合（方向相同但不共线）。

  **(3)(4) v1 不平行 v2 的情况**：
  两直线相交 ⇔ 存在 t,s 使得 P1+t·v1 = P2+s·v2 ⇔ P1P2 = s·v2 - t·v1。
  这意味着 P1P2 可以由 v1,v2 线性表示，即 P1P2, v1, v2 三向量共面。

  - 混合积≠0 ⇒ 三向量不共面 ⇒ 两直线不在同一平面内 ⇒ 异面。∎

  **几何意义**：
  混合积 (P1P2,v1,v2) 的绝对值=以 P1P2, v1, v2 为邻边的平行六面体体积。
  体积=0 ⇔ 三向量共面 ⇔ 两直线共面。
  体积≠0 ⇔ 三向量不共面 ⇔ 两直线异面。
  这是混合积的几何意义（体积）在位置关系判定中的应用。

  **完整判定流程**：
  1. v1∥v2？→ 是：P1P2∥v1？→ 是：重合 / 否：平行
  2. v1不平行v2？→ 混合积=0？→ 是：相交 / 否：异面
- **一句话点评**：两直线位置关系四分类：v1∥v2时，P1P2∥v1⇒重合，否则平行；v1不平行v2时，混合积(P1P2,v1,v2)=0⇒相交（共面），≠0⇒异面（不共面）。混合积绝对值=平行六面体体积，体积=0⇔三向量共面⇔两直线共面。完整流程：先判方向是否平行，再判混合积是否为零。这是向量代数（叉积/混合积）与几何位置关系的完美对应——三维空间中两直线有四种关系，比二维多了"异面"这种可能。

  **定理**：方程 F(x,y)=0（不含 z）在空间中表示母线平行于 z 轴的柱面，其准线是 xy-平面上的曲线 F(x,y)=0。

  **证明**：
  设点 P0(x0,y0,0) 在 xy-平面上满足 F(x0,y0)=0（即 P0 在准线上）。
  过 P0 作平行于 z 轴的直线 L: (x,y,z)=(x0,y0,t), t∈R。
  对 L 上任意点 (x0,y0,t)，代入方程 F(x,y)=0 得 F(x0,y0)=0（因为方程不含 z，z=t 不影响）。
  所以整条直线 L 都在曲面 F(x,y)=0 上。

  反过来，若点 P(x1,y1,z1) 在曲面 F(x,y)=0 上，则 F(x1,y1)=0，点 (x1,y1,0) 在准线上，P 在过 (x1,y1,0) 且平行于 z 轴的直线上。

  因此曲面 F(x,y)=0 是由所有平行于 z 轴且过准线 F(x,y)=0（在 xy-平面上）的直线组成的——这就是母线平行于 z 轴的柱面。∎

  **举例**：
  - x²+y²=R²（不含 z）：圆柱面，母线平行 z 轴，准线是 xy-平面上的圆 x²+y²=R²。
  - y²=2px（不含 z）：抛物柱面，母线平行 z 轴，准线是 xy-平面上的抛物线 y²=2px。
  - x²/a²+y²/b²=1（不含 z）：椭圆柱面。
  - x²/a²-y²/b²=1（不含 z）：双曲柱面。

  **一般化**：
  - F(x,y)=0：母线∥z轴，准线在xy-平面。
  - F(y,z)=0：母线∥x轴，准线在yz-平面。
  - F(x,z)=0：母线∥y轴，准线在xz-平面。

  **与商空间的联系**：
  柱面 F(x,y)=0 可以看作 xy-平面上的曲线 F(x,y)=0 沿 z 方向"拉伸"而成。z 方向是被"商掉"的方向——柱面=曲线×R（笛卡尔积），这是 G4 商空间思想在几何中的体现（沿 z 方向的每个拷贝都是同一条曲线）。
- **一句话点评**：缺一个变量的方程F(x,y)=0表示母线平行于z轴的柱面——证明：准线上点(x0,y0,0)满足F=0，过它作z方向直线(x0,y0,t)，代入方程仍F(x0,y0)=0（不含z），所以整条直线在曲面上。举例：x²+y²=R²圆柱面、y²=2px抛物柱面、x²/a²-y²/b²=1双曲柱面。一般化：缺哪个变量，母线就平行于哪个轴。与商空间联系：柱面=准线曲线×R（沿母线方向拉伸），z方向被"商掉"——每个z切片都是同一条曲线。柱面是"低维图形沿高维方向拉伸"的典型。

**【G5-B-★★★-018】** 证明坐标旋转变换是正交变换：设新坐标系由旧坐标系绕原点旋转得到，坐标变换公式 x=Qx'（Q 是正交矩阵），则 Q^T Q=I，且旋转保持距离和角度。

- **难度**：★★★
- **对应知识点**：坐标变换与正交矩阵（研究模块第 7 章）
- **耦合方向**：→ F7（正交矩阵）/ → T7（正交变换）/ → G3（内积）
- **来源**：性质证明题
- **解答**：
  **坐标旋转的矩阵表示**：
  设旧基 {e1,e2,e3}，新基 {e1',e2',e3'}，都是标准正交基。
  新基向量在旧基下的坐标为 e_j' = Σ_i Q_ij e_i，即矩阵 Q=(Q_ij) 的列是新基在旧基下的坐标。
  因为 {e_j'} 是标准正交基，<e_i',e_j'>=δ_ij。
  <e_i',e_j'> = (Σ_k Q_ki e_k)·(Σ_l Q_lj e_l) = Σ_k Q_ki Q_kj = (Q^T Q)_{ij}。
  所以 (Q^T Q)_{ij}=δ_ij，即 Q^T Q=I，Q 是正交矩阵。∎

  **坐标变换公式**：
  点 P 在旧基下坐标 x，在新基下坐标 x'。P=Σ x_i e_i=Σ x_j' e_j'=Σ_j x_j' Σ_i Q_ij e_i=Σ_i (Σ_j Q_ij x_j') e_i。
  所以 x_i=Σ_j Q_ij x_j'，即 x=Q x'（或 x'=Q^T x）。

  **保持距离**：
  两点 P,Q 的旧坐标差 Δx，新坐标差 Δx'=Q^T Δx。
  距离² = ||Δx||² = Δx^T Δx = (Q Δx')^T (Q Δx') = Δx'^T Q^T Q Δx' = Δx'^T Δx' = ||Δx'||²。
  所以距离不变。∎

  **保持角度**：
  两向量 u,v 的内积 u·v = u^T v = (Qu')^T(Qv') = u'^T Q^T Q v' = u'^T v' = u'·v'。
  内积不变，所以角度（由内积定义）不变。∎

  **几何意义**：
  坐标旋转=正交变换=刚体运动（不拉伸、不压缩、只旋转）。正交矩阵 Q 的列是新标准正交基，Q^T Q=I 保证了保内积=保长度保角度。
  这是 F7/T7 正交矩阵理论在解析几何坐标变换中的直接应用。

  **平移变换**：
  坐标平移 x=x'+x0（平移向量 x0）也保持距离和角度，但不是线性变换（是仿射变换）。
  刚体运动=平移+旋转=仿射正交变换，是欧几里得几何的对称群。
- **一句话点评**：坐标旋转矩阵Q是正交矩阵（Q^TQ=I）——因为新基是标准正交基，Q的列是新基坐标，<e_i',e_j'>=(Q^TQ)_{ij}=δ_ij。坐标变换x=Qx'。保距离：||Δx||²=Δx^TΔx=(QΔx')^T(QΔx')=Δx'^TQ^TQΔx'=||Δx'||²。保角度：u·v=u^Tv=(Qu')^T(Qv')=u'^Tv'=u'·v'。坐标旋转=正交变换=刚体运动（只旋转不拉伸）。平移x=x'+x0也保距离角度但是仿射变换不是线性变换。刚体运动=平移+旋转=欧几里得几何的对称群。这是F7/T7正交矩阵在解析几何中的核心应用。

**【G5-C-★-019】** 画图说明"平面=线性方程的解"：方程 2x-y+z-3=0 的解集是一个平面，法向量 (2,-1,1) 垂直于平面内所有向量。

- **难度**：★
- **对应知识点**：平面的线性代数本质（研究模块第 2 章）
- **耦合方向**：→ F2（线性方程组）/ → G3（正交/法向量）
- **来源**：几何直观题
- **解答**：
  **画图**：
  1. 画三维坐标系。
  2. 平面 2x-y+z-3=0 与三轴交点：x轴(3/2,0,0)、y轴(0,-3,0)、z轴(0,0,3)。画出由这三点确定的三角形平面。
  3. 从原点画法向量 n=(2,-1,1)（指向平面的一侧），标注 n 垂直于平面。
  4. 在平面内取两个向量，如从(3/2,0,0)到(0,-3,0)的向量(-3/2,-3,0)，验证 n·(-3/2,-3,0)=-3+3+0=0（垂直）。

  **线性代数本质**：
  方程 2x-y+z-3=0 是一个非齐次线性方程，3个变量1个方程，解空间是 3-1=2 维的仿射子空间=平面。
  对应的齐次方程 2x-y+z=0 的解空间是 2 维线性子空间（过原点的平面），非齐次方程的解=齐次解+一个特解（平面平移）。

  **法向量=系数行向量**：
  方程的系数 (A,B,C)=(2,-1,1) 就是法向量。对平面内任意两点 P1,P2，向量 P1P2 满足 AΔx+BΔy+CΔz=0（两点都满足方程，相减得），所以 n·P1P2=0，n 垂直于平面内所有向量。

  **几何意义**：
  一个线性方程=一个超平面（在三维中是平面，在 n 维中是 n-1 维超平面）。方程的系数行向量=超平面的法向量。这是线性方程组的几何意义——每个方程定义一个超平面，方程组的解=超平面的交。
- **一句话点评**：平面=非齐次线性方程的解集——3变量1方程，解空间是2维仿射子空间=平面。系数行向量(A,B,C)=法向量，因为平面内任意向量P1P2满足AΔx+BΔy+CΔz=0（两式相减），所以n·P1P2=0，n垂直平面。画图：平面与三轴交点(3/2,0,0),(0,-3,0),(0,0,3)，法向量(2,-1,1)从原点指向平面一侧。推广：n维中一个线性方程=n-1维超平面，系数=法向量。这是"线性方程组的几何化"——每个方程是一个超平面，方程组的解=超平面的交。

**【G5-C-★-020】** 画图说明"直线=两平面的交"：直线 (x-1)/2=(y-2)/(-1)=(z-3)/1 可以表示为两平面的交，方向向量=两法向量的叉积。

- **难度**：★
- **对应知识点**：直线的线性代数本质（研究模块第 1 章）
- **耦合方向**：→ F2（线性方程组）/ → G3（叉积）
- **来源**：几何直观题
- **解答**：
  **从对称式到两平面交**：
  (x-1)/2 = (y-2)/(-1) = (z-3)/1
  拆成两个等式：
  (x-1)/2 = (y-2)/(-1) → -(x-1) = 2(y-2) → -x+1 = 2y-4 → x+2y-5=0 ... 平面π1
  (y-2)/(-1) = (z-3)/1 → -(y-2) = z-3 → -y+2 = z-3 → y+z-5=0 ... 平面π2

  直线 = π1 ∩ π2（两平面的交线）。

  **画图**：
  1. 画三维坐标系。
  2. 画平面 π1: x+2y-5=0（平行于 z 轴的平面，法向量 n1=(1,2,0)）。
  3. 画平面 π2: y+z-5=0（法向量 n2=(0,1,1)）。
  4. 两平面相交于一条直线——标出交线，验证它过 (1,2,3) 且方向为 (2,-1,1)。

  **方向向量=两法向量的叉积**：
  n1=(1,2,0), n2=(0,1,1)。
  n1×n2 = |i j k; 1 2 0; 0 1 1| = (2×1-0×1, 0×0-1×1, 1×1-2×0) = (2,-1,1)。
  这正是直线的方向向量！

  **为什么方向向量=叉积**：
  交线同时在两个平面内，所以交线方向 v 同时垂直于两个法向量：v·n1=0, v·n2=0。
  同时垂直于 n1,n2 的向量 ∥ n1×n2（叉积的定义就是同时垂直于两个因子的向量）。
  所以 v ∥ n1×n2。

  **线性代数本质**：
  直线=两个线性方程的联立解，3变量2方程，解空间是 3-2=1 维仿射子空间=直线。
  系数矩阵的秩=2，零空间维数=1（方向向量），特解确定位置。
- **一句话点评**：直线=两平面的交——对称式拆成两个等式得到两个平面方程，直线=π1∩π2。这里 (x-1)/2=(2-y)=(z-3) 拆为 x+2y-5=0 和 y+z-5=0。方向向量=两法向量叉积 n1×n2=(1,2,0)×(0,1,1)=(2,-1,1)，因为交线方向同时垂直于两法向量，而叉积正是同时垂直于两因子的向量。线性代数本质：3变量2方程的解=1维仿射子空间=直线，系数矩阵秩2，零空间维数1=方向。这是"线性方程组解的维数=变量数-秩"在几何中的体现。

### ★★ 进阶几何

**【G5-C-★★-021】** 画图说明"距离=正交投影"：点到平面的距离=点到平面的垂线段=点与平面上点连线在法向量上的投影长度。

- **难度**：★★
- **对应知识点**：距离的正交投影本质（研究模块第 4 章）
- **耦合方向**：→ G3（正交投影）/ → F2（线性方程）
- **来源**：几何解释题
- **解答**：
  **画图**：
  1. 画一个平面 π（用平行四边形表示）。
  2. 画平面外一点 P。
  3. 从 P 向平面作垂线，垂足为 P'（P 在平面上的正交投影）。
  4. 在平面上任取一点 Q（不同于 P'），连接 PQ。
  5. 标注：PP' 是垂线（最短距离），PQ 是斜线（更长）。
  6. 画法向量 n，从 Q 指向平面外。标注 PQ 在 n 方向上的投影=PP' 的长度。

  **正交投影本质**：
  点 P 到平面 π 的距离 = ||P - P_π(P)||，其中 P_π(P) 是 P 在平面上的正交投影。
  等价地，距离 = ||P_n(PQ)|| = |PQ·n|/||n||，其中 Q 是平面上任意一点，P_n 是在法向量方向上的投影。

  **为什么投影长度=距离**：
  PQ = PP' + P'Q（向量分解），其中 PP' ∥ n（垂直于平面），P'Q 在平面内（垂直于 n）。
  PQ 在 n 方向的投影 = PP' 在 n 方向的投影 + P'Q 在 n 方向的投影 = ||PP'|| + 0 = ||PP'|| = 距离。
  （P'Q 在平面内，与 n 垂直，投影为零。）

  **"垂线段最短"的代数证明**：
  对平面上任意 Q，||PQ||² = ||PP'||² + ||P'Q||²（勾股定理，因为 PP'⊥P'Q）≥ ||PP'||²。
  等号当且仅当 P'=Q（即 Q 是垂足）。
  所以垂足是平面上离 P 最近的点，垂线段长度=最短距离。

  **与 G3 的联系**：
  这是 G3 投影定理的直接应用——子空间 W（平面的方向子空间）的正交补是 span{n}，P 在 W 上的投影=P'，残差=PP'∈W⊥，残差长度=距离。
- **一句话点评**：点到平面距离=正交投影的残差长度。画图：P到平面π的垂足P'，平面上任取Q，PQ=PP'+P'Q，PP'∥n（法向量），P'Q在平面内（⊥n）。PQ在n方向投影=||PP'||+0=距离。垂线段最短：||PQ||²=||PP'||²+||P'Q||²≥||PP'||²（勾股定理），等号当且仅当Q=P'。这是G3投影定理的直接应用：平面方向W是2维子空间，W⊥=span{n}，P在W上投影=P'，残差PP'∈W⊥，残差长度=距离。"距离=正交投影残差"是解析几何与线性代数的核心对应。

**【G5-C-★★-022】** 画图说明"夹角=内积"：线线角、线面角、面面角都可以用内积计算，本质是方向向量/法向量之间的夹角。

- **难度**：★★
- **对应知识点**：夹角的内积本质（研究模块第 3 章）
- **耦合方向**：→ G3（内积/夹角）/ → G1（向量）
- **来源**：几何解释题
- **解答**：
  **画图（三种夹角）**：
  1. **线线角**：画两条相交直线 L1,L2，方向向量 v1,v2，夹角 θ。标注 cosθ=|v1·v2|/(||v1||||v2||)。
  2. **线面角**：画直线 L 与平面 π 相交，方向向量 v，平面法向量 n。直线与平面中投影的夹角 θ。标注 sinθ=|v·n|/(||v||||n||)（因为 θ=90°-v与n的夹角）。
  3. **面面角**：画两相交平面 π1,π2，法向量 n1,n2，二面角 θ。标注 cosθ=|n1·n2|/(||n1||||n2||)。

  **统一本质：内积定义夹角**：
  G3 中定义了两个向量的夹角：cosφ=(u·v)/(||u||||v||)。
  解析几何中的所有夹角都是这个定义的应用：
  - 线线角：直接用方向向量的夹角（取锐角，所以加绝对值）。
  - 面面角：用法向量的夹角（取锐角）。
  - 线面角：直线与平面中投影的夹角=90°-直线与法向量的夹角，所以用 sinθ=cos(90°-θ)=|v·n|/(||v||||n||)。

  **为什么取绝对值（锐角）**：
  直线和平面没有"方向"——v 和 -v 表示同一条直线，n 和 -n 表示同一个平面的法向量。所以夹角取 0 到 90° 之间的锐角，用绝对值保证。
  （如果是有向直线或有向平面，则不取绝对值，夹角可以是钝角。）

  **几何意义**：
  内积是"量角器"——它把两个向量的方向关系转化为一个数值（夹角余弦）。解析几何中所有角度问题都归结为"找对方向向量/法向量，算内积"。
  这是 G3 内积理论在解析几何中的核心应用——内积不仅定义长度（范数），还定义角度。
- **一句话点评**：解析几何中所有夹角=内积的应用：线线角cosθ=|v1·v2|/(||v1||||v2||)（方向向量夹角），面面角cosθ=|n1·n2|/(||n1||||n2||)（法向量夹角），线面角sinθ=|v·n|/(||v||||n||)（=90°-v与n夹角，所以用sin）。统一本质：G3中内积定义了向量夹角cosφ=(u·v)/(||u||||v||)，解析几何只是找对向量（方向向量或法向量）代入公式。取绝对值是因为直线/平面无方向（v和-v同一直线），夹角取锐角。内积是线性空间的"量角器"——解析几何的角度问题全部归结为"找向量+算内积"。

**【G5-C-★★-023】** 画图说明"二面角=法向量夹角"：两平面的二面角等于它们法向量的夹角或补角，取决于法向量的指向。

- **难度**：★★
- **对应知识点**：二面角的几何（研究模块第 3 章）
- **耦合方向**：→ G3（内积/法向量）/ → G5（面面关系）
- **来源**：几何解释题
- **解答**：
  **画图**：
  1. 画两个相交平面 π1,π2，交线为 L。
  2. 在交线 L 上取一点 O，在 π1 内作垂直于 L 的射线 OA，在 π2 内作垂直于 L 的射线 OB——∠AOB 就是二面角的平面角 θ。
  3. 画两个法向量 n1（垂直 π1）和 n2（垂直 π2），都从 O 出发指向平面的同一侧（或都指向外侧）。
  4. 标注：n1 垂直于 π1 内所有直线（包括 OA），n2 垂直于 π2 内所有直线（包括 OB）。

  **二面角与法向量夹角的关系**：
  n1⊥OA, n2⊥OB。
  两个角的两边分别垂直，所以 ∠(n1,n2) 与 ∠AOB 相等或互补。
  - 若 n1,n2 都指向二面角内部（或都指向外部），则法向量夹角=180°-二面角（互补）。
  - 若一个指向内部一个指向外部，则法向量夹角=二面角（相等）。

  **为什么通常取绝对值**：
  cos(二面角)=|n1·n2|/(||n1||||n2||)——取绝对值后，不管法向量指向哪一侧，都得到二面角的锐角余弦。
  二面角本身可以是锐角或钝角（0到180°），但通常取锐角（0到90°）作为"两平面的夹角"。

  **具体例子**：
  π1: z=0（xy-平面，n1=(0,0,1)），π2: y=0（xz-平面，n2=(0,1,0)）。

**【G5-C-★★★-024】** 画图说明"异面直线距离=公垂线=正交投影"：两异面直线的距离是连接向量在公垂线方向上的投影长度，公垂线方向=两方向向量的叉积。

- **难度**：★★★
- **对应知识点**：异面直线距离的几何（研究模块第 4 章）
- **耦合方向**：→ G3（叉积/投影）/ → G4（商空间）
- **来源**：几何研究题
- **解答**：
  **画图**：
  1. 画两条异面直线 L1,L2（不平行不相交，不在同一平面内）。
  2. L1 过 P1 方向 v1，L2 过 P2 方向 v2。
  3. 画公垂线 AB：A 在 L1 上，B 在 L2 上，AB 同时垂直于 L1 和 L2。
  4. 标注 AB 的方向 = v1×v2（同时垂直于 v1,v2）。
  5. 画连接向量 P1P2，标注它在公垂线方向上的投影=AB 的长度=距离。

  **公垂线方向=v1×v2**：
  公垂线同时垂直于 L1 和 L2，所以其方向 w 满足 w·v1=0, w·v2=0。
  同时垂直于 v1,v2 的向量 ∥ v1×v2（叉积的定义）。
  所以公垂线方向 = v1×v2。

  **距离=投影长度**：
  设 A=P1+t·v1（L1上的点），B=P2+s·v2（L2上的点）。
  AB = B-A = P2-P1 + s·v2 - t·v1 = P1P2 + s·v2 - t·v1。
  AB 是公垂线 ⇒ AB·v1=0, AB·v2=0。
  距离 d=||AB||。

  因为 AB ∥ v1×v2（公垂线方向），所以
  d = |AB·(v1×v2)| / ||v1×v2||。
  而 AB·(v1×v2) = (P1P2 + s·v2 - t·v1)·(v1×v2) = P1P2·(v1×v2) + s·v2·(v1×v2) - t·v1·(v1×v2)。
  v2·(v1×v2)=0（v2 与 v1×v2 垂直），v1·(v1×v2)=0。
  所以 AB·(v1×v2) = P1P2·(v1×v2)。
  d = |P1P2·(v1×v2)| / ||v1×v2||。

  **几何意义**：
  异面直线距离=连接向量在公垂线方向上的投影长度。不管 A,B 具体在哪里，AB 在公垂线方向上的投影都是固定的（等于 P1P2 的投影），因为 v1,v2 方向的分量在叉积上投影为零。
  这是正交投影的又一应用——距离=投影到"同时垂直于两方向"的方向上的长度。

  **与商空间的联系**：
  两异面直线可以看作两个1维仿射子空间。它们的方向子空间 span{v1}, span{v2} 张成一个2维子空间（如果不平行），商空间 V/(span{v1}+span{v2}) 是1维的，公垂线方向就是这个商空间的方向。距离=两个仿射子空间在商空间中的"距离"。
- **一句话点评**：异面直线距离=连接向量在公垂线方向的投影长度 d=|P1P2·(v1×v2)|/||v1×v2||。公垂线方向=v1×v2（同时垂直于两直线方向）。推导：设A=P1+tv1,B=P2+sv2，AB=P1P2+sv2-tv1，AB·(v1×v2)=P1P2·(v1×v2)（因为v1,v2与叉积垂直，投影为零），所以d=|AB·(v1×v2)|/||v1×v2||=|P1P2·(v1×v2)|/||v1×v2||。几何上：不管A,B在哪，AB在公垂线方向投影固定=P1P2的投影。与商空间联系：两直线方向张成2维子空间，商空间1维=公垂线方向，距离=两仿射子空间在商空间中的距离。异面直线距离是正交投影在三维几何中最精妙的应用。

- **解答**：

  1. **椭球面** x²/a²+y²/b²+z²/c²=1：画一个三轴不等的椭球（如果 a=b=c 就是球面）。封闭、有界、三个半轴 a,b,c。

  **二次型的视角**：
  二次曲面的一般方程：x^T A x + b^T x + c = 0，其中 A 是 3×3 对称矩阵（二次型矩阵）。
  通过正交变换（旋转坐标）和配方（平移坐标），可以化为标准形：
  λ1 x'² + λ2 y'² + λ3 z'² = d（λ1,λ2,λ3 是 A 的特征值）。

  **特征值符号决定曲面类型**：
  - λ1,λ2,λ3 同号（正定/负定）：椭球面（或点球/虚球）。
  - 两个正一个负（或两个负一个正），d>0：单叶双曲面。
  - 两个正一个负，d<0：双叶双曲面。
  - 一个特征值为0：柱面（抛物柱面/椭圆柱面/双曲柱面）。
  - 两个特征值为0：抛物面（椭圆抛物面/双曲抛物面）。

  **几何意义**：
  二次曲面的类型由二次型矩阵 A 的惯性指数（正特征值个数、负特征值个数、零特征值个数）决定——这是 Sylvester 惯性定律的几何体现。
  正交变换（旋转）不改变特征值，所以不改变曲面类型；平移只改变中心位置，不改变类型。
  这是 G7 二次型理论在解析几何中的核心应用——二次型的标准形=二次曲面的标准方程，惯性指数=曲面类型。

  **与 F4/F7 的联系**：
  二次型矩阵 A 的特征值=曲面的"曲率参数"（半轴平方的倒数），特征向量=主轴方向。
  正交对角化 A=QΛQ^T 就是"找主轴方向"（坐标旋转），Q 是正交矩阵（旋转），Λ 是特征值对角矩阵。
- **一句话点评**：二次曲面=二次型的等值面——一般方程x^T A x+b^T x+c=0，通过正交变换（旋转）+平移化为标准形λ1x'²+λ2y'²+λ3z'²=d，特征值符号决定曲面类型：三同号⇒椭球面（正定），两正一负且d>0⇒单叶双曲面（不定），两正一负且d<0⇒双叶双曲面，有零特征值⇒柱面/抛物面。画图：椭球（封闭有界）、单叶双曲面（连通沙漏形）、双叶双曲面（两分离碗形）。这是G7二次型理论的几何应用——惯性指数决定曲面类型（Sylvester惯性定律），正交对角化=找主轴方向（旋转坐标），特征值=半轴平方倒数。二次曲面分类本质是二次型分类的几何化。

**【G5-C-★★★-026】** 画图说明"坐标变换=基变换+平移"：从旧坐标系到新坐标系，先平移原点（仿射部分），再旋转坐标轴（线性正交变换），这是欧几里得变换的分解。

- **难度**：★★★
- **对应知识点**：坐标变换的几何（研究模块第 7 章）
- **耦合方向**：→ G6（仿射空间）/ → T7（正交变换）/ → F7（正交矩阵）
- **来源**：几何研究题
- **解答**：
  **画图**：
  1. 画旧坐标系 Oxyz（原点 O，轴 e1,e2,e3）。
  2. 画新坐标系 O'x'y'z'（原点 O'，轴 e1',e2',e3'），O' 在旧坐标系中坐标为 (a,b,c)，新轴相对于旧轴旋转了角度。
  3. 标注：从旧到新 = 先平移（O→O'），再旋转（e→e'）。
  4. 画一个点 P，标注它在旧坐标系的坐标 (x,y,z) 和新坐标系的坐标 (x',y',z')。

  **坐标变换公式**：
  点 P 的位置向量：OP = OO' + O'P。
  旧坐标 x = OO'的旧坐标 + O'P的旧坐标 = (a,b,c) + Q·x'（Q 是新基在旧基下的坐标矩阵，正交矩阵）。
  即 x = x0 + Q·x'，其中 x0=(a,b,c) 是新原点在旧坐标系中的坐标，Q 是旋转矩阵（正交）。

  **欧几里得变换的分解**：
  任意刚体运动（保距离保角度的变换）可以分解为：
  1. 平移：x → x + x0（仿射部分，非线性）。
  2. 旋转：x → Q·x（线性正交变换，Q^T Q=I）。
  可能还有反射（det Q=-1），但旋转+反射都是正交变换。

  **为什么正交变换保距离保角度**：
  已在 G5-B-★★★-018 中证明：Q^T Q=I ⇒ ||Qx||=||x||（保长度）⇒ (Qx)·(Qy)=x·y（保内积）⇒ 保角度。
  平移也保距离保角度（只是移动位置，不改变相对关系）。
  所以刚体运动=平移+正交变换=欧几里得变换。

  **与 G6（仿射空间）的联系**：
  坐标变换是仿射变换的特例——仿射变换=线性变换+平移 x→Ax+b，欧几里得变换要求 A 是正交矩阵（保内积）。
  一般仿射变换不要求 A 正交（可以拉伸、剪切），不保持距离和角度。
  欧几里得变换是仿射变换的子群（保度量的仿射变换）。

  **几何意义**：
  坐标变换的本质="换一个角度看同一个几何对象"——几何对象（点、线、面、曲面）本身不变，只是我们用不同的坐标系描述它。
  好的坐标系（如二次曲面的主轴坐标系）可以让方程变得最简单（标准形），这就是"坐标变换化简方程"的思想。
- **一句话点评**：坐标变换=平移+旋转（正交变换）：x=x0+Qx'，x0=新原点旧坐标（平移），Q=旋转矩阵（正交，Q^TQ=I）。画图：旧系Oxyz，新系O'x'y'z'，OP=OO'+O'P。刚体运动（保距离保角度）=平移+正交变换，正交变换保长度（||Qx||=||x||）保内积（(Qx)·(Qy)=x·y）保角度。与G6联系：欧几里得变换是仿射变换x→Ax+b的特例（A正交），一般仿射变换A不必正交（可拉伸剪切）不保距离角度。坐标变换本质="换坐标系描述同一几何对象"，好的坐标系（如主轴系）让方程最简（标准形）。这是"坐标变换化简方程"思想的基础，也是二次曲面标准化的工具。

### ★★ 进阶综合

**【G5-D-★★-027】** 充要探究：方程 Ax+By+Cz+D=0 表示平面的充要条件。讨论退化情况（A=B=C=0、D=0 等），并说明"平面"与"仿射子空间"的关系。

- **难度**：★★
- **对应知识点**：平面方程的充要条件（研究模块第 2 章）
- **耦合方向**：→ F2（线性方程）/ → G6（仿射空间）/ → G1（子空间）
- **来源**：充要探究题
- **解答**：
  **充要条件**：方程 Ax+By+Cz+D=0 表示一个平面（2维仿射子空间），当且仅当 (A,B,C)≠(0,0,0)（即系数不全为零）。

  **证明**：
  必要性：若 (A,B,C)=(0,0,0)，方程变为 D=0。
  - D=0：0=0，所有点都满足，解集是整个 R³（不是平面，是3维空间）。
  - D≠0：0=D，无解，解集是空集（不是平面）。
  所以 (A,B,C) 不能全为零。

  充分性：若 (A,B,C)≠(0,0,0)，不妨设 A≠0。
  方程可解出 x = -(By+Cz+D)/A。
  令 y=s, z=t（两个自由参数），则 x=-(Bs+Ct+D)/A。
  解集 = {(-(Bs+Ct+D)/A, s, t) | s,t∈R} = (-D/A,0,0) + s·(-B/A,1,0) + t·(-C/A,0,1)。
  这是一个2维仿射子空间（1个特解+2个方向向量），即平面。∎

  **退化情况讨论**：
  - (A,B,C)≠(0,0,0), D=0：平面过原点（代入(0,0,0)满足），是2维线性子空间。
  - (A,B,C)≠(0,0,0), D≠0：平面不过原点，是2维仿射子空间（非子空间）。
  - (A,B,C)=(0,0,0), D=0：0=0恒成立，解集=R³（全空间，3维）。
  - (A,B,C)=(0,0,0), D≠0：无解，解集=∅（空集）。

  **平面与仿射子空间的关系**：
  平面=2维仿射子空间。仿射子空间=线性子空间的平移：S = p + W，其中 W 是线性子空间（方向子空间），p 是一个点。
  - 平面过原点 ⇔ 它是线性子空间（D=0）。
  - 平面不过原点 ⇔ 它是仿射子空间但不是线性子空间（D≠0）。
  平面的方向子空间 W = { (x,y,z) | Ax+By+Cz=0 }（齐次方程的解空间，2维线性子空间），法向量 n=(A,B,C) 是 W 的正交补（1维）。

  **n维推广**：
  在 R^n 中，一个非齐次线性方程 a1x1+...+anxn+b=0（系数不全为零）表示 n-1 维仿射子空间（超平面）。
  齐次方程（b=0）表示 n-1 维线性子空间。
  这是线性方程组解的理论的几何化。
- **一句话点评**：方程Ax+By+Cz+D=0表示平面⇔(A,B,C)≠(0,0,0)。证明：系数全零时D=0⇒解集=R³（全空间），D≠0⇒无解；系数不全零时可解出一个变量，解集=特解+2个方向向量=2维仿射子空间=平面。退化：D=0⇒过原点（线性子空间），D≠0⇒不过原点（仿射非子空间）。平面=2维仿射子空间=p+W（W=齐次解空间=方向子空间，法向量n=W⊥）。n维推广：一个非齐次线性方程=n-1维超平面。这是"线性方程=超平面"的精确表述，连接了F2线性方程组与G6仿射空间。

**【G5-D-★★-028】** 反例构造：
(1) 找一个三元一次方程不表示平面（退化情况）；
(2) 找两条直线既不平行也不相交但共面（可能吗？）；
(3) 找一个点到平面的"距离"为负的情况（有向距离）；
(4) 找两个平面的交线不是直线的情况。

- **难度**：★★
- **对应知识点**：解析几何的退化与反例（研究模块第 3-4 章）
- **耦合方向**：→ F2（线性方程组）/ → G1（子空间）
- **来源**：反例构造题
- **解答**：
  **(1) 三元一次方程不表示平面**：
  0x+0y+0z+0=0（即 0=0）：所有点都满足，解集是整个 R³，不是平面（是3维全空间）。
  0x+0y+0z+1=0（即 0=1）：无解，解集是空集，不是平面。
  这两种都是"系数全为零"的退化情况。

  **(2) 两条直线既不平行也不相交但共面——不可能！**
  在同一平面内，两条直线的位置关系只有两种：平行或相交（在欧几里得几何中）。
  证明：若两直线共面且不平行，则它们的方向向量不共线。在同一平面内，两个不共线方向的直线必相交（平面内两条不平行直线有唯一交点）。
  所以"不平行且不相交"的直线一定异面（不共面）。
  反过来，异面直线一定不平行且不相交。
  结论：不平行不相交 ⇔ 异面，不存在"共面但不平行不相交"的直线。

  **(3) 有向距离为负**：
  点 P(0,0,0) 到平面 2x-y+z-3=0 的有向距离：
  δ = (2·0-1·0+1·0-3)/sqrt(4+1+1) = -3/sqrt(6) < 0。
  负号表示 P 在法向量 n=(2,-1,1) 指向的反侧（平面的"负侧"）。
  距离（无向）= |δ| = 3/sqrt(6) > 0。
  有向距离的符号表示点在平面的哪一侧，这在判断点与平面的位置关系时有用。

  **(4) 两平面交线不是直线**：
  - 两平面重合：交线=整个平面（2维，不是直线）。如 π1: x+y+z=1, π2: 2x+2y+2z=2（同解方程）。
  - 两平面平行不重合：交线=空集（没有交点）。如 π1: x+y+z=1, π2: x+y+z=2。
  - 只有两平面相交（法向量不平行）时，交线才是直线。

  **几何意义**：
  这些反例说明解析几何中的"标准结论"（方程=平面、两直线平行/相交、交线=直线）都有前提条件（系数不全零、共面、法向量不平行等）。退化情况对应线性方程组的退化（秩不足、矛盾方程等）。
- **一句话点评**：反例集合：①0=0⇒解集R³（全空间非平面），0=1⇒无解（空集非平面）——系数全零的退化。②共面两直线不平行必相交⇒"不平行不相交但共面"不可能，不平行不相交⇔异面。③点(0,0,0)到平面2x-y+z-3=0的有向距离=-3/sqrt(6)<0（负号表示在法向量反侧），无向距离=3/sqrt(6)。④两平面重合⇒交=平面（非直线），平行不重合⇒交=空集。这些反例说明"方程=平面""交线=直线"等结论都有前提（系数不全零、法向量不平行），退化对应线性方程组的退化（秩不足/矛盾方程）。

**【G5-D-★★★-030】** 充要探究：设两平面 π1: A1x+B1y+C1z+D1=0 和 π2: A2x+B2y+C2z+D2=0。证明它们的交线是直线的充要条件是法向量不平行（系数不成比例），并讨论交线方向向量与法向量的关系。

- **难度**：★★★
- **对应知识点**：两平面交线的充要条件（研究模块第 3 章）
- **耦合方向**：→ F2（线性方程组）/ → G3（叉积/法向量）
- **来源**：充要探究题
- **解答**：
  **充要条件**：两平面的交线是直线 ⇔ 法向量 n1=(A1,B1,C1) 和 n2=(A2,B2,C2) 不平行（即不成比例）。

  **证明**：
  两平面的交=联立方程组的解：
  A1x+B1y+C1z+D1=0
  A2x+B2y+C2z+D2=0

  系数矩阵 M = `[[A1,B1,C1],[A2,B2,C2]]`。

  **充分性（n1不平行n2 ⇒ 交线是直线）**：
  n1 不平行 n2 ⇒ M 的秩=2（两行不成比例，线性无关）。
  3个变量，秩=2，解空间维数=3-2=1（齐次解空间）。
  非齐次方程组：因为秩=2=系数矩阵行数，增广矩阵的秩也=2（不可能矛盾，因为2个方程3个变量总有解），所以非齐次解=1维仿射子空间=直线。∎

  **必要性（交线是直线 ⇒ n1不平行n2）**：
  反证：若 n1∥n2，即 (A1,B1,C1)=k(A2,B2,C2)。
  - 若 D1=kD2：两方程等价，两平面重合，交=整个平面（2维，不是直线）。
  - 若 D1≠kD2：两方程矛盾，无解，交=空集（不是直线）。
  两种情况交线都不是直线，矛盾。所以 n1 不平行 n2。∎

  **交线方向向量与法向量的关系**：
  交线方向 v 同时在两个平面内，所以 v·n1=0, v·n2=0（v 与两个法向量都垂直）。
  同时垂直于 n1,n2 的向量 ∥ n1×n2（叉积的定义）。
  所以 v ∥ n1×n2，取 v=n1×n2。

  验证：(n1×n2)·n1=0, (n1×n2)·n2=0（叉积与每个因子垂直）。✓

  **退化情况总结**：
  - n1不平行n2：交于直线（1维）。
  - n1∥n2, D1=kD2：重合（交=平面，2维）。
  - n1∥n2, D1≠kD2：平行不重合（交=空集，0维）。

  **与线性方程组的对应**：
  这正是 2×3 线性方程组解的三种情况：秩2⇒1维解集（直线），秩1且相容⇒2维解集（平面），秩1且矛盾⇒无解（空集）。
  几何位置关系=方程组解的情况，完全由系数矩阵和增广矩阵的秩决定。
- **一句话点评**：两平面交线是直线⇔法向量不平行（系数不成比例）。证明：n1不平行n2⇒系数矩阵秩2⇒3变量2方程解维数=1⇒直线；反之若n1∥n2，则D1=kD2⇒重合（交=平面），D1≠kD2⇒矛盾无解（交=空集），都不是直线。交线方向v∥n1×n2（同时垂直于两法向量，叉积正是同时垂直两因子的向量）。退化三情况：法向量不平行⇒交于直线；平行且D成比例⇒重合；平行且D不成比例⇒平行不重合。这是2×3线性方程组解的理论（秩决定解集维数）的几何化——几何位置关系=方程组解的情况。

**【G5-D-★★★-031】** 综合计算：已知平面 π: x+y+z-1=0，点 P(1,2,3)，直线 L: (x,y,z)=(0,0,0)+t(1,1,1)。
(1) 求 P 在 π 上的投影 P' 和 P 到 π 的距离；
(2) 判断 L 与 π 的位置关系，若相交求交点；
(3) 求过 P 且与 π 平行的平面方程；
(4) 求过 P 且与 L 垂直的平面方程。

- **难度**：★★★
- **对应知识点**：解析几何综合计算（研究模块第 2-5 章）
- **耦合方向**：→ F2（线性方程）/ → G3（投影/内积）/ → G1（向量）
- **来源**：综合计算题
- **解答**：
  平面 π: x+y+z-1=0，法向量 n=(1,1,1)。

  **(1) P 在 π 上的投影和距离**：
  投影公式 P'=P - (Ax0+By0+Cz0+D)/(A²+B²+C²)·n。
  Ax0+By0+Cz0+D = 1+2+3-1 = 5。
  A²+B²+C² = 3。
  P' = (1,2,3) - 5/3·(1,1,1) = (1-5/3, 2-5/3, 3-5/3) = (-2/3, 1/3, 4/3)。

  验证 P' 在 π 上：-2/3+1/3+4/3-1 = 3/3-1 = 0 ✓。

  距离 d = |5|/sqrt(3) = 5/sqrt(3) = 5sqrt(3)/3 ≈ 2.89。
  验证 ||P-P'|| = ||(5/3,5/3,5/3)|| = 5/3·sqrt(3) = 5sqrt(3)/3 ✓。

  **(2) L 与 π 的位置关系**：
  L 方向 v=(1,1,1)，与 n=(1,1,1) 平行（v=n）！所以 L 垂直于 π。
  L 过原点 (0,0,0)，代入 π：0+0+0-1=-1≠0，原点不在 π 上。
  所以 L 与 π 相交（不平行，因为 v 不垂直 n；不在平面内，因为原点不在平面上）。

  求交点：L 上点 (t,t,t)，代入 π：t+t+t-1=0 ⇒ 3t=1 ⇒ t=1/3。
  交点 = (1/3,1/3,1/3)。

  **(3) 过 P 且与 π 平行的平面**：
  平行平面法向量相同 n=(1,1,1)。
  点法式：1(x-1)+1(y-2)+1(z-3)=0 ⇒ x+y+z-6=0。
  验证：P(1,2,3)代入 1+2+3-6=0 ✓；与 π: x+y+z-1=0 法向量相同，平行 ✓。

  **(4) 过 P 且与 L 垂直的平面**：
  与 L 垂直 ⇒ 平面法向量 ∥ L 方向 v=(1,1,1)。
  取 n=(1,1,1)，过 P(1,2,3)：
  1(x-1)+1(y-2)+1(z-3)=0 ⇒ x+y+z-6=0。
  （与(3)相同，因为 π 的法向量也是 (1,1,1)，而 L 方向也是 (1,1,1)，所以"与π平行"和"与L垂直"是同一个平面。）

  验证：平面法向量 (1,1,1) 与 L 方向 (1,1,1) 平行 ⇒ 平面与 L 垂直 ✓。
- **一句话点评**：综合计算：π:x+y+z-1=0（n=(1,1,1)），P(1,2,3)，L:(t,t,t)。①P投影P'=(-2/3,1/3,4/3)，距离=5√3/3；②L方向v=(1,1,1)=n，L垂直π，交点(1/3,1/3,1/3)；③过P平行π的平面：x+y+z-6=0（法向量相同）；④过P垂直L的平面：x+y+z-6=0（法向量∥v）。③和④是同一个平面，因为π的法向量=L的方向=(1,1,1)——"与平面平行"和"与平面法线方向的直线垂直"是同一回事。这道题综合了投影、距离、线面关系、平面方程，是解析几何基本计算的大练兵。

**【G5-D-★★★-032】** 开放探索：解析几何的本质与推广。思考：
(1) 为什么解析几何能"用代数方法解决几何问题"？核心机制是什么？
(2) 从三维解析几何到 n 维解析几何（线性代数），哪些概念推广了，哪些是三维特有的？
(3) 解析几何与微积分（多元函数、曲面微积分）的关系；
(4) 解析几何在现代科技中的应用（计算机图形学、机器人学、计算机视觉）。

- **难度**：★★★
- **对应知识点**：解析几何的本质与推广（研究模块第 8 章）
- **耦合方向**：→ T7（应用）/ → G7（二次型）/ → G6（仿射）
- **来源**：开放探索题
- **解答**：
  **(1) 解析几何的核心机制：坐标化+代数化**

  解析几何的核心思想：**给几何对象赋予坐标，把几何关系转化为代数方程，通过代数运算解决几何问题**。
  - 点 ↔ 坐标三元组 (x,y,z)。
  - 直线/平面 ↔ 线性方程（组）。
  - 距离/夹角 ↔ 内积/叉积（代数公式）。
  - 位置关系（平行/相交/垂直）↔ 代数条件（系数成比例/方程组有解/内积为零）。
  - 曲面 ↔ 方程（F(x,y,z)=0）。

  核心机制：**坐标映射**把几何空间 R³ 与代数空间 R³ 一一对应，几何变换对应代数运算（矩阵乘法、加法），几何不变量（距离、角度）对应代数不变量（内积、范数）。
  这是"数形结合"的典范——数与形通过坐标映射互相翻译。

  **(2) 三维到 n 维的推广**

  **推广了的概念**：
  - 点 ↔ n 维向量 (x1,...,xn)。
  - 超平面 ↔ 一个线性方程（n-1维仿射子空间）。
  - 线性子空间 ↔ 齐次线性方程组的解。
  - 内积/范数/夹角 ↔ 标准内积（或一般内积）。
  - 正交投影/距离 ↔ 正交投影公式（G3）。
  - 二次型/二次超曲面 ↔ x^T A x = c。
  - 正交变换/坐标旋转 ↔ 正交矩阵。

  **三维特有的概念**：
  - 叉积（×）：只在三维中有定义（n维中推广为楔积，但不是向量）。
  - 平面（2维超平面在3维中是"平面"，在n维中是n-1维超平面）。
  - 异面直线：n≥3才有，二维中直线必共面。
  - 右手系/定向：三维中有叉积定义的自然定向。
  - 球面/柱面/锥面等经典曲面：三维中的二次曲面有丰富的分类（椭球/双曲/抛物），n维中分类更简单（由惯性指数决定）。

  **本质**：n维解析几何就是线性代数本身——三维解析几何是线性代数在 n=3 时的"可视化特例"。学好了线性代数，就掌握了任意维的"解析几何"。

  **(3) 解析几何与微积分的关系**

  - **多元函数的图像**：z=f(x,y) 的图像是三维空间中的曲面，解析几何提供了曲面的语言（切平面、法向量、等高线）。
  - **切平面**：曲面 F(x,y,z)=0 在点 P 的切平面方程 F_x(P)(x-x0)+F_y(P)(y-y0)+F_z(P)(z-z0)=0，法向量=梯度 ∇F(P)。这是解析几何平面方程在微积分中的应用。
  - **曲线积分/曲面积分**：积分路径是曲线（解析几何的参数方程），积分曲面是曲面（解析几何的方程），需要参数化和法向量。
  - **条件极值**：拉格朗日乘数法中，约束条件 g(x,y,z)=0 是曲面，梯度 ∇g 是法向量，极值条件=目标函数梯度与约束曲面法向量平行。
  - **方向导数**：沿方向 v 的方向导数 = ∇f·v/||v||，这是内积在微积分中的应用。

  解析几何为多元微积分提供了几何语言（曲面、切平面、法向量、参数化），微积分为解析几何提供了分析工具（切线、曲率、极值）。两者相辅相成。

  **(4) 解析几何在现代科技中的应用**

  - **计算机图形学**：3D模型=顶点（点坐标）+面（平面/曲面），渲染=投影变换（透视投影=线性变换+齐次坐标），光照=法向量（计算反射方向），旋转=正交矩阵（四元数）。解析几何是图形学的数学基础。
  - **机器人学**：机械臂运动学=坐标变换（齐次变换矩阵=旋转+平移），逆运动学=求解关节角度（解析几何方程），障碍物避碰=距离计算（点到平面/直线距离）。
  - **计算机视觉**：相机模型=透视投影（3D到2D的线性变换），三维重建=从2D图像恢复3D坐标（三角测量=直线相交），特征匹配=向量内积（相似度）。
  - **CAD/CAM**：几何建模=参数曲面（B样条/NURBS），数控加工=刀具路径计算（曲面交线、偏移曲面）。
  - **GPS/导航**：定位=球面交会（到多颗卫星距离相等=球面交），路径规划=最短路径（距离计算）。
  - **机器学习**：SVM=最大间隔超平面（线性分类器=超平面，间隔=点到超平面距离），PCA=正交投影（降维=投影到低维子空间），k-NN=距离计算。

  **核心洞察**：
  解析几何的核心工具——坐标、线性方程、内积、投影、正交矩阵——是所有涉及"空间"和"几何"的科技领域的基础。
  从三维到高维（机器学习的特征空间），从欧几里得到非欧（流形学习），解析几何的思想在不断推广，但核心始终是"用代数描述几何，用计算解决空间问题"。
- **一句话点评**：解析几何本质=坐标化+代数化——点↔坐标，线面↔线性方程，距离角度↔内积叉积，位置关系↔代数条件，曲面↔方程。核心机制是坐标映射把几何空间与代数空间一一对应，几何变换↔代数运算，几何不变量↔代数不变量。三维到n维推广：超平面、子空间、内积、投影、二次型、正交变换都推广了；叉积、异面直线、右手系是三维特有。n维解析几何就是线性代数本身——三维是n=3的可视化特例。与微积分关系：切平面=梯度法向量，条件极值=梯度平行，曲面积分=参数化+法向量。现代应用：计算机图形学（投影/法向量/旋转矩阵）、机器人学（齐次变换/逆运动学）、计算机视觉（透视投影/三角测量）、CAD（参数曲面）、GPS（球面交会）、机器学习（SVM超平面/PCA投影/k-NN距离）。解析几何的核心工具——坐标、方程、内积、投影、正交矩阵——是所有"空间几何"领域的基础，从三维到高维、从欧氏到非欧不断推广。
