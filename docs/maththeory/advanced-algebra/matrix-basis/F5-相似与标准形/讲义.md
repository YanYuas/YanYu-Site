## 研究摘要

**核心命题**：相似变换的几何本质是"同一线性变换在不同基下的矩阵表示"。两个矩阵相似 ⇔ 它们是同一个线性变换在两组不同基下的"坐标翻译"。标准形理论的目标是：在所有相似的矩阵中，找到一个结构最简单的代表元，从而剥离基的表象，直达变换的内蕴本质。相似不变量（迹、行列式、特征多项式、秩、特征值、极小多项式）是"不随基改变而改变的变换属性"，它们构成了相似等价类的完整不变量系统。

**研究问题**：(RQ1) 为什么相似变换 A→P⁻¹AP 的几何意义是"换基"？P 的列向量在几何上扮演什么角色？(RQ2) 哪些量是相似不变量？它们的几何含义分别是什么？(RQ3) 标准形的本质是什么？为什么对角形、三角化、有理标准形是不同层次的"最简代表"？(RQ4) 如何判断两个矩阵是否相似？相似判定的完整算法是什么？

**研究方法**：几何还原法——从"同一个变换在不同坐标系下有不同的矩阵长相"这一直觉出发，建立相似变换的代数定义，用相似不变量刻画等价类，用三种标准形（对角形、三角化、有理标准形）展示"最简代表"的层次结构，所有数值经 Python 3 + numpy 复算。

**核心结论**：相似是矩阵之间的等价关系，它将所有 n×n 矩阵划分为若干等价类，每个等价类对应一个"本质相同的线性变换"。相似不变量是等价类的"指纹"——完整的不变量系统（初等因子或不变因子）可以唯一确定等价类。对角形是可对角化矩阵的最简形；三角化（舒尔定理）是所有复矩阵的通用最简形（酉相似下）；有理标准形是不依赖特征值分解的纯代数标准形。F5 是领域一的"分类层"，它承接 F4（特征理论）的对角化成果，并为 F6（若尔当标准形）提供分类框架。

**一句话定位**：相似 = 换基，标准形 = 等价类中最简单的代表。掌握了相似与标准形，就掌握了"如何在无数种矩阵长相中识别同一个变换"的能力——这是矩阵理论从"计算"走向"分类"的关键一跃。

## 引言：为什么需要相似与标准形

### 1.1 从"矩阵的长相"到"变换的等价类"

在 F1 中，我们知道矩阵的"长相"取决于基的选择——同一个线性变换在不同基下有不同的矩阵表示。在 F2 中，我们知道矩阵乘法对应变换复合。在 F3 中，我们知道行列式是体积缩放因子（相似不变量）。在 F4 中，我们知道特征值和特征向量是变换的内蕴属性（相似不变量）。

但一个根本问题尚未系统回答：**给定两个矩阵，如何判断它们是否表示同一个线性变换？**如果是，它们之间的关系是什么？如果不是，它们的本质差异在哪里？这就是相似与标准形理论要解决的核心问题。

相似变换 A→P⁻¹AP 就是"换基"的代数表达：P 的列是新基在旧基下的坐标，P⁻¹AP 是变换在新基下的矩阵。所有可以通过换基互相转化的矩阵构成一个"等价类"——它们本质上是同一个变换。

### 1.2 标准形：等价类中最简单的代表

在一个相似等价类中，有无穷多个矩阵（因为有无穷多种基的选择）。但我们希望找到其中结构最简单的一个，作为这个等价类的"代表元"——这就是标准形。

标准形的意义在于：(1) **识别**——两个矩阵相似 ⇔ 它们的标准形相同；(2) **简化计算**——在标准形下，矩阵的幂、指数函数、行列式等都更容易计算；(3) **揭示本质**——标准形的结构直接反映了变换的内蕴性质。

不同的标准形对应不同的"简化层次"：对角形是最强的简化（但不是所有矩阵都能达到）；三角化是通用的简化（所有复矩阵都能达到）；有理标准形是不依赖特征值的纯代数简化（在任意域上都有效）。

## 相似变换的几何本质

### 2.1 换基的代数表达

设 T: V→V 是线性变换，α={α₁,...,αₙ} 和 β={β₁,...,βₙ} 是 V 的两组基。T 在 α 下的矩阵为 A，在 β 下的矩阵为 B。

设 P 是从 β 到 α 的过渡矩阵（即 β 的每个向量在 α 下的坐标作为 P 的列），则坐标变换关系为 [x]_α = P[x]_β。

对任意向量 x，T(x) 在 α 下的坐标是 A[x]_α，在 β 下的坐标是 B[x]_β。因为 [T(x)]_α = P[T(x)]_β，所以 A[x]_α = P B [x]_β = P B P⁻¹ [x]_α。因此 A = PBP⁻¹，即 B = P⁻¹AP。

**几何结论**：B=P⁻¹AP 表示"同一个变换 T 在两组基下的矩阵表示"。P 是"基翻译器"——它把新基的坐标翻译成旧基的坐标。相似不是"变换变了"，而是"观察变换的坐标系变了"。

### 2.2 相似的直观理解

考虑一个 2D 旋转变换：逆时针旋转 θ 角。在标准基下，矩阵是 R(θ)=[[cosθ,-sinθ],[sinθ,cosθ]]。

如果我们换一组基——比如把坐标轴旋转 φ 角——那么同一个旋转变换在新基下的矩阵是什么？答案是 P⁻¹R(θ)P，其中 P 是基变换矩阵。

但旋转变换的本质（旋转角度 θ）不依赖于坐标系的选择。所以 R(θ) 和 P⁻¹R(θ)P 虽然"长相"不同，但它们表示同一个旋转变换——它们相似。

更一般地，任何线性变换的"本质行为"（旋转角度、伸缩因子、剪切方向等）都不依赖于基的选择。相似变换保持了这些本质行为，只改变了矩阵的"长相"。

**耦合索引 → F1（基底与坐标）**：相似变换的几何基础是 F1 建立的"换基"理论。P 的列是新基在旧基下的坐标，P⁻¹AP 是变换在新基下的矩阵。F1 是"如何换基"，F5 是"换基后什么不变"。

### 2.3 相似变换的基本性质

**自反性**：A 与 A 相似（取 P=I）。

**对称性**：如果 B=P⁻¹AP，那么 A=PBP⁻¹=(P⁻¹)⁻¹B(P⁻¹)，所以 A 与 B 相似。

**传递性**：如果 B=P⁻¹AP，C=Q⁻¹BQ，那么 C=Q⁻¹P⁻¹APQ=(PQ)⁻¹A(PQ)，所以 C 与 A 相似。

这三条性质说明相似是等价关系——它将所有 n×n 矩阵划分为互不相交的等价类，每个等价类中的矩阵"本质相同"。

**运算保持**：如果 B=P⁻¹AP，那么：

• Bᵏ=P⁻¹AᵏP（幂保持相似） • B⁻¹=P⁻¹A⁻¹P（逆保持相似，A可逆时） • p(B)=P⁻¹p(A)P（多项式保持相似） • det(B)=det(A), tr(B)=tr(A)（行列式和迹不变）

### 2.4 相似 vs 合同 vs 等价

矩阵之间有三种常见的等价关系，容易混淆：

**等价**（相抵）：B=PAQ，P,Q 可逆。几何意义：对变换的定义域和值域分别换基（不一定是同一个变换，因为定义域和值域可以不同）。等价标准形是 diag(Iᵣ, 0)，只由秩决定。

**相似**：B=P⁻¹AP，P 可逆。几何意义：同一个线性变换在不同基下的表示（定义域=值域，用同一组基）。相似不变量比等价多（特征多项式、迹等）。

**合同**：B=PᵀAP，P 可逆。几何意义：双线性型（或二次型）在不同基下的表示。合同保持惯性指数（正负特征值个数），但不保持特征值本身。

三者的关系：相似 ⇒ 等价（因为 P⁻¹AP=P⁻¹AP，取 P₁=P⁻¹, Q₁=P）；合同 ⇒ 等价。但相似和合同之间没有蕴含关系（除非 P 是正交矩阵，此时 P⁻¹=Pᵀ，相似=合同）。

### 2.5 相似变换的"主动"与"被动"视角

相似变换有两种互补的理解方式：

**被动视角（换基）**：A 和 B=P⁻¹AP 是同一个变换 T 在不同基下的矩阵。变换 T 没有变，变的是我们观察它的坐标系。这是"坐标系在动，变换不动"。

**主动视角（变换的共轭）**：B=P⁻¹AP 可以理解为"先做 P 变换，再做 A 变换，最后做 P⁻¹ 变换"。几何上，这是"把空间用 P 变形，在变形后的空间里做 A，再用 P⁻¹ 变回来"。如果 A 是伸缩，P 是旋转，那么 P⁻¹AP 就是"在旋转后的方向上做伸缩"——这正是特征分解的思想。

两种视角是等价的，但强调的重点不同：被动视角强调"不变性"（变换的本质不随基改变），主动视角强调"构造性"（如何通过共轭构造出具有特定性质的矩阵）。在标准形理论中，我们主要使用被动视角——寻找一组基使变换的矩阵最简。

## 相似不变量：变换的内蕴属性

### 3.1 什么是相似不变量

一个量 f(A) 称为相似不变量，如果对任意可逆矩阵 P，都有 f(P⁻¹AP)=f(A)。

几何上，相似不变量是"不随基的选择而改变的变换属性"——它们描述了变换本身的本质，而不是矩阵的"长相"。如果两个矩阵相似，它们的所有相似不变量都相同；反过来，如果两个矩阵的"完整不变量系统"相同，它们就相似。

相似不变量是分类理论的核心：它们是等价类的"指纹"。找到完整的不变量系统，就等于解决了相似判定问题。

### 3.2 基本相似不变量

**行列式**：det(P⁻¹AP)=det(P⁻¹)det(A)det(P)=det(A)。几何含义：体积缩放因子（F3）。

**迹**：tr(P⁻¹AP)=tr(APP⁻¹)=tr(A)。几何含义：特征值之和，"总伸缩量"（F2/F4）。

**秩**：rank(P⁻¹AP)=rank(A)。几何含义：像空间的维数，"变换保留的维度"。

**特征多项式**：det(λI-P⁻¹AP)=det(P⁻¹(λI-A)P)=det(λI-A)。几何含义：不变方向的计数（F4）。

**特征值（含代数重数）**：特征多项式相同 ⇒ 特征值相同。几何含义：各不变方向上的伸缩因子。

### 3.3 极小多项式：比特征多项式更精细的不变量

矩阵 A 的极小多项式 m_A(x) 是满足 m_A(A)=0 的次数最低的首一多项式。凯莱-哈密顿定理保证特征多项式 p_A(A)=0，所以极小多项式的次数 ≤ n，且 m_A(x) | p_A(x)。

**极小多项式是相似不变量**：如果 B=P⁻¹AP，那么 m_A(B)=P⁻¹m_A(A)P=0，所以 m_B(x) | m_A(x)；由对称性 m_A(x) | m_B(x)，因此 m_A=m_B。

**极小多项式比特征多项式更精细**：考虑 I=`[[1,0],[0,1]]` 和 J=`[[1,1],[0,1]]`。它们的特征多项式都是 (λ-1)²，但极小多项式不同：m_I(x)=x-1，m_J(x)=(x-1)²。这说明特征多项式相同的矩阵不一定相似——极小多项式提供了更精细的区分。

**几何含义**：极小多项式描述了"变换的幂何时开始线性相关"。m_A(A)=0 意味着 A 的 deg(m_A) 次幂可以表示为低次幂的线性组合。极小多项式的根是特征值，根的重数是"最大若尔当块的大小"——这是 F6（若尔当标准形）的核心预告。

**注意**：特征多项式和极小多项式都相同，仍然不能保证两个矩阵相似！例如 diag(J₂(1), J₂(1)) 和 diag(J₃(1), J₁(1)) 都有特征多项式 (λ-1)⁴ 和极小多项式 (λ-1)³，但它们不相似（若尔当块结构不同）。完整的不变量系统需要"初等因子"或"不变因子"——见第 6 章有理标准形。

### 3.4 相似不变量的层次结构

| 不变量 | 信息量 | 能否唯一确定相似类 |
|---|---|---|
| 行列式 | 1 个数 | 否（太粗糙） |
| 迹 | 1 个数 | 否 |
| 秩 | 1 个数 | 否 |
| 特征多项式 | n 个系数 | 否（I vs J 反例） |
| 特征多项式+极小多项式 | 更精细 | 否（4阶反例） |
| 不变因子（有理标准形） | 完整 | 是 ✓ |
| 初等因子（若尔当标准形） | 完整 | 是 ✓ |

这个层次结构说明：从简单的数值不变量到完整的多项式不变量，信息量逐步增加，直到能够唯一确定相似等价类。有理标准形和若尔当标准形提供了完整的不变量系统。

### 3.5 相似不变量的几何意义总览

每个相似不变量都对应变换的一个几何属性：

• **行列式**= 体积缩放因子 = 特征值之积 •**迹**=  infinitesimal 体积变化率 = 特征值之和 •**秩**= 像空间维数 = n - 零特征值几何重数之和 •**特征多项式**= 不变方向的"计数多项式" •**极小多项式**= 变换幂的"最小相关多项式" •**不变因子**= 循环子空间分解的"尺寸序列" •**初等因子**= 若尔当块的"尺寸-特征值"列表

这些不变量从不同角度描述了同一个变换的本质，它们之间有深刻的联系：特征多项式是不变因子的乘积，极小多项式是最后一个不变因子，初等因子是不变因子的素数幂分解。

## 等价关系与矩阵分类

### 4.1 等价关系的抽象定义

集合 S 上的关系 ~ 称为等价关系，如果满足：

•**自反性**：a~a • **对称性**：a~b ⇒ b~a • **传递性**：a~b, b~c ⇒ a~c

等价关系将集合划分为若干互不相交的子集，称为等价类。同一等价类中的元素"本质相同"，不同等价类中的元素"本质不同"。

在矩阵理论中，有三种重要的等价关系：等价（相抵）、相似、合同。它们对应三种不同的"本质相同"概念：

• 等价：秩相同（变换的"大小"相同） • 相似：同一个线性变换（变换的"行为"相同） • 合同：同一个二次型（几何的"形状"相同）

### 4.2 分类问题的哲学

数学中的许多问题本质上都是"分类问题"：给定一类对象和一种等价关系，找出每个等价类的"代表元"（标准形），并找到判断两个对象是否等价的方法（不变量）。

分类问题的三个要素：

1. **等价关系**：定义"什么是相同的" 2. **标准形**：每个等价类中选一个最简单的代表 3. **不变量**：可以计算的、在等价关系下不变的量，用于判定

在相似分类中：等价关系是 B=P⁻¹AP；标准形有对角形、三角化、有理标准形、若尔当标准形；不变量有迹、行列式、特征多项式、极小多项式、不变因子、初等因子。

分类问题的"完美解决"需要：(1) 标准形存在且唯一；(2) 不变量系统完整（相同 ⇔ 等价）；(3) 标准形和不变量都可以有效计算。

### 4.3 相似等价类的结构

所有 n×n 矩阵在相似关系下被划分为若干等价类。每个等价类有无穷多个元素（因为有无穷多种基的选择），但只有有限多个等价类吗？

答案是：在代数闭域（如复数域）上，相似等价类由若尔当标准形唯一确定，而若尔当标准形由特征值和若尔当块结构决定。由于特征值可以连续变化，所以等价类的数量是不可数无穷的。但对于给定的特征值集合，若尔当块结构只有有限种（对应整数分拆）。

例如，2×2 矩阵的相似类：如果特征值 λ₁≠λ₂，则可对角化，标准形 diag(λ₁,λ₂)；如果特征值 λ₁=λ₂=λ，则有两种可能：可对角化（标准形 λI）或亏损（标准形 J₂(λ)=[[λ,1],[0,λ]]）。所以对于固定的重特征值，有 2 种相似类。

对于 n×n 矩阵，特征值 λ 的代数重数为 m 时，若尔当块结构对应 m 的整数分拆，分拆数 p(m) 增长很快（p(10)=42, p(20)=627）。这说明高维矩阵的相似分类非常丰富。

**耦合索引 → F6（若尔当标准形）**：若尔当标准形是相似分类的"终极答案"——它提供了复矩阵相似类的唯一标准形。F5 建立分类框架和三种较简单的标准形，F6 展开若尔当标准形的完整理论。

### 4.4 标准形的"最简"含义

"最简"是一个相对概念，取决于我们允许的变换范围和追求的结构：

**对角形**：非零元只在对角线上。最强的简化，但不是所有矩阵都能达到（需要可对角化）。

**上三角形**：非零元只在对角线及以上。所有复矩阵都能达到（舒尔定理），但需要酉相似（更强的变换限制）。

**有理标准形**：分块对角，每个块是友矩阵。所有矩阵都能达到（任意域），不依赖特征值分解，但结构不如若尔当形直观。

**若尔当标准形**：分块对角，每个块是若尔当块。所有复矩阵都能达到，结构最清晰，是相似分类的"终极标准形"。

### 4.5 不变量系统的完备性

一个不变量系统称为完备的，如果"两个矩阵的不变量完全相同" ⇔ "两个矩阵相似"。

不完备的不变量系统只能给出"相似 ⇒ 不变量相同"的单向蕴含，不能反过来判定。例如：

• 行列式相同 ⇏ 相似 • 特征多项式相同 ⇏ 相似（I vs J 反例） • 特征多项式+极小多项式相同 ⇏ 相似（4阶反例）

完备的不变量系统：

• **不变因子组**（有理标准形的不变量）：d₁(x)|d₂(x)|...|dₛ(x)，乘积=特征多项式，最后一个=极小多项式 • **初等因子组**（若尔当标准形的不变量）：所有若尔当块的特征多项式 (λ-λᵢ)^mᵢ

这两个系统等价（可以互相转化），都能唯一确定相似等价类。

## 对角形与三角化标准形

### 5.1 对角形：最强的简化

如果矩阵 A 可对角化，即存在可逆矩阵 P 使得 P⁻¹AP=D=diag(λ₁,...,λₙ)，那么 D 就是 A 所在相似类的对角标准形。

**几何意义**：在特征向量基下，变换只是各方向独立伸缩。对角矩阵是"最简单"的矩阵——它的幂、指数函数、行列式都可以直接计算：Dᵏ=diag(λ₁ᵏ,...,λₙᵏ), e^D=diag(e^λ₁,...,e^λₙ), det(D)=∏λᵢ。

**存在条件**：A 可对角化 ⇔ A 有 n 个线性无关的特征向量 ⇔ 每个特征值的几何重数=代数重数 ⇔ 极小多项式无重根。

**唯一性**：对角标准形在不计特征值排列顺序的意义下唯一。这是因为特征值（含代数重数）是相似不变量。

**耦合索引 → F4（特征理论）**：对角化是 F4 的核心内容。F4 建立了"可对角化 ⇔ 不变方向铺满空间"的几何条件，F5 将对角形放在标准形理论的框架中重新审视——它是相似等价类中"最强的简化"，但不是所有等价类都能达到。

### 5.2 舒尔定理：酉相似三角化

**舒尔定理**：任何 n×n 复矩阵 A 都酉相似于一个上三角矩阵 T，即存在酉矩阵 U（U*U=I）使得 U*AU=T，其中 T 的对角线元素是 A 的特征值。

**几何意义**：在复数域上，任何线性变换都可以找到一组标准正交基，使得变换的矩阵是上三角的。上三角矩阵的对角线元素就是特征值——这给出了特征值的一种几何解释：在适当的正交基下，变换的"对角分量"就是特征值。

**证明思路**（数学归纳法）：n=1 时显然。对于 n>1，A 至少有一个复特征值 λ₁（因为复系数多项式必有复根），取对应的单位特征向量 u₁，扩充为标准正交基 {u₁,...,uₙ}。在这组基下，A 的矩阵形如 [[λ₁, *],[0, A₁]]，其中 A₁ 是 (n-1)×(n-1) 矩阵。对 A₁ 用归纳假设即可。

**重要性**：舒尔定理是许多矩阵定理的基础——它将一般矩阵"三角化"后，很多性质可以直接从上三角矩阵读出。例如，正规矩阵（A*A=AA*）的舒尔形是对角矩阵（因为上三角的正规矩阵必对角），这给出了谱定理的另一种证明。

### 5.3 三角化 vs 对角化

| 维度 | 对角化 | 三角化（舒尔） |
|---|---|---|
| 变换类型 | 相似（P可逆） | 酉相似（U酉矩阵） |
| 适用范围 | 仅可对角化矩阵 | 所有复矩阵 |
| 标准形结构 | 对角矩阵 | 上三角矩阵 |
| 对角线元素 | 特征值 | 特征值 |
| 非对角元 | 全零 | 可能非零 |
| 几何意义 | 不变方向铺满空间 | 存在不变子空间旗 |
| 唯一性 | 特征值排列唯一 | 不唯一（酉矩阵不唯一） |

三角化是"通用的简化"——所有复矩阵都能达到，但简化程度不如对角化。对角化是"最强的简化"——但只有部分矩阵能达到。若尔当标准形则介于两者之间：所有复矩阵都能达到，且结构比三角化更规范（分块对角而非一般上三角）。

### 5.4 不变子空间旗与三角化

舒尔定理的几何本质是"不变子空间旗"的存在性。一个不变子空间旗是一列子空间 {0}=V₀⊂V₁⊂...⊂Vₙ=V，其中 dim(Vᵢ)=i，且每个 Vᵢ 都是 A 的不变子空间（A(Vᵢ)⊆Vᵢ）。

如果存在这样的旗，那么取 Vᵢ\Vᵢ₋₁ 中的向量作为基向量，A 的矩阵就是上三角的——因为 A(vᵢ)∈Vᵢ=span(v₁,...,vᵢ)，所以第 i 列只有前 i 个元素可能非零。

在复数域上，不变子空间旗总是存在的：取一个特征向量 v₁，V₁=span(v₁)；在商空间 V/V₁ 上取一个特征向量，提升回 V 得到 v₂，V₂=span(v₁,v₂)；依此类推。

这就是三角化的几何本质：**复空间上的任何线性变换都有一个完整的不变子空间旗**。在实数域上，这不一定成立（因为实矩阵可能没有实特征值），所以实矩阵不一定能实相似于上三角矩阵。

### 5.5 同时三角化与同时对角化

**同时三角化定理**：如果矩阵族 {Aᵢ} 中的矩阵两两可交换（AᵢAⱼ=AⱼAᵢ），那么它们可以同时酉相似于上三角矩阵（存在同一个 U 使得所有 U*AᵢU 都是上三角）。

几何意义：可交换的变换族有共同的不变子空间旗。这是因为如果 A 和 B 可交换，那么 A 的特征子空间在 B 下不变，可以在 A 的特征子空间内继续找 B 的特征向量。

**同时对角化定理**：如果矩阵族 {Aᵢ} 两两可交换且每个 Aᵢ 都可对角化，那么它们可以同时对角化（存在同一个 P 使得所有 P⁻¹AᵢP 都是对角矩阵）。

特别地，如果 A 和 B 都是对称矩阵且 AB=BA，那么它们可以同时正交对角化。这在量子力学中意味着"可交换的可观测量可以同时测量"——这是量子力学的基本原理之一。

## 有理标准形：不依赖特征值的分类

### 6.1 为什么需要有理标准形

对角形和若尔当形都依赖于特征值的计算——需要求解特征多项式的根。但在一般域（如有理数域 Q）上，多项式可能没有根（不可约），此时若尔当形不存在。

有理标准形（Frobenius 标准形）解决了这个问题：它不依赖于特征值的分解，只使用多项式的整除关系，在任意域上都有效。

有理标准形的核心思想是"循环分解"：将向量空间分解为若干个循环子空间的直和，每个循环子空间由一个向量 v 及其在 A 下的迭代 {v, Av, A²v, ...} 生成。在每个循环子空间上，A 的矩阵是友矩阵（companion matrix）。

### 6.2 友矩阵与循环子空间

对于首一多项式 f(x)=xᵐ+cₘ₋₁xᵐ⁻¹+...+c₁x+c₀，其友矩阵 C(f) 是：

C(f) = [[0,0,...,0,-c₀],          [1,0,...,0,-c₁],          [0,1,...,0,-c₂],          [...,          [0,0,...,1,-cₘ₋₁]]

友矩阵的特征多项式和极小多项式都是 f(x)。它的几何意义是：在循环基 {v, Av, ..., Aᵐ⁻¹v} 下，A 把每个基向量移到下一个，最后一个映射为 -c₀v-c₁Av-...-cₘ₋₁Aᵐ⁻¹v。

一个循环子空间是形如 Z(v;A)=span{v, Av, A²v, ...} 的子空间。如果 v 的零化多项式（满足 p(A)v=0 的最低次首一多项式）是 f(x)，且 deg(f)=m，那么 {v, Av, ..., Aᵐ⁻¹v} 是 Z(v;A) 的一组基，A 在这组基下的矩阵就是 C(f)。

### 6.3 有理标准形定理

**有理标准形定理**：对于任意 n×n 矩阵 A（在任意域 F 上），存在唯一的首一多项式序列 d₁(x), d₂(x), ..., dₛ(x)，满足 d₁(x)|d₂(x)|...|dₛ(x)（整除链），使得 A 相似于分块对角矩阵 diag(C(d₁), C(d₂), ..., C(dₛ))，其中 C(dᵢ) 是 dᵢ 的友矩阵。

这个分块对角矩阵就是 A 的有理标准形（Frobenius 标准形）。多项式 dᵢ(x) 称为 A 的不变因子。

**不变因子的性质**：

• 乘积 d₁d₂...dₛ = 特征多项式 p_A(x) • 最后一个 dₛ(x) = 极小多项式 m_A(x) • 不变因子是相似不变量，且构成完备不变量系统 • 两个矩阵相似 ⇔ 它们的不变因子完全相同

**几何意义**：有理标准形将空间分解为 s 个循环子空间的直和 V=Z(v₁;A)⊕...⊕Z(vₛ;A)，每个循环子空间的"大小"由不变因子 dᵢ 的次数决定。整除链 d₁|d₂|...|dₛ 保证了分解的规范性。

**方法论注记**：有理标准形的"有理"二字指的是"只用到有理运算（加减乘除），不需要求根"——它在任意域上都有效。这与若尔当标准形形成对比：若尔当形需要代数闭域（特征值都在域内），但结构更直观。两者通过初等因子联系：将不变因子分解为不可约多项式的幂，就得到初等因子；在代数闭域上，不可约多项式都是一次的，初等因子就是 (λ-λᵢ)^mᵢ，对应若尔当块。

### 6.4 不变因子的计算

不变因子可以通过 λ-矩阵（特征矩阵 λI-A）的初等变换计算：

1. 构造 λ-矩阵 λI-A 2. 用初等变换（行/列交换、行/列乘非零常数、行/列加另一行/列的多项式倍）化为对角形 diag(d₁(λ), d₂(λ), ..., dₙ(λ))，其中 d₁|d₂|...|dₙ 3. 去掉 dᵢ=1 的项，剩下的就是不变因子

这个过程类似于整数矩阵的 Smith 标准形，只不过将整数换成了多项式。对角线上的非 1 元素就是不变因子。

另一种方法是通过行列式因子：Δₖ(λ) = λI-A 的所有 k 阶子式的最大公因式。则 dₖ=Δₖ/Δₖ₋₁（约定 Δ₀=1）。

### 6.5 有理标准形的实例

考虑 A=`[[0,-1],[1,0]]`（90°旋转矩阵）。特征多项式 λ²+1，在实数域上不可约。

极小多项式也是 λ²+1（因为 A²=-I，且没有一次多项式零化 A）。所以不变因子只有一个：d₁=λ²+1。

有理标准形就是友矩阵 C(λ²+1)=`[[0,-1],[1,0]]`=A 本身——A 已经是有理标准形！

在复数域上，λ²+1=(λ-i)(λ+i)，初等因子是 (λ-i) 和 (λ+i)，若尔当标准形是 diag(i, -i)。这说明：同一个矩阵在不同域上有不同的标准形——有理标准形在实数域上已经是"最简"，但若尔当形需要复数域。

几何上，这对应于"实空间中的旋转变换没有实的不变方向，但有二维循环子空间（整个平面）"。

## 相似判定与几何应用

### 7.1 相似判定的完整算法

给定两个 n×n 矩阵 A 和 B，判断它们是否相似的完整算法：

**方法一：不变因子法**（通用，任意域）

1. 分别计算 A 和 B 的 λ-矩阵 λI-A 和 λI-B 2. 用初等变换化为 Smith 标准形，得到不变因子 3. 比较两组不变因子：完全相同 ⇔ 相似

**方法二：若尔当标准形法**（代数闭域，如复数域）

1. 分别计算 A 和 B 的特征值和若尔当块结构 2. 比较若尔当标准形：相同（不计排列）⇔ 相似

**方法三：有理标准形法**（任意域，不需要求特征值）

1. 分别计算 A 和 B 的有理标准形 2. 比较有理标准形：相同 ⇔ 相似

这三种方法本质上等价——不变因子、初等因子、若尔当块结构可以互相转化。在实际计算中，低维矩阵可以用特征多项式+极小多项式快速排除不相似的情况，高维矩阵需要完整的不变因子计算。

### 7.2 相似判定的"快速排除法"

在实际应用中，通常先用简单的不变量快速排除不相似的情况：

**第一步**：比较行列式、迹、秩。任一不同 ⇒ 不相似。

**第二步**：比较特征多项式。不同 ⇒ 不相似。

**第三步**：比较极小多项式。不同 ⇒ 不相似。

**第四步**：比较各特征值的几何重数（rank(A-λI)）。不同 ⇒ 不相似。

**第五步**：如果以上都相同，计算完整的不变因子或若尔当标准形做最终判定。

大多数情况下，前几步就能排除不相似的情况。只有"特征多项式和极小多项式都相同但若尔当块结构不同"的矩阵才需要第五步——这种情况在 n≥4 时才可能出现。

**常见陷阱**：特征多项式相同 ⇏ 相似！反例：I₂ 和 J₂(1)=`[[1,1],[0,1]]` 都有特征多项式 (λ-1)²，但不相似。极小多项式相同也 ⇏ 相似！反例：diag(J₂(1),J₂(1)) 和 diag(J₃(1),J₁(1)) 都有特征多项式 (λ-1)⁴ 和极小多项式 (λ-1)³，但不相似。必须用完整的不变量系统。

### 7.3 应用一：动力系统的相似化简

考虑离散动力系统 x_{k+1}=Ax_k。如果 A=PDP⁻¹（可对角化），那么 x_k=PDᵏP⁻¹x₀，长期行为由最大特征值决定。

如果 A 不可对角化，若尔当标准形 J=P⁻¹AP 给出 x_k=PJᵏP⁻¹x₀。若尔当块 J_m(λ) 的 k 次幂是：

J_m(λ)^k = [[λᵏ, C(k,1)λᵏ⁻¹, ..., C(k,m-1)λᵏ⁻ᵐ⁺¹],              [0, λᵏ, ..., C(k,m-2)λᵏ⁻ᵐ⁺²],              [...,              [0, ..., λᵏ]]

这说明亏损矩阵的迭代行为比可对角化矩阵更复杂——除了指数增长 λᵏ，还有多项式因子 C(k,j)λᵏ⁻ʲ。当 |λ|=1 时，可对角化矩阵有界，但亏损矩阵会多项式增长（无界）。

相似化简的意义：将 A 化为若尔当标准形后，动力系统的行为可以逐块分析，每个若尔当块对应一个"广义不变方向"上的伸缩+剪切行为。

### 7.4 应用二：控制论中的能控标准形

在控制理论中，线性系统 ẋ=Ax+Bu 的能控性与 A 的有理标准形密切相关。

如果系统完全能控，那么存在坐标变换（相似变换）将 (A,B) 化为能控标准形：A 是友矩阵，B=[0,...,0,1]ᵀ。能控标准形就是有理标准形的一种特殊形式——它将系统矩阵化为友矩阵，使控制输入直接作用在"最后一个状态"上。

能控标准形的意义：(1) 简化控制器设计（极点配置可以直接在友矩阵上进行）；(2) 能控性判据可以用标准形的结构来表达；(3) 系统的传递函数可以直接从友矩阵的系数读出。

这是相似标准形在工程中的典型应用：通过相似变换将系统化为"标准结构"，在标准结构下分析和设计变得简单，再通过逆变换回到原坐标系。

### 7.5 应用三：马尔可夫链与 PageRank

马尔可夫链的转移矩阵 P 是随机矩阵（每行和为 1）。稳态分布 π 满足 πP=π，即 π 是 Pᵀ 的特征值 1 对应的特征向量。

如果马尔可夫链是不可约且非周期的，那么 P 的特征值 1 的代数重数为 1，且其他特征值的模都小于 1。此时 P 可以对角化（或化为若尔当形），迭代 Pᵏ 收敛到秩 1 矩阵（每行都是稳态分布）。

PageRank 算法的核心就是计算巨大转移矩阵的主特征向量（特征值 1 对应的特征向量）。由于矩阵维度巨大（数十亿网页），直接计算特征分解不现实，而是用幂迭代法——利用相似变换的思想，将矩阵投影到主特征子空间上。

相似标准形在这里的作用是理论分析：它告诉我们幂迭代的收敛速度由第二大特征值（按模）决定，收敛率是 |λ₂/λ₁|ᵏ。这为算法设计和参数选择提供了理论依据。

## 退化与边界：标准形的适用范围

### 8.1 不可对角化矩阵的处理

不是所有矩阵都可以对角化。亏损矩阵（几何重数<代数重数）的存在说明对角形不是通用的标准形。

处理不可对角化矩阵的层次：

1. **三角化**（舒尔定理）：所有复矩阵都可以酉相似于上三角矩阵。这是通用的，但上三角矩阵的结构不够规范（非对角元可以任意）。

2. **有理标准形**：所有矩阵（任意域）都相似于友矩阵的分块对角。结构规范，但友矩阵的几何意义不如若尔当块直观。

3. **若尔当标准形**：所有复矩阵都相似于若尔当块的分块对角。结构最清晰，是相似分类的"终极答案"。F6 将系统展开。

这三种标准形各有适用场景：三角化适合理论证明（如谱定理），有理标准形适合任意域上的代数计算，若尔当形适合复矩阵的深入分析。

### 8.2 非方阵的等价标准形

相似只对方阵有定义（因为 P⁻¹AP 要求 A 是方阵）。对于 m×n 非方阵矩阵，相应的概念是"等价"（相抵）：B=PAQ，P,Q 可逆。

等价标准形定理：任何秩为 r 的 m×n 矩阵 A 都等价于 [[Iᵣ, 0],[0, 0]]，其中 Iᵣ 是 r 阶单位矩阵。

几何意义：等价变换对应"对定义域和值域分别换基"。在适当的基下，任何线性变换都可以表示为"前 r 个坐标恒等，其余坐标映为零"的简单形式。

等价标准形只由秩决定——秩是等价关系下的完备不变量。这比相似分类简单得多（相似需要完整的不变因子系统），因为等价允许定义域和值域用不同的基，自由度更大。

奇异值分解（SVD）是等价标准形的"加强版"：要求 P 和 Q 是正交矩阵，此时标准形是 diag(σ₁,...,σᵣ, 0,...,0)，其中 σᵢ 是奇异值。SVD 是 F7（矩阵分解）的核心。

### 8.3 合同 vs 相似：二次型的标准形

合同变换 B=PᵀAP 是二次型理论中的等价关系。合同标准形是对角矩阵 diag(1,...,1,-1,...,-1,0,...,0)，其中正 1 的个数是正惯性指数，负 1 的个数是负惯性指数。

合同与相似的关键区别：

• 相似保持特征值，合同不保持特征值（但保持惯性指数） • 相似用于"同一个变换的不同表示"，合同用于"同一个二次型的不同表示" • 相似标准形由不变因子决定，合同标准形由惯性指数决定 • 当 P 是正交矩阵时，P⁻¹=Pᵀ，此时相似=合同（正交相似=正交合同）

对称矩阵的正交对角化（谱定理）同时是相似标准形和合同标准形——因为正交矩阵满足 P⁻¹=Pᵀ。这是对称矩阵的特殊性质：它的特征向量基既是"变换的不变方向基"（相似），又是"二次型的主轴基"（合同）。

### 8.4 实矩阵的复相似 vs 实相似

一个微妙的问题：两个实矩阵如果在复数域上相似（存在复可逆矩阵 P 使得 B=P⁻¹AP），它们是否一定在实数域上相似（存在实可逆矩阵 Q）？

答案是肯定的：如果两个实矩阵复相似，那么它们也实相似。这是因为实矩阵的有理标准形只涉及实系数多项式的运算，不依赖于复数域。如果复相似，则不变因子相同（不变因子是实系数的），所以实相似。

但实矩阵的若尔当标准形可能涉及复特征值（共轭成对出现）。在实数域上，对应的若尔当块需要替换为"实若尔当块"——形如 `[[a,-b],[b,a]]` 的 2×2 块（对应复特征值 a±bi），这是实相似标准形的形式。

几何上，这对应于"实空间中的旋转变换没有实的不变方向，但有二维不变子空间（旋转平面）"。实若尔当块描述了"在二维平面上的旋转+伸缩"行为。

### 8.5 标准形理论的边界与推广

**无穷维空间**：在无穷维空间中，算子的"标准形"理论要复杂得多。紧算子有类似若尔当形的谱分解，但一般算子可能有连续谱、剩余谱等，不存在简单的标准形。这是泛函分析的研究领域。

**非线性变换**：相似是线性变换的概念。对于非线性变换，相应的概念是"微分同胚共轭"（拓扑共轭或光滑共轭）。哈特曼-格罗布曼定理说：双曲不动点附近的非线性变换拓扑共轭于其线性化（雅可比矩阵）。这是线性标准形在非线性领域的推广。

**矩阵束**：对于矩阵对 (A,B)（广义特征值问题 Ax=λBx），相应的标准形是克罗内克标准形。它推广了若尔当标准形，包含了"奇异块"（对应 B 不可逆的情况）。这在广义特征值问题和微分代数方程中有重要应用。

这些推广说明：标准形的思想（在等价关系下找最简代表）是数学中的普遍方法，但具体的标准形取决于所研究的对象和等价关系。

## 实物验证：三个具体实例

### 9.1 实例一：相似验证与换基矩阵

**设置**：A=`[[2,1],[0,3]]`，B=`[[3,0],[1,2]]`。验证 A 和 B 是否相似，如果相似，求 P 使得 B=P⁻¹AP。

**第一步**：检查相似不变量。det(A)=6, det(B)=6 ✓。tr(A)=5, tr(B)=5 ✓。特征多项式：det(λI-A)=(λ-2)(λ-3)=λ²-5λ+6；det(λI-B)=(λ-3)(λ-2)=λ²-5λ+6 ✓。

**第二步**：A 有两个不同特征值 2 和 3，所以可对角化。A 的特征向量：对 λ=2，(A-2I)v=0 → `[[0,1],[0,1]]`v=0 → v=(1,0)。对 λ=3，(A-3I)v=0 → `[[-1,1],[0,0]]`v=0 → v=(1,1)。

B 的特征向量：对 λ=3，(B-3I)v=0 → `[[0,0],[1,-1]]`v=0 → v=(1,1)。对 λ=2，(B-2I)v=0 → `[[1,0],[1,0]]`v=0 → v=(0,1)。

**第三步**：A 的特征向量矩阵 P_A=`[[1,1],[0,1]]`，B 的特征向量矩阵 P_B=`[[1,0],[1,1]]`。A=P_A D P_A⁻¹，B=P_B D P_B⁻¹，其中 D=diag(2,3)。所以 B=(P_B P_A⁻¹)⁻¹ A (P_B P_A⁻¹)。

计算 P=P_B P_A⁻¹：P_A⁻¹=`[[1,-1],[0,1]]`，P=`[[1,0],[1,1]]``[[1,-1],[0,1]]`=`[[1,-1],[1,0]]`。验证 P⁻¹AP=B ✓。

**几何解读**：A 和 B 是同一个变换在不同基下的表示。P 的列是"B 的基在 A 的基下的坐标"。两个矩阵都可对角化且特征值相同，所以相似。

### 9.2 实例二：不相似的矩阵（特征多项式相同）

**设置**：A=I₂=`[[1,0],[0,1]]`，B=J₂(1)=`[[1,1],[0,1]]`。它们的特征多项式都是 (λ-1)²，但不相似。

**证明不相似**：

方法一（极小多项式）：m_A(x)=x-1（因为 A-I=0），m_B(x)=(x-1)²（因为 B-I≠0 但 (B-I)²=0）。极小多项式不同 ⇒ 不相似。

方法二（几何重数）：对 λ=1，A 的几何重数=dim N(A-I)=dim N(0)=2；B 的几何重数=dim N(B-I)=dim N(`[[0,1],[0,0]]`)=1。几何重数不同 ⇒ 不相似。

方法三（秩）：rank(A-I)=0，rank(B-I)=1。rank(A-λI) 是相似不变量 ⇒ 不相似。

**几何解读**：A 是恒等变换（所有方向都是不变方向，伸缩因子 1），B 是剪切+恒等（只有 (1,0) 方向是不变方向，(0,1) 方向被剪切）。虽然特征值都是 1（二重），但变换的本质行为不同——一个是纯伸缩，一个是伸缩+剪切。这说明特征多项式相同不足以判定相似。

### 9.3 实例三：有理标准形的计算

**设置**：A=`[[0,-1,0],[1,0,0],[0,0,2]]`。这是一个 3×3 矩阵，前 2×2 块是 90°旋转，第 3 个分量是伸缩 2 倍。

**特征多项式**：det(λI-A)=det [[λ,1,0],[-1,λ,0],[0,0,λ-2]]=(λ²+1)(λ-2)=λ³-2λ²+λ-2。

**极小多项式**：A 的前 2×2 块 C 满足 C²=-I，极小多项式 λ²+1；第 3 个分量 2 满足 (A-2I) 的第 3 行为 0，极小多项式 λ-2。因为 λ²+1 和 λ-2 互素，所以 A 的极小多项式是 (λ²+1)(λ-2)=λ³-2λ²+λ-2=特征多项式。

**不变因子**：因为极小多项式=特征多项式（3次），所以只有一个不变因子 d₁=λ³-2λ²+λ-2。有理标准形是 3 阶友矩阵 C(d₁)：

C(d₁) = `[[0,0,2],[1,0,-1],[0,1,2]]`

验证：C(d₁) 的特征多项式是 λ³-2λ²+λ-2 ✓，极小多项式也是 λ³-2λ²+λ-2 ✓。A 和 C(d₁) 有相同的不变因子 ⇒ 相似。

**几何解读**：A 的空间可以分解为一个 2 维循环子空间（旋转平面，零化多项式 λ²+1）和一个 1 维循环子空间（伸缩方向，零化多项式 λ-2）。但因为这两个零化多项式互素，整个空间实际上是一个 3 维循环子空间——存在一个向量 v 使得 {v, Av, A²v} 构成基。有理标准形就是在这个循环基下的矩阵表示。

### 10.2 常见误区与反例

**误区一**："特征多项式相同的矩阵相似。" → 反例：I₂ 和 J₂(1) 都有特征多项式 (λ-1)²，但不相似。

**误区二**："特征值相同的矩阵相似。" → 反例同上。特征值（含代数重数）相同只是相似的必要条件，不是充分条件。

**误区三**："相似矩阵的特征向量相同。" → 相似矩阵的特征值相同，但特征向量一般不同（因为基不同）。如果 B=P⁻¹AP，v 是 A 的特征向量，则 P⁻¹v 是 B 的特征向量。

**误区四**："所有矩阵都可以对角化。" → 反例：J₂(1) 亏损，不可对角化。需要若尔当标准形。

**误区五**："相似和合同是一回事。" → 相似是 B=P⁻¹AP（同一个变换），合同是 B=PᵀAP（同一个二次型）。只有 P 正交时才相同。

**误区六**："有理标准形需要求特征值。" → 有理标准形只用到多项式的整除和初等变换，不需要求根，在任意域上都有效。这是它与若尔当形的关键区别。

## 总结与展望

**F5 核心结论**：相似变换的几何本质是"同一线性变换在不同基下的矩阵表示"，B=P⁻¹AP 中的 P 是"基翻译器"。相似是等价关系，将所有 n×n 矩阵划分为若干等价类，每个等价类对应一个"本质相同的变换"。相似不变量（迹、行列式、特征多项式、秩、极小多项式、不变因子、初等因子）是等价类的"指纹"，其中不变因子和初等因子构成完备不变量系统。标准形理论在等价类中寻找最简代表：对角形是可对角化矩阵的最强简化；三角化（舒尔定理）是所有复矩阵的通用简化；有理标准形是不依赖特征值的纯代数标准形（任意域有效）。F5 是领域一的"分类层"，它承接 F4 的特征理论，为 F6（若尔当标准形）提供完整的分类框架。
