## 研究摘要

**核心命题**：基不是一组向量，而是一种"测量协议"——它决定了空间中每一个向量如何被赋予坐标、每一个线性变换如何被写成矩阵。高等代数中一切"矩阵的长相"都是基的选择的产物；换基不改变向量与变换本身，只改变它们的"地址"与"照片"。

**研究问题**：(RQ1) 基的几何本质是什么？为什么"线性无关+张成空间"这两个条件恰好刻画了"坐标系"？(RQ2) 坐标变换公式 x' = P⁻¹x 的几何意义是什么？为什么过渡矩阵必须可逆？(RQ3) 基的选择如何系统性地改变矩阵的形态——相似、合同、正交化分别对应怎样的"换基视角"？

**研究方法**：本模块采用"几何优先"的解析路径——每一个代数定义先还原为几何操作，再用三个实物实例（R² 斜基坐标、2×2 换基矩阵手算、Gram-Schmidt 正交化数值验证）锚定结论。所有数值经 Python 3 + numpy 复算。

**核心结论**：基是三核互译的"开关"——矩阵（代数表示）与线性变换（几何过程）之间的翻译必须经由基完成；可逆矩阵的本质是"合法的基变换"；正交基是"最友好的坐标系"，它使坐标等于投影长度、使矩阵的转置等于逆。F1 是领域一的入口，也是整个高等代数几何视域的第一把钥匙。

**一句话定位**：基是高等代数的"坐标系协议"——理解了基，就理解了为什么同一个变换在不同课本里看起来像完全不同的矩阵。

## 引言：为什么从基开始

### 1.1 一个令人困惑的现象

每一个学过线性代数的人都经历过这样的困惑：同一个线性变换，在一本教材里是对角矩阵，在另一本教材里却是充满非零元的一般矩阵；同一个二次型，在标准基下是 x²+4xy+5y²，换一组基后却变成了 u²+v²——仿佛数学对象本身在变。

这种困惑的根源不在于教材的矛盾，而在于一个被大多数课程轻描淡写带过的概念：**基（basis）**。矩阵不是变换本身，而是变换在某一组基下的"照片"；换一组基，就是换一个角度拍照，照片自然不同，但被拍的对象从未改变。

### 1.2 基是三核互译的开关

在本研究的三核架构中，矩阵、线性空间、线性变换三者可以相互转化。但这个转化不是无条件的——**它必须经由"基"这个开关完成**：

**线性空间 → 矩阵**：选定基后，每个向量获得坐标（一列数），空间变成 Rⁿ； **线性变换 → 矩阵**：选定基后，变换的作用被记录为矩阵乘法； **矩阵 → 线性变换**：矩阵的列就是标准基向量在变换下的像。

没有基，矩阵只是一堆无意义的数；有了基，矩阵才获得几何生命。这就是 F1 必须作为领域一入口的根本原因。

### 1.3 本模块的研究路径

本模块不走"定义→定理→证明"的传统路径，而是采用**几何还原法**：每一个代数概念先问"它在几何上是什么操作"，再回到代数语言精确表述。具体路径如下：

## 基的几何本质：从"尺子"到"坐标系"

### 2.1 基不是一组向量，是一种"测量协议"

大多数教材对基的定义是："线性无关且张成整个空间的一组向量"。这个定义在代数上精确，但在几何上是被动的——它只说了基"满足什么条件"，没说基"是什么"。

从几何视角看，**基是一种测量协议**。想象你要描述平面上一个点的位置：你需要先选两个方向（x 轴、y 轴），再在每个方向上选一个单位长度。这两个"方向+单位"的组合，就是一组基。有了它，平面上每一个点都能被唯一地赋予一对数（坐标）。

基的本质不是"那两个箭头"，而是"用这两个箭头去测量一切向量的协议"。换一组基，就是换一套测量工具——就像用英尺还是米来量长度，物体本身没变，但数字变了。

### 2.2 线性无关的几何含义

"线性无关"在代数上是说：不存在不全为零的系数使线性组合为零。在几何上，它的含义要直观得多：

**R² 中**：两个向量线性无关 ⇔ 它们不共线（不平行）。如果共线，那么一个方向上的信息是冗余的——你无法用两个同方向的尺子去测量平面上的所有点。

**R³ 中**：三个向量线性无关 ⇔ 它们不共面。如果共面，那么第三个向量无法提供"离开这个平面"的测量能力。

**一般地**：线性无关 ⇔ 没有一个向量能被其他向量的组合替代。每一个基向量都提供了一个"独立的测量方向"，缺一个就少一个维度的测量能力。

### 2.3 张成空间：基能"覆盖"的范围

"张成空间"（span）是基的另一个条件。几何上，张成空间就是"用这组基向量能到达的所有位置"。

在 R² 中，两个不共线的向量的张成空间是整个平面——因为平面上任何点都可以表示为这两个方向的组合。但如果两个向量共线，它们的张成空间只是一条直线——你无法用同方向的两把尺子到达直线外的点。

**基的两个条件合在一起的几何意义**：线性无关保证"每个测量方向都是独立的、不冗余的"；张成整个空间保证"测量范围覆盖全部对象"。两者结合，恰好就是"一套完整的坐标系"——不多不少，刚好够用。

**几何命题**：一组向量构成基 ⇔ 它们恰好提供了 n 个独立的测量方向，且这些方向的组合能到达空间中的每一个点。这是"坐标系"这个直觉概念的精确代数表述。

### 2.4 维数：基的大小=空间的"自由度"

一个空间的维数，就是它的任意一组基中向量的个数。几何上，维数是空间的"自由度"——你需要多少个独立的数才能确定一个点。

R² 的维数是 2：你需要两个数（x, y）。R³ 的维数是 3：你需要三个数（x, y, z）。一条直线的维数是 1：你只需要一个数（沿直线的位置）。一个点的维数是 0：你不需要任何数（它已经确定了）。

**维数不变性定理**：同一个空间的任意两组基，向量个数一定相同。这在几何上是显然的——一个平面不可能有时需要 2 个数、有时需要 3 个数来描述。但这个"显然"在代数上需要证明，而证明的核心就是线性无关与张成的交互作用。

### 2.5 标准基：为什么它是"默认坐标系"

在 Rⁿ 中，标准基 e₁=(1,0,...,0), e₂=(0,1,0,...,0), ..., eₙ=(0,...,0,1) 是最常用的基。它的几何优势是：每个基向量恰好对应一个坐标轴，且长度为 1、两两垂直。

在标准基下，一个向量的坐标就是它本身——(3, 5) 的坐标就是 (3, 5)。这种"自指性"让标准基成为代数计算的默认选择。但必须记住：**标准基只是无数组基中的一组，没有任何几何上的特权**。在很多问题中（如特征值问题），非标准基反而更自然。

一个深刻的视角：**矩阵的列就是标准基向量在该矩阵对应的线性变换下的像**。这是 F1 与 F2（矩阵运算）之间最核心的接口，将在第 5 章展开。

### 2.6 基的"非唯一性"：这不是缺陷，是自由

初学者常问："既然基不唯一，那哪一组基是'对的'？"答案是：**没有哪一组基是绝对对的，每一组基都是一个合法的视角**。

基的非唯一性恰恰是线性代数最强大的地方——它允许我们"换角度看问题"。一个在标准基下看起来复杂的矩阵，换到特征向量基下可能变成对角矩阵；一个在斜基下计算繁琐的内积，换到正交基下可能变成简单的点积。**选择合适的基，是线性代数中最核心的解题策略之一**。

这也解释了为什么"相似变换"（P⁻¹AP）如此重要——它不是什么神秘的代数操作，而是"换一组基来看同一个变换"。相似矩阵是同一个变换的不同"照片"，它们共享变换本身的所有本质属性（特征值、行列式、迹），只是"拍摄角度"不同。

## 坐标：向量在基下的"地址"

### 3.1 坐标是向量与基之间的"翻译表"

给定一组基 B = {v₁, v₂, ..., vₙ}，空间中任意向量 x 可以唯一表示为 x = a₁v₁ + a₂v₂ + ... + aₙvₙ。系数 (a₁, a₂, ..., aₙ) 就是 x 在基 B 下的坐标，记作 [x]B。

几何上，坐标是向量在基下的"地址"——就像你在城市中的位置可以用"第几街第几大道"来描述一样，向量在空间中的位置可以用"在 v₁ 方向上走 a₁、在 v₂ 方向上走 a₂"来描述。

**关键洞察**：坐标不是向量本身，而是向量在特定基下的"表示"。同一个向量，在不同基下有不同的坐标，就像同一个位置在不同的街道命名系统下有不同的地址。向量是几何对象，坐标是代数记录——两者通过基建立翻译关系。

### 3.2 坐标唯一性定理及其几何意义

**定理**：若 B 是一组基，则每个向量在 B 下的坐标是唯一的。

这个定理在代数上的证明很简单：若 x = Σaᵢvᵢ = Σbᵢvᵢ，则 Σ(aᵢ-bᵢ)vᵢ = 0，由线性无关得 aᵢ=bᵢ。但它的几何意义更深刻：

**坐标唯一性 = 地址系统的良定义性**。如果坐标不唯一，就意味着同一个位置可以有两个不同的地址——这会让整个测量协议失效。基的线性无关条件，正是保证地址唯一性的代数机制。

反过来，如果一组向量线性相关，那么某些向量的坐标就不唯一——你可以用不同的系数组合得到同一个向量。这就是为什么"线性相关的向量组不能作为基"的几何原因：它无法提供唯一的地址系统。

### 3.3 坐标的运算：线性结构的保持

坐标映射 [·]B: V → Rⁿ 不仅仅是一个翻译，它还保持线性结构：

[x + y]B = [x]B + [y]B [kx]B = k[x]B

几何上，这意味着"在空间中走两步"等价于"把两个地址相加"，"把向量放大 k 倍"等价于"把地址放大 k 倍"。坐标映射是一个线性同构——它在保持所有线性关系的前提下，把抽象的向量空间变成了具体的 Rⁿ。

这是高等代数中最深刻的事实之一：**任何 n 维线性空间都与 Rⁿ 线性同构**。这意味着，在选定基之后，所有 n 维空间的"代数行为"都是一样的——它们的区别只在几何解释（是 Rⁿ 本身、是多项式空间、还是矩阵空间），但坐标化之后，计算规则完全统一。

**耦合索引 → S2（线性空间·基与维数）**：坐标同构定理是"所有 n 维空间本质相同"这一命题的代数证明。在领域二中，这个定理将被用来解释为什么线性空间的分类只由维数决定。

### 3.4 斜基下的坐标：直觉的校准

在标准基下，坐标 (a, b) 对应"向右 a、向上 b"。但在斜基下，坐标的几何解释需要校准。

考虑 R² 中的斜基 v₁=(2,0), v₂=(1,1)。向量 x=(3,1) 在这组基下的坐标是什么？解方程 a(2,0)+b(1,1)=(3,1)，得 a=1, b=1。所以 [x]B=(1,1)。

注意：x 的标准坐标是 (3,1)，但斜基坐标是 (1,1)。**同一个向量，两组坐标，数值完全不同**。这就是"基决定地址"的最直接演示。斜基下的坐标不再对应"水平/垂直位移"，而是对应"沿 v₁ 方向/沿 v₂ 方向的位移"。

### 3.5 坐标与内积：为什么正交基更友好

在一般基下，两个向量的内积不等于它们坐标的点积。例如斜基 v₁=(2,0), v₂=(1,1)，向量 x=(1,1)B（即坐标 (1,1)）和 y=(1,0)B 的内积是 ⟨2v₁+v₂, v₁⟩ = 2⟨v₁,v₁⟩+⟨v₂,v₁⟩ = 2×4+2 = 10，但坐标点积是 1×1+1×0=1。

但在正交基下，内积等于坐标点积——因为 ⟨Σaᵢvᵢ, Σbⱼvⱼ⟩ = Σaᵢbᵢ⟨vᵢ,vᵢ⟩，若 vᵢ 两两正交且长度为 1，则 ⟨vᵢ,vᵢ⟩=1、⟨vᵢ,vⱼ⟩=0（i≠j），内积就简化为 Σaᵢbᵢ。

这就是正交基"友好"的根本原因：**它让几何操作（内积、长度、角度）与代数操作（坐标点积、范数、余弦）直接对应**。在非正交基下，这种对应被"度量矩阵"G=(⟨vᵢ,vⱼ⟩) 扭曲，计算变得繁琐。第 7 章将深入展开。

## 换基：坐标变换的几何

### 4.1 过渡矩阵：从一个坐标系到另一个坐标系的"地图"

设 B = {v₁,...,vₙ} 和 B' = {w₁,...,wₙ} 是空间 V 的两组基。每个 wⱼ 都可以用 B 表示：wⱼ = p₁ⱼv₁ + p₂ⱼv₂ + ... + pₙⱼvₙ。系数矩阵 P = (pᵢⱼ) 称为从 B 到 B' 的过渡矩阵。

几何上，P 的第 j 列就是新基向量 wⱼ 在旧基 B 下的坐标。所以 P 记录了"新坐标系的每一根轴在旧坐标系下指向哪里"——它是两张坐标系之间的"地图"。

**关键性质**：过渡矩阵 P 必须可逆。因为如果 P 不可逆，那么新基向量 wⱼ 在旧基下的坐标线性相关，意味着 wⱼ 本身线性相关——但 B' 是基，必须线性无关。所以 P 可逆是"新基确实是一组基"的代数签名。

### 4.2 坐标变换公式：x' = P⁻¹x 的几何解读

设向量 x 在旧基 B 下的坐标为 x（列向量），在新基 B' 下的坐标为 x'。则坐标变换公式为：**x = P x'**，即 **x' = P⁻¹x**。

这个公式的几何意义常常被误解。让我们拆解：x = P x' 的意思是"新坐标 x' 经过 P 的翻译，变成旧坐标 x"。因为 P 的列是新基向量在旧基下的坐标，所以 P x' = Σ x'ⱼ (P 的第 j 列) = Σ x'ⱼ [wⱼ]B = [Σ x'ⱼwⱼ]B = [x]B = x。

**几何直觉**：换基时，向量本身不动，是坐标系在变。坐标从 x 变成 x' = P⁻¹x，就像你从"用英尺描述身高"换成"用米描述身高"——身高没变，但数字变了，转换因子就是 P⁻¹。

### 4.3 换基不改变向量本身：几何不变量

换基操作中，**向量本身是不变的**——它在空间中的位置、长度、与其他向量的夹角都不依赖于基的选择。改变的只是它的"地址"（坐标）。

这引出了高等代数中一个核心的哲学区分：**什么是"几何对象"，什么是"代数表示"**。向量、线性变换、子空间是几何对象——它们不依赖基。坐标、矩阵、行列式是代数表示——它们依赖基的选择。好的数学应该关注几何对象本身，而代数表示只是我们用来计算的工具。

这个区分在后续模块中反复出现：特征值是几何不变量（不随基变化），但特征向量的坐标依赖基；行列式是几何不变量（体积缩放因子），但矩阵的具体元素依赖基；秩是几何不变量（像空间的维数），但矩阵的行/列形式依赖基。**F1 的核心训练之一，就是学会区分"什么在换基下不变，什么在变"**。

**不变量清单（换基下保持不变的量）**：向量本身、线性变换本身、子空间、维数、秩、行列式、特征值、迹、内积（在正交基下）、长度和角度（在正交基下）。 **变化的量**：坐标、矩阵的具体元素、矩阵的非对角元（一般情况下）。

### 4.4 换基的"主动"与"被动"视角

换基有两种等价的思考方式，初学者常混淆：

**被动视角（坐标系变换）**：向量不动，坐标系变。坐标从 x 变成 P⁻¹x。这是"换基"的本义。

**主动视角（向量变换）**：坐标系不动，向量被 P 作用。x → P x。这是"线性变换"的视角。

两种视角的数学表达式互为逆操作：被动是 x' = P⁻¹x，主动是 x' = P x。它们描述的是同一个代数关系的两种几何解释。**这种"主动-被动"对偶性是线性代数的深层结构之一**，在 T1（变换的矩阵表示）中将进一步展开。

### 4.5 实物：R² 中换基的手算

旧基 B = {e₁=(1,0), e₂=(0,1)}（标准基），新基 B' = {w₁=(1,1), w₂=(-1,1)}。

过渡矩阵 P 的列是 w₁, w₂ 在 B 下的坐标：P = `[[1,-1],[1,1]]`。P⁻¹ = (1/2)`[[1,1],[-1,1]]`。

向量 x=(2,0) 在 B 下坐标为 (2,0)。在 B' 下坐标为 P⁻¹(2,0)ᵀ = (1, -1)ᵀ。验证：1·w₁ + (-1)·w₂ = (1,1)-(-1,1) = (2,0) ✓。

几何解读：新基 w₁, w₂ 是旋转 45° 后的坐标轴（且长度为 √2）。向量 (2,0) 在新坐标系下的坐标是 (1,-1)——它在 w₁ 方向上走 1 个单位、在 w₂ 反方向上走 1 个单位。

## 基与矩阵的第一次握手

### 5.1 矩阵的列空间：列向量张成的空间

一个 m×n 矩阵 A 的列空间 C(A) 是 A 的列向量张成的 Rᵐ 子空间。几何上，C(A) 是"A 能把 Rⁿ 中的向量送到的所有位置"——即 A 作为线性映射的值域。

**耦合索引 → F4（特征理论）**：列空间是 A 的"像"，它与核空间 N(A) 一起构成秩-零化度定理的两端。在 F4 中，特征向量将被理解为"在 A 的作用下方向不变的向量"，而列空间则是"A 作用后能到达的范围"。

### 5.2 矩阵作为"基的变换"：A 的列是标准基的像

这是 F1 最核心的洞察之一：**矩阵 A 的第 j 列，就是标准基向量 eⱼ 在 A 对应的线性变换下的像 A(eⱼ)**。

为什么？因为 A eⱼ 就是 A 的第 j 列（矩阵乘法的定义）。所以，当你看到一个矩阵时，你可以逐列"读"出它对每一根标准坐标轴做了什么：第一列告诉你 x 轴被送到了哪里，第二列告诉你 y 轴被送到了哪里，以此类推。

这个视角让矩阵从"一堆数"变成了"一组变换后的基向量"。例如矩阵 `[[1,1],[0,1]]`（剪切阵）的列是 (1,0) 和 (1,1)——x 轴不动，y 轴被向右推了 1 个单位。这就是剪切变换的几何图像。

**记忆锚点**：矩阵的列 = 标准基的像。读矩阵 = 读"每根坐标轴被送到了哪里"。这是从"矩阵是数表"到"矩阵是几何变换"的认知跃迁。

### 5.3 可逆矩阵 = 基变换：A 可逆 ⇔ A 的列构成一组基

**定理**：对 n×n 方阵 A，以下命题等价：(1) A 可逆；(2) A 的列线性无关；(3) A 的列构成 Rⁿ 的一组基；(4) C(A)=Rⁿ；(5) N(A)={0}；(6) det(A)≠0；(7) Ax=b 对任意 b 有唯一解。

这个等价定理是 F1 的"枢纽定理"——它把可逆性、线性无关、基、列空间、核空间、行列式、解的存在唯一性全部串联起来。几何上，**可逆矩阵就是"合法的基变换"**：它把标准基送到一组新基（A 的列），且这个变换是可逆的（存在逆变换把新基送回标准基）。

反过来，奇异矩阵（不可逆）就是"不合法的基变换"：它把标准基送到一组线性相关的向量，意味着至少有一个维度被"压掉"了。奇异矩阵对应的变换是坍缩性的——它把高维空间压到低维子空间，信息不可逆地丢失了。

| 性质 | 可逆矩阵（基变换） | 奇异矩阵（坍缩） |
|---|---|---|
| 列的关系 | 线性无关，构成基 | 线性相关，不构成基 |
| 列空间 | = Rⁿ（满射） | ⊊ Rⁿ（非满射） |
| 核空间 | = {0}（单射） | ⊋ {0}（非单射） |
| 几何效果 | 坐标系的合法变换 | 空间的坍缩/投影 |
| 信息 | 可逆，无信息丢失 | 不可逆，信息丢失 |
| 行列式 | ≠ 0（体积缩放因子非零） | = 0（体积被压为零） |

### 5.4 矩阵乘法的几何：复合变换

矩阵乘法 AB 的几何意义是"先做 B 变换，再做 A 变换"——即线性映射的复合。从基的视角看：B 把标准基送到 B 的列，然后 A 把这些像再送到 A(B(eⱼ)) = AB 的第 j 列。

所以 AB 的第 j 列 = A × (B 的第 j 列)。这个规则让矩阵乘法从"行列点积"的机械操作变成了"变换的复合"的几何操作。

**耦合索引 → F2（矩阵运算与分块）**：矩阵乘法的复合语义是 F2 的核心。分块矩阵则是"把子空间当作整体来变换"——这是基的分块视角的自然延伸。

### 5.5 逆矩阵的几何：把基送回去

A⁻¹ 的几何意义是"A 变换的逆变换"——如果 A 把标准基送到新基 {Ae₁,...,Aeₙ}，那么 A⁻¹ 把这组新基送回标准基。

在换基语境中，A⁻¹ 就是"从新基回到旧基"的过渡矩阵。这也解释了为什么坐标变换公式是 x' = P⁻¹x 而不是 x' = Px：P 把新基的坐标"翻译"成旧基坐标，P⁻¹ 则反过来。

逆矩阵存在 ⇔ A 的列构成基 ⇔ 变换是双射。这三个等价表述从代数、几何、集合论三个角度描述了同一件事：**这个变换没有丢失任何信息，可以完全还原**。

## 基的选择如何改变矩阵的"长相"

### 6.1 同一个变换，不同基下有不同矩阵

设 T: V→V 是线性变换，B 和 B' 是 V 的两组基，P 是从 B 到 B' 的过渡矩阵。则 T 在 B 下的矩阵 A 和在 B' 下的矩阵 A' 满足：**A' = P⁻¹AP**。

这个公式的几何解读：AP 把"新基下的坐标"先翻译成"旧基下的坐标"（P），然后用旧基下的矩阵 A 作用，最后 P⁻¹ 把结果翻译回新基坐标。三步合起来，就是变换在新基下的矩阵 A'。

**核心洞察**：A 和 A' 是同一个变换的不同"照片"。它们的特征值、行列式、迹完全相同（这些是变换本身的属性），但矩阵的具体元素、是否对角化、是否稀疏，都取决于基的选择。**选择合适的基，可以让矩阵变得尽可能简单**——这就是特征值分解、若尔当标准形、SVD 等理论的根本动机。

### 6.2 相似变换 P⁻¹AP：换基看变换

相似变换是"换基看线性变换"的代数表达。两个矩阵相似 ⇔ 它们是同一个线性变换在不同基下的矩阵。

相似不变量（在相似变换下保持不变的量）：特征多项式、特征值、行列式、迹、秩、最小多项式。这些量刻画的是变换本身，与基无关。

相似变换的终极目标是找到一组基，使变换在该基下的矩阵最简单。如果变换可对角化，最简单的形式就是对角矩阵（特征向量基）。如果不可对角化，最简单的形式是若尔当标准形（广义特征向量基）。**整个 F5（相似与标准形）和 F6（若尔当形）都是在回答"如何选基让矩阵最简单"这个问题**。

**耦合索引 → F4/F5/T3**：特征向量基使变换对角化，这是 F4（特征理论）、F5（相似）、T3（特征向量与对角化）三个模块的共同核心。F1 提供"换基"的语言，F4/F5/T3 提供"选什么基"的答案。

### 6.3 合同变换 PᵀAP：换基看二次型

与相似变换并列的另一种"换基"是合同变换：A' = PᵀAP。它出现在二次型的语境中。

二次型 q(x) = xᵀAx 在坐标变换 x = Py 下变为 q(y) = yᵀ(PᵀAP)y。所以合同变换描述的是"换基后二次型的矩阵如何变化"。

**相似 vs 合同的几何区分**：相似变换 P⁻¹AP 关心的是"线性变换在换基下的表示"，保持特征值；合同变换 PᵀAP 关心的是"二次型在换基下的表示"，保持惯性指数（正/负/零特征值的个数）。两者都是换基，但换基的目的不同——一个是为了简化变换，一个是为了简化二次曲面。

当 P 是正交矩阵（Pᵀ=P⁻¹）时，相似与合同重合：P⁻¹AP = PᵀAP。这就是为什么实对称矩阵可以同时对角化（正交对角化）——正交基下，变换视角和二次型视角统一了。

### 6.4 矩阵的"双重身份"：相似与合同

一个方阵 A 有两种几何身份：(1) 作为线性变换的矩阵（相似视角）；(2) 作为二次型的矩阵（合同视角）。这两种身份对应两种不同的换基规则。

这就是本研究"矩阵双重身份"命题的具体呈现。在 F1 中，我们只需要知道这两种身份都存在、都由基的选择决定；在 F4（特征理论）中，我们将看到对称矩阵的两种身份如何在正交基下统一。

**实物锚点**：矩阵 B=`[[2,1],[1,2]]` 作为变换，特征值 3,1，可正交对角化为 diag(3,1)；作为二次型，xᵀBx=2x²+2xy+2y²，在特征向量基下变为 3u²+v²。同一个矩阵，两种身份，同一组基（特征向量基）让两种身份同时简化。

### 6.5 选基的艺术：什么时候用什么基

不同问题需要不同的基：

**标准基**：默认选择，计算简单，但可能不是最有洞察力的。 **特征向量基**：让变换对角化，是分析变换行为的最佳基。 **正交基**：让内积/长度/角度与坐标运算直接对应，是几何计算的最佳基。 **奇异向量基**：让矩阵分解为旋转-伸缩-旋转，是理解矩阵全部几何作用的最佳基。 **广义特征向量基**：不可对角化时的最佳基，给出若尔当标准形。

**选基不是技术细节，而是战略决策**。好的基让问题一目了然，差的基让问题晦涩难懂。高等代数中大量的"标准形"理论，本质上都是"为特定问题寻找最佳基"的理论。

## 正交基与标准正交基：最"友好"的坐标系

### 7.1 正交基的几何优势

正交基是指两两正交（内积为零）的一组基。标准正交基则进一步要求每个基向量长度为 1。

正交基的几何优势是根本性的：在正交基下，**坐标就是投影长度**。具体地，若 {e₁,...,eₙ} 是标准正交基，则向量 x 的第 i 个坐标 = ⟨x, eᵢ⟩——即 x 在 eᵢ 方向上的投影长度。这意味着你可以"独立地"读取每个坐标，不需要考虑基向量之间的相互干扰。

在非正交基下，坐标之间是"耦合"的——改变一个坐标会影响其他坐标的几何意义。正交基消除了这种耦合，让每个坐标轴"各司其职"。这就是为什么在物理、工程、统计中，正交基（尤其是标准正交基）几乎总是首选。

### 7.2 标准正交基与单位球

在标准正交基下，单位球 {x : ||x|| ≤ 1} 的方程就是 Σxᵢ² ≤ 1——一个完美的球。在非正交基下，单位球变成椭球，方程中出现交叉项。

这是正交基"友好性"的另一个体现：它让最基本的几何对象（球、距离、角度）保持最简单的代数形式。在正交基下，两点距离就是坐标差的平方和开根号，两个向量的夹角余弦就是坐标点积除以长度乘积——一切都回到了我们最熟悉的欧几里得公式。

**度量矩阵**：在一般基下，内积由度量矩阵 G=(⟨vᵢ,vⱼ⟩) 决定：⟨x,y⟩ = [x]ᵀ G [y]。在标准正交基下 G=I，内积简化为坐标点积。正交化的过程，本质上就是"把度量矩阵变成单位矩阵"的过程。

### 7.3 Gram-Schmidt 正交化：从任意基到正交基的几何过程

Gram-Schmidt 正交化是把任意一组基变成正交基的标准算法。它的几何过程非常直观：

给定基 {v₁,...,vₙ}，逐步构造正交基 {u₁,...,uₙ}：

**第一步**：u₁ = v₁（第一个方向直接保留）。 **第二步**：u₂ = v₂ - proj_{u₁}(v₂)（把 v₂ 在 u₁ 方向上的分量"削掉"，剩下的部分自然与 u₁ 正交）。 **第三步**：u₃ = v₃ - proj_{u₁}(v₃) - proj_{u₂}(v₃)（把 v₃ 在已有两个正交方向上的分量都削掉）。 ...以此类推。

**几何解读**：Gram-Schmidt 是一个"逐维剥离"的过程——每一步都把新向量在已有正交方向上的投影去掉，只保留"真正新的方向"。这就像建房子时，每一根新梁都要与已有的梁垂直，确保结构稳定。

最后，把每个 uᵢ 除以它的长度 ||uᵢ||，就得到标准正交基。Gram-Schmidt 的矩阵形式就是 QR 分解：A = QR，其中 Q 的列是标准正交基，R 是上三角矩阵（记录了"剥离投影"的系数）。

**耦合索引 → F7（矩阵分解）**：QR 分解是 Gram-Schmidt 的矩阵化，是 F7 的核心分解之一。SVD 则进一步把"正交基"的思想推广到非方阵——左奇异向量和右奇异向量都是标准正交基。

### 7.4 正交矩阵：保持几何的变换

正交矩阵 Q 满足 QᵀQ = I（即 Q⁻¹ = Qᵀ）。它的列构成一组标准正交基。

正交矩阵对应的变换保持内积：⟨Qx, Qy⟩ = ⟨x, y⟩。因此它保持长度、角度、距离——几何上，正交变换就是旋转和反射的组合。它不"拉伸"或"压缩"空间，只是把空间" rigidly "地转动或翻转。

正交矩阵的行列式只能是 +1（旋转）或 -1（反射+旋转）。这是"保持体积且不改变方向"（+1）或"保持体积但翻转方向"（-1）的代数签名。

### 7.5 正交基的局限与边界

正交基虽然友好，但不是万能的：

**不是所有空间都有自然的内积**：正交基依赖内积的定义。在没有内积的纯线性空间中，"正交"没有意义，只能谈一般的基。 **正交基不一定是最有洞察力的基**：例如特征向量基通常不是正交的（除非矩阵对称），但它让变换对角化，这是正交基做不到的。 **正交化可能放大数值误差**：经典 Gram-Schmidt 在数值上不稳定（当基向量接近线性相关时，舍入误差被放大）。实际计算中使用修正 Gram-Schmidt 或 Householder 变换。

**哲学**：正交基是"计算友好"的基，但不一定是"理解深刻"的基。好的研究者知道何时用正交基（做计算）、何时用特征向量基（做分析）、何时用其他基（做特定问题）。

## 基的退化与边界：什么时候"基"不存在

### 8.1 线性相关的几何：向量"挤"在低维子空间

一组向量线性相关，几何上意味着它们"挤"在一个比预期更低维的子空间里。例如 R³ 中三个向量共面，它们的张成空间只是一个二维平面——第三个向量没有提供新的测量方向。

线性相关的代数判据是存在不全为零的系数使线性组合为零。几何上，这意味着"至少有一个向量可以被其他向量的组合替代"——它是冗余的。

**反例簇**：(1) R² 中 {(1,0), (2,0)} 线性相关（共线）；(2) R³ 中 {(1,0,0), (0,1,0), (1,1,0)} 线性相关（共面，第三个=前两个之和）；(3) 包含零向量的任何向量组线性相关（0=1·0+0·...）。

### 8.2 奇异矩阵 = 列不构成基 = 空间坍缩

n×n 方阵 A 奇异（不可逆）⇔ A 的列线性相关 ⇔ A 的列不构成 Rⁿ 的基 ⇔ C(A) ⊊ Rⁿ ⇔ N(A) ⊋ {0}。

几何上，奇异矩阵把 n 维空间"压"到了一个更低维的子空间里。至少有一个非零向量被压成零（核空间非平凡），至少有一个方向"丢失"了。这个过程是不可逆的——你无法从压缩后的结果还原原始信息。

**实物**：矩阵 `[[1,2],[2,4]]` 的列是 (1,2) 和 (2,4)=2(1,2)，线性相关。它把整个 R² 压到直线 y=2x 上。核空间是 {(x,y): x+2y=0}，即直线 y=-x/2——这条直线上的所有向量都被压成零。

### 8.3 无穷维空间的基：概念的边界

在有限维空间中，基是"有限个线性无关且张成空间的向量"。但在无穷维空间（如多项式空间、连续函数空间）中，基的概念需要扩展：

**Hamel 基**：每个向量表示为有限个基向量的线性组合。无穷维空间的 Hamel 基存在（依赖选择公理），但不可构造、不实用。 **Schauder 基**：每个向量表示为基向量的无穷级数（收敛意义下）。例如傅里叶基是 L²[0,2π] 的 Schauder 基。 **正交基（Hilbert 空间）**：在无穷维内积空间中，正交基是最常用的"基"概念，它允许无穷级数展开。

F1 聚焦有限维空间，但知道基概念在无穷维的扩展有助于理解"为什么有限维的结论不能直接推广"。例如，无穷维空间中"线性无关+张成"不一定能推出"基的大小不变"——维数的概念在无穷维中更加微妙。

**边界声明**：本模块所有结论默认在有限维线性空间中成立。无穷维空间的基理论属于泛函分析范畴，此处仅作边界标注，不展开。

### 8.4 高维直觉的失效

在 R² 和 R³ 中，我们可以"看到"基——它们是坐标轴。但在高维空间（R⁴, R⁵, ...）中，几何直觉开始失效：

**高维球的体积集中在表面**：在 Rⁿ 中，单位球的大部分体积集中在薄球壳里（n→∞ 时，体积几乎全在半径 1 的表面）。这意味着"随机选一个向量"，它几乎与任何固定方向正交。 **高维空间中"几乎所有"基都是近似正交的**：随机选取的向量在高维中倾向于两两正交（内积相对于长度很小）。 **维数灾难**：高维空间中，最近邻和最远邻的距离比趋近于 1——"距离"这个概念本身变得不那么有区分度。

这些现象不改变基的代数定义，但提醒我们：**低维几何直觉不能无条件推广到高维**。在高维中，基仍然是"测量协议"，但这个协议的几何行为与低维有本质差异。

### 8.5 基与子空间：子空间的基

子空间 W ⊂ V 也有自己的基——一组线性无关且张成 W 的向量。子空间的基的大小就是子空间的维数 dim(W)。

子空间基的几何意义：它是"在 W 内部的坐标系"。例如 R³ 中一个平面的基是两个不共线的向量，它们提供了在这个平面内测量位置的能力。

**维数公式**：对有限维空间 V 的子空间 W₁, W₂，有 dim(W₁+W₂) = dim(W₁) + dim(W₂) - dim(W₁∩W₂)。几何上，这是"两个子空间合并后的维数 = 各自维数之和 - 重叠部分的维数"——与集合的容斥原理同构。

**耦合索引 → S2（线性空间·基与维数）**：子空间的基与维数公式是领域二的核心内容。F1 提供"基=坐标系"的语言，S2 提供"子空间的几何结构"的展开。

## 实物验证：三个具体实例

### 9.1 实例一：R² 中标准基 vs 斜基的坐标对比

**设置**：标准基 B={e₁=(1,0), e₂=(0,1)}，斜基 B'={v₁=(2,0), v₂=(1,1)}。向量 x=(5,2)。

**标准基坐标**：[x]B=(5,2)（自指性）。 **斜基坐标**：解 a(2,0)+b(1,1)=(5,2)，得 2a+b=5, b=2，所以 a=1.5, b=2。[x]B'=(1.5, 2)。 **验证**：1.5×(2,0)+2×(1,1)=(3,0)+(2,2)=(5,2) ✓。

**几何解读**：同一个向量 (5,2)，在标准基下"向右 5、向上 2"，在斜基下"沿 v₁ 走 1.5 个单位、沿 v₂ 走 2 个单位"。地址不同，但指向的是空间中同一个点。

### 9.2 实例二：2×2 换基矩阵的手算与几何

**设置**：旧基 B={e₁,e₂}，新基 B'={w₁=(1,1), w₂=(-1,1)}（旋转 45° + 缩放 √2）。

**过渡矩阵**：P=`[[1,-1],[1,1]]`（列是 w₁,w₂ 在 B 下的坐标）。 **逆矩阵**：P⁻¹=(1/2)`[[1,1],[-1,1]]`。 **坐标变换**：x=(3,1) 在 B' 下坐标 = P⁻¹(3,1)ᵀ = (2, -1)ᵀ。 **验证**：2w₁ + (-1)w₂ = 2(1,1) - (-1,1) = (2,2)+(1,-1) = (3,1) ✓。

**几何解读**：新基是旧基旋转 45° 并放大 √2 后的坐标系。向量 (3,1) 在新坐标系下"沿 w₁ 走 2、沿 w₂ 反方向走 1"。P 的行列式 det(P)=2，说明新基下的"单位面积"是旧基下的 2 倍——这是 F3（行列式）的预告。

### 9.3 实例三：Gram-Schmidt 正交化的数值验证

**设置**：R³ 中基 v₁=(1,1,0), v₂=(1,0,1), v₃=(0,1,1)。用 Gram-Schmidt 正交化。

**第一步**：u₁ = v₁ = (1,1,0)，||u₁||²=2。 **第二步**：proj_{u₁}(v₂) = ⟨v₂,u₁⟩/||u₁||² · u₁ = 1/2·(1,1,0) = (0.5,0.5,0)。u₂ = v₂ - proj = (1,0,1)-(0.5,0.5,0) = (0.5,-0.5,1)。验证 ⟨u₁,u₂⟩ = 0.5-0.5+0 = 0 ✓。 **第三步**：proj_{u₁}(v₃) = ⟨v₃,u₁⟩/2·u₁ = 1/2·(1,1,0)=(0.5,0.5,0)。proj_{u₂}(v₃) = ⟨v₃,u₂⟩/||u₂||²·u₂ = (0-0.5+1)/1.5·(0.5,-0.5,1) = 0.5/1.5·(0.5,-0.5,1) = (1/6,-1/6,1/3)。u₃ = v₃ - proj₁ - proj₂ = (0,1,1)-(0.5,0.5,0)-(1/6,-1/6,1/3) = (-2/3, 2/3, 2/3)。验证 ⟨u₁,u₃⟩=-2/3+2/3+0=0 ✓，⟨u₂,u₃⟩=-1/3-1/3+2/3=0 ✓。

**标准正交基**：e₁=u₁/√2=(1/√2,1/√2,0)，e₂=u₂/√1.5=(1/√6,-1/√6,2/√6)，e₃=u₃/√(4/3)=(-1/√3,1/√3,1/√3)。

pythonimport numpy as np
# Gram-Schmidt 验证
V = np.array(`[[1,1,0],[1,0,1],[0,1,1]]`, dtype=float)
Q, R = np.linalg.qr(V)
print("Q（标准正交基，列）：")
print(np.round(Q, 4))
print("QᵀQ（应为单位阵）：")
print(np.round(Q.T @ Q, 4))
print("R（上三角）：")
print(np.round(R, 4))
print("QR = V？", np.allclose(Q @ R, V))
**numpy 输出**：QᵀQ = I（单位阵），QR = V ✓。正交化成功，Q 的列构成标准正交基。

**验证结论**：三个实例全部手算 + numpy 复算通过。坐标变换、过渡矩阵、Gram-Schmidt 正交化的理论结论在具体数值上完全成立。F1 的核心命题——"基是坐标系、坐标是地址、换基是换角度拍照"——得到实物支撑。

### 10.2 常见误区与反例

**误区一**："基就是标准基。" → 反例：R² 中 {(1,1),(-1,1)} 也是基，且在很多问题中比标准基更自然。

**误区二**："坐标就是向量本身。" → 反例：向量 (3,1) 在标准基下坐标 (3,1)，在基 {(1,1),(-1,1)} 下坐标 (2,-1)。坐标依赖基，向量不依赖基。

**误区三**："正交基就是最好的基。" → 反例：特征向量基通常不正交，但它让变换对角化，这是正交基做不到的。正交基是"计算友好"，不一定是"理解深刻"。

**误区四**："换基会改变矩阵的特征值。" → 反例：相似变换 P⁻¹AP 保持特征值不变。特征值是变换本身的属性，与基无关。

**误区五**："线性无关的向量组一定是基。" → 反例：R³ 中 {(1,0,0),(0,1,0)} 线性无关但不是基（不张成 R³）。基需要同时满足线性无关和张成空间。
