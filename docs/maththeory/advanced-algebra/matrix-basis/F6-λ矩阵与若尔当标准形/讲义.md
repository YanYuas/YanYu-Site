λ-矩阵？因为相似分类的完整不变量（不变因子、初等因子）蕴含在特征矩阵 λI-A 的结构中。通过对 λI-A 做初等变换（行/列交换、行/列乘非零常数、行/列加另一行/列的多项式倍），可以将其化为 Smith 标准形 diag(d₁(λ),...,dₙ(λ))，其中 d₁|d₂|...|dₙ。Smith 标准形中的非 1 多项式就是不变因子。将不变因子分解为一次因子的幂（在复数域上），就得到初等因子 (λ-λᵢ)^mᵢⱼ，每个初等因子对应一个若尔当块。λ-矩阵的引入将"矩阵相似分类"转化为"特征矩阵的初等变换"——这是一个纯代数的、可计算的过程，不依赖于求解特征向量或特征值的精确值。### 1.3 本模块的研究路径| 章节 | 核心内容 | 几何还原 | 代数落点 ||---|---|---|---|| 2 手算+numpy | 全部数值可复算 |## λ-矩阵的几何本质### 2.1 什么是 λ-矩阵λ-矩阵（也叫多项式矩阵）是元素为 λ 的多项式的矩阵 A(λ)=(aᵢⱼ(λ))，其中 aᵢⱼ(λ)∈F[λ]。常义矩阵可以看作 λ-矩阵的特例（所有元素都是零次多项式）。最重要的 λ-矩阵是特征矩阵 λI-A，其中 A 是常义矩阵。λI-A 的行列式就是特征多项式 det(λI-A)=p_A(λ)。**几何意义**：λI-A 可以看作"带参数 λ 的线性变换族"——对于每个固定的 λ₀，λ₀I-A 是一个常义矩阵。当 λ₀ 是 A 的特征值时，λ₀I-A 是奇异的（行列式为零），存在非零向量 v 使得 (λ₀I-A)v=0，即 Av=λ₀v。更深刻地，λI-A 的初等变换记录了"A-λI 在各个 λ 处的奇异性结构"——这正是若尔当标准形的信息来源。### 2.2 λ-矩阵的初等变换λ-矩阵的初等变换有三种（与常义矩阵类似，但第三种允许多项式倍）：1. **交换两行（列）**2.**某行（列）乘非零常数**3.**某行（列）加上另一行（列）的 φ(λ) 倍，其中 φ(λ) 是任意多项式**第三种变换是 λ-矩阵特有的——常义矩阵的初等变换只允许加常数倍，而 λ-矩阵允许加多项式倍。这大大增强了变换能力，使得可以消去多项式元素。两个 λ-矩阵如果可以通过有限次初等变换互相转化，就称它们等价。λ-矩阵的等价关系对应于常义矩阵的相似关系：**A 与 B 相似 ⇔ λI-A 与 λI-B 等价**。这是 λ-矩阵理论的基本定理。**耦合索引 → F5（相似与标准形）**：F5 建立了相似等价类的概念，F6 通过 λI-A 的等价关系将相似分类转化为 λ-矩阵的等价分类。这是"常义矩阵的相似"与"λ-矩阵的等价"之间的深刻对应。### 2.3 λ-矩阵的秩与可逆性λ-矩阵 A(λ) 的秩定义为其非零子式的最高阶数。由于元素是多项式，子式也是多项式，"非零"指"不是零多项式"（可能在某些 λ 值处为零）。λ-矩阵 A(λ) 称为可逆的（幺模的），如果存在 λ-矩阵 B(λ) 使得 A(λ)B(λ)=I。可逆的充要条件是 det(A(λ)) 是非零常数（零次多项式）。注意：特征矩阵 λI-A 的行列式是特征多项式（n 次），不是常数，所以 λI-A 作为 λ-矩阵是不可逆的。但它的秩是 n（满秩），因为 det(λI-A) 不是零多项式。初等变换对应的初等矩阵都是可逆的（行列式为 ±1 或非零常数）。所以 λ-矩阵的等价变换就是"左乘和右乘可逆 λ-矩阵"：A(λ) 与 B(λ) 等价 ⇔ 存在可逆 λ-矩阵 P(λ), Q(λ) 使得 B(λ)=P(λ)A(λ)Q(λ)。### 2.4 为什么特征矩阵携带完整信息为什么 λI-A 的等价类完全决定了 A 的相似类？可以从两个角度理解：**代数角度**：λI-A 的 Smith 标准形给出了不变因子，而不变因子是相似的完备不变量（F5 有理标准形）。所以 λI-A 的等价类 ⇔ 不变因子 ⇔ 相似类。**几何角度**：λI-A 编码了"A 作为线性变换的全部行为"。对于每个向量 v，考虑序列 v, Av, A²v, ...。这个序列的线性相关性由 v 的零化多项式决定，而零化多项式的信息蕴含在 λI-A 的结构中。初等变换本质上是在"重新组织"这些序列，找到最简洁的表示。特别地，λI-A 的等价变换 P(λ)(λI-A)Q(λ) 可以看作"对 A 的循环子空间分解做基变换"——P(λ) 和 Q(λ) 分别对应"输出端"和"输入端"的基变换。### 2.5 λ-矩阵与模论的联系从更高的观点看，λ-矩阵理论是主理想整环（PID）上的模理论的特例。将向量空间 V 看作 F[λ]-模，其中 λ 的作用定义为 λ·v=Av。那么：• V 作为 F[λ]-模是有限生成的（因为 V 作为 F-向量空间有限维） • F[λ] 是主理想整环（PID） • PID 上的有限生成模有标准分解：V ≅ F[λ]/(d₁) ⊕ ... ⊕ F[λ]/(dₛ)，其中 d₁|d₂|...|dₛ • 这里的 dᵢ 就是不变因子！每个循环分量 F[λ]/(dᵢ) 对应一个友矩阵 C(dᵢ)在复数域上，F[λ] 中的不可约多项式都是一次的 (λ-λ₀)，所以中国剩余定理给出 F[λ]/((λ-λ₀)^m) 的分解，每个分量对应一个若尔当块 J_m(λ₀)。这个模论视角揭示了若尔当标准形的深层本质：它是 PID 上有限生成模的标准分解在向量空间上的具体实现。有理标准形对应不变因子分解，若尔当标准形对应初等因子分解（素数幂分解）。## Smith标准形与不变因子### 3.1 Smith标准形定理**定理**：任何秩为 r 的 λ-矩阵 A(λ) 都等价于对角矩阵 diag(d₁(λ), d₂(λ), ..., dᵣ(λ), 0, ..., 0)，其中 dᵢ(λ) 是首一多项式，且满足整除链 d₁(λ)|d₂(λ)|...|dᵣ(λ)。这个对角矩阵称为 A(λ) 的 Smith 标准形，dᵢ(λ) 称为不变因子。**存在性证明思路**：用初等变换将 A(λ) 化为对角形。关键引理：如果 A(λ) 的左上角元素 a₁₁(λ) 不能整除某个元素 aᵢⱼ(λ)，则可以通过初等变换将左上角元素替换为次数更低的多项式。反复应用，最终左上角元素能整除所有其他元素，然后对右下角的 (n-1)×(n-1) 子矩阵递归。**唯一性**：Smith 标准形是唯一的——不变因子不依赖于初等变换的选择。这由行列式因子的唯一性保证（见 3.2）。对于特征矩阵 λI-A（满秩 n×n），Smith 标准形是 diag(d₁(λ),...,dₙ(λ))，其中 d₁|d₂|...|dₙ，且 d₁d₂...dₙ=det(λI-A)=p_A(λ)（特征多项式）。### 3.2 行列式因子λ-矩阵 A(λ) 的 k 阶行列式因子 Δₖ(λ) 定义为 A(λ) 的所有 k 阶子式的最大公因式（首一）。约定 Δ₀(λ)=1。行列式因子是 λ-矩阵等价变换下的不变量——初等变换不改变行列式因子。这是因为：行/列交换只改变子式的符号或选择；行乘常数不改变 gcd；行加另一行的多项式倍后，新的子式可以表示为原子式的线性组合，gcd 不变。**不变因子与行列式因子的关系**：dₖ(λ)=Δₖ(λ)/Δₖ₋₁(λ)。即不变因子是相邻行列式因子的商。这给出了计算不变因子的另一种方法：先算各阶行列式因子，再相除。对于特征矩阵 λI-A，Δₙ(λ)=det(λI-A)=p_A(λ)（特征多项式），dₙ(λ)=Δₙ/Δₙ₋₁=极小多项式 m_A(λ)（最后一个不变因子是极小多项式）。**注意**：计算行列式因子时，所有 k 阶子式的 gcd 可能是 1（常数），此时对应的不变因子 dₖ=1。对于特征矩阵，通常前几个不变因子都是 1，只有最后几个是非平凡多项式。### 3.3 Smith标准形的计算实例**实例**：A=J₂(2)=`[[2,1],[0,2]]`（2阶若尔当块）。特征矩阵 λI-A=[[λ-2,-1],[0,λ-2]]。**方法一：初等变换**[[λ-2,-1],[0,λ-2]] → 交换两行 → [[0,λ-2],[λ-2,-1]] → 交换两列 → [[λ-2,0],[-1,λ-2]] → 第2行加第1行的(λ-2)倍 → [[λ-2,0],[0,(λ-2)²]]Smith 标准形：diag(λ-2, (λ-2)²)。不变因子 d₁=λ-2, d₂=(λ-2)²。**方法二：行列式因子**Δ₁=gcd(λ-2, -1, 0, λ-2)=1（因为有元素 -1，gcd 为 1） Δ₂=det(λI-A)=(λ-2)² d₁=Δ₁/Δ₀=1, d₂=Δ₂/Δ₁=(λ-2)²等等，两种方法得到的 d₁ 不同！方法一得到 d₁=λ-2，方法二得到 d₁=1。哪里出错了？方法一的初等变换有误。让我重新检查：交换两行后是 [[0,λ-2],[λ-2,-1]]，交换两列后是 [[λ-2,0],[-1,λ-2]]。第2行加第1行的(λ-2)倍：第2行变成 [-1+(λ-2)(λ-2), (λ-2)+0] = [(λ-2)²-1, λ-2]。这不对。正确的做法：[[λ-2,-1],[0,λ-2]]，第1列加第2列的(λ-2)倍：第1列变成 [λ-2+(λ-2)(-1)? 不对。让我用行列式因子法：Δ₁=1（因为有元素 -1），所以 d₁=1，d₂=(λ-2)²。Smith 标准形是 diag(1, (λ-2)²)。### 3.4 不变因子的几何意义不变因子 d₁|d₂|...|dₛ 对应于空间的循环子空间分解 V=Z(v₁;A)⊕...⊕Z(vₛ;A)，其中 vᵢ 的零化多项式是 dᵢ。整除链 d₁|d₂|...|dₛ 的几何意义：每个后续循环子空间的"复杂度"不低于前一个。dₛ 是极小多项式（最复杂的循环子空间的零化多项式），d₁ 通常是 1（最简单的循环子空间，可能是 1 维的特征向量方向）。对于可对角化矩阵，所有不变因子都是一次多项式的乘积（无重根），且 dᵢ=(λ-λᵢ₁)...(λ-λᵢₖ)。对于亏损矩阵，某些不变因子有重根，重根的次数对应若尔当块的大小。不变因子的个数 s 等于循环子空间的个数，也等于"矩阵的有理标准形中友矩阵的块数"。s 越小，矩阵越"集中"（少数几个大循环子空间）；s 越大，矩阵越"分散"（许多小循环子空间）。## 初等因子与若尔当块### 4.1 从不变因子到初等因子在代数闭域（如复数域 C）上，每个不变因子 dᵢ(λ) 可以分解为一次因子的幂：dᵢ(λ)=(λ-λ₁)^{mᵢ₁}(λ-λ₂)^{mᵢ₂}...(λ-λₖ)^{mᵢₖ}所有这些一次因子的幂 (λ-λⱼ)^{mᵢⱼ}（mᵢⱼ>0）合在一起，称为 A 的初等因子组。例如，不变因子 d₁=1, d₂=(λ-2)²(λ-3)，则初等因子是 (λ-2)² 和 (λ-3)。**关键定理**：两个复方阵相似 ⇔ 它们有相同的初等因子组（不计顺序）。初等因子是相似的完备不变量。初等因子比不变因子更精细地刻画了矩阵的结构——它将不变因子"拆分"为素数幂，每个素数幂对应一个若尔当块。### 4.2 若尔当块的结构m 阶若尔当块定义为：J_m(λ) = [[λ, 1, 0, ..., 0],            [0, λ, 1, ..., 0],            [...,            [0, 0, ..., λ, 1],            [0, 0, ..., 0, λ]]若尔当块的性质：• 特征多项式：(λ-λ₀)^m • 极小多项式：(λ-λ₀)^m • 特征值：λ₀（代数重数 m，几何重数 1） • 只有一个线性无关的特征向量 (1,0,...,0) • J_m(λ₀)-λ₀I 是幂零矩阵，幂零指数为 m**几何意义**：若尔当块描述了"在 m 维广义不变子空间上的伸缩+剪切"。λ₀ 是伸缩因子，次对角线上的 1 是剪切。空间被分解为一条若尔当链 v₁, v₂,...,vₘ，其中 Av₁=λ₀v₁, Av₂=λ₀v₂+v₁, ..., Avₘ=λ₀vₘ+vₘ₋₁。### 4.3 初等因子与若尔当块的对应**基本对应**：每个初等因子 (λ-λ₀)^m 对应一个 m 阶若尔当块 J_m(λ₀)。因此，知道了初等因子组，就可以直接写出若尔当标准形：将每个初等因子对应的若尔当块放在对角线上，得到分块对角矩阵。**实例**：3×3 矩阵 A，特征多项式 (λ-1)²(λ-2)。情况一：初等因子 (λ-1), (λ-1), (λ-2) → 若尔当标准形 diag(1, 1, 2)（可对角化）情况二：初等因子 (λ-1)², (λ-2) → 若尔当标准形 diag(J₂(1), 2) = `[[1,1,0],[0,1,0],[0,0,2]]`（亏损）两种情况有相同的特征多项式，但不同的初等因子组，因此不相似。这说明初等因子比特征多项式更精细。**重数关系**：对于特征值 λ₀，其代数重数 = 所有以 λ₀ 为根的初等因子的次数之和；其几何重数 = 以 λ₀ 为根的初等因子的个数（即对应若尔当块的个数）。代数重数 ≥ 几何重数，等号成立 ⇔ 所有以 λ₀ 为根的初等因子都是一次的 ⇔ λ₀ 对应的若尔当块都是 1 阶的。**几何洞察**：初等因子 (λ-λ₀)^m 的次数 m 是若尔当块的大小，也是"广义特征向量链的长度"。m=1 对应纯伸缩（特征向量方向），m>1 对应伸缩+剪切（广义特征向量方向）。初等因子的个数是"独立的广义不变方向"的数量。### 4.4 初等因子的计算初等因子可以通过以下方法计算：**方法一**：先求 Smith 标准形得到不变因子，再将每个不变因子分解为一次因子的幂。**方法二**：对特征矩阵 λI-A 做初等变换化为对角形（不一定是 Smith 标准形，只要对角线上是多项式即可），然后将每个对角元素分解为一次因子的幂。注意：这种方法得到的对角元素不一定满足整除链，但所有一次因子的幂合在一起就是初等因子组。**方法三**：通过 rank(A-λ₀I)^k 的变化来确定若尔当块的大小。对于特征值 λ₀，设 r_k=rank(A-λ₀I)^k，则大小为 k 的若尔当块的个数 = (r_{k-1}-r_k) - (r_k-r_{k+1}) = r_{k-1}-2r_k+r_{k+1}。方法三在实际计算中非常有用，因为它不需要做 λ-矩阵的初等变换，只需要计算常义矩阵的秩。### 4.5 不变因子 vs 初等因子| 维度 | 不变因子 | 初等因子 ||---|---|---|| 定义 | Smith标准形对角元 | 不变因子的一次因子幂分解 || 结构 | 整除链 d₁\|...\|dₛ | 一组 (λ-λᵢ)^mᵢⱼ || 对应标准形 | 有理标准形（友矩阵） | 若尔当标准形（若尔当块） || 适用域 | 任意域 | 代数闭域（如C） || 几何意义 | 循环子空间分解 | 广义特征子空间分解 || 完备性 | 完备（任意域） | 完备（代数闭域） J_{mₖ}(λₖ))，其中 J_{mᵢ}(λᵢ) 是 mᵢ 阶若尔当块，Σmᵢ=n。若尔当标准形在不计若尔当块排列顺序的意义下唯一。**存在性证明思路**（基于 λ-矩阵）：1. 对特征矩阵 λI-A 做初等变换，化为 Smith 标准形，得到不变因子 2. 将每个不变因子分解为一次因子的幂，得到初等因子组 3. 每个初等因子 (λ-λᵢ)^{mᵢ} 对应一个若尔当块 J_{mᵢ}(λᵢ) 4. 证明 A 相似于这些若尔当块的直和**唯一性**：若尔当标准形的唯一性来自初等因子组的唯一性——初等因子是相似不变量，且构成完备不变量系统。所以两个矩阵相似 ⇔ 它们的若尔当标准形相同（不计排列）。### 5.2 若尔当标准形的几何意义若尔当标准形的几何意义是"空间的广义特征子空间直和分解"：V = V_{λ₁} ⊕ V_{λ₂} ⊕ ... ⊕ V_{λₖ}其中 V_{λᵢ} = N((A-λᵢI)^{mᵢ}) 是对应特征值 λᵢ 的广义特征子空间，dim(V_{λᵢ})=λᵢ 的代数重数。在每个广义特征子空间 V_{λᵢ} 内，A-λᵢI 是幂零变换。幂零变换的标准形是幂零若尔当块 J_m(0) 的直和。所以 A 在 V_{λᵢ} 上的限制 = λᵢI + 幂零变换，其标准形是若尔当块 J_{m}(λᵢ) 的直和。这就是若尔当标准形的几何本质：**先按特征值分解空间为广义特征子空间的直和，再在每个广义特征子空间内按幂零指数分解为若尔当链的直和**。**耦合索引 → 领域三（线性变换·不变子空间）**：广义特征子空间是最重要的不变子空间。若尔当标准形的几何证明本质上是"不变子空间的精细分解"。领域三将系统展开不变子空间理论，F6 提供"广义特征子空间=若尔当块的直和"这一核心例子。### 5.3 若尔当标准形的特例**特例一：可对角化矩阵**。如果 A 可对角化，那么所有若尔当块都是 1 阶的（mᵢ=1），若尔当标准形就是对角矩阵 diag(λ₁,...,λₙ)。可对角化 ⇔ 所有初等因子都是一次的 ⇔ 极小多项式无重根 ⇔ 每个特征值的几何重数=代数重数。**特例二：幂零矩阵**。如果 A 是幂零矩阵（Aᵐ=0），那么所有特征值都是 0，若尔当标准形是幂零若尔当块 J_m(0) 的直和。幂零矩阵的若尔当块大小就是幂零指数的分布。**特例三：单个若尔当块**。如果 A 相似于单个若尔当块 J_n(λ₀)，那么 A 的特征多项式=极小多项式=(λ-λ₀)^n，几何重数=1。这样的矩阵称为"循环矩阵"或"非减次矩阵"——空间本身就是一个循环子空间。**特例四：实对称矩阵**。实对称矩阵的若尔当标准形是对角矩阵（因为实对称矩阵可正交对角化）。这是谱定理的推论——对称矩阵不会有亏损的特征值。### 5.4 若尔当标准形与矩阵函数若尔当标准形最重要的应用之一是计算矩阵函数。对于多项式 p(x)，如果 A=PJP⁻¹，则 p(A)=Pp(J)P⁻¹。而 p(J) 可以逐块计算：p(J_m(λ)) = [[p(λ), p'(λ), p''(λ)/2!, ..., p^{(m-1)}(λ)/(m-1)!],              [0, p(λ), p'(λ), ..., p^{(m-2)}(λ)/(m-2)!],              [...,              [0, ..., p(λ)]]即 p(J_m(λ)) 是上三角矩阵，第 k 条次对角线上的元素是 p^{(k)}(λ)/k!。这个公式对任何解析函数都成立（通过幂级数定义），包括 e^A, sin(A), cos(A), A^{-1} 等。几何上，这说明若尔当块上的函数值不仅取决于函数在 λ 处的值 p(λ)，还取决于各阶导数 p^{(k)}(λ)——这是"剪切"行为的体现：函数作用在若尔当块上时，不仅伸缩，还沿若尔当链"扩散"。### 5.5 若尔当标准形的存在性证明（几何法）除了 λ-矩阵方法，若尔当标准形还可以用纯几何的方法证明：**第一步**：证明空间可以分解为广义特征子空间的直和。这需要证明不同特征值的广义特征子空间的交为零，且它们的和为全空间。关键引理：如果 f(x), g(x) 互素，则 N(f(A)g(A))=N(f(A))⊕N(g(A))。**第二步**：在每个广义特征子空间内，A-λI 是幂零变换。证明任何幂零变换都相似于幂零若尔当块的直和。关键是构造若尔当链：取幂零指数最大的向量 v，构造链 v, Nv, ..., N^{m-1}v，然后在商空间中递归。**第三步**：将各广义特征子空间的若尔当基合并，得到全空间的若尔当基，A 在这组基下的矩阵就是若尔当标准形。几何法证明更直观地揭示了若尔当标准形的"空间分解"本质，但构造性不如 λ-矩阵法强。两种方法互为补充。## 广义特征向量与若尔当链### 6.1 广义特征向量的定义向量 v 称为 A 的对应于特征值 λ 的广义特征向量，如果存在正整数 k 使得 (A-λI)^k v=0。满足这个条件的最小 k 称为 v 的高度（或幂零指数）。普通特征向量是高度为 1 的广义特征向量（(A-λI)v=0）。广义特征向量扩展了"不变方向"的概念——普通特征向量是"严格不变"的方向（Av=λv），广义特征向量是"幂零后不变"的方向（(A-λI)^k v=0）。对应于特征值 λ 的所有广义特征向量构成广义特征子空间 V_λ=N((A-λI)^m)，其中 m 是 λ 的代数重数（或更大的数）。V_λ 是 A 的不变子空间，dim(V_λ)=λ 的代数重数。**几何意义**：广义特征子空间是"最终会被 A-λI 压成零"的向量集合。在这个子空间内，A=λI+N，其中 N 是幂零变换。A 的作用是"先伸缩 λ 倍，再沿若尔当链剪切"。### 6.2 若尔当链若尔当链是一列向量 v₁, v₂, ..., vₘ，满足：(A-λI)v₁=0 (A-λI)v₂=v₁ (A-λI)v₃=v₂ ... (A-λI)vₘ=vₘ₋₁等价地，Av₁=λv₁, Av₂=λv₂+v₁, ..., Avₘ=λvₘ+vₘ₋₁。若尔当链中的 v₁ 是普通特征向量（高度 1），v₂ 是高度 2 的广义特征向量，...，vₘ 是高度 m 的广义特征向量。若尔当链的长度 m 就是对应若尔当块的大小。**几何意义**：若尔当链描述了"剪切"的层级结构。A 对 vₘ 的作用不仅是伸缩 λvₘ，还加上了 vₘ₋₁（沿链的方向"移动"了一步）。这种"移动"就是剪切。链越长，剪切越复杂。**注意**：若尔当链的构造顺序是从"顶端"（普通特征向量 v₁）到"底端"（最高广义特征向量 vₘ）。但在实际计算中，通常先找到最高广义特征向量 vₘ，然后用 (A-λI) 逐步作用得到 vₘ₋₁, ..., v₁。### 6.3 若尔当基的构造若尔当基是由若尔当链组成的基。构造若尔当基的步骤：**第一步**：对每个特征值 λ，计算广义特征子空间 V_λ=N((A-λI)^m)。**第二步**：在 V_λ 内，确定若尔当块的大小分布。可以通过 rank((A-λI)^k) 的变化来确定：大小为 k 的若尔当块个数 = rank((A-λI)^{k-1}) - 2·rank((A-λI)^k) + rank((A-λI)^{k+1})。**第三步**：对每个大小为 m 的若尔当块，找到一个高度为 m 的广义特征向量 vₘ（即 (A-λI)^m vₘ=0 但 (A-λI)^{m-1} vₘ≠0），然后构造链 vₘ, (A-λI)vₘ, ..., (A-λI)^{m-1}vₘ。**第四步**：将所有若尔当链合并，得到全空间的若尔当基。A 在这组基下的矩阵就是若尔当标准形。构造若尔当基的关键是找到"足够高"的广义特征向量。如果 vₘ 的高度不够（小于 m），就无法构造长度为 m 的若尔当链。需要在商空间中仔细选择。### 6.4 若尔当链的几何直观以 2 阶若尔当块 J₂(λ)=[[λ,1],[0,λ]] 为例。若尔当基 {v₁, v₂} 满足 Av₁=λv₁, Av₂=λv₂+v₁。考虑 v₂ 的迭代：A^k v₂ = λ^k v₂ + kλ^{k-1} v₁。当 k 增大时：• 如果 |λ|<1：λ^k→0，kλ^{k-1}→0，v₂ 最终被压到零 • 如果 |λ|=1：λ^k 有界，但 kλ^{k-1} 线性增长，v₂ 无界！ • 如果 |λ|>1：λ^k 和 kλ^{k-1} 都指数增长这与可对角化矩阵形成对比：可对角化矩阵的特征向量迭代只有 λ^k 因子，当 |λ|=1 时有界。但若尔当块的广义特征向量迭代有 kλ^{k-1} 因子，即使 |λ|=1 也会线性增长——这就是"剪切"的长期效应。几何上，若尔当块把 v₂ 方向的向量"旋转"到 v₁ 方向（剪切），所以 v₂ 的迭代会逐渐积累 v₁ 分量。这就像一个"泄漏"——v₂ 方向的信息会泄漏到 v₁ 方向。### 6.5 广义特征子空间的直和分解**定理**：设 A 的互不相同的特征值为 λ₁,...,λₖ，代数重数分别为 m₁,...,mₖ。则V = N((A-λ₁I)^{m₁}) ⊕ N((A-λ₂I)^{m₂}) ⊕ ... ⊕ N((A-λₖI)^{mₖ})这是空间的广义特征子空间直和分解，每个广义特征子空间都是 A 的不变子空间。**证明关键**：特征多项式 p_A(x)=∏(x-λᵢ)^{mᵢ}。由凯莱-哈密顿定理 p_A(A)=0，即 ∏(A-λᵢI)^{mᵢ}=0。因为各因子 (x-λᵢ)^{mᵢ} 两两互素，所以可以用中国剩余定理（或 Bezout 等式）证明空间是各核的直和。这个分解是若尔当标准形的几何基础：先按特征值分解，再在每个广义特征子空间内按若尔当链分解。两步分解合起来就得到若尔当标准形。对于可对角化矩阵，广义特征子空间就是普通特征子空间（因为 (A-λI) 的幂零指数为 1），分解退化为特征子空间直和。## 若尔当标准形的计算与应用### 7.1 若尔当标准形的计算步骤**完整算法**：**第一步**：计算特征多项式 p_A(λ)=det(λI-A)，求出特征值 λ₁,...,λₖ 及代数重数 m₁,...,mₖ。**第二步**：对每个特征值 λᵢ，计算 r_k=rank((A-λᵢI)^k)，k=1,2,...，直到 r_k 稳定。**第三步**：大小为 j 的若尔当块个数 = r_{j-1} - 2r_j + r_{j+1}（约定 r₀=mᵢ, r_{mᵢ+1}=0）。或者等价地，大小 ≥ j 的若尔当块个数 = r_{j-1} - r_j。**第四步**：根据若尔当块大小分布，写出若尔当标准形 J。**第五步**（可选）：构造若尔当基 P，使得 P⁻¹AP=J。这个算法的核心是第二步——通过秩的变化确定若尔当块的大小。秩的变化直接反映了"广义特征向量的层级结构"。### 7.2 计算实例：3阶矩阵**设置**：A=`[[2,1,0],[0,2,1],[0,0,2]]`=J₃(2)（3阶若尔当块）。**特征值**：λ=2，代数重数 3。**秩的变化**：A-2I=`[[0,1,0],[0,0,1],[0,0,0]]`, rank=2 → r₁=2 (A-2I)²=`[[0,0,1],[0,0,0],[0,0,0]]`, rank=1 → r₂=1 (A-2I)³=0, rank=0 → r₃=0**若尔当块大小**：大小 ≥1 的块数 = r₀-r₁ = 3-2 = 1 大小 ≥2 的块数 = r₁-r₂ = 2-1 = 1 大小 ≥3 的块数 = r₂-r₃ = 1-0 = 1所以只有一个 3 阶若尔当块 J₃(2)。若尔当标准形就是 A 本身。**若尔当基**：取 v₃=(0,0,1)，则 (A-2I)v₃=(0,1,0)=v₂，(A-2I)v₂=(1,0,0)=v₁。若尔当链 {v₁,v₂,v₃}={(1,0,0),(0,1,0),(0,0,1)} 就是标准基。### 7.3 应用一：线性微分方程组考虑线性常系数微分方程组 dx/dt=Ax。解为 x(t)=e^{At}x(0)。若尔当标准形是计算 e^{At} 的关键工具。如果 A=PJP⁻¹，则 e^{At}=Pe^{Jt}P⁻¹。对于若尔当块 J_m(λ)：e^{J_m(λ)t} = e^{λt} [[1, t, t²/2!, ..., t^{m-1}/(m-1)!],                     [0, 1, t, ..., t^{m-2}/(m-2)!],                     [...,                     [0, ..., 1]]这说明若尔当块对应的解包含 e^{λt}, te^{λt}, t²e^{λt}, ..., t^{m-1}e^{λt} 等项。多项式因子 t^k 来自若尔当块的剪切行为——这是亏损矩阵的特征。对于可对角化矩阵（所有若尔当块 1 阶），解只包含 e^{λᵢt} 项，没有多项式因子。对于亏损矩阵，解中出现 t^k e^{λt} 项，这对应于"共振"现象。### 7.4 应用二：矩阵幂与动力系统若尔当标准形简化了矩阵幂的计算。对于若尔当块 J_m(λ)：J_m(λ)^k = [[λ^k, C(k,1)λ^{k-1}, ..., C(k,m-1)λ^{k-m+1}],              [0, λ^k, ..., C(k,m-2)λ^{k-m+2}],              [...,              [0, ..., λ^k]]其中 C(k,j)=k!/(j!(k-j)!) 是组合数。当 k对于离散动力系统 x_{k+1}=Ax_k，解为 x_k=A^k x₀。若尔当标准形将 A^k 分解为各若尔当块的幂，长期行为由最大特征值（按模）对应的若尔当块决定。关键结论：如果 |λ_max|<1，系统收敛（所有项→0）；如果 |λ_max|>1，系统发散；如果 |λ_max|=1 且对应的若尔当块大于 1 阶，系统多项式增长（无界）；如果 |λ_max|=1 且所有对应若尔当块都是 1 阶，系统有界。这说明若尔当块的大小直接影响动力系统的稳定性——亏损的特征值即使模为 1 也可能导致无界增长。### 7.5 应用三：极小多项式与凯莱-哈密顿若尔当标准形给出了极小多项式的清晰表达式：m_A(x)=∏(x-λᵢ)^{sᵢ}，其中 sᵢ 是对应特征值 λᵢ 的最大若尔当块的大小。这是因为：若尔当块 J_m(λ) 的极小多项式是 (x-λ)^m；分块对角矩阵的极小多项式是各块极小多项式的最小公倍式。所以 m_A(x)=lcm((x-λᵢ)^{mᵢⱼ})=∏(x-λᵢ)^{maxⱼ(mᵢⱼ)}。凯莱-哈密顿定理 p_A(A)=0 可以从若尔当标准形直接看出：p_A(J)=∏(J-λᵢI)^{mᵢ}=0，因为每个若尔当块 J_{mᵢⱼ}(λᵢ) 满足 (J-λᵢI)^{mᵢⱼ}=0，而 mᵢ≥mᵢⱼ，所以 (J-λᵢI)^{mᵢ}=0。极小多项式的次数 = 各特征值最大若尔当块大小之和。可对角化矩阵的极小多项式次数 = 不同特征值的个数（所有若尔当块 1 阶）。单个若尔当块的极小多项式次数 = 阶数（=特征多项式次数）。## 退化与边界：若尔当标准形的适用范围### 8.1 实若尔当标准形若尔当标准形要求代数闭域（如复数域），因为需要将特征多项式完全分解为一次因子。在实数域上，实矩阵可能有复特征值（共轭成对），对应的若尔当块是复矩阵。实若尔当标准形用实矩阵代替复若尔当块。对于复特征值 λ=a±bi，对应的 2m 阶实若尔当块是：J_m(a,b) = [[C, I, 0, ...],              [0, C, I, ...],              [...,              [0, ..., C]]其中 C=`[[a,-b],[b,a]]` 是 2×2 旋转-伸缩矩阵，I 是 2×2 单位矩阵。几何上，实若尔当块描述了"在二维旋转平面上的伸缩+剪切"——C 对应旋转角度 arctan(b/a) 和伸缩 √(a²+b²)，次对角线上的 I 对应沿若尔当链的剪切。实若尔当标准形是实矩阵在实相似变换下的标准形，它避免了引入复数，但块结构更复杂（2m 阶块代替 m 阶复块）。### 8.2 非方阵与广义若尔当形若尔当标准形只对方阵有定义（因为相似变换 P⁻¹AP 要求 A 是方阵）。对于非方阵，相应的概念是矩阵束（matrix pencil）A-λB 的克罗内克标准形。矩阵束的克罗内克标准形包含：• 若尔当块（对应有限特征值） • 无穷远若尔当块（对应 B 奇异的情况） • 右奇异块（对应"右最小指数"） • 左奇异块（对应"左最小指数"）奇异块是矩阵束特有的，它们对应于"齐次方程 (A-λB)v=0 有多项式解"的情况。这在广义特征值问题和微分代数方程（DAE）中有重要应用。当 B=I 时，矩阵束退化为常义特征矩阵 λI-A，克罗内克标准形退化为若尔当标准形（没有奇异块和无穷远块）。### 8.3 若尔当标准形的数值不稳定性若尔当标准形在数值计算中是不稳定的——矩阵元素的微小扰动可能导致若尔当块结构的剧烈变化。例如，J₂(0)=`[[0,1],[0,0]]` 的若尔当标准形是它本身（一个 2 阶块）。但微小扰动 J₂(ε)=[[ε,1],[0,0]] 的特征值是 ε 和 0（两个不同特征值），所以可对角化，若尔当标准形是 diag(ε,0)（两个 1 阶块）。这意味着：在浮点计算中，亏损矩阵的若尔当标准形几乎不可能准确计算——舍入误差会将重特征值分裂为不同的特征值，导致若尔当块"碎裂"。实际数值计算中，通常使用 Schur 分解（酉相似三角化）代替若尔当标准形。Schur 分解是数值稳定的，且上三角矩阵包含了若尔当标准形的大部分信息（特征值在对角线上）。**方法论注记**：若尔当标准形是"精确代数"的概念，不适用于"数值计算"。这是理论与计算的一个重要分野。在理论研究中，若尔当标准形是分类的终极工具；在实际计算中，需要使用更稳定的替代方法。### 8.4 无穷维空间的推广在无穷维空间中，算子的"若尔当标准形"推广为谱分解理论，但情况要复杂得多：• **紧算子**：紧算子的非零谱都是特征值，且只能以 0 为聚点。紧算子有类似若尔当形的谱分解，但可能有无穷多个特征值。• **自伴算子**：自伴算子有谱定理，可以对角化（通过投影值测度），但谱可能包含连续谱（不是特征值）。• **一般有界算子**：可能有连续谱、剩余谱，不存在简单的若尔当标准形。算子的结构由谱理论和不变子空间理论描述。若尔当标准形的核心思想（分解为不变子空间的直和，在每个子空间上算子=标量+幂零）在无穷维空间中仍然有效，但"幂零"的概念需要推广为"拟幂零"（谱半径为 0），分解可能是连续的（谱积分）而非离散的（直和）。### 8.5 若尔当标准形与其他标准形的关系若尔当标准形是矩阵理论中多种标准形的"交汇点"：• **与对角形的关系**：若尔当标准形是对角形的推广——当所有若尔当块为 1 阶时，退化为对角形。• **与有理标准形的关系**：有理标准形（友矩阵分块对角）和若尔当标准形通过不变因子↔初等因子的分解联系。有理标准形在任意域上有效，若尔当标准形需要代数闭域。• **与Schur标准形的关系**：Schur 标准形（酉相似上三角）是数值稳定的替代，若尔当标准形是代数精确的分类。上三角矩阵可以进一步通过相似变换化为若尔当形，但这个变换可能是病态的。• **与SVD的关系**：SVD 是等价标准形（允许定义域和值域用不同的正交基），若尔当标准形是相似标准形（用同一组基）。SVD 对所有矩阵（包括非方阵）有效，若尔当标准形只对方阵有效。这些标准形从不同角度刻画了矩阵的结构，共同构成了矩阵理论的"标准形体系"。## 实物验证：三个具体实例### 9.1 实例一：2阶亏损矩阵**设置**：A=`[[3,1],[0,3]]`=J₂(3)。**特征多项式**：det(λI-A)=(λ-3)²。特征值 λ=3，代数重数 2。**几何重数**：A-3I=`[[0,1],[0,0]]`,
