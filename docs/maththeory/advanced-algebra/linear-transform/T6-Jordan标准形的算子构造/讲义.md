1.1 相似分类问题线性代数的核心问题之一：在相似关系下，矩阵可以化简到什么程度？T2 建立了相似理论——相似变换对应换基，相似不变量（特征多项式、最小多项式、迹、行列式）描述了相似类的部分信息。但这些不变量不足以完全决定相似类。例如 J_2(0)⊕J_1(0) 和 J_1(0)⊕J_1(0)⊕J_1(0) 有相同的特征多项式 x³ 和最小多项式 x²（前者）vs x（后者）——最小多项式可以区分。但 J_2(0)⊕J_2(0) 和 J_3(0)⊕J_1(0) 有相同的特征多项式 x⁴ 和最小多项式 x³，却不相似。需要更精细的不变量。**Jordan 标准形定理**给出了完整的答案：在代数封闭域上，每个矩阵相似于唯一的 Jordan 标准形（不计块的排列）。Jordan 标准形是上三角矩阵，对角元是特征值，超对角元是 0 或 1，构成 Jordan 块。### 1.2 算子视角的构造路径传统构造路径（F6）：λ-矩阵 → Smith 标准形 → 不变因子 → 初等因子 → Jordan 形。这条路径计算有效但几何意义不直观。算子视角的构造路径（本模块）：**第一步：准素分解**（T4 第6章）。V=⊕G_λ，其中 G_λ=ker(T-λI)^m 是广义特征空间。在每个 G_λ 上，T=λI+N_λ，其中 N_λ=T-λI 是幂零算子。**第二步：循环分解**（T3 第6章）。在每个 G_λ 上，幂零算子 N_λ 可以分解为循环子空间的直和 G_λ=⊕Z(v_i,N_λ)。每个循环子空间上 N_λ 的矩阵是友矩阵 C(x^k)=J_k(0)（幂零 Jordan 块）。**第三步：组合**。在每个循环子空间上，T=λI+J_k(0)=J_k(λ)（Jordan 块）。所有 Jordan 块的直和就是 T 的 Jordan 标准形。这条路径的每一步都有清晰的几何意义：准素分解按特征值拆分空间，循环分解按"不可约原子"拆分幂零算子，Jordan 块是最终的标准单元。**耦合索引 → F6（λ-矩阵/Smith标准形/初等因子）/ T3（循环分解/准素分解前置）/ T4（广义特征空间/准素分解）/ T2（相似不变量）/ T5（Schur形/对角化）**：F6从λ-矩阵角度构造Jordan形，T6从算子角度构造，两者是同一理论的两种表述。T3的循环分解和T4的准素分解是T6的直接前置。T5的Schur形是Jordan形的数值稳定替代。## 广义特征空间的循环分解### 2.1 幂零算子的循环分解定理**幂零算子循环分解定理**：设 N:V→V 是幂零算子（N^m=0）。则 V 可以分解为循环子空间的直和**V = Z(v₁,N) ⊕ Z(v₂,N) ⊕ ... ⊕ Z(v_k,N)**其中 Z(v_i,N)=span{v_i, Nv_i, ..., N^{d_i-1}v_i}，d₁≥d₂≥...≥d_k≥1，且 N^{d_i}v_i=0。在循环基 {N^{d_i-1}v_i, ..., Nv_i, v_i}（倒序）下，N|_{Z(v_i,N)} 的矩阵是 J_{d_i}(0)（幂零 Jordan 块）。注意基的顺序：用倒序 {N^{d-1}v, N^{d-2}v, ..., Nv, v}，则 N(N^{j}v)=N^{j+1}v（前一个基向量），所以矩阵的超对角元为 1，即 J_d(0)。如果用正序 {v, Nv, ..., N^{d-1}v}，则矩阵是下 Jordan 块（次对角元为 1）。分解的唯一性：d₁,...,d_k（循环子空间的维数）在不计排列的意义下唯一。它们由 N 的核链完全决定（见下一节）。### 2.2 核链与循环子空间维数幂零算子 N 的循环子空间维数分布可以从核链读出：设核链为 {0}=K₀⊂K₁⊂K₂⊂...⊂K_m=V，其中 K_j=ker N^j。定义 r_j=dim K_j - dim K_{j-1}（核链的"增长"）。则：• 维数≥j 的循环子空间个数 = r_j = dim K_j - dim K_{j-1} • 维数恰好=j 的循环子空间个数 = r_j - r_{j+1} = 2 dim K_j - dim K_{j-1} - dim K_{j+1}证明思路：每个维数为 d 的循环子空间 Z(v,N) 对 K_j 的贡献是 min(j,d) 维（因为 N^j 在 Z 上的核是 span{N^{d-j}v,...,N^{d-1}v}，维数 min(j,d)）。所以 dim K_j=Σ min(j,d_i)，差分得到 r_j=#{i:d_i≥j}。这是计算 Jordan 块大小分布的标准方法——只需要计算核链的维度，不需要找到循环向量。### 2.3 循环分解的构造算法构造循环分解的算法（从核链出发）：(1) 计算核链 K₁⊂K₂⊂...⊂K_m=V。 (2) 在 K_m\K_{m-1} 中取向量 v₁（最大指数的循环向量），Z(v₁,N) 是维数 m 的循环子空间。 (3) 在商空间 V/Z(v₁,N) 中，取最大指数的循环向量的提升 v₂，使得 Z(v₂,N)∩Z(v₁,N)={0}。 (4) 重复直到 V 被完全分解。关键引理（提升引理）：如果 v+Z 在商空间中生成维数 d 的循环子空间，则可以选择提升 v 使得 v 在原空间中也生成维数 d 的循环子空间，且与已有循环子空间直和。另一种构造方法（Jordan 链法，下一章详细讨论）：从 ker N 的基出发，逐层提升到 K₂, K₃,...，构造 Jordan 链。这种方法更直接，不需要商空间。### 2.4 从幂零到一般算子对一般线性变换 T，先做准素分解 V=⊕G_λ（T4 第6章）。在每个 G_λ 上，N_λ=T-λI 是幂零算子（因为 (T-λI)^m=0 在 G_λ 上）。对 N_λ 做循环分解 G_λ=⊕Z(v_i,N_λ)，每个循环子空间上 N_λ 的矩阵是 J_{d_i}(0)。所以 T=λI+N_λ 在这个循环子空间上的矩阵是 λI+J_{d_i}(0)=J_{d_i}(λ)（Jordan 块）。组合所有广义特征空间的所有循环子空间，得到 T 的 Jordan 标准形：**T ~ diag(J_{d₁}(λ₁), J_{d₂}(λ₂), ..., J_{d_k}(λ_k))**其中每个 (λ_i, d_i) 对对应一个初等因子 (x-λ_i)^{d_i}。初等因子的多重集合是 T 的完全相似不变量。**几何要点**：Jordan形构造三步：准素分解V=⊕G_λ → 每个G_λ上幂零算子N_λ=T-λI循环分解 → 每个循环子空间对应Jordan块J_k(λ)。核链决定循环子空间维数分布：维数≥j的块数=dim ker N^j - dim ker N^{j-1}。循环基用倒序{N^{d-1}v,...,v}得到上Jordan块。初等因子(x-λ)^k的多重集合是完全相似不变量。## Jordan 链与 Jordan 块的构造### 3.1 Jordan 链的定义设 N 是幂零算子。一个**Jordan 链**（Jordan chain）或**广义特征向量链**是向量序列 {v₀, v₁, ..., v_{k-1}}，满足：Nv₀=0, Nv₁=v₀, Nv₂=v₁, ..., Nv_{k-1}=v_{k-2}等价地，v_j=N^j v_{k-1}（j=0,...,k-1），其中 v_{k-1} 是链的"顶端"（最高阶广义特征向量），v₀ 是链的"底端"（真正的特征向量，Nv₀=0）。对一般算子 T，对应于特征值 λ 的 Jordan 链满足：(T-λI)v₀=0, (T-λI)v₁=v₀, ..., (T-λI)v_{k-1}=v_{k-2}在 Jordan 链基 {v₀, v₁, ..., v_{k-1}} 下，T 的矩阵是 J_k(λ)：Tv_j=λv_j+v_{j-1}（j≥1），Tv₀=λv₀。所以矩阵的第 j 列是 λe_j+e_{j-1}，即对角元 λ、超对角元 1。Jordan 链的长度 k 就是 Jordan 块的大小。链的底端 v₀ 是特征向量，顶端 v_{k-1} 是最高阶广义特征向量（满足 (T-λI)^{k-1}v_{k-1}=v₀≠0 但 (T-λI)^k v_{k-1}=0）。### 3.2 Jordan 链的构造算法构造 Jordan 链的标准算法（从特征向量向上提升）：**第一步**：求 N 的特征向量（ker N 的基），设为 {u₁,...,u_g}（g=几何重数）。每个 u_i 是一个 Jordan 链的底端。**第二步**：对每个 u_i∈ker N，尝试解方程 Nv=u_i。如果有解 v，则 v 是链的上一层（Nv=u_i）。如果无解，则 u_i 所在的链长度为 1（就是 u_i 本身）。**第三步**：对每个 v，继续尝试解方程 Nw=v。如果有解，则 w 是更上一层。重复直到无解。但这个简单算法有问题——ker N 中的向量不一定都能作为链的底端（有些可能是更长链的中间层）。正确的算法需要从最高层开始：**正确算法（从顶端向下）**： (1) 找到最大的 m 使 K_m=ker N^m≠K_{m-1}。 (2) 在 K_m\K_{m-1} 中取向量 v（顶端），则 {N^{m-1}v, N^{m-2}v, ..., Nv, v} 是长度 m 的 Jordan 链。 (3) 在商空间中重复，取次长的链。 (4) 直到所有向量被覆盖。### 3.3 Jordan 链的线性无关性不同 Jordan 链的所有向量构成线性无关组。证明：设链 C_i={v_{i,0},...,v_{i,d_i-1}}（底端 v_{i,0}，顶端 v_{i,d_i-1}）。假设 Σa_{i,j}v_{i,j}=0。用 N^{d_max-1} 作用，只剩下顶端向量的系数（因为 N^{d_max-1} 把低于顶端的向量都消灭了），得到顶端系数为 0。然后用 N^{d_max-2} 作用，得到次顶层系数为 0。依此类推，所有系数为 0。所以 Jordan 链的并集是 V 的一组基（如果链的总长度=dim V）。在这组基下，N 的矩阵是 Jordan 块的直和。Jordan 链的构造本质上是在每个广义特征空间中找到一组"阶梯基"，使得 N 的作用是"向下移位"（Nv_j=v_{j-1}）。这是幂零算子的最简矩阵形式。### 3.4 Jordan 链的例子**例1：J_3(0)**。N=J_3(0)=`[[0,1,0],[0,0,1],[0,0,0]]`。ker N=span{e₁}（底端 e₁）。解方程 Nv=e₁：N(x,y,z)=(y,z,0)=(1,0,0) ⇒ y=1,z=0，v=e₂（N e₂=e₁）。解方程 Nw=e₂：N(x,y,z)=(y,z,0)=(0,1,0) ⇒ y=0,z=1，w=e₃（N e₃=e₂）。Jordan 链 {e₁,e₂,e₃}（底端到顶端），长度 3。**例2：J_2(0)⊕J_1(0)**。N=diag(J_2(0),0)。ker N=span{e₁,e₃}（两个底端）。e₁ 可以提升到 e₂（N e₂=e₁），e₃ 不能提升（N v=e₃ 无解，因为 N 的像=span{e₁}）。所以 Jordan 链为 {e₁,e₂}（长度2）和 {e₃}（长度1）。**例3：一般矩阵**。A=`[[2,1,0],[0,2,1],[0,0,2]]`=J_3(2)。N=A-2I=J_3(0)。Jordan 链 {e₁,e₂,e₃}，对应于 λ=2 的 Jordan 块 J_3(2)。**耦合索引 → T3（循环分解/核链）/ T4（广义特征空间）/ F6（初等因子/Jordan形计算）**：Jordan链是循环子空间的具体基。核链的增长决定Jordan链的长度分布。F6从λ-矩阵角度计算同样的Jordan块大小。## Jordan 标准形定理与唯一性### 4.1 Jordan 标准形定理**Jordan 标准形定理**（代数封闭域上）：设 T 是有限维线性空间 V 上的线性变换。则存在 V 的一组基，使得 T 在这组基下的矩阵为**J = diag(J_{n₁}(λ₁), J_{n₂}(λ₂), ..., J_{n_k}(λ_k))**其中 J_n(λ)=[[λ,1,0,...,0],[0,λ,1,...,0],...,[0,...,0,λ]] 是 n×n Jordan 块。这个矩阵称为 T 的**Jordan 标准形**。在不计 Jordan 块排列顺序的意义下，Jordan 标准形是唯一的。证明（算子视角）： (1) 准素分解 V=⊕G_λ（T4）。 (2) 在每个 G_λ 上，N_λ=T-λI 幂零，循环分解为 Jordan 块 J_{n_i}(0)（T3）。 (3) T=λI+N_λ 在每个循环子空间上是 J_{n_i}(λ)。 (4) 组合所有块得到 Jordan 标准形。 (5) 唯一性：每个特征值 λ 的 Jordan 块大小分布由核链 dim ker(T-λI)^j 唯一决定（第2章），所以唯一。### 4.2 唯一性的详细证明Jordan 标准形的唯一性（不计块排列）：设 T 有两个 Jordan 标准形 J 和 J'。则 J~J'（相似）。需要证明 J 和 J' 有相同的 Jordan 块（不计排列）。**特征值相同**：相似矩阵有相同的特征多项式，所以对角元（特征值）相同（计重数）。**每个特征值的块大小分布相同**：对特征值 λ，考虑 (J-λI)^j 的秩。J-λI 是幂零 Jordan 块的直和（对应 λ 的块）+ 可逆矩阵（对应其他特征值的块，因为 λ_i-λ≠0）。所以 rank(J-λI)^j = Σ_{λ_i≠λ} n_i + Σ_{λ_i=λ} max(0, n_i-j)。这个秩只依赖于 λ 的 Jordan 块大小分布。由于相似矩阵有相同的秩，J 和 J' 的对应秩相同，所以块大小分布相同。等价地，dim ker(J-λI)^j = Σ_{λ_i=λ} min(j, n_i)，这也只依赖于块大小分布。核链的维度完全决定了 Jordan 块的大小分布。所以 J 和 J' 有相同的特征值和相同的块大小分布，即相同的 Jordan 标准形（不计排列）。### 4.3 初等因子与完全不变量Jordan 标准形中的每个 Jordan 块 J_k(λ) 对应一个**初等因子**（elementary divisor）(x-λ)^k。所有初等因子的多重集合称为 T 的**初等因子组**。**定理**：两个矩阵相似 ⇔ 它们有相同的初等因子组。即初等因子组是相似关系的完全不变量。证明：初等因子组完全决定 Jordan 标准形（每个初等因子 (x-λ)^k 对应一个 Jordan 块 J_k(λ)），而 Jordan 标准形决定相似类。反之，相似矩阵有相同的 Jordan 标准形（唯一性），所以有相同的初等因子组。初等因子与不变因子的关系（F6）：不变因子 d₁|d₂|...|d_n 可以分解为初等因子的乘积。每个不变因子 d_i 是若干初等因子的乘积，且整除关系对应于初等因子的分配。从不变因子到初等因子：分解每个 d_i 为不可约因子的幂，所有这些幂就是初等因子。从初等因子到不变因子：按特征值分组，每组按降序排列，然后横向乘积得到不变因子。### 4.4 Jordan 形的性质(1) **对角元**：Jordan 形的对角元是特征值（计代数重数）。 (2) **超对角元**：超对角元为 1 当且仅当对应的两个基向量属于同一个 Jordan 块（且相邻）。 (3) **可对角化**：T 可对角化 ⇔ 所有 Jordan 块都是 1×1 的 ⇔ 超对角元全为 0。 (4) **最小多项式**：m_T(x)=Π(x-λ_i)^{max_j n_{i,j}}（每个特征值取最大块大小）。 (5) **特征多项式**：χ_T(x)=Π(x-λ_i)^{Σ_j n_{i,j}}（每个特征值取块大小之和=代数重数）。 (6) **几何重数**：g(λ)=λ 的 Jordan 块个数。 (7) **代数重数**：a(λ)=λ 的所有 Jordan 块大小之和。 (8) **幂零指数**：T 的零化指数=最大 Jordan 块大小（对零特征值）。**几何要点**：Jordan标准形定理：代数封闭域上每个矩阵相似于唯一的Jordan形（不计块排列）。唯一性证明：核链dim ker(T-λI)^j完全决定块大小分布，而核链是相似不变量。初等因子组(x-λ)^k的多重集合是完全相似不变量。Jordan形性质：对角元=特征值，超对角1=同块相邻，可对角化⇔全1×1块，最小多项式=每个特征值最大块，几何重数=块个数，代数重数=块大小和。## 从 Schur 形到 Jordan 形### 5.1 Schur 上三角化定理**Schur 定理**（复空间）：任何矩阵 A 都可以酉相似于上三角矩阵 U*AU=T，其中 U 是酉矩阵，T 是上三角矩阵，对角元是 A 的特征值。证明（归纳法）：A 有特征值 λ₁ 和单位特征向量 u₁。将 u₁ 扩充为标准正交基 {u₁,...,u_n}，则 U₁*AU₁=[[λ₁, *],[0, A₁]]，其中 A₁ 是 (n-1)×(n-1) 矩阵。归纳地，A₁=U₂*T₂U₂，所以 A=(U₁diag(1,U₂))*diag(λ₁,T₂)(U₁diag(1,U₂))。Schur 形总是存在（复空间上），且可以通过 QR 算法数值稳定地计算。Schur 形的对角元是特征值，但上三角部分不是标准形式——它依赖于基的选择。Schur 形是 Jordan 形的"弱化版"——它只要求上三角，不要求超对角元为 0 或 1。Schur 形不唯一（上三角部分可以变化），但对角元（特征值）唯一。### 5.2 从 Schur 形到 Jordan 形给定 Schur 形 T（上三角），如何进一步化简为 Jordan 形？Schur 形已经是上三角，对角元是特征值。如果特征值互异，则 Schur 形可以进一步对角化（因为特征值互异⇒可对角化）。如果有重特征值，则需要处理重特征值的上三角块。对重特征值 λ，Schur 形中对应 λ 的对角元构成一个上三角块 B（对角元全为 λ）。令 N=B-λI，则 N 是严格上三角矩阵（幂零）。需要找到相似变换将 N 化为幂零 Jordan 形。这可以通过 Jordan 链构造完成：在 N 的广义特征空间中构造 Jordan 链（第3章），得到 N 的 Jordan 形。然后 B=λI+N 的 Jordan 形就是 λI+Jordan(N)。但这个进一步化简（从 Schur 形到 Jordan 形）是数值不稳定的——它需要精确计算广义特征向量，而广义特征向量对扰动高度敏感。所以数值线性代数中通常只计算 Schur 形，不计算 Jordan 形。### 5.3 实 Schur 形对实矩阵，特征值可能是复数（共轭成对）。实 Schur 形是拟上三角矩阵：对角块是 1×1（实特征值）或 2×2（对应共轭复特征值对），2×2 块的形式为 `[[a,b],[c,d]]`，其特征值为 a±bi（b≠0）。实 Schur 形可以通过正交相似得到（不需要复数运算），是实矩阵的数值标准形。从实 Schur 形到实 Jordan 形：1×1 块直接是 Jordan 块 J₁(λ)；2×2 块对应复特征值 a±bi，在实 Jordan 形中保持为 2×2 块 `[[a,-b],[b,a]]`（旋转缩放块）。如果有重的复特征值，实 Jordan 形中会有 2×2 块的直和（对应复 Jordan 块的实表示）。### 5.4 QR 算法与 Schur 形QR 算法是计算特征值的标准数值方法。它通过迭代 A_k=Q_k R_k, A_{k+1}=R_k Q_k（QR 分解后逆序相乘），使 A_k 收敛到 Schur 形（上三角）。QR 算法的收敛性：在一般条件下，A_k 的下三角部分收敛到 0，对角元收敛到特征值。带位移的 QR 算法（Wilkinson 位移）收敛速度是立方级的。QR 算法计算的是 Schur 形，不是 Jordan 形。原因：Jordan 形需要精确的广义特征向量，而广义特征向量对舍入误差极其敏感——在浮点运算中，Jordan 块几乎总是分裂为多个 1×1 块（因为微小的扰动就会让重特征值分离）。所以在实际计算中，"Jordan 形"是一个理论概念，数值上用 Schur 形代替。如果需要 Jordan 形（如符号计算、理论分析），需要用精确算法（有理数运算、λ-矩阵）。**耦合索引 → T5（Schur形/正规算子）/ F2（QR分解）/ T7（数值计算/应用）**：Schur定理在T5引入。QR分解在F2。QR算法是T7数值线性代数的核心。Jordan形的数值不稳定性在第8章详细讨论。## 不变量：初等因子与有理标准形### 6.1 相似不变量的层级线性变换的相似不变量有不同的精细程度：| Frobenius 标准形。有理标准形是友矩阵的直和：T ~ diag(C(d₁), C(d₂), ..., C(d_k))，其中 d₁|d₂|...|d_k 是不变因子，C(d) 是多项式 d(x)=x^n+a_{n-1}x^{n-1}+...+a₀ C((x-λ)^e) 相似于 Jordan 块 J_e(λ)。所以有理标准形→Jordan 标准形。有理标准形的优点：在任何域上都存在，不需要代数封闭性。缺点：友矩阵不如 Jordan 块直观（特征值不直接出现在对角线上）。### 6.3 不变因子与初等因子的转换不变因子和初等因子是同一信息的两种组织方式，可以相互转换。**从不变因子到初等因子**：将每个不变因子 d_i 分解为不可约因子的幂 d_i=Π p_j(x)^{e_{ij}}。所有 p_j(x)^{e_{ij}}（e_{ij}>0）就是初等因子。**从初等因子到不变因子**：按不可约因子分组，每组按指数降序排列。然后构造一个矩阵，每行是一个不可约因子的指数序列（不足补0），每列的乘积就是一个不变因子。不变因子按整除关系升序排列。例子：初等因子 (x-2)^3, (x-2)^1, (x-5)^2。按特征值分组：λ=2: [3,1], λ=5: [2]。构造矩阵（每行一个特征值，按降序）：λ=2: 3,1,0; λ=5: 2,0,0。每列乘积：d₁=(x-2)^0(x-5)^0=1, d₂=(x-2)^1(x-5)^0=x-2, d₃=(x-2)^3(x-5)^2。所以不变因子 1|(x-2)|(x-2)^3(x-5)^2。### 6.4 λ-矩阵视角F6 从 λ-矩阵角度研究 Jordan 形：λI-A 的 Smith 标准形 diag(d₁(λ),...,d_n(λ)) 给出不变因子，初等因子来自不变因子的分解。算子视角和 λ-矩阵视角的对应：• 循环分解 → Smith 标准形 • 零化多项式 d_i → 不变因子 d_i(λ) • Jordan 块 J_k(λ) → 初等因子 (x-λ)^k • 准素分解 → 初等因子按特征值分组 • 核链维度 → 初等因子的指数分布两种视角给出相同的 Jordan 标准形，但算子视角更几何（不变子空间、循环分解），λ-矩阵视角更代数（多项式矩阵、Smith 标准形）。两者互补，共同构成 Jordan 形理论的完整理解。**几何要点**：相似不变量层级：迹/行列式/特征多项式/最小多项式都不完全，不变因子和初等因子是完全不变量。有理标准形=友矩阵直和，在任何域上存在，来自循环分解。代数封闭域上有理标准形→Jordan形。不变因子↔初等因子可相互转换（按不可约因子分组、横向乘积）。算子视角（循环分解）与λ-矩阵视角（Smith标准形）给出同一Jordan形。## Jordan 形的几何意义### 7.1 缩放与剪切的标准叠加Jordan 块 J_k(λ)=λI+N_k 的几何意义是**缩放+剪切**的标准叠加。λI 是均匀缩放（所有方向缩放 λ 倍），N_k 是剪切（把第 j 个方向的分量移到第 j-1 个方向）。在 Jordan 链基 {v₀,v₁,...,v_{k-1}} 中：• Tv₀=λv₀（v₀ 方向纯缩放） • Tv₁=λv₁+v₀（v₁ 方向缩放 λ，同时剪切到 v₀ 方向） • Tv₂=λv₂+v₁（v₂ 方向缩放 λ，同时剪切到 v₁ 方向） • ... • Tv_{k-1}=λv_{k-1}+v_{k-2}（顶端方向缩放 λ，剪切到下一层）所以 Jordan 块描述了一个"级联剪切"系统——每个高阶广义特征向量被变换推到低一阶，同时缩放 λ 倍。这种级联结构是 Jordan 块的几何本质。可对角化变换（所有块 1×1）只有缩放，没有剪切。不可对角化变换（有 >1 的块）包含剪切——剪切是变换"不可对角化"的几何根源。### 7.2 Jordan 块的幂与指数Jordan 块的幂：J_k(λ)^m=(λI+N)^m=Σ_{j=0}^{min(m,k-1)} C(m,j)λ^{m-j}N^j。因为 N^k=0，所以是有限和。矩阵指数：e^{J_k(λ)t}=e^{λt}e^{Nt}=e^{λt}Σ_{j=0}^{k-1}(tN)^j/j!=e^{λt}[[1,t,t²/2,...,t^{k-1}/(k-1)!],[0,1,t,...,t^{k-2}/(k-2)!],...,[0,...,1]]。这解释了线性 ODE dx/dt=Ax 解中的 t^j e^{λt} 项——它们来自 Jordan 块的 N^j 部分。j 的最大值=k-1（最大 Jordan 块大小减 1）。几何意义：Jordan 块对应的解不是简单的指数衰减/增长 e^{λt}，而是多项式×指数 t^j e^{λt}。多项式项来自剪切效应——高阶广义特征向量需要多次变换才能到达特征向量方向。如果 λ 的实部<0，t^j e^{λt} 最终衰减到 0（指数衰减战胜多项式增长），但 transient 阶段可能有增长（多项式增长先于指数衰减）。这就是非正规算子的"瞬态增长"现象。### 7.3 Jordan 形与不变子空间格Jordan 形直接决定了不变子空间格 Lat(T) 的结构（T3 第5章）。单个 Jordan 块 J_k(λ) 的不变子空间格是链：span{v₀}⊂span{v₀,v₁}⊂...⊂span{v₀,...,v_{k-1}}=V。每个不变子空间都是 Jordan 链的前 j 个向量张成的。多个 Jordan 块的直和的不变子空间格是各块格的"子直积"——比简单的乘积格更复杂，因为不同块之间可能有"混合"不变子空间（如果特征值相同）。具体地，如果 T=J_k(λ)⊕J_l(λ)（同特征值的两个块），则存在"混合"不变子空间——不是两个块的不变子空间的直和，而是跨块的组合。例如 span{(v₀, w₀)}（两个块的特征向量的线性组合）是不变的。这使得同特征值多块的不变子空间格更复杂。如果特征值不同，则不变子空间格是各块格的直积（因为准素分解 V=⊕G_λ，不同 G_λ 之间没有混合）。### 7.4 Jordan 形与循环分解Jordan 形是循环分解的"精细化"——循环分解给出有理标准形（友矩阵直和），Jordan 形在代数封闭域上将每个友矩阵进一步分解为 Jordan 块。每个 Jordan 块 J_k(λ) 是循环变换（有循环向量 v_{k-1}，因为 span{v_{k-1}, Jv_{k-1}=λv_{k-1}+v_{k-2}, ...}=全空间）。所以 Jordan 形本身就是循环分解的一种形式——每个块是一个循环子空间。但 Jordan 形的循环分解比一般的循环分解更精细——它按特征值分组（准素分解），且每个循环子空间的零化多项式是 (x-λ)^k（一次因子的幂），而不是一般多项式。Jordan 形的循环向量：每个 Jordan 块的顶端向量 v_{k-1} 是该块的循环向量。所有块的顶端向量构成循环分解的生成元集。**耦合索引 → T3（不变子空间格/循环分解）/ T4（广义特征空间/准素分解）/ T7（微分方程/瞬态增长）**：Jordan块的不变子空间格是T3的具体例子。瞬态增长在T7应用中讨论。## 数值不稳定性与计算### 8.1 Jordan 形的数值不稳定性Jordan 标准形在理论上是唯一的，但在数值计算中极其不稳定。原因：Jordan 块对扰动高度敏感。考虑 J_2(0)=`[[0,1],[0,0]]`。加微小扰动 εE₂₁=[[0,0],[ε,0]]，得到 [[0,1],[ε,0]]，其特征值为 ±√ε——一个 2×2 Jordan 块在任意小扰动下分裂为两个 1×1 块（特征值分离）。更一般地，J_k(λ) 的特征多项式 (x-λ)^k 在小扰动下变为有 k 个不同根的多项式（重根分裂），所以 Jordan 块分裂为 k 个 1×1 块。这意味着：在浮点运算中，几乎不可能观察到大于 1×1 的 Jordan 块——舍入误差就足以让重特征值分离。数值算法（如 QR）计算的是 Schur 形（上三角），而不是 Jordan 形。Jordan 形的不稳定性是"本质的"——不是算法问题，而是问题本身的条件数无穷大。Jordan 块的特征向量矩阵的条件数 κ(V)=||V||||V⁻¹|| 随块大小增长，块越大越病态。### 8.2 伪谱与 Jordan 形Jordan 形的数值不稳定性可以用伪谱（T5 第9章）精确描述。J_k(0) 的 ε-伪谱 σ_ε(J_k(0)) 近似为半径 ε^{1/k} 的圆盘。当 k=2 时，伪谱半径=√ε；当 k=3 时，伪谱半径=ε^{1/3}。块越大，伪谱越大（对相同的 ε）。这意味着：即使 ε 很小（如 10⁻¹⁶，机器精度），对于 k=16 的 Jordan 块，伪谱半径=10⁻¹——特征值的"不确定性"达到 0.1，完全不可信。伪谱解释了为什么大 Jordan 块在数值上不可观测——它们的特征值被大的伪谱"模糊"了，任何小扰动都会让特征值散布在伪谱区域内。在实际应用中，如果数值计算发现特征值聚集在某个区域（而不是离散点），可能意味着存在大 Jordan 块（或非正规性），需要用伪谱分析而不是简单的特征值分析。### 8.3 计算 Jordan 形的精确方法如果确实需要 Jordan 形（如符号计算、理论分析），必须用精确算法：**方法一：λ-矩阵法**（F6）。计算 λI-A 的 Smith 标准形，得到不变因子，分解为初等因子，构造 Jordan 形。需要多项式的精确运算（GCD、因式分解）。**方法二：核链法**。对每个特征值 λ，计算 dim ker(A-λI)^j（j=1,2,...），直到稳定。从核链的差分得到 Jordan 块大小分布。需要精确计算秩（有理数运算）。**方法三：循环向量法**。找到循环向量，构造循环分解，再在每个循环子空间上计算 Jordan 链。需要解线性方程组（精确运算）。所有精确方法都需要有理数或符号运算，不能用浮点数。在计算机代数系统（如 Mathematica、Maple、SymPy）中实现。### 8.4 数值替代：Schur 形与聚类在数值计算中，Jordan 形的替代是 Schur 形（QR 算法计算）。Schur 形是上三角矩阵，对角元是特征值，数值稳定。如果需要判断 Jordan 块结构（如控制理论中的可控性分析），可以用特征值聚类：如果多个特征值非常接近（在机器精度内），可能对应一个 Jordan 块。但这只是启发式，不精确。更可靠的方法是计算核链的数值秩：用 SVD 计算 rank(A-λI)^j，用阈值（如 10⁻¹⁰）判断秩。如果 rank 下降模式与某个 Jordan 块分布匹配，则推断 Jordan 形。但阈值的选择是主观的，结果可能不稳定。在大多数应用中，不需要精确的 Jordan 形——Schur 形和特征值就足够了。Jordan 形主要是理论工具，用于理解变换的结构和证明定理。**几何要点**：Jordan形数值不稳定——J_k(λ)在小扰动下分裂为k个1×1块，伪谱半径ε^{1/k}随块增大。QR算法计算Schur形而非Jordan形。精确计算需要λ-矩阵法/核链法/循环向量法（有理数运算）。数值替代是Schur形+特征值聚类。Jordan形主要是理论工具。## 应用：微分方程与 Markov 链### 9.1 线性常微分方程线性 ODE 系统 dx/dt=Ax 的解为 x(t)=e^{At}x(0)。Jordan 形给出了解的显式结构。如果 A=PJP⁻¹（Jordan 形），则 e^{At}=P e^{Jt} P⁻¹。每个 Jordan 块 J_k(λ) 对应的解包含 e^{λt}, te^{λt}, ..., t^{k-1}e^{λt}。解的渐近行为由特征值的实部决定：• Re(λ)<0：解衰减到 0（稳定） • Re(λ)>0：解增长（不稳定） • Re(λ)=0：解有界（临界，可能有多项式增长如果有 Jordan 块）Jordan 块的存在导致多项式因子 t^j，即使 Re(λ)<0，transient 阶段可能有增长（t^j 先增长后被 e^{λt} 压制）。这在流体稳定性、结构振动中重要。高阶 ODE y^{(n)}+a_{n-1}y^{(n-1)}+...+a₀y=0 可以化为一阶系统，其伴随矩阵的 Jordan 形决定了解的形式。重根对应 Jordan 块，解中出现 t^j e^{λt}。### 9.2 Markov 链Markov 链的转移矩阵 P 是随机矩阵（行和为 1，非负元）。P 的特征值满足 |λ|≤1，且 1 总是特征值（平稳分布对应的特征向量）。Markov 链的收敛性由 Jordan 形决定：• 如果 1 是单特征值（几何重数=代数重数=1），且其他特征值 |λ|<1，则 P^n 收敛到平稳分布矩阵（各行相同）。 • 如果 1 有 Jordan 块（代数重数>几何重数），则 P^n 不收敛（出现 n 的多项式）。但随机矩阵的 1 特征值总是半单的（几何重数=代数重数），因为随机矩阵不可约时 1 是单特征值，可约时每个不可约类贡献一个 1 特征值且都是单的。 • 如果有 |λ|=1 的其他特征值（周期链），则 P^n 振荡不收敛。收敛速度由第二大特征值的模 |λ₂| 决定——|λ₂| 越小收敛越快。Jordan 块（如果存在）会导致多项式因子，减慢收敛。PageRank 是 Markov 链的应用——Google 矩阵的特征值 1 对应 PageRank 向量，第二大特征值决定收敛速度（阻尼因子 0.85 使 |λ₂|≤0.85）。### 9.3 其他应用**控制理论**：线性系统 ẋ=Ax+Bu 的可控性、可观测性由 (A,B) 的 Jordan 形决定。可控性矩阵的秩=最小 A-不变子空间包含 im B 的维数。如果 A 有大 Jordan 块，可控性可能更难满足。极点配置通过反馈将 A 的特征值（Jordan 形）移到期望位置。**量子力学**：厄米算子（可观测量）总是可对角化（没有 Jordan 块），所以量子力学中通常不出现 Jordan 形。但非厄米算子（如有效哈密顿量、开放量子系统）可能有 Jordan 块，对应"例外点"（exceptional points）——特征值和特征向量同时合并的点，在 PT 对称量子力学中重要。**图论**：图的邻接矩阵的 Jordan 形决定了图上随机游走的行为。正则图的邻接矩阵可对角化（因为对称），但有向图的邻接矩阵可能不可对角化，Jordan 块对应图中的"共振"结构。**微分几何**：李代数的表示中，Jordan 形对应幂零元的作用。Jacobson-Morozov 定理将 sl₂ 三元组与幂零元的 Jordan 形联系起来。## 实物验证：三个具体实例### 10.1 实例一：核链计算 Jordan 块分布设置：A=diag(J_3(2), J_2(2), J_1(5))。特征值 2（代数重数5）和 形需要精确（符号）计算。**误区二**："特征值相同的矩阵相似。" → 错。还需要 Jordan 块大小分布相同。J_2(0)⊕J_2(0) 和 J_3(0)⊕J_1(0) 特征值相同（都是0，重数4），但 Jordan 块分布不同（2+2 vs 3+1），不相似。**误区三**："Jordan 链的底端是任意特征向量。" → 错。不是所有特征向量都能作为 Jordan 链的底端——有些特征向量可能是更长链的中间层（在多块情况下）。正确的构造从顶端（最高阶广义特征向量）开始，向下推导出底端。**误区四**："Jordan 形的超对角元都是 1。" → 错。不同 Jordan 块之间的超对角元是 0（因为块之间没有耦合）。只有同一个 Jordan 块内的相邻基向量之间的超对角元才是 1。**误区五**："有理标准形和 Jordan 标准形是一样的。" → 错。有理标准形是友矩阵直和，在任何域上存在；Jordan 形是 Jordan 块直和，需要代数封闭域。在代数封闭域上两者相似，但形式不同。友矩阵的特征值不直接出现在对角线上。**误区六**："最小多项式等于特征多项式意味着矩阵是单个 Jordan 块。" → 错。m=χ 意味着循环变换（每个特征值一个 Jordan 块），但可以有多个特征值。例如 diag(J_2(2), J_3(5)) 的 m=(x-2)²(x-5)³=χ，是循环变换，但不是单个 Jordan 块（有两个块，不同特征值）。**误区七**："实矩阵的 Jordan 形一定是实矩阵。" → 错。如果实矩阵有复特征值，Jordan 形包含复 Jordan 块（如 J₁(i)）。实 Jordan 形用 2×2 旋转缩放块代替复 Jordan 块，是实矩阵的实标准形。## 总结与展望T6 核心结论：Jordan 标准形的算子构造分三步——准素分解 V=⊕G_λ 将空间按特征值拆分，每个 G_λ 上幂零算子 N_λ=T-λI 做循环分解，每个循环子空间对应一个 Jordan 块 J_k(λ)。Jordan 链 {v₀,Nv₀,...,N^{k-1}v₀}（底端到顶端）是构造的基本单元，N v_j=v_{j-1}，在 Jordan 链基下 N 的矩阵是 J_k(0)。核链 dim ker N^j 完全决定
