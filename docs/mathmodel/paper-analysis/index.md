## 每篇精解的标准结构

1. **题目是什么**——一句话说清
2. **获奖等级和亮点**——它凭什么获奖
3. **核心模型拆解**——用了什么方法，为什么有效
4. **可复用的技巧**——我能学到什么，下次比赛能不能用
5. **如果是我来做**——对比自己的思路，差距在哪里
