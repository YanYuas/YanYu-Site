!!! tip "怎么写复盘"
    不要贴整篇论文。写这几个问题就够了：

    1. 拿到题的第一反应是什么，走了哪些弯路
    2. 最终用了什么方法，为什么选它
    3. 哪里卡住了，怎么解决的
    4. 如果重来一次，会改哪里

    这几条才是别人（和三个月后的你）真正想看的。
