## 作品展示原则

不贴整篇论文，只展示：

- 题目理解和核心思路——我是怎么想的
- 用了什么模型，为什么选它——不是什么好用什么，是匹配
- 关键结果和创新点——和普通做法的区别
- 遇到的最大困难和解决方法——最有价值的部分

完整论文和过程文档存在本地，需要时可以提供。
