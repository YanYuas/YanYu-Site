!!! tip "怎么添加一篇新文章"
    1. 在 `posts/` 里新建文件，名字格式：`2026-09-25_标题.md`
    2. 回到这一页，在对应的小节下加一行：

       `- 09-25 [标题](posts/2026-09-25_标题.md)`

    3. 文件名带日期是为了自动按时间排序，避免"最终版2.md"这种混乱

!!! note "什么时候某个主题该独立成板块"
    如果「作曲」下的文章积累到十几篇，就说明它值得单独开一个栏目了。
    那时把文章挪进 `docs/composition/`、在 `mkdocs.yml` 的 `nav` 里加一项即可，
    不需要推倒重来 —— 这就是按主题分小节的好处。
