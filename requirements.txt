# ================================================================
# requirements.txt · Python 依赖清单（零基础自学版）
# ================================================================
# 【这个文件是干什么的】
#   你的网站需要一些 Python 工具包才能运行。
#   这个文件就是"购物清单"——列出所有需要安装的包及其版本号。
#
# 【怎么用】
#   第一次搭建时，在终端运行：
#     .venv\Scripts\python.exe -m pip install -r requirements.txt
#   意思是：用虚拟环境里的 Python，按照这个清单安装所有包。
#
# 【版本号为什么要写死】
#   mkdocs==1.6.1 表示"必须装 1.6.1 这个版本"。
#   写死版本的好处：换一台电脑、过一年再装，装出来的东西完全一样，不会因为
#   某个包升级了导致网站报错。这叫"可复现"。
#
# 【怎么加新包】
#   想装新工具，就在下面加一行，比如：
#     mkdocs-awesome-pages-plugin==2.9.2
#   然后重新运行 pip install -r requirements.txt
# ================================================================

# ---------- 核心：网站引擎 ----------

# MkDocs 本体：把 Markdown 文件变成静态网站的工具
# 官网：https://www.mkdocs.org/
mkdocs==1.6.1

# Material 主题：目前最流行的 MkDocs 主题，提供搜索、导航、深色模式等功能
# 这是你网站外观的基础，所有页面样式都建立在它之上
# 官网：https://squidfunk.github.io/mkdocs-material/
mkdocs-material==9.7.7

# ---------- 中文搜索 ----------

# jieba：中文分词工具
# 【为什么需要它】
#   英文单词之间有空格，搜索引擎天然知道"hello world"是两个词。
#   但中文没有空格，"线性空间的定义"如果不分词，会被当成一整串字符。
#   jieba 能把"线性空间的定义"切成"线性 / 空间 / 的 / 定义"，
#   这样搜"线性空间"才能命中。
# 【怎么触发】
#   由 mkdocs.yml 的 plugins.search.lang: [zh, en] 自动触发，
#   不需要（也不能）在 plugins 里单独声明。
# 【去掉会怎样】
#   中文搜索退化成整词匹配——搜"线性空间"命中不了"线性空间的定义与基本性质"。
jieba==0.42.1

# 注意：必须在 Git 仓库里才有效；没 commit 的新文件不会显示
mkdocs-git-revision-date-localized-plugin==1.6.0

# 让站点能直接渲染 .ipynb（Jupyter 笔记本）文件

# 启用方式：mkdocs.yml 的 plugins 下已登记
