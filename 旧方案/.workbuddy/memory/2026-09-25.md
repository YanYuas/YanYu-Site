## 实战排障：python 命令本身是坏的（15:03）

用户执行 `python -m pip install -r requirements.txt` 报错：`error: uv trampoline failed to spawn Python child process / Caused by: entity not found (os error 2)`。

**根因**：uv 生成的 python.exe 是"跳板程序"（trampoline），只负责转发给真解释器；目标被删除/移动后就报 entity not found。本机 `where python` 首位是 `.workbuddy\binaries\python\versions\3.13.12\python.exe`（坏跳板），`py` 启动器指向已不存在的 `AppData\Local\Programs\Python\Python312`。

**实测可用的解释器（三个都在）**：
- `D:\Environment\Python\cpython-3.13.14-windows-x86_64-none\python.exe` → 3.13.14 ✅
- `D:\Environment\Python\cpython-3.12.13-windows-x86_64-none\python.exe` → 3.12.13 ✅（推荐）
- `D:\Environment\Python\cpython-3.11.15-windows-x86_64-none\python.exe` → 3.11.15 ✅
均为 uv 下载的独立 CPython 构建，pip 26.1.2 可用。uv 版本 0.11.25，位于 `D:\Environment\Python\cpython-3.13.14-windows-x86_64-none\Scripts\uv.exe`。

**给出的三档解法**：① 完整路径 + `&` 调用（立即可用）② `$env:PATH = "..." + $env:PATH` 当前窗口临时生效 ③ 修系统 PATH（GUI：sysdm.cpl → 环境变量 → Path，把好的上移、坏的删除/下移，改前截图备份）。

**给用户的核心知识**：`&` 在 PowerShell 里用于把长路径标记为"这是个程序"；PATH 越靠前优先级越高，改动只对新开的终端生效。
