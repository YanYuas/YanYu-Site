**【V6-A-★-001】** 曲面 $\Sigma:2x^2+2y^2+3z^2+2xy-2xz+2yz+2x-4y-2z-6=0$。按四刀走完：$I_3$ → $I_4$ → 中心与 $F$ → 特征值与标准形，并做三项自检。*（数值见 `v6_ex_output.txt` T1）*

**难度**：★
**对应知识点**：T-V6-01 四量定义、T-V6-02 $I_4=I_3F$、§5.1 中心、§8.5 自检三条
**耦合方向**：V5 四量 → 本模块六量；V4 特征方程 → 三维特征值
**来源**：自拟数据
**完整解答**：

抄系数：$A=\begin{pmatrix}2&1&-1\\1&2&1\\-1&1&3\end{pmatrix}$、$b=(1,-2,-1)$、$c=-6$。

**第一刀，$I_3$**：$\det A=3\neq0$ → 有唯一中心。

**第二刀，$I_4$**：$\det\tilde A=-44\neq0$ → 中心不在曲面上，属"中心型非退化"。

**第三步，中心与 $F$**：$P_c=-A^{-1}b=(-10/3,\ 11/3,\ -2)$，$F(P_c)=c-b^{\mathsf T}A^{-1}b=-44/3=-14.666667$。核对 $I_4=I_3F=3\times(-44/3)=-44$ ✔。

**第四步，特征值与标准形**：$\lambda^3-7\lambda^2+13\lambda-3=0$ 的三个根为

$$0.267949,\quad 3.000000,\quad 3.732051$$

即 $2-\sqrt3$、$3$、$2+\sqrt3$（和 $7=I_1$ ✔、积 $3=I_3$ ✔）。移轴后

$$0.267949x'^2+3y'^2+3.732051z'^2=14.666667$$

三个系数全正、右端正 → **椭球面**。

**自检三条**：$I_1=7$ ✔；$I_3=0.267949\times3\times3.732051=3.000000$ ✔；$I_4=3\times(-14.666667)=-44$ ✔。

**一句话点评**：四刀里前两刀只用行列式，第三步才开始碰 $b$。**顺序不能反**——若先求中心，会先花三分钟解方程组，而 $I_3=0$ 时那组方程根本没唯一解（`V6-R1`）。

**（几何回读）**：中心 $(-3.33,\ 3.67,\ -2)$ 离原点有 $5.2$ 的距离，说明这个椭球被"推"到了左前方。三个特征值 $0.268$ 与 $3.732$ 相差近 $14$ 倍，是最扁的一对轴；按半轴 $\propto1/\sqrt\lambda$ 算，两条轴长比 $\sqrt{3.732/0.268}=\sqrt{13.93}=3.73$。图上是一个被压扁的椭球，扁的方向沿 $\lambda=3.732$ 的特征向量。

**【V6-A-★-002】** 曲面 $\Sigma:x^2+2xy+2y^2-z=0$。它没有中心。请说明"$I_3=0$"如何预先告诉你这件事，然后判类、写标准形。*（数值见 T2）*

**难度**：★
**对应知识点**：T-V6-03 $I_3$ 管有无唯一中心、§8.3 抛物型的移轴失效
**耦合方向**：F6 线性方程组解的存在性 → 本模块"中心方程"
**来源**：自拟数据
**完整解答**：

$A=\begin{pmatrix}1&1&0\\1&2&0\\0&0&0\end{pmatrix}$、$b=(0,0,-1/2)$、$c=0$。

$I_1=3$、$I_2=1$、$I_3=0$ → **中心方程组 $AX=-b$ 的系数矩阵奇异，不能保证唯一解**。这就是"没有中心"的代数信号：$A$ 有一个零特征值，沿该特征方向平移曲面不变，于是"中心"这个概念本身失效。

$I_4=-0.25\neq0$ → 中心不在曲面上，走抛物面支。$I_2=1>0$ → **椭圆抛物面**。

特征值 $0,\ 0.381966,\ 2.618034$（$=(3\mp\sqrt5)/2$）；核方向 $(0,0,1)$；$b$ 在核方向的分量 $-0.5\neq0$ → 无法移轴消一次项。标准形

$$0.381966x'^2+2.618034y'^2-z'=0$$

$K_1=-0.25$、$K_2=-0.75$ 都不参与判定（$I_3\neq0$，`V6-R3`）。

**一句话点评**：$I_3=0$ 不是"退化"的同义词，它是"没有唯一中心"的判据。虚椭球面、椭球面都满足 $I_3\neq0$，锥面满足 $I_3\neq0$ 却也是退化类——**$I_3$ 管的是中心，不是退化**。

**（几何回读）**：沿 $z$ 轴切开是一族水平椭圆，$z$ 越大椭圆越大；它的"顶点"在 $z=0$ 处退化成一点 $(0,0,0)$。所以 $F(0,0,0)=0$ 而 $P_c$ 不存在——**抛物面与它的切平面在顶点"相切到无穷阶"**，这也是它没有中心的几何原因。

**【V6-A-★-003】** 曲面 $\Sigma:x^2+2xy+2y^2-1=0$。判类，并说明"$I_4=0$"为什么是必须的第四刀。*（数值见 T3 第一支）*

**难度**：★
**对应知识点**：T-V6-04 柱面支、T-V6-05 $K_1$ 与实虚
**耦合方向**：S5 柱面 → 本模块不变量判型
**来源**：自拟数据
**完整解答**：

$A=\begin{pmatrix}1&1&0\\1&2&0\\0&0&0\end{pmatrix}$、$b=0$、$c=-1$。

$I_1=3$、$I_2=1$、$I_3=0$、$I_4=0$、$K_1=cI_1=-3$、$K_2=-1$。

四刀：$I_3=0$（无唯一中心）→ $I_4=0$（**整个 $c$ 与 $b$ 都不贡献高阶项，曲面沿某方向无限延伸**）→ $K_2=-1\neq0$（存在非退化截面）→ 柱面；$I_2=1>0$ 且 $K_1=-3<0$ → **椭圆柱面**（实）。

**为什么 $I_4$ 是必须的**：$I_3=0$ 只说明"降了一维"，降成柱面还是降成平面偶，$I_3$ 一个字都说不出。$I_4\neq0$ 时降成抛物面（不是柱面），$I_4=0$ 才可能降成柱面。**少了这一刀，$I_3=0$ 之后的三种可能（抛物面、柱面、平面偶）无法分开。**

**一句话点评**：这道题的方程里根本没有 $z$，一眼看就是柱面。但不变量判据不靠"看见缺项"，它靠 $I_4=0$ 这个可计算的等式——**缺项只是特例，一般方程里的柱面常常看起来满项**（`V6-R2`）。

**（几何回读）**：$x^2+2xy+2y^2=1$ 是一条椭圆，沿 $z$ 平移到一条椭圆柱。判定它"实"的依据是 $K_1<0$：方程能配成"正定二次型 $=1$"，右边为正，有实点。把 $-1$ 改成 $+1$ 得虚椭圆柱（$K_1=3>0$）。

**【V6-A-★-004】** （故意错序）曲面 $\Sigma:x^2-y^2-1=0$。若按"$I_3=0$ 就查 $K_2$、$K_2$ 非零就用 $K_1/I_1$ 定实虚"走，会在哪一步炸？正确走法是什么？*（数值见 T3 第三支）*

**难度**：★
**对应知识点**：T-V6-04、§7.4 `V6-R4`
**耦合方向**：V5 的 $K_1/I_1$ 用法 → 三维的失效
**来源**：自拟数据（专设反例）
**完整解答**：

$I_1=0$、$I_2=-1$、$I_3=0$、$I_4=0$、$K_1=0$、$K_2=1$。

按错误走法：$I_3=0$ → 查 $K_2=1\neq0$ → "柱面" → 用 $K_1/I_1$ 定实虚 → **$K_1/I_1=0/0$，除零**。

正确走法：$K_2\neq0$ ⇒ 柱面；然后**不再看 $K_1$**，直接看 $I_2$ 的符号——$I_2=-1<0$ ⇒ **双曲柱面**（必为实，因为 $x^2-y^2=1$ 显然有实点）。

**双曲柱为什么要绕过 $K_1$**：$I_2<0$ 时二次型不定号，方程 $Q=1$ 一定可解（不定号形式能取到任意实数）。实虚之分只在 $I_2>0$ 的椭圆柱上才需要 $K_1$ 的符号。**"$K_1$ 定实虚"是椭圆柱一条的规则，不是柱面四支的通则。**这正是 `V6-R4`。

**一句话点评**：$I_1=0$ 在二维里意味着"抛物线型"，在三维里只意味着"特征值有正有负或含零"。**同一个 $I_1=0$ 在两种维数下的含义完全不同**，把二维直觉搬过来就会踩这个除零坑。

**（几何回读）**：$x^2-y^2=1$ 是一对双曲线，沿 $z$ 平移成双曲柱。$K_1=0$ 不是"虚"的证据——它的意思是"曲线到原点的最短距离是 0 的某种加权"，与实虚无关。实虚的信息全在 $I_2$ 的符号与 $K_1$ 的符号**在椭圆柱那一支上的配合**上。

**【V6-A-★-005】** 曲面 $\Sigma:x^2+y^2-z^2=0$。判类，并说明它为什么是"自己的渐近锥"。*（数值见 `v6_ex2_output.txt` 第一行）*

**难度**：★
**对应知识点**：T-V6-06 锥面支、§11.4 自洽性
**耦合方向**：S5 锥面 → 本模块 $I_1,I_2,I_3,I_4$ 全为判据
**来源**：自拟数据
**完整解答**：

$A=\mathrm{diag}(1,1,-1)$、$b=0$、$c=0$。

$I_1=1$、$I_2=-1$、$I_3=-1$、$I_4=0$、$K_1=0$、$K_2=0$。

四刀：$I_3=-1\neq0$（有唯一中心，即原点）→ $I_4=0$（中心在曲面上）→ 只剩两支：锥面或点。分界看 $A$ 定号与否：$I_2=-1<0$ 且特征值一正两负 ⇒ 不定号 ⇒ **二次锥面**。

"自己是自己的渐近锥"：渐近锥定义为 $X^{\mathsf T}AX=0$，而这条曲面的方程恰好就是 $X^{\mathsf T}AX=0$。所以 $I_4=0$ 时"曲面 = 渐近锥"是恒等式，不是巧合（`v6_ex2_output.txt` 末段那句"'器'与'非器'只差 $I_4$"）。

**一句话点评**：锥面是十七类里唯一一个"中心型 + 退化"的实类。$I_3\neq0$ 让人以为它跟椭球一样"实心"，$I_4=0$ 才把它打回"退化"。**两个量联手，单看任何一个都会误判**（`V6-R5`）。

**（几何回读）**：$x^2+y^2=z^2$ 是顶点在原点、轴沿 $z$ 的圆锥（半顶角 $45°$）。用 $z=h$ 截得半径 $h$ 的圆，$h$ 与半径同步增长——这是"锥"的直观特征：**截面相似而不等大**。椭球的截面是"先大后小"，一眼可分。

**【V6-A-★-006】** 曲面 $\Sigma:x^2+y^2+z^2=0$。它属于"一点"还是"虚椭球"？与 $\Sigma':x^2+y^2+z^2+1=0$ 的六量差在哪一个数上？*（数值见 `v6_ex2_output.txt`）*

**难度**：★
**对应知识点**：T-V6-06、§7.2 一点与虚椭球
**耦合方向**：V5 的"退化≠无解" → 三维的"一点"与"虚椭球"两支
**来源**：自拟数据
**完整解答**：

$\Sigma$：$I_1=3$、$I_2=3$、$I_3=1$、$I_4=0$、$K_1=0$、$K_2=0$ → $I_3\neq0$、$I_4=0$、$A$ 定号 ⇒ **一点** $(0,0,0)$。

$\Sigma'$：$I_1=3$、$I_2=3$、$I_3=1$、$I_4=1$、$K_1=3$、$K_2=3$ → $I_3\neq0$、$I_4\neq0$、$F=1>0$ 且 $\lambda$ 全正 ⇒ **虚椭球面**。

**【V6-A-★-007】** 曲面 $\Sigma:x^2-y=0$。判类，并指出 $I_2=0$ 时判据为什么不能靠 $I_2$ 自己。*（数值见 T3 第四支）*

**难度**：★
**对应知识点**：T-V6-04 抛物柱支
**耦合方向**：V5 的 $I_2=0$ 抛物型 → 三维的抛物柱
**来源**：自拟数据
**完整解答**：

$A=\mathrm{diag}(1,0,0)$、$b=(0,-0.5,0)$、$c=0$。

$I_1=1$、$I_2=0$、$I_3=0$、$I_4=0$、$K_1=-0.25$、$K_2=-0.25$。

四刀：$I_3=0$ → $I_4=0$ → $K_2=-0.25\neq0$ ⇒ 柱面 → $I_2=0$ ⇒ **抛物柱面**。

**$I_2=0$ 为什么不够**：$I_2=0$ 在三维里的含义是"至少有一个零特征值"（乘积为零）。它同时覆盖抛物面（$I_3=0,I_4\neq0$）与抛物柱（$I_3=I_4=0,K_2\neq0$）与平行平面（$I_3=I_4=K_2=0,I_2=0$）——**三类共用 $I_2=0$**，必须靠 $I_4$ 与 $K_2$ 把它们分开。

**（几何回读）**：$x^2=y$ 是抛物线，沿 $z$ 平移成抛物柱。它的"腰"不在原点而在 $y=0$ 的切线上——$K_1=-0.25$ 正是这个开口宽度的度量（$K_1=-b_2^2/I_1$ 之类）。图上就是一个躺着的、无限长的槽。

**【V6-A-★-008】** （故意错序）曲面 $\Sigma:x^2+y^2=2z$。若跳过 $I_4$ 直接查 $K_2$，会判成什么？它与真值差在哪一整支上？*（数值见本节末的六量核对）*

**难度**：★
**对应知识点**：T-V6-04、§6.4 `V6-R3`
**耦合方向**：F6 二次型 + 一次项 → 本模块"$I_4\neq0$ 的抛物面"
**来源**：自拟数据（专设反例）
**完整解答**：

$A=\mathrm{diag}(1,1,0)$、$b=(0,0,-1)$、$c=0$。

$I_1=2$、$I_2=1$、$I_3=0$、$I_4=-1$、$K_1=-1$、$K_2=-2$。

**真值**：$I_3=0$ → $I_4=-1\neq0$ ⇒ 抛物面；$I_2=1>0$ ⇒ **椭圆抛物面**。

**错序走法**：$I_3=0$ 就直接查 $K_2=-2\neq0$ ⇒ 误判"柱面"；再看 $I_2=1>0$、$K_1=-1<0$ ⇒ 误判"**椭圆柱面**"。

**差在哪一整支**：柱面支与抛物面支。两类的 $I_1=2$、$I_2=1$、$I_3=0$ **完全相同**，唯一的分界是 $I_4$ 为 $-1$ 还是 $0$。$K_2\neq0$ 这件事在抛物面上也成立（$K_2=-2$），所以"$K_2\neq0$ ⇒ 柱面"这条规则本身是错的——**它是 `V6-R3` 的原文**。

**一句话点评**：$K_2$ 之所以在抛物面上非零，是因为抛物面也有"截面"——它的 $K_2$ 在数"垂直于某轴的截线是否退化"，而抛物面的任意竖直截线都不退化。**$K_2$ 的职能被 $I_4$ 抢走了**，只有在 $I_4=0$ 它才有判据资格。

**（几何回读）**：$x^2+y^2=2z$ 是一个开口朝上的碗，$z=0$ 处缩成一点。它看起来"像个柱"是因为 $z$ 方向没有二次项——但 $z$ 方向确实在动（$z$ 越大碗越大），所以不是柱面。**"缺 $z^2$"与"沿 $z$ 平移不变"是两件不同的事**（`V6-R2` 的翻版）。

**【V6-B-★★-001】** 设 $A$ 可逆，$P_c=-A^{-1}b$。证明 $I_4=I_3F(P_c)$，并说明这条等式在"判中心是否在曲面上"里的作用。*（数值见 T1、T2）*

**难度**：★★
**对应知识点**：T-V6-02、§3.3 齐次化
**耦合方向**：F6 分块矩阵行列式 → 本模块 $I_4$
**来源**：自拟证明
**完整解答**：

$\tilde A=\begin{pmatrix}A&b\\b^{\mathsf T}&c\end{pmatrix}$，$A$ 可逆。对 $\tilde A$ 做分块消元：

$$\begin{pmatrix}I&0\\-b^{\mathsf T}A^{-1}&1\end{pmatrix}\begin{pmatrix}A&b\\b^{\mathsf T}&c\end{pmatrix}=\begin{pmatrix}A&b\\0&c-b^{\mathsf T}A^{-1}b\end{pmatrix}$$

左边第一个因子行列式为 $1$，右边是分块上三角，行列式 $=\det A\cdot(c-b^{\mathsf T}A^{-1}b)$。于是

$$I_4=I_3\,F(P_c),\qquad F(P_c)=c-b^{\mathsf T}A^{-1}b$$

$\square$

**作用**：$I_4$ 的符号就是 $F(P_c)$ 的符号（$I_3$ 是常数因子）。所以"$I_4\neq0$"与"$F(P_c)\neq0$"是同一件事，而后者正是"中心不在曲面上"。**这就是第二刀的全部内容**：它问的不是"行列式多大"，是"中心这个点到底在不在曲面上"。

T1 验：$I_3=3$、$F=-44/3$、$I_4=3\times(-44/3)=-44$ ✔（差 $0$）。T2 的 $A$ 奇异，等式不适用——**这条等式有前提，$A$ 可逆才成立**。

**一句话点评**：分块消元这一步就是 Schur 补，它在 G7 §7.2 用过同一步。**同一个代数动作，在 G7 里叫"配方法化简"，在这里叫"I_4 的来源"**——两处说的是同一件事（`V6-R6`）。

**（几何回读）**：$F(P_c)$ 是"把原点搬到中心之后，方程的常数项"。它为零，就是中心落在曲面上；中心在曲面上的中心型二次曲面只有两支——锥面与一点——正是 $I_4=0$ 覆盖的那两支。**"$I_4=0$"与"曲面过自己的中心"是同一句话的两种说法。**

**【V6-B-★★-002】** 方程两边同乘 $k\neq0$，图形不变。证明 $I_1,I_2,I_3,I_4$ 分别乘 $k,k^2,k^3,k^4$，$K_1$ 乘 $k^2$、$K_2$ 乘 $k^3$。*（数值见上述 $k=1,2,3$ 的验算）*

**对应知识点**：T-V6-02、§3.2
**耦合方向**：F6 行列式的多重线性 → 本模块六个量的阶数
**来源**：自拟证明
**完整解答**：

整式乘 $k$ 即 $(A,b,c)\mapsto(kA,kb,kc)$。

- $I_1=\mathrm{tr}(kA)=k\,\mathrm{tr}A=kI_1$（迹是一次量）；

**【V6-B-★★-003】** 平移坐标原点 $(1,-2,0.5)$，$K_1$ 与 $K_2$ 各会怎样变？请用四支实例给出规律，并解释"$K_1$ 只在 $I_3=K_2=0$ 时不动、$K_2$ 只在 $I_3=I_4=0$ 时不动"。*（数值见主验第 5 组）*

**难度**：★★
**对应知识点**：T-V6-05 平移律、§4.3
**耦合方向**：V5 的 $K_1$ 平移律 → 三维再加一条 $K_2$
**来源**：主验第 5 组
**完整解答**：

四支实例，平移 $(1,-2,0.5)$：

| 曲面 | $K_2$ 的改动 | $K_1$ 的改动 |
| --- | --- | --- |
| 椭球 | $9.11\times10^{-3}$ | $0.1879$ |
| 椭圆抛物 | $-2.78\times10^{-2}$ | $-0.2222$ |
| 椭圆柱 | $0$ | $0.1389$ |
| 平行平面 | $0$ | $0$ |

**读法**：

- $K_2$ 在椭球、抛物面上**都变**，在椭圆柱、平行平面上**都不变**。前者 $I_3\neq0$，后者 $I_3=I_4=0$ ⇒ **$K_2$ 只在 $I_3=I_4=0$ 时不动**；
- $K_1$ 在椭球、抛物面、椭圆柱上**都变**，只在平行平面上不变。前者 $I_3\neq0$ 或 $K_2\neq0$，后者 $I_3=K_2=0$ ⇒ **$K_1$ 只在 $I_3=K_2=0$ 时不动**。

**为什么规律是"越退越稳"**：$K$ 之所以在平移下会漂，是因为它们含 $b$（一次项）而 $b$ 随原点移动而变。$I_3=I_4=0$ 时曲面沿某方向无限延伸（柱面），平移若落在"垂直于母线"的方向上才改变 $b$——但柱面的方程不含母线方向的一次项，$b$ 只有垂直分量，而垂直分量的平方在配方后只影响常数项，影响量被 $I_3=0$ 吞掉。$I_3=K_2=0$ 时连截面都塌了（平面偶），$b$ 的残留也消失了。

**一句话点评**：**"半不变量"的"半"字是相对平移说的，不是相对旋转说的。** 旋转下两个 $K$ 都是严格不变的（主验第 4 组：绕 $z$ 转 $37°$，$K_1,K_2$ 改动全 $0$）；平移下它们只在退化支里不变。把"半"理解成"有时不变"没错，但要记住"哪种有时"。

**（几何回读）**：$K$ 不变的条件，几何上是"曲面在某方向上对平移免疫"。柱面对沿母线的平移免疫（但 $b$ 的垂直分量仍变）；平面偶对垂直于平面方向的平移也免疫（因为 $c$ 的变化被已塌的 $I_3$ 吞掉）。**"平移免疫的方向数"就是"退化掉的方向数"。**

**【V6-B-★★-004】** 证明 $I_2=\frac12(I_1^2-\mathrm{tr}A^2)$，并说明这条恒等式对"抄错 $I_2$"有什么诊断价值。*（数值见主验第 10 组）*

**难度**：★★
**对应知识点**：T-V6-01、§3.5
**耦合方向**：F6 特征多项式系数 → 本模块二阶量
**来源**：自拟证明
**完整解答**：

$A$ 实对称，设特征值 $\lambda_1,\lambda_2,\lambda_3$。则 $I_1=\sum\lambda_i$、$I_2=\sum_{i<j}\lambda_i\lambda_j$、$\mathrm{tr}A^2=\sum\lambda_i^2$。展开

$$\frac12\left[\left(\sum\lambda_i\right)^2-\sum\lambda_i^2\right]=\frac12\left[\sum_i\lambda_i^2+2\sum_{i<j}\lambda_i\lambda_j-\sum_i\lambda_i^2\right]=\sum_{i<j}\lambda_i\lambda_j=I_2$$

$\square$

**诊断价值**：$I_2$ 在三维要算**三个**二阶主子式，手算极易只算一个（左上角那个），或算错一个。用迹式复核只需 $\mathrm{tr}A$ 和 $\mathrm{tr}A^2$ 两个数——后者是九个元素平方的和（$A$ 对称，$\mathrm{tr}A^2=\sum_{i,j}a_{ij}^2$），一步可得。

**一句话点评**：这条恒等式是**唯一一条能自检 $I_2$ 的式子**。三个主子式算完必须过一遍它——因为 $I_2$ 一旦错，判据树在 $I_2$ 之后的四支（抛物面两支、柱面两支、平面偶支）全部错位，而前面三刀看起来都对（`V6-R3`）。

**难度**：★★
**对应知识点**：T-V6-07 主径面方程、§5.2–5.3
**耦合方向**：V4 主方向 → 三维主径面
**来源**：自拟证明
**完整解答**：

$A$ 实对称，三个特征向量 $u_1,u_2,u_3$ 可取为标准正交基（实对称矩阵的特征子空间互相正交；重特征值情形在子空间内取正交基即可）。

$$u_i^{\mathsf T}X=-u_i^{\mathsf T}b/\lambda_i\qquad(i=1,2,3)$$

**两两垂直**：两张平面的法向分别是 $u_i$ 与 $u_j$，而 $u_i^{\mathsf T}u_j=0$ ⇒ 垂直。$\square$

**交于中心**：$X=P_c=-A^{-1}b$ 时，$b=-AX=-A\sum x_iu_i=-\sum\lambda_ix_iu_i$，于是 $u_i^{\mathsf T}b=-\lambda_ix_i$，即

**（几何回读）**：三张主径面把空间分成八个卦限，椭球在每个卦限里占同样的八分之一。这也是"椭球有三条互相垂直的对称轴"的来源——**对称轴就是三张面的交线**。抛物面只有两张，因为它沿零特征方向平移不变，那个方向不是"轴"而是"脊"。

**【V6-B-★★-006】** $I_3\neq0$、$I_4=0$ 时，为什么只剩"锥面"与"一点"两支，而没有第三支？两支的分界是什么？*（数值见 `v6_ex2_output.txt` 前两行）*

**难度**：★★
**对应知识点**：T-V6-06、§7.2
**耦合方向**：F6 定号性 → 本模块锥面/点
**来源**：自拟证明
**完整解答**：

$I_3\neq0$ ⇒ 有唯一中心，移轴后

$$\lambda_1x'^2+\lambda_2y'^2+\lambda_3z'^2+F(P_c)=0$$

$I_4=I_3F(P_c)=0$ 且 $I_3\neq0$ ⇒ $F(P_c)=0$，于是

$$\lambda_1x'^2+\lambda_2y'^2+\lambda_3z'^2=0$$

$\lambda_i$ 都不为零（$I_3\neq0$），故只有两种可能：

- **$\lambda$ 不定号**：左边可正可负，零点集是一张实锥（沿三条特征轴各取符号）。~~$I_2<0$~~ → **判据见下方更正段**；
- **$\lambda$ 全同号（定号）**：左边恒同号，只有全零满足，零点集是单点 $P_c$。~~$I_2>0$~~ → 同上。

**没有第三支的原因**：定号情形左端恒 $\geq0$ 或恒 $\leq0$，等号只能在全零取到——这就是"一点"，它没有"虚"的版本（虚椭球要求 $F\neq0$，那是 $I_4\neq0$ 的支）。**"虚锥"这个名字指的就是这个一点**，不是另一个类。

**（更正：$I_2$ 单判会翻车；11-14）** 本题初稿把"不定号／定号"写成"$I_2<0$／$I_2>0$"，**这是错的**。反例：$0.1x^2-y^2-z^2=0$，$\lambda=(0.1,-1,-1)$，

$$I_1=-1.9,\qquad I_2=0.1\cdot(-1)+(-1)(-1)+(-1)\cdot 0.1=0.8>0,\qquad I_3=0.1,\qquad I_4=0 .$$

按初稿判据 $I_2>0$ 应判"一点"，而实际上 $0.1x^2=y^2+z^2$ 是一张**实锥**。$I_2$ 的符号管的是"二阶曲面在某个方向的弯曲"，管不了"三个特征值是否同号"。

**正确判据**：$\lambda$ 定号 $\iff$ $I_2>0$ **且** $I_1I_3>0$。两个方向的论证都不长：

- **定号 $\Rightarrow$ 该条件**：全正时 $I_1,I_2,I_3>0$；全负时 $I_1<0$、$I_3<0$、$I_2>0$（三个两两乘积皆正）。两种都是 $I_2>0$ 且 $I_1I_3>0$。
- **异号 $\Rightarrow$ 该条件不成立**：设一根为正、两根为负（一正两负），则 $I_3=\lambda_1\lambda_2\lambda_3>0$。若此时 $I_2>0$，记 $s=\lvert\lambda_2\rvert+\lvert\lambda_3\rvert$、$p=\lvert\lambda_2\lambda_3\rvert$，条件 $I_2>0$ 就是 $p>\lambda_1 s$；而 $p\le s^2/4$，于是 $\lambda_1<s/4$，从而 $I_1=\lambda_1-s<0$，故 $I_1I_3<0$——条件不成立。设两根为正、一根为负，则 $I_3<0$；若 $I_2>0$，同理逼出 $\lvert\lambda_3\rvert<\lambda_1\lambda_2/(\lambda_1+\lambda_2)$，于是 $I_1>0$，$I_1I_3<0$——同样不成立。

所以"$I_2>0$ 且 $I_1I_3>0$"与"定号"互为充要，**这才是这一支的不变量判据**。上例 $I_1I_3=-0.19<0$，一票否决，判为锥面，正确。

**这一处与 V5-B-006 是同一件事的两次出现**：二维里 $I_1I_3$ 在 $I_2>0$ 下判"实／虚椭圆"、在 $I_2<0$ 下失去指示力；三维里 $I_1I_3$ 必须与 $I_2$ 联手才判得出"锥／点"。**同一个乘积 $I_1I_3$，在两个维数里都得配一个条件才成判据**——这不是巧合，因为两者的分母都是 $I_2$ 携带的"二阶信息"。

**（翻译等价，11-14 补）** 这条判据要当等价用，两个方向都得写：

- **正向（符号 $\Rightarrow$ 图形）**：$\lambda$ 定号 $\Rightarrow$ 方程 $\lambda_1x'^2+\lambda_2y'^2+\lambda_3z'^2=0$ 只有全零解 $\Rightarrow$ 零点集是单点；$\lambda$ 不定号 $\Rightarrow$ 至少一个特征方向使左端取正、另一个使其取负 $\Rightarrow$ 由连续性存在零点集包含三条特征方向上的射线 $\Rightarrow$ 实锥。
- **反向（图形 $\Rightarrow$ 符号）**：若零点集只有一点，则任取非零 $X'$ 都有 $X'^{\mathsf T}AX'\neq0$；又 $X'$ 与 $-X'$ 给出同号的二次型值、取遍所有方向时符号不变，所以 $A$ 定号。若零点集含一条过中心的射线 $t\vec u$（$t\in\mathbb R$），则 $t^2\vec u^{\mathsf T}A\vec u=0$ 对 $t\neq0$ 成立，故 $\vec u^{\mathsf T}A\vec u=0$，即 $A$ 有一个零特征方向或沿 $\vec u$ 变号——在 $I_3\neq0$（无零特征值）的前提下只能是变号，即不定号。

**两边合起来：这里"锥／点"的区分不是"看起来像什么"，而是 $\lambda$ 的定号性；而定号性又被 $I_2,I_1I_3$ 的符号完全决定。** 三层说法（图形、$\lambda$ 符号、不变量符号）互为翻译，缺任何一层这条判据都站不稳。

实测：锥 $x^2+y^2-z^2=0$，$I_1=1,I_2=-1,I_3=-1,I_4=0$ ⇒ 锥面；一点 $x^2+y^2+z^2=0$，$I_1=3,I_2=3,I_3=1,I_4=0$ ⇒ 一点。

**一句话点评**：$I_4=0$ 把"椭球／虚椭球"那一对（$I_4\neq0$）压成"锥／点"这一对。**压的方式是：$F$ 从"可正可负"变成"必须为零"，于是"右端符号"这个自由度消失了，只剩"左端是否定号"。**自由度少一个，类数就从四降到二。

**$z=h$ 一族**：

| $h$ | 截线 | 半径／状态 |
| --- | --- | --- |
| $0$ | $x^2+y^2=1$ | $1.0000$ |

**过中心的斜截**：$ax+by+cz=0$ 与球交得大圆，半径恒 $1$——因为单位球对任意过中心的平面截口都是大圆。

**（几何回读）**：把四张 $z=h$ 的圆按 $h$ 排起来，就是球的样子——**半径随 $h$ 先不变后减小，直到零**。这正是"封闭曲面"的截口特征。若换成单叶双曲面，同样的表会变成"先减小后增大"，中间有一格的半径最小（喉部）。

**【V6-C-★★★-003】** 单叶双曲面 $x^2+y^2-z^2=1$ 过点 $(1,0,0)$ 的直母线方向是 $(0,1,\pm1)$。请给出两族的参数化通式，验证 $\lambda=1$ 给出 $(0,1,1)$ 那一条，并说明"两族"与"可展"的关系。*（数值见 T6）*

**难度**：★★★
**对应知识点**：T-V6-09 直母线、§10.5
**耦合方向**：S5 柱锥 → 本模块双族直纹
**来源**：T6 + 自拟
**完整解答**：

**通式**（由 $(x+z)(x-z)=(1+y)(1-y)$ 引入参数）：

$$\frac{x+z}{1+y}=\frac{1-y}{x-z}=\lambda$$

化为两条平面方程：$x+z=\lambda(1+y)$、$1-y=\lambda(x-z)$。$\lambda$ 取遍实数得**第一族**；把 $\lambda\mapsto1/\lambda$、$y\mapsto-y$ 得**第二族**。

**验 $\lambda=1$**：第一式 $x+z=1+y$，第二式 $1-y=x-z$。两式相加得 $2z=2y$，即 $z=y$——方向 $(0,1,1)$ ✔，过 $(1,0,0)$（$1+0=1+0$ ✔）。

**T6 的数值验证**：取 $\lambda$ 族上过 $(1,0,0)$ 的直线，$t=-2,0,3$ 三点代入原方程，$F$ 全部为 $0.00\times10^0$——**整条直线落在曲面上**，不是切点。

**两族与可展**：两族都存在，且**相邻两条母线异面**（不相交也不平行），所以曲面**不可展**（高斯曲率为负）。柱面只有一族且相邻母线平行，故可展（高斯曲率为零）。**"直纹"是拓扑性质（有没有直线），"可展"是度量性质（能不能摊平）**，两个概念必须分开。

**一句话点评**：$\lambda$ 的通式不是"猜出来的技巧"，它是**因式分解的直接产物**。二次曲面里只有单叶与双曲抛物面能做这种分解（因为它们的方程是"两平方差 = 常数"或"两平方差 = 一次项"），其余十五类都做不了。**"能不能分解"就是"有没有双族直纹"的代数判据。**

**（几何回读）**：一条母线绕轴旋转，扫出整个单叶双曲面——**这就是"单叶"这个名字的来源：它不是"一张叶片"，是"一族直线的旋转面"**。手放在腰上转一圈，掌心的那条直线永远贴着曲面。

**【V6-C-★★★-004】** 曲面 $x^2+y^2-z^2=1$ 的渐近锥是什么？沿渐近方向取三点，$F$ 的值如何？由此说明"$F$ 恒定"与"点在锥上"的关系。*（数值见主验第 11 组）*

**难度**：★★★
**对应知识点**：§11.4 渐近锥
**耦合方向**：S5 锥面 → 本模块渐近结构
**来源**：主验第 11 组
**完整解答**：

曲面 $I=(1,-1,-1,1)$（即 $I_1=1,I_2=-1,I_3=-1,I_4=1$）。渐近锥定义为只取二次部分：

$$x^2+y^2-z^2=0$$

沿渐近方向 $d=(0,\ 0.7071,\ 0.7071)$ 取 $t=0.1,\ 1,\ 10$，得三点 $(0,\ 0.0707,\ 0.0707)$、$(0,\ 0.7071,\ 0.7071)$、$(0,\ 7.0711,\ 7.0711)$，$F$ 全部 $-1.000000$。

**读法**：$F=X^{\mathsf T}AX-1$（$b=0$、$c=-1$）。沿 $d$ 有 $d^{\mathsf T}Ad=0-0.5+0.5=0$，故 $X^{\mathsf T}AX=0$ 对任意 $t$ 成立，$F\equiv-1$。

**"$F$ 恒定"与"点在锥上"的关系**：$F$ 恒等于常数 ⟺ 二次部分沿该方向恒为零 ⟺ **这条直线平行于锥的母线**。若换一个非渐近方向（如 $(1,0,0)$），$F=t^2-1$ 随 $t$ 二次增长，立刻露馅。

**注意一个容易误读的点**：这三点的 $F$ 是 $-1$ 不是 $0$。$-1$ 正是 $c$ 的值，说明**它们落在"把 $c$ 挪到原点后"的锥上**。曲面本身在 $t$ 变化时 $F$ 恒 $-1\neq0$，意味着这条线**不在曲面上**，只在锥上。

**一句话点评**：这道题的价值在于分清三种"在"：在曲面上（$F=0$）、在渐近锥上（$X^{\mathsf T}AX=0$）、在这条母线方向上（$F$ 恒定）。**三者只差一个常数项，肉眼难分，代数上一目了然。**

**（几何回读）**：单叶双曲面被它的渐近锥"穿过"（$I_4>0$），双叶则被锥"夹住"（$I_4<0$，把 T1 类的 $c$ 改符号即得）。**锥面是曲面在无穷远处的"极限形状"**——离开原点越远，曲面越贴近锥。冷却塔的轮廓线（双曲线）与它的渐近直线，正是这个关系的二维版。

**【V6-C-★★★-005】** 主径面为什么是"镜像对称面"？请写出反射矩阵并给出数值证据，再说明抛物面为什么只有两张。*（数值见主验第 13 组）*

**难度**：★★★
**对应知识点**：§5.5、T-V6-07
**耦合方向**：V4 主方向 → 三维的镜面对称
**来源**：主验第 13 组
**完整解答**：

法向 $u$ 的反射矩阵 $M=I-2uu^{\mathsf T}$（$u$ 单位）。若 $u$ 是 $A$ 的单位特征向量，在特征基 $\{u_1,u_2,u_3\}$ 下 $M=\mathrm{diag}(-1,1,1)$，$A=\mathrm{diag}(\lambda_1,\lambda_2,\lambda_3)$，于是

$$M^{\mathsf T}AM=\mathrm{diag}(\lambda_1,\lambda_2,\lambda_3)=A$$

**数值证据**（主验第 13 组）：逐张主径面反射，$A$ 的最大改动 $4.88\times10^{-15}$——$A$ 不变，即二次部分关于三面对称。

**抛物面只有两张**：$A$ 有一个零特征值 $\lambda_3=0$，第三张主径面的方程 $u_3^{\mathsf T}X=-u_3^{\mathsf T}b/0$ 无意义。几何上，沿 $u_3$ 方向平移曲面不变，**"镜面"变成了"平移面"**——这不是镜面对称，是平移对称。**抛物面的对称结构是"两张镜子 + 一个平移"，只有椭球类才是"三张镜子"。**

**柱面只有一张**：$A$ 有两个零特征值，只剩一张真镜面；另两个方向是平移对称（沿母线方向平移不变，垂直于母线的方向？不，柱面垂直方向没有平移对称）。准确说：柱面沿母线方向有无穷多平移对称面（任意平行于母线的平面），但镜面只有一张。

**一句话点评**："对称"在三维里有三种（镜面、旋转轴、平移），**主径面只对应第一种**。教材把"主径面"和"对称面"当同义词用，在中心型上没错，在抛物面上会误导（`V6-R7`）。

**（几何回读）**：椭球在每个卦限占八分之一，所以它有八块全等的"皮"。抛物面没有这种"八块"结构，它只有"上下两半"（$z$ 正半与 $z$ 负半不对称）——**"块数"就是"镜面数"的几何读数**。

**【V6-C-★★★-008】** 化简同一类曲面，两条路径：先转轴再移轴，与先移轴再转轴。请用中心型一支与抛物型一支各演示一次，说明为什么抛物型必须"先转轴"。*（数值见 T1、T2）*

**难度**：★★★
**对应知识点**：§8.4 动作顺序
**耦合方向**：V5 化简顺序 → 三维抛物型的特殊性
**来源**：T1、T2 + 自拟
**完整解答**：

**中心型（T1，先移轴也可以）**：$A$ 可逆，$P_c$ 存在。先移轴把原点搬到 $P_c$，一次项全消（因为 $P_c$ 就是 $AX+b=0$ 的解）；再转轴，交叉项全消。得到 $\lambda_1x'^2+\lambda_2y'^2+\lambda_3z'^2=-F$。**结果是 $0.267949x'^2+3y'^2+3.732051z'^2=14.666667$。**

**抛物型（T2，先移轴不行）**：$A$ 奇异，$AX=-b$ 无解（$b$ 在核方向分量 $-0.5\neq0$）。先移轴：$X\mapsto X+X_0$ 后方程变成

$$x'^2+2x'y'+2y'^2-z'+(2b^{\mathsf T}X_0-1)\ \text{（一次项没消尽）}$$

**核方向的一次项永远消不掉**——因为沿核方向平移不改变二次部分，只能改变常数与核方向一次项的系数，而后者永远与平移量成正比。**先把核方向定下来（转轴），才能知道哪一项消不掉、哪一项能消。**

**正确顺序（T2）**：转轴把 $A$ 对角化，得到 $0.381966x'^2+2.618034y'^2-z'=0$ 的形式；再沿核方向平移，如果 $b$ 的核分量为零就能消，这里不为零（$-0.5$），所以**只平移不消项，直接把一次项留下来作为"抛物项"**。

**一句话点评**：**"先移轴"的前提是"移轴能消一次项"，而这个前提只有中心型满足。** 抛物型强行先移轴，会在无解方程组上卡住，或者移完发现还有线性项——**这不是"顺序偏好"，是"可行性问题"**（`V6-R1` 的核心）。

**（几何回读）**：中心型曲面的"心"是唯一确定的点，所以先找心再摆正方向很自然。抛物型没有心，它只有"脊"（核方向）与"顶点"（$z=0$ 处的一点）。**先定脊（转轴），再定顶点（平移），这是唯一的次序。**

**【V6-D-★★★-004】** （接 V5）V5 给出二维九类，V6 给出三维十七类。请说清"类"的口径：是"$I$ 值相同"还是"实仿射等价"？并回答"椭球与单叶能不能通过某个变换互换"。*（接口：V5 §5.5、F6 惯性定理）*

**难度**：★★★
**对应知识点**：§9.4、T-V6-10
**耦合方向**：V5 九类口径 → 本模块十七类口径
**来源**：自拟
**完整解答**：

**口径是"实仿射等价类"**，不是"$I$ 值相同"。

理由：$I$ 是不变量，按 $I$ 分组只能得到"不变量相同的集合"，那不是轨道。**轨道要比"两个曲面能否由同一个实仿射变换互变"。**

**大部分类都是单个轨道**：椭球这一类里 $a,b,c$ 的比值可以用仿射变换连续调节，所以"椭球"整体是一个轨道。

**但有三处不是"不变量相同即同类"**：

- 椭球与虚椭球：$I$ 的绝对值可以相同（只差符号），但一个是实点集、一个是空集，**实仿射变换保"有实点"这件事**，故不互变；
- 一点与虚椭球：同理，不互变；
- 单叶与双叶：$I_1,I_2,I_3$ 的绝对值都相同，只差 $I_4$ 的符号，但一个是连通的、一个是两叶分开的，**仿射变换保连通性**，故不互变。

**椭球与单叶能不能互换**：**不能。** 因为惯性指数（正、负、零特征值的个数）是仿射不变量（F6 §3 的 Sylvester 惯性定理）：椭球 $(3,0,0)$，单叶 $(2,1,0)$。惯性指数不同，仿射轨道就不同。**这条是十七类"互斥"的最终依据。**

**一句话点评**：十七类里"看起来只差一个符号"的组有好几对（椭球/虚椭球、单叶/双叶、平行/虚平行、相交/虚相交），**每一对的差别都恰好是"某个仿射不变量"的符号**。这不是巧合：**实虚之分在仿射几何里对应"是否有实点"，而"是否有实点"由二次型的符号决定**。

**（几何回读）**：仿射变换可以把球压成椭球、把圆压成椭圆，但**不能把"封闭"压成"张开"**（那是拓扑性质）。十七类按仿射轨道分，实际上也是按"拓扑型 + 惯性指数"分。

**【V6-D-★★★-005】** （接 X1 微分几何）单叶双曲面与柱面都是直纹面，为什么一个不可展、一个可展？请用高斯曲率的符号解释，并指出这条结论在什么意义上超出解析几何的范围。*（接口：X1 微分几何；数值：无小数，定性）*

**难度**：★★★
**对应知识点**：§10.5、§10.4
**耦合方向**：解析几何直纹 → 微分几何可展性
**来源**：自拟
**完整解答**：

**判据**：可展曲面 $\iff$ 高斯曲率 $K=0$（处处为零）。

- **柱面**：沿母线方向的法曲率为零（母线是直线），另一主方向的曲率半径有限，故 $K=0$ ——**可展**；
- **单叶双曲面**：两条主方向的曲率符号相反（一个方向向内弯、一个方向向外弯），$K<0$ ——**不可展**；
- **双曲抛物面**：同理 $K<0$，**不可展**。

**几何图像**：柱面的两条相邻母线**平行**，把曲面沿母线剪开可以摊平；单叶的两条相邻母线**异面**，摊平时必撕裂。**"异面"是"不可展"的几何根源。**

**超出解析几何的地方**：$K$ 是度量量（由第一、第二基本形式算出），**在解析几何的不变量体系里没有对应物**。$I_1..I_4$、$K_1,K_2$ 六个量全是代数量，它们区分不了"单叶"与"双曲抛物"之外的更多结构（这两类本来就不同类）。**"可展性"必须离开代数不变量，进入微分几何。**

**一句话点评**：这条题的意义是划边界——**V6 的六个量能把十七类分完，但分完不等于理解了曲面**。$K$ 的符号、主曲率、渐近线，都是六个量给不出的信息。**V6 是"分类的终点"，不是"曲面的终点"**。

**（几何回读）**：把单叶的一小块剪下来，纸是撕不平的——只能撕碎。柱面的一小块能平铺在桌上。**"能不能平铺"是手感，$K=0$ 是它的数学名字。**
