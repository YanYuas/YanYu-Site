## 研究摘要

**核心命题**：数学里的"向量"不是有向线段，而是有向线段的一个等价类。有向线段带起点，自由向量不带起点——两者之间隔着一层"同向同长"的等价关系。中学教材把这一层当作常识直接跳过，代价是学生只会算不会判：知道怎么平移，却说不清凭什么可以平移，也就不知道什么时候不能平移。本模块的全部工作，是把这层被跳过的定义补上，并把它与位置向量、仿射空间、线性空间三条线索接起来。

**研究问题**：(RQ1) "两个向量相等"的充要条件是什么？"同向同长"为什么恰好等于"可平移重合"，这个等价依赖什么几何前提？(RQ2) 自由向量与位置向量是什么关系？位置向量为什么必须依赖原点，而点差为什么又不依赖？(RQ3) 自由向量的八条运算律为什么不是"规定"，而是几何操作的代数记录？

**研究方法**：定义辨析 + 几何回读 + 反例探边。每个代数定义先还原为一次几何操作（平移、伸缩、反向），再用五个边界反例钉住定义的边界；三个数值实例（相等判定、两法则一致性、换原点实验）经 Python 3 + numpy 复算；史料部分以 Hamilton、Grassmann、Gibbs 三条独立路径核对"向量"概念的实际形成过程。

**核心结论**：向量相等 ⇔ 同向且同长 ⇔ 可平移重合 ⇔ 以两向量为边构成平行四边形（顺序为 A-B-D-C）。四条说法互为充要，其中"可平移重合"是欧氏平行公理的产物，不是定义的附加条款。自由向量构成三维实向量空间（八律成立），位置向量则是把点"寄生"在向量上的临时手段：换原点，位置向量全变，点差不变。这一变一不变，正是仿射结构与向量空间的分界线。

**一句话定位**：向量不是箭，是箭的等价类；把这句话讲清楚，等于把"几何对象"与"代数对象"的第一道翻译关卡讲清楚。

## 一、引言：一个被跳过的定义

### 1.1 两道题的答案不一样

先看两道题。

**第一题**：已知 $A(1,2)$、$B(3,5)$、$C(0,1)$、$D(2,4)$，判断向量 $\overrightarrow{AB}$ 与 $\overrightarrow{CD}$ 是否相等。

高中做法：$\overrightarrow{AB}=(2,3)$，$\overrightarrow{CD}=(2,3)$，坐标差相同，所以相等。判得又快又对。

**第二题**：两个力，大小都是 10 N，方向都向东，一个作用在桌角，一个作用在桌面中心。这两个力是"同一个力"吗？

物理答案：不是。作用点不同，产生的力矩不同，效果不同。

两道题的判定标准冲突了：第一题说"起点不同不影响相等"，第二题说"起点不同就是不同"。哪个对？

都对，但前提不同。第一题里的对象是**自由向量**——起点被约定为可以随意挪动，起点信息根本不属于这个对象；第二题里的对象是**作用在一点的力**——作用点属于这个对象，挪了就不是同一个东西。

数学解析几何取的是第一种。教材第一章开篇就写"向量可以平移"，然后整章都在用这条性质，但**没有交代这条性质的资格从哪来**。这不是教材的疏忽，是课程的取舍：解析几何把"自由向量"当前概念用，把它的严格构造留给代数（等价类、商集）。取舍有代价：学生记住了"可以平移"，却不知道"为什么可以"，一旦遇到不能平移的对象（力、场、法向量场、切向量场），就分不清是题目特殊还是自己记错。

### 1.2 教材为什么跳过

翻开吕林根第四版第一章：1.1 给"向量"的定义——"既有大小又有方向的量叫向量"，然后说"我们只考虑自由向量，即可以平行移动的向量"；1.2 讲加法，直接给三角形法则；1.3 讲数乘。从头到尾，"相等"是默认的，"平移"是允许的，没有一处证明。

这个写法在数学上不算错，因为"自由向量"确实可以作为原始概念引入——就像欧氏几何把"点、线、面"作为原始概念一样。但它留下三个空洞：

其一，**"相等"是等价关系**这件事没被验证。自反、对称是白送的，传递性不是：若 $\overrightarrow{AB}$ 与 $\overrightarrow{CD}$ 同向同长，$\overrightarrow{CD}$ 与 $\overrightarrow{EF}$ 同向同长，凭什么 $\overrightarrow{AB}$ 与 $\overrightarrow{EF}$ 同向同长？直觉上显然，但"显然"在定义辨析里是禁词。

其二，**"可平移"与"同向同长"为什么等价**没被说明。这两句话一个是操作（平移），一个是判据（同向同长）。它们等价，依赖欧氏空间的平行公理——在非欧空间里，"同向同长"的两条测地线段未必能平移重合。

其三，**位置向量与自由向量的关系**没被区分。教材用 $\overrightarrow{OP}$ 表示点 $P$，这叫位置向量。位置向量带起点 $O$，它其实不是自由向量，而是"被钉住起点的有向线段"。同一个点，换一个原点，位置向量就变了。学生常常把"点的坐标"和"向量的坐标"混为一谈，根源就在这层没有分开。

本模块把这三个空洞补上。补法不是加定义，而是把定义拆开看：哪个是原始的，哪个是构造的，哪个是定理冒充定义。

### 1.3 本模块的路线

按五阶走：先定位（要辨清的是哪一对等价），再锚定基石（五个定义加一个位置向量），再双向拆（构造与解释），再直观验证（八律的几何对应），最后收敛（一张关系图谱、五条易错）。

中间插入两块本体系特有的内容：**六语言表**（同一个向量在六种语言里的六副面孔）与**几何回读**（每个代数结论后面补一段"这在图上是什么"）。

最后三节是史料、数值实验与反例库。史料不承担证明，只回答一个问题：为什么今天的向量长成"箭头"这个样子，而不是别的样子。

## 二、阶1 充要定位

### 2.1 本质逻辑问题

本模块要辨清的核心等价只有一对：

$$\overrightarrow{AB}=\overrightarrow{CD}\ \Longleftrightarrow\ \text{同向}\ \wedge\ \text{同长}$$

围绕这一对，还有三条等价的改写，必须一起证：

$$\text{同向}\wedge\text{同长}\ \Longleftrightarrow\ \text{平移可重合}\ \Longleftrightarrow\ ABDC\ \text{是平行四边形}\ \Longleftrightarrow\ A+D=B+C$$

四条说法看起来是同一句话的四种口音。但它们的证明难度不同：第一条是定义，第二条要平行公理，第三条要平行四边形判定，第四条要位置向量代数。把这四条串成一条链，本模块的核心就立住了。

### 2.2 问题类型与拆解路径

问题类型：**定义本质探究**。不是定理证明，不是计算训练，是把一个被当作常识的定义拆到骨头。

拆解路径：**双向完整**。充分性方向（怎么造出一个向量）与必要性方向（从一个相等的判断能推出什么）都要走。

预判核心误区，五条：

1. **把方向与长度当成两个独立条件**。实际上它们是同一个等价关系的两个坐标，"同向"负责方向分量，"同长"负责长度分量，缺一不可。
2. **把"平行"当成"相等"的必要条件用反**。相等 ⇒ 平行（同向必平行），但平行 ⇏ 相等。这是单向关系被误当充要的典型。
3. **把"起点相同"当成相等的条件**。自由向量里起点不参与判定；反而"起点相同且终点相同"只是相等的一个特例。
4. **把零向量的方向当成"任意"**。零向量的方向没有定义，不是"任意方向"。"任意"是一个可选取的集合，"没有定义"是空。
5. **把位置向量当成自由向量**。位置向量带起点，换原点就变；把它当自由向量，会在"点的坐标"与"向量的坐标"之间来回串味。

### 2.3 这一阶的产出

一句话：本模块要回答的不是"向量怎么算"，而是"两个向量什么时候是同一个"。这个问题在中学被跳过，在大学被默认，在物理里被否定——三种态度都有道理，区别只在"起点是否属于对象"。

## 三、阶2 基石锚定

### 3.1 原始概念

本课程不做公理化，只借三个直觉概念：**点**、**方向**、**长度**。点不带结构，方向与长度是欧氏空间的度量特征。三者的严格化分别属于几何基础（X3）与度量几何，本模块只使用，不追问。

这里要立一条纪律：**只用原始概念与已给定义，不用高阶定理做循环论证**。比如不能用"平行四边形对边相等"去证明"相等 ⇒ 可平移重合"，因为平行四边形的性质本身要靠向量相等来定义。

### 3.2 定义链

**定义 D1（有向线段）**：给定两点 $A$、$B$（允许 $A=B$），有序点对 $(A,B)$ 连同从 $A$ 到 $B$ 的直线段，称为一条有向线段，记 $\overrightarrow{AB}$。$A$ 叫起点，$B$ 叫终点。

有向线段是**带起点**的对象。$\overrightarrow{AB}$ 与 $\overrightarrow{BA}$ 是两条不同的有向线段：起点终点互换，方向相反（$A\neq B$ 时）。

**定义 D2（同向同长）**：两条有向线段 $\overrightarrow{AB}$、$\overrightarrow{CD}$ 称为同向同长，若

- 它们所在直线平行（含共线），且从 $A$ 到 $B$ 与从 $C$ 到 $D$ 的走向一致；
- $|AB|=|CD|$。

"走向一致"是一个需要小心的表述。它的精确意思是：把 $A$ 平移到 $C$ 后，$B$ 落在射线 $CD$ 上，而不是落在反向射线上。在平面与空间中，"走向一致"可以定义为"存在一个平移，把 $A$ 送到 $C$，把 $B$ 送到 $D$"。这个定义是循环的吗？不是——它用"平移"这个操作来定义"同向"，而平移是欧氏空间的等距变换，属于原始操作。后面 4.2 会说明这个循环风险如何被切断。

**定义 D3（自由向量）**：所有有向线段按"同向同长"分类，每一个等价类称为一个自由向量。即

$$\vec{a}=[\overrightarrow{AB}]=\{\overrightarrow{CD}:\ \overrightarrow{CD}\ \text{与}\ \overrightarrow{AB}\ \text{同向同长}\}$$

方括号读作"等价类"。同一个等价类里的任何一条有向线段，都叫这个向量的一个**代表**。

这一步是关键：自由向量**不是**一条线段，是一堆线段。你画出来的那支箭，只是这堆里挑出来的一个代表。换一个代表画，还是同一个向量。

**定义 D4（相等）**：$\vec{a}=\vec{b}$ 当且仅当它们作为等价类相同，即存在代表 $\overrightarrow{AB}\in\vec{a}$、$\overrightarrow{CD}\in\vec{b}$ 使二者同向同长。

**定义 D5（反向量与零向量）**：

- 反向量：$-\vec{a}$ 是 $\vec{a}$ 的所有代表反向后的等价类。若 $\vec{a}=[\overrightarrow{AB}]$，则 $-\vec{a}=[\overrightarrow{BA}]$。
- 零向量：$\vec{0}=[\overrightarrow{AA}]$，所有起点终点重合的有向线段归为一类。$|\vec{0}|=0$。

零向量的方向**没有定义**。教材常写"零向量与任何向量平行"，这是人为约定（为了让"平行"关系在零向量处不至于失效），不是从定义推出的性质。约定与定理必须分清，这是本模块的一条纪律。

### 3.3 等价关系三性

D3 用"分类"造对象，必须验证"同向同长"确实是等价关系，否则分类不成立。

- **自反**：$\overrightarrow{AB}$ 与自己同向同长。成立（长度相等、走向一致都是自反的）。
- **对称**：若 $\overrightarrow{AB}$ 与 $\overrightarrow{CD}$ 同向同长，则反之亦然。成立，因为两条判据都是对称的。
- **传递**：若 $\overrightarrow{AB}\sim\overrightarrow{CD}$，$\overrightarrow{CD}\sim\overrightarrow{EF}$，则 $\overrightarrow{AB}\sim\overrightarrow{EF}$。

传递性的证明分两半：

长度：$|AB|=|CD|$ 且 $|CD|=|EF|$ $\Rightarrow$ $|AB|=|EF|$，这是实数相等的传递性。

方向：$AB$ 与 $CD$ 走向一致，$CD$ 与 $EF$ 走向一致 $\Rightarrow$ $AB$ 与 $EF$ 走向一致。这一步依赖：三条直线彼此平行（平行的传递性），且三条线段在同一"走向"上。平行的传递性在欧氏平面与空间成立（平行公理的推论）；走向的一致性可这样验证：取平移 $T_1$ 把 $A$ 送到 $C$、$B$ 送到 $D$，取 $T_2$ 把 $C$ 送到 $E$、$D$ 送到 $F$，则复合平移 $T_2\circ T_1$ 把 $A$ 送到 $E$、$B$ 送到 $F$，故 $AB$ 与 $EF$ 同向同长。复合平移是平移，平移把直线送到平行直线——这条链把传递性证完了，且没有循环。

这段证明看似琐碎，价值在于：它把"显然"换成了"依赖平行公理"。凡是依赖平行公理的结论，在非欧几何里都可能失效（见 4.3 反例 E1-R7）。

### 3.4 位置向量

**定义 D6（位置向量）**：固定一点 $O$ 作为原点，对任意点 $P$，有向线段 $\overrightarrow{OP}$ 的等价类称为点 $P$ 关于原点 $O$ 的位置向量，记 $\vec{r}_P=\overrightarrow{OP}$。

注意三件事：

第一，位置向量是自由向量的一个特例用法：$\overrightarrow{OP}$ 本身是一条带起点的线段，取它的等价类才成为向量。所以"位置向量"严格说是"以 $O$ 为起点的代表所对应的自由向量"。

第二，这个对应依赖 $O$。换原点 $O'$，同一个点 $P$ 的位置向量变成 $\overrightarrow{O'P}$，与原来不同。用代数写：

$$\overrightarrow{O'P}=\overrightarrow{OP}-\overrightarrow{OO'}$$

（因为 $\overrightarrow{O'P}=\overrightarrow{O'O}+\overrightarrow{OP}=-\overrightarrow{OO'}+\overrightarrow{OP}$）。全体位置向量整体平移了一个 $-\overrightarrow{OO'}$。

第三，这个对应是双射：固定 $O$ 后，点与向量一一对应。于是"点"可以借"向量"的代数结构做运算——这就是坐标法能成立的底层机制。但双射依赖 $O$ 的选择，所以它不是"自然的"，是"人为约定"的。仿射几何的全部麻烦，都从这个人为主张开始。

### 3.5 判定方向与性质方向

按充要图谱的写法，每个定义都要拆成两个方向：

| 定义 | 判定方向（充分） | 性质方向（必要） |
| --- | --- | --- |
| 自由向量 | 给定同向同长的一族线段 $\Rightarrow$ 它们属于同一个向量 | 属于同一个向量 $\Rightarrow$ 任取两个代表必同向同长 |
| 相等 | 同向且同长 $\Rightarrow$ 相等 | 相等 $\Rightarrow$ 同向且同长 |
| 反向量 | 同长且反向 $\Rightarrow$ 互为反向量 | 互为反向量 $\Rightarrow$ 同长反向 |
| 零向量 | 长度为零 $\Rightarrow$ 是零向量 | 是零向量 $\Rightarrow$ 长度为零且方向无定义 |
| 位置向量 | 固定原点后取 $\overrightarrow{OP}$ 的类 $\Rightarrow$ 是 $P$ 的位置向量 | 是位置向量 $\Rightarrow$ 依赖所选原点，换原点即变 |

这张表是全模块的骨架。后面所有的辨析、反例、易错，都挂在这五行的某一格上。

## 四、阶3 充要双拆

### 4.1 充分性：构造

要得到"两个向量相等"的结论，有四种构造路径，对应四种证明风格。

**构造一（几何型）**：给定两点 $A$、$B$，作有向线段 $\overrightarrow{AB}$，取等价类。再用平移把 $A$ 送到 $C$、$B$ 送到 $D$，得到 $\overrightarrow{CD}$。若 $C$、$D$ 恰为给定点，则 $\overrightarrow{AB}=\overrightarrow{CD}$ 立即成立——因为它们是同一个等价类的两个代表。

这条路径的优点是"不证自明"：相等由构造保证，不需要判据。缺点是无法回答"给定两条线段，它们是否相等"这类判定问题。

**构造二（判据型）**：分别算方向与长度。方向用"所在直线平行且走向一致"判，长度用距离公式算。两条都成立则相等。

这条路径适合坐标已知的情形：设 $A(x_1,y_1,z_1)$、$B(x_2,y_2,z_2)$，则

$$\overrightarrow{AB}=(x_2-x_1,\ y_2-y_1,\ z_2-z_1)$$

两个向量相等 ⇔ 三组坐标差分别相等。这是中学最常用的判法，本质上是把"同向同长"翻译成"坐标差相等"。

**构造三（平行四边形型）**：若 $ABDC$ 是平行四边形（注意顺序：$A\to B$ 与 $D\to C$ 是对边），则 $\overrightarrow{AB}=\overrightarrow{CD}$。反之亦然。

这条路径的价值是把"相等"与一个**图形性质**挂钩。它解释了为什么中学课本总用平行四边形讲向量加法：平行四边形是"两个相等向量"的图形化身。

**构造四（代数型）**：固定原点，用位置向量。$\overrightarrow{AB}=\overrightarrow{CD}\iff \vec{r}_B-\vec{r}_A=\vec{r}_D-\vec{r}_C\iff \vec{r}_A+\vec{r}_D=\vec{r}_B+\vec{r}_C$。最后这个式子有几何意义：两条对角线 $AD$、$BC$ 的中点重合。

四条路径给出的是同一个对象，只是四种语言（几何操作、判据、图形、代数）。六语言表的第 1、2、3、4 行，在这里第一次显形。

### 4.2 必要性：解释

假设已知 $\vec{a}=\vec{b}$，能推出什么？逐条拆。

**第一条：同向。** 由定义 D4，相等意味着存在代表同向同长。但"存在代表"不等于"所有代表"都同向——需要验证等价类的良定性：若 $\overrightarrow{AB}\sim\overrightarrow{A'B'}$，$\overrightarrow{CD}\sim\overrightarrow{C'D'}$，且 $\overrightarrow{AB}\sim\overrightarrow{CD}$，则 $\overrightarrow{A'B'}\sim\overrightarrow{C'D'}$。这由传递性（3.3）保证。所以"相等"作为一个类的性质，与代表的挑选无关。

这一条是本模块技术上最容易被跳过的地方。跳过它，"相等"就变成"某两条具体线段同向同长"，而不是"两个类相同"。差别看似细微，后果在坐标表示上会暴露：同一个向量在不同基下坐标不同，若相等依赖代表，就会出现"坐标不同则向量不同"的谬误。

**第二条：同长。** 由定义直接得到，$|\vec{a}|=|\vec{b}|$。

**第三条：可平移重合。** 这是最值得推敲的一条。它说的是：存在平移，把 $\vec{a}$ 的任一个代表搬到 $\vec{b}$ 的任一个代表上。

证明：设 $\vec{a}=[\overrightarrow{AB}]$，$\vec{b}=[\overrightarrow{CD}]$，且同向同长。考虑平移 $T$：把 $A$ 送到 $C$。平移是等距变换，故 $T(B)$ 到 $C$ 的距离等于 $|AB|=|CD|$，且 $T(B)$ 落在过 $C$ 且平行于 $AB$ 的直线上——即直线 $CD$ 上。直线 $CD$ 上有两个点与 $C$ 距离为 $|CD|$：$D$ 与 $D$ 的反向点 $D'$。由于 $AB$ 与 $CD$ 走向一致，$T(B)$ 落在 $D$ 而不是 $D'$。故 $T(B)=D$，$T$ 把 $\overrightarrow{AB}$ 搬到 $\overrightarrow{CD}$。

这里用到了三个东西：平移是等距（欧氏度量）、平行的传递与唯一性（平行公理）、走向一致（D2）。三者缺一，证明断链。

**第三条的逆**：若存在平移把一个代表搬到另一个代表，则两者同向同长——平移保距、保方向。故"可平移重合" ⇔ "同向同长"，这是一条充要等价，而不是单向推论。

**第四条：坐标差相等。** 固定标架后，$\vec{a}=\vec{b}\Rightarrow$ 坐标差相等。反向也成立（坐标差相等 ⇒ 同向同长）。这条把几何等价翻译成代数等价，是 E3 的伏笔。

### 4.3 边界探针

定义的边界要靠反例钉住。七个反例，逐个说明它违反了哪条直觉。

**反例 E1-R1（同向不同长）**：$\overrightarrow{AB}=(1,0)$，$\overrightarrow{CD}=(2,0)$。同向，不等长，故不相等。违反的直觉："方向一样就是同一个方向上的向量，差不多相等"。纠正：长度是等价关系的独立坐标，不能由方向替代。

**反例 E1-R2（同长反向）**：$\overrightarrow{AB}=(1,0)$，$\overrightarrow{CD}=(-1,0)$。同长，反向，不相等，互为反向量。违反的直觉："长度一样、在同一条线上，就是一回事"。纠正：方向有正负，反向量与向量是两类。

**反例 E1-R3（平行不等）**：$\overrightarrow{AB}=(1,0)$，$\overrightarrow{CD}=(-3,0)$。平行，长度不同，方向相反，不相等，也不是反向量（反向量要求同长）。违反的直觉："平行就有关系"。纠正：平行是必要不充分条件；相等 ⇒ 平行，平行 ⇏ 相等。

**反例 E1-R4（零向量的方向）**：$\vec{0}$ 与任意 $\vec{a}$ 都"平行"（约定），但 $\vec{0}$ 与 $\vec{a}$（$a\neq0$）不相等。若强行给零向量定义方向角 $\theta=\arctan(0/0)$，数值计算会得到 $\theta=0$ 或 NaN（见第 11.4 节实验），两种结果都不合法。违反的直觉："平行就该方向相同，零向量平行于所有向量，所以零向量方向任意"。纠正：约定"平行"与"方向有定义"是两件事；零向量的方向是空集，不是全集。

**反例 E1-R5（力偶）**：两个大小方向相同的力，分别作用在 $A$、$B$ 两点。作为自由向量，它们相等；作为物理对象，只要 $A$、$B$ 的连线不平行于力的方向，两者的力矩就不同（一个使物体转动，一个只使物体平移）。违反的直觉："数学说相等，物理就该一样"。纠正：相等是**在某个模型内**的相等。自由向量模型把作用点信息扔掉了，所以它无法区分力偶——这不是数学的缺陷，是建模的取舍。注意：若力的方向恰好沿 $A$、$B$ 连线，两者力矩相同，"不等效"就不成立；所以这条反例的准确说法是"作用点信息被丢弃"，不是"任何情况下都不等效"。

**反例 E1-R6（异基同向量）**：同一个向量 $\vec{a}=(1,1)$，在标准基下坐标是 $(1,1)$，在斜基 $\{e_1=(1,0),\ e_2=(1,1)\}$ 下坐标是 $(0,1)$（因 $0\cdot e_1+1\cdot e_2=(1,1)$）。坐标不同，向量相同。违反的直觉："坐标不一样就不是同一个向量"。纠正：坐标是向量在某个基下的**地址**，不是向量本身；这正是 E3 要展开的主题。

**反例 E1-R7（非欧平移）**：在球面上，"同向同长"的两条大圆弧段未必能平移重合——球面上没有真正的平移（等距变换是旋转）。于是"相等 ⇔ 可平移重合"这条等价在球面几何里失效。违反的直觉："平移总是可以的"。纠正：这条等价的资格来自欧氏平行公理；换几何，资格就没了。这是 X3（几何公理体系）的伏笔。

七个反例，覆盖了方向、长度、起点、零元、模型、表示、公理七个维度。任何一个定义，边界都在这七个方向上。

### 4.4 不可逆步骤标注

沿 4.2 的四条推论，标出哪一步不可逆：

| 步骤 | 方向 | 是否可逆 | 说明 |
| --- | --- | --- | --- |
| 相等 ⇒ 同向同长 | ⇒ | 可逆 | 定义本身，双向成立 |
| 同向同长 ⇒ 可平移重合 | ⇒ | 可逆 | 需平行公理，欧氏内双向成立 |
| 相等 ⇒ 坐标差相等 | ⇒ | 可逆 | 固定标架后双向成立 |
| 相等 ⇒ 平行 | ⇒ | **不可逆** | 平行推不出相等（反例 E1-R3） |
| 同长 ⇒ 相等 | ⇒ | **不可逆** | 同长推不出相等（反例 E1-R1、E1-R2） |
| 同向 ⇒ 相等 | ⇒ | **不可逆** | 同向推不出相等（反例 E1-R1） |
| 零向量平行于 $\vec{a}$ ⇒ 方向相同 | ⇒ | **不可逆** | 零向量方向无定义（反例 E1-R4） |

三条可逆步骤构成本模块的"充要主干"；四条不可逆步骤构成"单向枝"。学习时容易把单向枝当主干用，这就是 2.2 里预判的"把平行当相等"的根源。

## 五、阶4 直观验证

### 5.1 加法：三角形法则与平行四边形法则为什么等价

**三角形法则**：把 $\vec{b}$ 平移，使它的起点落在 $\vec{a}$ 的终点；从 $\vec{a}$ 的起点到 $\vec{b}$ 的终点作向量，定义为 $\vec{a}+\vec{b}$。

**平行四边形法则**：把 $\vec{a}$、$\vec{b}$ 平移到同一起点；以二者为邻边作平行四边形；从公共起点出发的对角线定义为 $\vec{a}+\vec{b}$。

两条法则给出同一个结果，理由只有一句：平行四边形对边平行且相等，所以"从 $\vec{a}$ 终点接 $\vec{b}$"的那条折线，恰好是平行四边形的另一组对边。图形上，三角形是平行四边形的一半。

这个等价不是"两种记法"，而是**交换律的几何证明**：

$$\vec{a}+\vec{b}=\vec{b}+\vec{a}$$

证明：在平行四边形 $OACB$ 中，$OA$ 与 $BC$ 同向同长，$OB$ 与 $AC$ 同向同长。沿 $O\to A\to C$ 走，得 $\vec{a}+\vec{b}$；沿 $O\to B\to C$ 走，得 $\vec{b}+\vec{a}$。两条路径终点都是 $C$，起点都是 $O$，由 4.2 的必要性，两个和向量相等。交换律得证，且证法只用了几何，没有用坐标。

这就是"几何回读"的第一次完整示范：**代数里的一条交换律，在图上是一次"两条路径殊途同归"**。

### 5.2 数乘：伸缩与反向

**定义**：$\lambda\vec{a}$（$\lambda\in\mathbb{R}$）规定为：

- $|\lambda\vec{a}|=|\lambda|\,|\vec{a}|$；
- $\lambda>0$ 时与 $\vec{a}$ 同向，$\lambda<0$ 时反向；
- $\lambda=0$ 或 $\vec{a}=\vec{0}$ 时为零向量。

几何上，数乘是一次以起点为定点的伸缩：$\lambda>1$ 拉长，$0<\lambda<1$ 压短，$\lambda<0$ 翻转并伸缩，$\lambda=0$ 把整支箭压成一个点。

三个值得注意的边界：

其一，$\lambda=0$ 时**方向信息被彻底抹掉**：不论原向量朝哪，结果都是零向量。所以"数乘不改变方向"这句话只在 $\lambda\neq0$ 时成立。

其二，数乘不改变**所在直线**（$\lambda\neq0$ 时），只改变长度与指向。因此 $\vec{a}$ 与 $\lambda\vec{a}$ 共线——这是 E2 里"线性相关"的几何原型：一个向量能由另一个数乘表示，就是共线。

其三，$\lambda$ 的"数"是实数，不是有理数或整数。有理数伸缩只能得到可公度的长度，实数伸缩才能得到任意长度——这是欧氏连续性的用法，也是"向量空间建立在 $\mathbb{R}$ 上"的第一处体现。

### 5.3 减法：从被减数指向减数

$$\vec{a}-\vec{b}=\vec{a}+(-\vec{b})$$

几何上：当 $\vec{a}$、$\vec{b}$ 同起点 $O$ 时，$\vec{a}-\vec{b}=\overrightarrow{BA}$，即**从 $\vec{b}$ 的终点指向 $\vec{a}$ 的终点**。

口诀："差的箭头指向被减数"。这句口诀覆盖了中学所有"用向量表示边"的题：$\overrightarrow{AB}=\vec{r}_B-\vec{r}_A$，终点减起点。

减法最容易错的地方是把方向弄反。检验办法只有一个：代回定义。$\vec{r}_B-\vec{r}_A$ 的起点应当是 $A$、终点应当是 $B$，因为 $\vec{r}_A+(\vec{r}_B-\vec{r}_A)=\vec{r}_B$。加法验证通过，方向就对了。这是"用逆运算检验方向"的标准动作。

### 5.4 八律的几何回读

自由向量的八条运算律，不是"规定"，是几何操作的代数记录。逐条回读：

| 律 | 代数式 | 几何回读 |
| --- | --- | --- |
| 加法交换 | $\vec{a}+\vec{b}=\vec{b}+\vec{a}$ | 平行四边形两条路径殊途同归（5.1） |
| 加法结合 | $(\vec{a}+\vec{b})+\vec{c}=\vec{a}+(\vec{b}+\vec{c})$ | 三段折线首尾相接，先接哪一段不影响终点 |
| 零元 | $\vec{a}+\vec{0}=\vec{a}$ | 平移零长度，箭不动 |
| 负元 | $\vec{a}+(-\vec{a})=\vec{0}$ | 沿原路返回起点，净位移为零 |
| 数乘对矢量分配 | $\lambda(\vec{a}+\vec{b})=\lambda\vec{a}+\lambda\vec{b}$ | 把平行四边形整体按 $\lambda$ 缩放，对角线同步缩放（相似变换） |
| 数乘对标量分配 | $(\lambda+\mu)\vec{a}=\lambda\vec{a}+\mu\vec{a}$ | 同方向两次伸缩的叠加等于一次合成伸缩 |
| 数乘结合 | $\lambda(\mu\vec{a})=(\lambda\mu)\vec{a}$ | 连续两次缩放等价于一次按乘积缩放 |
| 单位元 | $1\cdot\vec{a}=\vec{a}$ | 不缩放 |

八条里，"数乘对矢量分配"值得单独说：它的几何内容是**相似变换保平行四边形**。把邻边同时缩放 $\lambda$ 倍，对角线也缩放 $\lambda$ 倍——这是平面几何的相似判定，被代数写成了一条分配律。反过来看，若这条律不成立，解析几何里所有"按比例设点"的技巧都会垮掉。

### 5.5 第一次互译：用向量证两条平面几何定理

八律不是摆设。它们一经成立，就能把一批需要辅助线的平面几何定理改成"算完即证完"。选两条最经典的，看互译的实际收益。

**定理一（三角形中位线）**：设 $M$、$N$ 分别是 $AB$、$AC$ 的中点，则 $MN\parallel BC$ 且 $|MN|=\dfrac12|BC|$。

向量证明：取任意原点，$\vec r_M=\dfrac{\vec r_A+\vec r_B}{2}$，$\vec r_N=\dfrac{\vec r_A+\vec r_C}{2}$。于是

$$\overrightarrow{MN}=\vec r_N-\vec r_M=\frac{\vec r_C-\vec r_B}{2}=\frac12\overrightarrow{BC}$$

一个等式同时给出两个结论：系数 $\dfrac12>0$ 说明同向（故平行），模为一半说明长度关系。传统证法要连辅助线、造平行四边形、用全等；向量证法只做了一次减法与一次数乘。

这里的关键不是"向量更快"，而是**向量把"平行"与"长度比"这两个结论合并成了一个等式**。几何证明里它们是两件事，代数里它们是同一件事的两个坐标——这正是 6.2 关系图谱中"相等 ⇒ 平行"那条单向枝的实际用法。

**定理二（对角线互相平分）**：四边形 $ABCD$ 的对角线 $AC$、$BD$ 互相平分 ⇔ $ABCD$ 是平行四边形。

向量证明：设对角线交点为 $M$。$M$ 平分 $AC$ ⇔ $\vec r_M=\dfrac{\vec r_A+\vec r_C}{2}$；$M$ 平分 $BD$ ⇔ $\vec r_M=\dfrac{\vec r_B+\vec r_D}{2}$。两式相等 ⇔ $\vec r_A+\vec r_C=\vec r_B+\vec r_D$ ⇔ $\vec r_C-\vec r_B=\vec r_D-\vec r_A$ ⇔ $\overrightarrow{BC}=\overrightarrow{AD}$ ⇔ 一组对边平行且相等 ⇔ $ABCD$ 是平行四边形。

整条链只用了一次"中点 = 平均"、一次移项、一次相等判据。4.1 构造四里那句 $\vec r_A+\vec r_D=\vec r_B+\vec r_C$ 与这里的 $\vec r_A+\vec r_C=\vec r_B+\vec r_D$ 只差下标顺序——它们分别是"$AB=CD$"与"$AD=BC$"的代数化身。两组对边分别相等，说的都是"对角线中点重合"。

值得停一下：这两条定理的向量证明，都没有用到"平行公理"以外的任何几何事实。也就是说，它们属于**仿射几何**的定理（只涉及平行与比），不属于欧氏几何（不涉及长度与角）。这个分层判断，是 V7 群链的第一课：定理属于哪个群，看它用了哪些不变量。

## 六、阶5 收敛沉淀

### 6.1 一句话本质

**向量相等，就是两个有向线段属于同一个"同向同长"的等价类；向量的全部代数自由，都来自这个等价类允许你随时换代表。**

### 6.2 关系图谱

用 ⇔ / ⇒ / ⊬ 三种符号（⊬ 表示推不出，必附反例）：

$$\vec{a}=\vec{b}\ \Leftrightarrow\ \text{同向}\wedge\text{同长}\ \Leftrightarrow\ \text{可平移重合}\ \Leftrightarrow\ ABDC\ \text{为平行四边形}\ \Leftrightarrow\ \vec r_A+\vec r_D=\vec r_B+\vec r_C$$

$$\vec{a}=\vec{b}\ \Rightarrow\ \vec{a}\parallel\vec{b}\qquad(\text{反之}\ \not\Rightarrow,\ \text{反例 E1-R3})$$

$$|\vec{a}|=|\vec{b}|\ \not\Rightarrow\ \vec{a}=\vec{b}\qquad(\text{反例 E1-R1、E1-R2})$$

$$\vec{a}\parallel\vec{b}\ \wedge\ |\vec{a}|=|\vec{b}|\ \Leftrightarrow\ \vec{a}=\vec{b}\ \vee\ \vec{a}=-\vec{b}\qquad(\vec{a},\vec{b}\neq\vec{0})$$

$$\vec{0}\parallel\vec{a}\ (\text{约定})\ \not\Rightarrow\ \vec{0}\ \text{与}\ \vec{a}\ \text{同向}\qquad(\text{反例 E1-R4})$$

$$\overrightarrow{OP}=\overrightarrow{OQ}\ \Leftrightarrow\ P=Q\qquad(\text{固定同一原点})$$

$$\overrightarrow{PQ}=\vec r_Q-\vec r_P\quad(\text{与原点选择无关，见 9.2})$$

这张图谱是全模块的收敛物。做题时若卡住，先定位卡在哪一条：是"平行当相等"（第三条错用），还是"同长当相等"（第四条错用），还是"位置向量当自由向量"（最后两条混用）。

### 6.3 高频易错

1. **最易搞反的方向**：把 $\vec{a}\parallel\vec{b}$ 当成 $\vec{a}=\vec{b}$ 的充要条件。正确是单向：相等 ⇒ 平行。
2. **最易遗漏的条件**：判断相等时漏掉"同向"，只比长度；或漏掉"同长"，只比方向。
3. **最易误当充要的单向条件**：$|\vec{a}|=|\vec{b}|$ 与 $\vec{a}\parallel\vec{b}$ 各自都是必要不充分；两者合起来（排除零向量）才成为"相等或互为反向"。
4. **最易混淆的对象**：位置向量与自由向量。前者带原点，后者不带；判断"点的坐标相等"和"向量相等"时不能混用同一个判据。
5. **最易忽略的约定**：零向量与任何向量"平行"是人为规定，方向无定义。凡涉及夹角、方向余弦、单位化的式子，必须先把零向量排除。

### 6.4 迁移题

**题目**：正六边形 $ABCDEF$ 的中心为 $O$。在所有以这七个点为起点和终点的有向线段中，与 $\overrightarrow{OA}$ 相等的向量有几个？与 $\overrightarrow{OA}$ 平行的有几个？两者为什么不同？

**提示**：相等要求同向同长（长度必须等于中心到顶点的距离）；平行只要求方向共线（长度不限）。正六边形里长度等于 $|OA|$ 的线段不止六条，方向与 $OA$ 共线的线段更多。数的时候先按"方向类"分组，再在每组里按"长度类"筛，最后用 4.3 反例 E1-R3 的教训检查有没有把"平行"混进"相等"。

**答案要点**：七个点之间只有 21 条无向线段，其长度只有三种——边长与半径 $1$、短对角线 $\sqrt3$、长对角线 $2$；方向只有六个类。按此分筛：

- 与 $\overrightarrow{OA}$ **相等**（同向且长为 1）的共 4 个：$\overrightarrow{OA}$ 自身、$\overrightarrow{CB}$、$\overrightarrow{EF}$，以及 $\overrightarrow{DO}$——$D(-1,0)$ 指向中心 $O$ 的方向也是 $(1,0)$，长度同样是 1。不计自身为 3 个。
- 与 $\overrightarrow{OA}$ **平行**（含同向与反向）的共 10 个：长度为 1 的八条——同向的四条 $\overrightarrow{OA},\overrightarrow{CB},\overrightarrow{EF},\overrightarrow{DO}$，反向的四条 $\overrightarrow{AO},\overrightarrow{BC},\overrightarrow{FE},\overrightarrow{OD}$；再加长度为 2 的两条 $\overrightarrow{AD},\overrightarrow{DA}$。不计自身为 9 个。

10 比 4 多出的 6 个，是"反向同长"的 4 条加"平行但不等长"的 2 条。本题的真正陷阱不在数字，而在分类依据：$DO$ 属于半径，$OA$、$CB$、$EF$ 分属半径与边，若按"半径还是边"这种几何名目去数，就会漏掉 $DO$。**分类依据必须是判据里的那两个量（方向、长度），不能是直观上的名目**。这也是本节提示"先按方向类、再按长度类"的用意：方向类与长度类是按判据切的，切完再数，才不会漏。

同一个向量，在六种语言里是六个东西。这张表是本体系的固定填空题，也是防止"只会在一种语言里做题"的装置。

| --- | --- | --- | --- | --- |

| 3 | 坐标语言 | 选定基后的三元数组 $(x,y,z)$ | 把"相等"化为三个数相等，可计算、可比较 | 4.1 构造二、11.1 |

## 八、自由向量的代数结构

### 8.1 八律与向量空间

自由向量全体记作 $V$。在 $V$ 上定义加法与数乘后，八律成立（5.4 已逐条回读）。这八律正是线性空间的公理。所以：

**命题**：自由向量集 $V$ 在加法与数乘下构成一个实线性空间。

这条命题的价值不在于"发现"，而在于"定位"：解析几何第一章看起来在讲箭头，实际在造一个线性空间的模型。等高代 G1 讲线性空间公理时，学生若记得 E1，就会知道那不是凭空抽象，而是把箭头运算的八条规律抽出来。

### 8.2 与 $\mathbb{R}^3$ 同构

选定一组基（比如两两垂直的单位向量 $\vec i,\vec j,\vec k$）后，每个向量唯一写成

$$\vec a=x\vec i+y\vec j+z\vec k$$

于是 $V\cong\mathbb{R}^3$（作为线性空间同构）。这个同构依赖基的选择，但**"同构"这个事实本身不依赖基**：换一组基，同构仍在，只是坐标变了。

这句区分很重要：同构是空间的结构性质，坐标是同构的具体实现。学生在 E1 阶段最容易把两者混为一谈，导致在 E3 换基时以为"向量变了"。

### 8.3 与 G1 的接口：线性空间与欧氏向量空间

G1 定义的线性空间只有加法与数乘，没有长度与角度。$V$ 比它多两样东西：内积（E4）与外积（E5）。所以严格说，$V$ 不是"线性空间"，而是"欧氏向量空间"——一个带内积的线性空间。

这个区分决定了后面两条路：

- 走 G1 的路，丢掉度量，只谈线性结构（基、维数、线性变换）；
- 走 E4/E5 的路，加上度量，才谈长度、夹角、面积、体积。

解析几何两样都要，所以它必须同时是"线性空间"与"度量空间"。这门课的所有公式，都可以按"用了内积没有"分成两类：用了的（距离、角、投影），没用的（共线、共面、线性组合）。

### 8.4 为什么是三维

$V$ 的维数是 3。为什么不是 2 或 4？

几何理由有两条，互相独立：

其一，**过一点最多有三条两两垂直的直线**。第四条垂直线无处可放——这不是"经验"，是三维欧氏空间的度量性质。

其二，**不共面的四点确定一个空间**。取四点 $O,A,B,C$ 不共面，则 $\overrightarrow{OA},\overrightarrow{OB},\overrightarrow{OC}$ 线性无关，任意向量可唯一表示为三者的组合。

代数理由是这两条的翻译：基恰含三个向量。

值得追问一句：为什么物理空间是三维？这是物理问题，不是数学问题。数学只回答"三维空间里向量的结构是什么"。解析几何的全部结论，都限定在 $\dim V=3$。高维情形属于高代与泛函，不属于这门课。

## 九、位置向量：点与向量的分离

### 9.1 原点依赖

固定原点 $O$，点 $P$ 与向量 $\overrightarrow{OP}$ 一一对应。这个对应让人可以把"点"当"向量"算，代价是**依赖 $O$**。

换原点 $O'$，全部位置向量整体平移：

$$\vec r'_P=\overrightarrow{O'P}=\vec r_P-\overrightarrow{OO'}$$

注意这个式子的结构：变化量 $-\overrightarrow{OO'}$ 对所有点**相同**。也就是说，换原点不是"重新给每个点单独编号"，而是"把整个点集平移一下再编号"。这个"整体平移"的性质，是仿射结构的第一个特征。

### 9.2 点差不变

位置向量会变，点差不变：

$$\overrightarrow{PQ}=\vec r_Q-\vec r_P=(\vec r'_Q+\overrightarrow{OO'})-(\vec r'_P+\overrightarrow{OO'})=\vec r'_Q-\vec r'_P$$

$-\overrightarrow{OO'}$ 抵消了。所以 $\overrightarrow{PQ}$ 与原点选择无关。

这条性质的意义：**点是相对的，点差是绝对的**。几何里所有"位移、方向、距离"都由点差表达，所以它们不依赖原点；而"位置"依赖原点，因此"绝对位置"在仿射几何里没有意义。坐标系的选取自由，正是建立在这条性质上。

### 9.3 仿射组合与重心

设 $P_1,\dots,P_n$ 为点，$\lambda_1,\dots,\lambda_n$ 为实数，且

$$\sum_{i=1}^{n}\lambda_i=1$$

则点

$$G=\sum_{i=1}^{n}\lambda_i P_i$$

（按位置向量计算）与原点选择无关。证明：换原点后

$$\sum\lambda_i(\vec r_i-\overrightarrow{OO'})=\sum\lambda_i\vec r_i-\left(\sum\lambda_i\right)\overrightarrow{OO'}=\sum\lambda_i\vec r_i-\overrightarrow{OO'}$$

与用旧原点算出的 $G$ 再减去 $\overrightarrow{OO'}$ 一致，说明 $G$ 作为点是同一个点。

条件是"系数和为 1"。系数和不为 1 时，换原点会多出一项，结果就随原点漂移，不是一个确定的点。这就是**仿射组合**的定义性条件。

两个直接应用：

- **重心**：$\lambda_i=1/n$，和为 1。三角形的重心 $G=(A+B+C)/3$。
- **定比分点**：$P$ 分 $AB$ 为 $\lambda$（$\overrightarrow{AP}=\lambda\overrightarrow{PB}$），则 $P=\dfrac{A+\lambda B}{1+\lambda}$，系数和 $\dfrac{1+\lambda}{1+\lambda}=1$。教材 §1.4 的定比分点公式，本质是仿射组合。

### 9.4 为什么点不能相加

$A+B$ 是什么？按位置向量算，是 $\vec r_A+\vec r_B$。换原点后变成 $\vec r_A+\vec r_B-2\overrightarrow{OO'}$，与原结果差 $2\overrightarrow{OO'}$——依赖原点，所以不是确定的点。

结论：**点与点之间只有一种合法运算——减法，得到向量；点与向量之间只有一种合法运算——加法，得到点**。点加点是非法运算，点乘点更非法（没有意义）。

这个"两运算"结构，正是仿射空间的定义：

$$\text{点}+\text{向量}=\text{点},\qquad \text{点}-\text{点}=\text{向量}$$

### 9.5 与 G6 的对接

高代 G6 把仿射空间定义为：点集 $A$ 配一个向量空间 $V$，并满足两条公理（点加向量得点；点减点得 $V$ 中向量，且满足相容性）。E1 的第 9 节，就是 G6 的几何来源。

对照读法：G6 是"公理化写法"，E1 是"从具体几何里长出来的写法"。两者说的是同一件事，但 G6 更干净（不依赖原点），E1 更可见（有图形）。双向审计的第一组材料，就是这两节。

## 十、史料与考据

史料不承担证明责任，只回答一个问题：为什么今天的向量是"箭头"而不是别的样子。

### 10.1 Hamilton 与四元数

1843 年 10 月 16 日，Hamilton 在都柏林散步时想出四元数，激动之下把公式刻在 Brougham 桥的石头上。1844 年发表《On Quaternions》。四元数形如

$$q=w+x\mathbf{i}+y\mathbf{j}+z\mathbf{k},\qquad \mathbf{i}^2=\mathbf{j}^2=\mathbf{k}^2=\mathbf{i}\mathbf{j}\mathbf{k}=-1$$

其中纯虚部分 $x\mathbf i+y\mathbf j+z\mathbf k$ 被 Hamilton 称为 **vector**（拉丁语 vehere，"携带"，指从原点指向点的"半径向量"）。这是"vector"一词进入数学的起点，但它当时指"四元数的一个部件"，不是独立对象。

四元数乘法非交换，这一反直觉性质让它在 19 世纪难以推广。但它把"方向"从"位置"里剥离出来，走出了第一步。

### 10.2 Grassmann 的扩张论

同年（1844），Grassmann 出版《Die lineale Ausdehnungslehre》（线性扩张论），提出 $n$ 维空间的抽象代数，包含外积（Aussere Produkt）。他的"扩张量"（Ausdehnungsgrösse）是比四元数更彻底的抽象：不依赖三维，不依赖具体坐标，直接把"方向与大小"作为代数对象。

这本书当时几乎无人读懂，卖不出去，Grassmann 转行做语言学研究。直到 20 世纪，人们才发现他的外积就是今天的楔积与行列式的祖先。

判断：Grassmann 走的是"公理化"路线，Hamilton 走的是"代数构造"路线。今天的解析几何取了后者的一半（向量），丢了前者的一半（外积的抽象形式，只在 E5 与微分形式里复活）。

### 10.3 Gibbs 与 Heaviside：向量分析的定型

1881 年，耶鲁的 Gibbs 私下印了一份《Elements of Vector Analysis》给学生的讲义；1884 年扩充。1893 年，Heaviside 在《Electromagnetic Theory》中使用同一套记号。两人把四元数拆成两半：标量部分与向量部分，独立出点积与叉积，形成今天的向量代数。

这场"拆分"引发了一场论战。四元数派（以 Tait 为代表）认为拆分破坏了四元数的统一性；向量派认为工程与物理需要的是可计算的三维工具。结果是向量派胜出：麦克斯韦方程组的现代写法，就是这场胜利的产物。

判断：今天教材里的"向量"，不是 Hamilton 的 vector，也不是 Grassmann 的扩张量，而是 Gibbs-Heaviside 为电磁学工程改造出来的**三维计算工具**。它天生带着"可算"的偏向，这也是解析几何重计算、轻结构的根源。

### 10.4 中文译名的分流

"vector" 传入中文有两条路：数学界译"向量"，物理界译"矢量"。前者强调"有向的量"，后者强调"既有大小又有方向的量"。吕林根教材用"向量"，丘维声也用"向量"；物理学教材多用"矢量"。

本文的用词：**一律作"向量"**，与教材一致。框架文档中的"矢量"是同一词的另一种译法，不作区分。凡引用教材原文，保留"向量"。

### 10.5 一个史学判断

向量的历史，不是"箭头的历史"，是"如何把方向与大小从具体位置中剥离"的历史。四元数剥了一次（虚部），Grassmann 剥了一次（扩张量），Gibbs 剥了一次（三维向量）。三次剥离，三种抽象程度，最后留下的是最便于计算的那一种。

这解释了一个教学现象：学生觉得"向量可以平移"很自然，因为教材给他的就是"已经剥好的箭头"；但若问"凭什么可以剥"，他答不上来。E1 的全部工作，就是把这层剥离重新演示一遍。

## 十一、实物验证

三个实例加一个反例实验，全部经 Python 3 + numpy 复算，脚本见 `_验证/e1_verify.py`。

### 11.1 实例一：相等判定

取 $A(1,2,3)$、$B(4,6,3)$、$C(-1,0,0)$、$D(2,4,0)$。

$$\overrightarrow{AB}=(3,4,0),\qquad \overrightarrow{CD}=(3,4,0)$$

坐标差逐项相等，故 $\overrightarrow{AB}=\overrightarrow{CD}$。

numpy 复算：`np.array_equal(B-A, D-C)` 返回 `True`；`np.linalg.norm(B-A)` 与 `np.linalg.norm(D-C)` 均为 5.0。

再加一组对照：$E(0,0,0)$、$F(3,-4,0)$，则 $\overrightarrow{EF}=(3,-4,0)$，与 $\overrightarrow{AB}$ 同长（5.0）但不同向（$y$ 分量符号相反），判定为不相等。这组对照验证了"同长不足"。

### 11.2 实例二：两法则一致

取 $\vec a=(2,1,0)$、$\vec b=(1,2,0)$。

三角形法则：$\vec a+\vec b=(2+1,\ 1+2,\ 0)=(3,3,0)$。
平行四边形法则：对角线 = 邻边之和，同样 $(3,3,0)$。

交换：$\vec b+\vec a=(1+2,\ 2+1,\ 0)=(3,3,0)$。两者相等，交换律在数值上成立。

进一步验证八律：随机取三组向量，逐条检验结合律、分配律，误差均在 $10^{-15}$ 量级（浮点舍入），说明八律在 $\mathbb{R}^3$ 的坐标实现中恒成立。

### 11.3 实例三：换原点实验

原原点 $O(0,0,0)$，新原点 $O'(1,1,1)$，点 $P(2,3,4)$、$Q(5,7,9)$。

$$\overrightarrow{OP}=(2,3,4),\qquad \overrightarrow{O'P}=(1,2,3)$$

差为 $(1,1,1)=\overrightarrow{OO'}$，验证 9.1 的平移公式。

点差：$\overrightarrow{PQ}=(3,4,5)$；用新原点算 $\overrightarrow{O'Q}-\overrightarrow{O'P}=(4,6,8)-(1,2,3)=(3,4,5)$。一致，验证 9.2 的不变性。

再验证仿射组合：三角形 $A(0,0,0)$、$B(3,0,0)$、$C(0,3,0)$ 的重心，两套原点都算出 $(1,1,0)$；把系数换成 $0.5,\ 0.25,\ 0.25$（和仍为 1），两套原点算出的仍是同一个点，说明"系数和为 1"才是与原点无关的资格。

### 11.4 反例实验：零向量的方向

用 `math.atan2(0.0, 0.0)` 计算零向量的"方向角"，Python 返回 `0.0`；用 `numpy.arccos(0.0/0.0)` 计算，返回 `nan` 并给出除零警告。两个结果都不合法：前者把"无定义"伪装成"正东"，后者直接把"无定义"暴露为 NaN。

这个实验的教学价值：**"无定义"在数值层面表现为"随便给一个值"或"报错"，两者都不能当成定义**。凡是涉及方向余弦、单位化、夹角的公式，第一步必须排除 $\vec 0$。

## 十二、边界与反例库

| 编号 | 反例 | 违反的直觉 | 归属 |
| --- | --- | --- | --- |
| E1-R1 | 同向不同长：$(1,0)$ 与 $(2,0)$ | 方向同即相等 | 定义边界 |
| E1-R2 | 同长反向：$(1,0)$ 与 $(-1,0)$ | 长度同、共线即相等 | 定义边界 |
| E1-R3 | 平行不等：$(1,0)$ 与 $(-3,0)$ | 平行就有关系 | 单向枝 |
| E1-R4 | 零向量方向无定义 | 平行则同向 | 约定与定理 |
| E1-R5 | 力偶：同向同长、作用点不同 | 数学相等 = 物理等效 | 模型边界 |
| E1-R6 | 异基同向量：坐标 $(1,1)$ 与 $(1,0)$ | 坐标同才同向量 | 表示边界 |
| E1-R7 | 球面：同向同长不可平移重合 | 平移总可行 | 公理边界 |

七条反例，七种边界。这张表是本模块的"边界探针总账"，后续模块遇到相似问题，可直接引用编号。

### 12.1 反例的三种用法

同样一条反例，在不同场合承担三种不同的责任。分清这三种，才不会把"模型问题"当成"数学错误"。

**用法一：否证充要**。要推翻"$P\Leftrightarrow Q$"，只需一条 $P$ 真 $Q$ 假或 $Q$ 真 $P$ 假的例子。E1-R1（同向不同长）否证"同向 $\Leftrightarrow$ 相等"；E1-R3（平行不等）否证"平行 $\Leftrightarrow$ 相等"。这类反例的任务是**砍枝**，砍掉关系图谱里那些不该画成双向箭头的边。

**用法二：划定义边界**。E1-R4（零向量方向无定义）与 E1-R2（同长反向）不否证任何定理，它们划的是定义的适用域：夹角公式在 $\vec 0$ 处无意义，单位化在 $\vec 0$ 处不合法。这类反例的任务是**圈地**，告诉后来的人哪块地不能踩。

**用法三：暴露模型与公理前提**。E1-R5（力偶）与 E1-R7（球面平移）最容易被误读。它们不是"向量相等算错了"，而是提醒：

- E1-R5 说明"自由向量"这个模型主动丢弃了作用点信息。在力学里必须换模型（力 + 作用点，或力旋量），数学没有错，是模型不够用。
- E1-R7 说明"相等 ⇔ 可平移重合"的资格来自欧氏平行公理。换到球面，这条资格失效，但"相等"作为等价类的定义仍然成立——失效的是那条等价改写，不是定义本身。

这个区分有实际的做题价值：遇到反例先问"它打的是哪一层"——定义、定理、模型、还是公理。打定义的，改定义；打定理的，砍边；打模型的，换模型；打公理的，换几何。四层处理方式完全不同。
