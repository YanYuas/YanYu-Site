> 解析几何不只是“把图形写成方程”。
> 这套讲义把对象、坐标、度量、变换和不变量放在同一条线上，每个模块都配一份习题集。

---

## 这套讲义怎么组织

四个领域，25 个模块，每个模块两篇：

- **讲义**：定义、定理、证明思路、几何直观、反例与边界；
- **习题集**：按 A / B / C / D 分层，含解答与耦合方向。

| 领域 | 模块 | 核心问题 |
|---|---|---|
| 一 · 标架与度量 | E1–E7 | 向量、坐标、度量与坐标系到底是什么？ |
| 二 · 形体与方程 | S1–S7 | 方程如何变成平面、直线、曲线和曲面？ |
| 三 · 变换与分类 | V1–V7 | 换坐标、换变换之后，什么不变？ |
| 四 · 延伸模块 | X1–X4 | 曲率、射影、公理体系、计算几何接口 |

## 和旧版导览的关系

原有「坐标与向量 / 曲线与曲面 / 变换与分类」三组短导览是快速入门，保留了交互实验台的入口。

这套系统讲义是**主教材层**：

- 每个模块都有完整讲义与习题；
- 每个概念都给边界、反例和失效条件；
- 与高等代数、数学分析同级，不再只是实验台的补充说明。

---

## 建议读法

1. 先读 E1–E3，把向量、分解、标架和坐标分开；
2. 读 E4–E7，补上内积、外积、坐标系与点向量分离；
3. 读 S1–S4，进入平面、直线、距离与角；
4. 读 S5–S7，进入柱锥旋、二次曲面与空间曲线；
5. 读 V1–V7，用变换和不变量回看整门课；
6. X1–X4 按兴趣选读。

每个领域索引页都有模块表，可以直接跳到讲义或习题集。
