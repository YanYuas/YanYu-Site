> 解析几何的很多“难点”其实是同一个词在不同书里指了不同的东西。
> 这一页约定本站统一用法；各模块正文遇到旧写法时，以本页为准。

---

## 一、对象与标架

| 采用 | 不采用 / 少用 | 说明 |
|---|---|---|
| 标架 / 坐标系 | 混着指两件事 | 标架强调“原点 + 一组基”；坐标系强调读数系统。多数语境同义，谈“基变换”时优先用标架 |
| 仿射标架 / 仿射坐标系 | 无 | 同义。本页采用“仿射标架”，E6 的正式定义仍写“仿射坐标系”，两者指同一个 $(O;\vec e_1,\vec e_2,\vec e_3)$ |
| 直角标架 | 笛卡尔标架、正交标架 | 基两两正交且长度为 1；坐标是带符号投影 |
| 位置向量 | 点向量、矢径 | 依赖原点；换原点会变 |
| 自由向量 | 有向线段 | 自由向量是有向线段的等价类，可以平移 |

## 二、向量与度量

| 采用 | 说明 |
|---|---|
| 方向向量 | 直线、平面的参数方向 |
| 法向量 | 平面的法向；二次曲面的梯度方向 |
| 内积 | 点积；给长度、角度、投影 |
| 外积 | 叉积；给有向面积、法向 |
| 混合积 | 给有向体积、共面判据 |
| 度量矩阵 | 基向量两两内积组成的矩阵 $G$；长度与角都由它读出 |

> 统一写「向量」，不写「矢量」；统一写「法向量」，不写「法矢量」。

---

## 三、方程与图形

| 采用 | 说明 |
|---|---|
| 一般方程 | 一次或二次方程的标准写法 |
| 参数方程 | 用参数表示点集；参数不是坐标 |
| 参数式 | 特指点向式或参数化写法；不与“参数方程”当同义词混用 |
| 点向式 | 点 + 方向向量写直线 |
| 点法式 | 点 + 法向量写平面 |
| 平面束 | 过一条直线的平面族 |
| 二次曲线 | 椭圆、双曲线、抛物线的统称；几何来源语境保留“圆锥曲线”别名 |
| 二次曲面 | 椭球面、双曲面、抛物面、柱面、锥面等的统称 |

> 本站正文以「二次曲线」为主；讲圆锥截线、射影定义或 Pascal 定理时保留「圆锥曲线」。
> 「参数式」是具体形式名，「参数方程」是更宽的说法，二者不能互换。

---

## 四、变换与分类

| 采用 | 说明 |
|---|---|
| 坐标变换 | 同一个点在不同标架下的坐标关系 |
| 标架变换 | 旧基到新基的过渡矩阵；与坐标变换方向相反 |
| 合同变换 | $A\mapsto P^{\mathsf T}AP$；保二次型 |
| 相似变换 | 矩阵相似 $A\mapsto P^{-1}AP$；保线性映射 |
| 不变量 | 变换下不改变的量或数 |
| 变换群 | 一组可复合、可求逆的变换；Klein 纲领的主语 |
| 齐次坐标 | 把仿射点嵌入射影空间的坐标写法 |

> 最容易混的两组：**合同**与**相似**，**标架变换**与**坐标变换**。
> 前者是矩阵关系不同，后者是矩阵方向相反。

---

## 五、固定写法

- 点用大写字母，向量用粗体或箭头：$P$、$\vec a$；
- 坐标三元组写 $(x,y,z)$，不写 $\{x,y,z\}$；
- 直线方向向量写 $\vec s$，平面法向量写 $\vec n$；
- 二次曲线方程写 $F(x,y)=0$，二次曲面写 $F(x,y,z)=0$；
- 矩阵用大写字母，行列式写 $\det A$，秩写 $\operatorname{rank} A$。

---

## 六、遇到旧写法怎么办

旧版快速导览里出现过「仿射坐标系」「点向量」「圆锥曲线」「方向矢量」等写法，
已并入系统讲义时统一改成上表用词；少数射影、圆锥截线语境保留「圆锥曲线」作为几何别名。读旧笔记时按本页对照即可。
