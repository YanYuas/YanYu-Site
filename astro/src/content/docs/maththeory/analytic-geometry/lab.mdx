这是解析几何专题的交互实验平台：每个实验是一个独立 Vue island，
按需加载、独立分块；切换标签即可进入不同实验。

<LabExplorer client:visible />

## 实验与定理对应

| 实验 | 观察到的现象 | 对应内容 |
|---|---|---|
| 向量与度量 | 点积、叉积、夹角与面积 | A2 向量代数 |
| 直线与平面 | 法向、方向与线面角 | B1 直线与平面 |
| 圆锥曲线 | 离心率连续变化，类型突变 | B2 圆锥曲线 |
| 二次曲面 | 特征值符号 → 封闭/张开/鞍形 | B3 二次曲面 |
| 参数曲面 | 环面与莫比乌斯环的拓扑差异 | B4 参数曲线与曲面 |
| 线性变换 | 网格变形、单位圆变椭圆、行列式 | C1 等距与仿射变换 |

## 开放与复用

- 每个实验都在 `src/components/labs/` 中独立实现，可单独抽出；
- 共享 `LabShell.vue` 布局与 `labs.json` 注册表；
- 全部为纯前端计算，不上传数据。
