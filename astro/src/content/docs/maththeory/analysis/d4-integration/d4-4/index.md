## 第一章 引言：从有限到无穷

### 1.1 反常积分的定位

D4-2 中建立的 Riemann 积分理论有两个基本限制：
1. **积分区间有限**：[a,b] 是有限闭区间
2. **被积函数有界**：f 在 [a,b] 上有界（可积的必要条件）

但在实际应用中，经常遇到不满足这两个条件的积分：
- **无穷区间**：∫₀^∞ e^{-x²}dx（高斯积分）、∫₀^∞ sin x/x dx（Dirichlet 积分）、∫_{-∞}^∞ 1/(1+x²)dx
- **无界函数**：∫₀¹ 1/√x dx（在 x=0 处无界）、∫₀¹ ln x dx（在 x=0 处无界）、∫₀¹ 1/√(1-x²)dx（在 x=1 处无界）

这些积分称为**反常积分**（improper integral）——它们不满足 Riemann 积分的基本条件，但可以通过取极限的方式定义。

### 1.2 反常积分的两种类型

1. **无穷限反常积分**（第一类反常积分）：积分区间无穷
   - ∫ₐ^∞ f(x)dx = lim_{b→∞}∫ₐᵇ f(x)dx
   - ∫_{-∞}^b f(x)dx = lim_{a→-∞}∫ₐᵇ f(x)dx
   - ∫_{-∞}^∞ f(x)dx = ∫_{-∞}^c f(x)dx + ∫_c^∞ f(x)dx

2. **无界函数反常积分**（第二类反常积分/瑕积分）：被积函数在积分区间内某点附近无界
   - 如果 f 在 x=a 附近无界（a 为瑕点）：∫ₐᵇ f(x)dx = lim_{ε→0+}∫_{a+ε}^b f(x)dx
   - 如果 f 在 x=b 附近无界（b 为瑕点）：∫ₐᵇ f(x)dx = lim_{ε→0+}∫ₐ^{b-ε} f(x)dx
   - 如果 f 在 x=c∈(a,b) 附近无界：∫ₐᵇ f(x)dx = ∫ₐᶜ f(x)dx + ∫_cᵇ f(x)dx（两个瑕积分都要收敛）

### 1.3 反常积分的历史定位

- **17-18 世纪**：牛顿、莱布尼茨、欧拉等已经使用了无穷区间和无界函数的积分，但没有严格的收敛性理论
- **19 世纪初**：柯西（1821-1823）给出了反常积分的严格定义，区分了收敛和发散
- **19 世纪中期**：狄利克雷（1829）、阿贝尔（1826）建立了条件收敛的判别法
- **19 世纪后期**：魏尔斯特拉斯建立了一致收敛理论，含参变量反常积分的理论成熟
- **20 世纪**：勒贝格积分理论使得反常积分的处理更加灵活（绝对收敛与 Lebesgue 可积的关系）

## 第二章 无穷限反常积分

### 2.1 定义

**定义**：设 f(x) 在 [a,+∞) 上有定义，且对任意 b>a，f 在 [a,b] 上 Riemann 可积。如果极限
lim_{b→+∞} ∫ₐᵇ f(x)dx
存在且有限，则称无穷限反常积分 ∫ₐ^∞ f(x)dx **收敛**，并定义
∫ₐ^∞ f(x)dx = lim_{b→+∞} ∫ₐᵇ f(x)dx
否则称反常积分 **发散**。

类似地：
- ∫_{-∞}^b f(x)dx = lim_{a→-∞} ∫ₐᵇ f(x)dx
- ∫_{-∞}^∞ f(x)dx = ∫_{-∞}^c f(x)dx + ∫_c^∞ f(x)dx（c 为任意实数，两个积分都收敛才收敛）

### 2.2 基本例子

**例 1**：∫₁^∞ 1/x^p dx（p-积分）

- 当 p>1 时：∫₁^∞ 1/x^p dx = [x^{1-p}/(1-p)]₁^∞ = 0 - 1/(1-p) = 1/(p-1)，收敛
- 当 p=1 时：∫₁^∞ 1/x dx = [ln x]₁^∞ = ∞，发散
- 当 p&lt;1 时：∫₁^∞ 1/x^p dx = [x^{1-p}/(1-p)]₁^∞ = ∞，发散

**结论**：∫₁^∞ 1/x^p dx 收敛当且仅当 p>1。

这是最基本的反常积分，是比较判别法的"标尺"。

**例 2**：∫₀^∞ e^{-ax}dx（a>0）

∫₀^∞ e^{-ax}dx = [-e^{-ax}/a]₀^∞ = 0 - (-1/a) = 1/a，收敛。

**例 3**：∫₀^∞ sin x dx

∫₀ᵇ sin x dx = [-cos x]₀ᵇ = 1-cos b，当 b→∞ 时极限不存在（振荡），所以发散。

注意：这个积分发散不是因为趋于无穷，而是因为振荡不收敛——这是"振荡发散"。

### 2.3 柯西收敛准则

**定理（柯西准则）**：∫ₐ^∞ f(x)dx 收敛，当且仅当对任意 ε>0，存在 A>a，使得对任意 b₂>b₁>A，有
|∫_{b₁}^{b₂} f(x)dx| &lt; ε

这是数列/函数极限的柯西准则在反常积分中的应用。

柯西准则的意义：它给出了收敛的充要条件，不需要知道极限值，只需要判断"尾部"积分是否可以任意小。

### 2.4 无穷限反常积分的性质

1. **线性性**：如果 ∫ₐ^∞ f 和 ∫ₐ^∞ g 都收敛，则 ∫ₐ^∞ (αf+βg) 收敛，且
   ∫ₐ^∞ (αf+βg)dx = α∫ₐ^∞ f dx + β∫ₐ^∞ g dx

2. **区间可加性**：∫ₐ^∞ f dx = ∫ₐᶜ f dx + ∫_c^∞ f dx（c>a），收敛性与 c 无关

3. **保号性**：如果 f≥0 且 ∫ₐ^∞ f 收敛，则 ∫ₐ^∞ f dx ≥ 0

4. **估值性质**：如果 |f(x)|≤g(x) 且 ∫ₐ^∞ g 收敛，则 ∫ₐ^∞ f 收敛（比较判别法的特殊情形）

### 2.5 几何理解

**📐 几何图像**：无穷限反常积分的几何意义是"无穷区间上曲线下面积"。∫ₐ^∞ f(x)dx 表示从 x=a 到无穷远的曲线下面积——这个面积是否有限？

- 收敛的几何意义：当 b→∞ 时，从 a 到 b 的面积趋于一个有限值——曲线下的"尾部面积"趋于零。
- 发散的几何意义：面积趋于无穷（如 1/x, p≤1）或振荡不趋于定值（如 sin x）。

p-积分 ∫₁^∞ 1/x^p dx 的几何意义：双曲线 y=1/x^p 下从 1 到无穷的面积。当 p>1 时，曲线衰减足够快，面积有限；当 p≤1 时，曲线衰减不够快，面积无穷。1/x 是"临界情形"——它的面积是对数增长的，趋于无穷但增长很慢。

柯西准则的几何意义：无穷远处任意一段"尾部面积"都可以任意小——这等价于总面积收敛。

无穷限反常积分的几何本质是"无穷区间上曲线下面积的有限性——曲线衰减足够快时面积有限，衰减不够快或振荡不收敛时面积发散"。

## 第三章 无界函数反常积分（瑕积分）

### 3.1 定义

**定义**：设 f(x) 在 (a,b] 上有定义，在 x=a 附近无界（a 称为瑕点），且对任意 ε>0，f 在 [a+ε,b] 上 Riemann 可积。如果极限
lim_{ε→0+} ∫_{a+ε}^b f(x)dx
存在且有限，则称无界函数反常积分 ∫ₐᵇ f(x)dx **收敛**，并定义
∫ₐᵇ f(x)dx = lim_{ε→0+} ∫_{a+ε}^b f(x)dx
否则称 **发散**。

类似地，如果瑕点在右端点 b：
∫ₐᵇ f(x)dx = lim_{ε→0+} ∫ₐ^{b-ε} f(x)dx

如果瑕点在内部 c∈(a,b)：
∫ₐᵇ f(x)dx = ∫ₐᶜ f(x)dx + ∫_cᵇ f(x)dx
两个瑕积分都收敛才收敛。

### 3.2 基本例子

**例 1**：∫₀¹ 1/x^p dx（p-积分，瑕点在 x=0）

- 当 p&lt;1 时：∫₀¹ 1/x^p dx = [x^{1-p}/(1-p)]₀¹ = 1/(1-p) - 0 = 1/(1-p)，收敛
- 当 p=1 时：∫₀¹ 1/x dx = [ln x]₀¹ = 0 - (-∞) = ∞，发散
- 当 p>1 时：∫₀¹ 1/x^p dx = [x^{1-p}/(1-p)]₀¹ = 1/(1-p) - (-∞) = ∞，发散

**结论**：∫₀¹ 1/x^p dx 收敛当且仅当 p&lt;1。

注意：和无穷限的 p-积分对比——无穷限 ∫₁^∞ 1/x^p dx 收敛当且仅当 p>1，瑕积分 ∫₀¹ 1/x^p dx 收敛当且仅当 p&lt;1。两者的收敛条件相反！这是因为无穷限关注"远处衰减"，瑕积分关注"近处奇异性"。

**例 2**：∫₀¹ 1/√x dx

p=1/2&lt;1，收敛。∫₀¹ 1/√x dx = [2√x]₀¹ = 2。

**例 3**：∫₀¹ ln x dx

瑕点在 x=0（ln x→-∞）。
∫₀¹ ln x dx = lim_{ε→0+} [x ln x - x]_ε¹ = (0-1) - lim_{ε→0+}(ε ln ε - ε) = -1 - 0 = -1，收敛。

（利用 lim_{ε→0+} ε ln ε = 0）

### 3.3 瑕积分与无穷限积分的联系

瑕积分可以通过变量替换转化为无穷限积分。

如果 x=a 是瑕点，令 t=1/(x-a)，则 x=a+1/t, dx=-1/t² dt，当 x→a+ 时 t→∞：
∫ₐᵇ f(x)dx = ∫_{1/(b-a)}^∞ f(a+1/t)·1/t² dt

这样，瑕积分就转化为无穷限积分，可以用无穷限积分的判别法。

### 3.4 瑕积分的柯西准则

**定理**：∫ₐᵇ f(x)dx（a 为瑕点）收敛，当且仅当对任意 ε>0，存在 δ>0，使得对任意 0&lt;ε₁&lt;ε₂&lt;δ，有
|∫_{a+ε₁}^{a+ε₂} f(x)dx| &lt; ε

即：瑕点附近任意一段"小面积"都可以任意小。

### 3.5 几何理解

**📐 几何图像**：无界函数反常积分（瑕积分）的几何意义是"无界函数曲线下的面积"。被积函数在瑕点附近趋于无穷（如 1/√x 在 x→0+ 时趋于无穷），曲线在瑕点处"冲向无穷远"，但曲线下的面积可能仍然有限——如果函数趋于无穷的"速度"不够快。

- 收敛的几何意义：当 ε→0+ 时，从 a+ε 到 b 的面积趋于有限值——瑕点附近的"小面积"趋于零。
- 发散的几何意义：面积趋于无穷（如 1/x, p≥1）。

p-积分 ∫₀¹ 1/x^p dx 的几何意义：双曲线 y=1/x^p 在 (0,1] 上下的面积。当 p&lt;1 时，函数在 x→0 时趋于无穷的速度"不够快"，面积有限；当 p≥1 时，趋于无穷的速度"太快"，面积无穷。1/x 是临界情形——面积是对数增长的。

对比无穷限和瑕积分的 p-积分：
- 无穷限 ∫₁^∞ 1/x^p dx：p>1 收敛（远处衰减快）
- 瑕积分 ∫₀¹ 1/x^p dx：p&lt;1 收敛（近处奇异性弱）
两者条件相反，体现了"无穷远"和"瑕点附近"的不同几何特征。

瑕积分的几何本质是"无界函数曲线下面积的有限性——函数在瑕点附近趋于无穷的速度不够快时面积有限，太快时面积发散"。

## 第四章 收敛判别法（一）——比较判别法与 Cauchy 判别法

### 4.1 非负函数的比较判别法

**定理（比较判别法）**：设 f(x), g(x) 在 [a,+∞) 上非负，且 f(x)≤g(x) 对所有 x≥a 成立。
- 如果 ∫ₐ^∞ g(x)dx 收敛，则 ∫ₐ^∞ f(x)dx 收敛
- 如果 ∫ₐ^∞ f(x)dx 发散，则 ∫ₐ^∞ g(x)dx 发散

即：大的收敛⇒小的收敛；小的发散⇒大的发散。

**证明思路**：非负函数的变上限积分 F(b)=∫ₐᵇ f(x)dx 是单调递增的。单调递增函数有界当且仅当收敛。如果 f≤g 且 ∫g 收敛，则 F(b)≤∫ₐᵇ g≤∫ₐ^∞ g&lt;∞，所以 F 有界，从而收敛。

**极限形式**：设 f,g≥0，且 lim_{x→∞} f(x)/g(x)=L（0≤L≤∞）。
- 如果 0&lt;L&lt;∞，则 ∫f 和 ∫g 同敛散
- 如果 L=0 且 ∫g 收敛，则 ∫f 收敛
- 如果 L=∞ 且 ∫g 发散，则 ∫f 发散

极限形式更实用——只需要比较 f 和 g 在无穷远处的"阶"。

### 4.2 Cauchy 判别法（p-判别法）

比较判别法中最常用的"标尺"是 p-积分 ∫₁^∞ 1/x^p dx。

**定理（Cauchy 判别法，无穷限）**：设 f(x)≥0 在 [a,+∞) 上有定义。
- 如果存在 p>1 和 M>0，使得 f(x)≤M/x^p 对所有 x≥a 成立，则 ∫ₐ^∞ f 收敛
- 如果存在 p≤1 和 M>0，使得 f(x)≥M/x^p 对所有 x≥a 成立，则 ∫ₐ^∞ f 发散

**极限形式**：设 f≥0，且 lim_{x→∞} x^p f(x)=L（0≤L≤∞）。
- 如果 p>1 且 0≤L&lt;∞，则 ∫f 收敛
- 如果 p≤1 且 0&lt;L≤∞，则 ∫f 发散

即：如果 f(x) 在无穷远处的阶是 1/x^p，则 p>1 收敛，p≤1 发散。

### 4.3 瑕积分的比较判别法与 Cauchy 判别法

**定理（比较判别法，瑕积分）**：设 f,g≥0 在 (a,b] 上有定义（a 为瑕点），且 f(x)≤g(x)。
- 如果 ∫ₐᵇ g 收敛，则 ∫ₐᵇ f 收敛
- 如果 ∫ₐᵇ f 发散，则 ∫ₐᵇ g 发散

**定理（Cauchy 判别法，瑕积分）**：设 f≥0，a 为瑕点。
- 如果存在 p&lt;1 和 M>0，使得 f(x)≤M/(x-a)^p，则 ∫ₐᵇ f 收敛
- 如果存在 p≥1 和 M>0，使得 f(x)≥M/(x-a)^p，则 ∫ₐᵇ f 发散

**极限形式**：设 f≥0，且 lim_{x→a+} (x-a)^p f(x)=L。
- 如果 p&lt;1 且 0≤L&lt;∞，则 ∫ₐᵇ f 收敛
- 如果 p≥1 且 0&lt;L≤∞，则 ∫ₐᵇ f 发散

### 4.4 例子

**例 1**：判断 ∫₁^∞ 1/(x√(1+x²)) dx 的敛散性

解：当 x→∞ 时，1/(x√(1+x²)) ~ 1/x²（因为 √(1+x²)~x）。p=2>1，所以收敛。

**例 2**：判断 ∫₀¹ 1/√(x(1-x)) dx 的敛散性

解：有两个瑕点 x=0 和 x=1。
- x→0+ 时：1/√(x(1-x)) ~ 1/√x = x^{-1/2}，p=1/2&lt;1，收敛
- x→1- 时：1/√(x(1-x)) ~ 1/√(1-x) = (1-x)^{-1/2}，p=1/2&lt;1，收敛
所以积分收敛。

**例 3**：判断 ∫₂^∞ 1/(x ln x) dx 的敛散性

解：令 u=ln x, du=dx/x。∫₂^∞ 1/(x ln x)dx=∫_{ln 2}^∞ 1/u du=∞，发散。

注意：这个函数比 1/x 衰减快（多了 ln x 因子），但仍然发散——因为 ∫1/(x ln x) 是对数的对数增长。需要 1/[x(ln x)^p] 且 p>1 才收敛。

### 4.5 几何理解

**📐 几何图像**：比较判别法的几何意义是"面积的大小比较"——如果曲线 g 下的面积有限（收敛），且曲线 f 在 g 下方（f≤g），那么 f 下的面积也有限。反过来，如果 f 下的面积无穷（发散），且 g 在 f 上方，那么 g 下的面积也无穷。

Cauchy 判别法的几何意义是"用双曲线 1/x^p 作为标尺"——双曲线下的面积是否有限取决于 p 的值。如果被积函数在无穷远处的"高度"和 1/x^p 差不多，那么面积的敛散性也和 1/x^p 一样。

极限形式的几何意义：只需要比较曲线在无穷远处的"渐近高度"——如果 f(x)/g(x)→L（有限正数），说明两条曲线在无穷远处"差不多高"，面积的敛散性相同。

比较判别法的几何本质是"面积的大小比较与渐近阶分析——用已知敛散性的简单函数（如 1/x^p）作为标尺，通过比较渐近阶判断复杂函数的敛散性"。

## 第五章 收敛判别法（二）——Dirichlet 判别法与 Abel 判别法

### 5.1 为什么需要更精细的判别法

比较判别法和 Cauchy 判别法只适用于非负函数（或绝对收敛，见第六章）。对于变号函数，特别是振荡函数（如 sin x, cos x），比较判别法不适用——因为函数有正有负，正负面积可能抵消。

例如 ∫₁^∞ sin x/x dx（Dirichlet 积分的变形）：sin x/x 是变号振荡函数，|sin x/x|≥sin²x/x，而 ∫sin²x/x dx 发散（可以证明），所以这个积分不是绝对收敛的。但 ∫₁^∞ sin x/x dx 本身是收敛的（条件收敛）——这需要更精细的判别法。

### 5.2 积分第二中值定理

Dirichlet 判别法和 Abel 判别法的基础是积分第二中值定理（D4-2 第十章已讨论）。

**定理（积分第二中值定理）**：如果 f 在 [a,b] 上可积，g 在 [a,b] 上单调，则存在 ξ∈[a,b]，使得
∫ₐᵇ f(x)g(x)dx = g(a)∫ₐ^ξ f(x)dx + g(b)∫_ξᵇ f(x)dx

这个定理的意义：把 f·g 的积分分解为 g 在端点的值乘以 f 的部分积分——这为处理"单调函数×振荡函数"的积分提供了工具。

### 5.3 Dirichlet 判别法

**定理（Dirichlet 判别法，无穷限）**：如果
1. F(A)=∫ₐ^A f(x)dx 在 [a,+∞) 上有界（即存在 M>0，使得 |∫ₐ^A f(x)dx|≤M 对所有 A≥a 成立）
2. g(x) 在 [a,+∞) 上单调且 lim_{x→∞}g(x)=0

则 ∫ₐ^∞ f(x)g(x)dx 收敛。

**证明思路**：利用积分第二中值定理和柯西准则。对任意 A₂>A₁>a，
|∫_{A₁}^{A₂} f(x)g(x)dx| = |g(A₁)∫_{A₁}^ξ f(x)dx + g(A₂)∫_ξ^{A₂} f(x)dx|
≤ |g(A₁)|·|∫_{A₁}^ξ f| + |g(A₂)|·|∫_ξ^{A₂} f|
≤ |g(A₁)|·2M + |g(A₂)|·2M
因为 g(x)→0，当 A₁,A₂ 足够大时，这个值可以任意小。由柯西准则，积分收敛。

**典型应用**：
- ∫ₐ^∞ sin x / x^p dx（a>0, p>0）：f=sin x（积分有界），g=1/x^p（单调趋于 0），收敛
- ∫ₐ^∞ cos x / x^p dx（a>0, p>0）：同理收敛
- ∫ₐ^∞ sin(x²)dx（Fresnel 积分）：令 t=x²，转化为 ∫ sin t/(2√t)dt，收敛

### 5.4 Abel 判别法

**定理（Abel 判别法，无穷限）**：如果
1. ∫ₐ^∞ f(x)dx 收敛
2. g(x) 在 [a,+∞) 上单调有界

则 ∫ₐ^∞ f(x)g(x)dx 收敛。

**证明思路**：Abel 判别法可以由 Dirichlet 判别法推出。因为 g 单调有界，所以 lim_{x→∞}g(x)=L 存在。令 h(x)=g(x)-L，则 h(x)→0 且单调。∫f·g = ∫f·h + L∫f。第一项由 Dirichlet 判别法收敛（∫ₐ^A f 有界，因为 ∫f 收敛），第二项收敛，所以整体收敛。

**典型应用**：
- ∫ₐ^∞ (sin x / x)·arctan x dx：∫sin x/x 收敛（Dirichlet），arctan x 单调有界（→π/2），收敛
- ∫ₐ^∞ f(x)·(1+1/x) dx：如果 ∫f 收敛，1+1/x 单调有界，收敛

### 5.5 瑕积分的 Dirichlet 判别法与 Abel 判别法

**Dirichlet 判别法（瑕积分，a 为瑕点）**：如果
1. F(ε)=∫_{a+ε}^b f(x)dx 在 (0,b-a] 上有界
2. g(x) 在 (a,b] 上单调且 lim_{x→a+}g(x)=0

则 ∫ₐᵇ f(x)g(x)dx 收敛。

**Abel 判别法（瑕积分，a 为瑕点）**：如果
1. ∫ₐᵇ f(x)dx 收敛
2. g(x) 在 (a,b] 上单调有界

则 ∫ₐᵇ f(x)g(x)dx 收敛。

### 5.6 例子

**例 1**：判断 ∫₁^∞ sin x / x dx 的敛散性

解：f=sin x，∫₁^A sin x dx = |cos 1 - cos A|≤2，有界；g=1/x，单调趋于 0。由 Dirichlet 判别法，收敛。

**例 2**：判断 ∫₁^∞ |sin x| / x dx 的敛散性

解：|sin x|≥sin²x=(1-cos 2x)/2。∫₁^∞ sin²x/x dx = (1/2)∫₁^∞ 1/x dx - (1/2)∫₁^∞ cos 2x/x dx。第一项发散，第二项收敛（Dirichlet），所以整体发散。由比较判别法，∫|sin x|/x 发散。

这说明 ∫sin x/x 是条件收敛（收敛但不绝对收敛）。

**例 3**：判断 ∫₀^1 sin(1/x)/x^p dx 的敛散性

解：瑕点在 x=0。令 t=1/x，dx=-1/t² dt：
∫₀^1 sin(1/x)/x^p dx = ∫₁^∞ t^{p-2} sin t dt
- 当 p&lt;2 时：t^{p-2}=1/t^{2-p}，2-p>0，单调趋于 0，sin t 积分有界，由 Dirichlet 收敛
- 当 p=2 时：∫₁^∞ sin t dt，发散（振荡不收敛）
- 当 p>2 时：t^{p-2}→∞，不满足 Dirichlet 条件，发散

### 5.7 几何理解

**📐 几何图像**：Dirichlet 判别法和 Abel 判别法的几何意义是"振荡函数的正负面积抵消"。

- Dirichlet 判别法的几何意义：f(x) 是振荡函数（如 sin x），其积分有界——正负面积不断抵消，累积面积在一个有界范围内振荡。g(x) 是单调衰减函数（如 1/x），给振荡加上一个逐渐减小的"振幅包络"。当 x→∞ 时，振幅越来越小，振荡越来越微弱，正负面积的抵消越来越完全，总面积收敛。
- Abel 判别法的几何意义：f(x) 的积分已经收敛（正负面积抵消到一个有限值），g(x) 是单调有界函数——给 f 乘上一个缓慢变化的因子，不改变收敛性。

积分第二中值定理的几何意义：把 f·g 的面积分解为 g 在端点的值乘以 f 的部分面积——这相当于把"变化的权重"g 简化为"端点权重"，利用 f 的部分积分有界来控制总面积。

Dirichlet 判别法的几何本质是"振荡衰减积分的收敛性——振荡函数的正负面积抵消，加上单调衰减的振幅包络，使得总面积收敛"。

## 第六章 绝对收敛与条件收敛

### 6.1 定义

**定义**：如果 ∫ₐ^∞ |f(x)|dx 收敛，则称 ∫ₐ^∞ f(x)dx **绝对收敛**。

如果 ∫ₐ^∞ f(x)dx 收敛但 ∫ₐ^∞ |f(x)|dx 发散，则称 **条件收敛**。

### 6.2 绝对收敛⇒收敛

**定理**：如果 ∫ₐ^∞ |f(x)|dx 收敛，则 ∫ₐ^∞ f(x)dx 收敛，且
|∫ₐ^∞ f(x)dx| ≤ ∫ₐ^∞ |f(x)|dx

**证明思路**：利用柯西准则。|∫_{A₁}^{A₂} f(x)dx| ≤ ∫_{A₁}^{A₂} |f(x)|dx，右边可以任意小（因为 ∫|f| 收敛），所以左边也可以任意小，由柯西准则 ∫f 收敛。

这个定理说明：绝对收敛是比收敛更强的条件——绝对收敛一定收敛，但收敛不一定绝对收敛。

### 6.3 条件收敛的典型例子

1. **Dirichlet 积分**：∫₁^∞ sin x/x dx 收敛（Dirichlet 判别法），但 ∫₁^∞ |sin x|/x dx 发散（第五章例 2），所以条件收敛。

2. **∫₁^∞ cos x / x^p dx（0&lt;p≤1）**：收敛（Dirichlet），但不绝对收敛（类似 sin x/x 的证明），条件收敛。

3. **Fresnel 积分**：∫₀^∞ sin(x²)dx 收敛（Dirichlet，令 t=x²），但 ∫₀^∞ |sin(x²)|dx 发散，条件收敛。

4. **∫₀^∞ sin x / √x dx**：收敛（Dirichlet），条件收敛。

### 6.4 绝对收敛与条件收敛的本质区别

绝对收敛和条件收敛的本质区别在于"正负面积的抵消程度"：

- **绝对收敛**：|f| 的积分收敛——即使不抵消，总面积也有限。正负面积的"绝对值之和"有限。
- **条件收敛**：|f| 的积分发散——如果不抵消，总面积无穷。但因为正负面积相互抵消，"代数和"有限。

条件收敛的积分依赖于正负面积的精确抵消——如果改变积分顺序（如重排），可能得到不同的结果（类似条件收敛级数的 Riemann 重排定理）。

### 6.5 绝对收敛的判别

因为绝对收敛⇒收敛，所以判断绝对收敛只需要对 |f| 使用非负函数的判别法（比较判别法、Cauchy 判别法）。

**例**：判断 ∫₁^∞ sin x / x² dx 的敛散性

解：|sin x / x²|≤1/x²，∫₁^∞ 1/x² dx 收敛（p=2>1），所以绝对收敛，从而收敛。

### 6.6 条件收敛的判别

条件收敛需要两步：
1. 证明收敛（通常用 Dirichlet 或 Abel 判别法）
2. 证明不绝对收敛（通常用比较判别法证明 |f| 的积分发散）

### 6.7 几何理解

**📐 几何图像**：绝对收敛与条件收敛的几何意义是"曲线下正负面积的抵消程度"。

- 绝对收敛的几何意义：曲线 y=|f(x)| 下的面积有限——即使把所有负面积"翻正"，总面积仍然有限。这说明函数衰减足够快，正负面积的绝对值之和有限。
- 条件收敛的几何意义：曲线 y=|f(x)| 下的面积无穷，但 y=f(x) 下的代数面积有限——正负面积相互抵消，使得"净面积"有限。这通常发生在振荡衰减函数中——函数振荡（有正有负），振幅衰减但不够快（绝对值积分发散），但正负面积的精确抵消使得代数和收敛。

条件收敛的几何图像最典型的是 sin x/x：曲线在 x 轴上下振荡，振幅逐渐减小。每个"波峰"和"波谷"的面积逐渐减小，但绝对值之和发散（类似调和级数）。然而，因为波峰和波谷交替出现，正负面积不断抵消，最终净面积收敛到一个有限值（Dirichlet 积分 π/2）。

绝对收敛与条件收敛的几何本质是"正负面积抵消的程度——绝对收敛是绝对值面积有限（不需要抵消），条件收敛是绝对值面积无穷但代数和有限（依赖精确抵消）"。

## 第七章 含参变量反常积分的一致收敛

### 7.1 含参变量反常积分的定义

设 f(x,y) 定义在 [a,+∞)×[c,d] 上，对每个 y∈[c,d]，反常积分 ∫ₐ^∞ f(x,y)dx 收敛。这样定义了一个关于 y 的函数
I(y)=∫ₐ^∞ f(x,y)dx, y∈[c,d]

称为**含参变量反常积分**，y 是参变量。

### 7.2 一致收敛的定义

**定义**：如果对任意 ε>0，存在 A₀>a（A₀ 只依赖于 ε，不依赖于 y），使得对所有 A>A₀ 和所有 y∈[c,d]，有
|∫_A^∞ f(x,y)dx| &lt; ε
则称含参变量反常积分 ∫ₐ^∞ f(x,y)dx 在 [c,d] 上**一致收敛**。

一致收敛的核心是"一致性"——A₀ 不依赖于 y，对所有 y 同时成立。这和函数项级数的一致收敛是类似的概念。

### 7.3 一致收敛的柯西准则

**定理**：∫ₐ^∞ f(x,y)dx 在 [c,d] 上一致收敛，当且仅当对任意 ε>0，存在 A₀>a，使得对所有 A₂>A₁>A₀ 和所有 y∈[c,d]，有
|∫_{A₁}^{A₂} f(x,y)dx| &lt; ε

### 7.4 一致收敛与逐点收敛的区别

- **逐点收敛**：对每个固定的 y，∫ₐ^∞ f(x,y)dx 收敛。A₀ 可以依赖于 y。
- **一致收敛**：对所有 y 同时收敛，且收敛速度"一致"——A₀ 不依赖于 y。

一致收敛比逐点收敛更强——一致收敛一定逐点收敛，但逐点收敛不一定一致收敛。

**例（不一致收敛）**：∫₀^∞ y e^{-xy}dx 在 y∈(0,1] 上逐点收敛（对每个 y>0，积分=1），但不一致收敛。因为 ∫_A^∞ y e^{-xy}dx=e^{-Ay}，对任意 A>0，取 y=1/A，则 e^{-Ay}=e^{-1}，不趋于 0。

### 7.5 几何理解

**📐 几何图像**：含参变量反常积分的几何意义是"一族曲线下的面积随参数变化"。对每个参数 y，f(x,y) 是一条关于 x 的曲线，I(y)=∫ₐ^∞ f(x,y)dx 是这条曲线下的面积。

一致收敛的几何意义："尾部面积"∫_A^∞ f(x,y)dx 对所有 y 同时趋于零——当 A 足够大时，所有参数对应的曲线的"尾部面积"都小于 ε。这意味着这族曲线的"衰减速度"是一致的——没有哪条曲线衰减得特别慢。

不一致收敛的几何意义：存在某些参数 y，对应的曲线衰减得特别慢——无论 A 多大，总有某些 y 的尾部面积不小于 ε。在例子 y e^{-xy} 中，y 越小，曲线衰减越慢（e^{-xy} 的衰减速度是 y），当 y→0+ 时衰减速度趋于零，所以不一致收敛。

一致收敛的几何本质是"一族曲线尾部面积的一致趋于零——所有参数对应的曲线衰减速度一致，没有特别慢的"。

## 第八章 一致收敛的判别法

### 8.1 Weierstrass M 判别法

**定理（M 判别法）**：如果存在函数 M(x)≥0，使得
1. |f(x,y)|≤M(x) 对所有 x≥a, y∈[c,d] 成立
2. ∫ₐ^∞ M(x)dx 收敛

则 ∫ₐ^∞ f(x,y)dx 在 [c,d] 上一致收敛（且绝对一致收敛）。

M 判别法是最常用的一致收敛判别法——它把含参变量积分的一致收敛转化为非参变量积分的收敛性判断。

**例**：∫₀^∞ e^{-yx} cos x dx 在 y∈[y₀,+∞)（y₀>0）上一致收敛，因为 |e^{-yx}cos x|≤e^{-y₀x}，而 ∫₀^∞ e^{-y₀x}dx 收敛。

### 8.2 Dirichlet 判别法

**定理（Dirichlet 判别法，一致收敛）**：如果
1. F(A,y)=∫ₐ^A f(x,y)dx 对 A≥a 和 y∈[c,d] 一致有界（即存在 M>0，使得 |∫ₐ^A f(x,y)dx|≤M 对所有 A,y 成立）
2. g(x,y) 对每个 y 关于 x 单调，且当 x→∞ 时，g(x,y) 关于 y∈[c,d] 一致趋于 0（即对任意 ε>0，存在 A₀，使得 x>A₀ 时 |g(x,y)|&lt;ε 对所有 y 成立）

则 ∫ₐ^∞ f(x,y)g(x,y)dx 在 [c,d] 上一致收敛。

**例**：∫₁^∞ sin x / x^y dx 在 y∈[y₀,+∞)（y₀>0）上一致收敛。f=sin x 积分一致有界，g=1/x^y 关于 x 单调且一致趋于 0（因为 y≥y₀>0）。

### 8.3 Abel 判别法

**定理（Abel 判别法，一致收敛）**：如果
1. ∫ₐ^∞ f(x,y)dx 在 [c,d] 上一致收敛
2. g(x,y) 对每个 y 关于 x 单调，且关于 x≥a, y∈[c,d] 一致有界

则 ∫ₐ^∞ f(x,y)g(x,y)dx 在 [c,d] 上一致收敛。

### 8.4 瑕积分的一致收敛判别法

以上判别法都可以类似地推广到瑕积分的一致收敛——只需要把"x→∞"改为"x→瑕点"，把"尾部积分"改为"瑕点附近积分"。

### 8.5 判别法的选择

1. **首选 M 判别法**：如果能找到与 y 无关的控制函数 M(x)，且 ∫M 收敛，用 M 判别法最简单。
2. **次选 Dirichlet/Abel**：如果 M 判别法不适用（如振荡函数，|f| 积分发散），用 Dirichlet 或 Abel 判别法。
3. **用定义或柯西准则**：如果以上都不适用，回到定义或柯西准则直接验证。

### 8.6 几何理解

**📐 几何图像**：一致收敛判别法的几何意义是"判断一族曲线尾部面积是否一致趋于零"。

- M 判别法的几何意义：如果所有曲线都被一条"主曲线"M(x) 控制（|f|≤M），且主曲线下的面积有限（∫M 收敛），那么所有曲线的尾部面积都不超过主曲线的尾部面积，从而一致趋于零。这是"控制收敛"的几何图像。
- Dirichlet 判别法的几何意义：f 是一致有界的振荡函数（正负面积一致抵消），g 是一致单调衰减的振幅包络——所有参数对应的振幅衰减速度一致，所以尾部面积一致趋于零。
- Abel 判别法的几何意义：f 的积分已经一致收敛，g 是一致有界的单调因子——乘上一个缓慢变化的有界因子不改变一致收敛性。

一致收敛判别法的几何本质是"通过控制函数、振荡抵消或单调因子，判断一族曲线尾部面积是否一致趋于零"。

## 第九章 一致收敛的性质

### 9.1 连续性定理

**定理**：如果
1. f(x,y) 在 [a,+∞)×[c,d] 上连续
2. ∫ₐ^∞ f(x,y)dx 在 [c,d] 上一致收敛

则 I(y)=∫ₐ^∞ f(x,y)dx 在 [c,d] 上连续。

即：lim_{y→y₀} ∫ₐ^∞ f(x,y)dx = ∫ₐ^∞ lim_{y→y₀} f(x,y)dx = ∫ₐ^∞ f(x,y₀)dx

极限和积分可以交换顺序。

### 9.2 积分号下积分定理

**定理**：在连续性定理的条件下，
∫_c^d [∫ₐ^∞ f(x,y)dx]dy = ∫ₐ^∞ [∫_c^d f(x,y)dy]dx

即：两个积分可以交换顺序（一个是反常积分，一个是正常积分）。

### 9.3 积分号下求导定理（Leibniz 法则）

**定理**：如果
1. f(x,y) 和 f_y(x,y) 在 [a,+∞)×[c,d] 上连续
2. ∫ₐ^∞ f(x,y)dx 对某个 y₀∈[c,d] 收敛（逐点收敛即可）
3. ∫ₐ^∞ f_y(x,y)dx 在 [c,d] 上一致收敛

则 I(y)=∫ₐ^∞ f(x,y)dx 在 [c,d] 上可导，且
I'(y)=∫ₐ^∞ f_y(x,y)dx

即：d/dy ∫ₐ^∞ f(x,y)dx = ∫ₐ^∞ ∂f/∂y (x,y)dx

求导和积分可以交换顺序。

注意：条件 2 只需要逐点收敛（在一个点收敛即可），关键是条件 3（导数积分一致收敛）。

### 9.4 无穷区间上的积分交换

**定理（Fubini 定理的特殊情形）**：如果 f(x,y)≥0 连续，或者 ∫∫|f| 收敛，则
∫ₐ^∞ [∫_c^∞ f(x,y)dy]dx = ∫_c^∞ [∫ₐ^∞ f(x,y)dx]dy

两个反常积分可以交换顺序。

### 9.5 性质的重要性

一致收敛的性质（连续性、可导性、可积性）是含参变量反常积分应用的基础——它们保证了可以在积分号下取极限、求导、积分。D4-3 中的参数积分法就是建立在这些性质之上的。

**典型应用**：
- Dirichlet 积分的参数积分法计算（D4-3 第五章）
- Poisson 积分的计算（对参数求导建立微分方程）
- Gamma 函数的可导性（Γ'(s)=∫₀^∞ t^{s-1}e^{-t}ln t dt）
- Beta 函数的可导性

### 9.6 几何理解

**📐 几何图像**：一致收敛性质的几何意义是"一族曲线下面积随参数的变化是'良好'的"。

- 连续性定理的几何意义：如果曲线族 f(x,y) 随参数 y 连续变化，且尾部面积一致趋于零，那么面积 I(y) 也随 y 连续变化——参数微小变化时，面积也微小变化。
- 积分号下求导的几何意义：面积 I(y) 对参数 y 的导数，等于曲线高度对 y 的偏导数 f_y 下的面积——参数微小变化 Δy 时，曲线高度变化了 f_y·Δy，面积变化就是高度变化在整个区间上的积分。一致收敛保证了这个"高度变化的积分"在无穷区间上也成立。
- 积分号下积分的几何意义：在参数-变量平面上的二重积分，可以按两种顺序积分——先对 x 积分再对 y 积分，或者先对 y 积分再对 x 积分。一致收敛保证了两种顺序的结果相同。

一致收敛性质的几何本质是"一族曲线下面积的良好性质——连续变化、可导、可积，极限/求导/积分可以与积分交换顺序"。

## 第十章 反常积分的计算

### 10.1 计算方法总览

反常积分的计算方法包括：
1. **直接用定义**：先算正常积分，再取极限
2. **Newton-Leibniz 公式**：如果原函数是初等函数，求出原函数后代入端点（取极限）
3. **换元法**：变量替换，可能把反常积分转化为正常积分或另一种反常积分
4. **分部积分法**：反常积分的分部积分
5. **参数积分法**：引入参数，积分号下求导/积分（D4-3 第四章）
6. **级数展开法**：展开为级数，逐项积分（D4-3 第十章）
7. **留数法**：复变方法（D4-3 第十一章）
8. **利用已知特殊积分**：Dirichlet、Gauss、Frullani 等（D4-3）

### 10.2 直接计算的例子

**例 1**：∫₀^∞ 1/(1+x²)dx

解：∫₀^∞ 1/(1+x²)dx = lim_{b→∞}[arctan x]₀ᵇ = lim_{b→∞}arctan b = π/2

**例 2**：∫₀¹ 1/√(1-x²)dx

解：瑕点在 x=1。∫₀¹ 1/√(1-x²)dx = lim_{ε→0+}[arcsin x]₀^{1-ε} = lim_{ε→0+}arcsin(1-ε) = π/2

**例 3**：∫₀^∞ x e^{-x}dx

解：分部积分，u=x, dv=e^{-x}dx：
∫₀^∞ x e^{-x}dx = [-x e^{-x}]₀^∞ + ∫₀^∞ e^{-x}dx = 0 + 1 = 1
（利用 lim_{x→∞}x e^{-x}=0）

### 10.3 换元法的例子

**例 4**：∫₀^∞ 1/[(1+x²)(1+x^α)]dx（α 任意）

解：令 x=1/t：
I=∫∞⁰ 1/[(1+1/t²)(1+t^{-α})]·(-1/t²)dt=∫₀^∞ t^α/[(1+t²)(1+t^α)]dt
两式相加：2I=∫₀^∞ (1+x^α)/[(1+x²)(1+x^α)]dx=∫₀^∞ 1/(1+x²)dx=π/2
所以 I=π/4（与 α 无关！）

**例 5**：∫₀^∞ 1/(x²+2x cos θ+1)dx（0&lt;θ&lt;π）

解：配方 x²+2x cos θ+1=(x+cos θ)²+sin²θ
令 u=x+cos θ：
∫₀^∞ 1/[(x+cos θ)²+sin²θ]dx=∫_{cos θ}^∞ 1/(u²+sin²θ)du
=[(1/sin θ)arctan(u/sin θ)]_{cos θ}^∞
=(1/sin θ)(π/2 - arctan(cot θ))
=(1/sin θ)(π/2 - (π/2-θ))=θ/sin θ

### 10.4 参数积分法的例子

**例 6（Dirichlet 积分）**：∫₀^∞ sin x/x dx=π/2（D4-3 第五章已详细讨论）

**例 7（Poisson 积分）**：∫₀^∞ e^{-ax²}cos(bx)dx=(1/2)√(π/a)e^{-b²/(4a)}（D4-3 第六章已讨论）

### 10.5 留数法的例子

**例 8（Laplace 积分）**：∫₀^∞ cos(ax)/(x²+b²)dx=π/(2b)e^{-ab}（D4-3 第九章已讨论）

### 10.6 几何理解

**📐 几何图像**：反常积分计算的几何意义是"无穷区域或无界函数的面积计算"。

- 直接计算的几何意义：先算有限区间的面积，再让区间趋于无穷或瑕点趋于极限——面积的极限就是反常积分的值。
- 换元法的几何意义：通过坐标变换把无穷区域转化为有限区域，或把无界函数转化为有界函数——面积在坐标变换下保持不变（但被积函数和积分区间都变了）。
- 参数积分法和留数法的几何意义同 D4-3——升维和扩域。

反常积分计算的几何本质是"无穷区域/无界函数面积的计算——通过取极限、坐标变换、升维扩域等方法把反常积分转化为可计算的形式"。

## 第十一章 Euler 积分的反常积分表示

### 11.1 Gamma 函数的反常积分表示

Gamma 函数的定义本身就是一个反常积分：
Γ(s)=∫₀^∞ t^{s-1}e^{-t}dt（s>0）

这个积分有两个反常之处：
1. **无穷限**：积分上限为 ∞——e^{-t} 指数衰减，保证收敛
2. **瑕点**：当 0&lt;s&lt;1 时，t^{s-1}=1/t^{1-s} 在 t→0+ 时无界——瑕积分，因为 1-s&lt;1，收敛

所以 Gamma 函数是一个"混合型反常积分"——既有瑕点又有无穷限。

### 11.2 Gamma 函数的收敛域

- 当 s>0 时，Γ(s) 收敛（瑕积分部分因为 s>0⇒s-1>-1⇒1/(t^{1-s}) 的指数 1-s&lt;1；无穷限部分因为 e^{-t} 指数衰减）
- 当 s≤0 时，Γ(s) 的积分定义发散（瑕点部分发散），但可以通过解析延拓定义（D4-3 第八章）

### 11.3 Beta 函数的反常积分表示

Beta 函数的定义也是反常积分：
B(p,q)=∫₀¹ t^{p-1}(1-t)^{q-1}dt（p>0,q>0）

这个积分有两个瑕点：
1. **t=0**：当 0&lt;p&lt;1 时，t^{p-1} 无界——瑕积分，因为 p>0⇒p-1>-1，收敛
2. **t=1**：当 0&lt;q&lt;1 时，(1-t)^{q-1} 无界——瑕积分，因为 q>0，收敛

### 11.4 Beta-Gamma 关系的反常积分证明

B(p,q)=Γ(p)Γ(q)/Γ(p+q) 的证明（D4-3 第八章）本身就是一个反常积分的交换顺序问题：
Γ(p)Γ(q)=∫₀^∞∫₀^∞ x^{p-1}y^{q-1}e^{-(x+y)}dxdy
转换为 u=x+y, v=x/(x+y)，利用 Fubini 定理交换积分顺序，得到 Γ(p+q)B(p,q)。

### 11.5 Gamma 函数的可导性

由一致收敛的性质（第九章），可以证明 Γ(s) 在 s>0 上任意阶可导：
Γ^(n)(s)=∫₀^∞ t^{s-1}e^{-t}(ln t)^n dt

这是因为对任意 [s₁,s₂]⊂(0,∞)，积分 ∫₀^∞ t^{s-1}e^{-t}(ln t)^n dt 一致收敛（可以用 M 判别法）。

### 11.6 其他特殊函数的反常积分表示

1. **误差函数**：erf(x)=(2/√π)∫₀ˣ e^{-t²}dt（正常积分，但 ∫₀^∞=1 是反常积分）
2. **正弦积分**：Si(x)=∫₀ˣ sin t/t dt（正常积分，∫₀^∞=π/2 是反常积分）
3. **对数积分**：li(x)=∫₀ˣ 1/ln t dt（瑕积分，t=1 为瑕点）
4. **指数积分**：Ei(x)=∫_{-∞}^x e^t/t dt（瑕积分，t=0 为瑕点）
5. **Fresnel 积分**：C(x)=∫₀ˣ cos(t²)dt, S(x)=∫₀ˣ sin(t²)dt（∫₀^∞=√(π/8) 是反常积分）

### 11.7 几何理解

**📐 几何图像**：Euler 积分的反常积分表示的几何意义是"特殊函数作为反常积分定义的曲线下面积"。

- Gamma 函数 Γ(s)=∫₀^∞ t^{s-1}e^{-t}dt 的几何意义：曲线 y=t^{s-1}e^{-t} 下从 0 到 ∞ 的面积。这条曲线在 t→0 时可能无界（s&lt;1 时），在 t→∞ 时指数衰减——是一个"混合型反常积分"。面积随参数 s 变化，定义了 Gamma 函数。
- Beta 函数 B(p,q)=∫₀¹ t^{p-1}(1-t)^{q-1}dt 的几何意义：曲线 y=t^{p-1}(1-t)^{q-1} 下从 0 到 1 的面积。这条曲线在端点 t=0 和 t=1 处可能无界——是一个"双瑕点反常积分"。

Euler 积分的反常积分表示体现了"特殊函数通常通过反常积分定义"——因为反常积分可以表示更广泛的函数类，包括那些在端点或无穷远处有奇异性的函数。

Euler 积分反常表示的几何本质是"特殊函数作为有奇异性的曲线下面积——端点或无穷远处的奇异性使得积分成为反常积分，但面积仍然有限（收敛）"。

## 第十二章 反常积分的应用

### 12.1 数学中的应用

1. **特殊函数定义**：Gamma、Beta、误差函数、正弦积分等都通过反常积分定义
2. **级数求和**：积分判别法、Abel 求和、用积分计算级数和（如 Basel 问题）
3. **Fourier 分析**：Fourier 变换、Fourier 逆变换都是反常积分
4. **概率论**：概率密度函数的归一化（∫f=1）、期望、方差、特征函数
5. **数论**：Riemann zeta 函数的积分表示、素数定理
6. **微分方程**：积分变换法解微分方程（Laplace 变换、Fourier 变换）

### 12.2 物理中的应用

1. **量子力学**：谐振子波函数归一化（高斯积分）、矩阵元计算、散射振幅
2. **统计力学**：配分函数计算（Gaussian 积分、Gamma 函数）、Bose-Einstein/Fermi-Dirac 分布（∫x/(e^x±1)dx）
3. **电磁学**：电场、磁场的积分计算（反常积分处理无穷远边界）
4. **热传导**：热核（基本解）是高斯函数，热传导方程的解用反常积分表示
5. **光学**：Fresnel 衍射（Fresnel 积分）、Fraunhofer 衍射（Fourier 变换）
6. **信号处理**：Fourier 变换、Laplace 变换、滤波器设计

### 12.3 工程中的应用

1. **控制系统**：Laplace 变换分析系统稳定性和响应
2. **通信工程**：Fourier 变换分析信号频谱、调制解调
3. **图像处理**：Fourier 变换、卷积、滤波
4. **土木工程**：结构动力学中的模态分析（特征函数展开）
5. **机械工程**：振动分析、随机振动（功率谱密度）

### 12.4 典型应用例子

**例 1（正态分布归一化）**：
∫_{-∞}^∞ (1/√(2π)σ)e^{-(x-μ)²/(2σ²)}dx=1
这是高斯积分的直接应用——正态分布的概率密度函数积分等于 1。

**例 2（Bose-Einstein 分布积分）**：
∫₀^∞ x^{n}/(e^x-1)dx=Γ(n+1)ζ(n+1)
这是统计力学中光子气体的态密度积分，n=3 时给出 Stefan-Boltzmann 定律。

**例 3（Fourier 变换）**：
F(ω)=∫_{-∞}^∞ f(t)e^{-iωt}dt
这是信号处理和物理学中最基本的反常积分之一。

### 12.5 几何理解

**📐 几何图像**：反常积分的应用的几何意义是"无穷区域/无界函数面积在各学科中的应用"。

- 概率论中的几何意义：概率密度函数下的面积=1（归一化），期望是"加权面积"，特征函数是密度函数的 Fourier 变换。
- 统计力学中的几何意义：配分函数是态密度函数下的面积——能量态密度 g(E) 乘以 Boltzmann 因子 e^{-βE}，积分得到配分函数。
- Fourier 变换的几何意义：把时域信号 f(t) 分解为不同频率的正弦波的叠加——F(ω) 是频率 ω 分量的"振幅密度"，积分是对所有时间的累积。

反常积分应用的几何本质是"无穷累积量在各学科中的普遍存在——概率、能量、信号频谱等都是无穷区间上的累积量，用反常积分表示"。

## 第十三章 反例库

### 13.1 收敛性反例

**反例 1**：∫₁^∞ 1/x dx 发散（p=1 临界情形，对数增长）。

**反例 2**：∫₁^∞ 1/(x ln x) dx 发散（比 1/x 衰减快但仍发散，需要 1/[x(ln x)^p], p>1 才收敛）。

**反例 3**：∫₀¹ 1/x dx 发散（瑕积分 p=1 临界情形）。

**反例 4**：∫₀^∞ sin x dx 发散（振荡不收敛，不是趋于无穷而是不趋于定值）。

### 13.2 绝对收敛与条件收敛反例

**反例 5**：∫₁^∞ sin x/x dx 条件收敛（收敛但不绝对收敛）。

**反例 6**：∫₁^∞ sin x/x² dx 绝对收敛（|sin x/x²|≤1/x²，收敛）。

**反例 7**：∫₀^∞ sin(x²)dx 条件收敛（Fresnel 积分，收敛但不绝对收敛）。

**反例 8**：收敛但不绝对收敛的瑕积分：∫₀¹ sin(1/x)/x dx。令 t=1/x，转化为 ∫₁^∞ sin t/t dt，条件收敛。

### 13.3 判别法反例

**反例 9**：比较判别法只适用于非负函数。对于变号函数，f≤g 且 ∫g 收敛不能推出 ∫f 收敛（例如 g=0, f=-1/x，f≤g 但 ∫f 发散到 -∞）。需要 |f|≤g 才行。

**反例 10**：Dirichlet 判别法中 g(x)→0 是必要的。如果 g(x) 不趋于 0（如 g=1），则 ∫sin x·1 dx 发散。

**反例 11**：Abel 判别法中 g 单调有界是重要的。如果 g 不单调，结论可能不成立。

### 13.4 一致收敛反例

**反例 12**：逐点收敛但不一致收敛：∫₀^∞ y e^{-xy}dx 在 (0,1] 上逐点收敛（=1）但不一致收敛（第七章已讨论）。

**反例 13**：M 判别法是充分条件不是必要条件。存在一致收敛但不满足 M 判别法的积分（如 ∫₁^∞ sin x/x^y dx 在 y≥y₀>0 上一致收敛，但 |sin x/x^y|≤1/x^{y₀}，实际上这个例子满足 M 判别法。需要更复杂的例子，如 ∫₁^∞ (sin x)/x·e^{-yx} dx 在 y≥0 上一致收敛但不满足 M 判别法——因为 |sin x/x| 的积分发散）。

**反例 14**：一致收敛的极限函数不一定连续（如果被积函数不连续）。连续性定理要求 f 连续。

### 13.5 计算反例

**反例 15**：Newton-Leibniz 公式对反常积分需要小心。如果原函数在瑕点处不连续或极限不存在，不能直接代入。例如 ∫₋₁¹ 1/x² dx，原函数 -1/x，直接代入得 -1/1-(-1/(-1))=-1-1=-2，但实际上积分发散（x=0 是瑕点，∫₀¹ 1/x² dx 发散）。

**反例 16**：换元法可能改变敛散性。不恰当的换元可能把收敛积分变成发散积分，或反之。需要验证换元的合法性。

### 13.6 反例总结

| 反例类型 | 典型例子 | 关键特征 |
|---|---|---|
| p=1 发散 | ∫₁^∞ 1/x dx | 临界情形，对数增长 |
| 对数因子发散 | ∫₁^∞ 1/(x ln x) dx | 比 1/x 快但仍发散 |
| 振荡发散 | ∫₀^∞ sin x dx | 不趋于定值 |
| 条件收敛 | ∫₁^∞ sin x/x dx | 收敛但不绝对收敛 |
| 绝对收敛 | ∫₁^∞ sin x/x² dx | |f|≤1/x² 收敛 |
| 比较法不适用于变号 | f≤g 不能推出 | 需 \|f\|≤g |
| Dirichlet g 不趋于0 | ∫sin x dx | g=1 不趋于0 |
| 逐点收敛不一致 | ∫y e^{-xy}dx | y→0 时衰减变慢 |
| M判别法非必要 | 一致收敛但无控制函数 | 振荡抵消 |
| Newton-Leibniz误用 | ∫₋₁¹ 1/x² dx | 瑕点未处理 |
| 换元不验证 | 不恰当换元 | 敛散性可能改变 |

## 第十四章 历史演进

### 14.1 反常积分理论的历史分期

**第一期：早期使用（17-18 世纪）**
- 牛顿、莱布尼茨：已经使用了无穷区间和无界函数的积分
- 欧拉：大量使用反常积分计算特殊函数（Gamma 函数等）
- 拉普拉斯：Laplace 积分、生成函数
- 这一时期没有严格的收敛性理论，凭直觉使用

**第二期：严格化（19 世纪初）**
- 柯西（1821-1823）：给出反常积分的严格定义，区分收敛和发散，提出柯西准则
- 柯西主值：对于某些发散积分，定义柯西主值（如 ∫_{-∞}^∞ sin x dx 的主值为 0）

**第三期：条件收敛与精细判别法（19 世纪中期）**

### 15.2 收敛性的跨层对比

| 层级 | "收敛"的含义 | 收敛函数类 | 典型不收敛 |
|---|---|---|---|
| L0 初等 | 面积有限 | 简单函数 | — |
| L1 Riemann | Riemann 和极限存在 | 满足判别法条件的函数 | 1/x (p≤1), sin x (振荡) |
| L2 复变 | 围道积分极限存在 | 解析/亚纯函数 | 本质奇点附近 |
| L3 Lebesgue | Lebesgue 积分有限 | 可测函数（L¹） | 非 L¹ 可测函数 |

注意：L1 层的"条件收敛"在 L3 层有更微妙的表现——Lebesgue 积分定义的是 |f| 的积分（绝对收敛），条件收敛的反常积分（如 ∫sin x/x）在 Lebesgue 框架下不是 Lebesgue 可积的（因为 |sin x/x| 积分发散），但作为反常积分（极限）存在。这是 Riemann 反常积分和 Lebesgue 积分的一个重要区别。

### 15.3 极限交换的跨层对比

| 层级 | 极限交换条件 | 灵活性 |
|---|---|---|
| L1 Riemann（一致收敛） | 一致收敛 | 较严格 |
| L2 复变（正规族） | 一致收敛/内闭一致收敛 | 中等 |
| L3 Lebesgue（DCT/MCT） | 控制收敛/单调收敛 | 最灵活 |

Lebesgue 框架下的控制收敛定理（DCT）比一致收敛更灵活——只需要存在可积的控制函数，不需要一致收敛。这是 Lebesgue 积分相对于 Riemann 积分的重要优势之一。

### 15.5 关键蜕变问题

**问题一：为什么条件收敛的反常积分在 Lebesgue 框架下不是 Lebesgue 可积的？**

回答：这是 Riemann 反常积分和 Lebesgue 积分的一个本质区别。

Lebesgue 积分的定义是基于 |f| 的——f 是 Lebesgue 可积的当且仅当 |f| 是 Lebesgue 可积的（即 ∫|f|&lt;∞）。这意味着 Lebesgue 积分本质上是"绝对收敛"的——它不承认条件收敛的积分。

而 Riemann 反常积分的定义是取极限 ∫ₐ^b f→∫ₐ^∞ f——这个极限可以在 |f| 的积分发散的情况下存在（条件收敛），因为正负面积相互抵消。

以 ∫₁^∞ sin x/x dx 为例：
- 作为 Riemann 反常积分：lim_{b→∞}∫₁ᵇ sin x/x dx 存在（=π/2-∫₀¹ sin x/x dx），因为正负面积抵消
- 作为 Lebesgue 积分：∫₁^∞ |sin x/x| dx=∞，所以 sin x/x 不是 Lebesgue 可积的

这个区别的根源是：Lebesgue 积分是"绝对积分"（先取绝对值再积分），而 Riemann 反常积分是"条件积分"（可以利用正负抵消）。Lebesgue 积分的这个特点使得它在处理极限交换时更灵活（DCT），但也使得它不能直接表示条件收敛的反常积分——需要用"反常 Lebesgue 积分"（取极限）来表示。

这个区别也体现在级数中：绝对收敛级数在 Riemann 和 Lebesgue 框架下都可以处理，但条件收敛级数的"和"依赖于求和顺序（Riemann 重排定理），Lebesgue 积分的"绝对"特性使得它更适合处理绝对收敛的对象。

**问题二：一致收敛和控制收敛（DCT）有什么本质区别？**

回答：一致收敛和控制收敛都是保证"极限和积分可以交换"的条件，但它们的本质和灵活性不同。

一致收敛（L1 层）：
- 定义：尾部积分 ∫_A^∞ f(x,y)dx 对所有 y 一致趋于零
- 几何意义：所有参数对应的曲线"尾部面积"一致趋于零——曲线族的衰减速度一致
- 条件较强：要求整个尾部面积一致小，不允许有"特别慢"的曲线
- 适用范围：Riemann 积分框架

控制收敛定理（L3 层，DCT）：
- 条件：存在可积函数 g(x)，使得 |f_n(x)|≤g(x) 对所有 n,x 成立，且 f_n→f 点态
- 几何意义：所有曲线都被一条"主曲线"g 控制，且主曲线下面积有限——不要求尾部面积一致小，只要求被同一条可积曲线控制
- 条件较弱：允许某些曲线在某些区域衰减慢，只要整体被控制
- 适用范围：Lebesgue 积分框架

本质区别：
1. **一致收敛是"均匀"条件**——要求所有曲线同时衰减，衰减速度一致
2. **控制收敛是"主导"条件**——只要求存在一条主导曲线控制所有曲线，不要求衰减速度一致

控制收敛更灵活的原因：它允许曲线族中有"特别慢"的成员，只要所有成员都被同一条可积曲线控制。例如 f_n(x)=n/(n²+x²) 在 [0,∞) 上逐点收敛到 0，且 |f_n|≤1/x（但 1/x 不可积），需要找其他控制函数。如果能找到可积的控制函数，DCT 就适用，即使不一致收敛。

在实际应用中，DCT 比一致收敛更常用——因为它更容易验证（只需要找一个控制函数），且适用范围更广。一致收敛通常用于需要更强性质（如连续性、可导性）的场合。

### 16.3 常见误区清单

1. **混淆无穷限和瑕积分的 p-判别条件** → 错（无穷限 p>1 收敛，瑕积分 p&lt;1 收敛）
2. **认为振荡函数一定发散** → 错（sin x/x 收敛，Dirichlet 判别法）
3. **认为收敛一定绝对收敛** → 错（条件收敛存在，如 sin x/x）
4. **比较判别法用于变号函数** → 错（比较判别法只适用于非负函数，变号函数需用 |f|≤g）
5. **Dirichlet 判别法忽略 g→0** → 错（g 必须单调趋于 0）
6. **逐点收敛等同于一致收敛** → 错（一致收敛更强，A₀ 不依赖于 y）
7. **M 判别法是必要条件** → 错（M 判别法是充分条件，一致收敛不一定满足 M 判别法）
8. **积分号下求导不验证一致收敛** → 错（需要导数积分一致收敛）
9. **Newton-Leibniz 公式忽略瑕点** → 错（有瑕点时必须取极限，不能直接代入）
10. **认为条件收敛的积分是 Lebesgue 可积的** → 错（Lebesgue 积分本质是绝对积分，条件收敛反常积分不是 Lebesgue 可积的）
11. **忽略积分区间内部的瑕点** → 错（内部瑕点必须拆分为两个瑕积分）
12. **认为 ∫f 收敛⇒f→0** → 错（收敛不能推出被积函数趋于 0，存在反例）
13. **换元法不验证合法性** → 错（换元可能改变敛散性，需验证）
14. **混淆柯西主值和收敛** → 错（柯西主值存在不代表积分收敛）
15. **认为无界函数积分一定发散** → 错（1/√x 在 [0,1] 上收敛，p&lt;1）

### 18.2 类比

- 反常积分与广义极限：都是取极限的过程
- 无穷限积分与瑕积分：两类反常积分，收敛条件相反（p>1 vs p&lt;1）
- 反常积分与无穷级数：收敛性理论类比（比较判别法、Cauchy 判别法、Dirichlet/Abel）
- 绝对收敛与条件收敛：类比级数的绝对收敛与条件收敛
- 一致收敛与函数项级数一致收敛：概念完全类比
- M 判别法与 Weierstrass M 判别法（级数）：完全类比
- Dirichlet 判别法（积分）与 Dirichlet 判别法（级数）：类比
- 柯西主值与级数的 Cauchy 乘积/重排：类比
- 控制收敛与一致收敛：极限交换的两种条件
- 反常积分与正常积分：反常积分是正常积分的极限推广
- 瑕点与奇点：复变函数中的奇点类比
- 换元法与坐标变换：反常积分换元需特别小心

### 18.4 特例

- ∫₁^∞ 1/x^p dx：p>1 收敛，p≤1 发散
- ∫₀¹ 1/x^p dx：p&lt;1 收敛，p≥1 发散
- ∫₀^∞ e^{-ax}dx=1/a（a>0）
- ∫₀^∞ 1/(1+x²)dx=π/2
- ∫₀^∞ sin x/x dx=π/2（Dirichlet，条件收敛）
- ∫₀^∞ e^{-x²}dx=√π/2（Gauss，绝对收敛）
- ∫₀¹ ln x dx=-1（瑕积分，收敛）
- ∫₀¹ 1/√x dx=2（瑕积分，收敛）
- ∫₀¹ 1/√(1-x²)dx=π/2（瑕积分，收敛）
- ∫₁^∞ sin x/x² dx（绝对收敛）
- ∫₁^∞ cos x/√x dx（条件收敛，Dirichlet）
- ∫₀^∞ sin(x²)dx=√(π/8)（Fresnel，条件收敛）
- Γ(s)=∫₀^∞ t^{s-1}e^{-t}dt（s>0，混合型反常积分）
- B(p,q)=∫₀¹ t^{p-1}(1-t)^{q-1}dt（p,q>0，双瑕点反常积分）

### 18.5 反例簇

- p=1 无穷限发散：∫₁^∞ 1/x dx
- p=1 瑕积分发散：∫₀¹ 1/x dx
- 对数因子发散：∫₁^∞ 1/(x ln x) dx
- 振荡发散：∫₀^∞ sin x dx
- 条件收敛：∫₁^∞ sin x/x dx
- 绝对收敛：∫₁^∞ sin x/x² dx
- 比较法用于变号：f≤g 不能推出收敛
- Dirichlet g 不趋于0：∫sin x dx 发散
- 逐点收敛不一致：∫y e^{-xy}dx
- M判别法非必要：一致收敛但无控制函数
- Newton-Leibniz误用：∫₋₁¹ 1/x² dx
- 收敛不能推出 f→0：存在反例
- 条件收敛非Lebesgue可积：∫sin x/x
- 柯西主值存在但发散：∫_{-∞}^∞ sin x dx 主值=0 但发散
- 内部瑕点未拆分：∫₋₁¹ 1/x dx（需拆分为两个瑕积分）

> **模块结语 · 从有限到无穷的飞跃**：
>
> D4-4 反常积分是 D4 积分领域的第四模块——定积分从有限区间、有界函数到无穷区间、无界函数的推广。反常积分的核心问题是"收敛性"——无穷区域或无界函数的"面积"是否有限。
>
> **两类反常积分**：无穷限反常积分（积分区间无穷）和无界函数反常积分（瑕积分，被积函数在瑕点附近无界）。两者都通过取极限定义。p-积分是最基本的标尺：无穷限 ∫₁^∞ 1/x^p dx 收敛当且仅当 p>1，瑕积分 ∫₀¹ 1/x^p dx 收敛当且仅当 p&lt;1——两者条件相反，体现了"无穷远"和"瑕点附近"的不同几何特征。
>
> **收敛判别法**：比较判别法（非负函数的大小比较）、Cauchy 判别法（p-判别法，用双曲线作为标尺）、Dirichlet 判别法（振荡函数×单调衰减函数，利用正负面积抵消）、Abel 判别法（收敛积分×单调有界因子）。比较判别法和 Cauchy 判别法适用于非负函数/绝对收敛，Dirichlet 和 Abel 判别法适用于条件收敛的振荡函数。
>
> **绝对收敛与条件收敛**：绝对收敛（|f| 的积分收敛）一定收敛，但收敛不一定绝对收敛。条件收敛依赖于正负面积的精确抵消——典型例子是 Dirichlet 积分 ∫sin x/x dx。绝对收敛是"绝对值面积有限"（不需要抵消），条件收敛是"绝对值面积无穷但代数和有限"（依赖精确抵消）。
>
> **含参变量反常积分的一致收敛**：一致收敛是比逐点收敛更强的条件——尾部面积对所有参数一致趋于零。Weierstrass M 判别法（控制函数）、Dirichlet 判别法、Abel 判别法是一致收敛的主要判别法。一致收敛保证了连续性、可导性、可积性——极限/求导/积分可以与积分交换顺序。
>
> **反常积分的计算**：直接用定义（取极限）、Newton-Leibniz 公式（小心瑕点）、换元法、分部积分法、参数积分法、级数展开法、留数法、利用已知特殊积分。
>
> **Euler 积分的反常积分表示**：Gamma 函数 Γ(s)=∫₀^∞ t^{s-1}e^{-t}dt 是混合型反常积分（既有瑕点又有无穷限），Beta 函数 B(p,q)=∫₀¹ t^{p-1}(1-t)^{q-1}dt 是双瑕点反常积分。特殊函数通常通过反常积分定义——因为反常积分可以表示更广泛的函数类。
>
> **跨层蜕变**：从 L0 初等直觉（面积有限）到 L1 经典分析（取极限定义、判别法、一致收敛）到 L2 复变函数（围道积分、留数法）到 L3 实变函数（Lebesgue 积分、控制收敛），反常积分的理论不断深化。一个重要的蜕变是：条件收敛的 Riemann 反常积分（如 ∫sin x/x）在 Lebesgue 框架下不是 Lebesgue 可积的——因为 Lebesgue 积分本质上是"绝对积分"。另一个重要蜕变是：一致收敛（L1）和控制收敛（L3, DCT）都是极限交换的条件，但 DCT 更灵活——只需要可积的控制函数，不需要一致衰减。
>
> 几何视角贯穿全章：无穷区域面积、无界函数面积、双曲线标尺（p-积分）、振荡衰减正负抵消（Dirichlet）、尾部面积一致趋于零（一致收敛）、控制函数主导（M 判别法/DCT）、特殊函数作为有奇异性的曲线下面积——所有反常积分概念都有清晰的几何图像。
>
> 反常积分的核心洞察是：**反常积分是定积分的极限推广——从有限到无穷，从有界到无界。收敛性的本质是"面积是否有限"，判别法的本质是"比较渐近阶"和"利用正负抵消"。绝对收敛是"绝对值面积有限"，条件收敛是"依赖精确抵消的代数和有限"。一致收敛是"尾部面积一致趋于零"，保证了极限/求导/积分与积分的交换。条件收敛的 Riemann 反常积分在 Lebesgue 框架下不是 Lebesgue 可积的——这是 Riemann 积分和 Lebesgue 积分的本质区别之一。控制收敛定理（DCT）比一致收敛更灵活——是 Lebesgue 积分相对于 Riemann 积分的重要优势。**
>
