## 第一章 引言：从 Riemann 到 Lebesgue

### 1.1 Riemann 积分的根本局限

Riemann 积分的核心思想是"分割定义域"——把区间 [a,b] 分成小区间，在每个小区间上用函数值近似，求和取极限。

这种方法有根本局限：
1. **可积函数类太窄**：Riemann 可积要求函数"几乎处处连续"（Lebesgue 准则）。像 Dirichlet 函数（有理点取 1，无理点取 0）这样的简单函数都不可积。
2. **极限与积分不能随意交换**：即使函数列逐点收敛，极限函数的积分也不一定等于积分的极限。需要一致收敛这样的强条件。
3. **微积分基本定理的条件太强**：FTC 要求导数 Riemann 可积，但存在导数有界但不 Riemann 可积的函数（Volterra 函数）。
4. **积分空间不完备**：Riemann 可积函数空间在 L¹ 范数下不完备——Cauchy 列的极限可能不是 Riemann 可积的。
5. **Fubini 定理条件强**：需要 Riemann 可积，否则累次积分可能不等。

### 1.2 Lebesgue 的核心思想

Lebesgue（1902）的革命性思想是：**不分割定义域，而是分割值域**。

Riemann 的方法：把 x 轴分成小区间，在每个小区间上 f(x) 变化不大时近似有效。如果 f(x) 剧烈震荡（如 Dirichlet 函数），每个小区间上 f 的值都在 0 和 1 之间跳，近似就失效了。

Lebesgue 的方法：把 y 轴（值域）分成小区间 [yᵢ, yᵢ₊₁]，考虑集合 Eᵢ={x: yᵢ≤f(x)&lt;yᵢ₊₁}。如果能度量 Eᵢ 的"长度"（测度）m(Eᵢ)，则积分近似为 ∑ yᵢ·m(Eᵢ)。

这样，即使函数剧烈震荡，只要每个"水平层"的集合可测，就能计算积分。Dirichlet 函数在有理点取 1（测度 0），无理点取 0（测度 1），积分 = 1·0 + 0·1 = 0。

Lebesgue 自己的比喻："我来付账。我把口袋里的钱按面值整理好，然后依次付清——这就是 Lebesgue 积分。而 Riemann 积分是按钱从口袋里掏出来的顺序付清。"

## 第二章 Riemann 积分的局限与 Lebesgue 的动机

### 2.1 Riemann 可积的 Lebesgue 准则

**定理（Lebesgue 准则，1902）**：有界函数 f 在 [a,b] 上 Riemann 可积的充要条件是 f 的不连续点集的 Lebesgue 测度为零。

这个定理深刻揭示了 Riemann 积分的局限：Riemann 可积要求函数"几乎处处连续"。

**推论**：
- 连续函数可积
- 单调函数可积（间断点至多可数，测度为零）
- 只有有限个间断点的函数可积
- 间断点集测度为零的有界函数可积
- **Dirichlet 函数不可积**（在每一点都不连续，间断点集 = [a,b]，测度 b-a≠0）

### 2.2 典型不可积函数

**Dirichlet 函数**：D(x)=1（x 有理），D(x)=0（x 无理）。
- 在每一点都不连续
- 上积分 = b-a，下积分 = 0，不相等
- Riemann 不可积
- 但 Lebesgue 可积，积分 = 0（因为有理点集测度为 0）

**Riemann 函数**（Thomae 函数）：R(x)=1/q（x=p/q 既约分数），R(x)=0（x 无理）。
- 在有理点不连续，在无理点连续
- 间断点集 = 有理数集，测度为 0
- Riemann 可积，积分 = 0
- 这个例子说明：Riemann 可积函数可以在一个稠密集上不连续

**Volterra 函数**（1881）：存在导数 f' 有界但不 Riemann 可积的函数 f。
- 这是 Riemann 积分的致命缺陷：微积分基本定理 ∫ₐᵇ f'(x)dx = f(b)-f(a) 对 Volterra 函数不成立，因为 f' 不 Riemann 可积
- Lebesgue 积分解决了这个问题：有界导数一定 Lebesgue 可积

### 2.3 极限与积分的交换问题

**问题**：如果 fₙ(x)→f(x) 逐点收敛，是否有 ∫fₙ→∫f？

Riemann 积分框架下，答案是**不一定**，即使 fₙ 和 f 都 Riemann 可积。

**反例**：设 {r₁,r₂,...} 是 [0,1] 中有理数的枚举。定义
fₙ(x)=1（x=r₁,...,rₙ），fₙ(x)=0（其他）
每个 fₙ 只有有限个间断点，Riemann 可积，∫fₙ=0。
但 fₙ→D（Dirichlet 函数）逐点收敛，D 不 Riemann 可积！

即使极限函数可积，也可能不收敛：
fₙ(x)=n（0&lt;x&lt;1/n），fₙ(x)=0（其他）
fₙ→0 逐点收敛，但 ∫fₙ=1 不趋于 0。

Riemann 框架下需要**一致收敛**才能保证极限与积分交换——这是一个非常强的条件。

Lebesgue 框架下，三大极限定理（单调收敛、Fatou、控制收敛）给出了更弱、更灵活的条件。

### 2.4 积分空间的不完备性

Riemann 可积函数空间 R[a,b] 在 L¹ 范数 ||f||₁=∫|f| 下**不完备**。

存在 Riemann 可积函数的 Cauchy 列，其极限不是 Riemann 可积的。例如上面的 fₙ（有限个有理点取 1）是 Cauchy 列，但极限是 Dirichlet 函数，不 Riemann 可积。

Lebesgue 可积函数空间 L¹[a,b] 是完备的（Riesz-Fischer 定理，1907）——这是 Lebesgue 积分的重要优势，也是泛函分析的基础。

### 2.5 几何理解

**📐 几何图像**：Riemann 积分的局限可以用"图像下面积"来理解。

Riemann 积分计算的是函数图像下方的面积——用竖直的小矩形近似。如果函数剧烈震荡（如 Dirichlet 函数），每个竖直小矩形内函数值都在 0 和 1 之间跳，上和和下和差距很大，面积无法定义。

Lebesgue 积分换了一个角度——用水平的小条带来近似。把值域分成小区间，每个水平条带对应的 x 集合的"宽度"（测度）乘以高度，就是这个条带的面积。即使函数剧烈震荡，每个水平层的集合仍然可以度量，面积就可以定义。

Dirichlet 函数的几何图像：图像是两条"虚线"——y=1 上的有理点（测度 0，"没有长度"）和 y=0 上的无理点（测度 1，"充满"区间）。图像下方面积 = 1×0 + 0×1 = 0。Riemann 积分看不到这个面积（因为竖直切割失效），Lebesgue 积分能看到（因为水平切割有效）。

Lebesgue 积分的几何本质是"水平切割求面积——分割值域而非定义域，用测度度量每个水平层的集合，克服了 Riemann 积分对函数连续性的强依赖"。

## 第三章 Lebesgue 测度

### 3.1 从长度到测度

区间 [a,b] 的长度是 b-a。我们希望把"长度"推广到更一般的集合——这就是测度。

**理想的测度应该满足**：
1. 非负性：m(E)≥0
2. 可数可加性：如果 E₁,E₂,... 两两不交，则 m(∪Eₙ)=∑m(Eₙ)
3. 平移不变性：m(E+a)=m(E)
4. 规范性：m([0,1])=1

但可以证明：在选择公理下，不可能对实数集的所有子集定义满足以上四条的测度（存在不可测集，如 Vitali 集）。

所以我们只对一部分集合（可测集）定义测度。

### 3.2 外测度

**定义（Lebesgue 外测度）**：对任意集合 E⊂ℝ，定义
m*(E)=inf{∑|Iₙ| : E⊂∪Iₙ, Iₙ 是开区间}

即用可数个开区间覆盖 E，取覆盖长度和的下确界。

**外测度的性质**：
1. 非负性：m*(E)≥0，m*(∅)=0
2. 单调性：如果 E⊂F，则 m*(E)≤m*(F)
3. 次可数可加性：m*(∪Eₙ)≤∑m*(Eₙ)
4. 区间的外测度等于长度：m*([a,b])=b-a
5. 可数集的外测度为 0：有理数集 m*(ℚ)=0

**注意**：外测度只有次可数可加性，没有可数可加性。这就是为什么需要"可测集"的概念。

### 3.3 可测集（Carathéodory 定义）

**定义（Carathéodory，1914）**：集合 E 称为**Lebesgue 可测**的，如果对任意集合 A，都有
m*(A)=m*(A∩E)+m*(A\E)

即 E 可以"分割"任意集合 A 的外测度。

这个定义看起来抽象，但它的好处是：可测集族构成 σ-代数，且外测度限制在可测集上满足可数可加性。

**可测集的性质**：
1. 可测集的补集可测
2. 可数个可测集的并集可测（σ-代数）
3. 可数个可测集的交集可测
4. 开集、闭集可测
5. Borel 集（由开集经可数并/交/补生成的集合）都可测
6. 可测集 = Borel 集 + 零测集的子集（Lebesgue 可测集是 Borel 集的完备化）

### 3.4 Lebesgue 测度

**定义**：对可测集 E，定义 m(E)=m*(E)，称为 E 的 Lebesgue 测度。

**Lebesgue 测度的性质**：
1. 非负性：m(E)≥0
2. 可数可加性：如果 Eₙ 两两不交且可测，则 m(∪Eₙ)=∑m(Eₙ)
3. 单调性：E⊂F ⟹ m(E)≤m(F)
4. 连续性（下连续）：如果 E₁⊂E₂⊂...，则 m(∪Eₙ)=lim m(Eₙ)
5. 连续性（上连续）：如果 E₁⊃E₂⊃... 且 m(E₁)&lt;∞，则 m(∩Eₙ)=lim m(Eₙ)
6. 平移不变性：m(E+a)=m(E)
7. 区间测度 = 长度：m([a,b])=b-a
8. 可数集测度为 0：m(ℚ)=0
9. 完备性：零测集的任何子集都可测且测度为 0

### 3.5 零测集

**定义**：测度为 0 的集合称为零测集。

**常见零测集**：
1. 有限集
2. 可数集（有理数集、整数集、代数数集）
3. Cantor 集（不可数但测度为 0！）
4. 光滑曲线（一维曲线在二维平面上测度为 0）
5. 低维流形在高维空间中测度为 0

**零测集的重要性**：
- "几乎处处"（a.e.）的概念：性质 P 在 E 上几乎处处成立，如果不成立的点集是零测集
- Riemann 可积 ⟺ 几乎处处连续
- 两个几乎处处相等的函数有相同的 Lebesgue 积分
- 零测集在积分理论中"可以忽略"

### 3.6 不可测集（Vitali 集）

**定理（Vitali，1905）**：存在 Lebesgue 不可测集。

**构造**：在 [0,1] 上定义等价关系 x~y 如果 x-y∈ℚ。每个等价类是可数集。用选择公理从每个等价类中选一个代表元，组成集合 V（Vitali 集）。

可以证明 V 不可测：如果 V 可测，则 {V+r: r∈ℚ∩[-1,1]} 是可数个两两不交的可测集，且都包含在 [-1,2] 中，其并包含 [0,1]。由平移不变性和可数可加性，得到矛盾（0&lt;m(V)≤1/3 不可能，因为可数个相同正数之和无穷大；m(V)=0 也不可能，因为并集包含 [0,1]）。

不可测集的存在说明：我们不能对所有集合定义测度，必须限制在可测集上。

### 3.7 高维 Lebesgue 测度

n 维 Lebesgue 测度 mₙ 类似定义：用 n 维开长方体覆盖，取下确界。
- m₂（二维测度）= 面积
- m₃（三维测度）= 体积
- 低维集合在高维空间中测度为 0（如曲线在平面上面积为 0，曲面在空间中体积为 0）

### 3.8 几何理解

**📐 几何图像**：Lebesgue 测度是"长度/面积/体积"的推广。

- 一维测度 = 长度：区间 [a,b] 的测度是 b-a
- 二维测度 = 面积：矩形 [a,b]×[c,d] 的测度是 (b-a)(d-c)
- 三维测度 = 体积：长方体的测度是长宽高之积

外测度的几何意义：用可数个"盒子"（区间/矩形/长方体）覆盖集合，取盒子总体积的下确界——这是"从外面逼近"集合的体积。

可测集的 Carathéodory 定义的几何意义：一个集合是可测的，如果它可以"干净地分割"任何测试集合——测试集合在 E 内的部分和在 E 外的部分的测度之和等于测试集合的测度。不可测集则会"模糊"测试集合的边界，导致分割后的测度之和大于原测度。

零测集的几何意义："可以忽略的集合"——它们在积分中不贡献任何值。可数集是零测集（因为可数个点的"长度"为 0），但 Cantor 集说明不可数集也可以是零测集（Cantor 集有连续统的基数，但"长度"为 0——它是一个"充满洞"的集合）。

不可测集的几何意义：选择公理允许我们构造出"无法度量体积"的集合——这些集合的边界如此复杂，以至于任何盒子覆盖都无法给出一致的体积。这是集合论和测度论的深刻结果。

Lebesgue 测度的几何本质是"长度/面积/体积的公理化推广——可数可加、平移不变、完备，覆盖了所有常见集合（Borel 集 + 零测集子集），但选择公理下存在不可测集"。

## 第四章 可测函数

### 4.1 可测函数的定义

**定义**：设 f: E→ℝ（E 可测）。f 称为**可测函数**，如果对任意实数 a，集合 {x∈E: f(x)>a} 都是可测集。

等价条件（以下任一即可）：
1. {x: f(x)>a} 可测（对所有 a）
2. {x: f(x)≥a} 可测
3. {x: f(x)&lt;a} 可测
4. {x: f(x)≤a} 可测

**直观理解**：可测函数就是"水平集可测"的函数——每个水平层 {a&lt;f≤b} 都是可测集。这正是 Lebesgue 积分所需要的！

### 4.2 可测函数的例子

1. **连续函数**：连续函数是可测的（因为 {f>a} 是开集，开集可测）
2. **单调函数**：单调函数是可测的（{f>a} 是区间，区间可测）
3. **Dirichlet 函数**：可测！{D>a} 要么是空集，要么是有理数集，要么是全空间——都可测
4. **简单函数**：只取有限个值的可测函数
5. **Riemann 可积函数**：可测（因为几乎处处连续）
6. **特征函数**：χ_E(x)=1（x∈E），0（x∉E），可测 ⟺ E 可测

### 4.3 可测函数的运算封闭性

**定理**：可测函数经过以下运算仍然可测：
1. 线性组合：αf+βg
2. 乘积：fg
3. 商：f/g（g≠0）
4. 绝对值：|f|
5. 最大值/最小值：max(f,g), min(f,g)
6. 正部/负部：f⁺=max(f,0), f⁻=max(-f,0)
7. 极限：如果 fₙ 可测且 fₙ→f 逐点收敛，则 f 可测
8. 上确界/下确界：sup fₙ, inf fₙ
9. 上极限/下极限：limsup fₙ, liminf fₙ

**关键性质**：可测函数对逐点极限封闭！这是 Riemann 可积函数不具备的（Riemann 可积函数列的逐点极限可能不 Riemann 可积，如 Dirichlet 函数的例子）。

### 4.4 简单函数逼近

**定义**：简单函数是只取有限个值的可测函数，形如 φ(x)=∑ᵢ₌₁ⁿ aᵢ χ_{Eᵢ}(x)，其中 Eᵢ 两两不交且可测。

**定理（简单函数逼近）**：
1. 非负可测函数 f 可以表示为非负简单函数递增列的极限：存在 φₙ↑f（φₙ≤φₙ₊₁，φₙ→f）
2. 一般可测函数 f 可以表示为简单函数列的极限
3. 有界可测函数可以用简单函数一致逼近

**标准构造**：对非负可测函数 f，定义
φₙ(x)=k/2ⁿ（当 k/2ⁿ≤f(x)&lt;(k+1)/2ⁿ, k=0,1,...,n2ⁿ-1）
φₙ(x)=n（当 f(x)≥n）
则 φₙ↑f。

这个构造是 Lebesgue 积分定义的基础——先用简单函数定义积分，再用简单函数逼近一般函数。

### 4.5 几乎处处收敛

**定义**：fₙ→f 几乎处处收敛（a.e.），如果 {x: fₙ(x)不收敛到 f(x)} 是零测集。

**性质**：
1. 几乎处处收敛的极限函数可测（如果 fₙ 可测）
2. 几乎处处相等的函数在积分中不可区分
3. 改变函数在零测集上的值不影响可测性和积分

### 4.6 可测函数的结构定理

**定理（Lusin 定理，1912）**：设 f 在可测集 E 上可测且几乎处处有限，m(E)&lt;∞。则对任意 ε>0，存在闭集 F⊂E，使得 m(E\F)&lt;ε，且 f 在 F 上连续。

**意义**：可测函数"差不多是连续的"——去掉一个任意小测度的集合后，函数在剩余集合上连续。这是可测函数的深刻结构定理，联系了可测性和连续性。

**定理（Egoroff 定理，1911）**：设 m(E)&lt;∞，fₙ→f a.e.，则对任意 δ>0，存在可测集 F⊂E，m(E\F)&lt;δ，使得 fₙ 在 F 上一致收敛到 f。

**意义**：在有限测度集上，几乎处处收敛"差不多是一致收敛"——去掉一个任意小测度的集合后，收敛是一致的。

Lusin 定理和 Egoroff 定理是"Littlewood 三原则"的体现：
1. 每个可测集差不多是有限个区间的并
2. 每个可测函数差不多是连续的（Lusin）
3. 每个逐点收敛的函数列差不多是一致收敛的（Egoroff）

### 4.7 几何理解

**📐 几何图像**：可测函数的几何意义是"水平集可测的函数"。

函数 f 的图像可以看作平面上的点集 {(x,f(x))}。可测函数的条件 {f>a} 可测意味着：图像在水平线 y=a 上方的部分对应的 x 集合是可测的——可以度量其"长度"。

简单函数逼近的几何意义：用阶梯函数（只取有限个值的函数）逼近一般可测函数。阶梯函数的图像是水平线段——每个水平段对应的 x 集合可测。随着阶梯越来越密（φₙ 的值越来越多），阶梯函数越来越接近原函数。

Lusin 定理的几何意义：可测函数的图像"差不多是连续曲线"——去掉一个任意小测度的 x 集合后，剩余部分的图像是连续的。这说明可测函数虽然可能处处不连续（如 Dirichlet 函数），但"不连续性"集中在一个可以任意小的集合上。

Egoroff 定理的几何意义：函数列的逐点收敛"差不多是一致收敛"——去掉一个任意小测度的集合后，在剩余集合上所有点以相同的速度收敛。

可测函数的几何本质是"水平集可测的函数——对逐点极限封闭，可以用简单函数逼近，差不多是连续的（Lusin），逐点收敛差不多是一致收敛（Egoroff）"。

## 第五章 Lebesgue 积分的定义（三步法）

### 5.1 第一步：非负简单函数的积分

**定义**：设 φ(x)=∑ᵢ₌₁ⁿ aᵢ χ_{Eᵢ}(x) 是非负简单函数（aᵢ≥0，Eᵢ 两两不交可测）。定义
∫_E φ dm = ∑ᵢ₌₁ⁿ aᵢ m(Eᵢ)

（如果某个 aᵢ=0 且 m(Eᵢ)=∞，约定 0·∞=0）

**性质**：
1. 定义良好（不依赖于简单函数的表示）
2. 线性性：∫(αφ+βψ)=α∫φ+β∫ψ
3. 单调性：φ≤ψ ⟹ ∫φ≤∫ψ
4. 可加性：∫_{E∪F}φ=∫_Eφ+∫_Fφ（E,F 不交）

### 5.2 第二步：非负可测函数的积分

**定义**：设 f≥0 可测。定义
∫_E f dm = sup{∫_E φ dm : 0≤φ≤f, φ 是简单函数}

即用所有不超过 f 的非负简单函数的积分的上确界来定义 f 的积分。

等价定义（用简单函数逼近）：如果 φₙ↑f（非负简单函数递增列），则
∫ f dm = lim ∫ φₙ dm

（这个极限不依赖于逼近列的选择——由单调收敛定理保证）

**性质**：
1. 非负性：∫f≥0
2. 线性性：∫(αf+βg)=α∫f+β∫g（α,β≥0）
3. 单调性：f≤g ⟹ ∫f≤∫g
4. 可加性：∫_{E∪F}f=∫_E f+∫_F f（E,F 不交）
5. Chebyshev 不等式：m({f≥a})≤(1/a)∫f（a>0）
6. ∫f=0 ⟺ f=0 a.e.

**积分可以是 +∞**：非负可测函数的积分可以是无穷大。如果 ∫f&lt;∞，称 f 可积。

### 5.3 第三步：一般可测函数的积分

**定义**：对一般可测函数 f，分解为正部和负部：
f⁺=max(f,0)≥0, f⁻=max(-f,0)≥0, f=f⁺-f⁻

定义
∫_E f dm = ∫_E f⁺ dm - ∫_E f⁻ dm

**注意**：这个定义要求 ∫f⁺ 和 ∫f⁻ 不同时为 +∞（否则 ∞-∞ 无意义）。

**可积的定义**：f 称为 Lebesgue 可积的，如果 ∫|f|dm&lt;∞。
- 因为 |f|=f⁺+f⁻，所以 ∫|f|&lt;∞ ⟺ ∫f⁺&lt;∞ 且 ∫f⁻&lt;∞
- 可积函数的积分是有限实数

**记号**：L¹(E) 表示 E 上所有 Lebesgue 可积函数的集合。

### 5.4 与 Riemann 积分的对比

| 方面 | Riemann 积分 | Lebesgue 积分 |
|---|---|---|
| 分割方式 | 分割定义域 | 分割值域（通过简单函数） |
| 可积条件 | 几乎处处连续（有界） | 可测且 ∫\|f\|&lt;∞ |
| 可积函数类 | 较窄 | 很宽（包含所有 Riemann 可积函数 + 更多） |
| 极限交换 | 需要一致收敛 | 单调收敛/Fatou/控制收敛 |
| 积分空间 | 不完备 | 完备（L¹） |
| 反常积分 | 需要单独定义 | 自然包含（可积=绝对可积） |
| Fubini 定理 | 条件强 | Fubini-Tonelli 更一般 |

### 5.5 例子

**例 1（Dirichlet 函数）**：D(x)=1（有理），0（无理）。
D 是非负简单函数：D=1·χ_ℚ + 0·χ_{ℚ^c}
∫D dm = 1·m(ℚ)+0·m(ℚ^c)=1·0+0·1=0
Dirichlet 函数 Lebesgue 可积，积分 = 0（Riemann 不可积！）

**例 2（f(x)=1/x 在 (0,1] 上）**：
∫₀¹ 1/x dx = ∞（Lebesgue 积分也是无穷大，和反常积分一致）
f 不可积（∫|f|=∞）

**例 3（f(x)=1/√x 在 (0,1] 上）**：
∫₀¹ 1/√x dx = 2（Lebesgue 积分 = 2，和反常积分一致）
f 可积

**例 4（f(x)=sin x/x 在 [0,∞) 上）**：
条件收敛的反常积分 ∫₀^∞ sin x/x dx = π/2
但 Lebesgue 积分 ∫₀^∞ |sin x/x| dx = ∞，所以 sin x/x 在 [0,∞) 上不是 Lebesgue 可积的！
这说明：Lebesgue 积分是"绝对可积"的积分，不包含条件收敛的反常积分。

### 5.6 几何理解

**📐 几何图像**：Lebesgue 积分的三步定义可以用"图像下方面积"来理解。

- 非负简单函数的积分：图像是有限个水平线段，图像下方是有限个矩形，面积 = ∑高度×宽度 = ∑aᵢm(Eᵢ)
- 非负可测函数的积分：用越来越密的阶梯函数（简单函数）从下方逼近，阶梯函数的面积递增趋于原函数图像下方面积——这是"从内部逼近"面积
- 一般可测函数的积分：图像在 x 轴上方的面积（正部积分）减去图像在 x 轴下方的面积（负部积分）

和 Riemann 积分的对比：
- Riemann 积分：用竖直小矩形从内部和外部同时逼近（Darboux 上和/下和），要求函数在每个竖直区间内变化不大
- Lebesgue 积分：用水平阶梯函数从内部逼近，要求每个水平层的集合可测

Dirichlet 函数的几何图像：图像是 y=1 上的有理点（测度 0，"没有宽度"）和 y=0 上的无理点（测度 1，"充满"区间）。图像下方面积 = 1×0 + 0×1 = 0。Lebesgue 积分能计算这个面积，Riemann 积分不能。

Lebesgue 积分的几何本质是"水平阶梯逼近求面积——从简单函数到非负函数到一般函数，用水平层的测度代替竖直区间的长度，克服了 Riemann 积分对函数连续性的依赖"。

## 第六章 Lebesgue 积分的性质

### 6.1 基本性质

设 f,g∈L¹(E)，则：
1. **线性性**：∫(αf+βg)=α∫f+β∫g（对任意实数 α,β）
2. **单调性**：f≤g a.e. ⟹ ∫f≤∫g
3. **绝对值性质**：|∫f|≤∫|f|
4. **可加性**：∫_{E∪F}f=∫_E f+∫_F f（E,F 不交可测）
5. **零测集不影响**：如果 f=g a.e.，则 ∫f=∫g
6. **积分绝对连续**：对任意 ε>0，存在 δ>0，使得当 m(A)&lt;δ 时，|∫_A f|&lt;ε
7. **积分的可数可加性**：如果 E=∪Eₙ（Eₙ 两两不交），则 ∫_E f=∑∫_{Eₙ} f

### 6.2 积分的绝对连续性

**定理（积分的绝对连续性）**：如果 f∈L¹(E)，则对任意 ε>0，存在 δ>0，使得对任意可测集 A⊂E，当 m(A)&lt;δ 时，有 ∫_A |f|&lt;ε。

**意义**：可积函数在小测度集合上的积分可以任意小。这是可积函数的重要性质，在证明极限定理和 Fubini 定理时常用。

**证明思路**：先对简单函数证明（显然，因为简单函数有界），再用简单函数逼近一般可积函数。

### 6.3 积分与集合的极限

**定理（积分的下连续）**：如果 E₁⊂E₂⊂...，f 在 ∪Eₙ 上可积，则
∫_{∪Eₙ} f = lim ∫_{Eₙ} f

**定理（积分的上连续）**：如果 E₁⊃E₂⊃...，m(E₁)&lt;∞，f 可积，则
∫_{∩Eₙ} f = lim ∫_{Eₙ} f

这些是测度连续性在积分中的推广。

### 6.4 平均值性质

**定理（积分中值定理的推广）**：如果 f 在 E 上可积，m(E)&lt;∞，且 a≤f≤b a.e.，则存在 c∈[a,b]，使得
∫_E f dm = c·m(E)

如果 f 连续且 E 连通，则 c 可以取为 f 在某点的值。

### 6.5 积分不等式

1. **Chebyshev 不等式**：m({|f|≥a})≤(1/a)∫|f|（a>0）
2. **Hölder 不等式**：∫|fg|≤||f||_p ||g||_q（1/p+1/q=1）
3. **Cauchy-Schwarz 不等式**：∫|fg|≤||f||₂ ||g||₂（Hölder 的 p=q=2 特例）
4. **Minkowski 不等式**：||f+g||_p≤||f||_p+||g||_p
5. **Jensen 不等式**：如果 φ 凸，则 φ(∫f)≤∫φ(f)（概率测度下）

### 6.6 几何理解

**📐 几何图像**：Lebesgue 积分的性质可以用"面积"来理解。

- 线性性：面积的可加性和数乘——两个函数图像下方面积之和等于和函数图像下方面积
- 单调性：如果 f 的图像在 g 下方，则 f 图像下方面积不超过 g 图像下方面积
- 绝对值性质：净面积（正负抵消后）不超过总面积（绝对值的积分）
- 零测集不影响：在"没有宽度"的集合上改变函数值，不影响图像下方面积
- 积分的绝对连续性：可积函数的图像下方面积是"有限的"，所以在任意小宽度的集合上，面积可以任意小——这类似于"总面积有限的图形，切下任意窄的一条，面积可以任意小"
- 积分的可数可加性：把区域分成可数个不相交的部分，各部分面积之和等于总面积

积分的绝对连续性是一个深刻的性质：它说明可积函数的"质量"（积分）是"连续分布"的——不会集中在一个任意小测度的集合上。不可积函数（如 1/x 在 0 附近）则可能把"无限质量"集中在任意小的集合附近。

Lebesgue 积分性质的几何本质是"面积的公理化性质——线性、单调、绝对连续、可数可加，零测集不影响，这些性质共同刻画了'图像下方面积'的本质"。

## 第七章 三大极限定理

### 7.1 单调收敛定理（Levi 定理）

**定理（单调收敛定理，Levi 1906）**：设 {fₙ} 是非负可测函数的递增列（0≤f₁≤f₂≤...），f=lim fₙ（可以是 +∞），则
∫ f dm = lim ∫ fₙ dm

即：积分与极限可以交换（对非负递增列）。

**意义**：这是 Lebesgue 积分最基本的极限定理。它说明非负递增函数列的积分极限等于极限函数的积分——不需要一致收敛，只需要单调递增和非负。

**证明思路**：
1. 由单调性，∫fₙ 递增，设极限为 L
2. 因为 fₙ≤f，所以 L≤∫f
3. 反过来，对任意简单函数 φ≤f 和任意 c&lt;1，考虑 Eₙ={fₙ≥cφ}，则 Eₙ↑E，利用积分的下连续性证明 L≥c∫φ，令 c→1 得 L≥∫φ，再取上确界得 L≥∫f

### 7.2 Fatou 引理

**定理（Fatou 引理，1906）**：设 {fₙ} 是非负可测函数列，则
∫ (liminf fₙ) dm ≤ liminf ∫ fₙ dm

**意义**：对非负函数列，下极限的积分不超过积分的下极限。这是一个"半交换"结果——积分和下极限不能完全交换，但有一个方向的不等式。

**注意方向**：是 ≤ 不是 ≥。经典反例 fₙ=nχ_{(0,1/n)}：liminf fₙ=0，∫fₙ=1，所以 0≤1。

**证明思路**：令 gₙ=inf_{k≥n} fₖ，则 gₙ 非负递增，lim gₙ=liminf fₙ。由单调收敛定理，∫liminf fₙ=lim∫gₙ≤liminf∫fₙ（因为 gₙ≤fₙ）。

### 7.3 控制收敛定理（Lebesgue 控制收敛定理）

**定理（控制收敛定理，Lebesgue 1910）**：设 {fₙ} 是可测函数列，满足：
1. fₙ→f a.e.（或依测度收敛）
2. 存在可积函数 g≥0，使得 |fₙ|≤g a.e.（控制函数）
则 f∈L¹，且
∫ f dm = lim ∫ fₙ dm

**意义**：这是最常用的极限定理。如果函数列被一个可积函数"控制"（绝对值不超过一个可积函数），则极限与积分可以交换。控制收敛定理把一致收敛的强条件弱化为"被可积函数控制"。

**证明思路**：
1. g+fₙ≥0，由 Fatou 引理：∫(g+f)≤liminf∫(g+fₙ)=∫g+liminf∫fₙ，所以 ∫f≤liminf∫fₙ
2. g-fₙ≥0，同理：∫(g-f)≤liminf∫(g-fₙ)=∫g-limsup∫fₙ，所以 ∫f≥limsup∫fₙ
3. 结合得 liminf∫fₙ≤∫f≤limsup∫fₙ，所以极限存在且等于 ∫f

### 7.4 三大定理的关系

```
单调收敛定理 (非负递增)
    ↓ 推导
Fatou 引理 (非负，下极限)
    ↓ 推导
控制收敛定理 (被可积函数控制)
```

实际上，三个定理是等价的——可以从任意一个推出另外两个。但通常按单调收敛→Fatou→控制收敛的顺序讲授。

**应用场景**：
- 单调收敛：非负递增列，如简单函数逼近、级数逐项积分
- Fatou：非负函数列，需要下界估计时
- 控制收敛：最常用，函数列被可积函数控制时

### 7.5 极限定理的应用

**应用 1（逐项积分）**：如果 fₙ≥0 可测，则 ∫∑fₙ=∑∫fₙ（由单调收敛定理，部分和递增）。
对一般级数，如果 ∑∫|fₙ|&lt;∞，则 ∫∑fₙ=∑∫fₙ（由控制收敛定理，控制函数 g=∑|fₙ|）。

**应用 2（含参积分的连续性）**：如果 f(x,t) 对每个 t 可测，f(x,t)→f(x,t₀) a.e.（t→t₀），且 |f(x,t)|≤g(x) 可积，则 ∫f(x,t)dx→∫f(x,t₀)dx（由控制收敛定理）。

**应用 3（含参积分的可导性）**：如果 ∂f/∂t 存在且 |∂f/∂t|≤g(x) 可积，则 d/dt∫f(x,t)dx=∫∂f/∂t dx（由控制收敛定理，差商被 g 控制）。

### 7.6 与 Riemann 框架的对比

Riemann 框架下，极限与积分交换需要**一致收敛**。
Lebesgue 框架下：
- 非负递增：单调收敛（无条件，除了非负递增）
- 非负一般：Fatou（半交换）
- 被可积函数控制：控制收敛（比一致收敛弱得多）

控制收敛定理的优势是巨大的：在很多应用中（如 Fourier 分析、偏微分方程、概率论），函数列不一致收敛，但被一个可积函数控制是很常见的。

### 7.7 几何理解

**📐 几何图像**：三大极限定理可以用"图像下方面积的极限"来理解。

- 单调收敛定理：如果函数列的图像从下方逐步升高（非负递增），则图像下方面积也逐步增大，极限面积等于极限图像的面积。几何上，这是"面积的下连续"——递增集合的面积极限等于极限集合的面积。
- Fatou 引理：非负函数列的图像可能"抖动"，但下极限图像的面积不超过面积的下极限。几何上，"liminf"对应于"最终在图像下方的区域"，这个区域的面积不超过各图像面积的下极限。
- 控制收敛定理：如果所有函数的图像都在一个"总面积有限"的图像（控制函数 g）下方，且函数图像逐点趋于极限图像，则面积也趋于极限面积。几何上，控制函数 g 提供了一个"有限的容器"，防止函数列的"质量"逃逸到无穷远（如 fₙ=nχ_{(0,1/n)} 没有可积控制函数，质量"浓缩"到一点，面积不趋于 0）。

控制收敛定理的几何本质是"有限容器中的面积收敛——如果所有图像都在一个总面积有限的容器内，且逐点收敛，则面积收敛。控制函数防止了质量的逃逸或浓缩"。

## 第八章 Lebesgue 积分与 Riemann 积分的关系

### 8.1 核心定理

**定理**：如果 f 在 [a,b] 上 Riemann 可积，则 f 在 [a,b] 上 Lebesgue 可积，且两个积分值相等。

**证明思路**：
1. Riemann 可积 ⟹ f 有界且几乎处处连续（Lebesgue 准则）
2. 几乎处处连续 ⟹ f 可测
3. 有界可测 ⟹ Lebesgue 可积
4. 积分值相等：用 Darboux 和逼近，Riemann 积分是 Darboux 上和/下和的公共极限，Lebesgue 积分也可以用简单函数（阶梯函数）逼近，两者极限相同

### 8.2 真包含关系

Lebesgue 可积函数类**真包含** Riemann 可积函数类：
- 所有 Riemann 可积函数都是 Lebesgue 可积的
- 存在 Lebesgue 可积但不 Riemann 可积的函数（如 Dirichlet 函数）

**包含关系图**：
连续函数 ⊂ 单调函数 ⊂ Riemann 可积函数 ⊂ Lebesgue 可积函数 ⊂ 可测函数

### 8.3 反常积分的关系

**无穷限反常积分**：
- 如果 f 在 [a,∞) 上的反常积分**绝对收敛**（∫ₐ^∞ |f|&lt;∞），则 f 在 [a,∞) 上 Lebesgue 可积，且积分值相等
- 如果反常积分**条件收敛**（如 ∫₀^∞ sin x/x dx），则 f 不是 Lebesgue 可积的（因为 ∫|f|=∞），Lebesgue 积分不存在

**瑕积分**：
- 如果瑕积分绝对收敛，则 Lebesgue 可积且值相等
- 如果瑕积分条件收敛，则不是 Lebesgue 可积

**结论**：Lebesgue 积分是"绝对收敛"的积分理论。它不包含条件收敛的反常积分。这是 Lebesgue 积分的一个局限（但可以通过条件收敛积分的专门理论补充，如 Henstock-Kurzweil 积分）。

### 8.4 微积分基本定理的 Lebesgue 版本

**Riemann 版本的 FTC**：如果 f' 在 [a,b] 上 Riemann 可积，则 ∫ₐᵇ f'(x)dx=f(b)-f(a)。
局限：f' 可能不 Riemann 可积（Volterra 函数）。

**Lebesgue 版本的 FTC**：
1. 如果 f 在 [a,b] 上绝对连续，则 f' 几乎处处存在且 Lebesgue 可积，且 ∫ₐᵇ f'(x)dx=f(b)-f(a)
2. 如果 f∈L¹[a,b]，则不定积分 F(x)=∫ₐˣ f(t)dt 绝对连续，且 F'=f a.e.

绝对连续是比连续更强的条件，它保证了 FTC 在 Lebesgue 框架下成立。Volterra 函数的导数有界但函数不是绝对连续的（实际上 Volterra 函数是连续但不是绝对连续的），所以 Lebesgue FTC 不适用——但有界导数一定 Lebesgue 可积，这是 Riemann 框架做不到的。

### 8.5 几何理解

**📐 几何图像**：Lebesgue 积分和 Riemann 积分的关系可以用"面积计算方法"来理解。

两种积分计算的是同一个几何量——函数图像下方的面积。区别在于计算方法：
- Riemann 积分：竖直切割，要求函数在每个竖直区间内变化不大（几乎处处连续）
- Lebesgue 积分：水平切割，要求每个水平层的集合可测

对于"足够好"的函数（几乎处处连续的有界函数），两种方法给出相同的面积。对于"不好"的函数（如 Dirichlet 函数，处处不连续），竖直切割失效但水平切割仍然有效——Lebesgue 积分能计算面积，Riemann 积分不能。

反常积分的关系：Lebesgue 积分计算的是"净面积"（正部面积减负部面积），要求正部和负部的面积都有限（绝对可积）。条件收敛的反常积分（如 sin x/x）正负面积都无穷大，但"交错求和"后得到有限值——这是 Lebesgue 积分不处理的情况。

Lebesgue 积分与 Riemann 积分关系的几何本质是"同一面积的两种计算方法——竖直切割（Riemann）和水平切割（Lebesgue）。对足够好的函数结果相同；Lebesgue 方法适用范围更广，但只处理绝对可积的情况"。

## 第九章 Fubini-Tonelli 定理

### 9.1 乘积测度

设 (X,𝓐,μ) 和 (Y,𝓑,ν) 是两个测度空间。乘积 σ-代数 𝓐×𝓑 由所有可测矩形 A×B（A∈𝓐, B∈𝓑）生成。

乘积测度 μ×ν 定义在 𝓐×𝓑 上，满足 (μ×ν)(A×B)=μ(A)ν(B)。

对于 Lebesgue 测度，ℝ² 上的二维 Lebesgue 测度 m₂ 就是 m₁×m₁（一维 Lebesgue 测度的乘积），对应面积。

### 9.2 Tonelli 定理

**定理（Tonelli，1909）**：设 f(x,y)≥0 是 X×Y 上的可测函数，则
1. 对每个 x，f(x,·) 是 Y 上的可测函数；对每个 y，f(·,y) 是 X 上的可测函数
2. g(x)=∫_Y f(x,y)dν(y) 是 X 上的可测函数；h(y)=∫_X f(x,y)dμ(x) 是 Y 上的可测函数
3. ∫_{X×Y} f d(μ×ν) = ∫_X [∫_Y f(x,y)dν(y)]dμ(x) = ∫_Y [∫_X f(x,y)dμ(x)]dν(y)

**关键特点**：
- 只要求 f≥0 可测，**不要求可积**！
- 即使积分值为 +∞，等式仍然成立
- 这是 Tonelli 定理的巨大优势：对非负函数，积分顺序可以无条件交换

### 9.3 Fubini 定理

**定理（Fubini，1907）**：设 f(x,y) 在 X×Y 上 Lebesgue 可积（∫|f|d(μ×ν)&lt;∞），则
1. 对几乎每个 x，f(x,·) 在 Y 上可积；对几乎每个 y，f(·,y) 在 X 上可积
2. g(x)=∫_Y f(x,y)dν(y) a.e. 有定义且在 X 上可积；h(y) 同理
3. ∫_{X×Y} f d(μ×ν) = ∫_X [∫_Y f dν]dμ = ∫_Y [∫_X f dμ]dν

**关键特点**：
- 要求 f 可积（绝对可积）
- 结论比 Tonelli 更强：内层积分几乎处处有限且可积

### 9.4 Fubini-Tonelli 的使用策略

实际应用中，通常的策略是：
1. 先用 Tonelli 定理计算 ∫|f|（因为 |f|≥0），判断 f 是否可积
2. 如果 ∫|f|&lt;∞，再用 Fubini 定理交换积分顺序计算 ∫f

这样就避免了直接验证可积性的困难——Tonelli 定理对非负函数无条件成立，可以用来"自检"可积性。

### 9.5 经典反例

**反例（Riemann 框架下 Fubini 失效）**：f(x,y)=(x²-y²)/(x²+y²)² 在 [0,1]×[0,1] 上。
- ∫₀¹∫₀¹ f dxdy = π/4
- ∫₀¹∫₀¹ f dydx = -π/4
- 两个累次积分不等！

在 Lebesgue 框架下：
- |f| 不可积（∫|f|=∞），所以 Fubini 定理不适用
- 但 Tonelli 定理告诉我们 ∫|f|=∞（因为两个累次积分的绝对值不相等，说明 |f| 的积分无穷大）
- 这正是 Fubini 定理要求可积的原因——不可积时累次积分可能不等

### 9.6 几何理解

**📐 几何图像**：Fubini-Tonelli 定理的几何意义是"体积可以用两种截面方法计算"。

- 先 y 后 x：固定 x，用垂直于 x 轴的平面切立体，截面面积 A(x)=∫f(x,y)dy，体积 V=∫A(x)dx
- 先 x 后 y：固定 y，用垂直于 y 轴的平面切立体，截面面积 B(y)=∫f(x,y)dx，体积 V=∫B(y)dy

Fubini-Tonelli 定理说这两种方法得到的体积相同——这是"体积的截面不变性"。

Tonelli 定理（非负函数）的几何意义：对于非负函数（图像在 x 轴上方），体积总是可以用两种截面方法计算，即使体积无穷大。这是因为非负函数的图像下方面积是"单调的"——不会出现正负抵消的情况。

Fubini 定理（可积函数）的几何意义：对于可积函数（总面积有限），两种截面方法得到相同的净体积。如果不可积（正负面积都无穷大），两种方法可能得到不同的结果（因为无穷大减无穷大不确定）。

经典反例 (x²-y²)/(x²+y²)² 的几何图像：这个函数在原点附近剧烈震荡，正负面积都无穷大。先 x 后 y 和先 y 后 x 给出不同的"条件收敛"结果——类似于条件收敛级数的重排可以改变和。Fubini 定理要求绝对可积，正是为了避免这种"重排效应"。

Fubini-Tonelli 定理的几何本质是"体积的截面不变性——非负函数无条件成立（Tonelli），可积函数成立（Fubini），不可积函数可能失效。Tonelli 可以用来自检可积性"。

## 第十章 Lebesgue 微分定理

### 10.1 定理陈述

**定理（Lebesgue 微分定理，1904）**：设 f∈L¹(ℝⁿ)，则对几乎所有 x∈ℝⁿ，
lim_{r→0} (1/m(B(x,r))) ∫_{B(x,r)} f(y)dm(y) = f(x)

其中 B(x,r) 是以 x 为中心、r 为半径的球。

**一维版本**：设 f∈L¹[a,b]，则对几乎所有 x∈[a,b]，
lim_{h→0} (1/(2h)) ∫_{x-h}^{x+h} f(t)dt = f(x)

等价地，不定积分 F(x)=∫ₐˣ f(t)dt 的导数 F'(x)=f(x) a.e.

### 10.2 定理的意义

Lebesgue 微分定理说明：可积函数的不定积分几乎处处可导，且导数等于原函数。

这是微积分基本定理的 Lebesgue 版本的一半：
- FTC 第一部分：如果 f 可积，则 F(x)=∫ₐˣ f 可导 a.e. 且 F'=f a.e.（Lebesgue 微分定理）
- FTC 第二部分：如果 F 绝对连续，则 ∫ₐᵇ F'=F(b)-F(a)（下一章）

### 10.3 证明思路：Hardy-Littlewood 极大函数

证明 Lebesgue 微分定理的关键工具是 **Hardy-Littlewood 极大函数**：
(Mf)(x)=sup_{r>0} (1/m(B(x,r))) ∫_{B(x,r)} |f(y)|dm(y)

**极大定理（弱 (1,1) 估计）**：m({Mf>λ})≤(C/λ)||f||₁（C 是常数）

**证明微分定理**：
1. 对连续函数，微分定理显然成立（积分平均趋于函数值）
2. 连续函数在 L¹ 中稠密，对任意 f∈L¹ 和 ε>0，取连续 g 使得 ||f-g||₁&lt;ε
3. 用极大函数估计 f 的积分平均与 f(x) 的差：|A_r f - f|≤|A_r(f-g)|+|A_r g-g|+|g-f|
4. 用极大定理控制第一项，用连续性控制第二项，用 Chebyshev 控制第三项
5. 令 ε→0 得结论

### 10.4 推论

**推论 1（Lebesgue 点）**：几乎所有 x 都是 f 的 Lebesgue 点，即
lim_{r→0} (1/m(B(x,r))) ∫_{B(x,r)} |f(y)-f(x)|dm(y)=0

Lebesgue 点比微分定理更强——不仅积分平均趋于 f(x)，而且绝对偏差的平均也趋于 0。

**推论 2（不定积分的可导性）**：如果 f∈L¹[a,b]，则 F(x)=∫ₐˣ f(t)dt 在 [a,b] 上几乎处处可导，且 F'(x)=f(x) a.e.

### 10.5 几何理解

**📐 几何图像**：Lebesgue 微分定理的几何意义是"可积函数在几乎每一点都是'局部平均连续'的"。

在一点 x 处，取一个越来越小的球（或区间），计算球内函数的平均值。Lebesgue 微分定理说：对几乎所有 x，这个平均值趋于 f(x)。

几何上，这意味着可积函数的图像在几乎每一点附近"震荡不剧烈"——缩小窗口后，窗口内的平均高度趋于窗口中心的高度。当然，可能存在一些"坏点"（如函数的不连续点或剧烈震荡点），但这些点的集合测度为 0。

Dirichlet 函数的例子：在无理点（测度 1），任意小区间内的平均值 = 0（因为有理点测度为 0），趋于 D(x)=0。在有理点（测度 0），平均值也 = 0，但 D(x)=1——所以有理点不是 Lebesgue 点。几乎处处（无理点）微分定理成立。

极大函数的几何意义：Mf(x) 是 x 处所有尺度上的"最大平均高度"——它控制了函数在 x 附近的"震荡幅度"。极大定理说：最大平均高度超过 λ 的点集的测度不超过 C||f||₁/λ——这是一个"弱型"估计，是证明微分定理的关键。

Lebesgue 微分定理的几何本质是"可积函数几乎处处局部平均连续——缩小窗口后平均高度趋于中心高度，通过极大函数的弱型估计证明"。

## 第十一章 绝对连续与不定积分

### 11.1 绝对连续函数

**定义**：函数 F:[a,b]→ℝ 称为**绝对连续**的，如果对任意 ε>0，存在 δ>0，使得对 [a,b] 中任意有限个互不相交的区间 (aᵢ,bᵢ)，当 ∑(bᵢ-aᵢ)&lt;δ 时，有 ∑|F(bᵢ)-F(aᵢ)|&lt;ε。

**绝对连续 vs 一致连续 vs Lipschitz**：
- Lipschitz ⟹ 绝对连续 ⟹ 一致连续 ⟹ 连续
- 反过来不成立：√x 在 [0,1] 上绝对连续但不是 Lipschitz
- Cantor 函数连续但不是绝对连续（它在 Cantor 集上"增长"，但 Cantor 集测度为 0）

### 11.2 绝对连续函数的性质

1. **绝对连续函数是有界变差的**
2. **绝对连续函数几乎处处可导**（因为有界变差函数几乎处处可导）
3. **导数可积**：如果 F 绝对连续，则 F'∈L¹[a,b]
4. **Newton-Leibniz 公式成立**：∫ₐᵇ F'(x)dx=F(b)-F(a)
5. **不定积分是绝对连续的**：如果 f∈L¹，则 F(x)=∫ₐˣ f(t)dt 绝对连续

### 11.3 微积分基本定理的完整 Lebesgue 版本

**定理（FTC，Lebesgue 版本）**：以下三个命题等价：
1. F 在 [a,b] 上绝对连续
2. 存在 f∈L¹[a,b]，使得 F(x)=F(a)+∫ₐˣ f(t)dt 对所有 x∈[a,b]
3. F 在 [a,b] 上几乎处处可导，F'∈L¹[a,b]，且 F(x)=F(a)+∫ₐˣ F'(t)dt 对所有 x

且在以上条件下，f=F' a.e.

**意义**：绝对连续函数恰好就是"可以表示为可积函数的不定积分"的函数。这是微积分基本定理在 Lebesgue 框架下的完整形式。

### 11.4 有界变差函数

**定义**：F 称为**有界变差**的，如果 sup{∑|F(xᵢ)-F(xᵢ₋₁)|}&lt;∞，其中上确界取遍所有分割。

**Jordan 分解**：有界变差函数可以分解为两个递增函数之差：F=F₁-F₂，其中 F₁,F₂ 递增。

**性质**：
- 有界变差函数几乎处处可导
- 导数可积
- 但 Newton-Leibniz 公式不一定成立！∫ₐᵇ F'≤F(b)-F(a)，可能严格小于
- Cantor 函数是有界变差的（递增），但 F'=0 a.e.，所以 ∫F'=0≠F(1)-F(0)=1

**绝对连续 = 有界变差 + Newton-Leibniz 公式成立**。

### 11.5 Cantor 函数

Cantor 函数（魔鬼阶梯）是一个重要的反例：
- 连续、递增、有界变差
- F(0)=0, F(1)=1
- F'=0 a.e.（在 Cantor 集的余集上，F 是常数，导数为 0；Cantor 集测度为 0）
- 但 ∫₀¹ F'=0≠F(1)-F(0)=1
- 不是绝对连续的

Cantor 函数说明：连续 + 有界变差 + 几乎处处可导 + 导数可积，还不足以保证 Newton-Leibniz 公式成立——需要绝对连续。

### 11.6 奇异函数

**定义**：连续递增函数 F 称为**奇异**的，如果 F'=0 a.e. 但 F 不是常数。

Cantor 函数是最典型的奇异函数。

**Lebesgue 分解**：任意有界变差函数 F 可以分解为
F=F_AC + F_sing + F_jump
其中 F_AC 绝对连续，F_sing 奇异连续，F_jump 跳跃函数。

这是测度的 Lebesgue 分解在函数中的对应。

### 11.7 几何理解

**📐 几何图像**：绝对连续函数的几何意义是"图像的'水平变化'完全由'斜率积分'决定"。

- 连续函数：图像没有断点
- 一致连续：图像的"震荡"在小尺度上均匀小
- 绝对连续：图像在任意小总宽度的区间集合上的总"高度变化"可以任意小——这意味着函数的"增长"完全分布在"有宽度"的集合上，不会集中在零测集上
- Lipschitz：图像的斜率有界

Cantor 函数的几何图像：它是一个"阶梯"——在 Cantor 集的余集（可数个开区间）上是常数（水平线段），在 Cantor 集（测度为 0 的"灰尘"集合）上"增长"。图像从 0 爬到 1，但几乎处处水平（导数为 0）。它的"增长"集中在一个零测集上——这就是为什么它不是绝对连续的，也是为什么 Newton-Leibniz 公式失效。

绝对连续函数的几何本质是"增长不集中在零测集上——总高度变化完全由斜率的积分决定，Newton-Leibniz 公式成立。Cantor 函数是反例：增长集中在零测集上，Newton-Leibniz 失效"。

## 第十二章 Lp 空间初步

### 12.1 Lp 空间的定义

**定义**：对 1≤p&lt;∞，Lp(E) 是 E 上所有满足 ∫_E |f|^p dm&lt;∞ 的可测函数的集合，模掉几乎处处相等的等价类。

范数：||f||_p=(∫|f|^p)^{1/p}

**L^∞ 空间**：L^∞(E) 是 E 上所有本性有界可测函数的集合。
范数：||f||_∞=ess sup |f|=inf{M: |f|≤M a.e.}

### 12.2 Lp 空间的性质

1. **Hölder 不等式**：如果 1/p+1/q=1（共轭指数），则 ||fg||₁≤||f||_p||g||_q
2. **Minkowski 不等式**：||f+g||_p≤||f||_p+||g||_p（三角不等式，说明 ||·||_p 是范数）
3. **完备性（Riesz-Fischer 定理，1907）**：Lp(E) 是 Banach 空间（完备的赋范线性空间）
4. **包含关系**：如果 m(E)&lt;∞，则 L^q(E)⊂Lp(E) 对 p&lt;q（有限测度集上，高阶可积蕴含低阶可积）
5. **稠密性**：连续函数、简单函数、阶梯函数在 Lp 中稠密（1≤p&lt;∞）
6. **可分性**：Lp(E) 可分（1≤p&lt;∞），L^∞ 不可分

### 12.3 Riesz-Fischer 定理

**定理（Riesz-Fischer，1907）**：Lp(E)（1≤p≤∞）是完备的——每个 Cauchy 列都收敛到 Lp 中的函数。

**意义**：这是 Lebesgue 积分相对于 Riemann 积分的决定性优势之一。Riemann 可积函数空间在 Lp 范数下不完备，而 Lebesgue 可积函数空间完备。完备性是泛函分析的基础——没有完备性，就没有 Banach 空间理论、Hilbert 空间理论、Fourier 分析的现代理论。

**证明思路**：
1. 取 Cauchy 列 {fₙ}，选子列 {f_{nₖ}} 使得 ||f_{nₖ₊₁}-f_{nₖ}||_p&lt;2^{-k}
2. 证明子列逐点收敛到某个 f（用单调收敛定理和 Chebyshev 不等式）
3. 用 Fatou 引理证明 f∈Lp 且 ||f_{nₖ}-f||_p→0
4. 因为原列是 Cauchy 列，所以整个列收敛到 f

### 12.4 L² 空间与 Hilbert 空间

L² 空间是特殊的 Lp 空间（p=2），它有内积：
⟨f,g⟩=∫ f·g dm

L² 是 Hilbert 空间（完备的内积空间），是 Fourier 分析和量子力学的数学基础。

**Riesz-Fischer 定理在 L² 中的形式**：L² 完备，这意味着 Fourier 级数在 L² 意义下总是收敛的（对任意 L² 函数）。这是 Fourier 分析的基本定理。

### 12.5 几何理解

**📐 几何图像**：Lp 空间可以看作"函数的几何空间"。

- Lp 范数 ||f||_p 是函数 f 到原点的"距离"——p 次幂积分的 p 次方根
- 两个函数的"距离"是 ||f-g||_p
- Lp 空间中的"球"是所有满足 ||f||_p≤R 的函数
- Hölder 不等式是"内积不等式"的推广——两个函数的"乘积积分"不超过各自范数的乘积
- Minkowski 不等式是"三角不等式"——两点之间直线最短

Riesz-Fischer 定理（完备性）的几何意义：Lp 空间中没有"洞"——Cauchy 列的极限仍然在空间中。Riemann 可积函数空间有"洞"（Cauchy 列的极限可能是 Dirichlet 函数，不在空间中），Lebesgue 可积函数空间把这些"洞"填上了。

L² 空间的几何意义最丰富：它是 Hilbert 空间，可以定义角度（内积）、正交性、正交投影。Fourier 级数就是 L² 中的正交展开——把函数投影到三角函数的正交基上。

Lp 空间的几何本质是"函数的 Banach 空间——p 次可积函数构成完备的赋范线性空间，L² 是 Hilbert 空间。完备性（Riesz-Fischer）是 Lebesgue 积分的决定性优势，为泛函分析和 Fourier 分析奠定基础"。

## 第十三章 反例库

### 13.1 测度反例

**反例 1（不可测集）**：Vitali 集——选择公理下存在 Lebesgue 不可测集。说明测度不能定义在所有集合上。

**反例 2（Cantor 集）**：不可数但测度为 0 的集合。说明"不可数"不等于"正测度"。

**反例 3（类 Cantor 集，正测度）**：存在类 Cantor 集（无处稠密、完备）但测度为正（如每次去掉中间 1/4 而非 1/3）。说明"无处稠密"不等于"零测度"。

**反例 4（Fat 集）**：开集可以包含所有有理点但测度任意小（用总长 ε 的区间覆盖有理数）。说明"稠密开集"可以有很小的测度。

### 13.2 可测函数反例

**反例 5（处处不连续但可测）**：Dirichlet 函数——处处不连续但可测（因为水平集是有理数集或无理数集，都可测）。

**反例 6（可测但不 Riemann 可积）**：Dirichlet 函数——Lebesgue 可积但 Riemann 不可积。

**反例 7（依测度收敛但不逐点收敛）**：fₙ=χ_{(k/2ᵐ,(k+1)/2ᵐ)}（滑动区间），依测度收敛到 0，但在每一点都不收敛（每个点属于无穷多个区间）。

**反例 8（逐点收敛但不依测度收敛）**：在无限测度空间上，fₙ=χ_{(n,n+1)}，逐点收敛到 0，但不依测度收敛（m({|fₙ|>1/2})=1 不趋于 0）。

### 13.3 积分反例

**反例 9（非负可测但积分无穷）**：f(x)=1/x 在 (0,1) 上——非负可测但 ∫f=∞，不可积。

**反例 10（条件收敛反常积分但不 Lebesgue 可积）**：sin x/x 在 [0,∞) 上——反常积分条件收敛（=π/2），但 |sin x/x| 不可积，所以不是 Lebesgue 可积的。

**反例 11（f 可积但 f² 不可积）**：f(x)=1/√x 在 (0,1) 上——f 可积（∫1/√x=2），但 f²=1/x 不可积。说明有限测度集上 L¹⊃L²。

**反例 12（f² 可积但 f 不可积）**：在无限测度空间上，f(x)=1/x 在 [1,∞) 上——f²=1/x² 可积，但 f=1/x 不可积。说明无限测度集上 L²⊃L¹（和有限测度相反）。

### 13.4 极限定理反例

**反例 13（控制收敛定理中控制函数不可少）**：fₙ=nχ_{(0,1/n)}——逐点收敛到 0，但 ∫fₙ=1 不趋于 0。没有可积的控制函数（任何控制 g 满足 g≥n 在 (0,1/n) 上，∫g≥1 对所有 n，但实际上 g(x)≥sup n·χ_{(0,1/n)}=1/x，∫1/x=∞）。

**反例 14（Fatou 引理中等号不一定成立）**：fₙ=χ_{(0,1)}（n 奇），fₙ=0（n 偶）——liminf fₙ=0，∫fₙ 在 0 和 1 之间交替，liminf∫fₙ=0，等号成立。但 fₙ=nχ_{(0,1/n)}：liminf fₙ=0，liminf∫fₙ=1，严格不等。

**反例 15（单调收敛定理中非负不可少）**：fₙ=-χ_{(n,∞)}——递增（-χ_{(n,∞)} 随 n 增大而增大，因为区间缩小），极限为 0，但 ∫fₙ=-∞ 不趋于 0。非负条件不可少（或需要有可积的下界控制）。

### 13.5 Fubini 反例

**反例 16（不可积时累次积分不等）**：f(x,y)=(x²-y²)/(x²+y²)² 在 [0,1]² 上——先 x 后 y = π/4，先 y 后 x = -π/4。|f| 不可积，Fubini 不适用。

**反例 17（内层积分不存在）**：f(x,y)=1/(x-y)² 在 [0,1]² 上——对每个 x≠y，内层积分发散。f 不可积。

### 13.6 微分与绝对连续反例

**反例 18（连续但导数不可积）**：f(x)=x² sin(1/x²)（x≠0），f(0)=0——处处可导，但 f' 在 0 附近无界且不可积（f' 包含 cos(1/x²)/x 项）。

**反例 19（有界变差但不绝对连续）**：Cantor 函数——连续递增有界变差，F'=0 a.e.，但 ∫F'=0≠F(1)-F(0)=1。不是绝对连续。

**反例 20（绝对连续但不是 Lipschitz）**：f(x)=√x 在 [0,1] 上——绝对连续（因为 f'=1/(2√x) 可积），但不是 Lipschitz（f' 在 0 附近无界）。

**反例 21（几乎处处可导且导数可积但 Newton-Leibniz 失效）**：Cantor 函数——F'=0 a.e. 可积，但 ∫F'≠F(1)-F(0)。需要绝对连续才能保证 FTC。

### 13.7 反例总结

| 反例类型 | 典型例子 | 关键特征 |
|---|---|---|
| 不可测集 | Vitali 集 | 选择公理，测度不能定义在所有集合上 |
| 不可数零测集 | Cantor 集 | 不可数但测度为 0 |
| 无处稠密正测集 | 类 Cantor 集（去 1/4） | 无处稠密但正测度 |
| 处处不连续可测 | Dirichlet 函数 | 处处不连续但可测可积 |
| 条件收敛非 L 可积 | sin x/x | 反常条件收敛但非 Lebesgue 可积 |
| 控制函数不可少 | nχ_{(0,1/n)} | 逐点收敛到 0 但积分不趋于 0 |
| Fubini 不可积失效 | (x²-y²)/(x²+y²)² | 两个累次积分不等 |
| 有界变差非绝对连续 | Cantor 函数 | F'=0 a.e. 但 FTC 失效 |
| 绝对连续非 Lipschitz | √x | 绝对连续但导数无界 |
| 导数不可积 | x² sin(1/x²) | 处处可导但导数不可积 |

## 第十四章 历史演进

### 14.1 Lebesgue 积分理论的历史分期

**第一期：测度论的先驱（1880s-1890s）**
- 1881：Volterra 构造导数有界但不 Riemann 可积的函数——暴露 Riemann 积分的根本缺陷
- 1887：Peano 引入内测度和外测度（Peano 测度，有限可加）
- 1892：Jordan 引入 Jordan 测度（有限可加，比 Peano 更系统）
- 1898：Borel 引入 Borel 测度（可数可加，定义在 Borel 集上）

**第二期：Lebesgue 的革命（1901-1910）**
- 1901：Lebesgue 引入 Lebesgue 测度（Borel 测度的完备化）
- 1902：Lebesgue 博士论文《积分、长度与面积》——建立 Lebesgue 积分理论
- 1904：Lebesgue 微分定理
- 1905：Lebesgue 引入可测函数，研究原函数问题
- 1906：Fatou 引理；Levi 单调收敛定理
- 1907：Fubini 定理；Riesz-Fischer 定理（L² 完备性）
- 1909：Tonelli 定理（非负函数的 Fubini）
- 1910：Lebesgue 系统阐述积分理论，引入绝对连续

**第三期：抽象化与公理化（1910s-1930s）**
- 1913：Radon 引入抽象测度（Radon 测度）
- 1915：Fréchet 提出抽象测度空间
- 1918：Carathéodory 给出可测集的公理化定义（外测度方法）
- 1920s：Lebesgue 积分成为分析学的标准工具
- 1930：Kolmogorov 用测度论建立概率论公理基础
- 1930s：Banach 空间理论发展，Lp 空间成为基本例子

**第四期：现代发展（1930s-至今）**
- 1930s：Hahn-Banach 定理、一致有界原理，泛函分析成熟
- 1940s：Schwartz 分布理论（广义函数），Lebesgue 积分的推广
- 1950s：Malliavin 分析，随机分析
- 1960s：Henstock-Kurzweil 积分（更一般的积分，包含条件收敛反常积分）
- 至今：测度论和 Lebesgue 积分是现代分析学、概率论、偏微分方程、量子力学的基础

### 14.3 历史发展的主线

1. **从 Riemann 的缺陷到 Lebesgue 的革命**：Volterra 函数暴露 Riemann 积分的根本缺陷（导数可能不可积），Lebesgue 通过"分割值域"的新思想彻底解决了这个问题
2. **从长度到测度**：从区间长度（Jordan 测度，有限可加）到 Borel 测度（可数可加）到 Lebesgue 测度（完备化），测度概念不断完善
3. **从具体到抽象**：从 ℝ 上的 Lebesgue 测度到抽象测度空间（Radon、Carathéodory），测度论成为独立的数学分支
4. **从积分到分析基础**：Lebesgue 积分成为现代分析学的基础——泛函分析（Lp 空间、Banach 空间）、概率论（Kolmogorov 公理）、偏微分方程（弱解、Sobolev 空间）、量子力学（L² 空间、Hilbert 空间）
5. **从积分到更一般的积分**：Henstock-Kurzweil 积分（包含条件收敛反常积分）、分布理论（广义函数的积分），Lebesgue 积分仍然是核心

### 15.3 关键蜕变问题

**问题一：Lebesgue 积分是否"完全取代"了 Riemann 积分？**

回答：在理论层面，Lebesgue 积分确实是 Riemann 积分的严格推广——所有 Riemann 可积函数都是 Lebesgue 可积的，且积分值相同；Lebesgue 可积函数类更宽；极限定理更强大；积分空间完备；Fubini 定理更一般。

但在以下方面，Riemann 积分仍有价值：
1. **教学**：Riemann 积分更直观（分割定义域、面积），是学习 Lebesgue 积分的基础
2. **计算**：Riemann 积分的计算方法（Newton-Leibniz 公式、换元法、分部积分）对 Lebesgue 积分同样适用（因为 Riemann 可积函数的 Lebesgue 积分值相同）
3. **条件收敛反常积分**：Lebesgue 积分不包含条件收敛的反常积分（如 sin x/x），这些需要 Riemann 反常积分或更一般的 Henstock-Kurzweil 积分
4. **数值积分**：Riemann 和的思想是数值积分的基础
5. **历史和概念理解**：Riemann 积分暴露的问题（Dirichlet 函数、Volterra 函数、极限交换）是理解 Lebesgue 积分动机的关键

所以更准确的说法是：Lebesgue 积分是 Riemann 积分的**理论推广和深化**，但 Riemann 积分在教学、计算、条件收敛反常积分等方面仍有独立价值。在现代分析学中，Lebesgue 积分是标准工具，但 Riemann 积分是不可或缺的入门阶梯。

**问题二：为什么 Lebesgue 积分只处理绝对可积的函数？这是局限吗？**

回答：Lebesgue 积分的定义（正部减负部）天然要求绝对可积——如果正部和负部的积分都是无穷大，∞-∞ 没有定义。

这确实是一个局限：
- 条件收敛的反常积分（如 ∫₀^∞ sin x/x dx=π/2）不是 Lebesgue 积分
- 某些 Fourier 积分的条件收敛情况需要特殊处理

但这个局限是有道理的：
1. **绝对可积是"好"的积分**：绝对可积函数的积分具有良好的性质（极限定理、Fubini 定理等），条件收敛积分的性质较差（重排可以改变值，类似条件收敛级数）
2. **大多数应用只需要绝对可积**：在 Lp 空间、概率论、偏微分方程等应用中，函数通常是绝对可积的
3. **可以补充**：条件收敛反常积分可以用 Riemann 反常积分或 Henstock-Kurzweil 积分处理，作为 Lebesgue 积分的补充

Henstock-Kurzweil 积分（1950s-1960s）是更一般的积分，它包含 Riemann 积分、Lebesgue 积分和条件收敛反常积分。但它的理论不如 Lebesgue 积分简洁，应用也不如 Lebesgue 积分广泛。所以在实践中，Lebesgue 积分仍然是标准选择，条件收敛反常积分作为补充。

### 16.3 常见误区清单

1. **混淆 Riemann 可积和 Lebesgue 可积** → Riemann 可积 ⟹ Lebesgue 可积，反过来不一定
2. **认为 Lebesgue 积分包含所有反常积分** → 只包含绝对收敛的反常积分，条件收敛的不包含
3. **忘记控制收敛定理需要控制函数** → 没有可积控制函数时极限与积分不一定交换（nχ_{(0,1/n)}）
4. **Fatou 引理方向搞反** → 是 ∫liminf ≤ liminf∫，不是 ≥
5. **单调收敛定理忘记非负条件** → 非负递增是必要条件
6. **Fubini 定理不验证可积性就交换** → 不可积时累次积分可能不等（(x²-y²)/(x²+y²)²）
7. **认为所有集合都可测** → 选择公理下存在不可测集（Vitali 集）
8. **认为不可数集一定正测度** → Cantor 集不可数但测度为 0
9. **认为无处稠密集一定零测度** → 类 Cantor 集（去 1/4）无处稠密但正测度
10. **混淆绝对连续和一致连续** → 绝对连续更强，Lipschitz ⟹ 绝对连续 ⟹ 一致连续
11. **认为有界变差函数满足 FTC** → 需要绝对连续，Cantor 函数是反例
12. **认为导数一定可积** → 处处可导函数的导数可能不可积（x² sin(1/x²)）
13. **认为 Lp 空间对所有 p 有包含关系** → 有限测度集上 p&lt;q 时 L^q⊂Lp；无限测度集上相反
14. **忘记积分定义中 0·∞=0 的约定** → 简单函数积分中 aᵢ=0 且 m(Eᵢ)=∞ 时约定为 0
15. **认为依测度收敛蕴含逐点收敛** → 不一定（滑动区间反例），但有子列逐点收敛

> **模块结语 · 分割值域的革命**：
>
> D4-6 Lebesgue 积分理论是 D4 积分领域的第六模块——积分理论的第二次飞跃（第一次是从不定积分到定积分/Riemann 积分，第二次是从 Riemann 积分到 Lebesgue 积分）。
>
> **Riemann 积分的根本局限**：Riemann 积分通过"分割定义域"来定义，要求函数"几乎处处连续"才能可积。这导致了一系列问题：Dirichlet 函数这样的简单函数不可积；导数可能不可积（Volterra 函数），微积分基本定理失效；极限与积分交换需要一致收敛这样的强条件；Riemann 可积函数空间不完备；Fubini 定理条件强。
>
> **Lebesgue 的核心思想**：不分割定义域，而是分割值域。把值域分成小区间，考虑每个水平层对应的 x 集合，如果能度量这些集合的"长度"（测度），就能定义积分。这样即使函数剧烈震荡，只要水平集可测，就能计算积分。Dirichlet 函数的积分 = 1·m(有理点)+0·m(无理点)=1·0+0·1=0。
>
> **Lebesgue 测度**：从区间长度推广到一般集合的测度。外测度用可数个区间覆盖取下确界；可测集用 Carathéodory 定义（可以分割任意集合的外测度）；Lebesgue 测度可数可加、平移不变、完备。零测集（可数集、Cantor 集）在积分中"可以忽略"。选择公理下存在不可测集（Vitali 集）。
>
> **可测函数**：水平集可测的函数。可测函数对逐点极限封闭（这是 Riemann 可积函数不具备的），可以用简单函数逼近。Lusin 定理说可测函数"差不多是连续的"，Egoroff 定理说逐点收敛"差不多是一致收敛的"——Littlewood 三原则。
>
> **Lebesgue 积分的三步定义**：非负简单函数（∑aᵢm(Eᵢ)）→ 非负可测函数（简单函数上确界）→ 一般可测函数（正部减负部）。可积 = 绝对可积（∫|f|&lt;∞）。
>
> **三大极限定理**：单调收敛定理（非负递增列，积分与极限交换）、Fatou 引理（非负函数列，下极限的积分≤积分的下极限）、控制收敛定理（被可积函数控制，极限与积分交换）。这三个定理等价，是 Lebesgue 积分最强大的工具——把一致收敛的强条件弱化为"被可积函数控制"。
>
> **Fubini-Tonelli 定理**：Tonelli 定理对非负函数无条件交换积分顺序（即使积分无穷），Fubini 定理对可积函数交换积分顺序。使用策略：先用 Tonelli 计算 ∫|f| 判断可积性，再用 Fubini 交换。这比 Riemann 框架下的 Fubini 定理更一般、更灵活。
>
> **Lebesgue 微分定理**：可积函数的不定积分几乎处处可导，导数等于原函数。通过 Hardy-Littlewood 极大函数的弱 (1,1) 估计证明。几乎每一点都是 Lebesgue 点（绝对偏差的平均趋于 0）。
>
> **绝对连续与微积分基本定理**：绝对连续函数恰好就是"可以表示为可积函数的不定积分"的函数。FTC 的 Lebesgue 版本：F 绝对连续 ⟺ F(x)=F(a)+∫ₐˣ f，且 f=F' a.e.。Cantor 函数是反例——连续递增有界变差，F'=0 a.e.，但 FTC 失效（因为不是绝对连续，增长集中在零测集上）。
>
> **Lp 空间与 Riesz-Fischer 定理**：Lp 空间是 p 次可积函数的 Banach 空间，Hölder 不等式和 Minkowski 不等式是基本工具。Riesz-Fischer 定理说 Lp 空间完备——这是 Lebesgue 积分相对于 Riemann 积分的决定性优势，为泛函分析和 Fourier 分析奠定了基础。L² 是 Hilbert 空间，是量子力学和 Fourier 分析的数学基础。
>
> **跨层蜕变**：从 L0 初等直觉（面积）到 L1 Riemann 积分（分割定义域，几乎处处连续可积）到 L3 Lebesgue 积分（分割值域，可测可积），积分理论不断深化。Lebesgue 积分解决了 Riemann 积分的所有根本局限：更宽的可积函数类、更强大的极限定理、更一般的 Fubini 定理、完备的积分空间、更一般的微积分基本定理。但 Lebesgue 积分只处理绝对可积的函数，条件收敛反常积分需要补充。
>
> 几何视角贯穿全章：水平切割求面积（Lebesgue 积分的核心思想）、长度/面积/体积的公理化推广（测度）、水平集可测的函数（可测函数）、面积的下连续（单调收敛）、有限容器中的面积收敛（控制收敛）、体积的截面不变性（Fubini-Tonelli）、可积函数几乎处处局部平均连续（Lebesgue 微分定理）、增长不集中在零测集上（绝对连续）、函数的 Banach 空间（Lp 完备性）——所有 Lebesgue 积分概念都有清晰的几何图像。
>
> Lebesgue 积分理论的核心洞察是：**通过"分割值域"而非"分割定义域"，Lebesgue 积分克服了 Riemann 积分对函数连续性的强依赖，建立了更一般、更强大的积分理论。三大极限定理（单调收敛、Fatou、控制收敛）给出了灵活的极限交换条件，Fubini-Tonelli 定理给出了一般的积分顺序交换条件，Lebesgue 微分定理和绝对连续函数给出了完整的微积分基本定理，Riesz-Fischer 定理保证了 Lp 空间的完备性。Lebesgue 积分是现代分析学（实变函数、泛函分析、概率论、偏微分方程、量子力学）的基石，是 20 世纪数学最重要的成就之一。**
