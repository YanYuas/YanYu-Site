## 第一章 引言：积分计算的艺术

### 1.1 积分计算的定位

微分和积分的一个重要区别是：
- **微分**：有系统的法则（链式法则、乘积法则、商法则），任何初等函数的导数都可以通过机械应用这些法则求出
- **积分**：没有统一的机械法则——积分是"艺术"，需要根据被积函数的特点选择合适的技巧，有些积分甚至"积不出来"（原函数不是初等函数）

D4-1 建立了不定积分的基本技巧（换元、分部、部分分式），D4-2 建立了定积分的理论基础。本模块在此基础上，深入研究更高级的积分计算技巧和著名特殊积分。

### 1.2 积分计算技巧的层次

| 层次 | 技巧 | 适用范围 |
|---|---|---|
| L1 基本 | 基本积分公式、代数化简 | 简单初等函数 |
| L2 标准 | 第一类换元（凑微分）、第二类换元、分部积分 | 大多数初等函数 |
| L3 系统 | 部分分式分解、万能代换、三角代换 | 有理函数、三角函数、无理函数 |
| L4 高级 | 参数积分法、递推公式、级数展开法、对称性技巧 | 复杂积分、特殊积分 |
| L5 超越 | 留数法（复变）、积分变换、特殊函数 | 困难积分、反常积分、物理应用 |

本模块重点覆盖 L4 和 L5 层次的技巧。

### 1.3 特殊积分的意义

特殊积分是指那些不能用初等函数表示原函数、但在数学和物理中有重要应用的定积分（通常是反常积分）。这些积分的计算需要创造性的技巧，而不是机械的公式应用。

著名特殊积分包括：
- Dirichlet 积分：∫₀^∞ sin x/x dx = π/2
- 高斯积分（Euler-Poisson 积分）：∫₀^∞ e^{-x²}dx = √π/2
- Frullani 积分：∫₀^∞ [f(ax)-f(bx)]/x dx
- Euler 积分：Beta 函数 B(p,q)、Gamma 函数 Γ(s)
- Poisson 积分：∫₀^∞ e^{-ax²}cos(bx)dx
- Fresnel 积分：∫₀^∞ cos(x²)dx, ∫₀^∞ sin(x²)dx
- Laplace 积分：∫₀^∞ cos(ax)/(x²+b²)dx

这些积分不仅有重要的应用价值，其计算方法本身也体现了积分计算的艺术。

## 第二章 高级换元技巧

### 2.1 换元法的回顾

D4-1 中讨论了基本的换元法：
- 第一类换元（凑微分）：∫f(φ(x))φ'(x)dx=∫f(u)du
- 第二类换元：令 x=ψ(t)，∫f(x)dx=∫f(ψ(t))ψ'(t)dt

本章讨论更高级的换元技巧。

### 2.2 对称换元

**原理**：利用积分区间的对称性，通过换元 x→a+b-x（区间中点对称）简化积分。

**公式**：∫ₐᵇ f(x)dx = ∫ₐᵇ f(a+b-x)dx

**应用**：
1. 如果 f(x)+f(a+b-x) 是简单函数，则
   ∫ₐᵇ f(x)dx = (1/2)∫ₐᵇ [f(x)+f(a+b-x)]dx

2. 特别地，在 [0,π/2] 上：
   ∫₀^{π/2} f(sin x)dx = ∫₀^{π/2} f(cos x)dx
   （因为 sin(π/2-x)=cos x）

**例**：I=∫₀^{π/2} sin x/(sin x+cos x)dx

解：由对称换元 x→π/2-x，
I=∫₀^{π/2} cos x/(sin x+cos x)dx
两式相加：2I=∫₀^{π/2} 1 dx=π/2，所以 I=π/4。

### 2.3 倒数换元

**原理**：令 x=1/t，把无穷远处的行为转化为原点附近的行为。

**应用场景**：
1. 被积函数中 x 的幂次有特定关系（如 x²+1, x⁴+1）
2. 无穷区间上的积分
3. 被积函数满足 f(1/x) 与 f(x) 有简单关系

**例**：I=∫₀^∞ 1/[(1+x²)(1+x^α)]dx（α 为任意实数）

解：令 x=1/t，
I=∫∞⁰ 1/[(1+1/t²)(1+t^{-α})]·(-1/t²)dt=∫₀^∞ t^α/[(1+t²)(1+t^α)]dt
两式相加：2I=∫₀^∞ (1+x^α)/[(1+x²)(1+x^α)]dx=∫₀^∞ 1/(1+x²)dx=π/2
所以 I=π/4（与 α 无关！）

### 2.4 平移换元

**原理**：令 x=t+c，把积分区间平移到对称区间或更方便的位置。

**应用**：
1. 把不对称区间平移为对称区间，利用奇偶性
2. 把被积函数中的线性项消去
3. 处理含 (x-a) 的积分

**例**：I=∫₀^π x sin x/(1+cos²x)dx

解：令 x=π-t，
I=∫π⁰ (π-t) sin(π-t)/(1+cos²(π-t))·(-dt)=∫₀^π (π-t) sin t/(1+cos²t)dt
=π∫₀^π sin t/(1+cos²t)dt - I
所以 2I=π∫₀^π sin t/(1+cos²t)dt
令 u=cos t, du=-sin t dt：
∫₀^π sin t/(1+cos²t)dt=∫₁^{-1} -1/(1+u²)du=∫_{-1}^1 1/(1+u²)du=[arctan u]_{-1}^1=π/2
所以 I=π²/4。

### 2.5 Euler 代换

D4-1 中简要提到了 Euler 代换，这里深入讨论。

对于含 √(ax²+bx+c) 的积分，Euler 代换有三种：

1. **第一类 Euler 代换**（a>0）：令 √(ax²+bx+c)=t±√a·x
   两边平方：ax²+bx+c=t²±2√a·tx+ax² ⇒ bx+c=t²±2√a·tx
   解出 x=(t²-c)/(b∓2√a·t)，是 t 的有理函数。

2. **第二类 Euler 代换**（c>0）：令 √(ax²+bx+c)=xt±√c
   类似地，解出 x 是 t 的有理函数。

3. **第三类 Euler 代换**（ax²+bx+c 有两个不同实根 α,β）：令 √(ax²+bx+c)=t(x-α)
   两边平方：a(x-α)(x-β)=t²(x-α)² ⇒ a(x-β)=t²(x-α)
   解出 x=(aβ+t²α)/(t²+a)，是 t 的有理函数。

Euler 代换的优势：可以把任何含二次根式的积分转化为有理函数积分，从而用部分分式分解求解。

### 2.6 万能代换的高级应用

D4-1 中讨论了万能代换 t=tan(x/2)。这里讨论一些高级应用：

1. **Weierstrass 代换的推广**：对于含 sin x 和 cos x 的积分，除了 t=tan(x/2)，还可以根据被积函数的特点选择 t=tan x, t=sin x, t=cos x 等。

2. **双曲函数的万能代换**：对于含 sinh x 和 cosh x 的积分，令 t=tanh(x/2)，则
   sinh x=2t/(1-t²), cosh x=(1+t²)/(1-t²), dx=2/(1-t²)dt

### 2.7 几何理解

**📐 几何图像**：高级换元技巧的几何意义是"通过巧妙的坐标变换简化积分区域和被积函数"。

- 对称换元 x→a+b-x 的几何意义：把积分区间关于中点翻转——如果被积函数在翻转后有简单的形式（如 f(x)+f(a+b-x) 是常数），就可以利用对称性简化计算。
- 倒数换元 x=1/t 的几何意义：把 x 轴上的无穷远点映射为 t 轴上的原点——把"无穷远处的行为"转化为"原点附近的行为"，这在处理无穷区间积分时特别有用。
- 平移换元 x=t+c 的几何意义：把积分区间平移到更对称的位置——利用奇偶性或其他对称性。
- Euler 代换的几何意义：把二次曲线（椭圆、双曲线、抛物线）参数化——二次根式 √(ax²+bx+c) 对应二次曲线，Euler 代换给出了二次曲线的有理参数化，把含根式的积分转化为有理函数积分。

高级换元技巧的几何本质是"通过创造性的坐标变换，利用积分区域和被积函数的对称性、特殊结构，把复杂积分转化为简单积分"。

## 第三章 高级分部积分技巧

### 3.1 分部积分法的回顾

D4-1 中讨论了基本的分部积分法：
∫u dv = uv - ∫v du

本章讨论更高级的分部积分技巧。

### 3.2 循环积分

**原理**：某些积分经过两次（或多次）分部积分后，会出现原来的积分，形成循环，通过解方程求出积分。

**典型类型**：
1. ∫e^{ax} sin(bx)dx, ∫e^{ax} cos(bx)dx
2. ∫sec³x dx 等
3. 某些含 √(a²±x²) 的积分

**例**：I=∫sec³x dx

解：令 u=sec x, dv=sec²x dx, du=sec x tan x dx, v=tan x
I=sec x tan x - ∫sec x tan²x dx=sec x tan x - ∫sec x(sec²x-1)dx
=sec x tan x - ∫sec³x dx + ∫sec x dx=sec x tan x - I + ln|sec x+tan x|
所以 2I=sec x tan x+ln|sec x+tan x|，I=(1/2)(sec x tan x+ln|sec x+tan x|)+C

### 3.3 递推公式

**原理**：对于含参数 n 的积分 Iₙ，通过分部积分建立 Iₙ 和 Iₙ₋₁（或 Iₙ₋₂）的递推关系，然后利用初始值求出 Iₙ。

**典型例子**：
1. Iₙ=∫₀^{π/2} sinⁿx dx（Wallis 公式）
2. Iₙ=∫₀^∞ xⁿ e^{-x}dx（Gamma 函数递推）
3. Iₙ=∫₀^1 x^α (ln x)^n dx
4. Iₙ=∫secⁿx dx

**例（Wallis 递推）**：Iₙ=∫₀^{π/2} sinⁿx dx

解：Iₙ=∫₀^{π/2} sin^{n-1}x·sin x dx
令 u=sin^{n-1}x, dv=sin x dx, du=(n-1)sin^{n-2}x cos x dx, v=-cos x
Iₙ=[-sin^{n-1}x cos x]₀^{π/2}+(n-1)∫₀^{π/2} sin^{n-2}x cos²x dx
=0+(n-1)∫₀^{π/2} sin^{n-2}x(1-sin²x)dx=(n-1)(Iₙ₋₂-Iₙ)
所以 nIₙ=(n-1)Iₙ₋₂，即 Iₙ=(n-1)/n·Iₙ₋₂。

初始值：I₀=π/2, I₁=1。
由此得到 Wallis 公式：
- n 为偶数：Iₙ=(n-1)!!/n!!·π/2
- n 为奇数：Iₙ=(n-1)!!/n!!

### 3.4 表格法（快速分部积分）

**原理**：对于 ∫u v^(n+1)dx 类型的积分，可以用表格法快速计算多次分部积分。

**方法**：
- 第一列：u 逐行求导（u, u', u'', ..., u^(n)）
- 第二列：v^(n+1) 逐行积分（v^(n), v^(n-1), ..., v）
- 交叉相乘，符号交替（+,-,+,-,...）

**适用场景**：u 是多项式（求导有限次后为零），v^(n+1) 是指数函数或三角函数（积分后仍是同类函数）。

**例**：∫x³ eˣ dx

| u 的导数 | v 的积分 | 符号 |
|---|---|---|
| x³ | eˣ | + |
| 3x² | eˣ | - |
| 6x | eˣ | + |
| 6 | eˣ | - |
| 0 | eˣ | + |

结果：x³eˣ-3x²eˣ+6xeˣ-6eˣ+C=(x³-3x²+6x-6)eˣ+C

### 3.5 Abel 变换（分部求和）

**原理**：Abel 变换是离散版本的分部积分，用于处理级数求和。在积分计算中，Abel 变换可以用于处理含级数的积分或建立积分不等式。

**公式**：∑ᵢ₌₁ⁿ aᵢ bᵢ = Aₙ bₙ + ∑ᵢ₌₁^{n-1} Aᵢ(bᵢ-bᵢ₊₁)，其中 Aᵢ=∑ⱼ₌₁ⁱ aⱼ。

这对应于积分的分部积分：∫u dv=uv-∫v du。

### 3.6 分部积分在定积分中的高级应用

1. **边界项为零的情形**：如果 u 在端点处为零（或 v 在端点处为零），分部积分的边界项消失，简化计算。

2. **多次分部积分**：某些积分需要多次分部积分，每次选择合适的 u 和 dv。

3. **分部积分与换元结合**：复杂积分往往需要换元和分部积分的组合使用。

4. **分部积分证明积分不等式**：如 Wirtinger 不等式的证明就使用了分部积分。

### 3.7 几何理解

**📐 几何图像**：高级分部积分技巧的几何意义是"通过面积的互补转化，建立递推关系或循环方程"。

- 循环积分的几何意义：某些面积经过两次互补转化后回到自身——形成一个方程，解这个方程就得到面积。
- 递推公式的几何意义：高次幂的面积可以用低次幂的面积表示——通过分部积分把 ∫sinⁿx 转化为 ∫sin^{n-2}x，建立递推链，最终归结为初始值（∫1 或 ∫sin x）。
- 表格法的几何意义：多项式×指数函数的面积可以快速计算——多项式求导有限次后为零，指数函数积分后仍是指数函数，所以表格法可以在有限步内完成。

高级分部积分技巧的几何本质是"通过面积的互补转化（分部积分），建立递推关系或循环方程，把复杂面积的计算归结为简单面积的计算"。

## 第四章 参数积分法

### 4.1 参数积分法的原理

参数积分法是积分计算中最强大的技巧之一——通过引入一个参数，把原来的积分转化为含参变量积分，然后利用积分号下求导或积分号下积分来求解。

**基本思想**：
1. 引入参数 a（或多个参数），定义含参变量积分 I(a)=∫f(x,a)dx
2. 对 a 求导（积分号下求导）：I'(a)=∫∂f/∂a dx，希望导数后的积分更容易计算
3. 求出 I'(a) 后，积分得到 I(a)
4. 代入特殊的 a 值（如 a=0 或 a→∞），利用已知的 I(a₀) 确定积分常数

或者：
1. 把被积函数表示为积分：f(x)=∫g(x,t)dt
2. 交换积分顺序（Fubini 定理）：∫f(x)dx=∫∫g(x,t)dxdt=∫[∫g(x,t)dx]dt
3. 希望内层积分更容易计算

### 4.2 积分号下求导（Leibniz 法则）

**定理**：如果 f(x,a) 和 ∂f/∂a 在矩形 [α,β]×[a,b] 上连续，则
d/da ∫ₐᵇ f(x,a)dx = ∫ₐᵇ ∂f/∂a (x,a)dx

对于反常积分，需要一致收敛的条件（D4-4 详细讨论）。

### 4.3 积分号下积分

**定理**：如果 f(x,a) 在矩形 [α,β]×[a,b] 上连续，则
∫_α^β [∫ₐᵇ f(x,a)dx]da = ∫ₐᵇ [∫_α^β f(x,a)da]dx

这是 Fubini 定理的特殊情形（D4-5 详细讨论）。

### 4.4 参数积分法的典型模式

**模式一：引入指数参数**
对于含 1/x 或类似因子的积分，引入 e^{-ax}：
I(a)=∫₀^∞ e^{-ax} f(x)/x dx
则 I'(a)=-∫₀^∞ e^{-ax} f(x)dx（消去了 1/x 因子）

**模式二：引入幂次参数**
对于含 x^α 的积分，把 α 视为参数：
I(α)=∫₀^1 x^α f(x)dx
则 I'(α)=∫₀^1 x^α ln x f(x)dx（引入了 ln x 因子）

**模式三：把常数表示为积分**
利用 1/x=∫₀^∞ e^{-xt}dt, 1/(x²+a²)=∫₀^∞ e^{-at}sin(xt)/a dt 等恒等式，把被积函数中的常数表示为积分，然后交换顺序。

**模式四：引入三角函数参数**
对于含 cos(ax) 或 sin(ax) 的积分，对 a 求导可以在 sin 和 cos 之间转换。

### 4.5 例子：Dirichlet 积分的参数积分法

I=∫₀^∞ sin x/x dx

引入参数 a：I(a)=∫₀^∞ e^{-ax} sin x/x dx（a>0）
则 I'(a)=∫₀^∞ -e^{-ax} sin x dx = -1/(1+a²)
（这个积分可以用两次分部积分求出）
积分：I(a)=-arctan a+C
由 I(+∞)=0（e^{-ax}→0），得 C=π/2
所以 I(a)=π/2-arctan a
令 a→0+，得 I=π/2。

### 4.6 例子：高斯积分的参数积分法

I=∫₀^∞ e^{-x²}dx

引入参数 a：I(a)=∫₀^∞ e^{-ax²}dx
已知 I(1)=I, I(+∞)=0。
对 a 求导：I'(a)=-∫₀^∞ x² e^{-ax²}dx
这个方法不直接——高斯积分通常用二重积分极坐标的方法（见第六章）。

但可以用参数积分法计算推广形式：
J(a,b)=∫₀^∞ e^{-ax²}cos(bx)dx（Poisson 积分）
对 b 求导：∂J/∂b=-∫₀^∞ x e^{-ax²}sin(bx)dx
分部积分后可以建立微分方程，解出 J(a,b)。

### 4.7 几何理解

**📐 几何图像**：参数积分法的几何意义是"把一个积分看作一族积分（参数化的积分族），通过研究这族积分随参数的变化来求出特定参数值的积分"。

- 积分号下求导的几何意义：参数 a 微小变化时，被积函数 f(x,a) 的高度变化了 ∂f/∂a·Δa，面积的变化就是高度变化在整个区间上的积分——即 I'(a)=∫∂f/∂a dx。
- 积分号下积分的几何意义：在参数-变量平面上的二重积分，可以按两种顺序积分——先对 x 积分再对 a 积分，或者先对 a 积分再对 x 积分。Fubini 定理保证了两种顺序的结果相同（在适当条件下）。
- 参数积分法的本质是"升维"——把一维积分问题提升为二维（含参变量）问题，利用二维空间中的灵活性（求导、交换积分顺序）来解决一维问题，然后再"降维"回到一维。

参数积分法的几何本质是"通过参数化把一维积分提升为二维问题，利用积分号下求导和交换积分顺序的灵活性，把困难的积分转化为容易的积分"。

## 第五章 Dirichlet 积分与相关积分

### 5.1 Dirichlet 积分

**定义**：I=∫₀^∞ sin x/x dx

**结果**：I=π/2

这是最著名的特殊积分之一，在 Fourier 分析、信号处理、数论中有重要应用。

### 5.2 Dirichlet 积分的多种计算方法

**方法一：参数积分法（第四章已讨论）**
引入 I(a)=∫₀^∞ e^{-ax} sin x/x dx，求导得 I'(a)=-1/(1+a²)，积分得 I(a)=π/2-arctan a，令 a→0+ 得 I=π/2。

**方法二：二重积分法**
利用 1/x=∫₀^∞ e^{-xt}dt：
I=∫₀^∞ sin x·(∫₀^∞ e^{-xt}dt)dx=∫₀^∞ [∫₀^∞ e^{-xt} sin x dx]dt=∫₀^∞ 1/(1+t²)dt=π/2

**方法三：级数展开法**
利用 1/x 的级数展开或 sin x 的积分表示（见第十章）。

**方法四：留数法**
考虑复积分 ∫e^{iz}/z dz 沿特定围道（见第十一章）。

**方法五：Fourier 积分公式**
利用 Fourier 逆变换公式，取 f(x)=1（|x|&lt;1）, 0（其他），其 Fourier 变换为 2 sin ω/ω，逆变换在 x=0 处给出 ∫₀^∞ sin ω/ω dω=π/2。

### 5.3 Dirichlet 积分的推广

**推广一：含参数的 Dirichlet 积分**
∫₀^∞ sin(ax)/x dx = π/2·sgn(a)（a≠0）
其中 sgn(a) 是符号函数（a>0 时为 1，a&lt;0 时为 -1）。

**推广二：Laplace 积分**
∫₀^∞ sin(ax)/(x²+b²)dx 和 ∫₀^∞ x cos(ax)/(x²+b²)dx
这些积分可以用留数法或参数积分法计算。

**推广三：Dirichlet 多重积分**
∫₀^∞ ∫₀^∞ sin x sin y/(xy) dxdy = (π/2)²

### 5.4 Dirichlet 积分的应用

1. **Fourier 分析**：Dirichlet 积分是 Fourier 级数收敛性证明的基础（Dirichlet 核的积分）
2. **信号处理**：理想低通滤波器的冲激响应是 sinc 函数，其积分就是 Dirichlet 积分
3. **数论**：Dirichlet 级数和素数定理的证明中用到类似积分
4. **概率论**：特征函数的计算
5. **物理**：衍射理论、波的传播

### 5.5 相关积分

**积分一**：∫₀^∞ (1-cos x)/x² dx = π/2

证明：分部积分，令 u=1-cos x, dv=1/x² dx：
∫₀^∞ (1-cos x)/x² dx = [-(1-cos x)/x]₀^∞ + ∫₀^∞ sin x/x dx = 0+π/2=π/2

**积分二**：∫₀^∞ sin²x/x² dx = π/2

证明：sin²x=(1-cos 2x)/2，所以
∫₀^∞ sin²x/x² dx=(1/2)∫₀^∞ (1-cos 2x)/x² dx
令 t=2x：=(1/2)·2·∫₀^∞ (1-cos t)/t² dt=∫₀^∞ (1-cos t)/t² dt=π/2

**积分三**：∫₀^∞ sin³x/x dx = π/4

证明：sin³x=(3 sin x-sin 3x)/4，所以
∫₀^∞ sin³x/x dx=(3/4)∫₀^∞ sin x/x dx-(1/4)∫₀^∞ sin 3x/x dx
=(3/4)(π/2)-(1/4)(π/2)=π/4

### 5.6 几何理解

**📐 几何图像**：Dirichlet 积分的几何意义是"sinc 函数 sin x/x 下的面积"。sinc 函数是一个衰减振荡函数——在 x=0 处取值 1，然后围绕 x 轴振荡，振幅逐渐衰减。Dirichlet 积分说的是这个衰减振荡曲线下的总面积（正负面积的代数和）等于 π/2。

参数积分法的几何图像：引入 e^{-ax} 相当于给 sinc 函数加上一个指数衰减的"权重"——a 越大，衰减越快，积分越小。当 a→∞ 时，积分趋于 0；当 a→0 时，衰减消失，得到原始积分。通过研究积分随 a 的变化（导数），可以求出积分值。

Dirichlet 积分的几何本质是"衰减振荡函数下的面积——通过指数衰减参数化，利用积分号下求导把困难的积分转化为简单的有理函数积分"。

## 第六章 高斯积分与相关积分

### 6.1 高斯积分

**定义**：I=∫₀^∞ e^{-x²}dx

**结果**：I=√π/2

全空间的高斯积分：∫_{-∞}^∞ e^{-x²}dx=√π

高斯积分是概率论中正态分布的归一化常数，在统计学、物理学、量子力学中有极其重要的应用。

### 6.2 高斯积分的计算方法

**方法一：二重积分极坐标法（最经典）**

考虑 I²=∫₀^∞ e^{-x²}dx·∫₀^∞ e^{-y²}dy=∫₀^∞∫₀^∞ e^{-(x²+y²)}dxdy

转换为极坐标：x=r cos θ, y=r sin θ, dxdy=r drdθ，第一象限对应 r∈[0,∞), θ∈[0,π/2]
I²=∫₀^{π/2}∫₀^∞ e^{-r²} r drdθ=∫₀^{π/2} [(-1/2)e^{-r²}]₀^∞ dθ=∫₀^{π/2} 1/2 dθ=π/4
所以 I=√π/2。

这个方法的巧妙之处：把一维积分的平方看作二维积分，利用极坐标把 e^{-(x²+y²)}=e^{-r²} 转化为只含 r 的函数，而 r dr 恰好可以凑微分（d(r²)=2r dr）。

**方法二：参数积分法**
引入 I(a)=∫₀^∞ e^{-ax²}dx，利用 I(a)=1/√a·I(1)（换元 x=√(t/a)），然后通过其他方法确定 I(1)。

**方法三：Wallis 公式法**
利用不等式 e^{-x²}≤1/(1+x²) 和极限，结合 Wallis 公式证明。

**方法四：Gamma 函数法**
∫₀^∞ e^{-x²}dx=(1/2)Γ(1/2)=(1/2)√π（利用 Γ(1/2)=√π，见第八章）。

### 6.3 高斯积分的推广

**推广一：含参数的高斯积分**
∫₀^∞ e^{-ax²}dx=√π/(2√a)（a>0）
∫_{-∞}^∞ e^{-ax²}dx=√(π/a)（a>0）

**推广二：Poisson 积分（含余弦的高斯积分）**
∫₀^∞ e^{-ax²}cos(bx)dx=(1/2)√(π/a)·e^{-b²/(4a)}（a>0）

这个结果可以通过参数积分法证明：令 J(b)=∫₀^∞ e^{-ax²}cos(bx)dx，对 b 求导，分部积分后得到微分方程 J'(b)=-b/(2a)J(b)，解出 J(b)=J(0)e^{-b²/(4a)}=(1/2)√(π/a)e^{-b²/(4a)}。

**推广三：含多项式的高斯积分**
∫_{-∞}^∞ x^{2n} e^{-ax²}dx=(2n-1)!!/(2a)^n·√(π/a)
∫_{-∞}^∞ x^{2n+1} e^{-ax²}dx=0（奇函数）

这些可以通过对 Poisson 积分求导得到，或者用递推公式。

**推广四：高维高斯积分**
∫_{ℝⁿ} e^{-xᵀAx}dx=π^{n/2}/√det(A)（A 正定对称）

### 6.4 高斯积分的应用

1. **概率论与统计学**：正态分布的归一化常数、矩的计算、特征函数
2. **量子力学**：谐振子波函数的归一化、矩阵元的计算
3. **统计力学**：配分函数的计算、Maxwell-Boltzmann 分布
4. **信号处理**：高斯滤波器、时频分析
5. **热传导方程**：基本解（热核）是高斯函数
6. **数论**：Theta 函数、模形式

### 6.5 相关积分

**积分一**：∫₀^∞ x² e^{-x²}dx=√π/4

证明：分部积分或对 Poisson 积分求导。

**积分二**：∫₀^∞ e^{-x⁴}dx（不是初等函数，用 Gamma 函数表示）
= (1/4)Γ(1/4)

**积分三**：Fresnel 积分
∫₀^∞ cos(x²)dx=∫₀^∞ sin(x²)dx=√(π/8)

Fresnel 积分在光学衍射理论中有重要应用，可以用留数法或 Gamma 函数（Γ(1/2) 的辐角）计算。

### 6.6 几何理解

**📐 几何图像**：高斯积分的几何意义是"钟形曲线 e^{-x²} 下的面积"。e^{-x²} 是一个钟形曲线——在 x=0 处取最大值 1，向两侧对称衰减，在 x→±∞ 时趋于 0。高斯积分说的是这个钟形曲线下的总面积等于 √π。

二重积分极坐标法的几何图像最精彩：把一维钟形曲线的面积平方，看作二维钟形曲面 e^{-(x²+y²)} 下的体积。这个二维钟形曲面是旋转对称的——在极坐标下只依赖于 r（到原点的距离）。旋转对称的体积可以用"圆柱壳"方法计算——半径 r 处的圆柱壳面积为 2πr dr，高度为 e^{-r²}，体积元素为 2πr e^{-r²}dr，而 r dr 恰好可以凑微分。这就是极坐标法的几何本质——利用旋转对称性把二维积分转化为一维积分。

Poisson 积分的几何意义：带余弦调制的高斯函数下的面积——cos(bx) 给高斯函数加上了振荡，结果是高斯函数的"宽度"不变但"高度"乘以 e^{-b²/(4a)}（仍然是高斯形式）。

高斯积分的几何本质是"钟形曲线下的面积——通过平方升维为二维旋转对称体积，利用极坐标和凑微分巧妙求解"。

## 第七章 Frullani 积分

### 7.1 Frullani 积分的定义

**定理（Frullani 积分）**：如果 f(x) 在 [0,∞) 上连续，且 f(∞)=lim_{x→∞}f(x) 存在有限，则
∫₀^∞ [f(ax)-f(bx)]/x dx = [f(0)-f(∞)]·ln(b/a)
其中 a,b>0。

**特殊情形**：如果 f(∞)=0，则
∫₀^∞ [f(ax)-f(bx)]/x dx = f(0)·ln(b/a)

### 7.2 Frullani 积分的证明

**证明方法一：二重积分法**
利用 1/x=∫₀^∞ e^{-xt}dt：
∫₀^∞ [f(ax)-f(bx)]/x dx=∫₀^∞ [f(ax)-f(bx)]∫₀^∞ e^{-xt}dt dx
=∫₀^∞ [∫₀^∞ f(ax)e^{-xt}dx - ∫₀^∞ f(bx)e^{-xt}dx]dt
对第一个积分令 u=ax，第二个令 u=bx：
=∫₀^∞ [1/a∫₀^∞ f(u)e^{-ut/a}du - 1/b∫₀^∞ f(u)e^{-ut/b}du]dt
交换积分顺序：
=∫₀^∞ f(u)[∫₀^∞ (1/a e^{-ut/a}-1/b e^{-ut/b})dt]du
=∫₀^∞ f(u)[1/u-1/u]du？这个方法需要更仔细的处理。

更简洁的证明：

**证明方法二：参数积分法**
令 I(a)=∫₀^∞ [f(ax)-f(bx)]/x dx
对 a 求导：I'(a)=∫₀^∞ f'(ax)dx=(1/a)[f(∞)-f(0)]
积分：I(a)=[f(∞)-f(0)]ln a+C
由 I(b)=0（a=b 时被积函数为零），得 C=-[f(∞)-f(0)]ln b
所以 I(a)=[f(∞)-f(0)]ln(a/b)=[f(0)-f(∞)]ln(b/a)

### 7.3 Frullani 积分的典型应用

**例 1**：f(x)=e^{-x}, f(0)=1, f(∞)=0
∫₀^∞ (e^{-ax}-e^{-bx})/x dx=ln(b/a)

**例 2**：f(x)=arctan x, f(0)=0, f(∞)=π/2
∫₀^∞ [arctan(ax)-arctan(bx)]/x dx=(π/2)ln(a/b)

**例 3**：f(x)=1/(1+x), f(0)=1, f(∞)=0
∫₀^∞ [1/(1+ax)-1/(1+bx)]/x dx=ln(b/a)

**例 4**：f(x)=ln(1+e^{-x}), f(0)=ln 2, f(∞)=0
∫₀^∞ [ln(1+e^{-ax})-ln(1+e^{-bx})]/x dx=ln 2·ln(b/a)

### 7.4 Frullani 积分的推广

**推广一：f(∞) 不存在的情形**
如果 f(∞) 不存在但 f(x)/x 可积，可以有更一般的公式。

**推广二：多个函数的差**
∫₀^∞ [∑ᵢ cᵢ f(aᵢx)]/x dx，其中 ∑ᵢ cᵢ=0（保证 x=0 处收敛）。

**推广三：Ramanujan 主定理**
Frullani 积分是 Ramanujan 主定理的特殊情形——Ramanujan 主定理给出了更一般的积分公式。

### 7.5 几何理解

**📐 几何图像**：Frullani 积分的几何意义是"两个尺度缩放后的函数之差除以 x 的积分"。f(ax) 和 f(bx) 是 f 在 x 轴上以不同尺度缩放后的版本——a 越大，函数在 x 轴上越"紧凑"（压缩）。[f(ax)-f(bx)]/x 是这两个缩放版本之差除以 x。

Frullani 公式说的是：这个积分只依赖于 f 在端点的值 f(0) 和 f(∞)，以及尺度比 b/a——中间的具体形状不影响积分值！这是一个非常深刻的结果——积分"抵消"了中间的所有细节，只保留了端点的信息。

参数积分法的几何图像：对 a 求导后，积分变成了 ∫f'(ax)dx——这是 f 的导数在缩放后的积分，结果只依赖于 f 的端点值（f(∞)-f(0)）/a。这说明 Frullani 积分对 a 的依赖是对数型的（因为导数是 1/a 型的）。

Frullani 积分的几何本质是"尺度缩放差的积分——中间细节被抵消，只保留端点信息，结果是端点差乘以尺度比的对数"。

## 第八章 Euler 积分——Beta 函数与 Gamma 函数

### 8.1 Gamma 函数

**定义**：Γ(s)=∫₀^∞ t^{s-1} e^{-t}dt（s>0）

Gamma 函数是阶乘的推广：Γ(n+1)=n!（n 为非负整数）。

**基本性质**：
1. **递推公式**：Γ(s+1)=sΓ(s)（分部积分证明）
2. **特殊值**：Γ(1)=1, Γ(1/2)=√π（高斯积分）, Γ(n+1)=n!
3. **解析延拓**：Gamma 函数可以解析延拓到除 s=0,-1,-2,... 外的整个复平面
4. **Euler 反射公式**：Γ(s)Γ(1-s)=π/sin(πs)
5. **加倍公式**：Γ(s)Γ(s+1/2)=2^{1-2s}√π Γ(2s)
6. **对数凸性**：ln Γ(s) 是凸函数（Bohr-Mollerup 定理：Gamma 函数是唯一满足 Γ(1)=1, Γ(s+1)=sΓ(s), 对数凸的函数）

### 8.2 Beta 函数

**定义**：B(p,q)=∫₀¹ t^{p-1}(1-t)^{q-1}dt（p>0, q>0）

**与 Gamma 函数的关系**：B(p,q)=Γ(p)Γ(q)/Γ(p+q)

**证明思路**：利用 Γ(p)Γ(q)=∫₀^∞∫₀^∞ x^{p-1}y^{q-1}e^{-(x+y)}dxdy，转换为 u=x+y, v=x/(x+y)，计算 Jacobian 后得到 Γ(p+q)B(p,q)。

**基本性质**：
1. **对称性**：B(p,q)=B(q,p)
2. **递推公式**：B(p+1,q)=p/(p+q)B(p,q)
3. **特殊值**：B(1,1)=1, B(1/2,1/2)=π
4. **三角函数形式**：令 t=sin²θ，B(p,q)=2∫₀^{π/2} sin^{2p-1}θ cos^{2q-1}θ dθ

### 8.3 Euler 积分的应用

**应用一：计算三角函数积分**
∫₀^{π/2} sin^m x cos^n x dx=(1/2)B((m+1)/2,(n+1)/2)
=(1/2)Γ((m+1)/2)Γ((n+1)/2)/Γ((m+n+2)/2)

当 m,n 为整数时，这给出了 Wallis 公式的推广。

**应用二：计算多项式积分**
∫₀¹ x^{p-1}(1-x)^{q-1}dx=B(p,q)

**应用三：概率论**
- Beta 分布：概率密度函数为 x^{p-1}(1-x)^{q-1}/B(p,q)
- Gamma 分布：概率密度函数为 x^{s-1}e^{-x/θ}/(θ^s Γ(s))
- t 分布、F 分布、卡方分布都与 Gamma/Beta 函数有关

**应用四：统计学**
- 方差分析、回归分析中的分布计算
- Bayesian 统计中的共轭先验

**应用五：物理**
- 量子场论中的圈图计算
- 统计力学中的配分函数
- 弦理论中的 Veneziano 振幅（就是 Beta 函数）

### 8.4 Gamma 函数的其他表示

1. **Euler 无穷乘积**：Γ(s)=lim_{n→∞} n^s n!/[s(s+1)...(s+n)]
2. **Weierstrass 乘积**：1/Γ(s)=s e^{γs}∏_{n=1}^∞ (1+s/n)e^{-s/n}，其中 γ 是 Euler-Mascheroni 常数
3. **Hankel 围道积分**：复平面上的围道积分表示

### 8.5 特殊值与常数

1. Γ(1)=1
2. Γ(1/2)=√π
3. Γ(1/4)≈3.6256（无初等表达式，与椭圆积分有关）
4. Γ(3/4)≈1.2254
5. Γ(1/3)≈2.6789
6. Euler-Mascheroni 常数 γ=lim_{n→∞}(∑_{k=1}^n 1/k-ln n)≈0.5772

### 8.6 几何理解

**📐 几何图像**：Gamma 函数的几何意义是"阶乘的连续推广"——阶乘 n! 只定义在非负整数上，Gamma 函数把它推广到所有正实数（甚至复数）。Γ(s) 可以看作"广义阶乘"——Γ(s+1)=sΓ(s) 是阶乘递推 (n+1)!=(n+1)n! 的连续版本。

积分表示 Γ(s)=∫₀^∞ t^{s-1}e^{-t}dt 的几何意义：t^{s-1}e^{-t} 是一个"先增后减"的函数（当 s>1 时），在 t=s-1 处取最大值——这是一个"偏态钟形曲线"。Gamma 函数就是这个曲线下的面积。s 越大，曲线越宽，面积越大（增长速度约为 s^s e^{-s}，即 Stirling 公式）。

Beta 函数 B(p,q)=∫₀¹ t^{p-1}(1-t)^{q-1}dt 的几何意义：[0,1] 区间上的"单峰曲线"下的面积——t^{p-1}(1-t)^{q-1} 在 t=(p-1)/(p+q-2) 处取最大值（当 p,q>1 时），是一个定义在有限区间上的钟形曲线。Beta 函数就是这个曲线下的面积。

Beta-Gamma 关系 B(p,q)=Γ(p)Γ(q)/Γ(p+q) 的几何意义：两个独立 Gamma 分布变量的归一化和服从 Beta 分布——这是概率论中的一个基本事实。

Euler 积分的几何本质是"阶乘的连续推广（Gamma）和有限区间钟形面积（Beta）——两者通过概率分布的归一化关系联系起来"。

## 第九章 其他著名特殊积分

### 9.1 Poisson 积分

**定义**：∫₀^∞ e^{-ax²}cos(bx)dx=(1/2)√(π/a)e^{-b²/(4a)}（a>0）

已在第六章讨论。

**相关积分**：
∫₀^∞ e^{-ax²}cosh(bx)dx=(1/2)√(π/a)e^{b²/(4a)}
∫₀^∞ x e^{-ax²}sin(bx)dx=(b√π)/(4a^{3/2})e^{-b²/(4a)}

### 9.2 Laplace 积分

**定义**：
L₁=∫₀^∞ cos(ax)/(x²+b²)dx=π/(2b)e^{-ab}（a,b>0）
L₂=∫₀^∞ x sin(ax)/(x²+b²)dx=π/2·e^{-ab}（a,b>0）

这两个积分可以用留数法（第十一章）或参数积分法计算。

注意 L₂ 是 L₁ 对 a 的导数（差一个符号）：dL₁/da=-∫₀^∞ x sin(ax)/(x²+b²)dx=-L₂，而 d/da[π/(2b)e^{-ab}]=-π/2·e^{-ab}，所以 L₂=π/2·e^{-ab}。

### 9.3 Fresnel 积分

**定义**：
C=∫₀^∞ cos(x²)dx=√(π/8)
S=∫₀^∞ sin(x²)dx=√(π/8)

**计算方法**：
1. 留数法：考虑 ∫e^{iz²}dz 沿扇形围道（角度 π/4）
2. Gamma 函数法：∫₀^∞ e^{ix²}dx=e^{iπ/4}Γ(1/2)/2=e^{iπ/4}√π/2，取实部和虚部

**应用**：光学中的 Fresnel 衍射、Cornu 螺线、天线理论。

### 9.4 对数积分

**类型一**：∫₀¹ ln x/(1-x)dx=-π²/6

证明：利用 1/(1-x)=∑_{n=0}^∞ x^n，逐项积分：
∫₀¹ ln x/(1-x)dx=∑_{n=0}^∞ ∫₀¹ x^n ln x dx=∑_{n=0}^∞ (-1)/(n+1)²=-∑_{n=1}^∞ 1/n²=-π²/6
（利用 Basel 问题 ∑1/n²=π²/6）

**类型二**：∫₀¹ ln(1+x)/x dx=π²/12

证明：类似地，ln(1+x)=∑_{n=1}^∞ (-1)^{n+1}x^n/n，逐项积分。

**类型三**：∫₀^{π/2} ln(sin x)dx=∫₀^{π/2} ln(cos x)dx=-(π/2)ln 2

证明：令 I=∫₀^{π/2} ln(sin x)dx，由对称换元 I=∫₀^{π/2} ln(cos x)dx。
2I=∫₀^{π/2} ln(sin x cos x)dx=∫₀^{π/2} ln(sin 2x/2)dx
=∫₀^{π/2} ln(sin 2x)dx-(π/2)ln 2
令 u=2x：∫₀^{π/2} ln(sin 2x)dx=(1/2)∫₀^π ln(sin u)du=∫₀^{π/2} ln(sin u)du=I
（利用 sin(π-u)=sin u）
所以 2I=I-(π/2)ln 2，I=-(π/2)ln 2。

### 9.5 Catalan 常数相关积分

**Catalan 常数**：G=∑_{n=0}^∞ (-1)^n/(2n+1)²≈0.915965

**积分表示**：
G=∫₀¹ arctan x/x dx
G=∫₀^{π/4} ln(cot x)dx
G=-(1/2)∫₀^{π/2} ln(tan(x/2))dx

Catalan 常数在组合数学、数论、量子力学中有应用。

### 9.6 几何理解

**📐 几何图像**：这些著名特殊积分的几何意义各不相同，但都体现了"特殊函数/特殊常数与积分的深刻联系"。

- Laplace 积分的几何意义：衰减振荡函数 cos(ax)/(x²+b²) 下的面积——结果是指数衰减 e^{-ab}，这说明这个积分作为 a 的函数是指数衰减的。
- Fresnel 积分的几何意义：高频振荡函数 cos(x²) 和 sin(x²) 下的面积——x² 的导数是 2x，随 x 增大频率越来越高，振荡越来越快，正负面积抵消，积分收敛。结果 √(π/8) 与 Gaussian 积分有关（通过 Gamma 函数的辐角）。
- 对数积分的几何意义：含对数函数的积分——结果通常与 π² 或其他特殊常数有关，因为对数函数的积分与级数（特别是 ∑1/n²）有深刻联系。
- Catalan 常数的几何意义：交错级数 ∑(-1)^n/(2n+1)² 的和——与 arctan x 的积分有关，是一个"超越常数"（不知道是否是无理数，更不知道是否是超越数）。

这些特殊积分的共同几何本质是"积分作为特殊函数和特殊常数的定义方式——许多重要的数学常数（π, e, γ, G）和特殊函数（Gamma, Beta, 误差函数）都可以通过积分来定义和计算"。

## 第十章 级数展开法

### 10.1 级数展开法的原理

级数展开法是积分计算的重要技巧——把被积函数展开为幂级数或 Fourier 级数，然后逐项积分。

**基本思想**：
1. 把被积函数 f(x) 展开为级数 f(x)=∑aₙ(x)
2. 逐项积分：∫f(x)dx=∑∫aₙ(x)dx
3. 希望逐项积分后的级数容易求和

**合法性条件**：
- 对于有限区间上的幂级数：在收敛区间内可以逐项积分（一致收敛）
- 对于 Fourier 级数：在适当条件下可以逐项积分（甚至比逐项求导的条件更弱）
- 对于反常积分：需要一致收敛或控制收敛的条件

### 10.2 幂级数展开法

**典型被积函数**：
1. 1/(1±x^α)=∑(∓1)^n x^{αn}（|x|&lt;1）
2. e^x=∑x^n/n!
3. sin x=∑(-1)^n x^{2n+1}/(2n+1)!
4. cos x=∑(-1)^n x^{2n}/(2n)!
5. ln(1+x)=∑(-1)^{n+1}x^n/n（|x|&lt;1）
6. arctan x=∑(-1)^n x^{2n+1}/(2n+1)（|x|≤1）
7. (1+x)^α=∑C(α,n)x^n（二项式级数，|x|&lt;1）

**例 1**：∫₀¹ ln(1+x)/x dx

解：ln(1+x)=∑_{n=1}^∞ (-1)^{n+1}x^n/n
∫₀¹ ln(1+x)/x dx=∑_{n=1}^∞ (-1)^{n+1}/n·∫₀¹ x^{n-1}dx=∑_{n=1}^∞ (-1)^{n+1}/n²=π²/12

**例 2**：∫₀¹ arctan x/x dx

解：arctan x=∑_{n=0}^∞ (-1)^n x^{2n+1}/(2n+1)
∫₀¹ arctan x/x dx=∑_{n=0}^∞ (-1)^n/(2n+1)·∫₀¹ x^{2n}dx=∑_{n=0}^∞ (-1)^n/(2n+1)²=G（Catalan 常数）

### 10.3 Fourier 级数展开法

**典型应用**：
1. 把被积函数展开为 Fourier 级数，利用正交性逐项积分
2. 计算含三角函数的积分
3. 利用 Parseval 等式计算级数和

**例**：利用 Parseval 等式计算 ∑1/n²

f(x)=x 在 [-π,π] 上的 Fourier 级数为 x=2∑_{n=1}^∞ (-1)^{n+1}sin(nx)/n
Parseval 等式：(1/π)∫_{-π}^π x² dx=∑|aₙ|²+∑|bₙ|²/2
左边=(1/π)·2π³/3=2π²/3
右边=∑4/n²/2=2∑1/n²
所以 2π²/3=2∑1/n²，∑1/n²=π²/6（Basel 问题）。

### 10.4 级数展开法与参数积分法的结合

许多特殊积分可以通过级数展开和参数积分的结合来计算。

**例**：∫₀^∞ x/(e^x-1)dx=π²/6

解：1/(e^x-1)=e^{-x}/(1-e^{-x})=∑_{n=1}^∞ e^{-nx}
∫₀^∞ x/(e^x-1)dx=∑_{n=1}^∞ ∫₀^∞ x e^{-nx}dx=∑_{n=1}^∞ 1/n²=π²/6

这个积分在统计力学（Planck 定律、黑体辐射）中有重要应用。

### 10.5 几何理解

**📐 几何图像**：级数展开法的几何意义是"把复杂曲线分解为简单曲线（幂函数、三角函数）的叠加，分别计算面积后求和"。

- 幂级数展开的几何意义：把复杂函数 f(x) 在某点附近用多项式逼近——Taylor 级数是无穷阶多项式逼近。逐项积分就是把每个多项式项的面积加起来。
- Fourier 级数展开的几何意义：把复杂周期函数分解为不同频率的正弦/余弦波的叠加——每个波的面积容易计算（利用正交性），加起来就是总面积。Parseval 等式的几何意义是"函数的能量（平方积分）等于各频率分量的能量之和"——这是勾股定理在无穷维函数空间中的推广。
- 级数展开法的本质是"线性化"——把非线性的、复杂的函数分解为线性的、简单的基函数的叠加，利用积分的线性性分别计算。

级数展开法的几何本质是"函数的正交分解——把复杂曲线分解为简单基函数的叠加，分别计算面积后求和，体现了积分的线性性和函数空间的几何结构"。

## 第十一章 留数法初步

### 11.1 留数法的原理

留数法是用复变函数的留数定理计算实积分的方法——这是复分析在实积分计算中的强大应用。

**留数定理**：如果 f(z) 在简单闭曲线 C 所围区域内除有限个孤立奇点 z₁,...,zₙ 外解析，在闭区域上除这些点外连续，则
∮_C f(z)dz=2πi∑_{k=1}^n Res(f,z_k)

其中 Res(f,z_k) 是 f 在 z_k 处的留数。

**基本思想**：
1. 把实积分 ∫ₐᵇ f(x)dx 看作复平面上沿实轴的积分
2. 添加辅助曲线（通常是上半平面的大半圆），构成闭合围道
3. 利用留数定理计算闭合围道的积分
4. 证明辅助曲线上的积分趋于零（或可以计算）
5. 得到实积分的值

### 11.2 留数的计算

**可去奇点**：留数为 0。

**极点**：如果 z₀ 是 f 的 m 阶极点，则
Res(f,z₀)=1/(m-1)!·lim_{z→z₀} d^{m-1}/dz^{m-1}[(z-z₀)^m f(z)]

特别地，一阶极点：Res(f,z₀)=lim_{z→z₀}(z-z₀)f(z)
如果 f(z)=g(z)/h(z)，g(z₀)≠0, h(z₀)=0, h'(z₀)≠0，则 Res(f,z₀)=g(z₀)/h'(z₀)。

**本性奇点**：需要展开为 Laurent 级数，留数是 z^{-1} 项的系数。

### 11.3 类型一：∫_{-∞}^∞ f(x)dx（有理函数）

**条件**：f(z)=P(z)/Q(z) 是有理函数，Q(z) 在实轴上无零点，deg Q≥deg P+2。

**方法**：取上半平面大半圆围道，证明圆弧上积分趋于零（由 deg Q≥deg P+2 保证），则
∫_{-∞}^∞ f(x)dx=2πi∑_{上半平面} Res(f,z_k)

**例**：∫_{-∞}^∞ 1/(1+x²)dx

f(z)=1/(1+z²)=1/[(z+i)(z-i)]，上半平面极点 z=i（一阶），Res(f,i)=1/(2i)
∫_{-∞}^∞ 1/(1+x²)dx=2πi·1/(2i)=π

### 11.4 类型二：∫_{-∞}^∞ f(x)e^{iax}dx（含指数函数）

**条件**：a>0，f(z) 满足适当条件（如有理函数且 deg Q>deg P）。

**Jordan 引理**：如果 f(z) 在圆弧 C_R: z=Re^{iθ}(0≤θ≤π) 上一致趋于 0（当 R→∞），则
lim_{R→∞}∫_{C_R} f(z)e^{iaz}dz=0（a>0）

**方法**：取上半平面大半圆围道，由 Jordan 引理圆弧积分趋于零，则
∫_{-∞}^∞ f(x)e^{iax}dx=2πi∑_{上半平面} Res(f(z)e^{iaz},z_k)

取实部和虚部可以得到含 cos(ax) 和 sin(ax) 的积分。

**例（Laplace 积分）**：∫_{-∞}^∞ e^{iax}/(x²+b²)dx

f(z)e^{iaz}=e^{iaz}/(z²+b²)=e^{iaz}/[(z+ib)(z-ib)]，上半平面极点 z=ib
Res=e^{ia(ib)}/(2ib)=e^{-ab}/(2ib)
∫_{-∞}^∞ e^{iax}/(x²+b²)dx=2πi·e^{-ab}/(2ib)=π/b·e^{-ab}
取实部：∫_{-∞}^∞ cos(ax)/(x²+b²)dx=π/b·e^{-ab}
所以 ∫₀^∞ cos(ax)/(x²+b²)dx=π/(2b)e^{-ab}（与第九章结果一致）

### 11.5 类型三：∫₀^∞ f(x)dx（其他围道）

对于某些积分，需要使用更复杂的围道：
1. **钥匙孔围道**：用于含多值函数（如 z^α, ln z）的积分
2. **扇形围道**：用于 Fresnel 积分（角度 π/4）、含 e^{iz²} 的积分
3. **矩形围道**：用于含周期函数的积分

### 11.6 留数法的优势与局限

**优势**：
1. 可以计算许多用实方法难以计算的积分
2. 方法系统——选择围道、找极点、算留数、取极限
3. 可以统一处理一大类积分（有理函数、含三角函数、含指数函数）

**局限**：
1. 需要复变函数的知识（解析性、奇点、留数）
2. 围道的选择需要经验和技巧
3. 辅助曲线上的积分趋于零需要证明（Jordan 引理等）
4. 不是所有积分都能用留数法计算

### 11.7 几何理解

**📐 几何图像**：留数法的几何意义是"把实轴上的积分提升为复平面上的围道积分，利用复平面的拓扑结构（围道包围的区域）和解析函数的性质（留数定理）来计算"。

- 围道的几何意义：在复平面上画一条闭合曲线，把实轴上的线段和辅助曲线（大半圆）连接起来。围道内部的区域包含了被积函数的奇点——留数定理说围道积分只依赖于内部奇点的留数。
- 留数的几何意义：留数是 Laurent 展开中 z^{-1} 项的系数——它度量了函数在奇点附近"绕奇点一周的积分变化"。几何上，留数与奇点的"涡旋强度"有关。
- Jordan 引理的几何意义：在上半平面的大半圆上，e^{iaz}=e^{iaR(cosθ+i sinθ)}=e^{-aR sinθ}e^{iaR cosθ}——当 θ∈(0,π) 时，sinθ>0，所以 e^{-aR sinθ} 指数衰减，圆弧上的积分趋于零。这是复平面上半部分的"衰减性质"——上半平面是 e^{iaz} 的"衰减区域"。

留数法的几何本质是"复平面围道积分——利用解析函数的拓扑性质（留数定理）和复指数的衰减性质（Jordan 引理），把困难的实积分转化为简单的留数计算"。

## 第十二章 对称性与周期性技巧

### 12.1 对称性技巧

对称性是积分计算中最常用的技巧之一——利用被积函数和积分区间的对称性，可以大大简化计算。

**类型一：奇偶对称性**
- 奇函数在对称区间上的积分为零：∫_{-a}^a f(x)dx=0（f 奇）
- 偶函数在对称区间上的积分加倍：∫_{-a}^a f(x)dx=2∫₀^a f(x)dx（f 偶）

**类型二：区间中点对称**
- ∫ₐᵇ f(x)dx=∫ₐᵇ f(a+b-x)dx
- 如果 f(x)+f(a+b-x) 简单，则积分可简化（见第二章对称换元）

**类型三：三角函数的特殊对称**
- ∫₀^{π/2} f(sin x)dx=∫₀^{π/2} f(cos x)dx
- ∫₀^π x f(sin x)dx=(π/2)∫₀^π f(sin x)dx
- ∫₀^π f(sin x)dx=2∫₀^{π/2} f(sin x)dx

### 12.2 周期性技巧

如果 f 是周期为 T 的周期函数，则：
1. ∫ₐ^{a+T} f(x)dx=∫₀^T f(x)dx（与 a 无关）
2. ∫ₐ^{a+nT} f(x)dx=n∫₀^T f(x)dx
3. 如果 f 在一个周期上的积分为零，则 ∫ₐ^b f(x)dx 只依赖于 b-a 模 T

**应用**：
1. 计算长区间上的周期函数积分
2. 证明某些积分与参数无关
3. 与 Fourier 级数结合

### 12.3 轮换对称性

对于多重积分（D4-5 详细讨论），轮换对称性是重要技巧：
- 如果被积函数和积分区域在变量轮换下不变，则积分可以简化
- 例如 ∫∫_{x²+y²≤1} x² dxdy=∫∫ y² dxdy=(1/2)∫∫(x²+y²)dxdy

### 12.4 隐含对称性

有些积分的对称性不是显而易见的，需要通过换元或变形来发现。

**例**：I=∫₀^{π/2} 1/(1+tan^α x)dx（α 为任意实数）

解：1/(1+tan^α x)=cos^α x/(sin^α x+cos^α x)
由对称换元 x→π/2-x：
I=∫₀^{π/2} sin^α x/(sin^α x+cos^α x)dx
两式相加：2I=∫₀^{π/2} 1 dx=π/2，I=π/4（与 α 无关！）

### 12.5 几何理解

**📐 几何图像**：对称性技巧的几何意义是"利用图形的对称性，把难以计算的面积转化为容易计算的面积"。

- 奇偶对称性的几何意义：奇函数关于原点对称——正负面积抵消，总面积为零；偶函数关于 y 轴对称——左右面积相等，总面积是一半的两倍。
- 区间中点对称的几何意义：把积分区间关于中点翻转——如果被积函数在翻转后有简单的形式（如 f(x)+f(a+b-x) 是常数），就可以利用对称性。
- 周期性的几何意义：周期函数的图像在水平方向上重复——每个周期内的面积相同，所以长区间上的面积就是周期数乘以单周期面积。
- 轮换对称性的几何意义：多重积分中，变量的轮换对应几何图形的旋转/反射——如果图形和被积函数在变换下不变，积分就不变。

对称性技巧的几何本质是"图形对称性的利用——通过对称变换把复杂面积转化为简单面积，体现了几何对称性在积分计算中的强大力量"。

## 第十三章 积分计算方法论

### 13.1 积分计算的一般策略

面对一个积分，按以下策略逐步尝试：

**第一步：识别类型**
- 是不定积分还是定积分？
- 被积函数是什么类型？（有理函数、三角函数、无理函数、指数函数、混合类型）
- 积分区间是什么？（有限、无穷、含奇点）

**第二步：尝试基本技巧**
- 代数化简（展开、拆分、同乘、有理化）
- 基本积分公式
- 第一类换元（凑微分）
- 分部积分

**第三步：尝试系统技巧**
- 部分分式分解（有理函数）
- 万能代换（三角函数有理式）
- 三角代换（含二次根式）
- Euler 代换（含二次根式）
- 第二类换元（根式代换、倒代换）

**第四步：尝试高级技巧**
- 高级换元（对称换元、倒数换元、平移换元）
- 高级分部积分（循环积分、递推公式、表格法）
- 参数积分法（积分号下求导/积分）
- 级数展开法（幂级数、Fourier 级数）
- 对称性技巧（奇偶、中点对称、周期、轮换）

**第五步：尝试超越技巧**
- 留数法（复变方法）
- 积分变换（Fourier 变换、Laplace 变换）
- 特殊函数（Gamma、Beta、误差函数、椭圆积分）
- 数值积分（如果解析方法都失败）

**第六步：判断是否"积不出来"**
- 如果以上方法都失败，考虑原函数是否不是初等函数（Liouville 定理、切比雪夫定理）
- 对于定积分，考虑是否需要用特殊函数或数值方法

### 13.2 积分计算的思维框架

**框架一：转化思维**
所有积分技巧的本质都是"转化"——把未知的、复杂的积分转化为已知的、简单的积分。转化的方式包括：
- 变量替换（换元法）
- 代数变形（部分分式、恒等式）
- 运算转化（分部积分——微分的逆用）
- 维度转化（参数积分——升维降维）
- 域的转化（留数法——实轴到复平面）

**框架二：结构思维**
分析被积函数的结构，选择合适的技巧：
- 复合函数结构→换元法
- 乘积结构→分部积分法
- 有理结构→部分分式
- 三角结构→万能代换/特殊代换
- 根式结构→三角代换/Euler 代换
- 参数结构→参数积分法
- 级数结构→级数展开法
- 对称结构→对称性技巧

**框架三：联想思维**
积分计算需要丰富的联想——看到被积函数就能联想到相关的积分公式、技巧、特殊积分。
- 看到 sin x/x→Dirichlet 积分
- 看到 e^{-x²}→高斯积分
- 看到 [f(ax)-f(bx)]/x→Frullani 积分
- 看到 x^{p-1}(1-x)^{q-1}→Beta 函数
- 看到 t^{s-1}e^{-t}→Gamma 函数
- 看到 1/(x²+b²)→Laplace 积分/留数法

### 13.3 积分计算的常见陷阱

1. **换元后忘记换上下限**（定积分）
2. **分部积分忘记边界项**（定积分）
3. **不定积分忘记加常数 C**
4. **积分号下求导不验证条件**（反常积分需要一致收敛）
5. **交换积分顺序不验证条件**（需要 Fubini 条件）
6. **逐项积分不验证收敛性**（需要一致收敛或控制收敛）
7. **留数法不验证圆弧积分趋于零**（需要 Jordan 引理或估计）
8. **把"积不出来"当作"不存在"**（原函数不是初等函数不代表积分不存在）
9. **忽略被积函数的奇点**（反常积分需要特殊处理）
10. **不验证换元的单调性/可导性**（第二类换元需要单调可导）

### 13.4 积分计算的练习方法

1. **分类练习**：按被积函数类型分类练习（有理函数、三角函数、无理函数等）
2. **一题多解**：对同一个积分尝试多种方法，比较优劣
3. **特殊积分记忆**：熟记著名特殊积分的结果和计算方法
4. **错题整理**：整理常见错误和陷阱
5. **循序渐进**：从简单到复杂，从基本技巧到高级技巧
6. **理解原理**：不仅要记住公式，更要理解每种技巧的原理和适用条件

### 13.5 几何理解

**📐 几何图像**：积分计算方法论的几何意义是"面积计算的系统方法论——根据图形的特点选择合适的方法，把复杂面积转化为简单面积"。

- 一般策略的几何意义：从简单到复杂、从基本到高级——先尝试最简单的方法（基本公式、代数化简），如果不行再逐步升级到更高级的技巧（参数积分、留数法）。这就像解决问题的一般策略——先易后难。
- 转化思维的几何意义：所有积分技巧都是"面积的转化"——通过变量替换、代数变形、维度提升、域的扩展，把难以计算的面积转化为容易计算的面积。
- 结构思维的几何意义：分析被积函数的几何结构（复合、乘积、有理、三角、根式），根据结构选择合适的转化方法。
- 联想思维的几何意义：看到被积函数的几何形状，联想到已知的特殊面积（钟形曲线→高斯积分，衰减振荡→Dirichlet 积分）。

积分计算方法论的几何本质是"面积计算的系统方法论——根据图形特点选择转化方法，把复杂面积转化为简单面积，体现了从简单到复杂、从特殊到一般的思维过程"。

## 第十四章 反例库

### 14.1 积分计算反例

**反例 1**：换元后不换上下限。∫₀¹ 2x√(1+x²)dx，令 u=1+x²，如果不换上下限（仍用 0 到 1），结果错误。正确：x=0→u=1, x=1→u=2。

**反例 2**：分部积分漏边界项。∫₀^π x sin x dx，如果漏掉 [-x cos x]₀^π，结果错误。

**反例 3**：不定积分忘记常数 C。∫cos x dx=sin x（不完整，应为 sin x+C）。

**反例 4**：积分号下求导不验证条件。对某些含参变量反常积分，积分号下求导可能不合法（不一致收敛时）。

### 14.2 特殊积分反例

**反例 5**：Frullani 积分条件不满足时公式不成立。如果 f(∞) 不存在，Frullani 公式可能不成立。

**反例 6**：高斯积分的被积函数 e^{-x²} 的原函数不是初等函数——不能用 Newton-Leibniz 公式直接计算，需要用二重积分或其他特殊方法。

**反例 7**：Dirichlet 积分的被积函数 sin x/x 在 x=0 处有可去间断点（定义为 1），在无穷远处是反常积分——需要特殊处理。

### 14.3 级数展开法反例

**反例 8**：逐项积分不验证收敛性。1/(1+x)=∑(-1)^n x^n 在 x=1 处不收敛（级数为 1-1+1-1+...，发散），所以逐项积分在 [0,1] 上需要验证（实际上可以用 Abel 定理证明结果正确，但不能直接逐项积分）。

**反例 9**：幂级数展开超出收敛半径。e^x=∑x^n/n! 在整个实轴上收敛，但 1/(1-x)=∑x^n 只在 |x|&lt;1 收敛，不能在 x>1 时使用。

### 14.4 留数法反例

**反例 10**：留数法中圆弧积分不趋于零。如果被积函数不满足 Jordan 引理的条件（如 deg Q=deg P+1 而不是 +2），圆弧积分可能不趋于零，需要特殊处理。

**反例 11**：实轴上有极点。如果被积函数在实轴上有极点，需要绕开极点（用小半圆），并计算极点处的贡献（通常是 πi 倍留数，而不是 2πi）。

**反例 12**：多值函数的分支切割。如果被积函数含多值函数（如 z^α, ln z），需要选择分支切割，并考虑切割上下岸的贡献差。

### 14.5 对称性反例

**反例 13**：误用奇偶性。f(x)=x² 在 [-1,1] 上是偶函数，积分加倍；但 f(x)=x³ 是奇函数，积分为零。如果判断错误（如把 x² 当作奇函数），结果错误。

**反例 14**：非对称区间上用奇偶性。奇偶性要求积分区间关于原点对称，如果区间不对称（如 [0,1]），不能直接用奇偶性。

### 14.6 反例总结

| 反例类型 | 典型例子 | 关键特征 |
|---|---|---|
| 换元不换限 | 定积分换元后仍用原上下限 | 定积分换元必须换上下限 |
| 分部积分漏边界项 | ∫x sin x dx 漏掉 [-x cos x] | 定积分分部积分有边界项 |
| 不定积分忘 C | ∫cos x dx=sin x | 不定积分必须加常数 |
| 积分号下求导不验证 | 不一致收敛时求导不合法 | 需验证一致收敛 |
| Frullani 条件不满足 | f(∞) 不存在时公式不成立 | 需 f(∞) 存在有限 |
| 高斯积不出来 | e^{-x²} 原函数非初等 | 需特殊方法 |
| 逐项积分不验证 | 收敛半径外逐项积分 | 需验证一致收敛 |
| 留数法圆弧不趋于零 | deg Q=deg P+1 | 需 Jordan 引理条件 |
| 实轴上有极点 | 需绕开极点 | 小半圆贡献 πi 留数 |
| 多值函数分支切割 | z^α, ln z | 需选分支切割 |
| 误用奇偶性 | 非对称区间用奇偶性 | 需对称区间 |
| 判断奇偶错误 | x² 当作奇函数 | 需正确判断 |

### 16.5 关键蜕变问题

**问题一：为什么有些积分需要用"超越技巧"（留数法、参数积分）才能计算？**

回答：许多积分的被积函数的原函数不是初等函数（如 e^{-x²}, sin x/x），所以不能用 Newton-Leibniz 公式直接计算。对于这些积分，需要用"超越技巧"——不通过原函数，而是通过其他途径计算定积分。

参数积分法的核心思想是"升维"——把一维积分提升为二维含参变量积分，利用积分号下求导（把困难的被积函数转化为容易的导数）和交换积分顺序（把困难的积分顺序转化为容易的顺序），然后再降维回到一维。这本质上是利用了二维空间比一维空间有更多的"自由度"和"灵活性"。

留数法的核心思想是"扩域"——把实轴上的积分扩展为复平面上的围道积分，利用复平面的拓扑结构（围道包围的区域）和解析函数的深刻性质（留数定理——围道积分只依赖于内部奇点的留数）。复平面比实轴有更丰富的几何和拓扑结构，这些结构为积分计算提供了强大的工具。

这些"超越技巧"的共同特点是：不直接计算原函数，而是通过提升维度（参数积分）或扩展数域（留数法），利用更丰富的数学结构来计算积分。这体现了数学中一个深刻的方法论原则：**有时候，解决一个困难问题的最好方法是把它放到更一般、更丰富的框架中去**。

**问题二：特殊函数（Gamma、Beta 等）在积分计算中的地位是什么？**

回答：特殊函数在积分计算中扮演着"基本积木"的角色——就像基本积分公式中的初等函数（sin, cos, e^x, ln）是简单积分的基本积木一样，特殊函数是复杂积分的基本积木。

Gamma 函数和 Beta 函数是最重要的特殊函数——它们把阶乘推广到连续变量，把许多复杂积分（如三角函数积分、多项式积分、概率分布归一化）统一到 Gamma/Beta 的框架中。许多著名特殊积分（高斯积分、Wallis 公式、三角函数积分）都可以用 Gamma 函数简洁地表示。

特殊函数的建立遵循一个模式：
1. 发现某些积分不能用初等函数表示
2. 定义新的函数来表示这些积分（如 Γ(s)=∫t^{s-1}e^{-t}dt）
3. 研究新函数的性质（递推、特殊值、解析延拓、函数方程）
4. 用新函数表示更多的积分和特殊常数
5. 新函数成为更高级理论的基础（如 Gamma 函数在数论、物理中的应用）

特殊函数的地位体现了数学发展的一个规律：**数学的发展是不断扩展"已知函数"范围的过程——从初等函数到特殊函数，每一次扩展都使得更多的积分可以"计算"（用已知函数表示）**。

### 17.3 常见误区清单

4. **积分号下求导不验证条件** → 错（需一致收敛）
5. **交换积分顺序不验证条件** → 错（需 Fubini 条件）
6. **逐项积分不验证收敛性** → 错（需一致收敛或控制收敛）
7. **留数法不验证圆弧积分趋于零** → 错（需 Jordan 引理）
8. **实轴上有极点不处理** → 错（需绕开，小半圆贡献 πi 留数）
9. **多值函数不选分支切割** → 错（需选分支切割并考虑上下岸差）
10. **非对称区间用奇偶性** → 错（需对称区间）
11. **把"积不出来"当作"不存在"** → 错（原函数非初等不代表积分不存在）
12. **Frullani 公式不验证条件** → 错（需 f(∞) 存在有限）
13. **幂级数展开超出收敛半径** → 错（需在收敛半径内）
14. **Gamma 函数定义域错误** → 错（Γ(s) 要求 s>0，其他需解析延拓）
15. **忽略被积函数的奇点** → 错（反常积分需特殊处理）

> **模块结语 · 积分计算的艺术**：
>
> D4-3 积分计算技巧与特殊积分是 D4 积分领域的第三模块——积分计算的"艺术"。如果说 D4-1 是积分的"语法"（基本规则），D4-2 是积分的"语义"（理论基础），那么 D4-3 就是积分的"修辞"（高级技巧和创造性应用）。
>
> **高级换元技巧**：对称换元（利用区间中点对称）、倒数换元（无穷远↔原点）、平移换元（对称化）、Euler 代换（二次曲线的有理参数化）。这些技巧的本质是通过创造性的坐标变换，利用被积函数和积分区间的特殊结构简化计算。
>
> **高级分部积分技巧**：循环积分（两次分部后回到自身，解方程）、递推公式（高次幂归约为低次幂，如 Wallis 公式）、表格法（多项式×指数的快速计算）、Abel 变换（离散分部求和）。
>
> **参数积分法**：积分计算中最强大的技巧之一——通过引入参数把一维积分提升为二维含参变量积分，利用积分号下求导（Leibniz 法则）和交换积分顺序（Fubini）把困难积分转化为容易积分。Dirichlet 积分、Poisson 积分都可以用参数积分法优雅地计算。
>
> **著名特殊积分**：
> - Dirichlet 积分 ∫₀^∞ sin x/x dx=π/2（5 种计算方法，Fourier 分析的基础）
> - 高斯积分 ∫₀^∞ e^{-x²}dx=√π/2（二重积分极坐标法，概率论的基石）
> - Frullani 积分 ∫₀^∞ [f(ax)-f(bx)]/x dx=[f(0)-f(∞)]ln(b/a)（中间细节被抵消，只保留端点信息）
> - Euler 积分（Gamma 函数 Γ(s)=∫t^{s-1}e^{-t}dt，Beta 函数 B(p,q)=Γ(p)Γ(q)/Γ(p+q)，阶乘的连续推广）
> - Poisson 积分、Laplace 积分、Fresnel 积分、对数积分、Catalan 常数
>
> **级数展开法**：把被积函数展开为幂级数或 Fourier 级数，逐项积分——利用积分的线性性和函数的正交分解。Basel 问题（∑1/n²=π²/6）可以用 Parseval 等式优雅地证明。
>
> **留数法**：复变方法在实积分计算中的强大应用——把实轴上的积分扩展为复平面上的围道积分，利用留数定理（围道积分只依赖于内部奇点的留数）和 Jordan 引理（上半平面圆弧积分趋于零）计算。有理函数积分、含三角函数积分、Laplace 积分、Fresnel 积分都可以用留数法系统计算。
>
> **对称性技巧**：奇偶对称、中点对称、三角函数特殊对称、周期性、轮换对称——利用图形的几何对称性把复杂面积转化为简单面积。
>
> **积分计算方法论**：六步策略（识别类型→基本技巧→系统技巧→高级技巧→超越技巧→判断积不出来）、转化思维（所有技巧都是转化）、结构思维（根据被积函数结构选技巧）、联想思维（看到被积函数联想到特殊积分）。
>
> **跨层蜕变**：从 L0 初等直觉（面积公式）到 L1 经典分析（换元/分部/参数积分/特殊积分）到 L2 复变函数（留数法/围道积分/解析延拓）到 L3 实变函数（测度论方法/控制收敛），积分计算的方法不断丰富和深化。特殊函数（Gamma/Beta）是连接各层的桥梁——它们在 L1 层通过积分定义，在 L2 层通过解析延拓推广，在 L3 层通过测度论统一。
>
> 几何视角贯穿全章：坐标变换（换元）、面积互补（分部积分）、参数化升维（参数积分）、钟形曲线面积（高斯积分）、衰减振荡面积（Dirichlet 积分）、尺度缩放差（Frullani 积分）、阶乘连续推广（Gamma）、复平面围道（留数法）、图形对称（对称性技巧）——所有积分计算技巧都有清晰的几何图像。
>
> 积分计算技巧与特殊积分的核心洞察是：**积分计算是"艺术"而非"机械"——没有统一的法则，需要根据被积函数的特点选择合适的技巧。所有技巧的本质都是"转化"——把未知复杂积分转化为已知简单积分。参数积分法（升维）和留数法（扩域）体现了数学中一个深刻的方法论原则：解决困难问题的最好方法是把它放到更一般、更丰富的框架中。特殊函数（Gamma/Beta 等）是积分计算的"基本积木"——数学的发展是不断扩展"已知函数"范围的过程，每一次扩展都使得更多的积分可以"计算"。**
