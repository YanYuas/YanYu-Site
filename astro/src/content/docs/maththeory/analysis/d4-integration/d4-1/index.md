## 第一章 引言：从微分到积分的逆运算

### 1.1 不定积分的定位

微分学解决的问题是：已知函数 f(x)，求它的导数 f'(x)（变化率）。
积分学解决的逆问题是：已知导数 f'(x)，求原函数 f(x)。

这个逆运算就是不定积分——它是积分学的"代数入口"，不涉及极限和面积的概念，纯粹是求导法则的逆向运用。

不定积分和定积分（D4-2）是两个不同的概念：
- **不定积分**：求原函数的运算，结果是一族函数（相差常数）
- **定积分**：求曲线下面积的运算，结果是一个数

两者通过微积分基本定理（D4-2 详细讨论）联系起来——但在本模块中，我们只关注不定积分的代数理论。

### 1.2 不定积分的历史定位

不定积分的历史比定积分短：
- **古代**：定积分的思想（穷竭法）可以追溯到古希腊（阿基米德求抛物弓形面积）
- **17 世纪**：牛顿和莱布尼茨发现微积分基本定理，把微分和积分联系起来，不定积分成为求积分的工具
- **18-19 世纪**：积分技巧大发展（换元法、分部积分法、部分分式分解），积分表大量出现
- **19 世纪末**：Liouville 建立微分代数理论，回答"哪些初等函数的原函数是初等函数"的问题
- **20 世纪**：Risch 算法（1969）实现了初等函数积分的计算机自动化

## 第二章 原函数的定义与存在性

### 2.1 原函数的定义

**定义**：设 f(x) 在区间 I 上有定义。如果存在可导函数 F(x)，使得对所有 x∈I，都有 F'(x)=f(x)，则称 F(x) 是 f(x) 在区间 I 上的一个原函数。

注意：原函数的定义是"逐点"的——F'(x)=f(x) 对区间上每一点都成立。

### 2.2 原函数的不唯一性

如果 F(x) 是 f(x) 的一个原函数，那么 F(x)+C（C 是任意常数）也是 f(x) 的原函数——因为常数的导数为零。

反过来，如果 F(x) 和 G(x) 都是 f(x) 在区间 I 上的原函数，则 F'(x)=G'(x)=f(x)，所以 (F-G)'(x)=0 对所有 x∈I 成立。由 Lagrange 中值定理的推论，F-G 在区间 I 上是常数。

**定理**：f(x) 在区间 I 上的任意两个原函数相差一个常数。

注意：这个结论要求区间是连通的（一个区间）。如果定义域是不连通的（如两个不相交的区间的并），则不同连通分支上的常数可以不同。

### 2.3 原函数的存在性

**问题**：什么样的函数有原函数？

**充分条件**：如果 f(x) 在区间 I 上连续，则 f(x) 在 I 上有原函数。

这是微积分基本定理的第一部分（D4-2 详细讨论）——连续函数的变上限积分 F(x)=∫ₐˣ f(t)dt 就是 f(x) 的一个原函数。

**必要条件**：有原函数的函数必须具有介值性（Darboux 性质）——如果 f 有原函数 F，则 f=F'，而导数具有介值性（Darboux 定理：导数具有介值性质，即如果 F'(a)&lt;c&lt;F'(b)，则存在 ξ∈(a,b) 使得 F'(ξ)=c）。

所以：**有第一类间断点（跳跃间断点）的函数没有原函数**——因为跳跃间断点不满足介值性。

但有第二类间断点的函数可能有原函数——例如 f(x)=2x sin(1/x²)-2/x cos(1/x²)（x≠0）, f(0)=0，这个函数在 0 处有第二类间断点（无界振荡），但它有原函数 F(x)=x² sin(1/x²)（x≠0）, F(0)=0。

### 2.4 原函数存在性的完整刻画

原函数存在性的完整刻画是一个深刻的问题：

1. **连续函数**：一定有原函数（充分条件）
2. **有第一类间断点的函数**：一定没有原函数（因为不满足介值性）
3. **有第二类间断点的函数**：可能有原函数，也可能没有
4. **单调函数**：如果单调函数有第一类间断点，则没有原函数；如果连续（如 Cantor 函数），则其导数 a.e. 存在但不一定有经典原函数（Cantor 函数的导数 a.e. 为零，但 Cantor 函数不是常数，所以它不是零函数的原函数——这里要注意，Cantor 函数本身是某个函数的原函数吗？它的导数 a.e. 为零，但不是处处为零，所以它不是零函数的原函数）

**精确刻画**：f 有原函数当且仅当 f 是某个可导函数的导数——这是同义反复。更深刻的刻画涉及导数的刻画问题（characterization of derivatives），这是实分析中的一个深刻课题，至今没有完全简洁的刻画。

### 2.5 几何理解

**📐 几何图像**：原函数的几何意义是"已知切线斜率，求曲线"。如果已知曲线上每一点的切线斜率 f(x)，那么原函数 F(x) 就是满足这个斜率条件的曲线。因为常数 C 不影响斜率（垂直平移不改变切线斜率），所以原函数不唯一——所有满足斜率条件的曲线构成一族"平行曲线"（垂直平移得到的曲线族）。

原函数存在性的几何意义：不是每一个"斜率函数"都对应一条曲线——如果斜率函数有跳跃（第一类间断点），就不存在一条曲线在每一点都有这个斜率，因为曲线的斜率不能"跳跃"（导数具有介值性，不能从一个值跳到另一个值而不经过中间值）。

原函数的几何本质是"已知斜率场，求积分曲线"——这是微分方程的几何观点，也是不定积分的几何本质。

## 第三章 不定积分的定义与性质

### 3.1 不定积分的定义

**定义**：f(x) 在区间 I 上的全体原函数称为 f(x) 的不定积分，记为
∫f(x)dx

如果 F(x) 是 f(x) 的一个原函数，则
∫f(x)dx = F(x) + C

其中 C 是任意常数，称为积分常数。

记号说明：
- ∫ 称为积分号（莱布尼茨引入，是"sum"的首字母 S 的拉长）
- f(x) 称为被积函数
- f(x)dx 称为被积表达式
- x 称为积分变量

### 3.2 不定积分的性质

1. **微分与积分的互逆性**：
   - d/dx [∫f(x)dx] = f(x)（先积分后微分，还原）
   - ∫F'(x)dx = F(x) + C（先微分后积分，差一个常数）

2. **线性性**：
   - ∫[αf(x)+βg(x)]dx = α∫f(x)dx + β∫g(x)dx + C
   （α, β 是常数，不同时为零）

3. **积分变量的替换**：
   - ∫f(x)dx 中的 x 是"哑变量"，可以换成任何字母：∫f(x)dx=∫f(t)dt=∫f(u)du
   （但要注意，这只是记号的替换，不涉及换元法）

### 3.3 不定积分与导数的对照表

不定积分是求导的逆运算，每一个求导公式对应一个积分公式：

| 求导公式 | 积分公式 |
|---|---|
| (x^α)'=αx^{α-1} | ∫x^α dx = x^{α+1}/(α+1)+C (α≠-1) |
| (ln|x|)'=1/x | ∫1/x dx = ln|x|+C |
| (eˣ)'=eˣ | ∫eˣ dx = eˣ+C |
| (aˣ)'=aˣ ln a | ∫aˣ dx = aˣ/ln a+C (a>0,a≠1) |
| (sin x)'=cos x | ∫cos x dx = sin x+C |
| (cos x)'=-sin x | ∫sin x dx = -cos x+C |
| (tan x)'=sec²x | ∫sec²x dx = tan x+C |
| (cot x)'=-csc²x | ∫csc²x dx = -cot x+C |
| (sec x)'=sec x tan x | ∫sec x tan x dx = sec x+C |
| (csc x)'=-csc x cot x | ∫csc x cot x dx = -csc x+C |
| (arcsin x)'=1/√(1-x²) | ∫1/√(1-x²) dx = arcsin x+C |
| (arctan x)'=1/(1+x²) | ∫1/(1+x²) dx = arctan x+C |

### 3.4 几何理解

**📐 几何图像**：不定积分的几何意义是"积分曲线族"。∫f(x)dx=F(x)+C 表示一族曲线，这些曲线在横坐标相同的点处有相同的切线斜率 f(x)——它们是彼此的垂直平移。给定一个初始条件（如 F(x₀)=y₀），就可以确定常数 C，从而确定唯一的一条积分曲线。

不定积分的线性性的几何意义：积分曲线族的线性组合对应斜率场的线性组合——如果曲线族 F 对应斜率 f，曲线族 G 对应斜率 g，那么 αF+βG 对应斜率 αf+βg。

不定积分的几何本质是"斜率场的积分曲线族——所有满足斜率条件的曲线的集合"。

## 第四章 基本积分公式表

### 4.1 幂函数与指数函数

1. ∫x^α dx = x^{α+1}/(α+1)+C (α≠-1)
2. ∫1/x dx = ln|x|+C
3. ∫eˣ dx = eˣ+C
4. ∫aˣ dx = aˣ/ln a+C (a>0, a≠1)

### 4.2 三角函数

5. ∫sin x dx = -cos x+C
6. ∫cos x dx = sin x+C
7. ∫tan x dx = -ln|cos x|+C
8. ∫cot x dx = ln|sin x|+C
9. ∫sec x dx = ln|sec x+tan x|+C
10. ∫csc x dx = ln|csc x-cot x|+C
11. ∫sec²x dx = tan x+C
12. ∫csc²x dx = -cot x+C
13. ∫sec x tan x dx = sec x+C
14. ∫csc x cot x dx = -csc x+C

### 4.3 反三角函数

15. ∫1/√(1-x²) dx = arcsin x+C = -arccos x+C
16. ∫1/(1+x²) dx = arctan x+C = -arccot x+C
17. ∫1/(x²-a²) dx = (1/2a)ln|(x-a)/(x+a)|+C
18. ∫1/(a²-x²) dx = (1/2a)ln|(a+x)/(a-x)|+C
19. ∫1/√(a²-x²) dx = arcsin(x/a)+C
20. ∫1/√(x²±a²) dx = ln|x+√(x²±a²)|+C

### 4.4 双曲函数

21. ∫sinh x dx = cosh x+C
22. ∫cosh x dx = sinh x+C
23. ∫tanh x dx = ln(cosh x)+C
24. ∫coth x dx = ln|sinh x|+C

### 4.5 使用基本积分公式的注意事项

1. **积分常数 C 不能忘**：不定积分的结果必须加上常数 C，否则只是一个原函数，不是全体原函数。
2. **绝对值不能忘**：∫1/x dx=ln|x|+C 中的绝对值不能丢——因为 ln x 只在 x>0 有定义，而 1/x 在 x&lt;0 也有定义，原函数应该是 ln|x|。
3. **定义域要注意**：不同的公式有不同的定义域（如 arcsin x 要求 |x|&lt;1），积分结果的定义域要和被积函数一致。
4. **公式的等价形式**：有些积分有多种等价形式（如 ∫1/√(1-x²)dx=arcsin x+C=-arccos x+C），它们相差一个常数，都是正确的。

### 4.6 几何理解

**📐 几何图像**：基本积分公式表的几何意义是"常见斜率场对应的积分曲线族"。每一个基本积分公式都对应一种常见的斜率场（如 f(x)=1/x 对应斜率与 x 成反比的斜率场），以及对应的积分曲线族（如 ln|x|+C 对应对数曲线族）。

熟记基本积分公式就像熟记乘法口诀——它们是进行更复杂积分运算的基础。所有复杂的积分最终都要通过各种技巧（换元、分部、部分分式等）转化为基本积分公式的形式。

基本积分公式的几何本质是"常见斜率场的积分曲线族速查表"。

## 第五章 换元积分法（第一类）

### 5.1 第一类换元法的原理

第一类换元法（也称为凑微分法）的原理是复合函数求导法则的逆用。

复合函数求导：d/dx [F(φ(x))] = F'(φ(x))·φ'(x)

逆过来：如果被积函数可以写成 f(φ(x))·φ'(x) 的形式，那么
∫f(φ(x))·φ'(x)dx = F(φ(x))+C
其中 F 是 f 的原函数。

**定理（第一类换元法）**：如果 ∫f(u)du=F(u)+C，且 u=φ(x) 可导，则
∫f(φ(x))φ'(x)dx = F(φ(x))+C

### 5.2 常见的凑微分形式

1. ∫f(ax+b)dx = (1/a)∫f(ax+b)d(ax+b)
2. ∫x^α f(x^{α+1})dx = 1/(α+1)∫f(x^{α+1})d(x^{α+1})
3. ∫f(ln x)·(1/x)dx = ∫f(ln x)d(ln x)
4. ∫f(eˣ)·eˣdx = ∫f(eˣ)d(eˣ)
5. ∫f(sin x)·cos x dx = ∫f(sin x)d(sin x)
6. ∫f(cos x)·sin x dx = -∫f(cos x)d(cos x)
7. ∫f(tan x)·sec²x dx = ∫f(tan x)d(tan x)
8. ∫f(arctan x)·1/(1+x²)dx = ∫f(arctan x)d(arctan x)
9. ∫f(arcsin x)·1/√(1-x²)dx = ∫f(arcsin x)d(arcsin x)

### 5.3 例子

**例 1**：∫(2x+1)¹⁰ dx

解：令 u=2x+1, du=2dx, dx=du/2。
∫(2x+1)¹⁰dx = (1/2)∫u¹⁰du = (1/2)·u¹¹/11+C = (2x+1)¹¹/22+C

**例 2**：∫x e^{x²} dx

解：令 u=x², du=2x dx, x dx=du/2。
∫x e^{x²}dx = (1/2)∫eᵘdu = (1/2)eᵘ+C = (1/2)e^{x²}+C

**例 3**：∫tan x dx

解：∫tan x dx = ∫sin x/cos x dx = -∫1/cos x d(cos x) = -ln|cos x|+C

**例 4**：∫1/(x ln x) dx

解：∫1/(x ln x)dx = ∫1/ln x d(ln x) = ln|ln x|+C

### 5.4 第一类换元法的技巧

第一类换元法的关键是"凑微分"——把被积函数中的一部分凑成某个函数的微分。常用技巧：

1. **观察被积函数的结构**：寻找复合函数 f(φ(x)) 和 φ'(x) 的因子
2. **从复杂部分入手**：被积函数中最复杂的部分通常是 f(φ(x))，尝试把它的"内层函数"φ(x) 设为 u
3. **利用基本微分公式**：熟记常见的凑微分形式（如 x dx=d(x²/2), 1/x dx=d(ln x), eˣdx=d(eˣ), cos x dx=d(sin x) 等）
4. **多次凑微分**：有些积分需要多次凑微分，逐步简化

### 5.5 几何理解

**📐 几何图像**：第一类换元法的几何意义是"变量替换改变了斜率场的坐标表示"。令 u=φ(x)，相当于在 x 轴上做一个非线性的坐标变换——把 x 轴上的点映射到 u 轴上。在这个变换下，原来的斜率场 f(φ(x))φ'(x) 变成了 u 轴上的简单斜率场 f(u)。积分曲线在 x 轴上的表示 F(φ(x))，对应于 u 轴上的积分曲线 F(u)。

第一类换元法的几何本质是"通过坐标变换把复杂斜率场转化为简单斜率场，求出积分曲线后再变换回来"。

## 第六章 换元积分法（第二类）

### 6.1 第二类换元法的原理

第二类换元法是主动引入新变量 t，令 x=ψ(t)，把关于 x 的积分转化为关于 t 的积分。

**定理（第二类换元法）**：设 x=ψ(t) 单调可导，ψ'(t)≠0，且 ∫f(ψ(t))ψ'(t)dt=G(t)+C，则
∫f(x)dx = G(ψ⁻¹(x))+C
其中 ψ⁻¹ 是 ψ 的反函数。

和第一类换元法的区别：
- 第一类：u=φ(x)，把 φ(x) 凑成 u（被动凑微分）
- 第二类：x=ψ(t)，主动令 x 等于某个函数 ψ(t)

### 6.2 常见的第二类换元

1. **三角代换**（处理含 √(a²-x²), √(a²+x²), √(x²-a²) 的积分）：
   - 含 √(a²-x²)：令 x=a sin t（或 a cos t）
   - 含 √(a²+x²)：令 x=a tan t（或 a sinh t）
   - 含 √(x²-a²)：令 x=a sec t（或 a cosh t）

2. **倒代换**：令 x=1/t，用于处理分母次数高于分子次数的有理函数积分

3. **根式代换**：令 t=√(ax+b)（或 t=ⁿ√(ax+b)），把无理函数转化为有理函数

4. **指数代换**：令 t=eˣ，处理含 eˣ 的积分

5. **万能代换**：令 t=tan(x/2)，处理三角函数有理式的积分（见第九章）

### 6.3 三角代换的例子

**例 1**：∫√(a²-x²) dx

解：令 x=a sin t, dx=a cos t dt, √(a²-x²)=a cos t。
∫√(a²-x²)dx = ∫a cos t·a cos t dt = a²∫cos²t dt = a²∫(1+cos 2t)/2 dt
= a²(t/2+sin 2t/4)+C = a²(t/2+sin t cos t/2)+C
= (a²/2)arcsin(x/a)+(x/2)√(a²-x²)+C

**例 2**：∫1/√(x²+a²) dx

解：令 x=a tan t, dx=a sec²t dt, √(x²+a²)=a sec t。
∫1/√(x²+a²)dx = ∫1/(a sec t)·a sec²t dt = ∫sec t dt = ln|sec t+tan t|+C
= ln|x/a+√(x²+a²)/a|+C = ln|x+√(x²+a²)|+C'

### 6.4 倒代换的例子

**例**：∫1/[x²√(1+x²)] dx

解：令 x=1/t, dx=-1/t² dt。
∫1/[x²√(1+x²)]dx = ∫1/[(1/t²)√(1+1/t²)]·(-1/t²)dt = -∫t/√(t²+1)dt
= -√(t²+1)+C = -√(1/x²+1)+C = -√(1+x²)/x+C

### 6.5 第二类换元法的注意事项

1. **反函数要存在**：x=ψ(t) 必须单调（保证反函数存在），通常取 t 的范围使 ψ 单调
2. **回代不能忘**：求出关于 t 的积分后，必须把 t 换回 x（t=ψ⁻¹(x)）
3. **三角代换的回代**：可以用辅助三角形法——根据 x=a sin t 画直角三角形，直接读出 sin t, cos t, tan t 等
4. **绝对值的处理**：三角代换后开方时要注意绝对值，通常取 t 的范围使根式非负

### 6.6 几何理解

**📐 几何图像**：第二类换元法的几何意义是"主动做坐标变换，把复杂的积分区域转化为简单的积分区域"。三角代换 x=a sin t 把 x 轴上的区间 [-a,a] 转化为 t 轴上的区间 [-π/2,π/2]，同时把半圆 √(a²-x²) 转化为简单的余弦函数 a cos t。这相当于把"弯曲"的坐标（x 轴上的半圆）"拉直"为 t 轴上的直线。

倒代换 x=1/t 是一种"倒数变换"——它把 x=∞ 附近的行为转化为 t=0 附近的行为，把无穷远的问题转化为原点附近的问题。

第二类换元法的几何本质是"主动选择合适的坐标变换，把复杂的被积函数和积分区域转化为简单的形式"。

## 第七章 分部积分法

### 7.1 分部积分法的原理

分部积分法是乘积求导法则的逆用。

乘积求导：(uv)'=u'v+uv'

逆过来：uv'=(uv)'-u'v

两边积分：∫u v' dx = uv - ∫u' v dx

**定理（分部积分法）**：
∫u dv = uv - ∫v du

这是分部积分法最简洁的形式——把 ∫u dv 转化为 uv - ∫v du，希望后者比前者更容易积分。

### 7.2 分部积分法的使用场景

分部积分法适用于以下类型的积分：

1. **幂函数 × 指数函数**：∫xⁿ e^{ax} dx（令 u=xⁿ, dv=e^{ax}dx）
2. **幂函数 × 三角函数**：∫xⁿ sin(ax)dx, ∫xⁿ cos(ax)dx（令 u=xⁿ）
3. **幂函数 × 对数函数**：∫xⁿ ln x dx（令 u=ln x, dv=xⁿdx——注意对数函数要设为 u，因为对数的积分更难）
4. **幂函数 × 反三角函数**：∫xⁿ arcsin x dx, ∫xⁿ arctan x dx（令 u=反三角函数）
5. **指数函数 × 三角函数**：∫e^{ax} sin(bx)dx, ∫e^{ax} cos(bx)dx（需要两次分部积分，然后解方程）
6. **递推公式**：某些积分需要通过分部积分建立递推关系

### 7.3 u 的选择原则（LIATE 法则）

选择 u 的优先级（从高到低）：
- **L**：Logarithmic（对数函数）
- **I**：Inverse trigonometric（反三角函数）
- **A**：Algebraic（代数函数/幂函数）
- **T**：Trigonometric（三角函数）
- **E**：Exponential（指数函数）

排在前面的设为 u，排在后面的设为 dv。因为对数和反三角函数的积分更难（它们不是基本积分公式的直接结果），所以设为 u（求导后变简单）；指数和三角函数的积分简单，所以设为 dv（积分后还是同类函数）。

### 7.4 例子

**例 1**：∫x eˣ dx

解：令 u=x, dv=eˣdx，则 du=dx, v=eˣ。
∫x eˣdx = x eˣ - ∫eˣdx = x eˣ - eˣ+C = (x-1)eˣ+C

**例 2**：∫ln x dx

解：令 u=ln x, dv=dx，则 du=1/x dx, v=x。
∫ln x dx = x ln x - ∫x·(1/x)dx = x ln x - ∫1 dx = x ln x - x+C

**例 3**：∫eˣ sin x dx（两次分部积分+解方程）

解：令 I=∫eˣ sin x dx。
第一次：u=sin x, dv=eˣdx ⇒ I=eˣ sin x - ∫eˣ cos x dx
第二次：u=cos x, dv=eˣdx ⇒ ∫eˣ cos x dx=eˣ cos x + ∫eˣ sin x dx=eˣ cos x+I
代入：I=eˣ sin x - (eˣ cos x+I)=eˣ sin x - eˣ cos x - I
2I=eˣ(sin x-cos x) ⇒ I=eˣ(sin x-cos x)/2+C

**例 4**：∫arctan x dx

解：令 u=arctan x, dv=dx，则 du=1/(1+x²)dx, v=x。
∫arctan x dx = x arctan x - ∫x/(1+x²)dx = x arctan x - (1/2)ln(1+x²)+C

### 7.5 分部积分法的推广

1. **多次分部积分**：有些积分需要多次分部积分（如 ∫xⁿ eˣdx 需要 n 次）
2. **分部积分的表格法**：对于 ∫u v^(n+1)dx 类型，可以用表格法快速计算（u 逐行求导，v 逐行积分，交叉相乘）
3. **递推公式**：通过分部积分建立 Iₙ 和 Iₙ₋₁ 的递推关系（如 ∫sinⁿx dx 的递推公式）
4. **分部积分的定积分形式**：∫ₐᵇ u dv = [uv]ₐᵇ - ∫ₐᵇ v du

### 7.6 几何理解

**📐 几何图像**：分部积分法的几何意义是"面积的互补计算"。考虑曲线 v=v(u) 下的面积——∫u dv 是曲线左侧的面积（对 v 积分），uv 是矩形的面积，∫v du 是曲线下侧的面积（对 u 积分）。分部积分公式 ∫u dv=uv-∫v du 说的是：矩形面积减去下侧面积等于左侧面积——这是面积的互补关系。

在实际应用中，分部积分法的几何意义是"把难以计算的面积（∫u dv）转化为容易计算的面积（∫v du）加上矩形面积"。选择 u 的原则（LIATE）就是让 ∫v du 比 ∫u dv 更容易计算。

分部积分法的几何本质是"面积的互补转化——把难以积分的部分转化为容易积分的部分"。

## 第八章 有理函数的积分

### 8.1 有理函数的定义

有理函数是两个多项式的商：
R(x)=P(x)/Q(x)
其中 P(x) 和 Q(x) 是实系数多项式，Q(x) 不恒为零。

如果 deg P &lt; deg Q，称为真分式；如果 deg P ≥ deg Q，称为假分式。假分式可以通过多项式除法化为多项式加真分式：
P(x)/Q(x) = S(x) + R(x)/Q(x)
其中 S(x) 是商式（多项式），R(x) 是余式（deg R &lt; deg Q）。

多项式的积分是基本的（幂函数积分），所以有理函数积分的关键是真分式的积分。

### 8.2 部分分式分解

**定理**：任何真分式 R(x)/Q(x) 都可以唯一地分解为以下四类部分分式的和：

1. **一次单因式**：如果 (x-a) 是 Q(x) 的单因式，则对应部分分式 A/(x-a)
2. **一次重因式**：如果 (x-a)^k 是 Q(x) 的因式（k≥2），则对应部分分式 A₁/(x-a)+A₂/(x-a)²+...+Aₖ/(x-a)^k
3. **二次单因式**：如果 (x²+px+q) 是 Q(x) 的单因式（判别式 p²-4q&lt;0，不可约），则对应部分分式 (Bx+C)/(x²+px+q)
4. **二次重因式**：如果 (x²+px+q)^k 是 Q(x) 的因式（k≥2），则对应部分分式 (B₁x+C₁)/(x²+px+q)+...+(Bₖx+Cₖ)/(x²+px+q)^k

### 8.3 部分分式系数的求法

1. **比较系数法**：通分后比较分子多项式的系数，解线性方程组
2. **代入法（赋值法）**：代入特殊的 x 值（如 Q(x) 的根），直接求出某些系数
3. **极限法**：对重因式，可以通过求极限或求导来确定系数
4. **综合法**：结合使用以上方法

### 8.4 四类部分分式的积分

1. **∫A/(x-a)dx = A ln|x-a|+C**（对数函数）

2. **∫A/(x-a)^k dx = A/[(1-k)(x-a)^{k-1}]+C**（k≥2，有理函数）

3. **∫(Bx+C)/(x²+px+q)dx**：
   - 把分子拆为 Bx+C = (B/2)(2x+p) + (C-Bp/2)
   - 第一部分：(B/2)∫(2x+p)/(x²+px+q)dx = (B/2)ln|x²+px+q|+C
   - 第二部分：(C-Bp/2)∫1/(x²+px+q)dx，配方后用 arctan 积分

4. **∫(Bx+C)/(x²+px+q)^k dx**（k≥2）：
   - 同样拆分子，第一部分直接积分
   - 第二部分需要用递推公式（通过分部积分建立 Iₖ 和 Iₖ₋₁ 的关系）

### 8.5 例子

**例 1**：∫1/(x²-1) dx

解：1/(x²-1)=1/[(x-1)(x+1)]=A/(x-1)+B/(x+1)
通分：1=A(x+1)+B(x-1)
令 x=1：1=2A ⇒ A=1/2
令 x=-1：1=-2B ⇒ B=-1/2
∫1/(x²-1)dx = (1/2)∫1/(x-1)dx - (1/2)∫1/(x+1)dx
= (1/2)ln|x-1| - (1/2)ln|x+1|+C = (1/2)ln|(x-1)/(x+1)|+C

**例 2**：∫(x²+2x-1)/[(x-1)(x²+1)] dx

解：(x²+2x-1)/[(x-1)(x²+1)] = A/(x-1) + (Bx+C)/(x²+1)
通分：x²+2x-1 = A(x²+1)+(Bx+C)(x-1)
令 x=1：1+2-1=2A ⇒ A=1
比较 x² 系数：1=A+B ⇒ B=0
比较常数项：-1=A-C ⇒ C=2
∫...dx = ∫1/(x-1)dx + ∫2/(x²+1)dx = ln|x-1|+2 arctan x+C

### 8.6 有理函数积分的结论

**定理**：任何有理函数的原函数都是初等函数，且只由三类函数组成：
1. 有理函数（多项式和真分式）
2. 对数函数（ln|x-a| 和 ln|x²+px+q|）
3. 反正切函数（arctan）

这是一个非常优美的结论——有理函数的积分"积得出来"，且结果不超出初等函数的范围。这和后面要讨论的某些初等函数（如 e^{-x²}）形成对比——那些函数的原函数不是初等函数。

### 8.7 几何理解

**📐 几何图像**：有理函数积分的几何意义是"把复杂的有理斜率场分解为简单的基本斜率场"。部分分式分解把一个复杂的有理函数 R(x)=P(x)/Q(x) 分解为简单的部分分式（1/(x-a), 1/(x-a)^k, (Bx+C)/(x²+px+q) 等），每个部分分式对应一个简单的斜率场（如 1/(x-a) 对应斜率与 x-a 成反比的斜率场，积分曲线是对数曲线）。把这些简单积分曲线加起来，就得到原有理函数的积分曲线。

部分分式分解的几何本质是"复杂斜率场的简单分解——把有理函数分解为基本斜率场的线性组合"。

## 第九章 三角函数有理式的积分

### 9.1 三角函数有理式的定义

三角函数有理式是由三角函数和常数经过有限次四则运算得到的函数，记为 R(sin x, cos x)。

例如：(1+sin x)/(sin x(1+cos x)), sin²x cos³x, 1/(a+b cos x) 等都是三角函数有理式。

### 9.2 万能代换

**万能代换**：令 t=tan(x/2)，则
- sin x = 2t/(1+t²)
- cos x = (1-t²)/(1+t²)
- dx = 2/(1+t²) dt

这样，任何三角函数有理式 R(sin x, cos x) 的积分都可以转化为关于 t 的有理函数积分：
∫R(sin x, cos x)dx = ∫R(2t/(1+t²), (1-t²)/(1+t²))·2/(1+t²) dt

因为有理函数的积分一定可以积出来（第八章），所以**任何三角函数有理式的积分都可以积出来**——这就是"万能代换"名称的由来。

### 9.3 万能代换的局限

万能代换虽然"万能"，但计算量往往很大——转化后的有理函数可能很复杂，部分分式分解很繁琐。所以在实际应用中，应该优先考虑更简单的代换，万能代换作为最后手段。

### 9.4 特殊情形的简单代换

1. **R(-sin x, cos x) = -R(sin x, cos x)**（关于 sin x 是奇函数）：令 t=cos x
   - 例：∫sin³x cos²x dx（令 t=cos x）

2. **R(sin x, -cos x) = -R(sin x, cos x)**（关于 cos x 是奇函数）：令 t=sin x
   - 例：∫sin²x cos³x dx（令 t=sin x）

3. **R(-sin x, -cos x) = R(sin x, cos x)**（关于 sin x 和 cos x 都是偶函数，即齐次）：令 t=tan x
   - 例：∫1/(a²sin²x+b²cos²x) dx（令 t=tan x）

4. **sin^m x cos^n x 的积分**：
   - m 为奇数：令 t=cos x（拆一个 sin x 凑微分）
   - n 为奇数：令 t=sin x（拆一个 cos x 凑微分）
   - m,n 均为偶数：用降幂公式（sin²x=(1-cos 2x)/2, cos²x=(1+cos 2x)/2）

### 9.5 例子

**例 1**：∫1/(sin x cos x) dx

解：1/(sin x cos x)=2/sin 2x=2 csc 2x
∫2 csc 2x dx = ln|csc 2x-cot 2x|+C = ln|tan x|+C
（也可以用万能代换，但更简单的方法是直接化简）

**例 2**：∫sin³x dx

解：sin³x=sin x·sin²x=sin x(1-cos²x)
令 t=cos x, dt=-sin x dx
∫sin³x dx = -∫(1-t²)dt = -t+t³/3+C = -cos x+cos³x/3+C

**例 3**：∫1/(a+b cos x) dx（用万能代换）

解：令 t=tan(x/2)，cos x=(1-t²)/(1+t²), dx=2/(1+t²)dt
∫1/(a+b cos x)dx = ∫1/[a+b(1-t²)/(1+t²)]·2/(1+t²)dt
= ∫2/[a(1+t²)+b(1-t²)]dt = ∫2/[(a+b)+(a-b)t²]dt
根据 a²-b² 的符号，结果为 arctan 或 ln 形式。

### 9.6 几何理解

**📐 几何图像**：三角函数有理式积分的几何意义是"周期斜率场的积分曲线"。三角函数是周期函数，所以三角函数有理式的斜率场是周期的——积分曲线也是周期的（或带有周期振荡的）。万能代换 t=tan(x/2) 是一个非线性的坐标变换，它把 x 轴上的周期区间 (-π,π) 映射到整个 t 轴（-∞,+∞），同时把三角函数有理式转化为有理函数——把"周期的、三角的"斜率场转化为"非周期的、有理的"斜率场。

特殊代换（如 t=cos x, t=sin x, t=tan x）的几何意义是针对特定对称性的简化——如果斜率场关于某个三角函数有奇偶对称性，就可以用对应的简单代换，避免万能代换的复杂计算。

三角函数有理式积分的几何本质是"周期斜率场的积分——通过坐标变换把三角斜率场转化为有理斜率场"。

## 第十章 无理函数的积分

### 10.1 无理函数积分的一般策略

无理函数是含有根号的函数。无理函数的积分没有统一的方法，需要根据根号的类型选择合适的代换，目标是把无理函数转化为有理函数（或其他可积形式）。

### 10.2 含 √(ax+b) 的积分

**代换**：令 t=√(ax+b)，则 x=(t²-b)/a, dx=2t/a dt。

这样，含 √(ax+b) 的无理函数就转化为关于 t 的有理函数。

**例**：∫x√(2x+1) dx

解：令 t=√(2x+1), x=(t²-1)/2, dx=t dt
∫x√(2x+1)dx = ∫(t²-1)/2·t·t dt = (1/2)∫(t⁴-t²)dt
= (1/2)(t⁵/5-t³/3)+C = (1/10)(2x+1)^{5/2}-(1/6)(2x+1)^{3/2}+C

### 10.3 含 ⁿ√(ax+b) 或多个根式的积分

**代换**：如果被积函数含有 ⁿ√(ax+b) 和 ᵐ√(ax+b)，令 t=ᵏ√(ax+b)，其中 k 是 m,n 的最小公倍数。

**例**：∫1/(√x+³√x) dx

解：令 t=⁶√x, x=t⁶, dx=6t⁵dt
∫1/(√x+³√x)dx = ∫1/(t³+t²)·6t⁵dt = 6∫t³/(t+1)dt
= 6∫(t²-t+1-1/(t+1))dt = 6(t³/3-t²/2+t-ln|t+1|)+C
= 2√x-3³√x+6⁶√x-6 ln(⁶√x+1)+C

### 10.4 含 √(a²-x²), √(a²+x²), √(x²-a²) 的积分

用三角代换（见第六章第二类换元法）：
- √(a²-x²)：令 x=a sin t
- √(a²+x²)：令 x=a tan t（或双曲代换 x=a sinh t）
- √(x²-a²)：令 x=a sec t（或双曲代换 x=a cosh t）

### 10.5 含 √(ax²+bx+c) 的积分

**方法**：先配方 ax²+bx+c=a[(x+b/2a)²+(4ac-b²)/(4a²)]，然后根据判别式的符号转化为 √(u²±k²) 或 √(k²-u²) 的形式，再用三角代换。

**欧拉代换**：对于含 √(ax²+bx+c) 的积分，也可以用欧拉代换：
- 第一类欧拉代换（a>0）：令 √(ax²+bx+c)=t±√a·x
- 第二类欧拉代换（c>0）：令 √(ax²+bx+c)=xt±√c
- 第三类欧拉代换（ax²+bx+c 有两个不同实根 α,β）：令 √(ax²+bx+c)=t(x-α)

### 10.6 二项微分式的积分

**定义**：形如 ∫x^m(a+bx^n)^p dx 的积分称为二项微分式的积分，其中 m,n,p 是有理数。

**切比雪夫定理**：二项微分式的原函数是初等函数，当且仅当以下三个条件至少有一个成立：
1. p 是整数
2. (m+1)/n 是整数
3. (m+1)/n+p 是整数

如果三个条件都不满足，则二项微分式的原函数不是初等函数（"积不出来"）。

**例**：∫√(1+x³)dx = ∫x⁰(1+x³)^{1/2}dx，m=0, n=3, p=1/2。
- p=1/2 不是整数
- (m+1)/n=1/3 不是整数
- (m+1)/n+p=1/3+1/2=5/6 不是整数
所以 ∫√(1+x³)dx 积不出来（原函数不是初等函数）。

### 10.7 几何理解

**📐 几何图像**：无理函数积分的几何意义是"含根号的斜率场的积分曲线"。根号通常对应几何中的距离、长度、面积等概念——如 √(a²-x²) 对应半圆，√(x²+y²) 对应距离。无理函数的斜率场往往有"边界"（根号内的表达式必须非负），积分曲线也只在这个边界内有定义。

代换法的几何意义是"通过坐标变换把含根号的斜率场转化为有理斜率场"——三角代换把半圆转化为余弦函数，根式代换把 √(ax+b) 转化为线性函数，欧拉代换把二次根式转化为有理函数。

二项微分式的切比雪夫定理是一个深刻的结果——它给出了"哪些无理函数积得出来"的精确判据，也说明了"积不出来"不是因为技巧不够，而是因为原函数确实不是初等函数。

无理函数积分的几何本质是"含根号的斜率场通过坐标变换转化为有理斜率场，切比雪夫定理给出了可积性的精确判据"。

## 第十一章 初等函数的可积性与 Liouville 定理

### 11.1 问题的提出

前面讨论的有理函数、三角函数有理式、某些无理函数的积分都"积得出来"（原函数是初等函数）。但并非所有初等函数的原函数都是初等函数——有些初等函数的原函数"积不出来"。

经典例子：
- ∫e^{-x²}dx（高斯积分，误差函数）
- ∫sin x/x dx（正弦积分）
- ∫1/ln x dx（对数积分）
- ∫√(1+x³)dx（椭圆积分）
- ∫√(1-k²sin²x)dx（椭圆积分）

这些积分在概率论、数论、物理学等领域有重要应用，但它们的原函数不是初等函数——需要定义新的特殊函数（误差函数 erf(x)、正弦积分 Si(x)、对数积分 li(x)、椭圆积分等）。

### 11.2 初等函数的定义

初等函数是由常数和基本初等函数（幂函数、指数函数、对数函数、三角函数、反三角函数）经过有限次四则运算和复合运算得到的函数。

注意：初等函数的定义中不包含积分——所以"初等函数的原函数是否是初等函数"是一个非平凡的问题。

### 11.3 Liouville 定理

**定理（Liouville，1833）**：设 f 是初等函数。如果 f 有初等原函数，则存在初等函数 g₁,...,gₙ 和常数 c₁,...,cₙ，使得
∫f(x)dx = g₀(x) + ∑ᵢ cᵢ ln gᵢ(x)
其中 g₀ 也是初等函数。

换句话说：**初等函数的初等原函数只能由初等函数加上对数函数的线性组合构成**。

这个定理是微分代数的基础——它把"初等函数的原函数是否初等"的问题转化为代数问题。

### 11.4 Liouville 定理的推论

利用 Liouville 定理可以证明某些函数的原函数不是初等函数：

1. **∫e^{-x²}dx 不是初等函数**：假设它是初等函数，由 Liouville 定理，e^{-x²}=g₀'+∑cᵢ gᵢ'/gᵢ。分析指数部分可以推出矛盾。

2. **∫sin x/x dx 不是初等函数**：sin x/x=(e^{ix}-e^{-ix})/(2ix)，可以用类似的方法证明。

3. **∫1/ln x dx 不是初等函数**：令 t=ln x，转化为 ∫eᵗ/t dt，可以证明不是初等函数。

4. **椭圆积分**：∫√(1-k²sin²x)dx 不是初等函数（一般情形）。

### 11.5 Risch 算法

1969 年，Robert Risch 提出了一个算法（Risch 算法），可以判定一个初等函数的原函数是否是初等函数，并在是的时候求出原函数。

Risch 算法是 Liouville 定理的算法化——它把微分代数的理论转化为计算机可以执行的步骤。现代计算机代数系统（如 Mathematica、Maple）中的积分功能都基于 Risch 算法（及其改进版本）。

### 11.6 特殊函数

对于"积不出来"的初等函数，人们定义了各种特殊函数来表示它们的原函数：

1. **误差函数**：erf(x)=(2/√π)∫₀ˣ e^{-t²}dt（概率论、统计学）
2. **正弦积分**：Si(x)=∫₀ˣ sin t/t dt（信号处理）
3. **余弦积分**：Ci(x)=-∫ₓ^∞ cos t/t dt
4. **对数积分**：li(x)=∫₀ˣ 1/ln t dt（数论，素数定理）
5. **指数积分**：Ei(x)=∫_{-∞}^x eᵗ/t dt
6. **椭圆积分**：第一类、第二类、第三类椭圆积分（椭圆弧长、物理）
7. **Fresnel 积分**：∫cos(t²)dt, ∫sin(t²)dt（光学、衍射）
8. **Gamma 函数**：Γ(x)=∫₀^∞ t^{x-1}e^{-t}dt（阶乘的推广）

这些特殊函数本身成为数学的重要研究对象，有各自的性质、递推公式、渐近展开等。

### 11.7 几何理解

**📐 几何图像**：初等函数可积性的几何意义是"某些斜率场的积分曲线不能用初等函数表示"。初等函数对应的曲线是"有限次代数和超越运算的组合"——它们构成一个相对小的函数类。某些斜率场（如 e^{-x²} 对应的斜率场）的积分曲线（高斯曲线的积分）不在这个小函数类里——需要引入新的特殊函数来表示。

Liouville 定理的几何意义是"初等原函数的结构限制"——如果一个初等函数的原函数是初等的，那么它只能由初等函数加对数组成。这说明对数函数在积分中扮演了特殊的角色——它是积分运算"产生"的主要新函数类型（有理函数积分产生对数，三角函数积分也可能产生对数）。

特殊函数的几何意义是"为了表示积不出来的积分曲线，需要扩展函数类"——每一个特殊函数都对应一类重要的积分曲线，它们在各自的应用领域（概率、数论、物理）中有重要意义。

初等函数可积性的几何本质是"初等函数类在积分运算下不封闭——积分运算产生了初等函数类之外的新函数（特殊函数），Liouville 定理刻画了初等原函数的结构，Risch 算法实现了可积性的判定"。

## 第十二章 积分技巧总览与策略

### 12.1 积分技巧的层次

不定积分的技巧可以分为几个层次：

1. **基本公式**：直接使用基本积分公式表（第四章）
2. **代数化简**：通过代数运算（展开、拆分、分子分母同乘、有理化等）把被积函数化简为基本公式的形式
3. **第一类换元法（凑微分）**：把被积函数凑成 f(φ(x))φ'(x) 的形式（第五章）
4. **第二类换元法**：主动引入新变量，把复杂积分转化为简单积分（第六章）
5. **分部积分法**：把 ∫u dv 转化为 uv-∫v du（第七章）
6. **部分分式分解**：有理函数的系统积分方法（第八章）
7. **特殊函数代换**：三角函数有理式（第九章）、无理函数（第十章）
8. **综合运用**：多种技巧的组合使用

### 12.2 积分策略的一般流程

面对一个不定积分，一般按以下流程尝试：

1. **能否直接用基本公式？**——如果被积函数就是基本公式的形式，直接写出结果
2. **能否通过代数化简转化为基本公式？**——展开、拆分、同乘、有理化等
3. **能否用第一类换元法（凑微分）？**——寻找复合函数 f(φ(x)) 和 φ'(x) 的因子
4. **能否用分部积分法？**——被积函数是否是两类函数的乘积？按 LIATE 法则选择 u
5. **是否是有理函数？**——用部分分式分解
6. **是否是三角函数有理式？**——先尝试特殊代换，最后用万能代换
7. **是否含根式？**——根据根式类型选择代换（根式代换、三角代换、欧拉代换）
8. **是否需要多种技巧组合？**——复杂积分往往需要多种技巧的组合
9. **是否积不出来？**——如果以上方法都失败，考虑是否原函数不是初等函数（参考 Liouville 定理和切比雪夫定理）

### 12.3 常见积分类型与对应技巧

| 积分类型 | 首选技巧 | 备选技巧 |
|---|---|---|
| 基本初等函数 | 基本公式 | — |
| 多项式×初等函数 | 分部积分 | 换元 |
| 复合函数×内层导数 | 第一类换元 | — |
| 含 √(ax+b) | 根式代换 | 凑微分 |
| 含 √(a²-x²) 等 | 三角代换 | 双曲代换 |
| 有理函数 | 部分分式 | 倒代换、凑微分 |
| 三角函数有理式 | 特殊代换 | 万能代换 |
| sin^m x cos^n x | 奇偶性代换 | 降幂公式 |
| 对数函数×幂函数 | 分部积分（u=对数） | — |
| 反三角函数×幂函数 | 分部积分（u=反三角） | 换元 |
| e^{ax}×sin(bx) | 分部积分两次+解方程 | 复数方法 |
| 二项微分式 | 切比雪夫判据 | 换元 |

### 12.4 积分技巧的本质

所有积分技巧的本质都是**转化**——把未知的、复杂的积分转化为已知的、简单的积分：

1. **换元法**：通过变量替换转化被积函数和积分变量
2. **分部积分法**：通过乘积求导的逆用转化被积函数的结构
3. **部分分式分解**：通过代数分解把复杂有理函数转化为简单部分分式
4. **万能代换**：通过三角恒等式把三角函数有理式转化为有理函数

积分技巧的学习不是死记硬背，而是理解每种技巧的转化原理，然后通过大量练习培养"积分直觉"——看到一个积分就能快速判断应该用哪种技巧。

### 12.5 几何理解

**📐 几何图像**：积分技巧总览的几何意义是"斜率场转化的工具箱"。每一种积分技巧都是一种"坐标变换"或"代数变形"，把复杂的斜率场转化为简单的斜率场。积分策略的一般流程就是"从最简单的转化开始尝试，逐步升级到更复杂的转化"。

积分技巧的学习曲线是：初学者需要按流程逐一尝试，熟练者可以一眼看出应该用哪种技巧，专家可以创造性地组合多种技巧。这和下棋类似——初学者背定式，熟练者看局面，专家创造新定式。

积分技巧的几何本质是"斜率场转化的方法论——通过系统化的转化策略把复杂积分转化为简单积分，理解转化原理比死记技巧更重要"。

## 第十三章 反例库

### 13.1 原函数存在性反例

**反例 1**：有第一类间断点的函数没有原函数。f(x)=1（x≥0）, f(x)=0（x&lt;0）（阶梯函数）。f 在 x=0 处有跳跃间断点（第一类间断点），不满足介值性，所以没有原函数。

**反例 2**：有第二类间断点的函数可能有原函数。f(x)=2x sin(1/x²)-2/x cos(1/x²)（x≠0）, f(0)=0。f 在 x=0 处有第二类间断点（无界振荡），但 f 有原函数 F(x)=x² sin(1/x²)（x≠0）, F(0)=0。

**反例 3**：无界函数可能有原函数。f(x)=1/√x（x>0）在 x=0 附近无界，但有原函数 F(x)=2√x。

### 13.2 不定积分计算反例

**反例 4**：∫1/x dx=ln x+C 是错误的（缺少绝对值）。正确的是 ∫1/x dx=ln|x|+C。因为 1/x 在 x&lt;0 也有定义，而 ln x 只在 x>0 有定义。

**反例 5**：不定积分忘记加常数 C。∫cos x dx=sin x 是不完整的，正确的是 ∫cos x dx=sin x+C。不定积分表示全体原函数，必须加常数。

**反例 6**：换元后忘记回代。用第二类换元法求出关于 t 的积分后，必须把 t 换回 x，否则结果是关于 t 的函数，不是关于 x 的原函数。

### 13.3 可积性反例

**反例 7**：∫e^{-x²}dx 积不出来（原函数不是初等函数）。这是高斯积分，需要用误差函数 erf(x) 表示。

**反例 8**：∫sin x/x dx 积不出来。这是正弦积分，需要用 Si(x) 表示。

**反例 9**：∫1/ln x dx 积不出来。这是对数积分，需要用 li(x) 表示。

**反例 10**：∫√(1+x³)dx 积不出来。由切比雪夫定理，m=0,n=3,p=1/2，三个条件都不满足，所以积不出来。

**反例 11**：∫√(1-k²sin²x)dx 积不出来（一般情形，k≠0,1）。这是第二类椭圆积分。

### 13.4 分部积分反例

**反例 12**：分部积分时 u 和 dv 选择错误。例如 ∫x ln x dx，如果令 u=x, dv=ln x dx，则 v=x ln x-x（需要先求 ln x 的积分，更复杂）。正确的选择是 u=ln x, dv=x dx（按 LIATE 法则，对数排在代数前面，所以 u=ln x）。

**反例 13**：分部积分后出现循环但忘记解方程。∫eˣ sin x dx 需要两次分部积分，第二次后会出现原来的积分 I，需要移项解方程，否则无法得到结果。

### 13.5 部分分式反例

**反例 14**：假分式没有先做多项式除法。如果 deg P≥deg Q，必须先用多项式除法化为多项式加真分式，否则部分分式分解不适用。

**反例 15**：重因式的部分分式遗漏低次项。对于 (x-a)^k，部分分式应该是 A₁/(x-a)+A₂/(x-a)²+...+Aₖ/(x-a)^k，不能只写 Aₖ/(x-a)^k。

### 13.6 反例总结

| 反例类型 | 典型例子 | 关键特征 |
|---|---|---|
| 有第一类间断点无原函数 | 阶梯函数 | 不满足介值性 |
| 有第二类间断点有原函数 | 2x sin(1/x²)-2/x cos(1/x²) | 无界振荡但有原函数 |
| 无界函数有原函数 | 1/√x | 原函数 2√x |
| 积分忘记绝对值 | ∫1/x dx=ln x | 应为 ln\|x\| |
| 积分忘记常数 C | ∫cos x dx=sin x | 应为 sin x+C |
| 换元后忘记回代 | 第二类换元法 | 结果是关于 t 的函数 |
| e^{-x²} 积不出来 | 高斯积分 | 需误差函数 |
| sin x/x 积不出来 | 正弦积分 | 需 Si(x) |
| 1/ln x 积不出来 | 对数积分 | 需 li(x) |
| √(1+x³) 积不出来 | 椭圆积分 | 切比雪夫定理 |
| 分部积分 u,dv 选择错误 | ∫x ln x dx | 应按 LIATE 法则 |
| 分部积分循环忘记解方程 | ∫eˣ sin x dx | 需移项解方程 |
| 假分式未先除法 | deg P≥deg Q | 需多项式除法 |
| 重因式遗漏低次项 | (x-a)^k | 需 A₁/(x-a)+...+Aₖ/(x-a)^k |

### 14.1 不定积分理论的历史分期

**第一期：微积分创立时期（17 世纪）**

- 欧拉（1740s-1760s）：大量积分技巧，积分表，椭圆积分的初步研究
- 拉格朗日（1760s）：换元积分法的系统研究
- 部分分式分解：18 世纪逐渐发展成熟

**第三期：可积性理论的建立（19 世纪）**
- Liouville（1833）：Liouville 定理，初等函数可积性的理论基础
- 切比雪夫（1853）：二项微分式的可积性判据（切比雪夫定理）
- 阿贝尔（1820s）：椭圆积分的深入研究，椭圆函数的发现
- 雅可比（1820s-1830s）：椭圆函数理论的建立
- 黎曼（1850s）：黎曼积分理论，定积分的严格定义

**第四期：现代发展（20 世纪 - 至今）**
- Risch（1969）：Risch 算法，初等函数积分的计算机自动化
- 计算机代数系统（Mathematica, Maple 等）：积分计算的自动化
- 特殊函数理论的深入发展（正交多项式、超几何函数、q-级数等）
- 微分代数（Differential Algebra）作为独立学科的发展

### 14.3 历史发展的主线

1. **从技巧到理论**：18 世纪是积分技巧的大发展（换元法、分部积分法、部分分式），19 世纪建立了可积性的理论（Liouville 定理、切比雪夫定理）
2. **从手算到自动化**：从手工计算积分、查积分表，到计算机代数系统自动积分（Risch 算法）
3. **从初等函数到特殊函数**：发现许多初等函数的原函数不是初等函数，定义了各种特殊函数（误差函数、椭圆积分、Gamma 函数等）
4. **从代数到微分代数**：Liouville 定理开创了微分代数这一学科，用代数方法研究微分和积分问题
5. **从实函数到复函数**：椭圆积分的研究导致了椭圆函数（复变函数）的发现，推动了复变函数论的发展

## 第十五章 跨层蜕变图谱

### 15.1 不定积分在各层的演化

| 维度 | L0 初等直觉 | L1 数学分析（经典） | L2 复变函数 | L3 实变函数 |
|---|---|---|---|---|
| 原函数定义 | "反导数"（直观） | F'(x)=f(x) 处处成立 | 解析函数的原函数（解析） | a.e. 原函数、弱原函数 |
| 原函数存在性 | 初等函数都有 | 连续函数有原函数 | 解析函数有原函数（区域单连通时） | L¹ 函数有 AC 原函数（不定积分） |
| 原函数不唯一性 | 差常数（直观） | 差常数（区间上） | 差常数（单连通区域） | a.e. 意义下不唯一（可差奇异函数） |
| 积分技巧 | 基本公式 | 换元、分部、部分分式 | 复积分技巧（留数、参数积分） | 不直接对应（Lebesgue 积分不强调原函数技巧） |
| 可积性 | 初等函数都积得出来 | 某些初等函数积不出来（e^{-x²}等） | 解析函数的原函数是解析的 | L¹ 函数都有 AC 原函数 |
| 特殊函数 | 不区分 | 误差函数、椭圆积分等 | 椭圆函数（复变） | 不直接对应 |
| 微积分基本定理 | 直观发现 | 连续可导条件下成立 | 解析函数条件下成立 | 绝对连续条件下成立 |

### 15.2 原函数存在性的跨层对比

| 层级 | 原函数存在条件 | 反例 |
|---|---|---|
| L1 经典 | 连续⇒有原函数（充分）；有第一类间断点⇒无原函数 | 阶梯函数（跳跃间断点无原函数） |
| L2 复变 | 解析函数在单连通区域内有原函数 | 1/z 在多连通区域（去心平面）上没有单值原函数（多值函数 ln z） |
| L3 实变 | L¹ 函数有 AC 原函数（不定积分）；BV 函数 a.e. 可导但不一定有经典原函数 | Cantor 函数不是零函数的原函数（导数 a.e. 为零但非常数） |

### 15.3 可积性的跨层对比

| 层级 | "可积"的含义 | 可积函数类 |
|---|---|---|
| L0 初等 | 原函数是初等函数 | 初等函数（但实际上某些初等函数积不出来） |
| L1 经典 | 原函数是初等函数（Liouville 意义） | 有理函数、三角函数有理式、某些无理函数；e^{-x²}等积不出来 |
| L2 复变 | 原函数是解析函数 | 解析函数在单连通区域内都有解析原函数 |
| L3 实变 | 原函数是 AC 函数（Lebesgue 意义） | 所有 L¹ 函数都有 AC 原函数 |

注意：L1 层的"可积"（原函数是初等函数）和 L3 层的"可积"（Lebesgue 可积）是完全不同的概念——L1 层关注原函数的形式（是否初等），L3 层关注函数本身是否可积（Lebesgue 积分是否存在）。

### 15.4 反例演化链

```
L0 初等: 无反例（初等函数都"积得出来"的错觉）
  ↓
L1 经典: 阶梯函数（有第一类间断点，无原函数）
  ↓
L1 经典: 2x sin(1/x²)-2/x cos(1/x²)（有第二类间断点但有原函数）
  ↓
L1 经典: ∫1/x dx=ln x（忘记绝对值的常见错误）
  ↓
L1 经典: e^{-x²}（积不出来，需误差函数）
  ↓
L1 经典: sin x/x（积不出来，需正弦积分）
  ↓
L1 经典: √(1+x³)（积不出来，切比雪夫定理判据）
  ↓
L2 复变: 1/z 在去心平面上无单值原函数（多值函数 ln z）
  ↓
L3 实变: Cantor 函数（导数 a.e. 为零但非常数，不是零函数的原函数）
```

### 15.5 关键蜕变问题

**问题一：为什么有些初等函数的原函数不是初等函数？**

回答：初等函数类在微分运算下是封闭的（初等函数的导数仍是初等函数），但在积分运算下不封闭——积分运算产生了初等函数类之外的新函数。Liouville 定理刻画了初等原函数的结构：如果初等函数的原函数是初等的，那么它只能由初等函数加对数的线性组合构成。这个结构限制非常强——许多初等函数的积分不满足这个结构，因此原函数不是初等函数。这不是因为积分技巧不够，而是因为初等函数类本身在积分下不封闭——需要引入新的特殊函数（误差函数、椭圆积分等）来表示这些积分。

**问题二：不定积分在 L3 实变函数层发生了什么变化？**

回答：在 L3 层，不定积分的概念发生了本质变化：
1. **原函数的定义弱化**：从"处处 F'=f"弱化为"a.e. F'=f"，进一步弱化为"弱导数/分布导数等于 f"
2. **原函数的存在性扩大**：从"连续函数有原函数"扩大到"所有 L¹ 函数有 AC 原函数"——Lebesgue 积分使得更广泛的函数类有原函数
3. **原函数的唯一性丧失**：在 a.e. 意义下，原函数不唯一（可差奇异函数，如 Cantor 函数）；只有在 AC 条件下才唯一（差常数）
4. **积分技巧不再重要**：Lebesgue 积分关注的是积分的存在性和性质，不是原函数的具体计算——不定积分的代数技巧（换元、分部、部分分式）在 L3 层不再是核心
5. **微积分基本定理的条件变化**：从"连续可导"变为"绝对连续"——AC 是微积分基本定理成立的充要条件

**问题三：Liouville 定理和 Risch 算法的意义是什么？**

回答：Liouville 定理（1833）是微分代数的奠基性定理——它把"初等函数的原函数是否初等"这个分析问题转化为代数问题，给出了初等原函数的结构刻画。在此之前，人们只能通过尝试各种积分技巧来判断一个积分是否"积得出来"，失败了也不知道是因为技巧不够还是因为确实积不出来。Liouville 定理给出了理论判据。

Risch 算法（1969）是 Liouville 定理的算法化——它把微分代数的理论转化为计算机可以执行的步骤，可以判定任何初等函数的原函数是否初等，并在是的时候求出原函数。Risch 算法是计算机代数系统的核心算法之一，它使得积分计算从"手工技巧"转变为"自动化计算"。

Liouville 定理和 Risch 算法的意义在于：它们把不定积分从"艺术"（需要灵感和经验的技巧）转变为"科学"（有理论判据和算法步骤的系统方法）。

### 16.3 常见误区清单

1. **所有函数都有原函数** → 错（有第一类间断点的函数没有原函数）
2. **原函数唯一** → 错（区间上差常数；不连通定义域上各分支常数可不同；a.e. 意义下可差奇异函数）
3. **∫1/x dx=ln x+C** → 错（应为 ln|x|+C，绝对值不能丢）
4. **不定积分忘记加常数 C** → 错（不定积分表示全体原函数，必须加 C）
5. **换元后忘记回代** → 错（第二类换元法必须把 t 换回 x）
6. **分部积分 u,dv 选择随意** → 错（应按 LIATE 法则选择，否则可能更复杂）
7. **假分式未先做多项式除法** → 错（deg P≥deg Q 时必须先化为多项式加真分式）
8. **重因式遗漏低次项** → 错（(x-a)^k 对应 A₁/(x-a)+...+Aₖ/(x-a)^k）
9. **万能代换是首选** → 错（应先尝试特殊代换，万能代换计算量大，作为最后手段）
10. **所有初等函数都积得出来** → 错（e^{-x²}, sin x/x, 1/ln x 等积不出来，原函数不是初等函数）
11. **积不出来是因为技巧不够** → 错（Liouville 定理和切比雪夫定理给出了理论判据，某些积分确实积不出来）
12. **分部积分后出现循环就放弃** → 错（应移项解方程，如 ∫eˣ sin x dx）
13. **三角代换后开方不注意绝对值** → 错（应取 t 的范围使根式非负，或保留绝对值）
14. **不定积分和定积分混淆** → 错（不定积分是函数族，定积分是数；两者通过微积分基本定理联系）
15. **L1 层的"可积"和 L3 层的"可积"混淆** → 错（L1 层指原函数是初等函数，L3 层指 Lebesgue 可积，完全不同的概念）

### 18.2 类比

- 导数与不定积分：互逆运算，导数是"变化率"，不定积分是"反变化率"
- 乘法与部分分式：都是分解，乘法把简单因子乘成复杂乘积，部分分式把复杂有理函数分解为简单部分分式
- 复合函数求导与第一类换元：互逆，复合函数求导是 f(φ(x))→f'(φ(x))φ'(x)，第一类换元是 f(φ(x))φ'(x)→f(φ(x))
- 乘积求导与分部积分：互逆，乘积求导是 (uv)'=u'v+uv'，分部积分是 uv'=(uv)'-u'v
- 有理函数积分与多项式除法：假分式先做除法化为真分式，类似带余除法
- 万能代换与坐标变换：万能代换把三角斜率场转化为有理斜率场，类似坐标变换
- 初等函数可积性与群论：Liouville 理论用微分代数（一种代数结构）研究可积性，类似用群论研究方程可解性（Galois 理论）
- 特殊函数与新数：积不出来的积分定义新特殊函数，类似负数开方定义虚数——都是扩展数系/函数类
- 不定积分与微分方程：求原函数是最简单的微分方程（y'=f(x)），不定积分技巧是解微分方程的基础
- Risch 算法与 Galois 算法：都是判定性算法，Risch 判定积分是否初等，Galois 判定方程是否可用根式解

### 18.3 推广

- 从一元不定积分到多元不定积分（全微分求积、曲线积分与路径无关）
- 从实函数不定积分到复函数不定积分（解析函数的原函数、多值函数）
- 从经典原函数到弱原函数（Sobolev 空间、弱导数）
- 从初等函数到广义函数（分布的原函数、分布积分）
- 从普通积分到随机积分（Itô 积分、Stratonovich 积分的原函数）
- 从有限维到无限维（Banach 空间值函数的积分、Bochner 积分）
- 从代数积分到符号积分（Risch 算法、计算机代数系统）
- 从初等可积性到微分代数（Liouville 理论、微分 Galois 理论）
- 从显式原函数到隐式原函数（隐函数定理、反函数定理）
- 从定积分到变限积分（含参变量积分、积分号下求导）
- 从普通函数到算子值函数（算子积分、泛函积分）

### 18.4 特例

- 常数函数：∫C dx=Cx+C'
- 幂函数：∫x^α dx=x^{α+1}/(α+1)+C（α≠-1）
- 指数函数：∫eˣ dx=eˣ+C
- 对数函数：∫ln x dx=x ln x-x+C（分部积分）
- 三角函数：∫sin x dx=-cos x+C, ∫cos x dx=sin x+C
- 有理函数：∫1/(x²-1)dx=(1/2)ln|(x-1)/(x+1)|+C
- 1/x：∫1/x dx=ln|x|+C（绝对值不能丢）
- 1/(1+x²)：∫1/(1+x²)dx=arctan x+C
- 1/√(1-x²)：∫1/√(1-x²)dx=arcsin x+C
- e^{-x²}：积不出来，需误差函数 erf(x)
- sin x/x：积不出来，需正弦积分 Si(x)
- 1/ln x：积不出来，需对数积分 li(x)
- √(1+x³)：积不出来（切比雪夫定理判据）
- √(1-k²sin²x)：椭圆积分，一般积不出来

> **模块结语 · D4 积分领域的代数入口**：
>
> D4-1 不定积分与原函数是 D4 积分领域的第一个模块——积分学的"代数入口"。不定积分是微分的逆运算，不涉及极限和面积的概念，纯粹是求导法则的逆向运用。
>
> **原函数与不定积分**：原函数是导数等于 f(x) 的函数，不定积分是全体原函数（差常数）。连续函数有原函数（充分条件），有第一类间断点的函数没有原函数（因为不满足介值性）。
>
> **基本积分公式**：24 个基本积分公式是不定积分的基础——每一个求导公式对应一个积分公式。熟记基本公式是进行更复杂积分运算的前提。
>
> **换元积分法**：第一类换元法（凑微分法）是复合函数求导的逆用，第二类换元法主动引入新变量（三角代换、倒代换、根式代换）。换元法的本质是通过坐标变换把复杂斜率场转化为简单斜率场。
>
> **分部积分法**：乘积求导法则的逆用，∫u dv=uv-∫v du。LIATE 法则给出了 u 的选择优先级（对数>反三角>代数>三角>指数）。分部积分法的几何本质是面积的互补转化。
>
> **有理函数积分**：部分分式分解把复杂有理函数分解为四类简单部分分式，每类部分分式的积分都是基本的。有理函数的原函数只由有理函数、对数函数、反正切函数构成——这是一个优美的封闭性结论。
>
> **三角函数有理式积分**：万能代换 t=tan(x/2) 把任何三角函数有理式转化为有理函数，所以任何三角函数有理式都积得出来。但万能代换计算量大，应优先考虑特殊代换（利用奇偶性、齐次性）。
>
> **无理函数积分**：根据根式类型选择代换（根式代换、三角代换、欧拉代换）。二项微分式的切比雪夫定理给出了精确的可积性判据——三个条件至少满足一个才积得出来。
>
> **初等函数可积性与 Liouville 定理**：初等函数类在积分运算下不封闭——某些初等函数的原函数不是初等函数（e^{-x²}, sin x/x, 1/ln x, 椭圆积分等）。Liouville 定理刻画了初等原函数的结构（初等函数加对数的线性组合），Risch 算法实现了可积性的计算机自动化判定。这些"积不出来"的积分定义了各种特殊函数（误差函数、正弦积分、对数积分、椭圆积分等），它们本身成为数学的重要研究对象。
>
> **跨层蜕变**：从 L0 初等直觉到 L1 经典分析到 L2 复变函数到 L3 实变函数，不定积分的概念不断演化——原函数的定义从处处弱化为 a.e./弱，存在性从连续函数扩大到所有 L¹ 函数，唯一性从差常数变为 a.e. 不唯一（可差奇异函数），可积性的含义从"原函数初等"变为"Lebesgue 可积"。
>
> 几何视角贯穿全章：原函数是"已知斜率求曲线"、不定积分是"积分曲线族"、换元法是"坐标变换转化斜率场"、分部积分法是"面积互补转化"、部分分式是"复杂斜率场的简单分解"、万能代换是"周期斜率场转化为有理斜率场"、Liouville 定理是"初等函数类在积分下不封闭"——所有不定积分概念都有清晰的几何图像。
>
> 不定积分与原函数的核心洞察是：**不定积分是微分的逆运算，所有积分技巧的本质都是"转化"——把未知的、复杂的积分转化为已知的、简单的积分。初等函数类在积分下不封闭——积分运算产生了初等函数类之外的新函数（特殊函数），Liouville 定理刻画了初等原函数的结构，Risch 算法实现了可积性的自动化判定。从 L1 经典层到 L3 实变层，原函数的概念不断弱化和推广——从"处处 F'=f"到"a.e. F'=f"到"弱导数等于 f"，存在性不断扩大，唯一性逐渐丧失，绝对连续是微积分基本定理成立的充要条件。**
>
