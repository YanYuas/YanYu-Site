## L0 初等直觉层（★ 基础）

**【D7-2-001】** 在单位圆上画出角 θ = 5π/6 对应的点 P，写出 P 的坐标，并分别用直角三角形定义和单位圆定义验证 sin(5π/6) 和 cos(5π/6) 的值。

- **难度**：★
- **对应知识点**：单位圆定义、特殊角、直角三角形定义的局限
- **解答**：
  5π/6 = 150°，在第二象限。
  点 P 坐标 = (cos 5π/6, sin 5π/6) = (-√3/2, 1/2)。

  **单位圆定义验证**：
  cos 5π/6 = P 的横坐标 = -√3/2
  sin 5π/6 = P 的纵坐标 = 1/2

  **直角三角形定义验证**：
  5π/6 是钝角，直角三角形定义不直接适用。但可以用补角：
  参考角 = π - 5π/6 = π/6（锐角）。
  sin(5π/6) = sin(π/6) = 1/2（第二象限 sin 为正）
  cos(5π/6) = -cos(π/6) = -√3/2（第二象限 cos 为负）
  ∎
- **一句话点评**：单位圆定义适用于任意角；钝角需用参考角+象限符号。5π/6的点=(-√3/2,1/2)。

**【D7-2-002】** 已知角 θ 的终边经过点 P(-3, 4)，求 sin θ, cos θ, tan θ 的值（注意：P 不在单位圆上）。

- **难度**：★
- **对应知识点**：任意角三角函数定义、点到原点距离
- **解答**：
  P(-3, 4) 到原点的距离 r = √((-3)² + 4²) = √(9+16) = √25 = 5。
  任意角三角函数定义（推广到任意半径的圆）：
  sin θ = y/r = 4/5
  cos θ = x/r = -3/5
  tan θ = y/x = 4/(-3) = -4/3
  ∎

  **几何理解**：将 P 缩放到单位圆上，得到点 P' = (-3/5, 4/5)，这就是单位圆上对应角 θ 的点。所以 cos θ = -3/5, sin θ = 4/5。缩放不改变角度，只改变半径。
- **一句话点评**：r=√(x²+y²)=5；sin=y/r=4/5，cos=x/r=-3/5，tan=y/x=-4/3。缩放P到单位圆得(-3/5,4/5)。

**【D7-2-003】** 用单位圆上的三角函数线说明：对于锐角 θ，sin θ &lt; θ &lt; tan θ，并指出这三条线段分别对应什么。

- **难度**：★
- **对应知识点**：三角函数线、面积比较、重要极限预备
- **解答**：
  在单位圆上，角 θ（锐角）的终边交单位圆于 P(cosθ, sinθ)。
  - **正弦线**：从 P 向 x 轴作垂线，垂足 M，|PM| = sin θ（垂线段长度）
  - **弧 AP**：从 A(1,0) 到 P 的圆弧长度 = θ（弧度制下弧长=角度）
  - **正切线**：终边延长线交切线 x=1 于 T(1, tanθ)，|AT| = tan θ（切线段长度）

  从图上可见：
  垂线段 PM &lt; 圆弧 AP &lt; 切线段 AT
  即 sin θ &lt; θ &lt; tan θ。∎

  **面积比较验证**：
  内接三角形 OAP 面积 = (1/2)sin θ
  扇形 OAP 面积 = (1/2)θ
  外切三角形 OAT 面积 = (1/2)tan θ
  面积关系：(1/2)sin θ &lt; (1/2)θ &lt; (1/2)tan θ ⟹ sin θ &lt; θ &lt; tan θ。
- **一句话点评**：正弦线=PM=sinθ，弧AP=θ，正切线=AT=tanθ。垂线段&lt;圆弧&lt;切线段⟹sinθ&lt;θ&lt;tanθ。面积比较也得同样结论。

**【D7-2-004】** 判断下列各角的三角函数符号：sin(3π/4), cos(7π/6), tan(5π/3), sin(11π/6), cos(2π/3)。用单位圆坐标解释，不要背口诀。

- **难度**：★
- **对应知识点**：象限符号、单位圆坐标
- **解答**：
  - sin(3π/4)：3π/4=135°在第二象限，y坐标>0 ⟹ sin > 0
  - cos(7π/6)：7π/6=210°在第三象限，x坐标&lt;0 ⟹ cos &lt; 0
  - tan(5π/3)：5π/3=300°在第四象限，y&lt;0,x>0 ⟹ tan=y/x &lt; 0
  - sin(11π/6)：11π/6=330°在第四象限，y坐标&lt;0 ⟹ sin &lt; 0
  - cos(2π/3)：2π/3=120°在第二象限，x坐标&lt;0 ⟹ cos &lt; 0
  ∎

  **不用背口诀**：cos的符号=x坐标符号，sin的符号=y坐标符号，tan=sin/cos同号为正异号为负。直接看点在哪个象限、坐标正负即可。
- **一句话点评**：sin符号=y坐标，cos符号=x坐标，tan=y/x同号正异号负。3π/4二象限sin+；7π/6三象限cos-；5π/3四象限tan-；11π/6四象限sin-；2π/3二象限cos-。

## L1 数学分析层

> **引导语**：L1层按"单位圆上的基本性质→诱导公式与恒等式→和角公式与倍角公式→最值与图像"四条线索推进。从有界性到周期性，从诱导公式到和角公式，从最值计算到图像的几何解释，层层递进。核心是单位圆上的投影视角。

### 组A：单位圆上的基本性质

**【D7-2-007】** 用单位圆说明为什么 |sin θ| ≤ 1 和 |cos θ| ≤ 1，而 tan θ 可以取任意实数值。从投影的范围解释有界性和无界性。

- **难度**：★★
- **对应知识点**：值域、有界性、正交投影vs中心投影
- **解答**：
  **sin 和 cos 有界**：
  sin θ 和 cos θ 是单位圆上点的坐标。
  单位圆上所有点的 x 坐标和 y 坐标都在 [-1, 1] 之间（因为 x²+y²=1 ⟹ |x|≤1, |y|≤1）。
  所以 |sin θ| ≤ 1, |cos θ| ≤ 1。
  从投影角度：正交投影将单位圆投影到坐标轴上，投影范围就是 [-1, 1]（单位圆在坐标轴上的投影区间）。

  **tan 无界**：
  tan θ 是从原点到切线 x=1 的中心投影的纵坐标。
  当 θ 从 -π/2 到 π/2 时，射线从接近垂直向下扫到接近垂直向上，与切线 x=1 的交点纵坐标从 -∞ 到 +∞。
  当 θ → π/2⁻ 时，射线接近垂直，与切线 x=1 的交点趋向无穷远（y → +∞）。
  当 θ → -π/2⁺ 时，y → -∞。
  所以 tan θ 可以取任意实数值，无界。∎

  **投影的本质区别**：
  - 正交投影（sin/cos）：投影线平行，将有限的圆投影到有限的区间 [-1,1]——有界
  - 中心投影（tan）：投影线从一点发出，将有限的圆弧投影到无限的直线——无界
  这是平行投影和中心投影的根本区别：平行投影保持有界性，中心投影不保持。

  **sec 和 csc**：
  sec θ = 1/cos θ，因为 |cos θ| ≤ 1，所以 |sec θ| ≥ 1，值域 (-∞,-1]∪[1,+∞)。
  几何上，sec 是从原点到切线投影点的距离，至少为 1（切线到原点的距离=1）。
- **一句话点评**：|sin|,|cos|≤1=单位圆坐标在[-1,1]内，正交投影将圆投影到有限区间。tan无界=中心投影将圆弧投影到无限直线，θ→π/2时交点→∞。平行投影保持有界性，中心投影不保持。sec≥1=原点到切线距离≥1。

**【D7-2-006】** 从几何上解释为什么 sin 和 cos 的周期是 2π，而 tan 的周期是 π。用中心投影的概念说明 tan 的半周期性。

- **难度**：★★
- **对应知识点**：周期性、中心投影、对径点
- **解答**：
  **sin 和 cos 周期 2π**：
  sin θ 和 cos θ 是单位圆上点 P(cosθ, sinθ) 的坐标。
  旋转 2π（一整圈）后，点回到原位，坐标不变。
  所以 sin(θ+2π)=sinθ, cos(θ+2π)=cosθ。
  而且 2π 是最小正周期——旋转任何小于 2π 的角度，点都不会回到原位。

  **tan 周期 π**：
  tan θ = sinθ/cosθ 是从原点到切线 x=1 的中心投影的纵坐标。
  中心投影只关心**射线的方向**，不关心点在射线上的位置。
  角 θ 和角 θ+π 对应的点是对径点（关于原点对称），它们在同一条直线上（方向相反）。
  从原点出发经过这两个点的射线是同一条（只是方向相反，但在同一直线上）。
  所以它们与切线 x=1 的交点相同（或需要反向延长，但交点的纵坐标相同）。
  因此 tan(θ+π) = tan θ。

  更精确地说：tan(θ+π) = sin(θ+π)/cos(θ+π) = (-sinθ)/(-cosθ) = sinθ/cosθ = tanθ。
  π 是最小正周期——旋转 π/2 时 tan 变号（tan(θ+π/2) = -cotθ ≠ tanθ）。∎

  **几何理解**：tan 的半周期性是中心投影的固有性质——中心投影将对径点（相差π）视为同一点（因为它们在同一条射线上）。这就像你站在原点看远处的墙，正前方和正后方的点在墙上的投影是同一个（只是需要转过身看）。sin/cos 是正交投影，对径点的投影坐标相反，所以需要完整的 2π 才回到原位。
- **一句话点评**：sin/cos周期2π=旋转一整圈点回原位。tan周期π=中心投影只关心射线方向，对径点(差π)在同一直线上⟹切线交点相同⟹tan(θ+π)=tanθ。正交投影对径点坐标相反⟹需2π。

### 组B：诱导公式与恒等式

**【D7-2-005】** 用单位圆上的几何变换（反射/旋转）证明诱导公式：sin(π/2 + θ) = cos θ，cos(π/2 + θ) = -sin θ，并说明这对应什么几何变换。

- **难度**：★★
- **对应知识点**：诱导公式、几何变换、旋转
- **解答**：
  角 θ 的终边交单位圆于 P(cos θ, sin θ)。
  角 π/2 + θ 的终边是将 OP 逆时针旋转 π/2（90°）。

  旋转 π/2 的变换矩阵：[0, -1; 1, 0]。
  点 P(cos θ, sin θ) 旋转 π/2 后：
  x' = 0·cos θ + (-1)·sin θ = -sin θ
  y' = 1·cos θ + 0·sin θ = cos θ
  所以旋转后的点 = (-sin θ, cos θ)。

  但这个点也是角 π/2 + θ 对应的单位圆点，其坐标 = (cos(π/2+θ), sin(π/2+θ))。
  比较坐标：
  cos(π/2 + θ) = -sin θ
  sin(π/2 + θ) = cos θ
  ∎

  **几何变换**：这是**逆时针旋转 90°**。旋转后 x 坐标变成原来的 -y，y 坐标变成原来的 x。这就是"加 π/2"的几何本质——不是代数变换，而是旋转。

  **推广**：所有诱导公式都是单位圆上的对称变换：
  - -θ：关于 x 轴反射（x不变，y变号）
  - π-θ：关于 y 轴反射（y不变，x变号）
  - π/2-θ：关于 y=x 反射（x,y互换）
  - θ+π：关于原点中心对称（x,y都变号）
  - θ+π/2：逆时针旋转90°
- **一句话点评**：π/2+θ=将P(cosθ,sinθ)逆时针转90°，旋转矩阵[0,-1;1,0]⟹新点=(-sinθ,cosθ)⟹cos(π/2+θ)=-sinθ,sin(π/2+θ)=cosθ。所有诱导公式=单位圆上的反射/旋转，不用背口诀。

**【D7-2-008】** 证明恒等式 1 + tan²θ = sec²θ 和 1 + cot²θ = csc²θ，并用单位圆上的几何线段解释这两个恒等式。

- **难度**：★★
- **对应知识点**：三角恒等式、单位圆几何、勾股定理
- **解答**：
  **代数证明**：
  1 + tan²θ = 1 + sin²θ/cos²θ = (cos²θ + sin²θ)/cos²θ = 1/cos²θ = sec²θ。
  1 + cot²θ = 1 + cos²θ/sin²θ = (sin²θ + cos²θ)/sin²θ = 1/sin²θ = csc²θ。∎

  **几何解释（1 + tan²θ = sec²θ）**：
  在单位圆上，切线 x=1 上的投影点 T(1, tanθ)。
  直角三角形 OAT 中（O=原点, A=(1,0), T=(1,tanθ)）：
  - OA = 1（邻边，水平）
  - AT = tan θ（对边，垂直）
  - OT = sec θ（斜边，从原点到T的距离）
  由勾股定理：OA² + AT² = OT² ⟹ 1² + tan²θ = sec²θ。
  这就是 1 + tan²θ = sec²θ 的几何来源——它就是直角三角形 OAT 的勾股定理！

  **几何解释（1 + cot²θ = csc²θ）**：
  类似地，切线 y=1 上的投影点 C(cotθ, 1)。
  直角三角形 OBC 中（O=原点, B=(0,1), C=(cotθ,1)）：
  - OB = 1
  - BC = cot θ
  - OC = csc θ
  勾股定理：1² + cot²θ = csc²θ。∎

  **深刻理解**：
  三个基本恒等式（sin²+cos²=1, 1+tan²=sec², 1+cot²=csc²）分别对应单位圆上三个直角三角形的勾股定理：
  - sin²+cos²=1：三角形 OMP（M=P在x轴垂足）
  - 1+tan²=sec²：三角形 OAT（T=切线x=1上投影点）
  - 1+cot²=csc²：三角形 OBC（C=切线y=1上投影点）
  这不是三个独立的公式，而是同一个几何事实（勾股定理）在三个不同三角形中的表现。
- **一句话点评**：1+tan²=sec²=直角三角形OAT的勾股定理（OA=1,AT=tanθ,OT=secθ）。1+cot²=csc²=三角形OBC的勾股定理。三个恒等式=勾股定理在单位圆三个直角三角形中的表现。

### 组C：和角公式与倍角公式

**【D7-2-010】** 用单位圆上的几何方法证明和角公式 sin(α+β) = sinα cosβ + cosα sinβ，并说明这与旋转矩阵的关系。

- **难度**：★★
- **对应知识点**：和角公式、旋转矩阵、单位圆几何
- **解答**：
  **旋转矩阵方法**：
  角 α 的终边对应单位圆上点 P(cosα, sinα)。
  将 OP 再旋转 β，得到角 α+β 的终边，对应点 P'。
  旋转 β 的变换矩阵 R(β) = [cosβ, -sinβ; sinβ, cosβ]。
  P' = R(β) · P = [cosβ, -sinβ; sinβ, cosβ] · [cosα; sinα]
  = [cosα cosβ - sinα sinβ; sinα cosβ + cosα sinβ]。
  但 P' 也是角 α+β 对应的单位圆点，坐标 = (cos(α+β), sin(α+β))。
  比较纵坐标：sin(α+β) = sinα cosβ + cosα sinβ。∎
  比较横坐标：cos(α+β) = cosα cosβ - sinα sinβ。

  **几何理解**：
  和角公式不是代数技巧——它是**旋转的合成**在坐标上的表现。
  先旋转 α，再旋转 β = 旋转 α+β。
  旋转矩阵的乘法 R(α+β) = R(β)·R(α) 展开后就是和角公式。
  这揭示了三角函数的本质：它们是旋转群 SO(2) 的矩阵元素。

  **验证**：
  R(α+β) = [cos(α+β), -sin(α+β); sin(α+β), cos(α+β)]
  R(β)R(α) = [cosβ,-sinβ;sinβ,cosβ][cosα,-sinα;sinα,cosα]
  = [cosαcosβ-sinαsinβ, -cosαsinβ-sinαcosβ; sinαcosβ+cosαsinβ, -sinαsinβ+cosαcosβ]
  比较即得和角公式。
- **一句话点评**：sin(α+β)=旋转β作用于点(cosα,sinα)后的纵坐标。R(β)=[cosβ,-sinβ;sinβ,cosβ]，R(β)·(cosα,sinα)=(cosαcosβ-sinαsinβ,sinαcosβ+cosαsinβ)⟹和角公式。本质=旋转合成R(α+β)=R(β)R(α)。

**【D7-2-009】** 求函数 f(θ) = 2sin θ + 3cos θ 的最大值和最小值，并从几何上解释（提示：写成 R sin(θ+φ) 的形式）。

- **难度**：★★
- **对应知识点**：辅助角公式、最大值最小值、几何解释
- **解答**：
  **代数方法**：
  设 2sin θ + 3cos θ = R sin(θ+φ) = R(sinθ cosφ + cosθ sinφ)。
  比较系数：R cosφ = 2, R sinφ = 3。
  R² = 2² + 3² = 13 ⟹ R = √13。
  tan φ = 3/2 ⟹ φ = arctan(3/2)。
  所以 f(θ) = √13 sin(θ + arctan(3/2))。
  最大值 = √13，最小值 = -√13。∎

  **几何解释**：
  2sin θ + 3cos θ 可以看作向量 (3, 2) 与单位向量 (cos θ, sin θ) 的点积：
  (3, 2) · (cos θ, sin θ) = 3cos θ + 2sin θ。
  点积的几何意义 = |(3,2)| × |(cosθ,sinθ)| × cos(夹角) = √13 × 1 × cos(夹角)。
  当单位向量 (cosθ, sinθ) 与 (3,2) 同向时，点积最大 = √13。
  当反向时，点积最小 = -√13。
  所以最大值 √13 在 θ = arctan(2/3) 时取得（此时 (cosθ,sinθ) 与 (3,2) 同向），最小值 -√13 在 θ = arctan(2/3) + π 时取得。

  **更一般的结论**：
  a sin θ + b cos θ 的最大值 = √(a²+b²)，最小值 = -√(a²+b²)。
  这是因为它是向量 (b,a) 与单位圆上点的点积，点积的最大值就是向量的模长。
- **一句话点评**：2sinθ+3cosθ=√13 sin(θ+φ),φ=arctan(3/2)。最大√13，最小-√13。几何=向量(3,2)·(cosθ,sinθ)=点积，最大=向量模√13（同向时），最小=-√13（反向时）。

**【D7-2-012】** 画出 y = sin x 和 y = cos x 的图像，从单位圆投影的角度解释为什么正弦曲线是"波浪形"，以及 sin 和 cos 图像之间的相位差 π/2 意味着什么。

- **难度**：★★
- **对应知识点**：三角函数图像、单位圆投影、相位差
- **解答**：
  **正弦曲线的波浪形**：
  y = sin x 的图像来自单位圆上点的纵坐标随角度的变化。
  当点 P 在单位圆上逆时针匀速运动时，它的纵坐标（y坐标）在 -1 和 1 之间周期性变化：
  - θ=0: y=0（点在(1,0)）
  - θ=π/2: y=1（点在(0,1)，最高点）
  - θ=π: y=0（点在(-1,0)）
  - θ=3π/2: y=-1（点在(0,-1)，最低点）
  - θ=2π: y=0（回到起点）
  纵坐标的变化不是匀速的——在最高点和最低点附近变化慢（投影压缩），在零点附近变化快（投影展开）。这形成了光滑的波浪形（正弦曲线）。

  **cos 图像**：
  y = cos x 是点的横坐标随角度的变化，形状与 sin 相同，但相位不同。

  **相位差 π/2**：
  cos x = sin(x + π/2)（由诱导公式）。
  这意味着 cos 图像是 sin 图像向左平移 π/2。
  几何上：cos θ 是点 P 的 x 坐标，sin θ 是 y 坐标。
  当点在 (1,0) 时（θ=0），x=1（cos最大），y=0（sin=0）。
  当点转到 (0,1) 时（θ=π/2），x=0（cos=0），y=1（sin最大）。
  所以 cos 的最大值比 sin 早 π/2 出现——cos 图像在 sin 左边 π/2。
  这就是相位差 π/2 的几何来源：x坐标和y坐标在单位圆上相差90°。∎

  **更深刻的理解**：
  sin 和 cos 不是两个独立的函数——它们是同一个圆周运动在两个垂直方向上的投影。
  圆周运动 = 两个垂直方向的简谐运动的合成，相位差 π/2。
  这就是为什么交流电、波动、振动中 sin 和 cos 总是成对出现——它们描述的是同一个旋转运动在不同方向上的投影。
- **一句话点评**：sin曲线=单位圆上点的纵坐标随角度变化，在±1间周期波动，最高点附近变化慢零点附近快⟹波浪形。cos=sin(x+π/2)=向左移π/2，因为x坐标比y坐标早π/2达到最大。sin和cos=同一圆周运动在两垂直方向的投影，相位差π/2。

## L2 复变函数层（★★★ 研究）

**【D7-2-013】** 从复平面的角度说明：单位圆上的点 z = e^{iθ}，其实部和虚部分别是 cos θ 和 sin θ。解释为什么这是单位圆定义在复数域的自然推广，以及正切函数如何对应复平面上的射影变换。

- **难度**：★★★
- **对应知识点**：Euler公式、复平面单位圆、正切与射影变换
- **解答**：
  **单位圆与复指数**：
  复平面上，单位圆 = {z ∈ ℂ | |z| = 1}。
  由 Euler 公式，e^{iθ} = cos θ + i sin θ，|e^{iθ}| = √(cos²θ+sin²θ) = 1。
  所以 e^{iθ} 在单位圆上，其实部 Re(e^{iθ}) = cos θ，虚部 Im(e^{iθ}) = sin θ。
  这正是单位圆定义在复数域的表达：单位圆上的点 = (cosθ, sinθ) = cosθ + i sinθ = e^{iθ}。

  **自然推广**：
  实数域中，单位圆上的点用坐标 (cosθ, sinθ) 表示。
  复数域中，这个点就是复数 cosθ + i sinθ = e^{iθ}。
  复数乘法 e^{iα} · e^{iβ} = e^{i(α+β)} 对应旋转的合成——这比实数域中的旋转矩阵更简洁。
  所以复指数是单位圆定义的"代数化"——将几何旋转变成了指数乘法。

  **正切与射影变换**：
  tan θ = sinθ/cosθ = Im(e^{iθ})/Re(e^{iθ})。
  在复平面上，tan θ 可以表示为：
  tan θ = (e^{iθ} - e^{-iθ}) / [i(e^{iθ} + e^{-iθ})]
  令 w = e^{iθ}，则 tan θ = (w - w^{-1}) / [i(w + w^{-1})] = (w² - 1) / [i(w² + 1)]。
  这是一个从 w（单位圆）到 tanθ（实数轴）的映射。

  更深刻地，正切的加法公式：
  tan(α+β) = (tanα + tanβ)/(1 - tanα tanβ)
  令 t = tan θ，则旋转 β 对应 t ↦ (t + tanβ)/(1 - t tanβ)，这是一个 Möbius 变换（分式线性变换）。
  Möbius 变换是复平面上的射影变换，保持交比和圆/直线。
  所以正切函数将单位圆上的旋转（角度加法）转化为实数轴上的 Möbius 变换——这是射影几何在复分析中的体现。∎

  **几何理解**：复平面将单位圆上的点"打包"成一个复数 e^{iθ}，旋转变成乘法。正切函数是从单位圆到实数轴的透视投影，旋转的合成变成了 Möbius 变换的复合——三角函数与射影几何在复平面上统一了。
- **一句话点评**：单位圆点z=e^{iθ}=cosθ+isinθ，Re=cos,Im=sin。复指数将旋转变成乘法e^{iα}e^{iβ}=e^{i(α+β)}。tanθ=(w²-1)/[i(w²+1)],w=e^{iθ}。正切加法公式=t↦(t+tanβ)/(1-ttanβ)=Möbius变换=射影变换。旋转合成→Möbius复合。

**【D7-2-014】** 说明反三角函数 arctan x 如何将实数轴 ℝ 紧致化为单位圆（射影直线 ℝℙ¹），并解释为什么 arctan(+∞) = π/2 和 arctan(-∞) = -π/2 在射影几何中是同一个点。

- **难度**：★★★
- **对应知识点**：arctan、紧致化、射影直线、无穷远点
- **解答**：
  **arctan 作为紧致化**：
  arctan: ℝ → (-π/2, π/2) 是正切函数 tan: (-π/2, π/2) → ℝ 的反函数。
  从几何上看：
  - tan θ 将开区间 (-π/2, π/2)（单位圆的右半部分，去掉端点）映射为整个实数轴 ℝ
  - 这是从单位圆（紧致）去掉两个点 (±π/2) 后到实数轴（非紧致）的映射
  - arctan 反向将实数轴"弯曲"成圆的一段

  **紧致化的具体实现**：
  实数轴 ℝ 加上一个"无穷远点" ∞ 得到射影直线 ℝℙ¹，它拓扑上等价于圆 S¹。
  arctan 给出了这个紧致化的坐标：
  - x ∈ ℝ ↔ θ = arctan x ∈ (-π/2, π/2)
  - x → +∞ ↔ θ → π/2⁻
  - x → -∞ ↔ θ → -π/2⁺
  在射影直线上，+∞ 和 -∞ 是同一个点（无穷远点），对应 θ = π/2 = -π/2（在圆上这两个端点重合）。
  所以 arctan(+∞) = π/2 和 arctan(-∞) = -π/2 在射影几何中表示同一个无穷远点。

  **与中心投影的关系**：
  tan θ 是从原点到切线 x=1 的中心投影。
  中心投影将单位圆（去掉投影中心点的对径点）映射为切线（实数轴）。
  当 θ → π/2 时，射线接近垂直，与切线的交点趋向无穷远——这就是"无穷远点"的几何来源。
  在射影几何中，平行线相交于无穷远点，而垂直方向的射线与切线 x=1 平行（不相交），所以对应无穷远点。

  **拓扑学视角**：
  ℝ 的一点紧致化（Alexandroff 紧致化）= ℝ ∪ {∞} ≅ S¹。
  arctan 给出了这个同胚的具体构造：
  f: ℝ ∪ {∞} → S¹, f(x) = e^{2i arctan x}（将 (-π/2,π/2) 映射到右半圆，∞ 映射到 (-1,0)）。
  这是一个同胚，证明了 ℝ ∪ {∞} ≅ S¹。∎

  **几何理解**：arctan 把"直的"实数轴弯成"圆的一段"，两端在无穷远处相接成完整的圆。+∞ 和 -∞ 不是两个方向，而是圆上的同一个点——就像你沿着直线一直走，最终会从另一边回来（在射影几何中）。这就是射影直线的紧致化，也是正切函数作为中心投影的深刻性质。
- **一句话点评**：arctan:ℝ→(-π/2,π/2)将实数轴弯成圆的一段。ℝ加无穷远点∞=射影直线ℝℙ¹≅S¹。x→±∞对应θ→±π/2，在圆上两端重合=同一个无穷远点。中心投影中θ→π/2时射线与切线平行⟹交点→∞=射影几何中平行线交于无穷远点。f(x)=e^{2iarctanx}给出ℝ∪{∞}≅S¹的同胚。

## L3 实变函数层（★★★ 研究）

**【D7-2-015】** 从测度论的角度讨论：单位圆上的正交投影（sin/cos）将圆周上的均匀测度映射为什么分布？中心投影（tan）又将其映射为什么分布？计算这两种分布的概率密度函数。

- **难度**：★★★
- **对应知识点**：投影测度、均匀分布、arcsine分布、Cauchy分布、变量替换
- **解答**：
  **正交投影的分布（arcsine 分布）**：
  设 Θ 在 [0, 2π) 上均匀分布，密度 f_Θ(θ) = 1/(2π)。
  令 X = cos Θ（正交投影到 x 轴）。
  X 的值域 [-1, 1]。对 x ∈ (-1,1)，cos θ = x 有两个解 θ = arccos x 和 θ = 2π - arccos x。
  用变量替换公式：
  f_X(x) = ∑ f_Θ(θ_i) / |d(cos θ)/dθ|_{θ=θ_i}
  = 2 × (1/(2π)) / |-sin(arccos x)|
  = (1/π) / √(1-x²)
  所以 X = cos Θ 服从 **arcsine 分布**，密度 f_X(x) = 1/(π√(1-x²)), x ∈ (-1,1)。

  这个分布在 x=±1 附近密度趋向无穷（投影压缩），在 x=0 附近密度最小（投影展开）——这正是正交投影的几何性质：端点附近投影变化慢，点被"压缩"到端点附近。

  **中心投影的分布（Cauchy 分布）**：
  令 Y = tan Θ，其中 Θ 在 (-π/2, π/2) 上均匀分布（密度 1/π）。
  对 y ∈ ℝ，tan θ = y 有唯一解 θ = arctan y。
  d(tan θ)/dθ = sec²θ = 1 + tan²θ = 1 + y²。
  f_Y(y) = f_Θ(arctan y) / |d(tanθ)/dθ|
  = (1/π) / (1 + y²)
  所以 Y = tan Θ 服从 **标准 Cauchy 分布**，密度 f_Y(y) = 1/[π(1+y²)]。

  Cauchy 分布是重尾分布（尾部 ~ 1/y²），没有有限的均值和方差——这反映了中心投影将均匀的角度映射为高度不均匀的实数分布，大部分值集中在 0 附近，但有很重的尾部（接近 π/2 时值急剧增大）。

  **对比**：
  | 投影类型 | 映射 | 分布 | 密度 | 尾部 |
  |---|---|---|---|---|
  | 正交投影 | cos Θ | arcsine | 1/(π√(1-x²)) | 有界[-1,1] |
  | 中心投影 | tan Θ | Cauchy | 1/[π(1+y²)] | 重尾，无界 |

  这两种分布的差异本质上是平行投影和中心投影的差异在测度论中的体现。∎

  **几何理解**：均匀分布的角度经过正交投影后变成 arcsine 分布（端点密集、中间稀疏），经过中心投影后变成 Cauchy 分布（0附近密集、重尾）。投影不仅改变了几何形状，也改变了测度分布——这是投影的测度论本质。
- **一句话点评**：Θ均匀⟹X=cosΘ服从arcsine分布，密度1/(π√(1-x²))（端点附近密度→∞=投影压缩）。Y=tanΘ服从Cauchy分布，密度1/[π(1+y²)]（重尾无均值=中心投影非线性）。平行投影→有界arcsine，中心投影→无界Cauchy。

**【D7-2-033】** 用投影定义三角函数：$\cos\theta$ 是单位圆上点的横坐标（$x$ 轴投影），$\sin\theta$ 是纵坐标（$y$ 轴投影）。

这个定义把三角函数与几何投影直接联系起来。∎
- **点评**：投影定义是三角函数的几何本质——$\cos$ 和 $\sin$ 就是单位圆上点的坐标，即两个正交方向上的投影。

**【D7-2-034】** 求特殊角的三角函数值：$\sin\frac{\pi}{6},\cos\frac{\pi}{6},\sin\frac{\pi}{4},\cos\frac{\pi}{4},\sin\frac{\pi}{3},\cos\frac{\pi}{3}$。

- $\theta=\frac{\pi}{6}$（30°）：直角三角形 30-60-90，对边:邻边:斜边 = $1:\sqrt{3}:2$。$\sin\frac{\pi}{6}=\frac{1}{2}$，$\cos\frac{\pi}{6}=\frac{\sqrt{3}}{2}$。
- $\theta=\frac{\pi}{4}$（45°）：等腰直角三角形，边比 $1:1:\sqrt{2}$。$\sin\frac{\pi}{4}=\cos\frac{\pi}{4}=\frac{\sqrt{2}}{2}$。
- $\theta=\frac{\pi}{3}$（60°）：$\sin\frac{\pi}{3}=\frac{\sqrt{3}}{2}$，$\cos\frac{\pi}{3}=\frac{1}{2}$。
注意 $\sin\frac{\pi}{6}=\cos\frac{\pi}{3}=\frac{1}{2}$（互余角的诱导公式）。∎
- **点评**：特殊角的三角函数值来自特殊直角三角形的边长比——这是三角函数"边长比"定义的直接应用。

**【D7-2-035】** 证明：$\sin x$ 在 $[-\frac{\pi}{2},\frac{\pi}{2}]$ 上严格递增，$\cos x$ 在 $[0,\pi]$ 上严格递减。

- **难度**：★★
- **解答**：几何证明：在单位圆上，$x$ 从 $-\frac{\pi}{2}$ 到 $\frac{\pi}{2}$ 时，点从 $(0,-1)$ 经 $(1,0)$ 到 $(0,1)$，纵坐标 $y=\sin x$ 从 $-1$ 单调递增到 $1$。
$x$ 从 $0$ 到 $\pi$ 时，点从 $(1,0)$ 经 $(0,1)$ 到 $(-1,0)$，横坐标 $x=\cos x$ 从 $1$ 单调递减到 $-1$。
分析证明：$(\sin x)'=\cos x>0$ 在 $(-\frac{\pi}{2},\frac{\pi}{2})$ 上，故严格递增。$(\cos x)'=-\sin x<0$ 在 $(0,\pi)$ 上，故严格递减。∎
- **点评**：三角函数的单调性可以从单位圆上的运动直接看出——这是几何视角的优势。单调性保证了反三角函数的存在性。

**【D7-2-036】** 叙述三角函数线：在单位圆中，$\sin\theta$ = 正弦线（有向线段 $MP$），$\cos\theta$ = 余弦线（有向线段 $OM$），$\tan\theta$ = 正切线（有向线段 $AT$）。

- **难度**：★★
- **解答**：设单位圆与 $x$ 轴正半轴交于 $A(1,0)$，角 $\theta$ 终边交圆于 $P$，$P$ 在 $x$ 轴上的垂足为 $M$，过 $A$ 的切线交终边（或延长线）于 $T$。
- 正弦线：$MP$（有向线段，向上为正），长度 = $\sin\theta$。
- 余弦线：$OM$（有向线段，向右为正），长度 = $\cos\theta$。
- 正切线：$AT$（有向线段，向上为正），长度 = $\tan\theta$（由相似三角形 $\triangle OMP\sim\triangle OAT$）。
三角函数线把三角函数值可视化为线段长度，是几何理解的重要工具。∎
- **点评**：三角函数线是三角函数的几何表示——每个三角函数值对应单位圆中的一条有向线段。这是古代数学家研究三角函数的基本方法。

### L2 复变函数基础

**【D7-2-037】** 证明：映射 $w=e^z$ 把水平直线 $\text{Im}(z)=y_0$ 映为射线 $\arg w=y_0$，把竖直直线 $\text{Re}(z)=x_0$ 映为圆 $|w|=e^{x_0}$。

- **难度**：★★
- **解答**：$z=x+iy$，$e^z=e^x e^{iy}$。
水平直线 $y=y_0$：$w=e^x e^{iy_0}$，$x\in\mathbb{R}$，$|w|=e^x\in(0,\infty)$，$\arg w=y_0$。故映为从原点出发的射线（不含原点）。
竖直直线 $x=x_0$：$w=e^{x_0}e^{iy}$，$y\in\mathbb{R}$，$|w|=e^{x_0}$，$\arg w=y$ 遍历所有角度。故映为以原点为心、半径 $e^{x_0}$ 的圆。
$e^z$ 是共形映射，把直角坐标网格映为极坐标网格（射线和同心圆）。∎
- **点评**：指数函数的几何意义——它是直角坐标到极坐标的转换。这是欧拉公式 $e^{iy}=\cos y+i\sin y$ 的直接推论。

**【D7-2-038】** 证明：$\sin z$ 把实轴映为实轴上的 $[-1,1]$，把虚轴映为虚轴（无界）。

- **难度**：★★
- **解答**：实轴 $z=x$：$\sin x\in[-1,1]$（实三角函数的值域）。
虚轴 $z=iy$：$\sin(iy)=\frac{e^{i(iy)}-e^{-i(iy)}}{2i}=\frac{e^{-y}-e^y}{2i}=i\frac{e^y-e^{-y}}{2}=i\sinh y$。
$\sinh y\in\mathbb{R}$ 且无界（$y\to\infty$ 时 $\sinh y\to\infty$），故 $\sin(iy)$ 遍历整个虚轴。
这说明复三角函数的值域是整个复平面（与实三角函数不同，实 $\sin$ 的值域是 $[-1,1]$）。∎
- **点评**：复三角函数在虚轴方向上无界——这是复分析与实分析的重要区别。$\sin z$ 把虚轴映为虚轴，把实轴映为有界区间，体现了复函数的"双曲"行为。

**【D7-2-039】** 叙述 Joukowski 映射 $w=\frac{1}{2}(z+\frac{1}{z})$ 的几何意义：它把单位圆映为线段 $[-1,1]$。

- **难度**：★★
- **解答**：在单位圆 $|z|=1$ 上，$z=e^{i\theta}$，$\frac{1}{z}=e^{-i\theta}$。
$w=\frac{1}{2}(e^{i\theta}+e^{-i\theta})=\cos\theta\in[-1,1]$。
故单位圆被映为实轴上的线段 $[-1,1]$（二对一映射，$z$ 和 $1/z$ 映为同一点）。
Joukowski 映射是共形映射的重要例子，在空气动力学中有应用（翼型变换）。
它与三角函数的关系：$w=\cos\theta$ 当 $z=e^{i\theta}$，即 Joukowski 映射在单位圆上就是余弦函数。∎
- **点评**：Joukowski 映射把单位圆"压扁"成线段——这是余弦函数的几何本质。它说明 $\cos\theta$ 就是单位圆上点在 Joukowski 映射下的像。

### L3 实变函数基础

**【D7-2-040】** 证明：周期函数的积分在一个周期上的值与起点无关：若 $f$ 周期为 $T$，则 $\int_a^{a+T}f(x)dx=\int_0^T f(x)dx$。

- **难度**：★★
- **解答**：$\int_a^{a+T}f(x)dx=\int_a^0 f(x)dx+\int_0^T f(x)dx+\int_T^{a+T}f(x)dx$。
对第三项做变量替换 $x=t+T$：$\int_T^{a+T}f(x)dx=\int_0^a f(t+T)dt=\int_0^a f(t)dt=-\int_a^0 f(t)dt$。
第一项和第三项抵消，剩下 $\int_0^T f(x)dx$。∎
- **点评**：周期函数的积分平移不变性——这是周期函数的基本性质，在 Fourier 分析中经常使用（积分区间可以取任意一个周期）。

**【D7-2-041】** 证明：$\sin x$ 的平移不变性：$\int_0^{2\pi}f(x+a)\sin(nx)dx$ 与 $a$ 的关系（Fourier 系数的平移性质）。

- **难度**：★★
- **解答**：设 $g(x)=f(x+a)$（平移）。
$g$ 的 Fourier 系数 $\hat{g}(n)=\frac{1}{2\pi}\int_0^{2\pi}f(x+a)e^{-inx}dx$。
令 $t=x+a$：$=\frac{1}{2\pi}\int_a^{a+2\pi}f(t)e^{-in(t-a)}dt=e^{ina}\frac{1}{2\pi}\int_a^{a+2\pi}f(t)e^{-int}dt=e^{ina}\hat{f}(n)$。
平移使 Fourier 系数乘以相位因子 $e^{ina}$，模不变。
对 $\sin(nx)$ 分量：平移 $a$ 后，$\sin(n(x-a))=\sin(nx-na)=\sin(nx)\cos(na)-\cos(nx)\sin(na)$。∎
- **点评**：Fourier 系数的平移性质——时域平移对应频域相位调制，幅度谱不变。这是信号处理中的基本原理。

**【D7-2-042】** 叙述 Weyl 等分布定理：若 $\alpha$ 是无理数，则序列 $\{n\alpha\bmod 1\}$ 在 $[0,1]$ 上等分布。

- **难度**：★★
- **解答**：Weyl 等分布定理：$\alpha$ 无理 ⟹ 对任何区间 $[a,b]\subset[0,1]$，$\lim_{N\to\infty}\frac{1}{N}\#\{n\leq N:\{n\alpha\}\in[a,b]\}=b-a$。
等价刻画（Weyl 判据）：$\{n\alpha\}$ 等分布 ⟺ 对所有非零整数 $k$，$\frac{1}{N}\sum_{n=1}^N e^{2\pi ikn\alpha}\to0$。
$\frac{1}{N}\sum_{n=1}^N e^{2\pi ikn\alpha}=\frac{1}{N}\cdot\frac{e^{2\pi ik\alpha}(1-e^{2\pi ikN\alpha})}{1-e^{2\pi ik\alpha}}\to0$（因为 $\alpha$ 无理，分母非零，分子有界）。
几何意义：无理数旋转在单位圆上是"均匀"的——点不会聚集在任何区域。∎
- **点评**：Weyl 等分布定理是遍历理论的基础结果——无理数旋转是唯一遍历的。它把三角函数（指数函数）与数论（无理数）深刻联系起来。

### 经典名题

**【D7-2-CROSS-016】**（D7 × D5 级数 × D8 解析）**从单位圆上的几何构造推导反正切级数 arctan x = x - x³/3 + x⁵/5 - ...，并用它计算 π（至少两种方法）。说明这个级数如何连接了几何（单位圆切线）、分析（级数）和数论（π的无理性）。**

- **难度**：★★★
- **对应知识点**：arctan级数、π的计算、几何到级数、积分
- **解答**：
  **arctan 级数推导**：
  方法一（几何级数积分）：
  1/(1+t²) = 1 - t² + t⁴ - t⁶ + ...（|t|&lt;1，几何级数）。
  两边从 0 到 x 积分：
  arctan x = ∫₀ˣ 1/(1+t²) dt = x - x³/3 + x⁵/5 - x⁷/7 + ...
  收敛域 |x| ≤ 1（端点 x=1 由交错级数判别法收敛）。

  方法二（Taylor 展开）：
  f(x) = arctan x，f'(x) = 1/(1+x²)，f''(x) = -2x/(1+x²)²，...
  在 x=0 处展开得到同样的级数。

  **计算 π 的方法**：
  方法一（Leibniz 公式）：
  令 x=1：arctan 1 = π/4 = 1 - 1/3 + 1/5 - 1/7 + ...
  所以 π = 4(1 - 1/3 + 1/5 - 1/7 + ...)。
  但收敛极慢（交错级数，第n项~1/n，需10^n项得n位精度）。

  方法二（Machin 公式）：
  π/4 = 4 arctan(1/5) - arctan(1/239)。
  代入级数：
  arctan(1/5) = 1/5 - 1/(3·5³) + 1/(5·5⁵) - ...
  arctan(1/239) = 1/239 - 1/(3·239³) + ...
  因为 (1/5)^n 和 (1/239)^n 快速衰减，只需几项就得高精度 π。

  **几何-分析-数论的连接**：
  - **几何**：arctan x 是单位圆上切线 x=1 处纵坐标为 x 的点对应的角度——它是中心投影的逆映射。
  - **分析**：arctan x 的导数 1/(1+x²) 有简单的几何级数展开，积分后得到 arctan 级数。
  - **数论**：π 是无理数（甚至超越数），arctan 级数提供了计算 π 的分析方法，而 π 的无理性证明（Lambert, 1761）也使用了 arctan 和 tan 的连分数展开。

  **几何理解**：arctan x 回答的是"切线墙上高度为 x 的点，对应多少角度"。这个几何问题的答案是一个无穷级数——几何与分析通过积分联系起来。π 的计算从"测量圆周长"（几何）演变为"求和级数"（分析），这是分析学战胜几何学的典范。∎
- **一句话点评**：arctanx=∫₀ˣ1/(1+t²)dt=∫₀ˣ(1-t²+t⁴-...)dt=x-x³/3+x⁵/5-...。π计算：①Leibniz:π=4(1-1/3+1/5-...)收敛慢；②Machin:π/4=4arctan(1/5)-arctan(1/239)收敛快。几何=中心投影逆映射，分析=几何级数积分，数论=π无理性。

**【D7-2-CROSS-017】**（D7 × D6 完备性 × D1 极限）**用单位圆上的投影证明 Bolzano-Weierstrass 定理的一个特例：有界数列必有收敛子列。具体地，设 {x_n} ⊂ [-1,1]，证明存在子列收敛。将每个 x_n 看作单位圆上点的余弦投影，利用圆周的紧致性。**

- **难度**：★★★
- **对应知识点**：Bolzano-Weierstrass、单位圆紧致性、投影、子列
- **解答**：
  **证明思路**：
  设 {x_n} ⊂ [-1,1] 是有界数列。
  对每个 x_n，取 θ_n = arccos x_n ∈ [0, π]（单位圆上半部分对应的角度）。
  则 x_n = cos θ_n，即 x_n 是单位圆上点 P_n = (cos θ_n, sin θ_n) 的 x 坐标（正交投影）。

  **利用圆周紧致性**：
  {θ_n} ⊂ [0, π] 是有界数列。
  由区间 [0, π] 的紧致性（Heine-Borel：闭区间紧致），{θ_n} 有收敛子列 {θ_{n_k}}，设 θ_{n_k} → θ* ∈ [0, π]。

  **投影的连续性**：
  cos 函数是连续的（单位圆上点的连续运动）。
  所以 x_{n_k} = cos θ_{n_k} → cos θ*。
  即 {x_n} 有收敛子列 {x_{n_k}}。∎

  **更一般的 Bolzano-Weierstrass**：
  对 ℝ^d 中的有界数列，可以类似地利用球面或立方体的紧致性。
  单位圆 S¹ 是紧致的（闭且有界），所以 S¹ 上的任何点列有收敛子列。
  正交投影是连续映射，连续映射保持紧致性（紧致集的连续像紧致），也保持序列收敛性。

  **几何理解**：
  有界数列 {x_n} ⊂ [-1,1] 可以"提升"到单位圆上的点列 {P_n}。
  单位圆是紧致的（闭合的环，没有"漏洞"），所以点列必有聚点——就像在一个环形跑道上跑，无限多个点必有地方聚集。
  聚点投影回 x 轴，就得到原数列的收敛子列。
  紧致性是完备性的几何表现——单位圆没有"洞"，所以点不会"跑掉"。

  **与实数完备性的关系**：
  这个证明本质上利用了 [0,π] 的紧致性，而 [0,π] 的紧致性等价于实数的完备性（确界原理、单调有界定理、区间套定理等）。
  所以 Bolzano-Weierstrass 定理是实数完备性的推论，单位圆的紧致性是实数完备性在几何中的体现。∎
- **一句话点评**：x_n∈[-1,1]⟹提升到单位圆点P_n=(cosθ_n,sinθ_n),θ_n=arccosx_n。[0,π]紧致⟹θ_n有收敛子列θ_{n_k}→θ*。cos连续⟹x_{n_k}=cosθ_{n_k}→cosθ*。单位圆紧致=闭且有界，连续投影保持收敛。紧致性=完备性的几何表现。

### 反例与构造

**【D7-2-CROSS-018】**（D7 × D2 连续 × D6 完备性）**构造一个函数 f: ℝ → ℝ，使得 f(x) = sin(1/x)（x≠0），f(0)=0。用单位圆上的投影解释为什么这个函数在 x=0 处不连续，并讨论它的图像如何体现了"正交投影的振荡"。**

- **难度**：★★★
- **对应知识点**：sin(1/x)、不连续性、振荡、单位圆投影
- **解答**：
  **函数定义**：
  f(x) = sin(1/x) for x ≠ 0, f(0) = 0。

  **在 x=0 处不连续**：
  取 x_n = 1/(2nπ + π/2)，则 1/x_n = 2nπ + π/2，f(x_n) = sin(2nπ + π/2) = 1。
  x_n → 0 但 f(x_n) → 1 ≠ 0 = f(0)。
  再取 y_n = 1/(2nπ)，则 f(y_n) = sin(2nπ) = 0 → 0。
  取 z_n = 1/(2nπ + 3π/2)，则 f(z_n) = -1 → -1。
  所以当 x→0 时，f(x) 在 -1 和 1 之间无限振荡，没有极限——不连续。∎

  **单位圆投影的解释**：
  sin(1/x) 可以看作：当 x→0 时，角度 θ = 1/x → ∞，单位圆上的点 P(θ) = (cos θ, sin θ) 以越来越快的速度绕圆旋转。
  f(x) = sin(1/x) 是这个快速旋转点的 y 坐标（正交投影）。
  当 x→0 时，旋转速度 1/x² → ∞，点在圆上飞速旋转，y 坐标在 -1 和 1 之间无限振荡，没有确定的极限。
  这就像一个转速越来越快的陀螺，你无法确定它在 t→∞ 时指向哪个方向。

  **图像特征**：
  sin(1/x) 的图像在 x=0 附近无限密集地振荡，振幅恒为 1（因为 |sin|≤1），频率趋向无穷。
  图像被"压缩"在 x=0 附近的狭窄区域内，但 y 值始终在 [-1,1]——这是正交投影有界性的体现。
  无论 x 多接近 0，f(x) 都能取到 [-1,1] 中的任何值（因为角度覆盖了所有方向）。

  **拓扑学意义**：
  sin(1/x) 的图像（拓扑学家的正弦曲线）是连通但不道路连通的经典例子。
  图像 ∪ {(0,y) | y∈[-1,1]} 是连通的，但从 (0,0) 无法通过图像中的连续路径到达其他点。
  这体现了正交投影的"病态"行为——连续函数的复合可以产生复杂的拓扑性质。∎

  **几何理解**：sin(1/x) = 单位圆上以角速度 1/x 旋转的点的 y 坐标。x→0 时转速→∞，点在圆上飞速转圈，投影无限振荡无极限。这是"正交投影+无限旋转"产生的经典反例，也是拓扑学家正弦曲线的来源。
- **一句话点评**：f(x)=sin(1/x),f(0)=0。x_n=1/(2nπ+π/2)→0但f(x_n)=1→1≠0⟹不连续。几何=θ=1/x→∞时单位圆点飞速旋转，y坐标在[-1,1]无限振荡。图像=拓扑学家正弦曲线，连通但不道路连通。正交投影有界但频率→∞。

### 定理串联

**【D7-2-CROSS-019】**（D7 × D8 解析 × D5 级数）**从单位圆上的中心投影出发，建立"正切加法公式 = Möbius 变换 = 射影变换"的完整链条，并说明这如何统一了三角函数、复分析和射影几何三个领域。**

- **难度**：★★★
- **对应知识点**：正切加法公式、Möbius变换、射影变换、三领域统一
- **解答**：
  **第一步：正切加法公式**：
  tan(α+β) = (tanα + tanβ)/(1 - tanα tanβ)。
  这是三角函数的基本公式，可以通过 sin/cos 的和角公式推导。

  **第二步：正切加法公式 = Möbius 变换**：
  令 t = tan θ，固定 β，定义变换 T_β(t) = tan(θ+β) = (t + tanβ)/(1 - t tanβ)。
  这是一个 Möbius 变换（分式线性变换）：T(t) = (at+b)/(ct+d)，其中 a=1, b=tanβ, c=-tanβ, d=1。
  矩阵表示：M_β = [[1, tanβ], [-tanβ, 1]]。

  **第三步：Möbius 变换 = 射影变换**：
  Möbius 变换是射影直线 ℝℙ¹（或 ℂℙ¹）上的射影变换。
  射影变换保持交比（cross ratio）：(T(a),T(b);T(c),T(d)) = (a,b;c,d)。
  验证：T_β 是可逆的（行列式 = 1+tan²β = sec²β ≠ 0），所以是射影变换。

  **第四步：旋转群的表示**：
  旋转 β 对应 Möbius 变换 T_β。
  旋转的合成对应 Möbius 变换的复合：T_{β₁} ∘ T_{β₂} = T_{β₁+β₂}。
  验证矩阵乘法：
  M_{β₁}M_{β₂} = [[1,tanβ₁],[-tanβ₁,1]][[1,tanβ₂],[-tanβ₂,1]]
  = [[1-tanβ₁tanβ₂, tanβ₁+tanβ₂], [-(tanβ₁+tanβ₂), 1-tanβ₁tanβ₂]]
  = (1-tanβ₁tanβ₂) [[1, (tanβ₁+tanβ₂)/(1-tanβ₁tanβ₂)], [-(tanβ₁+tanβ₂)/(1-tanβ₁tanβ₂), 1]]
  = (1-tanβ₁tanβ₂) M_{β₁+β₂}
  （Möbius 变换的矩阵差一个常数因子表示同一个变换）

  **三领域统一**：
  | 领域 | 对象 | 运算 |
  |---|---|---|
  | 三角函数 | 角度 θ | 加法 θ+β |
  | 复分析 | 复数 t=tanθ | Möbius 变换 T_β(t) |
  | 射影几何 | 射影直线上的点 | 射影变换（保持交比） |

  正切函数 tan: (-π/2,π/2) → ℝ 是这三个领域之间的"翻译器"：
  - 它将角度加法（旋转群 SO(2)）翻译为 Möbius 变换群 PSL(2,ℝ)
  - 它将单位圆（紧致）翻译为实数轴加无穷远点（射影直线）
  - 它将几何旋转翻译为代数变换

  **更深刻的联系**：
  SO(2) ≅ U(1) ≅ S¹（旋转群/单位圆/模1复数）
  PSL(2,ℝ) 是双曲平面的等距变换群，其边界（射影直线）上的作用就是 Möbius 变换。
  SO(2) 是 PSL(2,ℝ) 的子群（椭圆元素），正切函数给出了这个子群在边界上的作用。∎

  **几何理解**：正切函数是一座桥——它把"圆上的旋转"（几何）翻译成"直线上的分式线性变换"（代数），而分式线性变换正是射影几何的基本变换。三个领域（三角/复分析/射影几何）通过正切函数统一在同一个数学结构下：旋转群在射影直线上的表示。
- **一句话点评**：tan(α+β)=(tanα+tanβ)/(1-tanαtanβ)。令t=tanθ⟹旋转β对应T_β(t)=(t+tanβ)/(1-ttanβ)=Möbius变换=射影变换（保持交比）。旋转合成=T复合。三领域统一：角度加法(SO(2))→Möbius变换(PSL(2,ℝ))→射影变换(ℝℙ¹)。tan是翻译器。

**【D7-2-CROSS-020】**（D7 × D3 微分 × D4 积分）**用单位圆上的几何解释为什么 (arctan x)' = 1/(1+x²)，并利用这个结果计算 ∫₀¹ 1/(1+x²) dx。从中心投影的逆映射角度理解这个导数公式。**

- **难度**：★★
- **对应知识点**：arctan导数、积分、中心投影逆映射
- **解答**：
  **导数的几何推导**：
  y = arctan x 表示切线 x=1 上纵坐标为 x 的点 T(1,x) 对应的角度 θ。
  即 tan θ = x，θ = arctan x。
  当 x 增加微小量 dx 时，T 沿切线向上移动 dx，对应的角度增加 dθ。

  从几何上看，三角形 OPT（O=原点, P=单位圆上点, T=(1,x)）中：
  OT = √(1+x²)（视线长度）。
  T 移动 dx 时，角度变化 dθ 满足：弧长 = r·dθ，这里的"半径"是 OT = √(1+x²)，但移动方向垂直于 OT 的分量是 dx/√(1+x²)（因为切线方向与 OT 的夹角的余弦 = 1/√(1+x²)）。
  所以 dθ = (垂直分量)/OT = (dx/√(1+x²))/√(1+x²) = dx/(1+x²)。
  因此 dθ/dx = 1/(1+x²)，即 (arctan x)' = 1/(1+x²)。∎

  **代数验证**：
  y = arctan x ⟺ tan y = x。
  两边对 x 求导：sec²y · y' = 1 ⟹ y' = 1/sec²y = 1/(1+tan²y) = 1/(1+x²)。

  **积分计算**：
  ∫₀¹ 1/(1+x²) dx = [arctan x]₀¹ = arctan 1 - arctan 0 = π/4 - 0 = π/4。
  这也给出了 π/4 的积分表示。

  **中心投影逆映射的理解**：
  arctan 是中心投影 tan: (-π/2,π/2) → ℝ 的逆映射。
  中心投影将角度 θ 映射为切线纵坐标 x=tanθ。
  逆映射 arctan 将 x 映射回角度 θ。
  导数 1/(1+x²) 描述了"切线墙上移动单位距离，对应多少角度变化"。
  当 x=0 时，导数=1（切线墙底部，角度变化≈距离变化）。
  当 x→∞ 时，导数→0（切线墙高处，移动很大距离只对应很小的角度变化——因为视线接近水平，微小角度变化对应很大的切线位移）。
  这正是中心投影的非线性：同样的角度增量，在接近 π/2 时对应巨大的切线增量（伸长拉缩）。∎

  **几何理解**：(arctanx)'=1/(1+x²)说的是"切线墙上走dx，角度转dθ=dx/(1+x²)"。x大时dθ很小（高处移动大距离只转小角度），x小时dθ≈dx（底部近似线性）。这是中心投影非线性的逆映射表现——伸长拉缩的反方向。
- **一句话点评**：y=arctanx⟺tany=x，求导sec²y·y'=1⟹y'=1/(1+x²)。几何=T(1,x)移动dx时角度变化dθ=dx/(1+x²)（视线长√(1+x²)，垂直分量dx/√(1+x²)）。∫₀¹1/(1+x²)dx=π/4。x大时导数→0=高处移动大距离只转小角度=中心投影非线性。

**【D7-2-CROSS-021】**（D7 × D4 积分 × D6 完备性）**用变量替换 x = tan θ 计算积分 ∫₀^∞ 1/(1+x²) dx，并从几何上解释这个变量替换——它如何将"无限区间上的积分"转化为"有限角度上的积分"，这与实数轴的紧致化有什么关系。**

- **难度**：★★★
- **对应知识点**：变量替换、无穷积分、紧致化、tan替换
- **解答**：
  **积分计算**：
  ∫₀^∞ 1/(1+x²) dx。
  令 x = tan θ，则 dx = sec²θ dθ = (1+tan²θ)dθ = (1+x²)dθ。
  当 x=0 时，θ=0；当 x→∞ 时，θ→π/2。
  ∫₀^∞ 1/(1+x²) dx = ∫₀^{π/2} 1/(1+tan²θ) · sec²θ dθ
  = ∫₀^{π/2} 1/sec²θ · sec²θ dθ
  = ∫₀^{π/2} 1 dθ = π/2。∎

  **几何解释**：
  变量替换 x = tan θ 是中心投影：
  - x ∈ [0, ∞) 是切线 x=1 上从 (1,0) 到无穷远的半直线
  - θ ∈ [0, π/2) 是单位圆上从 (1,0) 到 (0,1) 的四分之一圆弧
  tan θ 将有限长度的圆弧（π/2）映射为无限长度的半直线（∞）。

  积分的转化：
  - 原积分在无限区间 [0,∞) 上，但被积函数 1/(1+x²) 衰减足够快（~1/x²），所以积分收敛。
  - 替换后，积分区间变成有限区间 [0, π/2]，被积函数变成 1（常数）。
  - 这是因为 dx = (1+x²)dθ 恰好"抵消"了被积函数的分母。

  **与紧致化的关系**：
  x = tan θ 将非紧致的实数轴 [0,∞) 映射为紧致的半开区间 [0,π/2)。
  加上端点 π/2（对应 x=∞），得到紧致区间 [0,π/2]。
  积分 ∫₀^∞ 收敛的本质是：在紧致化后的区间 [0,π/2] 上，被积"测度" dθ 是有限的。
  换句话说，1/(1+x²)dx = dθ 是有限测度，它将无限区间上的积分转化为有限测度空间上的积分。

  **更一般的观点**：
  任何形如 ∫₀^∞ f(x)/(1+x²) dx 的积分，通过 x=tanθ 变成 ∫₀^{π/2} f(tanθ) dθ。
  如果 f(tanθ) 在 [0,π/2] 上可积，则原积分收敛。
  这是处理无穷积分的标准技巧——通过紧致化将无限问题转化为有限问题。∎

  **几何理解**：x=tanθ把无限长的切线"弯成"有限长的圆弧。积分∫₀^∞1/(1+x²)dx在无限区间上，但替换后变成∫₀^{π/2}dθ=π/2——无限区间上的收敛积分对应紧致化后有限区间上的有限测度。这是"无穷可以被驯服"的几何表现。
- **一句话点评**：x=tanθ,dx=sec²θdθ=(1+x²)dθ⟹∫₀^∞1/(1+x²)dx=∫₀^{π/2}dθ=π/2。几何=中心投影将无限半直线[0,∞)映射为有限圆弧[0,π/2)。加端点π/2(x=∞)得紧致区间。收敛积分=紧致化后有限测度。1/(1+x²)dx=dθ是将无限测度拉回为有限测度。

**【D7-2-CROSS-022】**（D7 × D3 微分 × D1 极限）**从单位圆上的投影解释为什么 sin x / x → 1（x→0）和 tan x / x → 1（x→0），但 (1-cos x)/x → 0。用投影的"局部线性化"和"高阶小量"来理解。**

- **难度**：★★
- **对应知识点**：重要极限、局部线性化、高阶小量、投影
- **解答**：
  **sin x / x → 1**：
  sin x 是单位圆上点 P(cos x, sin x) 的纵坐标。
  当 x→0 时，P 接近 (1,0)，圆弧 AP 的长度 = x（弧度制）。
  在 (1,0) 附近，单位圆近似为切线 x=1（局部线性化），圆弧近似为切线段。
  纵坐标 sin x ≈ 弧长 x（因为在 (1,0) 附近，圆弧几乎是垂直的，纵坐标变化≈弧长变化）。
  更精确地，sin x = x - x³/6 + ...，所以 sin x / x = 1 - x²/6 + ... → 1。

  **tan x / x → 1**：
  tan x 是切线 x=1 上投影点 T(1, tan x) 的纵坐标。
  当 x→0 时，T 接近 (1,0)，视线 OT 接近水平。
  在小角度下，tan x ≈ sin x ≈ x（因为 cos x ≈ 1，tan x = sin x/cos x ≈ x/1 = x）。
  tan x = x + x³/3 + ...，所以 tan x / x = 1 + x²/3 + ... → 1。

  **(1-cos x)/x → 0**：
  1 - cos x 是点 P 到切线 x=1 的水平距离（1 - cos x）。
  在 (1,0) 附近，单位圆近似为抛物线 x = 1 - y²/2（曲率为 1 的圆的局部展开）。
  所以 1 - cos x ≈ x²/2（二阶小量）。
  因此 (1-cos x)/x ≈ x/2 → 0。
  这是因为 cos x 的一阶变化为 0（在 x=0 处 cos 取最大值，导数为 0），第一个非零项是二阶的。∎

  **投影的局部线性化**：
  在 x=0 附近：
  - sin x（y坐标投影）：一阶变化 = x（线性），所以 sin x ~ x
  - tan x（中心投影纵坐标）：一阶变化 = x（线性），所以 tan x ~ x
  - cos x（x坐标投影）：一阶变化 = 0（在极值点），二阶变化 = -x²/2，所以 1-cos x ~ x²/2

  这反映了单位圆在 (1,0) 处的局部几何：
  - 切线方向（y方向）：线性变化，投影≈弧长
  - 法线方向（x方向）：二次变化，投影差≈弧长²/2（曲率效应）
  这就是为什么 sin 和 tan 是一阶等价于 x，而 1-cos 是二阶小量。

  **几何理解**：在(1,0)附近，圆≈切线（y方向线性）+抛物线（x方向二次）。sin和tan是y方向投影⟹一阶~x；1-cos是x方向偏差⟹二阶~x²/2。局部线性化只捕捉一阶，曲率效应出现在二阶。
- **一句话点评**：sinx/x→1（y坐标投影，一阶~x）；tanx/x→1（中心投影，cos≈1⟹tan≈sin≈x）；(1-cosx)/x→0（x方向偏差，cos在极值点一阶变化=0，1-cos~x²/2二阶）。(1,0)处圆≈切线(y线性)+抛物线(x二次)，曲率效应在二阶。

**【D7-2-CROSS-023】**（D7 × D8 解析 × D4 积分）**说明留数定理中 ∮ dz/(z²+1) = π 如何与 arctan 和单位圆联系起来。从部分分式分解出发，将 1/(z²+1) 分解为 1/[2i(z-i)] - 1/[2i(z+i)]，计算上半平面积分，并解释为什么结果是 π 而不是 2π。**

- **难度**：★★★
- **对应知识点**：留数定理、部分分式、arctan、单位圆
- **解答**：
  **部分分式分解**：
  1/(z²+1) = 1/[(z-i)(z+i)] = A/(z-i) + B/(z+i)。
  1 = A(z+i) + B(z-i)。
  令 z=i：1 = A(2i) ⟹ A = 1/(2i) = -i/2。
  令 z=-i：1 = B(-2i) ⟹ B = -1/(2i) = i/2。
  所以 1/(z²+1) = 1/[2i(z-i)] - 1/[2i(z+i)]。

  **实轴积分**：
  ∫_{-∞}^∞ 1/(x²+1) dx。
  考虑上半平面的半圆围道 C_R = [-R,R] + 上半圆弧。
  被积函数在上半平面有一个极点 z=i（一阶），留数 Res(f,i) = 1/(2i)。
  由留数定理：∮_{C_R} f(z)dz = 2πi × (1/2i) = π。
  当 R→∞ 时，半圆弧积分 → 0（|f(z)| ~ 1/R²，弧长 ~ πR，积分 ~ π/R → 0）。
  所以 ∫_{-∞}^∞ 1/(x²+1) dx = π。∎

  **与 arctan 的联系**：
  直接用 Newton-Leibniz：
  ∫_{-∞}^∞ 1/(x²+1) dx = [arctan x]_{-∞}^∞ = π/2 - (-π/2) = π。
  两种方法结果一致。

  **为什么是 π 而不是 2π**：
  留数定理给出 2πi × 留数。这里留数 = 1/(2i)，所以 2πi × (1/2i) = π。
  因子 1/2 来自部分分式分解中的 1/(2i)——因为 z²+1 有两个共轭极点 ±i，每个极点的留数是 1/(2i) 而不是 1/i。
  从 arctan 角度：∫_{-∞}^∞ = arctan(∞) - arctan(-∞) = π/2 - (-π/2) = π。
  π 来自 arctan 的值域范围是 (-π/2, π/2)，长度为 π——这是单位圆右半部分的角度范围。

  **与单位圆的联系**：
  1/(x²+1) 是 arctan 的导数，arctan 将实数轴映射到 (-π/2, π/2)（单位圆的右半部分）。
  积分 ∫_{-∞}^∞ 1/(x²+1) dx = 右半圆的角度范围 = π。
  从留数角度，极点 z=i = e^{iπ/2} 在单位圆上（上半部分），围道积分"抓住"了这个极点，得到的 π 对应从 -π/2 到 π/2 的角度范围。

  **几何理解**：∫1/(x²+1)dx=arctanx，从-∞到∞覆盖了arctan的值域(-π/2,π/2)，长度π=单位圆右半部分的角度。留数定理中上半平面极点z=i=e^{iπ/2}，留数1/(2i)⟹2πi×1/(2i)=π。π不是2π因为只涉及半个圆（右半部分/上半平面）。
- **一句话点评**：1/(z²+1)=1/[2i(z-i)]-1/[2i(z+i)]。上半平面极点z=i，留数1/(2i)⟹∮=2πi×1/(2i)=π。半圆弧积分→0⟹∫_{-∞}^∞=π。arctan验证：[arctanx]_{-∞}^∞=π/2-(-π/2)=π。π=arctan值域长度=单位圆右半部分角度，不是2π因为只涉及半圆。

**【D7-2-CROSS-024】**（D7 × D5 级数 × D7 三角学）**用单位圆上的投影解释 Fourier 级数的几何意义：周期函数可以分解为不同频率的正弦/余弦波，而每个正弦/余弦波都是单位圆上匀速旋转点的投影。讨论这如何将"函数空间"与"圆周运动"联系起来。**

- **难度**：★★★
- **对应知识点**：Fourier级数、单位圆投影、函数空间、圆周运动
- **解答**：
  **Fourier 级数**：
  周期为 2π 的函数 f(x) 可以展开为：
  f(x) = a₀/2 + ∑_{n=1}^∞ [a_n cos(nx) + b_n sin(nx)]。
  其中 a_n = (1/π)∫_{-π}^π f(x)cos(nx)dx, b_n = (1/π)∫ f(x)sin(nx)dx。

  **几何意义**：
  每个 cos(nx) 和 sin(nx) 都是单位圆上点的投影：
  - cos(nx) = 单位圆上以角速度 n 匀速旋转的点的 x 坐标
  - sin(nx) = 同一点的 y 坐标
  点 P_n(x) = (cos(nx), sin(nx)) = e^{inx} 以角速度 n 绕单位圆旋转。

  所以 Fourier 级数说的是：**任何周期函数都可以表示为不同速度的圆周运动的投影的叠加**。
  这就像声音可以分解为不同频率的纯音（每个纯音对应一个匀速圆周运动的投影），光可以分解为不同颜色的单色光。

  **函数空间与圆周运动的联系**：
  - 函数空间 L²([0,2π]) 是一个无限维 Hilbert 空间
  - 基函数 {1, cos x, sin x, cos 2x, sin 2x, ...} 是这个空间的一组正交基
  - 每个基函数对应一个特定频率的圆周运动的投影
  - Fourier 系数 a_n, b_n 是 f 在这些基方向上的投影（内积）
  - 所以 f 的 Fourier 展开 = f 在"圆周运动基"下的坐标

  **复数形式**：
  f(x) = ∑_{n=-∞}^∞ c_n e^{inx}，c_n = (1/2π)∫ f(x)e^{-inx}dx。
  e^{inx} = cos(nx) + i sin(nx) 直接就是单位圆上的点（复指数）。
  复数形式更清楚地展示了 Fourier 级数 = 单位圆上不同速度旋转的复数的叠加。

  **几何理解**：
  Fourier 分析的本质是：**周期函数 = 圆周运动的叠加**。
  单位圆是最简单的周期运动（旋转），任何周期运动都可以分解为简单旋转的叠加。
  这就像任何振动都可以分解为简谐振动（匀速圆周运动的投影）的叠加——这是 Fourier 分析的物理直觉，也是它在信号处理、波动、量子力学中广泛应用的原因。

  **与投影的关系**：
  sin(nx) 和 cos(nx) 是 e^{inx} 在 y 轴和 x 轴上的正交投影。
  Fourier 级数将 f 投影到这些"旋转投影"张成的空间中。

  q 是连续的满射（指数映射）。

  周期为 2π 的连续函数 f ↔ S¹ 上的连续函数 f̃。
  正向：f ↦ f̃，f̃(e^{ix}) = f(x)。
  反向：f̃ ↦ f，f(x) = f̃(e^{ix})。
  这是一个双射，且保持代数结构（加法、数乘、乘法）。

  **商拓扑解释**：
  ℝ 上定义等价关系 x ~ y ⟺ x-y ∈ 2πℤ。
  商空间 ℝ/(2πℤ) 拓扑同胚于 S¹（通过 e^{ix}）。
  周期函数就是在等价类上取常值的函数，即商空间上的函数。
  商拓扑保证了：商空间上的函数连续 ⟺ 拉回函数（原周期函数）连续。

  **为什么是三角函数的拓扑基础**：
  三角函数 sin x, cos x 是周期为 2π 的函数，对应 S¹ 上的函数：
  sin x ↦ 投影到 y 轴的函数 pr_y: S¹ → ℝ
  cos x ↦ 投影到 x 轴的函数 pr_x: S¹ → ℝ
  所有周期函数都可以看作 S¹ 上的函数，而 S¹ 上最简单的连续函数就是坐标投影（sin, cos）及其组合。
  Fourier 级数说的是：S¹ 上的任何连续函数都可以用坐标投影的"谐波"（cos(nx), sin(nx)）一致逼近（Stone-Weierstrass 定理）。

  **几何理解**：周期函数=把实数轴"卷成"圆后的函数。f(x+2π)=f(x)意味着f不关心你转了多少圈，只关心你在圆上的位置。sin和cos是圆上的坐标投影，是最简单的圆周函数，所有周期函数都由它们生成（Fourier）。这是三角函数描述周期现象的拓扑本质。
- **一句话点评**：周期2π函数f↔S¹上连续函数f̃，f(x)=f̃(e^{ix})。q:ℝ→S¹,q(x)=e^{ix}是商映射，ℝ/(2πℤ)≅S¹。f连续⟺f̃连续（商拓扑性质）。sin/cos对应S¹上的y/x坐标投影。所有周期函数=圆周上函数，由坐标投影谐波生成（Fourier/Stone-Weierstrass）。

**【D7-2-CROSS-026】**（D7 × D8 解析 × D6 完备性）**计算交比 (tan 0, tan(π/6); tan(π/4), tan(π/3))，并验证它在旋转 β=π/6 后保持不变。说明交比如何是中心投影下的基本不变量，以及三角函数比值本质上是交比的表现。**

- **对应知识点**：交比、中心投影不变量、tan值、旋转
- **解答**：
  **交比定义**：
  (a, b; c, d) = [(a-c)/(b-c)] / [(a-d)/(b-d)] = (a-c)(b-d)/[(b-c)(a-d)]。

  **计算原始交比**：
  a = tan 0 = 0
  b = tan(π/6) = 1/√3
  c = tan(π/4) = 1
  d = tan(π/3) = √3

**【D7-2-CROSS-027】**（D7 × D3 微分 × D1 极限）**定量分析正切函数的"伸长拉缩"：计算 (tan θ)' = sec²θ，并说明当 θ 从 0 增加到 π/2 时，导数从 1 增加到 +∞。用这个导数解释为什么同样的角度增量 Δθ 在接近 π/2 时导致巨大的 tan 增量，并给出具体数值例子。**

- **难度**：★★★
- **对应知识点**：tan的导数、伸长拉缩、非线性映射、中心投影
- **解答**：
  **导数计算**：
  (tan θ)' = (sinθ/cosθ)' = (cosθ·cosθ - sinθ·(-sinθ))/cos²θ = (cos²θ+sin²θ)/cos²θ = 1/cos²θ = sec²θ。∎

  **伸长拉缩的定量分析**：
  当 θ 从 0 到 π/2 时：
  - θ=0: sec²0 = 1（导数=1，局部等距，角度增量≈tan增量）
  - θ=π/6(30°): sec²(π/6) = 1/(√3/2)² = 4/3 ≈ 1.33
  - θ=π/4(45°): sec²(π/4) = 1/(√2/2)² = 2
  - θ=π/3(60°): sec²(π/3) = 1/(1/2)² = 4
  - θ=π/2-0.1: sec²(1.47) ≈ 1/cos²(1.47) ≈ 1/(0.100)² ≈ 100
  - θ→π/2: sec²θ → +∞

  **具体数值例子**：
  取 Δθ = 0.01 弧度（约0.57°）：
  - 在 θ=0 附近：tan(0.01)-tan(0) ≈ 0.01（增量≈Δθ，导数≈1）
  - 在 θ=π/4 附近：tan(π/4+0.01)-tan(π/4) ≈ sec²(π/4)×0.01 = 0.02（增量是Δθ的2倍）
  - 在 θ=π/3 附近：tan(π/3+0.01)-tan(π/3) ≈ 4×0.01 = 0.04（增量是Δθ的4倍）
  - 在 θ=1.5（接近π/2≈1.5708）附近：sec²(1.5) ≈ 1/cos²(1.5) ≈ 1/(0.0707)² ≈ 200，增量≈200×0.01=2
  - 在 θ=1.56 附近：cos(1.56)≈0.0108，sec²≈8570，增量≈8570×0.01≈85.7！

  **几何解释**：
  tan θ 是从原点到切线 x=1 的中心投影。
  当 θ 接近 π/2 时，射线接近垂直，与切线 x=1 的交点趋向无穷远。
  微小的角度变化会导致交点位置的巨大变化——这就是"伸长拉缩"。
  导数 sec²θ = 1+tan²θ 定量描述了这个伸长率：tan 值越大，伸长越剧烈。
  这是中心投影的固有非线性——它将有限的圆弧 (0,π/2) 映射为无限的直线 (0,∞)，映射必然在端点附近"无限伸长"。

  **与平行投影的对比**：
  正交投影 sin θ 的导数 cos θ 在 [0,π/2] 上从 1 降到 0——平行投影是"压缩"而非"伸长"。
  中心投影 tan θ 的导数 sec²θ 从 1 升到 ∞——中心投影是"伸长"。
  这两种投影的导数行为完全相反，反映了平行投影和中心投影的本质区别。∎
- **一句话点评**：(tanθ)'=sec²θ=1+tan²θ。θ=0时导数=1（等距），π/4时=2，π/3时=4，接近π/2时→∞。Δθ=0.01在θ=1.56时导致tan增量≈85.7！中心投影将有限圆弧映射为无限直线，端点附近必然无限伸长。平行投影sin导数cosθ从1降到0（压缩），与中心投影相反。

- **难度**：★★★
- **对应知识点**：双曲几何、双曲函数、单位圆vs单位双曲线、投影统一
- **解答**：
  **欧氏几何中的角度**：
  角度 θ = 弧长/半径，在单位圆上 θ = 弧长。
  三角函数 = 单位圆上点的坐标（投影）：(cosθ, sinθ)。
  单位圆方程：x² + y² = 1。

  **双曲几何中的角度**：
  双曲几何中，"双曲角"（或"快度"，rapidity）φ 定义为单位双曲线上的弧长参数：
  单位双曲线方程：x² - y² = 1（右支）。
  双曲函数 = 单位双曲线上点的坐标（投影）：(coshφ, sinhφ)。
  其中 coshφ = (e^φ + e^{-φ})/2, sinhφ = (e^φ - e^{-φ})/2。

  **统一理解**：
  | | 欧氏（圆） | 双曲（双曲线） |
  |---|---|---|
  | 曲线 | x² + y² = 1 | x² - y² = 1 |
  | 参数 | 角度 θ | 快度 φ |
  | 坐标 | (cosθ, sinθ) | (coshφ, sinhφ) |
  | 恒等式 | cos²+sin²=1 | cosh²-sinh²=1 |
  | 导数 | (sinθ)'=cosθ | (sinhφ)'=coshφ |
  | 周期 | 2π | 无周期（φ∈ℝ） |
  | 加法公式 | sin(α+β)=sinαcosβ+cosαsinβ | sinh(φ+ψ)=sinhφcoshψ+coshφsinhψ |

  三角函数和双曲函数的形式高度相似，只是符号不同（+ vs -）。
  这可以通过"虚角度"统一：coshφ = cos(iφ), sinhφ = -i sin(iφ)。
  即双曲函数是三角函数在虚轴上的取值——单位圆 x²+y²=1 中令 y→iy 得到单位双曲线 x²-y²=1。

  **投影的角度**：
  - 三角函数：单位圆上的点正交投影到坐标轴
  - 双曲函数：单位双曲线上的点正交投影到坐标轴
  - tanθ = 中心投影到切线 x=1；tanhφ = sinhφ/coshφ = 单位双曲线上点的斜率
  - tanhφ 的值域是 (-1,1)（有界），与 tanθ 的值域 ℝ 不同——因为双曲线是开放的，投影范围有限

  **双曲几何中的角度**：
  在双曲几何中，两条曲线的交角仍然用欧氏方式定义（切向量的夹角），所以普通三角函数仍然用于描述双曲几何中的"角度"。
  但双曲几何中的"距离"和"平移"用双曲函数描述。
  快度 φ 是双曲几何中"速度"的自然度量——在狭义相对论中，快度叠加是线性的（φ_total = φ₁+φ₂），而速度叠加是非线性的。

  **几何理解**：三角函数和双曲函数是同一个数学结构在不同符号（+ vs -）下的表现——圆和双曲线在射影几何中是统一的（都是二次曲线），三角函数和双曲函数分别是它们的参数化。"角度"在圆上是紧致的（0到2π循环），在双曲线上是非紧致的（-∞到∞）——这反映了圆和双曲线的拓扑差异。∎
- **一句话点评**：欧氏角度θ=单位圆弧长，三角=(cosθ,sinθ)在圆x²+y²=1上。双曲快度φ=单位双曲线弧长，双曲=(coshφ,sinhφ)在x²-y²=1上。统一：coshφ=cos(iφ),sinhφ=-isin(iφ)，双曲线=圆令y→iy。tan值域ℝ（圆紧致→中心投影无界），tanh值域(-1,1)（双曲线开放→投影有界）。圆和双曲线都是二次曲线，射影几何中统一。

**【D7-2-CROSS-031】**（D7 × D3 微分 × D4 积分）**从投影的角度理解积化和差公式：sinα cosβ = [sin(α+β) + sin(α-β)]/2。说明这个公式如何对应于两个单位圆上旋转运动的投影的乘积分解，以及它在Fourier分析和信号处理中的意义。**

- **难度**：★★
- **对应知识点**：积化和差、投影乘积、Fourier分析、信号处理
- **解答**：
  **代数推导**：
  sin(α+β) = sinα cosβ + cosα sinβ
  sin(α-β) = sinα cosβ - cosα sinβ
  相加：sin(α+β) + sin(α-β) = 2 sinα cosβ
  ⟹ sinα cosβ = [sin(α+β) + sin(α-β)]/2。∎

  **投影的角度理解**：
  sinα 是单位圆上以角速度 1 旋转的点的 y 坐标投影。
  cosβ 是另一个单位圆上以角速度 1 旋转的点的 x 坐标投影（相位差 π/2）。
  它们的乘积 sinα cosβ 可以看作两个简谐运动的乘积。

  积化和差说：两个不同频率（这里相位差为 α-β 和 α+β）的简谐运动的乘积 = 两个频率的和与差的简谐运动的平均。
  具体地，如果 α = ω₁t, β = ω₂t：
  sin(ω₁t) cos(ω₂t) = [sin((ω₁+ω₂)t) + sin((ω₁-ω₂)t)]/2。
  即两个频率的乘积 = 和频 + 差频。

  **Fourier 分析的意义**：
  积化和差是 Fourier 分析中"调制"和"混频"的数学基础。
  - 调制：将信号 f(t) 乘以 cos(ω₀t)（载波），会将 f 的频谱搬移到 ±ω₀ 处。
  - 混频：两个信号相乘，产生和频与差频。
  这是无线电通信（AM调幅、超外差接收机）的基本原理。

  **正交性的来源**：
  Fourier 级数中基函数的正交性 ∫₀^{2π} sin(nx)cos(mx)dx = 0 可以用积化和差证明：
  sin(nx)cos(mx) = [sin((n+m)x) + sin((n-m)x)]/2。
  当 n≠m 时，两个正弦在一个周期内积分都是 0。
  当 n=m 时，sin((n-m)x)=sin(0)=0，仍有 ∫sin(nx)cos(nx)dx = 0。
  所以 sin 和 cos 总是正交的——这是因为它们相位差 π/2，乘积是纯正弦（没有直流分量）。

  **几何理解**：
  sinα cosβ 是两个垂直方向投影的乘积。
  积化和差将这个乘积分解为"同向旋转"（α+β）和"反向旋转"（α-β）的投影的平均。
  这就像两个旋转矢量的点积——一个在 y 方向，一个在 x 方向，它们的乘积可以分解为合旋转和差旋转。∎
- **一句话点评**：sinαcosβ=[sin(α+β)+sin(α-β)]/2（由和角公式相加）。投影角度=两个简谐运动乘积=和频+差频。Fourier意义=调制/混频的数学基础（AM无线电）。正交性∫sin(nx)cos(mx)dx=0由积化和差证明（n≠m时两正弦周期积分为0）。几何=两垂直方向投影乘积=同向+反向旋转投影平均。

**【D7-2-CROSS-032】**（D7 × D8 解析 × D6 完备性）**从单位圆上的中心投影理解 Riemann 球与复平面的紧致化：说明球极投影如何将复平面（加上无穷远点）映射为球面，而正切函数 tan θ 如何是这个构造的一维版本。讨论"无穷远点"在两种构造中的统一角色。**

- **难度**：★★★
- **对应知识点**：Riemann球、球极投影、紧致化、无穷远点、tan的一维版本
- **解答**：
  **Riemann 球与球极投影**：
  Riemann 球 = 复平面 ℂ 加上一个无穷远点 ∞，拓扑上等价于球面 S²。
  球极投影：将球面（去掉北极点）投影到赤道平面（复平面）。
  从北极 N(0,0,1) 出发，经过球面上点 P(x,y,z) 的直线交赤道平面 z=0 于点 (X,Y,0)。
  投影公式：X = x/(1-z), Y = y/(1-z)，对应复数 w = X + iY = (x+iy)/(1-z)。
  北极点 N 对应无穷远点 ∞——从 N 出发的任何直线都"平行于"赤道平面，不交于有限点。

  **tan θ 作为一维版本**：
  tan θ 将角度 θ ∈ (-π/2, π/2) 映射为实数 t ∈ ℝ。
  这可以看作一维的球极投影：
  - 单位圆 S¹（一维球面）去掉点 (0,1)（北极）
  - 从 (0,1) 出发，经过圆上点 (cosθ, sinθ) 的直线交"赤道"（x轴，y=0）于点 (tanθ, 0)
  - 验证：直线从 (0,1) 到 (cosθ,sinθ)，参数方程 (t cosθ, 1 + t(sinθ-1))。令 y=0：t = 1/(1-sinθ)，x = cosθ/(1-sinθ) = (1+sinθ)/cosθ = tan(π/4 + θ/2)。
  - 更标准的一维球极投影是从 (-1,0) 投影到 y 轴：t = sinθ/(1+cosθ) = tan(θ/2)。

  所以 tan(θ/2) = sinθ/(1+cosθ) 正是从 (-1,0) 到单位圆的球极投影！
  而 tan θ = sinθ/cosθ 是从原点到切线 x=1 的中心投影——两种投影在射影几何中是等价的（相差一个射影变换）。

  **无穷远点的统一角色**：
  - Riemann 球中：北极点 = ∞，所有"趋向无穷"的复数列都收敛到北极
  - tan 投影中：θ = π/2 对应 t = ∞，射线垂直于切线，交点在无穷远
  - 射影直线 ℝℙ¹ 中：无穷远点是直线紧致化的必要元素
  - 射影平面 ℝℙ² 中：无穷远直线是平面紧致化的必要元素

  无穷远点不是"一个很大的数"，而是拓扑紧致化的结构元素——加上它，非紧致的空间（ℂ, ℝ, 直线）变成紧致的空间（S², S¹, 圆）。

  **复分析中的应用**：
  - 亚纯函数 f: ℂ → ℂ∪{∞} 可以看作 f: S² → S² 的连续映射
  - 极点对应 f(z) = ∞，即映射到北极点
  - 留数定理中，围道积分 = 2πi × 内部极点留数之和——极点就是映射到无穷远点的地方
  - tan z 的极点在 z = π/2 + nπ，对应 tan 的"无穷远点"在角度轴上的周期性出现

  **几何理解**：Riemann 球是二维的"圆加无穷远点"，tan 投影是一维的。两者都是中心投影（球极投影），都通过添加一个无穷远点将非紧致空间紧致化为紧致空间（球面/圆）。无穷远点是投影中心的对径点——从投影中心看，对径点的投影线平行于投影面，所以"交于无穷远"。∎
- **一句话点评**：Riemann球=ℂ∪{∞}≅S²，球极投影从北极将球面映到复平面，北极=∞。tan(θ/2)=sinθ/(1+cosθ)=从(-1,0)到单位圆的一维球极投影；tanθ=从原点到切线的中心投影（射影等价）。无穷远点=投影中心的对径点，投影线平行于投影面⟹交于无穷远。亚纯函数f:S²→S²，极点=映到北极。tan z极点在π/2+nπ。

## 本模块易错点总结

1. **单位圆定义适用于任意角**：直角三角形定义只适用于锐角，单位圆定义突破了这个局限。cosθ=x坐标，sinθ=y坐标。
2. **tan 是中心投影不是比值**：tanθ=sinθ/cosθ是代数定义，几何上是从原点到切线x=1的透视投影的纵坐标。θ→π/2时投影点→∞，这是tan无界的几何原因。
3. **六个三角函数对应两种投影**：sin/cos=正交投影（平行投影），tan/cot=中心投影（透视投影），sec/csc=中心投影的距离参数。
4. **tan 的周期是 π 不是 2π**：因为对径点（相差π）在同一条射线上，中心投影相同。sin/cos周期2π因为对径点坐标相反。
5. **诱导公式是几何变换**：-θ=关于x轴反射，π-θ=关于y轴反射，π/2-θ=关于y=x反射，θ+π=中心对称，θ+π/2=旋转90°。不用背"奇变偶不变"。
6. **1+tan²=sec²是勾股定理**：对应直角三角形OAT（OA=1,AT=tanθ,OT=secθ）。三个恒等式对应单位圆上三个直角三角形。
7. **arctan 将实数轴紧致化为圆**：arctan:ℝ→(-π/2,π/2)，加无穷远点得射影直线≅S¹。+∞和-∞在射影几何中是同一个点。
8. **正切加法公式是Möbius变换**：t↦(t+tanβ)/(1-ttanβ)是分式线性变换，保持交比。旋转合成=Möbius复合。
9. **正交投影产生arcsine分布，中心投影产生Cauchy分布**：均匀角度经正交投影→arcsine（端点密集），经中心投影→Cauchy（重尾无均值）。
10. **伸长拉缩是中心投影的固有性质**：同样角度增量，接近π/2时tan增量巨大。这是将有限圆弧映射为无限直线的必然非线性结果。
