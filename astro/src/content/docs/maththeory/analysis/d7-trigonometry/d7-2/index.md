## 第一章 从直角三角形到单位圆——定义的范式转换

### 1.1 直角三角形定义及其局限

传统的三角函数定义是通过**直角三角形**的边长比值：

在一个直角三角形中，设一个锐角为 $\theta$，对边为 $a$，邻边为 $b$，斜边为 $c$，则：

$$\sin\theta = \frac{a}{c} = \frac{\text{对边}}{\text{斜边}}, \quad \cos\theta = \frac{b}{c} = \frac{\text{邻边}}{\text{斜边}}, \quad \tan\theta = \frac{a}{b} = \frac{\text{对边}}{\text{邻边}}$$

这个定义有几个根本局限：

1. **只适用于锐角**（$0 < \theta < \pi/2$）：直角三角形中的角必须是锐角，无法定义钝角、平角、负角或大于 $2\pi$ 的角。
2. **依赖三角形的存在**：必须有一个直角三角形才能定义三角函数，这使得三角函数看起来像是"三角形的附属品"，而不是独立的数学对象。
3. **没有揭示周期性**：直角三角形定义无法自然地解释三角函数的周期性（$\sin(\theta + 2\pi) = \sin\theta$）。
4. **没有揭示几何本质**：边长比值是一个代数定义，没有揭示三角函数的几何本质（投影）。

### 1.2 单位圆定义的引入

**单位圆定义**突破了直角三角形定义的所有局限：

> **定义**：在平面直角坐标系中，以原点为圆心作单位圆（半径为 1）。从正 x 轴出发，逆时针旋转角 $\theta$，与单位圆交于点 $P$。则点 $P$ 的坐标为：
> $$P = (\cos\theta, \sin\theta)$$
> 即：
> - $\cos\theta$ = 点 $P$ 的**横坐标**（x 坐标）
> - $\sin\theta$ = 点 $P$ 的**纵坐标**（y 坐标）

这个定义的革命性在于：
1. **适用于任意角**：$\theta$ 可以是任意实数（正的、负的、大于 $2\pi$ 的）。
2. **独立于三角形**：三角函数是"角度→坐标"的映射，不依赖任何三角形。
3. **自然揭示周期性**：旋转 $2\pi$ 后回到同一点，所以 $\cos(\theta+2\pi)=\cos\theta$，$\sin(\theta+2\pi)=\sin\theta$。
4. **揭示几何本质**：三角函数就是**投影**——$\cos\theta$ 是点到 x 轴的投影，$\sin\theta$ 是点到 y 轴的投影。

📐 **几何理解**：单位圆定义的核心是"三角函数 = 单位圆上点的坐标"。这不是一个简单的定义替换——它是一次**范式转换**：从"三角形的边长比值"（静态、有限、代数）到"圆上点的坐标"（动态、无限、几何）。这个转换使得三角函数从"三角形的附属品"变成了"描述旋转和振荡的基本函数"。

### 1.3 两种定义的关系

单位圆定义包含了直角三角形定义——当 $\theta$ 是锐角时，从点 $P$ 向 x 轴作垂线，就得到一个直角三角形：
- 斜边 = 1（单位圆半径）
- 对边 = $\sin\theta$（纵坐标）
- 邻边 = $\cos\theta$（横坐标）

所以直角三角形定义是单位圆定义在锐角情形下的特例。

## 第二章 六个三角函数的几何统一

### 2.1 六种三角函数的定义

在单位圆上，六种三角函数都有统一的几何解释：

| 函数 | 定义 | 几何意义 |
|------|------|---------|
| 正弦 $\sin\theta$ | 点 $P$ 的纵坐标 | 到 x 轴的**正交投影** |
| 余弦 $\cos\theta$ | 点 $P$ 的横坐标 | 到 y 轴的**正交投影** |
| 正切 $\tan\theta$ | $\sin\theta/\cos\theta$ | 从原点到切线 $x=1$ 的**中心投影**的纵坐标 |
| 余切 $\cot\theta$ | $\cos\theta/\sin\theta$ | 从原点到切线 $y=1$ 的**中心投影**的横坐标 |
| 正割 $\sec\theta$ | $1/\cos\theta$ | 从原点到切线投影点的**距离** |
| 余割 $\csc\theta$ | $1/\sin\theta$ | 从原点到另一切线投影点的**距离** |

### 2.2 正弦与余弦——正交投影（平行投影）

正弦和余弦是最简单的三角函数，它们的几何意义是**正交投影**：

- $\cos\theta$：单位圆上的点 $P$ 在 **x 轴**上的正交投影（即点 $P$ 的横坐标）
- $\sin\theta$：单位圆上的点 $P$ 在 **y 轴**上的正交投影（即点 $P$ 的纵坐标）

正交投影是一种**平行投影**——投影线是平行的（都垂直于投影轴）。

正交投影的性质：
- 保持平行性（平行线的投影仍然平行）
- 不保持长度（投影长度 = 原长度 × $\cos$ 夹角）
- 不保持角度（除非角的一边平行于投影轴）

📐 **几何理解**：正弦和余弦是"投影"——当你看着单位圆上的一个点时，它的横坐标就是余弦，纵坐标就是正弦。这就像你站在阳光下，你的影子的长度就是你的身高乘以太阳高度角的正弦——影子就是正交投影。

### 2.3 正切与余切——中心投影（透视投影）

正切和余切的几何意义更深刻，它们是**中心投影**（透视投影）：

**正切 $\tan\theta$**：
从原点 $O$ 出发，经过单位圆上的点 $P(\cos\theta, \sin\theta)$ 作射线，这条射线与切线 $x=1$（单位圆在 $(1,0)$ 处的切线）交于点 $T$。

点 $T$ 的坐标是什么？射线 $OP$ 的参数方程是 $(t\cos\theta, t\sin\theta)$。令 $x=1$，得 $t = 1/\cos\theta = \sec\theta$，所以 $y = t\sin\theta = \sin\theta/\cos\theta = \tan\theta$。

因此：
$$T = (1, \tan\theta)$$

即 $\tan\theta$ 是**从原点到切线 $x=1$ 的中心投影的纵坐标**。

**余切 $\cot\theta$**：
类似地，射线 $OP$ 与切线 $y=1$（单位圆在 $(0,1)$ 处的切线）交于点 $C$。

令 $y=1$，得 $t = 1/\sin\theta = \csc\theta$，所以 $x = t\cos\theta = \cos\theta/\sin\theta = \cot\theta$。

因此：
$$C = (\cot\theta, 1)$$

即 $\cot\theta$ 是**从原点到切线 $y=1$ 的中心投影的横坐标**。

中心投影（透视投影）的性质：
- **不保持平行性**（平行线的投影可能相交于消失点）
- **保持交比**（cross ratio，这是射影几何的基本不变量）
- 不保持长度和角度

📐 **几何理解**：正切函数是"透视投影"——就像你站在原点，透过单位圆看远处的一堵墙（切线 $x=1$），圆上的点在墙上的投影高度就是正切值。当角度接近 90°（$\pi/2$）时，投影点趋向无穷远——这就是 $\tan(\pi/2)$ 无定义的几何原因！这与绘画中的透视原理完全一致：平行线在远处汇聚于消失点。

### 2.4 正割与余割——中心投影的距离

正割和余割是中心投影点到圆心的距离：

**正割 $\sec\theta$**：
从原点到切线投影点 $T(1, \tan\theta)$ 的距离：
$$|OT| = \sqrt{1^2 + \tan^2\theta} = \sqrt{1 + \frac{\sin^2\theta}{\cos^2\theta}} = \sqrt{\frac{\cos^2\theta + \sin^2\theta}{\cos^2\theta}} = \frac{1}{|\cos\theta|}$$

考虑符号后，$\sec\theta = 1/\cos\theta$。

几何上，$\sec\theta$ 是**从原点到切线 $x=1$ 上投影点的有向距离**（参数 $t$ 的值）。

**余割 $\csc\theta$**：
类似地，$\csc\theta = 1/\sin\theta$ 是从原点到切线 $y=1$ 上投影点的有向距离。

📐 **几何理解**：正割和余割是"视线长度"——当你从原点看向切线墙上的投影点时，视线的长度就是正割（或余割）。当角度接近 90° 时，视线趋向无穷长——这与正切趋向无穷是一致的。

### 2.5 六个三角函数的几何统一图

在单位圆上，六个三角函数可以用以下几何线段统一表示：

设角 $\theta$ 的终边与单位圆交于 $P(\cos\theta, \sin\theta)$：
- 从 $P$ 向 x 轴作垂线，垂足为 $M(\cos\theta, 0)$，则 $|PM| = |\sin\theta|$，$|OM| = |\cos\theta|$
- 终边（或其反向延长线）与切线 $x=1$ 交于 $T(1, \tan\theta)$，则 $|AT| = |\tan\theta|$（$A=(1,0)$），$|OT| = |\sec\theta|$
- 终边（或其反向延长线）与切线 $y=1$ 交于 $C(\cot\theta, 1)$，则 $|BC| = |\cot\theta|$（$B=(0,1)$），$|OC| = |\csc\theta|$

这就是著名的**"单位圆上的三角函数线"**——六条线段分别对应六个三角函数。

## 第三章 射影几何视角下的三角函数——伸长拉缩的深刻意义

### 3.1 平行投影与中心投影——射影几何的两种基本投影

射影几何研究的是**投影变换下的不变量**。投影有两种基本类型：

**1. 平行投影（Parallel Projection）**：
- 投影线互相平行
- 特例：正交投影（投影线垂直于投影面）
- 保持：平行性、简比（segment ratio）
- 不保持：长度、角度、面积

**2. 中心投影（Central Projection / Perspective Projection）**：
- 所有投影线从一个中心点（投影中心）发出
- 保持：交比（cross ratio）
- 不保持：平行性、长度、角度、面积

三角函数恰好是这两种投影在单位圆上的具体表现：
- $\sin\theta, \cos\theta$ = **平行投影**（正交投影到坐标轴）
- $\tan\theta, \cot\theta$ = **中心投影**（从原点到切线的透视投影）
- $\sec\theta, \csc\theta$ = **中心投影的距离参数**

### 3.2 正切函数与透视投影——"伸长拉缩"的几何本质

用户提到的"三角函数的伸长拉缩"，在射影几何中有着深刻的意义。

**正切函数的"伸长拉缩"**：

考虑从单位圆到切线 $x=1$ 的中心投影。当角度 $\theta$ 从 0 增加到 $\pi/2$ 时：
- 单位圆上的点 $P$ 从 $(1,0)$ 移动到 $(0,1)$，走过的弧长是 $\pi/2 \approx 1.57$
- 切线投影点 $T$ 从 $(1,0)$ 移动到 $(1, +\infty)$，纵坐标从 0 增加到 $+\infty$

这是一个**非线性的"伸长"**——同样的角度增量，在接近 $\pi/2$ 时会导致正切值的巨大增量。具体来说：
- $\theta$ 从 0 到 $\pi/6$（30°）：$\tan\theta$ 从 0 到 $1/\sqrt{3} \approx 0.577$
- $\theta$ 从 $\pi/6$ 到 $\pi/3$（60°）：$\tan\theta$ 从 0.577 到 $\sqrt{3} \approx 1.732$
- $\theta$ 从 $\pi/3$ 到 $\pi/2 - 0.01$：$\tan\theta$ 从 1.732 到约 100

越接近 $\pi/2$，同样的角度增量导致的正切增量越大——这就是"伸长拉缩"的几何表现。

📐 **射影几何理解**：这种"伸长拉缩"不是任意的——它是**中心投影的固有性质**。中心投影将圆弧（有限长度）映射为直线（无限长度），这种映射必然是非线性的。在射影几何中，这对应于从射影直线（圆，紧致）到仿射直线（实数轴，非紧致）的去紧致化——去掉一个点（无穷远点），圆就变成了直线。

### 3.3 交比与三角函数——射影不变量

射影几何中最基本的不变量是**交比**（cross ratio）。

对于直线上的四个点 $A, B, C, D$，交比定义为：
$$(A, B; C, D) = \frac{AC/BC}{AD/BD} = \frac{AC \cdot BD}{BC \cdot AD}$$

交比在中心投影下保持不变。

**三角函数与交比的联系**：

考虑单位圆上的四个点，对应角度 $0, \theta, \pi/2, \pi$。将这些点通过中心投影映射到切线 $x=1$ 上，得到四个点：
- $\theta=0$ → $(1, 0)$，对应 $\tan 0 = 0$
- $\theta=\theta$ → $(1, \tan\theta)$
- $\theta=\pi/2$ → 无穷远点（$\tan(\pi/2)$ 无定义）
- $\theta=\pi$ → $(1, 0)$（反向延长线），对应 $\tan\pi = 0$

在包含无穷远点的射影直线上，交比可以用三角函数表示。具体来说，对于角度 $\alpha, \beta, \gamma, \delta$，有：
$$(\tan\alpha, \tan\beta; \tan\gamma, \tan\delta) = \frac{\sin(\alpha-\gamma)\sin(\beta-\delta)}{\sin(\beta-\gamma)\sin(\alpha-\delta)}$$

这个公式揭示了三角函数与交比的深刻联系——**三角函数的比值本质上是射影不变量（交比）的具体表现**。

### 3.4 正切加法公式的射影几何解释

正切的加法公式：
$$\tan(\alpha + \beta) = \frac{\tan\alpha + \tan\beta}{1 - \tan\alpha\tan\beta}$$

从射影几何的角度看，这个公式有深刻的意义：

**角度的加法 = 旋转的合成**：
- 先旋转 $\alpha$，再旋转 $\beta$，总旋转是 $\alpha+\beta$
- 在单位圆上，这对应于点的复合运动
- 在切线投影上，这对应于一个**射影变换**（Möbius 变换）

具体来说，令 $t = \tan\theta$，则旋转 $\beta$ 对应的变换是：
$$t \mapsto \frac{t + \tan\beta}{1 - t\tan\beta}$$

这是一个**Möbius 变换**（分式线性变换），形式为 $t \mapsto \frac{at+b}{ct+d}$。

Möbius 变换是射影几何的基本变换，它保持交比。正切加法公式说明：**旋转的合成对应于 Möbius 变换的复合**。

📐 **几何理解**：正切加法公式不是一个代数技巧——它是"旋转的合成在透视投影下的表现"。当你先转一个角度，再转一个角度，总效果在切线墙上的投影就是这两个投影的 Möbius 复合。这揭示了三角函数与射影变换之间的深层联系——**三角函数是旋转群在射影直线上的表示**。

### 3.5 反三角函数与射影直线的紧致化

**$\arctan$ 函数的几何意义**：

$\arctan: \mathbb{R} \to (-\pi/2, \pi/2)$ 是正切函数的反函数。

从射影几何的角度看，$\arctan$ 的意义是：
- 正切 $\tan: (-\pi/2, \pi/2) \to \mathbb{R}$ 将开区间（有限长度）映射为整个实数轴（无限长度）
- 这是从**射影直线**（圆，紧致）去掉一个点（$\theta = \pi/2$，对应无穷远点）得到**仿射直线**（实数轴）
- $\arctan$ 则是反向的——将实数轴"弯曲"成圆的一段

**实数轴的紧致化**：

在实数轴上加上一个"无穷远点"，就得到了**射影直线**（实射影直线 $\mathbb{RP}^1$），它拓扑上等价于一个圆。

$\arctan$ 给出了这个紧致化的具体实现：
- 实数 $t \in \mathbb{R}$ 对应角度 $\theta = \arctan t \in (-\pi/2, \pi/2)$
- $t \to +\infty$ 对应 $\theta \to \pi/2$
- $t \to -\infty$ 对应 $\theta \to -\pi/2$
- 在射影直线上，$+\infty$ 和 $-\infty$ 是同一个点（无穷远点），对应 $\theta = \pi/2 = -\pi/2$（在圆上这两个端点重合）

📐 **几何理解**：$\arctan$ 函数的深刻意义在于它将"直的"实数轴变成了"弯的"圆——这就是射影直线的紧致化。当你说"无穷大"时，在射影几何中它就是圆上的一个点，和其他点没有本质区别。$\tan$ 和 $\arctan$ 就是"直线"和"圆"之间的翻译器。

### 3.6 Dandelin 球与圆锥曲线——三角函数的射影起源

三角函数与圆锥曲线也有深刻的射影几何联系。

**Dandelin 球**：
Dandelin 球是证明圆锥曲线焦点性质的经典几何方法。在一个圆锥内放置一个球，使它与圆锥的切面和截面都相切，切点就是圆锥曲线的焦点。

**三角函数与圆锥截线**：
圆锥曲线（椭圆、抛物线、双曲线）是圆锥被平面截取的结果。截面与圆锥轴的夹角 $\theta$ 决定了截线的类型：
- $\theta >$ 圆锥半顶角 → 椭圆
- $\theta =$ 圆锥半顶角 → 抛物线
- $\theta <$ 圆锥半顶角 → 双曲线

三角函数（$\sin, \cos, \tan$）描述了这些角度关系，而圆锥曲线的参数化（如椭圆的参数方程 $x = a\cos t, y = b\sin t$）直接使用了三角函数。

从射影几何的角度看，所有圆锥曲线在射影变换下是等价的——椭圆、抛物线、双曲线的区别只是"无穷远直线"与曲线的交点数不同。三角函数的"伸长拉缩"恰好描述了从一种圆锥曲线到另一种的射影变换。

## 第四章 三角函数符号的几何理解

### 4.1 符号由象限决定

三角函数的符号由单位圆上点所在的象限决定：

| 象限 | 角度范围 | $\cos\theta$ (x坐标) | $\sin\theta$ (y坐标) | $\tan\theta$ (y/x) |
|------|---------|----------------------|----------------------|---------------------|
| 第一象限 | $0 < \theta < \pi/2$ | + | + | + |
| 第二象限 | $\pi/2 < \theta < \pi$ | - | + | - |
| 第三象限 | $\pi < \theta < 3\pi/2$ | - | - | + |
| 第四象限 | $3\pi/2 < \theta < 2\pi$ | + | - | - |

这不需要背"全正、正弦、正切、余弦"（ASTC）——直接看坐标的正负就知道了：
- $\cos\theta$ 的符号 = x 坐标的符号
- $\sin\theta$ 的符号 = y 坐标的符号
- $\tan\theta = \sin\theta/\cos\theta$ 的符号 = y/x 的符号（同号为正，异号为负）

### 4.2 符号的几何理解

📐 **几何理解**：三角函数的符号不是人为规定的——它是投影方向的自然结果。
- 当点在 y 轴右侧时，x 坐标为正，所以 $\cos\theta > 0$
- 当点在 x 轴上方时，y 坐标为正，所以 $\sin\theta > 0$
- 正切是中心投影的纵坐标，当点在第二、四象限时，射线与切线 $x=1$ 的交点在 x 轴下方（或需要反向延长射线），所以 $\tan\theta < 0$

## 第五章 周期性的几何本质

### 5.1 周期性的定义

三角函数是**周期函数**：
$$\sin(\theta + 2\pi) = \sin\theta, \quad \cos(\theta + 2\pi) = \cos\theta$$
$$\tan(\theta + \pi) = \tan\theta, \quad \cot(\theta + \pi) = \cot\theta$$

正弦和余弦的周期是 $2\pi$，正切和余切的周期是 $\pi$。

### 5.2 周期性的几何解释

📐 **几何理解**：周期性的几何本质是**旋转的周期性**。
- 旋转 $2\pi$（一周）后，点回到原位，所以 $\sin$ 和 $\cos$ 的周期是 $2\pi$
- 正切是从原点到切线的中心投影——旋转 $\pi$（半周）后，点到了对径点，但射线是同一条（方向相反但在同一直线上），所以与切线的交点相同，$\tan$ 的周期是 $\pi$

正切的周期为 $\pi$ 是一个很反直觉的结论——它的几何原因是"中心投影只关心射线的方向，不关心点在射线上的位置"。对径点（相差 $\pi$）在同一条射线上（方向相反），所以它们的中心投影相同。

## 第六章 诱导公式的几何证明

### 6.1 诱导公式的本质

诱导公式是三角函数在各种角度变换下的关系，例如：
$$\sin(\pi - \theta) = \sin\theta, \quad \cos(\pi - \theta) = -\cos\theta$$
$$\sin(\pi/2 - \theta) = \cos\theta, \quad \cos(\pi/2 - \theta) = \sin\theta$$
$$\sin(-\theta) = -\sin\theta, \quad \cos(-\theta) = \cos\theta$$

传统的记忆方法是"奇变偶不变，符号看象限"，但这只是记忆口诀，没有揭示几何本质。

### 6.2 诱导公式的几何证明

所有诱导公式都可以通过**单位圆上的几何变换**来证明：

**1. 负角公式 $\sin(-\theta) = -\sin\theta, \cos(-\theta) = \cos\theta$**：
- 角 $-\theta$ 是角 $\theta$ 关于 x 轴的**反射**
- 反射后，x 坐标不变，y 坐标变号
- 所以 $\cos(-\theta) = \cos\theta$，$\sin(-\theta) = -\sin\theta$

**2. 补角公式 $\sin(\pi-\theta) = \sin\theta, \cos(\pi-\theta) = -\cos\theta$**：
- 角 $\pi-\theta$ 是角 $\theta$ 关于 y 轴的**反射**
- 反射后，y 坐标不变，x 坐标变号
- 所以 $\sin(\pi-\theta) = \sin\theta$，$\cos(\pi-\theta) = -\cos\theta$

**3. 余角公式 $\sin(\pi/2-\theta) = \cos\theta, \cos(\pi/2-\theta) = \sin\theta$**：
- 角 $\pi/2-\theta$ 是角 $\theta$ 关于直线 $y=x$ 的**反射**
- 反射后，x 坐标和 y 坐标互换
- 所以 $\sin(\pi/2-\theta) = \cos\theta$，$\cos(\pi/2-\theta) = \sin\theta$

**4. 加 $\pi$ 公式 $\sin(\theta+\pi) = -\sin\theta, \cos(\theta+\pi) = -\cos\theta$**：
- 角 $\theta+\pi$ 是角 $\theta$ 关于原点的**中心对称**（旋转 $\pi$）
- 中心对称后，x 坐标和 y 坐标都变号
- 所以 $\sin(\theta+\pi) = -\sin\theta$，$\cos(\theta+\pi) = -\cos\theta$

📐 **几何理解**：所有诱导公式都是"单位圆上的对称变换"的结果——反射（关于 x 轴、y 轴、直线 y=x）和旋转（加 $\pi$、加 $\pi/2$）。不需要死记硬背"奇变偶不变符号看象限"——画一个单位圆，看点经过变换后坐标如何变化，公式自然就出来了。

## 第七章 值域与有界性的几何理解

### 7.1 正弦和余弦的值域

因为单位圆上点的坐标在 $[-1, 1]$ 之间，所以：
$$-1 \leq \sin\theta \leq 1, \quad -1 \leq \cos\theta \leq 1$$

正弦和余弦是**有界函数**。

### 7.2 正切和余切的值域

正切是从原点到切线 $x=1$ 的中心投影。当 $\theta$ 从 $-\pi/2$ 到 $\pi/2$ 时，投影点的纵坐标从 $-\infty$ 到 $+\infty$，所以：
$$\tan\theta \in (-\infty, +\infty)$$

正切和余切是**无界函数**。

### 7.3 正割和余割的值域

正割 $\sec\theta = 1/\cos\theta$，因为 $|\cos\theta| \leq 1$，所以：
$$|\sec\theta| \geq 1, \quad \sec\theta \in (-\infty, -1] \cup [1, +\infty)$$

余割类似。

📐 **几何理解**：有界性的几何本质是"投影的范围"。
- 正交投影（正弦/余弦）将单位圆投影到坐标轴上，投影范围是 $[-1, 1]$（有界）
- 中心投影（正切/余切）将单位圆投影到切线上，投影范围是整个实数轴（无界）
- 正割/余割是中心投影的距离，因为投影点到原点的距离至少为 1（切线到原点的距离），所以正割/余割的绝对值至少为 1

## 第八章 反三角函数的几何本质

### 8.1 反三角函数的定义

反三角函数是三角函数的反函数：
- $\arcsin x$：正弦值为 $x$ 的角（主值范围 $[-\pi/2, \pi/2]$）
- $\arccos x$：余弦值为 $x$ 的角（主值范围 $[0, \pi]$）
- $\arctan x$：正切值为 $x$ 的角（主值范围 $(-\pi/2, \pi/2)$）

### 8.2 反三角函数的几何意义

📐 **几何理解**：反三角函数的几何本质是"已知投影求角度"。
- $\arcsin y$：已知单位圆上点的纵坐标为 $y$，求对应的角度
- $\arccos x$：已知单位圆上点的横坐标为 $x$，求对应的角度
- $\arctan t$：已知切线投影点的纵坐标为 $t$，求对应的角度（即从原点看切线墙上高度为 $t$ 的点，视线与 x 轴的夹角）

### 8.3 主值分支的几何意义

由于三角函数是周期函数，一个函数值对应多个角度，所以反三角函数需要选择**主值分支**。

主值分支的几何意义：
- $\arcsin$ 主值 $[-\pi/2, \pi/2]$：选择单位圆的**右半圆**（x ≥ 0），这样每个 y 值对应唯一的点
- $\arccos$ 主值 $[0, \pi]$：选择单位圆的**上半圆**（y ≥ 0），这样每个 x 值对应唯一的点
- $\arctan$ 主值 $(-\pi/2, \pi/2)$：选择切线 $x=1$ 上的所有点（不包括无穷远点），这样每个 t 值对应唯一的射线方向

## 第九章 反直觉结论与常见误区

### 9.1 反直觉结论

**1. 三角函数不是"直角三角形的边长比值"，而是"单位圆上点的坐标"**：
这是最根本的范式转换。直角三角形定义只是锐角情形下的特例。

**2. 正切函数是"透视投影"，不是简单的"正弦除以余弦"**：
$\tan\theta$ 是从原点到切线的中心投影的纵坐标。当 $\theta \to \pi/2$ 时，投影点趋向无穷远——这与绘画中的透视原理一致。

**3. 正切的周期是 $\pi$，不是 $2\pi$**：
因为中心投影只关心射线方向，对径点（相差 $\pi$）在同一条射线上，所以投影相同。

**4. 三角函数与射影几何有深刻联系**：
正弦/余弦 = 平行投影，正切/余切 = 中心投影，正切加法公式 = Möbius 变换的复合，$\arctan$ = 实数轴的紧致化。

**5. 六个三角函数都可以在单位圆上用几何线段表示**：
正弦线、余弦线、正切线、余切线、正割线、余割线——六条线段统一了六个函数。

### 9.2 常见误区

**误区 1**：三角函数只能通过直角三角形定义。
- **纠正**：单位圆定义更一般、更深刻，适用于任意角。

**误区 2**：$\tan\theta = \sin\theta/\cos\theta$ 只是一个代数定义。
- **纠正**：正切有独立的几何意义——从原点到切线的中心投影。

**误区 3**：诱导公式需要死记硬背"奇变偶不变符号看象限"。
- **纠正**：所有诱导公式都是单位圆上对称变换的结果，画图即可推导。

**误区 4**：正切的周期是 $2\pi$。
- **纠正**：正切的周期是 $\pi$，因为对径点的中心投影相同。

**误区 5**：反三角函数的主值分支是人为规定的，没有几何意义。
- **纠正**：主值分支对应于选择单位圆的一个半圆（或切线的一部分），使得投影是一一对应的。

**误区 6**：三角函数的"伸长拉缩"只是数值上的现象，没有深刻几何意义。
- **纠正**：伸长拉缩是中心投影的固有性质，对应于从紧致的圆到非紧致的直线的去紧致化，是射影几何的基本现象。

## 第十章 历史演进

### 10.1 三角函数定义的发展

**古代（公元前）**：
- 古巴比伦：使用弦长（chord），相当于 $2\sin(\theta/2)$
- 古希腊 Hipparchus：编制了第一张弦表，将圆周分为 360 度
- Ptolemy：《天文学大成》中的弦表，精度达到 1/3600 度

**中世纪**：
- 印度数学家：引入了正弦（jya）和余弦（kojya）的概念
- 阿拉伯数学家：引入了正切（zill）和余切，发展了球面三角学

**近代**：
- Euler（1748）：《无穷分析引论》中系统使用单位圆定义三角函数，引入了现代记号 $\sin, \cos, \tan$
- Euler 证明了 $\sin^2 x + \cos^2 x = 1$，引入了弧度制
- Euler 公式 $e^{ix} = \cos x + i\sin x$ 统一了指数函数和三角函数

**射影几何的发展**：
- Desargues（1639）：射影几何的奠基人，引入了无穷远点和交比
- Poncelet（1822）：《论图形的射影性质》，系统建立了射影几何
- 三角函数与射影几何的联系在 19 世纪被逐渐认识，特别是通过 Möbius 变换和非欧几何的研究

### 11.4 特例边

- 特殊角（30°, 45°, 60°, 90°）：三角函数值为简单根式

### 11.5 反例簇边

- 诱导公式不能死记硬背，需要几何理解
