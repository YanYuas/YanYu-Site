## L0 初等直觉层（★ 基础）

**【D7-4-001】** 用欧拉公式计算 e^{iπ/3}，并在复平面上画出它的位置。验证它的模为 1、辐角为 π/3。

- **难度**：★
- **对应知识点**：欧拉公式、复平面、单位圆
- **解答**：
  e^{iπ/3} = cos(π/3) + i sin(π/3) = 1/2 + i(√3/2)。

  模：|e^{iπ/3}| = √((1/2)² + (√3/2)²) = √(1/4 + 3/4) = 1。
  辐角：arg(e^{iπ/3}) = arctan((√3/2)/(1/2)) = arctan(√3) = π/3。∎

  **几何意义**：e^{iπ/3} 是单位圆上角度为 60° 的点。从 (1,0) 出发逆时针旋转 60° 到达 (1/2, √3/2)。
  欧拉公式说的是"指数函数在虚数方向上不是增长，而是旋转"——这是最反直觉的核心。
- **一句话点评**：e^{iπ/3}=1/2+i√3/2，模=1，辐角=π/3。几何=单位圆上60°的点。欧拉公式核心反直觉：虚指数=旋转而非增长。

**【D7-4-002】** 用欧拉公式推导 sin x 和 cos x 的指数表达式：sin x = (e^{ix}-e^{-ix})/(2i)，cos x = (e^{ix}+e^{-ix})/2。

- **难度**：★
- **对应知识点**：欧拉公式、复指数、三角指数表达式
- **解答**：
  e^{ix} = cos x + i sin x ... (1)
  e^{-ix} = cos x - i sin x ... (2)（将 x 替换为 -x）

  (1)+(2)：e^{ix} + e^{-ix} = 2cos x ⟹ cos x = (e^{ix}+e^{-ix})/2。
  (1)-(2)：e^{ix} - e^{-ix} = 2i sin x ⟹ sin x = (e^{ix}-e^{-ix})/(2i)。∎

  **几何意义**：
  e^{ix} 和 e^{-ix} 是单位圆上两个对称的点（关于实轴对称）。
  它们的和 = 2×横坐标 = 2cos x（实部加倍）。
  它们的差 = 2i×纵坐标 = 2i sin x（虚部加倍）。
  所以 cos x 是"两个相反旋转的中点"，sin x 是"两个相反旋转的差除以 2i"。
- **一句话点评**：e^{ix}=cosx+isinx,e^{-ix}=cosx-isinx。相加⟹cosx=(e^{ix}+e^{-ix})/2，相减⟹sinx=(e^{ix}-e^{-ix})/(2i)。几何=单位圆上对称两点的和=2×横坐标，差=2i×纵坐标。

**【D7-4-003】** 计算 i^i 的主值，并验证它是正实数。这是数学中最反直觉的结论之一——虚数的虚数次幂竟然是实数。

- **难度**：★
- **对应知识点**：复幂函数、i^i、反直觉结论
- **解答**：
  i^i = e^{i log i}。
  i = e^{iπ/2}，所以 log i = ln|i| + i(arg i + 2kπ) = 0 + i(π/2 + 2kπ)。

  i^i = e^{i · i(π/2 + 2kπ)} = e^{-(π/2 + 2kπ)}。

  主值（k=0）：i^i = e^{-π/2} ≈ 0.2079。∎

  **为什么是正实数**：
  e^{-(π/2+2kπ)} 对所有整数 k 都是正实数（指数是负实数，e 的实数次幂为正）。
  所以 i^i 的所有值都是正实数！

  **几何理解**：
  i 是"旋转 90°"的操作。i^i 可以理解为"将旋转 90° 这个操作再旋转 90°"——结果变成了实数方向上的缩放（e^{-π/2}）。
  两次旋转的"复合"在指数层面抵消了虚部，留下了纯实数。
  这是欧拉公式最神奇的推论之一。
- **一句话点评**：i^i=e^{i log i}=e^{i·i(π/2+2kπ)}=e^{-(π/2+2kπ)}。主值=e^{-π/2}≈0.2079。所有值都是正实数！几何=旋转90°再旋转90°=实数方向缩放。虚数的虚数次幂=实数，最反直觉。

**【D7-4-004】** 验证欧拉恒等式 e^{iπ} + 1 = 0，并说明它连接了哪五个基本数学常数。

- **难度**：★
- **对应知识点**：欧拉恒等式、五个基本常数
- **解答**：
  e^{iπ} = cos π + i sin π = -1 + i·0 = -1。
  所以 e^{iπ} + 1 = -1 + 1 = 0。∎

  **五个基本常数**：
  | 常数 | 意义 | 来源领域 |
  |---|---|---|
  | 0 | 加法单位元 | 算术 |
  | 1 | 乘法单位元 | 算术 |
  | e | 增长的极限（自然对数底） | 分析 |
  | i | 旋转的生成元（i²=-1） | 代数/几何 |
  | π | 半圆的旋转量（圆周率） | 几何 |

  **几何理解**：
  e^{iπ}：从 (1,0) 出发，在单位圆上旋转 π 弧度（半周），到达 (-1,0)。
  +1：从 -1 加 1，回到 0。
  =0：最终回到原点。
  这是一个完整的"旅程"——从 0 到 1，旋转半周到 -1，再加 1 回到 0，形成完美闭环。
- **一句话点评**：e^{iπ}=cosπ+isinπ=-1⟹e^{iπ}+1=0。连接0(加法单位元)、1(乘法单位元)、e(增长极限)、i(旋转生成元)、π(半圆旋转量)。几何=从1旋转半周到-1再加1回到0=完美闭环。数学中最优美的公式。

## L1 数学分析层

> **引导语**：L1层按"欧拉公式的多种证明→复三角函数的性质→复对数与多值性"三条线索推进。从微分方程到幂级数到旋转群，三种视角证明同一个公式；从复正弦的无界性到复对数的多值性，展示复分析中最反直觉的现象。这是三角学从实数到复数的跃迁。

### 组A：欧拉公式的多种证明

**【D7-4-014】** 计算 e^{iθ} 的模和辐角，证明 |e^{iθ}|=1 对所有实数 θ 成立。由此说明 e^{iθ} 描绘的是单位圆，并解释为什么 e^z 在复平面上不是周期函数但 e^{iz} 是周期函数（周期 2π）。

- **难度**：★★
- **对应知识点**：复指数、模、辐角、周期性
- **解答**：
  **|e^{iθ}|=1**：
  e^{iθ} = cosθ + i sinθ。
  |e^{iθ}| = √(cos²θ + sin²θ) = √1 = 1。∎
  辐角 arg(e^{iθ}) = θ（模 2π）。

  **e^{iθ} 描绘单位圆**：
  当 θ 从 0 变到 2π 时，e^{iθ} 的模始终为 1，辐角从 0 变到 2π，所以它在单位圆上逆时针走了一圈。
  e^{iθ} 是单位圆的参数方程。

  **e^z 不是周期函数**：
  e^z = e^{x+iy} = e^x e^{iy}。
  假设 e^{z+T}=e^z 对所有 z，则 e^T=1 ⟹ T=2kπi。
  但 e^{z+2πi} = e^z e^{2πi} = e^z·1 = e^z——等等，e^z 实际上是周期函数，周期为 2πi！

  **纠正**：e^z 是周期函数，周期为 2πi（纯虚数周期）。
  e^z 在实轴方向上不是周期的（e^{x+T}≠e^x 对实数 T≠0），但在虚轴方向上是周期的。

  **e^{iz} 的周期性**：
  e^{i(z+2π)} = e^{iz+2πi} = e^{iz}·e^{2πi} = e^{iz}。
  所以 e^{iz} 的周期是 2π（实数周期）。
  这就是为什么 sin z 和 cos z（由 e^{iz} 和 e^{-iz} 组成）的周期是 2π。

  **几何理解**：
  e^z = e^x e^{iy}：实部 x 控制模（e^x，缩放），虚部 y 控制辐角（y，旋转）。
  x 增加 = 向外缩放（不周期），y 增加 2π = 旋转一周回到原位（周期）。
  所以 e^z 在虚数方向周期，实数方向不周期。
  e^{iz} = e^{i(x+iy)} = e^{-y}e^{ix}：x 控制旋转（周期 2π），y 控制缩放。
  所以 e^{iz} 在实数方向周期 2π。
- **一句话点评**：|e^{iθ}|=√(cos²θ+sin²θ)=1，辐角=θ⟹单位圆参数方程。e^z=e^x e^{iy}：x控制缩放(不周期),y控制旋转(周期2πi)。e^{iz}=e^{-y}e^{ix}：x控制旋转(周期2π),y控制缩放。sinz,cosz由e^{iz},e^{-iz}组成⟹周期2π。

**【D7-4-005】** 用微分方程法证明欧拉公式：考虑 f(θ)=e^{iθ} 和 g(θ)=cosθ+i sinθ，证明它们满足同一个微分方程 f'=if 和初始条件 f(0)=1，由解的唯一性得 f=g。从几何上解释 f'=if 意味着"速度垂直于位置"=匀速圆周运动。

- **难度**：★★
- **对应知识点**：微分方程法、欧拉公式、匀速圆周运动
- **解答**：
  **f(θ)=e^{iθ}**：
  f'(θ) = i e^{iθ} = i f(θ)。
  f(0) = e^0 = 1。

  **g(θ)=cosθ+i sinθ**：
  g'(θ) = -sinθ + i cosθ = i(cosθ + i sinθ) = i g(θ)。
  g(0) = cos0 + i sin0 = 1。

  f 和 g 满足同一个一阶线性微分方程 y'=iy 和同一个初始条件 y(0)=1。
  由微分方程解的唯一性（Picard-Lindelöf 定理），f(θ)=g(θ) 对所有 θ。
  所以 e^{iθ} = cosθ + i sinθ。∎

  **几何解释**：
  f(θ) 是复平面上的位置向量，f'(θ) 是速度向量。
  f'=if 意味着速度 = 位置 × i = 将位置向量逆时针旋转 90°。
  所以速度始终垂直于位置，且 |f'|=|if|=|f|（速度大小=位置大小）。
  初始位置 f(0)=1（在 (1,0)），初始速度 f'(0)=i（向上，逆时针方向）。
  这正是**匀速圆周运动**的条件——在单位圆上以角速度 1 逆时针运动。
  经过时间 θ 后，位置 = (cosθ, sinθ) = cosθ + i sinθ。

  **深刻理解**：
  指数函数的微分方程 f'=f 在实数轴上描述"增长"（速度=位置，同向加速）。
  在虚数轴上，f'=if 描述"旋转"（速度=位置旋转90°，垂直转向）。
  同一个微分方程，方向不同，行为完全不同——这是欧拉公式最深刻的几何本质。
- **一句话点评**：f=e^{iθ}和g=cosθ+isinθ都满足y'=iy,y(0)=1⟹唯一性⟹f=g。几何：f'=if=速度垂直于位置=匀速圆周运动。指数微分方程f'=f：实数方向=增长，虚数方向=旋转。同一方程不同方向=不同行为。

**【D7-4-006】** 用幂级数法证明欧拉公式：将 e^{iθ} 的 Taylor 展开分离实部和虚部，识别出 cosθ 和 sinθ 的级数。说明这个证明虽然代数严密但缺乏几何直观。

- **难度**：★★
- **对应知识点**：幂级数法、Taylor展开、欧拉公式
- **解答**：
  e^x = ∑_{n=0}^∞ x^n/n! = 1 + x + x²/2! + x³/3! + x⁴/4! + ...

  令 x = iθ：
  e^{iθ} = 1 + iθ + (iθ)²/2! + (iθ)³/3! + (iθ)⁴/4! + (iθ)⁵/5! + ...
  = 1 + iθ - θ²/2! - iθ³/3! + θ⁴/4! + iθ⁵/5! - θ⁶/6! - ...

  分离实部和虚部：
  Re(e^{iθ}) = 1 - θ²/2! + θ⁴/4! - θ⁶/6! + ... = ∑_{n=0}^∞ (-1)^n θ^{2n}/(2n)!
  Im(e^{iθ}) = θ - θ³/3! + θ⁵/5! - θ⁷/7! + ... = ∑_{n=0}^∞ (-1)^n θ^{2n+1}/(2n+1)!

  而 cosθ 和 sinθ 的 Taylor 展开恰好是：
  cosθ = ∑(-1)^n θ^{2n}/(2n)!，sinθ = ∑(-1)^n θ^{2n+1}/(2n+1)!。

  所以 e^{iθ} = cosθ + i sinθ。∎

  **为什么缺乏几何直观**：
  这个证明纯粹是代数操作——代入、展开、分离、识别。
  它没有解释"为什么指数函数和三角函数会有联系"，只是验证了它们的级数相同。
  微分方程法和旋转群法更能揭示几何本质（f'=if=圆周运动，无穷小旋转的极限=矩阵指数）。
  但幂级数法的优点是严格——不需要假设微分方程解的唯一性，只需要级数收敛性。

  **收敛性**：
  e^x 的级数对所有复数 x 绝对收敛（比值判别法：|x|^{n+1}/(n+1)! / (|x|^n/n!) = |x|/(n+1) → 0）。
  所以可以合法地分离实部虚部并重新排列。
- **一句话点评**：e^{iθ}=∑(iθ)^n/n!=1+iθ-θ²/2!-iθ³/3!+θ⁴/4!+...。实部=1-θ²/2!+θ⁴/4!...=cosθ，虚部=θ-θ³/3!+θ⁵/5!...=sinθ。代数严密但缺几何直观。微分方程法/旋转群法更深刻。级数对所有复数绝对收敛。

**【D7-4-011】** 用旋转群法证明欧拉公式：将旋转角 θ 表示为 n 个无穷小旋转 dθ=θ/n 的合成，证明 R(θ)=lim(I+Jθ/n)^n=e^{Jθ}，再通过 J↔i 的代数同构得到 e^{iθ}=cosθ+i sinθ。说明这是最几何化的证明。

- **难度**：★★
- **对应知识点**：旋转群法、矩阵指数、无穷小旋转、欧拉公式
- **解答**：
  **旋转矩阵**：R(θ) = [[cosθ, -sinθ],[sinθ, cosθ]]。
  旋转合成：R(α)R(β)=R(α+β)。

  **无穷小旋转**：
  当 dθ 很小时，cos(dθ)≈1, sin(dθ)≈dθ：
  R(dθ) ≈ [[1, -dθ],[dθ, 1]] = I + dθ [[0,-1],[1,0]] = I + J dθ。
  其中 J = [[0,-1],[1,0]]（旋转90°的矩阵，J²=-I）。

  **旋转 θ = n 个无穷小旋转的合成**：
  R(θ) = R(n·θ/n) = [R(θ/n)]^n ≈ (I + Jθ/n)^n。
  取极限 n→∞：R(θ) = lim_{n→∞}(I+Jθ/n)^n。

  **矩阵指数**：
  矩阵指数的定义：e^{Jθ} = lim_{n→∞}(I+Jθ/n)^n（与标量指数 e^x=lim(1+x/n)^n 完全类似）。
  所以 R(θ) = e^{Jθ}。

  **代数同构**：
  J²=-I，i²=-1，所以由 I,J 生成的代数 {aI+bJ} 与复数 {a+bi} 同构：
  I ↔ 1, J ↔ i, aI+bJ ↔ a+bi。
  在这个同构下：
  e^{Jθ} ↔ e^{iθ}
  R(θ) = [[cosθ,-sinθ],[sinθ,cosθ]] = cosθ·I + sinθ·J ↔ cosθ + i sinθ。
  所以 e^{iθ} = cosθ + i sinθ。∎

  **为什么最几何化**：
  这个证明直接从"旋转"的几何概念出发——旋转是可以合成的，无穷小旋转是 I+Jdθ，有限旋转是无穷小旋转的极限。
  它揭示了"指数"和"旋转"的群论联系：旋转群 SO(2) 的李代数是 so(2)={Jθ}，指数映射 exp: so(2)→SO(2) 将无穷小旋转 Jθ 映射为有限旋转 R(θ)。
  复数是 SO(2) 的一维表示，所以指数映射在复数中就是 e^{iθ}。
  这是李群-李代数理论的初等实例。
- **一句话点评**：R(dθ)≈I+Jdθ(J=[[0,-1],[1,0]],J²=-I)。R(θ)=lim(I+Jθ/n)^n=e^{Jθ}(矩阵指数)。J↔i同构⟹e^{Jθ}↔e^{iθ},R(θ)↔cosθ+isinθ。最几何化：直接从旋转合成出发，无穷小旋转极限=矩阵指数=复指数。李群SO(2)→李代数so(2)的指数映射。

### 组B：复三角函数的性质

**【D7-4-007】** 计算复正弦在纯虚数点的值：sin(iy) = i sinh y，cos(iy) = cosh y。由此证明 |sin(iy)| 可以任意大（复正弦无界），并从几何上解释为什么实正弦有界而复正弦无界。

- **难度**：★★
- **对应知识点**：复三角函数、无界性、双曲函数
- **解答**：
  sin(iy) = (e^{i(iy)} - e^{-i(iy)})/(2i) = (e^{-y} - e^y)/(2i) = i(e^y - e^{-y})/2 = i sinh y。
  cos(iy) = (e^{i(iy)} + e^{-i(iy)})/2 = (e^{-y} + e^y)/2 = cosh y。∎

  **无界性证明**：
  |sin(iy)| = |i sinh y| = |sinh y| = |e^y - e^{-y}|/2。
  当 y → +∞ 时，sinh y = (e^y - e^{-y})/2 → +∞。
  所以 |sin(iy)| → +∞——复正弦无界！

  同理 |cos(iy)| = cosh y → +∞（y→∞）。

  **几何解释**：
  对于实数 x：e^{ix} 和 e^{-ix} 都在单位圆上（模=1），它们的差/和也有界（模≤2），所以 |sin x|≤1, |cos x|≤1。

  对于纯虚数 iy：
  - e^{i(iy)} = e^{-y}（当 y>0 时，模 e^{-y}→0，收缩到原点）
  - e^{-i(iy)} = e^y（当 y>0 时，模 e^y→∞，膨胀到无穷远）
  sin(iy) = (e^{-y} - e^y)/(2i)，当 y 很大时，e^y 远大于 e^{-y}，所以 sin(iy) ≈ -e^y/(2i)，模 ≈ e^y/2 → ∞。

  **核心反直觉**：
  实正弦有界是因为 e^{ix} 和 e^{-ix} 都在单位圆上"互相牵制"。
  复正弦无界是因为在虚数方向上，e^{iz} 和 e^{-iz} 一个收缩一个膨胀，膨胀的那个主导了结果。
  这是"复平面比实轴多了一个维度"带来的深刻变化。
- **一句话点评**：sin(iy)=i sinh y,cos(iy)=cosh y。|sin(iy)|=|sinh y|→∞(y→∞)⟹复正弦无界。几何：实轴上e^{ix},e^{-ix}都在单位圆上(模1)互相牵制⟹有界；虚轴上e^{-y}收缩,e^y膨胀，膨胀主导⟹无界。复平面多一维=行为剧变。

**【D7-4-012】** 证明复三角函数保留所有实三角恒等式：sin²z+cos²z=1，和角公式 sin(z₁+z₂)=sinz₁cosz₂+cosz₁sinz₂。说明为什么这些恒等式从实数推广到复数后仍然成立（解析延拓原理）。

- **难度**：★★
- **对应知识点**：复三角恒等式、解析延拓原理、恒等定理
- **解答**：
  **sin²z+cos²z=1**：
  sin z = (e^{iz}-e^{-iz})/(2i), cos z = (e^{iz}+e^{-iz})/2。
  sin²z + cos²z = [(e^{iz}-e^{-iz})²/(2i)²] + [(e^{iz}+e^{-iz})²/4]
  = [-(e^{2iz}-2+e^{-2iz})/4] + [(e^{2iz}+2+e^{-2iz})/4]
  = (-e^{2iz}+2-e^{-2iz}+e^{2iz}+2+e^{-2iz})/4
  = 4/4 = 1。∎

  **和角公式**：
  sin(z₁+z₂) = (e^{i(z₁+z₂)}-e^{-i(z₁+z₂)})/(2i)
  = (e^{iz₁}e^{iz₂}-e^{-iz₁}e^{-iz₂})/(2i)。

  sinz₁cosz₂+cosz₁sinz₂
  = [(e^{iz₁}-e^{-iz₁})/(2i)]·[(e^{iz₂}+e^{-iz₂})/2] + [(e^{iz₁}+e^{-iz₁})/2]·[(e^{iz₂}-e^{-iz₂})/(2i)]
  = [e^{i(z₁+z₂)}+e^{i(z₁-z₂)}-e^{i(z₂-z₁)}-e^{-i(z₁+z₂)} + e^{i(z₁+z₂)}-e^{i(z₁-z₂)}+e^{i(z₂-z₁)}-e^{-i(z₁+z₂)}]/(4i)
  = [2e^{i(z₁+z₂)}-2e^{-i(z₁+z₂)}]/(4i)
  = (e^{i(z₁+z₂)}-e^{-i(z₁+z₂)})/(2i) = sin(z₁+z₂)。∎

  **解析延拓原理（恒等定理）**：
  如果两个解析函数在一个有聚点的集合上相等，则它们在整个定义域上相等。
  sin²z+cos²z 和 1 都是整函数，它们在实轴上相等（实三角恒等式），实轴有聚点，所以在整个复平面上相等。
  同理，sin(z₁+z₂) 和 sinz₁cosz₂+cosz₁sinz₂ 作为 z₁,z₂ 的解析函数，在实轴上相等，所以在复平面上相等。
  这就是为什么所有实三角恒等式都自动推广到复数——不需要重新证明，解析延拓原理保证了推广。

  **几何理解**：
  复三角函数是实三角函数的"解析延拓"——将定义在实轴上的函数"光滑地扩展"到整个复平面。
  解析延拓是唯一的（恒等定理），所以复三角函数是实三角函数的唯一自然推广。
  所有代数恒等式在延拓后保持，因为解析函数的等式一旦在有聚点的集合上成立，就处处成立。
- **一句话点评**：sin²z+cos²z=1（直接代入指数表达式化简）。和角公式同理。解析延拓原理：两解析函数在有聚点集合(实轴)上相等⟹处处相等。所有实三角恒等式自动推广到复数，不需重证。复三角=实三角的唯一解析延拓。

**【D7-4-008】** 用 Liouville 定理（有界整函数必为常数）证明复正弦和复余弦必然无界。说明这如何是"复分析的强性质迫使函数无界"，与实分析形成对比。

- **难度**：★★
- **对应知识点**：Liouville定理、整函数、无界性
- **解答**：
  **Liouville 定理**：如果 f 是整函数（在整个复平面上解析）且有界，则 f 为常数。

  **证明 sin z 无界**：
  sin z = (e^{iz}-e^{-iz})/(2i) 是整函数（e^{iz} 和 e^{-iz} 都是整函数，整函数的线性组合仍是整函数）。
  sin z 不是常数（例如 sin 0=0, sin(π/2)=1）。
  假设 sin z 有界，则由 Liouville 定理，sin z 为常数——矛盾！
  所以 sin z 无界。∎

  同理 cos z 无界。

  **复分析的强性质**：
  在实分析中，有界的非常数函数很常见（sin x, cos x, 1/(1+x²) 等）。
  但在复分析中，整函数的解析性是一个极强的条件——它意味着函数在每一点都可以展开为幂级数，且幂级数的收敛半径为无穷大。
  这样的函数如果有界，就必须是常数——它无法在无限大的复平面上"振荡"而不伸向无穷远。
  这是复分析独有的深刻结果，实分析中没有对应物。

  **几何理解**：
  整函数的图像是一个"无限光滑"的曲面（在四维空间中，因为复函数需要两个实维度描述定义域，两个描述值域）。
  如果这个曲面有界，它就必须是平的（常数）——无法在无限大的定义域上保持有界的弯曲。
  sin z 和 cos z 的曲面在虚数方向上"伸向无穷远"，这是它们保持非常数的代价。
- **一句话点评**：sinz=(e^{iz}-e^{-iz})/(2i)是整函数且非常数。若有界⟹Liouville定理⟹常数⟹矛盾⟹无界。复分析：整函数解析性极强，有界则必常数。实分析中有界非常数函数常见，复分析中不可能。几何=无限光滑曲面有界则必平。

### 组C：复对数与多值性

**【D7-4-009】** 推导复对数的多值性：log z = ln|z| + i(arg z + 2kπ)。计算 log(-1) 的所有值，并说明为什么实对数 ln(-1) 无意义而复对数 log(-1) 有无穷多个值。

- **难度**：★★
- **对应知识点**：复对数、多值性、辐角
- **解答**：
  **推导**：
  设 z = re^{iθ}（r=|z|>0, θ=arg z），w = log z = u+iv。
  e^w = z ⟹ e^u e^{iv} = re^{iθ}。
  比较模：e^u = r ⟹ u = ln r = ln|z|。
  比较辐角：v = θ + 2kπ（k∈ℤ），因为 e^{iv} 的周期是 2π。
  所以 log z = ln|z| + i(arg z + 2kπ)。∎

  **log(-1)**：
  |-1| = 1，arg(-1) = π（主辐角）。
  log(-1) = ln 1 + i(π + 2kπ) = i(π + 2kπ) = i(2k+1)π。
  所以 log(-1) = ..., -3πi, -πi, πi, 3πi, 5πi, ...（无穷多个值，都是纯虚数）。∎

  **为什么实对数 ln(-1) 无意义**：
  实对数 ln x 定义为 e^y = x 的实数解 y。
  对 x=-1，e^y=-1 没有实数解（因为 e^y>0 对所有实数 y）。
  所以 ln(-1) 在实数范围内无意义。

  **为什么复对数 log(-1) 有意义**：
  在复数范围内，e^y=-1 有解：y=iπ（因为 e^{iπ}=-1）。
  而且由于 e^y 的周期性（e^{y+2πi}=e^y），所有 y=i(2k+1)π 都是解。
  所以复对数有无穷多个值。

  **几何理解**：
  复对数的多值性来自角度的多值性——绕原点旋转一周，角度增加 2π，但点的位置不变。
  log(-1) 的多个值对应"从 1 出发，旋转 (2k+1)π 弧度到达 -1"的不同路径（旋转半周、一周半、两周半...）。
  每多转一周，对数值增加 2πi。
- **一句话点评**：log z=ln|z|+i(arg z+2kπ)。log(-1)=i(2k+1)π（无穷多纯虚数值）。实对数ln(-1)无意义(e^y>0)，复对数有解因为e^{iπ}=-1且周期2πi。几何=多值性来自角度多值性，绕原点一周角度+2π，对数值+2πi。

**【D7-4-010】** 计算 1^i 和 (-1)^i 的所有值，说明为什么 1^i 不只是 1（有无穷多个值），以及这如何挑战了"1 的任何次幂都是 1"的直觉。

- **难度**：★★
- **对应知识点**：复幂函数、多值性、反直觉
- **解答**：
  z^a = e^{a log z}。

  **1^i**：
  log 1 = ln 1 + i(0 + 2kπ) = 2kπi。
  1^i = e^{i · 2kπi} = e^{-2kπ}。
  所以 1^i = ..., e^{4π}, e^{2π}, 1, e^{-2π}, e^{-4π}, ...（无穷多个正实数值）。∎

  **(-1)^i**：
  log(-1) = i(2k+1)π。
  (-1)^i = e^{i · i(2k+1)π} = e^{-(2k+1)π}。
  所以 (-1)^i = ..., e^{3π}, e^π, e^{-π}, e^{-3π}, ...（无穷多个正实数值）。∎

  **为什么 1^i ≠ 1**：
  在实数范围内，1^x = 1 对所有实数 x 成立，因为 1 = e^0，1^x = e^{0·x} = 1。
  但在复数范围内，log 1 不只是 0——它有无穷多个值 2kπi。
  所以 1^i = e^{i · 2kπi} = e^{-2kπ}，不只是 1。
  主值（k=0）是 1，但其他值不是 1。

  **几何理解**：
  1 在复平面上对应"旋转 0 弧度"，但也可以理解为"旋转 2π 弧度"、"旋转 4π 弧度"等（都回到同一点）。
  1^i = e^{i log 1} 将"旋转 2kπ"转化为"缩放 e^{-2kπ}"——不同的旋转圈数对应不同的缩放因子。
  所以 1^i 有无穷多个值，取决于你认为 1 对应"转了多少圈"。
  这彻底挑战了"1 的任何次幂都是 1"的实数直觉。
- **一句话点评**：1^i=e^{i log 1}=e^{i·2kπi}=e^{-2kπ}（无穷多正实数值，主值1）。(-1)^i=e^{-(2k+1)π}。复对数多值⟹复幂多值。几何=1可理解为转0圈/1圈/2圈...，1^i将转圈数转化为缩放因子。挑战"1的任何次幂=1"。

**【D7-4-013】** 描述复对数 log z 的黎曼面构造：无穷多个复平面沿负实轴切开，第 k 层的上沿与第 k+1 层的下沿粘合。说明在这个黎曼面上 log z 是单值函数，以及绕原点一周如何从第 k 层上升到第 k+1 层。

- **难度**：★★
- **对应知识点**：黎曼面、复对数、螺旋面、单值化
- **解答**：
  **黎曼面构造**：
  1. 取无穷多个复平面（去掉原点），编号为 ..., -2, -1, 0, 1, 2, ...
  2. 每个平面沿负实轴切开，形成"上沿"（辐角接近 π）和"下沿"（辐角接近 -π）
  3. 将第 k 层的上沿与第 k+1 层的下沿粘合起来

  **单值性**：
  在第 k 层上，点 z 对应 log z = ln|z| + i(arg z + 2kπ)，其中 arg z ∈ (-π, π)。
  每一层对应 k 的一个值，所以在黎曼面上每个点对应唯一的对数值——log z 成为单值函数。∎

  **绕原点一周**：
  从第 0 层的点 z（辐角 θ）出发，绕原点逆时针旋转一周。
  当接近负实轴时，辐角接近 π，到达第 0 层的上沿。
  上沿与第 1 层的下沿粘合，所以跨过负实轴后进入第 1 层。
  在第 1 层上，辐角从 -π 开始继续增加，对数值 = ln|z| + i(arg z + 2π)。
  绕一周后，对数值增加了 2πi，从第 0 层上升到第 1 层。

  **几何图像**：
  这个黎曼面拓扑上是一个无穷多层的螺旋面——像一个无限长的螺旋楼梯或停车场的螺旋坡道。
  每绕原点一圈，就上升一层，高度（对数值的虚部）增加 2π。
  黎曼面将"多值性"这个代数/分析性质转化为"曲面的拓扑"这个几何性质——多值函数在高维曲面上成为单值函数。

  **与平方根黎曼面对比**：
  √z 的黎曼面只有两层（绕两周回到原值），拓扑上等价于圆柱面。
  log z 的黎曼面有无穷多层（绕任意多周都不回到原值），拓扑上等价于螺旋面。
  层数取决于多值性的"周期"——√z 周期为 2（两层），log z 周期为无穷（无穷层）。
- **一句话点评**：黎曼面=无穷多复平面沿负实轴切开，第k层上沿与第k+1层下沿粘合=螺旋面。第k层上log z=ln|z|+i(arg z+2kπ)，单值。绕原点一周=从第k层上升到k+1层，对数值+2πi。多值性(代数)→曲面拓扑(几何)。√z两层(圆柱面)vs log z无穷层(螺旋面)。

## L2 复变函数层（★★★ 研究）

**【D7-4-015】** 从欧拉公式出发推导 De Moivre 公式 (cosθ+i sinθ)^n = cos(nθ)+i sin(nθ)，并用它计算 (1+i)^100。说明 De Moivre 公式如何是"旋转的迭代"在复数中的表达。

- **难度**：★★★
- **对应知识点**：De Moivre公式、复幂、旋转迭代
- **解答**：
  **推导**：
  由欧拉公式，cosθ+i sinθ = e^{iθ}。
  (cosθ+i sinθ)^n = (e^{iθ})^n = e^{inθ} = cos(nθ)+i sin(nθ)。∎

  **计算 (1+i)^100**：
  1+i = √2 (cos(π/4)+i sin(π/4)) = √2 e^{iπ/4}。
  (1+i)^100 = (√2)^100 e^{i·100·π/4} = 2^50 e^{i25π} = 2^50 e^{iπ} = 2^50 · (-1) = -2^50。∎
  （25π = 12×2π + π，所以 e^{i25π}=e^{iπ}=-1。）

  **旋转的迭代**：
  cosθ+i sinθ = e^{iθ} 是"旋转 θ"的复数表示。
  (e^{iθ})^n = e^{inθ} 是"旋转 θ 重复 n 次" = "旋转 nθ"。
  De Moivre 公式说的就是"n 次旋转 θ 的合成 = 一次旋转 nθ"——这是旋转群可交换性的直接体现。

  在 (1+i)^100 的计算中：
  1+i 的模是 √2（缩放因子），辐角是 π/4（旋转角）。
  100 次幂 = 缩放 (√2)^100 = 2^50 倍，旋转 100×π/4 = 25π = 12圈+半周。
  所以结果是 -2^50（缩放 2^50 倍，旋转半周=取负）。

  **几何理解**：
  复数乘法 = 缩放 × 旋转。
  复数的 n 次幂 = 缩放^n × 旋转(n×角度)。
  De Moivre 公式分离了缩放和旋转——模的 n 次幂和辐角的 n 倍。
  这是复数极坐标形式的威力，也是欧拉公式的核心应用之一。
- **一句话点评**：(cosθ+isinθ)^n=(e^{iθ})^n=e^{inθ}=cos(nθ)+isin(nθ)。(1+i)^100=(√2 e^{iπ/4})^100=2^50 e^{i25π}=2^50 e^{iπ}=-2^50。De Moivre=旋转θ重复n次=旋转nθ。复数幂=缩放^n×旋转(n×角度)。

**【D7-4-016】** 讨论复对数的支割线问题：主值分支 Log z 在去掉负实轴的区域上解析，但跨过负实轴时函数值跳跃 2πi。解释为什么支割线是必要的（否则绕原点一周后函数值不回到原值，违反单值性），以及支割线的选择是任意的（可以选任何从原点出发的射线）。

- **难度**：★★★
- **对应知识点**：支割线、主值分支、单值性、解析性
- **解答**：
  **主值分支**：
  Log z = ln|z| + i Arg z，其中 Arg z ∈ (-π, π]（主辐角）。
  在去掉负实轴（包括原点）的区域 ℂ$-∞,0] 上，Arg z 是连续的，所以 Log z 是解析的。

  **跨过负实轴的跳跃**：
  从上方接近负实轴上的点 -r（r>0）：Arg z → π，Log z → ln r + iπ。
  从下方接近负实轴上的点 -r：Arg z → -π，Log z → ln r - iπ。
  跳跃量 = (ln r + iπ) - (ln r - iπ) = 2πi。∎

  **为什么支割线必要**：
  如果不在复平面上切开一条线，那么可以绕原点一周回到同一点。
  绕原点一周，辐角增加 2π，所以 log z 的值增加 2πi——不回到原值。
  这违反了函数的单值性（同一点对应两个不同的函数值）。
  支割线"禁止"了绕原点的路径，从而使辐角成为单值的，log z 成为单值函数。

  **支割线选择的任意性**：
  负实轴只是最常见的选择（因为主辐角范围 (-π,π] 自然地在负实轴处断开）。
  实际上，可以选任何从原点出发到无穷远的曲线作为支割线——正实轴、正虚轴、甚至一条曲线。
  不同的支割线对应不同的单值分支，它们之间相差 2πi 的整数倍。
  支割线的选择是"人为的"——它不是函数本身的性质，而是我们为了得到单值函数而做的切割。

  **几何理解**：
  支割线就像"把螺旋面剪开成平面"的切口——沿着这条线，螺旋面的不同层被分开了。
  跨过支割线 = 从螺旋面的一层跳到另一层，所以函数值跳跃 2πi。
  切口的位置不影响螺旋面本身的拓扑，只影响我们如何"展开"它。
  黎曼面是函数的"真正定义域"，支割线是将黎曼面投影回平面时产生的"人工边界"。
- **一句话点评**：主值Log z=ln|z|+iArg z,Arg∈(-π,π]，在ℂ$-∞,0]上解析。跨负实轴跳跃2πi(上沿lnr+iπ,下沿lnr-iπ)。支割线必要=禁止绕原点路径(否则辐角+2π,函数不回原值=违反单值性)。支割线选择任意=任何从原点出发的射线。几何=把螺旋面剪开成平面的切口，跨切口=跳层。

## L3 实变函数层（★★★ 研究）

**【D7-4-017】** 从测度论和泛函分析的角度讨论：欧拉公式如何将 L²([0,2π]) 中的 Fourier 基 {e^{inx}} 与三角函数基 {cos(nx), sin(nx)} 联系起来？说明复指数基的正交性 ∫₀^{2π} e^{imx}\overline{e^{inx}}dx = 2πδ_{mn} 如何比实三角基更简洁，以及这如何是"复化简化了正交结构"。

- **难度**：★★★
- **对应知识点**：Fourier基、复指数正交性、L²空间、复化
- **解答**：
  **复指数基**：
  {e^{inx}}_{n∈ℤ} 是 L²([0,2π]) 的正交基（复值函数空间）。
  正交性：∫₀^{2π} e^{imx} \overline{e^{inx}} dx = ∫₀^{2π} e^{i(m-n)x} dx。
  当 m=n 时：∫₀^{2π} 1 dx = 2π。
  当 m≠n 时：∫₀^{2π} e^{i(m-n)x} dx = [e^{i(m-n)x}/(i(m-n))]₀^{2π} = 0（因为 e^{i2πk}=1）。
  所以 ∫ = 2πδ_{mn}。∎

  **与实三角基的关系**：
  由欧拉公式：e^{inx} = cos(nx)+i sin(nx), e^{-inx}=cos(nx)-i sin(nx)。
  所以 cos(nx) = (e^{inx}+e^{-inx})/2, sin(nx) = (e^{inx}-e^{-inx})/(2i)。
  实三角基 {1, cos(nx), sin(nx)} 是复指数基 {e^{inx}} 的实部/虚部分解。

  **复化简化了正交结构**：
  实三角基的正交性需要区分三种情况（cos-cos, sin-sin, cos-sin），且归一化因子不同（1/√(2π), 1/√π）。
  复指数基的正交性只有一种情况：∫e^{imx}\overline{e^{inx}}=2πδ_{mn}，统一且简洁。
  复指数基还是"特征函数基"——e^{inx} 是微分算子 d/dx 的特征函数（特征值 in），而 cos/sin 不是（导数在两者之间转换）。
  这使得复指数基在微分方程、信号处理中更自然。

  **几何理解**：
  e^{inx} 是单位圆上以角速度 n 旋转的点的完整位置（复数值），而 cos(nx)/sin(nx) 只是它的 x/y 投影。
  完整的旋转（复指数）比投影（实三角）有更简洁的代数结构——乘法对应旋转合成，内积对应频率正交。
  这就像用向量 (x,y) 比分别用 x 和 y 更简洁一样——复化将两个实数维度统一为一个复数维度，正交结构自然简化。

  **Hilbert 空间视角**：
  L²([0,2π]; ℂ) 是复 Hilbert 空间，{e^{inx}/√(2π)} 是标准正交基。
  Fourier 级数 f = ∑c_n e^{inx} 中，c_n = (1/2π)∫f(x)e^{-inx}dx 是 f 在基向量上的投影系数。
  这是 Hilbert 空间中"正交分解"的标准形式，比实三角基的 a_n/b_n 双系数更统一。
- **一句话点评**：{e^{inx}}正交性∫e^{imx}\overline{e^{inx}}=2πδ_{mn}（m≠n时e^{i(m-n)x}周期积分=0）。cos=(e^{inx}+e^{-inx})/2,sin=(e^{inx}-e^{-inx})/(2i)。复指数基统一简洁(一种正交关系,归一化2π)，实三角基需区分三种。e^{inx}是d/dx特征函数(特征值in)。几何=完整旋转vs投影，复化统一两维度=正交结构简化。

## 补充基础题（L1 数学分析 / L2 复变函数 / L3 实变函数）

### L1 数学分析基础

**【D7-4-029】** 证明欧拉恒等式：$e^{i\pi}+1=0$。

- **难度**：★
- **解答**：由欧拉公式 $e^{i\theta}=\cos\theta+i\sin\theta$。
令 $\theta=\pi$：$e^{i\pi}=\cos\pi+i\sin\pi=-1+i\cdot0=-1$。
故 $e^{i\pi}+1=0$。
这个等式将数学中最重要的五个常数 $e,i,\pi,1,0$ 统一在一个等式中。∎
- **点评**：欧拉恒等式被誉为"数学中最美的公式"——它将加法、乘法、指数、虚数单位、圆周率、自然对数底和零统一在一起。

**【D7-4-030】** 用幂级数定义指数函数 $e^x=\sum_{n=0}^\infty\frac{x^n}{n!}$，证明其收敛半径为 $\infty$。

- **难度**：★
- **解答**：用比值判别法：$\lim_{n\to\infty}\frac{|x|^{n+1}/(n+1)!}{|x|^n/n!}=\lim\frac{|x|}{n+1}=0<1$ 对所有 $x$。
故收敛半径 $R=\infty$，$e^x$ 是整函数（在全平面解析）。
对复数 $z$，$e^z=\sum\frac{z^n}{n!}$ 同样在全平面收敛。∎
- **点评**：指数函数的幂级数定义——它是整函数（处处解析）。这是复分析中最基本的整函数之一。

**【D7-4-031】** 证明指数函数的加法定理：$e^{z_1+z_2}=e^{z_1}e^{z_2}$。

- **难度**：★★
- **解答**：用幂级数的 Cauchy 乘积：
$e^{z_1}e^{z_2}=(\sum_{n=0}^\infty\frac{z_1^n}{n!})(\sum_{m=0}^\infty\frac{z_2^m}{m!})=\sum_{k=0}^\infty\sum_{n=0}^k\frac{z_1^n z_2^{k-n}}{n!(k-n)!}$
$=\sum_{k=0}^\infty\frac{1}{k!}\sum_{n=0}^k\binom{k}{n}z_1^n z_2^{k-n}=\sum_{k=0}^\infty\frac{(z_1+z_2)^k}{k!}=e^{z_1+z_2}$。
（二项式定理）∎
- **点评**：指数函数的加法定理是其最基本的性质——它将加法转化为乘法。这是指数函数成为"群同态"（加法群到乘法群）的原因。

**【D7-4-032】** 证明：$e^z$ 是周期函数，周期为 $2\pi i$。

- **难度**：★
- **解答**：$e^{z+2\pi i}=e^z\cdot e^{2\pi i}=e^z(\cos 2\pi+i\sin 2\pi)=e^z\cdot1=e^z$。
故 $2\pi i$ 是周期。
$e^z$ 没有实周期（$e^{x+T}=e^x$ ⟹ $e^T=1$ ⟹ $T=2k\pi i$，纯虚数）。
$e^z$ 的所有周期为 $2k\pi i$（$k\in\mathbb{Z}$），基本周期为 $2\pi i$。∎
- **点评**：复指数函数有纯虚周期——这是复分析中最反直觉的事实之一。实指数函数单调递增无周期，但复指数函数在虚轴方向上周期为 $2\pi i$。

### L2 复变函数基础

**【D7-4-033】** 定义复对数函数：$\log z=\ln|z|+i\arg z$，说明其多值性。

- **难度**：★★
- **解答**：对 $z\neq0$，$z=re^{i\theta}$（$r=|z|>0$，$\theta=\arg z$）。
$\log z=\ln r+i(\theta+2k\pi)$（$k\in\mathbb{Z}$）。
多值性来自辐角的多值性：$\arg z$ 可以相差 $2\pi$ 的整数倍。
主值 $\Log z=\ln|z|+i\Arg z$（$\Arg z\in(-\pi,\pi]$），是单值函数。
$\log z$ 在除去负实轴（含原点）的平面上可以定义单值解析分支（取 $\Arg z\in(-\pi,\pi)$）。∎
- **点评**：复对数是多值函数——这是复分析中第一个遇到的多值函数。多值性来自辐角的多值性，需要通过割线（branch cut）来定义单值分支。

**【D7-4-034】** 定义复幂函数 $z^\alpha=e^{\alpha\log z}$，说明其多值性（$\alpha$ 非整数时）。

- **难度**：★★
- **解答**：$z^\alpha=e^{\alpha\log z}=e^{\alpha(\ln|z|+i\arg z)}=|z|^\alpha e^{i\alpha\arg z}$。
若 $\alpha$ 不是整数，$\arg z$ 相差 $2\pi$ 时，$z^\alpha$ 相差 $e^{i2\pi\alpha}\neq1$，故多值。
若 $\alpha=p/q$（有理数，既约分数），则有 $q$ 个不同的值。
若 $\alpha$ 无理数，则有无穷多个值。
若 $\alpha$ 是整数，则单值（$z^n$）。
主值 $z^\alpha=e^{\alpha\Log z}$（用主对数）。∎
- **点评**：复幂函数的多值性——非整数次幂都是多值的。这是复分析中"指数-对数"结构的直接推论。$i^i=e^{i\log i}=e^{i(i\pi/2)}=e^{-\pi/2}$ 是实数（主值），非常反直觉。

**【D7-4-035】** 计算 $i^i$ 的主值和所有值。

- **难度**：★★
- **解答**：$i=e^{i\pi/2}$，$\log i=i(\frac{\pi}{2}+2k\pi)$。
$i^i=e^{i\log i}=e^{i\cdot i(\frac{\pi}{2}+2k\pi)}=e^{-(\frac{\pi}{2}+2k\pi)}$。
主值（$k=0$）：$i^i=e^{-\pi/2}\approx0.2079$（实数！）。
所有值：$e^{-(\pi/2+2k\pi)}$（$k\in\mathbb{Z}$），都是正实数。
这是数学中最反直觉的结果之一——虚数的虚数次幂是实数。∎
- **点评**：$i^i$ 是实数——这是欧拉公式最令人惊叹的推论之一。它说明复数运算可以"跨越"实数和虚数的边界。

### L3 实变函数基础

**【D7-4-036】** 证明：指数函数 $e^x$ 是 $\mathbb{R}$ 上的可测函数（连续函数），且 $e^x>0$ 对所有 $x$。

- **难度**：★
- **解答**：$e^x$ 连续（幂级数定义，处处收敛且内闭一致收敛），故可测。
$e^x=\sum\frac{x^n}{n!}$。对 $x>0$，$e^x>0$（所有项非负且首项为 1）。
对 $x<0$，$e^x=1/e^{-x}>0$（因为 $-x>0$，$e^{-x}>0$）。
$e^0=1>0$。
故 $e^x>0$ 对所有 $x\in\mathbb{R}$。∎
- **点评**：指数函数恒正——这是其最基本的性质。它是从加法群 $(\mathbb{R},+)$ 到乘法群 $(\mathbb{R}_{>0},\times)$ 的同构。

**【D7-4-037】** 指数分布：若随机变量 $X$ 的密度为 $f(x)=\lambda e^{-\lambda x}$（$x\geq0$，$\lambda>0$），证明其无记忆性：$P(X>s+t|X>s)=P(X>t)$。

- **难度**：★★
- **解答**：$P(X>x)=\int_x^\infty\lambda e^{-\lambda t}dt=e^{-\lambda x}$。
$P(X>s+t|X>s)=\frac{P(X>s+t)}{P(X>s)}=\frac{e^{-\lambda(s+t)}}{e^{-\lambda s}}=e^{-\lambda t}=P(X>t)$。
无记忆性是指数分布的特征性质——唯一具有无记忆性的连续分布是指数分布。
几何意义：指数分布描述"等待时间"，已经等待了 $s$ 时间不影响还需等待 $t$ 时间的概率。∎
- **点评**：指数分布的无记忆性——它是唯一具有此性质的连续分布。这来自指数函数的加法定理 $e^{-\lambda(s+t)}=e^{-\lambda s}e^{-\lambda t}$。

**【D7-4-038】** 定义随机变量的特征函数：$\varphi_X(t)=E[e^{itX}]$，证明其一致连续且 $|\varphi_X(t)|\leq1$。

- **难度**：★★
- **解答**：$\varphi_X(t)=\int e^{itx}dF(x)=\int\cos(tx)dF(x)+i\int\sin(tx)dF(x)$。
$|\varphi_X(t)|=|\int e^{itx}dF(x)|\leq\int|e^{itx}|dF(x)=\int1\,dF(x)=1$。
一致连续：$|\varphi_X(t+h)-\varphi_X(t)|=|\int(e^{i(t+h)x}-e^{itx})dF(x)|=|\int e^{itx}(e^{ihx}-1)dF(x)|\leq\int|e^{ihx}-1|dF(x)$。
$|e^{ihx}-1|\leq2$ 且 $\to0$（$h\to0$），由控制收敛定理，$\to0$ 与 $t$ 无关。故一致连续。
特征函数是 Fourier 变换在概率论中的形式，它唯一确定分布。∎
- **点评**：特征函数是概率论的核心工具——它是分布的 Fourier 变换，将卷积转化为乘法。$e^{itx}$ 的有界性（模为 1）保证了特征函数对所有分布都存在。

## 跨领域综合题

### 经典名题

**【D7-4-CROSS-018】**（D7 × D5 级数 × D8 解析）**用欧拉公式计算 Basel 问题 ∑_{n=1}^∞ 1/n² = π²/6 的一种复分析方法：考虑函数 f(z)=π cot(πz)/z² 在正方形围道上的积分，利用留数定理。说明欧拉公式如何使 cot(πz) 的留数计算变得简洁。**

- **难度**：★★★
- **对应知识点**：Basel问题、留数定理、cot的留数、欧拉公式
- **解答**：
  **cot 的指数形式**：
  cot z = cos z/sin z = i(e^{iz}+e^{-iz})/(e^{iz}-e^{-iz})。
  由欧拉公式，这个表达式使得 cot z 的极点和留数分析变得清晰。

  **f(z)=π cot(πz)/z² 的极点**：
  - z=0：三阶极点（cot(πz)≈1/(πz)，所以 f(z)≈π·(1/(πz))/z²=1/z³）
  - z=n（n=±1,±2,...）：一阶极点（cot(πz) 的零点在 sin(πz)=0，即 z=n）

  **留数计算**：
  在 z=n（n≠0）处：
  Res(f, n) = lim_{z→n}(z-n)·π cot(πz)/z²。
  cot(πz) = cos(πz)/sin(πz)，sin(πz)≈π(z-n)（在 z=n 附近），cos(πn)=(-1)^n。
  所以 cot(πz)≈(-1)^n/[π(z-n)]，Res(f,n) = π·(-1)^n/π / n² = (-1)^n/n²。
  等等，实际上 cos(πn)=(-1)^n 但 sin'(πn)=πcos(πn)=π(-1)^n，所以 sin(πz)≈π(-1)^n(z-n)，cot≈(-1)^n/[π(-1)^n(z-n)]=1/[π(z-n)]。
  Res(f,n) = π·(1/π)/n² = 1/n²。∎

  在 z=0 处：
  cot(πz) = 1/(πz) - πz/3 - ...（Laurent 展开）
  f(z) = π[1/(πz) - πz/3 - ...]/z² = 1/z³ - π²/(3z) - ...
  Res(f,0) = -π²/3。

  **围道积分**：
  取顶点为 (N+1/2)(±1±i) 的正方形围道 C_N。
  在 C_N 上 |cot(πz)| 有界（因为远离极点），所以 ∮_{C_N} f(z)dz → 0（N→∞）。
  由留数定理：∮f = 2πi[Res(f,0) + ∑_{n=-N,n≠0}^N Res(f,n)]。
  0 = 2πi[-π²/3 + 2∑_{n=1}^N 1/n²]（因为 Res(f,n)=Res(f,-n)=1/n²）。
  所以 ∑_{n=1}^∞ 1/n² = π²/6。∎

  **欧拉公式的作用**：
  cot z = i(e^{iz}+e^{-iz})/(e^{iz}-e^{-iz}) 使得我们可以分析 cot z 在复平面上的行为。
  特别是，在正方形围道的竖直边上（z=(N+1/2)+iy），|e^{iπz}|=e^{-πy} 和 |e^{-iπz}|=e^{πy}，可以证明 |cot(πz)| 有界。
  没有欧拉公式，很难直接证明 cot(πz) 在大围道上有界——这是留数法的关键。

  **几何理解**：
  Basel 问题的复分析证明利用了 cot(πz) 的极点恰好位于所有整数点，且每个极点的留数为 1/n²。
  围道积分将"无穷级数求和"转化为"围道上的积分"，而围道积分趋于 0——这是留数定理的威力。
  欧拉公式将三角函数转化为复指数，使得极点分析和围道估计成为可能。
- **一句话点评**：f(z)=πcot(πz)/z²，极点z=n(n≠0)留数=1/n²，z=0留数=-π²/3。正方形围道积分→0(|cot|有界，由欧拉公式cot=i(e^{iz}+e^{-iz})/(e^{iz}-e^{-iz})估计)。留数定理⟹0=2πi[-π²/3+2∑1/n²]⟹∑1/n²=π²/6。欧拉公式使围道估计可行。

**【D7-4-CROSS-019】**（D7 × D8 解析 × D6 完备性）**用欧拉公式证明代数基本定理：任何非常数复系数多项式必有复根。思路：假设 P(z) 无实根，则 1/P(z) 是有界整函数，由 Liouville 定理为常数，矛盾。说明欧拉公式（通过复指数 e^{iθ} 参数化单位圆）在证明 |1/P(z)| 的有界性时的作用。**

- **难度**：★★★
- **对应知识点**：代数基本定理、Liouville定理、欧拉公式、有界性
- **解答**：
  **代数基本定理**：非常数复系数多项式 P(z) 至少有一个复根。

  **证明（Liouville 定理法）**：
  设 P(z) = a_n z^n + ... + a_0（a_n≠0, n≥1）。
  假设 P(z) 没有复根，则 1/P(z) 在整个复平面上解析（整函数）。

  **证明 1/P(z) 有界**：
  当 |z|→∞ 时，|P(z)| ≈ |a_n||z|^n → ∞，所以 |1/P(z)| → 0。
  因此存在 R>0，使得当 |z|>R 时 |1/P(z)|&lt;1。
  当 |z|≤R 时，1/P(z) 在紧集（闭圆盘）上连续，所以有界（连续函数在紧集上有界）。
  所以 1/P(z) 在整个复平面上有界。

  由 Liouville 定理，有界整函数 1/P(z) 必为常数 ⟹ P(z) 为常数，与 P 非常数矛盾。
  所以 P(z) 必有复根。∎

  **欧拉公式的作用**：
  在证明 |z|→∞ 时 |P(z)|→∞ 时，可以用欧拉公式参数化：
  令 z = re^{iθ}（r=|z|, θ=arg z），则 P(z) = a_n r^n e^{inθ} + 低次项。
  当 r→∞ 时，主导项 a_n r^n e^{inθ} 的模 |a_n|r^n → ∞，低次项相对可忽略。
  欧拉公式 e^{iθ}=cosθ+i sinθ 使得 z 的极坐标表示成为可能，从而清晰地分离了模（r）和辐角（θ）。
  没有欧拉公式，复数的极坐标形式不自然，多项式在无穷远处的行为分析会更困难。

  **更深刻的联系**：
  代数基本定理的另一种证明（辐角原理）直接使用欧拉公式：
  当 z 沿大圆 |z|=R 逆时针走一圈时，P(z) 的辐角变化 = n×2π（因为 P(z)≈a_n z^n，z 转一圈 P(z) 转 n 圈）。
  由辐角原理，P(z) 在圆内有 n 个零点（计重数）。
  这个证明中，欧拉公式 e^{iθ} 参数化圆周是核心——辐角的变化通过 e^{iθ} 的旋转来度量。

  **几何理解**：
  代数基本定理说"复平面是代数闭的"——任何多项式都能在复数范围内完全分解。
  这与实数域不同（x²+1=0 在实数范围内无解）。
  欧拉公式揭示了复数的"旋转"结构，正是这个二维结构（模+辐角）使得复数域成为代数闭域——多项式的零点可以通过辐角的旋转来"找到"。
- **一句话点评**：若P无实根⟹1/P整函数。|z|→∞时|P|≈|a_n||z|^n→∞(用z=re^{iθ}=欧拉公式极坐标)⟹1/P有界⟹Liouville⟹1/P常数⟹矛盾⟹P有根。辐角原理证明：z沿大圆一圈，P(z)辐角变n×2π⟹n个零点。欧拉公式参数化圆周=辐角变化度量。复数二维结构(模+辐角)=代数闭域。

### 反例与构造

**【D7-4-CROSS-020】**（D7 × D2 连续 × D6 完备性）**构造一个"反直觉"的例子：证明存在整函数 f(z) 使得 f(x) 对所有实数 x 有界，但 f(z) 在复平面上无界。提示：f(z)=sin z 就是这样的函数。讨论这如何说明"实轴上的有界性不能推广到复平面"，以及这与 Liouville 定理的关系。**

- **难度**：★★★
- **对应知识点**：整函数、实轴有界但复平面无界、Liouville定理
- **解答**：
  **例子：f(z)=sin z**：
  对实数 x：|sin x| ≤ 1（有界）。
  对复数 z：|sin z| 无界（如 D7-4-007 所证，|sin(iy)|=|sinh y|→∞）。
  所以 sin z 是整函数，在实轴上有界但在复平面上无界。∎

  **更多例子**：
  - cos z：同样在实轴上有界（|cos x|≤1），复平面上无界。
  - e^{iz}：在实轴上 |e^{ix}|=1（有界），但在虚轴上 |e^{i(iy)}|=e^{-y}→∞（y→-∞）。
  - 任何非常数整函数，如果在实轴上有界，在复平面上必然无界（Liouville 定理）。

  **为什么实轴有界不能推广到复平面**：
  实轴只是复平面的一个一维子集（一条线）。
  函数在一条线上有界，不代表在整个平面上有界——它可以在垂直于实轴的方向上"伸向无穷远"。
  sin z 在实轴上振荡（有界），在虚轴上指数增长（无界）——两个方向上的行为完全不同。
  这就像一个函数在 x 轴上有界，但在 y 轴方向上可以无限增长——一维的有界性不蕴含二维的有界性。

  **与 Liouville 定理的关系**：
  Liouville 定理说"整函数在整个复平面上有界 ⟹ 常数"。
  但"整函数在实轴上有界"不蕴含常数——sin z 就是反例。
  要从"实轴有界"推出"常数"，需要更强的条件，例如：
  - 在一个有聚点的集合上有界（如一个区域内）
  - 或者加上增长速度限制（如指数型 &lt; π 的整函数在实轴上有界 ⟹ 常数，这是 Carlson 定理的精神）

  **几何理解**：
  整函数的图像是四维空间中的二维曲面（定义域二维，值域二维）。
  这个曲面在实轴上方（x 轴方向）是有界的波浪，但在虚轴方向（y 轴方向）可以无限升高。
  就像一张纸——在一个方向上可以折叠（有界），但在垂直方向上可以无限延伸（无界）。
  复平面的二维性使得"一个方向有界、另一个方向无界"成为可能。
- **一句话点评**：sinz整函数，实轴|sinx|≤1有界，复平面|sin(iy)|=|sinh y|→∞无界。实轴只是复平面一维子集，线上有界≠面上有界。Liouville要求面上有界⟹常数，线上有界不够。需更强条件(区域内有界或增长限制)。几何=四维曲面x方向波浪有界，y方向无限延伸。

### 定理串联

**【D7-4-CROSS-021】**（D7 × D8 解析 × D5 级数 × D6 完备性）**建立"欧拉公式 → 复指数 → Fourier 级数 → 调和分析"的完整链条，说明欧拉公式如何是整个调和分析的基石，以及复指数基 e^{inx} 为什么比实三角基更本质。**

- **难度**：★★★
- **对应知识点**：欧拉公式、复指数、Fourier级数、调和分析、四领域统一
- **解答**：
  **第一步：欧拉公式**：
  e^{iθ} = cosθ + i sinθ。
  这将指数函数和三角函数统一，揭示了"虚指数=旋转"。

  **第二步：复指数函数**：
  e^{inx} = cos(nx) + i sin(nx) 是单位圆上以角速度 n 旋转的点。
  它是微分算子 d/dx 的特征函数：d/dx e^{inx} = in e^{inx}。
  它满足乘法性质：e^{imx}·e^{inx}=e^{i(m+n)x}（旋转合成）。

  **第三步：Fourier 级数**：
  任何周期函数 f(x) 可以展开为 f(x) = ∑_{n=-∞}^∞ c_n e^{inx}。
  基 {e^{inx}} 是 L²([0,2π]) 的正交基：∫e^{imx}\overline{e^{inx}}=2πδ_{mn}。
  系数 c_n = (1/2π)∫f(x)e^{-inx}dx 是 f 在频率 n 上的"分量"。

  **第四步：调和分析**：
  Fourier 级数推广到非周期函数 = Fourier 变换：
  \hat f(ξ) = ∫f(x)e^{-iξx}dx, f(x) = (1/2π)∫\hat f(ξ)e^{iξx}dξ。
  复指数 e^{iξx} 是所有频率的"基本振荡"，Fourier 变换将函数分解为不同频率的振荡叠加。
  调和分析研究函数在不同"频率"（群的特征标）上的分解——e^{iξx} 是加法群 ℝ 的特征标。

  **为什么复指数基更本质**：
  1. **特征函数**：e^{inx} 是 d/dx 的特征函数，cos/sin 不是。微分方程在复指数基下对角化。
  2. **乘法封闭**：e^{imx}·e^{inx}=e^{i(m+n)x}，复指数集在乘法下封闭（构成群），cos/sin 的乘积需要和角公式转化。
  3. **统一正交性**：∫e^{imx}\overline{e^{inx}}=2πδ_{mn}，一种关系；实三角基需要三种。
  4. **群论本质**：e^{inx} 是圆周群的特征标（不可约表示），这是 Peter-Weyl 定理的实例。cos/sin 是特征标的实部/虚部，是"派生"的。

  **几何理解**：
  欧拉公式将"旋转"（几何）转化为"复指数"（代数），复指数的叠加构成了所有周期函数。
  调和分析的本质是"将函数分解为不同速度的旋转"——e^{inx} 是角速度 n 的旋转，c_n 是这个旋转的"振幅"。
  这就像白光通过棱镜分解为不同颜色的光——Fourier 变换将函数分解为不同频率的振荡。
  欧拉公式是这个分解的"棱镜"——它让我们看到三角函数背后的旋转本质。

  **四领域统一**：
  | 领域 | 核心对象 | 欧拉公式的角色 |
  |---|---|---|
  | 三角学 | sin, cos | 定义为复指数的实/虚部 |
  | 复分析 | e^{iz}, 解析函数 | 欧拉公式是复指数的基本性质 |
  | 级数/Fourier | e^{inx} 基 | 正交基由复指数构成 |
  | 调和分析 | 特征标, Fourier变换 | e^{iξx} 是群特征标 |
- **一句话点评**：欧拉公式(e^{iθ}=cosθ+isinθ)→复指数e^{inx}(d/dx特征函数,乘法封闭)→Fourier级数(f=∑c_n e^{inx},正交基)→调和分析(Fourier变换,群特征标)。复指数更本质：特征函数/乘法封闭/统一正交/群论特征标。几何=函数分解为不同速度旋转，欧拉公式=棱镜。四领域(三角/复分析/级数/调和分析)通过复指数统一。

**【D7-4-CROSS-022】**（D7 × D3 微分 × D1 极限）**用欧拉公式推导重要极限 lim_{x→0} sin x/x = 1：将 sin x 表示为 (e^{ix}-e^{-ix})/(2i)，利用 e^x 的 Taylor 展开或 lim_{x→0}(e^x-1)/x=1。说明这个极限如何是"弧度制下旋转的局部线性化"。**

- **难度**：★★
- **对应知识点**：重要极限、欧拉公式、Taylor展开、弧度制
- **解答**：
  **方法一：Taylor 展开**：
  sin x = (e^{ix}-e^{-ix})/(2i)。
  e^{ix} = 1 + ix + (ix)²/2! + ... = 1 + ix - x²/2 - ix³/6 + ...
  e^{-ix} = 1 - ix - x²/2 + ix³/6 + ...
  e^{ix}-e^{-ix} = 2ix - 2ix³/6 + ... = 2i(x - x³/6 + ...)
  sin x = x - x³/6 + ...
  所以 sin x/x = 1 - x²/6 + ... → 1（x→0）。∎

  **方法二：利用 lim(e^x-1)/x=1**：
  sin x/x = (e^{ix}-e^{-ix})/(2ix) = [(e^{ix}-1) - (e^{-ix}-1)]/(2ix)
  = (1/2)·(e^{ix}-1)/(ix) + (1/2)·(e^{-ix}-1)/(-ix)
  令 t=ix, s=-ix，当 x→0 时 t,s→0：
  = (1/2)·lim(e^t-1)/t + (1/2)·lim(e^s-1)/s = (1/2)·1 + (1/2)·1 = 1。∎

  **弧度制下旋转的局部线性化**：
  sin x 是单位圆上角度 x 对应的纵坐标。
  当 x 很小时，圆弧 ≈ 弦 ≈ 纵坐标（因为角度小，弧长、弦长、纵坐标几乎相等）。
  弧长 = x（弧度制定义），纵坐标 = sin x，所以 sin x ≈ x ⟹ sin x/x ≈ 1。
  这是"局部线性化"——在小角度下，圆周运动近似为直线运动，弧长 ≈ 纵坐标。

  欧拉公式的视角：e^{ix} ≈ 1+ix（小角度旋转 ≈ 沿切线方向移动 ix），所以 sin x = Im(e^{ix}) ≈ Im(1+ix)=x。
  重要极限是"无穷小旋转 = 切线方向位移"的代数表达。

  **度制下的对比**：
  如果用度制，sin(x°)/x → π/180（因为 x° = πx/180 弧度，sin(πx/180)/(πx/180)→1，所以 sin(x°)/x→π/180）。
  只有弧度制下极限才是 1——这是弧度制"自然"的根本原因。
- **一句话点评**：sinx=(e^{ix}-e^{-ix})/(2i)=x-x³/6+...⟹sinx/x→1。或lim(e^t-1)/t=1代入。几何=小角度下圆弧≈弦≈纵坐标(弧长=x,纵坐标=sinx)⟹sinx≈x。欧拉公式：e^{ix}≈1+ix(小旋转≈切向位移)⟹sinx≈x。度制下极限=π/180，弧度制下=1=弧度制自然的根本原因。

**【D7-4-CROSS-023】**（D7 × D4 积分 × D8 解析）**用欧拉公式计算 ∫₀^{2π} e^{cosθ} cos(sinθ) dθ = 2π。提示：考虑 ∮_{|z|=1} e^z/z dz，用参数化 z=e^{iθ}。说明这如何是"复积分的实部=实积分"的典型技巧。**

- **难度**：★★★
- **对应知识点**：复积分、欧拉公式、Cauchy积分公式、实部技巧
- **解答**：
  **考虑复积分**：
  I = ∮_{|z|=1} e^z/z dz。
  由 Cauchy 积分公式（或留数定理），e^z/z 在 z=0 处的留数为 e^0=1，所以 I = 2πi·1 = 2πi。∎

  **参数化 z=e^{iθ}**：
  z = e^{iθ} = cosθ + i sinθ，dz = i e^{iθ} dθ = iz dθ。
  I = ∫₀^{2π} e^{e^{iθ}}/e^{iθ} · i e^{iθ} dθ = i ∫₀^{2π} e^{e^{iθ}} dθ。

  所以 ∫₀^{2π} e^{e^{iθ}} dθ = I/i = 2πi/i = 2π。

  **取实部**：
  e^{e^{iθ}} = e^{cosθ+i sinθ} = e^{cosθ}·e^{i sinθ} = e^{cosθ}[cos(sinθ)+i sin(sinθ)]。
  Re(e^{e^{iθ}}) = e^{cosθ} cos(sinθ)。
  所以 ∫₀^{2π} e^{cosθ} cos(sinθ) dθ = Re(∫e^{e^{iθ}}dθ) = Re(2π) = 2π。∎

  **复积分的实部=实积分**：
  这个技巧的核心是：将难以计算的实积分 ∫e^{cosθ}cos(sinθ)dθ 嵌入到复积分 ∫e^{e^{iθ}}dθ 中。
  复积分可以用 Cauchy 积分公式/留数定理轻松计算（=2π）。
  然后取实部就得到原实积分的值。
  欧拉公式 e^{iθ}=cosθ+i sinθ 是连接实积分和复积分的桥梁——它将三角函数参数化转化为复指数参数化。

  **几何理解**：
  e^{e^{iθ}} 是"指数函数在单位圆上的值"——e^{iθ} 在单位圆上旋转，e^z 将单位圆映射为一条复杂的曲线（心脏线的变种）。
  积分 ∫e^{e^{iθ}}dθ 是这条曲线的"平均位置"乘以 2π。
  Cauchy 积分公式告诉我们这个平均位置 = e^0 = 1（因为 e^z/z 的留数是 1），所以积分 = 2π。
  实部 e^{cosθ}cos(sinθ) 是这个平均位置的 x 坐标，积分 = 2π。
- **一句话点评**：∮_{|z|=1}e^z/z dz=2πi(Cauchy公式,留数=1)。z=e^{iθ},dz=izdθ⟹i∫e^{e^{iθ}}dθ=2πi⟹∫e^{e^{iθ}}dθ=2π。e^{e^{iθ}}=e^{cosθ}[cos(sinθ)+isin(sinθ)]，取实部⟹∫e^{cosθ}cos(sinθ)dθ=2π。欧拉公式=实积分↔复积分桥梁。几何=e^z将单位圆映射为曲线，平均位置=e^0=1。

**【D7-4-CROSS-024】**（D7 × D6 完备性 × D2 连续）**讨论欧拉公式在"实数完备性"中的角色：为什么必须先有实数的完备性（Dedekind 分割/Cauchy 序列），才能定义 e^x 和 sin x 的幂级数，进而证明欧拉公式？说明如果有理数不完备，e 和 π 都不存在，欧拉公式也无从谈起。**

- **难度**：★★★
- **对应知识点**：实数完备性、幂级数收敛、e和π的存在性、欧拉公式基础
- **解答**：
  **幂级数需要完备性**：
  e^x = ∑x^n/n! 的定义依赖于级数收敛——部分和序列 S_N = ∑_{n=0}^N x^n/n! 必须收敛到某个数。
  在有理数集 ℚ 中，这个序列可能不收敛（极限是无理数 e^x）。
  只有在完备的实数集 ℝ 中，Cauchy 序列才一定收敛，幂级数才有意义。

  **e 和 π 的存在性**：
  e = ∑1/n! 是无理数（实际上是超越数），在有理数集中不存在。
  π 可以定义为 2×∫₀^1 dx/√(1-x²) 或 sin x=0 的最小正根，也是无理数。
  在不完备的有理数集中，e 和 π 都不是"数"——它们只是有理序列的"极限"，但极限不在 ℚ 中。
  没有 e 和 π，欧拉公式 e^{iπ}+1=0 就无从谈起——左边的 e 和 π 都不存在。

  **欧拉公式的证明依赖完备性**：
  - 幂级数法：需要 e^{iθ} 的幂级数收敛到 cosθ+i sinθ——收敛性需要完备性。
  - 微分方程法：需要微分方程解的存在唯一性（Picard 迭代的收敛性）——需要完备性。
  - 旋转群法：需要 lim(I+Jθ/n)^n 存在——矩阵序列的收敛性需要完备性。
  三种证明都以某种方式依赖于"Cauchy 序列收敛"，即实数的完备性。

  **复数的完备性**：
  复数集 ℂ 作为 ℝ² 的度量空间也是完备的（因为 ℝ 完备，有限维完备空间的乘积完备）。
  所以复幂级数 ∑a_n z^n 在收敛圆内收敛到复数值——复指数函数有定义。
  如果实数不完备，复数也不完备，复分析的整个大厦都无法建立。

  **几何理解**：
  实数完备性说的是"实数轴上没有洞"——每一个 Cauchy 序列都有极限。
  e 和 π 就是"有理数轴上的洞"——它们是有理序列的极限，但不在有理数中。
  填满这些洞（完备化）后，e 和 π 成为真正的数，欧拉公式才能成立。
  这就像一幅画——有理数是画中的点，无理数是点之间的空隙，完备性将空隙填满，整幅画（包括 e 和 π）才完整。
  欧拉公式是这幅完整画作中最优美的一笔。
- **一句话点评**：幂级数e^x=∑x^n/n!需要部分和Cauchy序列收敛=实数完备性。e=∑1/n!,π=sinx最小正根都是无理数，在ℚ中不存在。三种证明(幂级数/微分方程/旋转群)都依赖Cauchy序列收敛。复数ℂ=ℝ²也完备⟹复幂级数收敛。不完备⇒e,π不存在⇒欧拉公式无意义。几何=有理数轴有洞，完备化填满洞，e和π成为实数，欧拉公式=完整画作最美一笔。

  **关系推导**：
  cos(ix) = (e^{i(ix)}+e^{-i(ix)})/2 = (e^{-x}+e^x)/2 = cosh x。
  sin(ix) = (e^{i(ix)}-e^{-i(ix)})/(2i) = (e^{-x}-e^x)/(2i) = i(e^x-e^{-x})/2 = i sinh x。
  所以 sinh x = -i sin(ix)（或 sin(ix)=i sinh x）。∎

  **双曲加法公式**：
  cosh(x+y) = cos(i(x+y)) = cos(ix+iy) = cos(ix)cos(iy) - sin(ix)sin(iy)
  = cosh x cosh y - (i sinh x)(i sinh y) = cosh x cosh y + sinh x sinh y。

  sinh(x+y) = -i sin(i(x+y)) = -i sin(ix+iy) = -i[sin(ix)cos(iy)+cos(ix)sin(iy)]
  = -i[i sinh x cosh y + cosh x · i sinh y] = -i·i[sinh x cosh y + cosh x sinh y]
  = sinh x cosh y + cosh x sinh y。∎

  **虚角度的三角恒等式**：
  双曲加法公式就是"将三角和角公式中的角度替换为虚数 ix, iy"后得到的。
  cos(x+y)=cosx cosy-sinx siny → 令 x→ix, y→iy → cosh(x+y)=cosh x cosh y+sinh x sinh y（注意 i²=-1 改变了符号）。
  符号差异（+ vs -）来自 i²=-1——这是欧氏几何和双曲几何的根本区别。

  **双曲几何中的"角度"**：
  在欧氏几何中，单位圆 x²+y²=1 参数化为 (cosθ, sinθ)，θ 是圆心角（弧长/半径）。
  在双曲几何中，单位双曲线 x²-y²=1 参数化为 (coshφ, sinhφ)，φ 称为"双曲角"或"快度"（rapidity）。
  双曲角不是"两条射线的夹角"（在双曲几何中角度的定义不同），而是"双曲线扇形的面积的 2 倍"——类似于欧氏角是圆扇形面积的 2 倍。
  在狭义相对论中，快度 φ 对应速度 v=tanhφ，速度叠加公式 v=(v₁+v₂)/(1+v₁v₂) 对应快度叠加 φ=φ₁+φ₂（线性！）。

  **几何理解**：
  三角函数描述圆（x²+y²=1），双曲函数描述双曲线（x²-y²=1）。
  通过虚角度 θ=iφ，圆变成双曲线（因为 cos(iφ)=coshφ, sin(iφ)=i sinhφ，所以 x²+y²=1 变为 cosh²φ + (i sinhφ)² = cosh²φ - sinh²φ = 1）。
  这是"Wick 旋转"——将欧氏几何的时间维度旋转 90°（虚数化），得到双曲几何/闵可夫斯基时空。
  欧拉公式是这个旋转的数学基础。
- **一句话点评**：cos(ix)=cosh x,sin(ix)=i sinh x⟹sinh x=-i sin(ix)。双曲加法：cosh(x+y)=cosh x cosh y+sinh x sinh y（由cos和角公式令角度→虚数，i²=-1改变符号）。双曲角φ=快度，双曲线扇形面积2倍，相对论速度叠加v=tanhφ对应φ=φ₁+φ₂(线性)。Wick旋转：圆x²+y²=1→θ=iφ→双曲线x²-y²=1。欧拉公式=旋转基础。

**【D7-4-CROSS-026】**（D7 × D5 级数 × D8 解析）**用欧拉公式推导 Gamma 函数的 Euler 反射公式 Γ(z)Γ(1-z)=π/sin(πz)。思路：利用 Γ(z)Γ(1-z)=∫₀^∞ t^{z-1}/(1+t)dt，再用留数定理计算这个积分。说明 sin(πz) 的零点如何对应 Γ 的极点，欧拉公式如何使留数计算简洁。**

- **难度**：★★★
- **对应知识点**：Gamma函数、Euler反射公式、留数定理、欧拉公式
- **解答**：
  **Gamma 函数的积分表示**：
  Γ(z) = ∫₀^∞ t^{z-1}e^{-t}dt（Re z>0）。
  Γ(z)Γ(1-z) = B(z,1-z)·Γ(1) = ∫₀^∞ t^{z-1}/(1+t)dt（Beta 函数积分表示，0&lt;Re z&lt;1）。

  **留数法计算 ∫₀^∞ t^{z-1}/(1+t)dt**：
  考虑多值函数 f(w)=w^{z-1}/(1+w)，取支割线沿正实轴。
  沿"钥匙孔"围道积分：上沿 t^{z-1}=t^{z-1}（辐角0），下沿 t^{z-1}=t^{z-1}e^{2πi(z-1)}（辐角2π）。
  围道内唯一极点 w=-1，留数 = (-1)^{z-1} = e^{iπ(z-1)} = -e^{iπz}。
  围道积分 = 2πi·(-e^{iπz}) = -2πi e^{iπz}。
  另一方面 = ∫₀^∞ t^{z-1}/(1+t)dt - ∫₀^∞ t^{z-1}e^{2πi(z-1)}/(1+t)dt
  = (1-e^{2πi(z-1)})∫₀^∞ t^{z-1}/(1+t)dt = (1-e^{2πiz})∫...
  所以 ∫ = -2πi e^{iπz}/(1-e^{2πiz}) = 2πi e^{iπz}/(e^{2πiz}-1) = 2πi/(e^{iπz}-e^{-iπz}) = π/sin(πz)。∎
  （最后一步：sin(πz)=(e^{iπz}-e^{-iπz})/(2i)，所以 π/sin(πz)=2πi/(e^{iπz}-e^{-iπz})。）

  **欧拉公式的作用**：
  留数计算中 (-1)^{z-1}=e^{iπ(z-1)} 使用了欧拉公式的极坐标形式 -1=e^{iπ}。
  最后的化简 2πi/(e^{iπz}-e^{-iπz})=π/sin(πz) 直接使用了 sin z 的指数表达式（来自欧拉公式）。
  没有欧拉公式，多值函数 w^{z-1} 的辐角处理和 sin(πz) 的表达都会更困难。

  **零点与极点的对应**：
  Γ(z) 在 z=0,-1,-2,... 有极点（Γ(z)≈(-1)^n/(n!(z+n))）。
  Γ(1-z) 在 1-z=0,-1,-2,... 即 z=1,2,3,... 有极点。
  所以 Γ(z)Γ(1-z) 在所有整数 z 处有极点。
  π/sin(πz) 也在所有整数 z 处有极点（sin(πz)=0）。
  反射公式说这两个函数的极点位置完全对应——Γ 的极点恰好是 sin(πz) 的零点。
  这是一个深刻的对应：Gamma 函数的极点结构由正弦函数的零点结构决定。

  **几何理解**：
  Gamma 函数是"阶乘的解析延拓"，它的极点在非正整数处。
  反射公式 Γ(z)Γ(1-z)=π/sin(πz) 将 Gamma 函数与三角函数联系起来——两个看似无关的函数共享极点结构。
  欧拉公式是这个联系的桥梁——它将 sin(πz) 表示为复指数，使得留数计算中自然出现 sin(πz)。
  这是复分析中"不同函数通过极点结构联系"的优美实例。
- **一句话点评**：Γ(z)Γ(1-z)=∫₀^∞t^{z-1}/(1+t)dt。钥匙孔围道：极点w=-1留数=(-1)^{z-1}=e^{iπ(z-1)}（欧拉公式-1=e^{iπ}）。上下沿差因子e^{2πi(z-1)}。⟹积分=2πi/(e^{iπz}-e^{-iπz})=π/sin(πz)（sin指数表达式）。Γ极点z=0,-1,...和Γ(1-z)极点z=1,2,...=所有整数=sin(πz)零点。欧拉公式=极坐标+sin表达。

**【D7-4-CROSS-027】**（D7 × D8 解析 × D6 完备性）**讨论欧拉公式与"解析延拓"的关系：实指数函数 e^x 如何通过幂级数唯一地解析延拓为复指数函数 e^z？实三角函数 sin x, cos x 如何唯一地延拓为复三角函数？说明解析延拓的唯一性（恒等定理）如何保证了欧拉公式 e^{iz}=cos z+i sin z 在整个复平面上成立，而不仅仅在实轴上。**

- **难度**：★★★
- **对应知识点**：解析延拓、恒等定理、欧拉公式、复指数复三角
- **解答**：
  **实指数的解析延拓**：
  e^x = ∑x^n/n! 对所有实数 x 收敛。
  将 x 替换为复数 z，幂级数 ∑z^n/n! 对所有复数 z 绝对收敛（比值判别法），定义了整函数 e^z。
  这是 e^x 从实轴到复平面的解析延拓。
  由恒等定理（两个解析函数在有聚点的集合上相等则处处相等），这个延拓是唯一的——任何在实轴上等于 e^x 的整函数只能是 ∑z^n/n!。

  **实三角函数的解析延拓**：
  sin x = ∑(-1)^n x^{2n+1}/(2n+1)!, cos x = ∑(-1)^n x^{2n}/(2n)!。
  替换 x→z，得到整函数 sin z, cos z——唯一的解析延拓。

  **欧拉公式在复平面上成立**：
  在实轴上，e^{ix}=cos x+i sin x（欧拉公式，对实数 x 成立）。
  考虑函数 F(z)=e^{iz}-cos z-i sin z。
  F(z) 是整函数（e^{iz}, cos z, sin z 都是整函数）。
  在实轴上 F(x)=0（欧拉公式），实轴有聚点。
  由恒等定理，F(z)≡0 在整个复平面上。
  所以 e^{iz}=cos z+i sin z 对所有复数 z 成立！∎

  **解析延拓的威力**：
  解析延拓原理说：如果一个等式在实轴上成立（且两边都是解析函数），那么它自动在整个复平面上成立。
  这意味着我们只需要在实轴上证明欧拉公式（可以用几何或微分方程），然后通过解析延拓，它自动对所有复数成立。
  不需要在复平面上重新证明——解析性"携带"了等式从实轴到整个复平面。

  **更一般的原理**：
  任何只涉及解析函数的等式（如三角恒等式、指数运算法则），如果在实轴上成立，就自动在复平面上成立。
  这就是为什么 sin²z+cos²z=1、和角公式等对复数自动成立（如 D7-4-012）。
  解析延拓是复分析中最强大的工具之一——它将实分析中的结果"免费"推广到复分析。

  **几何理解**：
  解析函数就像一块"无限光滑的冰面"——一旦你知道冰面上一条线（实轴）的形状，整个冰面的形状就被唯一确定了（因为冰面是无限光滑的，不能有折点或突变）。
  欧拉公式在实轴上成立，就像知道了冰面上一条线的高度——整个冰面的高度被唯一确定，所以欧拉公式在整个复平面上成立。
  恒等定理就是"无限光滑的冰面由一条线唯一确定"的数学表述。
- **一句话点评**：e^x=∑x^n/n!→e^z=∑z^n/n!(整函数,唯一解析延拓)。sinx,cosx同理延拓。F(z)=e^{iz}-cosz-isinz整函数，实轴上F=0(有聚点)⟹恒等定理⟹F≡0⟹e^{iz}=cosz+isinz对所有复数成立。解析延拓：实轴上成立的解析函数等式自动推广到复平面。几何=无限光滑冰面由一条线唯一确定，恒等定理=冰面无折点。

**【D7-4-CROSS-028】**（D7 × D1 极限 × D3 微分）**用欧拉公式严格证明重要极限 lim_{n→∞}(1+iθ/n)^n = e^{iθ}，并从几何上解释：(1+iθ/n) 是"接近 1 但稍微向上偏的复数"，自乘 n 次后辐角相加 = θ，模相乘 ≈ 1，所以极限是单位圆上角度 θ 的点。说明这如何是"连续复利"在虚数方向上的对应。**

- **难度**：★★
- **对应知识点**：重要极限、复指数定义、连续复利、几何理解
- **解答**：
  **代数证明**：
  取对数：ln(1+iθ/n) = iθ/n - (iθ/n)²/2 + (iθ/n)³/3 - ... = iθ/n + θ²/(2n²) + O(1/n³)。
  n ln(1+iθ/n) = iθ + θ²/(2n) + O(1/n²) → iθ（n→∞）。
  所以 (1+iθ/n)^n = e^{n ln(1+iθ/n)} → e^{iθ}。∎

  **几何解释**：
  1+iθ/n 对应复平面上的点 (1, θ/n)——非常接近 (1,0)，但稍微向上偏了 θ/n。
  这个点的辐角 ≈ θ/n（因为小角度 tanα≈α），模 ≈ √(1+(θ/n)²) ≈ 1+θ²/(2n²)。

  自乘 n 次（复数乘法=辐角相加+模相乘）：
  - 辐角：n × (θ/n) = θ
  - 模：(1+θ²/(2n²))^n ≈ e^{θ²/(2n)} → 1（n→∞）

  所以极限是模为 1、辐角为 θ 的复数 = e^{iθ} = cosθ+i sinθ。∎

  **连续复利的对应**：
  实数的连续复利：lim(1+x/n)^n = e^x——每次增长 x/n，重复 n 次，极限是连续增长 e^x。
  虚数的"连续复利"：lim(1+iθ/n)^n = e^{iθ}——每次"旋转"θ/n（向上偏），重复 n 次，极限是连续旋转 e^{iθ}。
  实数方向：复利 = 增长（模增加）。
  虚数方向：复利 = 旋转（辐角增加，模不变）。
  同一个极限公式，方向不同，结果完全不同——增长 vs 旋转。

  **深刻理解**：
  这个极限是 e^z 的定义式 e^z=lim(1+z/n)^n 在 z=iθ 时的特例。
  它揭示了 e^z 的几何本质：e^z = "将 1+z/n 这个微小变换重复 n 次的极限"。
  当 z 是实数时，微小变换是"缩放 1+x/n"，重复 = 连续缩放 = 增长。
  当 z 是虚数时，微小变换是"旋转 θ/n"（因为 1+iθ/n ≈ 旋转小角度），重复 = 连续旋转 = 圆周运动。
  这就是欧拉公式最本质的极限定义证明。
- **一句话点评**：n ln(1+iθ/n)=iθ+θ²/(2n)+O(1/n²)→iθ⟹(1+iθ/n)^n→e^{iθ}。几何：1+iθ/n点(1,θ/n)辐角≈θ/n,模≈1+θ²/(2n²)；自乘n次⟹辐角=θ,模→1⟹单位圆上角度θ。连续复利对应：实数lim(1+x/n)^n=e^x=增长，虚数lim(1+iθ/n)^n=e^{iθ}=旋转。同一极限公式方向不同=增长vs旋转。

## 本模块易错点总结

1. **e^{iθ} 不是"指数增长"而是"旋转"**：只有实指数 e^x 才是增长/衰减，虚指数 e^{iθ} 是单位圆上的旋转。这是最核心的反直觉点。
2. **复正弦无界**：|sin z| 可以任意大（取 z=iy，|sin(iy)|=|sinh y|→∞）。与实正弦 |sin x|≤1 形成强烈对比。几何来源是 e^{iz} 和 e^{-iz} 一个收缩一个膨胀。
3. **复对数多值**：log z = ln|z|+i(arg z+2kπ)，有无穷多个值，相差 2πi。实对数 ln x 是单值的。多值性来自角度的多值性（绕原点一周角度+2π）。
4. **i^i 是正实数**：i^i=e^{-(π/2+2kπ)}，所有值都是正实数。主值 e^{-π/2}≈0.2079。虚数的虚数次幂是实数——最反直觉的结论之一。
5. **1^i 不只是 1**：1^i=e^{-2kπ} 有无穷多个值。因为 log 1=2kπi 不只是 0。挑战"1的任何次幂都是1"的实数直觉。
6. **欧拉公式三种证明**：幂级数法（代数严密但缺几何）、微分方程法（f'=if=速度垂直位置=圆周运动，最深刻）、旋转群法（无穷小旋转极限=矩阵指数，最几何）。
7. **Liouville 定理**：有界整函数必为常数。sin z, cos z 是非常数整函数，所以必然无界。这是复分析独有的强性质，实分析中没有对应物。
8. **解析延拓原理**：实轴上成立的解析函数等式自动推广到复平面（恒等定理）。所以所有实三角恒等式对复数自动成立，欧拉公式 e^{iz}=cos z+i sin z 在整个复平面上成立。
9. **黎曼面**：复对数的黎曼面是无穷多层螺旋面，平方根是两层曲面。黎曼面将多值性（代数/分析）转化为曲面拓扑（几何）。
10. **欧拉恒等式**：e^{iπ}+1=0 连接 0（加法单位元）、1（乘法单位元）、e（增长极限）、i（旋转生成元）、π（半圆旋转量）五个基本常数。几何=从1旋转半周到-1再加1回到0=完美闭环。
