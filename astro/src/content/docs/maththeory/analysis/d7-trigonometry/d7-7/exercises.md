## L0 初等直觉层（★ 基础）

**【D7-7-001】** 验证双曲函数的几何定义：计算单位双曲线 x²-y²=1 右支上，由 x 轴、双曲线、从原点到点 (cosh t, sinh t) 的射线围成的面积，证明面积 = t/2。用极坐标面积公式 (1/2)∫(x dy' - y dx') du 计算。

- **难度**：★
- **对应知识点**：双曲函数几何定义、面积参数化、单位双曲线
- **解答**：
  **参数化**：x(u)=cosh u, y(u)=sinh u，u 从 0 到 t。
  dx/du = sinh u, dy/du = cosh u。

  **极坐标面积公式**：
  面积 = (1/2)∫₀ᵗ (x dy/du - y dx/du) du
  = (1/2)∫₀ᵗ (cosh u · cosh u - sinh u · sinh u) du
  = (1/2)∫₀ᵗ (cosh²u - sinh²u) du
  = (1/2)∫₀ᵗ 1 du（利用 cosh²-sinh²=1）
  = t/2。∎

  **与三角函数对比**：
  单位圆上点 (cos t, sin t)，由 x 轴、圆弧、射线围成的扇形面积 = t/2。
  圆用弧长参数化（弧长=t，扇形面积=t/2），双曲线用面积参数化（面积=t/2）。
  两者都是"几何量参数化"，只是圆的弧长简单（=t），双曲线的弧长复杂（涉及椭圆积分），但面积都简单（=t/2）。

  **几何理解**：
  双曲函数不是"人为定义的特殊函数"——它们是单位双曲线上面积参数化的点的坐标，与三角函数是单位圆上弧长参数化的点的坐标完全平行。
  圆和双曲线都是二次曲线（圆锥曲线），它们的"自然参数化"都给出了基本函数——圆给出三角函数，双曲线给出双曲函数。
- **一句话点评**：面积=(1/2)∫(x dy'-y dx')du=(1/2)∫(cosh²-sinh²)du=(1/2)∫1du=t/2。圆用弧长参数化(扇形面积=t/2)，双曲线用面积参数化(面积=t/2)。两者都是圆锥曲线的自然参数化，圆→三角函数，双曲线→双曲函数。

**【D7-7-002】** 用指数表示验证双曲基本恒等式 cosh²x - sinh²x = 1，并对比三角恒等式 cos²x + sin²x = 1。说明符号差异（- vs +）如何来自 i²=-1（将 x 替换为 ix 时 cos(ix)=cosh x, sin(ix)=i sinh x）。

- **难度**：★
- **对应知识点**：双曲基本恒等式、指数表示、符号差异、虚数化
- **解答**：
  **指数表示**：
  cosh x = (eˣ+e⁻ˣ)/2, sinh x = (eˣ-e⁻ˣ)/2。

  **验证恒等式**：
  cosh²x - sinh²x = [(eˣ+e⁻ˣ)/2]² - [(eˣ-e⁻ˣ)/2]²
  = (e²ˣ+2+e⁻²ˣ)/4 - (e²ˣ-2+e⁻²ˣ)/4
  = 4/4 = 1。∎

  **与三角恒等式对比**：
  cos²x + sin²x = [(e^{ix}+e^{-ix})/2]² + [(e^{ix}-e^{-ix})/(2i)]²
  = (e^{2ix}+2+e^{-2ix})/4 + (e^{2ix}-2+e^{-2ix})/(-4)
  = (e^{2ix}+2+e^{-2ix} - e^{2ix}+2-e^{-2ix})/4
  = 4/4 = 1。∎

  **符号差异的来源**：
  将三角函数中的 x 替换为 ix（虚数化）：
  cos(ix) = (e^{i(ix)}+e^{-i(ix)})/2 = (e^{-x}+e^{x})/2 = cosh x。
  sin(ix) = (e^{i(ix)}-e^{-i(ix)})/(2i) = (e^{-x}-e^{x})/(2i) = i(e^{x}-e^{-x})/2 = i sinh x。

  代入 cos²(ix)+sin²(ix)=1：
  cosh²x + (i sinh x)² = 1 ⟹ cosh²x - sinh²x = 1。∎
  负号来自 i²=-1——虚数化将"加"变成了"减"。

  **几何理解**：
  双曲函数和三角函数本质上是同一个复函数的不同侧面——三角函数在实轴上振荡（周期有界），在虚轴上增长（双曲无界）。
  符号差异（+ vs -）是"正曲率"与"负曲率"的代数体现——圆的方程 x²+y²=1 用 +，双曲线的方程 x²-y²=1 用 -。
- **一句话点评**：cosh²-sinh²=[(eˣ+e⁻ˣ)²-(eˣ-e⁻ˣ)²]/4=4/4=1。虚数化：cos(ix)=coshx,sin(ix)=i sinhx，代入cos²+sin²=1⟹cosh²+(i sinh)²=1⟹cosh²-sinh²=1。负号来自i²=-1。双曲函数=复三角函数在虚轴上的取值，振荡(实轴)vs增长(虚轴)。

**【D7-7-003】** 计算双曲函数的导数：(sinh x)'=cosh x, (cosh x)'=sinh x，对比三角函数导数 (sin x)'=cos x, (cos x)'=-sin x。说明为什么 cosh 的导数没有负号——从微分方程 y''=y（正号=指数增长）vs y''=-y（负号=振荡）理解。

- **难度**：★
- **对应知识点**：双曲函数导数、无负号、微分方程、指数增长vs振荡
- **解答**：
  **用指数表示求导**：
  (sinh x)' = [(eˣ-e⁻ˣ)/2]' = (eˣ+e⁻ˣ)/2 = cosh x。∎
  (cosh x)' = [(eˣ+e⁻ˣ)/2]' = (eˣ-e⁻ˣ)/2 = sinh x。∎

  **对比三角函数**：
  (sin x)' = cos x（相同）
  (cos x)' = -sin x（有负号！）

  **为什么 cosh 导数没有负号**：
  从微分方程看：
  - 三角函数满足 y''=-y（负号）。解为 sin x, cos x——振荡函数（周期、有界）。
  - 双曲函数满足 y''=y（正号）。解为 sinh x, cosh x——指数增长函数（无界）。

  负号导致振荡：y''=-y 的特征方程 r²=-1，根 r=±i，解为 e^{±ix}=cos x±i sin x——振荡。
  正号导致增长：y''=y 的特征方程 r²=1，根 r=±1，解为 e^{±x}——指数增长/衰减。

  **几何理解**：
  在单位圆上，点以角速度1运动时，速度方向垂直于半径——横坐标的变化率是 -sin t（逆时针运动时横坐标先减小，负号）。
  在单位双曲线上，点以"面积速度"1运动时，速度方向不垂直于半径——双曲线切线与半径不垂直。横坐标变化率是 sinh t（沿右支向上运动时横坐标在增大，正号）。
  双曲线上的运动是"单调的"（横纵坐标都增大），圆上的运动是"振荡的"（横纵坐标先增后减）。
- **一句话点评**：(sinh)'=cosh,(cosh)'=sinh（无负号）；(sin)'=cos,(cos)'=-sin（有负号）。微分方程：双曲y''=y(正号)⟹特征r²=1⟹r=±1⟹e^{±x}=指数增长；三角y''=-y(负号)⟹r²=-1⟹r=±i⟹e^{±ix}=振荡。圆上速度⊥半径(横坐标先减=负号)，双曲线上速度不⊥半径(横坐标递增=正号)。

**【D7-7-004】** 用双曲函数描述悬链线：悬挂的均匀链条的形状是 y=a cosh(x/a)（悬链线）。验证悬链线的弧长元素 ds=cosh(x/a)dx，并计算从 x=-a 到 x=a 的弧长。对比抛物线 y=x²/(2a)（小挠度近似）的弧长。

- **难度**：★
- **对应知识点**：悬链线、双曲余弦、弧长、抛物线近似
- **解答**：
  **悬链线**：y = a cosh(x/a)。
  dy/dx = a · sinh(x/a) · (1/a) = sinh(x/a)。

  **弧长元素**：
  ds = √(1+(dy/dx)²) dx = √(1+sinh²(x/a)) dx = √(cosh²(x/a)) dx = cosh(x/a) dx。∎
  （利用 1+sinh²=cosh²）

  **从 -a 到 a 的弧长**：
  s = ∫₋ₐᵃ cosh(x/a) dx = a[sinh(x/a)]₋ₐᵃ = a[sinh(1)-sinh(-1)] = 2a sinh(1) ≈ 2a×1.1752 = 2.3504a。∎

  **抛物线近似**：
  小挠度时，cosh(x/a) ≈ 1+x²/(2a²)，所以 y ≈ a+x²/(2a)——抛物线。
  抛物线 y=x²/(2a)（忽略常数a）的弧长：
  dy/dx=x/a, ds=√(1+x²/a²)dx。
  ∫₋ₐᵃ √(1+x²/a²)dx = a∫₋₁¹ √(1+u²)du = a[u√(1+u²)/2 + ln(u+√(1+u²))/2]₋₁¹
  = a[√2 + ln(1+√2)] ≈ a(1.414+0.881) = 2.296a。

  **对比**：
  悬链线弧长 ≈ 2.350a，抛物线近似 ≈ 2.296a，误差约 2.3%。
  小挠度时两者接近，但大挠度时悬链线（双曲余弦）才是精确解——抛物线只是小角度近似。

  **几何理解**：
  悬链线是重力作用下均匀链条的平衡形状——其曲率与高度成正比，cosh x 恰好满足这个条件。
  双曲余弦不仅是"另一个特殊函数"，它是自然界中悬挂链条、电线、拱门的精确形状——这是双曲函数最直观的物理应用。
- **一句话点评**：y=a cosh(x/a),y'=sinh(x/a),ds=√(1+sinh²)dx=cosh(x/a)dx。弧长=∫₋ₐᵃcosh(x/a)dx=2a sinh1≈2.350a。抛物线近似y≈a+x²/(2a),弧长≈2.296a(误差2.3%)。悬链线=均匀链条重力平衡形状,曲率∝高度,cosh精确满足。双曲余弦=自然界悬挂链条/电线/拱门的精确形状。

  双曲余弦不仅是"另一个特殊函数"，它是自然界中悬挂链条、电线、拱门的精确形状——这是双曲函数最直观的物理应用。
- **一句话点评**：y=a cosh(x/a),y'=sinh(x/a),ds=√(1+sinh²)dx=cosh(x/a)dx。弧长=∫₋ₐᵃcosh(x/a)dx=2a sinh1≈2.350a。抛物线近似y≈a+x²/(2a),弧长≈2.296a(误差2.3%)。悬链线=均匀链条重力平衡形状,曲率∝高度,cosh精确满足。双曲余弦=自然界悬挂链条/电线/拱门的精确形状。

### 组A：双曲函数基本性质

**【D7-7-005】** 推导双曲函数的加法公式：sinh(x+y)=sinh x cosh y+cosh x sinh y, cosh(x+y)=cosh x cosh y+sinh x sinh y。用指数表示证明，并对比三角加法公式（注意 cosh 加法公式中是 + 号，cos 加法公式中是 - 号）。

- **难度**：★★
- **对应知识点**：双曲加法公式、指数表示、符号对比、虚数化
- **解答**：
  **sinh(x+y)**：
  sinh(x+y) = [e^{x+y}-e^{-(x+y)}]/2
  = [eˣeʸ-e⁻ˣe⁻ʸ]/2。

  右边 = sinh x cosh y + cosh x sinh y
  = [(eˣ-e⁻ˣ)/2][(eʸ+e⁻ʸ)/2] + [(eˣ+e⁻ˣ)/2][(eʸ-e⁻ʸ)/2]
  = [eˣ⁺ʸ+eˣ⁻ʸ-e⁻ˣ⁺ʸ-e⁻ˣ⁻ʸ + eˣ⁺ʸ-eˣ⁻ʸ+e⁻ˣ⁺ʸ-e⁻ˣ⁻ʸ]/4
  = [2eˣ⁺ʸ-2e⁻ˣ⁻ʸ]/4 = [eˣ⁺ʸ-e⁻ˣ⁻ʸ]/2 = sinh(x+y)。∎

  **cosh(x+y)**：
  cosh(x+y) = [e^{x+y}+e^{-(x+y)}]/2。

  右边 = cosh x cosh y + sinh x sinh y
  = [(eˣ+e⁻ˣ)/2][(eʸ+e⁻ʸ)/2] + [(eˣ-e⁻ˣ)/2][(eʸ-e⁻ʸ)/2]
  = [eˣ⁺ʸ+eˣ⁻ʸ+e⁻ˣ⁺ʸ+e⁻ˣ⁻ʸ + eˣ⁺ʸ-eˣ⁻ʸ-e⁻ˣ⁺ʸ+e⁻ˣ⁻ʸ]/4
  = [2eˣ⁺ʸ+2e⁻ˣ⁻ʸ]/4 = [eˣ⁺ʸ+e⁻ˣ⁻ʸ]/2 = cosh(x+y)。∎

  **与三角加法公式对比**：
  sin(x+y)=sin x cos y+cos x sin y（与 sinh 完全相同）
  cos(x+y)=cos x cos y - sin x sin y（注意是 - 号！）
  cosh(x+y)=cosh x cosh y + sinh x sinh y（是 + 号！）

  **符号差异的来源**：
  将 cos(x+y) 中的 x,y 替换为 ix,iy：
  cos(ix+iy)=cos(ix)cos(iy)-sin(ix)sin(iy)
  = cosh x cosh y - (i sinh x)(i sinh y) = cosh x cosh y + sinh x sinh y。
  负号被 i²=-1 抵消，变成正号。∎

  **几何理解**：
  双曲加法公式与三角加法公式完全平行，只是 cosh 的公式中符号不同——这是"负曲率"的代数体现。
  统一理解：所有双曲函数公式都可以通过"将三角函数公式中的 x 替换为 ix"得到——虚数化自动处理了符号差异。
- **一句话点评**：sinh(x+y)=[eˣ⁺ʸ-e⁻ˣ⁻ʸ]/2=sinhx coshy+coshx sinhy。cosh(x+y)=[eˣ⁺ʸ+e⁻ˣ⁻ʸ]/2=coshx coshy+sinhx sinhy。对比：cos(x+y)=cosx cosy-sinx siny(-号)，cosh是+号。虚数化：cos(ix+iy)=coshx coshy-(i sinhx)(i sinhy)=coshx coshy+sinhx sinhy，负号被i²=-1抵消。

**【D7-7-006】** 推导反双曲函数的对数表示：arcsinh x = ln(x+√(x²+1)), arccosh x = ln(x+√(x²-1))（x≥1）。通过设 y=arcsinh x，则 x=sinh y=(eʸ-e⁻ʸ)/2，解关于 eʸ 的二次方程得到。

- **难度**：★★
- **对应知识点**：反双曲函数、对数表示、二次方程、定义域
- **解答**：
  **arcsinh x**：
  设 y=arcsinh x，则 x=sinh y=(eʸ-e⁻ʸ)/2。
  令 u=eʸ>0，则 x=(u-1/u)/2 ⟹ 2xu=u²-1 ⟹ u²-2xu-1=0。
  u = [2x±√(4x²+4)]/2 = x±√(x²+1)。
  因为 u=eʸ>0，而 x-√(x²+1)&lt;0（√(x²+1)>|x|），所以取正号：
  u=x+√(x²+1) ⟹ y=ln(x+√(x²+1))。∎
  定义域：x∈ℝ（因为 √(x²+1)>|x|，x+√(x²+1)>0 对所有 x 成立）。

  **arccosh x**：
  设 y=arccosh x（y≥0），则 x=cosh y=(eʸ+e⁻ʸ)/2。
  令 u=eʸ≥1，则 x=(u+1/u)/2 ⟹ u²-2xu+1=0。
  u = x±√(x²-1)。
  因为 u=eʸ≥1，需要 x≥1（否则根号内为负）。
  当 x≥1 时，x+√(x²-1)≥1，x-√(x²-1)=1/(x+√(x²-1))≤1。
  y≥0 对应 u≥1，所以取 u=x+√(x²-1)：
  y=ln(x+√(x²-1))。∎
  定义域：x≥1。

  **与反三角函数对比**：
  arcsin x 是三角函数（超越函数），没有简单的对数/代数表示。
  arcsinh x 是双曲函数，可以用对数表示——因为双曲函数是指数函数的组合，其反函数自然是对数。
  这再次说明双曲函数与指数函数的密切关系（实指数），而三角函数与复指数相关（反三角函数涉及复对数）。

  **几何理解**：
  反双曲函数的对数表示说明双曲函数是"指数级"的函数——它们的反函数涉及对数，这与指数函数的反函数是对数一致。
  arcsinh x 的定义域是全体实数（双曲正弦是双射），而 arccosh x 的定义域是 x≥1（双曲余弦不是单射，取主值 y≥0）。
- **一句话点评**：y=arcsinhx⟹x=(eʸ-e⁻ʸ)/2⟹u²-2xu-1=0⟹u=x+√(x²+1)(正根)⟹y=ln(x+√(x²+1)),定义域ℝ。y=arccoshx⟹x=(eʸ+e⁻ʸ)/2⟹u²-2xu+1=0⟹u=x+√(x²-1)⟹y=ln(x+√(x²-1)),定义域x≥1。双曲函数=指数组合⟹反函数=对数；三角函数=复指数⟹反函数=复对数。

**【D7-7-008】** 推导双曲函数的 Taylor 展开：sinh x=x+x³/3!+x⁵/5!+..., cosh x=1+x²/2!+x⁴/4!+...，对比三角函数的交错级数。说明双曲级数没有交错符号（所有项正），因为是实指数 eˣ 的展开，而三角函数是 e^{ix} 的展开（i 的幂交替引入负号）。

- **难度**：★★
- **对应知识点**：Taylor展开、双曲级数、无交错符号、指数展开
- **解答**：
  **从指数表示推导**：
  eˣ = 1+x+x²/2!+x³/3!+x⁴/4!+x⁵/5!+...
  e⁻ˣ = 1-x+x²/2!-x³/3!+x⁴/4!-x⁵/5!+...

  cosh x = (eˣ+e⁻ˣ)/2 = [2+2x²/2!+2x⁴/4!+...]/2 = 1+x²/2!+x⁴/4!+x⁶/6!+... = Σ x^{2n}/(2n)!。∎

  sinh x = (eˣ-e⁻ˣ)/2 = [2x+2x³/3!+2x⁵/5!+...]/2 = x+x³/3!+x⁵/5!+... = Σ x^{2n+1}/(2n+1)!。∎

  **与三角函数对比**：
  cos x = 1-x²/2!+x⁴/4!-x⁶/6!+...（交错符号）
  sin x = x-x³/3!+x⁵/5!-...（交错符号）

  **为什么双曲级数没有交错符号**：
  eˣ 是实指数，所有项都是正的（x>0时），cosh/sinh 是 eˣ 和 e⁻ˣ 的和/差，偶次项/奇次项保留，符号不变。
  e^{ix}=cos x+i sin x 是复指数，i 的幂 i^n 循环为 1,i,-1,-i——偶次项 i^{2n}=(-1)^n 交替引入负号。
  所以 cos x=Σ(-1)^n x^{2n}/(2n)! 有交错符号，cosh x=Σ x^{2n}/(2n)! 没有交错符号。

  **收敛性**：
  双曲函数和三角函数的 Taylor 级数都是整函数（收敛半径=∞），因为 eˣ 和 e^{ix} 都是整函数。
  但双曲级数增长更快（无交错抵消），三角函数级数有交错抵消（部分和振荡收敛到有界函数）。

  **几何理解**：
  Taylor 级数的符号差异反映了函数的本质：双曲函数是指数增长（无界、单调），三角函数是振荡（有界、周期）。
  所有项为正 = 单调增长；交错符号 = 振荡抵消。
  这又是"负曲率"（指数增长）与"零曲率/正曲率"（振荡）的代数体现。
- **一句话点评**：cosh=(eˣ+e⁻ˣ)/2=1+x²/2!+x⁴/4!+...（全正）；sinh=(eˣ-e⁻ˣ)/2=x+x³/3!+x⁵/5!+...（全正）。对比cos=1-x²/2!+x⁴/4!-...（交错），sin=x-x³/3!+...（交错）。双曲=实指数eˣ(无虚数单位)⟹无交错；三角=复指数e^{ix}(i^n=1,i,-1,-i循环)⟹交错负号。全正=单调增长，交错=振荡抵消。都是整函数收敛半径∞。

### 组B：双曲函数的应用

**【D7-7-007】** 用双曲代换计算积分 ∫√(x²+1) dx：令 x=sinh t，则 dx=cosh t dt, √(x²+1)=cosh t，积分变为 ∫cosh²t dt，用倍角公式 cosh²t=(cosh 2t+1)/2 计算，最后代回 x。

- **难度**：★★
- **对应知识点**：双曲代换、积分、倍角公式、反双曲函数
- **解答**：
  **双曲代换**：令 x=sinh t，则 dx=cosh t dt。
  √(x²+1)=√(sinh²t+1)=√(cosh²t)=cosh t（cosh t>0）。

  **积分**：
  ∫√(x²+1)dx = ∫cosh t · cosh t dt = ∫cosh²t dt。

  **倍角公式**：cosh 2t = 2cosh²t-1 ⟹ cosh²t=(cosh 2t+1)/2。
  ∫cosh²t dt = ∫(cosh 2t+1)/2 dt = (1/2)(sinh 2t/2 + t) + C = sinh 2t/4 + t/2 + C。

  **化简**：sinh 2t=2sinh t cosh t=2x√(x²+1)。
  所以积分 = (2x√(x²+1))/4 + t/2 + C = x√(x²+1)/2 + (1/2)arcsinh x + C。
  = x√(x²+1)/2 + (1/2)ln(x+√(x²+1)) + C。∎

  **与三角代换对比**：
  对于 ∫√(x²+1)dx，三角代换令 x=tan t，则 √(x²+1)=sec t, dx=sec²t dt，积分变为 ∫sec³t dt——需要分部积分，较复杂。
  双曲代换 x=sinh t 更简单——因为 sinh²+1=cosh²，根号直接消去，积分变成 cosh²t 的简单积分。
  这是双曲代换的优势：对于 √(x²+a²) 形式，双曲代换比三角代换更自然。

  **几何理解**：
  双曲代换的本质是利用双曲线 x²-y²=1 的参数化——令 x=sinh t 就相当于在双曲线上取点，√(x²+1)=cosh t 是双曲线上点的另一个坐标。
  这与三角代换利用圆 x²+y²=1 的参数化（x=sin t, √(1-x²)=cos t）完全平行——圆用三角代换，双曲线用双曲代换。
- **一句话点评**：x=sinh t,dx=cosh t dt,√(x²+1)=cosh t⟹∫cosh²t dt。cosh²=(cosh2t+1)/2⟹积分=sinh2t/4+t/2+C=x√(x²+1)/2+(1/2)arcsinhx+C=x√(x²+1)/2+(1/2)ln(x+√(x²+1))+C。对比三角代换x=tan t⟹∫sec³t dt(复杂)。双曲代换对√(x²+a²)更自然=双曲线参数化，平行于圆的三角代换。

### 组C：双曲三角学

**【D7-7-011】** 推导双曲余弦定理：cosh a = cosh b cosh c - sinh b sinh c cos A。对比球面余弦定理 cos a=cos b cos c+sin b sin c cos A，说明函数从三角变双曲、符号从+变-都是"曲率从正变负"的体现。用小角度展开验证退化为平面余弦定理。

- **难度**：★★
- **对应知识点**：双曲余弦定理、球面余弦定理对比、曲率决定公式、小角度退化
- **解答**：
  **双曲余弦定理**：cosh a = cosh b cosh c - sinh b sinh c cos A。∎
  （这是双曲几何中的基本定理，可以通过 Poincaré 模型中的距离公式或双曲几何的公理推导。）

  **与球面余弦定理对比**：
  球面：cos a = cos b cos c + sin b sin c cos A
  双曲：cosh a = cosh b cosh c - sinh b sinh c cos A

  两处变化：
  1. cos→cosh, sin→sinh（三角函数→双曲函数）
  2. +→-（中间符号变号）

  这两处变化都来自"曲率从正变负"：
  - 正曲率空间用三角函数（圆函数），负曲率空间用双曲函数（双曲线函数）
  - 正曲率时角盈贡献正号，负曲率时角亏贡献负号

  **虚数化验证**：
  将球面余弦定理中的 a,b,c 替换为 ia,ib,ic（虚数化）：
  cos(ia) = cos(ib)cos(ic) + sin(ib)sin(ic)cos A
  cosh a = cosh b cosh c + (i sinh b)(i sinh c)cos A
  = cosh b cosh c - sinh b sinh c cos A。∎
  正是双曲余弦定理！虚数化将球面公式转化为双曲公式。

  **小角度退化**：
  当 a,b,c≪1 时，cosh a≈1+a²/2, sinh b≈b, sinh c≈c。
  代入：1+a²/2 ≈ (1+b²/2)(1+c²/2) - bc cos A
  ≈ 1+b²/2+c²/2 - bc cos A。
  a²/2 ≈ b²/2+c²/2-bc cos A ⟹ a²≈b²+c²-2bc cos A。∎
  平面余弦定理！

  **几何理解**：
  双曲余弦定理与球面余弦定理形式完全平行，只是函数类型和符号不同——这是"曲率决定几何"的最直接体现。
  通过虚数化（a→ia），球面公式自动转化为双曲公式——正曲率和负曲率是同一个数学结构的两个侧面。
  小角度时两者都退化为平面余弦定理——在小范围内，任何常曲率空间都近似于平面。
- **一句话点评**：双曲余弦定理：cosh a=cosh b cosh c-sinh b sinh c cosA。对比球面：cos a=cos b cos c+sin b sin c cosA。变化：cos→cosh,sin→sinh(函数),+→-(符号)=曲率正→负。虚数化验证：cos(ia)=cosh a,sin(ia)=i sinh a代入球面公式⟹cosh a=cosh b cosh c-sinh b sinh c cosA✓。小角度：cosh≈1+x²/2,sinh≈x⟹a²≈b²+c²-2bc cosA=平面余弦定理。

**【D7-7-012】** 推导双曲正弦定理：sinh a/sin A = sinh b/sin B = sinh c/sin C。对比球面正弦定理 sin a/sin A=...，说明只是把 sin a 换成 sinh a。用双曲余弦定理推导（从 cos A 的表达式出发）。

- **难度**：★★
- **对应知识点**：双曲正弦定理、球面正弦定理对比、余弦定理推导
- **解答**：
  **从双曲余弦定理推导**：
  双曲余弦定理：cosh a = cosh b cosh c - sinh b sinh c cos A。
  解出 cos A = (cosh b cosh c - cosh a)/(sinh b sinh c)。

  sin²A = 1-cos²A = 1 - (cosh b cosh c - cosh a)²/(sinh²b sinh²c)
  = [sinh²b sinh²c - (cosh b cosh c - cosh a)²]/(sinh²b sinh²c)。

  分子展开：
  sinh²b sinh²c - (cosh²b cosh²c - 2cosh a cosh b cosh c + cosh²a)
  = (cosh²b-1)(cosh²c-1) - cosh²b cosh²c + 2cosh a cosh b cosh c - cosh²a
  = cosh²b cosh²c - cosh²b - cosh²c + 1 - cosh²b cosh²c + 2cosh a cosh b cosh c - cosh²a
  = 1 - cosh²a - cosh²b - cosh²c + 2cosh a cosh b cosh c。

  这个表达式关于 a,b,c 对称！记为 Δ = 1-cosh²a-cosh²b-cosh²c+2cosh a cosh b cosh c。

  所以 sin²A = Δ/(sinh²b sinh²c)，即 sin A/sinh a = √Δ/(sinh a sinh b sinh c)。
  同理 sin B/sinh b = √Δ/(sinh a sinh b sinh c)，sin C/sinh c = 同样。
  所以 sinh a/sin A = sinh b/sin B = sinh c/sin C。∎

  **与球面正弦定理对比**：
  球面：sin a/sin A = sin b/sin B = sin c/sin C
  双曲：sinh a/sin A = sinh b/sin B = sinh c/sin C
  只是 sin a→sinh a——边的函数从三角函数变成双曲函数。
  角的函数仍然是 sin A（因为角度在共形模型中保持欧氏角度）。

  **小角度退化**：
  sinh a≈a, sinh b≈b, sinh c≈c，双曲正弦定理退化为 a/sin A=b/sin B=c/sin C——平面正弦定理。∎

  **几何理解**：
  双曲正弦定理与球面正弦定理形式几乎相同，只是边的函数不同——这再次说明曲率决定了边的"度量函数"（正曲率用三角函数，负曲率用双曲函数，零曲率用恒等函数）。
  推导中出现的对称表达式 Δ 是双曲几何中"三角形面积"的代数表达——它与角亏 D 相关。
- **一句话点评**：由双曲余弦定理cosA=(cosh b cosh c-cosh a)/(sinh b sinh c)。sin²A=Δ/(sinh²b sinh²c),Δ=1-cosh²a-cosh²b-cosh²c+2cosh a cosh b cosh c(对称)。⟹sinA/sinh a=√Δ/(sinh a sinh b sinh c)=对称⟹sinh a/sinA=sinh b/sinB=sinh c/sinC。对比球面：sin a/sinA=...，只是sin→sinh。小角度sinh≈x⟹退化为平面正弦定理。曲率决定边的度量函数。

**【D7-7-009】** 证明双曲平面中三角形内角和 &lt; π：用高斯-博内定理 ∫K dA+外角和=2π，双曲平面 K=-1/R²&lt;0，所以 ∫K dA=-S/R²，外角和=3π-(A+B+C)，代入得 A+B+C=π-S/R²&lt;π。定义角亏 D=π-(A+B+C)=S/R²>0。

- **难度**：★★
- **对应知识点**：双曲三角形内角和、高斯-博内、角亏、负曲率
- **解答**：
  **高斯-博内定理**（对双曲三角形，边界是测地线 κ_g=0）：
  ∫_T K dA + Σ外角 = 2π。

  **双曲平面 K=-1/R²（常数）**：
  ∫_T K dA = K·S = -S/R²（S是三角形面积）。

  **外角和**：
  每个外角 = π-内角，外角和 = (π-A)+(π-B)+(π-C) = 3π-(A+B+C)。

  **代入**：
  -S/R² + 3π-(A+B+C) = 2π。
  A+B+C = π - S/R²。∎

  因为 S>0，所以 A+B+C &lt; π——内角和小于180°！

  **角亏**：
  定义 D = π-(A+B+C) = S/R² > 0。
  面积 S = D·R² = (π-A-B-C)R²——双曲三角形面积由角亏决定！

  **与球面/平面对比**：
  - 球面 K>0：A+B+C=π+S/R²>π，角盈 E=S/R²，面积=ER²
  - 平面 K=0：A+B+C=π，角盈=0，面积由边决定
  - 双曲 K&lt;0：A+B+C=π-S/R²&lt;π，角亏 D=S/R²，面积=DR²

  三种情况统一为：A+B+C = π + K·S（K=曲率）。
  正曲率→角盈（内角和>π），零曲率→无盈亏（=π），负曲率→角亏（&lt;π）。

  **几何理解**：
  双曲三角形内角和小于180°是负曲率空间最根本的特征。
  极端情况：当三角形趋向无穷大时，三个角都趋向0，内角和趋向0，面积趋向 πR²（最大面积）。
  这与球面三角形最大面积 2πR²（三角都趋向π）形成对比——双曲和球面的三角形面积都有上界，只有平面三角形面积无界。
- **一句话点评**：Gauss-Bonnet:∫K dA+Σ外角=2π。双曲K=-1/R²⟹∫K dA=-S/R²。外角和=3π-(A+B+C)。⟹-S/R²+3π-(A+B+C)=2π⟹A+B+C=π-S/R²&lt;π。角亏D=π-(A+B+C)=S/R²>0,面积S=DR²。统一公式A+B+C=π+K·S：K>0→角盈,K=0→无盈亏,K&lt;0→角亏。三角形→∞时三角→0,面积→πR²(双曲最大面积)。

### 组D：非欧几何模型

**【D7-7-010】** 在 Poincaré 圆盘模型中，说明"直线"（测地线）是垂直于边界圆的圆弧（或直径），并证明过直线外一点有无穷多条平行线（不与给定直线相交的测地线）。画图描述：给定一条测地线 L 和外一点 P，过 P 可以作无穷多条垂直于边界的圆弧不与 L 相交。

- **难度**：★★
- **对应知识点**：Poincaré圆盘模型、测地线、无穷多平行线、非欧几何
- **解答**：
  **Poincaré 圆盘模型**：
  双曲平面表示为单位圆盘内部（|z|&lt;1）。
  双曲度量：ds² = 4|dz|²/(1-|z|²)²——越靠近边界，同样的欧氏距离对应越大的双曲距离。
  边界圆 |z|=1 对应"无穷远"（双曲距离无穷大）。

  **测地线（"直线"）**：
  Poincaré 圆盘中的测地线是：
  1. 圆盘的直径（过圆心的直线段）
  2. 与边界圆垂直相交的圆弧
  （直径可以看作半径无穷大的圆弧的极限。）
  这些曲线在双曲度量下是"直线"——两点之间的最短路径。

  **无穷多平行线**：
  给定一条测地线 L（垂直于边界的圆弧）和外一点 P。
  过 P 作垂直于边界圆的圆弧——这样的圆弧有无穷多条（圆心在边界圆的极线上变动）。
  其中：
  - 有两条圆弧与 L 在边界上"相切"（渐近线，在无穷远处相交）——称为"平行"或"渐近平行"
  - 介于这两条渐近线之间的圆弧都不与 L 相交——有无穷多条！
  - 其他圆弧与 L 相交。

  所以过 P 有无穷多条不与 L 相交的测地线——双曲几何中过直线外一点有无穷多条平行线！∎

  **与欧氏/球面对比**：
  - 欧氏平面：过直线外一点有且仅有一条平行线（第五公设）
  - 球面：没有平行线（任意两大圆相交）
  - 双曲平面：有无穷多条平行线

  **几何理解**：
  Poincaré 圆盘是共形模型——角度保持不变，但距离被扭曲（边界在无穷远）。
  测地线是垂直于边界的圆弧，因为这样的圆弧在双曲度量下"最直"（测地方程的解）。
  无穷多平行线的存在是双曲几何最反直觉的性质之一——它否定了欧几里得第五公设，标志着非欧几何的诞生。
  Escher 的《圆极限》系列就是基于 Poincaré 圆盘模型——图案越靠近边界越小，但双曲大小相同。
- **一句话点评**：Poincaré圆盘|z|&lt;1,度量ds²=4|dz|²/(1-|z|²)²,边界=无穷远。测地线=垂直边界的圆弧(或直径)。给定L和外点P,过P作垂直边界的圆弧：两条与L在边界相切(渐近线),介于其间的无穷多条都不与L相交⟹无穷多平行线。欧氏=1条,球面=0条,双曲=无穷条。共形模型(角度保持,距离扭曲),Escher《圆极限》基于此模型。

**【D7-7-013】** 计算双曲平面（曲率=-1）中半径为 r 的圆的周长和面积：周长=2π sinh r，面积=2π(cosh r-1)。对比平面（2πr, πr²）和球面（2πR sin(r/R), 2πR²(1-cos(r/R))）。说明大 r 时双曲圆面积指数增长 ≈πeʳ，而平面是多项式增长。

- **难度**：★★
- **对应知识点**：双曲圆、周长面积、指数增长、三种几何对比
- **解答**：
  **双曲圆的周长**（曲率=-1）：
  在 Poincaré 圆盘或上半平面模型中，半径为 r 的圆的周长可以通过积分得到：
  C = 2π sinh r。∎

  **双曲圆的面积**：
  S = ∫₀ʳ C(ρ)dρ = ∫₀ʳ 2π sinh ρ dρ = 2π[cosh ρ]₀ʳ = 2π(cosh r - 1)。∎

  **大 r 渐近**：
  cosh r ≈ eʳ/2（r→∞），所以 S ≈ 2π(eʳ/2-1) ≈ πeʳ——指数增长！
  C ≈ 2π(eʳ/2) = πeʳ——也是指数增长。

  **三种几何对比**（曲率分别为 +1/R², 0, -1）：

  | 几何 | 周长 | 面积 | 大r行为 |
  |---|---|---|---|
  | 球面(K=1/R²) | 2πR sin(r/R) | 2πR²(1-cos(r/R)) | 有上界(≤4πR²) |
  | 平面(K=0) | 2πr | πr² | 多项式增长 |
  | 双曲(K=-1) | 2π sinh r | 2π(cosh r-1) | 指数增长≈πeʳ |

  **圆周率**：
  双曲几何中"圆周率" C/(2r) = π sinh r/r > π，且随 r 增大而增大。
  球面几何中 C/(2r) = πR sin(r/R)/r &lt; π。
  平面中 = π（常数）。

  **几何理解**：
  双曲圆面积指数增长是负曲率空间"无限膨胀"的体现——在双曲平面中，越往外空间"越大"，同样的半径增量对应越来越多的面积。
  这与球面（紧致有限，面积有上界）和平面（多项式增长）形成对比。
  指数增长意味着双曲平面中"邻居数量"指数增长——这是双曲几何在复杂网络中的应用基础（社交网络的度分布指数增长对应双曲几何结构）。
- **一句话点评**：双曲圆(K=-1)：周长=2π sinh r,面积=∫₀ʳ2πsinhρdρ=2π(cosh r-1)。大r：cosh≈eʳ/2⟹面积≈πeʳ(指数增长!),周长≈πeʳ。对比：球面周长=2πR sin(r/R),面积=2πR²(1-cos(r/R))(有上界);平面=2πr,πr²(多项式)。双曲"圆周率"=πsinh r/r>π且递增。负曲率=无限膨胀,邻居数指数增长=复杂网络双曲几何基础。

**【D7-7-014】** 用三种几何的统一公式描述余弦定理：定义广义三角函数 S_K(x)和 C_K(x)（K>0用sin/cos, K=0用x/1, K&lt;0用sinh/cosh），统一余弦定理为 C_K(a)=C_K(b)C_K(c)+K·S_K(b)S_K(c)cos A。验证 K=+1（球面）、K=0（平面）、K=-1（双曲）三种情况。

- **难度**：★★
- **对应知识点**：三种几何统一、广义三角函数、曲率参数、余弦定理统一
- **解答**：
  **广义三角函数定义**：
  - K>0（球面）：S_K(x)=sin(√K x)/√K, C_K(x)=cos(√K x)
  - K=0（平面）：S_K(x)=x, C_K(x)=1
  - K&lt;0（双曲）：S_K(x)=sinh(√|K| x)/√|K|, C_K(x)=cosh(√|K| x)

  **统一余弦定理**：
  C_K(a) = C_K(b)C_K(c) + K·S_K(b)S_K(c)cos A。∎

  **验证 K=+1（球面，单位半径）**：
  S₁(x)=sin x, C₁(x)=cos x。
  cos a = cos b cos c + 1·sin b sin c cos A。∎
  正是球面余弦定理！

  **验证 K=0（平面）**：
  S₀(x)=x, C₀(x)=1。
  1 = 1·1 + 0·b·c·cos A = 1。这是恒等式，没有信息。

  1-Ka²/2 ≈ 1-K(b²+c²)/2+Kbc cos A ⟹ a²≈b²+c²-2bc cos A。∎
  平面余弦定理！

  **验证 K=-1（双曲，曲率-1）**：

  正是双曲余弦定理！

  K=0: a/sinA=...（平面）

  广义三角函数 S_K, C_K 统一了 sin/cos（正曲率）、恒等/常数（零曲率）、sinh/cosh（负曲率）。
  曲率 K 是空间的"内蕴DNA"——它决定了余弦定理形式、正弦定理形式、内角和、平行线、相似性等一切几何性质。
  这是黎曼几何的核心洞察：曲率决定几何。
- **一句话点评**：广义函数：K>0:S_K=sin(√Kx)/√K,C_K=cos(√Kx);K=0:S_K=x,C_K=1;K&lt;0:S_K=sinh(√|K|x)/√|K|,C_K=cosh(√|K|x)。统一余弦定理：C_K(a)=C_K(b)C_K(c)+K S_K(b)S_K(c)cosA。K=+1⟹cosa=cosb cosc+sinb sinc cosA(球面);K→0⟹a²=b²+c²-2bc cosA(平面);K=-1⟹cosha=coshb coshc-sinhb sinhc cosA(双曲)。统一正弦定理S_K(a)/sinA=...。曲率K=空间DNA,决定一切几何性质。

## L2 复变函数层（★★★ 研究）

**【D7-7-015】** 从复分析的角度理解双曲函数：双曲函数是复三角函数在虚数轴上的取值，sin(ix)=i sinh x, cos(ix)=cosh x。说明复三角函数 sin z, cos z 是整函数，在实轴上振荡有界，在虚轴上指数增长无界——这是"同一个函数在不同方向上的不同表现"。讨论复平面上的"双曲区域"与"三角区域"。

- **难度**：★★★
- **对应知识点**：复三角函数、虚轴取值、整函数、振荡vs增长、复平面统一
- **解答**：
  **复三角函数定义**：
  sin z = (e^{iz}-e^{-iz})/(2i), cos z = (e^{iz}+e^{-iz})/2——整函数（全平面解析）。

  **虚轴上的取值**：
  令 z=ix（纯虚数）：
  sin(ix) = (e^{i(ix)}-e^{-i(ix)})/(2i) = (e^{-x}-e^{x})/(2i) = i(e^{x}-e^{-x})/2 = i sinh x。
  cos(ix) = (e^{-x}+e^{x})/2 = cosh x。∎

  **实轴 vs 虚轴**：
  - 实轴 z=x：sin x, cos x 是实值振荡函数，周期 2π，有界（|sin x|≤1, |cos x|≤1）。
  - 虚轴 z=ix：sin(ix)=i sinh x 是纯虚数，cos(ix)=cosh x 是实数，指数增长无界（|sinh x|, cosh x→∞ as x→∞）。
  - 一般复平面 z=x+iy：sin z=sin x cosh y+i cos x sinh y——实部振荡×增长，虚部振荡×增长。|sin z|可以任意大（复三角函数无界！）。

  **复三角函数的无界性**：
  与实三角函数不同，复三角函数 sin z, cos z 在复平面上是无界的——因为沿虚轴方向指数增长。
  这是复分析中"实函数性质不能直接推广到复函数"的经典例子。
  Liouville 定理说有界整函数必为常数——sin z 是整函数但不是常数，所以必然无界，无界性体现在虚轴方向。

  **双曲函数的解析性**：
  sinh z=(eᶻ-e⁻ᶻ)/2, cosh z=(eᶻ+e⁻ᶻ)/2 也是整函数。
  它们与三角函数的关系：sinh z=-i sin(iz), cosh z=cos(iz)——可以互相转化。
  双曲函数的零点：sinh z=0 ⟺ z=nπi（纯虚数！），cosh z=0 ⟺ z=(n+1/2)πi。
  对比：sin z=0 ⟺ z=nπ（实数），cos z=0 ⟺ z=(n+1/2)π。
  双曲函数的零点在虚轴上，三角函数的零点在实轴上——旋转90°的关系。

  **几何理解**：
  复平面将三角函数和双曲函数统一起来——它们是同一个整函数在不同方向上的表现。
  实轴方向=振荡（周期有界），虚轴方向=增长（双曲无界）。
  这就像一个圆柱体——从侧面看是矩形（振荡），从端面看是圆（增长）——同一个几何体的不同视角。
  欧拉公式 e^{ix}=cos x+i sin x 将指数与三角统一，而双曲函数是这个统一体在虚轴上的"投影"。
- **一句话点评**：sin(ix)=i sinhx,cos(ix)=coshx。复三角函数整函数：实轴z=x→振荡有界(|sin|≤1);虚轴z=ix→指数增长无界;一般z=x+iy→sinz=sinx coshy+i cosx sinhy(可任意大)。Liouville定理：有界整函数=常数,sin z非常数⟹必无界(虚轴方向)。双曲零点sinhz=0⟺z=nπi(虚轴),三角零点sinz=0⟺z=nπ(实轴)=旋转90°。复平面统一振荡(实轴)与增长(虚轴)。

**【D7-7-016】** 讨论上半平面模型（H={z:Im z>0}）与双曲几何的关系：双曲度量 ds²=(dx²+dy²)/y²，测地线是垂直于实轴的半圆（或垂直直线）。说明上半平面到 Poincaré 圆盘的 Cayley 变换 w=(z-i)/(z+i) 是 Möbius 变换，保持角度（共形）并将双曲度量相互转化。联系 D8 解析领域的共形映射理论。

- **难度**：★★★
- **对应知识点**：上半平面模型、双曲度量、Cayley变换、Möbius变换、共形映射
- **解答**：
  **上半平面模型**：
  H = {z∈ℂ : Im z > 0}，双曲度量 ds² = (dx²+dy²)/y² = |dz|²/(Im z)²。
  越靠近实轴（y→0），同样的欧氏距离对应越大的双曲距离——实轴是"无穷远边界"。

  **测地线**：
  上半平面中的测地线是：
  1. 垂直于实轴的直线（x=常数）
  2. 圆心在实轴上的半圆（垂直于实轴）
  这些是双曲几何中的"直线"。

  **Cayley 变换**：
  w = (z-i)/(z+i) 将上半平面 H 映射到单位圆盘 D={|w|&lt;1}。
  - z=i（上半平面的"中心"）→ w=0（圆盘中心）
  - z=0（实轴）→ w=-1（边界）
  - z→∞（实轴无穷远）→ w=1（边界）
  实轴映射到单位圆周（边界），上半平面映射到圆盘内部。

  **Cayley 变换是 Möbius 变换**：
  w=(az+b)/(cz+d) 形式，a=1,b=-i,c=1,d=i，满足 ad-bc=i-(-i)=2i≠0。
  Möbius 变换是共形映射（保持角度），且将广义圆（直线或圆）映射为广义圆。
  上半平面的测地线（垂直实轴的半圆/直线）被映射为圆盘的测地线（垂直边界的圆弧/直径）。

  **双曲度量的转化**：
  Cayley 变换将上半平面的度量 ds²=|dz|²/y² 转化为圆盘的度量 ds²=4|dw|²/(1-|w|²)²。
  两个模型是等距的——它们描述同一个双曲几何，只是坐标表示不同。

  **与 D8 解析领域的联系**：
  共形映射是复分析的核心内容——Möbius 变换是最简单的共形映射。
  Riemann 映射定理说任何单连通区域（不是全平面）都共形等价于单位圆盘——上半平面和圆盘只是其中两个例子。
  双曲几何的共形模型利用了复分析的共形映射理论——角度保持使得双曲几何的角度计算可以直接用欧氏角度。
  自守函数（Poincaré 的工作）就是定义在双曲平面上的复变函数，在双曲等距变换下不变。

  **几何理解**：
  上半平面和 Poincaré 圆盘是双曲几何的两个等价模型——通过 Cayley 变换（Möbius 变换）互相转化。
  两者都是共形模型——角度保持不变，但距离被扭曲（边界在无穷远）。
  双曲几何与复分析深刻交织——双曲平面的等距变换群就是 Möbius 变换群（PSL(2,ℝ)），这是复分析中最重要的群之一。
- **一句话点评**：上半平面H={Im z>0},度量ds²=|dz|²/y²,测地线=垂直实轴的半圆/直线。Cayley变换w=(z-i)/(z+i)是Möbius变换(ad-bc=2i≠0),将H共形映射到单位圆盘,实轴→边界圆周,测地线→测地线。度量转化：|dz|²/y²→4|dw|²/(1-|w|²)²,两模型等距。联系D8：Riemann映射定理(单连通区域共形等价圆盘),自守函数(双曲等距下不变的复函数)。双曲等距群=PSL(2,ℝ)=Möbius变换群。

## L3 实变函数层（★★★ 研究）

**【D7-7-017】** 从测度论和几何测度论的角度讨论双曲平面的"无限体积"：双曲平面面积无限（与球面面积有限4πR²对比），但双曲三角形面积有上界 πR²。说明这如何与"双曲圆面积指数增长"一致——圆面积指数增长但三角形面积有界，因为三角形的角趋向0时面积趋向 πR²。

- **难度**：★★★
- **对应知识点**：双曲平面无限体积、三角形面积有界、指数增长vs有界、几何测度论
- **解答**：
  **双曲平面的总面积**：
  双曲平面（曲率=-1/R²）是非紧致的——它的总面积是无限的。
  在 Poincaré 圆盘中，虽然欧氏面积有限（π），但双曲面积元素 dA=4dxdy/(1-|z|²)² 在边界附近发散——积分 ∫_D 4/(1-r²)² · r dr dθ = ∞。∎

  **与球面对比**：
  球面是紧致的，总面积=4πR²（有限）。
  双曲平面是非紧致的，总面积=∞（无限）。
  平面也是非紧致的，总面积=∞。

  **双曲三角形面积有上界**：
  双曲三角形面积 S=(π-A-B-C)R²=DR²（角亏×R²）。
  因为 A,B,C>0，所以 D&lt;π，S&lt;πR²。
  当三角形趋向无穷大（三个顶点趋向边界）时，A,B,C→0，D→π，S→πR²。
  所以双曲三角形面积有上界 πR²！∎

  **与双曲圆面积指数增长的一致性**：
  双曲圆面积=2πR²(cosh(r/R)-1)≈πR²e^{r/R}（大r时指数增长），是无界的。
  双曲三角形面积&lt;πR²，是有界的。
  这看似矛盾，实则一致：
  - 圆是"凸的"，半径增大时面积指数增长——圆可以无限增大。
  - 三角形的三个角必须>0，当三角形增大时角减小，但角不能为负——所以三角形不能无限增大（面积有上界）。
  - 大圆可以包含许多小三角形，但一个三角形不能覆盖整个圆（因为三角形只有三条边，圆有连续的边界）。
  - 指数增长的圆面积意味着可以放入越来越多的三角形，但每个三角形本身有最大面积。

  **几何测度论视角**：
  双曲平面是"无限体积但局部有限"的空间——任何紧致子集面积有限，但整体面积无限。
  这与平面类似（平面也是无限面积），但双曲平面的"增长速度"更快（指数 vs 多项式）。
  等周不等式：双曲平面中面积为 S 的区域，周长 L 满足 L²≥4πS+S²（双曲等周不等式）——比平面的 L²≥4πS 更强，因为负曲率空间中"边界效率"更高。
  球面的等周不等式方向相反（L²≤4πS-S²/R²）。

  **几何理解**：
  双曲平面的无限性是"指数级的无限"——比平面的"多项式无限"更"大"。
  三角形面积有界是因为角亏有上界 π——这是高斯-博内定理的直接推论。
  圆面积无界是因为圆可以无限增大——圆没有"角"的限制。
  这种"整体无限但某些子集有界"的结构是负曲率空间的特征。
- **一句话点评**：双曲平面总面积=∞(Poincaré圆盘dA=4dxdy/(1-r²)²,边界发散)，球面=4πR²(有限紧致)。但双曲三角形面积=(π-A-B-C)R²&lt;πR²(有上界),三角→∞时A,B,C→0,S→πR²。圆面积=2πR²(cosh(r/R)-1)≈πR²e^{r/R}(指数无界)。一致性：圆凸可无限增大,三角形角必须>0限制了最大面积。双曲等周不等式L²≥4πS+S²(比平面L²≥4πS更强,负曲率边界效率高)。指数级无限>多项式无限。

## 补充基础题（L1 数学分析 / L2 复变函数 / L3 实变函数）

### L1 数学分析基础

**【D7-7-028】** 定义双曲函数：$\sinh x=\frac{e^x-e^{-x}}{2}$，$\cosh x=\frac{e^x+e^{-x}}{2}$，$\tanh x=\frac{\sinh x}{\cosh x}$。

- **难度**：★
- **解答**：$\sinh x$（双曲正弦）是奇函数，$\cosh x$（双曲余弦）是偶函数，$\tanh x$（双曲正切）是奇函数。
$\cosh x\geq1$（最小值在 $x=0$ 处为 1），$\sinh x\in\mathbb{R}$，$\tanh x\in(-1,1)$。
与三角函数的类比：$\sinh$ 对应 $\sin$，$\cosh$ 对应 $\cos$，$\tanh$ 对应 $\tan$，但双曲函数不是周期函数。
几何意义：$(\cosh t,\sinh t)$ 参数化等轴双曲线 $x^2-y^2=1$ 的右支，正如 $(\cos t,\sin t)$ 参数化单位圆。∎
- **点评**：双曲函数的定义——它们是指数函数的线性组合，对应双曲线的参数化，正如三角函数对应圆的参数化。

**【D7-7-029】** 证明双曲基本恒等式：$\cosh^2 x-\sinh^2 x=1$。

- **难度**：★
- **解答**：$\cosh^2 x-\sinh^2 x=(\frac{e^x+e^{-x}}{2})^2-(\frac{e^x-e^{-x}}{2})^2$
$=\frac{e^{2x}+2+e^{-2x}}{4}-\frac{e^{2x}-2+e^{-2x}}{4}=\frac{4}{4}=1$。
这对应双曲线方程 $x^2-y^2=1$（$x=\cosh t$，$y=\sinh t$）。
类比：$\cos^2 x+\sin^2 x=1$（单位圆 $x^2+y^2=1$），双曲函数是减号而非加号。∎
- **点评**：双曲基本恒等式——它是双曲线方程 $x^2-y^2=1$ 的代数表达。与三角恒等式 $\cos^2+\sin^2=1$ 的唯一区别是符号。

**【D7-7-030】** 证明双曲函数的导数：$(\sinh x)'=\cosh x$，$(\cosh x)'=\sinh x$，$(\tanh x)'=\text{sech}^2 x$。

- **难度**：★
- **解答**：$(\sinh x)'=(\frac{e^x-e^{-x}}{2})'=\frac{e^x+e^{-x}}{2}=\cosh x$。
$(\cosh x)'=(\frac{e^x+e^{-x}}{2})'=\frac{e^x-e^{-x}}{2}=\sinh x$。
$(\tanh x)'=(\frac{\sinh x}{\cosh x})'=\frac{\cosh^2 x-\sinh^2 x}{\cosh^2 x}=\frac{1}{\cosh^2 x}=\text{sech}^2 x$。
注意：$(\sinh x)'=\cosh x$ 没有负号（与 $(\sin x)'=\cos x$ 相同），但 $(\cosh x)'=\sinh x$ 也没有负号（与 $(\cos x)'=-\sin x$ 不同！）。∎
- **点评**：双曲函数的导数——$\sinh$ 和 $\cosh$ 互为导数（没有负号循环），这与三角函数的 $\sin\leftrightarrow\cos$（带负号）不同。

**【D7-7-031】** 计算双曲函数的积分：$\int\sinh x\,dx=\cosh x+C$，$\int\cosh x\,dx=\sinh x+C$。

- **难度**：★
- **解答**：$\int\sinh x\,dx=\cosh x+C$（因为 $(\cosh x)'=\sinh x$）。
$\int\cosh x\,dx=\sinh x+C$（因为 $(\sinh x)'=\cosh x$）。
$\int\tanh x\,dx=\int\frac{\sinh x}{\cosh x}dx=\ln|\cosh x|+C$（令 $u=\cosh x$）。
类比：$\int\sin x\,dx=-\cos x+C$，$\int\cos x\,dx=\sin x+C$。∎
- **点评**：双曲函数的积分——与导数互为逆运算。$\sinh$ 和 $\cosh$ 的积分没有负号，比三角函数更"对称"。

### L2 复变函数基础

**【D7-7-032】** 证明双曲函数与三角函数的关系：$\sinh(iz)=i\sin z$，$\cosh(iz)=\cos z$，$\sin(iz)=i\sinh z$，$\cos(iz)=\cosh z$。

- **难度**：★★
- **解答**：$\sinh(iz)=\frac{e^{iz}-e^{-iz}}{2}=i\cdot\frac{e^{iz}-e^{-iz}}{2i}=i\sin z$。
$\cosh(iz)=\frac{e^{iz}+e^{-iz}}{2}=\cos z$。
$\sin(iz)=\frac{e^{i(iz)}-e^{-i(iz)}}{2i}=\frac{e^{-z}-e^z}{2i}=i\cdot\frac{e^z-e^{-z}}{2}=i\sinh z$。
$\cos(iz)=\frac{e^{i(iz)}+e^{-i(iz)}}{2}=\frac{e^{-z}+e^z}{2}=\cosh z$。
这些关系说明：双曲函数就是虚轴上的三角函数（旋转 90°）。∎
- **点评**：双曲函数与三角函数的关系——乘以 $i$（虚数单位）就在两者之间转换。这是欧拉公式的直接推论，说明双曲函数和三角函数本质上是同一个函数在不同方向上的限制。

**【D7-7-033】** 证明：$\sinh z$ 和 $\cosh z$ 是整函数，零点分别为 $z=k\pi i$ 和 $z=(k+\frac{1}{2})\pi i$。

- **难度**：★★
- **解答**：$\sinh z=\frac{e^z-e^{-z}}{2}$，$\cosh z=\frac{e^z+e^{-z}}{2}$，都是整函数（指数函数的线性组合）。
$\sinh z=0$ ⟺ $e^z=e^{-z}$ ⟺ $e^{2z}=1$ ⟺ $2z=2k\pi i$ ⟺ $z=k\pi i$（$k\in\mathbb{Z}$）。
$\cosh z=0$ ⟺ $e^z=-e^{-z}$ ⟺ $e^{2z}=-1$ ⟺ $2z=(2k+1)\pi i$ ⟺ $z=(k+\frac{1}{2})\pi i$。
注意：零点都在虚轴上！（与 $\sin z$ 的零点在实轴上对比）。∎
- **点评**：双曲函数的零点在虚轴上——这是因为双曲函数是三角函数旋转 90° 的结果。$\sinh z$ 的零点 $k\pi i$ 对应 $\sin z$ 的零点 $k\pi$（乘以 $i$）。

**【D7-7-034】** 叙述双曲平面（Poincaré 圆盘模型）：单位圆盘 $\mathbb{D}$ 上赋予度量 $ds^2=\frac{4|dz|^2}{(1-|z|^2)^2}$，是曲率为 $-1$ 的非欧几何。

- **难度**：★★
- **解答**：Poincaré 圆盘模型：
- 空间：单位圆盘 $\mathbb{D}=\{z:|z|<1\}$。
- 度量：$ds^2=\frac{4|dz|^2}{(1-|z|^2)^2}$（共形度量，与欧氏度量共形）。
- 测地线（"直线"）：与边界圆正交的圆弧（含直径）。
- 曲率：Gauss 曲率 $K=-1$（常数负曲率）。
- 平行公设：过直线外一点有无穷多条直线与已知直线不相交（双曲平行公设）。
- 三角形内角和 $<\pi$，角亏 $=\pi-(A+B+C)=$ 面积（Gauss-Bonnet）。
- 等距变换群：$\phi_a(z)=e^{i\theta}\frac{z-a}{1-\bar{a}z}$（Möbius 变换，D7-6-035）。∎
- **点评**：双曲几何是非欧几何的标准模型——它满足除平行公设外的所有欧氏公理。Poincaré 圆盘模型将双曲几何实现为复平面上的共形几何，是复分析与几何的深刻交汇。

### L3 实变函数基础

**【D7-7-035】** 证明：$\sinh x$ 和 $\cosh x$ 是 $\mathbb{R}$ 上的可测函数（连续函数）。

- **难度**：★
- **解答**：$\sinh x=\frac{e^x-e^{-x}}{2}$，$\cosh x=\frac{e^x+e^{-x}}{2}$。
$e^x$ 和 $e^{-x}$ 连续，故 $\sinh x,\cosh x$ 连续。
连续函数必可测。
$\cosh x\geq1>0$，$\sinh x$ 可取任意实数值。∎
- **点评**：双曲函数是连续可测函数——它们是指数函数的组合，继承了指数函数的良好性质。

**【D7-7-036】** 计算 Laplace 变换：$\mathcal{L}\{\sinh at\}(s)=\frac{a}{s^2-a^2}$，$\mathcal{L}\{\cosh at\}(s)=\frac{s}{s^2-a^2}$（$s>|a|$）。

- **难度**：★★
- **解答**：$\mathcal{L}\{\sinh at\}(s)=\int_0^\infty e^{-st}\sinh at\,dt=\int_0^\infty e^{-st}\frac{e^{at}-e^{-at}}{2}dt$
$=\frac{1}{2}\int_0^\infty(e^{-(s-a)t}-e^{-(s+a)t})dt=\frac{1}{2}(\frac{1}{s-a}-\frac{1}{s+a})=\frac{a}{s^2-a^2}$。
$\mathcal{L}\{\cosh at\}(s)=\int_0^\infty e^{-st}\cosh at\,dt=\frac{1}{2}(\frac{1}{s-a}+\frac{1}{s+a})=\frac{s}{s^2-a^2}$。
类比：$\mathcal{L}\{\sin at\}(s)=\frac{a}{s^2+a^2}$，$\mathcal{L}\{\cos at\}(s)=\frac{s}{s^2+a^2}$（符号从 $+$ 变 $-$）。∎
- **点评**：双曲函数的 Laplace 变换——与三角函数的 Laplace 变换形式相似，只是分母从 $s^2+a^2$ 变为 $s^2-a^2$。这是双曲函数与三角函数"虚数旋转"关系在变换域中的体现。

**【D7-7-037】** 证明：双曲平面上的面积元 $dA=\frac{4\,dxdy}{(1-x^2-y^2)^2}$（Poincaré 圆盘模型），并计算整个圆盘的面积为 $\infty$。

- **难度**：★★
- **解答**：共形度量 $ds^2=\lambda(z)^2|dz|^2$，$\lambda(z)=\frac{2}{1-|z|^2}$。
面积元 $dA=\lambda(z)^2dxdy=\frac{4\,dxdy}{(1-x^2-y^2)^2}$。
极坐标：$dA=\frac{4r\,dr\,d\theta}{(1-r^2)^2}$。
圆盘面积 $=\int_0^{2\pi}\int_0^1\frac{4r}{(1-r^2)^2}dr\,d\theta=2\pi\cdot[-2\ln(1-r^2)]_0^1=2\pi\cdot\infty=\infty$。
故双曲平面面积无穷大（尽管它"位于"单位圆盘内）。
有限区域的面积：半径为 $r_0$ 的双曲圆盘面积 $=4\pi\sinh^2(\frac{R}{2})$（$R$ 为双曲半径），随 $R$ 指数增长。∎
- **点评**：双曲平面面积无穷——这是非欧几何的反直觉特征之一。尽管 Poincaré 圆盘在欧氏意义下有界，但双曲度量在边界附近"膨胀"，使得总面积无穷。双曲圆盘面积随半径指数增长（而非欧氏的二次增长）。

## 跨领域综合题

### 经典名题

**【D7-7-CROSS-018】**（D7 × D6 完备性 × D8 解析）**证明双曲几何的一致性：通过 Poincaré 圆盘模型（在欧氏几何中构造），说明如果欧氏几何一致则双曲几何一致。这是 Beltrami（1868）和 Poincaré（1882）的历史性贡献——终结了两千年来对第五公设的质疑，证明非欧几何与欧氏几何一样"真实"。**

- **难度**：★★★
- **对应知识点**：双曲几何一致性、Poincaré模型、相对一致性、第五公设、非欧几何
- **解答**：
  **历史背景**：
  从欧几里得时代起，数学家们试图从其他公理推导出第五公设（平行公设），但都失败了。
  19世纪初，Gauss（未发表）、Lobachevsky（1829）、Bolyai（1832）独立发现了双曲几何——一种否定第五公设的几何。
  但问题是：双曲几何是否一致（无矛盾）？如果双曲几何内部有矛盾，那它只是"数学游戏"而非真实的几何。

  **Beltrami 的伪球面模型（1868）**：
  Beltrami 构造了伪球面（tractricoid）——三维欧氏空间中的一个旋转曲面，其高斯曲率为常数-1。
  伪球面上的几何局部等价于双曲几何——这证明了双曲几何的局部一致性。
  但伪球面不是完整的双曲平面（有边界，不是单连通的），只能表示双曲平面的一部分。

  **Poincaré 的圆盘模型（1882）**：
  Poincaré 构造了完整的双曲几何模型——单位圆盘内部，配备双曲度量 ds²=4|dz|²/(1-|z|²)²。
  这个模型完全在欧氏几何内部构造：
  - "点"=圆盘内部的欧氏点
  - "直线"=垂直于边界的欧氏圆弧（或直径）
  - "角度"=欧氏角度（共形）
  - "距离"=由双曲度量定义的距离
  所有双曲几何的公理（包括"过直线外一点有无穷多条平行线"）在这个模型中都成立——可以用欧氏几何的定理验证。

  **相对一致性证明**：
  如果双曲几何内部有矛盾，那么这个矛盾会翻译为 Poincaré 模型中的矛盾——也就是欧氏几何中的矛盾。
  所以：如果欧氏几何一致，则双曲几何一致。∎
  这是"相对一致性"证明——双曲几何不比欧氏几何更"危险"。

  **历史意义**：
  这终结了两千年来对第五公设的质疑——第五公设不能从其他公理推导出来（因为双曲几何是一致的替代方案）。
  非欧几何与欧氏几何一样"真实"——它们都是一致的数学体系，只是曲率不同。
  这开创了现代几何学的时代——从"唯一真实的几何"到"多种可能的几何"，为黎曼几何和广义相对论奠定了基础。

  **几何理解**：
  Poincaré 模型是"在欧氏几何内部模拟双曲几何"——就像在计算机中模拟另一个操作系统。
  模型中的"直线"看起来是弯曲的（圆弧），但在双曲度量下是"直的"（最短路径）。
  这说明"直线"的概念依赖于度量——不同的度量给出不同的"直线"，从而给出不同的几何。
- **一句话点评**：Lobachevsky(1829)/Bolyai(1832)发现双曲几何,但一致性存疑。Beltrami(1868)伪球面模型(局部,K=-1)。Poincaré(1882)圆盘模型(完整,在欧氏几何内构造:点=圆盘内欧氏点,直线=垂直边界圆弧,角度=欧氏角度,距离=双曲度量)。所有双曲公理在模型中成立(可用欧氏定理验证)。若双曲有矛盾⟹模型中有矛盾⟹欧氏有矛盾。⟹欧氏一致⟹双曲一致(相对一致性)。终结第五公设质疑,开创现代几何(多种几何=曲率不同)。

**【D7-7-CROSS-019】**（D7 × D8 解析 × D3 微分）**建立"三角函数→双曲函数→椭圆函数"的概念链条：三角函数是圆（1次代数曲线）上的函数，双曲函数是双曲线（2次代数曲线）上的函数，椭圆函数是椭圆曲线（3次代数曲线）上的函数。说明函数的复杂性随曲线次数增加：三角函数单周期，双曲函数非周期（指数），椭圆函数双周期。**

- **难度**：★★★
- **对应知识点**：三角函数、双曲函数、椭圆函数、代数曲线次数、周期性
- **解答**：
  **概念链条**：

  | 函数 | 对应曲线 | 曲线次数 | 周期性 | 参数化 |
  |---|---|---|---|---|
  | 三角函数 sin,cos | 圆 x²+y²=1 | 2次（亏格0） | 单周期（2π） | 弧长参数化（有理参数化） |
  | 双曲函数 sinh,cosh | 双曲线 x²-y²=1 | 2次（亏格0） | 非周期（指数增长） | 面积参数化（有理参数化） |
  | 椭圆函数 sn,cn | 椭圆曲线 y²=x³+ax+b | 3次（亏格1） | 双周期（复平面格点） | 椭圆积分反演（无理参数化） |

  **圆和双曲线（亏格0）**：
  圆和双曲线都是2次代数曲线（圆锥曲线），亏格为0——可以有理参数化。
  圆：(cos t, sin t)=((1-t²)/(1+t²), 2t/(1+t²))（有理参数化，t=tan(t/2)）。
  双曲线：(cosh t, sinh t)=((1+t²)/(1-t²), 2t/(1-t²))（有理参数化）。
  因为可以有理参数化，对应的函数（三角函数、双曲函数）是初等函数——可以用指数函数表示。
  圆是紧致的（有界），参数化是周期的（三角函数）；双曲线是非紧致的（无界），参数化是非周期的（双曲函数=指数）。

  **椭圆曲线（亏格1）**：
  椭圆曲线是3次代数曲线，亏格为1——不能有理参数化。
  椭圆曲线的弧长涉及椭圆积分（第一类椭圆积分），其反函数就是椭圆函数。
  椭圆函数是双周期的——复平面上有两个独立的周期，形成格点结构。
  椭圆函数比三角函数和双曲函数更复杂——它们是亚纯函数（有极点），不能用初等函数表示。

  **统一视角**：
  这三类函数都是"代数曲线上的自然函数"——由曲线的几何（弧长或面积参数化）定义。
  曲线的亏格（拓扑复杂性）决定了函数的性质：
  - 亏格0（圆、双曲线）→ 初等函数（指数/三角/双曲），单周期或非周期
  - 亏格1（椭圆曲线）→ 椭圆函数，双周期
  - 亏格≥2 → 更复杂的函数（自守函数），与双曲几何相关

  **与双曲几何的联系**：
  亏格≥2的曲面带有双曲度量（高斯-博内定理：χ=2-2g&lt;0，平均曲率为负）。
  自守函数是定义在双曲平面上、在离散等距群下不变的函数——它们是亏格≥2曲面上的"自然函数"。
  所以从三角函数（圆）→双曲函数（双曲线）→椭圆函数（椭圆曲线）→自守函数（双曲曲面），是一个随亏格增加的函数谱系。

  **几何理解**：
  函数的复杂性由其背后的代数曲线的拓扑复杂性（亏格）决定——这是代数几何的核心洞察。
  我们最熟悉的三角函数和双曲函数是最简单的情况（亏格0），椭圆函数已经需要复分析的深入工具，而自守函数则是现代数论和几何的核心。
  双曲函数处于这个谱系的"中间"——它比三角函数复杂（指数增长vs振荡），但仍然是初等函数（亏格0）。
- **一句话点评**：三角函数=圆(2次,亏格0,紧致)→单周期(2π),有理参数化;双曲函数=双曲线(2次,亏格0,非紧致)→非周期(指数),有理参数化;椭圆函数=椭圆曲线(3次,亏格1)→双周期(复格点),椭圆积分反演(无理参数化)。亏格决定函数性质：亏格0→初等函数(指数/三角/双曲),亏格1→椭圆函数(双周期亚纯),亏格≥2→自守函数(双曲几何)。谱系：三角(圆)→双曲(双曲线)→椭圆(椭圆曲线)→自守(双曲曲面)。函数复杂性=曲线拓扑复杂性(亏格)。

### 反例与构造

**【D7-7-CROSS-020】**（D7 × D2 连续 × D6 完备性）**构造一个"双曲相似三角形"的不可能性证明：假设两个双曲三角形角对应相等但边不相等，用双曲余弦定理推出矛盾。说明这与球面几何一样——只有零曲率的欧氏几何才有相似三角形，相似性等价于平行公设。**

- **难度**：★★★
- **对应知识点**：双曲无相似三角形、AAA全等、双曲余弦定理、相似性=平行公设
- **解答**：
  **假设**：存在两个双曲三角形 T₁ 和 T₂，角对应相等（A₁=A₂, B₁=B₂, C₁=C₂），但边不相等。

  **双曲余弦定理（角的形式）**：
  从双曲余弦定理 cosh a = cosh b cosh c - sinh b sinh c cos A，
  可以解出 cos A = (cosh b cosh c - cosh a)/(sinh b sinh c)。
  但更直接的是用"角的余弦定理"（通过极三角形或对偶推导）：
  cos A = -cos B cos C + sin B sin C cosh a。
  （注意：双曲几何中角的余弦定理有 +cosh a 项，与球面的 -cos a 形成对比。）

  解出 cosh a = (cos A + cos B cos C)/(sin B sin C)。∎

  如果两个三角形角相等（A₁=A₂,B₁=B₂,C₁=C₂），则：
  cosh a₁ = (cos A₁+cos B₁cos C₁)/(sin B₁sin C₁) = (cos A₂+cos B₂cos C₂)/(sin B₂sin C₂) = cosh a₂。
  因为 cosh 在 [0,∞) 上单调递增，所以 a₁=a₂。
  同理 b₁=b₂, c₁=c₂。
  三边相等，与假设矛盾。∎

  所以双曲几何中 AAA 全等成立——没有相似但不全等的三角形。

  **三种几何的相似性**：
  - 球面（K>0）：AAA 全等，无相似三角形
  - 平面（K=0）：AAA 相似，有相似三角形（无穷多组）
  - 双曲（K&lt;0）：AAA 全等，无相似三角形

  **相似性等价于平行公设**：
  在欧氏几何中，相似三角形的存在性等价于第五公设（平行公设）。
  证明：如果有相似但不全等的三角形，可以通过相似变换构造平行线，从而推出第五公设；反之，第五公设成立时可以构造相似三角形。
  在非欧几何（球面/双曲）中，第五公设不成立，相似三角形也不存在——这是等价的。

  **几何理解**：
  相似三角形的存在性是欧氏几何独有的特征——它依赖于"空间可以自由缩放"的性质。
  在常曲率非零空间中，缩放会改变曲率的相对效应——角相同的三角形大小被曲率固定了。
  只有零曲率空间允许自由缩放（缩放不改变零曲率），所以只有欧氏几何有相似三角形。
  这是"曲率决定几何"的又一体现——相似性不是几何的必然，而是零曲率的特例。
- **一句话点评**：双曲角的余弦定理：cosA=-cosB cosC+sinB sinC cosh a⟹cosh a=(cosA+cosB cosC)/(sinB sinC)。角相等⟹cosh a₁=cosh a₂⟹a₁=a₂(cosh单调)⟹三边相等⟹AAA全等⟹无相似三角形。球面(K>0)和双曲(K&lt;0)都AAA全等,只有平面(K=0)有相似三角形。相似性⟺第五公设(平行公设):相似⟹可构造平行线⟹第五公设;第五公设⟹可构造相似。非零曲率空间缩放改变曲率相对效应,角定大小;零曲率缩放不变⟹有相似。

### 定理串联

**【D7-7-CROSS-021】**（D7 × D6 完备性 × D8 解析 × D3 微分）**建立"圆→双曲线→悬链面→极小曲面"的概念链条：圆的旋转=球面（正曲率），双曲线的旋转=双叶双曲面（负曲率但非极小），悬链线的旋转=悬链面（极小曲面，平均曲率为0，高斯曲率为负）。说明悬链面是除平面外最早发现的极小曲面（Euler 1744），其参数化涉及双曲函数。**

- **难度**：★★★
- **对应知识点**：悬链面、极小曲面、平均曲率、双曲函数、旋转曲面、概念链条
- **解答**：
  **旋转曲面的曲率**：
  曲线 y=f(x) 绕 x 轴旋转得到旋转曲面。
  主曲率：k₁=f''/(1+f'^2)^{3/2}（经线方向），k₂=1/(f√(1+f'^2))（纬线方向）。
  平均曲率 H=(k₁+k₂)/2，高斯曲率 K=k₁k₂。

  **圆的旋转=球面**：
  圆 y=√(R²-x²) 绕 x 轴旋转=球面。
  k₁=k₂=1/R（常数），H=1/R>0，K=1/R²>0——正曲率，非极小。

  **双曲线的旋转=双叶双曲面**：
  双曲线 y=√(x²-a²) 绕 x 轴旋转=双叶双曲面。
  计算得 K&lt;0（负高斯曲率），但 H≠0（平均曲率非零）——非极小曲面。

  **悬链线的旋转=悬链面**：
  悬链线 y=a cosh(x/a) 绕 x 轴旋转=悬链面（catenoid）。
  f'=sinh(x/a), f''=(1/a)cosh(x/a)。
  k₁=(1/a cosh)/(1+sinh²)^{3/2}=(1/a cosh)/cosh³=1/(a cosh²)。
  k₂=1/(a cosh·cosh)=1/(a cosh²)。
  k₁=k₂=1/(a cosh²)？不对，符号应该相反...
  实际上悬链面的两个主曲率大小相等符号相反：k₁=1/(a cosh²(x/a)), k₂=-1/(a cosh²(x/a))。
  所以 H=(k₁+k₂)/2=0——平均曲率为零！∎
  K=k₁k₂=-1/(a² cosh⁴)&lt;0——负高斯曲率。
  悬链面是极小曲面（H=0）！

  **悬链面的参数化**：
  悬链面的标准参数化：
  x(u,v)=(a cosh(v/a)cos u, a cosh(v/a)sin u, v)。
  这里双曲函数 cosh 出现在参数化中——悬链面是悬链线的旋转，而悬链线就是双曲余弦曲线。

  **历史意义**：
  Euler（1744）发现悬链面是除平面外第一个极小曲面——这是变分法的早期成就（最小曲面面积问题）。
  悬链面和平面是仅有的两个旋转极小曲面（Bonnet 定理）。
  悬链面可以通过"螺旋面"经过伴随极小曲面形变得到——这是极小曲面理论中的经典结果。

  **与双曲几何的联系**：
  悬链面的高斯曲率为负——它局部是双曲几何的模型（虽然不是常曲率）。
  悬链面的"颈"处曲率最负（K=-1/a²），往远处曲率趋向0（近似平面）。
  这与双曲平面（常负曲率）不同，但展示了负曲率曲面的几何性质。

  **几何理解**：
  圆→球面（正曲率，非极小），双曲线→双曲面（负曲率，非极小），悬链线→悬链面（负曲率，极小）。
  双曲函数不仅描述双曲几何，还描述极小曲面——悬链线的旋转恰好满足平均曲率为零的条件。
  这是双曲函数在微分几何中的深刻应用——从"另一种三角学"到"极小曲面的参数化"。
- **一句话点评**：旋转曲面主曲率k₁=f''/(1+f'^2)^{3/2},k₂=1/(f√(1+f'^2))。圆旋转→球面(k₁=k₂=1/R,H>0,K>0)。双曲线旋转→双叶双曲面(K&lt;0,H≠0非极小)。悬链线y=a cosh(x/a)旋转→悬链面：f'=sinh,f''=(1/a)cosh,k₁=1/(a cosh²),k₂=-1/(a cosh²)⟹H=0(极小!),K=-1/(a²cosh⁴)&lt;0。参数化x=(a cosh(v/a)cosu,...,v)。Euler(1744)发现=除平面外第一个极小曲面。悬链面+平面=仅有的旋转极小曲面(Bonnet定理)。双曲函数描述极小曲面参数化。

### 基础综合

**【D7-7-CROSS-022】**（D7 × D4 积分 × D1 极限）**计算悬链面的表面积：悬链面由 y=a cosh(x/a) 绕 x 轴旋转而成，x 从 -b 到 b。用旋转曲面面积公式 S=2π∫y√(1+y'²)dx 计算，验证悬链面是极小曲面（在所有连接两个平行圆的旋转曲面中面积最小）。**

- **难度**：★★
- **对应知识点**：悬链面表面积、旋转曲面面积、极小曲面、变分法
- **解答**：
  **悬链面参数**：y=a cosh(x/a), y'=sinh(x/a)。
  √(1+y'²)=√(1+sinh²(x/a))=cosh(x/a)。

  **表面积**（x 从 -b 到 b）：
  S=2π∫₋ᵇᵇ y√(1+y'²)dx = 2π∫₋ᵇᵇ a cosh(x/a)·cosh(x/a)dx
  = 2πa∫₋ᵇᵇ cosh²(x/a)dx。
  用 cosh²t=(cosh 2t+1)/2：
  = 2πa·(a/2)∫₋ᵇ/ₐᵇ/ₐ (cosh 2u+1)du（令 u=x/a）
  = πa²[(sinh 2u)/2+u]₋ᵇ/ₐᵇ/ₐ
  = πa²[sinh(2b/a)+2b/a]
  = πa² sinh(2b/a)+2πab。∎

  **极小曲面验证（变分法）**：
  极小曲面满足平均曲率 H=0，等价于面积泛函的 Euler-Lagrange 方程。
  对于旋转曲面 y=f(x)，面积泛函 S=2π∫f√(1+f'²)dx。
  Euler-Lagrange 方程：∂L/∂f - d/dx(∂L/∂f')=0，L=f√(1+f'²)。
  ∂L/∂f=√(1+f'²), ∂L/∂f'=ff'/√(1+f'²)。
  方程化简为：1+f'²-ff''=0 ⟹ f f''=1+f'²。
  验证 f=a cosh(x/a)：
  f'=sinh(x/a), f''=(1/a)cosh(x/a)。
  f f''=a cosh(x/a)·(1/a)cosh(x/a)=cosh²(x/a)。
  1+f'²=1+sinh²(x/a)=cosh²(x/a)。∎
  相等！悬链线满足极小曲面方程。

  **与圆柱面对比**：
  连接两个半径为 a cosh(b/a) 的平行圆（间距 2b）的圆柱面面积 = 2π·a cosh(b/a)·2b = 4πab cosh(b/a)。
  悬链面面积 = πa² sinh(2b/a)+2πab = 2πa² sinh(b/a)cosh(b/a)+2πab。
  当 b/a 较小时，悬链面面积 &lt; 圆柱面面积——悬链面确实更小（极小）。
  当 b/a 太大时，悬链面不再是稳定的极小曲面（会断裂成两个圆盘——Goldschmidt 解）。

  **几何理解**：
  悬链面是肥皂泡的形状——在两个圆环之间形成的肥皂膜就是悬链面（因为表面张力使面积最小）。
  双曲余弦不仅描述悬挂链条的形状（悬链线），还描述肥皂膜的形状（悬链面）——一个是一维极小（势能最小），一个是二维极小（面积最小）。
  这是双曲函数在物理和几何中的优美应用。
- **一句话点评**：y=a cosh(x/a),y'=sinh,√(1+y'²)=cosh。表面积=2π∫y√(1+y'²)dx=2πa∫cosh²dx=πa² sinh(2b/a)+2πab。极小曲面Euler-Lagrange方程：1+f'²-ff''=0。验证：ff''=a cosh·(1/a)cosh=cosh²,1+f'²=1+sinh²=cosh²✓。对比圆柱面=4πab cosh(b/a),小b/a时悬链面更小。肥皂膜=悬链面(表面张力面积最小)。一维极小(悬链线,势能最小)↔二维极小(悬链面,面积最小)。

**【D7-7-CROSS-023】**（D7 × D8 解析 × D5 级数）**讨论双曲函数与 Fourier 级数的关系：双曲函数在有限区间上可以展开为 Fourier 级数（如 cosh x 在 [-π,π] 上的 Fourier 级数），但因为双曲函数不是周期函数，Fourier 级数只是它在一个周期上的表示，延拓后是周期函数（与原函数在区间外不同）。计算 cosh x 的 Fourier 系数。**

- **难度**：★★
- **对应知识点**：双曲函数Fourier展开、非周期函数、Fourier系数、周期延拓
- **解答**：
  **cosh x 在 [-π,π] 上的 Fourier 级数**：
  cosh x 是偶函数，所以只有余弦项：
  cosh x = a₀/2 + Σ_{n=1}^∞ a_n cos(nx)。

  **a₀**：
  a₀=(1/π)∫₋π^π cosh x dx = (2/π)sinh π。

  **a_n**（n≥1）：
  a_n=(1/π)∫₋π^π cosh x cos(nx)dx = (2/π)∫₀^π cosh x cos(nx)dx。
  用分部积分或公式 ∫cosh(ax)cos(bx)dx = [a sinh(ax)cos(bx)+b cosh(ax)sin(bx)]/(a²+b²)。
  代入 a=1,b=n，从 0 到 π：
  ∫₀^π cosh x cos(nx)dx = [sinh x cos(nx)+n cosh x sin(nx)]/(1+n²)|₀^π
  = [sinh π cos(nπ)+n cosh π sin(nπ) - sinh 0·cos0 - n cosh 0·sin0]/(1+n²)
  = sinh π·(-1)^n/(1+n²)。
  所以 a_n = (2/π)·sinh π·(-1)^n/(1+n²) = 2(-1)^n sinh π/[π(1+n²)]。∎

  **Fourier 级数**：
  cosh x = sinh π/π + (2 sinh π/π)Σ_{n=1}^∞ (-1)^n cos(nx)/(1+n²)，x∈[-π,π]。∎

  **非周期函数的 Fourier 表示**：
  cosh x 不是周期函数（指数增长），但它在有限区间 [-π,π] 上可以展开为 Fourier 级数。
  Fourier 级数的和函数是 cosh x 的周期延拓（周期 2π）——在 [-π,π] 内等于 cosh x，在区间外是 cosh x 的"复制粘贴"（不连续，因为 cosh(π)≠cosh(-π)... 实际上 cosh 是偶函数，cosh(π)=cosh(-π)，所以周期延拓是连续的，但导数不连续）。

  **与三角函数 Fourier 展开对比**：
  三角函数本身就是周期函数，其 Fourier 级数是有限项（自身）。
  双曲函数是非周期函数，其 Fourier 级数是无穷级数，系数衰减为 1/n²（因为函数连续但导数有跳跃）。
  这反映了周期函数和非周期函数的本质区别——Fourier 级数只"看到"一个周期内的行为。

  **几何理解**：
  双曲函数（指数增长）和三角函数（周期振荡）是复指数函数的两个侧面——在实轴上三角函数是周期的，双曲函数是非周期的。
  Fourier 级数将非周期函数在有限区间上"伪装"成周期函数——这是一种"周期化"操作。
  系数 1/(1+n²) 的衰减率反映了函数的光滑性——cosh x 连续但周期延拓后导数不连续，所以系数衰减为 1/n²（连续但导数跳跃的典型衰减率）。
- **一句话点评**：cosh x在[-π,π]上Fourier展开(偶函数仅余弦)：a₀=2sinhπ/π,a_n=2(-1)^n sinhπ/[π(1+n²)]。⟹cosh x=sinhπ/π+(2sinhπ/π)Σ(-1)^n cos(nx)/(1+n²)。cosh非周期(指数增长),Fourier级数=周期延拓(区间内=cosh,区间外=复制,导数不连续)。对比：三角函数本身周期⟹Fourier级数有限项;双曲非周期⟹无穷级数,系数~1/n²(连续但导数跳跃)。周期化操作,系数衰减率=光滑性反映。

**【D7-7-CROSS-024】**（D7 × D6 完备性 × D2 连续）**讨论双曲平面的"非紧致性"与"完备性"：双曲平面是非紧致的（无界），但作为度量空间是完备的（Cauchy 序列收敛）。对比球面（紧致且完备）和平面（非紧致但完备）。说明 Poincaré 圆盘的边界在无穷远——圆盘内的 Cauchy 序列不会趋向边界（因为边界在无穷远，趋向边界需要无穷长的路径）。**

- **难度**：★★
- **对应知识点**：双曲平面完备性、非紧致性、Poincaré圆盘边界、Cauchy序列、度量空间
- **解答**：
  **双曲平面的完备性**：
  完备度量空间：每个 Cauchy 序列都收敛。
  双曲平面（Poincaré 圆盘模型）作为度量空间是完备的——任何 Cauchy 序列都收敛到圆盘内部的一点。∎

  **为什么边界不影响完备性**：
  在 Poincaré 圆盘中，边界圆 |z|=1 对应双曲距离无穷远。
  从圆盘中心到边界点的双曲距离 = ∫₀¹ 2dr/(1-r²) = ∞（发散）。
  所以圆盘内的 Cauchy 序列不可能趋向边界——因为趋向边界需要走无穷远的距离，而 Cauchy 序列的点之间距离趋向0（有界）。
  因此 Cauchy 序列必然收敛到圆盘内部——双曲平面完备。∎

  **与球面/平面对比**：

  | 空间 | 紧致性 | 完备性 | 直径 |
  |---|---|---|---|
  | 球面 | 紧致（有界闭） | 完备 | 有限（πR） |
  | 平面 | 非紧致（无界） | 完备 | 无限 |
  | 双曲平面 | 非紧致（无界） | 完备 | 无限 |

  三种常曲率空间都是完备的——这是常曲率空间的良好性质。
  球面是紧致的（有限面积），平面和双曲平面是非紧致的（无限面积）。

  **不完备的例子**：
  去掉一个点的平面（ℝ²\{0}）不完备——趋向原点的 Cauchy 序列不收敛（原点不在空间中）。
  Poincaré 圆盘的"内部"（不包括边界）是完备的，因为边界在无穷远，不是"去掉的有限点"。
  这与"开区间 (0,1) 不完备"不同——(0,1) 的端点在有限距离处，Cauchy 序列可以趋向端点；Poincaré 圆盘的边界在无穷远处，Cauchy 序列无法趋向。

  **Hopf-Rinow 定理**：
  连通的有限维黎曼流形中，测地完备（所有测地线可以无限延伸）等价于度量完备（Cauchy 序列收敛）。
  双曲平面中所有测地线（垂直边界的圆弧）都可以无限延伸（趋向边界需要无穷远），所以测地完备⟹度量完备。
  球面也是测地完备的（大圆闭合，可以无限延伸），平面也是。

  **几何理解**：
  双曲平面的"无限"是"度量意义上的无限"——边界在无穷远，无法在有限距离内到达。
  这使得双曲平面虽然"看起来"是有限的圆盘（Poincaré 模型），但实际上是无限大的完备空间。
  完备性保证了微积分和分析学可以在双曲平面上良好运作——极限、导数、积分都有良好定义。
- **一句话点评**：双曲平面完备(Cauchy序列收敛)。Poincaré圆盘边界|z|=1=双曲距离∞(中心到边界∫₀¹2dr/(1-r²)=∞),Cauchy序列(点间距→0,有界)无法趋向边界⟹必收敛内部⟹完备。对比：球面(紧致完备,直径πR),平面(非紧致完备,无限),双曲(非紧致完备,无限)。区别于开区间(0,1)(端点有限距离,Cauchy可趋向端点=不完备)。Hopf-Rinow定理：测地完备⟺度量完备,双曲测地线可无限延伸(趋向边界=∞)⟹完备。完备性保证分析学良好运作。

**【D7-7-CROSS-025】**（D7 × D3 微分 × D5 级数）**用双曲函数求解微分方程 y''-y=0：通解 y=C₁eˣ+C₂e⁻ˣ=A cosh x+B sinh x。对比 y''+y=0 的通解 y=A cos x+B sin x。说明符号差异（- vs +）导致指数增长解 vs 振荡解，这是"负曲率"与"正曲率/零曲率"在微分方程中的体现。**

- **难度**：★★
- **对应知识点**：微分方程、双曲函数解、指数增长vs振荡、符号差异
- **解答**：
  **y''-y=0 的求解**：
  特征方程 r²-1=0 ⟹ r=±1。
  通解 y=C₁eˣ+C₂e⁻ˣ。
  用双曲函数表示：y=A cosh x+B sinh x，其中 A=C₁+C₂, B=C₁-C₂。∎

  **y''+y=0 的求解**：
  特征方程 r²+1=0 ⟹ r=±i。
  通解 y=C₁e^{ix}+C₂e^{-ix}=A cos x+B sin x。∎

  **符号差异的影响**：
  - y''-y=0（负号在 y 项）：特征根为实数 ±1，解为指数函数 e^{±x}——指数增长/衰减，无界。
  - y''+y=0（正号在 y 项）：特征根为虚数 ±i，解为复指数 e^{±ix}——三角函数，振荡有界。

  **初始条件对比**：
  y''-y=0, y(0)=1, y'(0)=0 ⟹ y=cosh x（U形，指数增长）。
  y''+y=0, y(0)=1, y'(0)=0 ⟹ y=cos x（振荡，有界）。
  y''-y=0, y(0)=0, y'(0)=1 ⟹ y=sinh x（S形，指数增长）。
  y''+y=0, y(0)=0, y'(0)=1 ⟹ y=sin x（振荡，有界）。

  **物理意义**：
  - y''+y=0 描述简谐振动（弹簧振子）——回复力与位移成正比且方向相反（F=-kx），导致振荡。
  - y''-y=0 描述"反回复力"系统（力与位移同方向）——导致指数增长（不稳定平衡）。
  - 双曲函数出现在不稳定平衡、指数增长、扩散等物理过程中。

  **与曲率的联系**：
  在曲面论中，测地线的 Jacobi 方程描述相邻测地线的分离：
  J''+K J=0（K=高斯曲率）。
  - K>0（球面）：J''+KJ=0 ⟹ 振荡解（测地线收敛再发散，焦点）。
  - K=0（平面）：J''=0 ⟹ 线性解（测地线平行，距离线性增长）。
  - K&lt;0（双曲）：J''-|K|J=0 ⟹ 双曲函数解（测地线指数发散——这是双曲几何"指数膨胀"的微分方程根源！）。

  **几何理解**：
  微分方程中符号的微小差异（+ vs -）导致解的性质完全不同——振荡 vs 指数增长。
  这与几何中曲率的符号完全对应：正曲率→振荡（测地线收敛），负曲率→指数增长（测地线发散）。
  双曲函数是"指数增长微分方程"的解，正如三角函数是"振荡微分方程"的解——它们是同一数学结构在不同符号下的表现。
- **一句话点评**：y''-y=0:特征r²-1=0⟹r=±1⟹y=C₁eˣ+C₂e⁻ˣ=A coshx+B sinhx(指数增长,无界)。y''+y=0:r²+1=0⟹r=±i⟹y=A cosx+B sinx(振荡,有界)。物理：y''+y=简谐振动(回复力F=-kx,振荡);y''-y=反回复力(不稳定,指数增长)。曲率联系：Jacobi方程J''+KJ=0,K>0→振荡(测地线收敛有焦点),K=0→线性(平行),K&lt;0→双曲解(测地线指数发散=双曲指数膨胀根源)。符号差异=曲率符号=振荡vs增长。

**【D7-7-CROSS-026】**（D7 × D8 解析 × D4 积分）**讨论双曲函数在复积分中的应用：利用双曲代换计算含有 √(x²+a²) 或 √(x²-a²) 的积分，如 ∫dx/√(x²+1)=arcsinh x=ln(x+√(x²+1))。对比三角代换 ∫dx/√(1-x²)=arcsin x。说明双曲代换在处理"加号根号"时比三角代换更自然。**

- **难度**：★★
- **对应知识点**：双曲代换积分、反双曲函数、根号积分、三角代换对比
- **解答**：
  **∫dx/√(x²+1)**：
  令 x=sinh t, dx=cosh t dt, √(x²+1)=cosh t。
  ∫dx/√(x²+1)=∫cosh t/cosh t dt=∫dt=t+C=arcsinh x+C=ln(x+√(x²+1))+C。∎

  **对比 ∫dx/√(1-x²)**：
  令 x=sin t, dx=cos t dt, √(1-x²)=cos t。
  ∫dx/√(1-x²)=∫cos t/cos t dt=∫dt=t+C=arcsin x+C。∎

  **双曲代换 vs 三角代换的选择**：

  | 根号形式 | 推荐代换 | 结果 |
  |---|---|---|
  | √(a²-x²) | x=a sin t（三角） | 反三角函数 |
  | √(x²+a²) | x=a sinh t（双曲） | 反双曲函数=对数 |
  | √(x²-a²) | x=a cosh t（双曲） | 反双曲函数=对数 |

  对于 √(x²+a²)，双曲代换 x=a sinh t 直接消去根号（√(a²sinh²t+a²)=a cosh t），积分变成简单的 ∫dt。
  如果用三角代换 x=a tan t，则 √(x²+a²)=a sec t, dx=a sec²t dt，积分变成 ∫sec t dt=ln|sec t+tan t|——也能做但更复杂（涉及 sec 的积分）。
  双曲代换更自然，因为 sinh²+1=cosh² 与 x²+a² 的"加号"匹配。

  **更复杂的例子**：
  ∫√(x²+a²)dx（已在 D7-7-007 计算）= (x√(x²+a²))/2 + (a²/2)arcsinh(x/a)+C。
  用双曲代换一步到位，而三角代换需要分部积分。

  **几何理解**：
  代换的选择本质上是"选择合适的代数曲线参数化"：
  - √(a²-x²) 对应圆 x²+y²=a²——用圆的参数化（三角代换）。
  - √(x²+a²) 对应双曲线 x²-y²=-a²——用双曲线的参数化（双曲代换）。
  - √(x²-a²) 对应双曲线 x²-y²=a²——用双曲线的参数化（双曲代换）。
  根号下的符号（+ vs -）决定了用圆还是双曲线——也就决定了用三角还是双曲代换。
  这是"代数曲线几何"在积分计算中的直接应用。
- **一句话点评**：∫dx/√(x²+1):x=sinh t,dx=cosh t dt,√=cosh t⟹∫dt=arcsinhx=ln(x+√(x²+1))。对比∫dx/√(1-x²):x=sin t⟹arcsin x。代换选择：√(a²-x²)→x=a sin t(圆参数化,反三角);√(x²+a²)→x=a sinh t(双曲线参数化,反双曲=对数);√(x²-a²)→x=a cosh t。双曲代换对"加号根号"更自然(sinh²+1=cosh²直接消去),三角代换x=a tan t→∫sec t dt更复杂。根号符号=圆vs双曲线=三角vs双曲代换。

**【D7-7-CROSS-027】**（D7 × D6 完备性 × D1 极限）**讨论双曲函数的渐近行为：当 x→+∞ 时，sinh x≈cosh x≈eˣ/2（指数增长），tanh x→1；当 x→0 时，sinh x≈x, cosh x≈1+x²/2（小角度近似=平面近似）。说明这两个极限分别对应"大尺度下的指数膨胀"和"小尺度下的平面近似"——与双曲几何的性质一致。**

- **难度**：★★
- **对应知识点**：双曲函数渐近、指数增长、小角度近似、大尺度vs小尺度
- **解答**：
  **x→+∞ 的渐近**：
  eˣ→∞, e⁻ˣ→0。
  sinh x=(eˣ-e⁻ˣ)/2≈eˣ/2。
  cosh x=(eˣ+e⁻ˣ)/2≈eˣ/2。
  tanh x=sinh x/cosh x=(eˣ-e⁻ˣ)/(eˣ+e⁻ˣ)→1。
  差 cosh x-sinh x=e⁻ˣ→0——sinh 和 cosh 在大 x 时几乎相等（都≈eˣ/2）。∎

  **x→0 的小角度近似**：
  Taylor 展开：
  sinh x=x+x³/6+...≈x。
  cosh x=1+x²/2+x⁴/24+...≈1+x²/2。
  tanh x=x-x³/3+...≈x。
  cosh²x-sinh²x≈(1+x²)-x²=1（恒等式精确成立）。∎

  **与双曲几何的对应**：
  - x→0（小尺度）：sinh x≈x, cosh x≈1+x²/2。
    双曲余弦定理 cosh a≈1+a²/2, sinh b≈b，代入得 a²≈b²+c²-2bc cos A——平面余弦定理。
    小尺度下双曲几何近似于平面几何——在小范围内，任何弯曲空间都近似平坦。
  - x→∞（大尺度）：sinh x≈cosh x≈eˣ/2（指数增长）。
    双曲圆面积≈πeʳ（指数增长），双曲距离指数膨胀。
    大尺度下双曲几何的负曲率效应显著——空间指数膨胀。

  **与三角函数的渐近对比**：
  三角函数 sin x, cos x 没有"x→∞的渐近"——它们是周期有界的，永远振荡。
  三角函数只有"x→0的小角度近似"：sin x≈x, cos x≈1-x²/2。
  双曲函数既有小角度近似（平面近似），又有大尺度渐近（指数膨胀）——这是非周期函数的特征。

  **几何理解**：
  双曲函数的两个极限对应双曲几何的两个尺度：
  - 微观（x→0）：空间近似平坦（平面几何）——局部欧氏化。
  - 宏观（x→∞）：空间指数膨胀（负曲率效应）——全局双曲化。
  这就像地球表面：小范围看起来是平的（平面近似），大范围是球面（曲率效应）。
  双曲平面也是如此：小范围近似平面，大范围指数膨胀。
- **一句话点评**：x→∞:sinh≈cosh≈eˣ/2(指数增长),tanh→1,cosh-sinh=e⁻ˣ→0。x→0:sinh≈x,cosh≈1+x²/2,tanh≈x(小角度=平面近似)。对应双曲几何：小尺度(a→0)⟹双曲余弦定理→平面余弦定理(局部平坦);大尺度(r→∞)⟹圆面积≈πeʳ(指数膨胀,负曲率显著)。对比：三角函数周期有界无∞渐近,只有x→0近似。微观平坦↔宏观膨胀=地球表面小范围平/大范围球面。

## 本模块易错点总结

1. **双曲函数不是"人为定义的特殊函数"**：它们是单位双曲线 x²-y²=1 右支上面积参数化的点坐标 (cosh t, sinh t)，与三角函数是单位圆上弧长参数化的点坐标完全平行。
2. **基本恒等式差一个符号**：cosh²x-sinh²x=1（-号）vs cos²x+sin²x=1（+号）。负号来自 i²=-1（虚数化 sin(ix)=i sinh x）。这是"负曲率"的代数体现。
3. **双曲函数导数没有负号**：(cosh x)'=sinh x（无负号）vs (cos x)'=-sin x（有负号）。因为双曲函数满足 y''=y（正号=指数增长），三角函数满足 y''=-y（负号=振荡）。
4. **双曲函数 Taylor 展开无交错符号**：cosh x=1+x²/2!+x⁴/4!+...（全正）vs cos x=1-x²/2!+x⁴/4!-...（交错）。因为是实指数 eˣ 的组合，没有虚数单位引入负号。
5. **双曲平面三角形内角和 &lt; 180°**：负曲率空间，A+B+C=π-S/R²&lt;π。角亏 D=π-(A+B+C)=S/R²>0，面积 S=DR²（由角亏决定）。对比球面内角和>180°（角盈）。
6. **双曲平面过直线外一点有无穷多条平行线**：否定第五公设。Poincaré 圆盘中过外点可作无穷多条垂直于边界的圆弧不与给定直线相交。对比平面1条、球面0条。
7. **双曲几何中也没有相似三角形（AAA全等）**：角的余弦定理 cosh a=(cos A+cos B cos C)/(sin B sin C) 说明角完全决定边。只有零曲率的欧氏几何才有相似三角形——相似性等价于平行公设。
8. **双曲余弦定理有负号**：cosh a=cosh b cosh c-sinh b sinh c cos A（-号）vs 球面 cos a=cos b cos c+sin b sin c cos A（+号）。函数从三角变双曲、符号从+变-都是曲率从正变负的体现。虚数化（a→ia）可将球面公式转化为双曲公式。
9. **双曲圆面积指数增长**：S=2π(cosh r-1)≈πeʳ（大r时），而平面是 πr²（多项式），球面有上界 4πR²。负曲率空间"无限膨胀"。
10. **双曲函数是复三角函数在虚轴上的取值**：sin(ix)=i sinh x, cos(ix)=cosh x。复三角函数是整函数，实轴上振荡有界，虚轴上指数增长无界——同一个函数的不同侧面。双曲函数零点在虚轴（z=nπi），三角函数零点在实轴（z=nπ）——旋转90°。
11. **Poincaré 圆盘和上半平面是等价的共形模型**：通过 Cayley 变换 w=(z-i)/(z+i)（Möbius变换）互相转化。角度保持（共形），距离被扭曲（边界在无穷远）。双曲平面不能等距嵌入三维欧氏空间（Hilbert定理）。
12. **三种几何统一于曲率 K**：广义三角函数 S_K,C_K，统一余弦定理 C_K(a)=C_K(b)C_K(c)+K S_K(b)S_K(c)cos A。K=+1→球面，K→0→平面，K=-1→双曲。曲率是空间的"内蕴DNA"，决定一切几何性质。
