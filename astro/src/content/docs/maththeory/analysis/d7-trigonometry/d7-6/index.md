## 第一章 球面的几何本质——正曲率空间

### 1.1 三种曲率空间

几何学可以按照空间的**曲率**分为三类：

| 空间类型 | 曲率 | 三角形内角和 | 平行线 | 典型模型 |
|---------|------|------------|--------|---------|
| 球面几何 | 正曲率（$K>0$） | $> 180°$ | 不存在平行线（任意两条"直线"都相交） | 球面 |
| 欧氏几何 | 零曲率（$K=0$） | $= 180°$ | 过直线外一点有且仅有一条平行线 | 平面 |
| 双曲几何 | 负曲率（$K<0$） | $< 180°$ | 过直线外一点有无穷多条平行线 | 双曲面（Poincaré 圆盘等） |

球面几何是**正曲率空间**的典型模型——在球面上，三角形的内角和**大于 180°**，这是对平面几何最根本的背离。

### 1.2 为什么球面三角形内角和大于 180°？

📐 **几何理解**：球面三角形内角和大于 180° 的几何本质是**球面的"弯曲"**。

想象在地球表面画一个三角形：
- 一个顶点在北极
- 另外两个顶点在赤道上，经度相差 90°

这个三角形的三个角都是 90°！
- 北极处的角：两条经线（从北极到赤道的两个点）之间的夹角是 90°
- 赤道上的两个角：经线与赤道垂直，所以都是 90°

内角和 = 90° + 90° + 90° = 270° > 180°！

这是一个非常直观的例子——在球面上，三角形的内角和可以达到 270°，甚至更大（最大可以接近 540°，即三个角都接近 180°）。

为什么会这样？因为球面是"弯的"——当你在球面上走一个三角形（沿着大圆弧走），你在每个顶点处的转向角度之和不等于 360°（平面上的情况），而是小于 360°。这个"亏缺"对应的就是内角和超出 180° 的部分。

更精确地说，根据**高斯-博内定理**（Gauss-Bonnet theorem）：
$$\int_{\text{三角形}} K \, dA + \text{外角和} = 2\pi$$

对于常曲率 $K$ 的球面，$\int K dA = K \cdot A$，外角和 = $3\pi - (A+B+C)$（因为每个外角 = $\pi -$ 内角）。

所以：
$$K \cdot A + 3\pi - (A+B+C) = 2\pi$$
$$A+B+C = \pi + K \cdot A$$

对于半径为 $R$ 的球面，$K = 1/R^2$，所以：
$$A+B+C = \pi + \frac{A_{\text{面积}}}{R^2}$$

内角和 = $\pi$ + 面积/半径²，因为面积 > 0，所以内角和 > $\pi$（180°）！

这就是球面三角形内角和大于 180° 的深刻几何原因——**正曲率空间中，面积贡献了额外的内角和**。

### 1.3 球面的"直线"——大圆

在平面上，"直线"是两点之间的最短路径。

在球面上，两点之间的最短路径是什么？

答案是：**大圆**（great circle）的弧。

> **定义**：大圆是球面上圆心与球心重合的圆——即过球心的平面与球面的交线。

大圆是球面上的"直线"，因为：
1. 大圆是球面上两点之间的最短路径（测地线）
2. 大圆在每一点的曲率最小（最"直"）
3. 任意两个大圆都相交（球面上没有平行线！）

球面上的"线段"就是大圆弧，"直线"就是整个大圆。

📐 **几何理解**：大圆是球面上的"直线"，这是因为球面是弯曲的——在弯曲的空间中，"直线"的定义从"不弯曲的线"变成了"最短路径"（测地线）。大圆恰好是球面上的最短路径，所以它就是球面几何中的"直线"。

这就像在地球上，从北京飞到纽约的最短航线不是沿着纬线飞，而是沿着大圆飞——经过北极附近。这就是大圆航线，是球面几何在现实中的应用。

## 第二章 球面三角形的定义与基本元素

### 2.1 球面三角形的定义

> **定义**：球面上由三条大圆弧围成的图形称为**球面三角形**。

三个大圆弧的交点称为球面三角形的**顶点**，三条大圆弧称为球面三角形的**边**。

球面三角形的三个顶点通常记为 $A, B, C$，对应的对边记为 $a, b, c$（与平面三角形的记法一致）。

### 2.2 球面三角形的边

球面三角形的**边**是大圆弧的**弧度长度**（不是长度，而是角度！）。

具体来说，边 $a$ 是顶点 $A$ 的对边，即顶点 $B$ 和 $C$ 之间的大圆弧所对的**球心角**：
$$a = \angle BOC$$
其中 $O$ 是球心。

因为是单位球面（半径 $R=1$），所以大圆弧的弧度长度等于球心角的弧度值。

对于半径为 $R$ 的球面，大圆弧的实际长度是 $R \cdot a$（$a$ 是弧度值）。

球面三角形的边满足：
- 每条边 $< \pi$（180°）——否则不是"最短路径"
- 三条边之和 $< 2\pi$（360°）
- 任意两边之和 > 第三边（球面三角不等式，与平面类似）

### 2.3 球面三角形的角

球面三角形的**角**是两条大圆弧在交点处的**切线夹角**。

具体来说，角 $A$ 是在顶点 $A$ 处，边 $AB$ 和边 $AC$ 的切线之间的夹角。

因为大圆的切线垂直于球的半径，所以两条大圆弧在交点处的切线都在该点的切平面内，它们的夹角就是球面三角形的角。

球面三角形的角满足：
- 每个角 $< \pi$（180°）
- 三个角之和 $> \pi$（180°）且 $< 3\pi$（540°）
- 内角和超出 $\pi$ 的部分称为**球面角盈**（spherical excess）

### 2.4 边与角的区别

球面三角形与平面三角形的一个重要区别是：

- **平面三角形**：边是长度，角是角度，两者量纲不同
- **球面三角形**：边是球心角（弧度），角是切线夹角（弧度），两者量纲相同！

球面三角形的边和角都是角度（弧度），这使得球面三角学中可以有"边与角互换"的对偶关系——极三角形（后面会详细讨论）。

📐 **几何理解**：球面三角形的边是"球心角"，角是"切线夹角"——两者都是角度，这是球面几何的独特性质。在平面几何中，边是长度，角是角度，两者不能直接比较；但在球面几何中，边和角都是弧度，可以直接比较，甚至可以互换（极三角形）。这是正曲率空间的一个深刻特征。

## 第三章 球面余弦定理

### 3.1 球面余弦定理

> **球面余弦定理**（边的余弦定理）：
> $$\cos a = \cos b \cos c + \sin b \sin c \cos A$$
> 其中 $a, b, c$ 是球面三角形的边（弧度），$A$ 是边 $a$ 的对角。

类似地：
$$\cos b = \cos a \cos c + \sin a \sin c \cos B$$
$$\cos c = \cos a \cos b + \sin a \sin b \cos C$$

### 3.2 与平面余弦定理的对比

平面余弦定理：
$$a^2 = b^2 + c^2 - 2bc \cos A$$

球面余弦定理：
$$\cos a = \cos b \cos c + \sin b \sin c \cos A$$

两者形式完全不同！平面余弦定理是关于边长的**二次式**，球面余弦定理是关于边的**三角函数式**。

但它们有一个共同点：都描述了"边与对角的关系"——已知两边及其夹角，可以求第三边。

### 3.3 球面余弦定理的几何证明

球面余弦定理可以用**向量方法**几何地证明。

设球心为原点 $O$，球面三角形的三个顶点对应的单位向量为 $\mathbf{a}, \mathbf{b}, \mathbf{c}$（从球心指向顶点）。

边 $a = \angle BOC$，所以 $\mathbf{b} \cdot \mathbf{c} = \cos a$。
同理，$\mathbf{a} \cdot \mathbf{c} = \cos b$，$\mathbf{a} \cdot \mathbf{b} = \cos c$。

角 $A$ 是在顶点 $A$ 处，边 $AB$ 和边 $AC$ 的切线夹角。

边 $AB$ 的切线方向（在 $A$ 点）是 $\mathbf{b} - (\mathbf{a} \cdot \mathbf{b})\mathbf{a} = \mathbf{b} - \cos c \cdot \mathbf{a}$（将 $\mathbf{b}$ 投影到与 $\mathbf{a}$ 垂直的平面）。

边 $AC$ 的切线方向是 $\mathbf{c} - \cos b \cdot \mathbf{a}$。

这两个切线向量的夹角就是角 $A$，所以它们的内积等于各自长度的乘积乘以 $\cos A$。

计算内积：
$$(\mathbf{b} - \cos c \cdot \mathbf{a}) \cdot (\mathbf{c} - \cos b \cdot \mathbf{a})$$
$$= \mathbf{b} \cdot \mathbf{c} - \cos b \cdot \mathbf{b} \cdot \mathbf{a} - \cos c \cdot \mathbf{a} \cdot \mathbf{c} + \cos b \cos c \cdot \mathbf{a} \cdot \mathbf{a}$$
$$= \cos a - \cos b \cos c - \cos c \cos b + \cos b \cos c$$
$$= \cos a - \cos b \cos c$$

计算长度：
$$|\mathbf{b} - \cos c \cdot \mathbf{a}|^2 = |\mathbf{b}|^2 - 2\cos c \cdot \mathbf{a} \cdot \mathbf{b} + \cos^2 c \cdot |\mathbf{a}|^2 = 1 - 2\cos^2 c + \cos^2 c = 1 - \cos^2 c = \sin^2 c$$
所以长度 = $\sin c$。

同理，$|\mathbf{c} - \cos b \cdot \mathbf{a}| = \sin b$。

因此：
$$\cos a - \cos b \cos c = \sin b \sin c \cos A$$
$$\cos a = \cos b \cos c + \sin b \sin c \cos A$$

这就是球面余弦定理！

📐 **几何理解**：球面余弦定理的几何本质是**球面上三个点的位置向量之间的内积关系**。边是向量之间的夹角（内积的反余弦），角是切线向量之间的夹角。通过计算切线向量的内积，就得到了边与角之间的关系——球面余弦定理。

这个证明完全是几何的——它利用了向量内积的几何意义（投影长度的乘积），没有用到任何代数技巧。

### 3.4 角的余弦定理

球面余弦定理还有一个"对偶"形式——**角的余弦定理**：

$$\cos A = -\cos B \cos C + \sin B \sin C \cos a$$

注意这里有一个**负号**！这与边的余弦定理不同。

角的余弦定理说明：已知两个角和它们的夹边，可以求第三个角。

在平面几何中，已知两个角就可以求第三个角（因为内角和 = 180°），不需要夹边。但在球面几何中，内角和不是固定的，所以需要夹边才能求第三个角。

角的余弦定理可以通过极三角形（后面会讨论）从边的余弦定理推导出来。

## 第四章 球面正弦定理

### 4.1 球面正弦定理

> **球面正弦定理**：
> $$\frac{\sin a}{\sin A} = \frac{\sin b}{\sin B} = \frac{\sin c}{\sin C}$$

与平面正弦定理 $\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C}$ 形式非常相似——只是把边长 $a$ 换成了 $\sin a$。

### 4.2 球面正弦定理的几何证明

球面正弦定理也可以用向量方法证明。

球面三角形的面积（在单位球面上）可以用向量的叉积表示：
$$\text{面积} \propto |(\mathbf{b} - \mathbf{a}) \times (\mathbf{c} - \mathbf{a})|$$

但更简洁的证明是利用**四面体的体积**。

考虑由球心 $O$ 和球面三角形三个顶点 $A, B, C$ 组成的四面体 $OABC$。

四面体的体积可以用标量三重积表示：
$$V = \frac{1}{6} |\mathbf{a} \cdot (\mathbf{b} \times \mathbf{c})|$$

另一方面，四面体的体积也可以用"底面积 × 高 / 3"来计算。

以三角形 $OBC$ 为底，底面积 = $\frac{1}{2} \sin a$（因为 $OB=OC=1$，夹角为 $a$）。
从 $A$ 到平面 $OBC$ 的高 = $\sin c \sin B$（需要一些几何推导）。

所以体积 = $\frac{1}{3} \times \frac{1}{2} \sin a \times \sin c \sin B = \frac{1}{6} \sin a \sin c \sin B$。

同理，以其他面为底，可以得到：
$$V = \frac{1}{6} \sin a \sin b \sin C = \frac{1}{6} \sin b \sin c \sin A = \frac{1}{6} \sin a \sin c \sin B$$

因此：
$$\sin a \sin b \sin C = \sin b \sin c \sin A = \sin a \sin c \sin B$$

约去公共因子，得到：
$$\frac{\sin a}{\sin A} = \frac{\sin b}{\sin B} = \frac{\sin c}{\sin C}$$

这就是球面正弦定理！

📐 **几何理解**：球面正弦定理的几何本质是**四面体体积的不变性**。同一个四面体，用不同的面作为底面，计算出的体积应该相同。体积涉及到"边的正弦 × 角的正弦"，所以不同底面的体积相等就导出了边的正弦与角的正弦的比例关系——球面正弦定理。

这与平面正弦定理的证明非常相似——平面正弦定理可以用三角形面积的不变性来证明（$S = \frac{1}{2}ab\sin C = \frac{1}{2}bc\sin A = \frac{1}{2}ac\sin B$）。球面正弦定理则是用四面体体积的不变性来证明——从二维的面积升到了三维的体积。

## 第五章 球面角盈与面积公式

### 5.1 球面角盈的定义

> **定义**：球面三角形的**球面角盈**（spherical excess）定义为内角和超出 $\pi$（180°）的部分：
> $$E = A + B + C - \pi$$

因为球面三角形内角和 > $\pi$，所以 $E > 0$。

球面角盈的范围是 $0 < E < 2\pi$（因为内角和 $< 3\pi$）。

### 5.2 球面三角形的面积公式

> **球面三角形面积公式**（Harriot-Girard 定理）：
> $$S = E \cdot R^2 = (A + B + C - \pi) R^2$$
> 其中 $R$ 是球面半径，$E$ 是球面角盈（弧度）。

对于单位球面（$R=1$）：
$$S = A + B + C - \pi = E$$

**这是最反直觉的结论之一**：球面三角形的面积直接由内角和超出 $\pi$ 的部分决定！

在平面几何中，三角形的面积与内角和无关（内角和总是 180°），面积由边长和高决定。但在球面几何中，**面积完全由角决定**——知道了三个角，就知道了面积！

### 5.3 面积公式的几何证明

球面三角形面积公式可以用**球面二角形**（lune）的面积来证明。

**球面二角形**是球面上由两条大圆弧围成的图形（像橘子的一瓣）。如果二角形的角是 $\alpha$（弧度），则它的面积是 $2\alpha R^2$（因为整个球面面积是 $4\pi R^2$，对应 $2\pi$ 的二角形角，所以比例是 $2R^2$ 每弧度）。

现在考虑球面三角形 $ABC$，三个角为 $A, B, C$。

将三角形的三条边延长为完整的大圆，这些大圆将球面分成 8 个球面三角形（类似于平面上三条直线将平面分成 7 个区域，但球面上是 8 个，因为球面是闭合的）。

利用球面二角形的面积，可以推导出：
- 以角 $A$ 为顶点的二角形面积 = $2A R^2$，包含三角形 $ABC$ 和它的对顶三角形
- 同理，以角 $B$ 和 $C$ 为顶点的二角形面积分别为 $2B R^2$ 和 $2C R^2$

将这三个二角形的面积相加：
$$2A R^2 + 2B R^2 + 2C R^2 = 2(A+B+C) R^2$$

这个和覆盖了整个球面（$4\pi R^2$）加上 4 倍的三角形 $ABC$ 的面积（因为三角形 $ABC$ 被计算了 3 次，它的对顶三角形被计算了 3 次，其他区域各被计算了 1 次，所以三角形 $ABC$ 多算了 2 次，加上对顶三角形的 2 次，总共多算了 4 次三角形面积）。

因此：
$$2(A+B+C) R^2 = 4\pi R^2 + 4S$$
$$S = \frac{2(A+B+C) R^2 - 4\pi R^2}{4} = (A+B+C-\pi) R^2 = E R^2$$

这就是球面三角形面积公式！

📐 **几何理解**：球面三角形面积公式的几何本质是**球面二角形面积的叠加**。将三角形的三个角对应的二角形面积相加，整个球面被覆盖，三角形被多计算了几次。通过简单的代数运算，就得到了面积 = 角盈 × 半径²。

这个公式最反直觉的地方在于：**面积完全由角决定**。在平面上，角相同的三角形可以有不同的面积（相似三角形），但在球面上，角相同的三角形面积必然相同——因为球面上没有相似三角形！（下一章会详细讨论）

### 5.4 例子验证

让我们用第一章的例子验证一下：

北极-赤道三角形，三个角都是 90°（$\pi/2$ 弧度）。

球面角盈 $E = 3 \times \pi/2 - \pi = \pi/2$。

单位球面上的面积 $S = E = \pi/2$。

整个单位球面面积是 $4\pi$，所以这个三角形占球面面积的 $(\pi/2)/(4\pi) = 1/8$。

这是正确的——三个互相垂直的大圆（如赤道、0°经线、90°经线）将球面分成 8 个全等的三角形，每个三角形的三个角都是 90°，面积都是球面的 1/8。

## 第六章 极三角形——球面三角形的对偶

### 6.1 极三角形的定义

> **定义**：对于球面三角形 $ABC$，它的**极三角形**（polar triangle）$A'B'C'$ 定义如下：
> - $A'$ 是边 $BC$ 所在大圆的一个极点（即与 $BC$ 平面垂直的半径与球面的交点），且与 $A$ 在 $BC$ 的同侧
> - $B'$ 是边 $AC$ 所在大圆的极点，与 $B$ 在 $AC$ 的同侧
> - $C'$ 是边 $AB$ 所在大圆的极点，与 $C$ 在 $AB$ 的同侧

极三角形是球面三角形的**对偶**（dual）——边与角互换。

### 6.2 极三角形的基本性质

极三角形有一个非常优美的性质：

> **极三角形定理**：如果球面三角形 $A'B'C'$ 是 $ABC$ 的极三角形，那么：
> - 极三角形的边 = $\pi -$ 原三角形的对应角
> - 极三角形的角 = $\pi -$ 原三角形的对应边

具体来说：
$$a' = \pi - A, \quad b' = \pi - B, \quad c' = \pi - C$$
$$A' = \pi - a, \quad B' = \pi - b, \quad C' = \pi - c$$

其中带撇的是极三角形的边和角。

而且，**极三角形的极三角形就是原三角形**（对偶的对偶 = 自身）。

### 6.3 极三角形的几何理解

📐 **几何理解**：极三角形的几何本质是**球面上的"对偶变换"**——将点（顶点）变换为大圆（边所在的圆），将大圆变换为点（极点）。

在球面上：
- 每个点（顶点）对应一个大圆（以该点为极点的大圆）
- 每个大圆对应一个点（它的极点）
- 点在大圆上当且仅当大圆的极点在以该点为极点的大圆上

这种"点-大圆"的对偶关系是射影几何中"点-线"对偶在球面上的具体表现。

极三角形就是将原三角形的三个顶点（点）对偶为三个大圆，这三个大圆围成的新三角形就是极三角形。

边与角互换的性质来自于：原三角形的角是两条边（大圆）的夹角，对偶后变成了两个顶点（极点）之间的距离（边），而这个距离恰好是 $\pi -$ 原角。

### 6.4 极三角形的应用：推导角的余弦定理

利用极三角形，可以从边的余弦定理推导出角的余弦定理。

对极三角形 $A'B'C'$ 应用边的余弦定理：
$$\cos a' = \cos b' \cos c' + \sin b' \sin c' \cos A'$$

代入极三角形的性质 $a' = \pi - A, b' = \pi - B, c' = \pi - C, A' = \pi - a$：
$$\cos(\pi - A) = \cos(\pi - B) \cos(\pi - C) + \sin(\pi - B) \sin(\pi - C) \cos(\pi - a)$$

利用 $\cos(\pi - x) = -\cos x$，$\sin(\pi - x) = \sin x$：
$$-\cos A = (-\cos B)(-\cos C) + \sin B \sin C (-\cos a)$$
$$-\cos A = \cos B \cos C - \sin B \sin C \cos a$$
$$\cos A = -\cos B \cos C + \sin B \sin C \cos a$$

这就是角的余弦定理！

极三角形使得"边的定理"和"角的定理"可以互相推导——这是对偶关系的威力。

## 第七章 球面上没有相似三角形——AAA 全等

### 7.1 平面上的相似三角形

在平面几何中，**相似三角形**是指角对应相等但边不一定相等的三角形。

相似三角形的判定：
- AA（两个角对应相等）→ 第三个角也相等（内角和=180°）→ 三角形相似
- 相似三角形的边成比例，但面积可以不同

平面上有无穷多组相似三角形——角相同，大小可以任意缩放。

### 7.2 球面上没有相似三角形

在球面几何中，**没有相似三角形**！

如果两个球面三角形的角对应相等（AAA），那么它们的边也必然对应相等——也就是说，**AAA 全等**在球面上成立！

这是球面几何最反直觉的结论之一。

### 7.3 为什么球面上 AAA 全等？

球面上 AAA 全等的原因有两个：

**1. 面积公式**：
球面三角形的面积 $S = (A+B+C-\pi) R^2$ 完全由角决定。如果两个三角形角对应相等，它们的面积就相等。

但面积相等还不足以说明全等——还需要边相等。

**2. 角的余弦定理**：
角的余弦定理 $\cos A = -\cos B \cos C + \sin B \sin C \cos a$ 说明：如果三个角 $A, B, C$ 已知，那么边 $a$ 就被唯一确定了：
$$\cos a = \frac{\cos A + \cos B \cos C}{\sin B \sin C}$$

同理，边 $b$ 和 $c$ 也被唯一确定。

所以，如果两个球面三角形的角对应相等，它们的边也必然对应相等——AAA 全等！

📐 **几何理解**：球面上 AAA 全等的几何本质是**正曲率空间的"刚性"**。

在平面（零曲率）上，空间是"柔软的"——可以自由缩放，角相同的三角形可以有不同的大小（相似三角形）。

在球面（正曲率）上，空间是"刚性的"——角完全决定了边，角相同的三角形必然全等。这是因为球面有固定的曲率（半径），缩放会改变曲率，而在固定曲率的空间中，角就决定了大小。

换句话说，在球面上，"大小"不是自由的——它被角和曲率共同决定。球面三角形不能像平面三角形那样自由缩放，因为缩放会改变球面的半径（曲率），而在固定半径的球面上，三角形的大小是固定的。

这与双曲几何（负曲率）形成对比——双曲几何中也没有相似三角形，AAA 也全等。只有在零曲率的欧氏几何中，才有相似三角形。

**相似三角形的存在性是欧氏几何独有的特征**——它等价于平行公设（第五公设），也等价于零曲率。

### 7.4 球面三角形的全等判定

球面三角形的全等判定：
- SSS（边边边）：三边对应相等 → 全等
- SAS（边角边）：两边及其夹角对应相等 → 全等
- ASA（角边角）：两角及其夹边对应相等 → 全等
- AAS（角角边）：两角及其中一角的对边对应相等 → 全等
- **AAA（角角角）：三角对应相等 → 全等**（球面独有！）

在平面上，AAA 只能判定相似，不能判定全等；但在球面上，AAA 可以判定全等。

这是球面几何与平面几何最根本的区别之一。

## 第八章 球面三角的应用

### 8.1 航海导航——大圆航线

球面三角学最早的应用就是**航海导航**。

在地球上，两点之间的最短路径是大圆航线（great circle route），而不是沿着纬线飞行的等角航线（rhumb line）。

例如，从北京（北纬 39.9°，东经 116.4°）飞到纽约（北纬 40.7°，西经 74.0°）：
- 等角航线（沿着北纬 40°飞）：距离约 14,500 公里
- 大圆航线（经过北极附近）：距离约 11,000 公里

大圆航线比等角航线短约 3,500 公里！

大圆航线的计算需要用到球面三角学——已知两点的经纬度（相当于球面三角形的两个顶点和球心角），求它们之间的大圆弧距离（球面三角形的边），以及航向角（球面三角形的角）。

### 8.2 天文学——天体位置计算

球面三角学在天文学中也有重要应用。

天球是一个以观测者为中心的假想球面，所有天体都投影在天球上。天体的位置用赤经、赤纬（或地平经度、地平高度）表示。

天体的升落时间、方位角、高度角等计算，都需要用到球面三角学——天球上的三角形（由天极、天顶、天体组成的三角形）是球面三角形。

例如，已知某天体的赤经赤纬和观测者的纬度，求该天体在某时刻的地平高度和方位角——这就是一个球面三角形的求解问题。

### 8.3 测地学——地球表面的测量

地球近似为一个球体（实际上是椭球），地球表面的测量（大地测量）需要用到球面三角学（或椭球三角学）。

大规模的三角测量网（trilateration network）就是在地球表面建立一系列球面三角形，通过测量角度和边长来确定地面点的精确位置。

GPS 定位也涉及到球面三角学——卫星和接收机之间的距离计算、位置解算都需要考虑地球的球面几何。

### 8.4 计算机图形学——球面网格与旋转

在计算机图形学中，球面三角学用于：
- 球面网格的生成与细分（如地球建模、天体模拟）
- 三维旋转的计算（四元数、旋转矩阵与球面三角的关系）
- 球面插值（slerp——球面线性插值，用于动画中的旋转过渡）

slerp 插值的公式就来自于球面三角学——在单位球面上，从一个点到另一个点的均匀旋转（沿着大圆匀速运动）需要用到球面正弦定理和余弦定理。

## 第九章 球面几何退化为平面几何——曲率→0 的极限

### 9.1 小三角形近似

当球面三角形的边长**远小于球面半径**时，球面三角形近似于平面三角形。

这是因为在很小的区域内，球面近似于平面（就像地球表面在小范围内看起来是平的一样）。

数学上，当 $a, b, c \ll 1$（单位球面上），可以用 Taylor 展开近似：
$$\cos a \approx 1 - \frac{a^2}{2}, \quad \sin a \approx a$$

代入球面余弦定理：
$$1 - \frac{a^2}{2} \approx (1 - \frac{b^2}{2})(1 - \frac{c^2}{2}) + bc \cos A$$
$$1 - \frac{a^2}{2} \approx 1 - \frac{b^2}{2} - \frac{c^2}{2} + \frac{b^2 c^2}{4} + bc \cos A$$

忽略高阶小量 $b^2 c^2 / 4$：
$$-\frac{a^2}{2} \approx -\frac{b^2}{2} - \frac{c^2}{2} + bc \cos A$$
$$a^2 \approx b^2 + c^2 - 2bc \cos A$$

这就是**平面余弦定理**！

所以，当球面三角形很小时，球面余弦定理退化为平面余弦定理。

### 9.2 球面半径→∞ 的极限

更一般地，当球面半径 $R \to \infty$ 时，球面几何退化为平面几何。

对于半径为 $R$ 的球面，边的实际长度是 $\hat{a} = R a$（$a$ 是弧度值）。

当 $R \to \infty$ 时，$a = \hat{a}/R \to 0$，所以 $\cos a \approx 1 - a^2/2 = 1 - \hat{a}^2/(2R^2)$，$\sin a \approx a = \hat{a}/R$。

代入球面余弦定理：
$$1 - \frac{\hat{a}^2}{2R^2} \approx (1 - \frac{\hat{b}^2}{2R^2})(1 - \frac{\hat{c}^2}{2R^2}) + \frac{\hat{b}\hat{c}}{R^2} \cos A$$

两边乘以 $R^2$ 并取 $R \to \infty$：
$$R^2 - \frac{\hat{a}^2}{2} \approx R^2 - \frac{\hat{b}^2}{2} - \frac{\hat{c}^2}{2} + \hat{b}\hat{c} \cos A$$
$$\hat{a}^2 = \hat{b}^2 + \hat{c}^2 - 2\hat{b}\hat{c} \cos A$$

这就是平面余弦定理（用实际边长表示）。

### 9.3 内角和的退化

当球面半径 $R \to \infty$ 时，球面三角形的面积 $S = E R^2$ 保持有限（因为实际边长保持有限），所以 $E = S/R^2 \to 0$。

因此内角和 $A+B+C = \pi + E \to \pi$（180°）。

这就是平面三角形的内角和公式！

### 9.4 相似三角形的出现

当 $R \to \infty$ 时，球面几何退化为平面几何，相似三角形出现了。

这是因为在平面（零曲率）上，缩放不改变曲率（始终为零），所以角相同的三角形可以有不同的大小——相似三角形。

而在球面（正曲率）上，缩放会改变曲率（半径改变），在固定半径的球面上，角决定了大小——没有相似三角形。

📐 **几何理解**：球面几何退化为平面几何的过程，就是"曲率从正变零"的过程。当球面半径趋向无穷大时，球面的弯曲变得越来越平缓，在极限情况下变成了平面。所有球面几何的独特性质（内角和>180°、AAA全等、没有相似三角形、面积由角决定）都在极限下退化为平面几何的对应性质（内角和=180°、AAA相似、有相似三角形、面积由边决定）。

这是"曲率决定几何"的最直观体现——曲率是空间的内蕴性质，它决定了三角形内角和、全等判定、相似性等一切几何性质。

## 第十章 反直觉结论与常见误区

### 10.1 反直觉结论

**1. 球面三角形内角和 > 180°**：
最根本的反直觉结论。正曲率空间中，面积贡献了额外的内角和（高斯-博内定理）。极端例子：北极-赤道三角形三个角都是 90°，内角和 270°。

**2. 球面上没有相似三角形——AAA 全等**：
角相同的球面三角形必然全等。角的余弦定理说明角完全决定了边。这与平面几何根本不同。

**3. 球面三角形的面积由角决定**：
$S = (A+B+C-\pi) R^2$——知道三个角就知道面积。平面上面积由边和高决定，与角无关（内角和固定）。

**4. 大圆是球面上的"直线"**：
两点之间最短路径是大圆弧，不是纬线。大圆在每一点最"直"（测地线）。

**5. 球面上任意两条"直线"（大圆）都相交**：
没有平行线！任意两个大圆都有两个交点（对径点）。

**6. 极三角形的边与角互换**：
极三角形的边 = $\pi -$ 原三角形的角，极三角形的角 = $\pi -$ 原三角形的边。对偶关系使得边的定理和角的定理可以互相推导。

**7. 球面余弦定理与平面余弦定理形式完全不同**：
球面是三角函数式，平面是二次式。但当球面半径→∞时，球面余弦定理退化为平面余弦定理。

### 10.2 常见误区

**误区 1**：球面三角形的边是长度。
- **纠正**：球面三角形的边是球心角（弧度），不是实际长度。实际长度 = 半径 × 弧度值。

**误区 2**：球面三角形内角和 = 180°。
- **纠正**：球面三角形内角和 > 180°，且 &lt; 540°。内角和由面积和半径决定。

**误区 3**：球面上有相似三角形。
- **纠正**：球面上没有相似三角形，AAA 全等成立。只有平面（零曲率）上才有相似三角形。

**误区 4**：两点之间最短路径是沿着纬线。
- **纠正**：最短路径是大圆航线，通常经过高纬度地区。

**误区 5**：球面三角形的面积由边长决定。
- **纠正**：球面三角形的面积由角决定（角盈公式），不是由边决定。当然，边和角是相关的（通过余弦定理），但面积公式直接用角表示。

**误区 6**：球面三角学只是平面三角学的简单推广。
- **纠正**：球面三角学有根本不同的性质（内角和、全等判定、相似性等），不是简单推广。它是正曲率空间的几何学，与平面几何（零曲率）和双曲几何（负曲率）并列。

**误区 7**：极三角形只是一个数学游戏，没有实际意义。
- **纠正**：极三角形是球面几何中"点-大圆"对偶的具体表现，是射影几何对偶原理在球面上的应用。它使得边的定理和角的定理可以互相推导，有深刻的理论意义。

## 第十一章 历史演进

### 11.1 球面三角学的发展

**古希腊**：
- Menelaus of Alexandria（约公元100年）：《球面学》（Sphaerica），最早系统研究球面三角学的著作，给出了球面三角形的一些基本定理
- Ptolemy（约公元150年）：《天文学大成》，系统应用球面三角学进行天文计算，编制了弦表

**中世纪阿拉伯**：
- al-Battani（约公元900年）：发现了球面余弦定理的等价形式，改进了天文计算
- Abu al-Wafa（约公元980年）：系统整理了球面三角学，给出了球面正弦定理
- Nasir al-Din al-Tusi（13世纪）：将球面三角学从天文学中独立出来，成为独立的数学分支

**近代欧洲**：
- Regiomontanus（1464）：《论各种三角形》（De Triangulis Omnimodis），欧洲第一部系统的三角学著作，包含平面和球面三角
- John Napier（1614）：发明对数，给出了球面直角三角形的 Napier 类推法（Napier's rules）
- Leonhard Euler（1753）：系统研究了球面三角学，给出了球面余弦定理和正弦定理的现代形式，发现了极三角形的性质
- Adrien-Marie Legendre（1787）：研究了球面三角形与平面三角形的关系（Legendre 定理——小球面三角形的角近似等于平面三角形的角加上面积/3R²）

**非欧几何的发现**：
- Carl Friedrich Gauss（1828）：《曲面的一般研究》，建立了曲面的内蕴几何，发现了高斯曲率
- Nikolai Lobachevsky（1829）和 János Bolyai（1832）：独立发现了双曲几何（非欧几何）
- Bernhard Riemann（1854）：建立了黎曼几何，将曲率概念推广到高维，为广义相对论奠定了数学基础

球面几何作为正曲率空间的模型，与双曲几何（负曲率）和欧氏几何（零曲率）一起，构成了常曲率空间的三种基本类型。

## 第十二章 五类边

- 球面三角学 → 全球导航（GPS）→ 空间几何

### 12.4 特例边

- 小三角形 → 平面三角形（曲率→0近似）

### 13.1 学习路径建议

4. **掌握球面余弦定理**：边的余弦定理和角的余弦定理，理解它们与平面余弦定理的区别和联系。
5. **掌握球面正弦定理**：理解它与平面正弦定理的相似性（$\sin a$ vs $a$），用四面体体积证明。
6. **理解球面角盈与面积公式**：$S=(A+B+C-\pi)R^2$，这是最反直觉的结论之一，用二角形面积证明。

8. **理解 AAA 全等**：球面上没有相似三角形，角决定边。这是正曲率空间的刚性。
9. **了解球面三角的应用**：航海（大圆航线）、天文学（天体位置）、测地学（大地测量）、计算机图形学（slerp）。
10. **理解球面→平面的退化**：当球面半径→∞时，球面几何退化为平面几何，所有独特性质都退化为平面性质。这是"曲率决定几何"的体现。

### 13.2 常见误区

1. **误区**：球面三角形的边是长度。
   - **纠正**：边是球心角（弧度），实际长度 = 半径 × 弧度。

2. **误区**：球面三角形内角和 = 180°。

3. **误区**：球面上有相似三角形。
   - **纠正**：没有，AAA 全等成立。

4. **误区**：两点之间最短路径是纬线。
   - **纠正**：是大圆航线，通常经过高纬度。

5. **误区**：球面三角形面积由边决定。
   - **纠正**：由角决定（角盈公式）。

6. **误区**：球面三角学只是平面三角学的推广。
   - **纠正**：有根本不同的性质，是正曲率空间的独立几何学。

## 第十四章 本章小结

D7-6 作为三角学领域的第六个模块，系统研究了球面三角学——最反直觉的几何领域，核心是从平面几何（零曲率）到球面几何（正曲率）的范式转换。

**核心内容回顾**：

1. **球面的几何本质**：球面是正曲率空间，三角形内角和 > 180°。三种曲率空间对比（球面>180°、平面=180°、双曲&lt;180°）。高斯-博内定理揭示了内角和超出 π 的部分 = 面积 × 曲率。

2. **球面三角形的定义**：由三条大圆弧围成。边是球心角（弧度），角是切线夹角（弧度）——两者量纲相同，这是球面几何的独特性质。

3. **球面余弦定理**：$\cos a = \cos b \cos c + \sin b \sin c \cos A$。与平面余弦定理（二次式）形式不同（三角函数式）。用向量内积几何证明。角的余弦定理 $\cos A = -\cos B \cos C + \sin B \sin C \cos a$（注意负号）。

4. **球面正弦定理**：$\frac{\sin a}{\sin A} = \frac{\sin b}{\sin B} = \frac{\sin c}{\sin C}$。与平面正弦定理相似（$\sin a$ vs $a$）。用四面体体积的不变性几何证明。

5. **球面角盈与面积公式**：$E = A+B+C-\pi$，$S = ER^2$。**最反直觉的结论之一**——面积完全由角决定！用球面二角形面积叠加证明。

6. **极三角形**：球面三角形的对偶，边 = π - 原角，角 = π - 原边。点-大圆对偶的具体表现。用于推导角的余弦定理。

7. **球面上没有相似三角形——AAA 全等**：**最反直觉的结论**。角的余弦定理说明角完全决定边。正曲率空间的"刚性"——只有零曲率的欧氏几何才有相似三角形。

8. **球面三角的应用**：航海（大圆航线）、天文学（天体位置）、测地学（大地测量）、计算机图形学（slerp 插值）。

9. **球面几何退化为平面几何**：当球面半径→∞时，所有球面独特性质退化为平面性质（内角和→180°、余弦定理→平面形式、AAA全等→AAA相似、出现相似三角形）。曲率决定几何。

**核心反直觉结论汇总**：
- 球面三角形内角和 > 180°（正曲率空间）
- 球面上没有相似三角形——AAA 全等成立（角决定边！）
- 球面三角形面积由角决定（$S=ER^2$）
- 大圆是球面上的"直线"（最短路径）
- 球面上没有平行线（任意两大圆相交）
- 极三角形边与角互换（对偶）
- 球面余弦定理是三角函数式（不是二次式）

**下一个模块 D7-7** 将研究双曲函数与非欧几何——另一种"三角学"。双曲函数 $\sinh x, \cosh x$ 不是"另一种特殊函数"，而是**双曲几何中的"三角函数"**——它们与三角函数有完全平行的恒等式，但对应于"负曲率"空间（双曲面）。双曲平面中三角形内角和 &lt; 180°，与球面 > 180° 形成对比。三种几何（球面、平面、双曲）的统一——曲率决定了一切。
