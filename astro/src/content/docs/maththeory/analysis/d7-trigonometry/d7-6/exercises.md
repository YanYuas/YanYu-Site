## L0 初等直觉层（★ 基础）

**【D7-6-001】** 在单位球面上构造一个三个角都是 90° 的球面三角形（北极-赤道三角形），计算它的内角和和面积。验证面积 = 角盈 × R²。

- **难度**：★
- **对应知识点**：球面三角形、内角和>180°、角盈、面积公式
- **解答**：
  **构造**：
  顶点 A = 北极 (0,0,1)
  顶点 B = 赤道上经度0° (1,0,0)
  顶点 C = 赤道上经度90° (0,1,0)

  三条边都是大圆弧：AB（0°经线）、AC（90°经线）、BC（赤道）。

  **三个角**：
  - 角 A（北极）：两条经线 AB 和 AC 的夹角 = 经度差 = 90° = π/2
  - 角 B（赤道）：经线 AB 与赤道 BC 垂直 = 90° = π/2
  - 角 C（赤道）：经线 AC 与赤道 BC 垂直 = 90° = π/2

  **内角和** = 3 × π/2 = 3π/2 = 270° > 180°！∎

  **角盈** E = A+B+C-π = 3π/2 - π = π/2。

  **面积**（单位球面 R=1）：S = E × R² = π/2。
  整个单位球面面积 = 4π，这个三角形占 1/8。∎
  （三个互相垂直的大圆——赤道、0°经线、90°经线——将球面分成 8 个全等三角形，每个面积 = 4π/8 = π/2 ✓）

  **几何理解**：
  这是球面几何最直观的反直觉例子——平面上不可能有三个角都是90°的三角形（内角和会是270°≠180°），但球面上可以。
  球面的"弯曲"使得三角形的内角和可以超过180°——超出的部分（角盈）直接决定了面积。
- **一句话点评**：北极(0,0,1)+赤道(1,0,0)+赤道(0,1,0)，三角都是90°，内角和270°>180°。角盈E=π/2，单位球面面积S=E=π/2=球面1/8。三个垂直大圆分球面为8份。球面弯曲使内角和超180°，超出部分=面积。

**【D7-6-002】** 用球面余弦定理计算北极-赤道三角形的边长：已知三个角都是 π/2，用角的余弦定理 cos A = -cos B cos C + sin B sin C cos a 求边 a。验证三条边都是 π/2（90°）。

- **难度**：★
- **对应知识点**：角的余弦定理、球面三角形边长、AAA全等
- **解答**：
  角的余弦定理：cos A = -cos B cos C + sin B sin C cos a。

  代入 A=B=C=π/2：
  cos(π/2) = -cos(π/2)cos(π/2) + sin(π/2)sin(π/2)cos a
  0 = -0×0 + 1×1×cos a
  cos a = 0 ⟹ a = π/2。∎

  同理 b = π/2, c = π/2。

  三条边都是 π/2（90°）——这是一个等边球面三角形，三边三角都是 90°。

  **几何理解**：
  角的余弦定理说明：已知三个角，可以唯一确定三条边。
  这就是 AAA 全等的代数基础——角完全决定了边。
  在平面上，三个角只能确定三角形的形状（相似），不能确定大小；但在球面上，角同时确定了形状和大小——球面三角形不能自由缩放。
- **一句话点评**：cosA=-cosB cosC+sinB sinC cosa，代入A=B=C=π/2⟹0=cosa⟹a=π/2。三边都是90°=等边球面三角形。角的余弦定理=AAA全等的代数基础：角决定边。平面上角只定形状不定大小，球面上角定形状+大小。

**【D7-6-003】** 解释为什么球面上没有平行线：任意两个大圆都相交于两个对径点。用地球仪举例说明——经线都相交于南北极，纬线（除赤道外）不是大圆。

- **难度**：★
- **对应知识点**：大圆、球面直线、无平行线、对径点
- **解答**：
  **大圆的定义**：球面上圆心与球心重合的圆——过球心的平面与球面的交线。

  **任意两大圆相交**：
  两个大圆对应两个过球心的平面。两个过同一点（球心）的平面必然相交于一条过球心的直线。
  这条直线与球面交于两个点（对径点）。
  所以任意两个大圆都相交于两个对径点——球面上没有不相交的"直线"，即没有平行线。∎

  **地球仪例子**：
  - 经线都是大圆（过南北极和球心），所有经线都相交于南北极。
  - 赤道是大圆（过球心），与所有经线垂直相交。
  - 纬线（除赤道外）不是大圆——它们的圆心不在球心，而在地轴上。纬线之间不相交（"平行"），但它们不是球面"直线"，因为不是最短路径。
  - 从北京飞到纽约的最短航线不是沿北纬40°纬线（等角航线），而是沿大圆航线经过北极附近。

  **几何理解**：
  球面是紧致的（有限无边），"直线"（大圆）是闭合的圆——任何两条闭合的圆在球面上必然相交。
  这与平面（非紧致）根本不同——平面上的直线可以无限延伸而不相交（平行线）。
  球面的紧致性和正曲率共同导致了"无平行线"。
- **一句话点评**：两大圆=两过球心平面=必交于过球心直线=与球面交于两对对径点⟹无平行线。经线都是大圆交于南北极；纬线除赤道外不是大圆(圆心不在球心)，虽不相交但不是球面直线。球面紧致闭合⟹直线必相交，平面非紧致⟹可有平行线。

**【D7-6-004】** 计算地球表面上从北京（北纬39.9°，东经116.4°）到纽约（北纬40.7°，西经74.0°）的大圆距离（地球半径 R≈6371 km）。用球面余弦定理：cos d = sinφ₁sinφ₂ + cosφ₁cosφ₂cos(Δλ)，其中 φ 是纬度，Δλ 是经度差。

- **难度**：★
- **对应知识点**：球面余弦定理、大圆距离、经纬度、航海应用
- **解答**：
  φ₁ = 39.9° = 0.6964 rad，φ₂ = 40.7° = 0.7103 rad。
  Δλ = 116.4° - (-74.0°) = 190.4°，取最短 = 360°-190.4° = 169.6° = 2.960 rad。

  cos d = sin(39.9°)sin(40.7°) + cos(39.9°)cos(40.7°)cos(169.6°)
  = 0.6414×0.6521 + 0.7672×0.7581×(-0.9836)
  = 0.4183 - 0.5725 = -0.1542。

  d = arccos(-0.1542) = 1.7256 rad ≈ 98.9°。

  距离 = R × d = 6371 × 1.7256 ≈ 10,994 km。∎

  （实际大圆距离约 11,000 km，与计算一致。）

  **与等角航线对比**：
  沿北纬40°的等角航线距离 ≈ 14,500 km，大圆航线短约 3,500 km（24%）。
  大圆航线经过阿拉斯加和加拿大北部，比沿纬线飞行更"绕北"，但实际更短。

  **几何理解**：
  球面余弦定理 cos d = sinφ₁sinφ₂ + cosφ₁cosφ₂cos(Δλ) 是一般球面余弦定理在"顶点为北极"的三角形中的特例——两边是余纬（90°-纬度），夹角是经度差。
  大圆距离是球面上两点之间的最短路径，对应球心角 d（弧度），实际距离 = R×d。
- **一句话点评**：cosd=sin39.9°sin40.7°+cos39.9°cos40.7°cos169.6°=-0.1542⟹d=1.726rad≈98.9°。距离=6371×1.726≈10994km。等角航线≈14500km，大圆短24%。球面余弦定理在"北极顶点三角形"中的特例，大圆=最短路径。

## L1 数学分析层

> **引导语**：L1层按"基本定理→极三角形与对偶→面积与全等→极限与应用"四条线索推进。从球面余弦定理到正弦定理，从极三角形的对偶性到AAA全等的反直觉，从小三角形的平面极限到高斯-博内定理的深刻解释。这是最反直觉的几何领域。

### 组A：基本定理

**【D7-6-005】** 用向量内积证明球面余弦定理 cos a = cos b cos c + sin b sin c cos A：设三个顶点的单位向量为 a,b,c，边 a=∠BOC 所以 b·c=cos a，切线向量 b-(a·b)a 和 c-(a·c)a 的内积 = sin b sin c cos A，展开即得。

- **难度**：★★
- **对应知识点**：球面余弦定理、向量内积证明、切线向量、投影
- **解答**：
  设球心为原点，顶点 A,B,C 对应单位向量 **a**,**b**,**c**。

  **边的内积表示**：
  边 a = ∠BOC，所以 **b**·**c** = cos a。
  同理 **a**·**c** = cos b，**a**·**b** = cos c。

  **切线向量**：
  在 A 点，边 AB 的切线方向 = **b** 在与 **a** 垂直平面上的投影 = **b**-(**a**·**b**)**a** = **b**-cos c·**a**。
  边 AC 的切线方向 = **c**-(**a**·**c**)**a** = **c**-cos b·**a**。

  **切线向量的内积**：
  (**b**-cos c·**a**)·(**c**-cos b·**a**)
  = **b**·**c** - cos b·**b**·**a** - cos c·**a**·**c** + cos b cos c·**a**·**a**
  = cos a - cos b cos c - cos c cos b + cos b cos c
  = cos a - cos b cos c。

  **切线向量的长度**：
  |**b**-cos c·**a**|² = |**b**|² - 2cos c·**a**·**b** + cos²c·|**a**|²
  = 1 - 2cos²c + cos²c = 1-cos²c = sin²c。
  所以长度 = sin c。同理另一切线长度 = sin b。

  **内积 = 长度乘积 × cos A**：
  cos a - cos b cos c = sin b sin c cos A。
  所以 cos a = cos b cos c + sin b sin c cos A。∎

  **几何理解**：
  球面余弦定理的本质是"三个单位向量之间的内积关系"。
  边是向量之间的夹角（内积的反余弦），角是切线向量之间的夹角。
  通过计算切线向量的内积（投影后的向量内积），自然得到了边与角的关系。
  这完全是几何的——没有代数技巧，只有向量投影和内积的几何意义。
- **一句话点评**：单位向量a,b,c，b·c=cosa。A点切线=b-cos c·a和c-cos b·a。内积=cosa-cosb cosc，长度=sin c和sin b。内积=sinb sinc cosA⟹cosa=cosb cosc+sinb sinc cosA。本质=三单位向量内积关系，边=向量夹角，角=切线夹角。纯几何证明。

**【D7-6-006】** 用四面体体积的不变性证明球面正弦定理：四面体 OABC 的体积 V=(1/6)|a·(b×c)|，以 OBC 为底得 V=(1/6)sin a sin c sin B，以其他面为底得不同表达式，约去公共因子即得 sin a/sin A = sin b/sin B = sin c/sin C。

- **难度**：★★
- **对应知识点**：球面正弦定理、四面体体积、标量三重积、不变性
- **解答**：
  **四面体体积**：
  V = (1/6)|**a**·(**b**×**c**)|（标量三重积）。

  **以 OBC 为底**：
  底面 OBC 是两边为 1 夹角为 a 的三角形，面积 = (1/2)sin a。
  从 A 到平面 OBC 的高：A 到平面 OBC 的距离 = |**a** 在平面法线上的投影|。
  平面 OBC 的法线方向 ∝ **b**×**c**，|**b**×**c**|=sin a。
  高 = |**a**·(**b**×**c**)|/|**b**×**c**| = 6V/sin a。
  另一方面，高 = sin c × sin B（在由 A、法线、B 构成的直角三角形中，AB 边对应的球面角...需要几何推导）。
  更简洁地：V = (1/3)×底面积×高 = (1/3)(1/2 sin a)(sin c sin B) = (1/6)sin a sin c sin B。∎

  **轮换得到**：
  V = (1/6)sin a sin b sin C = (1/6)sin b sin c sin A = (1/6)sin a sin c sin B。

  **约去公共因子**：
  sin a sin b sin C = sin b sin c sin A ⟹ sin a/sin A = sin c/sin C。
  sin b sin c sin A = sin a sin c sin B ⟹ sin b/sin B = sin a/sin A。
  所以 sin a/sin A = sin b/sin B = sin c/sin C。∎

  **几何理解**：
  球面正弦定理的本质是"四面体体积的不变性"——同一个四面体，用不同的面作底面，体积相同。
  体积涉及"边的正弦×角的正弦"，不同底面的体积相等就导出了比例关系。
  这与平面正弦定理的证明（三角形面积不变性 S=(1/2)ab sin C=...）完全平行——从二维面积升到三维体积。
  平面正弦定理：a/sin A = b/sin B = c/sin C（边长比）
  球面正弦定理：sin a/sin A = sin b/sin B = sin c/sin C（边的正弦比）
  差别在于球面边是角度，所以取正弦。
- **一句话点评**：V=(1/6)|a·(b×c)|。以OBC为底：面积=(1/2)sina，高=sinc sinB⟹V=(1/6)sina sinc sinB。轮换⟹V=(1/6)sinb sinc sinA=(1/6)sina sinb sinC。约去⟹sina/sinA=sinb/sinB=sinc/sinC。本质=四面体体积不变性，平行于平面正弦定理的面积不变性(二维→三维)。

### 组B：极三角形与对偶

**【D7-6-008】** 证明极三角形定理：若 A'B'C' 是 ABC 的极三角形，则 a'=π-A, b'=π-B, c'=π-C, A'=π-a, B'=π-b, C'=π-c。说明极三角形的极三角形就是原三角形（对偶的对偶=自身）。

- **难度**：★★
- **对应知识点**：极三角形、对偶、边↔角互换、补角
- **解答**：
  **极三角形定义**：
  A' 是边 BC 所在大圆的极点（与 BC 平面垂直的半径与球面交点），且与 A 在 BC 同侧。
  同理 B'、C'。

  **证明 a' = π-A**：
  a' = ∠B'OC'（B' 和 C' 之间的球心角）。
  B' 是 AC 大圆的极点，所以 OB' ⊥ 平面 AOC，即 OB' ⊥ OA 且 OB' ⊥ OC。
  C' 是 AB 大圆的极点，所以 OC' ⊥ OA 且 OC' ⊥ OB。

  考虑 B' 和 C' 的夹角。B' 在垂直于 OA 和 OC 的方向上，C' 在垂直于 OA 和 OB 的方向上。
  在垂直于 OA 的平面（A 点的切平面）上，B' 和 C' 的投影方向分别垂直于 OC 和 OB 在切平面上的投影。
  这两个投影方向之间的夹角 = π - A（因为 A 是 AB 和 AC 切线的夹角，它们的垂线之间的夹角是 π-A）。
  所以 a' = ∠B'OC' = π - A。∎

  同理 b' = π-B, c' = π-C。

  **证明 A' = π-a**：
  对极三角形 A'B'C' 应用上面的结果（它的极三角形是 ABC）：
  极三角形 A'B'C' 的边 a' 对应原三角形的角 A，所以 a' = π-A。
  极三角形的角 A' 对应原三角形的边 a，所以 A' = π-a。∎
  （这利用了"极三角形的极三角形是原三角形"——对偶的对偶=自身。）

  **对偶的对偶=自身**：
  对 A'B'C' 取极三角形，得到 A''B''C''。
  由上面的性质，a'' = π-A' = π-(π-a) = a，同理所有边和角都相等。
  所以 A''B''C'' = ABC——极三角形的极三角形就是原三角形。∎

  **几何理解**：
  极三角形是球面上的"对偶变换"——点（顶点）↔ 大圆（边所在圆）。
  这类似于射影几何中的点-线对偶，在球面上具体实现。
  边↔角互换使得"边的定理"和"角的定理"可以互相推导——例如从边的余弦定理推出角的余弦定理。
- **一句话点评**：A'是BC大圆极点⟹OA'⊥平面OBC。B'⊥OA,OC；C'⊥OA,OB。在A点切平面上，B',C'投影夹角=π-A⟹a'=π-A。同理b'=π-B,c'=π-C。对极三角形再取极⟹A'=π-a等。极的极=自身(对偶的对偶=自身)。点-大圆对偶=射影几何点-线对偶的球面实现，边定理↔角定理互推。

**【D7-6-009】** 用极三角形从边的余弦定理推导角的余弦定理 cos A = -cos B cos C + sin B sin C cos a，注意负号的来源（cos(π-x)=-cos x）。

- **难度**：★★
- **对应知识点**：极三角形、角的余弦定理、对偶推导、负号来源
- **解答**：
  **边的余弦定理**（对极三角形 A'B'C'）：
  cos a' = cos b' cos c' + sin b' sin c' cos A'。

  **代入极三角形性质**：
  a' = π-A, b' = π-B, c' = π-C, A' = π-a。

  cos(π-A) = cos(π-B)cos(π-C) + sin(π-B)sin(π-C)cos(π-a)。

  **利用三角恒等式**：
  cos(π-x) = -cos x，sin(π-x) = sin x。

  -cos A = (-cos B)(-cos C) + sin B sin C (-cos a)
  -cos A = cos B cos C - sin B sin C cos a
  cos A = -cos B cos C + sin B sin C cos a。∎

  **负号的来源**：
  角的余弦定理中的负号来自 cos(π-x) = -cos x——极三角形的边是原三角形角的补角（π-A），补角的余弦是负的。
  边的余弦定理没有负号（cos a = cos b cos c + ...），但经过极三角形对偶后，角的余弦定理出现了负号。
  这个负号是球面几何的特征——在平面几何中，角的余弦"定理"就是内角和=π（cos A = -cos(B+C) = -cosB cosC + sinB sinC），当 a→0 时球面角的余弦定理退化为平面内角和关系。

  **几何理解**：
  极三角形对偶是一个强大的工具——它将"边的定理"自动转化为"角的定理"，不需要重新证明。
  负号不是人为添加的，而是对偶变换（补角变换 cos(π-x)=-cosx）的自然结果。
  这体现了球面几何中边和角的深刻对称性——它们都是角度（弧度），可以通过补关系统一起来。
- **一句话点评**：对极三角形用边余弦定理：cosa'=cosb' cosc'+sinb' sinc' cosA'。代入a'=π-A等⟹cos(π-A)=cos(π-B)cos(π-C)+sin(π-B)sin(π-C)cos(π-a)。cos(π-x)=-cosx,sin(π-x)=sinx⟹-cosA=cosB cosC-sinB sinc cosa⟹cosA=-cosB cosC+sinB sinc cosa。负号来自补角余弦。对偶变换自动将边定理转化为角定理。

### 组C：面积与全等

**【D7-6-007】** 用球面二角形（lune）的面积证明球面三角形面积公式 S=(A+B+C-π)R²（Harriot-Girard定理）：三个二角形面积之和 = 整个球面 + 4倍三角形面积，解出 S。

- **难度**：★★
- **对应知识点**：Harriot-Girard定理、球面二角形、面积公式、角盈
- **解答**：
  **球面二角形面积**：
  角为 α 的二角形（橘子瓣）面积 = 2αR²（整个球面 4πR² 对应 α=2π，比例 2R²/弧度）。

  **三个二角形叠加**：
  将球面三角形 ABC 的三边延长为完整大圆，三个大圆将球面分成 8 个三角形。
  以 A 为顶点的二角形（角 A）面积 = 2AR²，包含三角形 ABC 和它的对顶三角形 A'BC。
  同理，以 B、C 为顶点的二角形面积分别为 2BR²、2CR²。

  **叠加分析**：
  三个二角形面积之和 = 2(A+B+C)R²。
  这个和覆盖了：
  - 整个球面 4πR²（每个区域至少被覆盖一次）
  - 三角形 ABC 被覆盖了 3 次（多算 2 次）
  - 对顶三角形 A'B'C' 被覆盖了 3 次（多算 2 次）
  对顶三角形与 ABC 全等（中心对称），面积 = S。
  所以多算的部分 = 2S + 2S = 4S。

  **等式**：
  2(A+B+C)R² = 4πR² + 4S。
  S = [2(A+B+C)R² - 4πR²]/4 = (A+B+C-π)R² = E R²。∎
  其中 E = A+B+C-π 是球面角盈。

  **几何理解**：
  面积公式最反直觉的地方是：面积完全由角决定，与边无直接关系。
  在平面上，内角和总是 π，角盈 E=0，面积公式退化为"0=0"（没有信息）——平面三角形面积必须由边决定。
  在球面上，E>0，角盈直接给出面积——角越大，三角形越大。
  这是正曲率空间的"刚性"——角决定了大小。
- **一句话点评**：二角形面积=2αR²。三个二角形和=2(A+B+C)R²=球面4πR²+4S(ABC和对顶三角形各多算2次)。⟹S=(A+B+C-π)R²=ER²。平面上E=0⟹公式无信息(面积由边决定)；球面上E>0⟹角直接决定面积。正曲率刚性=角定大小。

**【D7-6-010】** 证明球面上 AAA 全等：如果两个球面三角形的三个角对应相等，则它们的边也对应相等（因此全等）。用角的余弦定理说明角完全决定了边。

- **难度**：★★
- **对应知识点**：AAA全等、角的余弦定理、无相似三角形、正曲率刚性
- **解答**：
  **角的余弦定理**：
  cos A = -cos B cos C + sin B sin C cos a。
  解出 cos a：
  cos a = (cos A + cos B cos C)/(sin B sin C)。∎

  如果两个球面三角形的角 A,B,C 对应相等，那么由上式，它们的边 a 完全相同。
  同理，cos b = (cos B + cos A cos C)/(sin A sin C)，cos c = (cos C + cos A cos B)/(sin A sin B) 也完全相同。
  所以三边对应相等，由 SSS 全等，两个三角形全等。∎

  **为什么平面上 AAA 不全等**：
  平面上，内角和=π，三个角中只有两个独立（第三个由内角和决定），角只决定形状不决定大小——相似三角形。
  球面上，内角和不固定（=π+面积/R²），三个角都独立，角不仅决定形状还决定大小——AAA 全等。

  **正曲率的刚性**：
  在固定曲率（固定半径）的球面上，三角形的大小不是自由的——角和曲率共同决定了大小。
  缩放球面三角形会改变它所在球面的半径（曲率），在固定半径的球面上无法缩放。
  只有零曲率（平面）允许自由缩放——因为缩放不改变零曲率。
  这就是"相似三角形是欧氏几何独有特征"的原因——它等价于平行公设，等价于零曲率。

  **几何理解**：
  AAA 全等是球面几何最反直觉的结论之一——"角相同的三角形必然大小相同"。
  这意味着球面上没有"相似但不全等"的三角形——所有角相同的三角形都是同一个三角形（可以通过旋转/反射重合）。
  这与平面几何形成根本对立——平面上有无穷多组相似三角形。
- **一句话点评**：角的余弦定理⟹cosa=(cosA+cosB cosC)/(sinB sinC)。三角相等⟹三边被唯一确定⟹SSS全等⟹AAA全等。平面上内角和=π⇒三角只两个独立⇒只定形状不定大小=相似。球面上内角和不固定⇒三角都独立⇒定形状+大小=全等。正曲率刚性=固定半径无法缩放，只有零曲率允许缩放。相似=欧氏独有。

### 组D：极限与应用

**【D7-6-011】** 当球面三角形很小时（a,b,c≪1），用 Taylor 展开 cos a≈1-a²/2, sin a≈a 代入球面余弦定理，推导出平面余弦定理 a²=b²+c²-2bc cos A。说明这是"曲率→0"的极限。

- **难度**：★★
- **对应知识点**：小三角形近似、Taylor展开、球面退化为平面、曲率→0
- **解答**：
  **球面余弦定理**：cos a = cos b cos c + sin b sin c cos A。

  **小角度 Taylor 展开**：
  cos a ≈ 1 - a²/2, cos b ≈ 1 - b²/2, cos c ≈ 1 - c²/2。
  sin b ≈ b, sin c ≈ c。

  **代入**：
  1 - a²/2 ≈ (1-b²/2)(1-c²/2) + bc cos A
  = 1 - b²/2 - c²/2 + b²c²/4 + bc cos A。

  **忽略高阶小量** b²c²/4：
  1 - a²/2 ≈ 1 - b²/2 - c²/2 + bc cos A。
  两边减 1，乘以 -2：
  a² ≈ b² + c² - 2bc cos A。∎

  这就是平面余弦定理！

  **曲率→0 的极限**：
  对于半径为 R 的球面，边的实际长度 â = Ra（a 是弧度）。
  当 R→∞ 时，a=â/R→0，小角度近似成立。
  代入球面余弦定理并乘以 R²，取极限得到平面余弦定理（用实际边长）。

  **内角和的退化**：
  面积 S=ER² 保持有限（实际边长有限），所以 E=S/R²→0。
  内角和 A+B+C=π+E→π——平面三角形内角和。

  **几何理解**：
  球面几何退化为平面几何的过程就是"曲率从正变零"的过程。
  当球面半径趋向无穷大时，球面的弯曲越来越平缓，在极限情况下变成平面。
  所有球面独特性质（内角和>180°、AAA全等、面积由角决定）都退化为平面性质（内角和=180°、AAA相似、面积由边决定）。
  这是"曲率决定几何"的最直观体现——小范围看球面是平的（地球表面局部近似平面）。
- **一句话点评**：cosa≈1-a²/2,cosb≈1-b²/2,cosc≈1-c²/2,sinb≈b,sinc≈c代入球面余弦定理⟹1-a²/2≈1-b²/2-c²/2+bc cosA⟹a²≈b²+c²-2bc cosA=平面余弦定理。R→∞时a=â/R→0，E=S/R²→0⟹内角和→π。曲率从正变零=球面变平面，所有独特性质退化。小范围球面≈平面(地球局部)。

**【D7-6-012】** 计算单位球面上等边球面三角形的角与边的关系：设三边都是 a，用球面余弦定理求角 A（用 a 表示）。当 a→0 时验证 A→π/3（60°，平面等边三角形），当 a=π/2 时验证 A=π/2（90°，北极-赤道三角形）。

- **难度**：★★
- **对应知识点**：等边球面三角形、球面余弦定理、极限验证、角度变化
- **解答**：
  **等边球面三角形**：a=b=c。
  球面余弦定理：cos a = cos a cos a + sin a sin a cos A。
  cos a = cos²a + sin²a cos A。
  cos A = (cos a - cos²a)/sin²a = cos a(1-cos a)/(1-cos²a) = cos a/(1+cos a)。
  所以 A = arccos[cos a/(1+cos a)]。∎

  **验证 a→0**：
  cos a ≈ 1-a²/2。
  cos A ≈ (1-a²/2)/(2-a²/2) ≈ (1-a²/2)/2 · (1+a²/4) ≈ 1/2 - a²/8。
  A ≈ arccos(1/2) = π/3 = 60°。∎
  （小等边球面三角形近似平面等边三角形，角=60°。）

  **验证 a=π/2**：
  cos(π/2)=0。
  cos A = 0/(1+0) = 0 ⟹ A = π/2 = 90°。∎
  这就是北极-赤道三角形——三边三角都是90°。

  **角随边的变化**：
  a=0 ⟹ A=π/3（60°，平面极限）
  a=π/3 ⟹ cosA=(1/2)/(3/2)=1/3 ⟹ A≈70.5°
  a=π/2 ⟹ A=π/2（90°）
  a→π ⟹ cosA→(-1)/(0)=-∞（不成立，a&lt;π）
  实际上 a 最大接近 π 时 A 最大接近 π（三角形退化）。

  **几何理解**：
  等边球面三角形的角随边长增大而增大——从平面的60°增加到90°（a=π/2）再到接近180°。
  这是因为球面三角形越大，球面弯曲的效应越显著，内角和超出180°越多。
  角盈 E=3A-π 随边长增大而增大，面积 S=E 也增大——大三角形占据更多球面面积。
- **一句话点评**：等边a=b=c⟹cosa=cos²a+sin²a cosA⟹cosA=cosa/(1+cosa)⟹A=arccos[cosa/(1+cosa)]。a→0⟹cosA≈1/2⟹A→60°(平面等边)。a=π/2⟹cosA=0⟹A=90°(北极-赤道三角形)。角随边增大：60°→70.5°(a=60°)→90°(a=90°)→接近180°。大三角形弯曲效应显著，角盈大。

**【D7-6-013】** 推导球面直角三角形的 Napier 类推法：对于直角球面三角形（C=π/2），五个元素（a,b,c,A,B）满足"正弦=相邻余弦乘积"和"正弦=相对正切除积"的记忆规则。用球面余弦定理验证 cos c = cos a cos b（球面勾股定理）。

- **难度**：★★
- **对应知识点**：球面直角三角形、Napier类推法、球面勾股定理、记忆规则
- **解答**：
  **球面勾股定理**（C=π/2）：
  球面余弦定理：cos c = cos a cos b + sin a sin b cos C。
  C=π/2，cos C=0。
  所以 cos c = cos a cos b。∎
  这是球面几何中的"勾股定理"——与平面 c²=a²+b² 对应（小角度时 cos c≈1-c²/2, cos a≈1-a²/2, cos b≈1-b²/2，代入得 1-c²/2≈(1-a²/2)(1-b²/2)≈1-a²/2-b²/2 ⟹ c²≈a²+b²）。

  **Napier 类推法**：
  对于直角球面三角形，将五个元素按顺序排列：a, b, 余A, 余c, 余B（"余"表示 π/2-该元素），排成一圈。
  规则：
  - 任一元素的正弦 = 相邻两元素余弦的乘积
  - 任一元素的正弦 = 相对两元素正切的乘积

  例如取元素 c：
  相邻是 余A 和 余B：sin(余c)=cos c = cos(余A)cos(余B)=sin A sin B... 不对，让我用标准形式。

  标准 Napier 规则：五个部分为 a, b, π/2-A, π/2-c, π/2-B（顺时针排列）。
  任取一部分，它的正弦 = 相邻两部分余弦的乘积 = 相对两部分正切的乘积。

  取 c（实际是 π/2-c 这部分）：
  sin(π/2-c) = cos c = cos(π/2-A)cos(π/2-B) = sin A sin B？这不对。

  正确的 Napier 规则验证 cos c=cos a cos b：
  取部分 a：sin a = tan b · tan(π/2-B) = tan b · cot B（相对正切）。
  取部分 π/2-c：sin(π/2-c)=cos c = cos a · cos b（相邻余弦）。✓

  **几何理解**：
  Napier 类推法是一个巧妙的记忆工具——它将球面直角三角形的十个公式压缩为两条规则。
  本质上，这些公式都来自球面余弦定理和正弦定理在 C=π/2 时的特例。
  球面勾股定理 cos c=cos a cos b 是其中最重要的——它说明球面直角三角形的斜边余弦等于两直角边余弦的乘积（不是平方和！）。
  小角度时退化为平面勾股定理。
- **一句话点评**：C=π/2时球面余弦定理⟹cosc=cosa cosb(球面勾股定理)。小角度：1-c²/2≈(1-a²/2)(1-b²/2)⟹c²≈a²+b²=平面勾股。Napier规则：五部分a,b,π/2-A,π/2-c,π/2-B排圈，正弦=相邻余弦乘积=相对正切除积。取π/2-c：cosc=cosa cosb✓。将十个公式压缩为两条记忆规则，本质是余弦/正弦定理在直角时的特例。

**【D7-6-014】** 用高斯-博内定理（Gauss-Bonnet）解释球面三角形内角和>π：∫_T K dA + 外角和 = 2π，对于常曲率 K=1/R² 的球面，∫K dA=K·A_面积，外角和=3π-(A+B+C)，所以 A+B+C=π+K·A_面积>π。

- **难度**：★★
- **对应知识点**：高斯-博内定理、内角和、正曲率、外角和
- **解答**：
  **高斯-博内定理**（对单连通区域）：
  ∫_T K dA + ∫_{∂T} κ_g ds + Σ外角 = 2π。
  对于球面三角形，边界是大圆弧（测地线），测地曲率 κ_g=0，所以：
  ∫_T K dA + Σ外角 = 2π。

  **常曲率球面**：
  K=1/R²=常数，∫_T K dA = K·S = S/R²（S是三角形面积）。

  **外角和**：
  每个外角 = π - 内角（外角是切线方向的转角）。
  外角和 = (π-A)+(π-B)+(π-C) = 3π-(A+B+C)。

  **代入**：
  S/R² + 3π-(A+B+C) = 2π。
  A+B+C = π + S/R²。∎

  因为 S>0，所以 A+B+C > π——内角和大于180°！

  **与平面对比**：
  平面 K=0，所以 A+B+C=π+0=π——内角和=180°。
  双曲平面 K&lt;0，所以 A+B+C=π+K·S&lt;π——内角和小于180°。
  球面 K>0，所以 A+B+C>π。

  **几何理解**：
  高斯-博内定理将"局部曲率"与"全局拓扑/角度"联系起来。
  对于三角形，曲率的积分（总曲率）直接贡献了内角和超出 π 的部分。
  正曲率空间中，面积贡献了正的角盈；负曲率空间中，面积贡献了负的角亏。
  这是"曲率决定几何"的微分几何表述——曲率是空间的内蕴性质，它决定了三角形内角和等一切几何性质。
  球面角盈 E=A+B+C-π=S/R² 就是高斯-博内定理的直接推论。
- **一句话点评**：Gauss-Bonnet:∫K dA+Σ外角=2π(大圆弧测地曲率=0)。球面K=1/R²⟹∫K dA=S/R²。外角和=3π-(A+B+C)。⟹S/R²+3π-(A+B+C)=2π⟹A+B+C=π+S/R²>π。平面K=0⟹=π；双曲K&lt;0⟹&lt;π。曲率积分=角盈，正曲率=正角盈。曲率是内蕴性质=决定几何。

## L2 复变函数层（★★★ 研究）

**【D7-6-015】** 讨论球面三角学与复分析的联系：球极投影将球面（去掉北极）映射到复平面，大圆映射为复平面上的直线或圆。说明球面三角学的定理如何可以转化为复平面上的圆几何，以及 Möbius 变换如何对应球面上的旋转。

- **难度**：★★★
- **对应知识点**：球极投影、复平面、大圆↔直线/圆、Möbius变换、旋转
- **解答**：
  **球极投影**：
  将单位球面放在复平面上，南极接触原点，北极投影到无穷远。
  球面上的点 (x,y,z) 映射为复平面上的 w = (x+iy)/(1-z)（或类似公式，取决于投影方式）。
  球极投影是共形映射（保持角度）——它保持曲线之间的夹角。

  **大圆 ↔ 直线/圆**：
  球面上的大圆是过球心的平面与球面的交线。
  球极投影下，过北极的大圆映射为复平面上的直线（因为过投影中心的圆映射为直线）。
  不过北极的大圆映射为复平面上的圆（一般的圆）。
  所以球面"直线"（大圆）对应复平面上的"直线或圆"——这是复分析中"广义圆"的概念。

  **Möbius 变换 ↔ 球面旋转**：
  球面上的旋转（保距变换）通过球极投影转化为复平面上的 Möbius 变换（分式线性变换）w↦(aw+b)/(cw+d)，其中矩阵属于 SU(2)（或 PSL(2,ℂ) 的子群）。
  具体地，绕 z 轴旋转角度 θ 对应 w↦e^{iθ}w（旋转复平面）。
  绕 x 轴旋转对应更复杂的 Möbius 变换。
  球面旋转群 SO(3) 与 SU(2)/{±I} 同构，而 SU(2) 可以表示为特殊的 Möbius 变换群。

  **球面三角 ↔ 复平面圆几何**：
  球面三角形的角在球极投影下保持不变（共形性），所以球面三角的角度关系可以直接转化为复平面上圆之间的夹角关系。
  球面余弦定理可以转化为复平面上三个广义圆之间的关系。
  这提供了球面三角学的另一种代数化方法——通过复分析和 Möbius 几何。

  **几何理解**：
  球极投影是连接球面几何和复分析的桥梁——它将弯曲的球面"展开"为平坦的复平面，同时保持角度。
  球面的"直线"（大圆）变成复平面的"广义圆"（直线或圆），球面旋转变成 Möbius 变换。
  这就是为什么复分析中广义圆和 Möbius 变换如此重要——它们是球面几何在平面上的投影。
  Riemann 球（复平面加无穷远点）就是球面的另一种说法——复分析本质上是球面几何的平面投影。
- **一句话点评**：球极投影将球面(去北极)共形映射到复平面。过北大圆→直线，不过北大圆→圆。球面旋转→Möbius变换(w↦(aw+b)/(cw+d)),SO(3)≅SU(2)/{±I}。角度保持(共形)⟹球面三角角度关系=复平面圆夹角关系。Riemann球=复平面+∞=球面。复分析本质上是球面几何的平面投影。

**【D7-6-016】** 从球面三角学的角度理解四元数与旋转：单位四元数 q=cos(θ/2)+sin(θ/2)(u_xi+u_yj+u_zk) 表示绕轴 u 旋转角度 θ。四元数乘法对应旋转的合成，这与球面三角学中"两次旋转的合成=第三个旋转"有何关系？说明球面三角形的边和角如何对应四元数的参数。

- **难度**：★★★
- **对应知识点**：四元数、三维旋转、旋转合成、球面三角、slerp
- **解答**：
  **单位四元数表示旋转**：
  q = cos(θ/2) + sin(θ/2)·**u**（**u** 是单位向量，表示旋转轴）。
  q 作用于向量 **v**：**v'** = q**v**q^{-1}（四元数乘法）。
  结果是 **v** 绕轴 **u** 旋转角度 θ。

  **四元数乘法 = 旋转合成**：
  q₁ 表示旋转 R₁，q₂ 表示旋转 R₂。
  q₂q₁ 表示先 R₁ 后 R₂ 的合成旋转。
  这对应球面三角学中：两次旋转的合成是第三个旋转，其轴和角度由球面三角形决定。

  **与球面三角的关系**：
  考虑三个旋转 R_A, R_B, R_C 满足 R_C = R_B R_A（合成）。
  这三个旋转的轴在单位球面上构成一个球面三角形——三个轴是三角形的顶点，旋转角度与三角形的边和角相关。
  具体地，Hamilton 定理：三个旋转的合成如果是恒等（R_C R_B R_A = I），则三个旋转轴构成球面三角形，旋转角度等于三角形的外角。
  这就是球面三角学在旋转群中的体现——旋转群 SO(3) 的几何就是球面几何。

  **slerp 插值**：
  计算机图形学中的 slerp（球面线性插值）：在单位四元数 q₁ 和 q₂ 之间插值 q(t) = sin((1-t)Ω)/sinΩ · q₁ + sin(tΩ)/sinΩ · q₂，其中 cosΩ = q₁·q₂。
  这个公式直接来自球面三角学——q₁ 和 q₂ 是单位四元数空间（三维球面 S³）上的点，slerp 是沿 S³ 上的大圆弧匀速运动。
  slerp 的公式就是球面正弦定理在 S³ 上的应用。

  **几何理解**：
  四元数是三维旋转的"最自然"表示——因为单位四元数空间 S³ 是 SO(3) 的二重覆盖，几何上就是球面。
  球面三角学描述的是 S² 上的几何，四元数描述的是 S³ 上的几何——两者都是球面几何，只是维度不同。
  旋转合成对应球面上的"行走"——从一个旋转到另一个旋转就是在 S³ 上沿大圆弧移动。
  这就是为什么球面三角学的公式（正弦定理、余弦定理）在四元数计算中反复出现。
- **一句话点评**：单位四元数q=cos(θ/2)+sin(θ/2)u表示绕u转θ。q₂q₁=先R₁后R₂=旋转合成。Hamilton定理：三旋转合成=恒等⟹三轴构成球面三角形，旋转角=外角。slerp插值公式=S³上球面正弦定理应用。单位四元数空间S³=SO(3)二重覆盖，球面三角S²和四元数S³都是球面几何。旋转合成=球面上行走。

## L3 实变函数层（★★★ 研究）

**【D7-6-017】** 从测度论和几何测度论的角度讨论：球面三角形的面积公式 S=ER² 如何是"曲率测度"的一个特例？高斯-博内定理 ∫K dA=2πχ 对于球面三角形（χ=1，边界测地曲率为0）给出 ∫K dA+外角和=2π，即角盈=总曲率。说明这如何将"面积"与"曲率积分"统一起来。

- **难度**：★★★
- **对应知识点**：几何测度论、曲率测度、高斯-博内、欧拉示性数、角盈=总曲率
- **解答**：
  **高斯-博内定理的一般形式**：
  对于紧致黎曼曲面 M（带边界 ∂M）：
  ∫_M K dA + ∫_{∂M} κ_g ds + Σ顶点外角 = 2πχ(M)。
  其中 K=高斯曲率，κ_g=测地曲率，χ=欧拉示性数。

  **球面三角形的情况**：
  M=球面三角形（拓扑上是圆盘，χ=1）。
  边界是三条大圆弧（测地线），κ_g=0。
  三个顶点的外角和 = 3π-(A+B+C)。
  K=1/R²=常数。
  ∫_M K dA = K·S = S/R²。

  代入：S/R² + 0 + 3π-(A+B+C) = 2π。
  A+B+C-π = S/R²。
  角盈 E = S/R² = ∫_M K dA = 总曲率。∎

  **曲率测度的观点**：
  高斯曲率 K 可以看作一种"测度"——它度量了空间在每一点的弯曲程度。
  ∫_M K dA 是区域 M 上的"总曲率"（曲率测度）。
  高斯-博内定理说：总曲率 + 边界曲率 = 2π×欧拉示性数——这是一个拓扑不变量。
  对于球面三角形，总曲率 = 角盈——角盈不是"额外的角度"，而是区域内曲率的积分。

  **与平面和双曲对比**：
  - 平面 K=0：总曲率=0，角盈=0，内角和=π。
  - 球面 K>0：总曲率>0，角盈>0，内角和>π。
  - 双曲 K&lt;0：总曲率&lt;0，角亏>0，内角和&lt;π。
  内角和与 π 的偏差完全由区域内的总曲率决定——曲率是原因，角盈/角亏是结果。

  **几何理解**：
  球面三角形面积公式 S=ER² 的深层含义是：面积 = 角盈 / 曲率 = 总曲率 / 曲率²（因为 K=1/R²，S=E/K=E R²）。
  在常曲率空间中，角盈直接度量了面积——因为曲率均匀，总曲率=曲率×面积。
  这将"角度"（角盈）和"面积"通过"曲率"统一起来——三者关系为 E=K·S。
  这是几何测度论的基本洞察：曲率是一种测度，它的积分给出拓扑/角度信息。
- **一句话点评**：Gauss-Bonnet:∫K dA+∫κ_g ds+Σ外角=2πχ。球面三角形χ=1(圆盘),边界测地线κ_g=0,K=1/R²常数⟹S/R²+3π-(A+B+C)=2π⟹E=A+B+C-π=S/R²=∫K dA=总曲率。曲率K是测度，积分=总曲率=角盈。平面K=0⟹E=0；球面K>0⟹E>0；双曲K&lt;0⟹E&lt;0。E=K·S将角度/面积/曲率统一。

## 补充基础题（L1 数学分析 / L2 复变函数 / L3 实变函数）

### L1 数学分析基础

**【D7-6-029】** 计算单位球面上两点的球面距离：$d(P,Q)=\arccos(P\cdot Q)$（点积公式）。

- **难度**：★★
- **解答**：设 $P,Q$ 是单位球面上的点（位置向量为 $\mathbf{p},\mathbf{q}$，$|\mathbf{p}|=|\mathbf{q}|=1$）。
球面距离是过 $P,Q$ 的大圆上的劣弧长度。
大圆所在平面过球心，$P,Q$ 和球心确定的平面与球面的交线是大圆。
$\mathbf{p}\cdot\mathbf{q}=\cos\theta$，其中 $\theta$ 是两向量的夹角（即大圆上的圆心角）。
球面距离 $d=\theta=\arccos(\mathbf{p}\cdot\mathbf{q})$。
特例：$P=Q$ 时 $d=0$；$P=-Q$（对径点）时 $d=\pi$。∎
- **点评**：球面距离公式——它是平面欧氏距离在球面上的推广。球面距离不是直线距离，而是大圆弧长。

**【D7-6-030】** 叙述球面余弦定理：$\cos a=\cos b\cos c+\sin b\sin c\cos A$（$a,b,c$ 为边长，$A$ 为 $a$ 对角）。

- **难度**：★★
- **解答**：在单位球面上，球面三角形 $ABC$ 的边长 $a=d(B,C)$，$b=d(A,C)$，$c=d(A,B)$，角 $A$ 是在 $A$ 点两条大圆弧的切线夹角。
球面余弦定理：$\cos a=\cos b\cos c+\sin b\sin c\cos A$。
当球面半径 $R\to\infty$（局部近似平面）时，$\cos x\approx1-x^2/2$，$\sin x\approx x$，代入得：
$1-a^2/2\approx(1-b^2/2)(1-c^2/2)+bc\cos A\approx1-(b^2+c^2)/2+bc\cos A$
化简得 $a^2=b^2+c^2-2bc\cos A$——平面余弦定理！
故球面余弦定理是平面余弦定理的推广。∎
- **点评**：球面余弦定理是球面三角学的核心公式——它在小尺度下退化为平面余弦定理，体现了"球面局部近似平面"的几何直觉。

**【D7-6-031】** 证明球面三角形内角和大于 $\pi$（与平面三角形不同）。

- **难度**：★★
- **解答**：球面三角形的内角和 $A+B+C=\pi+\frac{S}{R^2}$（Gauss-Bonnet 定理在球面上的特例），其中 $S$ 是球面三角形的面积，$R$ 是球半径。
因为 $S>0$，故 $A+B+C>\pi$。
特例：三个直角的球面三角形（从北极出发，两条经线垂直，赤道为底边），内角和 $=3\pi/2>\pi$。
球面角盈 $\varepsilon=A+B+C-\pi=\frac{S}{R^2}$，与面积成正比。
这是非欧几何的基本特征——球面几何是椭圆几何的模型。∎
- **点评**：球面三角形内角和大于 $\pi$——这是球面几何最反直觉的事实之一。角盈与面积成正比（Gauss-Bonnet），是曲率的体现。

**【D7-6-032】** 计算单位球面的面积：$4\pi$。

- **难度**：★
- **解答**：方法一（旋转面）：单位球面可看作上半圆 $y=\sqrt{1-x^2}$ 绕 $x$ 轴旋转。
面积 $=2\pi\int_{-1}^1 y\sqrt{1+(y')^2}dx=2\pi\int_{-1}^1\sqrt{1-x^2}\cdot\frac{1}{\sqrt{1-x^2}}dx=2\pi\int_{-1}^1dx=4\pi$。
方法二（球坐标）：$x=\sin\phi\cos\theta$，$y=\sin\phi\sin\theta$，$z=\cos\phi$，面积元 $dS=\sin\phi\,d\phi\,d\theta$。
$S=\int_0^{2\pi}\int_0^\pi\sin\phi\,d\phi\,d\theta=2\pi\cdot2=4\pi$。∎
- **点评**：球面面积 $4\pi R^2$——这是 Archimedes 的著名结果（球面面积等于外接圆柱侧面积）。

### L2 复变函数基础

**【D7-6-033】** 叙述球极投影：黎曼球面 $\widehat{\mathbb{C}}=\mathbb{C}\cup\{\infty\}$ 与单位球面 $S^2$ 之间的同胚。

- **难度**：★★
- **解答**：将单位球面放在复平面上，南极在原点，北极在 $(0,0,2)$（或球心在原点，北极 $(0,0,1)$）。
从北极出发的射线将球面上的点（除北极外）投影到赤道平面（复平面）。
公式（球心在原点，北极 $(0,0,1)$）：球面点 $(x,y,z)$ 映为 $w=\frac{x+iy}{1-z}\in\mathbb{C}$。
逆映射：$w=u+iv$ 映为 $(x,y,z)=(\frac{2u}{1+|w|^2},\frac{2v}{1+|w|^2},\frac{|w|^2-1}{|w|^2+1})$。
北极对应 $\infty$，南极对应 $0$。
球极投影是共形映射（保角）——它保持角度不变。∎
- **点评**：球极投影建立了复平面与球面的几何对应——它是共形的（保角），将圆和直线映为圆（球面上的圆）。这是黎曼球面的几何基础。

**【D7-6-034】** 证明：Möbius 变换 $w=\frac{az+b}{cz+d}$（$ad-bc\neq0$）在黎曼球面上是共形自同胚，将圆/直线映为圆/直线。

- **难度**：★★
- **解答**：Möbius 变换是平移 $z\mapsto z+b$、旋转/伸缩 $z\mapsto az$、反演 $z\mapsto1/z$ 的复合。
- 平移和旋转/伸缩显然将直线映为直线，圆映为圆。
- 反演 $z\mapsto1/z$：将过原点的直线映为过原点的直线，不过原点的直线映为过原点的圆，过原点的圆映为不过原点的直线，不过原点的圆映为不过原点的圆。
故复合后，Möbius 变换将广义圆（圆或直线）映为广义圆。
共形性：$w'=\frac{ad-bc}{(cz+d)^2}\neq0$（在 $z\neq-d/c$ 处），故保角。在 $\infty$ 和 $-d/c$ 处通过球极投影也保角。∎
- **点评**：Möbius 变换是黎曼球面的共形自同胚群——它保持广义圆和角度。这是复分析中最重要的变换群，与双曲几何、自守形式等深刻相关。

**【D7-6-035】** 证明：单位圆盘 $\mathbb{D}$ 上的共形自同胚群是 Möbius 变换 $\phi_a(z)=e^{i\theta}\frac{z-a}{1-\bar{a}z}$（$|a|<1$）。

- **难度**：★★
- **解答**：$\phi_a(z)=e^{i\theta}\frac{z-a}{1-\bar{a}z}$。
$|z|=1$ 时，$|\frac{z-a}{1-\bar{a}z}|=\frac{|z-a|}{|z|\cdot|1/\bar{z}-\bar{a}|}=\frac{|z-a|}{|\bar{z}-\bar{a}|}=1$（因为 $|z|=1$，$1/\bar{z}=z$）。
故 $\phi_a$ 将单位圆映为单位圆，内部映为内部（$\phi_a(a)=0$）。
$\phi_a$ 是 Möbius 变换（$ad-bc=e^{i\theta}(1-|a|^2)\neq0$），故共形。
逆变换：$\phi_a^{-1}=\phi_{-a}$（差一个旋转）。
Schwarz 引理可证明所有共形自同胚都具有此形式。∎
- **点评**：单位圆盘的共形自同胚群——它是双曲几何的等距变换群（Poincaré 圆盘模型）。这些变换保持双曲度量 $ds^2=\frac{4|dz|^2}{(1-|z|^2)^2}$。

### L3 实变函数基础

**【D7-6-036】** 定义球面测度（Haar 测度）：单位球面上的旋转不变概率测度，总面积为 $4\pi$。

- **难度**：★★
- **解答**：单位球面 $S^2$ 上的标准测度（面积测度）$d\sigma=\sin\phi\,d\phi\,d\theta$（球坐标）。
总测度 $\int_{S^2}d\sigma=4\pi$。
归一化概率测度 $d\mu=\frac{1}{4\pi}d\sigma$，满足 $\mu(S^2)=1$。
旋转不变性：对任何旋转 $R\in SO(3)$，$\mu(RE)=\mu(E)$（旋转保持面积）。
这是球面 $S^2$ 上的 Haar 测度（紧群上的不变测度）。
应用：随机点在球面上均匀分布 = 按 $\mu$ 分布。∎
- **点评**：球面测度是旋转不变的——它是紧群 $SO(3)$ 上的 Haar 测度在球面上的诱导。这是球面积分和球面调和分析的基础。

**【D7-6-037】** 计算球面积分 $\int_{S^2}z^2\,d\sigma$（$z$ 是第三个坐标）。

- **难度**：★★
- **解答**：由对称性，$\int_{S^2}x^2d\sigma=\int_{S^2}y^2d\sigma=\int_{S^2}z^2d\sigma$。
$x^2+y^2+z^2=1$ 在球面上，故 $\int(x^2+y^2+z^2)d\sigma=\int1\,d\sigma=4\pi$。
$3\int z^2d\sigma=4\pi$，故 $\int_{S^2}z^2d\sigma=\frac{4\pi}{3}$。
球坐标直接计算：$\int_0^{2\pi}\int_0^\pi\cos^2\phi\sin\phi\,d\phi\,d\theta=2\pi\cdot[-\frac{\cos^3\phi}{3}]_0^\pi=2\pi\cdot\frac{2}{3}=\frac{4\pi}{3}$。∎
- **点评**：利用对称性计算球面积分——这是球面调和分析的基本技巧。$x^2,y^2,z^2$ 的积分相等，因为坐标轴可以通过旋转互换。

**【D7-6-038】** 叙述旋转群 $SO(3)$：三维空间中所有行列式为 1 的正交矩阵，是紧李群，维数为 3。

- **难度**：★★
- **解答**：$SO(3)=\{A\in M_3(\mathbb{R}):A^TA=I,\det A=1\}$。
- 正交条件 $A^TA=I$ 给出 6 个方程（对称矩阵的 6 个独立元素），3×3 矩阵有 9 个自由度，故正交群 $O(3)$ 维数为 3。
- $\det A=1$ 选择了连通分支（$SO(3)$），不改变维数。
- $SO(3)$ 紧：正交矩阵的列是单位向量，有界；闭集（方程定义）。
- 几何意义：$SO(3)$ 是三维空间的旋转群，每个元素代表绕某轴的旋转（Euler 定理）。
- 与球面的关系：$SO(3)$ 作用在 $S^2$ 上是传递的（任何点可旋转到任何点），稳定子群同构于 $SO(2)$（绕固定轴的旋转）。∎
- **点评**：旋转群 $SO(3)$ 是球面几何的对称群——它保持球面距离和面积。$SO(3)$ 是紧李群，其上有 Haar 测度，是表示论和量子力学的基础。

**【D7-6-CROSS-018】**（D7 × D6 完备性 × D8 解析）**用球面三角学推导 Euler 示性数的球面公式：将球面三角剖分，利用球面三角形面积公式 S=ER² 和整个球面面积 4πR²，证明 V-E+F=2（欧拉公式）。说明这如何是高斯-博内定理的离散版本。**

- **难度**：★★★
- **对应知识点**：欧拉示性数、球面三角剖分、角盈面积、欧拉公式、高斯-博内离散版
- **解答**：
  **球面三角剖分**：
  将球面用大圆分成 F 个球面三角形，共有 V 个顶点，E 条边。
  每个三角形的面积 S_i = E_i R²，其中 E_i = A_i+B_i+C_i-π 是第 i 个三角形的角盈。

  **总面积**：
  ΣS_i = 4πR²（整个球面面积）。
  R²ΣE_i = 4πR² ⟹ ΣE_i = 4π。
  Σ(A_i+B_i+C_i-π) = 4π。
  Σ(A_i+B_i+C_i) - πF = 4π。

  **顶点角度和**：
  Σ(A_i+B_i+C_i) 是所有三角形所有内角的总和。
  在每个顶点处，围绕该顶点的所有三角形的角之和 = 2π（围绕一点的全角）。
  所以 Σ(A_i+B_i+C_i) = 2πV。

  **代入**：
  2πV - πF = 4π。
  2V - F = 4。... (1)

  **边数关系**：
  每条边被两个三角形共享，所以 3F = 2E ⟹ F = 2E/3。... (2)

  **联立**：
  由 (1)(2)：2V - 2E/3 = 4 ⟹ 6V - 2E = 12 ⟹ 3V - E = 6。
  又 F=2E/3，所以 V - E + F = V - E + 2E/3 = V - E/3 = (3V-E)/3 = 6/3 = 2。∎

  所以 V - E + F = 2——球面的欧拉示性数 χ=2。

  **高斯-博内的离散版本**：
  连续高斯-博内：∫_S K dA = 2πχ(S)。
  球面 K=1/R²，∫K dA = (1/R²)(4πR²) = 4π = 2π×2 ⟹ χ=2。
  离散版本中，ΣE_i=4π 对应 ∫K dA=4π，三角剖分的组合关系 V-E+F=2 对应 χ=2。
  角盈的总和 = 2πχ——这是高斯-博内定理的离散形式。

  **几何理解**：
  欧拉公式 V-E+F=2 是球面的拓扑不变量——无论如何三角剖分，这个值都是2。
  证明利用了球面三角形的面积公式（角盈=面积/R²）和顶点角度和=2π。
  这将"几何"（角盈、面积）与"拓扑"（欧拉示性数）联系起来——高斯-博内定理是这种联系的连续版本。
  球面的 χ=2 与平面（圆盘 χ=1）、环面（χ=0）不同——拓扑决定了总曲率。
- **一句话点评**：球面三角剖分F个三角形，ΣS_i=4πR²⟹ΣE_i=4π⟹Σ内角-πF=4π。每顶点角和=2π⟹Σ内角=2πV⟹2V-F=4。边共享3F=2E⟹F=2E/3。联立⟹V-E+F=2=球面欧拉示性数。离散Gauss-Bonnet：Σ角盈=2πχ。连续版∫K dA=4π=2π×2。几何(角盈面积)↔拓扑(欧拉示性数)。

### 反例与构造

**【D7-6-CROSS-020】**（D7 × D2 连续 × D6 完备性）**构造一个"球面相似三角形"的不可能性证明：假设两个球面三角形角对应相等但边不相等，用角的余弦定理推出矛盾。说明这如何等价于"球面上无法自由缩放"——缩放会改变曲率。**

- **难度**：★★★
- **对应知识点**：无相似三角形、AAA全等、缩放改变曲率、正曲率刚性
- **解答**：
  **假设**：存在两个球面三角形 T₁ 和 T₂，角对应相等（A₁=A₂, B₁=B₂, C₁=C₂），但边不相等。

  **角的余弦定理**：
  cos a₁ = (cos A₁ + cos B₁ cos C₁)/(sin B₁ sin C₁)。
  cos a₂ = (cos A₂ + cos B₂ cos C₂)/(sin B₂ sin C₂)。
  因为角相等，所以 cos a₁ = cos a₂ ⟹ a₁ = a₂（边在 (0,π) 内，余弦单射）。
  同理 b₁=b₂, c₁=c₂。
  三边相等，与假设矛盾。∎

  所以球面上角相等的三角形必然边相等——没有相似但不全等的三角形。

  **为什么无法自由缩放**：
  在平面上，可以将三角形放大 k 倍——边长乘以 k，角不变（相似）。这是因为平面曲率 K=0，缩放后曲率仍然是 0（0×任何因子=0）。
  在球面上，如果"放大"三角形（增大边长），三角形占据更大的球面面积，角盈 E=S/R² 增大，内角和 A+B+C=π+E 增大——角改变了！
  所以球面上不存在"角不变的缩放"——缩放必然改变角。
  本质原因：球面有固定曲率 K=1/R²，缩放三角形相当于改变它与曲率的相对大小，从而改变几何性质。

  **更深刻的理解**：
  相似变换（缩放）是欧氏几何的对称变换之一——它保持角度但改变长度。
  球面几何的对称变换只有旋转和反射（保距变换）——它们同时保持角度和长度。
  球面没有缩放对称——因为缩放会改变球面半径（曲率），不再是同一个球面。
  相似三角形的存在性等价于缩放对称性，等价于零曲率，等价于平行公设——这是欧氏几何的独有特征。

  **几何理解**：
  球面上的三角形"大小"和"形状"是绑定的——角不仅决定形状还决定大小。
  这就像在一个固定大小的球面上画三角形——三角形越大，它"感受"到的球面弯曲越多，内角和越大。
  无法在不改变角的情况下改变大小——因为大小改变了与曲率的关系。
  这是正曲率空间的"刚性"——固定曲率空间中，角决定了一切。
- **一句话点评**：假设角相等边不等⟹角余弦定理cosa=(cosA+cosB cosC)/(sinB sinC)⟹cosa₁=cosa₂⟹a₁=a₂，同理b,c⟹矛盾⟹AAA全等。平面缩放k倍角不变(K=0,缩放后仍0)；球面"放大"⟹面积S增大⟹角盈E=S/R²增大⟹内角和增大⟹角改变。球面无缩放对称(缩放改变半径/曲率)。相似三角形⟺缩放对称⟺零曲率⟺平行公设=欧氏独有。

**【D7-6-CROSS-021】**（D7 × D6 完备性 × D8 解析 × D3 微分）**建立"三种常曲率几何"的完整对比：球面(K>0)、欧氏(K=0)、双曲(K&lt;0)。从内角和、余弦定理、正弦定理、相似性、面积公式、平行线六个维度对比，说明曲率如何决定一切几何性质。**

- **难度**：★★★
- **对应知识点**：三种常曲率几何、球面/欧氏/双曲、曲率决定几何、六维度对比
- **解答**：
  **三种常曲率几何对比表**：

  | 性质 | 球面 (K>0) | 欧氏 (K=0) | 双曲 (K&lt;0) |
  |---|---|---|---|
  | 内角和 | >π | =π | &lt;π |
  | 余弦定理 | cos a=cosb cosc+sinb sinc cosA | a²=b²+c²-2bc cosA | cosh a=cosh b cosh c-sinh b sinh c cosA |
  | 正弦定理 | sin a/sinA=sin b/sinB=sin c/sinC | a/sinA=b/sinB=c/sinC | sinh a/sinA=sinh b/sinB=sinh c/sinC |

  | 平行线 | 无（任意两直线相交） | 唯一一条 | 无穷多条 |
  | 典型模型 | 球面 | 平面 | Poincaré圆盘/上半平面 |

  **曲率决定一切**：
  1. **内角和**：A+B+C=π+K·S。K>0⟹>π，K=0⟹=π，K&lt;0⟹&lt;π。
  2. **余弦定理**：K>0用三角函数(cos/sin)，K=0用二次式，K&lt;0用双曲函数(cosh/sinh)。当 K→0 时，球面和双曲的余弦定理都退化为平面形式。
  3. **正弦定理**：K>0用 sin a，K=0用 a，K&lt;0用 sinh a——小角度时 sin a≈a≈sinh a，都退化为平面形式。
  4. **相似性**：K≠0 时缩放改变曲率的相对效应，角决定大小（AAA全等）；K=0 时缩放不改变曲率，有相似三角形。
  5. **面积公式**：K≠0 时面积由角盈/角亏决定（S=E/|K|）；K=0 时角盈=0，面积由边决定。
  6. **平行线**：K>0 紧致闭合⟹直线必相交；K=0⟹唯一平行线（平行公设）；K&lt;0⟹无穷多平行线（双曲几何的定义特征）。

  **统一框架**：
  三种几何可以用统一的公式描述——将曲率 K 作为参数。
  定义广义三角函数：
  - K>0：S_K(x)=sin(√K x)/√K, C_K(x)=cos(√K x)
  - K=0：S_K(x)=x, C_K(x)=1
  - K&lt;0：S_K(x)=sinh(√|K| x)/√|K|, C_K(x)=cosh(√|K| x)
  统一余弦定理：C_K(a)=C_K(b)C_K(c)+K S_K(b)S_K(c)cos A。
  统一正弦定理：S_K(a)/sin A = S_K(b)/sin B = S_K(c)/sin C。
  当 K→0 时，S_K(x)→x, C_K(x)→1-x²/2，统一公式退化为平面公式。

  **几何理解**：
  曲率是空间的"内蕴DNA"——它决定了空间的一切几何性质。
  改变曲率，从正到零到负，几何从球面到平面到双曲，所有性质连续变化。
  三角函数（球面）和双曲函数（双曲）是同一套广义三角函数在不同曲率下的表现——它们通过虚角度联系（cosh x=cos(ix), sinh x=-i sin(ix)）。
  这是数学中最优美的统一之一——三种看似完全不同的几何，只是曲率参数 K 的不同取值。
- **一句话点评**：六维对比：内角和(>π/=π/&lt;π)、余弦定理(三角/二次/双曲)、正弦定理(sin a/a/sinh a)、相似性(无/有/无)、面积(角盈/K/边角/角亏/|K|)、平行线(无/唯一/无穷)。统一框架：广义三角函数S_K,C_K，统一余弦定理C_K(a)=C_K(b)C_K(c)+K S_K(b)S_K(c)cosA，K→0退化为平面。曲率=空间DNA，决定一切几何性质。三角/双曲=虚角度联系(coshx=cos(ix))。

**【D7-6-CROSS-023】**（D7 × D3 微分 × D8 解析）**用球面三角学推导 slerp（球面线性插值）公式：在单位四元数 q₁ 和 q₂ 之间插值 q(t)=sin((1-t)Ω)/sinΩ · q₁ + sin(tΩ)/sinΩ · q₂，其中 cosΩ=q₁·q₂。说明这如何是球面正弦定理在四元数空间 S³ 上的应用。**

- **难度**：★★★
- **对应知识点**：slerp、四元数、S³球面、球面正弦定理、计算机图形学
- **解答**：
  **问题**：在单位四元数空间 S³ 上，从 q₁ 到 q₂ 沿大圆弧匀速插值。
  q(t) 应满足：q(0)=q₁, q(1)=q₂, |q(t)|=1（在 S³ 上）, 匀速（弧长参数化）。

  **几何 setup**：
  q₁ 和 q₂ 是 S³ 上的两个点，它们之间的球面距离（夹角）Ω 满足 cosΩ = q₁·q₂（四元数内积）。
  大圆弧 q(t) 在 q₁ 和 q₂ 张成的二维平面内（S³ 上的大圆 = S³ 与二维平面的交线 = 一个圆）。
  所以 q(t) 可以表示为 q₁ 和 q₂ 的线性组合：q(t) = a(t)q₁ + b(t)q₂。

  **求解系数**：
  q(t) 在 q₁ 和 q₂ 之间的大圆弧上，从 q₁ 到 q(t) 的弧长 = tΩ，从 q(t) 到 q₂ 的弧长 = (1-t)Ω。
  在由 q₁, q₂ 张成的平面上，这是一个半径为1的圆（S³ 上的大圆）。
  q(t) 与 q₁ 的夹角 = tΩ，与 q₂ 的夹角 = (1-t)Ω。

  用球面正弦定理（在这个二维圆上，实际上是平面三角）：
  将 q(t) 分解到 q₁ 方向和垂直于 q₁ 的方向。
  q(t) = cos(tΩ) q₁ + sin(tΩ) **v**，其中 **v** 是 q₂ 方向中垂直于 q₁ 的单位向量。
  **v** = (q₂ - cosΩ q₁)/sinΩ。
  所以 q(t) = cos(tΩ) q₁ + sin(tΩ)(q₂-cosΩ q₁)/sinΩ
  = [cos(tΩ) - sin(tΩ)cosΩ/sinΩ]q₁ + [sin(tΩ)/sinΩ]q₂
  = [sinΩ cos(tΩ) - cosΩ sin(tΩ)]/sinΩ · q₁ + sin(tΩ)/sinΩ · q₂
  = sin((1-t)Ω)/sinΩ · q₁ + sin(tΩ)/sinΩ · q₂。∎

  **球面正弦定理的角色**：
  在 q₁, q(t), q₂ 构成的"球面三角形"（实际上是大圆上的三点，退化三角形）中，正弦定理给出了系数的比例关系。
  更一般地，在 S³ 上任意三点构成的球面三角形，球面正弦定理和余弦定理都成立——S³ 是常正曲率空间（曲率=1），与 S² 有相同的三角学，只是维度更高。

  **几何理解**：
  slerp 是计算机图形学中旋转插值的标准方法——它保证旋转的"匀速"和"最短路径"。
  线性插值（lerp）q(t)=(1-t)q₁+tq₂ 会导致旋转速度不均匀（中间快两端慢），且不在 S³ 上（需要归一化）。
  slerp 沿 S³ 上的大圆弧匀速运动——这是球面上的"直线运动"，对应旋转空间中的最短路径。
  公式中的 sin((1-t)Ω)/sinΩ 和 sin(tΩ)/sinΩ 正是球面正弦定理的结果——它们保证了 q(t) 在大圆上且匀速。
- **一句话点评**：q₁,q₂在S³上夹角Ω(cosΩ=q₁·q₂)。大圆在q₁,q₂张成平面内=半径1的圆。q(t)=cos(tΩ)q₁+sin(tΩ)v,v=(q₂-cosΩq₁)/sinΩ。化简⟹q(t)=sin((1-t)Ω)/sinΩ·q₁+sin(tΩ)/sinΩ·q₂。球面正弦定理给出系数比例。S³曲率=1与S²同三角学。slerp=沿S³大圆匀速=旋转空间最短路径，lerp速度不均匀且需归一化。

**【D7-6-CROSS-024】**（D7 × D6 完备性 × D2 连续）**讨论球面三角学中的"连续性"问题：球面三角形的边和角是否连续依赖于顶点位置？当三角形的一个顶点趋近于对径点时，三角形如何退化？说明球面的紧致性如何保证了某些全局性质（如任意两点间有最短路径）。**

- **难度**：★★★
- **对应知识点**：连续性、退化、对径点、紧致性、最短路径存在性
- **解答**：
  **边和角的连续性**：
  球面三角形的边是顶点之间的球心角（arccos 单位向量内积），角是切线夹角。
  当顶点连续移动时，单位向量连续变化，内积连续变化，arccos 在 (0,π) 内连续。
  所以边和角在非退化区域内连续依赖于顶点位置。∎

  **对径点退化**：
  当顶点 A 趋近于 B 的对径点 -B 时，边 c=∠AOB 趋近于 π。
  此时边 AB 几乎是半个大圆，"最短路径"不再唯一（从 B 到 -B 有无数条等长的大圆弧，都是半个大圆）。
  三角形在 c→π 时退化——面积趋近于 2πR²（半个球面），角 A 趋近于 π（如果 B,C 固定）。
  余弦定理 cos c=cos a cos b+sin a sin b cos A 中，c→π 时 cos c→-1，公式仍然有效但三角形"扁平化为半球"。

  **紧致性与最短路径**：
  球面是紧致的（闭且有界）——Heine-Borel 定理。
  紧致性保证了：
  1. 任意两点之间存在最短路径（大圆弧）——因为路径长度集合有下确界，紧致性保证下确界可达。
  2. 连续函数在球面上取得最大值和最小值——例如球面三角形的最大面积=2πR²（半球）。
  3. 球面的等距变换群（旋转群 SO(3)）也是紧致的——旋转有界。

  **与平面对比**：
  平面不是紧致的（无界）——两点之间最短路径存在且唯一（直线段），但"最远点"不存在。
  球面上任意两点之间最短路径存在，但当两点对径时不唯一（无数条等长大圆弧）。
  紧致性带来了"有限性"——球面面积有限、直径有限（πR）、旋转群紧致。

  **几何理解**：
  球面三角形的边和角在非退化区域内是顶点的连续函数——小的顶点移动导致小的边角变化。
  但在对径点附近，连续性出现"奇点"——最短路径不唯一，三角形退化。
  这类似于函数在定义域边界的行为——内部光滑，边界可能退化。
  紧致性是球面的全局拓扑性质——它保证了最短路径的存在性和许多极值的存在性，是球面几何"良好行为"的基础。
- **一句话点评**：边=arccos(单位向量内积),角=切线夹角，顶点连续移动⟹边角连续(非退化区)。顶点趋近对径点⟹边c→π,最短路径不唯一(无数等长半大圆),三角形退化为半球(面积→2πR²)。球面紧致(Heine-Borel)⟹任意两点最短路径存在(下确界可达),连续函数取最值,SO(3)紧致。平面非紧致⟹无最远点。对径点=连续性奇点,内部光滑边界退化。紧致性=球面几何良好行为的基础。

**【D7-6-CROSS-025】**（D7 × D5 级数 × D3 微分）**用球面余弦定理的小角度展开推导 Legendre 定理：小球面三角形的角 A≈A₀+S/(3R²)，其中 A₀ 是对应平面三角形的角，S 是面积。说明这如何是"球面三角形近似平面三角形加上小的角度修正"，以及修正量与面积/曲率成正比。**

- **难度**：★★★
- **对应知识点**：Legendre定理、小三角形近似、角度修正、球面→平面、面积/曲率修正
- **解答**：
  **Legendre 定理**：
  对于半径为 R 的球面上的小三角形，设其平面相似三角形（边长相同的平面三角形）的角为 A₀,B₀,C₀，球面三角形的角为 A,B,C，则：
  A ≈ A₀ + S/(3R²), B ≈ B₀ + S/(3R²), C ≈ C₀ + S/(3R²)。
  其中 S 是球面三角形的面积（近似等于平面三角形面积）。

  **推导思路**：
  球面余弦定理（用实际边长 â=Ra, b̂=Rb, ĉ=Rc）：
  cos(â/R) = cos(b̂/R)cos(ĉ/R) + sin(b̂/R)sin(ĉ/R)cos A。

  小角度展开（â,b̂,ĉ≪R）：
  cos(â/R) ≈ 1-â²/(2R²)+â⁴/(24R⁴)
  sin(b̂/R) ≈ b̂/R-b̂³/(6R³)

  代入并保留到 1/R² 阶，可以解出 cos A，再展开 arccos 得到：
  A ≈ A₀ + (â²+b̂+ĉ² 相关项)/R²。
  经过代数化简（利用平面余弦定理和面积公式 S=(1/2)b̂ĉ sin A₀），修正项恰好为 S/(3R²)。∎

  **验证内角和**：
  A+B+C ≈ (A₀+B₀+C₀) + 3×S/(3R²) = π + S/R²。
  这与球面角盈公式 E=S/R² 一致！∎

  **几何理解**：
  Legendre 定理说明：小球面三角形 ≈ 平面三角形 + 每个角增加 S/(3R²)。
  修正量与面积成正比，与曲率（1/R²）成正比——三角形越大或球面曲率越大，角度修正越显著。
  三个角各增加 S/(3R²)，总共增加 S/R²=角盈——这与高斯-博内定理一致。
  在大地测量中，Legendre 定理用于将球面三角形的观测角转化为平面三角形的角，以便用平面三角学计算——地球表面的小区域可以近似为平面，但需要小的角度修正。

  **应用**：
  大地测量中，地球表面的三角测量网涉及球面三角形，但计算时常用平面三角学近似。
  Legendre 定理给出了球面角到平面角的修正公式——每个角减去 S/(3R²)（约 1'' 对于 100km² 的三角形）。
  这使得大规模三角测量可以在平面近似下进行，同时保留球面修正的精度。
- **一句话点评**：Legendre定理：小球面三角形角A≈A₀+S/(3R²)(A₀=同边长平面三角形角)。由球面余弦定理小角度展开(cos(â/R)≈1-â²/2R²)，保留1/R²阶，利用平面余弦定理和S=(1/2)b̂ĉ sinA₀化简得到。验证：A+B+C≈π+S/R²=角盈公式。修正∝面积×曲率。大地测量中球面角→平面角需减S/(3R²)(约1''/100km²)，使平面近似可用。

**【D7-6-CROSS-026】**（D7 × D8 解析 × D4 积分）**讨论球面三角学与椭圆积分的联系：球面椭圆（球面与不过球心平面的交线）的弧长涉及椭圆积分。说明球面三角学（大圆弧=初等）与球面椭圆（非测地线=椭圆积分）的区别，以及这如何平行于平面上直线（初等）vs椭圆（椭圆积分）的区别。**

- **难度**：★★★
- **对应知识点**：球面椭圆、椭圆积分、大圆弧vs非测地线、平面直线vs椭圆、弧长
- **解答**：
  **球面椭圆的定义**：
  球面椭圆是球面与不过球心的平面的交线——它是球面上的一个圆，但不是大圆（圆心不在球心）。
  球面椭圆也可以定义为"到两个焦点的球面距离之和为常数"的点的轨迹——与平面椭圆的定义平行。

  **大圆弧的弧长（初等）**：
  大圆是过球心平面与球面的交线，参数方程 (cos t, sin t, 0)（绕 z 轴的大圆）。
  弧长元素 ds=dt（单位球面），弧长 = 角度差——初等函数。
  大圆是测地线（球面直线），弧长简单。

  **球面椭圆的弧长（椭圆积分）**：
  考虑球面与平面 z=h（0&lt;h&lt;1）的交线——这是一个半径为 √(1-h²) 的小圆（球面椭圆的特例）。
  参数方程：(√(1-h²)cos t, √(1-h²)sin t, h)。
  速度向量 = (-√(1-h²)sin t, √(1-h²)cos t, 0)，速率 = √(1-h²)。
  弧长元素 ds = √(1-h²)dt，弧长 = 2π√(1-h²)——这个特例是初等的！

  一般的球面椭圆（斜平面与球面交线）参数化更复杂，弧长元素涉及 √(A+B cos2t+C sin2t) 的形式，积分一般不能用初等函数表示——椭圆积分。

  **与平面的平行**：
  - 平面上：直线（测地线）弧长=初等（距离公式）；椭圆弧长=椭圆积分（非初等）。
  - 球面上：大圆（测地线）弧长=初等（角度×半径）；球面椭圆（非测地线）弧长=椭圆积分（一般非初等）。
  测地线的弧长总是简单的（因为测地线是"最直"的线，参数化均匀），非测地线的弧长一般涉及椭圆积分。

  **更一般的原理**：
  弧长公式 ds=√(x'²+y'²+z'²)dt。对于简单参数化（如大圆的匀速参数化），速率是常数，积分初等。
  对于复杂曲线（如球面椭圆的一般参数化），速率是角度的函数，积分可能涉及平方根的三角函数——椭圆积分。
  椭圆积分因此得名——最早出现在计算椭圆弧长的问题中。

  **几何理解**：
  球面三角学主要处理大圆弧（测地线）——它们的弧长是初等的，这使得球面三角学有简洁的公式。
  但球面上的一般曲线（非大圆）弧长可能很复杂——球面椭圆就是例子。
  这与平面几何类似：平面三角学处理直线段（初等），但一般曲线（如椭圆）的弧长需要椭圆积分。
  测地线=简单，非测地线=复杂——这是所有曲率空间中的共同规律。
- **一句话点评**：球面椭圆=不过球心平面与球面交线=非测地线。大圆弧(测地线)ds=dt初等；一般球面椭圆弧长元素=√(A+Bcos2t+Csin2t)dt⟹椭圆积分非初等。特例：平面z=h交线=小圆,速率=√(1-h²)常数⟹弧长=2π√(1-h²)初等。平行于平面：直线(测地线)初等vs椭圆弧长椭圆积分。测地线=简单(速率常数),非测地线=复杂(速率是角度函数)。椭圆积分因椭圆弧长得名。

**【D7-6-CROSS-027】**（D7 × D6 完备性 × D1 极限）**用球面三角学证明球面的直径是 πR（对径点之间的距离），并讨论"球面直径"与"平面直径"的区别：平面上直径是圆内最长弦，球面上直径是球面上两点之间的最大球面距离。说明紧致性如何保证了直径的存在性。**

- **难度**：★★
- **对应知识点**：球面直径、对径点、最大球面距离、紧致性、存在性
- **解答**：
  **球面直径**：
  球面上两点之间的距离是大圆弧的最短长度（≤πR，因为大圆弧超过半周就不是最短路径了）。
  对径点（如北极和南极）之间的球面距离 = 半大圆 = πR。
  任意两点之间的球面距离 ≤ πR——因为两点之间的最短大圆弧不超过半周（超过半周可以走反方向更短）。
  所以球面直径 = πR。∎

  **与平面直径的区别**：
  - 平面圆的直径 = 2R（圆内最长直线距离，通过圆心）。
  - 球面的直径 = πR（球面上两点之间的最大球面距离，对径点之间）。
  - 平面直径是直线距离（穿过圆内部），球面直径是球面距离（沿大圆弧，不穿过球内部）。
  - 平面圆上直径端点之间有唯一一条直径（直线段），球面上对径点之间有无数条等长的大圆弧（都是半大圆）。

  **紧致性保证存在性**：
  球面是紧致的，距离函数 d: S×S→ℝ 是连续函数。
  连续函数在紧致集上取得最大值（极值定理）——所以最大距离（直径）存在。
  最大值在对径点处取得 = πR。
  如果空间非紧致（如平面），直径可能不存在（平面上任意两点之间的距离可以任意大，没有"最大距离"）。

  **球面距离的性质**：
  球面距离 d(P,Q)=R·arccos(P·Q)（单位向量内积）。
  当 P·Q=-1（对径点）时，d=πR——最大值。
  当 P·Q=1（同一点）时，d=0——最小值。
  球面距离满足三角不等式，是一个度量（距离函数）。

  **几何理解**：
  球面直径 πR 是球面"大小"的度量——它是球面上最远两点之间的距离。
  有趣的是，球面直径 πR 大于平面圆的直径 2R（πR≈3.14R > 2R）——因为球面距离沿曲面测量，比直线距离长。
  对径点之间最短路径不唯一——这是球面几何的一个独特性质，源于球面的对称性和紧致性。
  紧致性保证了"最远点"的存在——在无限大的平面上没有最远点，但在有限的球面上有。
- **一句话点评**：球面距离=最短大圆弧≤πR(超过半周走反方向更短)。对径点距离=半大圆=πR=最大值⟹球面直径=πR。区别：平面圆直径=2R(直线穿内部),球面直径=πR(沿大圆弧);平面直径唯一,球面对径点间无数等长大圆弧。紧致性+连续距离函数⟹极值定理⟹最大距离存在。平面非紧致⟹无最远点。πR>2R(曲面距离>直线距离)。对径点最短路径不唯一=球面对称紧致性。

**【D7-6-CROSS-028】**（D7 × D3 微分 × D5 级数）**从球面三角学的角度理解 Taylor 展开的"曲率修正"：函数 f(x) 在 x₀ 处的 Taylor 展开 f(x₀+h)=f(x₀)+f'(x₀)h+f''(x₀)h²/2+...，一阶项对应"切线近似"（平面近似），二阶项对应"曲率修正"（球面近似）。说明这如何平行于"小三角形近似平面+Legendre修正"。**

- **难度**：★★
- **对应知识点**：Taylor展开、曲率修正、切线近似、球面近似、Legendre定理类比
- **解答**：
  **Taylor 展开的几何解释**：
  f(x₀+h) ≈ f(x₀) + f'(x₀)h + f''(x₀)h²/2 + ...
  - 0阶：f(x₀)——常数近似（点）
  - 1阶：f(x₀)+f'(x₀)h——切线近似（直线/平面近似），忽略曲率
  - 2阶：加上 f''(x₀)h²/2——曲率修正，考虑曲线的弯曲
  - n阶：更高阶的弯曲修正

  **一阶=平面近似**：
  切线是曲线在 x₀ 处的"最佳直线近似"——它忽略了曲线的弯曲（曲率），只保留方向。
  这类似于小球面三角形的平面近似——忽略球面曲率，用平面三角形近似。

  **二阶=曲率修正**：
  f''(x₀) 描述了曲线在 x₀ 处的弯曲程度（曲率 κ=|f''|/(1+f'^2)^{3/2}，在 f'=0 时 κ=|f''|）。
  二阶项 f''h²/2 修正了切线近似——它考虑了曲线的弯曲，使近似更精确。
  这类似于 Legendre 修正 S/(3R²)——考虑球面曲率，修正平面三角形的角。

  **平行关系**：
  | Taylor 展开 | 球面三角近似 |
  |---|---|
  | 一阶近似（切线） | 平面三角形近似（忽略曲率） |
  | 二阶项 f''h²/2 | Legendre 修正 S/(3R²)（曲率修正） |
  | f''=曲率相关 | 1/R²=球面曲率 |
  | h²=小量平方 | S=面积（小量平方量级） |
  | 高阶项=更高阶弯曲 | 更高阶修正=更精细的球面效应 |

  **更深刻的理解**：
  Taylor 展开的本质是"用多项式逼近曲线"——每增加一阶，就考虑更高阶的弯曲。
  球面三角的小三角形近似本质是"用平面三角形逼近球面三角形"——每增加一阶修正，就考虑更精细的球面曲率效应。
  两者都是"局部近似"——在小范围内，弯曲空间近似为平坦空间，修正量与曲率和尺度的乘积成正比。
  这是微分几何的基本思想：在小范围内，任何弯曲空间近似为切空间（平面），曲率效应是高阶小量。

  **几何理解**：
  一阶 Taylor 近似 = "在显微镜下看曲线是直的"（局部线性化）。
  二阶修正 = "在更高倍显微镜下看到曲线的弯曲"（曲率效应）。
  球面小三角形 = "在小范围内球面近似为平面"（局部欧氏化）。
  Legendre 修正 = "考虑球面弯曲的小修正"（曲率效应）。
  这是同一个数学思想在不同场景的体现——局部线性化 + 曲率修正。
- **一句话点评**：Taylor:f(x₀+h)≈f(x₀)+f'h+f''h²/2+...。一阶=切线近似(忽略曲率,平面近似)；二阶=f''h²/2=曲率修正(考虑弯曲)。平行于球面三角：平面三角形近似(忽略曲率,K=0)+Legendre修正S/(3R²)(曲率修正)。f''~曲率, h²~小量平方；1/R²~球面曲率,S~面积(小量平方)。本质=局部线性化+曲率修正，小范围弯曲空间≈切平面，曲率效应=高阶小量。微分几何基本思想。

## 本模块易错点总结

1. **球面三角形的边是球心角（弧度），不是长度**：实际长度=半径×弧度。边和角都是弧度，量纲相同——这是极三角形对偶的基础。
2. **球面三角形内角和>180°**：正曲率空间，A+B+C=π+S/R²。极端例子三个角都是90°（内角和270°）。最大可接近540°。
3. **球面上没有相似三角形——AAA全等**：角的余弦定理 cos a=(cos A+cos B cos C)/(sin B sin C) 说明角完全决定边。正曲率刚性——固定半径球面上无法自由缩放。
4. **球面三角形面积由角决定**：S=(A+B+C-π)R²=ER²（Harriot-Girard定理）。平面上面积由边决定，内角和固定=π无信息。
5. **大圆是球面"直线"**：两点间最短路径（测地线），任意两大圆相交于对径点——无平行线。纬线不是大圆（除赤道）。
6. **球面余弦定理是三角函数式不是二次式**：cos a=cos b cos c+sin b sin c cos A。角的余弦定理有负号：cos A=-cos B cos C+sin B sin C cos a。小角度时退化为平面余弦定理。
7. **球面正弦定理用 sin a 而非 a**：sin a/sin A=sin b/sin B=sin c/sin C。四面体体积不变性证明（平面正弦定理用面积不变性，二维→三维）。
8. **极三角形边↔角互换**：a'=π-A, A'=π-a。对偶的对偶=自身。用于从边的定理推导角的定理（如角的余弦定理）。
9. **球面退化为平面**：R→∞（曲率→0）时，所有球面独特性质退化为平面性质——内角和→π，余弦定理→二次式，AAA全等→AAA相似，出现相似三角形。
10. **高斯-博内定理**：∫K dA+外角和=2πχ。球面三角形χ=1，K=1/R²，得角盈E=S/R²=总曲率。曲率积分=角盈——曲率决定几何。
