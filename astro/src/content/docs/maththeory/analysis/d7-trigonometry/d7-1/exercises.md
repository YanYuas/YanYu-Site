## L0 初等直觉层（★ 基础）

**【D7-1-001】** 将下列角度转换为弧度（用 π 表示）：30°, 45°, 60°, 120°, 135°, 150°, 210°, 300°。

- **难度**：★
- **对应知识点**：度与弧度换算、特殊角
- **解答**：
  换算公式：弧度 = 角度 × π/180。
  - 30° = π/6
  - 45° = π/4
  - 60° = π/3
  - 120° = 2π/3
  - 135° = 3π/4
  - 150° = 5π/6
  - 210° = 7π/6
  - 300° = 5π/3
  ∎
- **一句话点评**：角度×π/180=弧度；记住90°=π/2、180°=π、360°=2π，其余按比例推算。

**【D7-1-002】** 将下列弧度转换为度：π/12, 5π/12, 7π/6, 11π/6, 3π/8, 7π/4。

- **难度**：★
- **对应知识点**：弧度与度换算
- **解答**：
  换算公式：角度 = 弧度 × 180/π。
  - π/12 = 15°
  - 5π/12 = 75°
  - 7π/6 = 210°
  - 11π/6 = 330°
  - 3π/8 = 67.5°
  - 7π/4 = 315°
  ∎
- **一句话点评**：弧度×180/π=角度；π弧度=180°是核心锚点。

**【D7-1-003】** 在单位圆上，角 θ = 2π/3 对应的点坐标是什么？该点在第几象限？sin(2π/3) 和 cos(2π/3) 的值和符号是什么？

- **难度**：★
- **对应知识点**：单位圆坐标、三角函数定义、象限符号
- **解答**：
  2π/3 = 120°，在第二象限（π/2 &lt; 2π/3 &lt; π）。
  单位圆上点坐标 = (cos θ, sin θ)。
  cos(2π/3) = cos(π - π/3) = -cos(π/3) = -1/2。
  sin(2π/3) = sin(π - π/3) = sin(π/3) = √3/2。
  点坐标 = (-1/2, √3/2)。
  第二象限：cos &lt; 0, sin > 0。∎
- **一句话点评**：单位圆上点=(cosθ,sinθ)；第二象限x负y正⟹cos负sin正。

**【D7-1-004】** 求半径 r = 5cm 的圆中，圆心角 θ = 2 rad 所对的弧长和扇形面积。

- **难度**：★
- **对应知识点**：弧长公式、扇形面积公式、弧度制
- **解答**：
  弧长：s = rθ = 5 × 2 = 10 cm。
  扇形面积：A = (1/2)r²θ = (1/2) × 25 × 2 = 25 cm²。∎
- **一句话点评**：弧度制下s=rθ，A=(1/2)r²θ，无转换因子；若用度制则需乘π/180。

## L1 数学分析层

> **引导语**：L1层按"角与弧度的基本概念→弧度制的计算应用→单位圆与三角恒等式→重要极限与导数的几何意义"四条线索推进。从π的常数性到弧度的自然性，从扇形计算到重要极限，层层递进。所有题目都强调几何视角，这是三角学的根基。

### 组A：角与弧度的基本概念

**【D7-1-007】** 证明 π 是常数：即对任意两个圆，周长与直径的比值相同。用相似形的思想说明。

- **难度**：★★
- **对应知识点**：π的定义、相似形、圆的周长比
- **解答**：
  设圆 C₁ 半径 r₁，周长 C₁；圆 C₂ 半径 r₂，周长 C₂。
  所有圆都是相似形——将 C₁ 放大 k = r₂/r₁ 倍得到 C₂。
  相似变换中，所有长度按比例 k 放大，所以 C₂ = k · C₁ = (r₂/r₁) · C₁。
  因此 C₁/r₁ = C₂/r₂，即周长与半径的比值对所有圆相同。
  而直径 d = 2r，所以 C/d = C/(2r) 也是常数。
  这个常数定义为 π。∎

  **更严格的说明**：
  用内接正 n 边形逼近圆：正 n 边形周长 = 2nr sin(π/n)，与半径成正比（系数 2n sin(π/n) 与 r 无关）。
  当 n→∞ 时，正 n 边形周长→圆周长，所以圆周长与半径成正比，比例常数 = 2π。
- **一句话点评**：所有圆相似⟹放大k倍时周长也放大k倍⟹C/r=常数⟹C/d=常数=π。内接正n边形周长=2nr sin(π/n)也与r成正比，n→∞得圆周长。

**【D7-1-011】** 比较 1 弧度和 1 度的大小，并解释为什么 1 弧度 ≈ 57.3° 看起来"不整齐"却是最自然的角度度量。

- **难度**：★★
- **对应知识点**：弧度与度的比较、弧度的自然性
- **解答**：
  1 弧度 = 180°/π ≈ 57.2958°。
  1 度 = π/180 ≈ 0.01745 弧度。
  所以 1 弧度 > 1 度（约 57.3 倍）。

  **为什么 1 弧度"不整齐"却最自然**：
  - 度制中 360° = 一周是人为约定（巴比伦六十进制、一年约 360 天），1° = 一周的 1/360，是"整齐"的人为分割。
  - 弧度制中 2π 弧度 = 一周，π 是无理数，所以 1 弧度 = 180/π 度"不整齐"。
  - 但弧度的定义 θ = s/r 直接来自圆的几何，不需要任何人为数字。
  - 弧度制下：弧长 s = rθ、扇形面积 A = (1/2)r²θ、重要极限 lim sin x/x = 1、导数 (sin x)' = cos x、Taylor 展开 sin x = x - x³/3! + ... 全部最简洁。
  - 度制下这些公式都带有 π/180 的转换因子，繁琐且不自然。
  所以"不整齐"的弧度是"自然"的，"整齐"的度是"人为"的。∎
- **一句话点评**：1rad≈57.3°>1°。度制360是人为约定（整齐但不自然），弧度s/r来自几何（不整齐但自然）。弧度制下弧长、面积、极限、导数、Taylor全部最简洁，度制下都带π/180因子。

**【D7-1-009】** 写出与角 θ = -7π/3 终边相同的所有角的集合，并找出其中在 [0, 2π) 范围内的角。

- **难度**：★★
- **对应知识点**：终边相同的角、任意角、周期性
- **解答**：
  终边相同的角相差 2π 的整数倍：
  {θ + 2kπ | k ∈ ℤ} = {-7π/3 + 2kπ | k ∈ ℤ}。

  在 [0, 2π) 范围内：
  -7π/3 + 2π = -7π/3 + 6π/3 = -π/3（仍 &lt; 0）
  -7π/3 + 4π = -7π/3 + 12π/3 = 5π/3（在 [0, 2π) 内）✓
  -7π/3 + 6π = 11π/3 > 2π（超出）
  所以 [0, 2π) 内的角 = 5π/3。∎

  **几何理解**：-7π/3 = -2π - π/3，即顺时针转一整圈再多 π/3，终边与 -π/3 相同，也与 5π/3（逆时针）相同。
- **一句话点评**：终边相同角={-7π/3+2kπ}；加4π得5π/3∈[0,2π)。-7π/3=-2π-π/3，顺时针转一圈多π/3。

### 组B：弧度制的计算应用

**【D7-1-008】** 一个扇形的弧长为 6cm，面积为 12cm²，求该扇形的半径和圆心角（弧度）。

- **难度**：★★
- **对应知识点**：弧长公式、扇形面积公式、解方程组
- **解答**：
  设半径 r，圆心角 θ（弧度）。
  弧长：s = rθ = 6 ... (1)
  面积：A = (1/2)r²θ = 12 ... (2)
  由(1)：θ = 6/r。
  代入(2)：(1/2)r² · (6/r) = 3r = 12 ⟹ r = 4 cm。
  θ = 6/4 = 1.5 rad。
  验证：A = (1/2) × 16 × 1.5 = 12 ✓。∎
- **一句话点评**：s=rθ=6，A=(1/2)r²θ=12；两式相除A/s=r/2⟹r=2A/s=4，θ=s/r=1.5。

**【D7-1-012】** 地球赤道半径约 6378 km，求赤道上经度相差 1° 的两点之间的弧长（精确到 km）。如果用弧度计算呢？

- **难度**：★★
- **对应知识点**：弧长公式、度与弧度、实际应用
- **解答**：
  **度制计算**：
  s = πrθ/180 = π × 6378 × 1 / 180 ≈ 3.14159 × 6378 / 180 ≈ 111.32 km。

  **弧度计算**：
  1° = π/180 rad ≈ 0.017453 rad。
  s = rθ = 6378 × π/180 ≈ 6378 × 0.017453 ≈ 111.32 km。

  两种方法结果相同（本质一样），但弧度制公式 s = rθ 更简洁。∎

  **实际意义**：
  赤道上经度相差 1° ≈ 111 km，这是航海和地理中的常用数据。
  在更高纬度，弧长 = 111 × cos(纬度) km（因为纬线圈半径 = r cos φ）。
- **一句话点评**：赤道1°弧长=πr/180≈111km。弧度制：1°=π/180rad，s=rθ=6378×π/180≈111km。高纬度弧长=111×cos(纬度)。

### 组C：单位圆与三角恒等式

**【D7-1-010】** 用单位圆说明：对任意角 θ，cos²θ + sin²θ = 1，并利用这个恒等式已知 sin θ = 3/5（θ 在第二象限），求 cos θ 和 tan θ。

- **难度**：★★
- **对应知识点**：勾股恒等式、单位圆、象限符号
- **解答**：
  **恒等式证明**：
  单位圆上点 (cos θ, sin θ) 满足 x² + y² = 1（圆的方程），所以 cos²θ + sin²θ = 1。
  这不是需要记忆的公式，而是"点在单位圆上"的直接推论。∎

  **求值**：
  cos²θ = 1 - sin²θ = 1 - 9/25 = 16/25 ⟹ cos θ = ±4/5。
  θ 在第二象限，cos θ &lt; 0，所以 cos θ = -4/5。
  tan θ = sin θ / cos θ = (3/5)/(-4/5) = -3/4。∎
- **一句话点评**：cos²+sin²=1是单位圆方程x²+y²=1的直接推论。sin=3/5⟹cos=±4/5，第二象限cos负⟹cos=-4/5，tan=-3/4。

### 组D：重要极限与导数的几何意义

**【D7-1-005】** 用几何方法（面积比较）证明重要极限 lim_{x→0} sin x / x = 1，并说明为什么这个等式只在弧度制下成立。

- **难度**：★★
- **对应知识点**：重要极限、面积比较、夹逼定理、弧度制本质
- **解答**：
  在单位圆上，考虑 0 &lt; x &lt; π/2 的角 x：
  - 内接三角形面积 = (1/2)sin x
  - 扇形面积 = (1/2)x（弧度制下！）
  - 外切三角形面积 = (1/2)tan x
  面积关系：(1/2)sin x &lt; (1/2)x &lt; (1/2)tan x
  ⟹ sin x &lt; x &lt; tan x
  ⟹ 1 > sin x / x > cos x
  当 x→0⁺ 时 cos x→1，由夹逼定理 lim_{x→0⁺} sin x/x = 1。
  x→0⁻ 时同理（sin x/x 是偶函数）。∎

  **为什么只在弧度制下成立**：
  证明的关键是扇形面积 = (1/2)x，这个公式只在弧度制下成立。
  在度制下，扇形面积 = (1/2)r² · (πx/180)，所以面积比较给出 sin(x°)/(x°) → π/180，而不是 1。
  弧度制的"自然性"正在于此——它让扇形面积公式最简洁，进而让重要极限等于 1。
- **一句话点评**：单位圆上内接三角形&lt;扇形&lt;外切三角形⟹sinx&lt;x&lt;tanx⟹夹逼得lim sinx/x=1。关键是扇形面积=(1/2)x只在弧度制成立；度制下极限=π/180。

**【D7-1-006】** 用单位圆上的切线方向几何地解释为什么 (sin x)' = cos x，并说明这如何依赖于"单位圆上弧长=角度"。

- **难度**：★★
- **对应知识点**：导数的几何意义、单位圆切线、弧度制
- **解答**：
  sin x 是单位圆上点 P=(cos x, sin x) 的纵坐标。
  当 x 增加微小量 dx 时，P 沿单位圆移动了弧长 ds = dx（因为单位圆上弧长=角度，这只在弧度制下成立！）。
  移动方向是切线方向。半径方向向量 = (cos x, sin x)，逆时针旋转 90° 得到切线方向单位向量 = (-sin x, cos x)。
  所以 P 的位移 = dx × (-sin x, cos x)。
  纵坐标的变化量 d(sin x) = dx × cos x。
  因此 (sin x)' = cos x。∎

  **依赖弧长=角度**：
  如果用度制，x 增加 1° 时，点在圆上移动的弧长 = πr/180（不是 1），所以位移 = (π/180)dx × (-sin x, cos x)，导数 = (π/180)cos x。
  只有弧度制下"弧长=角度"，切线位移的系数才是 1，导数公式才最简洁。
- **一句话点评**：sinx=单位圆上点的纵坐标；x增加dx时，点沿切线移动弧长dx（弧度制下弧长=角度），切线方向=(-sinx,cosx)⟹纵坐标变化=cosx·dx⟹(sinx)'=cosx。度制下弧长=πdx/180⟹导数带π/180因子。

## L2 复变函数层（★★★ 研究）

**【D7-1-013】** 说明 Euler 公式 e^{iθ} = cos θ + i sin θ 为什么只在弧度制下具有最简洁形式，并从 Taylor 展开的角度推导它。

- **难度**：★★★
- **对应知识点**：Euler公式、Taylor展开、弧度制、复指数
- **解答**：
  **从 Taylor 展开推导**：
  e^x = ∑x^n/n!（对所有 x 成立，包括复数 x = iθ）。
  e^{iθ} = ∑(iθ)^n/n! = 1 + iθ - θ²/2! - iθ³/3! + θ⁴/4! + iθ⁵/5! - ...
  分离实部和虚部：
  实部 = 1 - θ²/2! + θ⁴/4! - ... = cos θ
  虚部 = θ - θ³/3! + θ⁵/5! - ... = sin θ
  所以 e^{iθ} = cos θ + i sin θ。∎

  **为什么只在弧度制下简洁**：
  上述推导中 cos θ 和 sin θ 的 Taylor 展开：
  cos θ = 1 - θ²/2! + θ⁴/4! - ...
  sin θ = θ - θ³/3! + θ⁵/5! - ...
  这些展开只在弧度制下具有这种简洁形式。
  在度制下，cos(x°) = 1 - (πx/180)²/2! + ...，带有 (π/180)^n 的因子。
  如果 θ 用度，e^{iθ°} 的展开中虚部系数会有 π/180 的因子，Euler 公式就变成 e^{iθ°} = cos(θ°) + i sin(θ°)，但指数函数的"自然参数"是弧度。
  只有弧度制下，e^{iθ} 的 Taylor 展开恰好分离为 cos θ 和 sin θ 的 Taylor 展开，Euler 公式才最优美。

  **几何理解**：e^{iθ} 表示复平面上单位圆上的点，θ 是从正实轴逆时针旋转的角度。e^{iθ} 的模 = 1（在单位圆上），辐角 = θ。只有 θ 用弧度时，e^{iθ} 对 θ 求导 = i e^{iθ}（旋转 90°），这是"匀速圆周运动"的自然描述。
- **一句话点评**：e^{iθ}=∑(iθ)^n/n!，分离实部=1-θ²/2!+...=cosθ，虚部=θ-θ³/3!+...=sinθ⟹Euler公式。关键是cos/sin的Taylor展开只在弧度制下简洁；度制下带(π/180)^n因子。e^{iθ}=单位圆上点，辐角θ，求导=ie^{iθ}=旋转90°。

**【D7-1-014】** 用 Euler 公式推导 de Moivre 公式 (cos θ + i sin θ)^n = cos(nθ) + i sin(nθ)，并说明这如何体现了"角的加法=指数的乘法"。

- **难度**：★★★
- **对应知识点**：de Moivre公式、Euler公式、角的加法、复指数乘法
- **解答**：
  **推导**：
  由 Euler 公式，cos θ + i sin θ = e^{iθ}。
  所以 (cos θ + i sin θ)^n = (e^{iθ})^n = e^{inθ} = cos(nθ) + i sin(nθ)。∎

  **角的加法=指数的乘法**：
  e^{iα} · e^{iβ} = e^{i(α+β)}。
  左边 = (cos α + i sin α)(cos β + i sin β)
  = (cos α cos β - sin α sin β) + i(sin α cos β + cos α sin β)
  右边 = cos(α+β) + i sin(α+β)
  比较实部虚部即得和角公式：
  cos(α+β) = cos α cos β - sin α sin β
  sin(α+β) = sin α cos β + cos α sin β

  这体现了：**角的加法对应复指数的乘法**。旋转 α 再旋转 β = 旋转 α+β，在复数中就是 e^{iα} × e^{iβ} = e^{i(α+β)}。
  这是"旋转构成群"的代数表达——旋转的合成对应乘法，单位元是 e^{i0}=1（不旋转），逆元是 e^{-iθ}（反向旋转）。

  **几何理解**：de Moivre 公式说"旋转 n 次 θ = 旋转一次 nθ"——这在几何上是显然的（旋转的合成），但用复数表达后变成了一个简洁的代数恒等式。弧度制是关键——只有弧度制下 e^{iθ} 才表示"旋转 θ"，度制下需要转换因子。
- **一句话点评**：(cosθ+isinθ)^n=(e^{iθ})^n=e^{inθ}=cos(nθ)+isin(nθ)。角的加法=指数乘法：e^{iα}e^{iβ}=e^{i(α+β)}⟹和角公式。旋转构成群：合成=乘法，单位元=e^{i0}=1，逆元=e^{-iθ}。

**【D7-1-015】** 说明复平面中"乘以 i"等价于"逆时针旋转 90°（π/2 弧度）"，并解释为什么旋转角必须用弧度而不是度。

- **难度**：★★★
- **对应知识点**：复数乘法、旋转、i的几何意义、弧度制
- **解答**：
  **乘以 i = 旋转 π/2**：
  i = e^{iπ/2}（由 Euler 公式，cos π/2 + i sin π/2 = 0 + i·1 = i）。
  对任意复数 z = re^{iθ}，乘以 i：
  i · z = e^{iπ/2} · re^{iθ} = re^{i(θ+π/2)}。
  模不变（仍为 r），辐角增加 π/2——即逆时针旋转 90°。∎

  **为什么用弧度**：
  Euler 公式 e^{iθ} = cos θ + i sin θ 中，θ 必须是弧度（因为 Taylor 展开只在弧度制下简洁，见 D7-1-013）。
  i = e^{iπ/2} 中的 π/2 是弧度。如果用度，i = e^{i·90°·π/180}，就多了一个 π/180 的转换因子，不简洁。
  复数乘法的几何意义"模相乘、辐角相加"中，辐角自然用弧度——因为辐角的微积分（导数、积分）只在弧度制下简洁。

  **推广**：
  乘以 e^{iφ} = 逆时针旋转 φ 弧度。
  乘以 re^{iφ} = 缩放 r 倍 + 旋转 φ 弧度。
  这是复数表示平面旋转和缩放的标准方式，也是复分析的几何基础。

  **几何理解**：i 不是"虚数"那么神秘——它就是"旋转 90°"的算子。i² = -1 意味着"旋转 90° 两次 = 旋转 180° = 反向"，这在几何上是显然的。弧度制让这个算子的指数表达 e^{iπ/2} 最简洁。
- **一句话点评**：i=e^{iπ/2}，z=re^{iθ}⟹iz=re^{i(θ+π/2)}=逆时针转90°。i²=-1=转180°=反向。弧度制关键：Euler公式中θ须为弧度，i=e^{iπ/2}才简洁。推广：乘e^{iφ}=转φ弧度，乘re^{iφ}=缩放+旋转。

## L3 实变函数层（★★★ 研究）

**【D7-1-016】** 从测度论的角度说明：弧度制下的角度度量本质上是单位圆上的弧长测度，而度制是人为的加权测度。讨论为什么 Lebesgue 积分中自然使用弧度。

- **难度**：★★★
- **对应知识点**：弧长测度、Lebesgue积分、弧度制的测度本质
- **解答**：
  **弧度制 = 弧长测度**：
  在单位圆上，弧度制下的角度 θ 恰好等于从 (1,0) 到 (cos θ, sin θ) 的弧长。
  所以弧度制本质上是单位圆上的**弧长测度**——一个集合的"角度大小"就是它在单位圆上对应的弧长。
  弧长测度是圆上最自然的测度，它来自圆的几何结构（Riemann 度量诱导的测度）。

  **度制 = 人为加权测度**：
  度制下，1° = 圆周的 1/360。对应的弧长 = 2πr/360 = πr/180。
  所以度制是弧长测度乘以常数因子 180/π（或 π/180，取决于方向）。
  这个因子是人为的（360 的选择来自巴比伦），没有几何必然性。

  **为什么 Lebesgue 积分自然使用弧度**：
  Lebesgue 积分建立在测度论基础上。在单位圆上，最自然的测度是弧长测度（Haar 测度在圆周群上的限制）。
  弧度制与弧长测度一致，所以在 Lebesgue 积分中：
  - ∫_0^{2π} f(θ) dθ 中的 dθ 就是弧长元素
  - 归一化测度 dθ/(2π) 是圆周群上的概率 Haar 测度
  - Fourier 系数 (1/2π)∫ f(θ)e^{-inθ}dθ 自然出现
  如果用度制，d(θ°) = (π/180)dθ，所有积分公式都多一个转换因子，不自然。

  **更深刻的联系**：
  圆周群 S¹ = {e^{iθ}} 上的 Haar 测度是唯一的（在归一化意义下）平移不变测度。
  弧长测度 dθ 是平移不变的（旋转不改变弧长），所以它就是 Haar 测度（差一个常数因子）。
  弧度制直接对应 Haar 测度，这是它在调和分析、Fourier 分析中自然使用的根本原因。∎
- **一句话点评**：弧度制=单位圆上的弧长测度（几何自然），度制=弧长测度×180/π（人为加权）。Lebesgue积分中dθ=弧长元素，归一化dθ/(2π)=圆周群Haar测度（平移不变），Fourier系数自然出现。度制下多π/180因子，不自然。

**【D7-1-017】** 讨论立体角（球面度）作为平面角（弧度）在三维空间的推广：定义 Ω = A/r²，整个球面 = 4π sr，并说明这与平面角中"整个圆周 = 2π 弧度"的平行关系。

- **难度**：★★★
- **对应知识点**：立体角、球面度、平面角推广、高维角
- **解答**：
  **平面角（二维）**：
  θ = s/r（弧长/半径），无量纲，单位"弧度"。
  整个圆周：s = 2πr ⟹ θ = 2π 弧度。

  **立体角（三维）**：
  Ω = A/r²（锥面在球面上截出的面积/半径²），无量纲，单位"球面度"（steradian, sr）。
  整个球面：A = 4πr² ⟹ Ω = 4π sr。

  **完美平行**：
  | | 平面角（2D） | 立体角（3D） |
  |---|---|---|
  | 定义 | θ = s/r | Ω = A/r² |
  | 分子 | 弧长（1D） | 面积（2D） |
  | 分母 | r¹ | r² |
  | 整个空间 | 2π 弧度 | 4π 球面度 |
  | 几何对象 | 圆弧 | 球面区域 |

  **为什么是 r²**：
  立体角度量的是"锥面张开的程度"。在半径 r 的球面上，锥面截出的面积 A 与 r² 成正比（相似形面积比 = 线度比²），所以 A/r² 与 r 无关——这是立体角的定义。
  类似地，平面角中弧长 s 与 r 成正比，s/r 与 r 无关。

  **推广到 n 维**：
  n 维空间中的"角"可以定义为 (n-1) 维球面上的 (n-1) 维体积 / r^{n-1}。
  整个 (n-1) 维球面的"角度" = 2π^{n/2}/Γ(n/2)（n 维球面的表面积公式）。
  n=2 时 = 2π（平面角），n=3 时 = 4π（立体角）。∎

  **几何理解**：平面角是"1D 弧长 / r"，立体角是"2D 面积 / r²"——维度差 1，分母的幂次就加 1。整个圆周 2π 和整个球面 4π 是同一个数学结构（球面测度）在不同维度的表现。
- **一句话点评**：立体角Ω=A/r²（面积/半径²），全球面=4πr²/r²=4π sr。平行平面角θ=s/r（弧长/半径），全圆周=2πr/r=2π。n维角=(n-1)维体积/r^{n-1}，全空间=2π^{n/2}/Γ(n/2)。维度差1⟹分母幂次+1。

## 补充基础题（L1 数学分析 / L2 复变函数 / L3 实变函数）

### L1 数学分析基础

**【D7-1-028】** 证明弧度制定义的合理性：圆心角 $\theta$ 的弧度数 = 弧长 / 半径，与圆的半径无关。

- **难度**：★
- **解答**：对半径为 $r$ 的圆，圆心角 $\theta$（角度制）对应的弧长 $s=2\pi r\cdot\frac{\theta}{360^\circ}$。
弧度数 $\alpha=\frac{s}{r}=2\pi\cdot\frac{\theta}{360^\circ}$，与 $r$ 无关。
故弧度是角的内蕴度量，不依赖于圆的大小。∎
- **点评**：弧度制的本质——它是角的无量纲度量，只依赖于角本身，与圆的半径无关。这是微积分中使用弧度制的根本原因（$\sin x$ 的导数为 $\cos x$ 只在弧度制下成立）。

**【D7-1-029】** 用单位圆定义三角函数：对任意角 $\theta$，$\sin\theta=y$，$\cos\theta=x$，其中 $(x,y)$ 是角 $\theta$ 终边与单位圆的交点。

- **难度**：★
- **解答**：单位圆 $x^2+y^2=1$。角 $\theta$ 的终边从正 $x$ 轴逆时针旋转 $\theta$ 弧度，与单位圆交于 $(x,y)$。
定义 $\cos\theta=x$，$\sin\theta=y$。
由 $x^2+y^2=1$ 得 $\sin^2\theta+\cos^2\theta=1$（基本恒等式）。
这个定义对任意角（正、负、大于 $2\pi$）都成立，是三角函数最一般的定义。∎
- **点评**：单位圆定义是三角函数的几何本质——它把三角函数从"直角三角形边长比"推广到任意角，同时给出了 $\sin^2+\cos^2=1$ 的几何解释（单位圆方程）。

**【D7-1-030】** 证明诱导公式：$\sin(\theta+\pi)=-\sin\theta$，$\cos(\theta+\pi)=-\cos\theta$。

- **难度**：★
- **解答**：角 $\theta+\pi$ 的终边是角 $\theta$ 终边绕原点旋转 $\pi$（即关于原点对称）。
若 $\theta$ 终边与单位圆交于 $(x,y)$，则 $\theta+\pi$ 终边交于 $(-x,-y)$。
故 $\sin(\theta+\pi)=-y=-\sin\theta$，$\cos(\theta+\pi)=-x=-\cos\theta$。∎
- **点评**：诱导公式的几何本质——它们都是单位圆上的对称性（旋转、反射）的代数表达。$\pi$ 旋转 = 中心对称，$\pi/2$ 旋转 = 坐标交换变号。

**【D7-1-031】** 证明：$\sin x$ 和 $\cos x$ 都是周期为 $2\pi$ 的周期函数。

- **难度**：★
- **解答**：角 $x+2\pi$ 的终边与角 $x$ 的终边相同（旋转一整圈），故与单位圆交于同一点 $(x,y)$。
$\sin(x+2\pi)=y=\sin x$，$\cos(x+2\pi)=x=\cos x$。
$2\pi$ 是最小正周期：若 $\sin(x+T)=\sin x$ 对所有 $x$，则 $T=2k\pi$（$k\in\mathbb{Z}$），最小正周期为 $2\pi$。∎
- **点评**：三角函数的周期性来自单位圆的旋转对称性——旋转 $2\pi$ 回到原位。这是三角函数最基本的性质。

### L2 复变函数基础

**【D7-1-032】** 证明欧拉公式：$e^{i\theta}=\cos\theta+i\sin\theta$。

- **难度**：★★
- **解答**：方法一（幂级数）：
$e^{i\theta}=\sum_{n=0}^\infty\frac{(i\theta)^n}{n!}=\sum\frac{(-1)^k\theta^{2k}}{(2k)!}+i\sum\frac{(-1)^k\theta^{2k+1}}{(2k+1)!}=\cos\theta+i\sin\theta$。
方法二（微分方程）：令 $f(\theta)=e^{i\theta}(\cos\theta-i\sin\theta)$，$f'(\theta)=0$，$f(0)=1$，故 $f\equiv1$。
方法三（几何）：$e^{i\theta}$ 是单位圆上的点，模为 1，辐角为 $\theta$。∎
- **点评**：欧拉公式是数学中最优美的公式之一——它把指数函数和三角函数统一起来。$\theta=\pi$ 时得到 $e^{i\pi}+1=0$（欧拉恒等式）。

**【D7-1-033】** 用欧拉公式推导 $\sin\theta=\frac{e^{i\theta}-e^{-i\theta}}{2i}$，$\cos\theta=\frac{e^{i\theta}+e^{-i\theta}}{2}$。

- **难度**：★
- **解答**：$e^{i\theta}=\cos\theta+i\sin\theta$，$e^{-i\theta}=\cos\theta-i\sin\theta$。
相加：$e^{i\theta}+e^{-i\theta}=2\cos\theta$ ⟹ $\cos\theta=\frac{e^{i\theta}+e^{-i\theta}}{2}$。
相减：$e^{i\theta}-e^{-i\theta}=2i\sin\theta$ ⟹ $\sin\theta=\frac{e^{i\theta}-e^{-i\theta}}{2i}$。∎
- **点评**：这是复三角函数的定义式——它们把实三角函数推广到复变量。对复数 $z$，$\sin z=\frac{e^{iz}-e^{-iz}}{2i}$，$\cos z=\frac{e^{iz}+e^{-iz}}{2}$。

**【D7-1-034】** 证明：复三角函数 $\sin z$ 和 $\cos z$ 是整函数（在全平面解析）。

- **难度**：★★
- **解答**：$\sin z=\frac{e^{iz}-e^{-iz}}{2i}$，$\cos z=\frac{e^{iz}+e^{-iz}}{2}$。
$e^{iz}$ 和 $e^{-iz}$ 都是整函数（指数函数是整函数，复合仍整函数）。
整函数的线性组合仍是整函数，故 $\sin z,\cos z$ 是整函数。
导数：$(\sin z)'=\cos z$，$(\cos z)'=-\sin z$（与实函数相同）。
但注意：复三角函数不再有界（$|\sin z|$ 可以任意大，因为 $\sin(iy)=i\sinh y$）。∎
- **点评**：复三角函数是整函数——这是复分析中重要的整函数类。与实三角函数不同，复三角函数无界（Liouville 定理的推论：非常数整函数必无界）。

### L3 实变函数基础

**【D7-1-035】** 证明：$\sin x$ 和 $\cos x$ 是 $\mathbb{R}$ 上的可测函数（连续函数）。

- **难度**：★
- **解答**：$\sin x$ 和 $\cos x$ 在 $\mathbb{R}$ 上连续（可以用单位圆定义或幂级数证明）。
连续函数是可测函数（开集的原像是开集，开集可测）。
故 $\sin x,\cos x$ 可测。∎
- **点评**：连续函数必可测——这是可测函数的基本例子。三角函数是最基本的连续周期函数。

**【D7-1-036】** 证明：$\sin x\in L^p[0,2\pi]$ 对所有 $1\leq p\leq\infty$ 成立，并计算 $\|\sin x\|_p$。

- **难度**：★★
- **解答**：$|\sin x|\leq1$，故 $\sin x\in L^\infty[0,2\pi]$，$\|\sin x\|_\infty=1$。
对 $1\leq p<\infty$，$\int_0^{2\pi}|\sin x|^p dx\leq2\pi<\infty$，故 $\sin x\in L^p[0,2\pi]$。
$\|\sin x\|_p=(\int_0^{2\pi}|\sin x|^p dx)^{1/p}$。
特例：$p=2$ 时，$\int_0^{2\pi}\sin^2 x dx=\pi$，故 $\|\sin x\|_2=\sqrt{\pi}$。∎
- **点评**：有界函数在有限测度空间上属于所有 $L^p$。三角函数是 $L^p$ 空间中的基本函数，其正交性是 Fourier 分析的基础。

**【D7-1-037】** 证明三角函数系的正交性：$\int_0^{2\pi}\sin(mx)\sin(nx)dx=0$（$m\neq n$），$\int_0^{2\pi}\cos(mx)\cos(nx)dx=0$（$m\neq n$），$\int_0^{2\pi}\sin(mx)\cos(nx)dx=0$。

- **难度**：★★
- **解答**：用积化和差公式：
$\sin(mx)\sin(nx)=\frac{1}{2}[\cos((m-n)x)-\cos((m+n)x)]$。
$m\neq n$ 时，$\int_0^{2\pi}\cos(kx)dx=0$（$k\neq0$），故积分为 0。
同理 $\cos(mx)\cos(nx)=\frac{1}{2}[\cos((m-n)x)+\cos((m+n)x)]$，$m\neq n$ 时积分为 0。
$\sin(mx)\cos(nx)=\frac{1}{2}[\sin((m+n)x)+\sin((m-n)x)]$，$\int_0^{2\pi}\sin(kx)dx=0$ 对所有整数 $k$，故积分为 0。
模长：$\int_0^{2\pi}\sin^2(nx)dx=\int_0^{2\pi}\cos^2(nx)dx=\pi$（$n\geq1$）。∎
- **点评**：三角函数系的正交性是 Fourier 分析的基础——它保证了 Fourier 系数可以通过内积直接计算，且 Bessel 不等式和 Parseval 等式成立。

## 跨领域综合题

### 经典名题

**【D7-1-CROSS-018】**（D7 × D5 级数 × D8 解析）**从 Archimedes 到 Machin：追踪 π 的计算历史，说明 π 如何从"几何比值"演变为"级数求和"，并推导 Machin 公式 π/4 = 4 arctan(1/5) - arctan(1/239)。**

- **难度**：★★★
- **对应知识点**：π的计算史、arctan级数、Machin公式、几何到级数
- **解答**：
  **π的计算史**：
  - Archimedes（约250 BC）：内接/外切正 96 边形，得 3+10/71 &lt; π &lt; 3+1/7 ≈ 3.14
  - 刘徽（263 AD）：割圆术，正 3072 边形得 π ≈ 3.1416
  - 祖冲之（480 AD）：3.1415926 &lt; π &lt; 3.1415927，领先千年
  - 级数方法（17世纪后）：利用 arctan x = x - x³/3 + x⁵/5 - ... 计算 π
  - Machin（1706）：提出快速收敛公式

  **arctan 的级数**：
  arctan x = ∑_{n=0}^∞ (-1)^n x^{2n+1}/(2n+1)，|x| ≤ 1。
  令 x = 1：π/4 = 1 - 1/3 + 1/5 - 1/7 + ...（Leibniz 公式，但收敛极慢）。
  令 x = 1/√3：π/6 = 1/√3 - 1/(3√3³) + ...（快一些）。
  关键是找到 x 小的组合，让级数快速收敛。

  **Machin 公式推导**：
  令 α = arctan(1/5)，则 tan α = 1/5。
  tan(2α) = 2tanα/(1-tan²α) = (2/5)/(1-1/25) = (2/5)/(24/25) = 5/12。
  tan(4α) = 2tan(2α)/(1-tan²(2α)) = (10/12)/(1-25/144) = (5/6)/(119/144) = 120/119。
  所以 4α 略大于 π/4（因为 tan(π/4)=1，120/119 > 1）。
  令 β = 4α - π/4，则：
  tan β = tan(4α - π/4) = (tan4α - 1)/(1 + tan4α) = (120/119 - 1)/(1 + 120/119) = (1/119)/(239/119) = 1/239。
  所以 β = arctan(1/239)。
  即 4 arctan(1/5) - π/4 = arctan(1/239)
  ⟹ **π/4 = 4 arctan(1/5) - arctan(1/239)**。∎

  **为什么 Machin 公式快**：
  arctan(1/5) 的级数中 (1/5)^n 快速衰减，arctan(1/239) 衰减更快。
  只需几项就能得到高精度的 π——这是前计算机时代计算 π 的主要方法。

  **几何理解**：π 的计算从"几何逼近"（多边形）演变为"级数求和"（arctan 级数）——这是分析学战胜几何学的胜利。Machin 公式的本质是"用两个小角度的正切组合出 π/4"，让级数快速收敛；4α≈π/4，差一个极小的 β=arctan(1/239)，这是数值计算的精妙设计。
- **一句话点评**：π计算：Archimedes多边形→刘徽割圆→祖冲之7位→级数法。arctan x=∑(-1)^n x^{2n+1}/(2n+1)。Machin：α=arctan(1/5)，tan4α=120/119，β=4α-π/4，tanβ=(120/119-1)/(1+120/119)=1/239⟹π/4=4arctan(1/5)-arctan(1/239)。(1/5)^n和(1/239)^n快速衰减⟹收敛快。

**【D7-1-CROSS-019】**（D7 × D1 极限 × D3 微分）**从弧度制的本质解释为什么 lim_{x→0} sin x / x = 1 是整个微积分的基石：它如何连接了三角函数的导数、Euler 公式、和角公式，以及如果没有弧度制微积分会变成什么样。**

- **难度**：★★★
- **对应知识点**：重要极限的基石地位、导数、Euler公式、和角公式、弧度制本质
- **解答**：
  **lim sin x/x = 1 的推导依赖弧度制**：
  如 D7-1-005 所证，这个极限通过面积比较（内接三角形 &lt; 扇形 &lt; 外切三角形）得到，关键是扇形面积 = (1/2)x（单位圆、弧度制）。
  在度制下，极限 = π/180 ≠ 1。

  **它如何连接各分支**：

  **1. 三角函数的导数**：
  (sin x)' = lim_{h→0} [sin(x+h)-sin x]/h
  = lim [sin x cos h + cos x sin h - sin x]/h
  = sin x · lim(cos h - 1)/h + cos x · lim sin h/h
  = sin x · 0 + cos x · 1 = cos x。
  这里 lim sin h/h = 1 是关键！没有它，(sin x)' = (π/180)cos x（度制）。

  **2. Taylor 展开与 Euler 公式**：
  由导数公式可得 sin x = x - x³/3! + x⁵/5! - ...，cos x = 1 - x²/2! + x⁴/4! - ...
  代入 e^{ix} 的 Taylor 展开即得 Euler 公式 e^{ix} = cos x + i sin x。
  弧度制让这些展开最简洁。

  **3. 和角公式**：
  和角公式 sin(α+β) = sin α cos β + cos α sin β 可以纯几何证明，但在微积分框架下，它是 Euler 公式 e^{i(α+β)} = e^{iα}e^{iβ} 的直接推论。
  而 Euler 公式依赖弧度制下的 Taylor 展开，最终依赖 lim sin x/x = 1。

  **如果没有弧度制**：
  所有三角公式都带 π/180 的因子：
  - (sin(x°))' = (π/180)cos(x°)
  - sin(x°) = (πx/180) - (πx/180)³/3! + ...
  - e^{ix°} = cos(x°) + i sin(x°)（但指数参数需要转换）
  微积分会变得繁琐且不优雅。弧度制的"自然性"不是审美偏好，而是数学结构的内在要求——微积分研究变化率，而变化率的自然度量是弧长/半径。

  **几何理解**：lim sin x/x = 1 说的是"在很小的角度下，正弦值 ≈ 角度值"——这是因为单位圆上小角度对应的弧长 ≈ 弦长（sin x 是弦长的一半），而弧长 = 角度（弧度制）。这个"局部线性近似"是微积分的核心思想，弧度制让它最自然。
- **一句话点评**：lim sinx/x=1（弧度制）是微积分基石：①导数(sinx)'=cosx依赖它；②Taylor展开⟹Euler公式依赖它；③和角公式=Euler公式推论依赖它。度制下所有公式带π/180因子。本质=小角度下sinx≈x（弧长≈弦长），弧度制让弧长=角度⟹局部线性近似最自然。

- **解答**：

  1 turn = 整个圆周 = 360° = 2π 弧度。
  所以 1 turn = 2π rad，1 rad = 1/(2π) turn。
  记角度（turn）为 τ，则 τ = θ/(2π)（θ 为弧度）。

  s = rθ = r · 2πτ = 2πrτ。

  d/dτ sin_turn(τ) = d/dτ sin(2πτ) = 2π cos(2πτ) = 2π cos_turn(τ)。

  - 弧度制：k = 1

  在微分几何中，流形上的"角度"由 Riemann 度量决定。单位圆上的弧长元素 ds = dθ（弧度制），这是度量诱导的自然参数化。

  弧长参数化（弧度制）是唯一让"速度 = 1"的参数化，因此在微积分中最自然。∎
- **一句话点评**：turn制：1turn=2πrad，τ=θ/(2π)。弧长s=2πrτ（带2π）；重要极限lim sin(2πτ)/τ=2π（非1）；导数=2πcos（带2π）；Taylor带(2π)^n。任何系统θ_sys=k·θ_rad，只有k=1（弧度）时所有公式无转换因子。微分几何中弧长参数化ds=dθ是唯一速度=1的参数化⟹最自然。

**【D7-1-CROSS-021】**（D7 × D8 解析 × D5 级数）**从"角是旋转量"到"旋转群 SO(2)"：说明平面旋转构成一个连续 Abel 群，与单位圆 S¹ 同构，也与模为 1 的复数乘法群 U(1) 同构，并讨论弧度制如何成为这个群的自然参数。**

- **难度**：★★★
- **对应知识点**：旋转群SO(2)、单位圆S¹、U(1)、群同构、弧度参数
- **解答**：
  **平面旋转群 SO(2)**：
  所有绕原点的平面旋转构成集合 SO(2) = {[cos θ, -sin θ; sin θ, cos θ] | θ ∈ ℝ}。
  群运算 = 矩阵乘法（旋转的合成）。
  这是一个 Abel 群（交换群），因为旋转的顺序不影响结果（平面旋转可交换）。

  **与单位圆 S¹ 同构**：
  S¹ = {(x,y) ∈ ℝ² | x²+y²=1} = {(cos θ, sin θ)}。
  旋转 θ 对应单位圆上的点 (cos θ, sin θ)。
  旋转合成 R_α ∘ R_β = R_{α+β} 对应点的"角度相加"。
  所以 SO(2) ≅ S¹（作为拓扑群同构）。

  **与 U(1) 同构**：
  U(1) = {z ∈ ℂ | |z|=1} = {e^{iθ}}。
  旋转 θ 对应复数 e^{iθ}。
  旋转合成对应复数乘法 e^{iα} · e^{iβ} = e^{i(α+β)}。
  所以 SO(2) ≅ S¹ ≅ U(1)。

  **弧度制作为自然参数**：
  群同构中，参数 θ 是弧度。为什么？
  - e^{iθ} 中，θ 必须是弧度（Euler 公式只在弧度制下简洁）。
  - 旋转矩阵中，cos θ 和 sin θ 的 Taylor 展开只在弧度制下简洁。
  - 群的指数映射：从李代数 so(2)（= ℝ，生成元是"无穷小旋转"）到群 SO(2) 的映射是 θ ↦ e^{θJ}，其中 J = [0,-1;1,0]，e^{θJ} = [cos θ, -sin θ; sin θ, cos θ]。
  这里的 θ 是弧长参数（弧度），因为指数映射的参数自然是李代数中的元素，而李代数的"长度"对应弧长。

  **李群视角**：
  SO(2) 是一个 1 维紧致连通李群，其李代数 so(2) ≅ ℝ。
  指数映射 exp: so(2) → SO(2) 是满射，核 = 2πℤ。
  所以 SO(2) ≅ ℝ/(2πℤ)——实数模 2π，这正是"角度相差 2π 等价"的代数表达。
  2π 来自弧度制——整个圆周的弧长 = 2πr，单位圆上 = 2π。∎

  **几何理解**：平面旋转 = 单位圆上的点 = 模 1 的复数，三者是同一个数学结构的三种表现。弧度制是这个结构的"自然坐标"——它让指数映射 e^{iθ} 最简洁，让群运算变成角度加法，让李代数参数等于弧长。
- **一句话点评**：SO(2)={旋转矩阵}≅S¹={单位圆点(cosθ,sinθ)}≅U(1)={e^{iθ}}。旋转合成=角度相加=复数乘法。弧度制自然：e^{iθ}需弧度，指数映射exp:so(2)→SO(2),θ↦e^{θJ}中θ=弧长参数。SO(2)≅ℝ/(2πℤ)，2π=单位圆周长=弧度制全周。

**【D7-1-CROSS-022】**（D7 × D4 积分 × D3 微分）**用变量替换证明高斯积分 ∫_{-∞}^∞ e^{-x²} dx = √π，并说明 π 如何从"圆的常数"出现在"指数函数的积分"中——这如何体现了极坐标（角度）与直角坐标的转换。**

- **难度**：★★★
- **对应知识点**：Gaussian积分、极坐标、π的出现、角度转换
- **解答**：
  **Gaussian 积分计算**：
  令 I = ∫_{-∞}^∞ e^{-x²} dx。
  I² = (∫e^{-x²}dx)(∫e^{-y²}dy) = ∬_{ℝ²} e^{-(x²+y²)} dx dy。
  转换为极坐标：x = r cos θ, y = r sin θ，dx dy = r dr dθ，x²+y² = r²。
  I² = ∫_0^{2π} ∫_0^∞ e^{-r²} r dr dθ
  = (∫_0^{2π} dθ)(∫_0^∞ e^{-r²} r dr)
  = 2π · [-(1/2)e^{-r²}]_0^∞
  = 2π · (1/2) = π。
  所以 I = √π。∎

  **π 如何出现**：
  π 来自角度积分 ∫_0^{2π} dθ = 2π——整个平面的角度范围是 0 到 2π（弧度制下整个圆周）。
  在直角坐标中，e^{-x²} 的积分似乎与圆无关，但转换为极坐标后，角度部分的积分自然给出 2π。
  这是因为 e^{-(x²+y²)} = e^{-r²} 是径向对称的（只依赖 r，不依赖 θ），所以角度积分可以分离出来，给出因子 2π。

  **极坐标转换的本质**：
  极坐标 x = r cos θ, y = r sin θ 中，θ 是角度（弧度）。
  面积元素 dx dy = r dr dθ 中的 r 来自 Jacobian 行列式，dθ 来自角度。
  整个平面 = {0 ≤ r &lt; ∞, 0 ≤ θ &lt; 2π}，角度范围 2π 是弧度制下的全圆周。
  如果用度制，θ 范围 0° 到 360°，dθ° = (π/180)dθ_rad，积分会多一个 π/180 因子，最终仍得到 √π（因为 360 × π/180 = 2π），但过程不简洁。

  **更深的联系**：
  Gaussian 函数 e^{-x²} 是 Fourier 变换的不动点（差一个常数因子），而 Fourier 变换中自然出现 2π（来自角度积分）。
  π 在 Gaussian 积分中的出现，本质上是"圆的对称性"在"指数衰减函数"中的体现——径向对称函数的积分必然包含全角度 2π。

  **几何理解**：e^{-x²} 在一维看似与圆无关，但平方后变成二维的 e^{-(x²+y²)}=e^{-r²}，这是一个"钟形山"，等高线是圆。极坐标把这座山分解为"径向高度"e^{-r²}和"角度环绕"2π，积分=径向积分×角度积分= (1/2) × 2π = π。π 来自"绕一圈"的角度——圆的对称性。
- **一句话点评**：I=∫e^{-x²}dx，I²=∬e^{-(x²+y²)}dxdy，极坐标x=rcosθ,y=rsinθ,dxdy=rdrdθ⟹I²=∫₀^{2π}dθ∫₀^∞e^{-r²}rdr=2π·(1/2)=π⟹I=√π。π来自角度积分∫₀^{2π}dθ=2π（全圆周弧度）。e^{-r²}径向对称⟹角度分离⟹2π因子。极坐标中θ用弧度，全周=2π最简洁。

**【D7-1-CROSS-023】**（D7 × D2 连续 × D6 完备性）**讨论"角的加法"的连续性：映射 (α, β) ↦ α + β（模 2π）在圆周上是连续的，但"取主值"的映射（如将角限制在 (-π, π]）在 π 处不连续。用这个例子说明拓扑学中"圆周不能连续参数化为区间"的本质。**

- **难度**：★★★
- **对应知识点**：角的加法连续性、主值不连续、圆周拓扑、连续参数化
- **解答**：
  **角的加法连续**：
  角的加法在圆周 S¹ = ℝ/(2πℤ) 上是连续的。
  因为 S¹ 是一个拓扑群，群运算（加法）连续。
  几何上，"旋转 α 再旋转 β"的结果连续依赖于 α 和 β。

  **主值映射不连续**：
  定义主值映射 Arg: S¹ → (-π, π]，将角映射到 (-π, π] 范围内的代表。
  这个映射在 -π（即 π）处不连续：
  - 从上方接近 π（如 π - ε），主值 → π
  - 从下方接近 -π（如 -π + ε），主值 → -π
  但 π 和 -π 在圆周上是同一个点！所以主值映射在该点"跳跃"了 2π，不连续。

  **圆周不能连续参数化为区间**：
  这是拓扑学的一个基本事实：不存在连续双射 f: S¹ → [0, 1)（或任何区间）。
  证明：如果 f 是连续双射，S¹ 紧致 ⟹ f(S¹) 紧致 ⟹ [0,1) 不紧致（开端）矛盾。
  或者：S¹ 去掉一个点后连通，区间去掉一个点后不连通（分成两段），拓扑性质不同。
  主值映射就是试图将圆周参数化为 (-π, π]，它在"接缝"处必然不连续。

  **与弧度制的关系**：
  弧度制将角表示为实数 θ ∈ ℝ，但角的真正空间是 ℝ/(2πℤ)（模 2π 的等价类）。
  从 ℝ 到 ℝ/(2πℤ) 的商映射是连续的，但从 ℝ/(2πℤ) 到 ℝ 的任何"截面"（选代表元）都不可能全局连续。
  这就是为什么"主值"在 π 处不连续——这不是弧度制的缺陷，而是圆周拓扑的本质。

  **实际影响**：
  - 复数的辐角 Arg(z) 是多值函数，主值在负实轴上不连续（分支切割）。
  - 复分析中，log z = ln|z| + i Arg z 也是多值函数，需要分支切割。
  - 这些"不连续"都源于圆周不能连续参数化为区间的拓扑事实。∎

  **几何理解**：角的真正空间是圆周（闭合的环），而不是直线（开放的区间）。把圆周"剪开"变成区间，必然在"剪口"处产生不连续——这就像把一个圆环剪断成线段，断点处两端虽然在环上相邻，但在线段上相距 2π。弧度制用实数表示角是方便的计算工具，但要记住角的真正拓扑是圆周。
- **一句话点评**：角加法在S¹=ℝ/(2πℤ)上连续（拓扑群）。主值映射Arg:S¹→(-π,π]在π处不连续（π-ε→π，-π+ε→-π，跳跃2π）。本质=圆周不能连续双射到区间（S¹紧致⟹像紧致，[0,1)不紧致；或去点后S¹连通vs区间不连通）。弧度制用ℝ表示角是计算工具，真正空间是ℝ/(2πℤ)，任何截面（主值）必在接缝处不连续。复分析中Arg和log的多值性/分支切割源于此。

**【D7-1-CROSS-024】**（D7 × D5 级数 × D1 极限）**用单位圆上的面积比较证明 lim_{x→0} (1 - cos x)/x² = 1/2，并说明这如何是 lim sin x/x = 1 的推论，以及在度制下这个极限会变成什么。**

- **难度**：★★
- **对应知识点**：重要极限推论、1-cosx、半角公式、度制转换
- **解答**：
  **方法一：代数推导**：
  1 - cos x = 2 sin²(x/2)。
  (1 - cos x)/x² = 2 sin²(x/2)/x² = (1/2) · [sin(x/2)/(x/2)]²。
  当 x→0 时，x/2→0，所以 sin(x/2)/(x/2)→1。
  因此 lim (1-cos x)/x² = (1/2) · 1² = 1/2。∎

  **方法二：面积比较（几何）**：
  在单位圆上，考虑角 x。
  1 - cos x 是点 (cos x, sin x) 到 y 轴的水平距离（1 - cos x）。
  当 x 很小时，这个距离 ≈ x²/2（抛物线近似）。
  更精确地，由 cos x 的 Taylor 展开 cos x = 1 - x²/2! + x⁴/4! - ...，得 1 - cos x = x²/2 - x⁴/24 + ...，所以 (1-cos x)/x² → 1/2。

  **是 lim sin x/x = 1 的推论**：
  上述代数推导只用了 lim sin t/t = 1（令 t = x/2），所以它是第一个重要极限的直接推论。
  这两个极限是微积分中三角函数极限的基础：
  - lim sin x/x = 1（一阶）
  - lim (1-cos x)/x² = 1/2（二阶）
  它们分别对应 sin x 和 cos x 的 Taylor 展开的首项。

  **度制下**：
  如果 x 用度，sin(x°) = sin(πx/180)（弧度）。
  1 - cos(x°) = 1 - cos(πx/180) ≈ (πx/180)²/2。
  所以 lim_{x→0} (1 - cos(x°))/x² = (π/180)²/2 = π²/(2·180²) ≈ 0.000152。
  带有 (π/180)² 因子，远非 1/2。

  **几何理解**：1 - cos x 是单位圆上点到 y 轴的"水平差距"，当 x 很小时，这个差距是 x 的二阶小量（~x²/2）——因为圆在 (1,0) 附近近似为抛物线 1 - x²/2（曲率为 1）。这个 1/2 来自圆的曲率，而曲率的自然度量是弧度制。
- **一句话点评**：1-cosx=2sin²(x/2)⟹(1-cosx)/x²=(1/2)[sin(x/2)/(x/2)]²→1/2。是lim sinx/x=1的推论。对应cosx=1-x²/2+...的首项。度制下=π²/(2·180²)。几何=单位圆在(1,0)附近近似抛物线1-x²/2，曲率=1（弧度制）。

**【D7-1-CROSS-025】**（D7 × D8 解析 × D4 积分）**说明辐角原理（Argument Principle）如何将"绕原点的圈数"（角度变化）与"复变函数的零点和极点"联系起来，并讨论弧度制在其中的角色。**

- **难度**：★★★
- **对应知识点**：辐角原理、环绕数、零点极点、留数定理、弧度制
- **解答**：
  **辐角原理**：
  设 f 在简单闭曲线 C 内部亚纯，在 C 上无零点和极点，则：
  (1/2πi) ∮_C f'(z)/f(z) dz = N - P，
  其中 N 是零点总数（计重数），P 是极点总数（计重数）。

  **与角度变化的关系**：
  f'(z)/f(z) = d/dz [ln f(z)] = d/dz [ln|f(z)| + i arg f(z)]。
  沿 C 积分一周：
  ∮ f'/f dz = ∮ d(ln|f|) + i ∮ d(arg f) = 0 + i · Δ_C arg f，
  其中 Δ_C arg f 是 f(z) 沿 C 绕一周时辐角的总变化量（弧度）。
  所以 (1/2πi) ∮ f'/f dz = Δ_C arg f / (2π) = 环绕数（winding number）。
  辐角原理说：环绕数 = N - P。

  **弧度制的角色**：
  辐角的变化量 Δ_C arg f 用弧度度量。
  绕一圈 = 2π 弧度，所以环绕数 = Δarg / (2π)。
  如果用度制，绕一圈 = 360°，环绕数 = Δarg(度) / 360，结果相同，但公式中会出现 360 而不是 2π。
  弧度制让公式 (1/2πi)∮f'/f = N-P 最简洁，因为 2π 是单位圆周长（弧度制下），与留数定理中的 2πi 一致。

  **几何理解**：
  辐角原理的几何本质是：当 z 沿 C 绕一圈时，f(z) 在复平面上绕原点 N-P 圈。
  每绕一圈，辐角增加 2π（弧度）。
  零点"吸引"曲线绕原点（+1），极点"排斥"（-1）。
  这是拓扑学中"度"（degree）的概念——连续映射的环绕数等于正则值的原像数（带符号）。

  **与留数定理的关系**：
  f'/f 在零点 z=a（m阶）处有留数 m，在极点 z=b（n阶）处有留数 -n。
  由留数定理，∮f'/f = 2πi(∑m - ∑n) = 2πi(N-P)。
  弧度制下的 2πi 是留数定理的标准形式，与辐角原理完美衔接。∎
- **一句话点评**：辐角原理：(1/2πi)∮f'/f=N-P。f'/f=d(ln|f|+iargf)，积分一周=iΔargf⟹环绕数=Δargf/(2π)=N-P。弧度制关键：绕一圈=2π弧度，与留数定理2πi一致；度制下用360不简洁。几何=z绕C一圈时f(z)绕原点N-P圈，零点+1极点-1。

**【D7-1-CROSS-026】**（D7 × D3 微分 × D6 完备性）**从曲率的角度理解弧度制：平面曲线的曲率 κ = dφ/ds，其中 φ 是切线角（弧度），s 是弧长。说明为什么曲率公式中角度必须用弧度，并计算单位圆的曲率。**

- **难度**：★★★
- **对应知识点**：曲率、切线角、弧长参数、弧度制、单位圆曲率
- **解答**：
  **曲率的定义**：
  平面曲线的曲率 κ = |dφ/ds|，其中 φ 是切线与 x 轴的夹角（切线角），s 是弧长。
  曲率度量曲线"弯曲的程度"——单位弧长内切线方向变化了多少。

  **为什么用弧度**：
  dφ/ds 中，φ 是角度，s 是长度。
  如果 φ 用弧度（无量纲，弧长/半径），则 κ 的量纲是 1/长度，这是曲率的自然量纲。
  如果 φ 用度，则 dφ(度)/ds 的量纲是 度/长度，需要转换因子 π/180 才能得到标准曲率。
  更本质地，曲率的几何定义是"单位弧长内切线旋转的角度"，而角度的自然度量是弧度（因为切线旋转可以看作单位圆上的运动，弧长=角度）。

  **单位圆的曲率**：
  单位圆参数化：r(s) = (cos s, sin s)（s 是弧长，因为 |r'(s)|=1）。
  切线向量 r'(s) = (-sin s, cos s)，切线角 φ = s + π/2（因为切线方向比半径方向超前 π/2）。
  dφ/ds = 1。
  所以单位圆的曲率 κ = 1（常数）。
  半径为 R 的圆曲率 κ = 1/R。∎

  **曲率与圆的关系**：
  曲率的倒数 1/κ 称为曲率半径——曲线在某点的曲率半径 = 密切圆的半径。
  单位圆的曲率半径 = 1（就是它自己的半径）。
  直线的曲率 = 0（曲率半径 = ∞，不弯曲）。

  **更深刻的联系**：
  在弧长参数化下，曲线的 Frenet 标架满足 T'(s) = κ N(s)，其中 T 是单位切向量，N 是法向量。
  T(s) = (cos φ(s), sin φ(s))，T'(s) = φ'(s)(-sin φ, cos φ) = κ N。
  所以 κ = φ'(s) = dφ/ds——这里 φ 必须用弧度，因为 T 的分量是 cos φ 和 sin φ，它们的导数公式只在弧度制下简洁。

  **几何理解**：曲率 = "走单位弧长时，切线转了多少角度"。单位圆上走 1 单位弧长，切线恰好转 1 弧度（因为弧长=角度），所以曲率=1。弧度制让"弧长"和"角度"在单位圆上统一，曲率公式最自然。
- **一句话点评**：曲率κ=|dφ/ds|，φ=切线角（弧度），s=弧长。弧度制使κ量纲=1/长度，且T=(cosφ,sinφ)的导数公式简洁。单位圆r(s)=(coss,sins)，φ=s+π/2⟹κ=dφ/ds=1。半径R的圆κ=1/R。曲率半径=1/κ=密切圆半径。本质=走单位弧长时切线转多少角度，单位圆上弧长=角度⟹κ=1。

**【D7-1-CROSS-027】**（D7 × D5 级数 × D7 三角学）**推导 Basel 问题 ∑1/n² = π²/6 的一种几何方法：利用 sin x 的无穷乘积 sin x = x ∏(1 - x²/n²π²)，比较 x³ 系数得到结果。说明 π 如何从"圆的常数"出现在"级数求和"中。**

- **难度**：★★★
- **对应知识点**：Basel问题、sin的无穷乘积、系数比较、π与级数
- **解答**：
  **sin x 的无穷乘积（Euler）**：
  sin x 的零点在 x = nπ（n ∈ ℤ），所以：
  sin x = x ∏_{n=1}^∞ (1 - x²/(n²π²))。
  （这是 Weierstrass 分解的特例，sin x 是整函数，零点 ±nπ。）

  **比较 x³ 系数**：
  左边 sin x 的 Taylor 展开：
  sin x = x - x³/6 + x⁵/120 - ...
  x³ 系数 = -1/6。

  右边展开：
  x ∏(1 - x²/(n²π²)) = x · [1 - (x²/π²)∑1/n² + x⁴(...) - ...]
  = x - (x³/π²)∑1/n² + ...
  x³ 系数 = -(1/π²)∑_{n=1}^∞ 1/n²。

  比较两边 x³ 系数：
  -1/6 = -(1/π²)∑1/n²
  ⟹ ∑1/n² = π²/6。∎

  **π 如何出现在级数中**：
  π 来自 sin x 的零点位置 x = nπ——零点是 π 的整数倍，因为 sin x 的周期是 2π（弧度制下）。
  如果用度制，sin(x°) 的零点在 x = 180n（度），无穷乘积变为 sin(x°) = (πx/180)∏(1 - x²/(180²n²))，比较系数后仍得到 ∑1/n² = π²/6，但过程中 π 以转换因子的形式出现，不自然。
  弧度制下，sin x 的零点自然是 nπ，π 直接出现在乘积中，系数比较最简洁。

  **更深刻的意义**：
  Basel 问题（1735年，Euler）是数学史上的著名结果——它将"自然数倒数平方和"与"圆的常数 π"联系起来。
  这个联系的桥梁是 sin x 的无穷乘积，而 sin x 的零点分布由 π 决定（周期性）。
  这是分析学（级数）与几何学（圆）深刻统一的典范。

  **几何理解**：sin x 的零点在 ±π, ±2π, ±3π,...——这些零点像"栅栏"一样排列在实轴上，间距 π。无穷乘积把 sin x 分解为"零点因子"的乘积，每个因子 (1 - x²/(nπ)²) 对应一对零点。展开后 x³ 系数涉及所有零点的倒数平方和 ∑1/(nπ)²，与 Taylor 展开比较即得 ∑1/n² = π²/6。π 是零点间距，也是圆的常数——级数与圆通过零点分布联系起来。
- **一句话点评**：Euler乘积sinx=x∏(1-x²/(n²π²))。左边sinx=x-x³/6+...，x³系数=-1/6。右边=x[1-(x²/π²)∑1/n²+...]，x³系数=-(1/π²)∑1/n²。比较得∑1/n²=π²/6。π来自sin零点x=nπ（周期2π弧度）。度制下零点x=180n，π以转换因子出现不自然。Basel问题=级数与圆通过零点分布深刻统一。

## 本模块易错点总结

1. **弧度是无量纲的**：θ = s/r 是纯数，不是"单位"。1 弧度 = 弧长等于半径的角。
2. **(sin x)' = cos x 只在弧度制下成立**：度制下带 π/180 因子。这是因为导数证明依赖 lim sin x/x = 1，而这个极限只在弧度制下等于 1。
3. **lim sin x/x = 1 依赖扇形面积公式**：扇形面积 = (1/2)r²θ 只在弧度制下成立，度制下是 πr²θ/360。
4. **π 的几何本质是周长/直径**：不是"3.14"这个数，而是圆的几何定义的常数。它的无理性和超越性是数论性质，定义是几何的。
5. **角可以取任意实数值**：有向角（旋转量）可以是正的、负的、大于 2π 的。终边相同的角相差 2π 的整数倍。
6. **单位圆上点 = (cos θ, sin θ)**：这是三角函数的深刻定义，比直角三角形边长比更一般。勾股恒等式 cos²+sin²=1 是单位圆方程的直接推论。
7. **立体角 Ω = A/r²**：是平面角 θ = s/r 在三维的推广，整个球面 = 4π sr，与整个圆周 = 2π 弧度平行。
8. **主值映射在 π 处不连续**：这不是弧度制的缺陷，而是圆周拓扑的本质——圆周不能连续参数化为区间。
9. **Euler 公式 e^{iθ} = cos θ + i sin θ 只在弧度制下最简洁**：因为 cos/sin 的 Taylor 展开只在弧度制下没有转换因子。
10. **曲率 κ = dφ/ds 中 φ 必须用弧度**：因为切向量 T = (cos φ, sin φ) 的导数公式只在弧度制下简洁，单位圆曲率 = 1。
