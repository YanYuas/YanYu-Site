## L0 初等直觉层（★ 基础）

**【D7-3-001】** 用和角公式计算 sin(75°) 和 cos(75°)，并在单位圆上画出 75° = 45° + 30° 的几何意义。

- **难度**：★
- **对应知识点**：和角公式、特殊角、单位圆
- **解答**：
  sin(75°) = sin(45°+30°) = sin45°cos30° + cos45°sin30°
  = (√2/2)(√3/2) + (√2/2)(1/2) = √6/4 + √2/4 = (√6+√2)/4。

  cos(75°) = cos(45°+30°) = cos45°cos30° - sin45°sin30°
  = (√2/2)(√3/2) - (√2/2)(1/2) = √6/4 - √2/4 = (√6-√2)/4。∎

  **几何意义**：在单位圆上，先旋转 45° 到达 (√2/2, √2/2)，再旋转 30° 到达 75° 的位置。和角公式说的是"两次旋转后的坐标"可以用"每次旋转的坐标"组合表示。
- **一句话点评**：sin75°=(√6+√2)/4，cos75°=(√6-√2)/4。几何=先转45°再转30°，和角公式=两次旋转后坐标的组合。

**【D7-3-002】** 用倍角公式计算 sin(120°) 和 cos(120°)，验证与直接用诱导公式的结果一致。

- **难度**：★
- **对应知识点**：倍角公式、诱导公式
- **解答**：
  120° = 2 × 60°。
  sin(120°) = 2sin60°cos60° = 2 × (√3/2) × (1/2) = √3/2。
  cos(120°) = cos²60° - sin²60° = 1/4 - 3/4 = -1/2。
  （也 = 2cos²60°-1 = 2×1/4-1 = -1/2，或 1-2sin²60° = 1-2×3/4 = -1/2）

  **诱导公式验证**：
  sin(120°) = sin(180°-60°) = sin60° = √3/2 ✓
  cos(120°) = cos(180°-60°) = -cos60° = -1/2 ✓∎
- **一句话点评**：sin120°=2sin60°cos60°=√3/2，cos120°=cos²60°-sin²60°=-1/2。倍角公式=和角公式在β=α时的特例。

**【D7-3-003】** 用和差化积将 sin(5x) + sin(3x) 化为乘积形式，并从几何上解释为什么两个正弦波的和等于一个振幅调制的正弦波。

- **难度**：★
- **对应知识点**：和差化积、拍频、振幅调制
- **解答**：
  sin α + sin β = 2 sin((α+β)/2) cos((α-β)/2)。
  令 α=5x, β=3x：
  sin(5x) + sin(3x) = 2 sin(4x) cos(x)。∎

  **几何解释**：
  sin(5x) 和 sin(3x) 是两个不同频率的简谐振动（单位圆上以角速度 5 和 3 旋转的点的 y 投影）。
  它们的和 = 2 sin(4x) cos(x)：
  - sin(4x) 是平均频率（载波），角速度 4
  - cos(x) 是半差频率（包络），角速度 1
  - 振幅 2cos(x) 随时间缓慢变化（调制）
  这就是"拍"现象——两个频率接近的波叠加时，振幅周期性变化（拍频 = 频率差）。
- **一句话点评**：sin5x+sin3x=2sin4x cosx。几何=两个旋转(角速度5和3)的y投影之和=平均频率4的载波×半差频率1的包络=拍频现象。

**【D7-3-004】** 用万能公式（t = tan(θ/2)）将 sin θ 和 cos θ 表示为 t 的有理函数，并计算当 θ = π/2 时 t 的值和对应的 sin、cos。

- **难度**：★
- **对应知识点**：万能公式、半角正切、有理参数化
- **解答**：
  万能公式：
  sin θ = 2t/(1+t²), cos θ = (1-t²)/(1+t²), 其中 t = tan(θ/2)。

  θ = π/2 时，t = tan(π/4) = 1。
  sin(π/2) = 2×1/(1+1) = 1 ✓
  cos(π/2) = (1-1)/(1+1) = 0 ✓∎

  **几何意义**：t = tan(θ/2) 是从 (-1,0) 到 (cosθ,sinθ) 的直线斜率。万能公式将单位圆上的点用斜率 t 有理参数化——这是球极投影的一维版本。
- **一句话点评**：sinθ=2t/(1+t²),cosθ=(1-t²)/(1+t²),t=tan(θ/2)。θ=π/2时t=1⟹sin=1,cos=0。几何=从(-1,0)出发斜率t的直线与单位圆交点=有理参数化。

## L1 数学分析层

> **引导语**：L1层按"和角公式的多种证明→和差化积与积化和差→积分技巧→深入应用"四条线索推进。从旋转矩阵到向量内积，从和差化积到Fourier正交性，展示三角恒等式背后的几何本质。每道题都强调"为什么这个公式是对的"的几何理解。

### 组A：和角公式的多种证明

**【D7-3-005】** 用旋转矩阵乘法证明和角公式，并说明为什么 R_{α+β} = R_α R_β 是"旋转的合成"的代数表达。

- **难度**：★★
- **对应知识点**：旋转矩阵、和角公式、旋转合成
- **解答**：
  旋转矩阵 R_θ = [[cosθ, -sinθ], [sinθ, cosθ]]。

  R_α R_β = [[cosα,-sinα],[sinα,cosα]] [[cosβ,-sinβ],[sinβ,cosβ]]
  = [[cosαcosβ-sinαsinβ, -cosαsinβ-sinαcosβ],
     [sinαcosβ+cosαsinβ, -sinαsinβ+cosαcosβ]]

  R_{α+β} = [[cos(α+β), -sin(α+β)], [sin(α+β), cos(α+β)]]

  比较元素：
  cos(α+β) = cosαcosβ - sinαsinβ
  sin(α+β) = sinαcosβ + cosαsinβ∎

  **为什么是旋转的合成**：
  R_β 先将点旋转 β，R_α 再将结果旋转 α，总效果 = 旋转 α+β。
  矩阵乘法 R_α R_β 对应变换的复合（先 R_β 后 R_α）。
  因为平面旋转可交换（R_α R_β = R_β R_α），所以顺序不影响结果——这是 SO(2) 是 Abel 群的体现。
- **一句话点评**：R_αR_β矩阵乘法展开后与R_{α+β}比较元素即得和角公式。R_{α+β}=R_αR_β=先转β再转α=旋转合成。平面旋转可交换=SO(2)是Abel群。

**【D7-3-006】** 用向量内积证明余弦差角公式 cos(α-β) = cosαcosβ + sinαsinβ，并从几何上解释内积与投影的关系。

- **难度**：★★
- **对应知识点**：向量内积、差角公式、投影
- **解答**：
  设单位向量 u = (cosα, sinα), v = (cosβ, sinβ)。
  内积 u·v = |u||v|cos(夹角) = cos(α-β)（因为 |u|=|v|=1，夹角=|α-β|）。
  按坐标计算：u·v = cosαcosβ + sinαsinβ。
  所以 cos(α-β) = cosαcosβ + sinαsinβ。∎

  **内积与投影的关系**：
  u·v = |u| × (v 在 u 方向上的投影长度)。
  对于单位向量，u·v = v 在 u 方向上的投影长度。
  所以 cos(α-β) = 向量 v 在向量 u 方向上的投影长度。
  几何上：将 v 投影到 u 的方向上，投影长度就是 cos(α-β)——这是差角公式的投影本质。

  **推广到和角**：
  用 -β 替换 β：cos(α+β) = cosαcos(-β) + sinαsin(-β) = cosαcosβ - sinαsinβ。
- **一句话点评**：单位向量u=(cosα,sinα),v=(cosβ,sinβ)，u·v=cos(α-β)=cosαcosβ+sinαsinβ。内积=v在u方向的投影长度⟹cos(α-β)=投影长度。和角=用-β替换。

**【D7-3-011】** 证明正切的和角公式 tan(α+β) = (tanα+tanβ)/(1-tanαtanβ)，并用它计算 tan(75°)。从射影几何角度说明这是 Möbius 变换。

- **难度**：★★
- **对应知识点**：正切和角公式、Möbius变换、射影几何
- **解答**：
  **证明**：
  tan(α+β) = sin(α+β)/cos(α+β)
  = (sinαcosβ+cosαsinβ)/(cosαcosβ-sinαsinβ)
  分子分母同除以 cosαcosβ：
  = (tanα+tanβ)/(1-tanαtanβ)。∎

  **计算 tan(75°)**：
  tan(75°) = tan(45°+30°) = (tan45°+tan30°)/(1-tan45°tan30°)
  = (1 + 1/√3)/(1 - 1×1/√3) = (√3+1)/(√3-1)
  = (√3+1)²/(3-1) = (3+2√3+1)/2 = 2+√3。∎

  **射影几何角度**：
  令 t = tanθ，固定 β，变换 T_β(t) = tan(θ+β) = (t+tanβ)/(1-ttanβ)。
  这是 Möbius 变换（分式线性变换）t ↦ (at+b)/(ct+d)，其中 a=1,b=tanβ,c=-tanβ,d=1。
  Möbius 变换是射影直线上的射影变换，保持交比。
  角度加法 = 旋转合成 = Möbius 变换复合。
  这揭示了正切函数是"旋转群在射影直线上的表示"。
- **一句话点评**：tan(α+β)=(tanα+tanβ)/(1-tanαtanβ)（分子分母同除cosαcosβ）。tan75°=2+√3。射影几何：t=tanθ⟹旋转β对应T_β(t)=(t+tanβ)/(1-ttanβ)=Möbius变换=射影变换，保持交比。

### 组B：和差化积与积化和差

**【D7-3-007】** 用和差化积的几何方法（平行四边形法则）证明：cosα + cosβ = 2cos((α+β)/2)cos((α-β)/2)，并画出两个单位向量构成的平行四边形。

- **难度**：★★
- **对应知识点**：和差化积、平行四边形法则、向量加法
- **解答**：
  设单位向量 u = (cosα, sinα), v = (cosβ, sinβ)。
  和向量 u+v = (cosα+cosβ, sinα+sinβ)。

  令 γ = (α+β)/2（平均角），δ = (α-β)/2（半差角）。
  则 α = γ+δ, β = γ-δ。
  u 和 v 关于角 γ 的射线对称。

  平行四边形 OUPV 中（O=原点, U=u, V=v, P=u+v）：
  - 对角线 OP = u+v，方向在角平分线上（角 γ）
  - 对角线长度 |OP| = 2cosδ（因为等腰三角形 OUV 中，底边 UV 的中线 = cosδ，平行四边形对角线 = 2×中线）

  所以 u+v = 2cosδ · (cosγ, sinγ) = (2cosδ cosγ, 2cosδ sinγ)。
  比较 x 坐标：cosα+cosβ = 2cos((α+β)/2)cos((α-β)/2)。
  比较 y 坐标：sinα+sinβ = 2sin((α+β)/2)cos((α-β)/2)。∎

  **几何图像**：
  两个长度为 1 的向量，夹角为 2δ，它们的和向量：
  - 方向：角平分线（γ）
  - 长度：2cosδ（当 δ&lt;π/2 时为正）
  这就是平行四边形法则——对角线在角平分线上，长度由夹角决定。
- **一句话点评**：u=(cosα,sinα),v=(cosβ,sinβ)，u+v方向在角平分线γ=(α+β)/2上，长度=2cosδ,δ=(α-β)/2。⟹u+v=2cosδ(cosγ,sinγ)⟹和差化积。平行四边形对角线=角平分线方向。

**【D7-3-008】** 用积化和差计算 ∫ sin(3x)cos(2x) dx，并说明积化和差如何将"乘积的积分"转化为"和的积分"。

- **难度**：★★
- **对应知识点**：积化和差、积分、三角函数积分
- **解答**：
  积化和差：sinαcosβ = [sin(α+β) + sin(α-β)]/2。
  sin(3x)cos(2x) = [sin(5x) + sin(x)]/2。

  ∫ sin(3x)cos(2x) dx = (1/2)∫[sin(5x) + sin(x)] dx
  = (1/2)[-cos(5x)/5 - cos(x)] + C
  = -cos(5x)/10 - cos(x)/2 + C。∎

  **为什么积化和差对积分有用**：
  直接积分 sin(3x)cos(2x) 不容易（乘积形式），但积化和差将其转化为 sin(5x)+sin(x) 的和，每个都是简单的正弦函数积分。
  一般地，∫ sin(mx)cos(nx)dx, ∫ sin(mx)sin(nx)dx, ∫ cos(mx)cos(nx)dx 都可以用积化和差转化为简单积分。
  这是 Fourier 级数中计算正交性积分的基础。
- **一句话点评**：sin3x cos2x=[sin5x+sinx]/2⟹积分=-cos5x/10-cosx/2+C。积化和差将乘积积分转化为和的积分，是Fourier正交性积分的基础。

### 组C：积分技巧

**【D7-3-010】** 用万能替换 t = tan(x/2) 计算 ∫ dx/(1+sin x+cos x)，并说明万能替换如何将三角积分转化为有理函数积分。

- **难度**：★★
- **对应知识点**：万能替换、三角积分、有理函数积分
- **解答**：
  令 t = tan(x/2)，则：
  sin x = 2t/(1+t²), cos x = (1-t²)/(1+t²), dx = 2dt/(1+t²)。

  1 + sin x + cos x = 1 + 2t/(1+t²) + (1-t²)/(1+t²)
  = [(1+t²) + 2t + (1-t²)]/(1+t²)
  = (2 + 2t)/(1+t²) = 2(1+t)/(1+t²)。

  ∫ dx/(1+sinx+cosx) = ∫ [2dt/(1+t²)] / [2(1+t)/(1+t²)]
  = ∫ dt/(1+t) = ln|1+t| + C = ln|1+tan(x/2)| + C。∎

  **万能替换的意义**：
  万能替换将任何由 sin x 和 cos x 组成的有理函数 R(sin x, cos x) 的积分转化为 t 的有理函数积分。
  因为 sin x, cos x, dx 都可以表示为 t 的有理函数，所以 R(sin x, cos x)dx 变成有理函数。
  有理函数的积分有系统的方法（部分分式分解），所以万能替换是三角积分的"万能钥匙"。
  几何上，这是单位圆的有理参数化（球极投影）在积分中的应用。
- **一句话点评**：t=tan(x/2),sin=2t/(1+t²),cos=(1-t²)/(1+t²),dx=2dt/(1+t²)。代入得∫dt/(1+t)=ln|1+tan(x/2)|+C。万能替换=单位圆有理参数化=将三角积分转化为有理函数积分。

### 组D：深入应用

**【D7-3-009】** 推导 Chebyshev 多项式 T_3(x) = 4x³ - 3x，并用它计算 cos(3θ) 在 θ = π/9 时的值（已知 cos(π/3) = 1/2）。

- **难度**：★★
- **对应知识点**：Chebyshev多项式、三倍角公式、方程求解
- **解答**：
  **推导 T_3**：
  cos(3θ) = cos(2θ+θ) = cos2θ cosθ - sin2θ sinθ
  = (2cos²θ-1)cosθ - (2sinθcosθ)sinθ
  = 2cos³θ - cosθ - 2sin²θ cosθ
  = 2cos³θ - cosθ - 2(1-cos²θ)cosθ
  = 2cos³θ - cosθ - 2cosθ + 2cos³θ
  = 4cos³θ - 3cosθ。
  所以 T_3(x) = 4x³ - 3x（令 x=cosθ）。∎

  **计算 cos(π/9)**：
  令 θ = π/9，则 3θ = π/3，cos(3θ) = cos(π/3) = 1/2。
  由 T_3(cosθ) = cos(3θ)：
  4cos³(π/9) - 3cos(π/9) = 1/2。
  令 x = cos(π/9)，则 4x³ - 3x = 1/2，即 8x³ - 6x - 1 = 0。
  这是一个三次方程，cos(π/9) 是它的一个根（约 0.9397）。
  （精确解需要用三次方程求根公式或复数方法，通常保留为方程的根。）∎

  **几何意义**：
  T_n(cosθ) = cos(nθ) 说的是"旋转 n 次 θ 后的横坐标"是"旋转一次 θ 后的横坐标"的 n 次多项式。
  T_3(x)=4x³-3x 是三倍角公式的多项式形式。
  Chebyshev 多项式的零点 cos((2k-1)π/(2n)) 和极值点 cos(kπ/n) 在单位圆上均匀分布——旋转均匀性。
- **一句话点评**：cos3θ=4cos³θ-3cosθ⟹T₃(x)=4x³-3x。θ=π/9时cos(π/3)=1/2⟹8cos³(π/9)-6cos(π/9)-1=0。Chebyshev=倍角公式多项式化=旋转迭代在横坐标上的多项式映射。

**【D7-3-012】** 用积化和差证明 Fourier 基函数的正交性：∫₀^{2π} sin(mx)sin(nx)dx = 0（m≠n），= π（m=n≥1）。说明这如何是"不同频率旋转的平均不相关"。

- **难度**：★★
- **对应知识点**：Fourier正交性、积化和差、不同频率
- **解答**：
  积化和差：sinαsinβ = [cos(α-β) - cos(α+β)]/2。

  **m ≠ n 时**：
  ∫₀^{2π} sin(mx)sin(nx)dx = (1/2)∫₀^{2π}[cos((m-n)x) - cos((m+n)x)]dx
  = (1/2)[sin((m-n)x)/(m-n) - sin((m+n)x)/(m+n)]₀^{2π}
  = 0（因为 sin(k·2π)=0 对整数 k≠0）。

  **m = n ≥ 1 时**：
  ∫₀^{2π} sin²(mx)dx = (1/2)∫₀^{2π}[1 - cos(2mx)]dx
  = (1/2)[x - sin(2mx)/(2m)]₀^{2π} = (1/2)(2π) = π。∎

  **几何理解**：
  sin(mx) 是单位圆上以角速度 m 旋转的点的 y 投影，sin(nx) 是以角速度 n 旋转的点的 y 投影。
  当 m≠n 时，两个旋转的频率不同，它们的乘积在一个周期内"平均为零"——有时同相（乘积正），有时反相（乘积负），正负抵消。
  当 m=n 时，两个旋转同频，乘积始终非负（sin²≥0），积分不为零。
  这就是"不同频率的简谐振动正交"——它们在 Hilbert 空间 L²([0,2π]) 中正交。
- **一句话点评**：sin(mx)sin(nx)=[cos((m-n)x)-cos((m+n)x)]/2。m≠n时两余弦周期积分=0⟹正交；m=n时=∫sin²=π。几何=不同频率旋转的y投影乘积在周期内正负抵消=平均不相关。

## L2 复变函数层（★★★ 研究）

**【D7-3-013】** 用 Euler 公式 e^{iθ} = cosθ + i sinθ 推导所有和角公式、差角公式、倍角公式，并说明这如何体现了"复指数乘法 = 旋转合成"。

- **难度**：★★★
- **对应知识点**：Euler公式、复指数、和角差角倍角、旋转合成
- **解答**：
  **和角公式**：
  e^{i(α+β)} = e^{iα} · e^{iβ}
  左边 = cos(α+β) + i sin(α+β)
  右边 = (cosα+i sinα)(cosβ+i sinβ)
  = (cosαcosβ - sinαsinβ) + i(sinαcosβ + cosαsinβ)
  比较实部虚部即得和角公式。∎

  **差角公式**：
  e^{i(α-β)} = e^{iα} · e^{-iβ} = e^{iα} · \overline{e^{iβ}}
  = (cosα+i sinα)(cosβ-i sinβ)
  = (cosαcosβ+sinαsinβ) + i(sinαcosβ-cosαsinβ)
  比较即得差角公式。∎

  **倍角公式**：
  e^{i2α} = (e^{iα})² = (cosα+i sinα)²
  = (cos²α-sin²α) + i(2sinαcosα)
  比较得 cos2α = cos²α-sin²α, sin2α = 2sinαcosα。∎

  **n 倍角（De Moivre）**：
  e^{inα} = (e^{iα})^n = (cosα+i sinα)^n = cos(nα)+i sin(nα)。
  展开右边的实部和虚部得到 cos(nα) 和 sin(nα) 的多项式表达式。

  **复指数乘法 = 旋转合成**：
  e^{iα} · e^{iβ} = e^{i(α+β)} 说的是"旋转 α 再旋转 β = 旋转 α+β"。
  在复数中，模 1 的复数乘法就是旋转——这比旋转矩阵更简洁。
  所有三角恒等式都可以通过复指数的乘法/除法/幂运算得到，本质上都是旋转的合成/逆/迭代。
- **一句话点评**：e^{i(α+β)}=e^{iα}e^{iβ}，展开比较实部虚部=和角公式；e^{i(α-β)}=e^{iα}e^{-iβ}=差角；e^{i2α}=(e^{iα})²=倍角；e^{inα}=(e^{iα})^n=De Moivre。所有恒等式=复指数运算=旋转的合成/逆/迭代。

**【D7-3-014】** 从复分析的角度理解万能公式：说明 t = tan(θ/2) 如何对应于 Riemann 球上的球极投影，以及为什么这个替换能将三角有理函数积分转化为复平面上的有理函数积分。

- **难度**：★★★
- **对应知识点**：万能公式、球极投影、Riemann球、复积分
- **解答**：
  **万能公式与球极投影**：
  t = tan(θ/2) = sinθ/(1+cosθ)。
  在单位圆上，从点 (-1,0)（对应复数 -1）出发，经过点 (cosθ, sinθ)（对应复数 e^{iθ}）的直线与虚轴（或 y 轴）的交点就是 t。
  这是一维的球极投影：将单位圆（去掉点 -1）投影到实数轴（切线或过原点的直线）。
  投影公式：t = i(1-e^{iθ})/(1+e^{iθ})（相差一个常数因子，取决于投影面）。

  在二维（Riemann 球）中，球极投影将球面（去掉北极）映射到复平面。
  万能公式是这个构造的一维版本：将单位圆（去掉 -1）映射到实数轴。

  **为什么能转化积分**：
  e^{iθ} = (1+it)/(1-it)（由 t = tan(θ/2) 反解）。
  这给出了单位圆的有理参数化——圆上的点用 t 的有理函数表示。
  任何三角有理函数 R(sinθ, cosθ) 都可以写成 R 的有理函数，因为 sinθ 和 cosθ 都是 t 的有理函数。
  dθ = 2dt/(1+t²) 也是 t 的有理函数。
  所以 ∫ R(sinθ,cosθ)dθ = ∫ 有理函数(t) dt——转化为有理函数积分。

  **复分析视角**：
  在复平面上，∮ R(z)dz/z（沿单位圆）可以通过 z = e^{iθ} 转化为 ∫ R(e^{iθ})i dθ。
  万能替换 t = tan(θ/2) 等价于 z = (1+it)/(1-it)，这是单位圆到实数轴的 Möbius 变换。
  留数定理中，单位圆上的积分可以通过变量替换转化为实轴上的积分，反之亦然——万能替换是这个变换的实版本。

  **几何理解**：
  万能替换的本质是"将圆剪开成直线"——从圆上一点出发的中心投影将圆（紧致）映射为直线（非紧致），去掉的那个点对应无穷远点。这个映射是有理的（Möbius 变换），所以能将圆上的超越函数（三角函数）转化为直线上的有理函数。∎
- **一句话点评**：t=tan(θ/2)=从(-1,0)到(cosθ,sinθ)的直线斜率=一维球极投影。e^{iθ}=(1+it)/(1-it)=单位圆有理参数化。三角有理函数积分⟹有理函数积分。复分析中=单位圆到实轴的Möbius变换，留数定理的实版本。

## L3 实变函数层（★★★ 研究）

**【D7-3-015】** 从测度论和 Fourier 分析的角度讨论：为什么 {cos(nx), sin(nx)} 构成 L²([0,2π]) 的正交基？这与单位圆上的旋转群有什么关系？说明三角恒等式（积化和差）在证明正交性中的核心作用。

- **难度**：★★★
- **对应知识点**：Fourier基、正交性、L²空间、旋转群、积化和差
- **解答**：
  **正交性证明**：
  如 D7-3-012 所证，利用积化和差：
  - ∫ sin(mx)sin(nx)dx = 0 (m≠n), = π (m=n≥1)
  - ∫ cos(mx)cos(nx)dx = 0 (m≠n), = π (m=n≥1), = 2π (m=n=0)
  - ∫ sin(mx)cos(nx)dx = 0（所有 m,n）
  所以 {1/√(2π), cos(nx)/√π, sin(nx)/√π} 是标准正交基。

  **与旋转群的关系**：
  cos(nx) 和 sin(nx) 是旋转群 SO(2) 的不可约表示的矩阵元素。
  具体地，旋转 θ 的矩阵 R_θ = [[cosθ, -sinθ], [sinθ, cosθ]]，其矩阵元素就是 cosθ 和 sinθ。
  n 次表示（旋转 nθ）的矩阵元素是 cos(nθ) 和 sin(nθ)。
  Peter-Weyl 定理说：紧致群的不可约表示的矩阵元素构成 L²(G) 的正交基。
  对 G=SO(2)（紧致 Abel 群），不可约表示都是一维的（特征标 e^{inθ}），矩阵元素就是 e^{inθ} = cos(nθ)+i sin(nθ)。
  所以 {cos(nx), sin(nx)} 的正交性是 Peter-Weyl 定理的特例。

  **积化和差的核心作用**：
  正交性的证明完全依赖积化和差：
  sin(mx)sin(nx) = [cos((m-n)x)-cos((m+n)x)]/2
  当 m≠n 时，右边是两个不同频率的余弦，周期积分都为 0。
  当 m=n 时，右边有一个常数项（cos(0)=1），积分不为 0。
  积化和差将"乘积的积分"转化为"和的积分"，而不同频率的三角函数在周期上积分为 0——这是正交性的代数基础。

  **几何理解**：
  不同频率的旋转（角速度 m vs n）在单位圆上"平均不相关"——它们的投影乘积在一个周期内正负抵消。
  这就像两个不同转速的陀螺，你无法用一个的运动来预测另一个的运动——它们在统计意义上正交。
  积化和差是证明这种"不相关"的代数工具。∎
- **一句话点评**：{cos(nx),sin(nx)}正交性由积化和差证明（m≠n时乘积=两不同频率余弦之差，周期积分=0）。Peter-Weyl定理：紧致群SO(2)的不可约表示矩阵元素e^{inθ}=cos(nθ)+isin(nθ)构成L²正交基。几何=不同频率旋转平均不相关。

## 补充基础题（L1 数学分析 / L2 复变函数 / L3 实变函数）

### L1 数学分析基础

**【D7-3-029】** 用几何方法证明和角公式：$\sin(\alpha+\beta)=\sin\alpha\cos\beta+\cos\alpha\sin\beta$。

- **难度**：★★
- **解答**：在单位圆上，角 $\alpha$ 的终边交圆于 $A(\cos\alpha,\sin\alpha)$，角 $\alpha+\beta$ 的终边交圆于 $B(\cos(\alpha+\beta),\sin(\alpha+\beta))$。
将 $OA$ 旋转 $\beta$ 角得到 $OB$。旋转矩阵 $R_\beta=\begin{pmatrix}\cos\beta&-\sin\beta\\\sin\beta&\cos\beta\end{pmatrix}$。
$B=R_\beta A$，故：
$\cos(\alpha+\beta)=\cos\alpha\cos\beta-\sin\alpha\sin\beta$
$\sin(\alpha+\beta)=\sin\alpha\cos\beta+\cos\alpha\sin\beta$
这就是和角公式的几何证明——旋转矩阵的坐标变换。∎
- **点评**：和角公式的本质是平面旋转的坐标表示——旋转矩阵的元素就是三角函数，矩阵乘法对应角的加法。

**【D7-3-030】** 由和角公式推导倍角公式：$\sin 2\alpha=2\sin\alpha\cos\alpha$，$\cos 2\alpha=\cos^2\alpha-\sin^2\alpha=2\cos^2\alpha-1=1-2\sin^2\alpha$。

- **难度**：★
- **解答**：在和角公式中令 $\beta=\alpha$：
$\sin 2\alpha=\sin(\alpha+\alpha)=\sin\alpha\cos\alpha+\cos\alpha\sin\alpha=2\sin\alpha\cos\alpha$。
$\cos 2\alpha=\cos(\alpha+\alpha)=\cos\alpha\cos\alpha-\sin\alpha\sin\alpha=\cos^2\alpha-\sin^2\alpha$。
用 $\sin^2+\cos^2=1$：$\cos 2\alpha=2\cos^2\alpha-1=1-2\sin^2\alpha$。∎
- **点评**：倍角公式是和角公式的特例——令两个角相等。$\cos 2\alpha$ 的三种形式各有用途（降幂、积分换元）。

**【D7-3-031】** 推导积化和差公式：$\sin\alpha\cos\beta=\frac{1}{2}[\sin(\alpha+\beta)+\sin(\alpha-\beta)]$。

- **难度**：★
- **解答**：$\sin(\alpha+\beta)=\sin\alpha\cos\beta+\cos\alpha\sin\beta$
$\sin(\alpha-\beta)=\sin\alpha\cos\beta-\cos\alpha\sin\beta$
相加：$\sin(\alpha+\beta)+\sin(\alpha-\beta)=2\sin\alpha\cos\beta$
故 $\sin\alpha\cos\beta=\frac{1}{2}[\sin(\alpha+\beta)+\sin(\alpha-\beta)]$。
同理：$\cos\alpha\cos\beta=\frac{1}{2}[\cos(\alpha+\beta)+\cos(\alpha-\beta)]$
$\sin\alpha\sin\beta=\frac{1}{2}[\cos(\alpha-\beta)-\cos(\alpha+\beta)]$。∎
- **点评**：积化和差公式把乘积转化为和差——这是 Fourier 分析中正交性证明的基础，也是积分计算的常用技巧。

**【D7-3-032】** 推导和差化积公式：$\sin A+\sin B=2\sin\frac{A+B}{2}\cos\frac{A-B}{2}$。

- **难度**：★
- **解答**：令 $A=\alpha+\beta$，$B=\alpha-\beta$，则 $\alpha=\frac{A+B}{2}$，$\beta=\frac{A-B}{2}$。
由积化和差 $\sin\alpha\cos\beta=\frac{1}{2}[\sin(\alpha+\beta)+\sin(\alpha-\beta)]=\frac{1}{2}(\sin A+\sin B)$。
故 $\sin A+\sin B=2\sin\frac{A+B}{2}\cos\frac{A-B}{2}$。
同理：$\sin A-\sin B=2\cos\frac{A+B}{2}\sin\frac{A-B}{2}$
$\cos A+\cos B=2\cos\frac{A+B}{2}\cos\frac{A-B}{2}$
$\cos A-\cos B=-2\sin\frac{A+B}{2}\sin\frac{A-B}{2}$。∎
- **点评**：和差化积是积化和差的逆运算——把和差转化为乘积。这两组公式是三角恒等变换的核心工具。

### L2 复变函数基础

**【D7-3-033】** 用欧拉公式证明棣莫弗公式：$(\cos\theta+i\sin\theta)^n=\cos n\theta+i\sin n\theta$。

- **难度**：★
- **解答**：由欧拉公式，$\cos\theta+i\sin\theta=e^{i\theta}$。
$(\cos\theta+i\sin\theta)^n=(e^{i\theta})^n=e^{in\theta}=\cos n\theta+i\sin n\theta$。
这是棣莫弗公式的最简证明——用指数函数的幂运算。
几何意义：单位圆上角度为 $\theta$ 的点，自乘 $n$ 次后角度变为 $n\theta$（模保持 1）。∎
- **点评**：棣莫弗公式是复数乘方的基本公式——它把三角学的倍角问题转化为指数运算。用它可以一次性得到所有倍角公式。

**【D7-3-034】** 用棣莫弗公式推导 $\cos 3\theta$ 和 $\sin 3\theta$ 的展开式。

- **难度**：★★
- **解答**：$(\cos\theta+i\sin\theta)^3=\cos 3\theta+i\sin 3\theta$。
左边展开（二项式定理）：
$\cos^3\theta+3i\cos^2\theta\sin\theta+3i^2\cos\theta\sin^2\theta+i^3\sin^3\theta$
$=(\cos^3\theta-3\cos\theta\sin^2\theta)+i(3\cos^2\theta\sin\theta-\sin^3\theta)$。
比较实部虚部：
$\cos 3\theta=\cos^3\theta-3\cos\theta\sin^2\theta=4\cos^3\theta-3\cos\theta$
$\sin 3\theta=3\cos^2\theta\sin\theta-\sin^3\theta=3\sin\theta-4\sin^3\theta$。∎
- **点评**：棣莫弗公式 + 二项式定理可以系统地推导任意倍角公式——实部给出 $\cos n\theta$，虚部给出 $\sin n\theta$。

**【D7-3-035】** 证明：$e^{iz}$ 是复平面上的共形映射，把实轴映为单位圆，把虚轴映为正实轴射线。

- **难度**：★★
- **解答**：$e^{iz}=e^{i(x+iy)}=e^{-y+ix}=e^{-y}(\cos x+i\sin x)$。
实轴 $y=0$：$e^{ix}=\cos x+i\sin x$，模为 1，辐角为 $x$——单位圆。
虚轴 $x=0$：$e^{-y}$，$y\in\mathbb{R}$，$e^{-y}\in(0,\infty)$——正实轴（不含原点）。
$e^{iz}$ 的导数为 $ie^{iz}\neq0$，故处处共形（保角）。
几何意义：$e^{iz}$ 把直角坐标网格映为极坐标网格（与 $e^z$ 类似，但旋转了 90°）。∎
- **点评**：$e^{iz}$ 的几何意义——它把实轴"弯成"单位圆，把虚轴"拉伸"为正实轴。这是欧拉公式的映射学解释。

### L3 实变函数基础

**【D7-3-036】** 证明：三角多项式 $T(x)=\sum_{n=-N}^N c_n e^{inx}$ 在 $[0,2\pi]$ 上稠密于连续周期函数（Weierstrass 三角逼近定理）。

- **难度**：★★
- **解答**：Weierstrass 三角逼近定理：任何 $2\pi$ 周期连续函数都可以被三角多项式一致逼近。
证明用 Fejér 核（D5-6-032）：Fourier 级数的 Cesàro 平均 $\sigma_N(f)$ 一致收敛到 $f$。
$\sigma_N(f)$ 是三角多项式（次数不超过 $N$）。
故三角多项式在 $C(\mathbb{T})$（连续周期函数空间，一致范数）中稠密。
这是 Fourier 分析的基础定理——它说明三角函数系是完备的。∎
- **点评**：Weierstrass 三角逼近定理是 Fourier 分析的基石——它保证了任何连续周期函数都可以用三角函数逼近到任意精度。

**【D7-3-037】** 证明：两个三角多项式的乘积仍是三角多项式，且 Fourier 系数是卷积。

- **难度**：★★
- **解答**：设 $f(x)=\sum_n a_n e^{inx}$，$g(x)=\sum_m b_m e^{imx}$。
$f(x)g(x)=\sum_{n,m}a_n b_m e^{i(n+m)x}=\sum_k(\sum_n a_n b_{k-n})e^{ikx}$。
故乘积的 Fourier 系数 $c_k=\sum_n a_n b_{k-n}=(a*b)_k$（离散卷积）。
这是卷积定理的离散版本：时域乘积对应频域卷积。
反过来，频域乘积对应时域卷积（Fourier 变换的卷积定理）。∎
- **点评**：三角多项式的乘法对应 Fourier 系数的卷积——这是调和分析的基本结构。卷积是交换代数的乘法，三角多项式空间构成一个代数。

**【D7-3-038】** 证明：若 $f\in L^1[0,2\pi]$ 且所有 Fourier 系数为 0，则 $f=0$ a.e.（唯一性定理）。

- **难度**：★★
- **解答**：若 $\hat{f}(n)=0$ 对所有 $n$，则 $f$ 与所有三角多项式正交（$\int f\bar{T}=0$）。
由 Weierstrass 三角逼近定理，三角多项式在连续函数中稠密。
故 $f$ 与所有连续函数正交：$\int f g=0$ 对所有连续 $g$。
取 $g=\text{sgn}(f)$ 的连续逼近（或用 Lusin 定理），得 $\int|f|=0$，故 $f=0$ a.e.。
这说明 Fourier 系数唯一确定 $L^1$ 函数。∎
- **点评**：Fourier 系数的唯一性——一个 $L^1$ 函数由其 Fourier 系数完全决定（a.e. 意义下）。这是 Fourier 变换可逆性的基础。

### 经典名题

**【D7-3-CROSS-016】**（D7 × D5 级数 × D8 解析）**从和角公式出发推导 Euler 公式 e^{iθ} = cosθ + i sinθ 的另一种路径：先定义复指数函数的幂级数，再利用和角公式的"加法性质"证明 e^{iθ} 满足三角函数的和角公式，从而建立等式。讨论这如何体现了"代数结构（加法）决定函数形式"。**

- **难度**：★★★
- **对应知识点**：Euler公式、幂级数、和角公式、代数结构
- **解答**：
  **幂级数定义复指数**：
  e^z = ∑_{n=0}^∞ z^n/n!（对所有复数 z 收敛）。
  关键性质：e^{z+w} = e^z e^w（由幂级数的二项式展开证明）。

  **令 z = iθ**：
  e^{iθ} = ∑(iθ)^n/n! = 1 + iθ - θ²/2! - iθ³/3! + θ⁴/4! + ...
  分离实部虚部：
  Re(e^{iθ}) = 1 - θ²/2! + θ⁴/4! - ... =: C(θ)
  Im(e^{iθ}) = θ - θ³/3! + θ⁵/5! - ... =: S(θ)

  **利用加法性质**：
  e^{i(α+β)} = e^{iα} e^{iβ}
  ⟹ C(α+β) + iS(α+β) = (C(α)+iS(α))(C(β)+iS(β))
  = [C(α)C(β)-S(α)S(β)] + i[S(α)C(β)+C(α)S(β)]
  比较得：
  C(α+β) = C(α)C(β) - S(α)S(β)
  S(α+β) = S(α)C(β) + C(α)S(β)
  这正是余弦和正弦的和角公式！

  **确定 C 和 S**：
  C(0) = 1, S(0) = 0（由幂级数）。
  C'(θ) = -S(θ), S'(θ) = C(θ)（逐项求导）。
  这些性质唯一确定了 C(θ) = cosθ, S(θ) = sinθ。
  所以 e^{iθ} = cosθ + i sinθ。∎

  **代数结构决定函数形式**：
  这个推导的核心是：e^z 的加法性质 e^{z+w}=e^z e^w 决定了 e^{iθ} 的实部和虚部必须满足和角公式。
  而满足和角公式、初始条件 C(0)=1,S(0)=0、导数关系 C'=-S,S'=C 的函数只能是 cos 和 sin。
  这体现了一个深刻的原理：**函数的代数性质（加法公式）决定了它的解析形式**。
  三角函数不是"人为定义"的——它们是满足和角公式的唯一（在适当条件下）函数。

  **几何理解**：
  e^{iθ} 的模 = √(C²+S²) = 1（因为 d/dθ(C²+S²)=2CC'+2SS'=2C(-S)+2S(C)=0，且 C(0)²+S(0)²=1）。
  所以 e^{iθ} 在单位圆上运动。
  导数 d/dθ e^{iθ} = i e^{iθ}，即速度方向垂直于位置向量——这正是匀速圆周运动。
  所以 e^{iθ} 描述单位圆上的匀速旋转，其实部虚部就是 cosθ 和 sinθ。∎
- **一句话点评**：e^z=∑z^n/n!,e^{z+w}=e^ze^w。e^{iθ}的实部C(θ)虚部S(θ)满足e^{i(α+β)}=e^{iα}e^{iβ}⟹C和S满足和角公式。C(0)=1,S(0)=0,C'=-S,S'=C唯一确定C=cos,S=sin。代数性质（加法公式）决定解析形式。e^{iθ}模=1,导数=ie^{iθ}=匀速圆周运动。

**【D7-3-CROSS-017】**（D7 × D6 完备性 × D3 微分）**用 Chebyshev 多项式证明：对于任意 n 次首一多项式 P(x)，max_{x∈[-1,1]}|P(x)| ≥ 1/2^{n-1}，等号当且仅当 P(x) = T_n(x)/2^{n-1}。说明这如何是"旋转均匀性"在逼近论中的体现，以及 Chebyshev 多项式的零点为什么在单位圆上均匀分布。**

- **难度**：★★★
- **对应知识点**：Chebyshev多项式、最小最大逼近、旋转均匀性、零点分布
- **解答**：
  **Chebyshev 多项式的极值性质**：
  T_n(x) = cos(n arccos x)，在 [-1,1] 上 |T_n(x)| ≤ 1。
  T_n 的首项系数是 2^{n-1}（n≥1）。
  所以 T_n(x)/2^{n-1} 是首一多项式，且 max|T_n/2^{n-1}| = 1/2^{n-1}。

  **证明下界**：
  假设存在首一 n 次多项式 P(x) 使得 max_{[-1,1]}|P(x)| &lt; 1/2^{n-1}。
  考虑 Q(x) = T_n(x)/2^{n-1} - P(x)。
  T_n/2^{n-1} 在点 x_k = cos(kπ/n)（k=0,1,...,n）处交替取 ±1/2^{n-1}。
  在这些点上，|P(x_k)| &lt; 1/2^{n-1}，所以 Q(x_k) 的符号与 T_n(x_k)/2^{n-1} 相同。
  因此 Q 在 n+1 个点上交替变号，由介值定理 Q 至少有 n 个零点。
  但 Q 是次数 ≤ n-1 的多项式（T_n/2^{n-1} 和 P 都是首一 n 次，相减消去 x^n 项），不可能有 n 个零点（除非 Q≡0）。
  矛盾！所以 max|P| ≥ 1/2^{n-1}。
  等号当且仅当 P = T_n/2^{n-1}。∎

  **旋转均匀性的体现**：
  T_n(x) = cos(nθ)（x=cosθ）在 θ ∈ [0,π] 上有 n+1 个极值点 θ_k = kπ/n，对应 x_k = cos(kπ/n)。
  这些极值点在角度 θ 上均匀分布（间距 π/n），但在 x 上不均匀（cos 压缩）。
  均匀分布的极值点使 T_n 在 [-1,1] 上"最均匀地振荡"，从而达到最小的最大绝对值。
  这是"旋转均匀性"——n 次旋转 nθ 在单位圆上均匀经过 n+1 个极值点——在多项式逼近中的体现。

  **零点分布**：
  T_n 的零点：cos(nθ)=0 ⟹ nθ = (2k-1)π/2 ⟹ θ = (2k-1)π/(2n)，x = cos((2k-1)π/(2n))。
  零点在角度 θ 上均匀分布（间距 π/n），在单位圆上对应均匀分布的点。
  极值点：x = cos(kπ/n)，也在角度上均匀分布。
  这种均匀分布来自 cos(nθ) 的周期性——n 次旋转在单位圆上均匀采样。

  **几何理解**：
  Chebyshev 多项式是"在 [-1,1] 上振荡最均匀的多项式"，因为它的极值点来自单位圆上的均匀旋转。
  任何其他首一多项式的极值点都不如 T_n 均匀，因此最大绝对值更大。
  这是"圆的对称性"在逼近论中的深刻应用——均匀旋转产生最优逼近。∎
- **一句话点评**：T_n首项系数2^{n-1},|T_n|≤1⟹T_n/2^{n-1}首一且max=1/2^{n-1}。若P更小则Q=T_n/2^{n-1}-P在n+1个极值点交替变号⟹Q有n个零点，但Q次数≤n-1矛盾。极值点x_k=cos(kπ/n)在角度上均匀分布=旋转均匀性。零点cos((2k-1)π/(2n))也均匀分布。圆的对称性⟹最优逼近。

### 反例与构造

**【D7-3-CROSS-018】**（D7 × D2 连续 × D6 完备性）**构造一个连续函数 f: ℝ → ℝ，满足 f(x+y) = f(x)f(y) 对所有 x,y，但 f 不是指数函数。提示：考虑不连续的解，但加上连续性后唯一解是指数函数。讨论这如何与三角函数的和角公式相关——和角公式加上连续性唯一确定了三角函数。**

- **难度**：★★★
- **对应知识点**：Cauchy指数方程、连续解、和角公式、Hamel基
- **解答**：
  **方程 f(x+y)=f(x)f(y)**：
  这是 Cauchy 指数方程。
  如果 f 连续且不恒为 0，则 f(x) = e^{cx} 对某个常数 c。
  证明：f(x) = f(x/2)² ≥ 0，若 f(x₀)=0 则 f≡0。非零解 f>0。
  令 g(x) = ln f(x)，则 g(x+y)=g(x)+g(y)（Cauchy 方程）。
  连续的 Cauchy 方程解为 g(x)=cx，所以 f(x)=e^{cx}。

  **不连续的解（需要选择公理）**：
  将 ℝ 看作 ℚ 上的向量空间，取一组 Hamel 基 {e_α}。
  任意函数 g: {e_α} → ℝ 线性延拓为 g: ℝ → ℝ，满足 g(x+y)=g(x)+g(y)。
  如果 g 不是线性的（即 g(x) ≠ cx），则 f(x)=e^{g(x)} 是不连续的解。
  这些解极度病态——在任何区间内无界、不连续、不可测。
  构造需要选择公理，在 ZF 公理系统中不能显式构造。

  **与三角函数和角公式的关系**：
  三角函数的和角公式：
  C(x+y)=C(x)C(y)-S(x)S(y), S(x+y)=S(x)C(y)+C(x)S(y)
  这是一个"二维的 Cauchy 方程"。
  加上连续性（和初始条件 C(0)=1,S(0)=0），唯一解是 C(x)=cos(cx), S(x)=sin(cx)。
  没有连续性，也存在病态解（类似 Hamel 基构造）。

  **更一般的原理**：
  许多函数方程（Cauchy 方程、和角公式、二倍角公式等）在没有正则性条件（连续、可测、有界）时有病态解，加上正则性后唯一确定"好"的函数。
  这体现了分析学的一个核心思想：**代数性质 + 正则性 = 解析形式**。
  三角函数不是任意满足和角公式的函数——它们是连续的（因此是光滑的、解析的）满足和角公式的函数。

  **几何理解**：
  和角公式说的是"旋转的合成"。连续的旋转合成只能是匀速旋转（cos(cx), sin(cx)）。
  不连续的解对应"病态的旋转"——在有理数倍和无理数倍上行为不一致，无法用几何图像描述。
  连续性保证了旋转是"光滑的"，从而唯一确定了三角函数。∎
- **一句话点评**：f(x+y)=f(x)f(y)连续解=e^{cx}。不连续解需Hamel基+选择公理，病态无界不可测。三角和角公式=二维Cauchy方程，加连续性+初始条件唯一确定(cos(cx),sin(cx))。原理：代数性质+正则性=解析形式。连续旋转合成=匀速旋转。

### 定理串联

**【D7-3-CROSS-019】**（D7 × D8 解析 × D5 级数）**建立"和角公式 → De Moivre 公式 → Chebyshev 多项式 → Fourier 级数"的完整链条，说明每一步如何是前一步的推广，以及这如何统一了三角恒等式、复分析、逼近论和调和分析四个领域。**

- **难度**：★★★
- **对应知识点**：和角公式、De Moivre、Chebyshev、Fourier、四领域统一
- **解答**：
  **第一步：和角公式**：
  sin(α+β)=sinαcosβ+cosαsinβ, cos(α+β)=cosαcosβ-sinαsinβ。
  几何本质：旋转的合成。这是最基本的三角恒等式。

  **第二步：De Moivre 公式**：
  令 α=β=θ，反复应用和角公式（或用 Euler 公式）：
  (cosθ+i sinθ)^n = cos(nθ)+i sin(nθ)。
  这是和角公式在 n 次旋转迭代下的推广。
  几何本质：旋转 n 次 θ = 旋转 nθ。

  **第三步：Chebyshev 多项式**：
  从 De Moivre 公式分离实部：cos(nθ) = Re[(cosθ+i sinθ)^n]。
  展开后，cos(nθ) 是 cosθ 的 n 次多项式：T_n(cosθ)=cos(nθ)。
  递推 T_{n+1}=2xT_n-T_{n-1}（来自和差化积 cos((n+1)θ)+cos((n-1)θ)=2cosθcos(nθ)）。
  这是 De Moivre 公式的"多项式化"——将超越函数 cos(nθ) 转化为多项式 T_n(x)。
  几何本质：旋转迭代在横坐标上的多项式映射。

  **第四步：Fourier 级数**：
  任何周期函数 f(x) 可以展开为 ∑[a_n cos(nx)+b_n sin(nx)]。
  基函数 {cos(nx), sin(nx)} 来自 n 次旋转的投影。
  正交性由积化和差证明（积化和差本身来自和角公式）。
  Chebyshev 多项式是 Fourier 余弦级数在 [-1,1] 上的正交多项式版本（权函数 1/√(1-x²)）。

  **四领域统一**：
  | 领域 | 对象 | 核心公式 |
  |---|---|---|
  | 三角恒等式 | 角度加法 | 和角公式 |
  | 复分析 | 复数乘法 | De Moivre / Euler |
  | 逼近论 | 多项式逼近 | Chebyshev T_n |
  | 调和分析 | 函数分解 | Fourier 级数 |

  这四个领域通过"旋转"统一起来：
  - 和角公式 = 旋转的合成
  - De Moivre = 旋转的迭代（复数形式）
  - Chebyshev = 旋转迭代在横坐标上的多项式化
  - Fourier = 任意周期函数分解为不同速度的旋转

  **几何理解**：
  一切始于"旋转"——单位圆上的匀速旋转。
  旋转的合成给出和角公式，旋转的迭代给出 De Moivre 和 Chebyshev，旋转的叠加给出 Fourier 级数。
  四个领域的核心概念都是旋转，只是视角不同：代数（恒等式）、几何（复数）、多项式（逼近）、函数空间（调和分析）。∎
- **一句话点评**：和角公式(旋转合成)→De Moivre((cosθ+isinθ)^n=cosnθ+isinnθ,旋转迭代)→Chebyshev(T_n(cosθ)=cosnθ,旋转迭代多项式化)→Fourier(周期函数=不同速度旋转的叠加,正交性由积化和差证明)。四领域通过"旋转"统一：代数/几何/多项式/函数空间。

**【D7-3-CROSS-020】**（D7 × D3 微分 × D4 积分）**用和角公式证明导数公式 (sin x)' = cos x 和 (cos x)' = -sin x，说明这如何依赖于重要极限 lim_{h→0} sin h/h = 1，以及导数的几何意义（投影的变化率）。**

- **难度**：★★
- **对应知识点**：导数公式、和角公式、重要极限、投影变化率
- **解答**：
  **(sin x)'**：
  (sin x)' = lim_{h→0}[sin(x+h)-sin x]/h
  = lim[sin x cos h + cos x sin h - sin x]/h
  = sin x · lim(cos h - 1)/h + cos x · lim sin h/h
  = sin x · 0 + cos x · 1 = cos x。∎
  这里 lim(cos h - 1)/h = 0（因为 1-cos h ~ h²/2 是二阶小量），lim sin h/h = 1（重要极限）。

  **(cos x)'**：
  (cos x)' = lim[cos(x+h)-cos x]/h
  = lim[cos x cos h - sin x sin h - cos x]/h
  = cos x · lim(cos h - 1)/h - sin x · lim sin h/h
  = cos x · 0 - sin x · 1 = -sin x。∎

  **几何意义**：
  sin x 是单位圆上点 (cos x, sin x) 的纵坐标（y 投影）。
  当 x 增加 h 时，点沿单位圆移动弧长 h（弧度制下），纵坐标变化 = sin(x+h)-sin x。
  导数 = 纵坐标的变化率 = 投影的变化率。
  在点 (cos x, sin x) 处，切线方向 = (-sin x, cos x)（垂直于半径）。
  沿切线移动 h（弧长），纵坐标变化 = h · cos x（切线方向的 y 分量）。
  所以 d(sin x)/dx = cos x——这正是切线方向的 y 分量！

  同理，cos x 是 x 投影，切线方向的 x 分量 = -sin x，所以 (cos x)' = -sin x。

  **对重要极限的依赖**：
  导数证明的关键是 lim sin h/h = 1。
  这个极限只在弧度制下成立（因为扇形面积 = h/2 只在弧度制下成立）。
  所以 (sin x)' = cos x 也只在弧度制下成立——度制下带 π/180 因子。
  这再次体现了弧度制的自然性。
- **一句话点评**：(sinx)'=lim[sin(x+h)-sinx]/h=sinx·lim(cosh-1)/h+cosx·lim sinh/h=cosx。(cosx)'=-sinx。几何=单位圆点的y投影变化率=切线方向(-sinx,cosx)的y分量=cosx。依赖lim sinh/h=1（弧度制），度制下带π/180。

**【D7-3-CROSS-021】**（D7 × D4 积分 × D6 完备性）**用和差化积计算 Dirichlet 积分 ∫₀^∞ sin x / x dx = π/2。具体步骤：先将积分写成极限 lim_{A→∞}∫₀^A sinx/x dx，利用积化和差或 Fourier 积分的方法计算。说明这个积分如何连接了三角函数、无穷积分和 π。**

- **难度**：★★★
- **对应知识点**：Dirichlet积分、无穷积分、Fourier积分、π
- **解答**：
  **方法一：含参积分**：
  定义 I(a) = ∫₀^∞ e^{-ax} sin x / x dx（a > 0）。
  对 a 求导：I'(a) = -∫₀^∞ e^{-ax} sin x dx。
  用分部积分或公式 ∫e^{-ax}sinbx dx = b/(a²+b²)：
  I'(a) = -1/(a²+1)。
  积分：I(a) = -arctan a + C。
  当 a→∞ 时 I(a)→0 ⟹ C = π/2。
  所以 I(a) = π/2 - arctan a。
  令 a→0⁺：∫₀^∞ sinx/x dx = π/2。∎

  **方法二：Fourier 积分**：
  考虑函数 f(x) = 1（|x|&lt;1），f(x)=0（|x|>1）的 Fourier 变换。
  \hat f(ω) = ∫_{-1}^1 e^{-iωx}dx = 2sinω/ω。
  Fourier 逆变换在 x=0 处：f(0) = (1/2π)∫_{-∞}^∞ \hat f(ω)dω。
  1 = (1/2π)∫_{-∞}^∞ 2sinω/ω dω = (2/π)∫₀^∞ sinω/ω dω。
  所以 ∫₀^∞ sinω/ω dω = π/2。∎

  **与三角恒等式的联系**：
  方法一中 ∫e^{-ax}sinx dx 的计算可以用积化和差：
  e^{-ax}sinx = Im[e^{(-a+i)x}]，积分 = Im[1/(a-i)] = 1/(a²+1)。
  或者用分部积分，本质上利用了 sin 和 cos 的导数关系（来自和角公式）。

  **π 的出现**：
  Dirichlet 积分的结果 π/2 中，π 来自 arctan∞ = π/2（方法一）或 Fourier 逆变换的归一化因子 1/(2π)（方法二）。
  几何上，π 来自单位圆的周长——arctan 的值域 (-π/2,π/2) 对应单位圆的右半部分。
  sinx/x 是" sinc 函数"，它的积分给出 π——这是信号处理中最重要的积分之一。

  **几何理解**：
  sinx/x 是单位圆上点的 y 投影除以角度 x。当 x→0 时 sinx/x→1（重要极限），当 x→∞ 时振荡衰减。
  积分从 0 到 ∞ 恰好是 π/2——半个 π。这个结果深刻连接了三角函数（振荡）、无穷积分（极限过程）和 π（圆的常数）。∎

**【D7-3-CROSS-024】**（D7 × D5 级数 × D6 完备性）**用和差化积证明 Weierstrass 逼近定理的一个特例：任何 [-π,π] 上的连续周期函数都可以用三角多项式一致逼近。说明 Fejér 和（Fourier 级数的 Cesàro 平均）如何利用和差化积构造正核，从而实现一致逼近。**

- **难度**：★★★
- **对应知识点**：Weierstrass逼近、Fejér和、三角多项式、正核、和差化积
- **解答**：
  **Fourier 级数与 Fejér 和**：
  f 的 Fourier 级数：S_n(f,x) = ∑_{k=-n}^n c_k e^{ikx}，c_k = (1/2π)∫f(t)e^{-ikt}dt。
  Fourier 级数不一定收敛，但 Fejér 和（Cesàro 平均）一致收敛：
  σ_n(f,x) = (S₀+S₁+...+S_n)/(n+1)。

  **Fejér 核**：
  σ_n(f,x) = (1/2π)∫f(t)F_n(x-t)dt，其中 Fejér 核：
  F_n(u) = (1/(n+1))∑_{k=0}^n D_k(u)，D_k(u)=∑_{j=-k}^k e^{iju} = sin((k+1/2)u)/sin(u/2)（Dirichlet 核）。
  利用等比级数求和：
  F_n(u) = (1/(n+1))[sin((n+1)u/2)/sin(u/2)]²。

  **和差化积的作用**：
  Dirichlet 核 D_k(u) = ∑_{j=-k}^k e^{iju} = e^{-iku}∑_{j=0}^{2k}e^{iju} = e^{-iku}(1-e^{i(2k+1)u})/(1-e^{iu})。
  化简为 sin((k+1/2)u)/sin(u/2)——这个化简用到了和差化积（sin A - sin B = 2cos((A+B)/2)sin((A-B)/2)）。
  Fejér 核是 Dirichlet 核的平均，其平方形式也依赖于和差化积。

  **正核性质**：
  F_n(u) ≥ 0（平方非负）——这是"正核"。
  (1/2π)∫F_n(u)du = 1（归一化）。
  对任何 δ>0，∫_{δ≤|u|≤π}F_n(u)du → 0（质量集中在 0 附近）。
  这些性质保证了 σ_n(f,x) → f(x) 一致收敛。

  **Weierstrass 逼近**：
  σ_n(f,x) 是三角多项式（次数 ≤ n），且一致收敛到 f。
  所以任何连续周期函数都可以用三角多项式一致逼近——这是 Weierstrass 三角逼近定理。
  （代数多项式版本可以通过变量替换 x=cosθ 从三角版本推出。）

  **几何理解**：
  Fejér 核 F_n(u) 是一个"钟形"函数，随着 n 增大越来越集中在 u=0 附近。
  卷积 (f*F_n)(x) 是 f 的"局部平均"——平均窗口越来越小，最终收敛到 f(x)。
  和差化积是构造这个钟形核的代数工具——它将 Dirichlet 核的振荡转化为 Fejér 核的非负平方。
  正核的非负性是一致收敛的关键（Fourier 部分和不收敛是因为 Dirichlet 核有负部分）。∎
- **一句话点评**：Fejér和σ_n=(S₀+...+S_n)/(n+1)一致收敛。Fejér核F_n(u)=(1/(n+1))[sin((n+1)u/2)/sin(u/2)]²≥0=正核。和差化积用于化简Dirichlet核D_k=sin((k+1/2)u)/sin(u/2)。正核性质(非负/归一/质量集中)⟹σ_n→f一致。Weierstrass三角逼近定理。几何=Fejér核是钟形，卷积=局部平均，窗口缩小→收敛。

**【D7-3-CROSS-025】**（D7 × D3 微分 × D8 解析）**从和角公式推导双曲函数的加法公式：sinh(x+y)=sinhx coshy+coshx sinhy, cosh(x+y)=coshx coshy+sinhx sinhy。说明这如何是"虚角度的和角公式"，以及双曲函数与三角函数的统一。**

- **对应知识点**：双曲函数、加法公式、虚角度、三角函数统一
- **解答**：
  **双曲函数定义**：
  sinh x = (e^x-e^{-x})/2, cosh x = (e^x+e^{-x})/2。

  **加法公式推导**：
  sinh(x+y) = [e^{x+y}-e^{-(x+y)}]/2
  = [e^x e^y - e^{-x}e^{-y}]/2。

  另一方面：

  = [(e^x-e^{-x})/2][(e^y+e^{-y})/2] + [(e^x+e^{-x})/2][(e^y-e^{-y})/2]
  = [e^{x+y}+e^{x-y}-e^{-x+y}-e^{-x-y} + e^{x+y}-e^{x-y}+e^{-x+y}-e^{-x-y}]/4
  = [2e^{x+y}-2e^{-x-y}]/4 = [e^{x+y}-e^{-x-y}]/2 = sinh(x+y)。∎

  同理 cosh(x+y) = coshx coshy + sinhx sinhy。

  **虚角度的和角公式**：
  由 Euler 公式的双曲版本：
  cosh x = cos(ix), sinh x = -i sin(ix)。
  （验证：cos(ix)=(e^{i·ix}+e^{-i·ix})/2=(e^{-x}+e^x)/2=cosh x ✓）

  将和角公式中的角度替换为虚数：
  cos(i(x+y)) = cos(ix+iy) = cos(ix)cos(iy) - sin(ix)sin(iy)
  ⟹ cosh(x+y) = coshx coshy - (i sinhx)(i sinhy) = coshx coshy + sinhx sinhy。

  sin(i(x+y)) = sin(ix+iy) = sin(ix)cos(iy)+cos(ix)sin(iy)
  ⟹ -i sinh(x+y) = (i sinhx)coshy + coshx(i sinhy) = i(sinhx coshy+coshx sinhy)
  ⟹ sinh(x+y) = sinhx coshy + coshx sinhy。

  所以双曲加法公式就是"虚角度的三角和角公式"！

  **统一理解**：
  三角函数和双曲函数是同一个数学结构在不同符号下的表现：
  - 三角函数：单位圆 x²+y²=1，参数 (cosθ, sinθ)
  - 双曲函数：单位双曲线 x²-y²=1，参数 (coshφ, sinhφ)
  - 通过 θ = iφ（虚角度），圆变成双曲线，三角函数变成双曲函数
  - 加法公式的形式几乎相同，只是符号差异（+ vs -）来自 i²=-1

  **几何理解**：
  双曲加法公式描述的是"双曲旋转"（洛伦兹变换）的合成，就像三角和角公式描述的是"欧氏旋转"的合成。
  在狭义相对论中，双曲加法公式对应速度叠加（快度叠加是线性的：φ_total=φ₁+φ₂）。
  虚角度 iφ 将欧氏几何和双曲几何联系起来——这是" Wick 旋转"的数学基础。∎
- **一句话点评**：sinh(x+y)=sinhx coshy+coshx sinhy,cosh(x+y)=coshx coshy+sinhx sinhy。由cosh x=cos(ix),sinh x=-isin(ix)，双曲加法=虚角度的三角和角公式。统一：圆x²+y²=1(cosθ,sinθ)↔双曲线x²-y²=1(coshφ,sinhφ)，θ=iφ。双曲旋转=洛伦兹变换，快度叠加线性。

**【D7-3-CROSS-026】**（D7 × D6 完备性 × D2 连续）**讨论和角公式的"函数方程"视角：寻找所有连续函数 C,S: ℝ→ℝ 满足 C(x+y)=C(x)C(y)-S(x)S(y), S(x+y)=S(x)C(y)+C(x)S(y)。证明唯一解是 C(x)=cos(kx), S(x)=sin(kx)（k为常数），并说明这如何是"连续旋转群的分类"。**

- **难度**：★★★
- **对应知识点**：函数方程、连续解、旋转群分类、和角公式
- **解答**：
  **函数方程**：
  C(x+y)=C(x)C(y)-S(x)S(y) ... (1)
  S(x+y)=S(x)C(y)+C(x)S(y) ... (2)
  C,S 连续。

  **第一步：初始条件**：
  令 x=y=0：C(0)=C(0)²-S(0)², S(0)=2S(0)C(0)。

  |f(x)|² = C(x)²+S(x)²。
  由 (1)(2)：|f(x+y)|²=|f(x)|²|f(y)|²。
  令 g(x)=|f(x)|²，则 g(x+y)=g(x)g(y)，g 连续，g(0)=1 ⟹ g(x)=e^{ax}。

  因此 C(x)=cos(kx), S(x)=sin(kx)。∎

  **如果不要求有界**：
  c 可以是任意复数，解为 C(x)=e^{ax}cos(bx), S(x)=e^{ax}sin(bx)（c=a+ib）。
  这是"衰减/放大的振荡"。
  有界性（或 C²+S²=1）强制 a=0，得到纯三角函数。

  矩阵 M(x) = [[C(x),-S(x)],[S(x),C(x)]] 满足 M(x+y)=M(x)M(y)。
  这是一个连续的一维旋转群（M(x)∈SO(2) 如果 C²+S²=1）。
  上述证明说明：所有连续的一维 SO(2) 子群都是 M(x)=[[cos(kx),-sin(kx)],[sin(kx),cos(kx)]]。
  即连续旋转群只有"匀速旋转"一种——参数 k 是角速度。
  这是李群理论中"一维紧致李群的分类"的初等版本。

  **几何理解**：
  和角公式说的是"旋转的合成"。连续的旋转合成只能是匀速旋转——你不能"时快时慢"地旋转还保持合成公式（因为合成公式强制了参数的可加性，而连续的可加函数只能是线性的）。
  所以连续旋转群唯一由角速度 k 决定——这就是为什么三角函数是唯一的连续和角公式解。∎
- **一句话点评**：f=C+iS满足f(x+y)=f(x)f(y)（复指数方程），连续解f=e^{cx}。有界性(C²+S²=1)强制Re(c)=0⟹c=ik⟹C=cos(kx),S=sin(kx)。无界解C=e^{ax}cos(bx),S=e^{ax}sin(bx)。这是连续一维SO(2)子群的分类=只有匀速旋转，k=角速度。连续可加函数只能线性⟹不能时快时慢。

**【D7-3-CROSS-027】**（D7 × D4 积分 × D5 级数）**用积化和差计算 ∫₀^π ln(1-2r cosx+r²) dx = 0（|r|&lt;1），并利用这个结果计算 Poisson 核的积分。说明这如何是 Fourier 级数的 Abel 求和，以及积化和差在其中的作用。**

- **难度**：★★★
- **对应知识点**：对数积分、Poisson核、Fourier级数Abel求和、积化和差
- **解答**：
  **积分计算**：
  对 |r|&lt;1，ln(1-2r cosx+r²) = ln|1-re^{ix}|² = 2 Re ln(1-re^{ix})。
  展开 ln(1-z) = -∑_{n=1}^∞ z^n/n（|z|&lt;1）：
  ln(1-re^{ix}) = -∑_{n=1}^∞ r^n e^{inx}/n。
  取实部：Re ln(1-re^{ix}) = -∑_{n=1}^∞ r^n cos(nx)/n。
  所以 ln(1-2r cosx+r²) = -2∑_{n=1}^∞ r^n cos(nx)/n。

  积分：∫₀^π ln(...)dx = -2∑_{n=1}^∞ r^n/n ∫₀^π cos(nx)dx = 0（因为 ∫₀^π cos(nx)dx = 0 对 n≥1）。∎

  **积化和差的作用**：
  ∫₀^π cos(nx)dx = [sin(nx)/n]₀^π = 0——这是简单的积分。
  但在更一般的正交性证明中，积化和差是核心工具。
  Poisson 核 P_r(x) = (1-r²)/(1-2r cosx+r²) 可以展开为：
  P_r(x) = 1 + 2∑_{n=1}^∞ r^n cos(nx)。
  这个展开利用了等比级数 ∑r^n e^{inx} = 1/(1-re^{ix})，取实部并利用积化和差化简。

  **Poisson 核积分**：
  ∫₀^{2π} P_r(x)dx = ∫₀^{2π}[1+2∑r^n cos(nx)]dx = 2π + 0 = 2π。
  （正交性：∫cos(nx)dx=0。）

  **Fourier 级数的 Abel 求和**：
  对 f 的 Fourier 级数 ∑c_n e^{inx}，Abel 和为 ∑c_n r^{|n|}e^{inx} = (f*P_r)(x)。
  当 r→1⁻ 时，Abel 和收敛到 f（在连续点）。
  Poisson 核 P_r 是 Abel 求和的核，它是正核（P_r≥0），保证了收敛性。
  这与 Fejér 和（Cesàro 平均）是两种不同的求和方法，但都利用了正核。

  **几何理解**：
  ln(1-2r cosx+r²) = 2ln|1-re^{ix}| 是复平面上点 1 到点 re^{ix} 的距离的对数的 2 倍。
  这个距离在 x 从 0 到 π 变化时，有时大于 1 有时小于 1，对数的正负恰好抵消，积分为 0。
  Poisson 核 (1-r²)/|1-re^{ix}|² 是这个距离平方的倒数乘以 (1-r²)——它描述了"从单位圆内一点 r 看边界点 e^{ix} 的调和测度"。
  积化和差将这个几何量展开为 Fourier 级数，揭示了其调和分析本质。∎
- **一句话点评**：ln(1-2r cosx+r²)=2Re ln(1-re^{ix})=-2∑r^n cos(nx)/n⟹∫₀^π=0（cos(nx)周期积分=0）。Poisson核P_r=(1-r²)/(1-2r cosx+r²)=1+2∑r^n cos(nx),∫P_r=2π。Abel求和=∑c_n r^{|n|}e^{inx}=(f*P_r)(x)→f。几何=ln|1-re^{ix}|²=点1到re^{ix}距离对数，正负抵消。P_r=调和测度。

**【D7-3-CROSS-028】**（D7 × D8 解析 × D6 完备性）**从和角公式出发证明 Liouville 定理的一个应用：非常数整函数不可能将复平面映入单位圆。具体地，若 f 是整函数且 |f(z)|≤1，则 f 为常数。用反证法结合 e^{f(z)} 的模和和角公式的指数版本。**

- **难度**：★★★
- **对应知识点**：Liouville定理、整函数、有界性、复指数
- **解答**：
  **Liouville 定理**：有界整函数必为常数。

  **证明（利用 Cauchy 积分公式）**：
  设 f 是整函数，|f(z)|≤M。
  对任意 z 和 R>|z|，Cauchy 导数公式：
  f'(z) = (1/2πi)∮_{|ζ-z|=R} f(ζ)/(ζ-z)² dζ。
  |f'(z)| ≤ (1/2π) · M/R² · 2πR = M/R。
  令 R→∞，得 f'(z)=0 对所有 z，所以 f 为常数。∎

  **与和角公式的联系**：
  和角公式的指数版本是 e^{z+w}=e^z e^w。
  如果 f 是有界整函数，考虑 g(z)=e^{f(z)}。
  g 也是整函数（整函数的复合），且 |g(z)|=e^{Re f(z)} ≤ e^{|f(z)|} ≤ e^M——有界。
  由 Liouville 定理，g 为常数，所以 e^{f(z)}=C ⟹ f(z)=ln C + 2πik(z)，其中 k(z) 是整数值函数。
  因为 f 连续，k(z) 连续且取整数值，所以 k(z) 为常数 ⟹ f 为常数。

  更直接地，如果 |f(z)|≤1，则 e^{f(z)} 的模 ≤ e，是有界整函数 ⟹ 常数 ⟹ f 常数。

  **几何理解**：
  整函数是复平面上的"光滑函数"，没有奇点。
  如果它有界，就意味着它的图像被限制在一个有限区域内——但复平面是"无限大"的，一个光滑的有界函数只能是常数（因为它无法在无限大的区域内"弯曲"而不产生奇点）。
  和角公式 e^{z+w}=e^z e^w 是复指数的基本性质，它使得 e^{f(z)} 继承了 f 的有界性，从而可以应用 Liouville 定理。

  **推广**：
  Liouville 定理的一个重要推论是代数基本定理：非常数多项式必有复根。
  证明：若 P(z) 无实根，则 1/P(z) 是有界整函数（当 |z|→∞ 时 |1/P(z)|→0），由 Liouville 定理为常数 ⟹ P 为常数，矛盾。
  和角公式（通过复指数）在复分析的基础定理中扮演着核心角色。∎
- **一句话点评**：Liouville定理：有界整函数必常数。Cauchy导数公式|f'(z)|≤M/R→0⟹f'=0。与和角公式联系：e^{z+w}=e^ze^w⟹e^{f(z)}整函数且|e^f|≤e^M有界⟹常数⟹f常数。几何=复平面无限大，光滑有界函数无法弯曲只能常数。推广=代数基本定理（1/P有界整函数⟹常数⟹P常数矛盾）。

## 本模块易错点总结

1. **和角公式是所有恒等式的基础**：倍角=和角在β=α时的特例，差角=用-β替换，半角=倍角反推，和差化积/积化和差=和角公式的加减组合。
2. **和角公式的几何本质是旋转合成**：R_{α+β}=R_αR_β，矩阵乘法展开即得公式。不是代数巧合。
3. **和差化积=平行四边形法则**：两个单位向量的和向量在角平分线上，长度2cos(半差角)。差向量垂直于角平分线，长度2sin(半差角)。
4. **积化和差=投影乘积的旋转分解**：sinαcosβ=[sin(α+β)+sin(α-β)]/2，是Fourier正交性证明的核心工具。
5. **万能公式=单位圆的有理参数化**：t=tan(θ/2)是从(-1,0)出发的球极投影，将三角函数转化为有理函数。
6. **Chebyshev多项式=倍角公式的多项式化**：T_n(cosθ)=cos(nθ)，递推T_{n+1}=2xT_n-T_{n-1}来自和差化积。零点和极值点在角度上均匀分布。
7. **正切和角公式=Möbius变换**：t↦(t+tanβ)/(1-ttanβ)是射影变换，保持交比。旋转合成=Möbius复合。
8. **双曲函数=虚角度的三角函数**：cosh x=cos(ix), sinh x=-i sin(ix)，加法公式形式相同仅符号差异。
9. **连续+和角公式=唯一确定三角函数**：函数方程C(x+y)=C(x)C(y)-S(x)S(y)加上连续性唯一解为(cos(kx),sin(kx))。
10. **Euler公式是和角公式的复指数版本**：e^{i(α+β)}=e^{iα}e^{iβ}，展开比较实部虚部即得所有和角差角倍角公式。
