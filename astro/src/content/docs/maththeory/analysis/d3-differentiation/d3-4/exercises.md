﻿# D3-4 多元函数微分学 · 习题集

> 模块定位 ：D3 微分领域第四模块。从一元到多元的"维度跃迁"——导数从数变成向量（梯度），微分从数乘变成线性映射（全微分），极值从一维变成高维（Hessian 矩阵），中值定理需要凸区域，隐函数定理涉及雅可比矩阵。

---

## 本模块核心考点

1. **偏导数**：定义、几何意义、计算、高阶偏导数、混合偏导数相等
2. **全微分**：定义、必要条件（连续+偏导存在）、充分条件（偏导连续）、几何意义（切平面）、近似计算
3. **方向导数与梯度**：方向导数定义、梯度定义、梯度与方向导数的关系、梯度的几何意义（最速上升方向）
4. **连续、可微、偏导存在的关系**：可微⇒连续+偏导存在；偏导连续⇒可微；偏导存在⇏连续；连续⇏偏导存在
5. **链式法则**：多元复合函数求导
6. **多元函数极值**：无条件极值、驻点、Hessian 矩阵正定性判别
7. **条件极值与拉格朗日乘数法**：原理、计算、几何意义
8. **多元泰勒公式**：二阶展开、Hessian 矩阵形式
9. **隐函数定理**：一元隐函数、多元隐函数组、雅可比行列式
10. **反函数定理**：条件与结论
11. **几何应用**：曲面切平面与法线、空间曲线切线与法平面

## L0 初等直觉层

> **引导语**：本层建立直觉，从几何和物理意义理解核心概念。

**【D3-4-001】** 什么是偏导数？它和一元函数的导数有什么区别？偏导数的几何意义是什么？

- **难度**：★
- **对应知识点**：偏导数的定义与几何意义
- **解答**：
  **偏导数的定义**：
  设 z=f(x,y)，固定 y=y₀，对 x 求导：
  ∂f/∂x(x₀,y₀)=lim_{Δx→0}[f(x₀+Δx,y₀)-f(x₀,y₀)]/Δx
  
  类似地，固定 x=x₀，对 y 求导得 ∂f/∂y。
  
  **和一元导数的区别**：
  
  | 性质 | 一元导数 | 偏导数 |
  |------|---------|--------|
  | 自变量 | 一个 | 多个（固定其他，只变一个） |
  | 结果 | 一个数 | 每个自变量对应一个数 |
  | 几何意义 | 平面曲线切线斜率 | 曲面与坐标平面交线的切线斜率 |
  | 方向 | 只有左右两个方向 | 只沿坐标轴方向 |
  
  **几何意义**：
  ∂f/∂x(x₀,y₀) 是曲面 z=f(x,y) 与平面 y=y₀ 的交线（一条平面曲线）在点 (x₀,y₀,f(x₀,y₀)) 处的切线对 x 轴的斜率。
  
  想象一个山坡（曲面），站在点 (x₀,y₀) 处：
  - 面向 x 轴方向走，山坡的坡度就是 ∂f/∂x
  - 面向 y 轴方向走，山坡的坡度就是 ∂f/∂y
  
  **关键理解**：
  偏导数只描述了曲面在两个坐标轴方向上的坡度，没有描述其他方向的坡度——这就是为什么需要方向导数（沿任意方向的变化率）和梯度（所有方向变化率的"总向量"）。∎
- **一句话点评**：偏导数=固定其他变量，只对一个变量求导。几何意义：曲面与坐标平面交线的切线斜率。和一元导数的区别：多元有多个偏导数，每个对应一个坐标方向。偏导数只描述坐标轴方向的坡度，其他方向需要方向导数和梯度。

**【D3-4-002】** 什么是全微分？它和偏导数有什么关系？全微分的几何意义是什么？

- **难度**：★
- **对应知识点**：全微分
- **解答**：
  **全微分的定义**：
  如果函数的全增量 Δz=f(x₀+Δx,y₀+Δy)-f(x₀,y₀) 可以表示为：
  Δz = AΔx + BΔy + o(ρ)，其中 ρ=√(Δx²+Δy²)
  则称 f 在 (x₀,y₀) 处可微，dz=AΔx+BΔy 称为全微分。
  
  **和偏导数的关系**：
  如果 f 可微，则偏导数存在，且 A=∂f/∂x, B=∂f/∂y。
  所以 dz = (∂f/∂x)dx + (∂f/∂y)dy。
  
  **可微的条件**：
  - 必要条件：可微 ⇒ 连续 + 偏导数存在
  - 充分条件：偏导数连续 ⇒ 可微
  - 注意：偏导数存在 ⇏ 可微（偏导数存在只是"坐标轴方向可导"，不保证"所有方向可线性逼近"）
  
  **几何意义**：
  全微分 dz 是曲面 z=f(x,y) 在点 (x₀,y₀,z₀) 处的**切平面**的增量。
  
  切平面方程：z-z₀ = fₓ(x₀,y₀)(x-x₀) + fᵧ(x₀,y₀)(y-y₀)
  
  当 (x,y) 接近 (x₀,y₀) 时，曲面的增量 Δz 可以用切平面的增量 dz 来近似，误差是比 ρ 高阶的无穷小 o(ρ)。
  
  **和一元的对比**：
  - 一元：dy=f'(x₀)dx，几何意义是切线的增量
  - 多元：dz=fₓdx+fᵧdy，几何意义是切平面的增量
  - 一元切线→多元切平面，这是维度跃迁的体现。∎
  
  **近似计算**：
  f(x₀+Δx,y₀+Δy) ≈ f(x₀,y₀) + fₓ(x₀,y₀)Δx + fᵧ(x₀,y₀)Δy
  这就是用切平面近似曲面——多元版本的"以直代曲"。
- **一句话点评**：全微分dz=fₓdx+fᵧdy，几何意义是切平面的增量（一元是切线增量）。可微⇒连续+偏导存在；偏导连续⇒可微。偏导存在⇏可微。近似计算：用切平面近似曲面，f(x₀+Δx,y₀+Δy)≈f(x₀,y₀)+fₓΔx+fᵧΔy。

### 组A：偏导数与全微分

**【D3-4-010】** 用全微分近似计算 √(1.02)³+(1.97)³ 的值。

- **难度**：★
- **对应知识点**：全微分近似计算
- **解答**：
  **解**：
  设 f(x,y)=√(x³+y³)，取 (x₀,y₀)=(1,2)，Δx=0.02，Δy=-0.03。
  
  f(1,2)=√(1+8)=√9=3
  
  fₓ = (1/2)(x³+y³)^(-1/2)·3x² = 3x²/[2√(x³+y³)]
  fᵧ = 3y²/[2√(x³+y³)]
  
  fₓ(1,2)=3·1/[2·3]=1/2
  fᵧ(1,2)=3·4/[2·3]=12/6=2
  
  **全微分近似**：
  f(1.02,1.97) ≈ f(1,2) + fₓ(1,2)·0.02 + fᵧ(1,2)·(-0.03)
  = 3 + (1/2)(0.02) + 2(-0.03)
  = 3 + 0.01 - 0.06
  = 2.95
  
  **真实值验证**：
  1.02³≈1.0612, 1.97³≈7.6454
  和≈8.7066, √8.7066≈2.9507
  
  近似值 2.95 和真实值 2.9507 非常接近，误差约 0.0007。∎
  
  **全微分近似的原理**：
  用切平面近似曲面：f(x₀+Δx,y₀+Δy)≈f(x₀,y₀)+fₓΔx+fᵧΔy。
  这是多元版本的"以直代曲"——一元函数用切线近似，多元函数用切平面近似。
  
  **误差分析**：
  误差是 o(ρ)，其中 ρ=√(Δx²+Δy²)=√(0.0004+0.0009)=√0.0013≈0.036。
  当 Δx,Δy 很小时，误差很小。∎
- **一句话点评**：f=√(x³+y³)，取(1,2)，Δx=0.02,Δy=-0.03。f(1,2)=3，fₓ=1/2,fᵧ=2。近似：3+0.5×0.02+2×(-0.03)=2.95。真实值≈2.9507，误差≈0.0007。原理：切平面近似曲面，多元版"以直代曲"。

**【D3-4-004】** 求 f(x,y)=x²y+sin(xy) 的所有一阶和二阶偏导数，并验证混合偏导数相等。

- **难度**：★★
- **对应知识点**：偏导数计算、混合偏导数
- **解答**：
  **解**：
  f(x,y)=x²y+sin(xy)
  
  **一阶偏导数**：
  fₓ = 2xy + y cos(xy)（把 y 当常数，对 x 求导）
  fᵧ = x² + x cos(xy)（把 x 当常数，对 y 求导）
  
  **二阶偏导数**：
  fₓₓ = ∂/∂x(2xy+y cos(xy)) = 2y + y·(-sin(xy))·y = 2y - y² sin(xy)
  
  fₓᵧ = ∂/∂y(2xy+y cos(xy)) = 2x + cos(xy) + y·(-sin(xy))·x = 2x + cos(xy) - xy sin(xy)
  
  fᵧₓ = ∂/∂x(x²+x cos(xy)) = 2x + cos(xy) + x·(-sin(xy))·y = 2x + cos(xy) - xy sin(xy)
  
  fᵧᵧ = ∂/∂y(x²+x cos(xy)) = 0 + x·(-sin(xy))·x = -x² sin(xy)
  
  **验证混合偏导数相等**：
  fₓᵧ = 2x + cos(xy) - xy sin(xy)
  fᵧₓ = 2x + cos(xy) - xy sin(xy)
  
  fₓᵧ = fᵧₓ ✓
  
  **为什么混合偏导数相等**：
  因为 fₓᵧ 和 fᵧₓ 都是初等函数（多项式和三角函数的组合），在全平面上连续。
  由混合偏导数相等定理：如果混合偏导数连续，则与求导顺序无关。∎
  
  **几何理解**：
  fₓᵧ 表示"x 方向坡度随 y 的变化率"，fᵧₓ 表示"y 方向坡度随 x 的变化率"。
  对于光滑曲面，这两个变化率相等——这是曲面"无扭曲"的体现。
  如果混合偏导数不相等，说明曲面有"扭曲"（不光滑）。∎
- **一句话点评**：f=x²y+sin(xy)。一阶：fₓ=2xy+y cos(xy), fᵧ=x²+x cos(xy)。二阶：fₓₓ=2y-y²sin(xy), fₓᵧ=fᵧₓ=2x+cos(xy)-xy sin(xy), fᵧᵧ=-x²sin(xy)。混合偏导相等因为连续。几何：fₓᵧ=x方向坡度随y的变化率，光滑曲面中等于fᵧₓ。

**【D3-4-006】** 用链式法则求 z=e^{xy}sin(x+y) 的 ∂z/∂x 和 ∂z/∂y。

- **难度**：★★
- **对应知识点**：链式法则
- **解答**：
  **解（直接求导）**：
  z=e^{xy}sin(x+y)
  
  ∂z/∂x = ∂/∂x(e^{xy})·sin(x+y) + e^{xy}·∂/∂x[sin(x+y)]
  = y e^{xy} sin(x+y) + e^{xy} cos(x+y)
  = e^{xy}[y sin(x+y) + cos(x+y)]
  
  ∂z/∂y = ∂/∂y(e^{xy})·sin(x+y) + e^{xy}·∂/∂y[sin(x+y)]
  = x e^{xy} sin(x+y) + e^{xy} cos(x+y)
  = e^{xy}[x sin(x+y) + cos(x+y)]
  
  **用链式法则的视角**：
  设 u=xy, v=x+y，则 z=e^u sin v。
  
  ∂z/∂x = (∂z/∂u)(∂u/∂x) + (∂z/∂v)(∂v/∂x)
  = (e^u sin v)·y + (e^u cos v)·1
  = e^{xy}[y sin(x+y) + cos(x+y)] ✓
  
  ∂z/∂y = (∂z/∂u)(∂u/∂y) + (∂z/∂v)(∂v/∂y)
  = (e^u sin v)·x + (e^u cos v)·1
  = e^{xy}[x sin(x+y) + cos(x+y)] ✓
  
  **链式法则的一般形式**：
  如果 z=f(u,v)，u=u(x,y)，v=v(x,y)，则：
  ∂z/∂x = (∂f/∂u)(∂u/∂x) + (∂f/∂v)(∂v/∂x)
  ∂z/∂y = (∂f/∂u)(∂u/∂y) + (∂f/∂v)(∂v/∂y)
  
  口诀："沿线相乘，分线相加"——从 z 到 x 有几条路径，每条路径上的偏导数相乘，不同路径的结果相加。∎
- **一句话点评**：z=e^{xy}sin(x+y)。∂z/∂x=e^{xy}[y sin(x+y)+cos(x+y)]，∂z/∂y=e^{xy}[x sin(x+y)+cos(x+y)]。链式法则：设u=xy,v=x+y，∂z/∂x=(∂z/∂u)(∂u/∂x)+(∂z/∂v)(∂v/∂x)。口诀：沿线相乘，分线相加。

### ★★★ 研究探索

**【D3-4-005】** 讨论函数 f(x,y)=xy/(x²+y²)（(x,y)≠(0,0)，f(0,0)=0）在原点的连续性、偏导数存在性和可微性。

- **难度**：★★
- **对应知识点**：连续、偏导存在、可微的关系
- **解答**：
  **解**：
  f(x,y)=xy/(x²+y²)，f(0,0)=0。
  
  **1. 连续性**：
  考虑沿直线 y=kx 趋近原点：
  lim_{x→0} f(x,kx) = lim x·kx/(x²+k²x²) = lim kx²/[(1+k²)x²] = k/(1+k²)
  
  这个极限值依赖于 k（路径）：
  - k=0（沿 x 轴）：极限=0
  - k=1（沿 y=x）：极限=1/2
  
  因为沿不同路径极限不同，所以 lim_{(x,y)→(0,0)} f(x,y) 不存在。
  因此 f 在原点不连续。∎
  
  **2. 偏导数存在性**：
  fₓ(0,0)=lim_{Δx→0}[f(Δx,0)-f(0,0)]/Δx = lim [0-0]/Δx = 0
  fᵧ(0,0)=lim_{Δy→0}[f(0,Δy)-f(0,0)]/Δy = lim [0-0]/Δy = 0
  
  所以两个偏导数都存在，且都等于 0。∎
  
  **3. 可微性**：
  可微的必要条件是连续。因为 f 在原点不连续，所以 f 在原点不可微。∎
  
  **也可以直接验证**：
  如果可微，则 Δz = fₓ(0,0)Δx+fᵧ(0,0)Δy+o(ρ) = 0+0+o(ρ)=o(ρ)
  即 Δz/ρ→0。
  
  但 Δz/ρ = [ΔxΔy/(Δx²+Δy²)]/√(Δx²+Δy²) = ΔxΔy/(Δx²+Δy²)^(3/2)
  
  沿 Δy=Δx：Δz/ρ = Δx²/(2Δx²)^(3/2) = 1/(2√2|Δx|) → ∞（不是 0）
  
  所以不可微。∎
  
  **这个例子的意义**：
  它说明了一个重要关系：**偏导数存在 ⇏ 连续 ⇏ 可微**。
  这个函数在原点偏导数都存在（都是 0），但不连续，更不可微。
  
  完整的关系图：
  偏导数连续 ⇒ 可微 ⇒ 连续 + 偏导数存在
  但反过来都不成立：
  - 可微 ⇏ 偏导数连续
  - 连续 ⇏ 偏导数存在（如 f=√(x²+y²) 在原点）
  - 偏导数存在 ⇏ 连续（本例）
  - 偏导数存在 ⇏ 可微（本例）∎
- **一句话点评**：f=xy/(x²+y²), f(0,0)=0。①不连续：沿y=kx极限=k/(1+k²)依赖路径②偏导存在：fₓ(0,0)=fᵧ(0,0)=0③不可微（因为不连续）。经典反例：偏导存在⇏连续⇏可微。完整关系：偏导连续⇒可微⇒连续+偏导存在，反过来都不成立。

### 组B：极值与条件极值

**【D3-4-011】** 求函数 f(x,y,z)=x²+y²+z² 在约束 x+y+z=1 下的最小值，并解释几何意义。

- **难度**：★★
- **对应知识点**：拉格朗日乘数法（三元）
- **解答**：
  **解**：
  目标函数 f(x,y,z)=x²+y²+z²，约束 g(x,y,z)=x+y+z-1=0。
  
  **拉格朗日函数**：
  L=x²+y²+z² - λ(x+y+z-1)
  
  Lₓ=2x-λ=0 ⇒ x=λ/2
  Lᵧ=2y-λ=0 ⇒ y=λ/2
  L_z=2z-λ=0 ⇒ z=λ/2
  L_λ=-(x+y+z-1)=0 ⇒ x+y+z=1
  
  所以 x=y=z=λ/2，代入约束：3λ/2=1 ⇒ λ=2/3
  x=y=z=1/3
  
  最小值 f(1/3,1/3,1/3)=3×(1/3)²=1/3。∎
  
  **几何意义**：
  f(x,y,z)=x²+y²+z² 是点 (x,y,z) 到原点的距离的平方。
  约束 x+y+z=1 是一个平面。
  
  所以这个问题是：**求平面 x+y+z=1 上到原点距离最近的点**。
  
  答案是 (1/3,1/3,1/3)，这正是原点到平面的垂足。
  原点到平面的距离 = |0+0+0-1|/√(1+1+1)=1/√3，距离平方=1/3。✓
  
  **拉格朗日乘数法的几何意义（三元）**：
  在极值点，∇f=λ∇g。
  ∇f=(2x,2y,2z) 是球面 x²+y²+z²=c 的法向量（径向）。
  ∇g=(1,1,1) 是平面 x+y+z=1 的法向量。
  
  条件 ∇f=λ∇g 意味着球面的法向量和平面的法向量平行——即球面和平面相切。
  当球面逐渐扩大（c 增大），第一次接触到平面时就是最小值——此时球面相切于平面。∎
  
  **更一般的结论（柯西不等式）**：
  (x²+y²+z²)(1+1+1)≥(x+y+z)²=1
  所以 x²+y²+z²≥1/3，等号当 x=y=z=1/3 时成立。
  拉格朗日乘数法和柯西不等式给出了相同的结果。∎
- **一句话点评**：f=x²+y²+z²在x+y+z=1下最小值=1/3，在(1/3,1/3,1/3)处。几何意义：平面x+y+z=1上到原点距离最近的点=垂足。∇f=λ∇g意味着球面和平面相切。柯西不等式验证：(x²+y²+z²)·3≥(x+y+z)²=1⇒≥1/3。

**【D3-4-007】** 求函数 f(x,y)=x³+y³-3xy 的极值。

- **难度**：★★★
- **对应知识点**：多元函数极值
- **解答**：
  **解**：
  f(x,y)=x³+y³-3xy
  
  **第一步：求驻点**
  fₓ=3x²-3y=3(x²-y)
  fᵧ=3y²-3x=3(y²-x)
  
  令 fₓ=0, fᵧ=0：
  x²=y, y²=x
  
  代入：(x²)²=x ⇒ x⁴=x ⇒ x(x³-1)=0 ⇒ x=0 或 x=1
  
  - x=0 ⇒ y=0，驻点 (0,0)
  - x=1 ⇒ y=1，驻点 (1,1)
  
  **第二步：Hessian 矩阵判别**
  fₓₓ=6x, fₓᵧ=-3, fᵧᵧ=6y
  
  Hessian 矩阵 H = [[6x, -3],[-3, 6y]]
  
  判别式 D = fₓₓfᵧᵧ - (fₓᵧ)² = 36xy - 9
  
  **在 (0,0) 处**：
  D = 0 - 9 = -9 &lt; 0
  所以 (0,0) 是鞍点（不是极值点）。
  
  **在 (1,1) 处**：
  D = 36 - 9 = 27 > 0
  fₓₓ(1,1)=6 > 0
  所以 (1,1) 是极小值点。
  极小值 f(1,1)=1+1-3=-1。∎
  
  **Hessian 判别法总结**：
  设驻点处 D=fₓₓfᵧᵧ-(fₓᵧ)²：
  - D>0 且 fₓₓ>0 ⇒ 极小值
  - D>0 且 fₓₓ&lt;0 ⇒ 极大值
  - D&lt;0 ⇒ 鞍点
  - D=0 ⇒ 无法判断（需要更高阶信息）
  
  **几何理解**：
  - 极小值点：曲面在该点附近像一个"碗"（向上凹）
  - 极大值点：曲面在该点附近像一个"丘"（向下凸）
  - 鞍点：曲面在该点附近像一个"马鞍"——一个方向向上，一个方向向下
  
  (0,0) 是鞍点：沿 y=x 方向 f(x,x)=2x³-3x²，在 x=0 附近，x>0 时 f&lt;0，x&lt;0 时 f>0——一个方向上升一个方向下降。∎
- **一句话点评**：f=x³+y³-3xy。驻点：(0,0)和(1,1)。Hessian判别D=36xy-9。(0,0)：D=-9&lt;0⇒鞍点。(1,1)：D=27>0,fₓₓ=6>0⇒极小值f(1,1)=-1。判别法：D>0且fₓₓ>0⇒极小，D>0且fₓₓ&lt;0⇒极大，D&lt;0⇒鞍点，D=0⇒不定。

**【D3-4-008】** 用拉格朗日乘数法求 f(x,y)=xy 在约束 x²+y²=1 下的极值。

- **难度**：★★★
- **对应知识点**：拉格朗日乘数法
- **解答**：
  **解**：
  目标函数 f(x,y)=xy，约束 g(x,y)=x²+y²-1=0。
  
  **拉格朗日函数**：
  L(x,y,λ)=xy - λ(x²+y²-1)
  
  **求偏导并令其为零**：
  Lₓ = y - 2λx = 0 ⇒ y = 2λx ...(1)
  Lᵧ = x - 2λy = 0 ⇒ x = 2λy ...(2)
  L_λ = -(x²+y²-1) = 0 ⇒ x²+y²=1 ...(3)
  
  **求解**：
  由 (1)(2)：y=2λx, x=2λy=2λ(2λx)=4λ²x
  如果 x≠0，则 4λ²=1 ⇒ λ=±1/2
  
  - λ=1/2：y=x，代入 (3)：2x²=1 ⇒ x=±1/√2
    点 (1/√2,1/√2) 和 (-1/√2,-1/√2)
    f=xy=1/2（极大值）
  
  - λ=-1/2：y=-x，代入 (3)：2x²=1 ⇒ x=±1/√2
    点 (1/√2,-1/√2) 和 (-1/√2,1/√2)
    f=xy=-1/2（极小值）
  
  如果 x=0，则由 (1) y=0，但不满足 (3)，舍去。
  
  **结论**：
  极大值 1/2，在 (±1/√2, ±1/√2) 处取得（同号）
  极小值 -1/2，在 (±1/√2, ∓1/√2) 处取得（异号）∎
  
  **拉格朗日乘数法的几何意义**：
  在极值点，目标函数的梯度 ∇f 和约束的梯度 ∇g 平行：
  ∇f = λ∇g
  
  几何上：f 的等值线和约束曲线 g=0 在极值点相切。
  因为如果不相切，沿着约束曲线移动还能让 f 增大或减小，就不是极值点。
  
  本例中：∇f=(y,x), ∇g=(2x,2y)，条件 (y,x)=λ(2x,2y) 就是等值线 xy=c 和圆 x²+y²=1 相切的条件。∎
  
  **验证（参数化方法）**：
  令 x=cos θ, y=sin θ，则 f=cos θ sin θ=sin(2θ)/2。
  最大值 1/2（2θ=π/2），最小值 -1/2（2θ=3π/2）。和拉格朗日乘数法结果一致。∎
- **一句话点评**：f=xy在x²+y²=1下的极值。拉格朗日函数L=xy-λ(x²+y²-1)。解得λ=±1/2。极大值1/2在(±1/√2,±1/√2)，极小值-1/2在(±1/√2,∓1/√2)。几何意义：极值点∇f=λ∇g，即f的等值线和约束曲线相切。参数化验证：f=sin(2θ)/2。

**【D3-4-012】** 写出二元函数 f(x,y) 在点 (x₀,y₀) 处的二阶泰勒公式，并解释 Hessian 矩阵在其中的作用。

- **难度**：★★
- **对应知识点**：多元泰勒公式
- **解答**：
  **二元函数的二阶泰勒公式**：
  f(x₀+h,y₀+k) = f(x₀,y₀) + (h∂/∂x + k∂/∂y)f(x₀,y₀) + (1/2!)(h∂/∂x + k∂/∂y)²f(x₀,y₀) + o(ρ²)
  
  展开写：
  f(x₀+h,y₀+k) = f(x₀,y₀) + fₓ(x₀,y₀)h + fᵧ(x₀,y₀)k
  + (1/2)[fₓₓ(x₀,y₀)h² + 2fₓᵧ(x₀,y₀)hk + fᵧᵧ(x₀,y₀)k²] + o(ρ²)
  
  其中 ρ=√(h²+k²)。
  
  **Hessian 矩阵形式**：
  设 ∇f=(fₓ,fᵧ) 为梯度（行向量），H=[[fₓₓ,fₓᵧ],[fₓᵧ,fᵧᵧ]] 为 Hessian 矩阵，Δx=(h,k)^T 为增量向量。
  
  泰勒公式可以写为：
  f(x₀+Δx) = f(x₀) + ∇f·Δx + (1/2)Δx^T H Δx + o(||Δx||²)
  
  **Hessian 矩阵的作用**：
  
  1. **描述曲面的局部弯曲**：
     一阶项 ∇f·Δx 是线性部分（切平面），二阶项 (1/2)Δx^T H Δx 描述了曲面相对于切平面的"弯曲"。
     H 正定⇒曲面向上弯（碗状），H 负定⇒曲面向下弯（丘状），H 不定⇒鞍状。
  
  2. **极值判别**：
     在驻点（∇f=0）处，泰勒公式简化为 f(x₀+Δx)=f(x₀)+(1/2)Δx^T H Δx+o(||Δx||²)。
     - H 正定⇒Δx^T H Δx>0⇒f(x₀+Δx)>f(x₀)⇒极小值
     - H 负定⇒极大值
     - H 不定⇒鞍点
     这就是 Hessian 判别法的理论基础。
  
  3. **和一元的对比**：
     一元：f(x₀+h)=f(x₀)+f'(x₀)h+(1/2)f''(x₀)h²+o(h²)
     多元：f(x₀+Δx)=f(x₀)+∇f·Δx+(1/2)Δx^T H Δx+o(||Δx||²)
     一元的 f''（一个数）对应多元的 H（一个矩阵）——这是维度跃迁的体现。∎
- **一句话点评**：二元二阶泰勒公式：f(x₀+h,y₀+k)=f₀+fₓh+fᵧk+(1/2)(fₓₓh²+2fₓᵧhk+fᵧᵧk²)+o(ρ²)。Hessian矩阵形式：f=f₀+∇f·Δx+(1/2)Δx^T H Δx+o(||Δx||²)。H的作用：①描述曲面弯曲②极值判别（正定⇒极小，负定⇒极大，不定⇒鞍点）③一元f''对应多元H矩阵。

**【D3-4-013】** 隐函数定理：设 F(x,y)=0 在点 (x₀,y₀) 附近确定了隐函数 y=f(x)，需要什么条件？求导公式是什么？

- **难度**：★★
- **对应知识点**：隐函数定理
- **解答**：
  **隐函数定理（一元隐函数）**：
  设 F(x,y) 满足：
  1. F 在点 (x₀,y₀) 的某邻域内具有连续偏导数
  2. F(x₀,y₀)=0
  3. Fᵧ(x₀,y₀)≠0
  
  则在 x₀ 的某邻域内，方程 F(x,y)=0 唯一确定了一个具有连续导数的函数 y=f(x)，满足 y₀=f(x₀)，且：
  dy/dx = -Fₓ/Fᵧ
  
  **求导公式的推导**：
  对 F(x,f(x))=0 两边关于 x 求导（链式法则）：
  Fₓ + Fᵧ·dy/dx = 0
  所以 dy/dx = -Fₓ/Fᵧ。∎
  
  **为什么需要 Fᵧ≠0**：
  Fᵧ≠0 保证了可以"解出 y"——由隐函数存在定理。
  几何上，Fᵧ≠0 意味着曲线 F(x,y)=0 在该点的切线不是垂直的（切线斜率有限），所以可以局部表示为 y=f(x)。
  
  如果 Fᵧ=0 但 Fₓ≠0，则可以表示为 x=g(y)，此时 dx/dy=-Fᵧ/Fₓ=0。
  
  **例子**：
  F(x,y)=x²+y²-1=0（单位圆），在点 (0,1) 处：
  Fₓ=2x=0, Fᵧ=2y=2≠0
  所以可以确定 y=f(x)=√(1-x²)（上半圆）
  dy/dx=-Fₓ/Fᵧ=-2x/(2y)=-x/y
  
  在点 (1,0) 处：
  Fₓ=2≠0, Fᵧ=0
  不能确定 y=f(x)（因为在 (1,0) 附近一个 x 对应两个 y），但可以确定 x=g(y)=√(1-y²)。∎
  
  **多元隐函数组**：
  对于方程组 F(x,y,u,v)=0, G(x,y,u,v)=0，隐函数定理的条件是雅可比行列式 ∂(F,G)/∂(u,v)≠0，此时可以解出 u=u(x,y), v=v(x,y)。∎
- **一句话点评**：隐函数定理条件：①F有连续偏导②F(x₀,y₀)=0③Fᵧ(x₀,y₀)≠0。结论：唯一确定y=f(x)，dy/dx=-Fₓ/Fᵧ。Fᵧ≠0保证切线不垂直⇒可局部表示为y=f(x)。例子：单位圆x²+y²=1在(0,1)处Fᵧ=2≠0⇒y=√(1-x²)，dy/dx=-x/y。多元隐函数组需要雅可比行列式≠0。

**【D3-4-015】** 反函数定理：设向量值函数 f:ℝⁿ→ℝⁿ 在点 x₀ 处可微，且雅可比矩阵 J_f(x₀) 可逆，则 f 在 x₀ 附近是局部可逆的，且反函数的导数为 J_{f⁻¹}(f(x₀))=[J_f(x₀)]⁻¹。解释这个定理的意义。

- **难度**：★★★
- **对应知识点**：反函数定理
- **解答**：
  **反函数定理的陈述**：
  设 f:U→ℝⁿ 是 C¹ 映射（U⊂ℝⁿ 开集），x₀∈U。如果雅可比矩阵 J_f(x₀) 可逆（即行列式 det J_f(x₀)≠0），则：
  1. 存在 x₀ 的邻域 V 和 f(x₀) 的邻域 W，使得 f:V→W 是双射
  2. 反函数 f⁻¹:W→V 是 C¹ 的
  3. J_{f⁻¹}(f(x₀)) = [J_f(x₀)]⁻¹
  
  **和一元反函数定理的对比**：
  一元：如果 f'(x₀)≠0，则 f 在 x₀ 附近局部可逆，且 (f⁻¹)'(f(x₀))=1/f'(x₀)。
  多元：如果 det J_f(x₀)≠0，则 f 在 x₀ 附近局部可逆，且 J_{f⁻¹}=[J_f]⁻¹。
  一元的"导数非零"对应多元的"雅可比行列式非零"，一元的"倒数"对应多元的"逆矩阵"。∎
  
  **几何意义**：
  雅可比矩阵 J_f(x₀) 是 f 在 x₀ 处的"最佳线性逼近"（微分）。
  如果 J_f 可逆，则这个线性映射是 ℝⁿ 到 ℝⁿ 的同构（一一对应且保持线性结构）。
  反函数定理说：如果最佳线性逼近是可逆的，那么函数本身在局部也是可逆的。
  
  这是"线性化原理"的体现——如果线性化版本有好的性质（可逆），那么原函数在局部也有好的性质（局部可逆）。
  
  **雅可比行列式的几何意义**：
  |det J_f(x₀)| 是 f 在 x₀ 处的"体积放大率"——小立方体经过 f 映射后变成平行六面体，体积放大了 |det J_f| 倍。
  det J_f≠0 意味着体积不被压缩到零（映射不退化），所以局部可逆。
  
  **例子（极坐标变换）**：
  f(r,θ)=(r cos θ, r sin θ)，J_f=[[cos θ, -r sin θ],[sin θ, r cos θ]]，det J_f=r。
  在 r≠0 处，det J_f≠0，所以极坐标变换在 r>0 处局部可逆（直角坐标↔极坐标）。
  在 r=0 处，det J_f=0，不可逆（原点对应所有 θ，不是一一对应）。∎
  
  **重要性**：
  反函数定理是微分几何、拓扑学、PDE 中的基本工具。它告诉我们：雅可比行列式非零是局部坐标变换的条件——可以在局部建立新的坐标系。
- **一句话点评**：反函数定理：f是C¹映射，det J_f(x₀)≠0⇒f在x₀附近局部可逆，且J_{f⁻¹}=[J_f]⁻¹。一元对应：f'≠0⇒局部可逆，(f⁻¹)'=1/f'。几何：J_f可逆⇒最佳线性逼近是同构⇒函数本身局部可逆。|det J_f|=体积放大率。例子：极坐标变换det J=r，r≠0时可逆。

## L2 复变函数层

> **引导语**：复变函数视角，展示复分析方法的强大。

**【D3-4-016】** 复变函数 f(z)=u(x,y)+iv(x,y) 可导（解析）的条件是什么？这和多元函数的可微有什么关系？

- **难度**：★★
- **对应知识点**：C-R 方程与可微性
- **解答**：
  **复可导的条件（Cauchy-Riemann 方程）**：
  f(z)=u(x,y)+iv(x,y) 在 z₀=x₀+iy₀ 处可导，当且仅当：
  1. u 和 v 在 (x₀,y₀) 处可微（作为二元实函数）
  2. 满足 Cauchy-Riemann 方程：uₓ=vᵧ, uᵧ=-vₓ
  
  **和多元函数可微的关系**：
  
  | 概念 | 条件 | 强度 |
  |------|------|------|
  | 二元实函数可微 | 全增量=AΔx+BΔy+o(ρ) | 较弱 |
  | 复函数可导（解析） | 实部虚部都可微 + C-R 方程 | 强得多 |
  
  复可导 = 两个二元实函数可微 + 额外的 C-R 约束。
  C-R 方程是复可导特有的条件——它要求 u 和 v 的偏导数满足特定关系，这在实函数可微中没有对应物。
  
  **为什么需要 C-R 方程**：
  复导数 f'(z₀)=lim_{Δz→0}[f(z₀+Δz)-f(z₀)]/Δz 要求 Δz 沿**任意方向**趋近 0 时极限相同。
  
  沿实轴方向（Δz=Δx）：f'=uₓ+ivₓ
  沿虚轴方向（Δz=iΔy）：f'=vᵧ-iuᵧ
  
  两者相等 ⇒ uₓ=vᵧ 且 vₓ=-uᵧ，这就是 C-R 方程。∎
  
  **几何意义（共形映射）**：
  C-R 方程保证了解析函数的导数是一个"相似变换"——同时旋转和缩放，但不改变角度（共形性）。
  具体来说，f'(z₀)=a+ib 对应的线性变换是矩阵 [[a,-b],[b,a]]，这是旋转+缩放，保持角度不变。
  
  如果没有 C-R 方程（只是两个实函数可微），雅可比矩阵是一般的 [[uₓ,uᵧ],[vₓ,vᵧ]]，可以是任意线性变换（包括拉伸、剪切），不一定保持角度。∎
  
  **极坐标形式的 C-R 方程**：
  uᵣ=(1/r)v_θ, vᵣ=-(1/r)u_θ
  这在处理极坐标下的解析函数时很方便。
- **一句话点评**：复可导条件：①u,v都可微②C-R方程uₓ=vᵧ,uᵧ=-vₓ。比二元实函数可微强得多——额外要求C-R方程。原因：复导数要求沿任意方向极限相同，沿实轴得uₓ+ivₓ，沿虚轴得vᵧ-iuᵧ，相等⇒C-R。几何：C-R保证导数是旋转+缩放（共形映射），保持角度。极坐标形式：uᵣ=(1/r)v_θ。

**【D3-4-017】** 用 C-R 方程验证 f(z)=z²=x²-y²+2ixy 是解析函数，并求其导数。

- **难度**：★★
- **对应知识点**：C-R 方程验证
- **解答**：
  **解**：
  f(z)=z²=(x+iy)²=x²-y²+2ixy
  所以 u(x,y)=x²-y², v(x,y)=2xy。
  
  **偏导数**：
  uₓ=2x, uᵧ=-2y
  vₓ=2y, vᵧ=2x
  
  **验证 C-R 方程**：
  uₓ=2x=vᵧ ✓
  uᵧ=-2y=-vₓ ✓（因为 vₓ=2y，所以 -vₓ=-2y=uᵧ）
  
  u 和 v 都是多项式，在全平面上可微。
  所以 f(z)=z² 在全平面上解析。∎
  
  **求导数**：
  f'(z)=uₓ+ivₓ=2x+i·2y=2(x+iy)=2z
  
  也可以用 f'(z)=vᵧ-iuᵧ=2x-i(-2y)=2x+2iy=2z。✓
  
  **几何意义**：
  f(z)=z² 将复平面映射为：
  - 模长：|z²|=|z|²（模长平方）
  - 辐角：arg(z²)=2arg(z)（辐角加倍）
  
  这是一个"平方映射"——将角度加倍，半径平方。
  在 z₀ 处，导数 f'(z₀)=2z₀，对应的线性变换是旋转 arg(2z₀) + 缩放 |2z₀|。
  
  **验证共形性**：
  在 z₀≠0 处，f'(z₀)≠0，所以映射是共形的（保持角度）。
  在 z₀=0 处，f'(0)=0，共形性失效——角度被加倍（不是保持）。
  例如，实轴（角度 0）和虚轴（角度 π/2）在 0 处的夹角是 π/2，映射后分别变成正实轴（角度 0）和负实轴（角度 π），夹角变成 π——角度被加倍了。∎
- **一句话点评**：f(z)=z²，u=x²-y²,v=2xy。uₓ=2x=vᵧ, uᵧ=-2y=-vₓ⇒C-R满足，全平面解析。f'(z)=2x+2iy=2z。几何：模长平方，辐角加倍。z₀≠0时共形（f'≠0），z=0处共形性失效（角度加倍）。

### ★★★ 研究探索

**【D3-4-018】** 解析函数的实部和虚部都是调和函数（满足拉普拉斯方程），反过来，给定一个调和函数 u，能否找到 v 使得 u+iv 解析？这就是共轭调和函数的问题。

- **难度**：★★★
- **对应知识点**：调和函数与共轭调和
- **解答**：
  **调和函数的定义**：
  如果二元函数 u(x,y) 满足拉普拉斯方程 uₓₓ+uᵧᵧ=0，则称 u 为调和函数。
  
  **解析函数的实部虚部都是调和函数**：
  设 f=u+iv 解析，则 C-R 方程 uₓ=vᵧ, uᵧ=-vₓ 成立。
  uₓₓ=(vᵧ)ₓ=vᵧₓ
  uᵧᵧ=(-vₓ)ᵧ=-vₓᵧ
  如果混合偏导连续，则 vᵧₓ=vₓᵧ，所以 uₓₓ+uᵧᵧ=vᵧₓ-vₓᵧ=0。
  所以 u 调和。同理 v 调和。∎
  
  **共轭调和函数**：
  给定调和函数 u，能否找到 v 使得 u+iv 解析？
  由 C-R 方程，v 需要满足 vᵧ=uₓ, vₓ=-uᵧ。
  
  这是一个偏微分方程组，可以通过线积分求解：
  v(x,y) = ∫_{(x₀,y₀)}^{(x,y)} (-uᵧ)dx + uₓ dy + C
  
  这个线积分与路径无关的条件是 ∂/∂y(-uᵧ)=∂/∂x(uₓ)，即 -uᵧᵧ=uₓₓ，即 uₓₓ+uᵧᵧ=0——正是 u 调和的条件！
  
  所以：**u 调和 ⟺ 存在（局部）共轭调和函数 v**。∎
  
  **例子**：
  给定 u(x,y)=x²-y²（调和函数，因为 uₓₓ=2, uᵧᵧ=-2, 和=0）。
  求 v：
  vᵧ=uₓ=2x ⇒ v=2xy+φ(x)
  vₓ=2y+φ'(x)=-uᵧ=2y ⇒ φ'(x)=0 ⇒ φ(x)=C
  所以 v=2xy+C，f=u+iv=x²-y²+i(2xy+C)=z²+iC。∎
  
  **几何意义**：
  调和函数的等值线 u=c 和 v=c 是正交的（因为 ∇u·∇v=uₓvₓ+uᵧvᵧ=uₓ(-uᵧ)+uᵧuₓ=0）。
  这两组正交曲线构成了一个"正交曲线网格"——解析函数将这个网格映射为另一个正交网格（共形性）。
  
  **物理意义**：
  调和函数描述了许多物理现象：静电势、稳态温度、不可压缩流体的速度势。
  共轭调和函数 v 对应的是"流函数"——u=电势，v=通量函数，它们一起描述了二维静电场或流体场。∎
- **一句话点评**：调和函数满足uₓₓ+uᵧᵧ=0。解析函数的实部虚部都调和（由C-R方程推出）。共轭调和：给定调和u，存在v使u+iv解析，v=∫(-uᵧ)dx+uₓdy+C，路径无关性等价于u调和。例子：u=x²-y²⇒v=2xy+C⇒f=z²+iC。几何：u=c和v=c等值线正交。物理：u=电势，v=流函数。

## L3 实变函数层

> **引导语**：实变函数视角，拓展概念的适用范围。

**【D3-4-019】** 实变函数中，多元函数的可微性有什么推广？什么是弱导数和 Sobolev 空间（多元版本）？

- **难度**：★★
- **对应知识点**：多元弱导数与 Sobolev 空间
- **解答**：
  **多元弱导数的定义**：
  对于 f∈L¹_loc(Ω)（Ω⊂ℝⁿ），如果存在 g∈L¹_loc(Ω) 使得对所有光滑紧支撑函数 φ∈C_c^∞(Ω)：
  ∫_Ω f·∂φ/∂xᵢ dx = -∫_Ω g·φ dx
  则称 g 是 f 对 xᵢ 的弱导数，记为 g=∂f/∂xᵢ（弱意义下）。
  
  **多元 Sobolev 空间**：
  W^{k,p}(Ω) = {f∈L^p(Ω) : 所有 |α|≤k 阶弱导数 D^α f∈L^p(Ω)}
  
  其中 α=(α₁,...,αₙ) 是多重指标，|α|=α₁+...+αₙ，D^α=∂^|α|/(∂x₁^α₁...∂xₙ^αₙ)。
  
  **和一元的区别**：
  - 一元：只有一个方向的导数，弱导数是一个函数
  - 多元：有 n 个方向的偏导数，弱梯度 ∇f=(∂f/∂x₁,...,∂f/∂xₙ) 是一个向量值函数
  - 高阶导数：多元有混合偏导数（如 ∂²f/∂x∂y），需要用多重指标来索引
  
  **Sobolev 嵌入定理（多元版本更丰富）**：
  多元 Sobolev 嵌入定理依赖于空间维数 n：
  - W^{1,p}(ℝⁿ) ⊂ L^q(ℝⁿ)，其中 1/q=1/p-1/n（当 p&lt;n 时）
  - W^{k,p}(ℝⁿ) ⊂ C^m(ℝⁿ)，当 k-m>n/p 时（Morrey 不等式）
  
  空间维数 n 出现在嵌入条件中——这是多元特有的现象。
  一元（n=1）是多元的特例。∎
  
  **例子**：
  f(x,y)=√(x²+y²)=r（距离函数）在 ℝ² 上：
  - 经典偏导数在原点不存在
  - 弱梯度 ∇f=(x/r, y/r)（单位径向向量），在 a.e. 意义下存在
  - f∈W^{1,p}(ℝ²) 对所有 p≥1（因为 |∇f|=1 有界）
  - 但 f∉W^{2,p}（二阶弱导数涉及 δ 函数）∎
  
  **为什么多元 Sobolev 空间重要**：
  PDE（偏微分方程）的解往往不是经典可导的，但可以是 Sobolev 空间中的弱解。
  多元 Sobolev 空间为研究 PDE 弱解提供了合适的框架。
  例如，拉普拉斯方程 Δu=0 的弱解 u∈W^{1,2}，然后用正则性理论证明它实际上是光滑的。∎
- **一句话点评**：多元弱导数：∫f·∂φ/∂xᵢ=-∫g·φ对所有φ成立。Sobolev空间W^{k,p}：所有|α|≤k阶弱导数D^αf∈L^p。多元特点：弱梯度是向量值函数，有混合偏导，嵌入定理依赖空间维数n（1/q=1/p-1/n）。例子：r=√(x²+y²)∈W^{1,p}但∉W^{2,p}。是PDE弱解的框架。

**【D3-4-020】** 什么是 Rademacher 定理？它在多元函数微分学中有什么意义？

- **难度**：★★
- **对应知识点**：Rademacher 定理
- **解答**：
  **Rademacher 定理**：
  ℝⁿ 上的 Lipschitz 函数几乎处处可微。
  
  即：如果 f:ℝⁿ→ℝ 满足 |f(x)-f(y)|≤L|x-y| 对所有 x,y（Lipschitz 条件），则 f 在 ℝⁿ 上几乎处处可微（经典意义下的全微分存在 a.e.）。
  
  **和一元的关系**：
  一元版本：Lipschitz 函数几乎处处可导（这是 Lebesgue 定理的推论——单调函数 a.e. 可导，而 Lipschitz 函数可以表示为两个单调函数之差）。
  多元版本（Rademacher 定理）是一元版本的高维推广，但证明更困难——需要处理"所有方向"的可微性。
  
  **为什么重要**：
  
  1. **Lipschitz 函数是"好函数"**：
     Lipschitz 条件比连续强，比 C¹ 弱。它描述了"变化率有界"的函数。
     Rademacher 定理说：这样的函数虽然可能有尖点（不可导点），但尖点的测度为零——几乎处处都是光滑的。
  
  2. **几何测度论的基础**：
     Rademacher 定理是几何测度论中的基本定理——它保证了 Lipschitz 映射的微分 a.e. 存在，从而可以定义"面积公式"和"余面积公式"。
  
  3. **和 Sobolev 空间的关系**：
     Lipschitz 函数 ⊂ W^{1,∞}（弱导数本质有界）。
     Rademacher 定理说 W^{1,∞} 中的函数 a.e. 经典可微，且经典导数等于弱导数。
     这是 Sobolev 函数正则性的一个特例。
  
  4. **凸函数的推广**：
     Alexandrov 定理：凸函数几乎处处二阶可导。
     Rademacher 定理（Lipschitz 函数 a.e. 一阶可导）和 Alexandrov 定理（凸函数 a.e. 二阶可导）是实变函数中关于"非光滑函数可微性"的两个基本定理。∎
  
  **例子**：
  f(x,y)=|x|+|y|（Lipschitz 函数，L=2）：
  - 在坐标轴上（x=0 或 y=0）不可导
  - 坐标轴的测度为零
  - 在其他点，fₓ=±1, fᵧ=±1，可微
  - 所以 f a.e. 可微，符合 Rademacher 定理。∎
  
  **注意**：
  Rademacher 定理只保证 a.e. 可微，不保证导数连续。
  Lipschitz 函数的导数是 L^∞ 函数（本质有界），但可能不连续。
- **一句话点评**：Rademacher定理：ℝⁿ上的Lipschitz函数几乎处处可微。是一元Lebesgue定理的高维推广。意义：①Lipschitz函数虽有尖点但a.e.光滑②几何测度论基础（面积公式/余面积公式）③Lipschitz⊂W^{1,∞}，a.e.经典可微④和Alexandrov定理（凸函数a.e.二阶可导）并列。例子：|x|+|y|在坐标轴上不可导（测度零），其他点可微。

### ★★★ 研究探索

**【D3-4-021】** 多元函数的变量替换公式（积分的几何意义）：雅可比行列式在积分变量替换中起什么作用？

- **难度**：★★★
- **对应知识点**：雅可比行列式与积分变换
- **解答**：
  **积分变量替换公式**：
  设 Φ:U→V 是 C¹ 微分同胚（一一对应、可逆、连续可微），则：
  ∫_V f(y)dy = ∫_U f(Φ(x))·|det J_Φ(x)| dx
  
  其中 J_Φ 是 Φ 的雅可比矩阵，det J_Φ 是雅可比行列式。
  
  **雅可比行列式的作用**：
  |det J_Φ(x)| 是 Φ 在 x 处的**体积放大率**。
  
  具体来说，取 x 处的一个小立方体，边长为 h，体积为 hⁿ。
  经过 Φ 映射后，这个小立方体变成一个小平行六面体，其体积近似为 |det J_Φ(x)|·hⁿ。
  
  所以在积分变量替换时，需要乘以 |det J_Φ| 来补偿体积的变化——映射后的"体积元"和原来的体积元差了一个雅可比行列式的因子。∎
  
  **经典例子（极坐标）**：
  Φ(r,θ)=(r cos θ, r sin θ)，J_Φ=[[cos θ,-r sin θ],[sin θ,r cos θ]]，det J_Φ=r。
  ∫∫ f(x,y)dxdy = ∫∫ f(r cos θ,r sin θ)·r dr dθ
  
  这里 r 就是面积放大率——在极坐标中，小区域的面积是 r dr dθ（不是 dr dθ），因为越往外，同样的 dr dθ 对应的面积越大。
  
  **球坐标（三维）**：
  Φ(r,θ,φ)=(r sin φ cos θ, r sin φ sin θ, r cos φ)
  det J_Φ=r² sin φ
  ∫∫∫ f dxdydz = ∫∫∫ f·r² sin φ dr dθ dφ
  
  **几何理解**：
  雅可比行列式是"局部体积变化率"——它告诉我们映射在每一点把体积放大（或缩小）了多少倍。
  - det J>0：保持定向（右手系→右手系）
  - det J&lt;0：反转定向（右手系→左手系）
  - |det J|>1：体积放大
  - |det J|&lt;1：体积缩小
  - det J=0：体积压缩到零（映射退化，不可逆）
  
  **和微分的关系**：
  全微分 df=∇f·dx 是函数的"最佳线性逼近"。
  雅可比矩阵 J_Φ 是向量值函数 Φ 的"最佳线性逼近"（微分）。
  雅可比行列式 det J_Φ 是这个线性映射的"体积放大率"——行列式的几何意义就是线性变换的体积放大率。∎
  
  **在实变函数中的推广**：
  变量替换公式可以推广到 Lebesgue 积分和更一般的映射（Lipschitz 映射，不需要 C¹）。
  此时 Rademacher 定理保证了 a.e. 可微，面积公式给出了积分变换的一般形式。
- **一句话点评**：变量替换公式：∫_V f(y)dy=∫_U f(Φ(x))|det J_Φ(x)|dx。|det J_Φ|=体积放大率——小立方体经映射后变平行六面体，体积放大|det J|倍。极坐标：det J=r⇒面积元r drdθ。球坐标：det J=r²sinφ。几何：det J>0保定向，&lt;0反定向，=0退化。是全微分（最佳线性逼近）的行列式=体积放大率。

## 补充基础题（L1 数学分析 / L2 复变函数 / L3 实变函数）

> **引导语**：针对三个阶段补充基础题。

**【D3-4-031】** 设 $F(x,y,z)=x^2+y^2+z^2-4=0$ 在点 $(1,1,\sqrt{2})$ 附近确定了隐函数 $z=f(x,y)$。用隐函数定理求 $\frac{\partial z}{\partial x}$ 和 $\frac{\partial z}{\partial y}$ 在该点的值。

- **难度**：★★
- **对应知识点**：隐函数定理、隐函数求导
- **解答**：
  $F_x=2x=2$，$F_y=2y=2$，$F_z=2z=2\sqrt{2}\neq 0$，满足隐函数定理条件。
  $\frac{\partial z}{\partial x}=-\frac{F_x}{F_z}=-\frac{2}{2\sqrt{2}}=-\frac{1}{\sqrt{2}}$。
  $\frac{\partial z}{\partial y}=-\frac{F_y}{F_z}=-\frac{1}{\sqrt{2}}$。∎
- **一句话点评**：隐函数定理把"解方程"变成"求偏导"，关键条件是 $F_z\neq 0$。

**【D3-4-032】** 用 Wirtinger 导数证明：$f(z)=\bar{z}=x-iy$ 不满足 Cauchy-Riemann 方程，因此处处不可导。

- **难度**：★★
- **对应知识点**：Wirtinger 导数、Cauchy-Riemann 方程
- **解答**：
  Wirtinger 导数：$\frac{\partial}{\partial \bar{z}}=\frac{1}{2}(\frac{\partial}{\partial x}+i\frac{\partial}{\partial y})$。
  对 $f=\bar{z}=x-iy$：$\frac{\partial f}{\partial x}=1$，$\frac{\partial f}{\partial y}=-i$。
  $\frac{\partial f}{\partial \bar{z}}=\frac{1}{2}(1+i(-i))=\frac{1}{2}(1+1)=1\neq 0$。
  解析函数要求 $\frac{\partial f}{\partial \bar{z}}=0$，故 $\bar{z}$ 处处不可导。∎
- **一句话点评**：Wirtinger 导数把 CR 方程写成简洁的 $\partial f/\partial\bar{z}=0$，是复分析的标准工具。

**【D3-4-033】** 定义 Wirtinger 导数：$\frac{\partial}{\partial z}=\frac{1}{2}(\frac{\partial}{\partial x}-i\frac{\partial}{\partial y})$，$\frac{\partial}{\partial\bar{z}}=\frac{1}{2}(\frac{\partial}{\partial x}+i\frac{\partial}{\partial y})$。证明 C-R 方程等价于 $\frac{\partial f}{\partial\bar{z}}=0$。

- **难度**：★★
- **解答**：$\frac{\partial f}{\partial\bar{z}}=\frac{1}{2}(\frac{\partial}{\partial x}+i\frac{\partial}{\partial y})(u+iv)=\frac{1}{2}[(u_x-v_y)+i(v_x+u_y)]$。
$\frac{\partial f}{\partial\bar{z}}=0$ ⟺ $u_x-v_y=0$ 且 $v_x+u_y=0$ ⟺ $u_x=v_y$ 且 $u_y=-v_x$（C-R）。∎
- **点评**：Wirtinger 导数是复分析的有力工具——C-R 方程被简洁地表达为 $\partial f/\partial\bar{z}=0$，即"解析函数与 $\bar{z}$ 无关"。

**【D3-4-034】** 证明：若 $f$ 在区域 $D$ 内解析，则 $|f|^2$ 的 Laplacian 为 $\Delta|f|^2=4|f'|^2$。

- **难度**：★★
- **解答**：$|f|^2=f\bar{f}$。用 Wirtinger 导数：$\Delta=4\frac{\partial^2}{\partial z\partial\bar{z}}$。
$\frac{\partial}{\partial\bar{z}}(f\bar{f})=f\frac{\partial\bar{f}}{\partial\bar{z}}=f\overline{f'}$（因为 $\partial f/\partial\bar{z}=0$）。
$\frac{\partial}{\partial z}(f\overline{f'})=f'\overline{f'}=|f'|^2$。
故 $\Delta|f|^2=4|f'|^2$。∎
- **点评**：这是一个重要公式——$|f|^2$ 是次调和函数（$\Delta|f|^2\geq0$），是最大模原理的另一种证明途径。

### L3 实变函数基础

**【D3-4-035】** 定义弱偏导数：若 $f,g_i\in L^1_{\text{loc}}$ 且 $\int f\frac{\partial\varphi}{\partial x_i}=-\int g_i\varphi$ 对所有 $\varphi\in C_c^\infty$ 成立，则 $g_i$ 是 $f$ 关于 $x_i$ 的弱偏导数。证明 $f(x,y)=|x|+|y|$ 的弱偏导数为 $\text{sgn}(x)+\text{sgn}(y)$（分别）。

- **难度**：★★
- **解答**：对 $\frac{\partial}{\partial x}$：$\int |x|\varphi_x dxdy=\int\left(\int |x|\varphi_x dx\right)dy=\int(-\int\text{sgn}(x)\varphi dx)dy=-\int\text{sgn}(x)\varphi dxdy$。
故 $\frac{\partial f}{\partial x}=\text{sgn}(x)$（弱导数）。同理 $\frac{\partial f}{\partial y}=\text{sgn}(y)$。∎
- **点评**：多元弱偏导数 = 对每个变量分别做一元弱导数——Fubini 定理将多元问题化为一元问题。

**【D3-4-036】** 证明：$f(x,y)=\sqrt{x^2+y^2}$ 在 $\mathbb{R}^2$ 上是 Lipschitz 函数，并说明它在原点不可导但几乎处处可导。

- **难度**：★★
- **对应知识点**：Lipschitz 函数、Rademacher 定理
- **解答**：
  由三角不等式，$|f(p)-f(q)|=||p|-|q||\leq|p-q|$，故 Lipschitz 常数为 1。
  在原点，沿 x 轴方向导数为 1，沿 y 轴方向导数为 1，但梯度不存在（方向导数不一致），故不可导。
  除原点外，$f$ 光滑可导，不可导点集测度为 0，故几乎处处可导。∎
- **一句话点评**：距离函数是 Lipschitz 但不可导的典型例子，Rademacher 定理保证了它几乎处处可导。

**【D3-4-037】** 举例说明：$f(x)=|x|$ 的弱导数为 $g(x)=\text{sgn}(x)$（$x\neq 0$ 时），并验证弱导数的定义。

- **难度**：★★
- **对应知识点**：弱导数、Sobolev 空间
- **解答**：
  对任意测试函数 $\varphi\in C_c^\infty(\mathbb{R})$：
  $\int_{-\infty}^{\infty}|x|\varphi'(x)dx=\int_0^\infty x\varphi'(x)dx+\int_{-\infty}^0(-x)\varphi'(x)dx$
  $=[x\varphi]_0^\infty-\int_0^\infty\varphi dx+[-x\varphi]_{-\infty}^0+\int_{-\infty}^0\varphi dx$
  $=-\int_0^\infty\varphi dx+\int_{-\infty}^0\varphi dx=-\int_{-\infty}^\infty\text{sgn}(x)\varphi(x)dx$。
  故弱导数为 $\text{sgn}(x)$。∎
- **一句话点评**：弱导数通过分部积分定义，允许函数在不可导点处有"跳跃"。

**【D3-4-CROSS-022】**（D3 × D4 积分 × D7 三角学）**极坐标变换的完整分析**：从雅可比行列式、面积元素、到极坐标下的二重积分计算，完整梳理极坐标变换的数学基础。

- **难度**：★★★
- **对应知识点**：极坐标变换（D4/D7 联动）
- **来源**：积分、几何与多元微分
- **解答**：
  **极坐标变换**：
  x=r cos θ, y=r sin θ，其中 r≥0, θ∈[0,2π)。
  
  **1. 雅可比行列式**：
  J = ∂(x,y)/∂(r,θ) = |xᵣ x_θ; yᵣ y_θ| = |cos θ  -r sin θ; sin θ  r cos θ|
  = cos θ·r cos θ - (-r sin θ)·sin θ
  = r cos²θ + r sin²θ = r(cos²θ+sin²θ)=r
  
  所以 |det J|=r。∎
  
  **2. 面积元素**：
  在直角坐标中，面积元素是 dxdy。
  在极坐标中，面积元素是 r dr dθ。
  
  几何理解：取小区域 [r,r+dr]×[θ,θ+dθ]，这是一个"曲边矩形"：
  - 径向边长：dr
  - 切向边长：r dθ（圆弧长度=半径×圆心角）
  - 面积≈dr·r dθ=r dr dθ（当 dr,dθ 很小时，曲边矩形近似为矩形）
  
  越往外（r 越大），同样的 dθ 对应的弧长越长，所以面积元素和 r 成正比。∎
  
  **3. 二重积分变换公式**：
  ∬_D f(x,y)dxdy = ∬_{D'} f(r cos θ,r sin θ)·r dr dθ
  
  其中 D' 是 D 在极坐标下的对应区域。
  
  **经典应用（高斯积分）**：
  I=∫_{-∞}^{∞} e^{-x²}dx
  I²=∫∫ e^{-(x²+y²)}dxdy = ∫₀²π∫₀^∞ e^{-r²}·r dr dθ
  =2π·∫₀^∞ r e^{-r²}dr = 2π·[-e^{-r²}/2]₀^∞ = 2π·(1/2)=π
  所以 I=√π。∎
  
  这个积分在直角坐标下无法直接计算（e^{-x²} 没有初等原函数），但通过极坐标变换，r dr 的出现使得 ∫r e^{-r²}dr 变得简单——这是极坐标变换最经典的应用。
  
  **4. 和三角学的联系**：
  极坐标变换本质上是三角函数的应用——x=r cos θ, y=r sin θ 就是三角函数的定义（单位圆上的投影）。
  雅可比行列式 r 的出现也和三角函数有关：det J=r(cos²θ+sin²θ)=r，用到了 sin²+cos²=1。
  
  **5. 奇点问题**：
  在 r=0 处，雅可比行列式为 0，极坐标变换不是一一对应（原点对应所有 θ）。
  但因为 r=0 是一条线（测度为零），不影响积分值。
  这和反函数定理一致——det J=0 处不可逆，但测度为零的集合不影响积分。∎
- **一句话点评**：极坐标变换x=r cosθ,y=r sinθ。雅可比det J=r。面积元素r drdθ（径向dr×切向r dθ）。积分变换：∬f dxdy=∬f(r cosθ,r sinθ)r drdθ。经典应用：高斯积分∫e^{-x²}dx=√π——极坐标下r e^{-r²}可积。和三角学联系：变换本身就是三角函数定义，det J=r用到sin²+cos²=1。r=0处det J=0但测度零不影响积分。

**【D3-4-CROSS-023】**（D3 × D6 完备性 × D8 解析）**从隐函数定理到反函数定理：完备性在其中的作用**：为什么隐函数定理和反函数定理需要完备性？它们的证明如何依赖实数的完备性？

- **难度**：★★★
- **对应知识点**：隐函数/反函数定理与完备性（D6/D8 联动）
- **来源**：完备性、解析与多元微分
- **解答**：
  **隐函数定理的证明思路（压缩映射原理）**：
  隐函数定理通常用压缩映射原理（Banach 不动点定理）证明。
  
  对于 F(x,y)=0，Fᵧ(x₀,y₀)≠0，考虑映射 T(y)=y - F(x,y)/Fᵧ(x₀,y₀)（对固定的 x）。
  可以证明 T 在 y₀ 附近是压缩映射，由压缩映射原理，T 有唯一不动点 y=f(x)，满足 F(x,f(x))=0。
  
  **压缩映射原理依赖完备性**：
  压缩映射原理：完备度量空间中的压缩映射有唯一不动点。
  证明中需要构造迭代序列 y_{n+1}=T(y_n)，证明它是 Cauchy 列，然后由完备性保证它收敛。
  
  如果空间不完备，Cauchy 列可能不收敛，不动点可能不存在。
  实数 ℝ（和 ℝⁿ）是完备的，所以隐函数定理在 ℝⁿ 中成立。∎
  
  **反函数定理的证明也依赖完备性**：
  反函数定理可以由隐函数定理推出（考虑 F(x,y)=f(x)-y=0），所以也间接依赖完备性。
  
  或者直接证明：用压缩映射原理构造反函数的迭代逼近，同样需要完备性保证收敛。
  
  **和复分析的联系**：
  复分析中的反函数定理：如果 f 在 z₀ 处解析且 f'(z₀)≠0，则 f 在 z₀ 附近局部可逆，且反函数解析。
  
  复版本的证明可以用实版本的反函数定理（把 f 看作 ℝ²→ℝ² 的映射），因为复可导⇒实可微且雅可比行列式=|f'|²≠0。
  然后再证明反函数满足 C-R 方程（从而解析）。
  
  所以复反函数定理也建立在实数完备性的基础上——复数域 ℂ 的完备性来自实数域 ℝ 的完备性。∎
  
  **更深层的理解**：
  隐函数定理和反函数定理是"线性化原理"的体现：
  如果最佳线性逼近（雅可比矩阵）可逆，那么函数本身在局部可逆。
  
  但"线性逼近"和"函数本身"之间的差距需要用迭代来弥合——迭代序列的收敛性需要完备性保证。
  没有完备性，线性化可能无法"积分"回非线性函数。
  
  这就是为什么这些定理只在完备空间（ℝⁿ, ℂⁿ）中成立——在不完备空间（如 ℚⁿ）中，即使雅可比矩阵可逆，也可能没有反函数。∎
  
  **例子（有理数中的反例）**：
  考虑 f(x)=x² 在 ℚ 中。f'(1)=2≠0，但 f 在 1 附近不是局部可逆的——因为 √2 不是有理数，f(x)=2 在 ℚ 中无解。
  这说明在不完备空间 ℚ 中，反函数定理不成立。
- **一句话点评**：隐函数/反函数定理用压缩映射原理证明，压缩映射原理需要完备性（Cauchy列收敛）。迭代构造y_{n+1}=T(y_n)，完备性保证收敛。复版本建立在实版本上（复可导⇒实可微且det J=|f'|²≠0），复数完备性来自实数完备性。反例：f(x)=x²在ℚ中f'(1)=2≠0但不可逆（√2∉ℚ）——不完备空间中反函数定理失效。

### 二、定理串联型

**【D3-4-CROSS-024】**（D3 × D2 连续 × D6 完备性）**从一维到高维：极值定理的推广**：闭区间上的连续函数有最值（一维极值定理），如何推广到高维？紧性在其中起什么作用？

- **难度**：★★
- **对应知识点**：高维极值定理（D2/D6 联动）
- **来源**：连续、完备性与多元微分
- **解答**：
  **一维极值定理**：
  闭区间 [a,b] 上的连续函数 f 一定能取到最大值和最小值。
  
  **高维推广**：
  ℝⁿ 中有界闭集（紧集）K 上的连续函数 f:K→ℝ 一定能取到最大值和最小值。
  
  **证明思路**：
  
  1. **有界性**：
     假设 f 无界，则存在 xₙ∈K 使得 |f(xₙ)|→∞。
     因为 K 有界，由 Bolzano-Weierstrass 定理（ℝⁿ 中有界数列有收敛子列，依赖完备性），xₙ 有收敛子列 xₙₖ→x₀∈K（K 闭⇒极限在 K 中）。
     由连续性，f(xₙₖ)→f(x₀)，但 |f(xₙₖ)|→∞，矛盾。
     所以 f 有界。∎
  
  2. **取到最值**：
     设 M=sup f(K)。由上确界定义，存在 xₙ∈K 使得 f(xₙ)→M。
     由 Bolzano-Weierstrass，xₙ 有收敛子列 xₙₖ→x₀∈K。
     由连续性，f(x₀)=lim f(xₙₖ)=M。
     所以 f 在 x₀ 处取到最大值 M。同理取到最小值。∎
  
  **紧性的作用**：
  高维极值定理的条件是"紧集上的连续函数"。
  紧集 = 有界闭集（在 ℝⁿ 中，由 Heine-Borel 定理）。
  
  - 有界性：保证 Bolzano-Weierstrass 定理可用（数列有收敛子列）
  - 闭性：保证子列的极限仍在集合内（不会"跑出去"）
  
  两者结合=紧性，保证了连续函数能取到最值。
  
  **和一元的对比**：
  一元的"闭区间 [a,b]"就是 ℝ 中的紧集——有界且闭。
  高维的"有界闭集"是"闭区间"的推广。
  证明方法完全一样：Bolzano-Weierstrass + 连续性。∎
  
  **反例**：
  - 开区间 (0,1) 上的 f(x)=1/x：连续但无界（不闭，不紧）
  - 无界集 ℝ 上的 f(x)=x：连续但无最值（无界，不紧）
  - 有界闭集上的连续函数：一定有最值（紧）
  
  **在多元微分学中的应用**：
  求多元函数在有界闭区域上的最值：
  1. 求内部驻点（偏导数为零的点）
  2. 求边界上的极值（用拉格朗日乘数法或参数化）
  3. 比较所有候选点的函数值，最大的就是最大值，最小的就是最小值
  
  极值定理保证了最大值和最小值一定存在——所以这个方法是完备的。∎
- **一句话点评**：高维极值定理：紧集（有界闭集）上的连续函数一定取到最值。证明：①有界性：若无界则xₙ使|f(xₙ)|→∞，Bolzano-Weierstrass⇒收敛子列→x₀，连续性⇒f(xₙₖ)→f(x₀)矛盾②取最值：sup f=M，取xₙ→M，子列收敛x₀，f(x₀)=M。紧性=有界（BW定理）+闭（极限在集合内）。一元闭区间=ℝ中的紧集。应用：求最值=内部驻点+边界极值+比较。

### 三、反例与构造

**【D3-4-CROSS-025】**（D3 × D2 连续）**多元函数的经典反例库**：构造一个函数，偏导数都存在但不连续；构造一个函数连续但偏导数不存在；构造一个函数可微但偏导数不连续。

- **难度**：★★★
- **对应知识点**：多元函数反例（D2 联动）
- **来源**：病态函数与多元微分
- **解答**：
  **反例 1：偏导数存在但不连续（也不可微）**
  f(x,y)=xy/(x²+y²)，f(0,0)=0（D3-4-005 已讨论）
  - 偏导数存在：fₓ(0,0)=fᵧ(0,0)=0
  - 不连续：沿 y=kx 极限依赖 k
  - 不可微：因为不连续
  
  **反例 2：连续但偏导数不存在**
  f(x,y)=√(x²+y²)=r（距离函数）
  - 连续：r 是连续函数
  - 在原点偏导数不存在：
    fₓ(0,0)=lim_{h→0}[√(h²+0)-0]/h=lim |h|/h，不存在（左右极限分别为 ±1）
  - 其他点偏导数存在：fₓ=x/r, fᵧ=y/r
  
  这是一元 |x| 的高维推广——在"尖点"处不可导。∎
  
  **反例 3：可微但偏导数不连续**
  f(x,y)=(x²+y²)sin(1/√(x²+y²))，f(0,0)=0
  
  - 可微性：
    fₓ(0,0)=lim_{h→0} h² sin(1/|h|)/h=lim h sin(1/|h|)=0（有界量×无穷小）
    同理 fᵧ(0,0)=0。
    Δz=f(h,k)-f(0,0)=(h²+k²)sin(1/√(h²+k²))=ρ² sin(1/ρ)
    Δz/ρ=ρ sin(1/ρ)→0
    所以 Δz=0·h+0·k+o(ρ)，可微，dz=0。∎
  
  - 偏导数不连续：
    当 (x,y)≠(0,0) 时：
    fₓ=2x sin(1/r) + (x²+y²)cos(1/r)·(-1/r²)·(x/r)
    =2x sin(1/r) - (x/r)cos(1/r)
    
    沿 x 轴（y=0, x→0⁺）：fₓ=2x sin(1/x) - cos(1/x)
    第一项→0，第二项 cos(1/x) 在 [-1,1] 振荡，极限不存在。
    所以 fₓ 在原点不连续。∎
  
  这个例子是一元 f(x)=x² sin(1/x) 的高维推广——可微但导数不连续。
  
  **完整的关系图**：
  
  ```
  偏导数连续 ⇒ 可微 ⇒ 连续 + 偏导数存在
       ↑           ↑           ↑
    反例3        反例1        反例2
  (可微但偏导  (偏导存在    (连续但偏导
   不连续)     但不连续)    不存在)
  ```
  
  每个箭头都不可逆，且都有经典反例。∎
  
  **这些反例的意义**：
  多元函数的"连续""偏导存在""可微""偏导连续"之间的关系比一元复杂得多——一元中"可导⇒连续"，但多元中"偏导存在⇏连续"。
  这些反例帮助我们理解每个概念的确切含义和边界——为什么需要"偏导连续"才能保证可微，为什么"可微"比"偏导存在"强得多。
- **一句话点评**：三个经典反例：①偏导存在但不连续/不可微：f=xy/(x²+y²),f(0,0)=0②连续但偏导不存在：f=√(x²+y²)在原点③可微但偏导不连续：f=(x²+y²)sin(1/√(x²+y²)),f(0,0)=0。关系图：偏导连续⇒可微⇒连续+偏导存在，每个箭头都不可逆。多元比一元复杂——一元可导⇒连续，但多元偏导存在⇏连续。

### 四、基础综合

**【D3-4-CROSS-026】**（D3 × D4 积分 × D7 三角学）**梯度、散度、旋度的统一理解**：从多元微分学的角度统一理解梯度 ∇f、散度 ∇·F、旋度 ∇×F，解释它们的几何意义和物理意义。

- **难度**：★★★
- **对应知识点**：向量微积分（D4/D7 联动）
- **来源**：几何、积分与多元微分
- **解答**：
  **三个基本微分算子**：
  
  **1. 梯度（Gradient）∇f**：
  输入：标量场 f(x,y,z)
  输出：向量场 ∇f=(fₓ,fᵧ,f_z)
  几何意义：指向函数值增长最快的方向，模长=最大变化率
  物理意义：保守力场 F=-∇V（力是势能的负梯度），热流 q=-k∇T（热从高温流向低温）
  
  **2. 散度（Divergence）∇·F**：
  输入：向量场 F=(P,Q,R)
  输出：标量 ∇·F=Pₓ+Qᵧ+R_z
  几何意义：向量场在某点的"净流出率"——单位体积的通量
  物理意义：流体的源汇（∇·v>0 有源，&lt;0 有汇），电场的电荷密度（∇·E=ρ/ε₀，高斯定律）
  
  **3. 旋度（Curl）∇×F**：
  输入：向量场 F=(P,Q,R)
  输出：向量 ∇×F=(Rᵧ-Q_z, P_z-Rₓ, Qₓ-Pᵧ)
  几何意义：向量场在某点的"旋转强度和方向"——右手螺旋方向
  物理意义：流体的涡旋（∇×v=2ω，角速度），磁场的电流密度（∇×B=μ₀J，安培定律）
  
  **统一理解（∇ 算子）**：
  ∇=(∂/∂x, ∂/∂y, ∂/∂z) 是一个"向量微分算子"。
  - ∇f = 向量 × 标量 = 梯度（类比数乘）
  - ∇·F = 向量 · 向量 = 散度（类比点积）
  - ∇×F = 向量 × 向量 = 旋度（类比叉积）
  
  三个算子分别对应了向量代数中的三种乘法：数乘、点积、叉积。∎
  
  **重要恒等式**：
  - ∇×(∇f)=0：梯度场无旋（保守场）
  - ∇·(∇×F)=0：旋度场无源
  - ∇×(∇×F)=∇(∇·F)-∇²F（向量拉普拉斯）
  
  这些恒等式是电磁学（Maxwell 方程）和流体力学的基础。
  
  **和积分定理的关系**：
  - 梯度定理（线积分基本定理）：∫_C ∇f·dr=f(B)-f(A)
  - 散度定理（高斯公式）：∭∇·F dV=∯F·dS
  - 旋度定理（斯托克斯公式）：∬(∇×F)·dS=∮F·dr
  
  三个微分算子对应三个积分定理——这是向量微积分的核心结构。∎
  
  **几何统一**：
  梯度、散度、旋度都可以用"微分形式"统一描述——它们是外微分 d 在不同次数微分形式上的表现。
  这是微分几何的观点——向量微积分是外微分的三维特例。
- **一句话点评**：三算子统一于∇=(∂/∂x,∂/∂y,∂/∂z)：①梯度∇f=向量×标量（最速上升方向）②散度∇·F=向量·向量（净流出率，源汇）③旋度∇×F=向量×向量（旋转强度，涡旋）。对应向量代数三种乘法。恒等式：∇×∇f=0,∇·∇×F=0。对应三积分定理：梯度定理、散度定理、斯托克斯公式。微分几何中统一为外微分d。

**【D3-4-CROSS-027】**（D3 × D5 级数 × D8 解析）**多元泰勒公式与解析函数**：从多元泰勒公式到复解析函数的幂级数展开，梳理"可微⇒可展幂级数"在多元和复分析中的不同表现。

- **难度**：★★★
- **对应知识点**：多元泰勒与解析（D5/D8 联动）
- **来源**：级数、解析与多元微分
- **解答**：
  **多元泰勒公式（实分析）**：
  f(x₀+Δx)=f(x₀)+∇f·Δx+(1/2)Δx^T H Δx+...+高阶项+余项
  
  多元泰勒公式是有限项+余项的形式——和一元一样，需要估计余项。
  多元 C^∞ 函数不一定能展开为收敛的幂级数（和一元一样，有 C^∞ 但不解析的反例）。
  
  **复解析函数的泰勒级数**：
  复可导（解析）函数一定可以展开为收敛的幂级数：
  f(z)=Σₙ₌₀^∞ f⁽ⁿ⁾(z₀)/n!·(z-z₀)ⁿ
  收敛半径=到最近奇点的距离。
  
  **关键区别**：
  
  | 性质 | 实多元函数 | 复解析函数 |
  |------|----------|-----------|
  | 可微 | 全微分存在 | C-R 方程+可微 |
  | C^∞ | 不一定能展幂级数 | 一定能展幂级数 |
  | 泰勒级数 | 可能不收敛到 f | 一定收敛到 f |
  | 收敛半径 | 可能为 0 或不收敛到 f | =到最近奇点距离 |
  | 反例 | e^{-1/||x||²}（C^∞但不解析） | 不存在 |
  
  **为什么复解析函数一定能展幂级数**：
  1. Cauchy 积分公式：f(z)=1/(2πi)∮f(ζ)/(ζ-z)dζ
  2. 展开 1/(ζ-z)=1/(ζ-z₀)·1/(1-(z-z₀)/(ζ-z₀))=Σ(z-z₀)ⁿ/(ζ-z₀)ⁿ⁺¹
  3. 逐项积分得 f(z)=Σ\[1/(2πi)∮f(ζ)/(ζ-z₀)ⁿ⁺¹dζ\](z-z₀)ⁿ=Σf⁽ⁿ⁾(z₀)/n!·(z-z₀)ⁿ
  
  Cauchy 积分公式是复分析特有的——它把函数值表示为围道积分，从而可以展开为幂级数。
  实分析中没有对应的公式——实函数的值不能用边界积分表示，所以不一定能展幂级数。∎
  
  **多元实解析函数**：
  如果一个多元实函数在某点可以展开为收敛的多元幂级数，则称为（实）解析函数。
  多元幂级数：Σ_{α} c_α (x-x₀)^α，其中 α 是多重指标。
  
  实解析函数比 C^∞ 函数少得多——C^∞ 但不解析的函数（如 e^{-1/||x||²}）是"光滑但不解析"的典型。
  
  **复解析⇒实解析**：
  复解析函数 f(z)=u(x,y)+iv(x,y) 的实部 u 和虚部 v 都是实解析函数（可以展开为二元实幂级数）。
  这是因为复幂级数展开后，分离实部虚部就得到 u 和 v 的实幂级数。∎
  
  **深层联系**：
  复可导是一个极强的条件——它自动保证了无穷正则性和幂级数展开。
  实可导（甚至 C^∞）条件弱得多——不能保证幂级数展开。
  这就是为什么复分析中有"解析函数"的丰富理论，而实分析中需要区分"C^∞"和"解析"。
- **一句话点评**：多元实泰勒公式是有限项+余项，C^∞不一定能展幂级数（e^{-1/||x||²}反例）。复解析函数一定能展幂级数，收敛半径=到最近奇点距离。原因：Cauchy积分公式f(z)=1/(2πi)∮f(ζ)/(ζ-z)dζ，展开1/(ζ-z)为几何级数，逐项积分得幂级数。实分析无Cauchy积分公式⇒不一定能展。复解析⇒实部虚部都是实解析。复可导条件极强⇒自动所有好性质。

## 本模块易错点总结

1. **偏导数与可微的关系**：
   - 可微 ⇒ 偏导数存在 + 连续
   - 偏导数连续 ⇒ 可微
   - 偏导数存在 ⇏ 可微（经典反例 xy/(x²+y²)）
   - 偏导数存在 ⇏ 连续
   - 连续 ⇏ 偏导数存在（如 √(x²+y²) 在原点）

2. **混合偏导数**：
   - 混合偏导数相等需要连续条件
   - fₓᵧ 和 fᵧₓ 不一定相等（不连续时）

3. **方向导数与梯度**：
   - 方向导数存在 ⇏ 可微
   - 可微 ⇒ 所有方向导数存在，且 ∂f/∂u=∇f·u
   - 梯度方向是最速上升方向，反方向是最速下降方向
   - 梯度垂直于等值线

4. **极值判别**：
   - 驻点不一定是极值点（可能是鞍点）
   - Hessian 判别法：D>0 且 fₓₓ>0 ⇒ 极小；D>0 且 fₓₓ&lt;0 ⇒ 极大；D&lt;0 ⇒ 鞍点；D=0 ⇒ 不定
   - 边界上的极值需要单独考虑（拉格朗日乘数法或参数化）

5. **拉格朗日乘数法**：
   - ∇f=λ∇g 是必要条件，不是充分条件
   - 需要比较所有候选点的函数值来确定最值
   - 几何意义：等值线和约束曲线相切

6. **隐函数定理**：
   - Fᵧ≠0 是关键条件（保证可以解出 y）
   - dy/dx=-Fₓ/Fᵧ
   - 多元隐函数组需要雅可比行列式≠0

7. **切平面与法线**：
   - 曲面 z=f(x,y) 的切平面：z-z₀=fₓ(x-x₀)+fᵧ(y-y₀)
   - 法向量：(fₓ, fᵧ, -1)
   - 一般曲面 F(x,y,z)=0 的法向量：∇F

8. **全微分近似计算**：
   - f(x₀+Δx,y₀+Δy)≈f(x₀,y₀)+fₓΔx+fᵧΔy
   - 误差是 o(ρ)，ρ=√(Δx²+Δy²)

9. **雅可比行列式**：
   - det J≠0 ⇒ 局部可逆（反函数定理）
   - |det J| = 体积放大率
   - 积分变量替换需要乘 |det J|

10. **C-R 方程**：
    - 复可导 ⟺ u,v 可微 + C-R 方程
    - C-R 方程：uₓ=vᵧ, uᵧ=-vₓ
    - 解析函数的实部虚部都是调和函数
