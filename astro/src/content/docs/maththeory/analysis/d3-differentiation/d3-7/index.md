## 第一章 引言：微分概念的四层蜕变

### 1.1 为什么需要蜕变图谱

D3-1 至 D3-6 分别从不同角度建立了微分学的各个分支，但这些材料是分散的——一元微分、多元微分、复变微分、实变微分各自有一套概念体系和定理。学习者容易陷入"学了六本教材"的困境，看不到它们之间的内在联系。

本模块的目标是建立一张完整的蜕变图谱，回答三个核心问题：
1. **微分概念如何从朴素直觉一步步严格化、高维化、弱化为几乎处处/弱导数？**
2. **每一层的核心定理（中值定理、链式法则、泰勒公式、微积分基本定理）如何演化？哪些定理在某一层消失或变形？**
3. **函数正则性的完整谱系是什么？每一类函数对应哪些定理成立？**

### 1.2 四层结构

本图谱采用四层结构：

| 层级 | 名称 | 核心特征 | 代表函数类 |
|---|---|---|---|
| L0 | 初等直觉层 | 朴素变化率、切线、速度，无严格定义 | 初等函数 |
| L1 | 数学分析层 | ε-δ 严格定义，一元/多元，处处可导 | C¹、C^k、C^∞ |
| L2 | 复变函数层 | 复可导=解析，极强刚性，一次可导⇒无穷次可导 | 解析函数、全纯函数 |
| L3 | 实变函数层 | 几乎处处可导、弱导数、分布导数，条件极弱 | 单调函数、BV、AC、可测函数 |

### 1.3 三条蜕变主线

微分概念的演化遵循三条主线：

1. **严格化主线**：L0 朴素无穷小 → L1 ε-δ 差商极限 → L2 复平面全方向极限 → L3 几乎处处极限/弱极限
2. **维度抬升主线**：L0 一元直观 → L1 一元+多元 → L2 复数（二维实函数+C-R约束） → L3 高维可测函数
3. **条件弱化主线**：L1 处处可导 → L2 处处复可导（更强） → L3 几乎处处可导 → 弱导数 → 分布导数（最弱）

这三条主线交织在一起，构成了微分概念的完整演化史。

## 第二章 L0 初等直觉层：朴素变化率

### 2.1 L0 层的核心概念

L0 层是微分学的"前史"——在严格的 ε-δ 定义建立之前，人们对微分的理解是朴素的、几何的、物理的：

1. **变化率**：函数值随自变量变化的快慢——"走得快不快"
2. **切线**：曲线在一点处"最接近"的直线——几何直观
3. **速度**：位移对时间的变化率——物理直观
4. **无穷小**：牛顿的"瞬"、莱布尼茨的"微分"——一种"无限小但不为零"的量

### 2.2 L0 层的成就

L0 层虽然不严格，但取得了巨大的成就：
- 牛顿和莱布尼茨创立了微积分，解决了大量物理和几何问题
- 发现了微积分基本定理——微分和积分是互逆运算
- 建立了求导法则、中值定理、泰勒展开的雏形
- 解决了极值、切线、面积、体积等大量实际问题

### 2.3 L0 层的局限

L0 层的核心局限是**不严格**：
1. **无穷小概念模糊**："无限小但不为零"的量在逻辑上站不住脚（贝克莱悖论）
2. **可导条件不明确**：什么样的函数可以求导？没有明确的判据
3. **定理证明不严谨**：中值定理、泰勒公式等的证明依赖直观
4. **无法处理病态函数**：处处连续处处不可导函数等病态函数的出现，暴露了 L0 层的局限

### 2.4 L0 层的几何直觉

L0 层的所有概念都有清晰的几何直觉：
- **导数=切线斜率**：曲线在一点处的倾斜程度
- **微分=切线增量**：用切线代替曲线的增量
- **极值=山峰山谷**：曲线的局部最高点和最低点
- **中值定理=切线平行于割线**：曲线上存在一点的切线平行于两端点连线
- **泰勒公式=多项式逼近**：用高阶多项式在一点附近逼近曲线

这些几何直觉是微分学的灵魂——即使在最抽象的 L3 层，这些直觉仍然是理解概念的基础。

### 2.5 从 L0 到 L1 的蜕变

L0 到 L1 的蜕变核心是**严格化**：
- 用 ε-δ 语言的极限定义代替模糊的无穷小
- 用差商极限的存在性定义可导性
- 用实数完备性定理（确界原理、区间套等）严格证明中值定理
- 建立函数类的层级（连续、可导、连续可导、光滑）

这一蜕变由柯西、魏尔斯特拉斯等人在 19 世纪完成，标志着微积分从"直观的演算技巧"转变为"严格的数学理论"。

## 第三章 L1 数学分析层：经典微分学

### 3.1 L1 层的核心概念

L1 层是经典数学分析中的微分学，建立在 ε-δ 严格极限的基础上：

1. **一元导数**：f'(x₀)=lim_{h→0} [f(x₀+h)-f(x₀)]/h，h 从左右两个方向趋近
2. **多元全微分**：df=∇f·dx，要求所有方向的线性近似一致
3. **偏导数**：固定其他变量，对一个变量求导
4. **方向导数**：沿任意方向的变化率
5. **高阶导数**：导数的导数，描述变化率的变化率

### 3.2 L1 层的核心定理

L1 层建立了微分学的完整定理体系：

| 定理 | 一元版本 | 多元版本 |
|---|---|---|
| Fermat 定理 | 可导极值点导数为零 | 可微极值点梯度为零 |
| Rolle 定理 | 端点相等⇒存在导数为零的点 | 不直接对应（多元无简单版本） |
| Lagrange 中值定理 | f(b)-f(a)=f'(ξ)(b-a) | 凸区域上的多元中值定理 |
| Cauchy 中值定理 | 参数形式的中值定理 | 不直接对应 |
| 泰勒公式 | Peano/Lagrange/Cauchy/积分余项 | 梯度+Hessian 矩阵形式 |
| 链式法则 | dy/dx=dy/du·du/dx | 雅可比矩阵乘法 |
| 隐函数定理 | Fᵧ≠0⇒y=f(x) | 雅可比行列式≠0 |
| 反函数定理 | f'≠0⇒反函数可导 | 雅可比行列式≠0 |
| 微积分基本定理 | 连续可导条件下成立 | 线积分基本定理 |

### 3.3 L1 层的函数正则性谱系

L1 层内部已经有函数正则性的层级：

```
解析函数 ⊂ C^∞ ⊂ C^k ⊂ C¹ ⊂ 可导 ⊂ 连续 ⊂ 可测
```

注意：在 L1 层，"解析函数"已经出现（实解析函数），但它是 C^∞ 的真子集——存在 C^∞ 但非解析的函数（如 e^{-1/x²}）。

### 3.4 L1 层的反例

L1 层的反例揭示了经典微分学的边界：

1. **连续但不可导**：|x| 在 x=0 处
2. **可导但导数不连续**：x²sin(1/x) 在 x=0 处可导，但导数在 0 处不连续
3. **驻点不是极值点**：x³ 在 x=0 处
4. **f''=0 不是拐点**：x⁴ 在 x=0 处
5. **C^∞ 但非解析**：e^{-1/x²}
6. **处处连续处处不可导**：Weierstrass 函数
7. **偏导存在但不连续**：xy/(x²+y²)
8. **偏导存在但不可微**：√|xy|
9. **可微但偏导不连续**：r²sin(1/r)
10. **混合偏导不相等**：xy(x²-y²)/(x²+y²)

### 3.5 从 L1 到 L2 的蜕变

L1 到 L2 的蜕变核心是**复数域的引入和 C-R 方程的强约束**：
- 自变量从实数变为复数，差商的 h 可以从复平面上无穷多个方向趋近
- 无穷多方向极限一致的要求导出 C-R 方程，对函数施加了极强约束
- 一次复可导自动保证无穷次可导（柯西积分公式）
- 解析函数等价于收敛到自身的幂级数
- 出现了 L1 层没有的独特性质：最大模原理、零点孤立性、唯一性定理

这一蜕变由柯西、黎曼、魏尔斯特拉斯在 19 世纪完成，标志着复变函数论的创立。

## 第四章 L2 复变函数层：解析函数的刚性微分

### 4.1 L2 层的核心概念

L2 层是复变函数论中的微分学，核心是**解析函数**（全纯函数）：

1. **复导数**：f'(z₀)=lim_{h→0} [f(z₀+h)-f(z₀)]/h，h 是复数，从无穷多方向趋近
2. **C-R 方程**：uₓ=vᵧ, uᵧ=-vₓ——复可导的代数条件
3. **解析函数**：在区域内每一点复可导的函数
4. **奇点**：可去奇点、极点、本性奇点——解析性被破坏的点
5. **留数**：洛朗展开中 -1 次项的系数——奇点的"旋转量"

### 4.2 L2 层的独特性质（L1 层没有的）

L2 层的解析函数具有一系列 L1 层实可导函数没有的"刚性"性质：

| 性质 | L1 实可导函数 | L2 解析函数 |
|---|---|---|
| 一次可导⇒无穷次可导 | 否（f'不一定可导） | 是（柯西积分公式） |
| 无穷次可导⇒泰勒级数收敛到函数 | 否（e^{-1/x²}） | 是（解析等价于幂级数） |
| 最大模原理 | 不成立（可在内部取最大值） | 成立（非常数解析函数不能在内部取最大模） |
| 零点孤立性 | 不成立（x²sin(1/x)零点不孤立） | 成立（不恒为零的解析函数零点孤立） |
| 唯一性定理 | 不成立（可在一个点列上相同但不同） | 成立（收敛点列上相同则恒等） |
| 内部值由边界值决定 | 不成立 | 成立（柯西积分公式） |
| 有界整函数为常数 | 不成立（sin x有界但非常数） | 成立（刘维尔定理） |

### 4.3 L2 层中"消失"或"变形"的定理

从 L1 到 L2，一些经典定理发生了变化：

1. **Lagrange 中值定理**：复变函数中没有简单的 Lagrange 中值定理——因为复平面上没有"区间"的自然序，中值点 ξ 不一定存在。但有积分形式的中值定理，以及对实部/虚部的中值定理。
2. **Rolle 定理**：复变函数中不成立——f(a)=f(b) 不能保证存在 f'(ξ)=0。
3. **极值理论**：复变函数中没有普通的极值（因为复数没有序），但有最大模原理（模的极值只能在边界上）。
4. **单调性**：复变函数中没有单调性概念（复数没有序）。
5. **凹凸性**：复变函数中没有凹凸性概念。

### 4.4 L2 层中"新增"的定理

L2 层新增了 L1 层没有的核心定理：

1. **柯西积分定理**：解析函数沿闭曲线积分为零
2. **柯西积分公式**：内部值由边界值的积分决定
3. **高阶导数公式**：解析函数无穷次可导，各阶导数由积分给出
4. **刘维尔定理**：有界整函数为常数
5. **代数基本定理**：n 次多项式至少有一个复根
6. **最大模原理**：非常数解析函数不能在内部取最大模
7. **零点孤立性定理**
8. **唯一性定理**
9. **洛朗展开定理**：圆环域内的展开
10. **留数定理**：沿闭曲线积分=2πi×内部留数之和
11. **黎曼映射定理**：所有单连通区域共形等价于单位圆盘
12. **皮卡定理**：本性奇点附近取遍几乎所有值

### 4.5 L2 层的反例

L2 层的反例揭示了解析函数的边界：

1. **处处不可导**：z̄（共轭函数）
2. **一点可导但不解析**：|z|²（只在原点可导）
3. **C-R 满足但不可导**：√|xy|（u,v 不可微）
4. **可去奇点**：sin z/z 在 z=0
5. **极点**：1/zⁿ 在 z=0
6. **本性奇点**：e^{1/z} 在 z=0
7. **非孤立奇点**：1/sin(1/z) 在 z=0（奇点聚点）
8. **f'=0 处不共形**：z² 在 z=0（角度加倍）
9. **整函数无零点且非常数**：eᶻ
10. **自然边界**：某些解析函数的收敛圆边界上每一点都是奇点

### 4.6 从 L2 到 L3 的蜕变

L2 到 L3 的蜕变核心是**从"正则性的极致"转向"正则性的底线"**：
- 从研究最强的函数类（解析函数）转向研究最弱的函数类（可测函数、可积函数）
- 从"处处可导"弱化为"几乎处处可导"
- 从经典导数推广到弱导数、分布导数
- 从"导数为零⇒常数"弱化为"导数 a.e. 为零⇏常数"（Cantor 函数）
- 微积分基本定理的成立条件从"连续可导"变为"绝对连续"

这一蜕变由 Lebesgue、Vitali、Radon-Nikodým 等人在 20 世纪初完成，标志着实变函数论的创立。

## 第五章 L3 实变函数层：几乎处处可导与弱导数

### 5.1 L3 层的核心概念

L3 层是实变函数论中的微分学，核心是**在极弱条件下建立微分理论**：

1. **几乎处处可导**：在一个满测度集合上可导，零测集上的行为忽略
2. **Dini 导数**：四个广义导数（上/下、左/右），用于研究不可导点的行为
3. **有界变差函数（BV）**：总变差有限的函数，两个单调函数的差
4. **绝对连续函数（AC）**：变化完全由导数记录的函数，恰好是 L¹ 函数的不定积分
5. **Lebesgue 点**：函数在平均意义下连续的点
6. **弱导数**：Sobolev 空间中的导数，通过分部积分定义
7. **分布导数**：Schwartz 分布理论中的导数，最广义的导数概念

### 5.2 L3 层的核心定理

| 定理 | 陈述 | 意义 |
|---|---|---|
| 单调函数 a.e. 可导 | 单调函数几乎处处可导 | 最弱条件下的可导性 |
| Jordan 分解 | BV=两个递增函数的差 | BV 函数的结构 |
| Lebesgue 分解 | BV=AC+奇异连续+跳跃 | BV 函数的精细分解 |
| Lebesgue 微分定理 | 可积函数的不定积分 a.e. 可导且导数=被积函数 | 微积分基本定理的第一部分 |
| AC 刻画定理 | AC⟺不定积分 | 微积分基本定理成立的充要条件 |
| 微积分基本定理（Lebesgue 版） | AC 函数满足 F(b)-F(a)=∫F' | 微积分基本定理的第二部分 |
| Vitali 覆盖引理 | 用互不重叠区间几乎覆盖任意集合 | 证明 a.e. 定理的核心工具 |
| Hardy-Littlewood 极大不等式 | Mf 的弱 (1,1) 型估计 | 证明点态收敛的核心工具 |
| Radon-Nikodým 定理 | 绝对连续测度有密度函数 | 微分理论的测度论表述 |
| Rademacher 定理 | Lipschitz 函数 a.e. 可导（高维） | 高维微分理论的基础 |

### 5.3 L3 层中"弱化"的定理

从 L1/L2 到 L3，一些定理被弱化了：

1. **"导数为零⇒常数"**：
   - L1：处处导数为零⇒常数（成立）
   - L2：解析函数导数为零⇒常数（成立）
   - L3：导数 a.e. 为零⇏常数（Cantor 函数是反例），需要附加绝对连续才成立

2. **微积分基本定理**：
   - L1：连续可导条件下成立
   - L2：解析函数条件下成立
   - L3：绝对连续条件下成立（比连续可导弱，但比 a.e. 可导强）

3. **可导⇒连续**：
   - L1：处处可导⇒连续（成立）
   - L2：处处复可导⇒连续（成立）
   - L3：a.e. 可导⇏连续（可测函数可以处处不连续）

4. **原函数唯一性**：
   - L1：处处可导意义下唯一（差常数）
   - L3：a.e. 可导意义下不唯一（可差奇异函数）

### 5.4 L3 层的函数正则性完整谱系

L3 层建立了最完整的函数正则性谱系：

```
解析函数 ⊂ C^∞ ⊂ C^k ⊂ C¹ ⊂ Lipschitz ⊂ 绝对连续(AC) ⊂ 有界变差(BV) ⊂ 连续? ⊂ 可测
```

注意：
- BV 不一定连续（可以有跳跃）
- 连续不一定 BV（如 x sin(1/x)）
- 可测是最弱的条件，几乎不要求正则性

每一类函数对应不同的定理成立：
- **解析函数**：所有微分定理+最大模原理+唯一性定理
- **C^k**：k 阶导数连续，k 阶泰勒公式成立
- **C¹**：一阶导数连续，经典微积分基本定理成立
- **Lipschitz**：导数 a.e. 存在且有界，Rademacher 定理
- **AC**：导数 a.e. 存在且可积，Lebesgue 版微积分基本定理成立
- **BV**：导数 a.e. 存在，但 ∫f'≤总增量（等号不一定成立）
- **连续**：不一定可导（Weierstrass 函数）
- **可测**：几乎不要求任何正则性

### 5.5 L3 层的反例

L3 层的反例揭示了实变微分理论的边界：

1. **单调但有无穷间断点**：有理点阶梯函数
2. **单调但导数 a.e. 为零**：Cantor 函数
3. **连续但非 BV**：x sin(1/x)
4. **BV 但不连续**：阶梯函数
5. **连续单调但非 AC**：Cantor 函数
6. **一致连续但非 AC**：x sin(1/x)
7. **AC 但非 Lipschitz**：√x
8. **处处连续处处不可导**：Weierstrass 函数
9. **导数有界但不 Riemann 可积**：Volterra 函数
10. **导数 a.e. 为零但非常数**：Cantor 函数
11. **严格递增但导数 a.e. 为零**：构造的严格递增奇异函数
12. **连续函数把零测集映为正测集**：Cantor 函数

## 第七章 核心定理跨层详细对照

### 7.1 中值定理的跨层演化

**L1 一元 Lagrange 中值定理**：
如果 f 在 [a,b] 连续、(a,b) 可导，则存在 ξ∈(a,b)，使得 f(b)-f(a)=f'(ξ)(b-a)。

**L1 多元中值定理**：
如果 f 在凸区域 D 上可微，则对任意 x₁,x₂∈D，存在 ξ 在线段 x₁x₂ 上，使得 f(x₂)-f(x₁)=∇f(ξ)·(x₂-x₁)。

**L2 复变函数**：
没有简单的 Lagrange 中值定理。原因：
1. 复平面上没有自然序，"区间"概念不自然
2. 中值点 ξ 不一定存在（反例：f(z)=eᶻ，f(2πi)-f(0)=0，但 eᶻ'=eᶻ≠0 处处）
3. 但有积分形式的中值定理：∫_a^b f(z)dz=f(ξ)(b-a) 对某些积分路径成立

**L3 实变函数**：
有积分形式的中值定理（对 AC 函数），但没有经典的点态中值定理——因为 a.e. 可导函数的导数可以在正测度集合上为零而函数非常数（Cantor 函数）。

**演化总结**：中值定理从 L1 的"点态形式"，在 L2 中"消失"（被积分形式和最大模原理替代），在 L3 中"弱化为积分形式"。

### 7.2 链式法则的跨层演化

**L1 一元链式法则**：
dy/dx=dy/du·du/dx

**L1 多元链式法则**：
J(f∘g)=J(f)·J(g)（雅可比矩阵乘法）

**L2 复变链式法则**：
(f∘g)'=f'(g(z))g'(z)（和一元形式完全相同，因为复导数是复数乘法）

**L3 实变链式法则**：
- 对 AC 函数：链式法则 a.e. 成立（如果外层函数 Lipschitz）
- 对 BV 函数：有分布意义下的链式法则
- 对弱导数：有 Sobolev 空间中的链式法则（如果外层函数 Lipschitz）

**演化总结**：链式法则是最"稳定"的微分法则——在所有四层都成立，只是适用的函数类和严格性不同。L2 层的链式法则形式最简单（和一元相同），L3 层需要附加条件（外层 Lipschitz）。

### 7.3 泰勒公式的跨层演化

**L1 一元泰勒公式**：
f(x)=∑ₖ₌₀ⁿ f⁽ᵏ⁾(x₀)/k!·(x-x₀)ᵏ+Rₙ(x)
余项形式：Peano（局部定性）、Lagrange/Cauchy（全局定量）、积分余项（最精确）

**L1 多元泰勒公式**：
f(x₀+h)=f(x₀)+∇f·h+(1/2)hᵀHh+o(|h|²)
（梯度+ Hessian 矩阵形式）

**L2 复变泰勒公式**：
f(z)=∑ₙ₌₀^∞ aₙ(z-z₀)ⁿ，aₙ=f⁽ⁿ⁾(z₀)/n!
收敛半径=z₀ 到最近奇点的距离
关键区别：**解析函数的泰勒级数一定收敛到函数本身**（L1 层的 e^{-1/x²} 是反例）

**L3 实变泰勒公式**：
- 对 AC 函数：有一阶泰勒公式（积分余项）
- 对更高阶：需要更高阶的 AC 条件
- a.e. 版本：在 a.e. 点处有渐近展开

**演化总结**：泰勒公式在 L1 层有多种余项形式（因为不一定收敛到函数），在 L2 层最完美（无穷级数且收敛到函数），在 L3 层最弱（低阶、a.e.）。

### 7.4 微积分基本定理的跨层演化

**L0 层**：牛顿-莱布尼茨直观发现——微分和积分互逆

**L1 层**：
- 第一部分：f 连续⇒F(x)=∫ₐˣ f 可导且 F'=f
- 第二部分：F 连续可导⇒F(b)-F(a)=∫ₐᵇ F'

**L2 层**：
- 解析函数的不定积分仍是解析函数
- 柯西积分公式是微积分基本定理的复变版本
- 沿路径积分只与端点有关（如果区域单连通且函数解析）

**L3 层**：
- 第一部分（Lebesgue 微分定理）：f∈L¹⇒F(x)=∫ₐˣ f 绝对连续且 F'=f a.e.
- 第二部分：F 绝对连续⇒F(b)-F(a)=∫ₐᵇ F'
- 关键：**绝对连续是微积分基本定理成立的充要条件**

**演化总结**：微积分基本定理的成立条件从 L1 的"连续可导"，到 L2 的"解析"，到 L3 的"绝对连续"。L3 层的条件最弱（绝对连续比连续可导弱得多），但也是最精确的刻画——恰好是不定积分的函数类。

## 第八章 函数正则性完整谱系

### 8.1 谱系总览

```
解析函数（实解析/复解析）
  ⊂
C^∞（光滑函数，无穷次可导）
  ⊂
C^k（k 阶导数连续，k≥1）
  ⊂
C¹（一阶导数连续）
  ⊂
可导（处处可导但导数不一定连续）
  ⊂
Lipschitz（满足 Lipschitz 条件）
  ⊂
绝对连续（AC）
  ⊂
有界变差（BV）
  ⊂
连续？（BV 不一定连续，连续不一定 BV）
  ⊂
可测（最广泛的函数类）
```

注意：连续和 BV 之间没有包含关系——存在连续但非 BV 的函数（x sin(1/x)），也存在 BV 但不连续的函数（阶梯函数）。

### 8.2 每一类函数的特征和定理

| 函数类 | 定义特征 | 可导性 | 微积分基本定理 | 代表反例 |
|---|---|---|---|---|
| 解析 | 幂级数收敛到函数 | 无穷次可导 | 成立 | 无（正则性极致） |
| C^∞ | 无穷次可导 | 无穷次可导 | 成立（如果导数可积） | e^{-1/x²}（非解析） |
| C^k | k 阶导数连续 | k 次可导 | 成立（k≥1） | C^k 但非 C^{k+1} |
| C¹ | 一阶导数连续 | 处处可导 | 成立 | 无 |
| 可导 | 处处可导 | 处处可导 | 导数不一定可积 | x²sin(1/x²)（导数不可积） |
| Lipschitz | |f(x)-f(y)|≤L|x-y| | a.e. 可导，导数有界 | 成立 | √x（非 Lipschitz） |
| AC | 小区间总变化被总长度控制 | a.e. 可导，导数可积 | **成立（充要条件）** | Cantor 函数（非 AC） |
| BV | 总变差有限 | a.e. 可导 | ∫f'≤总增量（等号不一定） | 阶梯函数（不连续） |
| 连续 | 极限值=函数值 | 不一定可导 | 不一定成立 | Weierstrass 函数（处处不可导） |
| 可测 | 原像可测 | 几乎不要求 | 不适用 | Dirichlet 函数（处处不连续） |

### 8.3 关键分界点

谱系中有几个关键的"分界点"：

1. **C¹ vs 可导**：C¹ 要求导数连续，可导只要求导数存在。导数不连续的可导函数（如 x²sin(1/x)）揭示了"可导"和"连续可导"的区别。

2. **Lipschitz vs AC**：Lipschitz 是 AC 的真子集。Lipschitz 函数的导数 a.e. 有界，AC 函数的导数 a.e. 可积但不一定有界。√x 是 AC 但非 Lipschitz 的经典例子。

3. **AC vs BV**：这是最重要的分界点！AC 函数满足微积分基本定理（∫f'=总增量），BV 函数只满足不等式（∫f'≤总增量）。Cantor 函数是 BV 但非 AC 的经典例子——它的上升"藏"在零测集里，没有被导数记录。

4. **BV vs 连续**：两者互不包含。BV 函数可以有跳跃（阶梯函数），连续函数可以有无穷振荡（x sin(1/x)）。

5. **连续 vs 可测**：连续函数是可测函数的真子集。可测函数可以处处不连续（Dirichlet 函数）。

### 8.4 正则性谱系的几何理解

**📐 几何图像**：函数正则性谱系的几何意义是"曲线的光滑程度"。
- **解析函数**：曲线"无限光滑"——每一点都可以用多项式无限逼近，曲线没有任何"折痕"
- **C^k**：曲线有 k 阶连续的"弯曲"——k 阶以下的曲率连续变化
- **C¹**：曲线有连续的切线——切线方向连续变化
- **可导**：曲线处处有切线，但切线方向可能不连续变化（有"抖动"）
- **Lipschitz**：曲线的斜率有界——不会"无限陡峭"
- **AC**：曲线的变化完全由斜率（导数）记录——没有"藏在零测集里"的变化
- **BV**：曲线的总变化有限——不会无限振荡，但可以有跳跃和"藏起来"的变化
- **连续**：曲线没有断点——但可以无限振荡、处处不可导
- **可测**：几乎不要求任何几何性质——可以是"完全混乱"的

正则性谱系的几何本质是"曲线光滑程度的层级——从无限光滑到完全混乱，每一层对应不同的定理成立"。

### 9.2 反例演化的规律

从反例演化链中可以看出几个规律：

1. **每一层都有前一层没有的新反例**：L1 层有处处不可导函数（L0 层无法想象），L2 层有本性奇点（L1 层没有对应），L3 层有 Cantor 函数（L1/L2 层没有对应）。

2. **反例的"狂野程度"随层级增加**：L1 层的反例最多是处处不可导，L2 层的反例可以取遍几乎所有值（本性奇点），L3 层的反例可以是"导数 a.e. 为零但非常数"（Cantor 函数）——完全违反 L1/L2 层的直觉。

3. **一些反例在多层出现，但意义不同**：如 √|xy| 在 L1 多元层是"偏导存在但不可微"，在 L2 复变层是"C-R 满足但不可导"——同一个函数在不同层级揭示不同的问题。

4. **反例定义了定理的边界**：每一个反例都对应一个定理的"不成立条件"——|x| 定义了"连续⇏可导"，Cantor 函数定义了"导数 a.e. 为零⇏常数"，e^{-1/x²} 定义了"C^∞⇏解析"。

### 9.3 最具标志性的三个反例

1. **Weierstrass 函数（L1 层）**：处处连续处处不可导——打破了"连续函数几乎处处可导"的直觉，标志着经典微分学的边界。

2. **e^{1/z} 的本性奇点（L2 层）**：在奇点附近取遍几乎所有复数值——展示了解析函数在奇点附近的"狂野"行为，是复分析独有的现象。

3. **Cantor 函数（L3 层）**：连续、单调、导数 a.e. 为零但非常数——打破了"导数为零⇒常数"的经典直觉，是实变函数论最具标志性的反例，定义了绝对连续的必要性。

## 第十章 充要关系演化图谱

### 10.1 "导数为零⇒常数"的充要条件演化

| 层级 | 命题 | 成立条件 | 反例 |
|---|---|---|---|
| L0 | 导数为零⇒常数 | 直观成立 | 无 |
| L1 | 处处导数为零⇒常数 | 处处可导+导数处处为零 | 无（成立） |
| L2 | 解析函数导数为零⇒常数 | 解析+导数为零 | 无（成立） |
| L3 | 导数 a.e. 为零⇒常数 | **不成立** | Cantor 函数 |
| L3 | 导数 a.e. 为零+绝对连续⇒常数 | **成立（充要条件）** | 无 |

关键蜕变：在 L3 层，"导数 a.e. 为零"不再蕴含"常数"——必须附加绝对连续条件。这是因为零测集上的行为可以决定函数的非常数性（Cantor 函数的上升发生在零测的 Cantor 集上）。

### 10.2 "微积分基本定理成立"的充要条件演化

| 层级 | 成立条件 | 函数类 |
|---|---|---|
| L0 | 直观成立（无严格条件） | 初等函数 |
| L1 第一部分 | f 连续 | 连续函数的不定积分 |
| L1 第二部分 | F 连续可导 | C¹ 函数 |
| L2 | F 解析 | 解析函数 |
| L3 第一部分 | f∈L¹ | 可积函数的不定积分（绝对连续） |
| L3 第二部分 | **F 绝对连续** | **AC 函数（充要条件）** |

关键蜕变：在 L3 层，微积分基本定理成立的充要条件是**绝对连续**——这比 L1 层的"连续可导"弱得多，但比"a.e. 可导"强。绝对连续恰好是"不定积分"的函数类的刻画。

### 10.3 "可导⇒连续"的充要条件演化

| 层级 | 命题 | 成立条件 |
|---|---|---|
| L1 | 处处可导⇒连续 | 成立 |
| L2 | 处处复可导⇒连续 | 成立（且更强：解析） |
| L3 | a.e. 可导⇒连续 | **不成立**（可测函数可处处不连续） |
| L3 | a.e. 可导+?⇒连续 | 需要附加条件（如 BV+某些条件） |

关键蜕变：在 L3 层，"a.e. 可导"不蕴含"连续"——因为可导只在一个满测度集合上成立，零测集上可以完全混乱。

### 10.4 "函数类=不定积分"的充要条件

这是 L3 层最核心的充要关系：

**定理**：F 是某个 L¹ 函数的不定积分，当且仅当 F 绝对连续。

这个定理的双向性：
- **正向**：如果 F(x)=C+∫ₐˣ f(t)dt，f∈L¹，则 F 绝对连续
- **反向**：如果 F 绝对连续，则 F'∈L¹ 且 F(x)=F(a)+∫ₐˣ F'(t)dt

这是 Lebesgue 积分理论最优美的结论之一——它精确刻画了"可以表示为积分的函数"的特征。

## 第十一章 存在性追溯图谱

### 11.1 可导存在性的空间基础

微分概念的每一层都依赖于特定的空间完备性：

| 层级 | 空间 | 完备性 | 可导存在性基础 |
|---|---|---|---|
| L0 | 实数直观 | 不明确 | 几何直观 |
| L1 | ℝ（实数域） | 实数完备性（确界原理等） | 中值定理、泰勒公式的证明 |
| L1 多元 | ℝⁿ | 欧氏空间完备性 | 多元中值定理、隐函数定理 |
| L2 | ℂ（复数域） | 复数域完备性（ℂ≅ℝ²） | 柯西积分定理、解析函数理论 |
| L3 | 测度空间 | 测度完备性（Lebesgue 测度完备） | a.e. 可导、Lebesgue 微分定理 |
| L3 弱导数 | Sobolev 空间 W^{k,p} | Sobolev 空间完备性（Banach/Hilbert） | 弱导数存在性 |
| L3 分布导数 | Schwartz 分布空间 | 分布空间完备性（拓扑向量空间） | 分布导数存在性 |

### 11.2 完备性的层级

```
实数完备性（确界原理、区间套、有限覆盖、Bolzano-Weierstrass）
  ↓ 推广
欧氏空间 ℝⁿ 完备性
  ↓ 等价
复数域 ℂ 完备性（ℂ≅ℝ²）
  ↓ 推广
Lebesgue 测度空间完备性（完备测度）
  ↓ 构造
Lᵖ 空间完备性（Banach 空间，1≤p≤∞）
  ↓ 构造
Sobolev 空间 W^{k,p} 完备性
  ↓ 构造
Schwartz 分布空间完备性（拓扑向量空间）
```

每一层空间的完备性都保证了相应层级微分概念的存在性定理：
- 实数完备性保证了中值定理（连续函数在闭区间上取最值）
- 复数完备性保证了柯西积分定理（积分与路径无关）
- 测度完备性保证了 Lebesgue 微分定理（a.e. 收敛）
- Sobolev 空间完备性保证了弱导数的存在性
- 分布空间完备性保证了任意可测函数都有分布导数

### 11.3 从"处处存在"到"几乎处处存在"到"弱存在"

可导性的存在性经历了三次弱化：

1. **处处存在**（L1/L2 层）：导数在定义域的每一点都存在
   - 优点：强结论，经典定理成立
   - 缺点：适用范围窄（很多函数不处处可导）

2. **几乎处处存在**（L3 层）：导数在满测度集合上存在，零测集上忽略
   - 优点：适用范围广（单调函数、BV 函数都 a.e. 可导）
   - 缺点：一些经典定理不成立（导数 a.e. 为零⇏常数），需要附加绝对连续

3. **弱存在/分布存在**（L3 深层）：通过分部积分或对偶定义导数
   - 优点：适用范围最广（任意可测函数、任意分布都有分布导数）
   - 缺点：导数不再是函数，而是分布；经典定理需要重新解释

这三次弱化是"存在性"与"适用性"的权衡——存在性越弱，适用范围越广，但结论也越弱。

## 第十二章 几何视角跨层演化

### 12.1 微分的几何本质：局部线性近似

贯穿所有四层，微分的几何本质是统一的：**微分是函数在一点处的局部线性近似**。

| 层级 | 线性近似对象 | 近似工具 | 几何图像 |
|---|---|---|---|
| L0 | 曲线 | 切线（直观） | 用切线代替曲线 |
| L1 一元 | 曲线 | 切线（严格定义） | 切线斜率=导数 |
| L1 多元 | 曲面 | 切平面 | 梯度=最陡方向，Hessian=弯曲 |
| L2 复变 | 复平面映射 | 相似变换（旋转+伸缩） | 共形映射，保角保形状 |
| L3 | 可测函数 | a.e. 切线/弱梯度 | 几乎处处有切线，零测集忽略 |

### 12.2 切线概念的跨层演化

**L1 一元切线**：曲线在一点处"最接近"的直线，斜率=导数。

**L1 多元切平面**：曲面在一点处"最接近"的平面，法向量=梯度（或 (-fₓ,-fᵧ,1)）。

**L2 复变共形映射**：复平面映射在一点处的局部行为是相似变换——旋转 arg f'(z₀) + 伸缩 |f'(z₀)|。这比切线更丰富——不仅有"方向"（旋转角），还有"大小"（伸缩率）。

**L3 a.e. 切线**：BV/AC 函数的图像几乎处处有切线——但在零测集上可以没有切线（如 Cantor 函数在 Cantor 集上不可导）。

### 12.3 极值/最值的几何跨层演化

**L1 一元极值**：山峰（极大值）和山谷（极小值），切线水平。

**L1 多元极值**：山峰、山谷、鞍点（Hessian 不定），切平面水平。

**L2 复变最大模**：没有普通极值（复数无序），但有最大模原理——|f| 的山峰只能在边界上，内部不能有山峰。

**L3 实变极值**：可测函数的极值概念弱化——a.e. 极值，几乎处处的山峰山谷。

### 12.4 曲率/弯曲的几何跨层演化

**L1 一元曲率**：K=|f''|/[1+(f')²]^{3/2}，描述曲线的弯曲程度。

**L1 多元曲率**：Hessian 矩阵描述曲面的弯曲，主曲率、高斯曲率、平均曲率。

**L2 复变曲率**：解析函数的映射保持角度（共形），但不保持曲率——曲率在映射下按一定公式变化。

**L3 实变曲率**：BV/AC 函数的曲率 a.e. 存在（如果二阶导数 a.e. 存在）。

### 12.5 几何视角的统一性

尽管各层的几何工具不同（切线、切平面、共形映射、a.e. 切线），但几何视角的核心是统一的：

1. **微分=局部线性近似**：所有层级的微分都是用线性对象（直线、平面、相似变换）在局部逼近非线性对象（曲线、曲面、映射）。

2. **导数=线性近似的参数**：一元导数是切线斜率，多元梯度是切平面的方向，复导数是相似变换的旋转+伸缩，弱导数是分布意义下的线性近似参数。

3. **高阶导数=弯曲程度**：二阶导数描述曲线/曲面的弯曲，Hessian 矩阵描述多元弯曲，高阶泰勒展开描述高阶近似。

4. **中值定理=局部与整体的桥梁**：中值定理用一点的导数（局部）描述区间上的平均变化率（整体）——在所有层级都是核心定理（虽然形式不同）。

5. **微积分基本定理=微分与积分的互逆**：所有层级的微积分基本定理都表达了"微分和积分是互逆运算"——只是成立条件不同。

几何视角的统一性说明：**微分学的本质是几何的——用线性近似研究非线性对象，用局部行为推断整体性质**。代数和分析的严格化只是为了让几何直觉精确化，并没有改变微分学的几何本质。

## 第十三章 微分学的历史-哲学反思

### 13.1 无穷小概念的变迁

微分学的历史核心是"无穷小"概念的变迁：

1. **牛顿-莱布尼茨时代（17 世纪）**：无穷小是"无限小但不为零"的量——直观但不严格（贝克莱悖论："已死量的幽灵"）。

2. **欧拉-拉格朗日时代（18 世纪）**：形式化操作——把无穷小当作代数符号进行运算，取得了大量结果但基础不牢。

3. **柯西-魏尔斯特拉斯时代（19 世纪）**：ε-δ 严格化——用极限语言代替无穷小，无穷小被"驱逐"出数学（成为"趋于零的变量"而非实体）。

4. **Lebesgue 时代（20 世纪初）**：几乎处处——进一步弱化，只要求在满测度集合上成立，零测集上的行为忽略。

5. **Robinson 非标准分析（1960 年代）**：无穷小的回归——在超实数框架中严格定义无穷小，证明了牛顿-莱布尼茨的直观操作可以被严格化。

### 13.2 潜无穷与实无穷

微分学的历史也涉及"潜无穷"与"实无穷"的哲学争论：

- **潜无穷**：无穷是一个过程（"趋于无穷"），永远不会完成。亚里士多德、高斯持这种观点。
- **实无穷**：无穷是一个完成的实体（"无穷集合"、"无穷小数"）。康托尔、戴德金持这种观点。

微分学的严格化（ε-δ）采用了潜无穷的观点——极限是"趋于"的过程，不是完成的实体。但实变函数论（Lebesgue 积分）采用了实无穷的观点——测度是对无穷集合的度量，a.e. 是对无穷集合的量化。

### 13.3 "处处"与"几乎处处"的哲学意义

从"处处可导"到"几乎处处可导"的转变，不仅是技术上的弱化，更有深刻的哲学意义：

1. **本体论**：数学对象的"存在"是否需要在每一点都成立？a.e. 可导函数在零测集上不可导，但我们仍然认为它"可导"（在 a.e. 意义下）。这说明数学中的"存在"可以是"几乎处处存在"。

2. **认识论**：人类对函数的认识是否需要掌握每一点的行为？a.e. 理论说明，忽略零测集上的行为不会影响积分、收敛等核心结论。这是一种"宏观"的认识方式——不纠结于个别点的异常。

3. **方法论**：从"逐点分析"到"测度分析"的转变——不再关心每一点的行为，而是关心集合的测度、函数的积分。这是 20 世纪数学的核心方法论转变之一。

### 13.4 局部与整体的辩证关系

微分学的核心辩证关系是"局部与整体"：

- **微分是局部的**：导数描述函数在一点附近的行为（局部变化率）。
- **积分是整体的**：积分描述函数在区间上的累积行为（整体面积）。
- **微积分基本定理**：局部（导数）与整体（积分）的桥梁——F(b)-F(a)=∫ₐᵇ F'。
- **中值定理**：局部（一点的导数）与整体（区间的平均变化率）的桥梁——f(b)-f(a)=f'(ξ)(b-a)。

从 L0 到 L3，局部与整体的关系不断演化：
- L1 层：中值定理建立了点态的局部-整体桥梁
- L2 层：柯西积分公式建立了边界（整体）与内部（局部）的桥梁
- L3 层：Lebesgue 微分定理建立了 a.e. 局部与整体的桥梁

### 13.5 微分学的统一性与多样性

微分学的四层蜕变展示了数学中"统一性与多样性"的辩证关系：

- **统一性**：微分的本质（局部线性近似）在所有四层都是统一的；微积分基本定理的核心思想（微分与积分互逆）在所有四层都成立（只是条件不同）；几何视角（切线、切平面、共形映射）在所有四层都有对应。

- **多样性**：每一层都有独特的概念（C-R 方程、解析函数、a.e. 可导、弱导数）、独特的定理（最大模原理、Lebesgue 微分定理、Radon-Nikodým 定理）、独特的反例（本性奇点、Cantor 函数）。

统一性说明微分学是一个有机的整体——不同层级是同一个核心思想的不同表现形式。多样性说明微分学是丰富的——每一层都有独特的问题和方法，不能互相替代。

## 第十五章 综合易错误区全集

### 15.1 D3-1 常见误区

1. **可导⇏连续可导**（导数不一定连续，如 x²sin(1/x)）
2. **连续⇏可导**（|x| 在 0 处）
3. **左右导数存在且相等⇏可导**（还需要函数在该点有定义——实际上左右导数存在且相等就蕴含可导，这是对的；但左右极限存在且相等不蕴含可导）
4. **导数为无穷大=不可导**（垂直切线是不可导的一种）

### 15.2 D3-2 常见误区

5. **洛必达法则可以用于任何不定式**（只能用于 0/0 和 ∞/∞，其他类型需要转化）
6. **洛必达法则失败=极限不存在**（洛必达法则失败时极限可能存在，需要用其他方法）
7. **泰勒公式的余项可以忽略**（余项决定了近似的精度和适用范围）
8. **中值定理的中值点可以具体求出**（中值定理只保证存在性，一般不能具体求出）

### 15.3 D3-3 常见误区

9. **f'(x)>0 是严格递增的必要条件**（x³ 严格递增但 f'(0)=0）
10. **驻点一定是极值点**（x³ 在 0 处是驻点但不是极值点）
11. **f''(x₀)=0⇒拐点**（x⁴ 在 0 处 f''=0 但不是拐点）
12. **牛顿法一定收敛**（x^{1/3} 的牛顿法发散）
13. **曲率只和二阶导数有关**（K=|f''|/[1+(f')²]^{3/2}，和一阶导数也有关）

### 15.4 D3-4 常见误区

14. **偏导数存在⇒连续**（xy/(x²+y²) 在原点偏导存在但不连续）
15. **偏导数存在⇒可微**（√|xy| 在原点偏导存在但不可微）
16. **可微⇒偏导数连续**（r²sin(1/r) 可微但偏导不连续）
17. **混合偏导数一定相等**（需要连续条件，xy(x²-y²)/(x²+y²) 不相等）
18. **驻点一定是极值点**（x²-y² 在原点是鞍点）
19. **拉格朗日乘数法得到的点一定是极值点**（只是候选点，需要进一步判断）

### 15.5 D3-5 常见误区

20. **复可导和实可导一样**（复可导要求全方向极限一致，强得多）
21. **C-R 方程满足就可导**（还需要 u,v 可微）
22. **在一点可导就在该点解析**（解析要求邻域内每一点可导，|z|² 只在原点可导但不解析）
23. **复三角函数有界**（sin z 和 cos z 在复平面上无界）
24. **复对数是单值函数**（复对数是多值函数，有无穷多个值）
25. **最大模原理对实函数也成立**（实函数可以在内部取最大值，最大模原理是解析函数特有的）
26. **泰勒级数收敛半径由实轴上的奇点决定**（由复平面上的最近奇点决定，1/(1+x²) 的收敛半径为 1 是因为复奇点 ±i）
27. **共形映射保持面积**（共形映射保持角度和局部形状，不保持面积）

### 15.6 D3-6 常见误区

28. **单调函数处处可导**（单调函数几乎处处可导，可以有不可导点，甚至无穷多个）
29. **∫f'=f(b)-f(a) 对所有单调函数成立**（只有绝对连续函数成立，Cantor 函数是反例）
30. **连续函数是有界变差函数**（x sin(1/x) 连续但非 BV）
31. **有界变差函数是连续函数**（阶梯函数是 BV 但不连续）
32. **一致连续⇒绝对连续**（x sin(1/x) 一致连续但非绝对连续）
33. **绝对连续⇒Lipschitz**（√x 绝对连续但非 Lipschitz）
34. **导数 a.e. 为零⇒常数**（Cantor 函数导数 a.e. 为零但非常数，需要绝对连续才成立）
35. **Lebesgue 微分定理说 F'=f 处处成立**（是 a.e. 成立，不是处处成立）
36. **a.e. 原函数唯一**（a.e. 意义下原函数不唯一，可差奇异函数；绝对连续条件下唯一）
37. **可积函数的不定积分处处可导**（是 a.e. 可导，在某些点可能不可导）

- D3-6 → 泛函分析（Sobolev 空间、BV 空间、分布理论）
- D3-6 → 偏微分方程（弱解、变分法）
- D3-6 → 几何测度论（高维微分理论、面积公式）
- D3-6 → 调和分析（极大函数、奇异积分）

### 19.2 类比

- 一元导数与多元梯度：都是"变化率"，一元是一个数（切线斜率），多元是一个向量（最陡方向）
- 一元微分与多元全微分：都是"线性近似"，一元是数乘，多元是线性映射（切平面）
- 一元极值与多元极值：都用二阶信息判别，一元用二阶导数符号，多元用 Hessian 正定性
- 实可导与复可导：都要求差商极限存在，实可导只要求左右方向，复可导要求全复平面方向
- 解析函数与 C^∞ 函数：都是无穷次可导，解析函数更强（泰勒级数收敛到函数）
- 处处可导与 a.e. 可导：都是"可导"，处处要求每一点，a.e. 只要求满测度集合
- 连续可导与绝对连续：都是"足够整齐"的函数类，C¹ 要求导数连续，AC 只要求导数 a.e. 可积
- 经典导数与弱导数：都是"导数"，经典导数逐点定义，弱导数通过分部积分定义
- 中值定理与最大模原理：都是"局部与整体的桥梁"，中值定理用一点导数描述整体平均，最大模原理说整体最大模在边界
- 微积分基本定理与柯西积分公式：都是"微分与积分的关系"，微积分基本定理说微分积分互逆，柯西积分公式说内部值由边界积分决定
- 黎曼积分与 Lebesgue 积分：都是积分，黎曼按定义域分割，Lebesgue 按值域分割；Lebesgue 可以积分更广泛的函数
- Cantor 函数与 Weierstrass 函数：都是"病态函数"，Weierstrass 处处连续处处不可导，Cantor 连续单调导数 a.e. 为零但非常数

### 19.3 推广

- 从一元到多元（偏导数、全微分、梯度、Hessian）
- 从实数到复数（复导数、C-R 方程、解析函数）
- 从处处到几乎处处（a.e. 可导、a.e. 连续、Lebesgue 点）
- 从经典导数到弱导数（Sobolev 空间、分部积分定义）
- 从弱导数到分布导数（Schwartz 分布、最广义导数）
- 从欧氏空间到流形（切空间、余切空间、外微分、联络）
- 从光滑函数到 Lipschitz 函数（Rademacher 定理、a.e. 可导）
- 从 Lipschitz 到 BV（分布梯度为有限测度）
- 从 BV 到可测（几乎不要求正则性）
- 从确定性函数到随机函数（Itô 微积分、随机微分方程）
- 从经典微分到非标准分析微分（超实数、无穷小实体）
- 从交换到非交换（非交换几何、量子微积分、q-导数）
- 从算术到几何（度量测度空间上的微分、Cheeger 导数）
- 从局部到非局部（分数阶导数、非局部微积分、积分-微分方程）

### 19.4 特例

- 常数函数：导数为零，所有层级都成立
- 线性函数：导数为常数，Lipschitz，绝对连续
- 多项式：C^∞，实解析（在实数域上），整函数（复系数多项式）
- 指数函数 eˣ：C^∞，实解析，整函数，无零点
- 三角函数 sin x, cos x：C^∞，实解析，整函数，有界（实轴上），无界（复平面上）
- 对数函数 ln x：C^∞（x>0），实解析，复对数多值
- |x|：连续，非可导（在 0 处），Lipschitz，绝对连续，BV
- x²sin(1/x)：可导，非 C¹（导数不连续），Lipschitz？（导数有界所以 Lipschitz）
- e^{-1/x²}：C^∞，非解析（实轴上），整函数？（复平面上有本性奇点在 0）
- Weierstrass 函数：连续，非 BV，处处不可导
- x sin(1/x)：连续，非 BV，非绝对连续
- √x：绝对连续，非 Lipschitz（导数在 0 附近无界）
- 阶梯函数：BV，非连续
- Cantor 函数：连续，单调，BV，非绝对连续，导数 a.e. 为零
- 有理点阶梯函数：单调，有无穷多个间断点，BV
- Dirichlet 函数：可测，处处不连续，非 Riemann 可积，Lebesgue 可积（积分为 0）
- z̄（共轭函数）：处处连续，处处不可导（复变意义下）
- |z|²：连续，只在原点可导（复变意义下），非解析
- e^{1/z}：解析（z≠0），本性奇点在 z=0

### 19.5 反例簇

- 连续但不可导：|x|, Weierstrass 函数
- 可导但导数不连续：x²sin(1/x), x²sin(1/x²)
- 驻点不是极值点：x³, x^{2k+1}
- f''=0 不是拐点：x⁴, x^{2k}
- C^∞ 但非解析：e^{-1/x²}, e^{-1/x⁴}
- 处处连续处处不可导：Weierstrass 函数, van der Waerden 函数
- 偏导存在但不连续：xy/(x²+y²)
- 偏导存在但不可微：√|xy|
- 可微但偏导不连续：r²sin(1/r)
- 混合偏导不相等：xy(x²-y²)/(x²+y²)
- 驻点是鞍点：x²-y²
- 处处不可导（复变）：z̄, Re z, Im z, |z|
- 一点可导但不解析：|z|²
- C-R 满足但不可导：√|xy|
- 可去奇点：sin z/z 在 z=0
- 极点：1/zⁿ 在 z=0
- 本性奇点：e^{1/z}, sin(1/z), cos(1/z)
- 非孤立奇点：1/sin(1/z)
- 单调但有无穷间断点：有理点阶梯函数
- 单调但导数 a.e. 为零：Cantor 函数
- 连续但非 BV：x sin(1/x)
- BV 但不连续：阶梯函数
- 连续单调但非 AC：Cantor 函数
- 一致连续但非 AC：x sin(1/x)
- AC 但非 Lipschitz：√x
- 导数有界但不 Riemann 可积：Volterra 函数
- 严格递增但导数 a.e. 为零：构造的严格递增奇异函数
- 可测但处处不连续：Dirichlet 函数
- 连续函数把零测集映为正测集：Cantor 函数
- 零测集但不可数：Cantor 集

> **模块结语 · D3 微分领域的总收束**：
>
> D3-7 微分的蜕变图谱是 D3 微分领域的收束总模块——把 D3-1 至 D3-6 的全部材料整合为一张完整的四层蜕变图谱。
>
> **四层结构**：L0 初等直觉（朴素变化率、切线、速度）→ L1 数学分析（ε-δ 严格定义，一元/多元经典微分学）→ L2 复变函数（解析函数的刚性微分，一次可导⇒无穷次可导）→ L3 实变函数（几乎处处可导、弱导数、分布导数，条件极弱）。
>
> **三条蜕变主线**：①严格化（朴素无穷小→ε-δ 极限→a.e. 极限/弱极限）；②维度抬升（一元→多元→复数→高维可测）；③条件弱化（处处可导→a.e. 可导→弱导数→分布导数）。
>
> **核心定理跨层演化**：中值定理从 L1 的点态形式，在 L2 中消失（被最大模原理替代），在 L3 中弱化为积分形式；链式法则在所有四层都成立（最稳定的微分法则）；泰勒公式在 L2 层最完美（收敛到函数），在 L3 层最弱（低阶 a.e.）；微积分基本定理的成立条件从 L1 的"连续可导"到 L2 的"解析"到 L3 的"绝对连续"（充要条件）。
>
> **函数正则性完整谱系**：解析⊂C^∞⊂C^k⊂C¹⊂Lipschitz⊂绝对连续(AC)⊂有界变差(BV)，连续和 BV 互不包含，可测是最弱的。每一类函数对应不同的定理成立——AC 是微积分基本定理成立的充要条件，BV 只满足不等式（∫f'≤总增量），Cantor 函数是 BV 但非 AC 的标志性反例。
>
> **反例演化链**：从 |x|（连续但不可导）→ Weierstrass（处处连续处处不可导）→ z̄（复变处处不可导）→ e^{1/z}（本性奇点）→ Cantor 函数（导数 a.e. 为零但非常数），每一层都有前一层没有的新反例，反例的"狂野程度"随层级增加。
>
> **充要关系演化**："导数为零⇒常数"在 L1/L2 成立，在 L3 不成立（需要附加绝对连续）；"微积分基本定理成立"的充要条件在 L3 是绝对连续；"可导⇒连续"在 L1/L2 成立，在 L3 不成立（a.e. 可导⇏连续）。
>
> **几何视角跨层统一**：微分的本质在所有四层都是"局部线性近似"——一元用切线，多元用切平面，复变用相似变换（旋转+伸缩），实变用 a.e. 切线/弱梯度。几何视角的统一性说明微分学的本质是几何的——代数和分析的严格化只是让几何直觉精确化。
>
> **历史-哲学反思**：无穷小概念从"已死量的幽灵"到 ε-δ 严格化到 a.e. 弱化为非标准分析的回归；潜无穷与实无穷的哲学争论；"处处"与"几乎处处"的本体论/认识论/方法论意义；局部与整体的辩证关系；统一性与多样性的辩证关系。
>
> 微分的蜕变图谱的核心洞察是：**微分概念从朴素直觉到实变函数经历了严格化、维度抬升、条件弱化三条主线的蜕变，每一层都不是简单推广而是本质变化——可导条件、核心定理、函数正则性、反例类型都在层层演化。但微分的几何本质（局部线性近似）在所有四层都是统一的，微积分基本定理的核心思想（微分与积分互逆）在所有四层都成立（只是条件不同）。绝对连续是"恰到好处"的函数类——它是微积分基本定理成立的充要条件，是不定积分的精确刻画。Cantor 函数是"正则性底线"的标志——连续、单调、导数 a.e. 为零但非常数，定义了绝对连续的必要性，也展示了 a.e. 条件与处处条件的本质区别。**
>
> D3 微分领域全部 7 个模块正式完成。下一步，D4 积分领域将建立积分学的完整体系——从不定积分到定积分，从 Riemann 积分到 Lebesgue 积分，从一元积分到多元积分，从积分计算到积分应用，最终收束为积分的蜕变图谱。
