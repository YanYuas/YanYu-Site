## 第一章 引言：从经典微分到实变微分

### 1.1 经典微分学的局限

经典微分学（数学分析中的微分学）研究的是连续函数、可导函数的微分理论。但在实变函数论中，我们需要处理更广泛的函数类——可测函数、Lebesgue 可积函数。这些函数可能处处不连续、处处不可导，经典微分学的工具完全失效。

实变函数论中的微分理论要回答的核心问题是：
1. **什么样的函数可以微分？**——在几乎处处（a.e.）意义下，单调函数、有界变差函数可以微分
2. **微分和积分的关系是什么？**——经典微积分基本定理 d/dx ∫ₐˣ f(t)dt=f(x) 在 Lebesgue 框架下是否成立？在什么条件下成立？
3. **什么样的函数是不定积分？**——绝对连续函数恰好是不定积分
4. **导数为零的函数是否一定是常数？**——在经典意义下是，但在实变意义下不是（Cantor 函数导数 a.e. 为零但非常数）

### 1.2 实变微分的核心工具

实变函数论中的微分理论依赖几个核心工具：
1. **Vitali 覆盖引理**：从一族区间中选出互不重叠的子族，覆盖原集合的绝大部分
2. **Hardy-Littlewood 极大函数**：控制函数在每一点附近的平均行为
3. **上升的太阳引理（Rising Sun Lemma）**：研究单调函数的微分
4. **Lebesgue 分解定理**：把有界变差函数分解为绝对连续部分、奇异部分和跳跃部分

## 第二章 Vitali 覆盖引理

### 2.1 Vitali 覆盖的定义

**定义**：设 E⊂ℝ，𝓑 是一族闭区间。如果对任意 x∈E 和任意 ε>0，存在区间 I∈𝓑 使得 x∈I 且 |I|&lt;ε，则称 𝓑 是 E 的一个 Vitali 覆盖。

换句话说，Vitali 覆盖意味着 E 中的每一点都可以被 𝓑 中任意小的区间覆盖。

### 2.2 Vitali 覆盖引理

**定理（Vitali 覆盖引理）**：设 E⊂ℝ 具有有限外测度，𝓑 是 E 的 Vitali 覆盖。则对任意 ε>0，存在 𝓑 中有限个互不相交的区间 I₁,...,Iₙ，使得
m*(E \ ⋃ᵢ₌₁ⁿ Iᵢ) &lt; ε

也就是说，可以从 Vitali 覆盖中选出有限个互不重叠的区间，覆盖 E 的绝大部分（剩下的部分测度任意小）。

### 2.3 Vitali 覆盖引理的证明思路

1. 因为 E 有有限外测度，可以取一个开集 O⊃E 且 m(O)&lt;∞
2. 只考虑包含在 O 中的区间（可以缩小覆盖族）
3. 贪心选择：每次选一个尽可能大的区间，然后去掉与它相交的区间
4. 重复这个过程，选出互不相交的区间序列
5. 证明未被覆盖的部分测度任意小（利用每个被去掉的区间都不超过选中区间的 3 倍）

### 2.4 Vitali 覆盖引理的意义

Vitali 覆盖引理是实变函数论中最基本的覆盖引理之一——它允许我们用互不重叠的区间来"几乎覆盖"任意集合。这是证明单调函数几乎处处可导、Lebesgue 微分定理等核心定理的关键工具。

Vitali 覆盖引理的思想可以推广到高维（用球代替区间），是几何测度论的基础。

### 2.5 几何理解

**📐 几何图像**：Vitali 覆盖引理的几何意义是"从一堆任意小的区间中选出互不重叠的子族，几乎覆盖整个集合"。想象你有一张桌子（集合 E），桌上撒满了各种大小的纸片（区间族 𝓑），每个点都被任意小的纸片覆盖（Vitali 覆盖）。Vitali 覆盖引理说：你可以从中选出有限张互不重叠的纸片，几乎覆盖整张桌子（剩下没被覆盖的部分面积任意小）。

证明中的"贪心选择"几何上就是：每次选一张尽可能大的纸片，然后把和它重叠的纸片都拿走（因为它们不够大，不值得选）。重复这个过程，选中的纸片互不重叠，而且覆盖了绝大部分面积。

Vitali 覆盖引理的几何本质是"用互不重叠的区间几乎覆盖任意集合——测度论中的'精选覆盖'"。

## 第三章 Hardy-Littlewood 极大函数

### 3.1 极大函数的定义

**定义**：设 f 是 ℝ 上的局部可积函数。Hardy-Littlewood 极大函数定义为
Mf(x)=sup_{I∋x} (1/|I|)∫_I |f(t)|dt
其中上确界取遍所有包含 x 的区间 I。

如果只考虑以 x 为中心的区间，则称为中心极大函数；如果考虑所有包含 x 的区间，则称为非中心极大函数。两者是等价的（相差一个常数因子）。

### 3.2 极大函数的基本性质

1. **Mf 是下半连续的**（因此是可测的）
2. **Mf≥|f| a.e.**
3. **次可加性**：M(f+g)≤Mf+Mg
4. **正齐次性**：M(αf)=|α|Mf

### 3.3 弱型估计

**定理（Hardy-Littlewood 极大不等式）**：对任意 λ>0，
m({x: Mf(x)>λ}) ≤ (C/λ)‖f‖₁
其中 C 是常数（一维情形 C=2 或 3，取决于中心/非中心）。

这是弱 (1,1) 型估计——极大函数不是 L¹ 有界的（即使 f∈L¹，Mf 也可能不在 L¹ 中），但满足弱型估计。

### 3.4 强型估计

**定理**：对 1&lt;p≤∞，Mf∈Lᵖ 且
‖Mf‖ₚ ≤ Cₚ‖f‖ₚ
其中 Cₚ 是只依赖于 p 的常数。

这是强 (p,p) 型估计——对 p>1，极大函数是 Lᵖ 有界的。

### 3.5 极大函数的应用

极大函数是调和分析中最基本的工具之一，主要应用：
1. **证明 Lebesgue 微分定理**——用极大函数控制平均收敛
2. **证明奇异积分算子的有界性**（Calderón-Zygmund 理论）
3. **证明点态收敛定理**
4. **函数空间的刻画**（Hardy 空间、BMO 等）

### 3.6 几何理解

**📐 几何图像**：Hardy-Littlewood 极大函数的几何意义是"函数在每一点附近的最大平均值"。对每一点 x，Mf(x) 是所有包含 x 的区间上 |f| 的平均值的最大值——它衡量了 f 在 x 附近"最坏情况下"的平均大小。

弱型估计的几何意义：如果 f 的 L¹ 范数有限，那么 Mf(x)>λ 的集合测度不超过 C‖f‖₁/λ——这意味着"平均值很大的地方"不会太多。可以用"日影"来理解：f 的图像下的面积是 ‖f‖₁，Mf>λ 的集合对应的"高度"超过 λ，面积不会超过总面积除以 λ。

极大函数的几何本质是"用局部最大平均值控制函数的局部行为——是证明点态收敛的关键工具"。

## 第四章 单调函数的微分

### 4.1 单调函数几乎处处可导

**定理（Lebesgue）**：单调函数在 ℝ 上几乎处处可导。

这是实变函数论中最经典的定理之一——即使单调函数可以有无穷多个间断点（如阶梯函数），它仍然几乎处处可导。

### 4.2 证明思路

证明单调函数几乎处处可导需要用到四个 Dini 导数：
- D⁺f(x)=limsup_{h→0⁺} [f(x+h)-f(x)]/h（右上导数）
- D₊f(x)=liminf_{h→0⁺} [f(x+h)-f(x)]/h（右下导数）
- D⁻f(x)=limsup_{h→0⁻} [f(x+h)-f(x)]/h（左上导数）
- D₋f(x)=liminf_{h→0⁻} [f(x+h)-f(x)]/h（左下导数）

f 在 x 处可导当且仅当四个 Dini 导数相等且有限。

证明步骤：
1. 证明 D⁺f≤D₋f a.e.（用 Vitali 覆盖引理）
2. 证明 D⁻f≤D₊f a.e.（同理）
3. 因为 D₊f≤D⁺f, D₋f≤D⁻f（定义），所以四个导数相等 a.e.
4. 证明导数有限 a.e.（利用单调函数在有限区间上的增量有限）

### 4.3 单调函数导数的积分

**定理**：如果 f 在 [a,b] 上单调递增，则 f' 在 [a,b] 上 Lebesgue 可积，且
∫ₐᵇ f'(x)dx ≤ f(b)-f(a)

注意是"≤"而不是"="——等号不一定成立！Cantor 函数就是一个反例：它单调递增，f(0)=0, f(1)=1，但 f'=0 a.e.，所以 ∫₀¹ f'=0 &lt; 1=f(1)-f(0)。

等号成立当且仅当 f 是绝对连续函数（见第六章）。

### 4.4 单调函数的结构

单调函数可以分解为：
f(x)=f_c(x)+f_s(x)+f_j(x)
其中：
- f_c 是绝对连续部分（导数可积，且 f_c(x)=f_c(a)+∫ₐˣ f_c'）
- f_s 是奇异连续部分（连续但导数 a.e. 为零，如 Cantor 函数）
- f_j 是跳跃部分（阶梯函数，由间断点的跳跃组成）

这是 Lebesgue 分解定理在单调函数上的体现。

### 4.5 几何理解

**📐 几何图像**：单调函数几乎处处可导的几何意义是"单调曲线几乎处处有切线"。单调函数的图像是一条"不断上升"的曲线——它可以有跳跃（间断点）、可以有平台（常数区间）、可以有 Cantor 函数那样的"魔鬼阶梯"（连续但几乎处处水平），但除了一个测度为零的集合外，曲线在每一点都有明确的切线（导数存在）。

为什么单调函数几乎处处可导？直观上，单调函数的"变化方向"是一致的（一直上升或一直下降），这种一致性限制了函数的"狂野程度"——它不能像 Weierstrass 函数那样处处振荡（因为振荡需要上升和下降交替）。单调函数可以有间断点，但间断点是可数的（单调函数的间断点至多可数）；可以有 Cantor 函数那样的奇异部分，但奇异部分的"上升"发生在一个测度为零的集合上（Cantor 集）。所以除了这些"坏点"外，函数是"光滑"的（可导的）。

∫f'≤f(b)-f(a) 的几何意义：曲线下的面积（导数的积分）不超过曲线的总上升量。对于绝对连续函数，面积等于总上升量（每一点的上升都"记录"在导数中）；对于奇异函数，部分上升发生在导数为零的地方（Cantor 集上），所以面积小于总上升量。

单调函数微分的几何本质是"单调曲线几乎处处有切线，导数的积分不超过总变化量——绝对连续时等号成立"。

## 第五章 有界变差函数

### 5.1 有界变差函数的定义

**定义**：设 f 是 [a,b] 上的函数。对 [a,b] 的任意分割 P: a=x₀&lt;x₁&lt;...&lt;xₙ=b，定义变差
V(f,P)=∑ᵢ₌₁ⁿ |f(xᵢ)-f(xᵢ₋₁)|
如果 sup_P V(f,P)&lt;∞，则称 f 是 [a,b] 上的有界变差函数，记为 f∈BV[a,b]。上确界称为 f 在 [a,b] 上的全变差，记为 Vₐᵇ(f)。

### 5.2 有界变差函数的例子

1. **单调函数**：单调函数是有界变差的，全变差=|f(b)-f(a)|
2. ** Lipschitz 函数**：满足 |f(x)-f(y)|≤L|x-y| 的函数是有界变差的
3. **连续可导函数**：如果 f' 在 [a,b] 上有界，则 f 是有界变差的，Vₐᵇ(f)=∫ₐᵇ |f'|
4. **有界变差函数不一定连续**：如阶梯函数是有界变差的（但有间断点）

### 5.3 有界变差函数的性质

1. **有界变差函数必有界**
2. **两个有界变差函数的和、差、积仍是有界变差函数**
3. **有界变差函数的复合不一定是有界变差函数**
4. **Jordan 分解定理**：f 是有界变差函数当且仅当 f 可以表示为两个递增函数的差：f=g-h，其中 g,h 递增。

Jordan 分解是有界变差函数最基本的结构定理——有界变差函数就是"两个单调函数的差"。

### 5.4 有界变差函数的微分

**定理**：有界变差函数几乎处处可导，且导数 Lebesgue 可积。

证明：由 Jordan 分解，f=g-h，g,h 单调递增。单调函数几乎处处可导（第四章），所以 f=g'-h' a.e.，且 |f'|≤g'+h' a.e.，可积。

### 5.5 有界变差函数的分解

有界变差函数可以进一步分解（Lebesgue 分解）：
f(x)=f_ac(x)+f_sc(x)+f_j(x)
其中：
- f_ac 是绝对连续部分
- f_sc 是奇异连续部分（连续但导数 a.e. 为零）
- f_j 是跳跃部分（由间断点的跳跃组成）

这个分解是唯一的（在相差常数的意义下）。

### 5.6 几何理解

**📐 几何图像**：有界变差函数的几何意义是"曲线的总变差（总长度的垂直分量）有限"。对函数图像做任意分割，把每一段的垂直变化量取绝对值相加，这个和的上确界就是全变差。全变差有限意味着曲线"不会无限振荡"——它的总上升量和总下降量都是有限的。

Jordan 分解的几何意义：任何有界变差曲线都可以看作两条单调上升曲线的差——一条记录"总上升"，一条记录"总下降"。这就像会计中的借贷记账——把所有收入记在一边，所有支出记在另一边，净额就是函数值。

有界变差函数几乎处处可导的几何意义：有界变差曲线几乎处处有切线。因为它是两个单调函数的差，而单调函数几乎处处有切线，所以差也几乎处处有切线。

Lebesgue 分解的几何意义：有界变差曲线可以分解为三部分——绝对连续部分（"光滑"部分，导数记录了所有变化）、奇异连续部分（"魔鬼阶梯"部分，连续但几乎处处水平，变化发生在测度为零的集合上）、跳跃部分（"阶梯"部分，在间断点跳跃）。

有界变差函数的几何本质是"总变差有限的曲线——两个单调函数的差，几乎处处可导，可分解为绝对连续+奇异连续+跳跃三部分"。

## 第六章 绝对连续函数

### 6.1 绝对连续的定义

**定义**：设 f 是 [a,b] 上的函数。如果对任意 ε>0，存在 δ>0，使得对 [a,b] 中任意有限个互不相交的开区间 (aᵢ,bᵢ)，只要 ∑(bᵢ-aᵢ)&lt;δ，就有 ∑|f(bᵢ)-f(aᵢ)|&lt;ε，则称 f 在 [a,b] 上绝对连续，记为 f∈AC[a,b]。

绝对连续比一致连续更强——一致连续只要求每个小区间上的变化小，绝对连续要求任意有限个小区间的变化之和小。

### 6.2 绝对连续函数的性质

1. **绝对连续⇒一致连续⇒连续**
2. **绝对连续⇒有界变差**
3. **Lipschitz 函数⇒绝对连续**
4. **两个绝对连续函数的和、差、积仍是绝对连续函数**
5. **绝对连续函数几乎处处可导**（因为是有界变差函数）
6. **绝对连续函数的导数 Lebesgue 可积**

### 6.3 绝对连续函数的刻画

**定理**：f 在 [a,b] 上绝对连续，当且仅当 f 在 [a,b] 上几乎处处可导，f'∈L¹[a,b]，且
f(x)=f(a)+∫ₐˣ f'(t)dt 对所有 x∈[a,b] 成立。

这是绝对连续函数最核心的刻画——绝对连续函数恰好就是"其导数的不定积分"。

### 6.4 绝对连续与微积分基本定理

**定理（微积分基本定理，Lebesgue 版本）**：
1. 如果 f∈L¹[a,b]，则 F(x)=∫ₐˣ f(t)dt 绝对连续，且 F'=f a.e.
2. 如果 F 在 [a,b] 上绝对连续，则 F'∈L¹[a,b]，且 F(x)-F(a)=∫ₐˣ F'(t)dt

这就是 Lebesgue 积分框架下的微积分基本定理——它在绝对连续的条件下完美成立。

### 6.5 几何理解

**📐 几何图像**：绝对连续的几何意义是"曲线在小区间上的总变化可以被区间总长度控制"。一致连续说的是：只要区间足够小，函数在这个区间上的变化就小。绝对连续更强：只要有限个互不相交区间的总长度足够小，函数在这些区间上的变化之和就小。这意味着曲线不能有"太多的小振荡"——即使每个振荡都很小，如果有无限多个振荡叠加起来，总变化也可能很大。绝对连续排除了这种情况。

绝对连续函数恰好是不定积分的几何意义：绝对连续曲线的"每一点上升"都被导数记录下来了——曲线的总上升量等于导数曲线下的面积。这和奇异函数（如 Cantor 函数）形成对比：奇异函数的部分上升发生在导数为零的地方（Cantor 集上），没有被导数记录，所以总上升量大于导数的积分。

绝对连续的几何本质是"曲线的变化完全由导数记录——总变化量等于导数的积分，是微积分基本定理成立的函数类"。

## 第七章 Lebesgue 微分定理

### 7.1 Lebesgue 微分定理

**定理（Lebesgue 微分定理）**：如果 f∈L¹_loc(ℝ)（局部可积），则
lim_{h→0} (1/h)∫ₓ^{x+h} f(t)dt = f(x) 对几乎所有 x∈ℝ 成立。

等价地，对不定积分 F(x)=∫ₐˣ f(t)dt，有 F'(x)=f(x) a.e.

这是实变函数论中最核心的定理之一——它说可积函数的不定积分几乎处处可导，且导数等于被积函数。

### 7.2 证明思路

Lebesgue 微分定理的证明依赖 Hardy-Littlewood 极大函数：

1. 对连续函数（如连续函数的稠密子集），定理显然成立（连续函数的不定积分可导且导数等于函数值）
2. 对一般可积函数 f，用连续函数 g 逼近 f（‖f-g‖₁&lt;ε）
3. 把平均差分解为两部分：|(1/h)∫ₓ^{x+h} f - f(x)| ≤ |(1/h)∫ₓ^{x+h} (f-g)| + |(1/h)∫ₓ^{x+h} g - g(x)| + |g(x)-f(x)|
4. 第一部分用极大函数控制（弱型估计），第二部分对连续函数趋于零，第三部分用可积函数在小测度集合外可以被连续函数逼近
5. 令 ε→0，得到平均差趋于零 a.e.

### 7.3 对称导数形式

Lebesgue 微分定理也可以写成对称形式：
lim_{h→0} (1/(2h))∫_{x-h}^{x+h} f(t)dt = f(x) a.e.

对称形式和非对称形式是等价的。

### 7.4 更一般的形式

Lebesgue 微分定理可以推广到更一般的平均核：
lim_{r→0} (1/|B(x,r)|)∫_{B(x,r)} f(t)dt = f(x) a.e.
其中 B(x,r) 是以 x 为中心、r 为半径的球（高维情形）。

### 7.5 几何理解

**📐 几何图像**：Lebesgue 微分定理的几何意义是"可积函数在几乎每一点处的小区间平均值趋于函数值"。对几乎每一点 x，当区间越来越小时，区间上 f 的平均值越来越接近 f(x)。这意味着可积函数在几乎每一点处都是"连续的"——在平均意义下连续。即使函数在该点不连续（甚至没有定义），只要它在该点附近的平均值趋于一个确定的值，这个值就是函数在该点的"代表值"。

对比经典微积分：经典微积分中，如果 f 连续，则不定积分 F(x)=∫ₐˣ f 可导且 F'=f。Lebesgue 微分定理把这个结论推广到了可积函数——即使 f 不连续，只要可积，F 就几乎处处可导且 F'=f a.e.。这是 Lebesgue 积分比 Riemann 积分强大的地方之一——它可以处理更广泛的函数类，同时保持微积分基本定理的核心结论。

Lebesgue 微分定理的几何本质是"可积函数几乎处处是平均连续的——不定积分几乎处处可导且导数等于被积函数"。

## 第八章 Lebesgue 点

### 8.1 Lebesgue 点的定义

**定义**：设 f∈L¹_loc(ℝ)。如果
lim_{h→0} (1/h)∫ₓ^{x+h} |f(t)-f(x)|dt = 0
则称 x 是 f 的 Lebesgue 点。

注意 Lebesgue 点的定义中用的是 |f(t)-f(x)| 的平均，而不是 (f(t)-f(x)) 的平均。Lebesgue 点比 Lebesgue 微分定理的结论更强——它要求绝对偏差的平均趋于零。

### 8.2 Lebesgue 点定理

**定理**：如果 f∈L¹_loc(ℝ)，则几乎所有 x 都是 f 的 Lebesgue 点。

这个定理比 Lebesgue 微分定理更强——Lebesgue 微分定理说 (1/h)∫ f→f(x) a.e.，而 Lebesgue 点定理说 (1/h)∫|f-f(x)|→0 a.e.。后者蕴含前者。

### 8.3 Lebesgue 点的意义

Lebesgue 点是可积函数的"好点"——在这些点处，函数在平均意义下是连续的。Lebesgue 点的概念在以下方面有重要应用：
1. **Fourier 级数的收敛性**：Dirichlet-Jordan 定理和 Dini 判别法都可以用 Lebesgue 点来表述
2. **奇异积分的点态收敛**：Poisson 积分、Hilbert 变换等在 Lebesgue 点处收敛
3. **函数的代表值**：在 Lebesgue 点处，f(x) 是函数的"自然"代表值（改变一个零测集上的值不影响 Lebesgue 点）

### 8.4 连续点与 Lebesgue 点的关系

- 如果 f 在 x 处连续，则 x 是 f 的 Lebesgue 点（显然）
- 但 Lebesgue 点不一定是连续点——例如 f(x)=1（x≠0）, f(0)=0，x=0 不是连续点，但是 Lebesgue 点（因为 |f(t)-f(0)|=1 a.e.，平均为 1≠0...等等，这个例子不对。让我重新想：f(x)=1 for x≠0, f(0)=0。在 x=0 处，(1/h)∫₀^h |f(t)-f(0)|dt=(1/h)∫₀^h 1 dt=1→1≠0，所以 0 不是 Lebesgue 点。正确的例子应该是 f(x)=1 for x≠0, f(0)=1（改变零测集不影响），或者 f 在 x 处有可去间断点但 f(x) 取极限值。

正确的关系：Lebesgue 点是"平均连续点"，比连续点弱——函数可以在 Lebesgue 点处不连续，但在该点附近的平均偏差趋于零。例如 f(x)=sin(1/x)（x≠0）, f(0)=0，x=0 不是 Lebesgue 点（因为振荡太剧烈）。但 f(x)=x sin(1/x)（x≠0）, f(0)=0，x=0 是连续点（也是 Lebesgue 点）。

### 8.5 几何理解

**📐 几何图像**：Lebesgue 点的几何意义是"函数在该点附近的平均绝对偏差趋于零"。在 Lebesgue 点处，函数图像在该点附近的"平均距离"趋于零——即使函数在该点不连续，只要它在该点附近的大部分地方都接近 f(x)，只有很小一部分偏离，那么平均绝对偏差就趋于零。

对比连续点：连续点要求"对任意 ε，存在 δ，使得 |t-x|&lt;δ 时 |f(t)-f(x)|&lt;ε"——所有附近的点都接近 f(x)。Lebesgue 点只要求"平均接近"——允许有一小部分点偏离，只要偏离部分的测度足够小。所以 Lebesgue 点比连续点弱（条件更宽松）。

Lebesgue 点的几何本质是"函数在该点处是平均连续的——大部分附近点都接近函数值，只有小部分偏离"。

## 第九章 微积分基本定理的 Lebesgue 版本

### 9.1 经典微积分基本定理的回顾

经典微积分基本定理（Riemann 积分框架下）：
1. 如果 f 在 [a,b] 上连续，则 F(x)=∫ₐˣ f(t)dt 在 [a,b] 上可导，且 F'(x)=f(x)
2. 如果 F 在 [a,b] 上连续可导，则 F(b)-F(a)=∫ₐᵇ F'(x)dx

经典版本要求 f 连续或 F 连续可导——条件比较强。

### 9.2 Lebesgue 版本的微积分基本定理

**定理（Lebesgue 微积分基本定理）**：
1. **第一部分**：如果 f∈L¹[a,b]，则 F(x)=∫ₐˣ f(t)dt 在 [a,b] 上绝对连续，且 F'(x)=f(x) a.e.
2. **第二部分**：如果 F 在 [a,b] 上绝对连续，则 F'∈L¹[a,b]，且 F(x)-F(a)=∫ₐˣ F'(t)dt 对所有 x∈[a,b] 成立

这就是 Lebesgue 积分框架下完整的微积分基本定理——它在绝对连续的条件下完美成立。

### 9.3 为什么需要绝对连续

如果 F 只是连续且几乎处处可导，F'∈L¹，那么 F(b)-F(a)=∫ₐᵇ F' 不一定成立。Cantor 函数就是反例——它连续、单调递增、F'=0 a.e.，但 F(1)-F(0)=1≠0=∫₀¹ F'。

绝对连续是保证"导数的积分等于函数增量"的充要条件——绝对连续函数的每一点变化都被导数记录下来了，没有"丢失"的变化。

### 9.4 更弱的条件

有没有比绝对连续更弱的条件，使得微积分基本定理成立？

- **F 连续 + F' 存在 a.e. + F'∈L¹ + F 是广义绝对连续（ACG*）**：在这些条件下，微积分基本定理成立。这是 Denjoy-Perron 积分（狭义 Denjoy 积分）的框架——比 Lebesgue 积分更广泛，可以积分某些不可 Lebesgue 积分的导数。
- **Henstock-Kurzweil 积分**：更一般的积分理论，微积分基本定理在"F 处处可导"的条件下成立（不需要 F' 可积）。

### 9.5 几何理解

**📐 几何图像**：Lebesgue 版本微积分基本定理的几何意义是"绝对连续曲线的总变化量等于导数曲线下的面积"。对于绝对连续函数，曲线的每一点上升/下降都被导数记录下来了——导数曲线下的面积恰好等于曲线的总变化量。这和经典版本一致，但适用范围更广——经典版本要求连续可导，Lebesgue 版本只要求绝对连续（允许导数在零测集上不存在，允许导数不连续）。

Cantor 函数的几何对比：Cantor 函数的图像是一条"魔鬼阶梯"——它连续上升，但几乎处处水平（导数为零）。它的上升发生在 Cantor 集上（一个测度为零的集合），这些上升没有被导数记录（导数在 Cantor 集上不存在或为无穷），所以导数的积分（0）小于总上升量（1）。绝对连续排除了这种情况——绝对连续函数的上升不能"藏"在零测集里。

微积分基本定理的几何本质是"绝对连续曲线的变化完全由导数记录——总变化量等于导数的积分"。

## 第十章 奇异函数与 Cantor 函数

### 10.1 奇异函数的定义

**定义**：如果 f 在 [a,b] 上连续、单调递增，且 f'=0 a.e.，但 f 不是常数，则称 f 是奇异函数。

奇异函数是实变函数论中最令人惊讶的对象之一——它连续、单调、导数几乎处处为零，但非常数。这在经典微积分中是不可想象的（经典微积分中，如果 f'=0 处处成立，则 f 是常数）。

### 10.2 Cantor 函数的构造

Cantor 函数（魔鬼阶梯）是最著名的奇异函数，构造如下：

1. **第一步**：在 [0,1] 上定义 f(0)=0, f(1)=1。去掉中间的三分开区间 (1/3,2/3)，在这个区间上定义 f(x)=1/2（常数）。
2. **第二步**：在剩下的两个区间 [0,1/3] 和 [2/3,1] 上，各去掉中间的三分开区间 (1/9,2/9) 和 (7/9,8/9)。在 (1/9,2/9) 上定义 f(x)=1/4，在 (7/9,8/9) 上定义 f(x)=3/4。
3. **第 n 步**：在剩下的 2ⁿ⁻¹ 个区间上，各去掉中间的三分开区间，在每个去掉的区间上定义 f 为常数（值为 k/2ⁿ）。
4. **极限**：在 Cantor 集 C（所有去掉区间的补集）上，定义 f(x)=sup{f(y): y&lt;x, y 在已定义的区间上}。

这样构造的 f 称为 Cantor 函数。

### 10.3 Cantor 函数的性质

1. **连续**：Cantor 函数在 [0,1] 上连续
2. **单调递增**：f(0)=0, f(1)=1，单调不减
3. **f'=0 a.e.**：在所有去掉的开区间上 f 是常数（导数为零），这些区间的总测度为 1，所以 f'=0 a.e.
4. **不是绝对连续**：因为 ∫₀¹ f'=0≠1=f(1)-f(0)
5. **是有界变差函数**：单调函数都是有界变差的
6. **满射**：f([0,1])=[0,1]——它把测度为零的 Cantor 集映到了 [0,1]！

### 10.4 Cantor 函数的意义

Cantor 函数是实变函数论中最重要的反例之一，它说明了：
1. **连续+单调+f'=0 a.e. ⇏ 常数**——经典微积分的结论在 a.e. 意义下不成立
2. **连续+单调 ⇏ 绝对连续**——绝对连续比连续+单调整齐更强
3. **微积分基本定理需要绝对连续**——没有绝对连续，∫f'=f(b)-f(a) 不成立
4. **连续函数可以把零测集映为正测集**——Cantor 函数把测度为零的 Cantor 集映到了测度为 1 的 [0,1]
5. **测度为零的集合可以有连续统的基数**——Cantor 集不可数但测度为零

### 10.5 几何理解

**📐 几何图像**：Cantor 函数的几何图像是一条"魔鬼阶梯"——它是一条连续上升的曲线，但几乎处处水平。曲线的"上升"全部发生在 Cantor 集上——一个测度为零、不可数、完全不连通的完美集合。在 Cantor 集上，曲线从 0 上升到 1，但因为 Cantor 集的测度为零，导数在几乎所有点处都是零（在去掉的区间上曲线是水平的）。

Cantor 函数的图像看起来像一个有无限多级的阶梯——每一级都很矮，但有无限多级，加起来总上升量为 1。这些阶梯的"落脚点"在 Cantor 集上——一个看起来"什么都没有"（测度为零）但实际上"什么都有"（不可数）的集合。

Cantor 函数的几何本质是"连续上升但几乎处处水平的魔鬼阶梯——上升发生在测度为零的 Cantor 集上，是绝对连续和奇异的分界线"。

## 第十一章 不定积分与原函数

### 11.1 不定积分的定义

**定义**：设 f∈L¹[a,b]。函数 F(x)=∫ₐˣ f(t)dt+C（C 是常数）称为 f 的不定积分。

不定积分是一族函数（相差一个常数），它们的导数都是 f a.e.

### 11.2 不定积分的性质

1. **绝对连续**：不定积分是绝对连续函数
2. **导数**：F'=f a.e.（Lebesgue 微分定理）
3. **线性**：∫(αf+βg)=α∫f+β∫g
4. **有界变差**：不定积分是有界变差函数，全变差=∫ₐᵇ |f|

### 11.3 原函数的存在性

**问题**：什么样的函数有原函数（即存在 F 使得 F'=f 处处或 a.e.）？

1. **连续函数**：连续函数一定有原函数（经典结论）
2. **可积函数**：可积函数有"a.e. 原函数"——不定积分 F 满足 F'=f a.e.
3. **导数函数**：什么样的函数可以是某个函数的导数？导数函数具有介值性（Darboux 定理——导数具有介值性质），所以不具有介值性的函数（如有跳跃间断点的函数）不可能是任何函数的导数
4. **Lebesgue 可积但不是导数**：存在 Lebesgue 可积函数不是任何函数的导数（处处意义下）

### 11.4 原函数的唯一性

如果 F 和 G 都是 f 的原函数（F'=G'=f 处处），则 F-G 是常数（经典结论）。

但在 a.e. 意义下，如果 F'=G'=f a.e.，则 F-G 不一定是常数——Cantor 函数的导数为 0 a.e.，但 Cantor 函数不是常数！所以在 a.e. 意义下，原函数不唯一（相差一个奇异函数）。

要保证唯一性，需要加上绝对连续的条件——绝对连续函数的导数 a.e. 为零，则函数是常数。

### 11.5 几何理解

**📐 几何图像**：不定积分的几何意义是"导数曲线下的累积面积"。F(x)=∫ₐˣ f(t)dt 表示从 a 到 x，f 曲线下的面积（带符号）。F 的导数是 f——面积的变化率等于被积函数的值。

不定积分是绝对连续函数的几何意义：累积面积曲线是绝对连续的——它的变化完全由被积函数决定，没有"藏在零测集里"的变化。这和奇异函数形成对比——奇异函数不是不定积分，因为它的变化没有被导数记录。

原函数唯一性的几何意义：在处处可导的意义下，导数相同的曲线只差一个常数（垂直平移）。但在 a.e. 可导的意义下，导数相同的曲线可以差一个奇异函数（如 Cantor 函数）——奇异函数的导数 a.e. 为零，但它不是常数，所以可以"加"在任何原函数上而不改变 a.e. 导数。

不定积分与原函数的几何本质是"累积面积曲线是绝对连续的——变化完全由被积函数记录，a.e. 原函数不唯一（可差奇异函数）"。

## 第十二章 高维微分理论

### 12.1 高维 Lebesgue 微分定理

**定理**：设 f∈L¹_loc(ℝⁿ)，则
lim_{r→0} (1/|B(x,r)|)∫_{B(x,r)} f(y)dy = f(x) 对几乎所有 x∈ℝⁿ 成立。

其中 B(x,r) 是以 x 为中心、r 为半径的球，|B(x,r)| 是球的体积。

高维 Lebesgue 微分定理的证明也依赖 Hardy-Littlewood 极大函数（高维版本）和 Vitali 覆盖引理（高维版本，用球代替区间）。

### 12.2 高维极大函数

高维 Hardy-Littlewood 极大函数：
Mf(x)=sup_{r>0} (1/|B(x,r)|)∫_{B(x,r)} |f(y)|dy

高维极大函数也满足弱 (1,1) 型估计和强 (p,p) 型估计（1&lt;p≤∞），常数依赖于维数 n。

### 12.3 高维 Vitali 覆盖引理

高维 Vitali 覆盖引理用闭球代替闭区间：从一族闭球中选出可数个互不相交的球，覆盖原集合的绝大部分（相差一个零测集）。

高维 Vitali 覆盖引理是几何测度论的基础工具。

### 12.4 高维有界变差与绝对连续

高维的有界变差函数和绝对连续函数理论更复杂：
- **BV 函数**：分布梯度是有限测度的函数
- **Sobolev 函数**：弱导数属于 Lᵖ 的函数
- **绝对连续函数**：在几乎所有直线上绝对连续（ACL 性质）

这些是高维实分析和偏微分方程的基础。

### 12.5 几何理解

**📐 几何图像**：高维微分理论的几何意义是"高维空间中函数在小球上的平均值趋于函数值"。在一维中，我们用区间来平均；在高维中，我们用球来平均。高维 Lebesgue 微分定理说：可积函数在几乎每一点处，小球上的平均值趋于函数值——这和一维的结论完全类似，只是把区间换成了球。

高维极大函数的几何意义：函数在每一点附近的最大球平均值——衡量函数在高维空间中"最坏情况下"的局部平均大小。

高维 Vitali 覆盖引理的几何意义：从一堆球中选出互不重叠的子族，几乎覆盖整个集合——和一维的区间覆盖类似，只是把区间换成了球。

高维微分理论的几何本质是"高维空间中的平均收敛——用球代替区间，结论和一维类似但证明更复杂"。

## 第十三章 反例库

### 13.1 单调函数反例

**反例 1**：单调函数可以有无穷多个间断点。f(x)=∑_{qₙ≤x} 1/2ⁿ，其中 {qₙ} 是有理数的枚举。f 单调递增，在每个有理点间断，在无理点连续。间断点可数（稠密），但 f 仍然几乎处处可导。

**反例 2**：单调函数的导数可以在正测度集合上为零。Cantor 函数单调递增，f'=0 a.e.（在测度为 1 的集合上导数为零），但非常数。

**反例 3**：∫f'&lt;f(b)-f(a)。Cantor 函数：∫₀¹ f'=0&lt;1=f(1)-f(0)。

### 13.2 有界变差反例

**反例 4**：连续函数不一定是有界变差函数。f(x)=x sin(1/x)（x≠0）, f(0)=0。f 在 [0,1] 上连续，但不是有界变差（振荡的总变差无穷大）。

**反例 5**：有界变差函数不一定连续。阶梯函数是有界变差的，但有间断点。

**反例 6**：两个有界变差函数的复合不一定是有界变差函数。

### 13.3 绝对连续反例

**反例 7**：连续+单调⇏绝对连续。Cantor 函数连续单调但不是绝对连续。

**反例 8**：一致连续⇏绝对连续。f(x)=x sin(1/x) 在 [0,1] 上一致连续（因为连续且闭区间），但不是绝对连续（不是有界变差）。

**反例 9**：Lipschitz⇒绝对连续，但绝对连续⇏Lipschitz。f(x)=√x 在 [0,1] 上绝对连续但不是 Lipschitz（在 0 附近导数无界）。

### 13.4 微分定理反例

**反例 10**：f∈L¹ 但不定积分 F 不是处处可导。F(x)=∫₀ˣ |t|^{-1/2}dt（在 0 附近可积），F 在 0 处不可导（导数无穷大）。但 F'=f a.e.（Lebesgue 微分定理保证 a.e. 可导）。

**反例 11**：连续函数可以处处不可导。Weierstrass 函数 f(x)=∑aⁿ cos(bⁿπx)（0&lt;a&lt;1, b 为奇数, ab>1+3π/2）处处连续但处处不可导。注意 Weierstrass 函数不是有界变差函数（总变差无穷大），所以不违反"有界变差函数 a.e. 可导"的定理。

**反例 12**：导数可以不 Riemann 可积。Volterra 函数的导数有界但不 Riemann 可积（在一个正测度的类 Cantor 集上不连续）。但 Volterra 函数的导数是 Lebesgue 可积的。

### 13.5 奇异函数反例

**反例 13**：Cantor 函数——连续、单调、f'=0 a.e.、非常数、不是绝对连续、把零测集映为正测集。

**反例 14**：存在严格递增的奇异函数。可以构造严格递增（不是单调不减）的连续函数，导数 a.e. 为零。

### 13.6 反例总结

| 反例类型 | 典型函数 | 关键特征 |
|---|---|---|
| 单调函数有无穷间断点 | 有理点阶梯函数 | 间断点可数稠密 |
| 单调函数导数a.e.为零 | Cantor函数 | 奇异函数 |
| 连续但非有界变差 | x sin(1/x) | 振荡总变差无穷 |
| 有界变差但不连续 | 阶梯函数 | 有跳跃 |
| 连续单调但非绝对连续 | Cantor函数 | 奇异 |
| 一致连续但非绝对连续 | x sin(1/x) | 非有界变差 |
| 绝对连续但非Lipschitz | √x | 导数无界 |

### 15.4 关键蜕变问题

**问题一：为什么实变函数论中的微分理论需要"几乎处处"的概念？**

回答：因为在 Lebesgue 积分的框架下，我们处理的函数类非常广泛（可测函数、可积函数），这些函数可能处处不连续、处处不可导。经典微分学的"处处可导"要求太强了，不适用于这些广泛的函数类。实变函数论的核心思想是"忽略零测集"——零测集上的行为不影响积分，也不影响大多数定理的结论。所以我们把"处处可导"弱化为"几乎处处可导"——只要在一个满测度集合上可导，就足够了。这种弱化使得微分理论可以应用于单调函数、有界变差函数等广泛的函数类，同时保持了定理的核心结论（如 Lebesgue 微分定理、微积分基本定理在绝对连续条件下成立）。

**问题二：Cantor 函数为什么是"导数几乎处处为零但非常数"的？这和经典微积分矛盾吗？**

回答：不矛盾。经典微积分说"如果 f'=0 处处成立，则 f 是常数"——注意是"处处"，不是"几乎处处"。Cantor 函数的导数在一个满测度集合上为零（在所有去掉的开区间上），但在 Cantor 集上（测度为零）导数不存在（或为无穷）。Cantor 函数的上升全部发生在 Cantor 集上——一个测度为零但不可数的集合。因为 Cantor 集的测度为零，导数在 a.e. 意义下为零，但函数在 Cantor 集上的上升没有被导数记录，所以函数不是常数。这说明"a.e. 导数为零"比"处处导数为零"弱得多——零测集上的行为可以决定函数的非常数性。要保证"导数 a.e. 为零⇒常数"，需要加上绝对连续的条件——绝对连续函数不能把变化"藏"在零测集里。

**问题三：绝对连续函数在微分理论中为什么如此重要？**

回答：绝对连续函数是微分理论中"恰到好处"的函数类——它足够广泛（包含所有连续可导函数、Lipschitz 函数、不定积分），又足够整齐（微积分基本定理完美成立）。具体来说：
1. **绝对连续⇒有界变差⇒a.e. 可导**：绝对连续函数有足够的正则性来保证 a.e. 可导
2. **绝对连续⇒F(x)=F(a)+∫ₐˣ F'**：微积分基本定理成立——函数的变化完全由导数记录
3. **不定积分⟺绝对连续**：绝对连续函数恰好就是 L¹ 函数的不定积分——这是双向的刻画
4. **绝对连续是"导数 a.e. 为零⇒常数"的充要条件**：排除了 Cantor 函数那样的奇异情况

绝对连续函数在经典微分（C¹）和实变微分（a.e. 可导）之间架起了桥梁——它既保留了经典微积分的核心结论（微积分基本定理），又适用于更广泛的函数类（不要求导数处处存在或连续）。

### 16.3 常见误区清单

1. **单调函数处处可导** → 错（单调函数几乎处处可导，可以有不可导点，甚至可以有无穷多个不可导点）

7. **导数 a.e. 为零⇒常数** → 错（Cantor 函数导数 a.e. 为零但非常数，需要绝对连续才成立）
8. **Lebesgue 微分定理说 F'=f 处处成立** → 错（是 a.e. 成立，不是处处成立）
9. **a.e. 原函数唯一** → 错（a.e. 意义下原函数不唯一，可差奇异函数；绝对连续条件下唯一）
10. **可积函数的不定积分处处可导** → 错（是 a.e. 可导，在某些点可能不可导，如被积函数在该点附近无界时）

### 18.2 类比

- 经典导数与 a.e. 导数：都是"变化率"，经典要求处处存在，a.e. 只要求几乎处处存在
- 连续可导与绝对连续：都是"足够整齐"的函数类，C¹ 要求导数连续，AC 只要求导数 a.e. 存在且可积
- Riemann 可积与 Lebesgue 可积：Riemann 积分要求几乎处处连续，Lebesgue 积分只要求可测
- 经典微积分基本定理与 Lebesgue 微积分基本定理：经典要求连续可导，Lebesgue 要求绝对连续
- 处处导数为零与 a.e. 导数为零：处处为零⇒常数，a.e. 为零⇏常数（Cantor 函数）
- 单调函数与有界变差函数：单调函数是 BV 的特例，BV=两个单调函数的差
- 绝对连续与 Lipschitz：Lipschitz⇒AC，AC⇏Lipschitz
- 原函数与不定积分：原函数是导数等于 f 的函数，不定积分是 L¹ 函数的积分（是绝对连续的原函数）
- Vitali 覆盖与 Besicovitch 覆盖：都是覆盖引理，Vitali 用区间/球，Besicovitch 用于更一般的度量空间
- 一维微分与高维微分：一维用区间平均，高维用球平均，结论类似

### 18.3 推广

- 从一维到高维（高维 Lebesgue 微分定理、高维极大函数）
- 从区间到球到更一般的集合（微分基的理论）
- 从 Lebesgue 测度到一般测度（关于一般测度的微分理论）
- 从函数到分布（分布导数、Schwartz 分布）
- 从经典导数到弱导数（Sobolev 空间）
- 从有界变差到 BV 函数（分布梯度为有限测度）
- 从绝对连续到 ACL 函数（高维绝对连续）
- 从 Lebesgue 积分到 Denjoy 积分（更广泛的积分，微积分基本定理在更弱条件下成立）
- 从 Lebesgue 积分到 Henstock-Kurzweil 积分（最一般的积分，处处可导函数的导数都可积）

- 从实直线到度量空间（度量空间上的测度微分理论）

### 18.4 特例

- 常数函数：绝对连续，导数为零，全变差为零
- 线性函数 f(x)=ax+b：Lipschitz，绝对连续，导数=a，全变差=|a|(b-a)
- C¹ 函数（闭区间上）：Lipschitz（导数有界），绝对连续
- Lipschitz 函数：绝对连续，导数 a.e. 存在且有界
- 单调函数：有界变差，a.e. 可导，∫f'≤总增量
- 阶梯函数：有界变差，不连续（有跳跃），导数 a.e. 为零
- Cantor 函数：连续单调，有界变差，非绝对连续，导数 a.e. 为零，奇异函数
- x sin(1/x)：连续，非有界变差，非绝对连续
- √x：绝对连续，非 Lipschitz（导数在 0 附近无界）
- Weierstrass 函数：连续，非有界变差，处处不可导

### 18.5 反例簇

- 单调但有无穷间断点：有理点阶梯函数
- 单调但导数 a.e. 为零：Cantor 函数
- 连续但非有界变差：x sin(1/x)
- 有界变差但不连续：阶梯函数
- 连续单调但非绝对连续：Cantor 函数
- 一致连续但非绝对连续：x sin(1/x)
- 绝对连续但非 Lipschitz：√x
- 处处连续处处不可导：Weierstrass 函数
- 导数有界但不 Riemann 可积：Volterra 函数
- 导数 a.e. 为零但非常数：Cantor 函数
- 严格递增但导数 a.e. 为零：构造的严格递增奇异函数

> **模块结语 · D3 微分领域的实变篇章**：
>
> D3-6 实变函数中的微分是 D3 微分领域的实变篇章——从经典微分到实变微分，微分学进入了"正则性的底线"。
>
> **Vitali 覆盖引理与极大函数**：Vitali 覆盖引理允许用互不重叠的区间几乎覆盖任意集合，Hardy-Littlewood 极大函数控制函数在每一点附近的最大平均值——这两个工具是实变微分理论的基石。
>
> **单调函数与有界变差函数**：单调函数几乎处处可导——即使有无穷多个间断点，即使有 Cantor 函数那样的奇异部分，单调曲线几乎处处有切线。有界变差函数是两个单调函数的差（Jordan 分解），因此也几乎处处可导。∫f'≤f(b)-f(a)——导数的积分不超过总变化量，等号当且仅当绝对连续。
>
> **绝对连续函数**：绝对连续是"恰到好处"的函数类——它足够广泛（包含所有 C¹、Lipschitz、不定积分），又足够整齐（微积分基本定理完美成立）。绝对连续函数恰好就是 L¹ 函数的不定积分——函数的变化完全由导数记录，没有"藏在零测集里"的变化。
>
> **Lebesgue 微分定理与微积分基本定理**：Lebesgue 微分定理说可积函数的不定积分几乎处处可导且导数等于被积函数。微积分基本定理在绝对连续条件下完美成立——这是 Lebesgue 积分比 Riemann 积分强大的地方之一。
>
> **奇异函数与 Cantor 函数**：Cantor 函数是实变函数论中最令人惊讶的对象——连续、单调、导数几乎处处为零，但非常数。它的上升发生在测度为零的 Cantor 集上，没有被导数记录。Cantor 函数说明了"a.e. 导数为零"不等于"处处导数为零"，也说明了绝对连续的必要性。
>
> **高维微分理论**：高维 Lebesgue 微分定理用球代替区间，结论和一维类似——可积函数在几乎每一点处小球上的平均值趋于函数值。高维理论发展为 Sobolev 空间、几何测度论和调和分析。
>
> **跨层蜕变**：从 L0 初等直觉到 L1 经典微分到 L2 复变（解析函数，正则性的极致）到 L3 实变（a.e. 导数，正则性的底线），微分概念不断演化——解析函数是最强的函数类，可测函数是最弱的函数类，绝对连续函数是微积分基本定理成立的函数类。
>
> 几何视角贯穿全章：Vitali 覆盖是精选覆盖、极大函数是最大平均、单调曲线几乎处处有切线、有界变差是总变差有限、绝对连续是变化完全由导数记录、Lebesgue 微分定理是平均连续、Cantor 函数是魔鬼阶梯、高维微分是球上平均——所有实变微分概念都有清晰的几何图像。
>
> 实变函数中的微分的核心洞察是：**实变微分理论的核心是"几乎处处"——忽略零测集上的行为，使得微分理论可以应用于广泛的函数类（单调、BV、可积），同时保持核心结论（Lebesgue 微分定理、微积分基本定理在绝对连续条件下成立）。绝对连续是"恰到好处"的函数类——它是微积分基本定理成立的充要条件，是 L¹ 函数不定积分的刻画。Cantor 函数是"正则性底线"的标志——连续、单调、导数 a.e. 为零但非常数，说明了 a.e. 条件和处处条件的本质区别，也说明了绝对连续的必要性。**
>
