## 本模块核心考点

1. **间断点的完整分类**：第一类（可去、跳跃）、第二类（无穷、振荡）
2. **单调函数的间断点定理**：都是第一类、至多可数个
3. **Dirichlet 函数**：处处不连续
4. **Thomae 函数**：有理点间断、无理点连续
5. **Weierstrass 函数**：处处连续处处不可导
6. **Cantor 函数**：单调连续但导数几乎处处为 0
7. **Baire 纲定理**：大多数连续函数处处不可导

## L0 初等直觉层

> **引导语**：间断点的直觉从断裂开始。函数图像在哪里断了？为什么有些断裂可以修复，有些不能？病态函数揭示了连续性的边界在哪里？这一层有3道直觉题，关键是建立对间断点分类的直观感觉。

**【D2-3-001】** 为什么说"研究间断点就是研究连续的反面"？为什么说"理解连续必须理解不连续"？

- **难度**：★
- **对应知识点**：间断点的意义
- **解答**：
  **为什么研究间断点**：
  连续性是分析学中最基本的正则性条件。但要真正理解连续，必须研究它的反面——不连续。
  
  **为什么理解连续必须理解不连续**：
  
  1. **连续是"不常见"的**：在数学上，"大多数"函数是不连续的（Baire 纲定理）。连续函数只是"例外"。
  2. **间断点揭示了连续的边界**：知道函数在哪里不连续，就知道了它在哪里连续——连续的范围就是间断点的补集。
  3. **病态函数推动了理论发展**：Dirichlet 函数、Thomae 函数、Weierstrass 函数等病态函数，推动了 Riemann 积分、Lebesgue 积分、Baire 纲理论的发展。
  
  **一句话总结**：连续不是函数的默认性质——它是需要验证的正则性条件。理解不连续，就是理解连续的边界在哪里。∎
- **一句话点评**：理解连续必须理解不连续——连续是需要验证的正则性条件，不是函数的默认性质。

**【D2-3-002】** 写出间断点的完整分类。第一类和第二类的区别是什么？

- **难度**：★
- **对应知识点**：间断点分类
- **解答**：
  **间断点分类**：
  
  **第一类间断点**：左右极限都存在（有限值）
  1. **可去间断点**：左极限=右极限≠函数值（或函数值不存在）
     - 例子：f(x)=sin x/x 在 x=0 处
  2. **跳跃间断点**：左极限≠右极限
     - 例子：f(x)=x/|x| 在 x=0 处
  
  **第二类间断点**：左右极限至少有一个不存在（或为无穷大）
  1. **无穷间断点**：极限为无穷大
     - 例子：f(x)=1/x 在 x=0 处
  2. **振荡间断点**：极限振荡不存在
     - 例子：f(x)=sin(1/x) 在 x=0 处
  
  **第一类和第二类的区别**：
  - 第一类：左右极限都存在（有限值）——函数在该点附近"行为有界"
  - 第二类：至少一个不存在（或无穷）——函数在该点附近"行为无界"或"振荡"∎
- **一句话点评**：第一类=左右极限都存在（可去、跳跃）；第二类=至少一个不存在（无穷、振荡）。

**【D2-3-003】** 什么是可去间断点？为什么叫"可去"？它和跳跃间断点有什么区别？

- **难度**：★
- **对应知识点**：可去间断点
- **解答**：
  **可去间断点**：
  左右极限存在且相等，但不等于函数值（或函数在该点无定义）。
  
  **为什么叫"可去"**：
  因为可以"去掉"这个间断点——只需要重新定义 f(x₀)=lim_{x→x₀} f(x)，函数就在 x₀ 处连续了。
  
  **和跳跃间断点的区别**：
  - 可去：左右极限相等——只是函数值"填错了"
  - 跳跃：左右极限不等——函数值"跳了一下"，无法通过重新定义来修复
  
  **例子**：
  - 可去：f(x)=sin x/x 在 x=0 处（极限=1，f(0) 未定义）
  - 跳跃：f(x)=x/|x| 在 x=0 处（左极限=-1，右极限=1）
  
  **几何图像**：
  - 可去间断点：图像在该点有一个"洞"——补上这个点就连贯了
  - 跳跃间断点：图像在该点有一个"断层"——左右两边高度不同∎
- **一句话点评**：可去间断点 = 极限存在但函数值不对。重新定义函数值就"可去"了。跳跃=左右极限不等，无法修复。

## L1 数学分析层

> **引导语**：从直觉到严格。这一层涵盖间断点的分类（第一类、第二类）、可去间断点、跳跃间断点、无穷间断点、振荡间断点，以及 Dirichlet 函数、Riemann 函数等病态函数。

**【D2-3-004】** 判断下列函数在 x=0 处的间断点类型：
(a) f(x)=sin x / x
(b) f(x)=x/|x|
(c) f(x)=1/x
(d) f(x)=sin(1/x)

- **难度**：★
- **对应知识点**：间断点类型判断
- **解答**：
  (a) **f(x)=sin x / x**：
  lim_{x→0} sin x / x = 1。
  左极限=右极限=1，但 f(0) 未定义（或不等于 1）。
  **类型**：可去间断点（第一类）。
  
  (b) **f(x)=x/|x|**：
  左极限 lim_{x→0⁻} x/|x| = -1。
  右极限 lim_{x→0⁺} x/|x| = 1。
  左极限≠右极限。
  **类型**：跳跃间断点（第一类），跳跃度=2。
  
  (c) **f(x)=1/x**：
  左极限 lim_{x→0⁻} 1/x = -∞。
  右极限 lim_{x→0⁺} 1/x = +∞。
  极限为无穷大。
  **类型**：无穷间断点（第二类）。
  
  (d) **f(x)=sin(1/x)**：
  lim_{x→0} sin(1/x) 不存在（在 [-1,1] 之间振荡）。
  **类型**：振荡间断点（第二类）。∎
- **一句话点评**：可去=极限存在但≠函数值；跳跃=左右极限不等；无穷=极限为无穷；振荡=极限振荡。

**【D2-3-005】** 什么是"病态函数"？为什么说它们是分析学严格化的产物？

- **难度**：★
- **对应知识点**：病态函数的意义
- **解答**：
  **病态函数**：
  指那些"反直觉"的函数——它们打破了"函数应该很光滑、很连续"的直觉。
  
  **常见的病态函数**：
  1. Dirichlet 函数：处处不连续
  2. Thomae 函数：有理点间断、无理点连续
  3. Weierstrass 函数：处处连续处处不可导
  4. Cantor 函数：单调连续但导数几乎处处为 0
  
  **为什么是分析学严格化的产物**：
  在微积分创立初期（牛顿、莱布尼茨时代），数学家默认函数都是"好"的——连续、可导、甚至光滑。
  
  但 19 世纪的严格化运动（柯西、魏尔斯特拉斯等）揭示了大量"病态"函数——这些函数都是在严格化过程中"构造"出来的。
  
  严格化让数学家能够精确地定义连续性、可导性，然后构造出"反例"来检验理论的边界。
  
  **一句话总结**：病态函数不是"怪物"——它们是分析学严格化的产物，是理解分析学本质的关键工具。∎
- **一句话点评**：病态函数是分析学严格化的产物——严格化让数学家能够精确地定义概念，然后构造反例来检验理论边界。

### ★★ 进阶应用

**【D2-3-006】** 证明：单调函数的所有间断点都是第一类间断点。

- **难度**：★★
- **对应知识点**：单调函数间断点定理（第一部分）
- **解答**：
  **证明**：
  设 f 单调递增。对任意 x₀∈I，考虑左极限 lim_{x→x₀⁻} f(x)。
  
  因为 f 单调递增，当 x&lt;x₀ 时 f(x)≤f(x₀)，所以 {f(x) : x&lt;x₀} 有上界 f(x₀)。
  
  由确界原理，sup{f(x) : x&lt;x₀} 存在。可以证明这个上确界就是左极限。
  
  同理，右极限 lim_{x→x₀⁺} f(x) = inf{f(x) : x>x₀} 存在。
  
  所以左右极限都存在，间断点只能是第一类。∎
  
  **为什么单调函数不会有第二类间断点**：
  因为单调函数的图像"不会回头"——它整体上升（或下降）。
  所以它不会"振荡"（不会上下跳），也不会"冲向无穷"（在有界区间上有界）。
  
  **几何图像**：单调函数的图像是"阶梯状"的——整体上升，但在某些点有"跳跃"。因为单调，所以不会有振荡。∎
- **一句话点评**：单调函数的间断点都是第一类——因为单调，所以不会振荡，也不会（在有界区间上）冲向无穷。

**【D2-3-007】** 证明：单调函数的间断点至多可数个。

- **难度**：★★
- **对应知识点**：单调函数间断点定理（第二部分）
- **解答**：
  **证明**：
  设 f 单调递增。对每个间断点 x₀，定义开区间 I_{x₀}=(lim_{x→x₀⁻} f(x), lim_{x→x₀⁺} f(x))（跳跃区间）。
  
  因为 f 单调递增，不同间断点对应的跳跃区间不相交（若 x₁&lt;x₂，则 lim_{x→x₁⁺} f(x)≤f((x₁+x₂)/2)≤lim_{x→x₂⁻} f(x)，所以 I_{x₁} 在 I_{x₂} 左边，不相交）。
  
  每个非空开区间包含一个有理数，而有理数可数，所以跳跃区间至多可数个，间断点至多可数个。∎
  
  **为什么可数**：
  每个跳跃区间对应一个有理数——有理数可数，所以跳跃区间可数，间断点可数。
  
  **几何图像**：单调函数的跳跃区间是"垂直缺口"——这些缺口互不相交，每个缺口里有一个有理数。有理数可数，所以缺口可数。∎
- **一句话点评**：单调函数的间断点至多可数——跳跃区间互不相交，每个区间对应一个有理数，有理数可数。

**【D2-3-008】** 证明 Dirichlet 函数 D(x)=1（x 有理）, 0（x 无理）在任意点都不连续。

- **难度**：★★
- **对应知识点**：Dirichlet 函数
- **解答**：
  **证明**：
  对任意 x₀，取有理数列 rₙ→x₀（有理数在实数中稠密），则 D(rₙ)=1→1。
  
  取无理数列 sₙ→x₀（无理数也稠密），则 D(sₙ)=0→0。
  
  两条数列的极限不同（1 vs 0），所以 D 在 x₀ 处不连续。∎
  
  **为什么这个证明很漂亮**：
  - 只需要两条数列
  - 利用了有理数和无理数在实数中都稠密
  - 非常简洁地证明了"处处不连续"
  
  **几何图像**：Dirichlet 函数的图像是"两条虚线"——y=1 上的有理点和 y=0 上的无理点。因为有理数和无理数都稠密，所以这两条"虚线"在任何区间内都有无穷多个点，且互相交织。∎
- **一句话点评**：Dirichlet 函数处处不连续的证明：有理数列→1，无理数列→0——两条路径极限不同。

**【D2-3-009】** 证明 Thomae 函数 T(x)=1/q（x=p/q 既约分数）, 0（x 无理）在无理点连续。

- **难度**：★★
- **对应知识点**：Thomae 函数
- **解答**：
  **证明**：
  设 x₀ 为无理数。需要证明 lim_{x→x₀} T(x)=0=T(x₀)。
  
  ∀ε>0，考虑满足 T(x)≥ε 的点 x。这些点只能是有理数 p/q，且 1/q≥ε，即 q≤1/ε。
  
  对于每个 q≤1/ε，满足 |p/q - x₀|&lt;1 的 p 只有有限个（因为 p 在 (q x₀ - q, q x₀ + q) 内，有限个整数）。
  
  所以满足 T(x)≥ε 且 |x-x₀|&lt;1 的点只有有限个（有限个 q，每个 q 有限个 p）。
  
  取 δ 为这些点到 x₀ 的最小距离（如果没有这样的点，取 δ=1），则当 |x-x₀|&lt;δ 时，T(x)&lt;ε。
  
  所以 lim_{x→x₀} T(x)=0，T 在无理点 x₀ 处连续。∎
  
  **为什么这个证明很巧妙**：
  满足 T(x)≥ε 的点只有有限个——因为分母 q≤1/ε 的有理数只有有限个。
  所以在无理点附近，只有有限个"高点"——避开这些高点，T(x) 就很小。∎
- **一句话点评**：Thomae 函数在无理点连续——满足 T(x)≥ε 的点只有有限个（q≤1/ε 的有理数有限）。

**【D2-3-010】** 证明 Thomae 函数在有理点不连续。它的间断点是什么类型？

- **难度**：★★
- **对应知识点**：Thomae 函数的有理点间断
- **解答**：
  **证明**：
  设 x₀=p/q 为有理数（既约分数）。则 T(x₀)=1/q>0。
  
  取无理数列 sₙ→x₀（无理数稠密），则 T(sₙ)=0→0≠1/q=T(x₀)。
  
  由 Heine 定理，lim_{x→x₀} T(x)≠T(x₀)，所以 T 在有理点 x₀ 处不连续。∎
  
  **间断点类型**：
  实际上，lim_{x→x₀} T(x)=0（和无理点一样，因为满足 T(x)≥ε 的点有限）。
  
  但 T(x₀)=1/q≠0。
  
  所以有理点是**可去间断点**——极限存在（=0）但不等于函数值（=1/q）。∎
  
  **一句话总结**：
  Thomae 函数：有理点=可去间断点，无理点=连续点。
  这是一个"有理点间断、无理点连续"的经典例子。∎
- **一句话点评**：Thomae 函数在有理点是可去间断点——极限=0 但函数值=1/q。有理点间断、无理点连续。

### ★★★ 研究探索

**【D2-3-011】** 为什么说 Thomae 函数是"最精细的间断点集"？它和 Dirichlet 函数有什么本质区别？

- **难度**：★★★
- **对应知识点**：Thomae 函数 vs Dirichlet 函数
- **解答**：
  **Thomae 函数是"最精细的间断点集"**：
  
  Thomae 函数的间断点集是有理数集——有理数集是可数集，测度为零。
  
  这意味着——Thomae 函数"几乎处处连续"（只有可数个间断点，测度为零）。
  
  **和 Dirichlet 函数的本质区别**：
  
  | 维度 | Dirichlet 函数 | Thomae 函数 |
  |------|---------------|-------------|
  | 间断点集 | 全部实数 | 有理数集 |
  | 连续点集 | 空集 | 无理数集 |
  | 间断点类型 | 第二类（振荡） | 第一类（可去） |
  | Riemann 可积 | 不可积 | 可积（积分=0） |
  | Lebesgue 可积 | 可积（积分=0） | 可积（积分=0） |
  | 复杂度 | 处处不连续 | 几乎处处连续 |
  
  **本质区别**：
  Dirichlet 函数"处处不连续"——它是"最不连续"的函数。
  Thomae 函数"几乎处处连续"——它是"几乎连续"的函数。
  
  这两个函数代表了"不连续"的两个极端——一个是"最不连续"，一个是"几乎连续"。∎
- **一句话点评**：Dirichlet 函数=处处不连续（最不连续）；Thomae 函数=几乎处处连续（最精细的间断点集）。两个极端。

**【D2-3-012】** 为什么说 Weierstrass 函数"打破了连续函数应该可导的直觉"？

- **难度**：★★★
- **对应知识点**：Weierstrass 函数
- **解答**：
  **Weierstrass 函数**：
  W(x)=Σ_{n=0}^∞ aⁿ cos(bⁿ π x)，其中 0&lt;a&lt;1，b 为奇数整数，ab>1+3π/2。
  
  **性质**：
  1. 处处连续（因为级数一致收敛，每一项连续）
  2. 处处不可导（证明非常复杂，涉及级数的不一致收敛）
  
  **为什么打破直觉**：
  
  在 Weierstrass 函数之前（1872 年之前），数学家默认：
  - 连续函数除了少数几个点外，都可导
  
  但 Weierstrass 函数表明：
  - 存在处处连续但处处不可导的函数
  - 连续函数可以"处处有尖点"
  
  **这为什么是革命性的**：
  它打破了"连续⇒几乎处处可导"的直觉——连续函数可以"处处不光滑"。
  
  这推动了实变函数和分形几何的发展——Weierstrass 函数是最早的分形例子之一。∎
  
  **几何图像**：Weierstrass 函数的图像在任何尺度下都有"尖点"——放大看，图像还是有尖点。它是"分形"的——自相似。∎
- **一句话点评**：Weierstrass 函数=处处连续处处不可导。它打破了"连续函数应该可导"的直觉——连续函数可以处处有尖点。

**【D2-3-013】** 什么是 Cantor 函数？为什么说它是"单调连续但导数几乎处处为 0"的经典例子？

- **难度**：★★★
- **对应知识点**：Cantor 函数
- **解答**：
  **Cantor 函数**：
  Cantor 函数是定义在 [0,1] 上的单调连续函数，它的图像被称为"魔鬼阶梯"。
  
  **构造**：
  1. 从 [0,1] 开始
  2. 去掉中间三分之一 (1/3, 2/3)，函数在这个区间上的值=1/2
  3. 去掉剩下两个区间的中间三分之一，函数在这两个区间上的值=1/4 和 3/4
  4. 重复这个过程——去掉每个剩余区间的中间三分之一
  
  **性质**：
  1. **单调递增**：函数值从 0 增加到 1
  2. **连续**：没有跳跃
  3. **导数几乎处处为 0**：在去掉的区间上（占总长度 1），导数=0
  4. **但不是常数函数**：函数从 0 增加到 1
  
  **为什么这个性质很深刻**：
  Cantor 函数"几乎处处平坦"——除了 Cantor 集（测度为零）外，导数都是 0。
  但它不是常数——它"偷偷地"在 Cantor 集上上升了 1。
  
  **这为什么很深刻**：
  它表明——"导数几乎处处为 0"不代表"函数是常数"。
  导数为 0 只说明函数"局部不变"——但"局部不变"不代表"全局不变"（在零测集上可以"偷偷变化"）。∎
- **一句话点评**：Cantor 函数=单调连续但导数几乎处处为 0。它"偷偷地"在零测集上上升——导数为 0 不代表函数是常数。

### ★★★ 研究探索（续）

**【D2-3-014】** 什么是 Baire 纲定理？为什么说"大多数连续函数处处不可导"？

- **难度**：★★★
- **对应知识点**：Baire 纲定理
- **解答**：
  **Baire 纲定理**：
  完备度量空间不能表示为可数个无处稠密集的并。
  
  **应用到连续函数空间**：
  C[a,b]（闭区间上的连续函数空间，sup 范数）是完备度量空间。
  
  可以证明：
  - "在至少一点可导的函数集"是 C[a,b] 中的第一纲集（可数个无处稠密集的并）
  - "处处不可导的函数集"是第二纲集（剩余集）
  
  **为什么说"大多数连续函数处处不可导"**：
  Baire 纲定理告诉我们——在 C[a,b] 中，"处处不可导的函数"是大多数（第二纲集）。
  "至少在一点可导的函数"是少数（第一纲集，"稀薄"的）。
  
  **这为什么很深刻**：
  它告诉我们——光滑函数（可导函数）是"例外"，病态函数（处处不可导）才是"常态"。
  我们平时研究的"好"函数（多项式、三角函数等）只是函数空间中的一小部分——大多数函数是"病态"的。∎
- **一句话点评**：Baire 纲定理说——大多数连续函数处处不可导。光滑函数是例外，病态才是常态。

**【D2-3-015】** 间断点分类的标准是什么？为什么说"左右极限是否存在"是分类的关键？

- **难度**：★
- **对应知识点**：间断点分类标准
- **解答**：
  **分类标准**：
  按左右极限是否存在来分类：
  - 左右极限都存在 → 第一类
  - 至少一个不存在 → 第二类
  
  **为什么是关键**：
  
  1. **左右极限存在 = 函数在该点附近"行为有界"**：
     如果左右极限都存在，那么函数在该点附近有界——它只是"跳了一下"（第一类）。
  
  2. **左右极限不存在 = 函数在该点附近"行为失控"**：
     如果左右极限不存在，那么函数在该点附近要么"冲向无穷"（无穷间断），要么"无限振荡"（振荡间断）——这是"失控"的。
  
  **几何图像**：
  - 第一类：函数图像在该点附近"有界"——只是"跳了一下"
  - 第二类：函数图像在该点附近"无界"——要么"冲向无穷"，要么"无限振荡"∎
- **一句话点评**：分类标准就是左右极限是否存在——存在=第一类（有界），不存在=第二类（失控）。

**【D2-3-016】** 为什么说单调函数是"比较好"的函数？

- **难度**：★
- **对应知识点**：单调函数的性质
- **解答**：
  **为什么说单调函数"比较好"**：
  
  1. **间断点都是第一类**：单调函数不会有振荡间断或无穷间断（在有界区间上）。
  
  2. **间断点至多可数个**：单调函数的间断点不会太多——至多可数个。
  
  3. **几乎处处连续**：因为间断点可数，可数集的测度为零——所以单调函数"几乎处处连续"。
  
  4. **Riemann 可积**：因为间断点至多可数个（测度为零），满足 Lebesgue 准则——所以单调函数在闭区间上 Riemann 可积。
  
  5. **几乎处处可导**：Lebesgue 定理——单调函数几乎处处可导。
  
  **一句话总结**：单调函数虽然可能有间断点，但它"比较好"——间断点都是第一类，至多可数个，几乎处处连续，几乎处处可导。∎
- **一句话点评**：单调函数"比较好"——间断点都是第一类，至多可数个，几乎处处连续，几乎处处可导。

### ★★ 进阶应用

**【D2-3-017】** 为什么说"可去间断点可以去掉，跳跃间断点无法去掉"？

- **难度**：★★
- **对应知识点**：可去 vs 跳跃
- **解答**：
  **可去间断点可以去掉**：
  可去间断点：左极限=右极限=A，但 f(x₀)≠A（或 f(x₀) 无定义）。
  
  重新定义 f(x₀)=A，函数就在 x₀ 处连续了。
  所以间断点"可去"。
  
  **跳跃间断点无法去掉**：
  跳跃间断点：左极限=A，右极限=B，A≠B。
  
  无论怎么定义 f(x₀)，都不可能同时等于 A 和 B。
  所以跳跃无法"去掉"——它是函数本身的性质，不是"定义错了"。
  
  **几何图像**：
  - 可去间断点：图像在该点有一个"洞"——补上这个点就连贯了
  - 跳跃间断点：图像在该点有一个"断层"——左右两边高度不同，无法通过"补点"来修复∎
- **一句话点评**：可去间断点=函数值填错了（重新定义就好）；跳跃间断点=左右高度不同（无法修复）。

**【D2-3-018】** 为什么说 Thomae 函数的间断点都是可去间断点？

- **难度**：★★
- **对应知识点**：Thomae 函数的间断点类型
- **解答**：
  **Thomae 函数的间断点**：
  Thomae 函数在有理点不连续，在无理点连续。
  
  **为什么都是可去间断点**：
  
  在有理点 x₀=p/q 处：
  - lim_{x→x₀} T(x) = 0（和无理点一样）
  - T(x₀) = 1/q ≠ 0
  
  所以：
  - 左极限=右极限=0
  - 但函数值=1/q≠0
  
  这正是可去间断点的定义——极限存在但不等于函数值。
  
  **一句话总结**：
  Thomae 函数的所有间断点都是可去间断点——极限=0，但函数值=1/q。∎
- **一句话点评**：Thomae 函数的间断点都是可去型——极限=0，但函数值=1/q。重新定义有理点的函数值=0，它就处处连续了。

### ★★★ 研究探索

**【D2-3-019】** 为什么说"间断点集的结构"是实变函数中的重要研究对象？

- **难度**：★★★
- **对应知识点**：间断点集的结构
- **解答**：
  **为什么间断点集的结构很重要**：
  
  1. **连续函数的刻画**：
     一个函数是否连续，取决于它的间断点集是什么。
     - 连续函数：间断点集=空集
     - 几乎处处连续：间断点集测度为零
     - 处处不连续：间断点集=整个实数轴
  
  2. **可积性的刻画**：
     Riemann 可积的充要条件是——间断点集的测度为零（Lebesgue 准则）。
     所以间断点集的测度决定了函数是否 Riemann 可积。
  
  3. **函数性质的分类**：
     不同类型的函数有不同结构的间断点集：
     - 单调函数：间断点至多可数（第一类）
     - 阶梯函数：间断点可数（第一类）
     - Thomae 函数：间断点=有理数集（可数）
     - Dirichlet 函数：间断点=整个实数轴（不可数）
  
  **几何图像**：
  间断点集就像函数图像上的"黑点"——黑点的分布（是可数个？测度为零？还是整个区间？）决定了函数的性质。∎
- **一句话点评**：间断点集的结构决定了函数的性质——是否连续、是否可积、是否几乎处处可导。

**【D2-3-020】** 为什么说"病态函数推动了实变函数的发展"？

- **难度**：★★★
- **对应知识点**：病态函数与实变函数
- **解答**：
  **病态函数推动实变函数发展**：
  
  1. **Dirichlet 函数 → Lebesgue 积分**：
     Dirichlet 函数 Riemann 不可积，但 Lebesgue 可积（积分=0）。
     这促使数学家思考——为什么 Riemann 积分不能处理这个函数？需要什么样的积分？
     最终导致了 Lebesgue 积分的创立。
  
  2. **Weierstrass 函数 → 实变函数**：
     Weierstrass 函数处处连续处处不可导——这打破了"连续函数应该可导"的直觉。
     这促使数学家思考——什么样的函数"好"？可导性的精确条件是什么？
     最终推动了实变函数的发展（可测函数、Lp 空间等）。
  
  3. **Cantor 函数 → 集合论**：
     Cantor 函数的构造用到了 Cantor 集——这是集合论的开端。
     Cantor 集是"测度为零但不可数"的集合——这打破了"测度为零就可数"的直觉。
  
  **一句话总结**：病态函数不是"怪物"——它们是理论发展的催化剂。每一个病态函数都暴露了旧理论的缺陷，推动了新理论的诞生。∎
- **一句话点评**：病态函数是理论发展的催化剂——Dirichlet 函数推动了 Lebesgue 积分，Weierstrass 函数推动了实变函数，Cantor 函数推动了集合论。

## 补充基础题（L1 数学分析 / L2 复变函数 / L3 实变函数）

> **引导语**：针对三个阶段补充基础题，巩固间断点分类和病态函数的核心概念。

### L1 数学分析基础

**【D2-3-061】** 求 $f(x)=\frac{x^2-1}{x^2-3x+2}$ 的间断点并分类。

- **难度**：★
- **解答**：$f(x)=\frac{(x-1)(x+1)}{(x-1)(x-2)}$。间断点为 $x=1$ 和 $x=2$。
$x=1$：$\lim_{x\to1}f(x)=\lim\frac{x+1}{x-2}=-2$，极限存在，是可去间断点。
$x=2$：$\lim_{x\to2^+}f(x)=+\infty$，$\lim_{x\to2^-}f(x)=-\infty$，是无穷间断点（第二类）。∎
- **点评**：有理函数的间断点来自分母零点——分子也为零的点可能是可去间断点，否则是无穷间断点。

**【D2-3-062】** 证明：单调函数的间断点都是第一类间断点（跳跃间断点），且至多可数个。

- **难度**：★★
- **解答**：设 $f$ 单调递增。对任意 $x_0$，$f(x_0^-)=\sup_{x<x_0}f(x)$ 和 $f(x_0^+)=\inf_{x>x_0}f(x)$ 都存在（单调有界），且 $f(x_0^-)\leq f(x_0)\leq f(x_0^+)$。若不等则为跳跃间断点，都是第一类。
至多可数：对每个间断点 $x$，对应区间 $(f(x^-),f(x^+))$，这些区间互不相交（单调性）。每个区间含一个有理数，故至多可数。∎
- **点评**：单调函数的间断点结构非常清晰——全是第一类，且至多可数。这是单调函数最重要的正则性性质之一。

**【D2-3-063】** 证明：Dirichlet 函数 $D(x)=\begin{cases}1, & x\in\mathbb{Q}\\0, & x\notin\mathbb{Q}\end{cases}$ 在每一点都不连续。

- **难度**：★
- **解答**：对任意 $x_0$，取有理数列 $r_n\to x_0$，则 $D(r_n)=1\to1$；取无理数列 $s_n\to x_0$，则 $D(s_n)=0\to0$。由 Heine 定理，极限不存在，故不连续。∎
- **点评**：Dirichlet 函数是"处处不连续"的经典例子——有理数和无理数在实数中都稠密，导致函数值在 0 和 1 之间无限振荡。

**【D2-3-064】** 证明：Riemann 函数 $R(x)=\begin{cases}1/q, & x=p/q\text{（既约分数）}\\0, & x\text{ 无理数}\end{cases}$ 在无理点连续，在有理点不连续。

- **难度**：★★
- **解答**：无理点连续：对任意 $\varepsilon>0$，只有有限个有理数 $p/q$ 满足 $1/q\geq\varepsilon$（即 $q\leq1/\varepsilon$）。取 $\delta$ 为 $x_0$ 到这些有理数的最小距离，则 $|x-x_0|<\delta$ 时 $|R(x)|<\varepsilon$。
有理点不连续：$x_0=p/q$ 时 $R(x_0)=1/q>0$，但附近有无理点 $R=0$，故不连续。∎
- **点评**：Riemann 函数是"几乎处处连续但在有理点不连续"的精妙例子——它是 Riemann 可积的（间断点集=有理数，零测），积分值为 0。

### L2 复变函数基础

**【D2-3-065】** 证明：$f(z)=\frac{1}{z}$ 在 $z=0$ 处不连续（在扩充复平面上视为极点）。

- **难度**：★
- **解答**：$\lim_{z\to0}|1/z|=+\infty$，极限不是有限复数，故不连续。在复分析中，$z=0$ 是 $1/z$ 的一阶极点。∎
- **点评**：复函数的"无穷间断"对应奇点理论中的极点——这是复分析独有的分类方式。

**【D2-3-066】** 设 $f(z)=\frac{\sin z}{z}$（$z\neq0$），$f(0)=1$。证明 $f$ 在 $z=0$ 处连续。

- **难度**：★
- **解答**：$\sin z=z-\frac{z^3}{3!}+\cdots$，故 $\frac{\sin z}{z}=1-\frac{z^2}{3!}+\cdots\to1$（$z\to0$）。$f(0)=1$ 等于极限值，故连续。∎
- **点评**：这是复分析中的"可去奇点"例子——补充定义后函数连续且实际上解析。

**【D2-3-067】** 证明：若 $f$ 在 $z_0$ 处连续且 $f(z_0)\neq0$，则存在 $z_0$ 的邻域使 $f(z)\neq0$。

- **难度**：★★
- **解答**：取 $\varepsilon=|f(z_0)|/2>0$。由连续性，$\exists\delta>0$ 使 $|z-z_0|<\delta$ 时 $|f(z)-f(z_0)|<|f(z_0)|/2$。
则 $|f(z)|\geq|f(z_0)|-|f(z)-f(z_0)|>|f(z_0)|/2>0$。∎
- **点评**：连续函数的"保号性"在复分析中同样成立——非零点附近函数值都不为零。这是零点孤立性定理的预备。

### L3 实变函数基础

**【D2-3-068】** 证明：Dirichlet 函数 $D(x)$ 是 Lebesgue 可测函数，且 $\int_{[0,1]}D(x)dx=0$。

- **难度**：★
- **解答**：$D(x)=\chi_{\mathbb{Q}}(x)$。有理数集 $\mathbb{Q}$ 是可数集，故可测（可数集都是 Borel 集），特征函数可测。
$\int D\,dx=m(\mathbb{Q}\cap[0,1])=0$（可数集测度为 0）。∎
- **点评**：Dirichlet 函数不是 Riemann 可积的（上下积分分别为 1 和 0），但它是 Lebesgue 可积的，积分值为 0——这是 Lebesgue 积分优于 Riemann 积分的经典例证。

**【D2-3-069】** 用 Lusin 定理说明：Riemann 函数 $R(x)$ 在 $[0,1]$ 上"几乎连续"。

- **难度**：★★
- **解答**：Riemann 函数的间断点集是有理数集 $\mathbb{Q}\cap[0,1]$，测度为 0。
由 Lusin 定理，$\forall\varepsilon>0$，存在闭集 $F\subset[0,1]$ 使 $m([0,1]\setminus F)<\varepsilon$ 且 $R|_F$ 连续。
实际上，可以取 $F=[0,1]\setminus\bigcup_{q\in\mathbb{Q}\cap[0,1]}(q-\varepsilon/2^n,q+\varepsilon/2^n)$（去掉有理数的小邻域），则 $m(F)>1-\varepsilon$，且 $R$ 在 $F$ 上连续（因为 $F$ 中无理点附近没有有理点）。∎
- **点评**：Lusin 定理的具体应用——去掉有理数的小邻域后，Riemann 函数在剩余闭集上连续。

**【D2-3-070】** 证明：若 $f$ 在 $[a,b]$ 上几乎处处连续且有界，则 $f$ Riemann 可积（Lebesgue 准则）。

- **难度**：★★
- **解答**：Lebesgue 准则：有界函数 $f$ 在 $[a,b]$ 上 Riemann 可积 ⟺ $f$ 的间断点集测度为 0。
$f$ 几乎处处连续 ⟹ 间断点集零测。又 $f$ 有界，由 Lebesgue 准则，$f$ Riemann 可积。∎
- **点评**：这是 Riemann 可积的充要条件——有界 + 几乎处处连续。Dirichlet 函数不满足（处处不连续），Riemann 函数满足（仅有理点不连续）。

## 跨领域综合题

> **引导语**：间断点是连续性的反面。病态函数挑战了我们对函数的直觉，也推动了测度论和积分论的发展。

> 定位：串联多个概念领域的综合题，培养全局视野和数学思考的"爽感"。

### 一、经典名题（做一遍爽一遍）

**【D2-3-CROSS-021】**（D2 × D4 积分）**Lebesgue 准则**：为什么说"闭区间上有界函数 Riemann 可积⟺间断点集测度为零"是 Riemann 积分的完整刻画？

- **难度**：★★★
- **对应知识点**：Riemann 可积性（D4 联动）、间断点集（D2）
- **来源**：间断点与积分
- **解答**：
  **Lebesgue 准则**：
  闭区间 [a,b] 上的有界函数 f 是 Riemann 可积的 ⟺ f 的间断点集的测度为零。
  
  **为什么是"完整刻画"**：
  
  1. **必要条件**：
     如果 f Riemann 可积，那么间断点集测度为零。
     （如果间断点集测度>0，那么上和-下和不会→0，不可积）
  
  2. **充分条件**：
     如果间断点集测度为零，那么 f Riemann 可积。
     （可以证明——上和-下和→0）
  
  3. **完整刻画**：
     充要条件——既必要又充分。
     所以"间断点集测度为零"是 Riemann 可积的完整刻画。
  
  **为什么这个准则很重要**：
  它告诉我们——Riemann 积分只能处理"几乎连续"的函数。
  如果函数在一个测度大于零的集合上不连续，Riemann 积分就不能处理它。
  
  **例子**：
  - Thomae 函数：间断点=有理数集（测度为零）→ Riemann 可积 ✓
  - Dirichlet 函数：间断点=整个实数轴（测度>0）→ Riemann 不可积 ✗∎
- **一句话点评**：Lebesgue 准则 = Riemann 可积 ⟺ 间断点集测度为零。Riemann 积分只能处理"几乎连续"的函数。

**【D2-3-CROSS-022】**（D2 × D6 完备性）**单调函数与完备性**：为什么说单调函数的间断点定理的基础是实数完备性？

- **难度**：★★★
- **对应知识点**：单调函数间断点定理（D6 联动）、完备性（D6）
- **来源**：完备性与间断点
- **解答**：
  **单调函数的间断点定理**：
  1. 单调函数的所有间断点都是第一类间断点
  2. 单调函数的间断点至多可数个
  
  **为什么基础是实数完备性**：
  
  第一部分（都是第一类）的证明用了确界原理——单调有界必有确界。
  确界原理是实数完备性六定理之一。
  
  第二部分（至多可数）的证明用了"有理数可数"——这是集合论的结果。
  但第一部分的基础——确界原理——本身就是实数完备性的体现。
  
  **如果实数不完备呢**：
  如果实数不完备（如有理数），那么单调有界函数可能没有确界——左极限和右极限可能不存在。
  这样单调函数就可能有"第二类间断点"——极限"跑到空隙里去了"。
  
  **一句话总结**：单调函数的间断点定理基础是实数完备性——确界原理保证了左右极限存在。∎
- **一句话点评**：单调函数间断点定理的基础是实数完备性——确界原理保证了左右极限存在。如果不完备，极限可能"跑到空隙里去"。

**【D2-3-CROSS-023】**（D2 × D4 积分）**Thomae 函数与 Riemann 可积**：为什么说 Thomae 函数是"几乎处处连续但 Riemann 可积"的经典例子？

- **难度**：★★★
- **对应知识点**：Thomae 函数（D2）、Riemann 可积（D4 联动）
- **来源**：间断点与积分
- **解答**：
  **Thomae 函数**：
  T(x)=1/q（x=p/q 既约分数）, 0（x 无理）。
  
  **几乎处处连续**：
  - 间断点集 = 有理数集
  - 有理数集测度为零
  - 所以 T 几乎处处连续
  
  **Riemann 可积**：
  由 Lebesgue 准则，间断点集测度为零⇒Riemann 可积。
  实际上，∫₀¹ T(x) dx = 0。
  
  **为什么这个例子很经典**：
  
  1. **它展示了"几乎处处连续"的精确含义**：
     Thomae 函数不是处处连续——它在所有有理点间断。
     但它几乎处处连续——间断点集测度为零。
  
  2. **它展示了 Lebesgue 准则的应用**：
     间断点集测度为零⇒Riemann 可积。
     Thomae 函数就是这个准则的完美例证。
  
  3. **它是"病态函数"但可积**：
     Thomae 函数看起来很"病态"——有理点间断、无理点连续。
     但它 Riemann 可积（积分=0）——因为间断点集测度为零。∎
- **一句话点评**：Thomae 函数=几乎处处连续+Riemann 可积。间断点=有理数集（测度为零）——Lebesgue 准则的完美例证。

**【D2-3-CROSS-024】**（D2 × D4 积分）**Dirichlet 函数与 Riemann 不可积**：为什么说 Dirichlet 函数是"Riemann 不可积但 Lebesgue 可积"的经典例子？

- **难度**：★★★
- **对应知识点**：Dirichlet 函数（D2）、Riemann vs Lebesgue（D4 联动）
- **来源**：间断点与积分
- **解答**：
  **Dirichlet 函数**：
  D(x)=1（x 有理）, 0（x 无理）。
  
  **Riemann 不可积**：
  - 间断点集 = 整个实数轴（测度>0）
  - 由 Lebesgue 准则，间断点集测度>0⇒Riemann 不可积
  
  直观上：
  - 上和=区间长度（取有理点的函数值=1）
  - 下和=0（取无理点的函数值=0）
  - 上和-下和=区间长度≠0——不可积
  
  **Lebesgue 可积**：
  - D(x)=0 a.e.（有理数集测度为零）
  - Lebesgue 积分 = 0
  
  **为什么这个例子很经典**：
  
  1. **它展示了 Riemann 积分的局限性**：
     Riemann 积分不能处理"处处不连续"的函数。
  
  2. **它展示了 Lebesgue 积分的优越性**：
     Lebesgue 积分可以处理——因为它按函数值"分层"来积分。
     D(x) 几乎处处=0，所以 Lebesgue 积分=0。
  
  3. **它推动了积分理论的发展**：
     Dirichlet 函数的 Riemann 不可积，促使数学家思考——为什么 Riemann 积分不能处理这个函数？需要什么样的积分？
     最终导致了 Lebesgue 积分的创立。∎
- **一句话点评**：Dirichlet 函数=Riemann 不可积但 Lebesgue 可积。它展示了两种积分的区别——也推动了 Lebesgue 积分的创立。

**【D2-3-CROSS-025】**（D2 × D8 解析）**解析函数的间断点**：为什么说解析函数没有第二类间断点？

- **难度**：★★★
- **对应知识点**：解析函数的连续性（D8 联动）、间断点分类（D2）
- **来源**：复连续与间断点
- **解答**：
  **解析函数没有第二类间断点**：
  
  解析函数在定义域内处处可导——可导⇒连续。
  所以解析函数在定义域内处处连续——没有间断点。
  
  但解析函数有"奇点"——不在定义域内的点。
  奇点的分类：
  1. **可去奇点**：类似可去间断点——极限存在但函数值不对
  2. **极点**：类似无穷间断点——极限为无穷大
  3. **本性奇点**：复函数独有的"最严重"奇点——极限不存在（Casorati-Weierstrass 定理：在任意邻域内可以取到任意复数值）
  
  **为什么解析函数的"间断点"分类和实函数不同**：
  
  1. **解析函数"内部"没有间断点**：
     解析函数在定义域内处处连续——它的"间断点"都在定义域外（奇点）。
  
  2. **本性奇点是复函数独有的**：
     实函数的第二类间断点只有无穷型和振荡型。
     复函数多了一种——本性奇点。
     这是复结构带来的——复函数的"振荡"可以非常剧烈。
  
  **一句话总结**：解析函数在定义域内处处连续——没有间断点。它的"奇点"（定义域外的点）有可去、极点、本性奇点三种。本性奇点是复函数独有的。∎
- **一句话点评**：解析函数在定义域内处处连续——没有间断点。它的"奇点"分三类：可去、极点、本性奇点。本性奇点是复函数独有的。

- **一句话点评**：Baire 纲定理的基础是完备性——完备空间中，可数个稀薄集不能覆盖整个空间。不完备空间（如 ℚ）就可以。

**【D2-3-040】** 什么是振荡间断点？它和无穷间断点有什么区别？

- **难度**：★
- **对应知识点**：振荡间断点
- **解答**：
  **振荡间断点**：
  函数在该点附近的极限不存在——函数值在某个范围内"无限振荡"，不趋于任何固定值。
  
  **典型例子**：
  f(x)=sin(1/x) 在 x=0 处——x→0 时，1/x→∞，sin(1/x) 在 [-1,1] 之间无限振荡。
  
  **和无穷间断点的区别**：
  
  | 维度 | 无穷间断点 | 振荡间断点 |
  |------|-----------|-----------|
  | 极限 | 为无穷大（±∞） | 不存在（振荡） |
  | 函数值 | 趋向无穷大 | 在有界范围内振荡 |
  | 有界性 | 无界 | 可以有界（如 sin(1/x) 有界） |
  | 例子 | 1/x 在 x=0 处 | sin(1/x) 在 x=0 处 |
  
  **关键区别**：
  无穷间断点的函数值"冲向无穷"——无界。
  振荡间断点的函数值"来回振荡"——可以有界（如 sin(1/x) 在 [-1,1] 内振荡）。∎
- **一句话点评**：振荡间断点=极限不存在（在有界范围内振荡）；无穷间断点=极限为无穷。振荡可以有界，无穷一定无界。

**【D2-3-041】** 判断 f(x)=e^(1/x) 在 x=0 处的间断点类型。

- **难度**：★
- **对应知识点**：间断点类型判断
- **解答**：
  **左极限**：
  lim_{x→0⁻} e^(1/x) = e^(-∞) = 0。
  
  **右极限**：
  lim_{x→0⁺} e^(1/x) = e^(+∞) = +∞。
  
  **判断**：
  右极限为无穷大（不存在有限值），所以 x=0 是**第二类间断点**（无穷间断点）。
  
  **注意**：
  虽然左极限存在（=0），但右极限不存在（为无穷大），所以仍然是第二类间断点。
  
  第二类间断点的定义是"左右极限至少有一个不存在"——只要有一个不存在，就是第二类。∎
- **一句话点评**：e^(1/x) 在 x=0 处是无穷间断点（第二类）——左极限=0，但右极限=+∞。只要一个极限不存在就是第二类。

**【D2-3-042】** 什么是阶梯函数？它的间断点是什么类型？

- **难度**：★
- **对应知识点**：阶梯函数
- **解答**：
  **阶梯函数定义**：
  阶梯函数是分段常值函数——它的图像像"阶梯"一样，在每个区间上取常数值，在区间端点处跳跃。
  
  **典型例子**：
  1. 取整函数 f(x)=⌊x⌋（不超过 x 的最大整数）
  2. 符号函数 f(x)=sgn(x)（x>0 时=1，x=0 时=0，x&lt;0 时=-1）
  3. Heaviside 函数 H(x)（x≥0 时=1，x&lt;0 时=0）
  
  **间断点类型**：
  阶梯函数的间断点都是**跳跃间断点**（第一类）。
  
  因为在每个跳跃点，左极限和右极限都存在（等于左右两段的常数值），但不相等。
  
  **跳跃度**：
  跳跃度 = 右极限 - 左极限 = 右侧常数值 - 左侧常数值。
  
  **几何图像**：
  阶梯函数的图像是"水平线段 + 垂直跳跃"——在每个区间上水平，在端点处垂直跳跃。∎
- **一句话点评**：阶梯函数=分段常值函数，间断点都是跳跃型（第一类）。图像是"水平线段+垂直跳跃"。

**【D2-3-043】** 证明 f(x)=x·D(x)（D 是 Dirichlet 函数）在 x=0 处连续。

- **难度**：★
- **对应知识点**：Dirichlet 函数的变种
- **解答**：
  **证明**：
  f(x)=x·D(x)，其中 D(x)=1（x 有理）, 0（x 无理）。
  
  所以 f(x)=x（x 有理）, 0（x 无理）。
  
  f(0)=0·D(0)=0。
  
  现在证明 lim_{x→0} f(x)=0=f(0)。
  
  对任意 x，|f(x)|≤|x|（因为有理点 f(x)=x，无理点 f(x)=0，都满足 |f(x)|≤|x|）。
  
  所以 ∀ε>0，取 δ=ε，则 |x-0|&lt;δ ⇒ |f(x)-0|=|f(x)|≤|x|&lt;ε。
  
  所以 lim_{x→0} f(x)=0=f(0)，f 在 x=0 处连续。∎
  
  **为什么这个函数很有趣**：
  Dirichlet 函数处处不连续，但乘以 x 后，在 x=0 处就连续了——因为 x→0 时，x 这个因子"压住了"Dirichlet 函数的不连续性。
  
  **对比**：
  - D(x)：处处不连续
  - x·D(x)：只在 x=0 处连续，其他点不连续∎
- **一句话点评**：x·D(x) 在 x=0 处连续——|f(x)|≤|x|，用夹逼定理。乘以 x 后，Dirichlet 函数在 0 处的不连续性被"压住"了。

**【D2-3-044】** 什么是"几乎处处连续"？它和"处处连续"有什么区别？

- **难度**：★
- **对应知识点**：几乎处处连续
- **解答**：
  **几乎处处连续的定义**：
  如果函数 f 的间断点集的测度为零，则称 f 几乎处处连续（a.e. 连续）。
  
  **和处处连续的区别**：
  - 处处连续：间断点集=空集（没有任何间断点）
  - 几乎处处连续：间断点集测度为零（可以有间断点，但"很少"）
  
  **"测度为零"的含义**：
  测度为零的集合可以是：
  - 空集（处处连续）
  - 有限集（如有限个间断点）
  - 可数集（如有理数集——Thomae 函数的间断点集）
  - 不可数集（如 Cantor 集——测度为零但不可数）
  
  **典型例子**：
  - 连续函数：处处连续（间断点集=空集）
  - Thomae 函数：几乎处处连续（间断点集=有理数集，测度为零）
  - 单调函数：几乎处处连续（间断点至多可数，测度为零）
  - Dirichlet 函数：不是几乎处处连续（间断点集=整个实数轴，测度>0）∎
- **一句话点评**：几乎处处连续=间断点集测度为零。处处连续是特例（间断点集=空集）。Thomae 函数是几乎处处连续的经典例子。

**【D2-3-046】** 构造一个在所有整数点间断、在其他点连续的函数。

- **对应知识点**：间断点的构造
- **解答**：
  **构造**：
  f(x)=sin(πx)·D(x)？不对，这样在非整数点也不连续。
  
  更好的构造：
  f(x)=0（x 不是整数），f(n)=1（n 是整数）。
  
  即 f(x)=1 如果 x∈ℤ，否则 f(x)=0。
  
  **验证**：
  
  在整数点 x=n 处：
  f(n)=1。
  但 lim_{x→n} f(x)=0（因为在 n 附近，除了 n 本身，其他点的函数值都是 0）。
  极限=0≠1=f(n)。
  所以 f 在整数点不连续（可去间断点）。

  存在 δ>0 使得 (x₀-δ, x₀+δ) 内没有整数（因为整数集是离散的，非整数点和最近的整数有正距离）。

  所以 f 在 x₀ 处连续。∎

  对于任意离散集 A（没有聚点的集合），可以构造 f(x)=1（x∈A），f(x)=0（x∉A）。
  这个函数在 A 的点处间断，在其他点连续。∎
- **一句话点评**：构造 f(x)=1（x 整数），0（其他）——整数点可去间断，其他点连续。关键是整数集离散，非整数点有邻域不含整数。

**【D2-3-047】** 什么是半连续？它和连续有什么关系？

- **难度**：★★
- **对应知识点**：半连续
- **解答**：
  **上半连续的定义**：
  如果对任意 x₀ 和任意 ε>0，存在 δ>0 使得 |x-x₀|&lt;δ ⇒ f(x)&lt;f(x₀)+ε，则称 f 在 x₀ 处上半连续。
  
  等价地：limsup_{x→x₀} f(x)≤f(x₀)。
  
  **下半连续的定义**：
  如果对任意 x₀ 和任意 ε>0，存在 δ>0 使得 |x-x₀|&lt;δ ⇒ f(x)>f(x₀)-ε，则称 f 在 x₀ 处下半连续。
  
  等价地：liminf_{x→x₀} f(x)≥f(x₀)。
  
  **和连续的关系**：
  f 在 x₀ 处连续 ⟺ f 在 x₀ 处既上半连续又下半连续。
  
  **典型例子**：
  - 取整函数 f(x)=⌊x⌋：上半连续（在整数点，limsup=f(x₀)），但不是下半连续
  - Dirichlet 函数：既不上半连续也不下半连续
  - 连续函数：既上半连续又下半连续
  
  **为什么半连续很重要**：
  半连续函数在最优化理论中很重要——上半连续函数在紧集上有最大值，下半连续函数在紧集上有最小值。∎
- **一句话点评**：上半连续=limsup≤f(x₀)，下半连续=liminf≥f(x₀)。连续=既上半又下半。取整函数是上半连续的经典例子。

**【D2-3-048】** 证明 f(x)=sin x·D(x) 在 x=kπ 处连续，在其他点不连续。

- **难度**：★★
- **对应知识点**：Dirichlet 函数的变种
- **解答**：
  **证明**：
  f(x)=sin x·D(x)，其中 D(x)=1（x 有理）, 0（x 无理）。
  
  所以 f(x)=sin x（x 有理）, 0（x 无理）。
  
  **在 x=kπ 处**：
  f(kπ)=sin(kπ)·D(kπ)=0·1=0。
  
  对任意 x，|f(x)|≤|sin x|（有理点 f(x)=sin x，无理点 f(x)=0）。
  
  所以 ∀ε>0，因为 sin x 在 x=kπ 处连续，存在 δ>0 使得 |x-kπ|&lt;δ ⇒ |sin x|&lt;ε。
  
  所以 |f(x)-f(kπ)|=|f(x)|≤|sin x|&lt;ε。
  
  所以 f 在 x=kπ 处连续。∎
  
  **在 x₀≠kπ 处**：
  sin x₀≠0。
  
  取有理数列 rₙ→x₀，则 f(rₙ)=sin rₙ→sin x₀≠0。
  取无理数列 sₙ→x₀，则 f(sₙ)=0→0。
  
  两条数列的极限不同（sin x₀ vs 0），所以 f 在 x₀ 处不连续。∎
  
  **总结**：
  f(x)=sin x·D(x) 的连续点集是 {kπ : k∈ℤ}（离散集），间断点集是 ℝ\{kπ}。
  
  这和 x·D(x) 类似——乘以一个在某点为 0 的连续函数，可以"消除"Dirichlet 函数在该点的不连续性。∎
- **一句话点评**：sin x·D(x) 在 x=kπ 处连续（sin kπ=0 压住了不连续），其他点不连续（有理数列→sin x₀≠0，无理数列→0）。

**【D2-3-049】** 什么是 Volterra 函数？它为什么很特殊？

- **难度**：★★
- **对应知识点**：Volterra 函数
- **解答**：
  **Volterra 函数的构造**：
  Volterra 函数是 Vito Volterra 在 1881 年构造的一个函数。
  
  构造方法：
  1. 在 [0,1] 中去掉一个类 Cantor 集（测度为 1/2 的闭集，无处稠密）
  2. 在每个去掉的区间上，构造一个"小山峰"函数（类似 sin(1/x) 的变种，但连续可导）
  3. 把这些"小山峰"拼接起来，得到 Volterra 函数
  
  **性质**：
  1. **处处可导**：Volterra 函数在 [0,1] 上处处可导
  2. **导数有界**：|V'(x)|≤1
  3. **导数不连续**：V' 在一个正测度集上不连续（在类 Cantor 集上）
  4. **导数不是 Riemann 可积的**：因为 V' 的间断点集测度>0（由 Lebesgue 准则）
  
  **为什么很特殊**：
  
  Volterra 函数是第一个"处处可导但导数不可积"的例子——它打破了"导数应该可积"的直觉。
  
  在 Volterra 函数之前，数学家认为：
  - 如果 f 处处可导，那么 f' 应该 Riemann 可积
  - 微积分基本定理应该成立：∫ f'(x) dx = f(b)-f(a)
  
  但 Volterra 函数表明：
  - 处处可导的函数，其导数可能 Riemann 不可积
  - 微积分基本定理对 Riemann 积分不总是成立
  
  **这推动了什么**：
  Volterra 函数推动了 Lebesgue 积分的创立——Lebesgue 积分可以处理 Volterra 函数的导数（Lebesgue 可积），并且微积分基本定理在 Lebesgue 积分下成立（对绝对连续函数）。∎
- **一句话点评**：Volterra 函数=处处可导但导数 Riemann 不可积。它打破了"导数应该可积"的直觉——推动了 Lebesgue 积分的创立。

**【D2-3-050】** 证明单调函数的左右极限都存在（用确界原理）。

- **难度**：★★
- **对应知识点**：单调函数的极限
- **解答**：
  **证明**：
  设 f 在区间 I 上单调递增。对任意 x₀∈I（不是左端点），考虑左极限 lim_{x→x₀⁻} f(x)。
  
  集合 A={f(x) : x&lt;x₀, x∈I}。
  
  因为 f 单调递增，对任意 x&lt;x₀，f(x)≤f(x₀)。
  所以 A 有上界 f(x₀)。
  
  由确界原理，A 有上确界，记为 L=sup A。
  
  现在证明 lim_{x→x₀⁻} f(x)=L。
  
  ∀ε>0，因为 L 是上确界，存在 x₁&lt;x₀ 使得 f(x₁)>L-ε（上确界的定义）。
  
  取 δ=x₀-x₁>0，则当 x₀-δ&lt;x&lt;x₀ 时，x>x₁，由单调性 f(x)≥f(x₁)>L-ε。
  
  又因为 f(x)≤L（L 是上界），所以 L-ε&lt;f(x)≤L&lt;L+ε。
  
  即 |f(x)-L|&lt;ε。
  
  所以 lim_{x→x₀⁻} f(x)=L 存在。∎
  
  同理，右极限 lim_{x→x₀⁺} f(x)=inf{f(x) : x>x₀} 存在。∎
  
  **为什么用确界原理**：
  确界原理是实数完备性的体现——它保证了"有上界的集合必有上确界"。
  单调函数的函数值集合是有界的（被 f(x₀) 界住），所以确界存在，这个确界就是极限。∎
- **一句话点评**：单调函数左右极限存在的证明：函数值集合有界→确界原理→上确界/下确界就是左/右极限。基础是确界原理（实数完备性）。

**【D2-3-050b】** 什么是"函数的振幅"？它和连续性有什么关系？

- **难度**：★★
- **对应知识点**：振幅与连续
- **解答**：
  **振幅的定义**：
  函数 f 在点 x₀ 处的振幅定义为：
  ω_f(x₀)=lim_{δ→0⁺} (sup_{|x-x₀|&lt;δ} f(x) - inf_{|x-x₀|&lt;δ} f(x))
  
  即 f 在 x₀ 的越来越小的邻域内的"上下波动范围"的极限。
  
  **和连续性的关系**：
  f 在 x₀ 处连续 ⟺ ω_f(x₀)=0。
  
  **证明**：
  如果 f 在 x₀ 处连续，则 ∀ε>0，存在 δ>0 使得 |x-x₀|&lt;δ ⇒ |f(x)-f(x₀)|&lt;ε/2。
  所以 sup f - inf f ≤ ε（因为所有函数值都在 (f(x₀)-ε/2, f(x₀)+ε/2) 内）。
  所以 ω_f(x₀)≤ε，由 ε 任意性，ω_f(x₀)=0。
  
  反过来，如果 ω_f(x₀)=0，则 ∀ε>0，存在 δ>0 使得 sup f - inf f &lt; ε。
  所以对任意 |x-x₀|&lt;δ，|f(x)-f(x₀)|≤sup f - inf f &lt; ε。
  所以 f 在 x₀ 处连续。∎
  
  **为什么振幅很重要**：
  
  1. **它给出了连续性的等价刻画**：
     连续 ⟺ 振幅为 0。这个刻画不依赖极限的 ε-δ 定义，更几何。
  
  2. **它是 Lebesgue 准则证明的基础**：
     间断点集 = {x : ω_f(x)>0} = ∪ₙ {x : ω_f(x)≥1/n}。
     每个 {x : ω_f(x)≥1/n} 是闭集，所以间断点集是 Fσ 集。
  
  3. **它有明确的几何意义**：
     振幅就是函数图像在该点附近的"上下厚度"——连续函数的图像在每一点处"厚度为零"。∎
  
  **几何图像**：想象函数图像在 x₀ 处的一个"竖直切片"——振幅就是这个切片的高度。连续函数的切片高度趋于 0，不连续函数的切片高度大于 0（有"跳跃"或"振荡"）。
- **一句话点评**：振幅=函数在该点附近的上下波动范围。连续⟺振幅=0。振幅是连续性的几何刻画——图像在每一点处的"厚度"。

**【D2-3-051】** 为什么说"函数的间断点集可以是任意 Fσ 集"？

- **难度**：★★★
- **对应知识点**：间断点集的结构
- **解答**：
  **定理**：
  对于实数轴上的任意 Fσ 集 A（可数个闭集的并），存在一个函数 f，使得 f 的间断点集恰好是 A。
  
  **为什么是 Fσ 集**：
  
  首先，任意函数的间断点集一定是 Fσ 集。
  
  证明：定义 ω_f(x)=lim_{δ→0⁺} (sup_{|y-x|&lt;δ} f(y) - inf_{|y-x|&lt;δ} f(y))（振幅）。
  
  f 在 x 处连续 ⟺ ω_f(x)=0。
  
  间断点集 = {x : ω_f(x)>0} = ∪_{n=1}^∞ {x : ω_f(x)≥1/n}。
  
  可以证明 {x : ω_f(x)≥1/n} 是闭集。
  
  所以间断点集是可数个闭集的并，即 Fσ 集。∎
  
  **反过来，任意 Fσ 集都可以实现**：
  给定任意 Fσ 集 A=∪Fₙ（Fₙ 闭集），可以构造函数 f 使得 f 的间断点集=A。
  
  构造方法（思路）：
  定义 f(x)=Σ_{n=1}^∞ (1/2ⁿ)·g_{Fₙ}(x)，其中 g_F(x)=1（x∈F），0（x∉F）的某种连续化版本。
  
  这个构造比较复杂，但结论是——任意 Fσ 集都可以是某个函数的间断点集。∎
  
  **为什么这个定理很深刻**：
  它完全刻画了"函数的间断点集可以是什么样的集合"——答案是：恰好是 Fσ 集。
  
  这意味着：
  - 间断点集可以很简单（空集、有限集、可数集）
  - 间断点集可以很复杂（任意 Fσ 集，包括一些很复杂的集合）
  - 但间断点集不能是任意集合——它必须是 Fσ 集∎
- **一句话点评**：函数的间断点集恰好是 Fσ 集——既必要又充分。这完全刻画了间断点集的可能结构。

**【D2-3-052】** 什么是 Lebesgue 奇异函数？它和 Cantor 函数有什么关系？

- **难度**：★★★
- **对应知识点**：Lebesgue 奇异函数
- **解答**：
  **Lebesgue 奇异函数的定义**：
  如果函数 f 满足：
  1. f 在 [a,b] 上单调递增
  2. f 连续
  3. f'=0 a.e.（几乎处处导数为 0）
  4. f 不是常数函数
  
  则称 f 为 Lebesgue 奇异函数（或奇异函数）。
  
  **Cantor 函数是 Lebesgue 奇异函数**：
  Cantor 函数满足以上所有条件：
  1. 单调递增 ✓
  2. 连续 ✓
  3. 导数几乎处处为 0（在去掉的区间上导数=0，这些区间的总长度=1）✓
  4. 不是常数（从 0 增加到 1）✓
  
  所以 Cantor 函数是 Lebesgue 奇异函数的一个经典例子。
  
  **关系**：
  Cantor 函数是 Lebesgue 奇异函数的一个特例——它是基于 Cantor 集构造的。
  
  但 Lebesgue 奇异函数更一般——可以基于任意"正测度的无处稠密闭集"（类 Cantor 集）来构造奇异函数。
  
  **为什么奇异函数很重要**：
  
  1. **它表明"导数几乎处处为 0"不代表"函数是常数"**：
     这是对"微积分基本定理"直觉的挑战——如果 f'=0 a.e.，但 f 不是常数，那么 ∫ f'(x) dx=0≠f(b)-f(a)。
  
  2. **它推动了绝对连续概念的产生**：
     为了让微积分基本定理成立，需要比"连续"更强的条件——绝对连续。
     绝对连续函数满足：f'=0 a.e. ⇒ f 是常数。
  
  3. **它是 Lebesgue 分解定理的基础**：
     任意单调递增函数可以分解为三个部分：绝对连续部分 + 奇异部分 + 跳跃部分。
     奇异部分就是 Lebesgue 奇异函数。∎
- **一句话点评**：Lebesgue 奇异函数=单调连续+导数 a.e.=0+非常数。Cantor 函数是其经典例子。它表明"导数 a.e.=0"不代表"函数是常数"。

**【D2-3-053】** 证明：如果 f 的间断点集是可数集，那么 f 在闭区间上 Riemann 可积。

- **难度**：★★★
- **对应知识点**：可数间断点与可积性
- **解答**：
  **证明**：
  设 f 在 [a,b] 上有界，间断点集 D 是可数集。
  
  可数集的测度为零（可数个单点集的并，每个单点集测度为零）。
  
  由 Lebesgue 准则，闭区间上有界函数 Riemann 可积 ⟺ 间断点集测度为零。
  
  所以 f Riemann 可积。∎
  
  **不使用 Lebesgue 准则的直接证明**：
  
  设 D={x₁, x₂, x₃, ...}（可数个间断点），|f(x)|≤M。
  
  ∀ε>0，用总长度小于 ε/(4M) 的开区间覆盖 D（可数个点，可以用总长度任意小的开区间覆盖）。
  
  这些开区间记为 U₁, U₂, ...，总长度 &lt; ε/(4M)。
  
  [a,b] 去掉这些开区间后，剩下有限个闭区间（因为开区间的并是开集，补集是闭集，有界闭集的紧性保证有限覆盖）。
  
  在这些闭区间上，f 连续（因为去掉了所有间断点）。
  
  由 Cantor 定理，f 在这些闭区间上一致连续。
  
  所以可以把这些闭区间分割得足够细，使得每个小区间上的振幅 &lt; ε/(2(b-a))。
  
  现在考虑整个 [a,b] 的分割：
  - 在 Uᵢ 上的振幅 ≤ 2M（因为 |f|≤M），总长度 &lt; ε/(4M)，所以这部分对上和-下和的贡献 &lt; 2M·ε/(4M)=ε/2。
  - 在剩余闭区间上的振幅 &lt; ε/(2(b-a))，总长度 ≤ b-a，所以这部分贡献 &lt; ε/(2(b-a))·(b-a)=ε/2。
  
  总贡献 &lt; ε/2 + ε/2 = ε。
  
  所以上和-下和可以任意小，f Riemann 可积。∎
  
  **为什么这个证明很重要**：
  它不依赖 Lebesgue 准则，直接用"可数集可以用总长度任意小的开区间覆盖"来证明。
  这是实变函数中"小测度集可以忽略"思想的体现。∎
- **一句话点评**：可数间断点⇒Riemann 可积。证明：可数集可用总长度任意小的开区间覆盖→间断点贡献可忽略→连续部分用 Cantor 定理。

**【D2-3-054】** 什么是 Darboux 函数？为什么说"导数都是 Darboux 函数"？

- **难度**：★★★
- **对应知识点**：Darboux 函数
- **解答**：
  **Darboux 函数的定义**：
  如果函数 f 满足介值性质——对任意 a&lt;b 和任意介于 f(a) 和 f(b) 之间的值 c，存在 ξ∈(a,b) 使得 f(ξ)=c，则称 f 为 Darboux 函数。
  
  换句话说，Darboux 函数的图像"不会跳过任何中间值"。
  
  **为什么导数都是 Darboux 函数**：
  
  **Darboux 定理**：如果 f 在 [a,b] 上可导，则 f' 具有介值性质（是 Darboux 函数）。
  
  **证明思路**：
  假设 f'(a)&lt;c&lt;f'(b)，需要证明存在 ξ∈(a,b) 使得 f'(ξ)=c。
  
  定义 g(x)=f(x)-cx。则 g'(x)=f'(x)-c。
  
  g'(a)=f'(a)-c&lt;0，g'(b)=f'(b)-c>0。
  
  g 在 [a,b] 上可导（所以连续），所以 g 在 [a,b] 上有最小值。
  
  因为 g'(a)&lt;0，g 在 a 附近递减，所以最小值不在 a 处。
  因为 g'(b)>0，g 在 b 附近递增，所以最小值不在 b 处。
  
  所以最小值在某个 ξ∈(a,b) 处取得。
  
  由 Fermat 定理，g'(ξ)=0，即 f'(ξ)=c。∎
  
  **为什么这个定理很深刻**：
  
  1. **导数可以不连续，但必须满足介值性质**：
     导数不一定连续（如 f(x)=x²sin(1/x) 的导数在 0 处不连续），但导数一定满足介值性质。
  
  2. **有跳跃间断点的函数不可能是导数**：
     因为跳跃间断点不满足介值性质（跳过了中间值）。
     所以如果一个函数有跳跃间断点，它不可能是某个函数的导数。
  
  3. **这是对"导数应该连续"直觉的挑战**：
     导数可以很"病态"（处处不连续的导数存在吗？这是一个深刻的问题——答案是：导数可以在一个稠密集上不连续，但不能处处不连续）。∎
- **一句话点评**：Darboux 函数=满足介值性质的函数。导数都是 Darboux 函数（Darboux 定理）。所以有跳跃间断点的函数不可能是导数。

**【D2-3-055】** 构造一个处处不连续但满足介值定理的函数（Darboux 函数）。

- **难度**：★★★
- **对应知识点**：病态 Darboux 函数
- **解答**：
  **构造（Conway 基 13 函数）**：
  
  这是一个非常巧妙的构造，由 John Horton Conway 提出。
  
  定义：将实数 x 写成三进制小数（允许以 2 结尾的有限表示），然后：
  - 如果 x 的三进制表示从某一位开始全是 0 或 1（即尾部只有 0 和 1），则 f(x) 等于把尾部的 0 和 1 看成二进制数后的值（乘以适当的比例）
  - 否则 f(x)=0
  
  这个函数满足：
  1. **处处不连续**：在任何区间内，都有 f(x)≠0 的点和 f(x)=0 的点，且两种点都稠密
  2. **满足介值性质**：在任何区间内，f 可以取到 [0,1] 内的任意值
  
  **更简单的构造（思路）**：
  
  另一个经典例子是"把实数分成两个稠密集 A 和 B，然后在 A 上定义 f(x)=sin x，在 B 上定义 f(x)=cos x"——但这个构造不一定满足介值性质。
  
  **为什么处处不连续的 Darboux 函数很令人惊讶**：
  
  直觉上，"满足介值性质"意味着函数"不会跳跃"——应该是"比较连续"的。
  
  但 Conway 基 13 函数表明——存在处处不连续但满足介值性质的函数！
  
  这意味着：
  - 介值性质 ≠ 连续
  - Darboux 函数可以非常病态
  - "不跳跃"不代表"连续"∎
  
  **几何图像**：
  这个函数的图像"到处都是"——在任何区间内，函数值都可以取到 [0,1] 内的任意值。图像是"完全混乱"的——处处不连续，但又"不会跳过任何值"。
- **一句话点评**：Conway 基 13 函数=处处不连续但满足介值性质。它打破了"介值性质⇒连续"的直觉——Darboux 函数可以非常病态。

**【D2-3-056】** 为什么说"单调函数几乎处处可导"？这个定理（Lebesgue 定理）的思路是什么？

- **难度**：★★★
- **对应知识点**：Lebesgue 定理
- **解答**：
  **Lebesgue 定理**：
  单调函数在其定义域内几乎处处可导。
  
  **为什么这个定理很令人惊讶**：
  单调函数可以有很多间断点（至多可数个），可以很"不光滑"。
  但 Lebesgue 定理表明——单调函数"几乎处处"可导！
  
  这意味着——单调性是一个很强的正则性条件，它保证了函数在"几乎所有"点处都有导数。
  
  **证明思路**：
  
  证明比较复杂，核心思想是用"导数的四个 Dini 导数"来刻画。
  
  对任意 x，定义四个 Dini 导数：
  - D⁺f(x)=limsup_{h→0⁺} (f(x+h)-f(x))/h（右上导数）
  - D₊f(x)=liminf_{h→0⁺} (f(x+h)-f(x))/h（右下导数）
  - D⁻f(x)=limsup_{h→0⁻} (f(x+h)-f(x))/h（左上导数）
  - D₋f(x)=liminf_{h→0⁻} (f(x+h)-f(x))/h（左下导数）
  
  f 在 x 处可导 ⟺ 四个 Dini 导数都相等且有限。
  
  证明的关键是证明：
  1. 四个 Dini 导数几乎处处有限
  2. D⁺f=D₊f=D⁻f=D₋f a.e.
  
  这用到了 Vitali 覆盖引理和测度论的技巧。∎
  
  **为什么这个定理很重要**：
  
  1. **它是微积分基本定理的基础**：
     单调函数几乎处处可导，所以可以讨论 f' 的积分。
     但注意：∫ f'(x) dx ≤ f(b)-f(a)，等号不一定成立（奇异函数就是反例）。
  
  2. **它推动了有界变差函数的研究**：
     有界变差函数可以分解为两个单调函数的差，所以有界变差函数也几乎处处可导。
  
  3. **它是实变函数的核心定理之一**：
     Lebesgue 定理是实变函数中最深刻的定理之一——它揭示了单调性和可导性之间的深刻联系。∎
- **一句话点评**：Lebesgue 定理=单调函数几乎处处可导。证明用 Dini 导数+Vitali 覆盖引理。单调性是很强的正则性条件——保证几乎处处可导。

**【D2-3-057】** 什么是"第一纲集"和"第二纲集"？为什么说"可导函数集是第一纲集"？

- **难度**：★★★
- **对应知识点**：Baire 纲定理
- **解答**：
  **无处稠密集的定义**：
  如果集合 A 的闭包的内部是空集，则称 A 为无处稠密集（稀薄集）。
  
  直观上，无处稠密集就是"在任何区间内都不稠密"的集合——它"很稀薄"。
  
  **第一纲集和第二纲集**：
  - 第一纲集（贫集）：可数个无处稠密集的并
  - 第二纲集（剩余集）：不是第一纲集的集合
  
  **Baire 纲定理**：
  完备度量空间是第二纲集——不能表示为可数个无处稠密集的并。
  
  **为什么"可导函数集是第一纲集"**：
  
  考虑 C[0,1]（闭区间上的连续函数空间，sup 范数），它是完备度量空间。
  
  定义 Aₙ={f∈C[0,1] : 存在 x₀∈[0,1] 使得对所有 |h|≤1/n，|f(x₀+h)-f(x₀)|≤n|h|}。
  
  可以证明：
  1. Aₙ 是闭集
  2. Aₙ 是无处稠密集（内部为空）
  
  "在至少一点可导的函数集" ⊂ ∪ₙ Aₙ。
  
  所以"在至少一点可导的函数集"是第一纲集（可数个无处稠密集的并）。
  
  由 Baire 纲定理，C[0,1] 是第二纲集，所以"处处不可导的函数集"是第二纲集（剩余集）。
  
  **这意味着什么**：
  在 C[0,1] 中，"大多数"连续函数是处处不可导的！
  "至少在一点可导"的函数是"少数"（第一纲集，"稀薄"的）。∎
  
  **为什么这个结论很深刻**：
  它打破了"连续函数应该可导"的直觉——不仅存在处处不可导的连续函数（Weierstrass 函数），而且"大多数"连续函数都是处处不可导的！
  
  我们平时研究的"好"函数（多项式、三角函数等）只是函数空间中的一小部分。∎
- **一句话点评**：第一纲集=可数个无处稠密集的并（稀薄），第二纲集=不是第一纲（大多数）。可导函数集是第一纲集——大多数连续函数处处不可导。

**【D2-3-058】** 什么是"几乎处处连续"的精确含义？用测度论语言描述。

- **难度**：★★★
- **对应知识点**：几乎处处连续的测度论描述
- **解答**：
  **几乎处处连续的定义**：
  设 f 是定义在可测集 E 上的函数。如果 f 的间断点集 D 的测度为零（m(D)=0），则称 f 在 E 上几乎处处连续（a.e. 连续）。
  
  **等价描述**：
  f 几乎处处连续 ⟺ 存在零测集 N，使得 f 在 E\N 上处处连续。
  
  **用测度论语言精确描述**：
  
  对任意 ε>0，存在闭集 F⊂E 使得：
  1. m(E\F)&lt;ε
  2. f 在 F 上的限制是连续函数（相对于 F 的子空间拓扑）
  
  这是 Lusin 定理的一个特例——Lusin 定理说的是可测函数"几乎处处连续"（在上述意义下）。
  
  **为什么这个描述很重要**：
  
  1. **它把"几乎处处连续"和"可测性"联系起来**：
     在完备测度空间中，几乎处处连续的函数是可测函数。
     反过来，Lusin 定理表明可测函数"几乎处处连续"（在上述意义下）。
  
  2. **它是 Riemann 可积性的基础**：
     Lebesgue 准则——有界函数 Riemann 可积 ⟺ 几乎处处连续。
  
  3. **它揭示了"连续"和"可测"的关系**：
     连续函数一定可测，可测函数"几乎处处连续"（Lusin 定理）。
     这两个概念在"几乎处处"的意义下是等价的。∎
  
  **注意**：
  "几乎处处连续"和"几乎处处等于一个连续函数"是不同的概念！
  - 几乎处处连续：f 在除零测集外的点处连续
  - 几乎处处等于连续函数：存在连续函数 g，使得 f=g a.e.
  
  例如 Dirichlet 函数几乎处处等于 0（连续函数），但它不是几乎处处连续的（处处不连续）。∎
- **一句话点评**：几乎处处连续=间断点集测度为零。等价于：对任意 ε>0，存在闭集 F，m(E\F)&lt;ε 且 f|_F 连续。注意和"几乎处处等于连续函数"的区别。

**【D2-3-059】** 为什么说"间断点集可以是不可数的零测集"？请举例说明。

- **难度**：★★★
- **对应知识点**：间断点集的复杂性
- **解答**：
  **定理**：
  存在函数 f，其间断点集是不可数的零测集。
  
  **例子（基于 Cantor 集的构造）**：
  
  Cantor 集 C 是一个不可数的零测集（测度为 0，但基数等于连续统）。
  
  构造函数 f(x)=1（x∈C），0（x∉C）。
  
  **验证间断点集**：
  
  在 x∉C 处：
  因为 C 是闭集，x∉C 意味着存在 x 的邻域与 C 不相交（因为 C 是闭集，补集是开集）。
  在这个邻域内，f(x)=0 恒成立。
  所以 f 在 x 处连续。
  
  在 x∈C 处：
  因为 C 是无处稠密集（内部为空），x 的任何邻域内都有不属于 C 的点。
  取 yₙ∉C，yₙ→x，则 f(yₙ)=0→0。
  但 f(x)=1。
  所以 f 在 x 处不连续。
  
  所以 f 的间断点集恰好是 C——不可数的零测集。∎
  
  **为什么这个例子很重要**：
  
  1. **它表明间断点集可以很复杂**：
     间断点集不一定是可数集——它可以是不可数集（如 Cantor 集）。
  
  2. **它表明"不可数"和"测度为零"可以同时成立**：
     Cantor 集是不可数的，但测度为零。
     这打破了"不可数集测度一定大于零"的直觉。
  
  3. **它和 Lebesgue 准则的关系**：
     这个函数的间断点集测度为零，所以它 Riemann 可积（积分=0）。
     虽然它在不可数个点上间断，但这些点的测度为零，不影响积分。∎
  
  **几何图像**：
  这个函数的图像是"两条虚线"——y=1 上的 Cantor 集点和 y=0 上的其他点。Cantor 集很"稀疏"（测度为零），但又"很多"（不可数）。
- **一句话点评**：构造 f(x)=1（x∈Cantor 集），0（其他）——间断点集=Cantor 集（不可数零测集）。不可数和零测可以同时成立。

**【D2-3-060】** 什么是"函数的正则性谱系"？请从间断点的角度描述。

- **难度**：★★★
- **对应知识点**：函数正则性谱系
- **解答**：
  **函数的正则性谱系（从弱到强）**：
  
  从间断点的角度，函数的正则性可以排成一个谱系：
  
  1. **任意函数**：间断点集可以是任意 Fσ 集
     - 例子：Conway 基 13 函数（处处不连续但 Darboux）
  
  2. **可测函数**：间断点集是可测集（Lusin 定理：几乎处处连续）
     - 例子：Dirichlet 函数（可测，处处不连续）
  
  3. **几乎处处连续**：间断点集测度为零
     - 例子：Thomae 函数（间断点=有理数集）
  
  4. **Riemann 可积函数**：有界 + 几乎处处连续（Lebesgue 准则）
     - 例子：单调函数、Thomae 函数
  
  5. **逐段连续函数**：间断点有限个（都是第一类）
     - 例子：阶梯函数、分段多项式
  
  6. **连续函数**：间断点集=空集
     - 例子：多项式、三角函数、Weierstrass 函数（连续但不可导）
  
  7. **Lipschitz 连续函数**：连续 + 斜率有界
     - 例子：sin x、|x|（连续但不可导）
  
  8. **C¹ 函数**：连续可导
     - 例子：x²、eˣ
  
  9. **C^∞ 函数**：无穷次可导
     - 例子：eˣ、sin x
  
  10. **解析函数**：可以展开为幂级数
      - 例子：eˣ、sin x（实解析）、复解析函数
  
  **为什么这个谱系很重要**：
  
  1. **它揭示了不同正则性条件之间的关系**：
     从"任意函数"到"解析函数"，正则性越来越强，条件越来越严格。
  
  2. **它帮助理解不同定理的适用范围**：
     不同的定理需要不同的正则性条件——了解谱系就知道定理在哪里适用。
  
  3. **它是分析学的核心框架**：
     整个分析学就是在研究不同正则性的函数——从最一般的可测函数，到最特殊的解析函数。∎
- **一句话点评**：函数正则性谱系：任意函数→可测→a.e.连续→Riemann可积→逐段连续→连续→Lipschitz→C¹→C^∞→解析。从弱到强，条件越来越严格。

**【D2-3-061】** 求 $f(x)=\frac{x^2-1}{x^2-3x+2}$ 的间断点并分类。

- **难度**：★
- **解答**：$f(x)=\frac{(x-1)(x+1)}{(x-1)(x-2)}$。间断点为 $x=1$ 和 $x=2$。
$x=1$：$\lim_{x\to1}f(x)=\lim\frac{x+1}{x-2}=-2$，极限存在，是可去间断点。
$x=2$：$\lim_{x\to2^+}f(x)=+\infty$，$\lim_{x\to2^-}f(x)=-\infty$，是无穷间断点（第二类）。∎
- **点评**：有理函数的间断点来自分母零点——分子也为零的点可能是可去间断点，否则是无穷间断点。

**【D2-3-062】** 证明：单调函数的间断点都是第一类间断点（跳跃间断点），且至多可数个。

- **难度**：★★
- **解答**：设 $f$ 单调递增。对任意 $x_0$，$f(x_0^-)=\sup_{x<x_0}f(x)$ 和 $f(x_0^+)=\inf_{x>x_0}f(x)$ 都存在（单调有界），且 $f(x_0^-)\leq f(x_0)\leq f(x_0^+)$。若不等则为跳跃间断点，都是第一类。
至多可数：对每个间断点 $x$，对应区间 $(f(x^-),f(x^+))$，这些区间互不相交（单调性）。每个区间含一个有理数，故至多可数。∎
- **点评**：单调函数的间断点结构非常清晰——全是第一类，且至多可数。这是单调函数最重要的正则性性质之一。

**【D2-3-063】** 证明：Dirichlet 函数 $D(x)=\begin{cases}1, & x\in\mathbb{Q}\\0, & x\notin\mathbb{Q}\end{cases}$ 在每一点都不连续。

- **难度**：★
- **解答**：对任意 $x_0$，取有理数列 $r_n\to x_0$，则 $D(r_n)=1\to1$；取无理数列 $s_n\to x_0$，则 $D(s_n)=0\to0$。由 Heine 定理，极限不存在，故不连续。∎
- **点评**：Dirichlet 函数是"处处不连续"的经典例子——有理数和无理数在实数中都稠密，导致函数值在 0 和 1 之间无限振荡。

**【D2-3-064】** 证明：Riemann 函数 $R(x)=\begin{cases}1/q, & x=p/q\text{（既约分数）}\\0, & x\text{ 无理数}\end{cases}$ 在无理点连续，在有理点不连续。

- **难度**：★★
- **解答**：无理点连续：对任意 $\varepsilon>0$，只有有限个有理数 $p/q$ 满足 $1/q\geq\varepsilon$（即 $q\leq1/\varepsilon$）。取 $\delta$ 为 $x_0$ 到这些有理数的最小距离，则 $|x-x_0|<\delta$ 时 $|R(x)|<\varepsilon$。
有理点不连续：$x_0=p/q$ 时 $R(x_0)=1/q>0$，但附近有无理点 $R=0$，故不连续。∎
- **点评**：Riemann 函数是"几乎处处连续但在有理点不连续"的精妙例子——它是 Riemann 可积的（间断点集=有理数，零测），积分值为 0。

### L2 复变函数基础

**【D2-3-065】** 证明：$f(z)=\frac{1}{z}$ 在 $z=0$ 处不连续（在扩充复平面上视为极点）。

- **难度**：★
- **解答**：$\lim_{z\to0}|1/z|=+\infty$，极限不是有限复数，故不连续。在复分析中，$z=0$ 是 $1/z$ 的一阶极点。∎
- **点评**：复函数的"无穷间断"对应奇点理论中的极点——这是复分析独有的分类方式。

**【D2-3-066】** 设 $f(z)=\frac{\sin z}{z}$（$z\neq0$），$f(0)=1$。证明 $f$ 在 $z=0$ 处连续。

- **难度**：★
- **解答**：$\sin z=z-\frac{z^3}{3!}+\cdots$，故 $\frac{\sin z}{z}=1-\frac{z^2}{3!}+\cdots\to1$（$z\to0$）。$f(0)=1$ 等于极限值，故连续。∎
- **点评**：这是复分析中的"可去奇点"例子——补充定义后函数连续且实际上解析。

**【D2-3-067】** 证明：若 $f$ 在 $z_0$ 处连续且 $f(z_0)\neq0$，则存在 $z_0$ 的邻域使 $f(z)\neq0$。

- **难度**：★★
- **解答**：取 $\varepsilon=|f(z_0)|/2>0$。由连续性，$\exists\delta>0$ 使 $|z-z_0|<\delta$ 时 $|f(z)-f(z_0)|<|f(z_0)|/2$。
则 $|f(z)|\geq|f(z_0)|-|f(z)-f(z_0)|>|f(z_0)|/2>0$。∎
- **点评**：连续函数的"保号性"在复分析中同样成立——非零点附近函数值都不为零。这是零点孤立性定理的预备。

### L3 实变函数基础

**【D2-3-068】** 证明：Dirichlet 函数 $D(x)$ 是 Lebesgue 可测函数，且 $\int_{[0,1]}D(x)dx=0$。

- **难度**：★
- **解答**：$D(x)=\chi_{\mathbb{Q}}(x)$。有理数集 $\mathbb{Q}$ 是可数集，故可测（可数集都是 Borel 集），特征函数可测。
$\int D\,dx=m(\mathbb{Q}\cap[0,1])=0$（可数集测度为 0）。∎
- **点评**：Dirichlet 函数不是 Riemann 可积的（上下积分分别为 1 和 0），但它是 Lebesgue 可积的，积分值为 0——这是 Lebesgue 积分优于 Riemann 积分的经典例证。

**【D2-3-069】** 用 Lusin 定理说明：Riemann 函数 $R(x)$ 在 $[0,1]$ 上"几乎连续"。

- **难度**：★★
- **解答**：Riemann 函数的间断点集是有理数集 $\mathbb{Q}\cap[0,1]$，测度为 0。
由 Lusin 定理，$\forall\varepsilon>0$，存在闭集 $F\subset[0,1]$ 使 $m([0,1]\setminus F)<\varepsilon$ 且 $R|_F$ 连续。
实际上，可以取 $F=[0,1]\setminus\bigcup_{q\in\mathbb{Q}\cap[0,1]}(q-\varepsilon/2^n,q+\varepsilon/2^n)$（去掉有理数的小邻域），则 $m(F)>1-\varepsilon$，且 $R$ 在 $F$ 上连续（因为 $F$ 中无理点附近没有有理点）。∎
- **点评**：Lusin 定理的具体应用——去掉有理数的小邻域后，Riemann 函数在剩余闭集上连续。

**【D2-3-070】** 证明：若 $f$ 在 $[a,b]$ 上几乎处处连续且有界，则 $f$ Riemann 可积（Lebesgue 准则）。

- **难度**：★★
- **解答**：Lebesgue 准则：有界函数 $f$ 在 $[a,b]$ 上 Riemann 可积 ⟺ $f$ 的间断点集测度为 0。
$f$ 几乎处处连续 ⟹ 间断点集零测。又 $f$ 有界，由 Lebesgue 准则，$f$ Riemann 可积。∎
- **点评**：这是 Riemann 可积的充要条件——有界 + 几乎处处连续。Dirichlet 函数不满足（处处不连续），Riemann 函数满足（仅有理点不连续）。

## 跨领域综合题（补充）

**【D2-3-CROSS-040】**（D2 × D7 三角学）**三角函数的间断点**：tan x, cot x, sec x, csc x 的间断点是什么类型？这和三角函数的几何定义有什么关系？

- **难度**：★★★
- **对应知识点**：三角函数的间断点（D7 联动）、几何定义
- **来源**：间断点与三角学
- **解答**：
  **四个三角函数的间断点**：
  
  1. **tan x = sin x / cos x**：
     间断点：cos x=0，即 x=π/2+kπ。
     类型：无穷间断点（左右极限分别为 +∞ 和 -∞）。
  
  2. **cot x = cos x / sin x**：
     间断点：sin x=0，即 x=kπ。
     类型：无穷间断点。
  
  3. **sec x = 1 / cos x**：
     间断点：cos x=0，即 x=π/2+kπ。
     类型：无穷间断点。
  
  4. **csc x = 1 / sin x**：
     间断点：sin x=0，即 x=kπ。
     类型：无穷间断点。
  
  **为什么都是无穷间断点**：
  这四个函数都是"分子有界、分母趋于 0"的形式——当分母趋于 0 时，函数值趋于无穷大。
  
  **和几何定义的关系**：
  
  从单位圆的几何定义来看：
  - tan x = 对边/邻边 = y/x——当 x=0（邻边为 0）时，tan x 无定义
  - cot x = 邻边/对边 = x/y——当 y=0（对边为 0）时，cot x 无定义
  - sec x = 斜边/邻边 = 1/x——当 x=0 时，sec x 无定义
  - csc x = 斜边/对边 = 1/y——当 y=0 时，csc x 无定义
  
  在单位圆上，"邻边为 0"对应角度 π/2+kπ（点在 y 轴上），"对边为 0"对应角度 kπ（点在 x 轴上）。
  
  当角度趋近这些值时，单位圆上的点趋近坐标轴——邻边或对边趋近 0，所以比值趋于无穷大。∎
  
  **几何图像**：想象单位圆上的点趋近 y 轴——邻边（x 坐标）越来越小，对边（y 坐标）趋近 1。tan x=对边/邻边 趋于无穷大——这就是无穷间断点的几何来源。
- **一句话点评**：tan/cot/sec/csc 的间断点都是无穷型——分母（sin 或 cos）趋于 0。几何上对应单位圆上的点趋近坐标轴——邻边或对边趋于 0。

**【D2-3-CROSS-041】**（D2 × D5 级数）**函数项级数的间断点**：为什么说"一致收敛保持连续性"，但"逐点收敛不一定"？请举例说明。

- **难度**：★★★
- **对应知识点**：一致收敛与连续（D5 联动）、间断点
- **来源**：级数与间断点
- **解答**：
  **一致收敛保持连续性**：
  如果连续函数列 {fₙ} 一致收敛于 f，则 f 连续。
  
  证明（三点论证法）：
  对任意 x₀，任意 ε>0：
  1. 一致收敛 ⇒ 存在 N 使得 |fₙ(x)-f(x)|&lt;ε/3 对所有 x 成立
  2. fₙ 连续 ⇒ 存在 δ>0 使得 |x-x₀|&lt;δ ⇒ |fₙ(x)-fₙ(x₀)|&lt;ε/3
  3. 三角不等式 ⇒ |f(x)-f(x₀)|&lt;ε
  
  所以 f 连续。∎
  
  **逐点收敛不一定保持连续性**：
  逐点收敛的连续函数列，极限函数可能不连续。
  
  **经典反例**：
  fₙ(x)=xⁿ 在 [0,1] 上。
  
  逐点收敛于 f(x)=0（x&lt;1）, f(1)=1。
  
  f 在 x=1 处不连续（跳跃间断点）。
  
  但收敛不是一致的——sup_{x∈[0,1]} |fₙ(x)-f(x)|=1（在 x 接近 1 时，xⁿ 接近 1，但 f(x)=0）。
  
  **为什么一致收敛能保持连续**：
  一致收敛保证了"对所有 x 都成立"——这样我们可以用同一个 N 来估计 f(x) 和 f(x₀)。
  
  逐点收敛的 N 依赖于 x——不能用同一个 N 来估计不同点的函数值。
  
  **更深的意义**：
  这个定理告诉我们——"极限"和"连续"不一定可交换：
  lim_{n→∞} (lim_{x→x₀} fₙ(x)) = lim_{n→∞} fₙ(x₀) = f(x₀)
  但 lim_{x→x₀} (lim_{n→∞} fₙ(x)) = lim_{x→x₀} f(x) 可能不等于 f(x₀)
  
  一致收敛保证了这两个极限可交换。∎
  
  **几何图像**：一致收敛的函数列，所有函数的图像"一起"趋近极限图像——没有任何点"掉队"。逐点收敛的函数列，某些点可能"掉队"——在这些点处，极限图像可能有"跳跃"。
- **一句话点评**：一致收敛⇒极限连续（三点论证法）；逐点收敛⇏极限连续（xⁿ 反例）。一致收敛保证"极限"和"连续"可交换。

## 本模块易错点总结

1. **间断点分类**：
   - 第一类：左右极限都存在（可去、跳跃）
   - 第二类：至少一个不存在（无穷、振荡）
   - 可去：极限存在但≠函数值；跳跃：左右极限不等

2. **单调函数的间断点**：
   - 都是第一类（跳跃型）
   - 至多可数个
   - 基础是实数完备性（确界原理）

3. **Dirichlet 函数**：
   - 处处不连续
   - Riemann 不可积（间断点集测度>0）
   - Lebesgue 可积（积分=0）

4. **Thomae 函数**：
   - 有理点间断（可去型），无理点连续
   - 间断点集=有理数集（测度为零）
   - Riemann 可积（积分=0）

5. **Weierstrass 函数**：
   - 处处连续处处不可导
   - 打破了"连续函数应该可导"的直觉
   - 是最早的分形例子之一

6. **Cantor 函数**：
   - 单调连续但导数几乎处处为零
   - "偷偷地"在 Cantor 集上上升
   - 导数为零不代表函数是常数

7. **Baire 纲定理**：
   - 大多数连续函数处处不可导
   - 光滑函数是例外，病态才是常态
   - 基础是完备性

8. **Lebesgue 准则**：
   - Riemann 可积 ⟺ 间断点集测度为零
   - 间断点多不一定不可积——关键看测度
   - Thomae 函数可积（间断点可数，测度为零）
   - Dirichlet 函数不可积（间断点集测度>0）

9. **可去 vs 跳跃**：
   - 可去：极限存在但≠函数值——可以"去掉"
   - 跳跃：左右极限不等——无法"去掉"
   - Thomae 函数的有理点是可去间断点

10. **病态函数的意义**：
    - 不是"怪物"，而是理论发展的催化剂
    - Dirichlet 函数 → Lebesgue 积分
    - Weierstrass 函数 → 实变函数
    - Cantor 函数 → 集合论
