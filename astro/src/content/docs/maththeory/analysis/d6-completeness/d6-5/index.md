## 第一章 引言：从不完备到完备的跨越

### 1.1 问题的提出

D6-4 中我们证明了：(C[a,b], ||·||_p) 对 1 ≤ p &lt; ∞ 是不完备的。具体地，存在连续函数列 {fₙ} 是 Lp-Cauchy 列，但它的 Lp 极限是一个不连续的阶跃函数，不在 C[a,b] 中。

这意味着：如果我们只允许连续函数，那么在 Lp 范数下，"Cauchy 列收敛"这件事不成立。分析学中大量的存在性证明（微分方程的解、变分问题的极值、积分方程的解）都依赖于"取 Cauchy 列的极限"这一技术。如果空间不完备，极限可能不在空间内，存在性证明就无法完成。

**解决思路**：完备化。把 C[a,b] 在 Lp 范数下的完备化记为 Lp[a,b]。D6-4 第七章中我们给出了度量空间完备化的一般构造（Cauchy 列等价类法），但那个构造是抽象的——Lp[a,b] 中的元素是"连续函数 Cauchy 列的等价类"，不是具体的函数。

**本模块的核心任务**：证明 Lp[a,b] 可以具体实现为"Lebesgue 可积函数的等价类空间"，并且在这个具体实现下，Riesz-Fischer 定理证明了 Lp[a,b] 的完备性。

### 1.2 为什么是 Lebesgue 可积函数

D6-4 第六章中我们看到，Riemann 可积函数空间 R[a,b] 在 L¹ 范数下也不完备——Cauchy 列可以收敛到处处不连续的 Dirichlet 函数，而 Dirichlet 函数不是 Riemann 可积的。

Lebesgue 积分的核心创新是"分割值域而非定义域"，这使得可积函数类大大扩展：
- Riemann 可积 ⇔ 有界且 a.e. 连续
- Lebesgue 可积 ⇔ 可测且 ∫|f| &lt; ∞（不要求 a.e. 连续）

Dirichlet 函数是 Lebesgue 可积的（积分值为 0，因为有理点集测度为 0），但不是 Riemann 可积的。

**关键事实**：C[a,b] 在 Lp 范数下的完备化，恰好等于 Lebesgue p-次可积函数的等价类空间 Lp[a,b]。

**📐 几何锚定**：Lp 空间的几何图像是"把函数看作无限维空间中的点"。每个 Lebesgue 可积函数 f 是 Lp 空间中的一个"点"，两个函数 f 和 g 的"距离"是 ||f-g||_p = (∫|f-g|^p)^{1/p}。p=1 时，距离就是两个函数图像之间的"面积差"；p=2 时，距离是"面积差的平方根"，类似于欧氏距离的无限维推广；p=∞ 时，距离是两个函数图像之间的"最大垂直间隙"（sup 范数）。Lp 空间的完备性意味着：任何一串"越来越靠近"的函数点，必然凝聚到 Lp 空间中的某个函数点上——Lp 空间没有针孔。

## 第二章 Lp 空间的定义

### 2.1 可测函数

设 (X, ℳ, μ) 是一个测度空间（本模块主要考虑 X=[a,b], ℳ=Lebesgue 可测集, μ=Lebesgue 测度）。

**定义（可测函数）**：函数 f : X → ℝ（或 ℂ）称为可测函数，如果对任意开集 U ⊂ ℝ（或 ℂ），f^{-1}(U) ∈ ℳ。

等价地：对任意 a ∈ ℝ，{x : f(x) > a} ∈ ℳ。

**可测函数的运算封闭性**：
- 可测函数的线性组合仍可测
- 可测函数的乘积仍可测
- 可测函数列的逐点极限仍可测（这是可测函数比连续函数更"稳定"的关键性质）
- 可测函数的 |f|, max(f,g), min(f,g) 仍可测

**简单函数**：只取有限个值的可测函数。简单函数是可测函数的"基本构件"——任何非负可测函数都可以表示为递增简单函数列的极限。

### 2.2 Lp 空间的定义

**定义（Lp 空间）**：对 1 ≤ p &lt; ∞，定义
Lp(X, μ) = {f : X → ℝ（或 ℂ）: f 可测且 ∫_X |f|^p dμ &lt; ∞}

对 p = ∞，定义
L^∞(X, μ) = {f : f 可测且存在 M 使得 |f(x)| ≤ M a.e.}
即本性有界函数空间。

**Lp 范数**：
- 1 ≤ p &lt; ∞：||f||_p = (∫ |f|^p dμ)^{1/p}
- p = ∞：||f||_∞ = ess sup |f| = inf{M : |f(x)| ≤ M a.e.}

**等价类**：Lp 空间中的元素不是单个函数，而是"a.e. 相等的函数的等价类"。即如果 f = g a.e.，则 [f] = [g]。这是因为 ||f||_p = 0 ⇔ f = 0 a.e.，为了满足范数的"正定性"（||f||=0 ⇔ f=0），必须把 a.e. 相等的函数视为同一元素。

**📐 几何图像**：Lp 空间的"点"是函数的等价类，这在几何上意味着：我们不关心函数在零测集上的取值。零测集就像"零体积的尘埃"——在 Lp 距离的度量下，改变函数在零测集上的值不改变函数的"位置"。这与 C[a,b] 形成对比：C[a,b] 中的元素是具体的连续函数，每个点的取值都重要（因为连续性由每个点的邻域决定）。Lp 空间的"模糊性"（忽略零测集）正是它完备性的来源——我们允许函数在零测集上"任意行为"，从而 Cauchy 列的极限总是可测函数（可测函数列的极限可测），不需要额外的连续性条件。

### 2.3 Lp 是线性空间

**定理**：Lp(X, μ) 对 1 ≤ p ≤ ∞ 是线性空间。

**证明**：
- 加法封闭：若 f, g ∈ Lp，则 |f+g|^p ≤ (|f|+|g|)^p ≤ 2^p(|f|^p+|g|^p)（因为 (a+b)^p ≤ 2^p(a^p+b^p) 对 a,b≥0），故 ∫|f+g|^p ≤ 2^p(∫|f|^p+∫|g|^p) &lt; ∞。
- 数乘封闭：||αf||_p = |α| ||f||_p &lt; ∞。
- 零元：零函数的等价类。
- 负元：-f 的等价类。
- 线性空间公理可逐条验证。∎

### 2.4 典型例子

**例 1**：[0,1] 上的函数 f(x) = x^{-α}。
- f ∈ Lp[0,1] ⇔ ∫₀¹ x^{-αp} dx &lt; ∞ ⇔ αp &lt; 1 ⇔ α &lt; 1/p。
- 所以 α 越大（在 0 附近越奇异），需要越大的 p 才能可积。

**例 2**：(1,∞) 上的函数 f(x) = x^{-α}。
- f ∈ Lp(1,∞) ⇔ ∫₁^∞ x^{-αp} dx &lt; ∞ ⇔ αp > 1 ⇔ α > 1/p。
- 所以 α 越小（在无穷远处衰减越慢），需要越小的 p 才能可积。

**例 3**：Dirichlet 函数 D(x)（有理点 1，无理点 0）。
- D ∈ Lp[0,1] 对所有 p，因为 D = 0 a.e.，||D||_p = 0。
- D 是 Lp 中的零元。

**例 4**：f(x) = 1/x 在 (0,1) 上。
- f ∉ Lp(0,1) 对任何 p ≥ 1，因为 ∫₀¹ x^{-p} dx = ∞。

## 第三章 Hölder 不等式

### 3.1 共轭指数

**定义**：对 1 ≤ p ≤ ∞，定义其共轭指数 q 满足 1/p + 1/q = 1。
- p=1 ⟺ q=∞
- p=2 ⟺ q=2（自共轭）
- 1 &lt; p &lt; ∞ ⟺ q = p/(p-1)

### 3.2 Hölder 不等式

**定理（Hölder 不等式）**：设 1 ≤ p ≤ ∞，q 是 p 的共轭指数。若 f ∈ Lp, g ∈ Lq，则 fg ∈ L¹，且
||fg||₁ ≤ ||f||_p ||g||_q

即 ∫|fg| ≤ (∫|f|^p)^{1/p} (∫|g|^q)^{1/q}（p=∞ 时右端为 ||f||∞ ||g||₁）。

### 3.3 证明（1 &lt; p &lt; ∞ 的情形）

**第一步：Young 不等式**
对 a, b ≥ 0，有 ab ≤ a^p/p + b^q/q，其中 1/p+1/q=1。

证明：考虑函数 φ(t) = t^p/p + 1/q - t（t ≥ 0）。φ'(t) = t^{p-1} - 1，φ'(t)=0 ⟺ t=1。φ(1) = 1/p + 1/q - 1 = 0。φ''(t) = (p-1)t^{p-2} > 0，故 t=1 是全局最小值。所以 φ(t) ≥ 0，即 t ≤ t^p/p + 1/q。令 t = a b^{-q/p}（b>0），得 a b^{-q/p} ≤ a^p b^{-q}/p + 1/q。两边乘 b^q，注意 q + q/p = q(1+1/p) = q·(1/p+1/q)·p? 不对，直接算：b^q · b^{-q/p} = b^{q(1-1/p)} = b^{q·1/q} = b。所以 ab ≤ a^p/p + b^q/q。∎

**第二步：标准化**
若 ||f||_p = 0 或 ||g||_q = 0，则 f=0 a.e. 或 g=0 a.e.，不等式显然成立。
否则令 F = f/||f||_p, G = g/||g||_q，则 ||F||_p = ||G||_q = 1。

**第三步：应用 Young 不等式并积分**
对每个 x，|F(x)G(x)| ≤ |F(x)|^p/p + |G(x)|^q/q。
积分得 ∫|FG| ≤ (1/p)∫|F|^p + (1/q)∫|G|^q = 1/p + 1/q = 1。
即 ∫|fg|/(||f||_p ||g||_q) ≤ 1，故 ∫|fg| ≤ ||f||_p ||g||_q。∎

### 3.4 p=1 和 p=∞ 的情形

**p=1, q=∞**：∫|fg| ≤ ∫(|f| · ||g||∞) = ||g||∞ ∫|f| = ||f||₁ ||g||∞。

**p=∞, q=1**：同理。

### 3.5 Hölder 不等式的意义

Hölder 不等式是 Lp 空间理论中最基本的不等式，它的意义包括：

1. **对偶性的基础**：Hölder 不等式说明每个 g ∈ Lq 定义了 Lp 上的一个有界线性泛函 φ_g(f) = ∫fg，且 ||φ_g|| ≤ ||g||_q。这是 Lp 空间对偶理论的基础（第七章）。

2. **Minkowski 不等式的证明工具**：下一章将用 Hölder 不等式证明 Minkowski 不等式。

3. **插值不等式的基础**：Hölder 不等式可以推广为多个函数的乘积不等式，以及 Lp 插值定理。

4. **等号成立条件**：Hölder 不等式等号成立当且仅当存在常数 α, β 不全为零，使得 α|f|^p = β|g|^q a.e.。即 |f|^p 和 |g|^q 成比例。

**📐 几何图像**：Hölder 不等式的几何图像是"无限维空间中的角度"。在欧氏空间 ℝⁿ 中，Cauchy-Schwarz 不等式 |a·b| ≤ ||a|| ||b|| 说的是两个向量的内积不超过它们长度的乘积——这是角度的余弦不超过 1。Hölder 不等式是 Cauchy-Schwarz 不等式在 Lp 空间中的推广：当 p=q=2 时，Hölder 不等式就是 Cauchy-Schwarz 不等式 |∫fg| ≤ ||f||₂ ||g||₂，它说的是 L² 空间中两个"函数向量"的内积不超过它们长度的乘积。对于一般的 p 和 q，Hölder 不等式描述了 Lp 和 Lq 这两个"互补空间"之间的"配对"——就像 ℝⁿ 中的行向量和列向量的配对一样。

## 第四章 Minkowski 不等式与范数验证

### 4.1 Minkowski 不等式

**定理（Minkowski 不等式）**：对 1 ≤ p ≤ ∞，若 f, g ∈ Lp，则
||f+g||_p ≤ ||f||_p + ||g||_p

### 4.2 证明（1 &lt; p &lt; ∞ 的情形）

**第一步：p=1 的情形**
||f+g||₁ = ∫|f+g| ≤ ∫(|f|+|g|) = ||f||₁ + ||g||₁。

**第二步：1 &lt; p &lt; ∞ 的情形**
若 ||f+g||_p = 0，不等式显然成立。否则：
|f+g|^p = |f+g| · |f+g|^{p-1} ≤ (|f|+|g|) · |f+g|^{p-1}

积分得：
∫|f+g|^p ≤ ∫|f|·|f+g|^{p-1} + ∫|g|·|f+g|^{p-1}

对右端两项分别应用 Hölder 不等式。注意 |f+g|^{p-1} ∈ Lq，因为
∫(|f+g|^{p-1})^q = ∫|f+g|^{(p-1)q} = ∫|f+g|^p &lt; ∞（因为 (p-1)q = p）。

所以：
∫|f|·|f+g|^{p-1} ≤ ||f||_p · |||f+g|^{p-1}||_q = ||f||_p · (∫|f+g|^p)^{1/q} = ||f||_p · ||f+g||_p^{p/q}

同理 ∫|g|·|f+g|^{p-1} ≤ ||g||_p · ||f+g||_p^{p/q}。

因此：
||f+g||_p^p ≤ (||f||_p + ||g||_p) · ||f+g||_p^{p/q}

两边除以 ||f+g||_p^{p/q}（非零），注意 p - p/q = p(1-1/q) = p·1/p = 1，得：
||f+g||_p ≤ ||f||_p + ||g||_p。∎

**第三步：p=∞ 的情形**
|f+g| ≤ |f|+|g| ≤ ||f||∞ + ||g||∞ a.e.，故 ||f+g||∞ ≤ ||f||∞ + ||g||∞。

### 4.3 范数验证

**定理**：(Lp, ||·||_p) 是赋范线性空间。

**验证范数三公理**：
1. **非负性**：||f||_p ≥ 0 显然。||f||_p = 0 ⇔ ∫|f|^p = 0 ⇔ |f|^p = 0 a.e. ⇔ f = 0 a.e. ⇔ [f] 是零元。（这里用到了等价类的定义）
2. **齐次性**：||αf||_p = (∫|αf|^p)^{1/p} = (|α|^p ∫|f|^p)^{1/p} = |α| ||f||_p。
3. **三角不等式**：即 Minkowski 不等式。

因此 Lp 是赋范线性空间。∎

### 4.4 0 &lt; p &lt; 1 的情形

值得注意的是，当 0 &lt; p &lt; 1 时，Minkowski 不等式**反向**成立：||f+g||_p ≥ ||f||_p + ||g||_p（在某种意义下）。此时 ||·||_p 不是范数（不满足三角不等式），但 d(f,g) = ∫|f-g|^p 是一个度量（准范数）。0 &lt; p &lt; 1 的 Lp 空间是完备的度量空间，但不是赋范线性空间，也不是局部凸的。

**📐 几何深化**：Minkowski 不等式在几何上是"无限维空间中的三角不等式"。在欧氏空间中，三角不等式 ||a+b|| ≤ ||a||+||b|| 说的是"两点之间直线最短"——从原点到 a+b 的距离不超过从原点到 a 再到 b 的距离。Minkowski 不等式是这个几何事实在 Lp 空间中的推广：两个函数向量 f 和 g 的和的"长度"不超过它们各自长度的和。p=2 时，这就是欧氏几何中的三角不等式；p=1 时，这是"曼哈顿距离"的三角不等式；p=∞ 时，这是"切比雪夫距离"的三角不等式。不同的 p 对应不同的几何，但三角不等式始终成立——这是 Lp 空间成为"几何空间"的基础。

## 第五章 Riesz-Fischer 定理（核心）

### 5.1 定理陈述

**定理（Riesz-Fischer 定理）**：对 1 ≤ p ≤ ∞，赋范线性空间 (Lp(X, μ), ||·||_p) 是完备的，即 Lp 中的每个 Cauchy 列都收敛到 Lp 中的某个元素。

这个定理是 Lp 空间理论的核心，也是本模块最重要的结果。它说明：Lebesgue p-次可积函数的等价类空间在 Lp 范数下没有针孔。

### 5.2 证明策略

Riesz-Fischer 定理的证明采用以下策略：

1. 取 Lp 中的 Cauchy 列 {fₙ}
2. 取一个"快速收敛"的子列 {f_{n_k}}，使得 ||f_{n_{k+1}} - f_{n_k}||_p &lt; 2^{-k}
3. 证明这个子列几乎处处收敛到某个可测函数 f
4. 证明 f ∈ Lp 且 f_{n_k} → f 在 Lp 中
5. 由 Cauchy 列的性质，原序列 fₙ → f 在 Lp 中

关键的技术工具是：**Lp 收敛的 Cauchy 列存在子列几乎处处收敛**。

### 5.3 完整证明（1 ≤ p &lt; ∞）

**第一步：取快速收敛子列**
设 {fₙ} 是 Lp 中的 Cauchy 列。对每个 k，取 n_k 使得当 m,n ≥ n_k 时，||fₘ - fₙ||_p &lt; 2^{-k}。可以取 n₁ &lt; n₂ &lt; n₃ &lt; ...（递增）。

令 g_k = f_{n_k}，则 ||g_{k+1} - g_k||_p &lt; 2^{-k}。

**第二步：构造控制级数**
令 h = Σ_{k=1}^∞ |g_{k+1} - g_k|。由 Minkowski 不等式的级数形式（三角不等式的推广）：
||h||_p ≤ Σ_{k=1}^∞ ||g_{k+1} - g_k||_p &lt; Σ_{k=1}^∞ 2^{-k} = 1 &lt; ∞。

所以 h ∈ Lp，特别地 h &lt; ∞ a.e.（因为如果 h=∞ 在正测度集上，则 ∫h^p = ∞）。

**第三步：子列几乎处处收敛**
对使得 h(x) &lt; ∞ 的 x，级数 Σ(g_{k+1}(x) - g_k(x)) 绝对收敛（因为 |g_{k+1}(x)-g_k(x)| ≤ h(x) 且 Σ|g_{k+1}-g_k| = h(x) &lt; ∞）。

因此 g_k(x) = g₁(x) + Σ_{j=1}^{k-1}(g_{j+1}(x)-g_j(x)) 收敛。

定义 f(x) = lim_{k→∞} g_k(x)（当极限存在时），f(x)=0（否则）。则 f 是可测函数（可测函数列的极限可测），且 g_k → f a.e.

**第四步：f ∈ Lp**
由 Fatou 引理：
∫|f|^p = ∫lim inf |g_k|^p ≤ lim inf ∫|g_k|^p。

因为 {g_k} 是 Cauchy 列的子列，所以 {g_k} 有界（Cauchy 列必有界）：存在 M 使得 ||g_k||_p ≤ M 对所有 k。
故 ∫|f|^p ≤ M^p &lt; ∞，即 f ∈ Lp。

**第五步：g_k → f 在 Lp 中**
对任意 ε > 0，取 K 使得当 k,l ≥ K 时，||g_k - g_l||_p &lt; ε（因为 {g_k} 是 Cauchy 列）。

固定 k ≥ K，令 l → ∞。g_l → f a.e.，所以 |g_k - g_l|^p → |g_k - f|^p a.e.

由 Fatou 引理：
∫|g_k - f|^p = ∫lim inf |g_k - g_l|^p ≤ lim inf ∫|g_k - g_l|^p ≤ ε^p。

所以 ||g_k - f||_p ≤ ε 对所有 k ≥ K。即 g_k → f 在 Lp 中。

**第六步：原序列 fₙ → f 在 Lp 中**
对任意 ε > 0，取 N 使得当 m,n ≥ N 时，||fₘ - fₙ||_p &lt; ε/2。
取 K 使得 n_K ≥ N 且 ||g_K - f||_p &lt; ε/2（因为 g_k → f 在 Lp 中）。
则当 n ≥ N 时：
||fₙ - f||_p ≤ ||fₙ - f_{n_K}||_p + ||f_{n_K} - f||_p &lt; ε/2 + ε/2 = ε。

所以 fₙ → f 在 Lp 中。∎

### 5.4 p=∞ 的情形

**证明**：设 {fₙ} 是 L^∞ 中的 Cauchy 列。对每个 m,n，|fₘ(x)-fₙ(x)| ≤ ||fₘ-fₙ||∞ a.e.。

令 E_{m,n} = {x : |fₘ(x)-fₙ(x)| > ||fₘ-fₙ||∞}，则 μ(E_{m,n})=0。令 E = ⋃_{m,n} E_{m,n}，则 μ(E)=0（可数个零测集的并）。

在 E^c 上，{fₙ(x)} 是一致 Cauchy 列（因为 |fₘ(x)-fₙ(x)| ≤ ||fₘ-fₙ||∞ → 0 对所有 x ∈ E^c 一致成立）。

由实数（或复数）的完备性，对每个 x ∈ E^c，fₙ(x) 收敛到某个 f(x)。定义 f(x)=0（x∈E）。

收敛在 E^c 上一致，故 ||fₙ-f||∞ → 0。且 f ∈ L^∞（因为 ||f||∞ ≤ ||f-fₙ||∞ + ||fₙ||∞ &lt; ∞）。∎

### 5.5 证明的关键洞察

Riesz-Fischer 定理的证明有几个关键洞察：

1. **快速收敛子列**：Cauchy 列不一定 a.e. 收敛，但可以取子列使得"相邻项的 Lp 距离"可和（Σ2^{-k}&lt;∞），从而控制级数收敛，保证 a.e. 收敛。

2. **Fatou 引理的作用**：Fatou 引理（∫lim inf ≤ lim inf ∫）是连接 a.e. 收敛和 Lp 收敛的桥梁。它允许我们从 a.e. 收敛的子列推出极限函数在 Lp 中，并且子列在 Lp 中收敛到极限。

3. **Lebesgue 积分的关键优势**：证明中用到了"可测函数列的极限可测"和 Fatou 引理，这两个性质都是 Lebesgue 积分框架下的。Riemann 积分框架下，可积函数列的极限不一定可积（Dirichlet 函数反例），这就是 R[a,b] 不完备而 Lp[a,b] 完备的根本原因。

**📐 几何图像**：Riesz-Fischer 定理的几何图像是"无限维空间中 Cauchy 列的凝聚"。在 Lp 空间中，Cauchy 列是一串"越来越靠近"的函数点。证明的关键是取一个"快速收敛"的子列——相邻函数点之间的距离可和（&lt; 2^{-k}），这意味着这些函数点沿着一条"长度有限"的路径排列。在有限维欧氏空间中，长度有限的路径必然有终点（由实数完备性）；在 Lp 空间中，"长度有限的路径"也必然有终点——这就是 Riesz-Fischer 定理。终点 f 是子列的 a.e. 极限，而 a.e. 极限的可测性（Lebesgue 框架）保证了 f 在 Lp 空间中。几何上，这就像 Lp 空间中没有"针孔"——任何沿着有限长度路径逼近的点，都在空间内有一个实实在在的"终点"。

### 5.6 Riesz-Fischer 定理的历史注记

Riesz-Fischer 定理由 Frigyes Riesz 和 Ernst Fischer 于 1907 年独立证明。最初的形式是关于 L² 空间的：L²[0,1] 中的每个 Cauchy 列都收敛到 L² 中的函数。这个定理与 Hilbert 空间理论的诞生密切相关——它证明了 L² 是完备的内积空间（Hilbert 空间），为 Fourier 分析的严格化奠定了基础。

Riesz 在 1910 年将定理推广到一般的 Lp 空间（1 &lt; p &lt; ∞），并建立了 Lp 空间的对偶理论。

## 第六章 L² 作为 Hilbert 空间

### 6.1 内积结构

L² 空间在所有 Lp 空间中是最特殊的——它具有内积结构。

**定义（L² 内积）**：对 f, g ∈ L²(X, μ)，定义
⟨f, g⟩ = ∫_X f(x) \overline{g(x)} dμ
（实值函数时为 ∫fg）

**验证内积公理**：
1. 线性性：⟨αf+βg, h⟩ = α⟨f,h⟩ + β⟨g,h⟩
2. 共轭对称性：⟨f,g⟩ = \overline{⟨g,f⟩}
3. 正定性：⟨f,f⟩ = ∫|f|² ≥ 0，且 ⟨f,f⟩=0 ⇔ f=0 a.e.

由 Hölder 不等式（p=q=2），|⟨f,g⟩| ≤ ||f||₂ ||g||₂，所以内积是良定义的（积分有限）。

**范数与内积的关系**：||f||₂ = √⟨f,f⟩。

### 6.2 Hilbert 空间

**定义**：完备的内积空间称为 Hilbert 空间。

由 Riesz-Fischer 定理，L² 是完备的；由内积结构，L² 是内积空间。因此：

**定理**：L²(X, μ) 是 Hilbert 空间。

**📐 几何图像**：L² 作为 Hilbert 空间的几何图像是"无限维欧氏空间"。在有限维欧氏空间 ℝⁿ 中，我们有内积 a·b = Σaᵢbᵢ，范数 ||a|| = √(Σaᵢ²)，角度 cos θ = (a·b)/(||a||||b||)，正交投影，勾股定理等几何概念。L² 空间把这些概念推广到无限维：内积 ⟨f,g⟩ = ∫fg 是"无限维的点积"（把函数值看作无限多个坐标），范数 ||f||₂ = √(∫f²) 是"无限维的长度"，正交 ⟨f,g⟩=0 是"无限维的垂直"。L² 空间中的勾股定理：若 f⊥g，则 ||f+g||₂² = ||f||₂² + ||g||₂²。Hilbert 空间是欧氏几何在无限维的最自然推广。

### 6.3 正交与正交系

**定义（正交）**：f, g ∈ L² 称为正交的，如果 ⟨f,g⟩ = 0。

**定义（规范正交系）**：L² 中的函数族 {e_α} 称为规范正交系，如果 ⟨e_α, e_β⟩ = δ_{αβ}（α=β 时为 1，否则为 0）。

**经典例子：三角函数系**
在 L²[0, 2π] 中，函数族
{1/√(2π), cos x/√π, sin x/√π, cos 2x/√π, sin 2x/√π, ...}
是规范正交系。

验证：∫₀^{2π} cos(mx)cos(nx)dx = πδ_{mn}（m,n≥1），∫₀^{2π} sin(mx)sin(nx)dx = πδ_{mn}，∫₀^{2π} cos(mx)sin(nx)dx = 0。

**Bessel 不等式**：若 {eₙ} 是规范正交系，f ∈ L²，则
Σ_{n=1}^∞ |⟨f,eₙ⟩|² ≤ ||f||₂²

**Parseval 等式**：若 {eₙ} 是完备的规范正交系（即其有限线性组合在 L² 中稠密），则
Σ_{n=1}^∞ |⟨f,eₙ⟩|² = ||f||₂²

且 f = Σ ⟨f,eₙ⟩ eₙ（在 L² 意义下收敛）。

### 6.4 三角函数系的完备性

**定理（Riesz-Fischer + Fourier）**：三角函数系在 L²[0,2π] 中是完备的规范正交系。

这意味着：对任何 f ∈ L²[0,2π]，其 Fourier 级数
a₀/2 + Σ(aₙ cos nx + bₙ sin nx)
在 L² 意义下收敛到 f，且 Parseval 等式成立：
(1/π)∫₀^{2π} |f|² = a₀²/2 + Σ(aₙ² + bₙ²)

**证明思路**：
1. 三角函数系是规范正交系（直接积分验证）
2. 三角多项式在 L²[0,2π] 中稠密（Weierstrass 三角逼近定理 + 连续函数在 L² 中稠密）
3. 由稠密性，三角函数系是完备的规范正交系
4. 由 Hilbert 空间理论，完备规范正交系给出 Parseval 等式和 Fourier 展开

**历史意义**：三角函数系的 L² 完备性是 Fourier 分析严格化的核心。在 Riesz-Fischer 定理之前，Fourier 级数的收敛性是一个难题（逐点收敛极难，需要 Dirichlet 条件等）。Riesz-Fischer 定理表明：在 L² 意义下，Fourier 级数总是收敛的——这是 Fourier 分析的"正确"收敛概念。

### 6.5 最佳逼近

**定理（最佳逼近）**：设 M 是 Hilbert 空间 H 的闭子空间，x ∈ H。则存在唯一的 y₀ ∈ M 使得 ||x-y₀|| = inf_{y∈M} ||x-y||。且 y₀ 是 x 在 M 上的正交投影，即 x-y₀ ⊥ M。

在 L² 空间中，最佳逼近定理有广泛应用：
- Fourier 级数的部分和是 f 在三角多项式子空间中的最佳 L² 逼近
- 最小二乘法是 L² 最佳逼近的离散版本
- 条件期望是 L² 最佳逼近（在子 σ-代数可测函数子空间中的投影）

## 第七章 Lp 空间的包含关系与对偶

### 7.1 有限测度空间上的包含关系

**定理**：若 μ(X) &lt; ∞，则对 1 ≤ p &lt; q ≤ ∞，有 L^q(X) ⊂ Lp(X)。

**证明**：设 f ∈ L^q。
- 若 q &lt; ∞：由 Hölder 不等式（指数 q/p 和 q/(q-p)），
  ∫|f|^p = ∫|f|^p · 1 ≤ (∫|f|^{p·q/p})^{p/q} · (∫1^{q/(q-p)})^{(q-p)/q} = ||f||_q^p · μ(X)^{(q-p)/q} &lt; ∞。
- 若 q = ∞：∫|f|^p ≤ ||f||∞^p · μ(X) &lt; ∞。

所以 f ∈ Lp。∎

**推论**：在有限测度空间上，p 越大，Lp 空间越小。L^∞ 是最小的（只有本性有界函数），L¹ 是最大的。

**反例（无限测度空间）**：在 (1,∞) 上，f(x)=1/x ∈ L² 但 f ∉ L¹。所以无限测度空间上 L^q ⊄ Lp。

**📐 几何图像**：有限测度空间上 Lp 包含关系的几何图像是"p 越大，对函数的'大值'越敏感"。L^∞ 范数只看函数的"最大高度"（本性上确界），任何超过某个高度的值都被"惩罚"；L¹ 范数看函数的"总面积"，偶尔的大值如果只在很小的区域出现，对总面积的贡献很小。所以 L^∞ 中的函数必须"处处不高"（本性有界），而 L¹ 中的函数可以"偶尔很高"（只要高值区域很小）。p 越大，范数越接近 L^∞，对大值越敏感，空间越小。

### 7.2 对偶空间

**定义（对偶空间）**：赋范线性空间 X 的对偶空间 X* 是 X 上所有有界线性泛函的集合，配范数 ||φ|| = sup_{||x||≤1} |φ(x)|。

**定理（Lp 空间的对偶）**：对 1 &lt; p &lt; ∞，(Lp)* ≅ L^q（等距同构），其中 q 是 p 的共轭指数。具体地，每个 g ∈ L^q 定义了 Lp 上的有界线性泛函 φ_g(f) = ∫fg，且 ||φ_g|| = ||g||_q。反过来，Lp 上的每个有界线性泛函都可以表示为这种形式。

对 p=1：(L¹)* ≅ L^∞（在 σ-有限测度空间上）。
对 p=∞：(L^∞)* 严格大于 L¹——存在 L^∞ 上的有界线性泛函不能表示为 L¹ 函数的积分。这些"额外"的泛函与测度的绝对连续性有关（需要用到有限可加测度）。

**证明思路（1 &lt; p &lt; ∞）**：
1. 由 Hölder 不等式，每个 g ∈ L^q 定义有界线性泛函 φ_g，且 ||φ_g|| ≤ ||g||_q
2. 证明 ||φ_g|| = ||g||_q（取 f = |g|^{q-1} sign(g) / ||g||_q^{q-1}，则 ||f||_p = 1 且 φ_g(f) = ||g||_q）
3. 证明每个有界线性泛函 φ 都可以表示为 φ = φ_g（需要 Radon-Nikodym 定理或更基础的构造）

**意义**：Lp 空间的对偶理论是泛函分析的核心结果之一。它说明：对于 1 &lt; p &lt; ∞，Lp 空间是"自反的"（(Lp)** ≅ Lp），这使得弱拓扑和弱收敛理论特别简洁。

### 7.3 自反性

**定义（自反空间）**：赋范线性空间 X 称为自反的，如果自然嵌入 J : X → X**（J(x)(φ) = φ(x)）是满射（等距同构）。

**定理**：对 1 &lt; p &lt; ∞，Lp 空间是自反的。

**证明**：(Lp)* ≅ L^q，(Lp)** ≅ (L^q)* ≅ Lp。自然嵌入在这个同构下是恒等映射。∎

**L¹ 和 L^∞ 不是自反的**：(L¹)* ≅ L^∞，但 (L^∞)* 严格大于 L¹，所以 (L¹)** ≅ (L^∞)* ⊋ L¹，自然嵌入不是满射。

**自反性的意义**：自反空间具有许多好的性质：
- 有界序列有弱收敛子列（Banach-Alaoglu 定理 + 自反性）
- 闭单位球在弱拓扑下紧
- 最佳逼近问题在闭凸子集上有解

这些性质使得 Lp（1&lt;p&lt;∞）成为 PDE 和变分法的自然框架。

## 第八章 Banach 空间入门

### 8.1 Banach 空间的定义

**定义**：完备的赋范线性空间称为 Banach 空间。

由 Riesz-Fischer 定理，Lp 空间（1 ≤ p ≤ ∞）是 Banach 空间。C[a,b]（sup 范数）也是 Banach 空间（D6-4）。

**经典 Banach 空间例子**：
- ℝⁿ（或 ℂⁿ）配任意范数——有限维 Banach 空间
- ℓ^p（1 ≤ p ≤ ∞）——序列空间，Lp 的离散版本
- C(K)（紧空间 K 上的连续函数，sup 范数）
- Lp(X, μ)（1 ≤ p ≤ ∞）
- 有界线性算子空间 B(X,Y)（算子范数）

### 8.2 Banach 空间的基本定理

**定理 1（Hahn-Banach 延拓定理）**：设 M 是赋范线性空间 X 的子空间，φ 是 M 上的有界线性泛函。则 φ 可以延拓为 X 上的有界线性泛函 Φ，且 ||Φ|| = ||φ||。

Hahn-Banach 定理是泛函分析中最基本的定理之一，它保证了对偶空间"足够大"——有足够多的有界线性泛函来区分空间中的点。

**推论**：对任意 x ∈ X, x ≠ 0，存在 φ ∈ X* 使得 ||φ||=1 且 φ(x)=||x||。

**定理 2（Banach-Steinhaus 定理/一致有界原理）**：设 {T_α} 是从 Banach 空间 X 到赋范空间 Y 的有界线性算子族。若对每个 x ∈ X，sup_α ||T_α x|| &lt; ∞，则 sup_α ||T_α|| &lt; ∞。

即逐点有界蕴含一致有界。

**定理 3（开映射定理）**：设 T 是从 Banach 空间 X 到 Banach 空间 Y 的有界线性满射。则 T 是开映射（开集的像为开集）。

**推论（逆算子定理/有界逆定理）**：设 T 是 Banach 空间之间的有界线性双射，则 T^{-1} 有界。

**定理 4（闭图像定理）**：设 T 是从 Banach 空间 X 到 Banach 空间 Y 的线性算子。若 T 的图像 {(x, Tx) : x ∈ X} 在 X×Y 中闭，则 T 有界。

这四大定理（Hahn-Banach、Banach-Steinhaus、开映射、闭图像）是 Banach 空间理论的基石。

### 8.3 弱拓扑与弱收敛

**定义（弱收敛）**：赋范空间 X 中的序列 {xₙ} 弱收敛到 x，如果对每个 φ ∈ X*，φ(xₙ) → φ(x)。记为 xₙ ⇀ x。

**强收敛**：||xₙ - x|| → 0。强收敛蕴含弱收敛，反之不成立。

**Lp 空间中的弱收敛（1 &lt; p &lt; ∞）**：fₙ ⇀ f 在 Lp 中 ⇔ 对每个 g ∈ L^q，∫fₙg → ∫fg。

**经典例子**：在 L²[0,2π] 中，fₙ(x) = sin(nx) 弱收敛到 0（因为对任何 g ∈ L²，∫g sin(nx) → 0，这是 Riemann-Lebesgue 引理），但 ||fₙ||₂ = √π ≠ 0，所以不强收敛。

**弱收敛的意义**：弱收敛是比强收敛更弱的收敛概念，在无限维空间中，有界序列不一定有强收敛子列，但在自反空间中（如 Lp, 1&lt;p&lt;∞），有界序列必有弱收敛子列。这是变分法和 PDE 中"直接方法"的基础。

**📐 几何图像**：弱收敛的几何图像是"在所有方向上的投影都收敛"。在有限维空间中，弱收敛等价于强收敛（因为所有方向上的投影收敛蕴含向量本身收敛）。但在无限维空间中，"所有方向上的投影收敛"不蕴含"距离收敛"——就像 sin(nx) 在每个 g 方向上的投影 ∫g sin(nx) 都趋于 0，但 sin(nx) 本身的"长度" √π 不变。弱收敛描述的是函数的"宏观形状"趋于稳定，而"微观振荡"可以持续存在——sin(nx) 的宏观形状是 0（平均值为 0），但微观上在 ±1 之间快速振荡。

## 第九章 反例库

### 反例 1：Lp 收敛不蕴含逐点收敛

构造：滑动区间特征函数列（D6-4 反例 7）。
fₙ → 0 在 Lp 中，但对每个 x，fₙ(x) 无限次取 1。
意义：Lp 收敛是"平均"收敛，不控制逐点行为。但存在子列 a.e. 收敛（Riesz 定理）。

### 反例 2：逐点收敛 + 一致有界不蕴含 Lp 收敛

构造：fₙ(x) = n χ_{(0,1/n)}(x) 在 [0,1] 上。
fₙ → 0 逐点，|fₙ| ≤ n（不一致有界）。修改：fₙ(x) = χ_{(0,1/n)}(x)，则 fₙ → 0 逐点且一致有界（≤1），且 ||fₙ||_p = (1/n)^{1/p} → 0，所以 Lp 收敛。
需要更微妙的反例：fₙ(x) = √n χ_{(0,1/n)}(x)，则 fₙ → 0 逐点，||fₙ||₂ = 1（不收敛到 0），但 ||fₙ||₁ = 1/√n → 0。
意义：逐点收敛不控制 Lp 范数，需要额外条件（如控制收敛定理中的控制函数）。

### 反例 3：Lp 收敛不蕴含 Lq 收敛（p≠q）

构造：在 [0,1] 上，fₙ(x) = n^{1/p} χ_{(0,1/n)}(x)。
||fₙ||_p = 1（不趋于 0），但 ||fₙ||_q = n^{1/p-1/q} → 0（q>p 时）。
意义：不同 Lp 范数下的收敛性不等价。

### 反例 4：L^∞ 不是自反的

(L^∞)* 严格大于 L¹。存在 L^∞ 上的有界线性泛函不能表示为 L¹ 函数的积分。
构造：利用 Hahn-Banach 定理，将"极限"泛函从收敛序列空间 c 延拓到 ℓ^∞，得到一个 Banach 极限（广义极限），它不能表示为 ℓ¹ 元素。
意义：L^∞ 的对偶空间比 L¹ 大，包含"有限可加测度"类型的泛函。

### 反例 5：弱收敛不蕴含强收敛

构造：fₙ(x) = sin(nx) 在 L²[0,2π] 中。
fₙ ⇀ 0（Riemann-Lebesgue 引理），但 ||fₙ||₂ = √π ≠ 0。
意义：无限维空间中弱收敛严格弱于强收敛。

### 反例 6：Lp 中 Cauchy 列的 a.e. 极限可以不在 Lp 中（如果不用 Lebesgue 积分）

这正是 C[a,b] 在 Lp 下不完备的原因（D6-4）。在 Lebesgue 框架下，a.e. 极限总是可测的，且由 Fatou 引理可证明在 Lp 中。
意义：Lebesgue 可测函数类对极限运算封闭，这是 Lp 完备的关键。

### 反例 7：Minkowski 不等式等号成立条件

等号成立当且仅当存在 α, β ≥ 0 不全为零，使得 αf = βg a.e.（f,g ≥ 0 时）。
反例：f(x)=1, g(x)=2 在 [0,1] 上。||f+g||₁ = 3 = ||f||₁+||g||₁ = 1+2，等号成立，因为 f 和 g 成比例。
f(x)=1, g(x)=x 在 [0,1] 上。||f+g||₁ = 3/2 &lt; ||f||₁+||g||₁ = 1+1/2 = 3/2？不对，等于。让我换 p=2：||f+g||₂² = ∫(1+x)² = 7/3，(||f||₂+||g||₂)² = (1+1/√3)² = 1+2/√3+1/3 = 4/3+2/√3 ≈ 2.488，而 7/3 ≈ 2.333，所以严格不等式成立。
意义：Minkowski 不等式一般是严格的，只有当函数成比例时等号成立。

### 反例 8：Hölder 不等式等号成立条件

等号成立当且仅当 |f|^p 和 |g|^q 成比例 a.e.。
构造：f(x)=1, g(x)=1 在 [0,1] 上，p=q=2。∫fg=1, ||f||₂||g||₂=1，等号成立。
f(x)=1, g(x)=x，∫fg=1/2, ||f||₂||g||₂=1/√3≈0.577，严格不等式。
意义：Hölder 不等式等号成立要求两个函数的"幂"成比例。

### 反例 9：Lp 空间中闭单位球不紧

构造：标准正交基 {eₙ}（如 eₙ(x)=sin(nx)/√π）。||eₙ||₂=1，但 ||eₘ-eₙ||₂=√2（m≠n），所以没有收敛子列。
意义：无限维 Banach 空间中闭单位球不紧（Riesz 引理：赋范空间有限维 ⟺ 闭单位球紧）。

### 反例 10：L¹ 不是自反的

(L¹)** = (L^∞)* ⊋ L¹。
意义：L¹ 缺乏自反性带来的好性质（有界序列不一定有弱收敛子列）。

## 第十章 历史演进

### 10.1 Lebesgue 积分的诞生（1902）

- **1902**：Henri Lebesgue 发表博士论文《积分、长度与面积》，建立了测度和积分的新理论。核心创新是"分割值域而非定义域"。
- **1904**：Lebesgue 出版《积分与原函数的研究》，系统发展了积分理论。

### 10.2 Riesz-Fischer 定理（1907）

- **1907**：Frigyes Riesz 和 Ernst Fischer 独立证明了 L²[0,1] 的完备性。这是 Hilbert 空间理论的起点。
- Riesz 的证明使用了"逐项积分"技术，Fischer 的证明使用了"平均收敛"概念。
- 这个定理解决了 Fourier 分析的基础问题：Fourier 级数在 L² 意义下总是收敛的。

### 10.3 Lp 空间理论的建立（1910-1930）

- **1910**：Riesz 发表《关于可积函数系的研究》，将 L² 理论推广到一般的 Lp 空间（1 &lt; p &lt; ∞），证明了 Hölder 不等式、Minkowski 不等式、Lp 完备性和对偶性。
- **1913**：Riesz 出版《线性方程组的无穷多个未知数系统》，系统发展了 Hilbert 空间上的算子理论。
- **1922**：Stefan Banach 在博士论文中建立了完备赋范线性空间的一般理论，后被称为 Banach 空间。
- **1927**：Hahn 和 Banach 独立证明了 Hahn-Banach 延拓定理。
- **1929**：Banach 引入了对偶空间和弱拓扑。
- **1932**：Banach 出版《线性算子理论》，标志着泛函分析成为独立学科。

### 10.4 现代发展（1930-至今）

- **1930s**：弱拓扑和弱收敛理论发展，Banach-Alaoglu 定理（1940）证明了对偶空间闭单位球在弱*拓扑下紧。
- **1940s**：Lp 空间在 PDE 中的应用开始发展（Sobolev 空间 W^{k,p} 是 Lp 的推广）。
- **1950s**：插值理论发展（Riesz-Thorin 插值定理、Marcinkiewicz 插值定理），调和分析与 Lp 空间深度结合。
- **1960s-至今**：Lp 空间理论在几何测度论、非交换几何、数学物理等领域持续发展。

### 11.1 四层 Lp 空间对照表

| 层级 | 空间 | 范数 | 完备性 | 内积 | 核心定理 |
|---|---|---|---|---|---|
| L1 数分 | C[a,b] sup | sup | 完备 | 无 | 一致收敛保持连续 |
| L1 数分 | C[a,b] Lp | Lp | 不完备 | 无 | 阶跃函数=针孔 |
| L2 复变 | H(Ω) 内闭一致 | 半范数族 | 完备 | 无 | Weierstrass 定理 |

| L3 实变 | L²[a,b] | L² | 完备（Hilbert） | 有 | Fourier 级数 L² 收敛 |

### 11.2 完备性的升维链

```
ℚ 不完备
  ↓ Dedekind/Cantor
ℝ 完备（一维，无内积结构）
  ↓ 乘积
ℂ 完备（二维）
  ↓ 函数作为点，sup 范数
C[a,b] 完备（Banach，无内积）
  ↓ 换 Lp 范数
C[a,b] Lp 不完备
  ↓ 完备化（Lebesgue 可积函数）
Lp[a,b] 完备（Banach）
  ↓ p=2，加内积
L²[a,b] 完备（Hilbert）
  ↓ 三角函数系完备
Fourier 分析严格化
```

### 11.3 关键蜕变问题

**问题 1：为什么 Lp 空间完备而 C[a,b] 在 Lp 下不完备？**

回答：C[a,b] 要求函数连续，而 Lp-Cauchy 列的极限可以不连续（阶跃函数）。Lp 空间只要求函数可测且 p-次可积，不要求连续。可测函数类对极限运算封闭（可测函数列的极限可测），所以 Lp-Cauchy 列的极限总是可测函数。再由 Fatou 引理，极限函数在 Lp 中。连续性不是极限运算保持的性质（连续函数列的极限可以不连续），但可测性是极限运算保持的性质——这就是 Lp 完备而 C[a,b] Lp 不完备的根本原因。

**问题 2：为什么 L² 是 Hilbert 空间而其他 Lp 不是？**

回答：只有 p=2 时，Lp 范数满足平行四边形等式 ||f+g||²+||f-g||²=2(||f||²+||g||²)，这是内积空间的特征（Jordan-von Neumann 定理：范数由内积诱导当且仅当平行四边形等式成立）。p=2 时，范数 ||f||₂=√(∫f²) 自然对应内积 ⟨f,g⟩=∫fg。p≠2 时，范数不满足平行四边形等式，不能由内积诱导。L² 的内积结构使得它具有其他 Lp 空间没有的几何性质（正交、投影、勾股定理、最佳逼近唯一等）。

**问题 3：为什么 Fourier 级数在 L² 中总是收敛，而逐点收敛是百年难题？**

回答：L² 收敛是"平均"收敛，只要求 ∫|f-Sₙ|²→0，不要求在每个点上收敛。L² 收敛的证明只需要 Riesz-Fischer 定理（L² 完备）和三角函数系的完备性（稠密性），这是相对简单的。逐点收敛要求对每个 x，Sₙ(x)→f(x)，这需要控制 Fourier 级数的逐点行为，涉及函数的光滑性、局部性质等微妙因素。Lusin 猜想（1913 年提出，1966 年由 Carleson 证明）说 L² 函数的 Fourier 级数几乎处处收敛——这个结果的证明极其困难，需要深刻的调和分析技术。L² 收敛是"宏观"收敛（平均意义），逐点收敛是"微观"收敛（每个点），微观比宏观困难得多。

**问题 4：为什么 Lp（1&lt;p&lt;∞）是自反的，而 L¹ 和 L^∞ 不是？**

回答：自反性要求 (Lp)** ≅ Lp。对 1&lt;p&lt;∞，(Lp)* ≅ L^q 且 (L^q)* ≅ Lp，所以自反。对 p=1，(L¹)* ≅ L^∞，但 (L^∞)* 严格大于 L¹（存在不能表示为 L¹ 函数的泛函），所以 (L¹)** = (L^∞)* ⊋ L¹，不自反。p=∞ 时，(L^∞)* ⊋ L¹，所以 (L^∞)** = (L¹)* = L^∞？不对，(L^∞)** = ((L^∞)*)*，而 (L^∞)* ⊋ L¹，所以 (L^∞)** = ((L^∞)*)* ⊋ (L¹)* = L^∞，也不自反。几何上，L¹ 和 L^∞ 的单位球"形状不规则"（不是严格凸的），缺乏自反空间的"圆润"几何。

## 第十二章 收敛沉淀

### 12.1 核心定理清单

1. **Hölder 不等式**：||fg||₁ ≤ ||f||_p ||g||_q（1/p+1/q=1）
2. **Minkowski 不等式**：||f+g||_p ≤ ||f||_p + ||g||_p
3. **Riesz-Fischer 定理**：Lp 空间完备（1 ≤ p ≤ ∞）
4. **L² 是 Hilbert 空间**：内积 ⟨f,g⟩=∫fg
5. **三角函数系完备**：L²[0,2π] 中 Fourier 级数 L² 收敛
6. **Bessel 不等式 / Parseval 等式**
7. **Lp 包含关系**：有限测度时 p&lt;q ⟹ L^q ⊂ Lp
8. **Lp 对偶**：(Lp)* ≅ L^q（1&lt;p&lt;∞）
9. **Lp 自反**：1&lt;p&lt;∞ 时 Lp 自反
10. **最佳逼近定理**：Hilbert 空间闭子空间中的最佳逼近唯一且为正交投影
11. **Hahn-Banach 定理**：有界线性泛函可保范延拓
12. **Banach-Steinhaus 定理**：逐点有界蕴含一致有界

### 12.2 方法论沉淀

**Lp 完备性证明的标准方法**：
1. 取 Cauchy 列
2. 取快速收敛子列（相邻距离 &lt; 2^{-k}）
3. 构造控制级数，证明子列 a.e. 收敛
4. 用 Fatou 引理证明极限在 Lp 中
5. 用 Fatou 引理证明子列 Lp 收敛到极限
6. 由 Cauchy 列性质推出原序列收敛

**Hölder 不等式的应用场景**：
- 证明 Minkowski 不等式
- 证明 Lp 对偶性
- 证明乘积可积性
- 插值不等式

**Lp 空间中的收敛类型**：
- 强收敛（Lp 收敛）：||fₙ-f||_p → 0
- 弱收敛：∫fₙg → ∫fg 对所有 g ∈ L^q
- 几乎处处收敛：fₙ(x) → f(x) a.e.
- 依测度收敛：μ({|fₙ-f|>ε}) → 0
关系：强收敛 ⇒ 弱收敛和依测度收敛；强收敛存在子列 a.e. 收敛；a.e. 收敛 + 控制函数 ⇒ 强收敛（控制收敛定理）。

### 12.3 常见误区

**误区一：Lp 收敛蕴含逐点收敛**
澄清：不蕴含。滑动区间反例。但存在子列 a.e. 收敛。

**误区二：逐点收敛 + Lp 有界蕴含 Lp 收敛**
澄清：不蕴含。需要控制函数（控制收敛定理）或一致可积条件。

**误区三：所有 Lp 空间都是 Hilbert 空间**
澄清：只有 L² 是 Hilbert 空间（有内积）。其他 Lp 是 Banach 空间但不是 Hilbert 空间。

**误区四：L^∞ 的对偶是 L¹**
澄清：(L^∞)* 严格大于 L¹。只有 (L¹)* ≅ L^∞（σ-有限测度）。

**误区五：Lp 空间中闭单位球紧**
澄清：无限维空间中闭单位球不紧（Riesz 引理）。标准正交基没有收敛子列。

**误区六：弱收敛蕴含强收敛**
澄清：无限维空间中不蕴含。sin(nx) 弱收敛到 0 但不强收敛。有限维空间中等价。

## 第十四章 五类边

### 14.1 前驱→后继

- D6-1 实数完备性 → 本模块（实数完备性是 Lp 完备性证明的基础，特别是 Cauchy 列收敛到实数）
- D6-4 函数空间完备性 → 本模块（D6-4 证明 C[a,b] Lp 不完备，本模块证明完备化 Lp 完备）
- D5-6 Fourier 级数 → 本模块（L² 中 Fourier 级数的收敛性是 Riesz-Fischer 定理的应用）
- 本模块 → D6-6 完备化理论（本模块给出了 Lp 完备化的具体实现，D6-6 讨论一般完备化与不可测集）
- 本模块 → D3-6 弱导数与 Sobolev 空间（Sobolev 空间 W^{k,p} 是 Lp 的推广，其完备性依赖于 Lp 完备性）

### 14.2 类比

- 实数完备性（D6-1）与 Lp 完备性（本模块）：都是"Cauchy 列收敛"，但空间从一维升到无限维
- C[a,b] sup 完备（D6-4）与 Lp 完备（本模块）：都是函数空间的完备性，但拓扑不同（sup vs Lp）
- ℚ 不完备与 C[a,b] Lp 不完备（D6-4）：都是"空间有针孔"，前者针孔=无理数，后者针孔=不连续函数
- Dedekind 分割构造 ℝ 与 Lebesgue 可积函数构造 Lp：都是完备化，但前者用分割，后者用可测函数类
- ℓ^p（序列空间）与 Lp（函数空间）：ℓ^p 是 Lp 的离散版本（计数测度），理论完全平行

### 14.3 推广

- 从 Lp[a,b] 到 Lp(X, μ)（任意测度空间）：Riesz-Fischer 定理对任意测度空间成立
- 从 Lp 到 Sobolev 空间 W^{k,p}：弱导数版本的 Lp 空间，PDE 的自然框架
- 从标量值 Lp 到向量值 Lp（Bochner 空间）：函数取值在 Banach 空间中
- 从 Banach 空间到 Fréchet 空间（局部凸完备空间）：H(Ω) 是 Fréchet 空间
- 从 Lp 到 Orlicz 空间（更一般的凸函数积分）：Lp 是 Orlicz 空间的特例

### 14.4 特例

- L² 是 Lp 的特例（p=2），但具有内积结构，是 Hilbert 空间
- ℓ^p 是 Lp 的特例（计数测度）
- 有限维 ℝⁿ 配 ℓ^p 范数是 Lp 的特例（有限集计数测度）
- C[a,b] sup 完备是 L^∞ 的子空间（连续函数在本性有界函数中）
- Riemann 可积函数空间是 Lp 的子空间（但不完备）

### 14.5 反例簇

- 收敛不蕴含簇：Lp 收敛不蕴含逐点收敛、弱收敛不蕴含强收敛、逐点收敛不蕴含 Lp 收敛
- 不完备空间簇：C[a,b] Lp、R[a,b] L¹、P[a,b] sup
- 无限维病态簇：闭单位球不紧、有界序列无强收敛子列、最佳逼近可能不唯一（非 Hilbert 空间）
- 对偶病态簇：(L^∞)* ⊋ L¹、L¹ 和 L^∞ 不自反

> **模块结语**：本模块完成了完备性从实数到函数空间的最终升维——Riesz-Fischer 定理证明了 Lp 空间是完备的 Banach 空间，L² 空间因其内积结构成为 Hilbert 空间。核心洞察是：Lebesgue 可测函数类对极限运算封闭，这是 Lp 完备而连续函数空间在 Lp 下不完备的根本原因。Hölder 不等式和 Minkowski 不等式是 Lp 空间理论的两大基石，前者建立了 Lp 和 L^q 的对偶配对，后者验证了 Lp 范数的三角不等式。L² 空间的 Hilbert 结构使得 Fourier 分析严格化——三角函数系在 L² 中完备，Fourier 级数在 L² 意义下总是收敛。Banach 空间的四大定理（Hahn-Banach、Banach-Steinhaus、开映射、闭图像）和弱拓扑理论为 Lp 空间提供了丰富的分析工具。下一模块 D6-6 将讨论完备化理论的一般构造与不可测集的存在性，完成完备性领域的理论闭环。
