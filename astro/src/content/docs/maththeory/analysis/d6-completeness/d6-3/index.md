## 第一章 引言：连通性为什么是分析的"第三根支柱"

### 1.1 从介值定理说起

考虑以下经典定理：若 f : [a,b] → ℝ 连续，且 f(a) &lt; 0 &lt; f(b)，则存在 c ∈ (a,b) 使得 f(c) = 0。

这个定理的证明依赖于什么？直觉上，"连续函数的图像不能跳过 x 轴"。但这个直觉的严格基础是 **[a,b] 是连通集**，而连续映射保持连通性。

如果把 [a,b] 换成不连通的集合，比如 [0,1] ∪ [2,3]，介值定理立即失效：定义 f(x) = -1 (x ∈ [0,1])，f(x) = 1 (x ∈ [2,3])，这是连续函数（在子空间拓扑下），f(0) = -1 &lt; 0 &lt; 1 = f(3)，但 f 永远不为 0。

**连通性的本质**：它保证了空间"没有缝隙"，从而使连续变化的量不能从一个值跳到另一个值而不经过中间值。

**📐 几何锚定**：把连通集想象成一块"不能用剪刀剪成两块"的实体——无论你怎么下剪刀，都无法把它干净利落地分成两个不相交的非空部分。道路连通性则更进一步——不仅"连在一起"，而且任意两点之间可以"走过去"，存在一条连续的路径。连通性只关心"能不能分成两块"（拓扑性质），道路连通性关心"能不能走过去"（构造性质）。两者之间的鸿沟——连通但不道路连通——最经典的化身就是拓扑正弦曲线：几何上"粘在一起"，但"无法穿越"。

### 1.2 完备性、紧性、连通性的三足鼎立

分析学的三大拓扑支柱各有分工：

| 支柱 | 核心问题 | 典型定理 | 本质 |
|---|---|---|---|
| 完备性 | Cauchy 列的极限是否在空间内？ | Cauchy 收敛准则 | 没有"洞" |
| 紧性 | 任意序列是否有收敛子列？ | Bolzano-Weierstrass | 没有"逃逸到无穷" |
| 连通性 | 空间能否被分成两块？ | 介值定理 | 没有"缝隙" |

三者的关系：
- 完备性和紧性关注"极限行为"，连通性关注"整体结构"
- 紧 ⇒ 完备（度量空间中），但紧和连通之间没有蕴含关系
- ℝ 完备但不紧、连通；[0,1] 完备、紧、连通；[0,1] ∪ [2,3] 完备、紧但不连通；ℚ 不完备、不紧、不连通（完全不连通）

### 1.3 连通性的四层蜕变预览

| 层级 | 连通性的表现形式 | 核心定理 |
|---|---|---|
| L0 初等直觉 | "区间是连在一起的" | 介值定理 |
| L1 数学分析 | 实数轴上的连通集 = 区间 | 区间定理、介值定理 |
| L2 复变函数 | 区域（连通开集）、解析延拓 | 区域不变性、Riemann 面连通性 |
| L3 实变函数 | 可测集的连通性、Borel 集结构、Cantor 集 | 完全不连通集、不可测集的连通性 |

## 第二章 连通性的定义与等价刻画

### 2.1 定义一：分离定义

**定义**：拓扑空间 X 称为连通的（connected），如果 X 不能表示为两个非空不相交开集的并。

即：不存在非空开集 U, V ⊂ X 使得 U ∪ V = X 且 U ∩ V = ∅。

这样的 U, V 称为 X 的一个分离（separation）。连通空间就是没有分离的空间。

**等价表述**：
- X 不能表示为两个非空不相交闭集的并
- X 中既开又闭的子集（clopen set）只有 ∅ 和 X
- 不存在连续满射 f : X → {0,1}（离散拓扑）

**为什么这是最根本的定义**：分离定义是纯拓扑定义，不依赖度量、路径或任何额外结构。它直接表达了"空间不能被分成两块"的核心思想。

**直观理解**：想象一块土地。如果能挖一条"壕沟"（开集的边界）把它完全分成两块，那它就不连通。如果无论怎么挖都不能彻底分开，那它就是连通的。

**📐 几何深化**：分离定义的几何图像是"无法插入一把完整的剪刀"。如果空间不连通，你可以找到两个不相交的开集 U 和 V，它们的并是整个空间——这就像在空间中找到了一条"完整的裂缝"，沿着这条裂缝可以把空间掰成两块。连通空间则不存在这样的裂缝——任何试图把空间分成两块的尝试，都会在两块之间留下"粘连"的部分。等价地，连通空间中既开又闭的子集只有空集和全集——这意味着空间中没有"边界干净利落"的非平凡子集，任何子集的边界都是"模糊"的（非空），无法干净地分开。

### 2.2 定义二：连续映射保持

**定理**：连通性在连续映射下保持。即若 f : X → Y 连续，X 连通，则 f(X) 连通。

**证明**：反证。若 f(X) 不连通，则存在非空不相交开集 U, V ⊂ f(X) 使得 U ∪ V = f(X)。则 f^{-1}(U), f^{-1}(V) 是 X 中的非空不相交开集，且 f^{-1}(U) ∪ f^{-1}(V) = X，与 X 连通矛盾。

**推论（介值定理的一般形式）**：若 X 连通，f : X → ℝ 连续，则 f(X) 是 ℝ 中的区间。

这是介值定理的最一般形式：连通空间上的连续实值函数的值域是区间，因此不能"跳过"任何中间值。

### 2.3 定义三：闭包刻画

**定理**：拓扑空间 X 连通，当且仅当对任意非空真子集 A ⊂ X，有 ∂A ≠ ∅（A 的边界非空）。

等价地：X 连通，当且仅当 X 中不存在非空真子集 A 使得 A 既开又闭。

**证明思路**：
- 若 A 是 clopen 且非空真子集，则 A 和 A^c 是 X 的一个分离。
- 反之，若 U, V 是分离，则 U（和 V）是 clopen。

**边界的直观意义**：一个集合的边界是"从集合内到集合外的过渡带"。如果一个非空真子集没有边界，意味着可以"干净利落地"把空间分成集合内和集合外，没有任何过渡——这正是不连通的特征。

### 2.4 连通集的基本性质

**性质 1**：连通集的闭包是连通的。

即：若 A ⊂ X 连通，则 \overline{A} 连通。

**证明**：反证。若 \overline{A} 不连通，设 U, V 是分离。则 A = (A ∩ U) ∪ (A ∩ V)。因 A 连通，必有 A ∩ U = ∅ 或 A ∩ V = ∅。若 A ∩ U = ∅，则 A ⊂ V，故 \overline{A} ⊂ \overline{V}。但 V 在 \overline{A} 中是闭集（因为 U 开，V = \overline{A} \ U 闭），故 \overline{V} = V，从而 \overline{A} ⊂ V，U = ∅，矛盾。

**性质 2**：若 {A_α} 是一族连通集，且 ⋂ A_α ≠ ∅，则 ⋃ A_α 连通。

**证明**：设 p ∈ ⋂ A_α。若 ⋃ A_α 不连通，设 U, V 是分离。不妨设 p ∈ U。对每个 α，A_α 连通且 p ∈ A_α ∩ U，故 A_α ⊂ U（否则 A_α ∩ V 非空，A_α 被 U, V 分离）。因此 ⋃ A_α ⊂ U，V = ∅，矛盾。

**性质 3**：若 A 连通，A ⊂ B ⊂ \overline{A}，则 B 连通。

这是性质 1 的推广：介于连通集和其闭包之间的任何集合都是连通的。

**性质 4**：连通性是拓扑性质（同胚不变量）。

这是"连续映射保持连通性"的直接推论：同胚是连续双射且逆连续，因此连通性在同胚下保持。

### 2.5 实数轴上的连通集：区间定理

**定理（区间定理）**：ℝ 中的子集是连通的，当且仅当它是区间（包括开区间、闭区间、半开半闭区间、无限区间、单点集、空集）。

**证明**：

**(⇒) 连通 ⇒ 区间**：
设 A ⊂ ℝ 连通。若 A 不是区间，则存在 a, b ∈ A 和 c ∉ A 使得 a &lt; c &lt; b。则 A = (A ∩ (-∞, c)) ∪ (A ∩ (c, ∞))，这是 A 的一个分离（两个都是 A 中的非空开集），矛盾。

**(⇐) 区间 ⇒ 连通**：
设 I 是区间。反证，若 I 不连通，设 U, V 是分离。取 a ∈ U, b ∈ V，不妨设 a &lt; b。令 S = {x ∈ [a,b] : [a,x] ⊂ U}，c = sup S。
- 若 c ∈ U，则因 U 开，存在 ε > 0 使 (c-ε, c+ε) ⊂ U，故 c+ε/2 ∈ S，与 c = sup S 矛盾。
- 若 c ∈ V，则因 V 开，存在 ε > 0 使 (c-ε, c+ε) ⊂ V，但 c-ε/2 ∈ S（由上确界定义），故 [a, c-ε/2] ⊂ U，而 c-ε/2 ∈ V ∩ U，矛盾。
- c 不能在 U 也不能在 V，但 U ∪ V = I 且 c ∈ [a,b] ⊂ I，矛盾。

**区间定理的重要性**：这是连通性在实数轴上的完整分类，也是介值定理的严格基础。它告诉我们，ℝ 中的连通集只有区间，没有其他可能。

**📐 几何深化**：区间定理的几何本质是"一维直线上的连通集只能是线段"。在一维空间中，点只能左右排列，所以"连在一起"的点集必然是一段连续的线段——可以是开的、闭的、半开半闭的、有限的、无限的、单点的。如果一个集合不是区间，那么存在 a,b 在集合内，c 在 a,b 之间但不在集合内——c 就像一个"楔子"，把集合分成左右两块，集合不连通。在高维空间中，这个分类不再成立——连通集可以是圆盘、圆环、曲线、分形等无限多种形态。高维空间的"自由度"使得连通集的几何形态极其丰富。

## 第三章 道路连通性

### 3.1 道路的定义

**定义**：拓扑空间 X 中从点 x 到点 y 的一条道路（path）是一个连续映射 γ : [0,1] → X，使得 γ(0) = x, γ(1) = y。

x 称为道路的起点，y 称为终点。

**道路的直观意义**：道路是"从 x 走到 y 的一条连续轨迹"。参数 t ∈ [0,1] 可以理解为时间，γ(t) 是时刻 t 所在的位置。

**道路 vs 曲线**：
- 道路是映射 γ : [0,1] → X
- 曲线通常指道路的像 γ([0,1])
- 不同的道路可以有相同的像（比如沿同一条曲线走不同的速度）
- 在拓扑学中，道路是映射，不是像集

### 3.2 道路连通的定义

**定义**：拓扑空间 X 称为道路连通的（path connected），如果对任意 x, y ∈ X，存在 X 中从 x 到 y 的道路。

**直观理解**：道路连通意味着空间中任意两点之间都可以"走过去"，不需要跳跃或传送。

**📐 几何深化**：道路连通的几何图像是"任意两点之间可以画一条连续的线"。你从任何一点出发，都可以沿着一条连续的路线走到任何其他点，不需要跳跃、传送或飞越空隙。道路连通 ⇒ 连通在几何上很直观：如果一个集合可以被分成两块（不连通），那么从一块的点走到另一块的点必须"跨越"两块之间的空隙——但空隙不在集合内，所以道路不存在。

**道路连通 ⇒ 连通**：

**定理**：道路连通空间一定是连通的。

**证明**：设 X 道路连通。反证，若 X 不连通，设 U, V 是分离。取 x ∈ U, y ∈ V。因 X 道路连通，存在道路 γ : [0,1] → X 从 x 到 y。则 γ([0,1]) 是 [0,1] 的连续像，故连通（[0,1] 连通，连续映射保持连通性）。但 γ([0,1]) = (γ([0,1]) ∩ U) ∪ (γ([0,1]) ∩ V)，这是一个分离（因为 γ(0) ∈ U, γ(1) ∈ V，两者非空），矛盾。

**关键洞察**：道路连通是比连通更强的条件。道路连通 ⇒ 连通，但连通 ⇏ 道路连通。这个反向不成立是整个连通性理论中最精妙的部分，将在第四章和反例库中详细讨论。

### 3.3 道路连通的基本性质

**性质 1**：道路连通性在连续映射下保持。

即若 f : X → Y 连续，X 道路连通，则 f(X) 道路连通。

**证明**：对任意 f(x), f(y) ∈ f(X)，取 X 中从 x 到 y 的道路 γ，则 f ∘ γ 是 f(X) 中从 f(x) 到 f(y) 的道路。

**性质 2**：若 {A_α} 是一族道路连通集，且 ⋂ A_α ≠ ∅，则 ⋃ A_α 道路连通。

**证明**：设 p ∈ ⋂ A_α。对任意 x ∈ A_α, y ∈ A_β，存在从 x 到 p 的道路（在 A_α 中）和从 p 到 y 的道路（在 A_β 中）。两条道路拼接（concatenation）得到从 x 到 y 的道路。

**道路拼接**：若 γ₁ 从 x 到 y，γ₂ 从 y 到 z，则拼接道路 γ₁ * γ₂ 定义为：
(γ₁ * γ₂)(t) = γ₁(2t), 0 ≤ t ≤ 1/2
(γ₁ * γ₂)(t) = γ₂(2t-1), 1/2 ≤ t ≤ 1

拼接在 t = 1/2 处连续，因为 γ₁(1) = y = γ₂(0)。

**性质 3**：道路连通空间的商空间是道路连通的。

商映射是连续满射，由性质 1 即得。

### 3.4 凸集与星形域

**凸集（convex set）**：ℝⁿ 中的子集 C 称为凸的，如果对任意 x, y ∈ C 和 t ∈ [0,1]，有 (1-t)x + ty ∈ C。

**凸集 ⇒ 道路连通**：对任意 x, y ∈ C，直线段 γ(t) = (1-t)x + ty 是 C 中从 x 到 y 的道路。

**凸集的例子**：
- ℝⁿ 本身是凸的
- 开球和闭球是凸的
- 线性子空间是凸的
- 半空间是凸的

**星形域（star-shaped / star-convex）**：ℝⁿ 中的子集 S 称为关于点 p ∈ S 星形的，如果对任意 x ∈ S，线段 [p,x] ⊂ S。

**星形域 ⇒ 道路连通**：任意两点 x, y 可以通过 x → p → y 的折线路径连接。

**凸 vs 星形**：
- 凸 ⇒ 关于任何点星形
- 星形 ⇏ 凸（比如十字形、五角星）
- 星形 ⇒ 道路连通
- 道路连通 ⇏ 星形（比如圆环、圆周）

**在复分析中**：区域（连通开集）不一定是凸的，也不一定是星形的。但单连通区域在某种意义上"没有洞"，可以通过共形映射变为圆盘（Riemann 映射定理），从而"变成"凸的。

## 第四章 连通但不道路连通：拓扑正弦曲线

### 4.1 拓扑正弦曲线的构造

连通和道路连通之间的鸿沟，最经典的例子是**拓扑正弦曲线**（topologist's sine curve），也称为 Warsaw circle 的一部分。

**定义**：设
S = {(x, sin(1/x)) : 0 &lt; x ≤ 1} ⊂ ℝ²
T = {(0, y) : -1 ≤ y ≤ 1} ⊂ ℝ²
X = S ∪ T

X 就是拓扑正弦曲线。

**📐 几何图像**：拓扑正弦曲线的几何图像既美丽又令人震惊。想象一条曲线 y = sin(1/x)，当 x 从 1 向 0 靠近时，曲线在 y = -1 和 y = 1 之间无限振荡，振荡频率越来越高，振幅保持不变。当 x → 0⁺ 时，曲线"无限密集地"填满了 y 轴上的线段 [-1,1]。然后把 y 轴上的这条线段也加进来，就得到了拓扑正弦曲线。几何上，这条曲线"粘"在 y 轴上——y 轴上的每个点都是振荡曲线的极限点，两者之间没有"空隙"可以让剪刀插入。但你无法从振荡曲线"走"到 y 轴——因为越靠近 y 轴，振荡越剧烈，任何连续道路都会被振荡"卡住"，无法确定终点的 y 坐标。

**几何描述**：
- S 是函数 y = sin(1/x) 在 (0,1] 上的图像，当 x → 0⁺ 时，sin(1/x) 在 [-1,1] 之间无限振荡
- T 是 y 轴上的线段 [-1,1]
- X = S ∪ T 把振荡的曲线和 y 轴上的线段粘在一起

### 4.2 X 是连通的

**证明**：S 是 (0,1] 在连续映射 x ↦ (x, sin(1/x)) 下的像，(0,1] 连通，故 S 连通。

X = S ∪ T，且 T ⊂ \overline{S}（因为对任意 y₀ ∈ [-1,1]，存在序列 x_n → 0⁺ 使得 sin(1/x_n) → y₀，故 (0,y₀) 是 S 的极限点）。

因此 S ⊂ X ⊂ \overline{S}，由连通集的性质 3（介于连通集和其闭包之间的集合连通），X 连通。

### 4.3 X 不是道路连通的

**证明**：我们证明不存在 X 中从点 (1, sin 1) ∈ S 到点 (0, 0) ∈ T 的道路。

反证，假设存在连续映射 γ : [0,1] → X，γ(0) = (1, sin 1), γ(1) = (0, 0)。

设 γ(t) = (x(t), y(t))。则 x(0) = 1, x(1) = 0，且 x(t) ≥ 0 对所有 t。

令 t₀ = sup{t ∈ [0,1] : x(t) > 0}。由连续性，x(t₀) = 0（因为 t > t₀ 时 x(t) = 0，取极限得 x(t₀) = 0）。

考虑 γ 在 [0, t₀) 上的限制。对 t &lt; t₀，x(t) > 0，故 γ(t) ∈ S，即 y(t) = sin(1/x(t))。

当 t → t₀⁻ 时，x(t) → 0⁺。但 y(t) = sin(1/x(t)) 的极限不存在——因为 x(t) 可以以不同方式趋于 0，使得 sin(1/x(t)) 振荡。

更严格地：因为 x(t) 在 [0, t₀) 上连续且 x(0) = 1, x(t₀) = 0，由介值定理，对任意小的 ε > 0，存在 t 使得 x(t) = ε。具体地，存在序列 t_n → t₀⁻ 使得 x(t_n) = 1/(2nπ)（此时 y = 0），也存在序列 s_n → t₀⁻ 使得 x(s_n) = 1/(2nπ + π/2)（此时 y = 1）。

因此 y(t) 在 t → t₀⁻ 时不收敛（有子列趋于 0，有子列趋于 1），与 γ 的连续性矛盾。

**直观解释**：要从 S 走到 T，必须经过 x → 0 的区域。但在这个区域中，sin(1/x) 无限振荡，任何连续路径都无法"穿越"这个振荡区域到达 y 轴。路径在接近 y 轴时会被振荡"卡住"，无法确定终点的 y 坐标。

### 4.4 拓扑正弦曲线的变体

**变体一：闭拓扑正弦曲线**
\overline{X} = X（X 已经是闭的，因为 T 包含了所有极限点）。

**变体二：Warsaw circle**
在拓扑正弦曲线的基础上，用一段弧连接 (1, sin 1) 和 (0, -1)（或 (0,1)），得到一个闭曲线。Warsaw circle 是连通的、紧的，但不是道路连通的，也不是局部连通的。它是"看起来像圆但不是圆"的经典例子。

**变体三：删除一个点的拓扑正弦曲线**
X \ {(0,0)} 仍然连通（因为 S 连通且在 X \ {(0,0)} 中稠密），但更不道路连通。

**变体四：高维推广**
在 ℝⁿ 中可以构造类似的"拓扑正弦超曲面"，连通但不道路连通。

### 4.5 连通 ⇒ 道路连通的充分条件

虽然连通一般不蕴含道路连通，但在附加条件下可以：

**定理 1**：连通且局部道路连通的空间是道路连通的。

**证明**：设 X 连通且局部道路连通。固定 x₀ ∈ X，令 U = {x ∈ X : 存在从 x₀ 到 x 的道路}。
- U 非空（x₀ ∈ U）
- U 是开集：对任意 x ∈ U，取 x 的道路连通邻域 V（局部道路连通），则 V 中任意点可通过 x 连接到 x₀，故 V ⊂ U
- U 是闭集：U^c 也是开集（同理，对 x ∉ U，取道路连通邻域 V，若 V ∩ U ≠ ∅，则 x 可通过 V 中的点连接到 x₀，矛盾，故 V ⊂ U^c）
- 因 X 连通，U = X

**定理 2**：ℝⁿ 中的连通开集（区域）是道路连通的。

**证明**：ℝⁿ 中的开集是局部道路连通的（每个点有凸的球邻域），由定理 1 即得。

这是复分析中"区域"概念的基础：复平面上的连通开集自动是道路连通的，因此可以用道路来定义积分、解析延拓等概念。

**定理 3**：连通的拓扑流形是道路连通的。

拓扑流形是局部同胚于 ℝⁿ 的 Hausdorff 空间，因此是局部道路连通的，由定理 1 即得。

## 第五章 连通分支与局部连通性

### 5.1 连通分支

**定义**：拓扑空间 X 中，点 x 的连通分支（connected component）是包含 x 的最大连通子集。

等价地，x 的连通分支是所有包含 x 的连通子集的并。

**📐 几何图像**：连通分支的几何图像是"沿着所有缝隙拆开的碎片"。你把一个集合"沿着所有的缝隙"拆开，得到的每一块就是一个连通分支。[0,1] ∪ [2,3] 有两个连通分支——中间的空隙 (1,2) 就是"缝隙"，沿着它拆开得到两块。ℚ 的连通分支都是单点集——ℚ 被无理数"切割"成了无限多个单点，每个有理数都是一块碎片。Cantor 集的连通分支也都是单点集——被去掉的开区间就是"缝隙"，沿着所有缝隙拆开，每粒粉尘都是一块。拓扑正弦曲线只有一个连通分支（整个 X）——虽然有两个道路分支（S 和 T），但它们之间没有"缝隙"，T 上的点都是 S 的极限点，无法沿着缝隙拆开。

**性质**：
- 连通分支是连通的（一族有公共点的连通集的并连通）
- 连通分支是闭集（连通集的闭包连通，故最大连通集必为闭集）
- 不同的连通分支不相交
- 所有连通分支构成 X 的一个划分
- 连通分支不一定是开集！（这是一个重要的反例点）

**例子**：
- ℚ 的连通分支都是单点集（ℚ 完全不连通），每个单点集是闭集但不是开集
- ℝ \ {0} 的连通分支是 (-∞,0) 和 (0,∞)，都是既开又闭的
- 拓扑正弦曲线 X 是连通的，只有一个连通分支（X 本身）

### 5.2 道路分支

**定义**：拓扑空间 X 中，点 x 的道路分支（path component）是所有可以通过道路与 x 连接的点的集合。

**性质**：
- 道路分支是道路连通的
- 道路分支不一定是闭集，也不一定是开集
- 每个道路分支包含在一个连通分支中
- 连通分支可以包含多个道路分支

**拓扑正弦曲线的道路分支**：
X = S ∪ T 有两个道路分支：
- S（S 本身是道路连通的，因为 S 是 (0,1] 的连续像，(0,1] 道路连通）
- T（T 是线段，道路连通）

S 和 T 之间没有道路连接，因此是不同的道路分支。但它们在同一个连通分支中（X 连通）。

**这正是连通和道路连通的本质区别**：连通分支看的是"能不能用开集分开"，道路分支看的是"能不能走过去"。拓扑正弦曲线中，S 和 T 不能用开集分开（因为 T 中的点都是 S 的极限点），但也走不过去（因为振荡区域无法穿越）。

### 5.3 局部连通性

**定义**：拓扑空间 X 称为局部连通的（locally connected），如果每个点都有由连通开集组成的邻域基。

即：对任意 x ∈ X 和任意邻域 U ∋ x，存在连通开集 V 使得 x ∈ V ⊂ U。

**局部连通 ⇏ 连通**：离散空间是局部连通的（每个单点集是连通开邻域），但多于一个点的离散空间不连通。

**连通 ⇏ 局部连通**：拓扑正弦曲线是连通的，但不是局部连通的。在 T 上的点附近，任何小邻域都包含 S 的无限多个振荡"分支"，无法包含在一个连通开集中。

**📐 几何深化**：局部连通的几何图像是"每一点附近都有连通的小块"。在局部连通空间中，你把放大镜放在任何一点上，看到的邻域都是"连在一起"的——没有被分割成碎片。拓扑正弦曲线不是局部连通的——在 y 轴上的点附近，任何小邻域都包含振荡曲线的无限多个"段"，这些段之间被空隙隔开，无法找到一个连通的小邻域。ℚ 也不是局部连通的——每个有理数附近都有无理数"穿插"，邻域被分割成不连通的碎片。局部连通性保证了连通分支是开集（clopen）——每块碎片都有"干净的边界"，可以用开集分开。

**局部连通空间的性质**：
- 连通分支是开集（因此是 clopen）
- 局部连通性在连续开映射下保持
- 局部连通 + 连通 ⇒ 道路连通（如果同时局部道路连通）

### 5.4 局部道路连通性

**定义**：拓扑空间 X 称为局部道路连通的，如果每个点都有由道路连通开集组成的邻域基。

**局部道路连通 ⇒ 局部连通**（道路连通 ⇒ 连通）。

**局部道路连通空间的性质**：
- 道路分支是开集（因此是 clopen）
- 连通 + 局部道路连通 ⇒ 道路连通（已证）
- ℝⁿ 中的开集是局部道路连通的
- 拓扑流形是局部道路连通的

**局部连通 vs 局部道路连通**：
- 存在局部连通但不局部道路连通的空间（构造较复杂，需要"连通但不道路连通"的局部版本）
- 在"好"的空间中（如流形、CW 复形），两者等价

### 5.5 完全不连通空间

**定义**：拓扑空间 X 称为完全不连通的（totally disconnected），如果每个连通分支都是单点集。

等价地：X 中没有多于一个点的连通子集。

**例子**：
- 离散空间是完全不连通的
- ℚ 是完全不连通的（任意两个不同有理数之间存在无理数，可作为分离点）
- ℝ \ ℚ（无理数集）是完全不连通的
- Cantor 集是完全不连通的（但不是离散的！）
- p-adic 数集是完全不连通的
- 零维空间（有由 clopen 集组成的基）是完全不连通的

**Cantor 集的特殊性**：

**📐 几何图像**：Cantor 集的几何图像是"零体积的粉尘云"。构造过程是：从线段 [0,1] 开始，不断去掉中间的 1/3 开区间——第一次去掉 (1/3,2/3)，第二次去掉剩下两段中间的 1/3，无限继续。最终剩下的点集就是 Cantor 集。几何上，Cantor 集看起来像是一条线段被"砍"成了无限多段，每一段又被砍成更小的段，最终剩下的是一堆"粉尘"一样的点——没有任何两个点是"直接相连"的（完全不连通），但每个点都被其他点"无限逼近"（完美，没有孤立点）。更惊人的是，这堆粉尘的"总长度"为零（测度为零），但包含的点和实数一样多（不可数）。Cantor 集是"零体积的不可数粉尘云"——连通性和"大小"（测度、基数）完全独立。


- Cantor 集是紧的、完全不连通的、完美的（没有孤立点）
- 它是完全不连通但非离散的最经典例子
- Cantor 集同胚于 {0,1}^ℕ（可数个两点空间的积）
- 任何紧度量空间都是 Cantor 集的连续像（Alexandrov-Urysohn 定理）

**完全不连通空间在实变函数中的意义**：
- Cantor 集是测度为零的不可数集，是"长度为零但元素和实数一样多"的经典例子
- Cantor 函数（Cantor 集上的魔鬼阶梯）是连续、单调、几乎处处导数为零但非常数的函数
- 完全不连通集在测度论和分形几何中扮演重要角色

## 第六章 度量空间中的连通性

### 6.1 度量空间中连通性的刻画

在度量空间中，连通性有一些更具体的刻画方式。

**定理（ε-链刻画）**：度量空间 X 连通，当且仅当对任意 ε > 0 和任意 x, y ∈ X，存在有限点列 x = x₀, x₁, ..., x_n = y 使得 d(x_i, x_{i+1}) &lt; ε 对所有 i。

这样的点列称为 ε-链（ε-chain）。

**证明思路**：
- (⇒) 固定 x₀ 和 ε，令 U = {x ∈ X : 存在从 x₀ 到 x 的 ε-链}。U 是非空开集（若 x ∈ U，则 B(x,ε) ⊂ U）。U^c 也是开集（若 x ∉ U，则 B(x,ε) ∩ U = ∅，否则可延长 ε-链）。因 X 连通，U = X。
- (⇐) 反证，若 X 不连通，设 U, V 是分离。取 x ∈ U, y ∈ V。因 U, V 是不相交开集，存在 ε > 0 使得 B(x, ε) ⊂ U 且 B(y, ε) ⊂ V（更准确地说，U 和 V 之间有正距离——在紧空间中成立，在一般度量空间中需要调整论证）。实际上，ε-链条件在一般度量空间中只蕴含"链连通"（chain connected），比连通弱。在紧度量空间中两者等价。

**链连通（chain connected / well-chained）**：满足 ε-链条件的空间称为链连通的。
- 连通 ⇒ 链连通
- 链连通 ⇏ 连通（一般度量空间中）
- 紧度量空间中：连通 ⟺ 链连通

### 6.2 度量空间中道路连通的刻画

**定理**：度量空间 X 道路连通，当且仅当 X 连通且对任意 x ∈ X，x 的道路分支是开集。

这是"连通 + 局部道路连通 ⇒ 道路连通"的更一般形式。

**度量空间中连通开集道路连通**：
- ℝⁿ 中的连通开集是道路连通的（已证）
- 更一般地，局部道路连通空间中的连通开集是道路连通的
- 但度量空间中的连通集（不一定开）不一定道路连通（拓扑正弦曲线是度量空间中的连通但不道路连通的例子）

### 6.3 连通性与完备性、紧性的关系

在度量空间中，三大拓扑性质的关系：

| 性质 | 蕴含关系 | 反例 |
|---|---|---|
| 紧 ⇒ 完备 | 成立 | — |
| 紧 ⇒ 连通 | 不成立 | [0,1] ∪ [2,3] 紧但不连通 |
| 连通 ⇒ 紧 | 不成立 | ℝ 连通但不紧 |
| 连通 ⇒ 完备 | 不成立 | (0,1) 连通但不完备 |
| 完备 ⇒ 连通 | 不成立 | ℚ 的完备化是 ℝ，但 ℚ 本身不完备也不连通；{0} ∪ {1/n} 完备但不连通 |
| 完备 ⇒ 紧 | 不成立 | ℝ 完备但不紧 |

**三者同时成立的空间**：
- [0,1]（完备、紧、连通）
- 闭球 \overline{B}(0,r) ⊂ ℝⁿ（完备、紧、连通）
- 紧连通度量空间（continuum）

**连续统（continuum）**：非空紧连通度量空间称为连续统。
- 例子：[0,1]、圆周 S¹、圆盘、闭球、拓扑正弦曲线
- 连续统理论是拓扑学的一个分支，研究连续统的结构和分类
- 拓扑正弦曲线是一个"不可分解连续统"的边界情况

### 6.4 度量空间中的连通分支

**定理**：度量空间中的连通分支是闭集。

（已证：连通集的闭包连通，故最大连通集必为闭集。）

**定理**：局部连通度量空间中的连通分支是 clopen（既开又闭）。

**定理**：紧度量空间中，只有有限个连通分支当且仅当空间是局部连通的（在某种意义下）。

更准确地：紧度量空间中，连通分支和拟分支（quasi-component）一致。

**拟分支（quasi-component）**：点 x 的拟分支是所有包含 x 的 clopen 集的交。
- 连通分支 ⊂ 拟分支
- 紧 Hausdorff 空间中：连通分支 = 拟分支
- 一般拓扑空间中：连通分支可以严格小于拟分支

## 第七章 拓扑空间中的连通性与推广

### 7.1 连通性的拓扑不变量

连通性是拓扑性质，以下是连通空间的重要拓扑性质：

**定理**：
- 连通空间的连续像是连通的
- 连通空间的商空间是连通的
- 一族连通空间的积是连通的（任意个因子！）
- 连通空间的覆盖空间不一定连通（覆盖空间的连通分支对应基本群的子群）

**积空间的连通性**：
- 有限个连通空间的积是连通的
- 任意个连通空间的积是连通的（证明需要选择公理，通过"先证明有限积连通，再利用稠密性"）
- 例子：ℝ^ℕ（可数个 ℝ 的积）是连通的；{0,1}^ℕ（Cantor 集）是完全不连通的

### 7.2 超连通与超连通性

**超连通（hyperconnected / irreducible）**：拓扑空间 X 称为超连通的，如果任意两个非空开集相交。

即：X 不能有两个不相交的非空开集。

**超连通 ⇒ 连通**：若 X 不连通，则存在不相交的非空开集 U, V，与超连通矛盾。

**连通 ⇏ 超连通**：ℝ 是连通的，但 (0,1) 和 (2,3) 是不相交的非空开集。

**超连通的例子**：
- 余有限拓扑（cofinite topology）下的无限集：任意两个非空开集相交（因为每个开集的补集有限，两个有限集的并不是全集）
- Sierpiński 空间 {0,1}，开集为 {∅, {1}, {0,1}}：唯一的非空真开集是 {1}，没有两个不相交的非空开集
- 特定点拓扑（particular point topology）

**超连通在代数几何中的意义**：
- Zariski 拓扑下的不可约代数簇是超连通的
- 不可约性 = 超连通性（在 Zariski 拓扑下）
- 代数簇的不可约分解对应连通分支的"代数版本"

### 7.3 极端不连通

**极端不连通（extremally disconnected）**：拓扑空间 X 称为极端不连通的，如果每个开集的闭包是开集。

等价地：任意两个不相交的开集的闭包不相交。

**极端不连通空间的性质**：
- 极端不连通的 Hausdorff 空间是完全不连通的
- 极端不连通空间中的无限子集有极限点（在紧的情况下）
- Stone-Čech 紧化 βℕ 是极端不连通的

**极端不连通在泛函分析中的意义**：
- 极端不连通紧空间上的连续函数空间 C(X) 是 Dedekind 完备的 Banach 格
- 这是 ℓ^∞ = C(βℕ) 的格论性质
- Gleason 定理：极不连通紧空间是紧 Hausdorff 空间范畴中的投射对象

### 7.4 连通性的其他推广

**弧连通（arc connected）**：空间 X 弧连通，如果任意两点之间存在弧（arc）——即 [0,1] 的同胚像。

- 弧连通 ⇒ 道路连通
- 道路连通 ⇏ 弧连通（一般空间中）
- Hausdorff 空间中：道路连通 ⟺ 弧连通（任何道路可以"修剪"为弧，除非有自交；在 Hausdorff 空间中，Peano 曲线定理保证连续像可以参数化为弧）

**Peano 曲线定理**：任何连通、局部连通、紧的度量空间（Peano 连续统）都是 [0,1] 的连续像。

**📐 几何深化**：Peano 曲线的几何图像颠覆了"曲线是一维的"这个直觉——一条一维的连续曲线可以填满一个二维的正方形！这意味着连续映射可以把一维的 [0,1] "展开"成二维的 [0,1]²，维度在连续映射下不是不变量。Hahn-Mazurkiewicz 定理给出了完整刻画：紧、连通、局部连通的度量空间（Peano 连续统）都可以被一条连续曲线填满。几何上，这意味着任何"结实的"（紧）、"连在一起的"（连通）、"局部也是连在一起的"（局部连通）实体，都可以被一条曲线"遍历"——不管它是线段、圆盘、球面，还是更复杂的形状。拓扑正弦曲线虽然紧且连通，但不局部连通，所以不是 Peano 连续统——它无法被一条连续曲线填满，因为它"内部不连通"，无法被遍历。

这是一个深刻的结果：[0,1] 的连续像可以是填满空间的曲线（如 Peano 曲线），只要目标空间是 Peano 连续统。

**n-连通（n-connected）**：空间 X 称为 n-连通的，如果它是道路连通的，且对所有 k ≤ n，第 k 同伦群 π_k(X) 平凡。

- 0-连通 = 道路连通
- 1-连通 = 单连通（道路连通且基本群平凡）
- n-连通性是同伦论中的概念，比单纯的连通性强得多

**单连通（simply connected）**：道路连通且基本群平凡的空间。

**📐 几何图像**：单连通的几何图像是"没有洞的区域"。单连通区域中，任何闭曲线都可以"收缩"到一个点——就像一根橡皮筋套在区域里，你可以把它越缩越小，最终缩成一个点，不会被任何"洞"卡住。圆盘是单连通的——橡皮筋可以缩到圆心。圆环（空心圆盘）不是单连通的——绕着中间洞的橡皮筋无法收缩，会被洞"卡住"。圆周 S¹ 不是单连通的——圆周本身无法收缩到一个点（在圆周内）。球面 S² 是单连通的——球面上的任何闭曲线都可以收缩到一个点（球面没有"贯穿的洞"）。单连通性是 Riemann 映射定理的核心条件——任何单连通真子区域都可以共形映射为单位圆盘，因为"没有洞"的区域可以"拉圆"。
- 例子：ℝⁿ、圆盘、球面 Sⁿ (n ≥ 2)
- 非例子：圆周 S¹、圆环、穿孔平面
- 单连通性是复分析中 Riemann 映射定理的条件之一（单连通区域共形等价于圆盘）

## 第八章 复变函数中的连通性

### 8.1 区域与连通性

**区域（domain）**：复平面 ℂ 中的连通开集称为区域。

**区域的基本性质**：
- 区域是道路连通的（ℂ 中的连通开集自动道路连通）
- 区域是局部道路连通的
- 区域中任意两点之间存在折线道路（实际上，多边形道路就够了）

**为什么区域是复分析的基本舞台**：
- 全纯函数的定义需要开集（导数定义需要邻域）
- 连通性保证了解析延拓的唯一性（恒等定理）
- 道路连通性保证了积分路径的存在性

**恒等定理（Identity Theorem）**：若 f, g 在区域 D 上全纯，且在 D 的有聚点的子集上相等，则 f ≡ g 在 D 上。

连通性在恒等定理中的作用：设 A = {z ∈ D : f(z) = g(z)}。A 是非空闭集（f-g 连续，零点集闭）。A 也是开集（若 z₀ ∈ A，由 Taylor 展开，f-g 在 z₀ 附近恒为零）。因 D 连通，A = D。

### 8.2 解析延拓与连通性

**解析延拓（analytic continuation）**：将全纯函数的定义域扩大的过程。

**连通性在解析延拓中的作用**：
- 解析延拓的唯一性：沿同一条路径的解析延拓是唯一的
- 单值性定理（Monodromy Theorem）：在单连通区域中，沿所有路径的解析延拓得到同一个函数
- 多连通区域中，沿不同路径可能得到不同的分支（如 √z 在穿孔平面上）

**Riemann 面的连通性**：
- 解析函数的 Riemann 面是连通的（如果函数是"不可约"的）
- Riemann 面的连通分支对应函数的不同"分支"
- 紧 Riemann 面是连通的紧复流形，是复几何的基本对象

**Riemann 面的例子**：
- √z 的 Riemann 面：两叶曲面，在 0 和 ∞ 处分支，同胚于球面（连通）
- log z 的 Riemann 面：无限多叶螺旋面，同胚于 ℂ（连通但非紧）
- 椭圆函数的 Riemann 面：环面（紧连通）

### 8.3 单连通性与 Riemann 映射定理

**单连通区域**：道路连通且基本群平凡的区域。

等价刻画（复平面上的区域）：
- D 单连通 ⟺ ℂ^* \ D 连通（在 Riemann 球面上）
- D 单连通 ⟺ D 中任何闭曲线可以连续收缩到一点
- D 单连通 ⟺ D 中任何全纯函数有原函数
- D 单连通 ⟺ D 中任何无处为零的全纯函数有全纯对数

**Riemann 映射定理**：任何单连通真子区域 D ⊂ ℂ 共形等价于单位圆盘 𝔻。

**连通性在 Riemann 映射定理中的角色**：
- 单连通性是定理的必要条件（多连通区域不能共形等价于圆盘，因为基本群是共形不变量）
- 定理的证明使用正规族（紧性），但单连通性（连通性的加强）是前提条件
- 映射的存在性依赖于极值函数的构造，而极值函数在单连通区域中良定义

**多连通区域的共形分类**：
- 二连通区域共形等价于圆环 {r &lt; |z| &lt; 1}（模由 r 决定）
- n 连通区域共形等价于圆盘去掉 n-1 个同心圆弧（Koebe 域）
- 连通性的"阶"（基本群的秩）是共形不变量

### 8.4 最大模原理与连通性

**最大模原理**：若 f 在区域 D 上全纯且非常数，则 |f| 在 D 内不能取得局部最大值。

**连通性的作用**：
- 设 |f| 在 z₀ ∈ D 取得局部最大值。由平均值性质，f 在 z₀ 附近为常数。
- 令 A = {z ∈ D : f(z) = f(z₀)}。A 是非空开集（由平均值性质）和闭集（由连续性）。
- 因 D 连通，A = D，故 f 常数，矛盾。

**最小模原理**：若 f 在区域 D 上全纯、非常数且无处为零，则 |f| 在 D 内不能取得局部最小值。

**Schwarz 引理、Phragmén-Lindelöf 原理**等都依赖连通性来保证"局部常数 ⇒ 全局常数"。

### 8.5 连通性在复积分中的应用

**Cauchy 积分定理**：若 f 在单连通区域 D 上全纯，则 f 沿 D 中任何闭曲线的积分为零。

**连通性的作用**：
- 单连通性保证闭曲线可以收缩到一点，从而可以用 Green 定理 / Stokes 定理
- 多连通区域中，Cauchy 积分定理推广为：沿外边界的积分等于沿内边界积分之和（留数定理的基础）

**留数定理**：f 在区域 D 上除有限个极点外全纯，γ 是 D 中不经过极点的闭曲线，则 ∮_γ f(z)dz = 2πi Σ Res(f, a_k)，其中 a_k 是 γ 内部的极点。

连通性保证了"内部"概念的良定义（Jordan 曲线定理需要连通性）。

## 第九章 实变函数中的连通性

### 9.1 可测集的连通性

**Lebesgue 可测集的连通性**：可测集可以是连通的、不连通的、完全不连通的。

**连通可测集的例子**：
- 区间（连通，测度为长度）
- 开集（ℝⁿ 中的开集是可数个连通开集的并，每个连通分支可测）
- 闭球、闭立方体

**完全不连通可测集的例子**：
- Cantor 集（紧、完全不连通、测度为 0、不可数）
- 类 Cantor 集（Smith-Volterra-Cantor 集，测度为正的完全不连通集）
- ℚ（测度为 0，完全不连通）
- 任何零测集的子集（可测，可能完全不连通）

**Smith-Volterra-Cantor 集**：
- 构造：从 [0,1] 开始，第 n 步去掉中间长度为 1/4^n 的开区间
- 结果：紧、完全不连通、测度为 1 - Σ 2^{n-1}/4^n = 1 - 1/2 = 1/2
- 意义：存在测度为正的无处稠密完全不连通集
- 这个集的特征函数是 Riemann 不可积的（不连续点集测度为正），但 Lebesgue 可积

### 9.2 连通性与测度的微妙关系

**定理**：ℝⁿ 中具有正测度的集合不一定包含连通子集（除了单点集）。

**反例**：Smith-Volterra-Cantor 集测度为 1/2，但完全不连通，没有非平凡连通子集。

**定理（Steinhaus）**：若 A ⊂ ℝⁿ 可测且测度为正，则差集 A - A = {x - y : x, y ∈ A} 包含原点的一个邻域。

这意味着正测度集在"差集"意义下有局部连通性（包含开集），尽管集合本身可能完全不连通。

**证明思路**：取 A 的稠密点 x₀，在 x₀ 附近 A 的密度接近 1。对小的 h，A 和 A+h 都占据 x₀ 附近大部分区域，故相交，即 h ∈ A - A。

**Steinhaus 定理的推论**：
- 正测度集的差集包含开集
- 正测度的加法子群是 ℝⁿ 本身（因为子群包含邻域，而包含邻域的加法子群是整个空间）
- 这是"不可测集不能是可测加法子群"的基础

### 9.3 不可测集的连通性

**Vitali 不可测集**：
- 构造：在 ℝ 上定义等价关系 x ~ y ⟺ x - y ∈ ℚ，从每个等价类中选一个代表元，组成 V ⊂ [0,1]
- V 不可测（若可测，则 m(V) > 0，但 {V + q : q ∈ ℚ ∩ [-1,1]} 是不相交的可数个测度相同的集，都包含在 [-1,2] 中，故 m(V) = 0；但 [0,1] ⊂ ⋃(V+q)，故 m(V) > 0，矛盾）

**Vitali 集的连通性**：
- V 是完全不连通的吗？不一定。V 的构造依赖选择公理，其拓扑性质不确定。
- 但可以证明：V 不包含任何非平凡区间（否则 V 中有两个有理数差的元素，与等价类代表元的选取矛盾）。
- 不包含区间的集合在 ℝ 中不一定完全不连通（存在不包含区间的连通集，如"不可分解连续统"的子集），但 Vitali 集通常被认为是"高度不连通"的。

**不可测集与连通性的一般关系**：
- 存在连通的不可测集（构造：选择一个连通集的不可测子集，或者用传递归纳法构造）
- 存在完全不连通的不可测集（Vitali 集的某种变体）
- 连通性和可测性是独立的性质

**Bernstein 集**：
- 定义：集合 B ⊂ ℝ 称为 Bernstein 集，如果 B 和 B^c 都与每个不可数闭集相交。
- Bernstein 集不可测（任何正测度可测集包含不可数闭集，故 Bernstein 集不可测）。
- Bernstein 集是完全不连通的吗？Bernstein 集不包含任何不可数闭集，因此不包含任何非平凡区间。但它可能包含连通的不可数子集（如果存在的话）。实际上，Bernstein 集是"完全不连通"的强形式：它不包含任何不可数紧集。

### 9.4 Cantor 集与连通性

**Cantor 集的拓扑性质**：
- 紧（有界闭集）
- 完全不连通（连通分支都是单点）
- 完美（没有孤立点，每个点都是极限点）
- 无处稠密（内部为空）
- 测度为 0（标准 Cantor 集）
- 基数为连续统（和 ℝ 一样多的点）

**Cantor 集的连通性分析**：
- 对任意 x &lt; y ∈ C，存在 z ∉ C 使得 x &lt; z &lt; y（因为 C 中没有区间）
- 因此 C = (C ∩ (-∞, z)) ∪ (C ∩ (z, ∞)) 是一个分离
- 故任意两个不同点不在同一个连通分支中，连通分支都是单点

**Cantor 函数（魔鬼阶梯）**：
- 定义：Cantor 函数 f : [0,1] → [0,1] 是连续、单调不减函数，f(0)=0, f(1)=1
- f 在 Cantor 集的补集（被去掉的开区间）上是常数
- f 几乎处处可导，导数几乎处处为 0
- 但 f 不是常数！它从 0 连续增长到 1

**Cantor 函数与连通性的关系**：
- f 是连续函数，[0,1] 连通，故 f([0,1]) = [0,1] 连通（区间定理）
- 但 f 在一个稠密开集上是局部常数（导数为 0）
- 这说明：连续函数可以在"大部分"区域平坦，但仍然通过一个完全不连通的集（Cantor 集）实现增长
- Cantor 函数是"连通性可以通过完全不连通集传递"的惊人例子

**Cantor 集的同胚分类**：
- 任何非空、紧、完全不连通、完美的度量空间同胚于 Cantor 集（Brouwer 定理）
- 因此 Cantor 集是这类空间的"唯一"模型
- 例子：{0,1}^ℕ、p-adic 整数集、三进制 Cantor 集，都互相同胚

### 9.5 连通性在积分理论中的作用

**Lebesgue 积分与连通性**：
- 积分理论本身不直接依赖连通性（可测集可以任意不连通）
- 但一些重要定理使用连通性作为条件

**定理（积分的绝对连续性）**：若 f 可积，则对任意 ε > 0，存在 δ > 0 使得 m(A) &lt; δ ⇒ ∫_A |f| &lt; ε。

这个定理不依赖连通性，但它的证明使用了"简单函数逼近"，而简单函数的支撑集可以不连通。

**Fubini 定理与连通性**：
- Fubini 定理不依赖连通性
- 但在连通区域上，积分的几何意义更清晰（体积、面积等）

**分部积分与连通性**：
- 分部积分公式 ∫ f'g = fg| - ∫ fg' 需要在连通区间上定义边界值
- 在不连通集上，边界项需要对每个连通分支分别计算

## 第十章 反例库

### 10.1 实数轴上的反例

**反例 1：不连通的开集**
- (0,1) ∪ (2,3) 是开集但不连通
- 连通分支是 (0,1) 和 (2,3)，都是 clopen

**反例 2：连通但不是区间的集（在 ℝ 中不存在！）**
- 区间定理保证 ℝ 中连通集只有区间
- 这是实数轴的特殊性质，在高维空间中不成立

**反例 3：完全不连通的不可数集**
- Cantor 集：不可数、紧、完全不连通、测度为 0
- Smith-Volterra-Cantor 集：不可数、紧、完全不连通、测度为 1/2

**反例 4：连通但无处稠密的集**
- 在 ℝ 中不存在（ℝ 中的连通集是区间，区间有非空内部除非是单点）
- 在 ℝ² 中存在：拓扑正弦曲线是连通的且无处稠密（内部为空）

### 10.2 平面上的反例

**反例 5：连通但不道路连通——拓扑正弦曲线**
- X = {(x, sin(1/x)) : 0 &lt; x ≤ 1} ∪ {(0, y) : -1 ≤ y ≤ 1}
- 连通但不道路连通
- 有两个道路分支（S 和 T），一个连通分支（X）

**反例 6：连通但不局部连通**
- 拓扑正弦曲线 X：连通但在 T 上的点不局部连通
- 任何 T 上的点的小邻域都包含 S 的无限多个振荡"段"，无法包含在连通开集中

**反例 7：道路连通但不局部连通**
- "扫帚空间"（broom space）：在原点连接无限多条线段，每条线段的长度递减且角度不同
- 道路连通（任意两点通过原点连接）但在原点不局部连通（原点的小邻域包含无限多条线段的"碎片"）

**反例 8：连通、局部连通但不道路连通**
- 这样的空间存在吗？在一般拓扑空间中存在，但构造复杂。
- 在度量空间中：连通 + 局部连通 ⇒ 道路连通吗？不一定！存在连通、局部连通但不道路连通的度量空间（如"无限 broom"的某种变体）。
- 实际上，连通 + 局部道路连通 ⇒ 道路连通，但局部连通（不是局部道路连通）不够。

**反例 9：完全不连通但不是离散的**
- Cantor 集：完全不连通、紧、完美（没有孤立点）
- ℚ：完全不连通但不是离散的（每个点都是聚点）
- 无理数集：完全不连通但不是离散的

**反例 10：连通分支不是开集的空间**
- ℚ：连通分支是单点集，单点集不是开集（ℚ 没有孤立点）
- Cantor 集：连通分支是单点集，单点集不是开集

### 10.3 复分析中的反例

**反例 11：连通但不是区域的集**
- 闭圆盘 \overline{D}：连通但不是开集，故不是区域
- 圆周 S¹：连通但不是开集
- 拓扑正弦曲线：连通但不是开集

**反例 12：开集但不连通**
- D = {z : |z| &lt; 1} ∪ {z : |z-3| &lt; 1}：开集但不连通
- 连通分支是两个圆盘

**反例 13：多连通区域**
- 圆环 {r &lt; |z| &lt; R}：二连通区域
- 穿孔平面 ℂ \ {0}：二连通区域
- 去 n 个点的平面：(n+1)-连通区域

**反例 14：单连通但不是凸的区域**
- 单位圆盘去掉一条半径：单连通但不是凸的
- 五角星内部：单连通、星形但不是凸的
- 上半平面：单连通、凸的

**反例 15：全纯函数的零点集不连通**
- f(z) = sin z：零点集是 {nπ : n ∈ ℤ}，完全不连通
- f(z) = z² - 1：零点集是 {-1, 1}，不连通
- 但零点集的每个聚点所在的连通分支上，f 恒为零（恒等定理）

### 10.4 实变函数中的反例

**反例 16：正测度的完全不连通集**
- Smith-Volterra-Cantor 集：测度 1/2，完全不连通
- 类 Cantor 集：可以构造任意测度 &lt; 1 的完全不连通紧集

**反例 17：零测度的连通集**
- 在 ℝ 中：只有单点集（区间的测度是长度，非单点区间测度 > 0）
- 在 ℝ² 中：线段（测度为 0，连通）、拓扑正弦曲线（测度为 0，连通）
- 在 ℝⁿ 中：任何低维子流形（测度为 0，连通）

**反例 18：不可测的连通集**
- 存在连通的不可测集（用选择公理和传递归纳法构造）
- 构造思路：从一个连通集开始，逐步添加点以保持连通性，同时避开所有可测集的"约束"
- 这样的集合是高度病态的，依赖选择公理

**反例 19：可测函数的不连续点集连通**
- Dirichlet 函数：不连续点集是 ℝ（连通），函数处处不连续
- Thomae 函数：不连续点集是 ℚ（完全不连通），函数在无理点连续
- 可以构造不连续点集为任意 F_σ 型集的函数（包括连通的 F_σ 集）

**反例 20：连续函数把连通集映为不连通集**
- 不可能！连续映射保持连通性
- 但连续函数可以把完全不连通集映为连通集：Cantor 函数把 Cantor 集（完全不连通）映为 [0,1]（连通）

### 10.5 拓扑空间中的反例

**反例 21：连通但不是道路连通的紧空间**
- 拓扑正弦曲线（紧、连通、不道路连通）
- Warsaw circle（紧、连通、不道路连通）

**反例 22：道路连通但不是单连通的空间**
- 圆周 S¹：道路连通但基本群为 ℤ
- 圆环 T²：道路连通但基本群为 ℤ²
- 穿孔平面 ℂ \ {0}：道路连通但基本群为 ℤ

**反例 23：连通空间的积不连通**
- 不可能！连通空间的任意积都是连通的
- 但完全不连通空间的积可以是连通的吗？不，完全不连通空间的积是完全不连通的（{0,1}^ℕ = Cantor 集完全不连通）

**反例 24：连通空间的子空间不连通**
- [0,1] 连通，但 [0,1] \ {1/2} = [0,1/2) ∪ (1/2,1] 不连通
- 这说明连通性不是遗传性质（子空间不一定保持）

**反例 25：局部连通但不连通的空间**
- 离散空间：局部连通但不连通（多于一个点时）
- [0,1] ∪ [2,3]：局部连通但不连通

## 第十一章 历史演进

### 11.1 前史：从介值定理到连通性

**Bernhard Bolzano（1781-1848）**：
- 1817 年证明介值定理时，首次隐含使用了"区间是连通的"这一性质
- 他的证明使用了"最小上界"思想，本质上依赖实数的完备性和连通性

**Augustin-Louis Cauchy（1789-1857）**：
- 1821 年在《分析教程》中严格表述了介值定理
- 他的证明使用了区间套方法，隐含了连通性

**Karl Weierstrass（1815-1897）**：
- 1860 年代的讲座中，系统发展了 ε-δ 语言
- 他的学生 Cantor、Dedekind 等人后来建立了严格的实数理论和拓扑学

### 11.2 连通性概念的诞生

**Georg Cantor（1845-1918）**：
- 1879 年引入了"连通"（continuum / zusammenhängend）的概念
- 他定义：一个集合是连通的，如果对任意两点，存在一条由集合中的点组成的"连续路径"
- 这实际上是道路连通的定义，不是现代的连通性定义

**Camille Jordan（1838-1922）**：
- 1893 年在《分析教程》中给出了连通性的更精确定义
- 他使用了"不能被分成两个没有公共点的闭集"的定义

**Felix Hausdorff（1868-1942）**：
- 1914 年在《集合论基础》中给出了现代的连通性定义（不能表示为两个不相交非空开集的并）
- 他系统研究了连通性的性质，包括连通分支、局部连通性等
- Hausdorff 是拓扑学的奠基人之一，他的工作确立了连通性作为基本拓扑概念的地位

### 11.3 道路连通性的发展

**道路概念的起源**：
- 道路（path）的概念在分析中早就存在（曲线积分、变分法）
- 但作为拓扑概念的"道路连通性"是 20 世纪初才明确的

**Hans Hahn（1879-1934）和 Stefan Mazurkiewicz（1888-1945）**：
- 1913 年左右，独立证明了"局部连通的连续统是道路连通的"（Hahn-Mazurkiewicz 定理的前身）
- 他们的工作澄清了连通和道路连通之间的关系

**Hahn-Mazurkiewicz 定理（1914）**：
- 一个空间是 [0,1] 的连续像（Peano 连续统）当且仅当它是紧、连通、局部连通的度量空间
- 这个定理深刻揭示了道路连通性和局部连通性之间的关系

### 11.4 拓扑正弦曲线的发现

**Wacław Sierpiński（1882-1969）**：
- 1916 年左右构造了"拓扑正弦曲线"（也称为 Sierpiński 曲线的一种）
- 这是第一个明确的"连通但不道路连通"的例子
- 它的发现揭示了连通和道路连通之间的本质区别

**Warsaw circle**：
- 由波兰拓扑学派（Sierpiński、Kuratowski 等人）在 1920 年代研究
- Warsaw circle 是紧、连通、但不道路连通、也不局部连通的空间
- 它是"看起来像圆但不是圆"的经典反例

**波兰拓扑学派的贡献**：
- 20 世纪 20-30 年代，华沙数学学派（Sierpiński、Kuratowski、Mazurkiewicz、Borsuk 等人）系统研究了连通性理论
- 他们发现了大量反例，建立了连续统理论
- 《Fundamenta Mathematicae》杂志是这一学派的阵地，发表了大量连通性理论的经典论文

### 11.5 连通性在复分析中的发展

**Bernhard Riemann（1826-1866）**：
- 1851 年博士论文中引入了 Riemann 面的概念
- 他的工作隐含了连通性的思想（Riemann 面的连通分支对应函数的分支）
- 但 Riemann 没有给出连通性的严格定义

**Hermann Schwarz（1843-1921）**：
- 1870 年代证明了 Schwarz 反射原理，使用了连通性来保证解析延拓的唯一性

**Paul Montel（1876-1975）**：
- 1907 年引入正规族概念，紧性和连通性在复分析中交汇
- 正规族理论使 Riemann 映射定理的证明更加简洁

**Constantin Carathéodory（1873-1950）**：
- 1913 年证明了单连通区域的边界对应定理
- 他的工作深入研究了区域的连通性和边界结构

### 11.6 连通性在实变函数中的发展

**Émile Borel（1871-1956）**：
- 1898 年引入了 Borel 集的概念
- Borel 集的结构（开集、闭集、G_δ、F_σ 等）与连通性有密切关系

**Henri Lebesgue（1875-1941）**：
- 1902 年建立了 Lebesgue 积分理论
- 他研究了可测集的结构，包括 Cantor 集等完全不连通集
- Lebesgue 证明了"可测函数几乎处处连续"（Lusin 定理的前身）

**Nikolai Luzin（1883-1950）**：
- 1912 年证明了 Lusin 定理：可测函数在去掉一个小测度集后是连续的
- 他的工作揭示了可测性和连续性之间的深刻联系

**Wacław Sierpiński（1882-1969）**：
- 研究了不可测集的拓扑性质
- Sierpiński 集、Sierpiński 曲线等以他命名
- 他证明了"连续统假设下，存在不可数的 Sierpiński 集，与每个零测集交于可数集"

## 第十二章 跨层对照与蜕变图谱

### 12.1 连通性定义的四层蜕变

| 层级 | 连通性的定义形式 | 核心特征 | 典型定理 |
|---|---|---|---|
| L0 初等 | "区间是连在一起的" | 几何直观 | 介值定理 |
| L1 数分 | 不能分成两个不相交非空开集 | 拓扑定义 | 区间定理、介值定理 |
| L2 复变 | 区域（连通开集）、单连通性 | 开集 + 连通 + 基本群 | 恒等定理、Riemann 映射定理 |
| L3 实变 | 可测集的连通性、完全不连通集 | 可测性 + 连通性 | Cantor 集、Steinhaus 定理 |

### 12.2 连通与道路连通的关系演化

| 层级 | 连通 ⇒ 道路连通？ | 反例 |
|---|---|---|
| L0 初等 | 是（区间自动道路连通） | 无 |
| L1 数分（ℝⁿ 开集） | 是（连通开集道路连通） | 无（开集） |
| L1 数分（ℝⁿ 任意集） | 否 | 拓扑正弦曲线 |
| L2 复变（区域） | 是（区域自动道路连通） | 无 |
| L2 复变（任意集） | 否 | 拓扑正弦曲线（在 ℂ ≅ ℝ² 中） |
| L3 实变（可测集） | 否 | 可测的拓扑正弦曲线变体 |

**关键洞察**：在"好"的空间中（开集、流形、局部道路连通空间），连通自动蕴含道路连通。但在一般集合中，两者之间存在深刻的鸿沟，拓扑正弦曲线是这个鸿沟的经典化身。

### 12.3 关键定理的蜕变链

**介值定理的蜕变**：
- L1：连续函数 f : [a,b] → ℝ，f(a) &lt; 0 &lt; f(b) ⇒ 存在 c 使 f(c) = 0
- L1 一般形式：连通空间 X 上的连续实值函数的值域是区间
- L2：全纯函数在区域上的介值性（开映射定理：非常数全纯函数把开集映为开集，因此值域是开区域）
- L3：可测函数的介值性（可测函数不一定连续，介值定理不直接成立；但 Lusin 定理说可测函数"几乎"连续）

**区间定理的蜕变**：
- L1：ℝ 中连通集 = 区间
- L2：ℂ 中连通开集 = 区域（但 ℂ 中的连通集不一定是"区域"，因为区域要求开集）
- L3：ℝⁿ 中连通可测集的分类（没有简单分类，可以是任意复杂的）

**恒等定理的蜕变**：
- L2：区域上的全纯函数，若在有聚点的子集上相等，则恒等
- L1 类比：区间上的连续函数，若在稠密子集上相等，则恒等（但连续函数不需要"有聚点"，只需要稠密）
- L3 类比：可测函数若在正测度集上相等，则"几乎处处"相等（但不是处处相等）

### 12.4 反例的演化

| 反例类型 | L1 数分 | L2 复变 | L3 实变 |
|---|---|---|---|
| 连通但不道路连通 | 拓扑正弦曲线（ℝ² 中） | 同左（ℂ ≅ ℝ²） | 可测的拓扑正弦曲线变体 |
| 完全不连通的不可数集 | Cantor 集 | Cantor 集（在 ℂ 中） | Smith-Volterra-Cantor 集（正测度） |
| 连通但无处稠密 | 拓扑正弦曲线（ℝ² 中） | 同左 | 可测的连通无处稠密集 |
| 不连通的开集 | (0,1) ∪ (2,3) | 两个不相交圆盘的并 | 可测的不连通开集 |
| 正测度的完全不连通集 | （L1 中测度=长度，Cantor 集测度 0） | （L2 中测度=面积，平面 Cantor 集可以正测度） | Smith-Volterra-Cantor 集 |

### 12.5 连通性与完备性、紧性的跨层关系

| 层级 | 完备性 | 紧性 | 连通性 | 三者交集 |
|---|---|---|---|---|
| L1 | ℝ 完备 | [0,1] 紧 | 区间连通 | [0,1]（三者皆备） |
| L2 | ℂ 完备 | 紧集有界闭 | 区域连通 | 闭圆盘（三者皆备） |
| L3 | Lp 完备 | 弱紧性 | 可测集连通性 | 紧连通可测集（连续统） |

**三大支柱的协同**：
- 完备性保证"极限不跑出空间"
- 紧性保证"收敛子列存在"
- 连通性保证"不能分成两块"
- 三者同时成立时，空间具有最强的存在性和结构性（如 [0,1]、闭圆盘）

## 第十三章 收敛沉淀与方法论

### 13.1 连通性证明的标准技术

**技术一：分离反证法**
- 适用：证明空间连通或不连通
- 步骤：假设存在分离 U, V → 利用连通集的性质导出矛盾（或构造分离证明不连通）
- 典型应用：区间定理证明、连续映射保持连通性证明

**技术二：clopen 集法**
- 适用：证明连通性或连通分支的性质
- 步骤：证明某个集合是 clopen → 利用连通空间只有平凡 clopen 集 → 得出集合为全空间或空集
- 典型应用：恒等定理证明、"连通 + 局部道路连通 ⇒ 道路连通"证明

**技术三：道路拼接法**
- 适用：证明道路连通性
- 步骤：固定一点 → 定义"可通过道路到达的点集" → 证明该集是 clopen → 利用连通性得出全空间
- 典型应用：区域道路连通性证明

**技术四：闭包法**
- 适用：证明包含连通集的集合连通
- 步骤：证明 A 连通 → 证明 A ⊂ B ⊂ \overline{A} → 得出 B 连通
- 典型应用：拓扑正弦曲线连通性证明

**技术五：介值定理法**
- 适用：证明连通性或利用连通性
- 步骤：构造连续函数 → 利用介值定理（值域为区间）→ 得出结论
- 典型应用：证明空间不连通（构造连续函数值域不连通）、不动点定理

### 13.2 连通性的"充要图谱"学习法

对每个连通性概念，建立以下图谱：

**定义图谱**：
- 原始定义（分离定义）
- 等价定义（clopen 刻画、连续映射刻画、边界刻画）
- 加强版本（道路连通、弧连通、单连通、n-连通）
- 弱化版本（链连通、超连通）

**条件图谱**：
- 充分条件：什么条件能推出连通性？（区间、凸集、道路连通、连续像、有公共点的连通集的并）
- 必要条件：连通性能推出什么？（连续像连通、介值定理、clopen 集平凡）
- 反例：每个蕴含关系的反例是什么？

**定理图谱**：
- 以连通性为条件的定理（介值定理、恒等定理、最大模原理）
- 以连通性为结论的定理（区间定理、连续映射保持连通性）
- 连通性在证明中扮演的角色（"局部常数 ⇒ 全局常数"、"值域是区间"）

**跨层图谱**：
- 同一概念在 L0/L1/L2/L3 中的形式变化
- 连通和道路连通的关系在各层中的差异
- 反例的层级差异

### 13.3 常见误区与澄清

**误区一：连通集一定是道路连通的**
- 澄清：只在附加条件下成立（局部道路连通、开集在 ℝⁿ 中、流形等）。一般情况下不成立，拓扑正弦曲线是经典反例。

**误区二：ℝⁿ 中的连通集是道路连通的**
- 澄清：ℝⁿ 中的连通**开集**是道路连通的，但连通集（不一定开）不一定。拓扑正弦曲线是 ℝ² 中的连通但不道路连通的集。

**误区三：连通分支是开集**
- 澄清：连通分支一定是闭集，但不一定是开集。在局部连通空间中，连通分支是开集（因此是 clopen）。ℚ 和 Cantor 集的连通分支是单点集，不是开集。

**误区四：完全不连通 = 离散**
- 澄清：完全不连通意味着连通分支都是单点，但单点不一定是开集。Cantor 集、ℚ、无理数集都是完全不连通但非离散的。

**误区五：紧 + 连通 ⇒ 道路连通**
- 澄清：不一定。拓扑正弦曲线是紧、连通但不道路连通的。需要附加局部连通性（Hahn-Mazurkiewicz 定理：紧、连通、局部连通的度量空间是道路连通的）。

**误区六：单连通 = 连通**
- 澄清：单连通比连通强得多。单连通要求道路连通且基本群平凡。圆周 S¹ 连通但不单连通。

**误区七：可测集的连通性有简单分类**
- 澄清：没有。可测集可以是连通的、不连通的、完全不连通的，可以有任意测度。Smith-Volterra-Cantor 集是正测度完全不连通集的例子。

### 13.4 连通性在分析学体系中的定位

连通性是分析学的"结构性支柱"：

1. **完备性**是"地基"——保证极限存在于空间内
2. **紧性**是"引擎"——保证收敛子列存在
3. **连通性**是"结构"——保证空间不能被分成两块
4. **可微性/可积性**是在三大支柱基础上的"高级功能"

连通性的核心作用：
- **存在性**：介值定理保证中间值存在
- **唯一性**：恒等定理保证解析延拓唯一（"局部常数 ⇒ 全局常数"）
- **分类**：连通分支给出空间的基本分解
- **不变量**：基本群、同调群等代数不变量以连通性和道路连通性为基础

**连通性的本质**：它是一种"整体性"条件，无法通过局部检查来验证。一个空间的每个点附近都可以是"连通的"（局部连通），但整体可能不连通。反过来，整体连通的空间可能在局部非常病态（拓扑正弦曲线）。这种"整体-局部"的张力是连通性理论最深刻的方面。

## 外部校验

### 证伪任务

**任务 1**：找一个连通但不是道路连通的子集，要求它是 ℝ² 中的有界闭集。
- 答案：拓扑正弦曲线 X = {(x, sin(1/x)) : 0 &lt; x ≤ 1} ∪ {(0, y) : -1 ≤ y ≤ 1}。它是 ℝ² 中的有界闭集（紧集），连通但不道路连通。

**任务 2**：找一个完全不连通但不是离散的空间，要求是紧的。
- 答案：Cantor 集。紧、完全不连通、完美（没有孤立点），因此不是离散的。

**任务 3**：找一个连通开集，要求不是凸的，也不是星形的。
- 答案：圆环 {1 &lt; |z| &lt; 2}。连通开集（区域），但不是凸的（原点不在圆环内，圆环内两点的连线可能经过原点），也不是星形的（没有点使得到所有其他点的线段都在圆环内）。

**任务 4**：找一个正测度的完全不连通集。
- 答案：Smith-Volterra-Cantor 集。从 [0,1] 开始，第 n 步去掉中间长度为 1/4^n 的开区间，最终得到的集测度为 1/2，完全不连通。

### 真题锚点

**数学分析考研真题**：
1. 证明：连通空间上的连续实值函数的值域是区间。
2. 设 A ⊂ ℝⁿ 连通，A ⊂ B ⊂ \overline{A}，证明 B 连通。
3. 证明：ℝⁿ 中的连通开集是道路连通的。

**复变函数考研真题**：
1. 叙述并证明恒等定理（Identity Theorem）。
2. 证明：区域上的非常数全纯函数是开映射（开映射定理）。
3. 叙述 Riemann 映射定理，并说明单连通性的作用。

**实变函数考研真题**：
1. 证明：Cantor 集是完全不连通的、完美的、测度为 0 的不可数集。
2. 叙述并证明 Steinhaus 定理（正测度集的差集包含邻域）。
3. 构造一个测度为正的无处稠密闭集（Smith-Volterra-Cantor 集）。

**拓扑学考研真题**：
1. 证明：连通性在连续映射下保持。
2. 证明：一族有公共点的连通集的并是连通的。
3. 证明：局部道路连通的连通空间是道路连通的。
4. 构造一个连通但不道路连通的空间，并证明。

### 例生成

**例 1（连通性判定）**：判断以下集合在指定空间中是否连通、是否道路连通：
(a) (0,1) ∪ (2,3) 在 ℝ 中
(b) 圆周 S¹ 在 ℝ² 中
(c) 拓扑正弦曲线 X 在 ℝ² 中
(d) Cantor 集在 ℝ 中
(e) 圆环 {1 &lt; |z| &lt; 2} 在 ℂ 中

答案：
(a) 不连通、不道路连通（两个连通分支）
(b) 连通、道路连通（圆周上任意两点有圆弧道路）
(c) 连通、不道路连通（拓扑正弦曲线）
(d) 不连通（完全不连通）、不道路连通（除单点外无道路）
(e) 连通、道路连通（区域自动道路连通）

**例 2（反例构造）**：构造一个 ℝ² 中的连通集，使得它的补集也是连通的。
- 构造：x 轴（ℝ × {0}）。x 轴连通，其补集 ℝ² \ (ℝ × {0}) = 上半平面 ∪ 下半平面，不连通。
- 正确构造：一条从原点出发的螺旋线，无限绕原点旋转且半径递增。它的补集是连通的（可以"绕过"螺旋线的端点），但螺旋线本身连通。
- 更简单：ℝ² 本身（连通，补集为空集——空集连通吗？空集是连通的，因为不存在分离）。
- 非平凡例子：一条直线（连通），其补集不连通；但一条"填满"的曲线（如 Peano 曲线的像 = 整个正方形）的补集是连通的。

**例 3（连通性应用）**：用连通性证明：若 f : [a,b] → [a,b] 连续，则 f 有不动点。
- 证明：令 g(x) = f(x) - x。g(a) = f(a) - a ≥ 0，g(b) = f(b) - b ≤ 0。若 g(a) = 0 或 g(b) = 0，则 a 或 b 是不动点。否则 g(a) > 0 > g(b)，由介值定理（[a,b] 连通，g 连续），存在 c ∈ (a,b) 使 g(c) = 0，即 f(c) = c。

### 五类边

**边界一：连通 vs 不连通**
- 判定标准：是否存在分离（两个不相交非空开集的并）
- 临界案例：(0,1)（连通）vs (0,1) ∪ (2,3)（不连通）
- 关键：一个点的删除可以使连通变不连通（如 [0,1] 删除中点）

**边界二：道路连通 vs 连通**
- 在"好"空间中重合，在一般空间中分离
- 临界案例：拓扑正弦曲线（连通非道路连通）
- 关键：局部道路连通性是两者等价的桥梁

**边界三：局部连通 vs 连通**
- 两者独立：连通不一定局部连通（拓扑正弦曲线），局部连通不一定连通（离散空间）
- 临界案例：拓扑正弦曲线（连通非局部连通）
- 关键：局部连通性保证连通分支是开集

**边界四：完全不连通 vs 离散**
- 完全不连通要求连通分支为单点，离散要求单点为开集
- 临界案例：Cantor 集（完全不连通非离散）
- 关键：完美性（没有孤立点）是两者分离的核心

**边界五：单连通 vs 道路连通**
- 单连通 = 道路连通 + 基本群平凡
- 临界案例：圆周 S¹（道路连通非单连通）
- 关键：基本群（闭曲线的同伦类）是两者分离的不变量

---

> **模块结语**：连通性是拓扑学中最基本的概念之一，它刻画了空间"不能被分成两块"的整体性质。从实数轴上的区间到复平面上的区域，从拓扑正弦曲线的精妙反例到 Cantor 集的完全不连通，连通性理论展示了数学中"整体与局部"的深刻张力。道路连通性作为连通性的构造性加强，在"好"的空间中与连通性重合，但在一般空间中存在深刻的鸿沟。掌握连通性，就掌握了分析学中"整体性"论证的钥匙——从介值定理到恒等定理，从 Riemann 映射定理到 Cantor 集的结构，无不以连通性为根基。
