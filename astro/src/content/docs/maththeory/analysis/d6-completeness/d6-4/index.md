## 第一章 引言：完备性的维度跃迁

### 1.1 从"点的完备"到"空间的完备"

D6-1 中我们建立了实数系的完备性：实数轴上的每一个 Cauchy 列都收敛到一个实数。这个结论的几何图像是"实数轴没有针孔"——任何一串越来越靠近的点，最终都会凝聚到轴上的某个实实在在的点。

但分析学的研究对象远不止实数。当我们研究复变函数时，"点"是复数；当我们研究实变函数和泛函分析时，"点"甚至可以是函数本身。完备性的概念必须随之升维：

- **L1 数分**：点是实数，完备性 = 实数轴无洞
- **L2 复变**：点是复数，完备性 = 复平面无洞
- **L3 实变/泛函**：点是函数，完备性 = 函数空间无洞

**📐 几何锚定**：完备性的升维在几何上是一个"空间尺度的放大"过程。实数完备性是一维直线上的"无针孔"；复数完备性是二维平面上的"无针孔"（平面上的 Cauchy 列就是一串越来越靠近的点，它们必然凝聚到平面上的某个点）；函数空间完备性则是无限维空间中的"无针孔"——把每个函数看作无限维空间中的一个"点"，Cauchy 列就是一串"越来越靠近"的函数，完备性意味着这串函数必然凝聚到空间中的某个"函数点"。这个升维不是平凡的：在无限维空间中，"有界"不再蕴含"紧"，完备性需要更精细的分析。

### 1.2 为什么函数空间的完备性重要

函数空间的完备性是整个现代分析学的基石。没有它，以下事情都无法成立：

1. **存在性证明**：微分方程的解、变分问题的极值、积分方程的解——这些存在性证明的核心技术是"构造 Cauchy 列 → 取极限"，而取极限的合法性依赖于空间的完备性。
2. **泛函分析的框架**：Banach 空间（完备的赋范线性空间）和 Hilbert 空间（完备的内积空间）是泛函分析的基本框架，没有完备性就没有 Banach 空间理论，没有 Hilbert 空间理论，也就没有现代 PDE、量子力学、信号处理。
3. **Lebesgue 积分的诞生**：Riemann 可积函数空间在 L¹ 范数下不完备，这是 Lebesgue 积分理论诞生的直接动机之一——完备化 Riemann 可积函数空间，得到的就是 Lebesgue 可积函数空间。

## 第二章 复数域的完备性

### 2.1 复数域作为度量空间

复数域 ℂ 上的标准度量是模长：对 z = x + iy, w = u + iv ∈ ℂ，定义
d(z, w) = |z - w| = √((x-u)² + (y-v)²)

这恰好是 ℝ² 上的欧氏度量。因此，作为度量空间，ℂ 与 ℝ² 等距同构。

**复数域的拓扑性质**：
- ℂ 是完备的度量空间（将在 2.2 证明）
- ℂ 是可分的（有理实部+有理虚部的复数可数稠密）
- ℂ 是局部紧的（每个点有紧邻域）
- ℂ 不是紧的（无界）
- ℂ 是连通的，甚至是道路连通的、单连通的

### 2.2 复数域完备性的证明

**定理**：复数域 ℂ 在模长度量下是完备的。

**证明**：设 {zₙ} 是 ℂ 中的 Cauchy 列。记 zₙ = xₙ + iyₙ，其中 xₙ, yₙ ∈ ℝ。

对任意 ε > 0，存在 N 使得当 m, n > N 时，|zₘ - zₙ| &lt; ε。

而 |zₘ - zₙ| = √((xₘ-xₙ)² + (yₘ-yₙ)²) ≥ |xₘ - xₙ|，同理 ≥ |yₘ - yₙ|。

因此 |xₘ - xₙ| &lt; ε 且 |yₘ - yₙ| &lt; ε，即 {xₙ} 和 {yₙ} 都是 ℝ 中的 Cauchy 列。

由实数的完备性（D6-1），存在 x, y ∈ ℝ 使得 xₙ → x, yₙ → y。

令 z = x + iy ∈ ℂ。则 |zₙ - z| = √((xₙ-x)² + (yₙ-y)²) ≤ |xₙ-x| + |yₙ-y| → 0。

因此 zₙ → z，ℂ 完备。∎

**📐 几何图像**：复数域完备性的证明在几何上极其直观——复平面上的 Cauchy 列就是一串"越来越挤在一起"的点。把每个点投影到 x 轴和 y 轴上，得到两个实数 Cauchy 列。实数轴没有针孔，所以这两个投影列分别凝聚到 x 轴和 y 轴上的某个点。这两个点"组合"起来就是复平面上的凝聚点。本质上，复平面的完备性是实数轴完备性在两个正交方向上的"乘积"——两个没有针孔的直线张成的平面也没有针孔。

### 2.3 复数域完备性的推论

**推论 1（复数列的 Bolzano-Weierstrass 定理）**：ℂ 中的有界数列必有收敛子列。

证明：有界复数列的实部和虚部都是有界实数列，由实数的 Bolzano-Weierstrass 定理，实部有收敛子列；在该子列中，虚部仍有界，再取收敛子列。得到的子列实部虚部都收敛，故复数列收敛。

**推论 2（ℂ 中的 Heine-Borel 定理）**：ℂ 中的子集是紧集，当且仅当它是有界闭集。

证明：ℂ≅ℝ²，由 ℝⁿ 中的 Heine-Borel 定理（D6-2）即得。

**推论 3（复数域的闭集完备性）**：ℂ 中的闭子集在子空间度量下是完备的。

证明：闭子集中的 Cauchy 列也是 ℂ 中的 Cauchy 列，由 ℂ 完备，收敛到 ℂ 中某点；又因子集闭，极限在子集内。

### 2.4 复数域与实数域的本质差异

虽然 ℂ 的完备性直接来自 ℝ，但复数域有一些实数域不具备的独特性质，这些性质与完备性结合，产生了复分析的强大理论：

1. **代数封闭性**：ℂ 是代数封闭域（代数基本定理），而 ℝ 不是。完备性 + 代数封闭性使得复分析中的许多存在性证明比实分析更简洁。
2. **方向自由度**：在 ℝ 中，极限只有两个方向（左和右）；在 ℂ 中，极限有无穷多个方向（可以沿任意曲线趋近）。这使得复可导（解析）成为极强的条件（D3-5）。
3. **共形结构**：ℂ 有自然的复结构，使得角度保持映射（共形映射）成为研究对象。完备性保证了共形映射的极限仍保持共形性（Weierstrass 定理，第四章）。

**📐 几何深化**：复数域完备性与实数域完备性的几何差异在于"维度"。实数轴是一维的，Cauchy 列的凝聚只能沿一个方向发生；复平面是二维的，Cauchy 列的凝聚可以在平面上的任意位置发生，点列可以沿螺旋线、折线、任意曲线趋近极限。但完备性的本质不变——"越来越挤的点列必然凝聚到某个点"，无论空间是一维还是二维。维度的增加不改变完备性的本质，但改变了"点"的结构和"收敛"的方式。

## 第三章 连续函数空间 C[a,b] 的完备性（sup 范数）

### 3.1 函数空间的基本概念

设 C[a,b] 表示闭区间 [a,b] 上所有连续实值函数的集合。这是一个线性空间（函数的加法和数乘）。

**sup 范数（一致范数）**：对 f ∈ C[a,b]，定义
||f||_∞ = sup_{x∈[a,b]} |f(x)|

由于 [a,b] 紧且 f 连续，sup 实际上是 max，即 ||f||_∞ = max_{x∈[a,b]} |f(x)|。

**验证范数三公理**：
1. 非负性：||f||_∞ ≥ 0，且 ||f||_∞ = 0 ⇔ f ≡ 0
2. 齐次性：||αf||_∞ = |α| ||f||_∞
3. 三角不等式：||f+g||_∞ ≤ ||f||_∞ + ||g||_∞

因此 (C[a,b], ||·||_∞) 是一个赋范线性空间，由范数诱导的度量为 d(f,g) = ||f-g||_∞ = sup |f(x)-g(x)|。

**📐 几何图像**：C[a,b] 在 sup 范数下的几何图像是"函数图像之间的最大垂直距离"。把每个连续函数想象成平面上的一条曲线。两个函数 f 和 g 的"距离"就是它们的图像之间的最大垂直间隙——||f-g||_∞ = max |f(x)-g(x)|。如果 ||f-g||_∞ &lt; ε，意味着 g 的图像完全落在 f 的图像上下各 ε 的"带形区域"内。sup 范数下的收敛就是"一致收敛"——函数图像整体越来越靠近，不允许在任何点上有大的偏差。

### 3.2 一致收敛的定义与性质

**定义**：函数列 {fₙ} ⊂ C[a,b] 一致收敛到 f，如果对任意 ε > 0，存在 N 使得当 n > N 时，对所有 x ∈ [a,b]，有 |fₙ(x) - f(x)| &lt; ε。

等价地：||fₙ - f||_∞ → 0。

**一致收敛 vs 逐点收敛**：
- 逐点收敛：对每个固定的 x，fₙ(x) → f(x)。N 可以依赖于 x。
- 一致收敛：对所有 x 同时成立。N 不依赖于 x。
- 一致收敛 ⇒ 逐点收敛，反之不成立。

**经典反例**：fₙ(x) = xⁿ 在 [0,1] 上逐点收敛到 f(x) = 0 (x&lt;1), f(1)=1，但不一致收敛（在 x 接近 1 时收敛越来越慢）。

### 3.3 C[a,b] 在 sup 范数下的完备性

**定理（C[a,b] 的完备性）**：赋范线性空间 (C[a,b], ||·||_∞) 是完备的，即 C[a,b] 中的每个 sup-Cauchy 列都一致收敛到某个连续函数。

**证明**：设 {fₙ} 是 C[a,b] 中的 Cauchy 列（关于 sup 范数）。

**第一步：逐点极限的存在性**
对任意固定的 x₀ ∈ [a,b]，有 |fₘ(x₀) - fₙ(x₀)| ≤ ||fₘ - fₙ||_∞。
因此 {fₙ(x₀)} 是 ℝ 中的 Cauchy 列。由实数完备性，存在 f(x₀) ∈ ℝ 使得 fₙ(x₀) → f(x₀)。
这样我们定义了一个函数 f : [a,b] → ℝ。

**第二步：一致收敛性**
对任意 ε > 0，存在 N 使得当 m, n > N 时，||fₘ - fₙ||_∞ &lt; ε/2。
即对所有 x ∈ [a,b]，|fₘ(x) - fₙ(x)| &lt; ε/2。
固定 n > N，令 m → ∞，得 |f(x) - fₙ(x)| ≤ ε/2 &lt; ε 对所有 x 成立。
因此 ||f - fₙ||_∞ ≤ ε/2 &lt; ε，即 fₙ 一致收敛到 f。

**第三步：f 的连续性**
需要证明 f ∈ C[a,b]。固定 x₀ ∈ [a,b]，对任意 ε > 0：
- 取 n 足够大使得 ||f - fₙ||_∞ &lt; ε/3
- 因 fₙ 连续，存在 δ > 0 使得当 |x - x₀| &lt; δ 时，|fₙ(x) - fₙ(x₀)| &lt; ε/3
- 则 |f(x) - f(x₀)| ≤ |f(x)-fₙ(x)| + |fₙ(x)-fₙ(x₀)| + |fₙ(x₀)-f(x₀)| &lt; ε/3 + ε/3 + ε/3 = ε

因此 f 在 x₀ 连续。由 x₀ 任意，f ∈ C[a,b]。∎

**📐 几何图像**：C[a,b] 完备性的证明在几何上是"函数图像带形区域的收缩"。Cauchy 列意味着，当 n 足够大时，所有 fₙ 的图像都落在彼此之间的一个 ε-带形区域内。这个带形区域随着 n→∞ 越来越窄，最终"收缩"到一条极限曲线 f 上。关键的第三步（极限函数连续）在几何上是"带形区域的边界是连续的"——因为每个 fₙ 都是连续曲线，而带形区域的宽度一致趋于零，所以极限曲线也必然是连续的，不会出现"断裂"或"跳跃"。这就是"一致收敛保持连续性"定理的几何本质。

### 3.4 完备性的意义：一致收敛的三大定理

C[a,b] 的完备性是以下三个经典定理的基础：

**定理 1（一致收敛保持连续性）**：若 fₙ ∈ C[a,b] 且 fₙ 一致收敛到 f，则 f ∈ C[a,b]。

这正是完备性证明的第三步。逐点收敛不保持连续性（fₙ(x)=xⁿ 的极限在 x=1 处不连续），但一致收敛保持。

**定理 2（一致收敛可逐项积分）**：若 fₙ ∈ C[a,b] 且 fₙ 一致收敛到 f，则
lim_{n→∞} ∫ₐᵇ fₙ(x)dx = ∫ₐᵇ f(x)dx = ∫ₐᵇ lim_{n→∞} fₙ(x)dx

证明：|∫fₙ - ∫f| ≤ ∫|fₙ-f| ≤ (b-a)||fₙ-f||_∞ → 0。

**定理 3（一致收敛可逐项求导的条件）**：若 fₙ ∈ C¹[a,b]，fₙ 逐点收敛到 f，且 fₙ' 一致收敛到 g，则 f ∈ C¹[a,b] 且 f' = g。

注意：这里需要的是导数列一致收敛，而不是函数列本身一致收敛。函数列只需要逐点收敛（实际上由中值定理可推出一致收敛）。

### 3.5 C[a,b] 的其他拓扑性质

**可分性**：C[a,b] 在 sup 范数下是可分的。Weierstrass 逼近定理说多项式在 C[a,b] 中稠密，而有理系数多项式可数，故 C[a,b] 可分。

**非自反性**：C[a,b] 不是自反的 Banach 空间。其对偶空间是 BV[a,b]（有界变差函数空间，Riesz 表示定理），二次对偶严格大于 C[a,b]。

**非一致凸性**：C[a,b] 的单位球不是严格凸的——单位球面上存在线段（例如 f(x)=1 和 g(x)=sign(x) 类的函数，但需要连续，所以用 f(x)=1 和 g(x)=1-2|x-1/2| 在 [0,1] 上，两者范数都是 1，中点范数也是 1）。

**📐 几何深化**：C[a,b] 的非自反性和非一致凸性在几何上反映了"连续函数空间的形状不规则"。Hilbert 空间（如 L²）的单位球是"圆润"的（一致凸），任何两个单位向量的中点严格在球内部。但 C[a,b] 的单位球有"平坦的面"——存在两个不同的连续函数，范数都是 1，它们的凸组合范数仍然是 1。这意味着 C[a,b] 中没有"唯一的最佳逼近"——给定点到子空间的最佳逼近可能不唯一。这与 Hilbert 空间中的投影定理（最佳逼近唯一）形成鲜明对比。

## 第四章 解析函数空间的完备性（Weierstrass 定理）

### 4.1 复分析中的函数空间

设 Ω ⊂ ℂ 是一个区域（连通开集）。记 H(Ω) 为 Ω 上所有全纯函数的集合。H(Ω) 是一个复线性空间。

H(Ω) 上的标准拓扑不是由单个范数诱导的，而是由"紧集上的一致收敛"（内闭一致收敛）诱导的局部凸拓扑。

**定义（内闭一致收敛）**：函数列 {fₙ} ⊂ H(Ω) 内闭一致收敛到 f，如果对 Ω 中的任意紧子集 K，fₙ 在 K 上一致收敛到 f。

等价地，对 Ω 的任意紧子集 K，||fₙ - f||_{K,∞} = sup_{z∈K} |fₙ(z) - f(z)| → 0。

**为什么不用单个 sup 范数**：在无界区域（如整个 ℂ）上，全纯函数可以无界（如 f(z)=z），sup 范数可能是无穷大。即使在有界区域上，全纯函数在边界附近可能无界（如 f(z)=1/(1-z) 在单位圆盘上）。因此需要用紧集上的 sup 范数来定义拓扑。

### 4.2 Weierstrass 定理

**定理（Weierstrass 解析函数列定理）**：设 Ω ⊂ ℂ 是区域，{fₙ} ⊂ H(Ω)。若 fₙ 在 Ω 上内闭一致收敛到函数 f，则 f ∈ H(Ω)，且对每个 k ≥ 1，fₙ^(k) 在 Ω 上内闭一致收敛到 f^(k)。

这是复分析中最深刻的定理之一，它说的是：**全纯函数列的内闭一致收敛极限仍然全纯，而且可以逐项求任意阶导数**。

**证明概要**：

**第一步：f 连续**
内闭一致收敛 ⇒ 在每个紧集上一致收敛 ⇒ 极限连续（由 C(K) 的完备性）。故 f 在 Ω 上连续。

**第二步：f 满足 Cauchy 积分公式**
对 Ω 中任意闭圆盘 D(z₀,r) ⊂ Ω，其边界 γ 是紧集。fₙ 在 γ 上一致收敛到 f，故
f(z₀) = lim fₙ(z₀) = lim (1/2πi) ∮_γ fₙ(ζ)/(ζ-z₀) dζ = (1/2πi) ∮_γ f(ζ)/(ζ-z₀) dζ
（积分与极限可交换，因为一致收敛）

**第三步：f 全纯**
由 Morera 定理（Cauchy 积分定理的逆定理）：若 f 连续且沿任意三角形的积分为零，则 f 全纯。由 Cauchy 积分公式可推出沿三角形积分为零，故 f 全纯。

**第四步：导数的内闭一致收敛**
由 Cauchy 高阶导数公式：
fₙ^(k)(z₀) = k!/(2πi) ∮_γ fₙ(ζ)/(ζ-z₀)^{k+1} dζ
fₙ 在 γ 上一致收敛 ⇒ 右端积分一致收敛 ⇒ fₙ^(k)(z₀) → f^(k)(z₀)
且收敛在紧集上一致。∎

**📐 几何图像**：Weierstrass 定理的几何图像是"全纯函数图像的刚性"。全纯函数的图像（作为 ℝ²→ℝ² 的映射）必须保持角度（共形性），不能随意变形。当一列全纯函数内闭一致收敛时，它们的图像在每个紧集上"整体靠近"极限图像。由于全纯函数的"刚性"（导数由 Cauchy 积分公式控制，不能随意振荡），这种"整体靠近"自动蕴含了导数的"整体靠近"——不仅函数图像靠近，图像的"斜率"（一阶导数）、"曲率"（二阶导数）、所有阶导数都一起靠近。这与实连续函数形成鲜明对比：实连续函数列一致收敛时，导数列可能完全不收敛（甚至不存在），因为实函数没有全纯函数的刚性。

### 4.3 Weierstrass 定理与实分析的对比

Weierstrass 定理在实分析中**没有直接对应物**。考虑以下对比：

| 性质 | 实连续函数 C[a,b] | 全纯函数 H(Ω) |
|---|---|---|
| 一致收敛极限 | 连续 | 全纯（更强！） |
| 可逐项求导 | 需要导数列一致收敛 | 自动成立（内闭一致收敛即可） |
| 导数列收敛 | 不保证 | 内闭一致收敛到极限的导数 |
| 根源 | 实函数无刚性 | 全纯函数有共形刚性 |

**经典实分析反例**：存在 C∞ 函数列 fₙ 一致收敛到 0，但 fₙ' 不一致收敛（甚至无界）。例如 fₙ(x) = sin(nx)/n 在 ℝ 上一致收敛到 0，但 fₙ'(x) = cos(nx) 不收敛。

在复分析中，这种情况不可能发生：如果全纯函数列内闭一致收敛到 0，那么它的所有阶导数也内闭一致收敛到 0。

### 4.4 完备性的精确表述

H(Ω) 在内闭一致收敛拓扑下是完备的：每个内闭一致 Cauchy 列都内闭一致收敛到某个全纯函数。

**定义（内闭一致 Cauchy 列）**：{fₙ} 称为内闭一致 Cauchy 列，如果对 Ω 的任意紧子集 K 和任意 ε > 0，存在 N 使得当 m,n > N 时，sup_{z∈K} |fₘ(z) - fₙ(z)| &lt; ε。

**定理**：H(Ω) 在内闭一致收敛拓扑下是完备的（Fréchet 空间）。

证明：内闭一致 Cauchy 列 ⇒ 在每个紧集上是 sup-Cauchy 列 ⇒ 由 C(K) 完备，在每个紧集上一致收敛到某个连续函数 ⇒ 这些极限函数在紧集的重叠处一致（由唯一性）⇒ 拼成 Ω 上的连续函数 f ⇒ 由 Weierstrass 定理，f 全纯。

### 4.5 应用：正规族与 Montel 定理

Weierstrass 定理的完备性是 Montel 定理（D6-2 中讨论的紧性定理）的基础。

**定义（正规族）**：H(Ω) 中的函数族 F 称为正规族，如果 F 中的每个序列都有内闭一致收敛的子列。

**Montel 定理**：若 F ⊂ H(Ω) 在 Ω 的每个紧集上一致有界，则 F 是正规族。

Montel 定理是 Arzelà-Ascoli 定理在全纯函数空间中的特殊形式。全纯函数的刚性使得"一致有界"自动蕴含"等度连续"（由 Cauchy 积分公式估计导数），因此 Arzelà-Ascoli 的条件自动满足。

**完备性 + 紧性 = 存在性**：正规族（紧性）保证了子列的存在性，Weierstrass 定理（完备性）保证了子列的极限仍在 H(Ω) 中。两者结合，是复分析中许多存在性证明的核心技术（如 Riemann 映射定理的证明）。

## 第五章 不完备的函数空间

### 5.1 C[a,b] 在 Lp 范数下的不完备性

C[a,b] 上除了 sup 范数，还可以定义 Lp 范数：
||f||_p = (∫ₐᵇ |f(x)|^p dx)^{1/p}, 1 ≤ p &lt; ∞

**定理**：(C[a,b], ||·||_p) 对 1 ≤ p &lt; ∞ 是不完备的。

**证明（构造 Cauchy 列不收敛到连续函数）**：

考虑 [0,1] 上的连续函数列：
fₙ(x) = 
- 0, 0 ≤ x ≤ 1/2 - 1/n
- n(x - 1/2 + 1/n), 1/2 - 1/n &lt; x &lt; 1/2 + 1/n
- 1, x ≥ 1/2 + 1/n

这是一个从 0 线性过渡到 1 的连续函数，过渡区间宽度为 2/n，中心在 x=1/2。

**第一步：{fₙ} 是 Lp-Cauchy 列**
对 m > n，fₘ 和 fₙ 只在 [1/2-1/n, 1/2+1/n] 上不同（因为 m > n 时 fₘ 的过渡区间更窄，包含在 fₙ 的过渡区间内）。
在这个区间上，|fₘ - fₙ| ≤ 1，区间长度为 2/n。
因此 ||fₘ - fₙ||_p^p = ∫|fₘ-fₙ|^p ≤ 2/n → 0 (n→∞)。
故 {fₙ} 是 Lp-Cauchy 列。

**第二步：{fₙ} 在 Lp 意义下收敛到不连续函数**
fₙ 逐点收敛到 Heaviside 阶跃函数：
f(x) = 0 (x &lt; 1/2), f(x) = 1 (x ≥ 1/2)
且 ||fₙ - f||_p^p = ∫|fₙ-f|^p ≤ 2/n → 0。
所以 fₙ 在 Lp 范数下收敛到 f。

**第三步：f 不连续，且不存在连续函数 g 使得 ||fₙ - g||_p → 0**
如果存在连续 g 使得 ||fₙ - g||_p → 0，则由 ||f-g||_p ≤ ||f-fₙ||_p + ||fₙ-g||_p → 0，得 ||f-g||_p = 0，即 f = g a.e.。
但 f 在 x=1/2 处有跳跃，任何 a.e. 等于 f 的函数在 x=1/2 附近必然有跳跃（除非在一个正测度集上改变值，但那样就不等于 f a.e. 了），不可能连续。
更严格地：若 g 连续且 g=f a.e.，则 g(1/2⁻)=0, g(1/2⁺)=1，与连续性矛盾。

因此 (C[a,b], ||·||_p) 不完备。∎

**📐 几何图像**：C[a,b] 在 Lp 范数下不完备的几何图像是"函数图像可以出现越来越陡的跳跃"。Lp 范数度量的是函数图像与 x 轴之间的"面积差"（p=1 时就是面积，p>1 时是加权面积）。一个连续函数可以在一个越来越窄的区间内从 0 快速过渡到 1——这个过渡区间的面积趋于零，所以在 Lp 意义下函数列"收敛"到一个有跳跃的阶跃函数。但阶跃函数不连续，不在 C[a,b] 中。几何上，这就像 C[a,b] 这个"空间"在 Lp 范数下有"针孔"——阶跃函数就是一个针孔，连续函数列可以"挤向"这个针孔，但针孔本身不在空间内。

### 5.2 多项式空间在 sup 范数下的不完备性

设 P[a,b] 表示 [a,b] 上所有多项式函数的集合。P[a,b] ⊂ C[a,b]，在 sup 范数下是 C[a,b] 的子空间。

**定理**：(P[a,b], ||·||_∞) 不完备。

**证明**：Weierstrass 逼近定理说 P[a,b] 在 C[a,b] 中稠密。取一个非多项式的连续函数 f ∈ C[a,b] \ P[a,b]（如 f(x)=e^x 或 f(x)=|x-1/2|）。由稠密性，存在多项式列 pₙ 使得 ||pₙ - f||_∞ → 0。收敛列必为 Cauchy 列，故 {pₙ} 是 P[a,b] 中的 sup-Cauchy 列。但 pₙ 在 sup 范数下的极限是 f，而 f 不是多项式，不在 P[a,b] 中。故 P[a,b] 不完备。∎

**📐 几何图像**：多项式空间不完备的几何图像是"多项式曲线可以逼近任意连续曲线，但极限曲线不一定是多项式"。多项式的图像是"代数曲线"——由有限次幂的线性组合构成，形状受代数结构限制。但多项式列可以一致逼近任意连续曲线（Weierstrass 定理），这意味着多项式曲线可以"无限靠近"非多项式的连续曲线。非多项式连续曲线就是多项式空间中的"针孔"——多项式列可以挤向它，但它不在多项式空间内。P[a,b] 的完备化就是 C[a,b]（在 sup 范数下）。

### 5.3 C¹[a,b] 在 C⁰ 范数下的不完备性

设 C¹[a,b] 表示 [a,b] 上连续可微函数的集合。在 sup 范数（只看函数值，不看导数）下：

**定理**：(C¹[a,b], ||·||_∞) 不完备。

**证明**：取 fₙ(x) = √(x² + 1/n²) 在 [-1,1] 上。每个 fₙ ∈ C¹（导数 fₙ'(x) = x/√(x²+1/n²) 连续）。fₙ 一致收敛到 f(x)=|x|，但 |x| 在 x=0 处不可导，不在 C¹ 中。故不完备。∎

**几何图像**：C¹ 函数的图像是"光滑曲线"（没有尖点）。但光滑曲线列可以一致收敛到有尖点的曲线（如 |x|）。有尖点的曲线就是 C¹ 空间在 C⁰ 范数下的"针孔"。

### 5.4 不完备空间的共同特征

以上三个不完备空间有一个共同特征：**它们都是某个更大完备空间的稠密真子空间**。

| 不完备空间 | 范数 | 完备化 | 针孔的本质 |
|---|---|---|---|
| C[a,b] | Lp | Lp[a,b] | 不连续函数（有跳跃/尖点） |
| P[a,b] | sup | C[a,b] | 非多项式连续函数 |
| C¹[a,b] | sup | C[a,b] | 连续但不可微函数 |
| Riemann 可积 | L¹ | L¹[a,b] | Lebesgue 可积但非 Riemann 可积函数 |

**核心洞察**：不完备性总是源于"空间的定义条件太强"——C[a,b] 要求连续，P[a,b] 要求多项式，C¹ 要求可微，Riemann 可积要求几乎处处连续。这些强条件排除了一些"极限函数"，而这些极限函数就是空间的"针孔"。完备化就是把这些针孔填上——放宽条件，把极限函数也包含进来。

## 第六章 Riemann 可积函数空间的不完备性

### 6.1 Riemann 可积函数空间

设 R[a,b] 表示 [a,b] 上所有 Riemann 可积函数的集合。在 L¹ 范数 ||f||₁ = ∫ₐᵇ |f(x)|dx 下，R[a,b] 是一个赋范线性空间（需要把 a.e. 相等的函数视为同一元素，否则 ||f||₁=0 不蕴含 f=0）。

**Riemann 可积的 Lebesgue 准则**：f 在 [a,b] 上 Riemann 可积，当且仅当 f 有界且不连续点集的测度为零。

### 6.2 R[a,b] 在 L¹ 范数下的不完备性

**定理**：(R[a,b], ||·||₁) 不完备。

**证明（利用 Cantor 集构造）**：

设 C 是 [0,1] 中的标准 Cantor 集（测度为 0，不可数，完全不连通，完美）。

**第一步：构造开集列**
Cantor 集的构造过程中，第 n 步去掉 2^{n-1} 个开区间，记这些开区间的并为 Uₙ。则 Uₙ 是开集，m(Uₙ) = 1 - (2/3)^n。

令 Gₙ = U₁ ∪ U₂ ∪ ... ∪ Uₙ = Uₙ（因为 Uₙ 递增）。则 Gₙ 是开集，m(Gₙ) = 1 - (2/3)^n。

**第二步：构造连续函数列**
令 fₙ(x) = dist(x, Gₙ^c) / (dist(x, Gₙ^c) + dist(x, C))，其中 dist(x, A) = inf_{y∈A} |x-y|。

fₙ 是连续函数（距离函数连续），且：
- 在 Gₙ 上，dist(x, Gₙ^c) > 0，dist(x, C) 可能为 0（如果 x∈C∩Gₙ，但 C∩Gₙ=∅，因为 Gₙ 是去掉的区间的并），所以 fₙ(x) = 1
- 在 C 上，dist(x, C)=0，所以 fₙ(x)=0
- 在其他地方，0 &lt; fₙ(x) &lt; 1

实际上更简单的构造：令 fₙ 是 Gₙ 的特征函数的连续逼近。但为了严格，我们用以下构造：

令 fₙ(x) = 1 - (3/2)^n · dist(x, C)，当 dist(x,C) ≤ (2/3)^n 时；否则 fₙ(x)=0。不对，这也不够简洁。

让我用更标准的构造：

考虑 [0,1] 中的有理数集 ℚ∩[0,1] = {r₁, r₂, ...}（可数）。对每个 n，定义
fₙ(x) = 1 如果 x ∈ {r₁, ..., rₙ}，否则 fₙ(x) = 0。

每个 fₙ 只有有限个不连续点，故 Riemann 可积。fₙ 逐点收敛到 Dirichlet 函数 D(x)（有理点为 1，无理点为 0）。

||fₘ - fₙ||₁ = ∫|fₘ-fₙ| = 0（因为只在有限个点上不同，积分值为 0）。所以 {fₙ} 是 L¹-Cauchy 列（实际上是 L¹-常数列，范数差恒为 0）。

但 fₙ 在 L¹ 意义下"收敛"到 Dirichlet 函数 D(x)，而 D(x) 处处不连续，不 Riemann 可积。

更严格地：如果存在 g ∈ R[0,1] 使得 ||fₙ - g||₁ → 0，则 ||D - g||₁ ≤ ||D-fₙ||₁ + ||fₙ-g||₁ = 0 + 0 = 0（因为 ||D-fₙ||₁ = ∫|D-fₙ| = 0，只在有限个点不同），所以 D=g a.e.。但 D 处处不连续，任何 a.e. 等于 D 的函数也处处不连续（因为在任何点的任何邻域内都有有理点和无理点，函数值在 0 和 1 之间跳跃），不可能 Riemann 可积。矛盾。

因此 R[0,1] 在 L¹ 范数下不完备。∎

**📐 几何图像**：Riemann 可积函数空间不完备的几何图像是"几乎处处连续的函数列可以收敛到处处不连续的函数"。Riemann 可积要求不连续点集测度为零——这是一个"几乎处处连续"的条件。但有限个不连续点的函数列（阶梯函数）可以在 L¹ 意义下收敛到处处不连续的 Dirichlet 函数。Dirichlet 函数的图像是"两条虚线"——有理点上 y=1，无理点上 y=0，图像在任何区间内都在 0 和 1 之间无限跳跃。这个函数就是 Riemann 可积空间的"针孔"——Riemann 可积函数列可以挤向它，但它本身不在空间内。完备化 Riemann 可积空间，得到的就是 Lebesgue 可积函数空间——Dirichlet 函数是 Lebesgue 可积的（积分值为 0，因为有理点集测度为 0）。

### 6.3 不完备性是 Lebesgue 积分的直接动机

R[a,b] 在 L¹ 范数下的不完备性，是 Lebesgue 积分理论诞生的核心动机之一。

**历史背景**：19 世纪末，数学家们发现 Riemann 积分有两个严重缺陷：
1. **可积函数类太窄**：Dirichlet 函数等处处不连续函数不可积
2. **极限与积分交换条件苛刻**：需要一致收敛才能逐项积分

Lebesgue 在 1902 年的博士论文中提出了新的积分理论，其核心创新是"分割值域而非定义域"：
- Riemann 积分：分割定义域 [a,b]，在每个小区间上取样本点
- Lebesgue 积分：分割值域 [0,M]，考虑 f(x) 落在每个值区间内的 x 的集合的测度

**Lebesgue 积分的优势**：
1. **可积函数类更广**：所有有界可测函数都可积，包括 Dirichlet 函数
2. **极限交换自由**：单调收敛定理、Fatou 引理、控制收敛定理——只需要很弱的条件
3. **空间完备**：L¹[a,b]（Lebesgue 可积函数空间）在 L¹ 范数下完备

**核心定理（Riesz-Fischer 定理的 L¹ 版本）**：L¹[a,b] 在 L¹ 范数下是完备的 Banach 空间。

这个定理将在 D6-5 中详细证明。这里只需指出：L¹[a,b] 正是 R[a,b] 在 L¹ 范数下的完备化。

### 6.4 Riemann 可积与 Lebesgue 可积的关系

**定理**：若 f 在 [a,b] 上 Riemann 可积，则 f 在 [a,b] 上 Lebesgue 可积，且两个积分值相等。

**证明**：Riemann 可积 ⇒ f 有界且 a.e. 连续 ⇒ f 可测（a.e. 连续函数可测）⇒ 有界可测 ⇒ Lebesgue 可积。积分值相等由达布和与 Lebesgue 积分的关系证明。

**逆命题不成立**：Lebesgue 可积不一定 Riemann 可积。反例：Dirichlet 函数 D(x)（有理点 1，无理点 0）Lebesgue 可积（积分=0），但不 Riemann 可积（处处不连续）。

**📐 几何深化**：Riemann 可积函数空间是 Lebesgue 可积函数空间的稠密子空间。简单函数（有限个值的可测函数）在 Lp 中稠密，而简单函数可以用阶梯函数（Riemann 可积）逼近，阶梯函数又可以用连续函数逼近。所以 C[a,b] ⊂ R[a,b] ⊂ Lp[a,b]，且 C[a,b] 在 Lp[a,b] 中稠密。几何上，Lp[a,b] 是一个"大空间"，C[a,b] 和 R[a,b] 是它的"稠密子集"——就像有理数是实数的稠密子集一样。Lp 空间的完备性，正是通过把 C[a,b] 和 R[a,b] 的"针孔"（不连续函数、不可测函数）填上得到的。

## 第七章 函数空间完备化的一般理论

### 7.1 度量空间完备化定理

**定理（度量空间完备化）**：任何度量空间 (X, d) 都可以等距嵌入一个完备度量空间 (X̃, d̃) 中，且 X 在 X̃ 中稠密。X̃ 在等距同构意义下唯一，称为 X 的完备化。

**构造方法（Cantor 基本列法）**：

**第一步：定义 Cauchy 列等价类**
设 X 中的所有 Cauchy 列构成集合 C(X)。在 C(X) 上定义等价关系：
{xₙ} ~ {yₙ} ⇔ lim_{n→∞} d(xₙ, yₙ) = 0

令 X̃ = C(X)/~（所有等价类的集合）。

**第二步：定义 X̃ 上的度量**
对 [{xₙ}], [{yₙ}] ∈ X̃，定义
d̃([{xₙ}], [{yₙ}]) = lim_{n→∞} d(xₙ, yₙ)

需要验证：
- 极限存在：|d(xₘ,yₘ) - d(xₙ,yₙ)| ≤ d(xₘ,xₙ) + d(yₘ,yₙ) → 0，故 {d(xₙ,yₙ)} 是实数 Cauchy 列，由实数完备性收敛
- 与代表元选取无关：若 {xₙ}~{xₙ'}, {yₙ}~{yₙ'}，则 |d(xₙ,yₙ)-d(xₙ',yₙ')| ≤ d(xₙ,xₙ')+d(yₙ,yₙ') → 0
- 满足度量三公理

**第三步：等距嵌入**
定义映射 i : X → X̃，i(x) = [{x, x, x, ...}]（常值列的等价类）。
则 d̃(i(x), i(y)) = lim d(x,y) = d(x,y)，故 i 是等距嵌入。

**第四步：X 在 X̃ 中稠密**
对任意 [{xₙ}] ∈ X̃，考虑 i(xₙ) ∈ X̃。则
d̃(i(xₙ), [{xₙ}]) = lim_{m→∞} d(xₙ, xₘ) → 0 (n→∞)
因为 {xₙ} 是 Cauchy 列。故 i(X) 在 X̃ 中稠密。

**第五步：X̃ 完备**
设 {ξₙ} 是 X̃ 中的 Cauchy 列。每个 ξₙ = [{xₙₖ}]ₖ。由稠密性，取 yₙ ∈ X 使得 d̃(ξₙ, i(yₙ)) &lt; 1/n。则 {yₙ} 是 X 中的 Cauchy 列（因为 d(yₘ,yₙ) = d̃(i(yₘ),i(yₙ)) ≤ d̃(i(yₘ),ξₘ)+d̃(ξₘ,ξₙ)+d̃(ξₙ,i(yₙ)) → 0）。令 ξ = [{yₙ}] ∈ X̃，则 d̃(ξₙ, ξ) ≤ d̃(ξₙ,i(yₙ)) + d̃(i(yₙ),ξ) → 0。故 X̃ 完备。∎

**📐 几何图像**：度量空间完备化的几何图像是"给有针孔的空间填补针孔"。每个 Cauchy 列代表一个"指向针孔的逼近序列"——它在空间中越来越挤，但极限不在空间内（因为是针孔）。把所有"指向同一个针孔"的 Cauchy 列归为一类，这个等价类就代表了那个针孔的位置。通过把所有等价类都加进来，我们填补了所有的针孔，得到一个没有针孔的完备空间。这个构造与从 ℚ 构造 ℝ 的 Cantor 基本列法完全一致（D6-1 第六章），只是把"有理数 Cauchy 列"换成了"任意度量空间中的 Cauchy 列"。

### 7.2 赋范空间的完备化

若 (X, ||·||) 是赋范线性空间，则其完备化 X̃ 也是赋范线性空间（Banach 空间）。

线性运算的定义：对 [{xₙ}], [{yₙ}] ∈ X̃ 和 α ∈ 𝕂，
[{xₙ}] + [{yₙ}] = [{xₙ + yₙ}]
α[{xₙ}] = [{αxₙ}]

需要验证这些定义与代表元选取无关，且满足线性空间公理。范数定义为 ||[{xₙ}]|| = lim ||xₙ||。

完备的赋范线性空间称为 **Banach 空间**。

### 7.3 内积空间的完备化

若 (X, ⟨·,·⟩) 是内积空间，则其完备化 X̃ 也是内积空间（Hilbert 空间）。

内积的定义：⟨[{xₙ}], [{yₙ}]⟩ = lim ⟨xₙ, yₙ⟩。

完备的内积空间称为 **Hilbert 空间**。

**经典例子**：
- C[a,b] 在 L² 内积 ⟨f,g⟩ = ∫fg 下的完备化是 L²[a,b]（Hilbert 空间）
- 有理数 ℚ 在标准内积下的完备化是 ℝ（Hilbert 空间，一维）
- 多项式空间 P 在 L² 内积下的完备化是 L²[a,b]

### 7.4 完备化的泛性质

**定理（完备化的泛性质）**：设 X 是度量空间，X̃ 是其完备化，i : X → X̃ 是等距嵌入。对任何完备度量空间 Y 和任何一致连续映射 f : X → Y，存在唯一的连续映射 f̃ : X̃ → Y 使得 f̃ ∘ i = f。

即 f 可以唯一地延拓到完备化上。

**证明**：对 ξ = [{xₙ}] ∈ X̃，定义 f̃(ξ) = lim f(xₙ)。因为 f 一致连续，{f(xₙ)} 是 Y 中的 Cauchy 列（d(f(xₘ),f(xₙ)) ≤ ω(d(xₘ,xₙ)) → 0，其中 ω 是 f 的连续模），由 Y 完备，极限存在。唯一性和连续性由一致连续性保证。∎

**意义**：完备化不仅填补了针孔，还使得所有一致连续映射都可以延拓到完备化上。这是泛函分析中许多"延拓定理"的基础。

## 第八章 反例库

### 反例 1：C[0,1] 在 L¹ 范数下的 Cauchy 列不收敛到连续函数

构造：fₙ(x) = 0 (x ≤ 1/2-1/n), fₙ(x) = n(x-1/2+1/n) (1/2-1/n &lt; x &lt; 1/2+1/n), fₙ(x) = 1 (x ≥ 1/2+1/n)。
Cauchy 列，L¹ 收敛到阶跃函数（不连续）。
意义：C[a,b] 在 Lp 范数下不完备。

### 反例 2：多项式空间在 sup 范数下的 Cauchy 列不收敛到多项式

构造：e^x 的 Taylor 多项式部分和 pₙ(x) = Σ_{k=0}^n x^k/k!。
pₙ 在 [0,1] 上一致收敛到 e^x，但 e^x 不是多项式。
意义：P[a,b] 在 sup 范数下不完备，完备化为 C[a,b]。

### 反例 3：C¹ 函数列一致收敛到不可微函数

构造：fₙ(x) = √(x²+1/n²) 在 [-1,1] 上。
fₙ ∈ C¹，一致收敛到 |x|，但 |x| 在 x=0 不可导。
意义：C¹[a,b] 在 sup 范数下不完备。

### 反例 4：Riemann 可积函数列 L¹ 收敛到不可积函数

构造：fₙ(x) = 1 如果 x ∈ {r₁,...,rₙ}，否则 0（rₙ 是有理数枚举）。
每个 fₙ Riemann 可积（有限个不连续点），L¹ 收敛到 Dirichlet 函数（处处不连续，不可积）。
意义：R[a,b] 在 L¹ 范数下不完备，完备化为 L¹[a,b]。

### 反例 5：逐点收敛但不一致收敛的连续函数列

构造：fₙ(x) = xⁿ 在 [0,1] 上。
逐点收敛到 f(x)=0 (x&lt;1), f(1)=1（不连续）。
不一致收敛。
意义：逐点收敛不保持连续性，需要一致收敛。

### 反例 6：一致收敛但导数列不收敛的 C∞ 函数列

构造：fₙ(x) = sin(nx)/n 在 ℝ 上。
fₙ 一致收敛到 0，但 fₙ'(x) = cos(nx) 不收敛。
意义：实函数一致收敛不保证导数收敛；全纯函数则自动保证（Weierstrass 定理）。

### 反例 7：Lp 空间中 Cauchy 列不逐点收敛

构造：在 L¹[0,1] 中，考虑"滑动区间"特征函数列：
f₁ = χ_{[0,1]}, f₂ = χ_{[0,1/2]}, f₃ = χ_{[1/2,1]}, f₄ = χ_{[0,1/4]}, f₅ = χ_{[1/4,1/2]}, ...
||fₙ||₁ → 0，故 fₙ → 0 在 L¹ 中。但对每个 x ∈ [0,1]，fₙ(x) 无限次取 1（因为包含 x 的区间无限次出现），所以 fₙ(x) 不逐点收敛到 0。
意义：Lp 收敛不蕴含逐点收敛；但存在子列几乎处处收敛（Riesz 定理）。

### 反例 8：有界但不全有界的集合（无限维空间）

构造：在 C[0,1] 的 sup 范数下，单位球 {f : ||f||∞ ≤ 1} 有界但不全有界。
取 fₙ(x) = sin(2πnx)，则 ||fₙ||∞ = 1，但 ||fₘ - fₙ||∞ = 2 (m≠n)（在某些点上 sin 取 1 和 -1）。所以单位球不能被有限个 1-球覆盖。
意义：无限维空间中有界不蕴含全有界，Heine-Borel 定理不成立。

### 反例 9：完备空间中的非闭子集不完备

构造：(0,1) 作为 ℝ 的子空间。ℝ 完备，但 (0,1) 不完备（Cauchy 列 1/n 收敛到 0，不在 (0,1) 中）。
意义：完备空间的子集完备当且仅当它是闭集。

### 反例 10：离散度量空间的完备性

构造：任何集合 X 配离散度量 d(x,y)=1 (x≠y)。
离散度量空间是完备的（Cauchy 列最终是常值列）。
但离散度量空间如果是无限的，就不是紧的（开覆盖 {{x} : x∈X} 没有有限子覆盖）。
意义：完备性和紧性是独立的概念；紧⇒完备，但完备⇏紧。

## 第九章 历史演进

### 9.1 实数完备性的确立（1850-1872）

- **1817**：Bolzano 首次给出了序列收敛的严格定义（ε-N 语言的雏形），并证明了有界数列有收敛子列（Bolzano-Weierstrass 定理）。
- **1821**：Cauchy 在《分析教程》中给出了 Cauchy 收敛准则，但没有证明其充分性（因为实数的严格构造尚未建立）。
- **1854**：Riemann 在就职论文中定义了 Riemann 积分，提出了可积性问题。
- **1872**：这一年被称为"分析算术化之年"。Dedekind 发表《连续性与无理数》，提出 Dedekind 分割；Cantor 发表基本列构造法；Heine 发表区间套定理。实数的严格构造完成，完备性六定理的等价性确立。

### 9.2 一致收敛概念的出现（1841-1870）

- **1841**：Weierstrass 在一篇未发表的论文中首次使用了一致收敛的概念。
- **1848**：Seidel 独立发现了一致收敛的概念，并指出逐点收敛不保持连续性。
- **1853**：Cauchy 修正了他之前关于"连续函数列的和连续"的错误断言，引入了一致收敛的条件。
- **1870s**：Weierstrass 在柏林大学的讲座中系统发展了一致收敛理论，包括 Weierstrass 逼近定理（1885）和 Weierstrass 解析函数列定理。

### 9.3 函数空间概念的诞生（1880-1910）

- **1885**：Weierstrass 逼近定理：多项式在 C[a,b] 中稠密。这是函数空间拓扑性质的第一个深刻结果。
- **1889**：Peano 构造了填满空间的曲线，挑战了"维度"的直观概念。
- **1897**：Borel 在博士论文中引入了 Heine-Borel 定理的现代形式。
- **1906**：Fréchet 在博士论文中引入了度量空间的抽象概念，定义了完备性、紧性、可分性等拓扑性质。这是泛函分析的诞生标志。
- **1907**：Riesz 和 Fischer 独立证明了 L² 空间的完备性（Riesz-Fischer 定理），建立了 Hilbert 空间理论的基础。
- **1910**：Riesz 引入了 Lp 空间（1 &lt; p &lt; ∞），证明了其完备性和对偶性。

### 9.4 Lebesgue 积分与完备化（1902-1930）

- **1902**：Lebesgue 发表博士论文《积分、长度与面积》，建立了测度和积分的新理论。Lebesgue 积分的直接动机之一就是 Riemann 可积函数空间在 L¹ 范数下的不完备性。
- **1907**：Riesz-Fischer 定理：L² 完备。
- **1910**：Riesz 证明 Lp 完备（1 &lt; p &lt; ∞）。
- **1918**：Riesz 引入了紧算子的概念。
- **1922**：Banach 在博士论文中系统建立了 Banach 空间理论（完备的赋范线性空间）。
- **1927**：Hahn 和 Banach 独立证明了 Hahn-Banach 延拓定理。
- **1929**：Banach 引入了对偶空间和弱拓扑。
- **1932**：Banach 出版《线性算子理论》，标志着泛函分析成为独立学科。

### 9.5 复分析中函数空间理论的发展（1900-1950）

- **1907**：Montel 引入正规族概念，证明了 Montel 定理（一致有界全纯函数族是正规族）。
- **1912**：Carathéodory 用正规族理论给出了 Riemann 映射定理的简洁证明。
- **1920s**：Hardy 空间 H^p 理论开始发展（Hardy 1915, Riesz 1923）。
- **1930s**：F. Riesz 和 M. Riesz 兄弟系统发展了 Hardy 空间理论。
- **1940s**：Beurling 引入了不变子空间理论，Hardy 空间成为算子理论的核心框架。

### 10.2 完备性的升维链

```
ℚ 不完备
  ↓ Dedekind 分割 / Cantor 基本列
ℝ 完备（一维）
  ↓ 乘积（实部+虚部）
ℂ 完备（二维）
  ↓ 函数作为点（sup 范数）
C[a,b] 完备（无限维，sup 拓扑）
  ↓ 换范数（Lp 范数）
C[a,b] 不完备（Lp 拓扑）
  ↓ 完备化（Cauchy 列等价类）
Lp[a,b] 完备（Banach 空间）
  ↓ p=2 时加内积
L²[a,b] 完备（Hilbert 空间）
```

### 10.3 关键蜕变问题

**问题 1：为什么 C[a,b] 在 sup 范数下完备，但在 Lp 范数下不完备？**

回答：sup 范数要求函数图像"整体靠近"，不允许在任何点上有大偏差。这种强拓扑下，连续函数列的极限必然连续（因为连续性是"局部"性质，而 sup 收敛是"全局"控制，全局控制保证了局部的连续性）。Lp 范数只要求"面积差"趋于零，允许在越来越窄的区间上有大偏差（跳跃）。这种弱拓扑下，连续函数列的极限可以有跳跃，不连续。拓扑越强，完备性越容易成立（因为 Cauchy 条件更强，极限更"好"）；拓扑越弱，完备性越难成立。

**问题 2：为什么全纯函数列的内闭一致收敛极限仍然全纯？**

回答：全纯函数有"刚性"——由 Cauchy 积分公式，全纯函数的所有阶导数都由边界值控制。内闭一致收敛意味着在每个紧集（包括其边界）上函数值一致靠近，由 Cauchy 积分公式，导数也一致靠近。因此极限函数满足 Cauchy 积分公式，从而全纯。实连续函数没有这种刚性——导数不由函数值控制，所以一致收敛不保证导数收敛。

**问题 3：为什么 Lebesgue 积分能使 Lp 空间完备？**

回答：Lebesgue 积分的核心创新是"分割值域而非定义域"，这使得可积函数类大大扩展（所有可测函数，只要积分有限）。特别是，Lebesgue 积分允许函数在零测集上"任意行为"——Dirichlet 函数在有理点上为 1，但有理点集测度为零，所以积分值为 0。这种"忽略零测集"的特性，使得 Lp 空间中的 Cauchy 列的极限总是可测函数（可测函数列的极限可测），从而在 Lp 中。Riemann 积分要求 a.e. 连续，这个条件在极限运算下不保持（a.e. 连续函数列的极限可以处处不连续），所以 Riemann 可积空间不完备。

**问题 4：完备化为什么总是可能的？**

回答：完备化的构造（Cauchy 列等价类法）是纯代数/拓扑的，不依赖空间的具体性质。任何度量空间中的 Cauchy 列都代表一个"潜在的极限点"，把所有潜在极限点加进来就得到完备化。这个构造的代价是：完备化空间中的元素可能是抽象的（等价类），不一定有直观的"点"的解释。例如，Lp 空间中的元素是函数的等价类（a.e. 相等的函数视为同一元素），而不是具体的函数。

## 第十一章 收敛沉淀

### 11.1 核心定理清单

1. **复数域完备性**：ℂ 在模长度量下完备（实部虚部分别收敛）
2. **C[a,b] 完备性**：(C[a,b], ||·||∞) 是 Banach 空间
3. **Weierstrass 定理**：全纯函数列内闭一致收敛 ⇒ 极限全纯且可逐项求导
4. **H(Ω) 完备性**：H(Ω) 在内闭一致收敛拓扑下是 Fréchet 空间
5. **C[a,b] 在 Lp 下不完备**：1 ≤ p &lt; ∞
6. **P[a,b] 在 sup 下不完备**：完备化为 C[a,b]
7. **R[a,b] 在 L¹ 下不完备**：完备化为 L¹[a,b]
8. **度量空间完备化定理**：任何度量空间可等距嵌入完备空间，且唯一
9. **Riesz-Fischer 定理（L¹ 版本）**：L¹[a,b] 完备（D6-5 详细证明）
10. **Weierstrass 逼近定理**：多项式在 C[a,b] 中稠密

### 11.2 方法论沉淀

**完备性证明的标准方法**：
1. 取 Cauchy 列
2. 逐点/逐坐标取极限（利用更基础空间的完备性）
3. 证明极限在空间内（验证空间的定义条件）
4. 证明收敛是在原拓扑/范数下的（不是更弱的收敛）

**不完备性证明的标准方法**：
1. 构造一个 Cauchy 列
2. 证明它在更弱的意义下收敛到某个"极限函数"
3. 证明这个极限函数不在原空间中（不满足空间的定义条件）
4. 证明不存在原空间中的元素是该 Cauchy 列的极限

**完备化的标准构造**：
1. 取所有 Cauchy 列
2. 定义等价关系（极限距离为零）
3. 等价类作为新空间的元素
4. 延拓度量/范数/内积
5. 验证完备性

### 11.3 常见误区

**误区一：完备性是空间的内在性质，与度量无关**
澄清：完备性依赖于度量。同一个集合，不同的度量可以有不同的完备性。例如 C[a,b] 在 sup 范数下完备，在 Lp 范数下不完备。

**误区二：完备空间的子空间也完备**
澄清：完备空间的闭子空间完备，但非闭子空间不完备。例如 ℝ 完备，但 (0,1) 不完备。

**误区三：紧空间一定完备，完备空间一定紧**
澄清：紧⇒完备（度量空间中），但完备⇏紧。反例：ℝ 完备但不紧。

**误区四：逐点收敛的连续函数列极限连续**
澄清：需要一致收敛。反例：fₙ(x)=xⁿ 在 [0,1] 上逐点收敛到不连续函数。

**误区五：全纯函数列逐点收敛极限全纯**
澄清：需要内闭一致收敛。逐点收敛不够（可以构造反例）。

## 第十三章 五类边

### 13.1 前驱→后继

- D6-1 实数完备性 → 本模块（复数完备性是实数完备性的乘积，函数空间完备性是实数完备性的升维）
- D6-2 紧性 → 本模块（紧集上连续函数性质、Arzelà-Ascoli、Montel 定理）
- 本模块 → D6-5 Lp 空间完备性（本模块证明了 C[a,b] 在 Lp 下不完备，D6-5 证明完备化 Lp 空间完备）
- 本模块 → D6-6 完备化理论（本模块介绍了完备化的基本构造，D6-6 深入讨论完备化与不可测集）

### 13.2 类比

- 实数完备性（D6-1）与函数空间完备性（本模块）：都是"Cauchy 列收敛"，但空间维度从一维升到无限维
- C[a,b] sup 完备与 H(Ω) 内闭一致收敛完备：都是"一致收敛保持空间性质"，但前者保持连续性，后者保持全纯性（更强）
- ℚ 不完备与 C[a,b] Lp 不完备：都是"空间有针孔"，前者的针孔是无理数，后者的针孔是不连续函数
- Dedekind 分割构造 ℝ 与 Cauchy 列等价类构造 Lp：都是完备化构造，前者用分割，后者用 Cauchy 列

### 13.3 推广

- 从 C[a,b] 到 C(X)（任意紧拓扑空间 X 上的连续函数空间）：sup 范数下完备
- 从 Lp[a,b] 到 Lp(μ)（任意测度空间）：Riesz-Fischer 定理推广
- 从 H(Ω) 到 Banach 空间值全纯函数：Weierstrass 定理推广
- 从度量空间完备化到一致空间完备化：更一般的拓扑结构

### 13.4 特例

- C[a,b] sup 完备是 C(X) 完备的特例（X=[a,b]）
- ℂ 完备是 ℝⁿ 完备的特例（n=2）
- H(Ω) 完备是 Fréchet 空间完备的特例
- L² 完备是 Lp 完备的特例（p=2，且有内积结构）

### 13.5 反例簇

- 不完备空间簇：C[a,b] Lp、P[a,b] sup、C¹ sup、R[a,b] L¹、(0,1) 子空间
- 收敛不保持性质簇：逐点收敛不保持连续、一致收敛不保持可导（实函数）、Lp 收敛不保持逐点收敛
- 无限维病态簇：有界不全有界、单位球不紧、最佳逼近不唯一

> **模块结语**：本模块完成了完备性从实数到复数再到函数空间的维度跃迁。核心洞察是：完备性不是空间的绝对性质，而是依赖于度量/范数/拓扑的相对性质。同一个函数空间（C[a,b]）在 sup 范数下完备，在 Lp 范数下不完备——拓扑的强弱决定了完备性是否成立。全纯函数的刚性使得内闭一致收敛保持全纯性，这是复分析独有的强大性质。Riemann 可积函数空间的不完备性直接催生了 Lebesgue 积分理论，而完备化的一般构造（Cauchy 列等价类法）是泛函分析的基石。下一模块 D6-5 将深入 Lp 空间的完备性，证明 Riesz-Fischer 定理，并建立 Banach 空间和 Hilbert 空间的完整框架。
