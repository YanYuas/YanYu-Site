## 第一章 引言：紧性为什么是分析的"第二根支柱"

### 1.1 从一个朴素问题开始

考虑以下问题：定义在区间 [0,1] 上的连续函数 f，它是否一定能取到最大值和最小值？

直觉上答案是肯定的——连续函数在闭区间上"跑不出去"，必然在某个点达到最高和最低。但这个直觉的严格证明依赖于一个深刻的拓扑性质：**[0,1] 是紧集**。

如果把 [0,1] 换成 (0,1)，结论立即失效：f(x) = 1/x 在 (0,1) 上连续但无上界。如果把 [0,1] 换成 [0,∞)，同样失效：f(x) = x 连续但无界。

**紧性的本质**：它是一种"有限性条件"，保证无限过程中必然出现"凝聚点"，从而使存在性证明成为可能。

### 1.2 紧性与完备性的辩证关系

完备性和紧性是分析学的两根支柱，它们的关系可以用以下对照表理解：

| 维度 | 完备性 | 紧性 |
|---|---|---|
| 核心问题 | Cauchy 列是否收敛？ | 任意序列是否有收敛子列？ |
| 空间要求 | 整个空间 | 子集（可以是非紧空间中的紧子集） |
| 有限性含义 | 没有"洞" | 没有"逃逸到无穷远"的可能 |
| 典型定理 | Cauchy 收敛准则 | Bolzano-Weierstrass 定理 |
| 函数空间对应 | 完备空间（Banach 空间） | 紧算子、紧集（Arzela-Ascoli） |

**关键洞察**：在度量空间中，紧性 ⇒ 完备性，但完备性 ⇏ 紧性。紧性是比完备性更强的条件。ℝ 是完备的但不是紧的；[0,1] 既是完备的又是紧的。

### 1.3 紧性的四层蜕变预览

| 层级 | 紧性的表现形式 | 核心定理 |
|---|---|---|
| L0 初等直觉 | "有界闭区间"上的连续函数有最值 | 闭区间上连续函数性质 |
| L1 数学分析 | Heine-Borel 定理、Bolzano-Weierstrass 定理 | 紧集 = 有界闭集（ℝⁿ 中） |
| L2 复变函数 | Montel 定理、正规族、Riemann 映射定理 | 全纯函数族的紧性 |
| L3 实变函数 | Lp 空间紧性、Kolmogorov-Riesz 定理、弱紧性 | 自反空间的弱紧性、Eberlein-Šmulian |

## 第二章 紧性的四种等价定义

紧性有多种等价定义，每一种都从不同角度刻画了"有限性"这一本质。在度量空间中这四种定义完全等价，但在更一般的拓扑空间中它们会分道扬镳。

### 2.1 定义一：开覆盖紧（拓扑紧）

**定义**：拓扑空间 X 称为紧的（compact），如果 X 的每个开覆盖都有有限子覆盖。

即：若 {U_α}_{α∈A} 是 X 的一族开集且 ⋃_{α∈A} U_α = X，则存在有限子集 {α₁, ..., αₙ} ⊂ A 使得 ⋃_{i=1}^n U_{α_i} = X。

**为什么这是最根本的定义**：开覆盖紧是纯拓扑定义，不依赖度量、序列或任何额外结构。它直接表达了"无限可以被有限控制"这一核心思想。

**📐 几何图像**：想象用无数条"小毯子"（开集）覆盖一个空间。紧性意味着，无论这些小毯子多么细碎，你总能从中挑出有限条就把整个空间盖住。非紧空间则存在一种"毯子铺法"——必须用无限条才能盖住，因为空间"延伸到无穷远"，毯子只能一条比一条远，永远无法用有限条覆盖全部。

**直观理解**：想象用无数个"小毯子"覆盖一个空间。紧性意味着，无论这些小毯子多么细碎，你总能从中挑出有限条就把整个空间盖住。非紧空间则存在一种"毯子铺法"，必须用无限条才能盖住。

**经典反例**：ℝ 不是紧的。开覆盖 {(-n, n) : n ∈ ℕ} 覆盖 ℝ，但任何有限子族 {(-n₁,n₁), ..., (-n_k,n_k)} 只能覆盖 (-max(n_i), max(n_i))，不能覆盖整个 ℝ。

### 2.2 定义二：序列紧

**定义**：拓扑空间 X 称为序列紧的（sequentially compact），如果 X 中的每个序列都有收敛子列。

即：对任意 {x_n} ⊂ X，存在子列 {x_{n_k}} 和 x ∈ X，使得 x_{n_k} → x。

**为什么重要**：序列紧是分析学家最常用的紧性形式，因为分析中大量论证采用"取子列"的技术。Bolzano-Weierstrass 定理就是序列紧的经典表述。

**📐 几何图像**：序列紧的几何图像是"在有限空间里跳舞的无穷多个人"——你让无穷多个人在一个有限的房间里跳舞，不管他们怎么跳，必然有一群人在某个位置附近"无限拥挤"。这个拥挤的位置就是收敛子列的极限。非紧空间（比如整个平面）中，人们可以越跳越远，永远不会拥挤。

**与开覆盖紧的关系**：
- 在度量空间中：序列紧 ⟺ 开覆盖紧
- 在一般拓扑空间中：开覆盖紧 ⇒ 序列紧（需附加第一可数公理），但序列紧 ⇏ 开覆盖紧

**经典反例**：存在序列紧但非紧的拓扑空间（如序数空间 [0,ω₁)），也存在紧但非序列紧的空间（如 βℕ \ ℕ）。这说明在非度量空间中，两种紧性确实不同。

### 2.3 定义三：列紧（极限点紧）

**定义**：拓扑空间 X 称为列紧的（countably compact）或极限点紧的（limit point compact），如果 X 的每个无限子集都有极限点（聚点）。

即：对任意无限子集 A ⊂ X，存在 x ∈ X 使得 x 的每个邻域都包含 A 中不同于 x 的点。

**名称辨析**：
- **列紧**（countably compact）：每个可数开覆盖有有限子覆盖
- **极限点紧**（limit point compact）：每个无限子集有极限点
- 在 T₁ 空间中，列紧 ⟺ 极限点紧

**与其他紧性的关系**：
- 紧 ⇒ 列紧 ⇒ 极限点紧
- 在度量空间中：三者等价
- 在一般拓扑空间中：反向蕴含不成立

### 2.4 定义四：全有界 + 完备

**定义（度量空间专用）**：度量空间 (X, d) 是紧的，当且仅当它是全有界的且完备的。

**全有界（totally bounded）**：对任意 ε > 0，存在有限个点 x₁, ..., xₙ ∈ X 使得 X ⊂ ⋃_{i=1}^n B(x_i, ε)。即 X 可以被有限个 ε-球覆盖。

**全有界 vs 有界**：
- 有界：存在 M > 0 使得 d(x,y) ≤ M 对所有 x,y ∈ X
- 全有界：对任意 ε > 0，有限个 ε-球覆盖 X
- 全有界 ⇒ 有界，但有界 ⇏ 全有界

**📐 几何图像**：全有界性的几何图像是"在任意小尺度上都是有限的"。想象你用一个"放大镜"来看一个集合——不管你把放大镜调到多大倍数（ε 多小），你看到的集合始终只占据有限个"像素"（有限个 ε-球）。有界但不全有界的集合（比如无限维空间的单位球）就像一幅"无限分辨率"的图像——你放大得越厉害，看到的细节越多，永远无法用有限个像素覆盖。

**经典反例**：无限维 Hilbert 空间中的单位球是有界的但不是全有界的。标准正交基 {e_n} 中任意两点距离为 √2，所以半径为 √2/2 的球互不相交，需要无限个才能覆盖单位球。

**为什么这个刻画重要**：它把紧性分解为两个更易验证的条件——"小尺度上有限"（全有界）和"极限不跑出空间"（完备性）。这是证明度量空间中集合紧性的标准方法。

### 2.5 四种定义的等价性证明（度量空间中）

**定理**：在度量空间 (X, d) 中，以下四条等价：
1. X 是开覆盖紧的
2. X 是序列紧的
3. X 是极限点紧的
4. X 是全有界且完备的

**证明链**：(1)⇒(3)⇒(2)⇒(4)⇒(1)

**(1)⇒(3)**：设 X 紧，A 是无限子集。若 A 无极限点，则每个 x ∈ X 有邻域 U_x 使得 U_x ∩ A ⊂ {x}。{U_x} 是 X 的开覆盖，有有限子覆盖 {U_{x₁},...,U_{xₙ}}。则 A ⊂ {x₁,...,xₙ}，与 A 无限矛盾。

**(3)⇒(2)**：设 {x_n} 是 X 中的序列。若 {x_n} 有无限多个不同项，则其值域是无限子集，有极限点 x。可构造子列收敛到 x。若 {x_n} 只有有限多个不同项，则某项重复出现无限次，常数子列收敛。

**(2)⇒(4)**：
- 完备性：设 {x_n} 是 Cauchy 列。由序列紧，有收敛子列 x_{n_k} → x。则 x_n → x（Cauchy 列有收敛子列则自身收敛）。
- 全有界：反证。若存在 ε > 0 不能被有限个 ε-球覆盖。任取 x₁ ∈ X，B(x₁,ε) 不覆盖 X，取 x₂ ∉ B(x₁,ε)。归纳取 x_{n+1} ∉ ⋃_{i=1}^n B(x_i,ε)。则 d(x_m,x_n) ≥ ε 对 m ≠ n，此序列无收敛子列，矛盾。

**(4)⇒(1)**：设 X 全有界且完备。反证，存在开覆盖 {U_α} 无有限子覆盖。
- 由全有界，X 可被有限个 1-球覆盖。至少一个球 B₁ 不能被有限个 U_α 覆盖。
- B₁ 可被有限个 1/2-球覆盖，取其中一个 B₂ 不能被有限覆盖，且 B₂ ∩ B₁ ≠ ∅。
- 归纳得嵌套球列 B_n，半径 1/n，每个都不能被有限覆盖。
- 取 x_n ∈ B_n，则 {x_n} 是 Cauchy 列（d(x_m,x_n) ≤ 1/m + 1/n → 0）。
- 由完备性，x_n → x ∈ X。x ∈ 某个 U_{α₀}。因 U_{α₀} 开，存在 δ > 0 使 B(x,δ) ⊂ U_{α₀}。
- 取 n 充分大使 1/n &lt; δ/2 且 d(x_n,x) &lt; δ/2，则 B_n ⊂ B(x,δ) ⊂ U_{α₀}，与 B_n 不能被有限覆盖矛盾。

## 第三章 实数轴上的紧性定理

### 3.1 Heine-Borel 定理

**定理（Heine-Borel）**：ℝⁿ 中的子集 K 是紧的，当且仅当 K 是有界闭集。

这是欧氏空间中紧性的最简洁刻画，也是整个分析学中最常用的定理之一。

**📐 几何图像**：Heine-Borel 定理的几何图像是"被围墙围起来且围墙本身也属于场地的封闭区域"。"有界"意味着集合被限制在一个有限大小的区域内（被围墙围住），不能延伸到无穷远；"闭"意味着集合包含了所有的边界点和极限点（围墙本身也属于场地），点不能"挤到围墙外面消失"。两者结合，无限多个点就不可能逃逸到无穷远，也不可能消失在边界外——必然有凝聚点，这就是紧性。

**证明**：

**(⇒) 紧 ⇒ 有界闭**：
- 有界：{B(0, n) : n ∈ ℕ} 是 K 的开覆盖，有有限子覆盖，取最大半径即得有界。
- 闭：设 x ∉ K。对每个 y ∈ K，取不相交邻域 U_y ∋ y 和 V_y ∋ x。{U_y} 覆盖 K，有有限子覆盖 {U_{y₁},...,U_{yₙ}}。令 V = ⋂_{i=1}^n V_{y_i}，则 V 是 x 的邻域且 V ∩ K = ∅。故 K^c 开，K 闭。

**(⇐) 有界闭 ⇒ 紧**：
- 有界 ⇒ K ⊂ [-M,M]^n 对某个 M。
- [-M,M]^n 是紧的（用区间套或 Bolzano-Weierstrass 证明）。
- 紧空间的闭子集是紧的。

**历史注记**：Heine-Borel 定理的名称有些误导。Heine 在 1872 年证明了闭区间上连续函数一致连续时隐含使用了有限覆盖性质；Borel 在 1895 年明确表述了可数覆盖的情形；Lebesgue 和 Cousin 推广到任意覆盖。定理的现代形式归功于多人。

### 3.2 Bolzano-Weierstrass 定理

**定理（Bolzano-Weierstrass）**：ℝⁿ 中的每个有界序列都有收敛子列。

等价表述：ℝⁿ 中的每个有界无限子集都有极限点。

**证明（二分法）**：
以 ℝ 为例。设 {x_n} 有界，存在 [a,b] 包含所有 x_n。
- 将 [a,b] 二等分，至少一个子区间包含序列中无限多项，记为 [a₁,b₁]。
- 再将 [a₁,b₁] 二等分，取含无限多项的子区间 [a₂,b₂]。
- 归纳得区间套 [a_k,b_k]，长度 (b-a)/2^k → 0，每个含序列无限多项。
- 由区间套定理，存在唯一 x ∈ ⋂ [a_k,b_k]。
- 在每个 [a_k,b_k] 中取 x_{n_k}（n_k 递增），则 |x_{n_k} - x| ≤ (b-a)/2^k → 0。

**与 Heine-Borel 的关系**：在 ℝⁿ 中，Bolzano-Weierstrass 定理（序列紧）和 Heine-Borel 定理（开覆盖紧）是等价的，都是实数完备性的推论。

### 3.3 紧集上的连续函数

**定理（极值定理）**：若 K 是紧度量空间，f : K → ℝ 连续，则 f 在 K 上取得最大值和最小值。

**证明**：
- f(K) 是 ℝ 中的紧集（连续映射保持紧性），故 f(K) 是有界闭集。
- 有界闭集包含其上确界和下确界，故 f 取得最值。

**定理（一致连续性定理）**：若 K 是紧度量空间，f : K → Y 连续，则 f 在 K 上一致连续。

**证明（Lebesgue 数法）**：
- 对每个 x ∈ K，由连续性，存在 δ_x > 0 使 d(x,y) &lt; δ_x ⇒ d(f(x),f(y)) &lt; ε/2。
- {B(x, δ_x/2)} 覆盖 K，由紧性有有限子覆盖 {B(x_i, δ_{x_i}/2)}。
- 令 δ = min(δ_{x_i}/2) > 0。
- 若 d(x,y) &lt; δ，取 x_i 使 x ∈ B(x_i, δ_{x_i}/2)，则 d(y,x_i) ≤ d(y,x) + d(x,x_i) &lt; δ + δ_{x_i}/2 ≤ δ_{x_i}。
- 故 d(f(x),f(y)) ≤ d(f(x),f(x_i)) + d(f(x_i),f(y)) &lt; ε/2 + ε/2 = ε。

**Lebesgue 数引理**：紧度量空间的每个开覆盖都有 Lebesgue 数 δ > 0，使得任何直径小于 δ 的子集都包含在某个覆盖元素中。

这是紧性最深刻的推论之一，也是一致连续性定理的核心。

### 3.4 紧性的传递性质

**定理**：紧性在连续映射下保持。即若 f : X → Y 连续，K ⊂ X 紧，则 f(K) ⊂ Y 紧。

**证明**：设 {V_α} 是 f(K) 的开覆盖，则 {f^{-1}(V_α)} 是 K 的开覆盖。K 紧，有有限子覆盖 {f^{-1}(V_{α₁}),...,f^{-1}(V_{αₙ})}。则 {V_{α₁},...,V_{αₙ}} 覆盖 f(K)。

**推论**：
- 紧集的闭子集是紧的
- 有限个紧集的并是紧的
- 紧集的 Cartesian 积是紧的（Tychonoff 定理的特殊情形）
- Hausdorff 空间中的紧集是闭的

**Tychonoff 定理（简述）**：任意一族紧空间的 Cartesian 积在积拓扑下是紧的。这是拓扑学中最重要的定理之一，其证明依赖选择公理（或等价的 Zorn 引理）。在分析中，Tychonoff 定理是 Banach-Alaoglu 定理的基础。

## 第四章 度量空间中的紧性

### 4.1 全有界性的深入分析

全有界性是度量空间中紧性的"一半"，值得深入理解。

**等价刻画**：度量空间 X 全有界，当且仅当 X 中的每个序列都有 Cauchy 子列。

**证明**：
- (⇒) 用 1/n-网的对角线法构造 Cauchy 子列。
- (⇐) 反证，若不全有界，构造两两距离 ≥ ε 的序列，无 Cauchy 子列。

**全有界空间的性质**：
- 全有界空间是可分的（有可数稠密子集）
- 全有界空间的子集是全有界的
- 全有界空间的完备化是紧的
- 全有界 ⇏ 完备（如 (0,1) 全有界但不完备）

**有限 ε-网**：全有界性的另一种表述是，对任意 ε > 0，存在有限 ε-网。ε-网是指有限点集 {x₁,...,xₙ} 使得 X ⊂ ⋃ B(x_i, ε)。

### 4.2 紧度量空间的性质

**定理**：紧度量空间是完备的、全有界的、可分的、第二可数的。

**证明要点**：
- 完备 + 全有界：由第二章等价性
- 可分：对每个 n，取有限 1/n-网，所有网的并是可数稠密集
- 第二可数：以有理半径、可数稠密集中点为中心的球构成可数基

**紧度量空间上的连续函数**：
- 连续 ⇒ 一致连续（已证）
- 连续实值函数 ⇒ 有界且取得最值
- 连续函数空间 C(K) 是 Banach 空间（上确界范数）

### 4.3 紧性与完备性的精细关系

在度量空间中，紧性 = 全有界 + 完备。这个分解揭示了紧性和完备性的精确关系。

**完备但非紧的空间**：
- ℝ（完备，非全有界）
- 任何无限维 Banach 空间（完备，单位球非全有界）
- ℓ^∞（完备，非可分，非全有界）

**全有界但非完备的空间**：
- (0,1)（全有界，不完备，完备化是 [0,1]）
- ℚ ∩ [0,1]（全有界，不完备）
- 任何紧空间的非闭子集

**既非全有界也非完备的空间**：
- (0,∞)（非全有界，不完备）
- ℚ（非全有界，不完备）

**关键洞察**：完备化操作可以"修复"不完备性，但不能修复非全有界性。一个全有界空间的完备化是紧的；一个非全有界空间的完备化仍然非紧。

### 4.4 局部紧空间

**定义**：拓扑空间 X 称为局部紧的（locally compact），如果每个点都有一个紧邻域。

即：对每个 x ∈ X，存在开集 U ∋ x 和紧集 K 使得 x ∈ U ⊂ K。

**例子**：
- ℝⁿ 是局部紧的（每个点有闭球邻域，紧）
- 任何离散空间是局部紧的
- 无限维 Banach 空间不是局部紧的（单位球非紧，任何邻域包含非紧闭球）
- 紧空间是局部紧的（整个空间是紧邻域）

**局部紧 Hausdorff 空间的重要性质**：
- 一点紧化（Alexandrov 紧化）：局部紧 Hausdorff 空间 X 可以加一个点 ∞ 变成紧 Hausdorff 空间 X* = X ∪ {∞}
- 例子：ℝ 的一点紧化同胚于圆周 S¹；ℝ² 的一点紧化同胚于球面 S²（Riemann 球面！）
- Urysohn 引理和 Tietze 扩张定理在局部紧 Hausdorff 空间中成立

**局部紧性在分析中的作用**：
- 积分理论：局部紧 Hausdorff 空间上可以建立 Radon 测度和 Riesz 表示定理
- 调和分析：局部紧群上的 Haar 测度和 Fourier 变换
- 函数空间：C_c(X)（紧支撑连续函数）和 C_0(X)（无穷远消失的连续函数）

## 第五章 拓扑空间中的紧性与推广

### 5.1 紧性的拓扑不变量

紧性是拓扑性质（同胚不变量）。以下是紧空间的重要拓扑性质：

**定理**：
- 紧空间的闭子集是紧的
- Hausdorff 空间中的紧子集是闭的
- 紧空间到 Hausdorff 空间的连续双射是同胚
- 紧空间上的连续实值函数有界且取得最值
- 有限个紧空间的积是紧的（Tychonoff 定理的有限情形，不需选择公理）

**紧 Hausdorff 空间的特殊性**：
- 紧 Hausdorff 空间是正规的（T₄）
- 紧 Hausdorff 空间上的拓扑是"极小 Hausdorff 拓扑"：不能在保持 Hausdorff 的前提下弱化
- 紧 Hausdorff 空间是"极大紧拓扑"：不能在保持紧的前提下强化

### 5.2 仿紧性

**定义**：拓扑空间 X 称为仿紧的（paracompact），如果 X 的每个开覆盖都有局部有限的开加细。

**局部有限**：族 {V_β} 是局部有限的，如果每个 x ∈ X 有邻域只与有限个 V_β 相交。

**开加细**：{V_β} 是 {U_α} 的加细，如果每个 V_β 包含在某个 U_α 中。

**仿紧性 vs 紧性**：
- 紧 ⇒ 仿紧（有限子覆盖是局部有限加细）
- 仿紧 ⇏ 紧（ℝ 是仿紧的但非紧）
- 仿紧性是紧性的"局部化推广"

**重要定理**：
- 度量空间是仿紧的（Stone 定理）
- 仿紧 Hausdorff 空间是正规的
- 仿紧空间上存在单位分解（partition of unity）——这是微分几何和流形理论的基础工具

**单位分解定理**：若 X 是仿紧 Hausdorff 空间，{U_α} 是局部有限开覆盖，则存在连续函数族 {φ_α} 满足：
1. 0 ≤ φ_α ≤ 1
2. supp(φ_α) ⊂ U_α
3. ⋃ supp(φ_α) 局部有限
4. Σ φ_α(x) = 1 对所有 x ∈ X

单位分解是把局部构造"粘合"成全局构造的标准工具。

### 5.3 σ-紧性与林德勒夫性质

**σ-紧**：空间 X 是 σ-紧的，如果 X 是可数个紧子集的并。

**例子**：
- ℝⁿ 是 σ-紧的（ℝⁿ = ⋃_{k=1}^∞ [-k,k]^n）
- 任何紧空间是 σ-紧的
- 离散不可数空间不是 σ-紧的（紧子集有限，可数并可数）

**林德勒夫性质（Lindelöf）**：空间 X 是林德勒夫的，如果每个开覆盖有可数子覆盖。

**关系**：
- 紧 ⇒ 林德勒夫 ⇒ （正则空间中）仿紧
- σ-紧 + 正则 ⇒ 林德勒夫
- 第二可数 ⇒ 林德勒夫
- 度量空间中：可分 ⟺ 第二可数 ⟺ 林德勒夫

### 5.4 可数紧与伪紧

**可数紧（countably compact）**：每个可数开覆盖有有限子覆盖。

**伪紧（pseudocompact）**：每个连续实值函数有界。

**关系链**：
紧 ⇒ 可数紧 ⇒ 极限点紧 ⇒ （T₁ 空间中）伪紧

在度量空间或正规空间中，以上概念全部等价于紧性。

**反例**：
- 序数空间 [0,ω₁) 是可数紧、极限点紧、伪紧，但不是紧的（也不是林德勒夫的）
- 长直线是伪紧的但不是可数紧的

## 第六章 Arzelà-Ascoli 定理

### 6.1 函数空间紧性的核心问题

考虑 C(K)，即紧度量空间 K 上的连续函数空间，赋以上确界范数 ||f||_∞ = sup_{x∈K} |f(x)|。

**问题**：C(K) 中的子集 F 什么时候是紧的？

C(K) 本身通常是无限维 Banach 空间，其单位球不是紧的。例如 C[0,1] 中的函数列 f_n(x) = x^n 没有一致收敛子列。

Arzelà-Ascoli 定理给出了 C(K) 中紧集的完整刻画。

### 6.2 等度连续性

**定义**：函数族 F ⊂ C(K) 称为等度连续的（equicontinuous），如果对任意 ε > 0，存在 δ > 0 使得对所有 f ∈ F 和所有 x,y ∈ K，d(x,y) &lt; δ ⇒ |f(x) - f(y)| &lt; ε。

**关键区别**：
- 单个 f 连续：δ 依赖于 f 和 x
- f 一致连续：δ 依赖于 f 但不依赖于 x
- 族 F 等度连续：δ 不依赖于 f 也不依赖于 x

等度连续性是"整个函数族共享同一个连续模"的性质。

**例子**：
- {f_n(x) = sin(nx)} 在 [0,1] 上不是等度连续的（频率越高，振荡越快）
- {f_n(x) = x^n} 在 [0,1] 上不是等度连续的（在 x=1 附近变化越来越陡）
- Lipschitz 常数一致有界的函数族是等度连续的
- 导数一致有界的可微函数族是等度连续的（由中值定理）

### 6.3 Arzelà-Ascoli 定理

**定理（Arzelà-Ascoli）**：设 K 是紧度量空间，F ⊂ C(K)。则 F 在 C(K) 中是相对紧的（闭包紧），当且仅当：
1. F 是逐点有界的（对每个 x ∈ K，{f(x) : f ∈ F} 在 ℝ 中有界）
2. F 是等度连续的

**相对紧（relatively compact）**：子集的闭包是紧的。等价于每个序列有收敛子列（极限可能在闭包中，不一定在子集内）。

**证明概要**：

**(⇒) 相对紧 ⇒ 逐点有界 + 等度连续**：
- 逐点有界：紧集有界，评价映射 ev_x : C(K) → ℝ 连续，故 ev_x(F) 有界。
- 等度连续：F 的闭包紧，故完全有界。对 ε > 0，取有限 ε/3-网 {f₁,...,fₙ}。每个 f_i 一致连续，取公共 δ。对任意 f ∈ F，取 f_i 使 ||f-f_i|| &lt; ε/3，则 |f(x)-f(y)| ≤ |f(x)-f_i(x)| + |f_i(x)-f_i(y)| + |f_i(y)-f(y)| &lt; ε。

**(⇐) 逐点有界 + 等度连续 ⇒ 相对紧**：
- K 紧可分，取可数稠密集 D = {x₁, x₂, ...}。
- 对 F 中任意序列 {f_n}，用对角线法构造子列在 D 上逐点收敛：
  - {f_n(x₁)} 有界，有收敛子列 {f_{n¹_k}(x₁)}
  - {f_{n¹_k}(x₂)} 有界，有收敛子列 {f_{n²_k}(x₂)}
  - 对角线子列 {f_{n^k_k}} 在所有 x_i 上收敛
- 等度连续性 + K 紧 + D 稠密 ⇒ 子列在 K 上一致收敛。
- 故 F 中每个序列有一致收敛子列，F 相对紧。

### 6.4 Arzelà-Ascoli 定理的推广

**推广一：到任意度量空间**：设 X 是紧拓扑空间，Y 是度量空间。F ⊂ C(X,Y) 相对紧（在一致拓扑下）当且仅当 F 等度连续且对每个 x ∈ X，F(x) = {f(x) : f ∈ F} 在 Y 中相对紧。

**推广二：局部紧空间**：设 X 是局部紧 Hausdorff 空间，F ⊂ C(X)。F 在紧开拓扑下相对紧当且仅当 F 等度连续且逐点相对紧。

**推广三：Montel 定理（复分析版本）**：全纯函数族的正规性等价于局部一致有界性。这是 Arzelà-Ascoli 在复分析中的特殊形式，将在第八章详细讨论。

**📐 几何图像**：Montel 定理的几何图像揭示了全纯函数的"刚性"。全纯函数的图像（作为 ℝ²→ℝ² 的映射）必须保持角度（共形性），不能随意变形。这种刚性使得"局部一致有界"自动蕴含"等度连续"——只要图像被限制在有界区域内，图像的变形速度（导数）就自动有界（由 Cauchy 积分公式估计）。所以全纯函数族不需要额外的等度连续条件，只要局部有界就有内闭一致收敛子列。这是全纯函数比实连续函数"更刚性"的几何体现。

### 6.5 Arzelà-Ascoli 定理的应用

**应用一：常微分方程存在性定理（Peano）**：
- 考虑初值问题 y' = f(t,y), y(t₀) = y₀，f 连续。
- 用 Euler 法构造近似解序列 {y_n}。
- 证明 {y_n} 等度连续且一致有界。
- 由 Arzelà-Ascoli，有一致收敛子列，极限是解。

**应用二：变分法中的直接方法**：
- 极小化序列 {u_n} 在某个函数空间中有界。
- 证明 {u_n} 等度连续（或某种弱紧性）。
- 取收敛子列，极限是极小元。

**应用三：紧算子**：
- 线性算子 T : X → Y 是紧的，如果 T 将有界集映为相对紧集。
- 在 C(K) 上，积分算子 Tf(x) = ∫ K(x,y)f(y)dy 是紧的（可用 Arzelà-Ascoli 验证像集等度连续）。
- 紧算子是泛函分析和积分方程理论的核心。

**📐 几何图像**：紧算子的几何图像是"把大球压成小核桃"。非紧算子（比如恒等算子）把单位球映成单位球——在无限维空间中，单位球是"蓬松"的，里面有无限多个互相保持距离的点。紧算子则把单位球"压缩"成一个"结实"的核桃——像集是全有界的，可以被有限个任意小的球覆盖。紧算子"压缩"了空间的维度，把无限维的蓬松球压成了"近似有限维"的结实集合。积分算子是紧算子的经典例子——积分把函数的"高频振荡"平滑掉了，像集自动等度连续，从而相对紧。

## 第七章 复变函数中的紧性

### 7.1 复平面上的紧性

ℂ 作为度量空间同胚于 ℝ²，因此 Heine-Borel 定理直接适用：

**定理**：ℂ 中的子集 K 是紧的，当且仅当 K 是有界闭集。

**复分析中的紧集例子**：
- 闭圆盘 \overline{D}(a,r) = {z : |z-a| ≤ r} 是紧的
- 紧集上的连续函数有最值（最大模原理的基础）
- 紧集上的全纯函数一致连续

**最大模原理的紧性基础**：
- 若 f 在区域 D 上全纯，K ⊂ D 紧，则 |f| 在 K 上取得最大值。
- 最大模原理进一步指出：非常数全纯函数的最大值只能在边界取得。
- 紧性保证了"最大值存在"，全纯性保证了"最大值在边界"。

### 7.2 正规族与 Montel 定理

**定义**：设 F 是区域 D 上的全纯函数族。F 称为正规族（normal family），如果 F 中的每个序列都有子列在 D 的每个紧子集上一致收敛（内闭一致收敛）。

内闭一致收敛的极限函数仍然是全纯的（Weierstrass 定理），所以正规族的极限仍在全纯函数空间中。

**Montel 定理（第一定理）**：区域 D 上的全纯函数族 F 是正规族，当且仅当 F 在 D 的每个紧子集上一致有界。

即：对每个紧 K ⊂ D，存在 M_K > 0 使得 |f(z)| ≤ M_K 对所有 f ∈ F, z ∈ K。

**为什么这是 Arzelà-Ascoli 的推论**：
- 局部一致有界 + Cauchy 积分公式 ⇒ 导数局部一致有界
- 导数一致有界 ⇒ 等度连续（中值定理 / 积分估计）
- 由 Arzelà-Ascoli，每个紧子集上有一致收敛子列
- 用对角线法得到在所有紧子集上一致收敛的子列

**Montel 定理（第二定理 / 正规族定则）**：若区域 D 上的全纯函数族 F 中每个函数都不取两个固定值 a, b（a ≠ b），则 F 是正规族。

这是 Montel 最深刻的结果，也是 Picard 定理的基础。它的证明需要更深入的工具（如 Ahlfors-Schwarz 引理或椭圆模函数）。

### 7.3 正规族的应用

**应用一：Riemann 映射定理**：
- 定理：任何单连通真子区域 D ⊂ ℂ 共形等价于单位圆盘。
- 证明的核心步骤：构造一个单叶全纯函数族，证明其正规性，取极限得到极值函数，证明极值函数是满射。
- 紧性（正规族）保证了极值函数的存在性。

**应用二：Picard 小定理**：
- 定理：非常数整函数至多有一个例外值（不取的值）。
- 证明：若整函数 f 不取 a, b 两个值，考虑函数族 f_n(z) = f(2^n z)。由 Montel 第二定理，{f_n} 正规。但 f_n 在原点附近的行为导致矛盾，故 f 不能有两个例外值。

**应用三：Picard 大定理**：
- 定理：本性奇点附近，函数取每个值（至多一个例外）无限多次。
- 证明同样依赖正规族理论。

**应用四：共形映射的边界行为**：
- 正规族用于研究共形映射序列的收敛性和边界对应。

### 7.4 紧 Riemann 面

**定义**：Riemann 面是一维复流形。紧 Riemann 面是紧的一维复流形。

**例子**：
- Riemann 球面 ℙ¹ = ℂ ∪ {∞}（ℂ 的一点紧化）
- 环面 ℂ / Λ（复平面模去格点）
- 高亏格紧 Riemann 面

**紧 Riemann 面上的分析**：
- 紧 Riemann 面上的全纯函数必为常数（最大模原理 + 紧性）
- 亚纯函数的零点数等于极点数（留数定理）
- Riemann-Roch 定理：紧 Riemann 面上亚纯函数空间的维数公式
- 紧性是 Riemann 面分类理论的基础

**Riemann 球面的特殊地位**：
- ℂ 的一点紧化就是 Riemann 球面
- 球面是唯一的亏格 0 紧 Riemann 面（由单值化定理）
- 球面上的亚纯函数就是有理函数
- 球面几何（球面度量）与双曲几何、欧氏几何并列，构成单值化定理的三种几何

## 第八章 实变函数中的紧性

### 8.1 Lp 空间中的紧性

Lp 空间（1 ≤ p &lt; ∞）是 Banach 空间，完备但通常非紧。Lp 中的紧集有特殊的刻画。

**Kolmogorov-Riesz 定理**：设 1 ≤ p &lt; ∞，Ω ⊂ ℝⁿ 可测。F ⊂ L^p(Ω) 是相对紧的，当且仅当：
1. F 是有界的（sup_{f∈F} ||f||_p &lt; ∞）
2. F 是 p-等度连续的：lim_{h→0} sup_{f∈F} ||f(·+h) - f(·)||_p = 0（平移连续模一致趋于 0）
3. F 在无穷远一致消失：lim_{R→∞} sup_{f∈F} ∫_{Ω \ B(0,R)} |f|^p = 0（当 Ω 无界时需要）

**与 Arzelà-Ascoli 的类比**：
- Arzelà-Ascoli：逐点有界 + 等度连续 ⇒ 紧
- Kolmogorov-Riesz：Lp 有界 + 平移等度连续 + 无穷远消失 ⇒ 紧
- 平移等度连续是 Lp 版本的"等度连续"

**证明思路**：
- 用光滑化（mollifier）将 Lp 函数逼近为连续函数
- 对光滑化后的函数族应用 Arzelà-Ascoli
- 用逼近误差控制收敛性

### 8.2 弱紧性与自反空间

在无限维 Banach 空间中，范数拓扑下的紧集非常"小"（有限维本质）。弱拓扑下的紧性更有用。

**📐 几何图像**：弱紧性的几何图像是"方向上的凝聚"。在无限维空间中，范数拓扑下的单位球不是紧的——里面有无限多个"互相垂直的方向"，标准正交基的点两两距离为 √2，永远不会拥挤。但弱拓扑就像"透过一个有限孔径的筛子看空间"——你只能看到空间在有限个方向上的投影，看不到全貌。在这个"模糊"的视角下，有界序列在每个固定方向上的投影都趋于稳定，从而"方向上凝聚"——这就是弱收敛。自反空间的单位球在弱拓扑下紧，意味着有界序列在"方向意义"上必有凝聚点。

**定义**：Banach 空间 X 中的子集 K 称为弱紧的，如果 K 在弱拓扑 σ(X, X*) 下是紧的。

**弱序列紧**：每个序列有弱收敛子列。

**Eberlein-Šmulian 定理**：在 Banach 空间中，弱紧 ⟺ 弱序列紧。

这是一个深刻的结果：在一般拓扑空间中紧和序列紧不等价，但在 Banach 空间的弱拓扑下它们等价。

**自反空间的弱紧性**：
- Banach 空间 X 是自反的，如果自然嵌入 J : X → X** 是满射。
- 自反空间的闭单位球是弱紧的（Banach-Alaoglu 定理 + 自反性）。
- 例子：Lp(1 &lt; p &lt; ∞)、Hilbert 空间、有限维空间是自反的；L¹、L^∞、C(K) 通常非自反。

**Banach-Alaoglu 定理**：Banach 空间 X 的对偶空间 X* 的闭单位球是弱*紧的（在 σ(X*, X) 拓扑下）。

这是 Tychonoff 定理在泛函分析中的直接应用：X* 的单位球可以嵌入到 [-1,1]^X 中，后者由 Tychonoff 定理紧。

### 8.3 紧算子

**定义**：线性算子 T : X → Y 称为紧算子，如果 T 将 X 中的有界集映为 Y 中的相对紧集。

等价地，T 是紧的，如果对 X 中的每个有界序列 {x_n}，{Tx_n} 有收敛子列。

**紧算子的性质**：
- 紧算子是有界的（连续的）
- 有限秩算子（值域有限维）是紧的
- 紧算子的极限（算子范数下）是紧的
- 紧算子与有界算子的复合是紧的
- 紧算子的伴随是紧的（Schauder 定理）

**紧算子的谱理论（Riesz-Schauder 理论）**：
- 非零谱点都是特征值
- 特征值的聚点只能是 0
- 每个非零特征值的代数重数有限
- 这是有限维矩阵谱理论在无限维的推广

**积分算子是紧算子**：
- 设 K(x,y) 在 [a,b]×[a,b] 上连续，定义 Tf(x) = ∫_a^b K(x,y)f(y)dy。
- T : C[a,b] → C[a,b] 是紧的（可用 Arzelà-Ascoli 验证）。
- T : L²[a,b] → L²[a,b] 也是紧的（Hilbert-Schmidt 算子）。

**紧算子在实变函数中的应用**：
- 积分方程理论（Fredholm 二择一定理）
- 偏微分方程的紧性方法
- 变分法中的 Palais-Smale 条件
- 遍历理论中的紧算子

### 8.4 测度论中的紧性

**测度的紧性（内正则性）**：测度 μ 称为紧的（或内正则的），如果对每个可测集 A 和 ε > 0，存在紧集 K ⊂ A 使得 μ(A \ K) &lt; ε。

**Radon 测度**：局部紧 Hausdorff 空间上的 Borel 测度，如果内正则（紧集逼近）且外正则（开集逼近），且紧集上有限，则称为 Radon 测度。

**Riesz 表示定理**：局部紧 Hausdorff 空间 X 上，C_c(X) 上的正线性泛函与 X 上的 Radon 测度一一对应。

**测度族的紧性（Prokhorov 定理）**：
- 定义：完备可分度量空间上的概率测度族 P 称为胎紧的（tight），如果对任意 ε > 0，存在紧集 K 使得 μ(K) > 1-ε 对所有 μ ∈ P。
- Prokhorov 定理：概率测度族 P 相对紧（弱收敛拓扑下）当且仅当 P 是胎紧的。
- 这是概率论中最重要的紧性定理，是中心极限定理证明的基础。

**📐 几何图像**：Prokhorov 定理的几何图像是"概率质量的不逃逸性"。胎紧性意味着，对任意 ε，所有测度的大部分质量（1-ε）都被压缩在一个紧集内。几何上，这就像把无穷多堆沙子限制在一个有限的沙盒里——沙堆的质量不会"逃逸到无穷远"。非胎紧的测度族（比如 δ_n）就像一堆堆沙子被越放越远，质量全部逃逸到了无穷远，没有弱收敛子列。胎紧性保证了质量"不逃逸"，从而有弱收敛子列——这是中心极限定理证明的核心。

**弱收敛与紧性**：
- 概率测度的弱收敛：μ_n ⇒ μ 如果 ∫ f dμ_n → ∫ f dμ 对所有有界连续 f。
- 胎紧性保证了弱收敛序列不会"质量逃逸到无穷远"。
- Helly 选择定理：ℝ 上的概率测度族有弱收敛子列当且仅当胎紧。

## 第九章 反例库

紧性理论中有大量精妙的反例，它们揭示了各种紧性概念之间的精确边界。

### 9.1 实数轴上的反例

**反例 1：有界但非闭的集不是紧的**
- (0,1) 有界但非闭，不是紧的。
- 开覆盖 {(1/n, 1) : n ≥ 2} 覆盖 (0,1)，但无有限子覆盖。
- 序列 {1/n} ⊂ (0,1) 收敛到 0 ∉ (0,1)，无收敛子列在 (0,1) 内。

**反例 2：闭但无界的集不是紧的**
- ℤ 是闭集（离散）但无界，不是紧的。
- 序列 {n} 无收敛子列。

**反例 3：有界闭集在无限维空间中不紧**
- 这是 Heine-Borel 定理在无限维空间的失效，见 9.2。

### 9.2 函数空间中的反例

**反例 4：C[0,1] 的单位球不紧**
- 考虑 f_n(x) = x^n。||f_n||_∞ = 1，在单位球内。
- {f_n} 逐点收敛到 f(x) = 0 (x&lt;1), f(1) = 1，但不一致收敛。
- 任何子列都不一致收敛（若一致收敛，极限必连续，但逐点极限不连续）。
- 故单位球非紧。

**反例 5：一致有界但非等度连续的函数族**
- f_n(x) = sin(nx) 在 [0,2π] 上一致有界（|f_n| ≤ 1）。
- 但不是等度连续的：取 x = π/(2n), y = 0，则 |x-y| = π/(2n) → 0，但 |f_n(x)-f_n(y)| = 1。
- 由 Arzelà-Ascoli，此族不相对紧。事实上 {sin(nx)} 没有一致收敛子列。

**反例 6：逐点收敛但不一致收敛的连续函数列**
- f_n(x) = n x e^{-nx} 在 [0,1] 上。
- 逐点收敛到 0（x=0 时 f_n(0)=0；x>0 时 n x e^{-nx} → 0）。
- 但 sup |f_n| = f_n(1/n) = e^{-1}，不一致收敛到 0。
- {f_n} 不是等度连续的（在 x=0 附近变化剧烈）。

### 9.3 拓扑空间中的反例

**反例 7：紧但非序列紧的空间**
- βℕ（ℕ 的 Stone-Čech 紧化）是紧的但非序列紧的。
- βℕ \ ℕ 中的序列可能没有收敛子列。
- 这需要选择公理和超滤子理论。

**反例 8：序列紧但非紧的空间**
- 序数空间 [0, ω₁)（所有可数序数的集合，序拓扑）是序列紧的但非紧的。
- 每个序列有上确界（可数个可数序数的上确界仍可数），故有收敛子列。
- 但开覆盖 {[0, α) : α &lt; ω₁} 无有限子覆盖。

**反例 9：极限点紧但非可数紧的空间**
- 存在这样的空间，但构造较复杂，需要非 T₁ 空间或特殊集合论公理。

**反例 10：局部紧但非 σ-紧的空间**
- 不可数离散空间是局部紧的（每个点是紧集）但非 σ-紧的（紧子集有限，可数并可数）。

**反例 11：仿紧但非局部紧的空间**
- ℚ（有理数，子空间拓扑）是仿紧的（度量空间）但非局部紧的（任何邻域的闭包不紧）。

### 9.4 复分析中的反例

**反例 12：非正规的全纯函数族**
- f_n(z) = n z 在单位圆盘上。不是局部一致有界的（在任何紧子集上 sup |n z| = n r → ∞）。
- 不是正规族：{f_n} 的任何子列在包含 0 的紧集上都不一致收敛（在 z=0 处为 0，在 z≠0 处趋于 ∞）。

**反例 13：内闭一致有界但在整个区域无界的全纯函数族**
- f_n(z) = z^n 在单位圆盘 D 上。
- 对任何紧 K ⊂ D，sup_{z∈K} |z^n| = r^n → 0（r = sup |z| &lt; 1），故内闭一致有界（实际上内闭一致收敛到 0）。
- 但在整个 D 上 sup |z^n| = 1（上确界，不是最大值），且当 z → 1⁻ 时 z^n → 1。
- 这是正规族（内闭一致收敛到 0）。

**反例 14：不取一个值但非正规的全纯函数族**
- f_n(z) = e^{nz} 在右半平面 {Re z > 0} 上。
- 每个 f_n 不取 0（指数函数永不为 0）。
- 但 {f_n} 不是正规族：在 z = 1 处 f_n(1) = e^n → ∞，在 z = -1（不在区域内）... 实际上在右半平面内，取 z = 1/n ∈ 右半平面，f_n(1/n) = e，但取 z = 2/n，f_n(2/n) = e²。族在紧集 {1/n : n} ∪ {0} 上... 需要更仔细的分析。
- 关键：Montel 第二定理要求不取**两个**值，不取一个值不足以保证正规性。

### 9.5 实变函数中的反例

**反例 15：L² 中有界但非相对紧的集**
- L²[0,1] 中的标准正交基 {e_n}（如三角函数系或 Rademacher 函数）。
- ||e_n||₂ = 1，有界。
- 但 ||e_m - e_n||₂ = √2（m ≠ n），无收敛子列。
- 这是无限维空间单位球非紧的标准例子。

**反例 16：L¹ 中有界且等度可积但非相对紧的集**
- Rademacher 函数 r_n(t) = sign(sin(2^n π t)) 在 L¹[0,1] 中。
- ||r_n||₁ = 1，有界。
- 等度可积（一致绝对连续）：|r_n| = 1，对任意可测集 A，∫_A |r_n| = m(A)，与 n 无关。
- 但 ||r_m - r_n||₁ = 1（m ≠ n，因为 r_m 和 r_n 在一半区间上同号、一半异号），无收敛子列。
- 这说明 L¹ 中仅有界 + 等度可积不足以保证紧性，还需要平移等度连续（Kolmogorov-Riesz 条件）。

**反例 17：弱收敛但不范数收敛的序列**
- 在 L²[0,1] 中，标准正交基 {e_n} 弱收敛到 0（Bessel 不等式：⟨e_n, f⟩ → 0）。
- 但 ||e_n||₂ = 1，不范数收敛到 0。
- 这说明弱紧性（弱收敛子列存在）比范数紧性弱得多。

**反例 18：非胎紧的概率测度族**
- δ_n（在点 n 处的 Dirac 测度）在 ℝ 上。
- 对任何紧集 K = [-M, M]，当 n > M 时 δ_n(K) = 0，故不是胎紧的。
- {δ_n} 没有弱收敛子列（任何子列的质量都"逃逸到无穷远"）。
- 这是 Prokhorov 定理中胎紧性必要性的标准例子。

## 第十章 历史演进

### 10.1 前史：从 Bolzano 到 Weierstrass

**Bernhard Bolzano（1781-1848）**：
- 1817 年证明了介值定理，首次使用了"有界无限集有极限点"的思想（后来的 Bolzano-Weierstrass 定理）。
- 他的工作在生前未被广泛认知，直到 20 世纪才被重新发现。

**Karl Weierstrass（1815-1897）**：
- 在 1860 年代的柏林讲座中，系统发展了 ε-δ 语言和紧性思想。
- 证明了"有界无限集有极限点"（Bolzano-Weierstrass 定理），并将其作为分析的基础工具。
- 他的学生（如 Cantor、Kowalevski、Schwarz）传播了他的思想。

### 10.2 Heine-Borel 定理的诞生

**Eduard Heine（1821-1881）**：
- 1872 年证明闭区间上连续函数一致连续时，使用了"可数开覆盖有有限子覆盖"的论证。
- 他没有明确表述紧性概念，但隐含使用了有限覆盖性质。

**Émile Borel（1871-1956）**：
- 1895 年在博士论文中明确表述了：闭区间的可数开覆盖有有限子覆盖。
- 这是第一个明确的"有限覆盖"定理。

**推广到任意覆盖**：
- Henri Lebesgue（1875-1941）和 Pierre Cousin（1867-1933）独立将 Borel 的结果推广到任意（不可数）开覆盖。
- Lebesgue 在 1902 年的积分理论论文中使用了一般形式的 Heine-Borel 定理。

**命名**："Heine-Borel 定理"这一名称由 Schoenflies 在 1900 年左右提出，尽管 Heine 从未明确表述过这个定理。

### 10.3 紧性概念的抽象化

**Maurice Fréchet（1878-1973）**：
- 1906 年在博士论文中创立了度量空间理论。
- 首次在一般度量空间中讨论紧性，使用"序列紧"的定义。
- 证明了度量空间中紧集的基本性质。

**Felix Hausdorff（1868-1942）**：
- 1914 年在《集合论基础》中创立了一般拓扑学。
- 引入了"开覆盖紧"的定义，并讨论了紧性的各种等价形式。
- 证明了紧 Hausdorff 空间的基本性质。

**Pavel Alexandrov（1896-1982）和 Pavel Urysohn（1898-1924）**：
- 1920 年代系统研究了紧性和仿紧性。
- 证明了紧度量空间的刻画定理。
- Urysohn 引理和 Urysohn 度量化定理是拓扑学的里程碑。

**"紧"（compact）一词的由来**：
- Fréchet 使用"compact"来描述序列紧空间。
- Hausdorff 使用"kompakt"来描述开覆盖紧空间。
- 经过一段时间的术语混乱，"compact"最终统一为开覆盖紧，"sequentially compact"用于序列紧。

### 10.4 函数空间紧性：Arzelà-Ascoli

**Giulio Ascoli（1843-1896）**：
- 1883 年引入了等度连续性的概念。
- 证明了等度连续 + 逐点有界 ⇒ 有一致收敛子列（在区间上）。

**Cesare Arzelà（1847-1912）**：
- 1895 年将 Ascoli 的结果推广并给出了完整证明。
- 明确表述了"等度连续 + 一致有界 ⇒ 相对紧"的定理。

**后续推广**：
- Fréchet 将定理推广到一般度量空间上的连续函数。
- 20 世纪进一步推广到拓扑空间和向量值函数。

### 10.5 复分析中的紧性：Montel

**Paul Montel（1876-1975）**：
- 1907 年在博士论文中引入了正规族的概念。
- 证明了 Montel 第一定理（局部一致有界 ⇒ 正规）。
- 1912 年证明了 Montel 第二定理（不取两个值 ⇒ 正规），这是他最深刻的结果。

**影响**：
- Montel 的正规族理论彻底改变了复分析的面貌。
- Picard 定理、Riemann 映射定理、Julia 集理论都以正规族为基础。
- 正规族概念后来推广到多复变和微分几何（Kobayashi 双曲性）。

### 10.6 20 世纪的发展

**Tychonoff 定理（1930）**：
- Andrey Tychonoff 证明了任意紧空间的积是紧的。
- 这是选择公理的等价形式之一，是拓扑学和泛函分析的基础。

**Banach-Alaoglu 定理（1940）**：
- Stefan Banach 在 1932 年证明了可分空间的情形。
- Leonidas Alaoglu 在 1940 年推广到一般 Banach 空间。
- 对偶空间单位球的弱*紧性是泛函分析的核心工具。

**Eberlein-Šmulian 定理（1947）**：
- William Eberlein 和 Witold Šmulian 独立证明了 Banach 空间中弱紧 ⟺ 弱序列紧。
- 这澄清了弱拓扑下紧性和序列紧性的关系。

**Prokhorov 定理（1956）**：
- Yuri Prokhorov 证明了概率测度族的紧性刻画（胎紧性）。
- 这是现代概率论和随机过程理论的基础。

## 第十一章 跨层对照与蜕变图谱

### 11.1 紧性定义的四层蜕变

| 层级 | 紧性的定义形式 | 核心特征 | 典型定理 |
|---|---|---|---|
| L0 初等 | "有界闭区间" | 几何直观 | 闭区间上连续函数有最值 |
| L1 数分 | 有界闭集（ℝⁿ 中） | Heine-Borel | Bolzano-Weierstrass、极值定理、一致连续 |
| L2 复变 | 正规族（函数空间的紧性） | 内闭一致收敛子列 | Montel 定理、Riemann 映射定理 |
| L3 实变 | 弱紧性、测度胎紧性 | 弱收敛子列、质量不逃逸 | Banach-Alaoglu、Eberlein-Šmulian、Prokhorov |

### 11.2 紧性条件的强度演化

从 L0 到 L3，紧性的"门槛"逐渐降低，但应用范围逐渐扩大：

**L0：有界闭区间**
- 条件最强：必须是 ℝ 中的闭区间
- 结论最强：连续函数有最值、一致连续
- 适用范围：仅限一元函数

**L1：ℝⁿ 中有界闭集**
- 条件：Heine-Borel 刻画
- 结论：连续函数有最值、一致连续、有限覆盖
- 适用范围：多元函数、欧氏空间

**L2：复平面上的紧集 + 函数族紧性**
- 紧集：同 L1（ℂ ≅ ℝ²）
- 函数族紧性：正规族（局部一致有界 ⇒ 内闭一致收敛子列）
- 新增：全纯性带来的强化（导数自动有界 ⇒ 等度连续）
- 适用范围：全纯函数族、共形映射

**L3：抽象空间中的各种紧性**
- 度量空间：全有界 + 完备
- Banach 空间：弱紧性（自反空间单位球弱紧）
- 测度空间：胎紧性（Prokhorov）
- 算子理论：紧算子
- 条件最弱、形式最多样，但每个都有特定的应用场景

### 11.3 关键定理的蜕变链

**Bolzano-Weierstrass 定理的蜕变**：
- L1：ℝⁿ 中有界序列有收敛子列
- L2：全纯函数族局部一致有界 ⇒ 有内闭一致收敛子列（Montel 第一定理）
- L3：自反空间中有界序列有弱收敛子列（Eberlein-Šmulian + 自反性）
- 共同本质：有界性 + 某种"完备性/全纯性/自反性" ⇒ 收敛子列存在

**Heine-Borel 定理的蜕变**：
- L1：ℝⁿ 中紧 = 有界闭
- L2：ℂ 中紧 = 有界闭（同 L1）；函数空间中紧 = 等度连续 + 逐点有界（Arzelà-Ascoli）
- L3：Lp 中紧 = 有界 + 平移等度连续 + 无穷远消失（Kolmogorov-Riesz）；测度族中紧 = 胎紧（Prokhorov）
- 共同本质：紧性 = "有界性" + "某种等度连续性/正则性" + "不逃逸条件"

**极值定理的蜕变**：
- L1：紧集上连续实值函数有最值
- L2：紧集上全纯函数的最大模在边界取得（最大模原理）
- L3：弱紧集上弱下半连续泛函有极小值（变分法直接方法）
- 共同本质：紧性保证存在性，额外结构（全纯/弱下半连续）决定位置/性质

### 11.4 反例的演化

| 反例类型 | L1 数分 | L2 复变 | L3 实变 |
|---|---|---|---|
| 有界但非紧 | (0,1) | 开圆盘内的函数族 | Lp 单位球 |
| 有界闭但非紧 | （ℝⁿ 中不存在） | （ℂ 中不存在） | 无限维 Banach 空间单位球 |
| 一致有界但非紧 | 无收敛子列的连续函数列 | 非正规全纯函数族 | 无弱收敛子列的有界序列（非自反空间） |
| 质量逃逸 | （不适用） | （不适用） | δ_n 测度族 |

### 11.5 紧性与完备性的跨层关系

| 层级 | 完备性 | 紧性 | 关系 |
|---|---|---|---|
| L1 | ℝ 完备 | [0,1] 紧 | 紧 ⇒ 完备；完备 ⇏ 紧 |
| L2 | ℂ 完备 | 紧 Riemann 面 | 紧 ⇒ 完备；全纯性强化紧性 |
| L3 | Banach 空间完备 | 弱紧性、紧算子 | 弱紧 ⇒ （弱）完备；紧算子是有限维的推广 |

## 第十二章 收敛沉淀与方法论

### 12.1 紧性证明的标准技术

**技术一：有限覆盖法**
- 适用：证明紧集上的整体性质（一致连续、有限交性质等）
- 步骤：对每个点取局部邻域满足性质 → 开覆盖 → 有限子覆盖 → 取最小参数得到全局性质
- 典型应用：一致连续性定理、Lebesgue 数引理

**技术二：取子列法（Bolzano-Weierstrass 法）**
- 适用：存在性证明、反证法
- 步骤：构造序列 → 紧性保证有收敛子列 → 子列极限满足目标性质
- 典型应用：极值定理、Peano 存在性定理、变分法直接方法

**技术三：区间套/二分法**
- 适用：实数轴或欧氏空间上的构造性证明
- 步骤：将空间二分 → 选保留性质的一半 → 区间套 → 极限点
- 典型应用：Bolzano-Weierstrass 定理、Heine-Borel 定理

**技术四：对角线法**
- 适用：函数空间、可数稠密点集上的逐点收敛
- 步骤：在可数点集上逐次取子列 → 对角线子列在所有点上收敛 → 等度连续性推广到全局
- 典型应用：Arzelà-Ascoli 定理、Montel 定理

**技术五：反证法 + 逃逸序列**
- 适用：证明非紧性或紧性的必要条件
- 步骤：假设性质不成立 → 构造"逃逸到无穷远"或"越来越分散"的序列 → 与紧性矛盾
- 典型应用：全有界性证明、胎紧性必要性

### 12.2 紧性的"充要图谱"学习法

对每个紧性概念，建立以下图谱：

**定义图谱**：
- 原始定义（开覆盖紧）
- 等价定义（序列紧、极限点紧、全有界+完备）
- 每个等价定义的适用场景和证明方法

**条件图谱**：
- 充分条件：什么条件能推出紧性？（有界闭、等度连续+有界、胎紧、自反+有界...）
- 必要条件：紧性能推出什么？（有界、闭、完备、可分...）
- 反例：每个蕴含关系的反例是什么？

**定理图谱**：
- 以紧性为条件的定理（极值定理、一致连续定理、Tychonoff...）
- 以紧性为结论的定理（Heine-Borel、Arzelà-Ascoli、Montel、Prokhorov...）
- 紧性在证明中扮演的角色（存在性、有限性、凝聚性）

**跨层图谱**：
- 同一概念在 L0/L1/L2/L3 中的形式变化
- 定理强度的演化（加强/弱化/推广）
- 反例的层级差异

### 12.3 常见误区与澄清

**误区一：有界闭集一定是紧的**
- 澄清：只在 ℝⁿ（有限维欧氏空间）中成立。无限维 Banach 空间中单位球是有界闭集但不紧。

**误区二：紧集一定是闭的**
- 澄清：只在 Hausdorff 空间中成立。非 Hausdorff 空间中紧集不一定闭。例如余有限拓扑中的任何子集都是紧的，但不一定闭。

**误区三：连续函数一定把紧集映为紧集，所以紧性是拓扑不变量**
- 澄清：前半句正确（连续映射保持紧性），但紧性是拓扑不变量是因为同胚（连续双射且逆连续）保持紧性。连续映射本身不保持拓扑结构。

**误区四：序列紧和紧是一回事**
- 澄清：在度量空间中等价，在一般拓扑空间中不等价。存在紧但非序列紧的空间（βℕ），也存在序列紧但非紧的空间（[0,ω₁)）。

**误区五：全纯函数族一致有界就一定正规**
- 澄清：需要**局部**一致有界（在每个紧子集上一致有界），而不是在整个区域上一致有界。整个区域上一致有界当然蕴含局部一致有界，但局部一致有界是更弱的条件。

**误区六：Lp 中有界序列一定有收敛子列**
- 澄清：范数拓扑下不一定（无限维空间单位球非紧）。弱拓扑下，自反空间（如 Lp, 1&lt;p&lt;∞）中有界序列有弱收敛子列；非自反空间（如 L¹, L^∞）中不一定。

### 12.4 紧性在分析学体系中的定位

紧性是分析学的"存在性引擎"：

1. **完备性**回答"Cauchy 列的极限是否在空间内"——是分析的"地基"
2. **紧性**回答"任意序列是否有收敛子列"——是分析的"引擎"
3. **连续性**回答"极限运算是否保持"——是分析的"传动装置"
4. **可微性/可积性**是在紧性和连续性基础上的"高级功能"

没有紧性，大量存在性定理无法证明：
- 极值定理（紧集上连续函数有最值）
- 常微分方程解的存在性（Peano 定理）
- Riemann 映射定理（正规族保证极值函数存在）
- 变分法中的极小元存在性（弱紧性 + 弱下半连续）
- 中心极限定理（Prokhorov 定理保证测度弱收敛子列）

紧性的本质是"有限性"：它把无限过程压缩到有限范围内处理，从而使存在性证明成为可能。这是分析学最深刻的思想之一。

## 第十三章 外部校验与五类边

### 13.1 证伪任务

**任务 1**：找一个度量空间，其中存在有界闭集但不是紧集。
- 答案：无限维 Hilbert 空间 ℓ² 中的单位球 {x : ||x|| ≤ 1}。它是有界闭集，但标准正交基 {e_n} 没有收敛子列（||e_m - e_n|| = √2），故不紧。

**任务 2**：找一个拓扑空间，其中紧集不一定是闭集。
- 答案：至少两个点的集合赋以余有限拓扑（补集有限的集是开集）。任何子集都是紧的（任何开覆盖中任取一个非空开集，其补集有限，再取有限个覆盖补集），但任何无限真子集都不是闭集（闭集是有限集或全集）。

**任务 3**：找一个全纯函数族，在区域上逐点有界但不是正规族。
- 答案：在单位圆盘 D 上，f_n(z) = n。这是常函数族，逐点有界吗？不，在每个固定点 z，f_n(z) = n → ∞，不是逐点有界。需要找逐点有界但非局部一致有界的例子。
- 正确答案：f_n(z) = n z^n。在每个固定 z ∈ D，|n z^n| → 0（因为 |z| &lt; 1，指数衰减快于线性增长），故逐点有界（实际上逐点收敛到 0）。但在紧集 K = {r e^{iθ} : 0 ≤ θ ≤ 2π}（r 接近 1）上，sup |n z^n| = n r^n，当 n = 1/|ln r| 时取最大值约 1/(e|ln r|)，当 r → 1 时趋于无穷。故不是局部一致有界，不是正规族。

**任务 4**：找一个概率测度族，有界（总变差为 1）但不相对紧。
- 答案：δ_n（在点 n 处的 Dirac 测度）在 ℝ 上。总变差为 1（有界），但不是胎紧的，故不相对紧（Prokhorov 定理）。

### 13.2 真题锚点

**数学分析考研真题**：
1. 证明：闭区间 [a,b] 上的连续函数族 F 等度连续且一致有界，则 F 有一致收敛子列。（Arzelà-Ascoli 定理的直接应用）
2. 设 f 在 ℝ 上一致连续，证明存在常数 A, B > 0 使得 |f(x)| ≤ A|x| + B。（紧性 + 一致连续的标准题）
3. 证明：紧度量空间上的连续函数是一致连续的。（Lebesgue 数法或有限覆盖法）

**复变函数考研真题**：
1. 叙述并证明 Montel 定理（第一定理）。
2. 用正规族理论证明 Riemann 映射定理的存在性部分。
3. 设 {f_n} 是区域 D 上的全纯函数列，内闭一致有界，证明 {f_n'} 也内闭一致有界。（Cauchy 积分公式 + Montel）

**实变函数/泛函分析考研真题**：
1. 证明：无限维 Banach 空间的单位球不是紧的。（Riesz 引理）
2. 叙述并证明 Kolmogorov-Riesz 定理（Lp 空间紧性刻画）。
3. 证明：自反 Banach 空间的闭单位球是弱紧的。（Banach-Alaoglu + 自反性）
4. 叙述 Prokhorov 定理并说明其在中心极限定理证明中的作用。

### 13.3 例生成

**例 1（紧性判定）**：判断以下集合在指定空间中是否紧：
(a) [0,1] ∩ ℚ 在 ℚ 中（子空间拓扑）
(b) {1/n : n ∈ ℕ} 在 ℝ 中
(c) {1/n : n ∈ ℕ} ∪ {0} 在 ℝ 中
(d) 单位球面 S² 在 ℝ³ 中
(e) C[0,1] 中的 {f : ||f||_∞ ≤ 1 且 f 是 Lipschitz 常数为 1 的函数}

答案：
(a) 不紧。{1/n} ⊂ [0,1] ∩ ℚ 收敛到 0 ∉ ℚ，无收敛子列在 ℚ 内。
(b) 不紧。{1/n} 收敛到 0 ∉ {1/n}，不是闭集。
(c) 紧。有界闭集（Heine-Borel）。
(d) 紧。有界闭集。
(e) 紧。等度连续（Lipschitz 常数为 1）+ 一致有界（||f|| ≤ 1），由 Arzelà-Ascoli，闭包紧。此集本身是闭集（Lipschitz 条件和范数条件在一致收敛下保持），故紧。

**例 2（反例构造）**：构造一个连续函数列 {f_n} 在 [0,1] 上一致有界，但没有一致收敛子列。
- 构造：f_n(x) = sin(nx)。一致有界（|f_n| ≤ 1）。
- 证明无一致收敛子列：假设 {sin(n_k x)} 一致收敛到 f。则 f 连续。但 ∫₀^π sin(n_k x) sin(n_m x) dx = 0（n_k ≠ n_m），而若一致收敛，∫ (sin(n_k x) - sin(n_m x))² dx → 0。计算得 ∫ (sin(n_k x) - sin(n_m x))² dx = π（n_k ≠ n_m），矛盾。故无一致收敛子列。

**例 3（紧性应用）**：用紧性证明：若 f : [a,b] → ℝ 连续且 f(x) > 0 对所有 x，则存在 c > 0 使得 f(x) ≥ c 对所有 x。
- 证明：[a,b] 紧，f 连续，故 f 取得最小值 m = min f。由 f(x) > 0，m > 0。取 c = m/2 > 0，则 f(x) ≥ m > c。

### 13.4 五类边

**边界一：紧 vs 非紧**
- 判定标准：开覆盖是否有有限子覆盖 / 序列是否有收敛子列
- 临界案例：[0,1)（非紧，因为 1 是"缺失的极限点"）；[0,1]（紧）
- 关键：紧性对"边界点"的包含非常敏感

**边界二：序列紧 vs 开覆盖紧**
- 在度量空间中重合，在一般拓扑空间中分离
- 临界案例：[0,ω₁)（序列紧非紧）、βℕ（紧非序列紧）
- 关键：第一可数性是两者等价的桥梁

**边界三：强紧性 vs 弱紧性**
- 范数拓扑紧（强紧）vs 弱拓扑紧
- 临界案例：无限维自反空间单位球（弱紧非强紧）
- 关键：弱拓扑开集更少，更容易紧

**边界四：点态紧性 vs 函数族紧性**
- 空间中点集的紧性 vs 函数空间中函数族的紧性
- 临界案例：C(K) 中单位球（非紧）vs 等度连续有界族（紧）
- 关键：函数族紧性需要额外的"等度连续"条件

**边界五：测度的紧性（胎紧）vs 函数的紧性**
- 测度族的胎紧性（质量不逃逸）vs 函数族的紧性
- 临界案例：δ_n（非胎紧）vs 一致可积族（可能紧）
- 关键：测度紧性关注"质量分布"，函数紧性关注"函数值行为"

---

> **模块结语**：紧性是分析学中最深刻的概念之一。从实数轴上的"有界闭集"到度量空间的"全有界+完备"，从函数空间的 Arzelà-Ascoli 到复分析的 Montel 正规族，从 Banach 空间的弱紧性到测度论的胎紧性，紧性的形式不断蜕变，但其核心始终如一——**在无限中找到有限的控制，在变化中找到不变的凝聚**。掌握紧性，就掌握了分析学存在性证明的钥匙。
