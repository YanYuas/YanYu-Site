## 第一章 引言：完备化的哲学——填补针孔与选择公理的代价

### 1.1 完备化的双重面孔

在 D6-1 到 D6-5 中，我们反复遇到"完备化"这个概念：

- D6-1：从 ℚ 完备化得到 ℝ（Dedekind 分割 / Cantor 基本列）
- D6-4：从 C[a,b] 在 Lp 范数下完备化得到 Lp[a,b]
- D6-5：Riesz-Fischer 定理证明 Lp 空间完备

完备化的形象是"填补针孔"——把空间中缺失的极限点加进来，使 Cauchy 列都有极限。这是一个"建设性"的操作，它扩展了空间，使分析学的存在性证明成为可能。

但完备化还有另一张面孔：**测度的完备化**。当我们从 Borel 测度完备化到 Lebesgue 测度时，我们把所有零测集的子集都加进了可测集族。这看起来也是"填补针孔"——把"应该测度为零但原来不可测"的集合加进来。

然而，这个过程引出了一个深刻的问题：**我们能否把所有子集都变成可测的？** 答案是否定的——在选择公理下，存在不可测集。不可测集的存在是完备性的"阴暗面"——我们为了获得完备的测度理论（Lebesgue 测度），必须接受一些集合不可测的事实。

**📐 几何锚定**：完备化的几何图像是"给有针孔的空间填补针孔"。实数轴的针孔是无理数，填补后得到完整的实数轴；函数空间的针孔是不连续函数，填补后得到 Lp 空间。但测度完备化的几何图像更微妙——Borel 集是"可以通过开集的可数并/交/补得到的集合"，它们在几何上是"可构造的"集合。Lebesgue 可测集是在 Borel 集的基础上加上所有零测集的子集——这些子集在几何上可能是"极其病态"的，无法通过简单的构造得到。不可测集则是"完全无法测量的集合"——它们在几何上没有明确的"体积"或"长度"，就像现实中"没有面积的图形"一样。选择公理允许我们构造这样的集合，但代价是我们必须接受它们的存在。

## 第二章 度量空间完备化的一般理论

### 2.1 完备化的定义

**定义**：设 (X, d) 是度量空间。X 的完备化是一个完备度量空间 (X̃, d̃)，以及一个等距嵌入 i : X → X̃，使得 i(X) 在 X̃ 中稠密。

**完备化的唯一性**：若 (X̃₁, d̃₁, i₁) 和 (X̃₂, d̃₂, i₂) 都是 X 的完备化，则存在等距同构 φ : X̃₁ → X̃₂ 使得 φ ∘ i₁ = i₂。因此完备化在等距同构意义下唯一。

### 2.2 完备化的构造（Cantor 基本列法）

D6-4 第七章中我们给出了完备化的构造方法，这里回顾并深化：

**第一步**：设 C(X) 为 X 中所有 Cauchy 列的集合。

**第二步**：在 C(X) 上定义等价关系：{xₙ} ~ {yₙ} ⇔ lim d(xₙ, yₙ) = 0。

**第三步**：令 X̃ = C(X)/~，定义 d̃([{xₙ}], [{yₙ}]) = lim d(xₙ, yₙ)。

**第四步**：定义 i(x) = [{x, x, x, ...}]（常值列的等价类）。

**第五步**：验证 (X̃, d̃) 完备，i 等距，i(X) 稠密。

### 2.3 完备化的例子

| 原空间 | 度量/范数 | 完备化 | 针孔的本质 |
|---|---|---|---|
| ℚ | |x-y| | ℝ | 无理数 |
| (0,1) | |x-y| | [0,1] | 端点 0 和 1 |
| C[a,b] | Lp 范数 | Lp[a,b] | 不连续函数 |
| R[a,b] | L¹ 范数 | L¹[a,b] | 非 Riemann 可积函数 |
| P[a,b] | sup 范数 | C[a,b] | 非多项式连续函数 |
| C¹[a,b] | sup 范数 | C[a,b] | 连续但不可微函数 |
| 连续函数 | L² 内积 | L²[a,b] | 不连续函数 |

**📐 几何图像**：完备化的几何图像是"给有洞的空间补洞"。每个不完备空间都有"针孔"——Cauchy 列可以挤向但不在空间内的点。完备化就是把所有针孔都填上，得到一个没有针孔的完备空间。不同空间的针孔有不同的"形状"：ℚ 的针孔是无理数（一维直线上的点），C[a,b] Lp 的针孔是不连续函数（无限维空间中的点），P[a,b] sup 的针孔是非多项式连续函数。完备化的构造方法（Cauchy 列等价类）是通用的——不管针孔是什么形状，都可以用"指向针孔的逼近序列"来定位并填补它。

### 2.4 完备化中的元素是什么？

完备化空间 X̃ 中的元素是 X 中 Cauchy 列的等价类。这是一个抽象的构造——X̃ 中的元素不是 X 中的"点"，而是"X 中点列的等价类"。

但在许多具体情况下，完备化可以有更具体的实现：
- ℚ 的完备化 ℝ：元素是实数（可以用 Dedekind 分割或小数展开具体表示）
- C[a,b] Lp 的完备化 Lp[a,b]：元素是 Lebesgue p-次可积函数的等价类
- P[a,b] sup 的完备化 C[a,b]：元素是连续函数

**关键洞察**：完备化的抽象构造（Cauchy 列等价类）总是可行的，但找到完备化的"具体实现"（用更熟悉的对象表示等价类）可能需要深刻的理论。Lebesgue 积分理论的核心成就之一，就是给出了 C[a,b] Lp 完备化的具体实现——Lp 空间中的元素是 Lebesgue 可积函数，而不是抽象的 Cauchy 列等价类。

## 第三章 完备化的泛性质与延拓定理

### 3.1 完备化的泛性质

**定理（完备化的泛性质）**：设 (X̃, d̃, i) 是度量空间 X 的完备化。对任何完备度量空间 Y 和任何一致连续映射 f : X → Y，存在唯一的连续映射 f̃ : X̃ → Y 使得 f̃ ∘ i = f。

而且 f̃ 是一致连续的，且如果 f 是 Lipschitz 常数为 K 的 Lipschitz 映射，则 f̃ 也是 Lipschitz 常数为 K 的 Lipschitz 映射。

**证明**：
- **存在性**：对 ξ = [{xₙ}] ∈ X̃，定义 f̃(ξ) = lim f(xₙ)。因为 f 一致连续，{f(xₙ)} 是 Y 中的 Cauchy 列（d(f(xₘ),f(xₙ)) ≤ ω(d(xₘ,xₙ)) → 0，其中 ω 是 f 的连续模），由 Y 完备，极限存在。
- **良定义**：若 {xₙ} ~ {yₙ}，则 d(xₙ,yₙ) → 0，由一致连续性 d(f(xₙ),f(yₙ)) → 0，故 lim f(xₙ) = lim f(yₙ)。
- **唯一性**：若 g̃ 也满足 g̃ ∘ i = f，则 g̃ 和 f̃ 在稠密子集 i(X) 上相等，由连续性，在整个 X̃ 上相等。
- **一致连续性**：由 f 的一致连续性和极限的定义可推出 f̃ 的一致连续性。∎

### 3.2 泛性质的意义

完备化的泛性质是一个强大的工具，它说明：

1. **完备化是"最小"的完备扩张**：任何从 X 到完备空间的一致连续映射都可以唯一延拓到完备化上。这意味着完备化是 X 的"泛完备扩张"——它不包含任何多余的结构。

2. **延拓的唯一性**：延拓是唯一的，这使得我们可以无歧义地谈论"f 在完备化上的延拓"。

3. **保持 Lipschitz 常数**：如果 f 是 Lipschitz 映射，其延拓保持相同的 Lipschitz 常数。这在泛函分析中有重要应用。

### 3.3 线性延拓

**定理（有界线性算子的延拓）**：设 X 是赋范线性空间，X̃ 是其完备化（Banach 空间），Y 是 Banach 空间。任何有界线性算子 T : X → Y 可以唯一延拓为有界线性算子 T̃ : X̃ → Y，且 ||T̃|| = ||T||。

**证明**：有界线性算子是 Lipschitz 映射（Lipschitz 常数为 ||T||），由完备化的泛性质，T 可以唯一延拓为连续映射 T̃。T̃ 的线性性由 T 的线性性和连续性推出（T̃(αξ+βη) = lim T(αxₙ+βyₙ) = α lim T(xₙ) + β lim T(yₙ) = αT̃(ξ)+βT̃(η)）。范数保持由泛性质推出。∎

**应用**：
- Fourier 变换：从 Schwartz 空间（或 L¹∩L²）延拓到 L² 上的酉算子
- 微分算子：从 C^∞ 延拓到 Sobolev 空间上的有界算子
- 积分算子：从连续函数空间延拓到 Lp 空间上的有界算子

### 3.4 Hahn-Banach 延拓定理

与完备化的泛性质不同，Hahn-Banach 定理处理的是"从子空间到全空间"的延拓，而不是"从不完备空间到完备化"的延拓。

**定理（Hahn-Banach 定理）**：设 M 是赋范线性空间 X 的子空间，φ 是 M 上的有界线性泛函。则 φ 可以延拓为 X 上的有界线性泛函 Φ，且 ||Φ|| = ||φ||。

Hahn-Banach 定理不需要完备性——它对任何赋范线性空间成立。但它在完备化理论中有重要应用：它保证了 Banach 空间的对偶空间"足够大"。

**📐 几何深化**：完备化泛性质的几何图像是"地图的延拓"。想象你有一张不完备空间 X 的地图，地图上的每个点 x 对应完备空间 Y 中的一个点 f(x)。由于 X 有针孔，地图只覆盖了 X 的部分区域。完备化 X̃ 填补了所有针孔，泛性质说的是：你可以把地图唯一地延拓到整个 X̃ 上——每个针孔（Cauchy 列的等价类）在 Y 中都有唯一的对应点（f(xₙ) 的极限）。延拓后的地图 f̃ 保持了原地图的所有性质（一致连续性、Lipschitz 常数）。这就像给一张有洞的地图补洞——洞的位置由周围的地图信息唯一确定。

## 第四章 测度的完备化

### 4.1 测度空间的完备化

**定义**：设 (X, ℳ, μ) 是测度空间。定义
ℳ̄ = {E ∪ N : E ∈ ℳ, N ⊂ F 对某个 F ∈ ℳ 且 μ(F)=0}
即 ℳ̄ 是所有"可测集并上零测集的子集"的集合。

定义 μ̄(E ∪ N) = μ(E)。

**定理**：(X, ℳ̄, μ̄) 是完备测度空间，且 ℳ ⊂ ℳ̄，μ̄|_ℳ = μ。(X, ℳ̄, μ̄) 称为 (X, ℳ, μ) 的完备化。

**完备测度空间的定义**：测度空间 (X, ℳ, μ) 称为完备的，如果任何零测集的子集都属于 ℳ（即可测）。

**证明**：
1. **ℳ̄ 是 σ-代数**：
   - ∅ ∈ ℳ̄（∅ = ∅ ∪ ∅）
   - 若 A = E ∪ N ∈ ℳ̄，则 A^c = E^c ∩ N^c。需要证明 A^c ∈ ℳ̄。设 N ⊂ F, μ(F)=0。则 A^c = (E^c \ F) ∪ (F \ (E ∪ N))，其中 E^c \ F ∈ ℳ，F \ (E ∪ N) ⊂ F（零测集的子集）。故 A^c ∈ ℳ̄。
   - 可数并：若 Aₙ = Eₙ ∪ Nₙ ∈ ℳ̄，Nₙ ⊂ Fₙ, μ(Fₙ)=0，则 ⋃Aₙ = (⋃Eₙ) ∪ (⋃Nₙ)，其中 ⋃Eₙ ∈ ℳ，⋃Nₙ ⊂ ⋃Fₙ，μ(⋃Fₙ) ≤ Σμ(Fₙ)=0。故 ⋃Aₙ ∈ ℳ̄。
2. **μ̄ 是测度**：可数可加性由 μ 的可数可加性和零测集的性质推出。
3. **完备性**：若 A ∈ ℳ̄ 且 μ̄(A)=0，则 A = E ∪ N, μ(E)=0。A 的任何子集 B 可以写成 B = (B∩E) ∪ (B∩N)，其中 B∩E ⊂ E（零测集的子集），B∩N ⊂ N ⊂ F（零测集的子集）。故 B ∈ ℳ̄。
4. **延拓**：ℳ ⊂ ℳ̄（取 N=∅），μ̄|_ℳ = μ。∎

### 4.2 为什么需要测度完备化

测度完备化的必要性体现在以下几个方面：

1. **零测集的子集应该可测**：如果一个集合的测度为零，那么它的任何子集"应该"也有测度零（因为子集的"大小"不超过原集合）。但在非完备测度空间中，零测集的子集可能不可测。

2. **Lebesgue 积分理论需要完备测度**：在 Lebesgue 积分理论中，"几乎处处"是一个核心概念。如果 f = g a.e. 且 f 可测，那么 g 也应该可测。但 g 与 f 的差异集是零测集的子集，如果测度不完备，这个子集可能不可测，从而 g 可能不可测。完备测度保证了 a.e. 相等的函数具有相同的可测性。

3. **Fubini 定理需要完备测度**：Fubini 定理的某些形式需要测度完备化才能成立。

**📐 几何图像**：测度完备化的几何图像是"给零测集的'影子'也赋予测度"。想象一个零测集 F（比如 Cantor 集，测度为零但不可数）。F 有不可数多个子集，但在非完备测度（如 Borel 测度）中，F 的许多子集可能不可测——它们是"没有面积的阴影"。测度完备化把所有这些阴影都加进可测集族，并赋予它们测度零。几何上，这就像承认"零体积物体的任何部分也有零体积"——一个点没有长度，点的任何子集（还是点或空集）也没有长度；Cantor 集没有长度，Cantor 集的任何子集也没有长度。完备化使这个几何直觉严格化。

### 4.3 Borel 测度与 Lebesgue 测度

**Borel σ-代数**：ℝ 上的 Borel σ-代数 ℬ(ℝ) 是由所有开集生成的 σ-代数。Borel 集包括开集、闭集、可数个开集的交（G_δ 集）、可数个闭集的并（F_σ 集）等。

**Borel 测度**：定义在 Borel σ-代数上的测度。ℝ 上的 Lebesgue 测度最初定义在 Borel σ-代数上（通过外测度或 Riesz 表示定理），但这个测度不完备。

**Lebesgue 可测集**：Lebesgue 可测集的 σ-代数 ℒ(ℝ) 是 Borel σ-代数的完备化。即
ℒ(ℝ) = {E ∪ N : E ∈ ℬ(ℝ), N ⊂ F, F ∈ ℬ(ℝ), m(F)=0}

**定理**：Lebesgue 测度是完备的。

**Borel 集与 Lebesgue 可测集的关系**：
- ℬ(ℝ) ⊊ ℒ(ℝ)（严格包含）
- 每个 Lebesgue 可测集可以表示为 Borel 集与零测集子集的并
- 存在 Lebesgue 可测但不是 Borel 的集合（需要选择公理或连续统假设）

**基数比较**：
- Borel 集的基数是 c（连续统基数，与实数一样多）
- Lebesgue 可测集的基数是 2^c（与 ℝ 的所有子集一样多）
- 因此"大多数"Lebesgue 可测集不是 Borel 集

## 第五章 Lebesgue 测度的构造与性质

### 5.1 外测度

**定义（Lebesgue 外测度）**：对 E ⊂ ℝ，定义
m*(E) = inf{Σ |Iₙ| : E ⊂ ⋃ Iₙ, Iₙ 是开区间}

其中 |Iₙ| 是区间 Iₙ 的长度。

**外测度的性质**：
1. 非负性：m*(E) ≥ 0，m*(∅)=0
2. 单调性：E ⊂ F ⟹ m*(E) ≤ m*(F)
3. 次可数可加性：m*(⋃Eₙ) ≤ Σm*(Eₙ)
4. 区间的外测度等于其长度：m*([a,b]) = b-a

**外测度不是测度**：外测度定义在 ℝ 的所有子集上，但不满足可数可加性（存在不相交的集合 A,B 使得 m*(A∪B) &lt; m*(A)+m*(B)）。这是不可测集存在的另一种表现。

### 5.2 Carathéodory 可测性判据

**定义（Carathéodory 可测）**：集合 E ⊂ ℝ 称为 Lebesgue 可测的，如果对任意 A ⊂ ℝ，
m*(A) = m*(A ∩ E) + m*(A ∩ E^c)

即可测集 E 可以"干净利落地"分割任何集合 A 的外测度。

**定理**：Lebesgue 可测集构成 σ-代数，外测度在这个 σ-代数上的限制是完备测度（Lebesgue 测度）。

**为什么这个判据有效？**：Carathéodory 判据的几何意义是：可测集是"边界足够规则"的集合——它不会在分割其他集合时"丢失"或"增加"测度。不可测集的"边界"极其病态，以至于它在分割某些集合时会导致测度的"丢失"。

### 5.3 Lebesgue 测度的性质

**定理**：Lebesgue 测度 m 具有以下性质：
1. **完备性**：任何零测集的子集可测且测度为零
2. **平移不变性**：m(E+x) = m(E) 对所有 x ∈ ℝ
3. **可数可加性**：对不相交的可测集列 {Eₙ}，m(⋃Eₙ) = Σm(Eₙ)
4. **正则性**：
   - 外正则：m(E) = inf{m(U) : E ⊂ U, U 开}
   - 内正则：m(E) = sup{m(K) : K ⊂ E, K 紧}（对 σ-有限集）
5. **连续性**：
   - 下连续：若 E₁ ⊂ E₂ ⊂ ...，则 m(⋃Eₙ) = lim m(Eₙ)
   - 上连续：若 E₁ ⊃ E₂ ⊃ ... 且 m(E₁) &lt; ∞，则 m(⋂Eₙ) = lim m(Eₙ)

**📐 几何深化**：Lebesgue 测度的几何图像是"给所有'足够规则'的集合赋予长度"。Borel 集是"通过开集的可数运算构造的集合"——它们在几何上是"可构造的"。Lebesgue 可测集在 Borel 集的基础上加上了所有零测集的子集——这些子集在几何上可能是"极其病态"的，但因为它们"包含在零体积的集合中"，所以测度为零。Lebesgue 测度的平移不变性是一个关键性质——它说的是"长度不依赖于位置"，这与我们的几何直觉一致。但正是平移不变性 + 可数可加性 + 选择公理，导致了不可测集的存在（Vitali 定理，下一章）。

## 第六章 不可测集的存在性——Vitali 定理

### 6.1 Vitali 定理

**定理（Vitali，1905）**：在选择公理下，存在 ℝ 的子集 V，使得 V 不是 Lebesgue 可测的。

更准确地说：不存在定义在 ℝ 的所有子集上的测度 μ，满足以下三个条件：
1. μ 是可数可加的
2. μ 是平移不变的（μ(E+x)=μ(E)）
3. μ([0,1]) = 1（或任何有限正数）

这三个条件不可兼得。Lebesgue 测度满足 1, 2, 3，但只定义在可测集上，不定义在所有子集上。如果要求定义在所有子集上，就必须放弃其中一个条件。

### 6.2 Vitali 定理的证明

**证明**：反证，假设存在定义在所有子集上的可数可加平移不变测度 μ，且 μ([0,1])=1。

**第一步：定义等价关系**
在 [0,1] 上定义等价关系：x ~ y ⇔ x - y ∈ ℚ（即 x 和 y 差一个有理数）。

这个等价关系把 [0,1] 分成了不可数多个等价类，每个等价类是可数集（因为 ℚ 可数）。

**第二步：用选择公理选取代表元**
由选择公理，存在集合 V ⊂ [0,1]，使得 V 与每个等价类恰好交于一个点。V 称为 Vitali 集。

**第三步：V 的平移覆盖 [0,1]**
设 ℚ∩[-1,1] = {r₁, r₂, ...}（可数枚举）。考虑 V 的平移 V + rₙ = {v + rₙ : v ∈ V}。

- **不相交性**：若 (V + rₘ) ∩ (V + rₙ) ≠ ∅，则存在 v₁, v₂ ∈ V 使得 v₁ + rₘ = v₂ + rₙ，即 v₁ - v₂ = rₙ - rₘ ∈ ℚ。由 V 的定义（每个等价类一个代表元），v₁ = v₂，故 rₘ = rₙ，即 m=n。因此 {V + rₙ} 两两不相交。

- **包含关系**：对任意 x ∈ [0,1]，存在 v ∈ V 使得 x ~ v（因为 V 包含每个等价类的代表元），即 x - v = r ∈ ℚ。由于 x, v ∈ [0,1]，r ∈ [-1,1]，故 r = rₙ 对某个 n。因此 x = v + rₙ ∈ V + rₙ。所以 [0,1] ⊂ ⋃(V + rₙ)。

- **上界**：⋃(V + rₙ) ⊂ [-1, 2]（因为 V ⊂ [0,1], rₙ ∈ [-1,1]）。

**第四步：测度计算导致矛盾**
由可数可加性和平移不变性：
μ(⋃(V + rₙ)) = Σ μ(V + rₙ) = Σ μ(V)

由包含关系 [0,1] ⊂ ⋃(V + rₙ) ⊂ [-1,2]：
1 = μ([0,1]) ≤ μ(⋃(V + rₙ)) ≤ μ([-1,2]) = 3

所以 1 ≤ Σ μ(V) ≤ 3。

但 Σ μ(V) 是可数个相同数 μ(V) 的和：
- 若 μ(V) = 0，则 Σ μ(V) = 0，与 ≥ 1 矛盾
- 若 μ(V) > 0，则 Σ μ(V) = ∞，与 ≤ 3 矛盾

因此不存在这样的测度。∎

### 6.3 Vitali 集的性质

Vitali 集 V 具有以下性质：
1. **不可测**：V 不是 Lebesgue 可测的
2. **外测度大于零**：m*(V) > 0（如果 m*(V)=0，则 V 可测且测度为零，矛盾）
3. **内测度为零**：m_*(V) = 0（V 的任何可测子集测度为零，否则可以用类似的平移论证导致矛盾）
4. **不可测集的"稠密性"**：V 在 [0,1] 中稠密吗？不一定，但 V 的平移族覆盖 [0,1]
5. **基数**：V 的基数是 c（连续统基数），因为 [0,1] 有 c 个点，分成 c 个等价类（每个可数），所以有 c 个等价类，V 选 c 个代表元

**📐 几何图像**：Vitali 集的几何图像是"从每个有理数平移轨道上选一个点"。想象把 [0,1] 中的点按"差为有理数"分组——每组是一条"有理数轨道"（可数个点，彼此差有理数）。Vitali 集从每条轨道上选恰好一个点。这个选择需要选择公理，因为有不可数多条轨道，我们无法给出一个明确的选择规则。Vitali 集的几何图像极其病态——它在 [0,1] 中"均匀分布"，但没有明确的"长度"。如果它有长度 L，那么把它平移所有有理数距离（可数多个），得到的不相交并集的长度应该是可数个 L 的和——如果 L=0，总和为 0，但并集包含 [0,1]（长度 1），矛盾；如果 L>0，总和为无穷大，但并集包含在 [-1,2]（长度 3）中，矛盾。Vitali 集就是一个"没有长度的集合"——它在几何上无法被测量。

### 6.4 Vitali 定理的意义

Vitali 定理是测度论中最深刻的结果之一，它的意义包括：

1. **测度论的逻辑边界**：我们不能测量所有集合。任何试图给所有集合赋予平移不变可数可加测度的尝试都注定失败。

2. **选择公理的代价**：不可测集的存在依赖于选择公理。如果放弃选择公理（如在 Solovay 模型中），可以构造一个集合论模型，其中所有实数集都是 Lebesgue 可测的。但这需要放弃选择公理（或接受不可达基数的存在）。

3. **Lebesgue 测度的"最优性"**：Lebesgue 测度在"定义在尽可能多的集合上"和"保持平移不变可数可加性"之间取得了最优平衡。它定义在所有 Borel 集和零测集的子集上，但不能定义在所有子集上。

4. **分析学的基础**：不可测集的存在意味着分析学中的许多定理（如 Fubini 定理、控制收敛定理）需要可测性条件。我们不能随意对函数和集合进行操作，必须验证可测性。

## 第七章 Vitali 不可测集的深度剖析

### 7.1 Vitali 集的构造细节

让我们更仔细地考察 Vitali 集的构造：

**等价类的结构**：对 x ∈ [0,1]，其等价类 [x] = {y ∈ [0,1] : y - x ∈ ℚ}。每个等价类是可数无穷集（因为 ℚ 可数，且对每个有理数 q，x+q 可能落在 [0,1] 内或外，但落在 [0,1] 内的有无穷多个）。

**等价类的数量**：[0,1] 有 c 个点，每个等价类可数（ℵ₀ 个点），所以等价类的数量是 c/ℵ₀ = c（连续统基数）。

**选择公理的作用**：从 c 个等价类中各选一个代表元，需要选择公理。没有选择公理，我们无法保证这样的选择集合存在（在某些没有选择公理的集合论模型中，所有实数集都可测）。

### 7.2 Vitali 集的不可测性证明（直接证明）

上面我们用反证法证明了"不存在定义在所有子集上的平移不变可数可加测度"。这里直接证明 Vitali 集 V 不是 Lebesgue 可测的。

**证明**：反证，假设 V 可测。

由平移不变性，每个 V + rₙ 可测且 m(V + rₙ) = m(V)。

由不相交性和可数可加性：
m(⋃(V + rₙ)) = Σ m(V + rₙ) = Σ m(V)

由 [0,1] ⊂ ⋃(V + rₙ) ⊂ [-1,2]：
1 = m([0,1]) ≤ m(⋃(V + rₙ)) ≤ m([-1,2]) = 3

所以 1 ≤ Σ m(V) ≤ 3。

但 Σ m(V) 是可数个 m(V) 的和：
- m(V) = 0 ⟹ Σ m(V) = 0 &lt; 1，矛盾
- m(V) > 0 ⟹ Σ m(V) = ∞ > 3，矛盾

因此 V 不可测。∎

### 7.3 Vitali 集的外测度和内测度

**外测度**：m*(V) > 0。

证明：若 m*(V)=0，则 V 可测（外测度为零的集合可测，因为任何零测集的子集在完备测度中可测），与 V 不可测矛盾。

更精确地，可以证明 m*(V) > 0，但 m*(V) 的具体值不确定（依赖于代表元的选择）。

**内测度**：m_*(V) = 0。

内测度定义为 m_*(E) = sup{m(K) : K ⊂ E, K 紧（或可测）}。

证明：若存在可测集 K ⊂ V 且 m(K) > 0，则考虑 K 的平移 K + rₙ。这些平移两两不相交（因为 K ⊂ V，V 的平移不相交），且 ⋃(K + rₙ) ⊂ [-1,2]。由可数可加性，m(⋃(K+rₙ)) = Σm(K) = ∞（因为 m(K)>0），但 m([-1,2])=3，矛盾。故 m_*(V)=0。

**内外测度的差距**：m*(V) > 0 但 m_*(V) = 0。这是不可测集的特征——内外测度不一致。对于可测集，m*(E) = m_*(E) = m(E)。

### 7.4 Vitali 集的平移族

Vitali 集的有理数平移族 {V + r : r ∈ ℚ} 具有以下性质：
1. 两两不相交
2. 并集覆盖 ℝ（不仅是 [0,1]）
3. 每个 V + r 都是不可测集
4. 每个 V + r 的外测度相同（平移不变性），内测度相同

这意味着 ℝ 可以被分成可数多个两两不相交的不可测集，每个都有相同的外测度和内测度。这是一个极其病态的分解——实数轴被"均匀地"分成了可数多个"没有长度"的集合。

**📐 几何深化**：Vitali 集的深度几何图像是"选择公理创造的不可测量的集合"。在欧几里得几何中，我们习惯于认为任何"合理的"集合都有长度或面积。但 Vitali 集表明，在选择公理下，存在"完全不合理"的集合——它们在实数轴上"均匀分布"，但没有明确的长度。Vitali 集的平移族把实数轴分成了可数多个"幽灵"集合——每个都不可测，但它们的并集是整个实数轴（长度无穷大）。这就像把一条无限长的绳子剪成可数多段，每段都"没有长度"，但把它们接起来又恢复了无限长——这在经典几何中是不可能的，但在选择公理下，Vitali 集实现了这个"悖论"。

## 第八章 其他不可测集

### 8.1 Bernstein 集

**定义**：集合 B ⊂ ℝ 称为 Bernstein 集，如果 B 和 B^c 都与每个不可数闭集相交。

**存在性**：在选择公理下，Bernstein 集存在。

**构造**：ℝ 中有 c 个不可数闭集。用超限归纳法构造：对每个不可数闭集 F_α（α &lt; c，c 是连续统基数），选取两个不同的点 x_α, y_α ∈ F_α，且不与之前选取的点重复。令 B = {x_α : α &lt; c}，则 B^c 包含 {y_α : α &lt; c}。B 和 B^c 都与每个不可数闭集相交。

**性质**：
1. Bernstein 集不可测（任何正测度可测集包含不可数闭子集，而 Bernstein 集和补集都与它相交，所以 Bernstein 集不能有正测度的可测子集，也不能包含在零测集中）
2. Bernstein 集的内测度为 0，外测度为 ∞（在无界区间上）或正数
3. Bernstein 集没有 Baire 性质
4. Bernstein 集的基数是 c

### 8.2 Sierpinski 集

**定义（连续统假设下）**：集合 S ⊂ ℝ 称为 Sierpinski 集，如果 S 不可数，但 S 与每个零测集的交都是可数的。

**存在性**：在连续统假设（CH）下，Sierpinski 集存在。

**性质**：
1. Sierpinski 集不可测（如果可测，因为与每个零测集交可数，所以 S 的任何零测子集可数；但 S 不可数，如果可测且测度为正则包含不可数零测子集（如 Cantor 型子集），矛盾；如果测度为零，则 S 本身是零测集，S∩S=S 不可数，矛盾）
2. Sierpinski 集的任何子集要么可数要么不可测
3. Sierpinski 集是"强零测集"的反例（强零测集是指对任何正数列 εₙ，存在区间列 Iₙ 覆盖 S 且 |Iₙ| &lt; εₙ）

### 8.3 Luzin 集

**定义（连续统假设下）**：集合 L ⊂ ℝ 称为 Luzin 集，如果 L 不可数，但 L 与每个贫集（第一纲集）的交都是可数的。

**存在性**：在连续统假设下，Luzin 集存在。

**性质**：
1. Luzin 集不可测（类似 Sierpinski 集的论证）
2. Luzin 集与 Sierpinski 集是对偶的（一个关于测度，一个关于纲）
3. Luzin 集的任何子集要么可数要么不可测

### 8.4 不可测集的分类

| 类型 | 构造依赖 | 关键性质 | 与零测集的交 |
|---|---|---|---|
| Vitali 集 | 选择公理 | 平移族不相交且覆盖 | 可以不可数 |
| Bernstein 集 | 选择公理 | 与补集都交不可数闭集 | 可以不可数 |
| Sierpinski 集 | CH | 与任何零测集交可数 | 可数 |
| Luzin 集 | CH | 与任何贫集交可数 | 可以不可数 |

**共同特征**：所有这些不可测集的构造都依赖于选择公理（或更强的连续统假设）。在没有选择公理的集合论模型中（如 Solovay 模型），所有实数集都可以是 Lebesgue 可测的。

## 第九章 选择公理与 Banach-Tarski 悖论

### 9.1 选择公理

**选择公理（AC）**：给定一族非空集合 {A_α : α ∈ I}，存在一个选择函数 f : I → ⋃A_α，使得 f(α) ∈ A_α 对所有 α ∈ I。

即：可以从每个非空集合中选出一个元素。

**选择公理的等价形式**：
1. 良序原理：每个集合都可以良序化
2. Zorn 引理：每个非空偏序集，若每个链都有上界，则有极大元
3. Tukey 引理：每个具有有限特征的集族有极大元
4. 乘积定理：任意一族非空集合的笛卡尔积非空

**选择公理在分析中的应用**：
- Vitali 不可测集的构造
- Hahn-Banach 延拓定理的证明（需要选择公理的某种形式）
- 紧性定理（Tychonoff 定理等价于选择公理）
- 线性空间基的存在性
- 不可测集的存在性

### 9.2 Banach-Tarski 悖论

**定理（Banach-Tarski，1924）**：在选择公理下，三维空间中的单位球可以被分成有限个（5 个）不相交的子集，通过旋转和平移（保距变换）可以重新组合成两个与原球大小相同的球。

更一般地：任何两个有非空内部的有界三维集合，可以通过有限分割和保距变换互相转化（等可分解性）。

**证明概要**：
1. 构造自由群 F₂（两个生成元的自由群）在三维旋转群 SO(3) 中的嵌入
2. F₂ 可以被分成 4 个不相交的子集 A, B, C, D，使得 F₂ = A ∪ B ∪ C ∪ D，且 A ∪ aA = F₂，B ∪ bB = F₂（其中 a, b 是生成元）
3. 利用这个分解，把球面 S² 分成轨道（F₂ 作用下的等价类），用选择公理从每个轨道选代表元
4. 通过 F₂ 的分解诱导球面的分解，再加上球心，得到球体的分解
5. 每个分解部分通过旋转可以"复制"出更多部分，最终拼成两个球

**关键洞察**：Banach-Tarski 悖论的核心是"不可测集"——分解出的 5 个子集都是不可测的（Lebesgue 不可测），它们没有明确的体积。如果它们都可测，那么体积在旋转平移下不变，不可能一个球变成两个球。

**📐 几何图像**：Banach-Tarski 悖论的几何图像是"用不可测集复制体积"。想象一个球被切成 5 块，每块都是"没有体积的幽灵"（不可测集）。这些幽灵块可以通过旋转和平移重新排列——因为它们没有体积，旋转平移不改变"体积"（本来就没有），但重新排列后可以拼成两个完整的球。这在经典几何中是不可能的，因为经典几何中的"块"都是可测的（有明确体积），体积守恒。但 Banach-Tarski 分解中的块是不可测的——它们超越了经典几何的"可测量"范畴，就像 Vitali 集超越了"有长度"的范畴一样。选择公理允许我们构造这些幽灵块，代价是我们必须接受"一个球可以变成两个球"的悖论。

### 9.3 选择公理的争议

选择公理是数学中最有争议的公理之一：

**支持选择公理的理由**：
1. 它是许多重要定理的基础（Hahn-Banach、Tychonoff、Gödel 完备性等）
2. 它在直觉上是"显然的"——当然可以从每个非空集合中选一个元素
3. 它与 ZF 公理系统相容（Gödel，1938）

**反对选择公理的理由**：
1. 它导致了不可测集的存在（Vitali）和 Banach-Tarski 悖论——这些结果在直觉上"荒谬"
2. 它是非构造性的——选择公理保证了选择函数的存在，但不给出具体的构造方法
3. 它与某些"好"的集合论模型不相容（如所有实数集都可测的 Solovay 模型）

**主流立场**：大多数数学家接受选择公理（或其弱化形式，如可数选择公理或依赖选择公理），因为它是许多数学分支的基础。但在测度论和分析中，人们清楚地意识到选择公理的代价——不可测集的存在——并在定理中明确要求可测性条件。

### 9.4 不使用选择公理的世界

**Solovay 模型（1970）**：Solovay 构造了一个集合论模型，其中：
1. 所有实数集都是 Lebesgue 可测的
2. 所有实数集都有 Baire 性质
3. 依赖选择公理（DC）成立（比选择公理弱，但足以支持大部分分析学）
4. 存在不可达基数（比连续统大的基数，不能通过更小基数的运算得到）

Solovay 模型表明：如果愿意接受不可达基数的存在并放弃完整选择公理（只保留依赖选择公理），可以得到一个"所有实数集都可测"的数学世界。在这个世界中，Vitali 集不存在，Banach-Tarski 悖论不成立。

**分析学的选择**：大多数分析学家接受选择公理（或依赖选择公理），因为：
1. Hahn-Banach 定理等基础结果需要选择公理
2. 不可测集在"实际应用"中很少出现——大多数自然构造的集合都是可测的
3. 选择公理使数学更"完整"——更多定理成立

但分析学家始终意识到不可测集的存在，并在定理中谨慎地要求可测性条件。

## 第十章 反例库

### 反例 1：Vitali 集（不可测集的经典例子）

构造：从 [0,1] 的有理数等价类中各选一个代表元。
性质：不可测，外测度>0，内测度=0，平移族不相交且覆盖 ℝ。
意义：选择公理下不可测集存在。

### 反例 2：外测度为零但不可测的集合？

不存在。外测度为零的集合一定可测（完备测度中，零测集的子集可测）。
意义：不可测集的外测度必须大于零。

### 反例 3：可测集但不是 Borel 集

存在（需要选择公理或连续统假设）。例如，Cantor 集的某些子集是 Lebesgue 可测（测度为零）但不是 Borel 集。
意义：Lebesgue 可测集严格多于 Borel 集。

### 反例 4：Bernstein 集（不可测且无 Baire 性质）

构造：与每个不可数闭集及其补集都相交。
性质：不可测，无 Baire 性质，内测度=0。
意义：比 Vitali 集更强的病态集合。

### 反例 5：Sierpinski 集（CH 下不可测）

构造：与每个零测集交可数。
性质：不可测，任何子集要么可数要么不可测。
意义：连续统假设下的病态集合。

### 反例 6：不可测函数

存在不可测函数：取 Vitali 集 V，定义 f(x)=1 如果 x∈V，f(x)=0 否则。f 不可测（因为 f^{-1}({1})=V 不可测）。
意义：不是所有函数都可测，可测性是 Lebesgue 积分的前提。

### 反例 7：两个不可测集的并可测

V ∪ V^c = ℝ 可测，但 V 和 V^c 都不可测。
意义：可测集族对补封闭，但不可测集的并可以可测。

### 反例 8：不可测集的平移

Vitali 集的任何平移都是不可测的（平移不变性）。
意义：不可测性在平移下保持。

### 反例 9：Fubini 定理的失效（不可测集）

存在 ℝ² 的子集 E，使得每个竖直截线 E_x 可数（测度为零），每个水平截线 E^y 可数（测度为零），但 E 不可测（或外测度为正）。
构造：在连续统假设下，将 [0,1] 良序化，令 E = {(x,y) : x &lt; y 在良序中}。每个竖直截线可数（良序中在 x 之前的元素可数，在 CH 下），每个水平截线的补可数。
意义：Fubini 定理需要可测性条件，不可测集可以导致"截线都零测但整体非零测"的悖论。

### 反例 10：Banach-Tarski 分解

单位球分成 5 个不可测子集，通过旋转平移拼成两个球。
意义：不可测集可以导致"体积不守恒"的悖论。

## 第十一章 历史演进

### 11.1 测度论的先驱（1880-1900）

- **1882**：Stolz 引入了内容量（content）的概念，用有限个区间覆盖集合
- **1887**：Peano 引入了内内容量和外内容量
- **1892**：Jordan 发展了 Jordan 测度（有限可加，定义在 Jordan 可测集上）
- **1898**：Borel 引入了 Borel 测度（可数可加，定义在 Borel 集上）

### 11.2 Lebesgue 积分的诞生（1902）

- **1902**：Lebesgue 发表博士论文《积分、长度与面积》，建立了 Lebesgue 测度和积分理论。核心创新是"分割值域而非定义域"和可数可加测度。
- **1904**：Lebesgue 出版《积分与原函数的研究》

### 11.3 不可测集的发现（1905-1924）

- **1905**：Vitali 构造了第一个不可测集，证明了不存在定义在所有子集上的平移不变可数可加测度。这是测度论的里程碑——它揭示了测度论的逻辑边界。
- **1914**：Hausdorff 发现了球面的"悖论分解"（Hausdorff 悖论），球面可以分成 3 个部分，其中两个通过旋转分别等于第三个，也等于两个的并。这是 Banach-Tarski 悖论的先驱。
- **1924**：Banach 和 Tarski 发表了著名的 Banach-Tarski 悖论：三维球可以分成有限个部分，通过旋转平移拼成两个相同的球。

### 11.4 选择公理的争议（1904-1960）

- **1904**：Zermelo 明确表述了选择公理，并用它证明了良序原理。这引发了关于选择公理的激烈争论。
- **1938**：Gödel 证明了选择公理与 ZF 公理系统相容（如果 ZF 相容，则 ZFC 相容）。
- **1940**：Gödel 证明了连续统假设与 ZFC 相容。
- **1963**：Cohen 发明了力迫法，证明了选择公理和连续统假设都独立于 ZF 公理系统（如果 ZF 相容，则 ZF+¬AC 和 ZF+¬CH 都相容）。

### 11.5 现代发展（1960-至今）

- **1970**：Solovay 构造了"所有实数集都可测"的集合论模型（需要不可达基数）。
- **1970s-1980s**：描述集合论发展，研究"可定义"集合的可测性（所有投影集可测需要大基数假设）。
- **1990s-至今**：内模型理论和大基数理论发展，深入研究选择公理、可测性和大基数之间的关系。

## 第十二章 跨层蜕变图谱

### 12.1 四层完备化与可测性对照表

| 层级 | 空间/测度 | 完备化 | 可测集范围 | 不可测集 |
|---|---|---|---|---|
| L0 初等 | 长度（区间） | 不需要 | 区间 | 不讨论 |
| L1 数分 | Jordan 测度 | 不完备（有限可加） | Jordan 可测集 | 存在（如 ℚ∩[0,1] 不可 Jordan 测） |
| L1 数分 | Riemann 积分 | 不完备（L¹ 范数） | a.e. 连续函数 | Dirichlet 函数不可积 |
| L2 复变 | 面积（二维 Lebesgue） | 完备 | Lebesgue 可测集 | 存在（高维 Vitali 集） |
| L3 实变 | Lebesgue 测度 | 完备 | Borel + 零测子集 | 存在（Vitali, Bernstein） |
| L3 实变 | 完备测度 | 完备 | 所有可测集+零测子集 | 仍存在（完备化不能消除不可测集） |

### 12.2 完备化的升维链

```
Jordan 测度（有限可加，不完备）
  ↓ 可数可加
Borel 测度（可数可加，不完备）
  ↓ 完备化（加零测集子集）
Lebesgue 测度（可数可加，完备）
  ↓ 但仍有不可测集
选择公理的代价：Vitali 集、Banach-Tarski 悖论
  ↓ 放弃选择公理（Solovay 模型）
所有集合可测（但需要不可达基数）
```

### 12.3 关键蜕变问题

**问题 1：为什么完备化不能消除不可测集？**

回答：测度完备化只是把零测集的子集加进可测集族。但不可测集（如 Vitali 集）的外测度大于零，不是零测集的子集，所以完备化不能使它们可测。完备化填补的是"零测集的影子"，而不可测集是"完全无法测量的集合"——它们的存在源于选择公理和平移不变性的冲突，不是测度不完备的问题。即使把测度完备化到极致（所有零测集的子集都可测），不可测集仍然存在。

**问题 2：为什么我们不能放弃选择公理？**

回答：可以放弃，但代价很大。选择公理是许多数学分支的基础：Hahn-Banach 定理（泛函分析）、Tychonoff 定理（拓扑）、Gödel 完备性定理（数理逻辑）、线性空间基的存在性（代数）等都需要选择公理（或其等价形式）。如果放弃选择公理，这些定理可能不再成立，数学的许多领域会变得"残缺"。Solovay 模型表明可以保留依赖选择公理（DC，足以支持大部分分析学）并使所有实数集可测，但需要不可达基数的存在——这本身是一个强集合论假设。大多数数学家选择接受选择公理，同时清醒地意识到它的代价（不可测集）。

**问题 3：不可测集在"实际数学"中重要吗？**

回答：在某种意义上不重要——大多数自然构造的集合（开集、闭集、Borel 集、连续函数的像等）都是可测的。不可测集的构造总是需要选择公理，无法给出明确的构造公式。但在另一种意义上很重要——不可测集的存在揭示了测度论的逻辑边界，提醒我们在定理中必须要求可测性条件。Fubini 定理、控制收敛定理、Riesz-Fischer 定理等都需要可测性前提。如果忽略可测性，可能得到荒谬的结论（如"截线都零测但整体非零测"）。

**问题 4：完备化与选择公理的关系是什么？**

回答：完备化是一个"建设性"的操作——它用 Cauchy 列等价类或零测集子集来扩展空间/测度，使空间/测度更"完整"。选择公理是一个"存在性"公理——它保证某些集合存在（如 Vitali 集的代表元集合），但不给出构造。完备化本身不需要选择公理（Cauchy 列等价类的构造是构造性的），但完备化的某些应用（如 Hahn-Banach 延拓）需要选择公理。不可测集的存在是选择公理的代价，与完备化无关——即使在不完备的 Borel 测度中，Vitali 集也不可测（因为它不是 Borel 集，且外测度>0）。

## 第十三章 收敛沉淀

### 13.1 核心定理清单

1. **度量空间完备化定理**：任何度量空间可等距嵌入完备空间，唯一
2. **完备化泛性质**：一致连续映射可唯一延拓到完备化
3. **测度完备化定理**：任何测度空间可完备化（加零测集子集）
4. **Lebesgue 测度完备性**：Lebesgue 测度是 Borel 测度的完备化
5. **Carathéodory 可测性判据**：m*(A)=m*(A∩E)+m*(A∩E^c)
6. **Vitali 定理**：选择公理下存在不可测集；平移不变+可数可加+全实轴有限不可兼得
7. **Vitali 集性质**：外测度>0，内测度=0，平移族不相交且覆盖 ℝ
8. **Bernstein 集存在性**：选择公理下存在
9. **Banach-Tarski 悖论**：选择公理下三维球可分解为两个球
10. **Gödel 相容性**：选择公理与 ZF 相容
11. **Cohen 独立性**：选择公理独立于 ZF
12. **Solovay 模型**：存在所有实数集可测的集合论模型（需不可达基数+DC）

### 13.2 方法论沉淀

**完备化的标准方法**：
1. 取所有 Cauchy 列
2. 定义等价关系（极限距离为零）
3. 等价类作为新空间元素
4. 延拓度量/范数/内积
5. 验证完备性

**测度完备化的标准方法**：
1. 取所有可测集并上零测集的子集
2. 延拓测度（μ̄(E∪N)=μ(E)）
3. 验证 σ-代数、可数可加、完备性

**不可测集证明的标准方法**：
1. 定义等价关系（如差为有理数）
2. 用选择公理选取代表元
3. 考虑代表元集合的平移/变换
4. 利用不相交性和覆盖关系计算测度
5. 导出矛盾（可数个零的和=零 vs 可数个正数的和=无穷）

### 13.3 常见误区

**误区一：完备化可以消除不可测集**
澄清：不能。完备化只加零测集的子集，不可测集外测度>0，不受影响。

**误区二：不可测集是"罕见"的集合**
澄清：在基数意义上，不可测集比可测集多得多（可测集基数 2^c，所有子集基数 2^c——实际上在 ZFC 中可测集基数也是 2^c，但"随机"子集不可测的概率为 1）。

**误区三：选择公理是唯一导致不可测集的原因**
澄清：在 ZF 中，不可测集的存在性不可证也不可否。选择公理蕴含不可测集存在，但没有选择公理时，不可测集可能存在也可能不存在（依赖于具体模型）。

**误区四：Lebesgue 测度可以定义在所有子集上**
澄清：不能。Vitali 定理证明了平移不变+可数可加+有限测度的测度不能定义在所有子集上。

**误区五：Banach-Tarski 悖论说明数学是矛盾的**
澄清：不是。Banach-Tarski 悖论只在选择公理下成立，且分解出的子集是不可测的（没有体积）。悖论的"荒谬"在于我们直觉上认为所有集合都有体积，但不可测集没有体积。

**误区六：完备化总是具体的**
澄清：完备化的抽象构造（Cauchy 列等价类）总是可行的，但找到具体实现（如用 Lebesgue 可积函数表示 C[a,b] Lp 的完备化）可能需要深刻理论。

- 完备化泛性质与 Hahn-Banach 延拓：都是延拓定理，前者延拓到完备化，后者延拓到全空间
