> 分析学通常按教材纵向学：数学分析、复变函数、实变函数各来一遍。
> 这里换一种组织方式：以概念为中心，把同一概念在不同层次中的形态放在一起。

---

## 这套内容怎么用

每个领域按四层展开：

| 层 | 名称 | 典型语言 |
|---|---|---|
| L0 | 初等 / 直觉 | 图像、物理直觉、中学数学 |
| L1 | 数学分析 | ε-δ、Riemann 积分 |
| L2 | 复变函数 | 解析函数、Cauchy 定理、留数 |
| L3 | 实变函数 | 测度、Lebesgue 积分、Lp 空间 |

层与层之间不是简单重复，而是**蜕变**：定义如何推广、条件如何放宽或收紧、结论如何变化、反例如何演化。

每个领域包含若干模块，每个模块有两篇：

- **完整研究**：定义、定理、证明思路、几何直观、反例与历史；
- **习题集**：按难度分层的练习与解答。

## 阅读顺序

如果第一次读，建议：

1. 先看 **D6 完备性**：它解释“实数为什么没有洞”；
2. 再看 **D1 极限** 与 **D2 连续**：分析学的语言；
3. 然后 **D3 微分**、**D4 积分**、**D5 级数**：三大运算；
4. 最后 **D7 三角学** 与 **D8 解析**：两个横向专题。

不需要按 D 编号顺序读。每个领域索引页都有模块入口，可以先挑感兴趣的模块。
