## L0 初等直觉层（★ 基础）

**【D8-2-001】** 计算基本积分 ∮_C dz/(z-z₀)，其中 C 是绕 z₀ 的正向圆周 |z-z₀|=R。参数化 z=z₀+Re^{iθ}，dz=iRe^{iθ}dθ，积分=∫₀²π i dθ=2πi。再计算 ∮ dz/(z-z₀)ⁿ（n为整数），说明只有 n=1 时非零。

- **难度**：★
- **对应知识点**：基本积分、∮dz/(z-z₀)=2πi、参数化
- **解答**：
  **n=1**：
  z=z₀+Re^{iθ}, dz=iRe^{iθ}dθ。
  ∮ dz/(z-z₀)=∫₀²π (iRe^{iθ}dθ)/(Re^{iθ})=∫₀²π i dθ=2πi。∎

  **n≠1（整数）**：
  ∮ dz/(z-z₀)ⁿ=∫₀²π (iRe^{iθ}dθ)/(Rⁿe^{inθ})=iR^{1-n}∫₀²π e^{i(1-n)θ}dθ。
  当 n≠1 时，1-n≠0，∫₀²π e^{i(1-n)θ}dθ=[e^{i(1-n)θ}/(i(1-n))]₀²π=0。
  所以积分=0。∎

  **总结**：
  ∮ dz/(z-z₀)ⁿ = {2πi, n=1; 0, n≠1（整数）}

  **几何理解**：
  ∮ dz/(z-z₀)=2πi 的几何意义是"绕 z₀ 转一圈，角度增加 2π"。
  dz/(z-z₀)=d(log(z-z₀))=d(ln|z-z₀|+i arg(z-z₀))。
  绕一圈后 ln|z-z₀| 回到原值，但 arg(z-z₀) 增加 2π，所以积分=2πi。
  这是"多值性"的积分体现——也是留数定理的基础。
- **一句话点评**：z=z₀+Re^{iθ},dz=iRe^{iθ}dθ。∮dz/(z-z₀)=∫₀²πi dθ=2πi。n≠1时∫₀²πe^{i(1-n)θ}dθ=0。几何:dz/(z-z₀)=d(log(z-z₀)),绕一圈arg增加2π⟹积分=2πi=多值性的积分体现=留数定理基础。

**【D8-2-002】** 用 ML 不等式估计积分 |∮_C f(z)dz|≤M·L：若 |f(z)|≤M 在 C 上，L 是 C 的长度。验证 f(z)=1/z 在 |z|=R 上的积分：|1/z|=1/R，L=2πR，所以 |∮dz/z|≤(1/R)(2πR)=2π，而实际值=|2πi|=2π，等号成立。

- **难度**：★
- **对应知识点**：ML不等式、积分估计、等号成立条件
- **解答**：
  **ML 不等式**：
  |∮_C f(z)dz|=|lim Σf(ζ_k)Δz_k|≤lim Σ|f(ζ_k)||Δz_k|≤M·lim Σ|Δz_k|=M·L。∎

  **验证 f(z)=1/z, C:|z|=R**：
  |f(z)|=|1/z|=1/R=M（常数）。
  L=2πR。
  ML=(1/R)(2πR)=2π。
  实际积分=2πi，|2πi|=2π。
  所以 |∮dz/z|=2π=ML——等号成立！∎

  **等号成立条件**：
  ML 不等式等号成立当且仅当 |f(z)|=M 常数且 f(z)dz 的方向始终一致（被积函数的辐角不变）。
  对于 1/z 在圆周上：|1/z|=1/R 常数，且 dz/z=i dθ 是纯虚数（辐角恒为 π/2），所以等号成立。

  **应用**：
  ML 不等式是复分析中最常用的估计工具——用于证明 Cauchy 不等式、Liouville 定理、高阶导数公式等。
  关键是找到合适的 M（函数上界）和 L（曲线长度），然后让某个参数趋于 0 或 ∞ 使估计趋于 0。

  **几何理解**：
  ML 不等式是"向量场做功"的估计——做功不超过力的最大值乘以路程。
  这与物理中"功≤力×距离"完全一致——复积分就是向量场沿曲线的做功。
- **一句话点评**：|∮fdz|≤limΣ|f||Δz|≤M·L。f=1/z,|z|=R:|f|=1/R,L=2πR,ML=2π=|2πi|等号成立。等号条件:|f|=常数且fdz辐角不变(1/z时dz/z=idθ纯虚数)。ML=Cauchy不等式/Liouville/高阶导数的核心估计工具。复积分=向量场做功,功≤力×距离。

**【D8-2-003】** 验证 Cauchy 积分定理对 f(z)=z² 的情形：∮_C z² dz=0 对任意闭曲线 C。用参数化 C:z=e^{iθ}（单位圆）直接计算：∫₀²π e^{2iθ}·ie^{iθ}dθ=i∫₀²π e^{3iθ}dθ=0。说明多项式的闭路积分都为零（因为多项式是整函数）。

- **难度**：★
- **对应知识点**：Cauchy积分定理验证、多项式闭路积分、参数化计算
- **解答**：
  **f(z)=z², C:|z|=1（z=e^{iθ}, dz=ie^{iθ}dθ）**：
  ∮ z² dz=∫₀²π e^{2iθ}·ie^{iθ}dθ=i∫₀²π e^{3iθ}dθ=i·[e^{3iθ}/(3i)]₀²π=i·(1-1)/(3i)=0。∎

  **一般多项式**：
  f(z)=a₀+a₁z+...+aₙzⁿ。
  ∮ zᵏ dz=∫₀²π e^{ikθ}·ie^{iθ}dθ=i∫₀²π e^{i(k+1)θ}dθ=0（k≥0时 k+1≠0）。
  所以 ∮ f(z)dz=Σa_k∮zᵏdz=0。∎
  所有多项式的闭路积分都为零——因为多项式是整函数（全平面解析），Cauchy 积分定理适用。

  **对比 f(z)=1/z**：
  ∮ dz/z=2πi≠0——因为 1/z 在 z=0 处不解析（有奇点），Cauchy 积分定理不适用。
  这就是"解析"和"有奇点"的关键区别——解析函数闭路积分为零，有奇点时积分可能非零。

  **几何理解**：
  多项式 z² 是"光滑"的向量场——没有奇点，旋度为零（C-R 方程），所以沿闭路做功为零。
  1/z 在原点有奇点——奇点处旋度不为零（相当于一个"涡旋"），绕奇点一圈做功不为零。
  这就是 Cauchy 积分定理的物理图像：无旋场沿闭路做功为零，有涡旋时做功非零。
- **一句话点评**：z=e^{iθ},dz=ie^{iθ}dθ。∮z²dz=i∫₀²πe^{3iθ}dθ=0。一般多项式∮zᵏdz=i∫e^{i(k+1)θ}dθ=0(k≥0)⟹多项式闭路积分全为零(整函数)。对比1/z:∮dz/z=2πi≠0(原点奇点,Cauchy不适用)。解析=无旋场(做功为零),有奇点=有涡旋(做功非零)。

**【D8-2-004】** 用 Cauchy 积分公式计算 f(z₀)：设 f(z)=z²，C 是绕 z₀=1 的正向圆周 |z-1|=1。Cauchy 公式说 f(1)=(1/2πi)∮_C z²/(z-1)dz。直接计算 f(1)=1，验证积分=2πi。

- **难度**：★
- **对应知识点**：Cauchy积分公式、边界值决定内部值、直接验证
- **解答**：
  **Cauchy 积分公式**：
  f(z₀)=(1/2πi)∮_C f(z)/(z-z₀) dz。

  **f(z)=z², z₀=1, C:|z-1|=1**：
  f(1)=1²=1。
  所以 ∮_C z²/(z-1) dz 应该 = 2πi·f(1)=2πi。

  **直接计算验证**：
  z=1+e^{iθ}, dz=ie^{iθ}dθ。
  z²=(1+e^{iθ})²=1+2e^{iθ}+e^{2iθ}。
  z²/(z-1)=(1+2e^{iθ}+e^{2iθ})/e^{iθ}=e^{-iθ}+2+e^{iθ}。
  ∮ z²/(z-1)dz=∫₀²π (e^{-iθ}+2+e^{iθ})·ie^{iθ}dθ
  =i∫₀²π (1+2e^{iθ}+e^{2iθ})dθ
  =i[θ+2e^{iθ}/i+e^{2iθ}/(2i)]₀²π
  =i[(2π-0)+(2/i-2/i)+(1/(2i)-1/(2i))]
  =i·2π=2πi。∎
  与 Cauchy 公式一致！

  **几何理解**：
  Cauchy 积分公式说"内部点的值=边界值的加权平均"。
  权重是柯西核 1/(2πi(z-z₀))——在 z₀ 附近有"峰值"，离 z₀ 越近的边界点权重越大。
  这与调和函数的平均值原理一致——解析函数在圆心的值等于圆周上的平均值。
  实变函数完全没有这个性质——边界值不能决定内部值。
- **一句话点评**：f(z)=z²,z₀=1,C:|z-1|=1。f(1)=1⟹∮z²/(z-1)dz应=2πi。直接算:z=1+e^{iθ},z²/(z-1)=e^{-iθ}+2+e^{iθ},积分=i∫(1+2e^{iθ}+e^{2iθ})dθ=2πi✓。Cauchy公式=内部值=边界值加权平均,权重柯西核1/(2πi(z-z₀))在z₀附近有峰值。与调和函数平均值原理一致。实变无此性质。

### 组A：Cauchy积分定理

**【D8-2-005】** 复述 Goursat 证明 Cauchy 积分定理的三角形法核心步骤：(1)将三角形四等分，选积分绝对值最大的小三角形；(2)得到嵌套三角形序列收缩到一点 z₀；(3)在 z₀ 处可导意味着 f≈线性+高阶小量；(4)线性部分闭路积分为零，高阶小量用 ML 不等式估计趋于零；(5)推出原三角形积分为零。说明每一步的关键思想。

- **难度**：★★
- **对应知识点**：Goursat证明、三角形法、二分法、局部线性化、ML估计
- **解答**：
  **Goursat 三角形法证明步骤**：

  **第1步：四等分**
  连接三角形三边中点，将 T 分成 4 个全等小三角形 T₁~T₄。
  沿内部线段的积分正向反向抵消，所以 ∮_T f = Σ∮_{T_k} f。
  至少有一个 T^{(1)} 满足 |∮_{T^{(1)}} f| ≥ (1/4)|∮_T f|。

  **第2步：嵌套序列**
  对 T^{(1)} 重复四等分，得到 T⊃T^{(1)}⊃T^{(2)}⊃...
  满足 |∮_{T^{(n)}} f| ≥ |∮_T f|/4ⁿ。
  直径 diam(T^{(n)})=diam(T)/2ⁿ→0，周长 L_n=L/2ⁿ。
  由闭区间套定理（二维版本），三角形收缩到一点 z₀∈T。

  **第3步：局部线性化**
  f 在 z₀ 可导：f(z)=f(z₀)+f'(z₀)(z-z₀)+ε(z)(z-z₀)，ε(z)→0（z→z₀）。

  **第4步：线性部分积分为零**
  ∮ [f(z₀)+f'(z₀)(z-z₀)]dz = f(z₀)∮dz + f'(z₀)∮z dz - f'(z₀)z₀∮dz = 0+0-0=0。
  （因为 ∮dz=0, ∮z dz=0 对任意闭曲线成立——多项式闭路积分为零。）
  所以 ∮_{T^{(n)}} f = ∮_{T^{(n)}} ε(z)(z-z₀) dz。

  **第5步：ML 估计**
  n 足够大时 |ε(z)|&lt;ε 在 T^{(n)} 上。
  |z-z₀|≤diam(T^{(n)})=diam(T)/2ⁿ。
  |∮_{T^{(n)}} f| ≤ ε·(diam(T)/2ⁿ)·(L/2ⁿ)=ε·diam(T)·L/4ⁿ。

  **第6步：推出结论**
  结合第2步：|∮_T f|/4ⁿ ≤ ε·diam(T)·L/4ⁿ ⟹ |∮_T f| ≤ ε·diam(T)·L。
  ε 任意小 ⟹ ∮_T f=0。∎

  **关键思想**：
  - 二分法：将大问题分解为小问题，用可加性传递积分下界。
  - 局部线性化：可导=局部近似线性，线性函数闭路积分为零。
  - ML 估计：高阶小量在细分后趋于零。
  - 这就是"无限细分+局部线性化+全局抵消"的证明策略。

  **几何理解**：
  Goursat 证明的本质是"用局部线性逼近全局"——在每个小三角形上，可导意味着 f≈线性，线性函数无旋（积分为零），所以小三角形积分趋于零。
  这与实变中 Riemann 积分的思想类似，但复可导的"各向同性"使得线性逼近在所有方向上都成立——这是证明的关键。
- **一句话点评**：Goursat五步:①四等分选最大(积分可加性)②嵌套收缩到z₀(直径→0)③可导⟹f≈线性+ε(z)(z-z₀)④线性部分∮=0(∮dz=∮zdz=0)⑤ML:|∮|≤ε·(diam/2ⁿ)·(L/2ⁿ)=ε·diam·L/4ⁿ⑥结合下界⟹|∮_T f|≤ε·diam·L⟹=0。核心:二分法+局部线性化+ML估计。可导各向同性⟹线性逼近所有方向成立。

**【D8-2-006】** 证明原函数存在性：若 f 在单连通区域 D 内解析，则 F(z)=∫_{z₀}^z f(ζ)dζ 是 f 的原函数（F'=f）。用导数定义验证：[F(z+h)-F(z)]/h=(1/h)∫_z^{z+h} f(ζ)dζ，减去 f(z) 后用 ML 不等式估计趋于零。说明这与实变微积分基本定理平行。

- **难度**：★★
- **对应知识点**：原函数存在性、变上限积分、导数定义、ML估计、微积分基本定理
- **解答**：
  **定义 F(z)**：
  F(z)=∫_{z₀}^z f(ζ)dζ（由 Cauchy 积分定理，积分与路径无关，F 良定义）。

  **验证 F'(z)=f(z)**：
  [F(z+h)-F(z)]/h = (1/h)[∫_{z₀}^{z+h}f - ∫_{z₀}^z f] = (1/h)∫_z^{z+h} f(ζ)dζ。
  （取直线路径，因为单连通区域内积分与路径无关。）

  减去 f(z)：
  [F(z+h)-F(z)]/h - f(z) = (1/h)∫_z^{z+h} [f(ζ)-f(z)]dζ。

  **ML 估计**：
  f 连续（解析当然连续），所以 ∀ε>0, ∃δ>0, 当 |ζ-z|&lt;δ 时 |f(ζ)-f(z)|&lt;ε。
  当 |h|&lt;δ 时，直线路径上 |ζ-z|≤|h|&lt;δ，所以 |f(ζ)-f(z)|&lt;ε。
  路径长度=|h|。
  |(1/h)∫_z^{z+h}[f(ζ)-f(z)]dζ| ≤ (1/|h|)·ε·|h|=ε。
  所以 lim_{h→0} [F(z+h)-F(z)]/h = f(z)。∎
  F'(z)=f(z)，F 是 f 的原函数。

  **与实变对比**：
  实变微积分基本定理：若 f 连续，则 F(x)=∫ₐˣf(t)dt 可导且 F'=f。
  复变：若 f 解析，则 F(z)=∫_{z₀}^z f(ζ)dζ 解析且 F'=f。
  形式完全平行，但复变多了"积分与路径无关"的前提（需要 Cauchy 积分定理）。

  **注意**：
  在多连通区域内，原函数可能是多值的——如 1/z 在 ℂ\{0} 内的原函数 log z 是多值的（绕原点一圈增加 2πi）。
  单连通区域内原函数单值。

  **几何理解**：
  原函数存在性说明解析函数是"梯度场"——存在势函数 F 使得 f=F'。
  这与保守场（无旋场）有势函数完全一致——Cauchy 积分定理说解析函数是无旋场，无旋场必有势函数。
- **一句话点评**：F(z)=∫_{z₀}^z f(与路径无关)。[F(z+h)-F(z)]/h=(1/h)∫_z^{z+h}f(ζ)dζ。减f(z):(1/h)∫[f(ζ)-f(z)]dζ。f连续⟹|ζ-z|&lt;δ时|f(ζ)-f(z)|&lt;ε,ML≤(1/|h|)·ε·|h|=ε⟹F'=f。平行实变微积分基本定理,但复变需"路径无关"(Cauchy定理)。多连通区域原函数可能多值(1/z→log z)。解析函数=无旋场=有势函数F。

**【D8-2-007】** 用闭路变形原理计算 ∮_C dz/(z²+1)，其中 C 是绕 i 但不绕 -i 的正向闭曲线。将 1/(z²+1) 部分分式分解为 (1/(2i))[1/(z-i)-1/(z+i)]，绕 i 的积分=2πi，绕 -i 的积分=0（因为 -i 在 C 外），所以结果=(1/(2i))·2πi=π。

- **难度**：★★
- **对应知识点**：闭路变形原理、部分分式、绕奇点积分
- **解答**：
  **部分分式分解**：
  1/(z²+1)=1/[(z-i)(z+i)]=(1/(2i))[1/(z-i)-1/(z+i)]。
  验证：(1/(2i))[(z+i)-(z-i)]/[(z-i)(z+i)]=(1/(2i))(2i)/(z²+1)=1/(z²+1)。∎

  **闭路变形原理**：
  C 绕 i 但不绕 -i。
  ∮_C 1/(z-i) dz=2πi（i 在 C 内，基本积分）。
  ∮_C 1/(z+i) dz=0（-i 在 C 外，1/(z+i) 在 C 内解析，Cauchy 积分定理）。

  **计算**：
  ∮_C dz/(z²+1)=(1/(2i))[∮dz/(z-i)-∮dz/(z+i)]=(1/(2i))[2πi-0]=π。∎

  **如果 C 同时绕 i 和 -i**：
  ∮dz/(z²+1)=(1/(2i))[2πi-2πi]=0。
  两个奇点的贡献抵消了！

  **如果 C 绕 -i 但不绕 i**：
  ∮dz/(z²+1)=(1/(2i))[0-2πi]=-π。

  **几何理解**：
  闭路变形原理说积分只依赖于曲线包围的奇点——可以将曲线连续变形为绕每个奇点的小圆周，积分不变。
  这是拓扑性质的体现——积分是"同伦不变量"。
  部分分式分解将复杂函数分解为简单的 1/(z-a) 项，每项的积分只取决于 a 是否在曲线内。
  这就是留数定理的雏形——积分=2πi×（内部奇点留数之和）。
- **一句话点评**：1/(z²+1)=(1/(2i))[1/(z-i)-1/(z+i)]。C绕i不绕-i:∮1/(z-i)=2πi,∮1/(z+i)=0(-i在C外,Cauchy定理)⟹积分=(1/(2i))·2πi=π。同时绕i和-i:(1/(2i))(2πi-2πi)=0(抵消)。闭路变形=积分只依赖包围的奇点=同伦不变量。部分分式→留数定理雏形(积分=2πi×内部留数和)。

**【D8-2-008】** 证明复合闭路定理：多连通区域 D，外边界 C（逆时针），内边界 C₁...Cₙ（顺时针），f 在 D 内解析，则 ∮_C f + Σ∮_{C_k} f = 0。用"割线"将多连通区域剪开为单连通，沿割线的积分正向反向抵消，剩下外边界和内边界的积分。

- **难度**：★★
- **对应知识点**：复合闭路定理、割线法、多连通区域、通量守恒
- **解答**：
  **复合闭路定理**：
  ∮_C f(z)dz + Σ_{k=1}^n ∮_{C_k} f(z)dz = 0，
  其中 C 逆时针（正向），C_k 顺时针（负向）。
  等价地：∮_C f = Σ∮_{C_k^+} f（C_k^+ 逆时针）。

  **证明（割线法）**：
  用 n 条割线将外边界 C 和各内边界 C_k 连接起来，将多连通区域 D 剪开为一个单连通区域 D'。
  D' 的边界由 C（逆时针）、各 C_k（顺时针）、以及两条割线（正向和反向）组成。

  在 D' 上应用 Cauchy 积分定理（单连通）：
  ∮_{∂D'} f = 0。

  沿每条割线的积分出现两次（一次正向一次反向），相互抵消。
  剩下：∮_C f + Σ∮_{C_k} f = 0。∎

  **等价形式**：
  ∮_C f = -Σ∮_{C_k} f = Σ∮_{C_k^+} f（因为 C_k 顺时针=-C_k^+ 逆时针）。
  外边界积分=所有内边界（正向）积分之和。

  **几何理解**：
  复合闭路定理的本质是"通量守恒"——解析函数的向量场是无旋的，通过外边界的通量等于通过所有内边界的通量之和。
  这类似于静电学中的高斯定理——通过外闭合面的电通量等于内部所有电荷的通量之和。
  割线法是拓扑学中的标准技巧——将多连通区域转化为单连通区域，利用单连通区域的已知结论。

  **应用**：
  复合闭路定理是计算含多个奇点的闭路积分的基础——可以将外边界变形为绕每个奇点的小圆周，积分等于各小圆周积分之和。
  这是留数定理的直接前身。
- **一句话点评**：用割线连接外边界C和内边界C_k,剪开为单连通D'。D'边界=C(逆)+C_k(顺)+割线(正反向抵消)。Cauchy定理∮_{∂D'}f=0⟹∮_C f+Σ∮_{C_k}f=0。等价:∮_C f=Σ∮_{C_k^+}f。本质=通量守恒(无旋场外边界通量=内边界通量和),类比静电高斯定理。割线法=多连通→单连通的拓扑技巧。留数定理前身。

**【D8-2-009】** 用 Cauchy 积分公式证明高阶导数公式 f^{(n)}(z₀)=n!/(2πi)∮f(z)/(z-z₀)^{n+1}dz：对 n=1 用差商 [f(z₀+h)-f(z₀)]/h=(1/2πi)∮f(z)·[1/(h)(1/(z-z₀-h)-1/(z-z₀))]dz=(1/2πi)∮f(z)/[(z-z₀-h)(z-z₀)]dz，令 h→0 一致收敛得 f'(z₀)=(1/2πi)∮f/(z-z₀)²。归纳得一般公式。

- **难度**：★★
- **对应知识点**：高阶导数公式、差商、一致收敛、数学归纳法
- **解答**：
  **n=1 的证明**：
  由 Cauchy 积分公式：
  f(z₀+h)=(1/2πi)∮ f(z)/(z-z₀-h) dz,
  f(z₀)=(1/2πi)∮ f(z)/(z-z₀) dz。

  差商：
  [f(z₀+h)-f(z₀)]/h = (1/2πi)∮ f(z)·(1/h)[1/(z-z₀-h)-1/(z-z₀)] dz
  = (1/2πi)∮ f(z)·(1/h)[(z-z₀)-(z-z₀-h)]/[(z-z₀-h)(z-z₀)] dz
  = (1/2πi)∮ f(z)/[(z-z₀-h)(z-z₀)] dz。

  令 h→0：被积函数一致收敛到 f(z)/(z-z₀)²（因为 z 在 C 上，|z-z₀|≥d>0，h 足够小时分母一致有界）。
  所以 f'(z₀)=(1/2πi)∮ f(z)/(z-z₀)² dz。∎

  **归纳步**：
  假设 f^{(n)}(z₀)=n!/(2πi)∮ f(z)/(z-z₀)^{n+1} dz。
  对 f^{(n)} 用同样的差商方法：
  [f^{(n)}(z₀+h)-f^{(n)}(z₀)]/h = n!/(2πi)∮ f(z)·(1/h)[1/(z-z₀-h)^{n+1}-1/(z-z₀)^{n+1}] dz。
  利用恒等式 (1/h)[1/(a-h)^{n+1}-1/a^{n+1}]→(n+1)/a^{n+2}（h→0）。
  得 f^{(n+1)}(z₀)=(n+1)!/(2πi)∮ f(z)/(z-z₀)^{n+2} dz。∎

  **意义**：
  高阶导数公式说明：只要 f 连续（解析当然连续），它的所有阶导数都存在——因为导数用积分表示，积分号下可以自由求导。
  这是"一次可导自动蕴含无穷可导"的关键机制。
  实变中完全没有这种性质——连续函数不一定可导，可导函数不一定二阶可导。

  **几何理解**：
  高阶导数公式意味着"边界值决定了内部所有阶导数"——边界上的函数值包含了内部的全部信息（函数值和所有导数值）。
  这是解析函数"全局刚性"的最强表达——边界确定了内部的一切。
- **一句话点评**：n=1:[f(z₀+h)-f(z₀)]/h=(1/2πi)∮f/[(z-z₀-h)(z-z₀)]→(1/2πi)∮f/(z-z₀)²(一致收敛)。归纳:假设n成立,对f^{(n)}用差商,(1/h)[1/(a-h)^{n+1}-1/a^{n+1}]→(n+1)/a^{n+2}⟹n+1成立。关键:导数用积分表示,积分号下可自由求导⟹只要f连续就无穷可导。边界值决定内部所有阶导数=全局刚性最强表达。

**【D8-2-010】** 证明 Cauchy 不等式：若 f 在 |z-z₀|&lt;R 内解析且 |f(z)|≤M，则 |f^{(n)}(z₀)|≤n!M/Rⁿ。用高阶导数公式取 C 为 |z-z₀|=r&lt;R，ML 估计得 |f^{(n)}|≤n!/(2π)·M/r^{n+1}·2πr=n!M/rⁿ，令 r→R 得结论。

- **难度**：★★
- **对应知识点**：Cauchy不等式、高阶导数公式、ML估计、令r→R
- **解答**：
  **高阶导数公式**：
  f^{(n)}(z₀)=n!/(2πi)∮_C f(z)/(z-z₀)^{n+1} dz，取 C:|z-z₀|=r（r&lt;R）。

  **ML 估计**：
  |f^{(n)}(z₀)| ≤ n!/(2π)·∮ |f(z)|/|z-z₀|^{n+1} |dz|
  ≤ n!/(2π)·(M/r^{n+1})·(2πr)
  = n!M/rⁿ。

  **令 r→R**：
  因为 r 可以任意接近 R（f 在 |z-z₀|&lt;R 内解析，任意 r&lt;R 都可以），
  所以 |f^{(n)}(z₀)| ≤ n!M/Rⁿ。∎

  **n=0 时**：
  |f(z₀)|≤M——这就是最大值原理的特殊形式（内部值不超过边界最大值）。

  **n=1 时**：
  |f'(z₀)|≤M/R——导数的界由函数值的界和区域大小决定。

  **意义**：
  Cauchy 不等式量化了解析函数的"全局刚性"——函数值的界控制了所有导数的界。
  阶数越高，界越严格（除以 Rⁿ）——高阶导数比低阶导数受到更强的约束。
  这是 Liouville 定理的基础——令 R→∞ 时导数界趋于 0。

  **几何理解**：
  Cauchy 不等式说明解析函数不能"剧烈变化"——如果函数值有界，那么导数也有界，且区域越大导数界越小。
  这与实变函数不同——实变有界函数可以有任意大的导数（如 sin(1/x) 在 0 附近）。
  解析函数的"光滑度"是无限的——所有阶导数都受到函数值界的控制。
- **一句话点评**：f^{(n)}=n!/(2πi)∮f/(z-z₀)^{n+1},取|z-z₀|=r&lt;R。ML:|f^{(n)}|≤n!/(2π)·M/r^{n+1}·2πr=n!M/rⁿ。令r→R⟹≤n!M/Rⁿ。n=0⟹|f(z₀)|≤M(最大值原理);n=1⟹|f'|≤M/R。函数值界控制所有导数界,阶数越高界越严。实变有界函数可有任意大导数(sin(1/x)),解析函数无限光滑。

**【D8-2-011】** 证明 Liouville 定理：有界整函数必为常数。设 f 整函数且 |f|≤M，对任意 z₀ 和任意 R>0 用 Cauchy 不等式（n=1）得 |f'(z₀)|≤M/R，令 R→∞ 得 f'(z₀)=0，z₀ 任意故 f'≡0，f 为常数。说明这是"全平面有界的解析函数没有变化空间"。

- **难度**：★★
- **对应知识点**：Liouville定理、Cauchy不等式、令R→∞、有界整函数
- **解答**：
  **Liouville 定理**：有界整函数必为常数。

  **证明**：
  设 f 是整函数（全平面解析），且 |f(z)|≤M 对所有 z∈ℂ。
  对任意 z₀∈ℂ 和任意 R>0，f 在 |z-z₀|&lt;R 内解析（整函数），且 |f|≤M。
  由 Cauchy 不等式（n=1）：
  |f'(z₀)| ≤ M/R。

  令 R→∞（因为 f 是整函数，R 可以任意大）：
  |f'(z₀)| ≤ lim_{R→∞} M/R = 0。
  所以 f'(z₀)=0。

  z₀ 是任意的，所以 f'(z)≡0 对所有 z 成立。
  导数恒为零的函数是常数——f(z)≡C。∎

  **推广**：
  更一般地，如果整函数 f 满足 |f(z)|≤C|z|ⁿ（多项式增长），则 f 是次数不超过 n 的多项式。
  证明：对 k>n 用 Cauchy 不等式 |f^{(k)}(0)|≤k!C Rⁿ/Rᵏ=k!C/R^{k-n}→0（R→∞），所以 f^{(k)}(0)=0（k>n），f 是 n 次多项式。

  **几何理解**：
  Liouville 定理的几何本质是"全平面上有界的解析函数没有变化空间"——如果函数在无穷远处也"表现良好"（有界），那么它就不能有任何变化，只能是常数。
  这与实变函数不同——实变有界函数可以非常数（如 sin x），因为实变函数不需要在"所有方向"上有界（复平面有无穷多方向，实轴只有两个）。
  Liouville 定理是复分析中最"反直觉"的定理之一——有界性+解析性=常数。

  **应用**：
  Liouville 定理最著名的应用是证明代数基本定理（n 次多项式必有 n 个复根）。
- **一句话点评**：f整函数且|f|≤M。∀z₀,∀R>0,Cauchy不等式|f'(z₀)|≤M/R。令R→∞⟹f'(z₀)=0。z₀任意⟹f'≡0⟹f=常数。推广:|f(z)|≤C|z|ⁿ⟹f是≤n次多项式(k>n时f^{(k)}(0)≤k!C/R^{k-n}→0)。几何:全平面有界的解析函数无变化空间=常数。实变有界函数可非常数(sin x),复平面有无穷多方向约束更强。应用=代数基本定理。

**【D8-2-012】** 用 Liouville 定理证明代数基本定理：n 次多项式 p(z)=aₙzⁿ+...+a₀（aₙ≠0）必有复根。反证：若 p 无零点，则 1/p 是整函数。证明 1/p 有界（当 |z|→∞ 时 |p(z)|→∞，所以 |1/p|→0；在有界区域上连续函数有界），由 Liouville 定理 1/p 为常数，矛盾。

- **难度**：★★
- **对应知识点**：代数基本定理、Liouville定理应用、反证法、1/p有界性
- **解答**：
  **代数基本定理**：n 次多项式 p(z)=aₙzⁿ+...+a₀（aₙ≠0, n≥1）至少有一个复根。

  **反证**：
  假设 p(z) 没有复零点（p(z)≠0 对所有 z∈ℂ）。
  则 1/p(z) 在全平面有定义且解析（因为 p 是整函数且无零点，商的解析性）——1/p 是整函数。

  **证明 1/p 有界**：
  当 |z|→∞ 时：
  |p(z)|=|z|ⁿ|aₙ+aₙ₋₁/z+...+a₀/zⁿ|≥|z|ⁿ(|aₙ|-|aₙ₋₁|/|z|-...-|a₀|/|z|ⁿ)。
  当 |z| 足够大时，括号内 ≥|aₙ|/2>0，所以 |p(z)|≥(|aₙ|/2)|z|ⁿ→∞。
  因此 |1/p(z)|≤2/(|aₙ||z|ⁿ)→0（|z|→∞）。
  存在 R，当 |z|>R 时 |1/p(z)|≤1。

  在 |z|≤R 上，1/p 连续（解析当然连续），有界闭区域上连续函数有界——存在 M₁ 使得 |1/p(z)|≤M₁。
  所以 |1/p(z)|≤max(1, M₁) 对所有 z——1/p 有界。

  **应用 Liouville 定理**：
  1/p 是有界整函数 ⟹ 1/p 为常数 ⟹ p 为常数。
  但 p 是 n≥1 次多项式，不是常数——矛盾！
  所以 p 必有复零点。∎

  **进一步**：
  找到一个根 z₁ 后，p(z)=(z-z₁)p₁(z)，p₁ 是 n-1 次多项式。
  归纳可得 p 有 n 个复根（计重数）。∎

  **几何理解**：
  代数基本定理的复分析证明展示了 Liouville 定理的威力——用"有界整函数=常数"这个简单结论，证明了代数中最基本的定理。
  关键洞察：如果多项式无零点，则 1/p 是整函数；而多项式在无穷远处增长足够快，使得 1/p 在无穷远处趋于 0，从而有界。
  这是"解析函数的全局刚性"在代数中的应用——解析性+增长条件=强结论。
- **一句话点评**：反证:p无零点⟹1/p整函数。|z|→∞时|p(z)|≥(|aₙ|/2)|z|ⁿ→∞⟹|1/p|→0。|z|>R时|1/p|≤1;|z|≤R时连续有界M₁⟹1/p全局有界。Liouville⟹1/p=常数⟹p=常数,与n≥1矛盾⟹p必有根。归纳得n个根(计重数)。关键:多项式无穷远增长快⟹倒数有界⟹Liouville适用。解析性+增长条件=强结论。

**【D8-2-013】** 证明 Morera 定理：若 f 在区域 D 内连续且沿任意闭曲线积分为零，则 f 解析。构造原函数 F(z)=∫_{z₀}^z f(ζ)dζ（路径无关），证明 F 解析且 F'=f（类似 D8-2-006），再由"解析函数的导数仍解析"得 f 解析。说明这是 Cauchy 定理的逆定理。

- **难度**：★★
- **对应知识点**：Morera定理、Cauchy定理逆定理、原函数构造、解析函数导数解析
- **解答**：
  **Morera 定理**：
  若 f 在区域 D 内连续，且对 D 内任意闭曲线 C 有 ∮_C f(z)dz=0，则 f 在 D 内解析。

  **证明**：
  **第1步：积分与路径无关**
  闭路积分为零 ⟹ 积分与路径无关（两条路径组成闭曲线，积分相等）。

  **第2步：构造原函数**
  固定 z₀∈D，定义 F(z)=∫_{z₀}^z f(ζ)dζ（与路径无关，良定义）。

  **第3步：证明 F'=f**
  与 D8-2-006 完全相同：
  [F(z+h)-F(z)]/h=(1/h)∫_z^{z+h}f(ζ)dζ。
  f 连续 ⟹ ML 估计 ⟹ F'(z)=f(z)。∎
  所以 F 可导（在 D 内处处可导），F 解析。

  **第4步：f 解析**
  F 解析 ⟹ F' 解析（解析函数的导数仍解析——高阶导数公式的推论）。
  而 F'=f，所以 f 解析。∎

  **与 Cauchy 定理的关系**：
  Cauchy 定理：解析 ⟹ 闭路积分为零。
  Morera 定理：连续 + 闭路积分为零 ⟹ 解析。
  两者结合：在连续函数类中，解析 ⟺ 闭路积分为零。
  这给出了解析函数的"积分定义"——不需要假设可导，只需要连续+闭路积分为零。

  **注意**：
  Morera 定理中的"连续"条件不能去掉——如果 f 不连续，闭路积分为零也不能推出解析（可以有很病态的函数）。
  但实际上，闭路积分为零+局部可积往往已经蕴含了某种正则性。

  **几何理解**：
  Morera 定理说明"无旋场（闭路积分为零）+ 连续 = 解析函数"——这是向量场理论中的"保守场=梯度场"在复分析中的对应。
  在二维向量场中，无旋+连续 ⟹ 存在势函数（原函数），势函数可导 ⟹ 场函数是势函数的导数 ⟹ 场函数解析。
  这是"整体条件（积分）决定局部性质（可导）"的典范。
- **一句话点评**：闭路积分=0⟹路径无关⟹F(z)=∫_{z₀}^z f良定义。f连续⟹F'=f(ML估计)⟹F解析。F解析⟹F'解析(高阶导数公式)⟹f=F'解析。Cauchy:解析⟹闭路积分=0;Morera:连续+闭路积分=0⟹解析。结合:连续函数类中解析⟺闭路积分=0=积分定义。无旋场+连续=解析=保守场=梯度场的复分析对应。整体条件(积分)决定局部性质(可导)。

**【D8-2-014】** 计算 ∮_{|z|=2} z²/(z²+1) dz：部分分式 z²/(z²+1)=1-1/(z²+1)=1-(1/(2i))[1/(z-i)-1/(z+i)]。|z|=2 同时包围 i 和 -i，∮1 dz=0，∮1/(z-i)=2πi，∮1/(z+i)=2πi，所以积分=0-(1/(2i))(2πi-2πi)=0。

- **难度**：★★
- **对应知识点**：闭路积分计算、部分分式、两个奇点都在内部
- **解答**：
  **部分分式**：
  z²/(z²+1)=(z²+1-1)/(z²+1)=1-1/(z²+1)=1-(1/(2i))[1/(z-i)-1/(z+i)]。

  **积分**：
  C:|z|=2 同时包围 i 和 -i（都在内部）。
  ∮_C 1 dz=0（常数解析，Cauchy 定理）。
  ∮_C 1/(z-i) dz=2πi（i 在内部）。
  ∮_C 1/(z+i) dz=2πi（-i 在内部）。

  ∮_C z²/(z²+1) dz = ∮1 dz - (1/(2i))[∮1/(z-i)dz - ∮1/(z+i)dz]
  = 0 - (1/(2i))[2πi - 2πi]
  = 0 - 0 = 0。∎

  **验证（无穷远点视角）**：
  z²/(z²+1)→1（z→∞），在无穷远点是"可去奇点"（极限存在且有限）。
  对于在无穷远可去的函数，绕所有有限奇点的积分之和为零——与计算一致。

  **如果 C:|z|=1/2（不包围任何奇点）**：
  z²/(z²+1) 在 |z|&lt;1/2 内解析（奇点 ±i 都在外部），Cauchy 定理 ⟹ 积分=0。

  **如果 C 只包围 i（如 |z-i|=1/2）**：
  ∮ z²/(z²+1)dz = 0 - (1/(2i))[2πi - 0] = -π。

  **几何理解**：
  当曲线包围所有奇点时，积分可以从"无穷远"的角度看——函数在无穷远的行为决定了总积分。
  z²/(z²+1)→1（常数），在无穷远是"平凡的"，所以总积分为零。
  这是留数定理中"无穷远点留数"的概念——所有有限点留数+无穷远点留数=0。
- **一句话点评**：z²/(z²+1)=1-(1/(2i))[1/(z-i)-1/(z+i)]。|z|=2包围±i:∮1=0,∮1/(z-i)=2πi,∮1/(z+i)=2πi⟹积分=0-(1/(2i))(2πi-2πi)=0。无穷远视角:z²/(z²+1)→1(可去奇点)⟹所有有限奇点积分和=0。只包围i时积分=-π。留数定理:有限留数和+无穷远留数=0。

**【D8-2-015】** 用 Cauchy 积分公式计算 ∮_{|z|=1} eᶻ/z dz：f(z)=eᶻ 在 |z|≤1 上解析，z₀=0 在内部，所以 ∮eᶻ/z dz=2πi·f(0)=2πi·1=2πi。再用高阶导数公式计算 ∮eᶻ/z³ dz=f''(0)·2πi/2!=1·πi=πi。

- **难度**：★★
- **对应知识点**：Cauchy积分公式应用、高阶导数公式应用、eᶻ的导数
- **解答**：
  **∮_{|z|=1} eᶻ/z dz**：
  f(z)=eᶻ 在 |z|≤1 上解析（整函数），z₀=0 在 C 内部。
  Cauchy 积分公式：f(z₀)=(1/2πi)∮f(z)/(z-z₀)dz。
  ∮eᶻ/z dz = 2πi·f(0) = 2πi·e⁰ = 2πi。∎

  **∮_{|z|=1} eᶻ/z³ dz**：
  高阶导数公式：f^{(n)}(z₀)=n!/(2πi)∮f(z)/(z-z₀)^{n+1}dz。
  这里 n+1=3 ⟹ n=2，z₀=0。
  f''(z)=eᶻ, f''(0)=1。
  ∮eᶻ/z³ dz = (2πi/2!)·f''(0) = πi·1 = πi。∎

  **一般公式**：
  ∮_{|z|=1} eᶻ/z^{n+1} dz = (2πi/n!)·f^{(n)}(0) = (2πi/n!)·1 = 2πi/n!。
  （因为 eᶻ 的所有阶导数都是 eᶻ，在 0 处为 1。）

  **验证（级数法）**：
  eᶻ=Σzᵏ/k!，eᶻ/z³=Σz^{k-3}/k!。
  闭路积分只有 z^{-1} 项非零：k-3=-1 ⟹ k=2，系数=1/2!。
  ∮eᶻ/z³dz=2πi·(1/2!)=πi。∎
  与高阶导数公式一致！

  **几何理解**：
  Cauchy 积分公式将"绕奇点的积分"转化为"函数在奇点处的值"——奇点处的函数值决定了积分。
  高阶导数公式将"更高阶极点的积分"转化为"函数的导数值"——极点阶数越高，需要的导数阶数越高。
  这是留数定理的具体应用——留数就是 Laurent 展开中 z^{-1} 项的系数。
- **一句话点评**：∮eᶻ/z=2πi·f(0)=2πi(Cauchy公式,f=eᶻ)。∮eᶻ/z³=(2πi/2!)f''(0)=πi(高阶导数n=2,f''=eᶻ,f''(0)=1)。一般∮eᶻ/z^{n+1}=2πi/n!。级数验证:eᶻ/z³=Σz^{k-3}/k!,z^{-1}项k=2系数1/2!,积分=2πi/2!=πi✓。积分=奇点处函数值/导数值决定=留数定理具体应用。

**【D8-2-016】** 讨论无界区域的 Cauchy 积分公式：若 f 在无界区域 D（外部区域）内解析，且 lim_{z→∞}f(z)=0，则 f(z₀)=(1/2πi)∮_C f(z)/(z-z₀)dz，其中 C 是 D 的边界（顺时针方向，因为区域在左侧）。说明方向反转的原因。

- **难度**：★★
- **对应知识点**：无界区域Cauchy公式、边界方向、lim f=0条件、方向反转
- **解答**：
  **无界区域 Cauchy 积分公式**：
  设 D 是简单闭曲线 C 的外部区域（无界），f 在 D 内解析（包括无穷远点附近），且 lim_{z→∞}f(z)=0。
  对 z₀∈D（C 外部）：
  f(z₀)=(1/2πi)∮_C f(z)/(z-z₀) dz，
  其中 C 取**顺时针**方向（区域 D 在曲线左侧——顺时针时外部在左侧）。

  **证明思路**：
  取大圆周 C_R:|z|=R（R 足够大，包围 C 和 z₀）。
  在 C 和 C_R 之间的有界区域（环形）上应用复合闭路定理：
  ∮_{C_R（逆时针）} f/(z-z₀) dz + ∮_{C（顺时针）} f/(z-z₀) dz = 2πi f(z₀)。
  （z₀ 在环形区域内，Cauchy 积分公式。）

  当 R→∞ 时：
  |∮_{C_R} f/(z-z₀)dz| ≤ (max|f|)/(R-|z₀|)·2πR → 0（因为 f→0，max|f|→0，而 2πR/(R-|z₀|)→2π）。
  所以 C_R 积分趋于 0。

  剩下：∮_{C（顺时针）} f/(z-z₀) dz = 2πi f(z₀)。
  即 f(z₀)=(1/2πi)∮_{C（顺时针）} f/(z-z₀) dz。∎

  **方向反转的原因**：
  有界区域中，正向=逆时针（区域在左侧）。
  无界区域（外部）中，区域在曲线的"外侧"，要让区域在左侧，曲线必须顺时针走。
  所以无界区域的边界正向是顺时针——与有界区域相反。

  **条件 lim f=0 的必要性**：
  如果 f 在无穷远不趋于 0，C_R 积分可能不趋于 0——如 f(z)=1，∮_{C_R}1/(z-z₀)dz=2πi≠0。
  lim f=0 保证了大圆周积分消失，从而公式成立。

  **几何理解**：
  无界区域 Cauchy 公式说明"外部区域的值也由边界决定"——只要函数在无穷远消失，边界值就决定了外部所有点的值。
  这与有界区域的公式对称——解析函数在"两侧"都由边界决定。
  方向反转是因为"左侧规则"在外部区域需要顺时针才能让外部在左侧。
- **一句话点评**：无界区域(C外部),f解析且lim_{z→∞}f=0。取大圆周C_R包围C和z₀,环形区域复合闭路:∮_{C_R(逆)}+∮_{C(顺)}=2πif(z₀)。R→∞时|∮_{C_R}|≤max|f|·2πR/(R-|z₀|)→0(f→0)⟹∮_{C(顺)}=2πif(z₀)。方向:有界区域正向=逆(区域左),无界区域正向=顺(外部在左)。lim f=0必要(f=1时C_R积分=2πi≠0)。外部值也由边界决定,与有界对称。

## L2 复变函数层（★★★ 研究）

**【D8-2-017】** 讨论 Cauchy 积分公式与 Poisson 积分公式的关系：将 f=u+iv 代入 Cauchy 公式，取实部得到调和函数的 Poisson 积分公式 u(r,θ)=(1/2π)∫₀²π u(R,φ)·(R²-r²)/(R²-2Rr cos(θ-φ)+r²) dφ。说明解析函数的实部/虚部（调和函数）由边界值决定，Poisson 核是柯西核的实部。

- **难度**：★★★
- **对应知识点**：Poisson积分公式、调和函数边界值、柯西核实部、Poisson核
- **解答**：
  **Cauchy 积分公式（单位圆盘）**：
  f(z)=(1/2πi)∮_{|ζ|=1} f(ζ)/(ζ-z) dζ。
  参数化 ζ=e^{iφ}, dζ=ie^{iφ}dφ：
  f(z)=(1/2π)∫₀²π f(e^{iφ})·e^{iφ}/(e^{iφ}-z) dφ。

  **取实部**：
  设 z=re^{iθ}, f=u+iv。
  Re[e^{iφ}/(e^{iφ}-re^{iθ})] = Re[1/(1-re^{i(θ-φ)})] = (1-r cos(θ-φ))/(1-2r cos(θ-φ)+r²)。
  但这还不是 Poisson 核——需要利用 f 的共轭值。

  **Poisson 公式推导**：
  利用 f(z)=(1/2π)∫f(e^{iφ})·(e^{iφ}+z)/(e^{iφ}-z) dφ（Schwarz 公式，对实部成立）。
  取实部：
  u(r,θ)=(1/2π)∫₀²π u(R,φ)·Re[(e^{iφ}+z)/(e^{iφ}-z)] dφ。
  Re[(e^{iφ}+re^{iθ})/(e^{iφ}-re^{iθ})] = (R²-r²)/(R²-2Rr cos(θ-φ)+r²)（一般半径 R）。
  这就是 Poisson 核 P_R(r,θ-φ)=(R²-r²)/(R²-2Rr cos(θ-φ)+r²)。∎

  **Poisson 积分公式**：
  u(r,θ)=(1/2π)∫₀²π u(R,φ)·P_R(r,θ-φ) dφ。

  **Poisson 核的性质**：
  1. P_R(r,θ-φ)>0（正核）
  2. (1/2π)∫₀²π P_R(r,θ-φ)dφ=1（归一化）
  3. r→R 时 P_R→δ(θ-φ)（逼近 δ 函数）
  4. P_R 是调和函数（在 r&lt;R 内）

  **几何理解**：
  Poisson 公式说明调和函数在内部的值是边界值的"加权平均"——权重是 Poisson 核，在正对的方向（θ=φ）权重最大，偏离方向权重减小。
  这是调和函数"平均值原理"的推广——不只是圆心的平均值，而是任意点的加权平均。
  Cauchy 积分公式（复）→ Poisson 积分公式（实，调和函数）是"复分析→实分析"的经典转化。
  Poisson 核在概率论中是"布朗运动的击中分布"——从 (r,θ) 出发的布朗运动首次到达边界时在 φ 处的概率密度就是 Poisson 核。
- **一句话点评**：Cauchy公式f(z)=(1/2π)∫f(e^{iφ})e^{iφ}/(e^{iφ}-z)dφ。利用Schwarz公式取实部⟹u(r,θ)=(1/2π)∫u(R,φ)·P_R(r,θ-φ)dφ。Poisson核P_R=(R²-r²)/(R²-2Rr cos(θ-φ)+r²)=柯西核的实部。性质:正核/归一化(积分=1)/r→R→δ函数/调和。调和函数内部值=边界值加权平均(正对方向权重最大)。Poisson核=布朗运动击中分布概率密度。

**【D8-2-018】** 讨论 Cauchy 积分公式的平均值原理推论：若 f 在 |z-z₀|&lt;R 内解析，则 f(z₀)=(1/2π)∫₀²π f(z₀+re^{iθ})dθ（对任意 r&lt;R）。即解析函数在圆心的值等于圆周上的平均值。取模得 |f(z₀)|≤max|f|——最大值原理的积分证明。

- **难度**：★★★
- **对应知识点**：平均值原理、Cauchy公式推论、最大值原理积分证明、模的估计
- **解答**：
  **平均值原理**：
  f 在 |z-z₀|&lt;R 内解析，对任意 r&lt;R：
  f(z₀)=(1/2πi)∮_{|z-z₀|=r} f(z)/(z-z₀) dz。
  参数化 z=z₀+re^{iθ}, dz=ire^{iθ}dθ：
  f(z₀)=(1/2πi)∫₀²π f(z₀+re^{iθ})/(re^{iθ})·ire^{iθ}dθ=(1/2π)∫₀²π f(z₀+re^{iθ})dθ。∎
  解析函数在圆心的值=圆周上的平均值。

  **最大值原理（积分证明）**：
  取模：|f(z₀)|=|(1/2π)∫f(z₀+re^{iθ})dθ|≤(1/2π)∫|f(z₀+re^{iθ})|dθ≤max_{|z-z₀|=r}|f(z)|。
  所以圆心值的模≤圆周上的最大模。

  如果 f 在区域内部取到最大值 M（|f(z₀)|=M），则：
  M=|f(z₀)|≤(1/2π)∫|f|dθ≤M。
  所有不等式取等号 ⟹ |f(z₀+re^{iθ})|=M 对所有 θ（因为连续函数的平均等于最大值当且仅当函数恒为最大值）。
  所以 |f|=M 在圆周上恒成立。
  对任意 r&lt;R 都成立 ⟹ |f|=M 在整个圆盘内成立。
  由解析函数的性质（|f|=常数 ⟹ f=常数，因为 u²+v²=常数蕴含 C-R 方程下 u,v 为常数），f 为常数。∎
  非常数解析函数在区域内部不能取最大值——最大值原理。

  **与调和函数的关系**：
  平均值原理对调和函数也成立——u(z₀)=(1/2π)∫u(z₀+re^{iθ})dθ。
  调和函数的最大值原理：非常数调和函数在内部不能取最大值。
  解析函数的实部/虚部是调和函数，所以解析函数的模的最大值原理可以通过调和函数推导。

  **几何理解**：
  平均值原理是解析函数"全局刚性"的最直观表达——圆心的值由圆周上的值平均决定，不能"偏离"圆周值太远。
  这与实变函数不同——实变函数在区间内部的值可以远大于端点值（如 -x² 在 0 处取最大值）。
  解析函数不能"内部凸起"——它必须是"鞍状"的（实部和虚部都是调和函数，没有局部极值）。
- **一句话点评**：f(z₀)=(1/2πi)∮f/(z-z₀)dz,参数化⟹f(z₀)=(1/2π)∫₀²πf(z₀+re^{iθ})dθ=圆周平均。取模:|f(z₀)|≤(1/2π)∫|f|≤max|f|。若内部取最大值M⟹平均=M⟹|f|=M在圆周恒成立⟹对所有r成立⟹|f|=M全域⟹f=常数。非常数解析函数内部不能取最大值=最大值原理。解析函数不能"内部凸起",必须"鞍状"(调和函数无局部极值)。

## L3 实变函数层（★★★ 研究）

**【D8-2-019】** 从实变函数论的角度对比 Cauchy 积分定理与 Green 公式：Cauchy 原始证明用 Green 公式 ∮Pdx+Qdy=∬(Q_x-P_y)dA，代入 fdz=(u dx-v dy)+i(v dx+u dy)，两个实积分的旋度分别为 -v_x-u_y 和 u_x-v_y，由 C-R 方程都为零。说明 Green 公式需要偏导连续（f'连续），而 Goursat 去掉了这个假设——这是实变方法和复变方法的区别。

- **难度**：★★★
- **对应知识点**：Green公式证Cauchy、旋度为零、f'连续假设、Goursat改进、实变vs复变方法
- **解答**：
  **Cauchy 原始证明（Green 公式）**：
  fdz=(u+iv)(dx+idy)=(u dx-v dy)+i(v dx+u dy)。

  第一个实积分 ∮(u dx-v dy)：
  Green 公式：∮P dx+Q dy=∬(Q_x-P_y)dA。
  P=u, Q=-v。Q_x-P_y=(-v)_x-u_y=-v_x-u_y。
  由 C-R：u_y=-v_x ⟹ -v_x-u_y=-v_x-(-v_x)=0。
  所以第一个积分=∬0 dA=0。∎

  第二个实积分 ∮(v dx+u dy)：
  P=v, Q=u。Q_x-P_y=u_x-v_y。
  由 C-R：u_x=v_y ⟹ u_x-v_y=0。
  所以第二个积分=0。∎

  ∮fdz=0+i·0=0。

  **Green 公式的条件**：
  Green 公式要求 P,Q 有连续偏导数——即 u_x,u_y,v_x,v_y 连续，即 f' 连续。
  Cauchy 原始证明假设了 f' 连续。

  **Goursat 的改进**：
  Goursat（1900）去掉了 f' 连续的假设——只需要 f 处处可导。
  方法是三角形二分法（不用 Green 公式，不需要偏导连续）。
  这意味着"可导"本身已经蕴含了"f' 连续"（甚至 f' 解析）——Cauchy 积分定理+Cauchy 公式推出 f' 解析，所以 f' 连续是可导的推论，不是额外假设。

  **实变 vs 复变方法**：
  - 实变方法（Green 公式）：需要强假设（偏导连续），但证明简单直接。
  - 复变方法（Goursat 二分法）：只需要弱假设（可导），但证明更精巧。
  复变方法的优势在于揭示了"可导=解析"的等价性——不需要额外的连续性假设。

  **几何理解**：
  Green 公式将"闭路积分"转化为"区域内旋度的积分"——Cauchy 定理说解析函数的旋度为零（C-R 方程），所以闭路积分为零。
  这是"无旋场=保守场"的二维版本——旋度为零的场沿闭路做功为零。
  Goursat 的改进说明：即使不假设旋度连续，只要场是"复可导"的（各向同性），旋度就自动为零且连续——复可导比"实可导+旋度为零"更强。
- **一句话点评**：fdz=(u dx-v dy)+i(v dx+u dy)。Green公式:第一个∮(u dx-v dy)=∬(-v_x-u_y)dA=0(C-R:u_y=-v_x);第二个∮(v dx+u dy)=∬(u_x-v_y)dA=0(C-R:u_x=v_y)。Green需偏导连续=f'连续(Cauchy原始假设)。Goursat去掉f'连续(三角形二分法),证明可导⟹f'连续(甚至解析)=推论非假设。实变方法(Green)强假设简单;复变方法(Goursat)弱假设精巧。复可导=各向同性⟹旋度自动为零且连续>实可导+旋度为零。

## 补充基础题（L1 数学分析 / L2 复变函数 / L3 实变函数）

### L1 数学分析基础

**【D8-2-020】** 叙述 Green 公式：$\oint_C Pdx+Qdy=\iint_D(\frac{\partial Q}{\partial x}-\frac{\partial P}{\partial y})dxdy$，并说明它是 Cauchy 定理的实分析基础。

- **难度**：★★
- **解答**：Green 公式：设 $D$ 是平面有界区域，边界 $C$ 为分段光滑正向闭曲线，$P,Q$ 在 $D$ 上有连续偏导数，则
$\oint_C Pdx+Qdy=\iint_D(\frac{\partial Q}{\partial x}-\frac{\partial P}{\partial y})dxdy$。
对复积分 $\oint_C f(z)dz=\oint_C(u+iv)(dx+idy)=\oint_C(udx-vdy)+i\oint_C(vdx+udy)$。
由 Green 公式：
$\oint_C(udx-vdy)=\iint_D(-v_x-u_y)dxdy=0$（C-R 方程 $u_y=-v_x$）
$\oint_C(vdx+udy)=\iint_D(u_x-v_y)dxdy=0$（C-R 方程 $u_x=v_y$）
故 $\oint_C f(z)dz=0$——Cauchy 定理。∎
- **点评**：Green 公式是 Cauchy 定理的实分析基础——复积分的实部和虚部分别应用 Green 公式，C-R 方程使被积函数为零。这是复分析与实分析的桥梁。

**【D8-2-021】** 证明：若 $Pdx+Qdy$ 在单连通区域内满足 $\frac{\partial Q}{\partial x}=\frac{\partial P}{\partial y}$，则积分与路径无关，且存在原函数 $U$ 使 $dU=Pdx+Qdy$。

- **难度**：★★
- **解答**：设 $D$ 单连通，$\frac{\partial Q}{\partial x}=\frac{\partial P}{\partial y}$ 在 $D$ 内。
对任意两条从 $A$ 到 $B$ 的路径 $C_1,C_2$，$C_1-C_2$ 是闭曲线，由 Green 公式：
$\oint_{C_1-C_2}Pdx+Qdy=\iint(\frac{\partial Q}{\partial x}-\frac{\partial P}{\partial y})dxdy=0$。
故 $\int_{C_1}=\int_{C_2}$，积分与路径无关。
定义 $U(x,y)=\int_{(x_0,y_0)}^{(x,y)}Pdx+Qdy$（路径无关，定义合理）。
$\frac{\partial U}{\partial x}=P$，$\frac{\partial U}{\partial y}=Q$，故 $dU=Pdx+Qdy$。∎
- **点评**：路径无关性与原函数存在性等价——这是实分析中的基本定理。在复分析中，对应"解析函数在单连通区域内有原函数"。

**【D8-2-022】** 计算 $\oint_{|z|=1}\frac{dz}{z}=2\pi i$，并说明为什么这个积分不为零（尽管 $1/z$ 在 $0<|z|$ 内解析）。

- **难度**：★★
- **解答**：参数化 $z=e^{i\theta}$，$\theta\in[0,2\pi]$，$dz=ie^{i\theta}d\theta$。
$\oint_{|z|=1}\frac{dz}{z}=\int_0^{2\pi}\frac{ie^{i\theta}}{e^{i\theta}}d\theta=\int_0^{2\pi}i\,d\theta=2\pi i$。
$1/z$ 在 $0<|z|$ 内解析，但区域不是单连通的（有一个洞 $z=0$）。
Cauchy 定理要求区域单连通（或函数在整个区域包括内部解析）。这里 $z=0$ 是奇点，不在解析区域内，所以积分可以不为零。
$2\pi i$ 是"绕奇点一周"的拓扑不变量——与路径无关，只与绕奇点的圈数有关。∎
- **点评**：$\oint\frac{dz}{z}=2\pi i$ 是复分析中最重要的积分——它是留数定理的基础。积分不为零是因为区域不单连通（有洞），这是拓扑对分析的影响。

**【D8-2-023】** 证明：若 $f$ 在单连通区域 $D$ 内解析，则 $f$ 在 $D$ 内有原函数 $F$（$F'=f$），且 $\int_\gamma f(z)dz=F(\gamma(b))-F(\gamma(a))$。

- **难度**：★★
- **解答**：由 Cauchy 定理，$f$ 沿 $D$ 内任何闭曲线积分为 0，故积分与路径无关。
固定 $z_0\in D$，定义 $F(z)=\int_{z_0}^z f(\zeta)d\zeta$（路径无关）。
$F'(z)=\lim_{h\to0}\frac{F(z+h)-F(z)}{h}=\lim_{h\to0}\frac{1}{h}\int_z^{z+h}f(\zeta)d\zeta=f(z)$（由 $f$ 连续性）。
故 $F'=f$，$F$ 是原函数。
对任意路径 $\gamma$ 从 $a$ 到 $b$，$\int_\gamma f(z)dz=F(b)-F(a)$（Newton-Leibniz 公式的复版本）。∎
- **点评**：单连通区域内解析函数必有原函数——这是 Cauchy 定理的重要推论。原函数的存在性使得复积分可以像实积分一样用"端点值之差"计算。

### L2 复变函数基础

**【D8-2-024】** 叙述 Cauchy 积分公式：$f(z_0)=\frac{1}{2\pi i}\oint_C\frac{f(z)}{z-z_0}dz$（$z_0$ 在 $C$ 内部）。

- **难度**：★★
- **解答**：Cauchy 积分公式：设 $f$ 在区域 $D$ 内解析，$C$ 是 $D$ 内正向简单闭曲线，$z_0$ 在 $C$ 内部，则
$f(z_0)=\frac{1}{2\pi i}\oint_C\frac{f(z)}{z-z_0}dz$。
证明：$\oint_C\frac{f(z)}{z-z_0}dz=\oint_{|z-z_0|=\varepsilon}\frac{f(z)}{z-z_0}dz$（围道变形，因为 $\frac{f(z)}{z-z_0}$ 在两围道之间解析）。
参数化 $z=z_0+\varepsilon e^{i\theta}$：$=\int_0^{2\pi}\frac{f(z_0+\varepsilon e^{i\theta})}{\varepsilon e^{i\theta}}i\varepsilon e^{i\theta}d\theta=i\int_0^{2\pi}f(z_0+\varepsilon e^{i\theta})d\theta$。
令 $\varepsilon\to0$，$f(z_0+\varepsilon e^{i\theta})\to f(z_0)$ 一致，故 $=i\cdot2\pi f(z_0)=2\pi i f(z_0)$。∎
- **点评**：Cauchy 积分公式是复分析的核心定理——解析函数在内部的值完全由边界值决定。这是解析函数"刚性"的极致体现：边界值决定内部一切。

**【D8-2-025】** 叙述 Cauchy 导数公式：$f^{(n)}(z_0)=\frac{n!}{2\pi i}\oint_C\frac{f(z)}{(z-z_0)^{n+1}}dz$，说明解析函数无穷次可微。

- **难度**：★★
- **解答**：Cauchy 导数公式：$f^{(n)}(z_0)=\frac{n!}{2\pi i}\oint_C\frac{f(z)}{(z-z_0)^{n+1}}dz$（$n=0,1,2,\ldots$）。
$n=0$ 就是 Cauchy 积分公式。
$n=1$：$f'(z_0)=\frac{1}{2\pi i}\oint_C\frac{f(z)}{(z-z_0)^2}dz$。
证明：对 Cauchy 积分公式在积分号下求导（可由差商极限 + 一致收敛证明）。
推论：解析函数无穷次可微（所有阶导数都存在且解析）。
这与实函数截然不同：实可微函数不一定二次可微，而复可微（解析）函数自动无穷次可微。∎
- **点评**：Cauchy 导数公式说明解析函数无穷次可微——这是复分析最令人惊叹的结果之一。复可微（一阶）蕴含无穷次可微，这是实函数没有的"刚性"。

**【D8-2-026】** 用 Cauchy 不等式证明 Liouville 定理：有界整函数必为常数。

- **难度**：★★
- **解答**：Cauchy 不等式：$|f^{(n)}(z_0)|\leq\frac{n!M_R}{R^n}$，其中 $M_R=\max_{|z-z_0|=R}|f(z)|$。
设 $f$ 是有界整函数，$|f(z)|\leq M$ 对所有 $z$。
对 $n=1$：$|f'(z_0)|\leq\frac{M}{R}$ 对所有 $R>0$。
令 $R\to\infty$，得 $|f'(z_0)|=0$，故 $f'(z_0)=0$ 对所有 $z_0$。
$f'\equiv0$ ⟹ $f$ 为常数（D8-1-023）。
Liouville 定理是代数基本定理的证明基础：非常数多项式 $p(z)$ 必有零点（否则 $1/p$ 是有界整函数，必为常数，矛盾）。∎
- **点评**：Liouville 定理——有界整函数必为常数。这是解析函数"刚性"的又一体现：整函数要么无界，要么常数。它给出了代数基本定理的最简洁证明。

### L3 实变函数基础

**【D8-2-027】** 叙述 Fubini 定理：若 $f\in L^1(X\times Y)$，则 $\int_{X\times Y}f(x,y)d(\mu\times\nu)=\int_X\int_Y f(x,y)d\nu(y)d\mu(x)=\int_Y\int_X f(x,y)d\mu(x)d\nu(y)$。

- **难度**：★★
- **解答**：Fubini 定理：设 $(X,\mu),(Y,\nu)$ 是 $\sigma$-有限测度空间，$f\in L^1(X\times Y)$（即 $\int|f|d(\mu\times\nu)<\infty$），则
(1) 对几乎所有 $x$，$f(x,\cdot)\in L^1(Y)$；对几乎所有 $y$，$f(\cdot,y)\in L^1(X)$。
(2) $x\mapsto\int_Y f(x,y)d\nu(y)$ 和 $y\mapsto\int_X f(x,y)d\mu(x)$ 分别在 $X,Y$ 上可积。
(3) 三重积分相等：$\int_{X\times Y}f=\int_X\int_Y f=\int_Y\int_X f$。
注意：若 $f\geq0$，即使积分无穷，等式也成立（Tonelli 定理）。
若 $f$ 不是绝对可积的，积分次序可能不同（条件收敛的反例）。∎
- **点评**：Fubini 定理是重积分交换次序的理论基础——它要求绝对可积。在复分析中，Cauchy 积分公式的证明、幂级数逐项积分等都隐含使用了 Fubini/Tonelli。

**【D8-2-028】** 证明：绝对连续函数 $F$ 几乎处处可微，且 $F(b)-F(a)=\int_a^b F'(x)dx$（Lebesgue 版本的 Newton-Leibniz 公式）。

- **难度**：★★
- **解答**：Lebesgue 微分定理：若 $F$ 在 $[a,b]$ 上绝对连续，则 $F$ 几乎处处可微，$F'\in L^1[a,b]$，且
$F(b)-F(a)=\int_a^b F'(x)dx$。
证明思路：(1) 绝对连续函数是有界变差函数（可以分解为两个递增函数之差）；(2) 单调函数几乎处处可微（Lebesgue 定理）；(3) 绝对连续性保证 $\int F'=F(b)-F(a)$（普通有界变差函数可能有"奇异部分"，使积分小于差值）。
反例：Cantor 函数（连续、单调递增、导数 a.e. 为 0）不是绝对连续的，$\int F'=0\neq F(1)-F(0)=1$。∎
- **点评**：绝对连续函数是 Newton-Leibniz 公式成立的精确条件——连续不够（Cantor 函数），Lipschitz 连续太强，绝对连续恰好。这是实变函数对微积分基本定理的深化。

**【D8-2-029】** 叙述 Riesz 表示定理：$C[0,1]$ 上的有界线性泛函都可以表示为 Riemann-Stieltjes 积分 $\Phi(f)=\int f\,d\mu$（有界变差函数 $\mu$）。

- **难度**：★★
- **解答**：Riesz 表示定理（$C[0,1]$ 的对偶）：对 $C[0,1]$ 上的任何有界线性泛函 $\Phi$，存在有界变差函数 $g$ 使
$\Phi(f)=\int_0^1 f(x)dg(x)$（Riemann-Stieltjes 积分），且 $\|\Phi\|=\text{Var}(g)$。
等价地（Lebesgue 版本）：$C(K)$（紧空间 $K$ 上连续函数）的对偶是 $K$ 上的有限正则 Borel 测度空间 $M(K)$，$\Phi(f)=\int_K f\,d\mu$。
在复分析中，Cauchy 积分公式可以看作 Riesz 表示定理的特例：$f(z_0)$ 是 $f$ 在边界上的积分表示，对应一个测度（调和测度）。∎
- **点评**：Riesz 表示定理将线性泛函具体化为测度积分——它是泛函分析的核心定理之一。Cauchy 积分公式、Poisson 积分公式等都可以看作 Riesz 表示定理在解析/调和函数空间上的特例。

## 跨领域综合题

### 经典名题

**【D8-2-CROSS-020】**（D8 × D6 完备性 × D5 级数）**用 Cauchy 积分公式证明 Taylor 级数展开：f(z)=Σ f^{(n)}(z₀)/n! (z-z₀)^n。将 Cauchy 公式中的 1/(ζ-z) 展开为几何级数 1/(ζ-z)=1/(ζ-z₀)·Σ[(z-z₀)/(ζ-z₀)]^n（因为 |z-z₀|&lt;|ζ-z₀|），逐项积分，用高阶导数公式识别系数。说明这是"可导=解析=幂级数展开"等价性的关键一步。**

- **难度**：★★★
- **对应知识点**：Taylor展开、Cauchy公式+几何级数、逐项积分、可导=解析
- **解答**：
  **Cauchy 积分公式**：
  f(z)=(1/2πi)∮_C f(ζ)/(ζ-z) dζ，C:|ζ-z₀|=R, |z-z₀|&lt;R。

  **几何级数展开**：
  1/(ζ-z)=1/[(ζ-z₀)-(z-z₀)]=1/(ζ-z₀)·1/[1-(z-z₀)/(ζ-z₀)]。
  因为 |z-z₀|&lt;|ζ-z₀|=R，所以 |(z-z₀)/(ζ-z₀)|&lt;1，几何级数收敛：
  1/[1-w]=Σ_{n=0}^∞ wⁿ，w=(z-z₀)/(ζ-z₀)。
  1/(ζ-z)=Σ_{n=0}^∞ (z-z₀)^n/(ζ-z₀)^{n+1}。∎

  **逐项积分**：
  f(z)=(1/2πi)∮ f(ζ)·Σ (z-z₀)^n/(ζ-z₀)^{n+1} dζ
  =Σ (z-z₀)^n · (1/2πi)∮ f(ζ)/(ζ-z₀)^{n+1} dζ
  （级数在 C 上一致收敛，可以逐项积分。）

  **识别系数**：
  由高阶导数公式：f^{(n)}(z₀)=n!/(2πi)∮ f(ζ)/(ζ-z₀)^{n+1} dζ。
  所以 (1/2πi)∮ f/(ζ-z₀)^{n+1} dζ = f^{(n)}(z₀)/n!。

  **Taylor 展开**：
  f(z)=Σ_{n=0}^∞ f^{(n)}(z₀)/n! · (z-z₀)^n。∎

  **等价性链条**：
  可导（区域内处处）⟹ Cauchy 积分定理（Goursat）⟹ Cauchy 积分公式 ⟹ 高阶导数公式 ⟹ Taylor 幂级数展开 ⟹ 解析（幂级数定义）。
  反过来，幂级数在收敛圆内逐项可导 ⟹ 可导。
  所以可导 ⟺ 解析（幂级数展开）——这是复变函数论最核心的等价性。

  **几何理解**：
  Taylor 展开说明解析函数在局部是"多项式的极限"——可以用任意高精度的多项式逼近。
  几何级数 1/(1-w)=Σwⁿ 是整个证明的引擎——它将"分式"转化为"幂级数"，而 Cauchy 公式将函数表示为分式的积分，从而自动得到幂级数。
  这是"积分表示→级数展开"的经典转化。
- **一句话点评**：f(z)=(1/2πi)∮f(ζ)/(ζ-z)dζ。1/(ζ-z)=1/(ζ-z₀)·1/[1-(z-z₀)/(ζ-z₀)]=Σ(z-z₀)^n/(ζ-z₀)^{n+1}(几何级数,|w|&lt;1)。逐项积分⟹Σ(z-z₀)^n·(1/2πi)∮f/(ζ-z₀)^{n+1}。高阶导数公式⟹系数=f^{(n)}(z₀)/n!⟹Taylor展开。链条:可导⟹Cauchy定理⟹Cauchy公式⟹高阶导数⟹Taylor⟹解析;幂级数逐项可导⟹可导。可导⟺解析。几何级数1/(1-w)=Σwⁿ是引擎。

**【D8-2-CROSS-021】**（D8 × D7 三角学 × D4 积分）**用留数思想计算实积分 ∫₀²π dθ/(a+b cosθ)（a>b>0）：令 z=e^{iθ}, cosθ=(z+z^{-1})/2, dθ=dz/(iz)，积分化为 ∮_{|z|=1} dz/[iz(a+b(z+z^{-1})/2)] = (2/i)∮dz/[bz²+2az+b]。求分母的根，只有一个在单位圆内，用 Cauchy 积分公式得结果=2π/√(a²-b²)。**

- **难度**：★★★
- **对应知识点**：实积分复化、单位圆参数化、留数/Cauchy公式、三角积分
- **解答**：
  **积分**：I=∫₀²π dθ/(a+b cosθ), a>b>0。

  **复化**：
  z=e^{iθ}, cosθ=(z+z^{-1})/2, dθ=dz/(iz)。
  I=∮_{|z|=1} [1/(a+b(z+z^{-1})/2)]·dz/(iz)
  =∮ dz/[iz(a+b(z+z^{-1})/2)]
  =∮ dz/[i(az+b(z²+1)/2)]
  =(2/i)∮ dz/[bz²+2az+b]。

  **求分母的根**：
  bz²+2az+b=0 ⟹ z=(-2a±√(4a²-4b²))/(2b)=(-a±√(a²-b²))/b。
  记 z₁=(-a+√(a²-b²))/b, z₂=(-a-√(a²-b²))/b。
  z₁·z₂=b/b=1（韦达定理），所以一个在单位圆内，一个在外部。
  |z₁|=|(-a+√(a²-b²))/b|&lt;1（因为 a>√(a²-b²)，分子绝对值&lt;a，但需验证）。
  实际上 z₁z₂=1 且 |z₁|&lt;1&lt;|z₂|（因为 z₁+z₂=-2a/b&lt;0，两根都负，z₁ 靠近 0，z₂ 靠近 -∞）。
  z₁ 在单位圆内，z₂ 在外部。

  **Cauchy 积分公式**：
  bz²+2az+b=b(z-z₁)(z-z₂)。
  I=(2/i)∮ dz/[b(z-z₁)(z-z₂)] = (2/(ib))·(1/(z₁-z₂))·∮ dz/(z-z₁)
  = (2/(ib))·(1/(z₁-z₂))·2πi
  = 4π/[b(z₁-z₂)]。
  z₁-z₂=2√(a²-b²)/b。
  I=4π/[b·2√(a²-b²)/b]=2π/√(a²-b²)。∎

  **验证**：
  b=0 时 I=∫dθ/a=2π/a，公式 2π/√(a²-0)=2π/a ✓。
  a=2,b=1 时 I=2π/√3≈3.628，合理（分母 a+b cosθ∈[1,3]，积分≈2π/2=π 到 2π 之间）。

  **几何理解**：
  这是"实积分复化"的经典技巧——将三角函数积分转化为单位圆上的复积分，用 Cauchy 公式/留数定理计算。
  关键是 z=e^{iθ} 将 [0,2π] 转化为单位圆，cosθ, sinθ 转化为 z 的有理函数，dθ 转化为 dz/(iz)。
  这展示了复分析在计算实积分中的强大威力——许多难以用实变方法计算的积分，复化后变得简单。
- **一句话点评**：I=∫₀²πdθ/(a+bcosθ)。z=e^{iθ},cosθ=(z+z^{-1})/2,dθ=dz/(iz)⟹I=(2/i)∮dz/(bz²+2az+b)。根z₁=(-a+√(a²-b²))/b(圆内),z₂=(-a-√...)/b(圆外),z₁z₂=1。bz²+2az+b=b(z-z₁)(z-z₂)。I=(2/(ib))·(1/(z₁-z₂))·2πi=4π/[b(z₁-z₂)]=4π/[2√(a²-b²)]=2π/√(a²-b²)。实积分复化=单位圆上复积分=Cauchy公式。复分析计算实积分的经典技巧。

### 反例与构造

**【D8-2-CROSS-022】**（D8 × D3 微分 × D2 连续）**构造一个连续函数 f(z) 满足 C-R 方程但不解析：f(z)=e^{-1/z⁴}（z≠0）, f(0)=0。在 z≠0 处解析（C-R 成立），在 z=0 处偏导数都为 0（C-R 成立），但 f 在 z=0 处不连续（沿 45° 方向发散），所以不解析。说明 C-R 方程+偏导存在≠解析，还需要连续性/可导性。**

- **难度**：★★★
- **对应知识点**：C-R成立但不解析反例、e^{-1/z⁴}、路径极限、连续性必要
- **解答**：
  **f(z)=e^{-1/z⁴}（z≠0）, f(0)=0**

  **z≠0 处**：
  f 是 eᶻ 和 -1/z⁴ 的复合，在 z≠0 处解析（C-R 方程成立）。∎

  **z=0 处的偏导数**：
  沿实轴 z=x→0：f(x)=e^{-1/x⁴}→0，所有偏导数在 0 处为 0（类似 e^{-1/x²} 的论证，指数衰减快于任何多项式）。
  所以 u_x(0,0)=u_y(0,0)=v_x(0,0)=v_y(0,0)=0。
  C-R 方程在 0 处成立（0=0, 0=-0）。∎

  **但 f 在 z=0 处不连续**：
  沿路径 z=re^{iπ/4}（45° 方向）→0：
  z⁴=r⁴e^{iπ}=-r⁴，所以 -1/z⁴=-1/(-r⁴)=1/r⁴→+∞。
  f(z)=e^{1/r⁴}→+∞≠0=f(0)。
  所以 f 在 0 处不连续——更不可导、不解析。∎

  **教训**：
  C-R 方程在一点成立 + 偏导数存在 ≠ 在该点可导/解析。
  还需要：(1) 函数在该点连续；(2) 差商极限沿所有方向相同。
  充分条件：C-R 方程 + 偏导数连续（这蕴含了可导性）。
  这个反例中偏导数在 0 处存在但不连续（在 45° 方向附近偏导数无界），所以充分条件不满足。

  **与实变 e^{-1/x²} 对比**：
  实变 e^{-1/x²} 在 0 处连续（甚至 C^∞），只是不解析。
  复变 e^{-1/z⁴} 在 0 处连连续性都不满足（沿 45° 方向发散）——复变的"病态"更严重，因为复平面有更多方向。
  这再次说明复可导比实可导强得多——方向自由度带来了更多的约束和更严格的正则性。

  **几何理解**：
  e^{-1/z⁴} 在 z→0 时的行为高度依赖方向：
  - 沿实轴/虚轴（z⁴>0）：-1/z⁴→-∞，f→0
  - 沿 45°/135°/225°/315°（z⁴&lt;0）：-1/z⁴→+∞，f→∞
  这种方向依赖的极限是复变函数的典型特征——复可导要求所有方向极限相同，而这个函数在不同方向上极限不同（0 vs ∞），所以不可导。
- **一句话点评**：f=e^{-1/z⁴}(z≠0),f(0)=0。z≠0解析(C-R成立)。z=0偏导全为0(C-R成立)。但沿z=re^{iπ/4}→0:z⁴=-r⁴,-1/z⁴=1/r⁴→∞,f=e^{1/r⁴}→∞≠0⟹不连续⟹不解析。教训:C-R+偏导存在≠可导,还需连续+所有方向差商相同。充分条件:C-R+偏导连续。对比实变e^{-1/x²}连续(C∞)不解析;复变e^{-1/z⁴}连连续都不满足(方向依赖:实轴→0,45°→∞)。复可导=所有方向极限相同。

### 定理串联

**【D8-2-CROSS-023】**（D8 × D6 完备性 × D1 极限）**建立"Cauchy积分定理→Cauchy积分公式→高阶导数公式→Cauchy不等式→Liouville定理→代数基本定理"的完整链条，说明每一步如何依赖前一步。这是复变函数论中最经典的定理链条，从"闭路积分为零"一路推到"n次多项式必有n个复根"。**

- **难度**：★★★
- **对应知识点**：完整定理链条、Cauchy定理→公式→高阶导数→不等式→Liouville→代数基本定理
- **解答**：
  **完整链条**：

  **第1步：Cauchy 积分定理**
  f 在单连通区域解析 ⟹ ∮_C f(z)dz=0。
  证明：Goursat 三角形法（可导⟹局部线性化⟹细分后积分趋于零）。
  依赖：复可导的定义（所有方向差商相同）。

  **第2步：Cauchy 积分公式**
  f 解析 ⟹ f(z₀)=(1/2πi)∮ f(z)/(z-z₀) dz。
  证明：闭路变形原理（Cauchy 定理的推论）将 C 变形为绕 z₀ 的小圆，f(z)/(z-z₀)=f(z₀)/(z-z₀)+[f(z)-f(z₀)]/(z-z₀)，第一项积分=2πi f(z₀)，第二项用 ML 估计趋于零。
  依赖：Cauchy 积分定理（闭路变形）+ f 的连续性。

  **第3步：高阶导数公式**
  f 解析 ⟹ f^{(n)}(z₀)=n!/(2πi)∮ f(z)/(z-z₀)^{n+1} dz。
  证明：对 Cauchy 公式用差商+一致收敛，归纳法。
  依赖：Cauchy 积分公式 + 一致收敛性（积分号下求导）。
  意义：一次可导⟹无穷可导。

  **第4步：Cauchy 不等式**
  f 在 |z-z₀|&lt;R 解析且 |f|≤M ⟹ |f^{(n)}(z₀)|≤n!M/Rⁿ。
  证明：高阶导数公式 + ML 不等式，令 r→R。
  依赖：高阶导数公式 + ML 不等式。
  意义：函数值的界控制所有导数的界。

  **第5步：Liouville 定理**
  有界整函数 ⟹ 常数。
  证明：Cauchy 不等式（n=1）+ 令 R→∞ ⟹ f'=0 ⟹ f=常数。
  依赖：Cauchy 不等式 + 整函数（R 可以任意大）。

  **第6步：代数基本定理**
  n 次多项式 ⟹ 至少有一个复根。
  证明：反证——若无零点则 1/p 是整函数；多项式在无穷远增长快 ⟹ 1/p 有界；Liouville ⟹ 1/p=常数 ⟹ p=常数，矛盾。
  依赖：Liouville 定理 + 多项式的增长性。

  **链条总结**：
  可导 →(Goursat)→ 闭路积分为零 →(闭路变形)→ 边界值决定内部值 →(积分号下求导)→ 无穷可导 →(ML估计)→ 导数有界 →(R→∞)→ 有界整函数=常数 →(反证)→ 多项式必有根。

  **几何理解**：
  这条链条展示了复分析的"多米诺骨牌效应"——一个简单的定义（复可导）推出了越来越强的结论，最终证明了代数中的基本定理。
  每一步都是"前一步的推论"，但结论的强度逐级提升——从积分性质到函数值决定，到导数存在，到导数有界，到有界=常数，到代数基本定理。
  这是复变函数论"全局刚性"的完整体现——可导性是一个极强的条件，它蕴含了整个理论的核心定理。
- **一句话点评**：链条:①Cauchy定理(可导⟹∮f=0,Goursat三角形法)→②Cauchy公式(闭路变形+ML⟹f(z₀)=边界加权平均)→③高阶导数(差商+一致收敛⟹f^{(n)}=积分表示,一次可导⟹无穷可导)→④Cauchy不等式(高阶导数+ML⟹|f^{(n)}|≤n!M/Rⁿ)→⑤Liouville(Cauchy不等式n=1+R→∞⟹f'=0⟹有界整函数=常数)→⑥代数基本定理(反证:1/p整函数+有界⟹Liouville⟹1/p=常数⟹矛盾⟹p有根)。多米诺骨牌:可导→积分性质→值决定→无穷可导→导数有界→有界=常数→代数定理。全局刚性完整体现。

**【D8-2-CROSS-024】**（D8 × D4 积分 × D1 极限）**计算 ∮_{|z|=1} sin z / z² dz：用高阶导数公式 n=1，f(z)=sin z，f'(0)=cos 0=1，所以积分=(2πi/1!)·f'(0)=2πi。验证：sin z/z²=(z-z³/6+...)/z²=1/z-z/6+...，只有 1/z 项贡献积分 2πi。**

- **难度**：★★
- **对应知识点**：高阶导数公式应用、sin z导数、级数验证
- **解答**：
  **高阶导数公式（n=1）**：
  f'(z₀)=(1!/2πi)∮ f(z)/(z-z₀)² dz。
  f(z)=sin z, z₀=0。
  f'(z)=cos z, f'(0)=1。
  ∮_{|z|=1} sin z/z² dz = 2πi·f'(0) = 2πi·1 = 2πi。∎

  **级数验证**：
  sin z=z-z³/3!+z⁵/5!-...
  sin z/z²=1/z - z/6 + z³/120 - ...
  Laurent 展开中 z^{-1} 项的系数=1。
  ∮ sin z/z² dz = 2πi·(z^{-1}项系数)=2πi·1=2πi。∎
  与高阶导数公式一致！

  **一般公式**：
  ∮_{|z|=1} sin z/z^{n+1} dz = (2πi/n!)·sin^{(n)}(0)。
  sin^{(n)}(0)=sin(nπ/2)：n=0→0, n=1→1, n=2→0, n=3→-1, n=4→0,...
  所以 n 为偶数时积分=0，n=4k+1 时积分=2πi/n!，n=4k+3 时积分=-2πi/n!。

  **几何理解**：
  高阶导数公式将"高阶极点的积分"转化为"函数的导数值"——极点阶数 n+1 对应 n 阶导数。
  级数方法将函数展开为 Laurent 级数，积分只由 z^{-1} 项（留数）决定——这是留数定理的雏形。
  两种方法等价：留数=Laurent展开z^{-1}系数=f^{(n)}(z₀)/n!（高阶导数公式）。
- **一句话点评**：高阶导数n=1:∮sinz/z²=2πi·f'(0)=2πi·cos0=2πi。级数验证:sinz/z²=1/z-z/6+...,z^{-1}系数=1⟹积分=2πi✓。一般:∮sinz/z^{n+1}=2πi/n!·sin^{(n)}(0),sin^{(n)}(0)=sin(nπ/2)(偶数=0,4k+1=1,4k+3=-1)。高阶极点积分=导数值;Laurent展开积分=z^{-1}系数(留数)。两种方法等价:留数=f^{(n)}/n!。

**【D8-2-CROSS-025】**（D8 × D7 三角学 × D5 级数）**用 Cauchy 积分公式证明平均值原理对 eᶻ 成立：e⁰=(1/2π)∫₀²π e^{re^{iθ}}dθ。将 e^{re^{iθ}}=e^{r cosθ}·e^{ir sinθ} 展开，实部=e^{r cosθ}cos(r sinθ)，积分=2π（因为 e⁰=1）。这就是修正贝塞尔函数 I₀(r)=(1/2π)∫e^{r cosθ}dθ=1 的来源。**

- **难度**：★★
- **对应知识点**：平均值原理、eᶻ验证、修正贝塞尔函数I₀、实部虚部积分
- **解答**：
  **平均值原理**：
  f(z)=eᶻ 在全平面解析，z₀=0。
  e⁰=(1/2π)∫₀²π e^{re^{iθ}} dθ 对任意 r 成立。
  e⁰=1，所以 (1/2π)∫₀²π e^{re^{iθ}} dθ=1。∎

  **展开**：
  e^{re^{iθ}}=e^{r(cosθ+i sinθ)}=e^{r cosθ}·e^{ir sinθ}=e^{r cosθ}[cos(r sinθ)+i sin(r sinθ)]。

  取实部和虚部：
  (1/2π)∫₀²π e^{r cosθ}cos(r sinθ) dθ = 1（实部）
  (1/2π)∫₀²π e^{r cosθ}sin(r sinθ) dθ = 0（虚部）

  **修正贝塞尔函数**：
  第一类修正贝塞尔函数 I₀(r)=(1/2π)∫₀²π e^{r cosθ} dθ。
  注意这里没有 cos(r sinθ) 因子——I₀(r) 不等于 1！
  实际上 I₀(r)=Σ_{n=0}^∞ (r²/4)^n/(n!)²，是 r 的递增函数（I₀(0)=1, I₀(1)≈1.266）。

  但 (1/2π)∫ e^{r cosθ}cos(r sinθ)dθ = Re[(1/2π)∫e^{re^{iθ}}dθ] = Re[1] = 1。
  这个积分（带 cos(r sinθ) 因子）等于 1——它是 e^{re^{iθ}} 平均值的实部。

  **几何理解**：
  平均值原理说解析函数在圆心的值=圆周上的平均值——对 eᶻ 来说，圆周上的值是复数（模和辐角都变化），但平均值恰好是圆心值 1。
  实部积分=1，虚部积分=0——圆周上的"振荡"（sin(r sinθ)）在平均中抵消了，而"增长"（e^{r cosθ}）被 cos(r sinθ) 调制后平均为 1。
  这是解析函数"全局刚性"的又一体现——圆周上复杂变化的函数，平均值恰好是圆心值。
- **一句话点评**：eᶻ解析⟹e⁰=(1/2π)∫e^{re^{iθ}}dθ=1。e^{re^{iθ}}=e^{r cosθ}[cos(r sinθ)+i sin(r sinθ)]。实部:(1/2π)∫e^{r cosθ}cos(r sinθ)dθ=1;虚部=0。注意修正贝塞尔I₀(r)=(1/2π)∫e^{r cosθ}dθ≠1(无cos因子,I₀递增)。带cos(r sinθ)的积分=1=e^{re^{iθ}}平均的实部。圆周上振荡抵消,增长被调制后平均=圆心值=全局刚性。

**【D8-2-CROSS-026】**（D8 × D6 完备性 × D2 连续）**讨论闭路变形原理的拓扑意义：积分只依赖于曲线的同伦类（连续变形不经过奇点），这是"同伦不变量"。说明这与代数拓扑中的基本群有关——绕奇点的曲线对应基本群的元素，积分是基本群到 ℂ 的同态。联系 D6 完备性中的"区域的拓扑性质影响分析性质"。**

- **难度**：★★
- **对应知识点**：闭路变形原理、同伦不变量、基本群、拓扑影响分析
- **解答**：
  **闭路变形原理**：
  若 C₁ 和 C₂ 是两条同向闭曲线，C₁ 可以在 D 内连续变形为 C₂（不经过 f 的奇点），则 ∮_{C₁}f dz=∮_{C₂}f dz。
  证明：C₁ 和 C₂ 之间的区域是 f 的解析区域，用复合闭路定理（割线法）得 ∮_{C₁}f - ∮_{C₂}f=0。

  **同伦不变量**：
  闭路变形就是"同伦"——两条曲线可以通过连续族 C_t（t∈[0,1]）连接，C₀=C₁, C₁=C₂，且每个 C_t 不经过奇点。
  积分在同伦下不变——积分是"同伦不变量"。

  **基本群的联系**：
  区域 D 的基本群 π₁(D) 由闭曲线的同伦类组成（运算=曲线的连接）。
  对固定的解析函数 f（在 D 内可能有奇点），映射 [C]↦∮_C f dz 是基本群到 ℂ 的同态：
  ∮_{C₁*C₂} f dz = ∮_{C₁}f dz + ∮_{C₂}f dz（C₁*C₂ 是先 C₁ 后 C₂ 的连接）。
  这个同态的像就是"周期"——绕奇点的积分值（留数的 2πi 倍）。

  **例子：D=ℂ\{0}**
  基本群 π₁(ℂ\{0})≅ℤ（由绕原点的圈数生成）。
  f(z)=1/z：∮_C dz/z=2πi·n（n=绕原点的圈数）。
  同态：n↦2πi·n，是 ℤ→ℂ 的单同态。

  **拓扑影响分析**：
  区域的拓扑性质（是否单连通、有几个洞）决定了解析函数的积分行为：
  - 单连通区域（无洞）：所有闭曲线同伦于点，积分=0（Cauchy 定理），原函数单值。
  - 多连通区域（有洞）：绕洞的曲线不同伦于点，积分可能非零，原函数可能多值（如 log z）。
  这就是"区域的拓扑性质影响分析性质"——洞的数量决定了独立周期的数量。

  **几何理解**：
  闭路变形原理是"分析与拓扑的桥梁"——积分（分析概念）在同伦（拓扑概念）下不变。
  基本群是拓扑不变量，积分是分析量，两者通过留数联系起来——留数是"解析函数在奇点处的拓扑电荷"。
  这是复分析中最深刻的洞察之一：函数的解析性质（奇点、留数）与区域的拓扑性质（洞、基本群）深刻交织。
- **一句话点评**：闭路变形=C₁可连续变形为C₂(不过奇点)⟹积分相等=同伦不变量。基本群π₁(D)=闭曲线同伦类,映射[C]↦∮_C f dz是π₁(D)→ℂ的同态(∮_{C₁*C₂}=∮_{C₁}+∮_{C₂})。例:D=ℂ\{0},π₁≅ℤ,∮dz/z=2πi·n(圈数n)。单连通(无洞)⟹所有曲线同伦于点⟹积分=0,原函数单值;多连通(有洞)⟹绕洞积分非零,原函数多值(log z)。分析(积分)与拓扑(同伦/基本群)的桥梁,留数=奇点处的拓扑电荷。

  (z^m)^{(n)}=m!/(m-n)! z^{m-n}（n≤m），=0（n>m）。

  **几何理解**：
  高阶导数公式将"高阶极点的积分"转化为"多项式的导数"——z³ 的二阶导数是线性函数 6z，在 z₀=1 处的值为 6。

**【D8-2-CROSS-028】**（D8 × D5 级数 × D6 完备性）**讨论 Cauchy 积分公式与 Taylor 级数的收敛半径：f(z)=Σa_n(z-z₀)^n 的收敛半径 R 等于 z₀ 到最近奇点的距离。用 Cauchy 公式证明：在 |z-z₀|&lt;R 内（R&lt;到奇点距离）f 解析，可以展开为 Taylor 级数；在边界 |z-z₀|=R 上至少有一个奇点（否则可以延拓到更大圆，与 R 最大矛盾）。**

- **难度**：★★
- **对应知识点**：Taylor收敛半径、到奇点距离、Cauchy公式展开、边界奇点
- **解答**：
  **定理**：幂级数 f(z)=Σa_n(z-z₀)^n 的收敛半径 R = z₀ 到 f 的最近奇点的距离。

  **证明 R≥到奇点距离**：
  设 d=z₀ 到最近奇点的距离。对任意 r&lt;d，f 在 |z-z₀|≤r 上解析（无奇点）。
  由 Cauchy 积分公式+几何级数展开（D8-2-CROSS-020），f 在 |z-z₀|&lt;r 内可展开为 Taylor 级数。
  因为 r&lt;d 任意，所以收敛半径 R≥d。

  **证明 R≤到奇点距离**：
  假设 R>d，则 f 在 |z-z₀|&lt;R 内解析（幂级数和函数在收敛圆内解析）。
  但 d 是到最近奇点的距离，意味着在 |z-z₀|=d 上有奇点——f 在该点不解析，与 f 在 |z-z₀|&lt;R（R>d）内解析矛盾。
  所以 R≤d。

  结合 R≥d 和 R≤d ⟹ R=d。∎

  **边界上至少有一个奇点**：
  假设收敛圆 |z-z₀|=R 上没有奇点，则 f 在闭圆盘上解析，可以用 Cauchy 公式展开到更大的圆（半径 R+ε），与 R 是最大收敛半径矛盾。
  所以收敛圆边界上至少有一个奇点。∎

  **例子**：
  1/(1-z)=Σzⁿ，收敛半径 R=1，奇点 z=1 在边界上。
  1/(1+z²)=Σ(-1)^n z^{2n}，收敛半径 R=1，奇点 z=±i 在边界上（虽然在实轴上 [-1,1] 内函数光滑）。
  eᶻ=Σzⁿ/n!，收敛半径 R=∞，没有有限奇点。

  **几何理解**：
  收敛半径是"解析性的边界"——圆内函数解析，圆上至少有一个点函数不解析（奇点）。
  奇点像"障碍物"，限制了幂级数能展开的范围——到最近障碍物的距离就是收敛半径。
  这与实变不同：实变幂级数的收敛半径可能被"看不见的"复奇点限制（如 1/(1+x²) 在实轴上光滑但收敛半径只有1，因为复奇点 ±i）。
  复分析揭示了收敛半径的真正原因——不是实变函数的性质，而是复奇点的位置。
- **一句话点评**：R=z₀到最近奇点距离。R≥d:∀r&lt;d,f在|z-z₀|≤r解析⟹Cauchy公式+几何级数⟹Taylor展开⟹R≥d。R≤d:若R>d则f在|z|&lt;R解析,但|z|=d上有奇点⟹矛盾。边界至少有一个奇点:否则可延拓到更大圆,与R最大矛盾。例:1/(1-z),R=1,奇点z=1在边界;1/(1+z²),R=1,奇点±i(实轴光滑但复奇点限制半径);eᶻ,R=∞无有限奇点。收敛半径=解析性边界,奇点=障碍物。实变收敛半径由复奇点位置决定。

**【D8-2-CROSS-030】**（D8 × D6 完备性 × D2 连续）**讨论 Cauchy 积分定理在多连通区域的"周期"概念：f=1/z 在 ℂ\{0} 内，绕原点一圈积分=2πi，所以原函数 log z 是多值的（每绕一圈增加 2πi）。说明"周期"是多连通区域解析函数的特征——单连通区域内周期为零（原函数单值），多连通区域内周期由绕洞的积分决定。**

- **难度**：★★
- **对应知识点**：多连通区域周期、1/z的原函数log z多值、绕洞积分、单连通vs多连通
- **解答**：
  **f(z)=1/z 在 ℂ\{0} 内**：
  f 在 ℂ\{0} 内解析（z=0 是奇点，不在区域内）。
  绕原点的正向闭曲线 C：∮_C dz/z=2πi（基本积分）。

  **原函数的多值性**：
  尝试构造原函数 F(z)=∫_{z₀}^z dζ/ζ。
  沿不同路径从 z₀ 到 z，积分值可能不同——如果两条路径绕原点的圈数不同，积分相差 2πi·n（n=圈数差）。
  所以 F(z) 是多值的——F(z)=log z=ln|z|+i arg z，arg z 多值（相差 2πn）。
  每绕原点一圈，F(z) 增加 2πi——这就是"周期"。

  **周期的定义**：
  多连通区域 D 内解析函数 f 的"周期"是绕洞的闭曲线积分 ∮_C f dz。
  单连通区域（无洞）：所有闭曲线同伦于点，周期=0，原函数单值。
  多连通区域（有 n 个洞）：有 n 个独立周期（绕每个洞的积分），原函数多值（值在 ℂ/(周期格) 中）。

  **例子**：
  - D=ℂ（单连通）：f=1/z 不在全平面解析（z=0 奇点），但 eᶻ 是整函数，原函数 eᶻ 单值。
  - D=ℂ\{0}（多连通，1个洞）：f=1/z 有 1 个周期 2πi，原函数 log z 多值。
  - D=ℂ\{0,1}（2个洞）：f=1/[z(z-1)] 有 2 个独立周期（绕0和绕1），原函数是双周期多值函数。

  **与拓扑的联系**：
  周期的数量=区域的"洞数"=基本群的秩（Betti 数）。
  这是 de Rham 上同调的雏形——解析函数的导数（1-形式）的周期由区域的拓扑决定。
  单连通区域 H¹=0（所有闭形式恰当），多连通区域 H¹≠0（有非平凡周期）。

  **几何理解**：
  周期是"分析与拓扑的交汇"——解析函数的积分（分析）在绕洞的闭曲线上的值（周期）由区域的拓扑（洞数）决定。
  多连通区域的原函数就像"螺旋楼梯"——每绕一圈上升一个周期（2πi），永远回不到原值。
  单连通区域的原函数是"平面"——没有洞可以绕，路径无关，原函数单值。
- **一句话点评**：f=1/z在ℂ\{0},∮dz/z=2πi。原函数F=∫dζ/ζ,路径绕原点圈数不同⟹积分差2πi·n⟹F=log z多值(arg z差2πn),每绕一圈+2πi=周期。单连通(无洞):所有曲线同伦于点⟹周期=0⟹原函数单值。多连通(n洞):n个独立周期⟹原函数多值。例:ℂ\{0,1}有2个周期。周期数=洞数=基本群秩=Betti数=de Rham上同调H¹。多连通原函数=螺旋楼梯(绕一圈升周期),单连通=平面(无洞可绕)。

## 本模块易错点总结

1. **复积分是向量场做功**：∫f dz=∫(u dx-v dy)+i∫(v dx+u dy)，是两个第二型曲线积分的组合。ML不等式|∫fdz|≤M·L是"功≤力×距离"。

2. **基本积分 ∮dz/(z-z₀)=2πi**：只有 n=1 时非零，n≠1（整数）时为零。几何意义是"绕一圈角度增加2π"=多值性的积分体现=留数定理基础。

3. **Cauchy积分定理需要单连通/曲线不包围奇点**：解析函数沿闭曲线积分为零，但如果曲线包围奇点，积分可能非零（如1/z）。闭路变形原理说积分只依赖于包围的奇点。

4. **Goursat证明去掉了f'连续的假设**：Cauchy原始证明用Green公式需要偏导连续（f'连续），Goursat用三角形二分法只需要处处可导。这意味着可导自动蕴含f'连续（甚至解析）。

5. **Cauchy积分公式=边界值决定内部值**：f(z₀)=(1/2πi)∮f(z)/(z-z₀)dz。这是解析函数"全局刚性"的最强表达——实变函数完全没有这个性质。

6. **高阶导数公式=一次可导→无穷可导**：f^{(n)}(z₀)=n!/(2πi)∮f/(z-z₀)^{n+1}。导数用积分表示，只要f连续就存在所有阶导数。实变中完全不可能。

7. **Cauchy不等式=函数值界控制所有导数界**：|f^{(n)}(z₀)|≤n!M/Rⁿ。阶数越高界越严。这是Liouville定理的基础。

8. **Liouville定理=有界整函数必为常数**：用Cauchy不等式令R→∞得f'=0。推广：|f(z)|≤C|z|ⁿ⟹f是≤n次多项式。

9. **代数基本定理的复分析证明**：n次多项式无零点⟹1/p整函数；多项式无穷远增长快⟹1/p有界；Liouville⟹1/p=常数⟹矛盾。

10. **Morera定理=Cauchy定理的逆**：连续+闭路积分为零⟹解析。构造原函数F=∫f，F'=f，F解析⟹f解析。给出了解析函数的"积分定义"。

11. **复合闭路定理=通量守恒**：外边界积分=所有内边界（正向）积分之和。用割线法将多连通剪开为单连通。留数定理的前身。

12. **C-R方程+偏导存在≠解析**：e^{-1/z⁴}在原点C-R成立（偏导全0）但不连续（沿45°发散），所以不解析。充分条件是C-R+偏导数连续。

13. **收敛半径=到最近奇点距离**：幂级数收敛圆边界上至少有一个奇点。1/(1+x²)在实轴光滑但收敛半径只有1，因为复奇点±i限制了半径——实变看不到但复变暴露了。

14. **无界区域Cauchy公式边界方向反转**：外部区域的正向是顺时针（让外部在左侧），且需要lim_{z→∞}f=0保证大圆周积分消失。

15. **Poisson积分公式=Cauchy公式的实部**：调和函数内部值=边界值的Poisson核加权平均。Poisson核是柯西核的实部，在概率论中是布朗运动击中分布。

16. **周期=多连通区域的特征**：f=1/z绕原点积分=2πi，原函数log z多值。周期数=洞数=基本群秩。单连通区域周期为零（原函数单值）。
