> 解析性在实分析里指幂级数展开，在复分析里等价于复可导；到实变函数与椭圆方程里，又变成弱解的正则性。

## 领域定位

- **核心问题**：解析性在不同分析层次中如何变化？
- **四层张力**：初等幂级数 → 实解析 → 复解析（复可导 = 解析）→ 弱解析 / 椭圆正则性。

## 四层结构

| 层 | 名称 | 核心内容 |
|---|---|---|
| L0 | 初等/直觉 | 幂级数、Taylor 展开的直观 |
| L1 | 数学分析 | 实解析、收敛半径、Taylor 余项 |
| L2 | 复变函数 | 复可导 = 解析、Cauchy–Riemann |
| L3 | 实变/偏微分方程 | 弱解析、椭圆正则性 |
