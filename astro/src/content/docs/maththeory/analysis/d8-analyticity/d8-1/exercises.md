## L0 初等直觉层（★ 基础）

**【D8-1-001】** 验证 f(z)=z² 在任意点 z₀ 处复可导：直接用定义计算 lim_{Δz→0} [(z₀+Δz)²-z₀²]/Δz，说明这个极限与 Δz 趋近的方向无关（因为化简后不含 Δz 的方向信息）。

- **难度**：★
- **对应知识点**：复可导定义、差商极限、方向无关性
- **解答**：
  **差商**：
  [(z₀+Δz)²-z₀²]/Δz = [z₀²+2z₀Δz+(Δz)²-z₀²]/Δz = (2z₀Δz+(Δz)²)/Δz = 2z₀+Δz。

  **极限**：
  lim_{Δz→0} (2z₀+Δz) = 2z₀。∎

  **为什么与方向无关**：
  化简后差商 = 2z₀+Δz，Δz→0 时极限为 2z₀——这个结果不依赖 Δz 的方向（无论沿实轴、虚轴还是任意斜线趋近，Δz→0 时都得到 2z₀）。
  这是因为 z² 是多项式，代数运算自然消去了方向信息。

  **对比实变**：
  实变中 f(x)=x² 也可导，f'(x)=2x——形式上相同。
  但复变中"可导"的含义强得多：它要求所有方向的差商极限相同，而 z² 恰好满足。

  **几何理解**：
  f(z)=z² 在 z₀ 附近的局部行为是"旋转+缩放"：导数 f'(z₀)=2z₀，模 |2z₀| 是缩放因子，辐角 arg(2z₀) 是旋转角。
  这就是"复可导=局部保角映射"的最简单例子。
- **一句话点评**：[(z₀+Δz)²-z₀²]/Δz=2z₀+Δz→2z₀。化简后不含Δz方向信息⟹极限与方向无关。复可导要求所有方向差商极限相同,z²是多项式自然满足。f'(z₀)=2z₀,模=缩放因子,辐角=旋转角=局部保角映射。

**【D8-1-002】** 证明 f(z)=|z|² 在 z=0 处可导但在 z≠0 处不可导：在 z=0 处差商=Δz̄→0（可导，导数为0）；在 z≠0 处沿实轴方向差商=z+z̄+Δx，沿虚轴方向差商=z-z̄-iΔy，两者不相等（除非 z=0）。

- **难度**：★
- **对应知识点**：|z|²可导性、方向差商对比、一点可导≠解析
- **解答**：
  **f(z)=|z|²=z·z̄**

  **在 z=0 处**：
  差商 = [|Δz|²-0]/Δz = (Δz·Δz̄)/Δz = Δz̄。
  lim_{Δz→0} Δz̄ = 0。∎
  所以 f(z) 在 z=0 处可导，f'(0)=0。

  **在 z≠0 处**：
  差商 = [|z+Δz|²-|z|²]/Δz = [(z+Δz)(z̄+Δz̄)-z z̄]/Δz = (z Δz̄+z̄ Δz+Δz Δz̄)/Δz = z·(Δz̄/Δz)+z̄+Δz̄。

  沿实轴方向（Δz=Δx 实数）：Δz̄/Δz=1，差商→z+z̄=2Re(z)。
  沿虚轴方向（Δz=iΔy）：Δz̄/Δz=(-iΔy)/(iΔy)=-1，差商→-z+z̄=-2i Im(z)。

  两者相等当且仅当 2Re(z)=-2i Im(z)，即 Re(z)=Im(z)=0，即 z=0。
  所以 z≠0 时不可导。∎

  **一点可导 ≠ 解析**：
  f(z)=|z|² 只在 z=0 一点可导，在 0 的任何邻域内都不是处处可导的——所以 f(z) 在 0 处不解析。
  解析要求"在某个邻域内处处可导"，而不仅仅是"在一点可导"。

  **几何理解**：
  |z|² 是到原点距离的平方——它是"径向"函数，只依赖 |z| 不依赖角度。
  径向函数在原点附近是"各向同性"的（可导），但在其他点处，沿径向和切向的变化率不同（不可导）。
  这就是为什么 |z|² 只在原点可导——只有原点处所有方向对称。
- **一句话点评**：f(z)=|z|²=z z̄。z=0处差商=Δz̄→0(可导,f'(0)=0)。z≠0处差商=z(Δz̄/Δz)+z̄+Δz̄。实轴方向Δz̄/Δz=1→2Re(z);虚轴方向=-1→-2i Im(z)。z≠0时不相等⟹不可导。一点可导≠解析(解析要求邻域内处处可导)。|z|²是径向函数,只有原点各向同性可导。

**【D8-1-003】** 验证 f(z)=eᶻ 在任意点可导：用 e^{z+Δz}=eᶻ·e^{Δz}，差商=eᶻ·(e^{Δz}-1)/Δz→eᶻ（因为 lim_{w→0}(eʷ-1)/w=1）。说明 eᶻ 是整函数（全平面解析）。

- **难度**：★
- **对应知识点**：eᶻ可导性、整函数、指数函数性质
- **解答**：
  **差商**：
  [e^{z₀+Δz}-e^{z₀}]/Δz = e^{z₀}·(e^{Δz}-1)/Δz。

  **极限**：
  lim_{Δz→0} (e^{Δz}-1)/Δz = 1（复变中的基本极限，与实变相同，因为 eʷ 的 Taylor 展开 eʷ=1+w+w²/2!+... 在全平面收敛）。
  所以 f'(z₀)=e^{z₀}。∎

  **整函数**：
  eᶻ 在全平面 ℂ 上处处可导，所以是整函数（entire function）。
  整函数=在全复平面上解析的函数。

  **与实变对比**：
  实变中 eˣ 也可导，(eˣ)'=eˣ——形式相同。
  但复变中 eᶻ=e^{x+iy}=eˣ(cos y+i sin y)，它是周期函数（周期 2πi），且无界（沿实轴方向指数增长）。
  实变 eˣ 不是周期函数。

  **几何理解**：
  eᶻ 将复平面映射为 ℂ\{0}（去掉原点）。
  水平线 y=常数 映射为从原点出发的射线（辐角=y）。
  垂直线 x=常数 映射为以原点为圆心的圆（半径=eˣ）。
  这是"指数映射=极坐标变换"——把直角坐标 (x,y) 变为极坐标 (eˣ, y)。
- **一句话点评**：[e^{z₀+Δz}-e^{z₀}]/Δz=e^{z₀}(e^{Δz}-1)/Δz→e^{z₀}·1=e^{z₀}。eᶻ全平面可导=整函数。eᶻ=eˣ(cosy+i siny),周期2πi,无界(实轴方向增长)。几何：水平线→射线(辐角y),垂直线→圆(半径eˣ)=指数映射=极坐标变换。

**【D8-1-004】** 用 C-R 方程验证 f(z)=z² 解析：f(z)=(x+iy)²=(x²-y²)+i(2xy)，所以 u=x²-y², v=2xy。计算 u_x=2x, v_y=2x（相等）；u_y=-2y, v_x=2y（满足 u_y=-v_x）。C-R 方程在全平面成立。

- **难度**：★
- **对应知识点**：C-R方程验证、z²解析性、偏导数计算
- **解答**：
  **f(z)=z²=(x+iy)²=x²-y²+i(2xy)**
  u(x,y)=x²-y², v(x,y)=2xy。

  **偏导数**：
  u_x=2x, u_y=-2y
  v_x=2y, v_y=2x

  **C-R 方程**：
  u_x=v_y: 2x=2x ✓
  u_y=-v_x: -2y=-(2y) ✓

  C-R 方程在全平面成立，且偏导数连续（多项式），所以 f(z)=z² 在全平面解析。∎

  **导数**：
  f'(z)=u_x+iv_x=2x+i(2y)=2(x+iy)=2z。∎
  与直接计算一致。

  **几何理解**：
  u=x²-y² 是双曲抛物面（马鞍面），v=2xy 也是双曲抛物面（旋转45°）。
  它们的等值线 u=c₁ 和 v=c₂ 是正交的双曲线族——这就是共轭调和函数的等值线正交性。
  z² 将第一象限映射为上半平面（角度加倍），是保角映射的经典例子。
- **一句话点评**：z²=(x²-y²)+i(2xy),u=x²-y²,v=2xy。u_x=2x=v_y✓,u_y=-2y=-v_x✓。C-R全平面成立+偏导连续⟹全平面解析。f'=u_x+iv_x=2x+i2y=2z。u和v都是双曲抛物面,等值线=正交双曲线族。z²将第一象限→上半平面(角度加倍)=保角映射经典例。

## L1 数学分析层

> **引导语**：L1层按"CR方程与调和函数→解析性的本质→零点孤立性与反例"三条线索推进。从CR方程的极坐标形式到几何意义，从调和函数到共轭调和，从一点可导与解析的区别到三种等价定义的证明链条，层层递进。核心是理解"解析"为什么比"可导"强得多。

### 组A：CR方程与调和函数

**【D8-1-005】** 推导 C-R 方程的极坐标形式：在 z=re^{iθ} 下，f(z)=u(r,θ)+iv(r,θ)，C-R 方程为 u_r=(1/r)v_θ, v_r=-(1/r)u_θ。用坐标变换 x=r cosθ, y=r sinθ 从直角坐标形式推导。

- **难度**：★★
- **对应知识点**：C-R方程极坐标形式、坐标变换、链式法则
- **解答**：
  **坐标变换**：x=r cosθ, y=r sinθ。
  链式法则：
  u_r = u_x·cosθ + u_y·sinθ
  u_θ = u_x·(-r sinθ) + u_y·(r cosθ) = r(-u_x sinθ+u_y cosθ)
  v_r = v_x·cosθ + v_y·sinθ
  v_θ = r(-v_x sinθ+v_y cosθ)

  **利用直角 C-R 方程**：u_x=v_y, u_y=-v_x。

  **验证 u_r=(1/r)v_θ**：
  (1/r)v_θ = -v_x sinθ+v_y cosθ = u_y sinθ+u_x cosθ（用 v_y=u_x, v_x=-u_y）
  = u_x cosθ+u_y sinθ = u_r。∎

  **验证 v_r=-(1/r)u_θ**：
  -(1/r)u_θ = u_x sinθ-u_y cosθ = v_y sinθ+v_x cosθ（用 u_x=v_y, -u_y=v_x）
  = v_x cosθ+v_y sinθ = v_r。∎

  所以极坐标 C-R 方程：u_r=(1/r)v_θ, v_r=-(1/r)u_θ。∎

  **应用**：
  对于 f(z)=zⁿ=rⁿ e^{inθ}=rⁿ cos(nθ)+i rⁿ sin(nθ)：
  u=rⁿ cos(nθ), v=rⁿ sin(nθ)。
  u_r=n r^{n-1} cos(nθ), (1/r)v_θ=(1/r)·rⁿ·n cos(nθ)=n r^{n-1} cos(nθ) ✓
  v_r=n r^{n-1} sin(nθ), -(1/r)u_θ=-(1/r)·rⁿ·(-n sin(nθ))=n r^{n-1} sin(nθ) ✓
  zⁿ 解析（n为正整数）。

  **几何理解**：
  极坐标 C-R 方程说明：径向变化率 u_r 与角向变化率 v_θ 成正比（比例 1/r）。
  这是"旋转+缩放"在极坐标下的体现——径向缩放和角向旋转必须协调。
- **一句话点评**：x=r cosθ,y=r sinθ。链式法则u_r=u_x cosθ+u_y sinθ,u_θ=r(-u_x sinθ+u_y cosθ)。代入u_x=v_y,u_y=-v_x：(1/r)v_θ=-v_x sinθ+v_y cosθ=u_y sinθ+u_x cosθ=u_r✓。v_r=-(1/r)u_θ同理✓。极坐标C-R:u_r=(1/r)v_θ,v_r=-(1/r)u_θ。zⁿ验证通过。径向变化率与角向变化率协调=旋转缩放的极坐标体现。

**【D8-1-006】** 证明 C-R 方程的几何意义：雅可比矩阵 J=[[u_x,u_y],[v_x,v_y]] 在 C-R 条件下变为 [[a,-b],[b,a]]=√(a²+b²)·旋转矩阵。说明这意味着解析函数在可导点附近保持角度（保角），且缩放因子=|f'(z)|。

- **难度**：★★
- **对应知识点**：雅可比矩阵、旋转缩放矩阵、保角映射、|f'|=缩放因子
- **解答**：
  **雅可比矩阵**：
  J = [[u_x, u_y], [v_x, v_y]]

  **C-R 条件**：u_x=v_y=a, u_y=-v_x=-b（令 b=v_x）。
  J = [[a, -b], [b, a]]

  **分解为缩放×旋转**：
  J = √(a²+b²) · [[a/√(a²+b²), -b/√(a²+b²)], [b/√(a²+b²), a/√(a²+b²)]]

  右边的矩阵满足：行向量模长=1，两行正交（点积= -ab/(a²+b²)+ab/(a²+b²)=0），行列式=1。
  这正是旋转矩阵 R(φ)，其中 cosφ=a/√(a²+b²), sinφ=b/√(a²+b²)。

  所以 J = |f'(z)| · R(φ)，其中：
  - 缩放因子 = √(a²+b²) = √(u_x²+v_x²) = |f'(z)|（因为 f'=u_x+iv_x）
  - 旋转角 φ = arg f'(z) = arctan(v_x/u_x)

  **保角性**：
  雅可比矩阵为旋转×缩放意味着：任意两条曲线的夹角在映射后保持不变（旋转不改变角度，缩放也不改变角度）。
  所以解析函数（f'≠0 时）是保角映射（共形映射）。∎

  **面积缩放**：
  det J = a²+b² = |f'(z)|²——面积元素被放大 |f'|² 倍。
  这与二维线性变换的面积缩放因子=行列式一致。

  **几何理解**：
  解析函数在小范围内的行为就像"先旋转一个角度，再缩放一个比例"——就像相似变换。
  这就是为什么解析函数的图像看起来"很光滑"——局部没有拉伸变形（各向同性），只有整体的旋转和缩放。
  对比非解析函数（如 |z|²），其雅可比矩阵不是旋转缩放矩阵，局部行为是"各向异性"的（径向和切向变化率不同），不保角。
- **一句话点评**：J=[[u_x,u_y],[v_x,v_y]],C-R⟹J=[[a,-b],[b,a]]=√(a²+b²)·[[cosφ,-sinφ],[sinφ,cosφ]]=|f'|·R(φ)。缩放因子=|f'|,旋转角=arg f'。旋转+缩放⟹保角(角度不变)。面积缩放=det J=|f'|²。解析函数局部=相似变换(各向同性),非解析函数=各向异性(不保角)。

**【D8-1-007】** 证明解析函数的实部和虚部满足 Laplace 方程：由 C-R 方程 u_x=v_y, u_y=-v_x，对第一式求 x 偏导、第二式求 y 偏导，相加得 u_xx+u_yy=v_yx-v_xy=0（混合偏导相等）。同理 v 也调和。说明这是"一次可导自动蕴含二阶性质"的体现。

- **难度**：★★
- **对应知识点**：共轭调和函数、Laplace方程、混合偏导相等、可导蕴含调和
- **解答**：
  **C-R 方程**：u_x=v_y ...(1), u_y=-v_x ...(2)

  **对 (1) 求 x 偏导**：u_xx = v_yx。
  **对 (2) 求 y 偏导**：u_yy = -v_xy。

  **相加**：u_xx+u_yy = v_yx - v_xy。

  由于解析函数无穷可导（偏导数连续），混合偏导数相等 v_yx=v_xy（Clairaut 定理）。
  所以 u_xx+u_yy=0。∎
  u 满足 Laplace 方程，是调和函数。

  **同理证 v**：
  对 (1) 求 y 偏导：u_xy=v_yy。
  对 (2) 求 x 偏导：u_yx=-v_xx。
  相减（利用 u_xy=u_yx）：v_yy+v_xx=0。∎
  v 也是调和函数。

  **u 和 v 互为共轭调和函数**——通过 C-R 方程联系。

  **一次可导自动蕴含二阶性质**：
  只假设了 f 一阶可导（C-R 方程成立），就推出了 u,v 满足二阶偏微分方程（Laplace）。
  这在实变中是不可能的——实变一阶可导函数不一定二阶可导（如 x²sin(1/x)）。
  复可导的强度再次体现：一次可导自动蕴含所有高阶性质。

  **几何理解**：
  Laplace 方程 Δu=0 意味着 u 没有"局部极值"（最大值原理：调和函数在区域内部不能取最大值，除非常数）。
  等值线 u=c₁ 和 v=c₂ 正交（已证 ∇u·∇v=0）。
  调和函数描述了稳态物理现象（静电势、温度分布、速度势）——解析函数天然给出了一对正交的调和函数，这是复分析在数学物理中强大的原因。
- **一句话点评**：C-R:u_x=v_y,u_y=-v_x。对第一式求x:u_xx=v_yx;对第二式求y:u_yy=-v_xy。相加:u_xx+u_yy=v_yx-v_xy=0(混合偏导相等)。同理v_xx+v_yy=0。一次可导⟹二阶Laplace方程(实变不可能!)。调和函数无内部极值(最大值原理),等值线正交。解析函数=天然的正交调和函数对=数学物理强大工具。

**【D8-1-008】** 已知调和函数 u(x,y)=x²-y²，求其共轭调和函数 v(x,y)：由 C-R 方程 v_x=-u_y=2y, v_y=u_x=2x。积分 v_x=2y 得 v=2xy+φ(y)，再由 v_y=2x+φ'(y)=2x 得 φ'(y)=0，所以 v=2xy+C。验证 f(z)=u+iv=(x²-y²)+i(2xy)=z²。

- **难度**：★★
- **对应知识点**：已知调和函数求共轭调和、C-R方程积分、构造解析函数
- **解答**：
  **u(x,y)=x²-y²**（先验证调和：u_xx=2, u_yy=-2, u_xx+u_yy=0 ✓）

  **C-R 方程**：
  v_x = -u_y = -(-2y) = 2y
  v_y = u_x = 2x

  **积分求 v**：
  由 v_x=2y，对 x 积分：v(x,y)=∫2y dx=2xy+φ(y)（φ(y)是 y 的待定函数）。
  对 y 求偏导：v_y=2x+φ'(y)。
  由 v_y=2x：2x+φ'(y)=2x ⟹ φ'(y)=0 ⟹ φ(y)=C（常数）。
  所以 v(x,y)=2xy+C。∎

  **构造解析函数**：
  f(z)=u+iv=(x²-y²)+i(2xy+C)=(x+iy)²+iC=z²+iC。∎
  （取 C=0 得 f(z)=z²）

  **曲线积分方法**：
  v(x,y)=∫_{(x₀,y₀)}^{(x,y)} (-u_y)dx+u_x dy+C
  =∫ 2y dx+2x dy+C（因为 -u_y=2y, u_x=2x）
  这个微分形式 2y dx+2x dy 是恰当的（∂(2y)/∂y=2=∂(2x)/∂x），积分与路径无关。
  沿折线路径 (0,0)→(x,0)→(x,y)：∫₀ˣ 0 dx+∫₀ʸ 2x dy=2xy。
  v=2xy+C。∎

  **几何理解**：
  已知一个调和函数 u（如电势分布），可以通过 C-R 方程求出共轭调和函数 v（如电场线流函数）。
  u 和 v 的等值线正交——等势线与电场线垂直。
  这就是复分析在静电学中的应用：给定电势，自动得到电场线分布。
- **一句话点评**：u=x²-y²(调和✓)。C-R:v_x=-u_y=2y,v_y=u_x=2x。积分v_x=2y⟹v=2xy+φ(y),v_y=2x+φ'=2x⟹φ'=0⟹v=2xy+C。f=z²+iC。曲线积分法:v=∫2y dx+2x dy(恰当,与路径无关)=2xy+C。已知调和u(电势)⟹求共轭v(流函数),等值线正交=等势线⊥电场线。

**【D8-1-010】** 证明解析函数的等值线正交：若 f=u+iv 解析且 f'(z)≠0，则等值线 u(x,y)=c₁ 和 v(x,y)=c₂ 在交点处正交。计算法向量 ∇u=(u_x,u_y), ∇v=(v_x,v_y)，点积 ∇u·∇v=u_x v_x+u_y v_y=u_x(-u_y)+u_y u_x=0（用 C-R 方程）。

- **难度**：★★
- **对应知识点**：等值线正交、梯度点积、C-R方程应用、物理意义
- **解答**：
  **等值线的法向量**：
  u(x,y)=c₁ 的法向量 = ∇u = (u_x, u_y)。
  v(x,y)=c₂ 的法向量 = ∇v = (v_x, v_y)。

  **点积**：
  ∇u·∇v = u_x v_x + u_y v_y。

  **用 C-R 方程**：v_x=-u_y, v_y=u_x。
  ∇u·∇v = u_x(-u_y) + u_y(u_x) = -u_x u_y + u_x u_y = 0。∎

  所以 ∇u⊥∇v，等值线在交点处正交。

  **f'(z)≠0 的条件**：
  如果 f'(z)=0，则 ∇u=(u_x,u_y)=(0,0) 或 ∇v=(0,0)（因为 f'=u_x+iv_x=0 意味着 u_x=v_x=0，由 C-R 得 u_y=v_y=0），等值线退化（临界点），正交性无意义。
  所以需要 f'(z)≠0。

  **物理意义**：
  - 静电学：u=电势，v=电场线流函数——等势线⊥电场线（电场方向=电势下降最快方向，与等势面垂直）。
  - 流体力学：u=速度势，v=流函数——等势线⊥流线。
  - 热传导：u=温度，v=热流线流函数——等温线⊥热流线。
  解析函数天然提供了一对正交曲线族——这是复分析在数学物理中的核心应用。

  **例子 f(z)=z²**：
  u=x²-y²=c₁（双曲线），v=2xy=c₂（双曲线）。
  两族双曲线正交——可以验证：u的法向量(2x,-2y)，v的法向量(2y,2x)，点积=4xy-4xy=0。∎
- **一句话点评**：∇u=(u_x,u_y),∇v=(v_x,v_y)。∇u·∇v=u_x v_x+u_y v_y=u_x(-u_y)+u_y u_x=0(C-R:v_x=-u_y)。⟹等值线正交。需f'≠0(否则梯度为0退化)。物理：u=电势,v=流函数⟹等势线⊥电场线;u=速度势,v=流函数⟹等势线⊥流线。f(z)=z²:u=x²-y²,v=2xy,两族双曲线正交(点积4xy-4xy=0)。

### 组B：解析性的本质

**【D8-1-011】** 讨论"一点可导"与"在一点解析"的区别：解析要求在 z₀ 的某个邻域内处处可导，而不仅仅是在 z₀ 处可导。举例 f(z)=|z|² 只在 z=0 可导但不在 0 解析；f(z)=z·Re(z) 只在 z=0 可导。说明"解析"是局部概念（邻域性质），不是逐点概念。

- **难度**：★★
- **对应知识点**：一点可导vs解析、邻域性质、|z|²和zRe(z)反例
- **解答**：
  **定义区别**：
  - 在 z₀ 处可导：差商极限在 z₀ 存在（逐点概念）。
  - 在 z₀ 处解析：存在 z₀ 的邻域 U，使得 f 在 U 内**处处**可导（邻域概念）。
  解析比可导强——解析要求"附近所有点都可导"。

  **反例 1：f(z)=|z|²**
  已证（D8-1-002）：只在 z=0 可导，z≠0 不可导。
  在 0 的任何邻域内都有 z≠0 的点不可导——所以 f 在 0 处不解析。∎

  **反例 2：f(z)=z·Re(z)=z·x=(x+iy)x=x²+i xy**
  u=x², v=xy。
  u_x=2x, u_y=0, v_x=y, v_y=x。
  C-R: u_x=v_y ⟹ 2x=x ⟹ x=0；u_y=-v_x ⟹ 0=-y ⟹ y=0。
  只在 z=0 满足 C-R——只在 0 可导，不在 0 解析。∎

  **反例 3：f(z)=x²+iy²**
  u=x², v=y²。u_x=2x, v_y=2y（C-R第一式要求 x=y）；u_y=0, v_x=0（第二式恒成立）。
  只在直线 x=y 上满足 C-R——在这条直线上的点可导，但任何点的邻域内都有不满足 C-R 的点——不解析。∎

  **为什么解析是邻域概念**：
  解析函数的好性质（无穷可导、幂级数展开、零点孤立、唯一性）都依赖于"在一个开集内可导"——需要用 Cauchy 积分公式（沿闭曲线积分），而闭曲线需要包围一个区域，这就要求函数在区域内处处可导。
  只在一点可导无法使用积分工具，因此无法推出好性质。

  **几何理解**：
  "在一点可导"只保证该点附近的"无穷小"行为是旋转+缩放，但附近的点可能行为各异。
  "在一点解析"保证该点整个邻域内的行为都是旋转+缩放——函数在局部是"均匀保角"的。
  解析=局部均匀保角，可导=单点保角（但附近可能不保角）。
- **一句话点评**：可导=逐点(差商极限存在);解析=邻域(存在邻域处处可导)。反例:|z|²只在0可导;zRe(z)=x²+ixy,C-R只在0满足;x²+iy²只在直线x=y上满足。解析需开集内可导才能用Cauchy积分(闭曲线包围区域)。几何:可导=单点保角(附近可能不保角);解析=局部均匀保角(整个邻域旋转缩放)。

**【D8-1-012】** 验证 f(z)=sin z 是整函数：sin z=(e^{iz}-e^{-iz})/(2i)，由 eᶻ 整函数和四则运算封闭性可知 sin z 整函数。用 C-R 方程验证：sin z=sin x cosh y+i cos x sinh y，u=sin x cosh y, v=cos x sinh y，u_x=cos x cosh y=v_y, u_y=sin x sinh y=-v_x。

- **难度**：★★
- **对应知识点**：sin z整函数、C-R方程验证、复三角函数
- **解答**：
  **sin z=(e^{iz}-e^{-iz})/(2i)**
  eᶻ 是整函数，e^{iz} 和 e^{-iz} 也是整函数（复合），它们的差和除以常数（2i≠0）仍是整函数。
  所以 sin z 是整函数。∎

  **C-R 验证**：
  sin(x+iy)=sin x cos(iy)+cos x sin(iy)=sin x cosh y+i cos x sinh y。
  （用 cos(iy)=cosh y, sin(iy)=i sinh y）
  u=sin x cosh y, v=cos x sinh y。

  u_x=cos x cosh y, u_y=sin x sinh y
  v_x=-sin x sinh y, v_y=cos x cosh y

  C-R: u_x=v_y: cos x cosh y=cos x cosh y ✓
  u_y=-v_x: sin x sinh y=-(-sin x sinh y)=sin x sinh y ✓

  全平面成立，偏导数连续——sin z 全平面解析。∎

  **导数**：
  (sin z)'=cos z（与实变相同）。
  但复 sin z 是无界的！|sin(iy)|=|sinh y|→∞（y→∞）。
  实 sin x 有界 |sin x|≤1——这是实变和复变的重要区别。

  **几何理解**：
  sin z 将带状区域 -π/2≤Re z≤π/2 映射为半平面（共形映射）。
  水平线 y=常数 映射为椭圆，垂直线 x=常数 映射为双曲线——椭圆和双曲线正交（共焦二次曲线族）。
  这是 sin z 作为共形映射的几何图像。
- **一句话点评**：sin z=(e^{iz}-e^{-iz})/(2i),eᶻ整函数+四则封闭⟹sin z整函数。sin(x+iy)=sinx coshy+i cosx sinhy,u=sinx coshy,v=cosx sinhy。u_x=cosx coshy=v_y✓,u_y=sinx sinhy=-v_x✓。(sin z)'=cos z。但复sin z无界(|sin(iy)|=|sinh y|→∞),实sinx有界。几何:sin z将带状→半平面,水平线→椭圆,垂直线→双曲线(共焦正交二次曲线族)。

**【D8-1-014】** 证明解析函数的导数仍解析：若 f 在 D 内解析，则 f' 也在 D 内解析。用幂级数定义说明：f(z)=Σa_n(z-z₀)^n，逐项求导得 f'(z)=Σn a_n(z-z₀)^{n-1}，这个幂级数收敛半径与原级数相同，所以 f' 可展开为幂级数——f' 解析。由此归纳得 f 无穷可导。

- **难度**：★★
- **对应知识点**：导数仍解析、幂级数逐项求导、收敛半径不变、无穷可导
- **解答**：
  **幂级数逐项求导**：
  f(z)=Σ_{n=0}^∞ a_n(z-z₀)^n，收敛半径 R。
  逐项求导：f'(z)=Σ_{n=1}^∞ n a_n(z-z₀)^{n-1}=Σ_{n=0}^∞ (n+1)a_{n+1}(z-z₀)^n。

  **收敛半径不变**：
  幂级数 Σa_n w^n 的收敛半径 R=1/limsup |a_n|^{1/n}（Cauchy-Hadamard）。
  导级数系数 b_n=(n+1)a_{n+1}，limsup |b_n|^{1/n}=limsup [(n+1)|a_{n+1}|]^{1/n}。
  (n+1)^{1/n}→1，|a_{n+1}|^{1/n}=|a_{n+1}|^{1/(n+1)}·|a_{n+1}|^{1/(n(n+1))}→limsup |a_n|^{1/n}（因为第二个因子→1）。
  所以导级数收敛半径 = R。∎

  **f' 解析**：
  f'(z) 在 |z-z₀|&lt;R 内可展开为收敛幂级数——所以 f' 在 z₀ 处解析。
  由于 z₀ 是 D 内任意点，f' 在 D 内解析。∎

  **归纳得无穷可导**：
  f 解析 ⟹ f' 解析 ⟹ f'' 解析 ⟹ ... ⟹ f^{(n)} 解析对所有 n。
  所以解析函数无穷可导（C^∞）。∎

  **与实变对比**：
  实变中可导函数的导数不一定可导（如 f(x)=x|x| 一阶可导但二阶不可导）。
  复变中可导（在区域内）自动蕴含无穷可导——这是方向自由度的威力。

  **几何理解**：
  解析函数的"光滑度"是无限的——一旦局部是旋转+缩放，它的所有阶导数也都是旋转+缩放（因为导数仍是解析函数）。
  这就像一个"分形"结构——每一层放大后都是同样的保角行为。
  幂级数是这种无限光滑性的代数表达——函数可以用多项式任意精度逼近。
- **一句话点评**：f=Σa_n(z-z₀)^n(半径R),逐项求导f'=Σn a_n(z-z₀)^{n-1}。Cauchy-Hadamard:R=1/limsup|a_n|^{1/n},导级数系数(n+1)a_{n+1},limsup|(n+1)a_{n+1}|^{1/n}=limsup|a_n|^{1/n}⟹半径不变。f'可展幂级数⟹f'解析。归纳⟹f无穷可导。实变可导⇏导数可导(x|x|),复变可导⟹无穷可导。幂级数=无限光滑的代数表达=多项式任意精度逼近。

**【D8-1-015】** 讨论三种等价定义的证明链条：(1)幂级数定义→复可导定义（逐项求导）；(2)复可导定义→Cauchy定义（Cauchy积分定理/Goursat证明）；(3)Cauchy定义→幂级数定义（Cauchy积分公式+几何级数展开）。说明这个循环证明了"可导=解析=闭路积分为零"在复变中是同一个概念。

- **难度**：★★
- **对应知识点**：三种等价定义、证明链条、Cauchy积分定理、Cauchy积分公式
- **解答**：
  **三种定义**：
  A. 幂级数定义：f 在 z₀ 邻域可展开为收敛幂级数。
  B. 复可导定义：f 在 z₀ 邻域内处处可导。
  C. Cauchy定义：f 连续且沿区域内任意闭曲线积分为零。

  **证明链条 A→B**：
  幂级数在收敛圆内可以逐项求导（已证收敛半径不变），所以和函数在收敛圆内处处可导。
  A⟹B。∎

  **证明链条 B→C**：
  Cauchy积分定理（Goursat证明）：若 f 在单连通区域 D 内处处可导，则 ∮_C f(z)dz=0 对 D 内任意闭曲线 C 成立。
  Goursat 的贡献是去掉了"f' 连续"的假设——只需要 f 处处可导。
  证明思路：对三角形用二分法，若积分非零则存在一个三角形序列积分不趋于零，但 f 可导意味着在小三角形上 f≈线性函数，线性函数的闭路积分为零，矛盾。
  B⟹C。∎

  **证明链条 C→A**：
  Cauchy积分公式：f(z₀)=(1/2πi)∮_C f(z)/(z-z₀) dz。
  对 z 在 z₀ 附近，1/(ζ-z)=1/(ζ-z₀)·1/(1-(z-z₀)/(ζ-z₀))=Σ (z-z₀)^n/(ζ-z₀)^{n+1}（几何级数，因为 |z-z₀|&lt;|ζ-z₀|）。
  代入积分公式：f(z)=Σ [(1/2πi)∮ f(ζ)/(ζ-z₀)^{n+1}dζ] (z-z₀)^n=Σ f^{(n)}(z₀)/n! (z-z₀)^n。
  这就是 Taylor 展开——f 可展开为幂级数。
  C⟹A。∎

  **循环闭合**：A⟹B⟹C⟹A，三种定义等价。

  **与实变对比**：
  实变中：可导 ≠ 解析 ≠ 闭路积分为零（实变没有"闭路积分"概念，因为一维没有闭曲线）。
  复变中：三者等价——这是二维复平面的特殊性质（闭路积分有意义，Cauchy定理成立）。

  **几何理解**：
  三种定义从三个角度描述了同一个概念：
  - 幂级数：代数角度（局部多项式逼近）
  - 复可导：极限角度（方向无关的差商）
  - Cauchy积分：几何角度（闭路积分为零=保守场）
  三者等价说明解析函数是一个非常"刚性"的对象——从任何一个角度定义都得到同样的函数类。
- **一句话点评**：A(幂级数)→B(可导):逐项求导半径不变。B→C(Cauchy):Goursat定理,处处可导⟹闭路积分=0(二分法+小三角形f≈线性)。C→A(幂级数):Cauchy公式f(z₀)=(1/2πi)∮f/(z-z₀),几何级数展开1/(ζ-z)=Σ(z-z₀)^n/(ζ-z₀)^{n+1}⟹Taylor展开。循环闭合A⟹B⟹C⟹A。三角度:代数(幂级数)/极限(可导)/几何(闭路积分)=同一刚性对象。

### 组C：零点孤立性与反例

**【D8-1-009】** 讨论实变反例 f(x)=e^{-1/x²}（x≠0）, f(0)=0：证明它是 C^∞ 但在 x=0 处不解析。计算 f^{(n)}(0)=0（所有阶导数在0处为0），所以 Taylor 级数恒为0，但 f(x)≠0（x≠0），级数不收敛到函数本身。

- **难度**：★★
- **对应知识点**：实变C∞≠解析、e^{-1/x²}反例、Taylor级数不收敛到函数
- **解答**：
  **f(x)=e^{-1/x²}（x≠0）, f(0)=0**

  **C^∞ 证明**：
  x≠0 时，f(x)=e^{-1/x²} 是初等函数，无穷可导。
  x=0 处，用归纳法证明 f^{(n)}(0)=0：
  - n=0: f(0)=0。
  - 假设 f^{(n)}(0)=0，则 f^{(n)}(x) 在 x≠0 处形如 P_n(1/x)e^{-1/x²}（P_n 是多项式）。
  - f^{(n+1)}(0)=lim_{x→0}[f^{(n)}(x)-f^{(n)}(0)]/x=lim_{x→0} P_n(1/x)e^{-1/x²}/x。
  - 令 t=1/x→∞，=lim_{t→∞} P_n(t)·t·e^{-t²}=0（指数衰减快于任何多项式增长）。∎
  所以 f^{(n)}(0)=0 对所有 n 成立，f 是 C^∞。

  **不解析**：
  f 在 x=0 处的 Taylor 级数：
  Σ f^{(n)}(0)/n! · xⁿ = Σ 0·xⁿ = 0。
  这个级数恒等于 0，但 f(x)=e^{-1/x²}≠0（x≠0）。
  所以 Taylor 级数不收敛到 f(x)——f 在 x=0 处不解析。∎

  **与复变对比**：
  如果把 f 延拓到复平面 f(z)=e^{-1/z²}，则 z=0 是本性奇点（不是可去奇点）——在复平面上 f 在 0 附近无界且振荡，根本不连续，更不可能解析。
  实变中 f 在 0 处看起来"很光滑"（C^∞），但复变中暴露了它的奇异性——这就是"复可导比实可导强得多"的体现。

  **几何理解**：
  e^{-1/x²} 在 x=0 处"太平滑了"——所有导数都为0，函数在0附近"几乎是常数0"，但又不是真正的0。
  这种"无限平坦但非零"的函数在实变中存在，但在复变中不可能——复可导函数如果在一点的所有导数为0，则函数在该点邻域内恒为0（唯一性定理）。
  这就是复可导的"刚性"——一旦可导，函数的行为被完全决定，不能有"偷偷非零"的部分。
- **一句话点评**：f(x)=e^{-1/x²}(x≠0),f(0)=0。归纳法f^{(n)}(0)=0(f^{(n)}(x)=P_n(1/x)e^{-1/x²},lim P_n(t)t e^{-t²}=0)。Taylor级数=Σ0=0≠f(x)(x≠0)⟹不解析。复变延拓f(z)=e^{-1/z²},z=0是本性奇点(无界振荡)。实变"看起来光滑"但复变暴露奇异性。复可导刚性:一点所有导数为0⟹邻域恒为0(唯一性定理),不能"偷偷非零"。

**【D8-1-013】** 讨论解析函数的零点孤立性预备：若 f 不恒为零且在 z₀ 处解析，f(z₀)=0，则存在 z₀ 的邻域，使得 z₀ 是该邻域内 f 的唯一零点。用幂级数展开说明：f(z)=Σa_n(z-z₀)^n，a₀=0，设第一个非零系数为 a_m，则 f(z)=(z-z₀)^m·g(z)，g(z₀)=a_m≠0，由连续性 g 在邻域内非零。

- **难度**：★★
- **对应知识点**：零点孤立性、幂级数展开、零点阶数、连续性
- **解答**：
  **幂级数展开**：
  f 在 z₀ 解析，所以 f(z)=Σ_{n=0}^∞ a_n(z-z₀)^n（在某个收敛圆内）。
  f(z₀)=0 ⟹ a₀=0。

  **零点阶数**：
  设 a₀=a₁=...=a_{m-1}=0，但 a_m≠0（m 是零点的阶数）。
  则 f(z)=a_m(z-z₀)^m+a_{m+1}(z-z₀)^{m+1}+...=(z-z₀)^m·[a_m+a_{m+1}(z-z₀)+...]
  =(z-z₀)^m·g(z)，其中 g(z)=Σ_{n=m}^∞ a_n(z-z₀)^{n-m}。

  **g(z₀)=a_m≠0**。
  g(z) 是幂级数，在收敛圆内连续（解析函数连续）。
  由连续性，存在 z₀ 的邻域 U，使得 g(z)≠0 对所有 z∈U 成立（因为 g(z₀)≠0，连续函数在附近保持非零）。

  **零点孤立**：
  在 U 内，f(z)=(z-z₀)^m·g(z)，g(z)≠0，所以 f(z)=0 ⟺ (z-z₀)^m=0 ⟺ z=z₀。
  z₀ 是 U 内 f 的唯一零点。∎

  **与实变对比**：
  实变中 C^∞ 函数的零点可以有聚点——如 f(x)=x²sin(1/x)（补充 f(0)=0），零点为 x=0 和 x=1/(nπ)，0 是零点的聚点。
  但这个函数在 0 处不解析（甚至不是 C²）。
  复变中解析函数的零点一定孤立——这是解析函数"刚性"的又一体现。

  **几何理解**：
  零点孤立性意味着解析函数不能"在一条曲线上为零"（除非恒为零）。
  如果两个解析函数在一条有聚点的曲线上相等，则它们恒等（唯一性定理）——这是零点孤立性的直接推论。
  这就是为什么解析延拓是唯一的——函数在一个小区域上的值决定了它在整个连通区域上的值。
- **一句话点评**：f解析⟹f(z)=Σa_n(z-z₀)^n。f(z₀)=0⟹a₀=0。设首个非零a_m⟹f=(z-z₀)^m·g(z),g(z₀)=a_m≠0。g连续⟹邻域内g≠0⟹f=0⟺z=z₀⟹零点孤立。实变反例x²sin(1/x)零点有聚点(但不解析)。解析函数不能在曲线上为零(除非恒零)⟹唯一性定理⟹解析延拓唯一。

## L2 复变函数层（★★★ 研究）

**【D8-1-016】** 讨论 Goursat 定理的历史意义：Cauchy 最初证明积分定理时假设了 f' 连续，Goursat（1900）证明了只需要 f 处处可导（不需要 f' 连续）。说明这个改进的深刻性：它意味着"可导"本身已经足够强，不需要额外的连续性假设——这是复可导强度的终极体现。

- **难度**：★★★
- **对应知识点**：Goursat定理、Cauchy积分定理历史、可导蕴含导数连续
- **解答**：
  **Cauchy 的原始证明（1825）**：
  Cauchy 证明 ∮f(z)dz=0 时，假设了 f' 连续。
  他用 Green 公式：∮(u dx - v dy)+i∮(v dx+u dy) = ∬(-v_x-u_y)dA+i∬(u_x-v_y)dA。
  由 C-R 方程 u_x=v_y, u_y=-v_x，两个被积函数都为0，所以积分为0。
  但 Green 公式需要偏导数连续——即 f' 连续。

  **Goursat 的改进（1900）**：
  Goursat 证明了：只需要 f 在区域内处处可导（不需要 f' 连续），就有 ∮f(z)dz=0。
  证明方法：对三角形 T，将其等分为4个小三角形，选择积分绝对值最大的一个 T₁，继续二分...
  得到三角形序列 T⊃T₁⊃T₂⊃...，直径→0，且 |∮_{T_n} f dz|≥|∮_T f dz|/4ⁿ。
  因为 f 在 z₀（序列交点）可导，f(z)=f(z₀)+f'(z₀)(z-z₀)+ε(z)(z-z₀)，ε(z)→0。
  线性部分 f(z₀)+f'(z₀)(z-z₀) 的闭路积分为0（线性函数是解析函数的原型）。
  余项 ∮ε(z)(z-z₀)dz 的绝对值 ≤ ε·(直径)·(周长) → 0（因为直径→0，周长~直径，乘积~直径²→0）。
  所以 |∮_{T_n} f dz|→0，但 ≥|∮_T f dz|/4ⁿ，而 4ⁿ·(直径²)→0，推出 ∮_T f dz=0。∎

  **深刻性**：
  Goursat 定理意味着：复可导自动蕴含 f' 连续！
  因为 f 可导 ⟹ Cauchy定理 ⟹ Cauchy公式 ⟹ f' 存在且连续（甚至解析）。
  所以"f' 连续"不是额外假设——它是可导的推论。
  在实变中，可导不蕴含导数连续（如 x²sin(1/x) 可导但导数不连续）。
  复变中，可导自动蕴含导数连续（甚至无穷可导）——这是方向自由度的终极威力。

  **历史意义**：
  Goursat 定理是复变函数论的基石之一——它确立了"可导=解析"的等价性，不需要任何额外假设。
  这使得复变函数论成为一个极其"干净"的理论——定义简单（可导），结论强大（无穷可导、幂级数、零点孤立）。

  **几何理解**：
  Goursat 的二分法证明本质上是"用局部线性逼近全局"——在每个小三角形上，可导意味着 f≈线性，线性函数积分为零，所以小三角形积分趋于零。
  这与实变中的 Riemann 积分类似，但复可导的"各向同性"使得线性逼近在所有方向上都成立——这是证明的关键。
- **一句话点评**：Cauchy(1825)假设f'连续,用Green公式+C-R⟹积分=0。Goursat(1900)去掉f'连续:三角形二分法,T⊃T₁⊃...直径→0,|∮_{T_n}f|≥|∮_T f|/4ⁿ。可导⟹f≈线性+ε(z)(z-z₀),线性闭路积分=0,余项≤ε·直径·周长→0⟹∮_T f=0。深刻性:可导⟹f'连续(甚至解析)!实变可导⇏导数连续(x²sin(1/x))。复可导各向同性⟹局部线性逼近全局。

**【D8-1-017】** 讨论解析函数的开映射定理：非常数解析函数将开集映射为开集。用幂级数展开说明：若 f(z₀)=w₀ 且 f'(z₀)≠0，则 f 在 z₀ 附近是局部同胚（逆函数存在且解析），所以像集是开的。若 f'(z₀)=...=f^{(m-1)}(z₀)=0, f^{(m)}(z₀)≠0，则 f(z)-w₀=(z-z₀)^m g(z)，局部是 m 对 1 的映射，但像集仍是开的。

- **难度**：★★★
- **对应知识点**：开映射定理、局部同胚、零点阶数、m对1映射
- **解答**：
  **开映射定理**：非常数解析函数 f 将开集映射为开集。
  即：若 U 是开集，则 f(U) 是开集。

  **情形 1：f'(z₀)≠0**
  f(z)=w₀+f'(z₀)(z-z₀)+高阶项。
  因为 f'(z₀)≠0，由逆函数定理，f 在 z₀ 附近是局部同胚——存在 z₀ 的邻域 U 和 w₀ 的邻域 V，使得 f:U→V 是双射且 f^{-1} 解析。
  所以 w₀ 是 f(U) 的内点——f(U) 是开集。∎

  **情形 2：f'(z₀)=...=f^{(m-1)}(z₀)=0, f^{(m)}(z₀)≠0（m阶零点）**
  f(z)-w₀=(z-z₀)^m g(z)，g(z₀)≠0。
  取 m 次根：h(z)=(f(z)-w₀)^{1/m}=(z-z₀)g(z)^{1/m}。
  h'(z₀)=g(z₀)^{1/m}≠0，所以 h 在 z₀ 附近是局部同胚。
  f(z)=w₀+h(z)^m。
  h 将 z₀ 邻域映射为 0 的邻域（开集），再取 m 次方——w↦w^m 将 0 的邻域映射为 0 的邻域（开集，虽然是 m 对 1 的映射）。
  所以 f(U) 包含 w₀ 的邻域——w₀ 是内点，f(U) 开。∎

  **与实变对比**：
  实变中可导函数不一定是开映射——如 f(x)=x² 将开区间 (-1,1) 映射为 [0,1)，不是开集（0 不是内点）。
  复变中非常数解析函数一定是开映射——这是解析函数的"刚性"又一体现。

  **几何理解**：
  开映射定理意味着解析函数不能"压扁"区域——它不能将二维开集映射为一维曲线或一个点（除非常数）。
  解析函数保持"开性"——开集的像仍是开集。
  这与保角性一致：局部是旋转+缩放（m阶时是旋转+缩放+取m次方），都是开映射。
  最大值原理是开映射定理的推论：非常数解析函数在区域内部不能取最大值（因为最大值点的邻域会被映射到包含更大值的开集）。
- **一句话点评**：非常数解析f将开集映为开集。f'(z₀)≠0⟹逆函数定理⟹局部同胚⟹像开。m阶零点:f-w₀=(z-z₀)^m g(z),取m次根h=(f-w₀)^{1/m},h'≠0⟹h局部同胚,f=w₀+h^m,w↦w^m是开映射⟹像开。实变x²将(-1,1)→[0,1)非开。解析函数不能压扁区域(不能映为曲线/点除非常数)。最大值原理=开映射推论(内部不能取最大值)。

## L3 实变函数层（★★★ 研究）

**【D8-1-018】** 从实变函数论的角度理解"复可导=解析"的强度：在实变中，可导函数可以很病态（一阶可导但二阶不可导、C^∞但不解析、零点有聚点）；在复变中，一次可导自动蕴含所有好性质。说明这是因为 ℂ 作为 ℝ² 的"域结构"（乘法）带来了额外的约束——C-R 方程将两个实变量函数耦合在一起。

- **难度**：★★★
- **对应知识点**：实变病态函数vs复可导、域结构、C-R方程耦合、方向自由度
- **解答**：
  **实变中的病态函数**：
  1. 一阶可导但二阶不可导：f(x)=x²sin(1/x)（f(0)=0）。f'(x)=2xsin(1/x)-cos(1/x)，f'(0)=0，但 f' 在 0 不连续，f''(0) 不存在。
  2. C^∞ 但不解析：f(x)=e^{-1/x²}（已证）。
  3. 零点有聚点：f(x)=x²sin(1/x)，零点 {0}∪{1/(nπ)}，0 是聚点。
  4. 处处连续但处处不可导：Weierstrass 函数 f(x)=Σaⁿcos(bⁿπx)。

  这些函数在实变中都存在，但在复变中"解析函数"类中都不可能存在。

  **复可导的额外约束**：
  复可导 f=u+iv 要求 C-R 方程 u_x=v_y, u_y=-v_x。
  这将 u 和 v 两个独立的实函数耦合在一起——它们不再是任意的二元函数，而是满足一组偏微分方程的解。
  C-R 方程蕴含 Laplace 方程（调和函数），而调和函数有很好的性质（平均值原理、最大值原理、解析性）。
  所以复可导 = 两个共轭调和函数的组合——调和性自动带来了所有好性质。

  **域结构的作用**：
  ℂ 是一个域（有乘法），而 ℝ² 通常只是向量空间（没有自然的乘法）。
  复可导的定义 f'(z₀)=lim [f(z₀+Δz)-f(z₀)]/Δz 用到了复数除法——这要求 Δz 可以作为分母，而除法在所有方向上都有意义。
  实变中导数 lim [f(x+Δx)-f(x)]/Δx 只用到了实数除法，Δx 只有两个方向。
  复数乘法的"旋转+缩放"结构使得可导条件自动蕴含了保角性和调和性。

  **几何理解**：
  实变函数 f:ℝ→ℝ 的图像是一条曲线——可以很"曲折"（处处不可导）。
  复变函数 f:ℂ→ℂ 的图像是四维的（两个输入两个输出），但可导条件要求局部行为是"旋转+缩放"——这是一个非常强的几何约束，排除了所有"曲折"的可能性。
  方向自由度从2（实变）到无穷多（复变）意味着更多的约束=更强的正则性。
  这就是为什么复变函数论是一个"干净"的理论——定义简单，结论强大，没有病态函数。
- **一句话点评**：实变病态:x²sin(1/x)(一阶可导二阶不可导/零点聚点),e^{-1/x²}(C∞不解析),Weierstrass(连续不可导)。复可导=C-R方程耦合u,v⟹共轭调和⟹Laplace⟹平均值原理/最大值原理/解析性。ℂ是域(有乘法/除法),ℝ²只是向量空间。复可导用到复数除法(所有方向有意义),实变只用实数除法(2方向)。方向自由度2→无穷多=更多约束=更强正则性。复变函数论"干净"无病态函数。

## 补充基础题（L1 数学分析 / L2 复变函数 / L3 实变函数）

### L1 数学分析基础

**【D8-1-019】** 证明：若复函数 $f(z)=u(x,y)+iv(x,y)$ 在 $z_0=x_0+iy_0$ 处复可微，则 $u,v$ 在 $(x_0,y_0)$ 处实可微，且满足 Cauchy-Riemann 方程 $u_x=v_y$，$u_y=-v_x$。

- **难度**：★★
- **解答**：$f'(z_0)=\lim_{h\to0}\frac{f(z_0+h)-f(z_0)}{h}$ 存在。
沿实方向 $h=\Delta x\to0$：$f'(z_0)=\lim\frac{u(x_0+\Delta x,y_0)-u(x_0,y_0)+i[v(x_0+\Delta x,y_0)-v(x_0,y_0)]}{\Delta x}=u_x+iv_x$。
沿虚方向 $h=i\Delta y\to0$：$f'(z_0)=\lim\frac{u(x_0,y_0+\Delta y)-u(x_0,y_0)+i[v(x_0,y_0+\Delta y)-v(x_0,y_0)]}{i\Delta y}=\frac{u_y+iv_y}{i}=v_y-iu_y$。
两式相等：$u_x+iv_x=v_y-iu_y$ ⟹ $u_x=v_y$，$v_x=-u_y$（即 $u_y=-v_x$）。
实可微性：复可微蕴含 $u,v$ 的偏导数存在且满足 C-R 方程，进一步可推出 $u,v$ 实可微。∎
- **点评**：Cauchy-Riemann 方程是复可微的必要条件——它来自"沿实轴和虚轴方向的导数必须相等"这一几何事实。复可微比实可微强得多。

**【D8-1-020】** 证明：若 $u,v$ 在 $(x_0,y_0)$ 处实可微且满足 C-R 方程，则 $f=u+iv$ 在 $z_0$ 处复可微。

- **难度**：★★
- **解答**：$u,v$ 实可微 ⟹ $u(x_0+h,y_0+k)-u(x_0,y_0)=u_x h+u_y k+o(\sqrt{h^2+k^2})$，同理 $v$。
$f(z_0+\Delta z)-f(z_0)=(u_x+iv_x)h+(u_y+iv_y)k+o(|\Delta z|)$，其中 $\Delta z=h+ik$。
由 C-R 方程 $u_y=-v_x$，$v_y=u_x$：
$(u_x+iv_x)h+(-v_x+iu_x)k=u_x(h+ik)+iv_x(h+ik)=(u_x+iv_x)(h+ik)=(u_x+iv_x)\Delta z$。
故 $\frac{f(z_0+\Delta z)-f(z_0)}{\Delta z}=u_x+iv_x+o(1)\to u_x+iv_x$。
$f'(z_0)=u_x+iv_x$ 存在。∎
- **点评**：C-R 方程 + 实可微 = 复可微。这是复可微的充分必要条件（在实可微的前提下）。C-R 方程是复分析的"入口"。

**【D8-1-021】** 证明：解析函数的实部和虚部都是调和函数（满足 Laplace 方程 $\Delta u=0$，$\Delta v=0$）。

- **难度**：★★
- **解答**：设 $f=u+iv$ 解析，则 C-R 方程 $u_x=v_y$，$u_y=-v_x$ 成立。
假设 $u,v$ 二阶连续可偏导（解析函数实际上是无穷次可微的，这可以后续证明）。
$\Delta u=u_{xx}+u_{yy}=(v_y)_x+(-v_x)_y=v_{yx}-v_{xy}=0$（混合偏导相等）。
$\Delta v=v_{xx}+v_{yy}=(-u_y)_x+(u_x)_y=-u_{yx}+u_{xy}=0$。
故 $u,v$ 都是调和函数，且互为共轭调和函数。∎
- **点评**：解析函数的实部和虚部都是调和函数——这是复分析与位势理论（Laplace 方程）的深刻联系。反过来，给定一个调和函数 $u$，可以局部构造共轭调和函数 $v$ 使 $u+iv$ 解析。

**【D8-1-022】** 证明：幂级数 $\sum a_n z^n$ 的和函数在收敛圆内解析（可以逐项求导）。

- **难度**：★★
- **解答**：设收敛半径为 $R>0$。在 $|z|<R$ 内，幂级数内闭一致收敛。
逐项求导得到的级数 $\sum na_n z^{n-1}$ 收敛半径仍为 $R$（因为 $\limsup|na_n|^{1/n}=\limsup|a_n|^{1/n}$）。
由 Weierstrass 定理（内闭一致收敛的解析函数列的极限解析，且可逐项求导），和函数 $f(z)=\sum a_n z^n$ 在 $|z|<R$ 内解析，且 $f'(z)=\sum na_n z^{n-1}$。
这说明幂级数是解析函数的"标准形式"——解析函数局部都可以表示为幂级数（Taylor 定理）。∎
- **点评**：幂级数在收敛圆内解析——这是解析函数的基本构造。反过来，任何解析函数在其定义域内每一点附近都可以展开为幂级数（Taylor 展开），这是解析函数的核心定理。

### L2 复变函数基础

**【D8-1-023】** 证明：若 $f$ 在区域 $D$ 内解析且 $f'(z)=0$ 对所有 $z\in D$，则 $f$ 在 $D$ 上为常数。

- **难度**：★
- **解答**：$f'(z)=u_x+iv_x=0$ ⟹ $u_x=0$，$v_x=0$。
由 C-R 方程，$u_y=-v_x=0$，$v_y=u_x=0$。
故 $u_x=u_y=v_x=v_y=0$ 在 $D$ 内。
$u,v$ 的所有偏导数为 0 ⟹ $u,v$ 在连通区域 $D$ 上为常数 ⟹ $f$ 为常数。∎
- **点评**：导数恒为零的解析函数是常数——这与实函数的结论类似，但解析函数的"刚性"更强（即使导数只在一个有聚点的集合上为零，函数也是常数，由唯一性定理）。

**【D8-1-024】** 证明：若 $f$ 在区域 $D$ 内解析且 $|f(z)|$ 为常数，则 $f$ 为常数。

- **难度**：★★
- **解答**：设 $|f(z)|^2=u^2+v^2=c$（常数）。
若 $c=0$，则 $f\equiv0$。
若 $c>0$，对 $x,y$ 求偏导：
$2uu_x+2vv_x=0$，$2uu_y+2vv_y=0$。
由 C-R 方程 $u_y=-v_x$，$v_y=u_x$：
$uu_x+vv_x=0$，$-uv_x+vu_x=0$。
写成矩阵形式：$\begin{pmatrix}u&v\\v&-u\end{pmatrix}\begin{pmatrix}u_x\\v_x\end{pmatrix}=0$。
行列式 $-(u^2+v^2)=-c\neq0$，故只有零解 $u_x=v_x=0$。
由 C-R 方程，所有偏导为 0 ⟹ $f$ 为常数。∎
- **点评**：模为常数的解析函数是常数——这是最大模原理的特例。解析函数的"刚性"使得模的常数性蕴含函数本身的常数性。

**【D8-1-025】** 叙述解析函数的开映射定理：非常数解析函数将开集映为开集。

- **难度**：★★
- **解答**：开映射定理：若 $f$ 在区域 $D$ 内非常数解析，则 $f(D)$ 是开集，且 $f$ 将开集映为开集。
证明思路：(1) 对任意 $z_0\in D$，$f(z)-f(z_0)$ 以 $z_0$ 为零点（设阶数为 $m\geq1$）；(2) 由辐角原理/Rouché 定理，$f(z)-w$ 在 $z_0$ 附近对 $w$ 接近 $f(z_0)$ 时有 $m$ 个零点；(3) 故 $f(z_0)$ 的邻域包含在 $f(D)$ 中，$f(D)$ 开。
推论：非常数解析函数不能将区域映为直线或曲线（因为直线不是开集）。
这与实可微函数不同（如 $f(x)=x^2$ 将 $\mathbb{R}$ 映为 $[0,\infty)$，不是开集）。∎
- **点评**：开映射定理是解析函数"刚性"的深刻体现——非常数解析函数的像一定是开的，不能"压扁"成低维集合。这是复分析独有的性质。

### L3 实变函数基础

**【D8-1-026】** 证明：连续函数是可测函数，解析函数（作为二元实函数）是可测函数。

- **难度**：★
- **解答**：连续函数 $f:\mathbb{R}^n\to\mathbb{R}$ 可测：对任意开集 $U\subset\mathbb{R}$，$f^{-1}(U)$ 是开集（连续函数的原像），开集可测。
解析函数 $f=u+iv$ 的实部 $u$ 和虚部 $v$ 都是连续函数（解析函数连续），故 $u,v$ 可测。
复值函数可测定义为实部和虚部都可测，故 $f$ 可测。
实际上，解析函数是光滑函数（$C^\infty$），当然可测。∎
- **点评**：连续函数必可测——这是可测函数的基本例子。解析函数作为特殊的连续函数，当然可测。可测性是 Lebesgue 积分的前提。

**【D8-1-027】** 叙述弱导数的定义：$g$ 是 $f$ 的弱导数（$\partial^\alpha f=g$ 弱意义下），若对所有测试函数 $\phi\in C_c^\infty$，$\int f\partial^\alpha\phi=(-1)^{|\alpha|}\int g\phi$。

- **难度**：★★
- **解答**：弱导数定义：$f,g\in L^1_{\text{loc}}$，称 $g=\partial^\alpha f$（弱导数），若
$\int_\Omega f\,\partial^\alpha\phi\,dx=(-1)^{|\alpha|}\int_\Omega g\phi\,dx$ 对所有 $\phi\in C_c^\infty(\Omega)$ 成立。
这是分部积分的"逆"：经典导数满足 $\int f\phi'=-\int f'\phi$（边界项为 0），弱导数将此作为定义。
解析函数的弱导数就是经典导数（因为解析函数光滑，经典导数存在）。
Sobolev 空间 $W^{k,p}(\Omega)=\{f\in L^p: \partial^\alpha f\in L^p\text{ 弱意义下}, |\alpha|\leq k\}$。∎
- **点评**：弱导数将导数概念推广到不可微函数——它通过分部积分来定义，不需要函数本身可微。解析函数的弱导数就是经典导数，因为解析函数足够光滑。

**【D8-1-028】** 证明：若 $u$ 是调和函数（$\Delta u=0$）且 $u\in L^p(\mathbb{R}^n)$（$1\leq p<\infty$），则 $u\equiv0$。

- **难度**：★★
- **解答**：调和函数满足均值性质：$u(x)=\frac{1}{|B_r(x)|}\int_{B_r(x)}u(y)dy$。
$|u(x)|\leq\frac{1}{|B_r|}\int_{B_r(x)}|u(y)|dy\leq\frac{1}{|B_r|}(\int_{B_r(x)}|u|^p)^{1/p}|B_r|^{1-1/p}$（Hölder）
$=\frac{1}{|B_r|^{1/p}}(\int_{B_r(x)}|u|^p)^{1/p}\leq\frac{\|u\|_p}{|B_r|^{1/p}}\to0$（$r\to\infty$，因为 $|B_r|\sim r^n\to\infty$）。
故 $u(x)=0$ 对所有 $x$。
这是 Liouville 定理在调和函数上的推广：$L^p$ 调和函数必为零（$p<\infty$）。
$p=\infty$ 时，有界调和函数为常数（Liouville 定理），不一定为零。∎
- **点评**：$L^p$ 调和函数必为零——这是调和函数的"刚性"。解析函数的实部和虚部都是调和函数，故 $L^p$ 解析函数（$p<\infty$）必为零。

## 跨领域综合题

### 经典名题

**【D8-1-CROSS-019】**（D8 × D7 三角学 × D5 级数）**用幂级数定义证明 eᶻ, sin z, cos z 是整函数，并验证它们满足欧拉公式 e^{iz}=cos z+i sin z。说明这三个函数的幂级数在全平面收敛（收敛半径∞），所以是整函数。联系 D7 中"复三角函数无界"的结论——整函数可以无界（Liouville定理说有界整函数必为常数）。**

- **难度**：★★★
- **对应知识点**：整函数幂级数、欧拉公式、收敛半径∞、Liouville定理
- **解答**：
  **幂级数定义**：
  eᶻ=Σ zⁿ/n!，收敛半径 R=1/limsup (1/n!)^{1/n}=∞（因为 n!^{1/n}→∞）。
  sin z=Σ(-1)^n z^{2n+1}/(2n+1)!，R=∞。
  cos z=Σ(-1)^n z^{2n}/(2n)!，R=∞。
  三者都在全平面可展开为收敛幂级数——都是整函数。∎

  **欧拉公式**：
  e^{iz}=Σ(iz)^n/n!=Σ i^n z^n/n!。
  分离偶次和奇次：
  偶次(n=2k): Σ i^{2k} z^{2k}/(2k)!=Σ (-1)^k z^{2k}/(2k)!=cos z。
  奇次(n=2k+1): Σ i^{2k+1} z^{2k+1}/(2k+1)!=i Σ (-1)^k z^{2k+1}/(2k+1)!=i sin z。
  所以 e^{iz}=cos z+i sin z。∎

  **整函数的无界性**：
  eᶻ 无界（沿实轴 eˣ→∞）。
  sin z 无界（|sin(iy)|=|sinh y|→∞）。
  cos z 无界（|cos(iy)|=cosh y→∞）。
  Liouville 定理：有界整函数必为常数。
  这三个函数都是非常数整函数，所以必然无界——与计算一致。∎

  **与 D7 的联系**：
  D7 中讨论了复三角函数无界——这里从整函数和 Liouville 定理的角度给出了更一般的解释：任何非常数整函数都无界，sin z, cos z 只是其中的例子。
  实三角函数有界是因为只看实轴方向；复三角函数在全平面无界是因为它是整函数。

  **几何理解**：
  eᶻ, sin z, cos z 的幂级数收敛半径∞意味着它们在全平面"无限光滑"——没有奇点。
  但无限光滑不意味着有界——整函数可以在某些方向上指数增长。
  欧拉公式将指数增长（eᶻ）和振荡（sin,cos）统一在同一个复函数中——实轴方向振荡，虚轴方向增长。
- **一句话点评**：eᶻ=Σzⁿ/n!,sinz=Σ(-1)^n z^{2n+1}/(2n+1)!,cosz=Σ(-1)^n z^{2n}/(2n)!，R=∞(n!^{1/n}→∞)⟹都是整函数。e^{iz}=Σi^n z^n/n!,偶次=cosz,奇次=i sinz⟹欧拉公式。三者无界(eᶻ沿实轴→∞,sin(iy)=i sinhy→∞)。Liouville:有界整函数=常数,非常数整函数必无界。整函数无限光滑但可以无界。欧拉公式统一振荡(实轴)和增长(虚轴)。

**【D8-1-CROSS-020】**（D8 × D6 完备性 × D2 连续）**讨论解析函数的唯一性定理：若 f 和 g 在区域 D 内解析，且在 D 内一个有聚点的集合上相等，则 f≡g。用零点孤立性证明：h=f-g 解析，零点集有聚点 z₀∈D，若 h 不恒为零则 z₀ 是孤立零点（矛盾），所以 h≡0。说明这是"局部决定全局"的刚性——与实变函数完全不同。**

- **难度**：★★★
- **对应知识点**：唯一性定理、零点孤立性、局部决定全局、与实变对比
- **解答**：
  **唯一性定理**：
  设 f,g 在区域 D 内解析，集合 E⊂D 有聚点 z₀∈D，且 f(z)=g(z) 对所有 z∈E。
  令 h=f-g，则 h 在 D 内解析，且 E 中的点都是 h 的零点。

  **证明**：
  z₀ 是 E 的聚点，所以 z₀ 也是 h 的零点集的聚点（因为 E⊂零点集）。
  假设 h 不恒为零。由零点孤立性，h 的零点是孤立的——存在 z₀ 的邻域 U，使得 z₀ 是 U 内 h 的唯一零点。
  但 z₀ 是 E 的聚点，所以 U 内含有 E 中异于 z₀ 的点，这些点也是 h 的零点——与 z₀ 是 U 内唯一零点矛盾。
  所以 h≡0，即 f≡g。∎

  **"局部决定全局"**：
  解析函数在一个小集合（甚至一条线段、一个收敛序列）上的值，决定了它在整个连通区域上的值。
  这就是解析延拓的唯一性——从一个小区域出发，解析延拓到更大区域时结果唯一。

  **与实变对比**：
  实变中，两个 C^∞ 函数可以在一个区间上相等但在区间外不同——如 f(x)=0 和 g(x)=e^{-1/x²}（x>0时）, g(x)=0（x≤0）。它们在 x≤0 上相等（有聚点），但不恒等。
  这是因为 g 不是实解析函数（在 x=0 处不解析）。
  实解析函数也满足唯一性定理（如果两个实解析函数在有聚点的集合上相等则恒等），但实解析函数类比 C^∞ 函数类小得多。
  复变中"可导=解析"，所以所有可导函数都满足唯一性定理——这是复可导强度的又一体现。

  **几何理解**：
  唯一性定理意味着解析函数是"全息"的——一小片包含了整体的信息。
  这与调和函数的平均值原理一致：函数在一点的值由周围圆周上的平均值决定——局部和全局紧密耦合。
  实变函数是"局部的"——每个点的行为可以独立变化；解析函数是"全局的"——一点的变化会影响整个区域。
- **一句话点评**：h=f-g解析,E有聚点z₀且E⊂h的零点。若h不恒零⟹零点孤立⟹z₀邻域内唯一零点,但E在邻域内有异于z₀的零点⟹矛盾⟹h≡0。局部决定全局=解析延拓唯一。实变反例:f=0和g=e^{-1/x²}(x>0),0(x≤0),在x≤0相等(有聚点)但不恒等(g非实解析)。解析函数=全息(小片含整体信息),实变函数=局部(各点独立)。

### 反例与构造

**【D8-1-CROSS-021】**（D8 × D3 微分 × D2 连续）**构造一个在全平面连续、满足 C-R 方程但不解析的函数：f(z)=e^{-1/z⁴}（z≠0）, f(0)=0。验证在 z≠0 处解析（C-R 成立），在 z=0 处偏导数都为0（C-R 成立），但 f 在 z=0 处不连续（沿不同路径极限不同），所以不解析。说明 C-R 方程+偏导数存在≠解析，还需要连续性/可导性。**

- **难度**：★★★
- **对应知识点**：C-R方程≠解析、e^{-1/z⁴}反例、路径极限、连续性必要
- **解答**：
  **f(z)=e^{-1/z⁴}（z≠0）, f(0)=0**

  **z≠0 处**：
  f(z) 是 eᶻ 和 -1/z⁴ 的复合，在 z≠0 处解析（C-R 方程成立）。∎

  **z=0 处的偏导数**：
  沿实轴 z=x→0：f(x)=e^{-1/x⁴}→0，所有偏导数在0处为0（类似 e^{-1/x²} 的论证）。
  所以 u_x(0,0)=u_y(0,0)=v_x(0,0)=v_y(0,0)=0。
  C-R 方程在 0 处成立（0=0, 0=-0）。∎

  **但 f 在 z=0 处不连续**：
  沿路径 z=re^{iπ/4}（45°方向）→0：
  z⁴=r⁴e^{iπ}=-r⁴，所以 -1/z⁴=-1/(-r⁴)=1/r⁴→+∞。
  f(z)=e^{1/r⁴}→∞≠0=f(0)。
  所以 f 在 0 处不连续——更不可导、不解析。∎

  **教训**：
  C-R 方程在一点成立 + 偏导数存在 ≠ 在该点可导。
  还需要：(1) 函数在该点连续；(2) 差商极限沿所有方向相同。
  充分条件是：C-R 方程 + 偏导数连续（这蕴含了可导性）。
  这个反例中偏导数在 0 处存在但不连续（在 45° 方向附近偏导数无界），所以充分条件不满足。

  **与实变 e^{-1/x²} 对比**：
  实变 e^{-1/x²} 在 0 处连续（甚至 C^∞），只是不解析。
  复变 e^{-1/z⁴} 在 0 处连连续性都不满足（沿 45° 方向发散）——复变的"病态"更严重。
  这是因为复平面有更多方向，函数可以在某些方向上发散而在其他方向上趋于0。

  **几何理解**：
  e^{-1/z⁴} 在 z→0 时的行为依赖于方向：
  - 沿实轴/虚轴：z⁴>0，-1/z⁴→-∞，f→0
  - 沿 45°/135°/225°/315°：z⁴&lt;0，-1/z⁴→+∞，f→∞
  这种方向依赖的极限是复变函数的典型特征——复可导要求所有方向极限相同，而这个函数在不同方向上极限不同（0 vs ∞），所以不可导。
- **一句话点评**：f=e^{-1/z⁴}(z≠0),f(0)=0。z≠0解析。z=0偏导全为0(C-R成立)。但沿z=re^{iπ/4}→0:z⁴=-r⁴,-1/z⁴=1/r⁴→∞,f=e^{1/r⁴}→∞≠0⟹不连续⟹不解析。教训:C-R+偏导存在≠可导,还需连续+所有方向差商相同。充分条件:C-R+偏导连续。对比实变e^{-1/x²}连续(C∞)但不解析;复变e^{-1/z⁴}连连续性都不满足(方向依赖:实轴→0,45°→∞)。

### 定理串联

**【D8-1-CROSS-022】**（D8 × D6 完备性 × D4 积分）**建立"复可导→C-R→调和→平均值原理→最大值原理→唯一性"的完整链条：复可导⟹C-R方程⟹u,v调和⟹调和函数满足平均值原理（u(z₀)=圆周平均）⟹最大值原理（内部不能取最大值）⟹唯一性定理。说明每一步如何依赖于前一步，以及为什么这个链条在实变中断裂。**

- **难度**：★★★
- **对应知识点**：完整推理链条、调和函数平均值原理、最大值原理、唯一性、实变断裂点
- **解答**：
  **完整链条**：

  **第1步：复可导 ⟹ C-R 方程**
  差商极限沿实轴和虚轴方向相等 ⟹ u_x=v_y, u_y=-v_x。
  （这一步在实变中没有对应——实变只有一个方向，没有 C-R 方程。）

  **第2步：C-R ⟹ u,v 调和**
  u_xx+u_yy=v_yx-v_xy=0（混合偏导相等）。
  （实变中可导函数不一定满足任何二阶 PDE——断裂点1。）

  **第3步：调和 ⟹ 平均值原理**
  调和函数满足 u(z₀)=(1/2π)∫₀²π u(z₀+re^{iθ})dθ——函数在一点的值等于周围圆周上的平均值。
  证明用 Green 公式或调和函数的基本解。
  （实变中没有"二维调和函数"的概念——一维的"调和函数"是线性函数 u''=0，太简单。）

  **第4步：平均值原理 ⟹ 最大值原理**
  若 u 在内部取最大值 M，则平均值 u(z₀)=M 意味着周围圆周上的平均值=M，而每个 u≤M，所以圆周上 u≡M。
  逐步推广到整个区域——u≡M（常数）。
  所以非常数调和函数在区域内部不能取最大值。
  （实变中可导函数可以在内部取最大值——如 f(x)=-x² 在 x=0 取最大值。断裂点2。）

  **第5步：最大值原理 ⟹ 唯一性定理**
  若 f,g 解析且在有聚点的集合上相等，h=f-g 解析。
  |h| 是次调和函数，满足最大值原理。
  h 在聚点 z₀ 处为0，若 h 不恒为零，则 |h| 在 z₀ 附近有非零值，但由零点孤立性...
  （更直接用零点孤立性，已证。）

  **链条在实变中断裂**：
  - 断裂点1：实变可导 ⟹ C-R？没有 C-R（一维没有两个偏导数）。
  - 断裂点2：实变可导 ⟹ 调和？没有二维调和性。
  - 断裂点3：实变可导 ⟹ 平均值原理？没有（一维"平均值"只是左右平均，不蕴含全局约束）。
  - 断裂点4：实变可导 ⟹ 最大值原理？不成立（-x² 在内部取最大值）。
  - 断裂点5：实变可导 ⟹ 唯一性？不成立（e^{-1/x²} 反例）。

  **几何理解**：
  这个链条的核心是"复可导⟹调和"——C-R 方程将复可导转化为二阶椭圆型 PDE（Laplace方程）。
  椭圆型 PDE 有很强的正则性（平均值原理、最大值原理、唯一延拓）——这些性质传递给解析函数。
  实变中可导只对应一阶条件，没有二阶 PDE 的约束——所以链条从第一步就断裂了。
  二维是关键：一维没有"调和函数"的丰富理论，二维及以上才有 Laplace 方程和椭圆型 PDE 的完整理论。
- **一句话点评**：链条:复可导⟹C-R(实虚轴差商相等)⟹调和(u_xx+u_yy=0)⟹平均值原理(u(z₀)=圆周平均)⟹最大值原理(内部不能取最大值)⟹唯一性。实变断裂:①无C-R(一维)②无可导⟹调和③无二维平均值原理④可导函数可内部取最大值(-x²)⑤无唯一性(e^{-1/x²})。核心:复可导⟹调和=二阶椭圆PDE(Laplace),椭圆PDE强正则性传递给解析函数。二维是关键(一维无丰富调和理论)。

**【D8-1-CROSS-023】**（D8 × D7 三角学 × D4 积分）**讨论 f(z)=log z 的多值性：log z=ln|z|+i arg z，arg z 多值（相差 2πi）。在去掉负实轴的平面上取主值后，log z 是解析的，导数为 1/z。验证 C-R 方程（极坐标形式）：u=ln r, v=θ，u_r=1/r=(1/r)v_θ（v_θ=1），v_r=0=-(1/r)u_θ（u_θ=0）。说明多值性来自拓扑（平面去掉原点后不是单连通的）。**

- **难度**：★★
- **对应知识点**：log z多值性、主值分支、极坐标C-R、拓扑多连通
- **解答**：
  **log z 的定义**：
  log z = ln|z| + i arg z = ln r + iθ。
  arg z 多值：θ 和 θ+2π 表示同一个 z，但 log z 相差 2πi。
  所以 log z 是多值函数。

  **主值分支**：
  在区域 D=ℂ\{负实轴}（或 ℂ\{从0出发的任意射线}）上，取 arg z∈(-π,π)，得到单值函数 Log z（主值）。
  Log z 在 D 内解析。

  **极坐标 C-R 验证**：
  u=ln r, v=θ。
  u_r=1/r, u_θ=0
  v_r=0, v_θ=1
  极坐标 C-R：u_r=(1/r)v_θ ⟹ 1/r=(1/r)·1 ✓
  v_r=-(1/r)u_θ ⟹ 0=-(1/r)·0 ✓
  C-R 成立，偏导数在 D 内连续——Log z 在 D 内解析。∎

  **导数**：
  f'(z)=e^{-iθ}(u_r+iv_r)=e^{-iθ}(1/r+i·0)=1/(re^{iθ})=1/z。∎
  与实变 (ln x)'=1/x 形式相同。

  **多值性的拓扑来源**：
  log z 的多值性来自 ℂ\{0} 不是单连通的——绕原点一圈后 arg z 增加 2π，函数值不回到原值。
  在单连通区域（如去掉负实轴的平面）上，log z 可以取单值分支（解析）。
  在多连通区域（如 ℂ\{0}）上，log z 不能全局单值解析——需要黎曼面（无穷多叶螺旋面）来表示。

  **几何理解**：
  log z 将复平面（去掉原点）映射为水平带形区域（主值映射为 -π&lt;Im z&lt;π）。
  极坐标 (r,θ) 映射为直角坐标 (ln r, θ)——对数变换=极坐标转直角坐标。
  多值性对应于"绕原点一圈"在 θ 方向上走了 2π——在黎曼面上就是从一叶走到下一葉。
- **一句话点评**：log z=ln r+iθ,arg多值(差2πi)。主值Log z在ℂ\{负实轴}上单值解析。极坐标C-R:u=lnr,v=θ,u_r=1/r=(1/r)v_θ✓,v_r=0=-(1/r)u_θ✓。导数=1/z。多值性=拓扑:ℂ\{0}非单连通,绕原点一圈arg+2π。单连通区域可取单值分支;多连通需黎曼面(无穷多叶螺旋面)。log z=极坐标(r,θ)→直角(lnr,θ),多值=绕原点在θ方向走2π。

**【D8-1-CROSS-024】**（D8 × D3 微分 × D2 连续）**讨论 f(z)=z̄（共轭函数）处处不可导：差商=Δz̄/Δz，沿实轴方向=1，沿虚轴方向=-1，极限不相等。用 C-R 方程验证：f(z)=x-iy, u=x, v=-y, u_x=1, v_y=-1（不满足 u_x=v_y）。说明共轭函数是"反解析"的——它保持角度但反转方向（反共形映射）。**

- **难度**：★★
- **对应知识点**：z̄处处不可导、方向差商、反共形映射、C-R不满足
- **解答**：
  **差商法**：
  f(z)=z̄。
  差商=[(z+Δz)̄-z̄]/Δz=Δz̄/Δz。
  沿实轴 Δz=Δx：Δz̄/Δz=Δx/Δx=1。
  沿虚轴 Δz=iΔy：Δz̄/Δz=(-iΔy)/(iΔy)=-1。
  1≠-1，极限不存在——f(z)=z̄ 处处不可导。∎

  **C-R 验证**：
  f(z)=x-iy，u=x, v=-y。
  u_x=1, u_y=0, v_x=0, v_y=-1。
  C-R 第一式 u_x=v_y：1=-1 ✗（不满足）。
  所以处处不满足 C-R——处处不可导。∎

  **反共形映射**：
  z̄ 是关于实轴的反射——它保持角度的大小但反转角度的方向（顺时针变逆时针）。
  雅可比矩阵 J=[[1,0],[0,-1]]=反射矩阵——行列式=-1（保面积但反转定向）。
  这种映射称为"反共形"（anti-conformal）或"反解析"——保持角度但反转定向。
  解析函数的雅可比是旋转×缩放（行列式=|f'|²>0，保定向）；共轭函数的雅可比是反射×缩放（行列式&lt;0，反定向）。

  **与解析函数的关系**：
  如果 f(z) 解析，则 f(z̄) 是"反解析"的（共轭解析）。
  任何反共形映射都可以写成解析函数的共轭：g(z)=f(z̄) 或 g(z)=f(z)̄。
  共形映射保持定向，反共形映射反转定向——两者都保持角度大小。

  **几何理解**：
  z̄ 是最简单的反共形映射——镜面反射。
  它不可导是因为复可导要求"旋转+缩放"（保定向），而反射是"旋转+缩放+反射"（反定向）——多了一个反射，不满足 C-R。
  这就是为什么复分析中"解析"和"共轭解析"是两个不同的函数类——定向的保持 vs 反转。
- **一句话点评**：f(z)=z̄,差商=Δz̄/Δz。实轴方向=1,虚轴方向=-1⟹极限不存在⟹处处不可导。C-R:u=x,v=-y,u_x=1≠v_y=-1✗。反共形映射:雅可比[[1,0],[0,-1]]=反射,行列式=-1(保角度但反转定向)。解析=旋转×缩放(行列式>0保定向);共轭=反射×缩放(行列式&lt;0反定向)。反共形=解析函数的共轭g(z)=f(z̄)。复可导要求保定向,反射反定向⟹不可导。

**【D8-1-CROSS-025】**（D8 × D5 级数 × D6 完备性）**讨论幂级数的收敛圆与奇点：幂级数 Σa_n(z-z₀)^n 的收敛半径 R 等于 z₀ 到最近奇点的距离。用例子说明：1/(1-z)=Σzⁿ 的收敛半径 R=1，因为 z=1 是奇点；eᶻ=Σzⁿ/n! 的 R=∞，因为没有奇点。说明收敛圆边界上至少有一个奇点（否则可以解析延拓到更大圆，与 R 是最大收敛半径矛盾）。**

- **难度**：★★
- **对应知识点**：收敛半径=到最近奇点距离、收敛圆边界奇点、解析延拓
- **解答**：
  **定理**：幂级数 f(z)=Σa_n(z-z₀)^n 的收敛半径 R 等于 z₀ 到 f 的最近奇点的距离。

  **例子 1：1/(1-z)=Σzⁿ**
  收敛半径 R=1（几何级数，|z|&lt;1 收敛）。
  z=1 是奇点（极点），到原点距离=1=R。∎
  收敛圆 |z|=1 上 z=1 是奇点。

  **例子 2：eᶻ=Σzⁿ/n!**
  收敛半径 R=∞。
  eᶻ 是整函数，没有有限奇点——到最近奇点的距离=∞=R。∎

  **例子 3：1/(1+z²)=Σ(-1)^n z^{2n}**
  收敛半径 R=1。
  奇点在 z=±i（到原点距离=1=R）。
  注意：这个函数在实轴上 [-1,1] 内是光滑的（1/(1+x²) 是 C^∞），但幂级数收敛半径只有1——因为复平面上 z=±i 是奇点，限制了收敛半径。
  这是"实变光滑但复变有奇点"的经典例子——实变看不到奇点，但复变暴露了。

  **收敛圆边界上至少有一个奇点**：
  假设收敛圆 |z-z₀|=R 上没有奇点，则 f 在闭圆盘上解析，可以展开为更大的幂级数（以边界上某点为中心），从而解析延拓到更大的圆。
  这意味着原幂级数的收敛半径可以大于 R——与 R 是最大收敛半径矛盾。
  所以收敛圆边界上至少有一个奇点。∎

  **几何理解**：
  收敛圆是"解析性的边界"——圆内函数解析，圆上至少有一个点函数不解析（奇点）。
  奇点像"障碍物"，限制了幂级数能展开的范围——到最近障碍物的距离就是收敛半径。
  这与实变不同：实变幂级数的收敛半径可能被"看不见的"复奇点限制（如 1/(1+x²)），实变函数本身在收敛区间内是光滑的，但复奇点决定了半径。
- **一句话点评**：收敛半径R=z₀到最近奇点距离。1/(1-z)=Σzⁿ,R=1(z=1奇点)。eᶻ=Σzⁿ/n!,R=∞(无有限奇点)。1/(1+z²)=Σ(-1)^n z^{2n},R=1(奇点z=±i,实轴上1/(1+x²)光滑但复奇点限制半径)。收敛圆边界至少有一个奇点(否则可解析延拓到更大圆,与R最大矛盾)。奇点=障碍物限制展开范围。实变看不到复奇点但复奇点决定收敛半径。

**【D8-1-CROSS-026】**（D8 × D4 积分 × D6 完备性）**用 Green 公式推导 Cauchy 积分定理（假设 f' 连续）：∮f(z)dz=∮(u dx-v dy)+i∮(v dx+u dy)，对两个实积分分别用 Green 公式得 ∬(-v_x-u_y)dA+i∬(u_x-v_y)dA，由 C-R 方程两个被积函数都为0，所以积分为0。说明这是 Cauchy 原始证明，Goursat 后来去掉了 f' 连续的假设。**

  **f(z)=u+iv, dz=dx+i dy**
  f(z)dz=(u+iv)(dx+i dy)=(u dx-v dy)+i(v dx+u dy)。

  **闭路积分**：
  ∮_C f(z)dz = ∮_C (u dx-v dy) + i∮_C (v dx+u dy)。

  **Green 公式**：∮_C P dx+Q dy = ∬_D (Q_x-P_y) dA。

  第一个积分：P=u, Q=-v。
  ∮(u dx-v dy)=∬[(-v)_x-u_y]dA=∬(-v_x-u_y)dA。
  由 C-R：u_y=-v_x ⟹ -v_x-u_y=-v_x-(-v_x)=0。
  所以第一个积分=0。∎

  第二个积分：P=v, Q=u。
  ∮(v dx+u dy)=∬(u_x-v_y)dA。
  由 C-R：u_x=v_y ⟹ u_x-v_y=0。
  所以第二个积分=0。∎

  因此 ∮f(z)dz=0+i·0=0。∎

  **假设条件**：
  Green 公式要求 P,Q 有连续偏导数——即 u_x,u_y,v_x,v_y 连续，即 f' 连续。
  这是 Cauchy 原始证明的假设。

  **Goursat 改进**：
  Goursat（1900）证明了不需要 f' 连续——只需要 f 处处可导。
  方法是三角形二分法（已在 D8-1-016 讨论），不使用 Green 公式。
  这个改进很重要：它意味着"可导"本身已经足够强，不需要额外假设导数连续。
  事实上，由 Goursat 定理+Cauchy 公式可以推出 f' 连续（甚至解析）——所以 f' 连续是可导的推论，不是额外假设。

  **几何理解**：
  Cauchy 积分定理的本质是：解析函数的实部和虚部满足 C-R 方程，使得二维旋度为零（Green 公式中的被积函数为零）。
  这类似于向量场中的"保守场"——旋度为零的场沿闭路积分为零。
  解析函数 f(z) 可以看作两个保守场（u dx-v dy 和 v dx+u dy）的组合——C-R 方程保证了两者都是无旋的。
- **一句话点评**：fdz=(u dx-v dy)+i(v dx+u dy)。Green公式:∮Pdx+Qdy=∬(Q_x-P_y)dA。第一个:∬(-v_x-u_y)dA=0(C-R:u_y=-v_x)。第二个:∬(u_x-v_y)dA=0(C-R:u_x=v_y)。⟹∮fdz=0。需f'连续(Green公式要求偏导连续)。Goursat去掉f'连续假设(三角形二分法)。事实上可导⟹f'连续(推论),所以f'连续不是额外假设。解析函数=两个保守场组合(C-R保证无旋)=保守场的复分析版本。

**【D8-1-CROSS-027】**（D8 × D7 三角学 × D3 微分）**讨论解析函数的导数的几何意义：f'(z₀) 的模 |f'(z₀)| 是局部缩放因子，辐角 arg f'(z₀) 是局部旋转角。用 f(z)=z² 在 z₀=1+i 处验证：f'(z₀)=2(1+i)=2√2 e^{iπ/4}，所以缩放因子=2√2，旋转角=45°。说明这就是保角映射的"局部相似变换"。**

- **难度**：★★
- **对应知识点**：导数几何意义、|f'|=缩放因子、arg f'=旋转角、局部相似变换
- **解答**：
  **f(z)=z², z₀=1+i**
  f'(z)=2z, f'(z₀)=2(1+i)=2+2i。
  |f'(z₀)|=√(4+4)=√8=2√2。
  arg f'(z₀)=arctan(2/2)=π/4=45°。

  **局部行为**：
  在 z₀ 附近，f(z)≈f(z₀)+f'(z₀)(z-z₀)。
  这意味着：z 平面上 z₀ 附近的一个小图形，被映射到 w 平面上 f(z₀) 附近的一个图形，这个图形是原图形的"旋转45°+缩放2√2倍"。

  **验证角度保持**：
  z 平面上从 z₀ 出发的两条曲线，夹角为 α。
  映射后，两条曲线的切线方向都旋转了 arg f'(z₀)=45°，所以夹角不变（仍为 α）。
  这就是保角性。

  **验证长度缩放**：
  z 平面上从 z₀ 出发的小线段长度 Δs，映射后长度≈|f'(z₀)|·Δs=2√2·Δs。
  所有方向的缩放因子相同（各向同性）——这是保角映射的特征。

  **面积缩放**：
  小面积 ΔA 映射后面积≈|f'(z₀)|²·ΔA=(2√2)²·ΔA=8ΔA。
  这与雅可比行列式 det J=|f'|²=8 一致。

  **几何理解**：
  复导数 f'(z₀) 是一个复数——它同时编码了缩放因子（模）和旋转角（辐角）。
  这比实导数 f'(x₀)（只是一个数，表示斜率/缩放）信息更丰富——复导数是一个"相似变换参数"。
  解析函数在每一点附近都像一个相似变换（旋转+缩放），这就是为什么解析函数的图像看起来"很光滑"——局部没有畸变，只有整体旋转和缩放。
  对比实变函数 f(x)=x² 在 x₀ 处的导数 2x₀——只是一个标量，表示切线斜率，没有"旋转"概念（一维没有旋转）。
- **一句话点评**：f(z)=z²,z₀=1+i,f'=2(1+i)=2√2 e^{iπ/4}。|f'|=2√2=缩放因子,arg f'=45°=旋转角。局部f≈f(z₀)+f'(z₀)(z-z₀)=旋转45°+缩放2√2。保角:两曲线切线都转45°⟹夹角不变。各向同性缩放:所有方向缩放因子相同。面积缩放=|f'|²=8。复导数=复数(模=缩放,辐角=旋转)=相似变换参数,比实导数(标量=斜率)信息丰富。解析函数局部=相似变换(无畸变只有旋转缩放)。

**【D8-1-CROSS-028】**（D8 × D6 完备性 × D2 连续）**讨论解析函数的无穷可导性与实变的对比：解析函数 f^{(n)}(z₀)=n!/(2πi)∮f(z)/(z-z₀)^{n+1}dz——高阶导数用积分表示，只要 f 连续就存在所有阶导数。实变中 f(x)=x|x| 一阶可导但二阶不可导。说明复可导的"积分表示"是关键——积分号下可以自由求导，自动产生高阶导数。**

- **难度**：★★
- **对应知识点**：高阶导数公式、积分表示、无穷可导、实变对比
- **解答**：
  **高阶导数公式**（Cauchy）：
  f^{(n)}(z₀) = n!/(2πi) ∮_C f(z)/(z-z₀)^{n+1} dz。
  这个公式表明：只要 f 在 C 上连续（解析当然连续），它的所有阶导数都存在——因为右边是积分，积分号下可以对 z₀ 求导（被积函数光滑）。

  **推导思路**：
  Cauchy 积分公式 f(z₀)=(1/2πi)∮f(z)/(z-z₀)dz。
  对 z₀ 求导（积分号下求导）：
  f'(z₀)=(1/2πi)∮f(z)·1/(z-z₀)² dz。
  再求导：f''(z₀)=(2!/2πi)∮f(z)/(z-z₀)³ dz。
  归纳得 f^{(n)}(z₀)=n!/(2πi)∮f(z)/(z-z₀)^{n+1} dz。∎

  **为什么积分表示自动产生高阶导数**：
  被积函数 f(z)/(z-z₀)^{n+1} 作为 z₀ 的函数是光滑的（分母是 z₀ 的有理函数，在 C 内 z≠z₀）。
  积分保持光滑性——积分号下可以任意次求导。
  所以 f 的高阶导数自动存在。

  **与实变对比**：
  实变中没有"闭路积分公式"——一维没有闭曲线，Cauchy 积分公式不适用。
  实变可导函数的导数不一定可导：f(x)=x|x|，f'(x)=2|x|（连续但在0不可导），f''(0)不存在。
  复变中，可导⟹解析⟹Cauchy公式⟹高阶导数公式⟹无穷可导。
  积分表示是关键——它把"求导"转化为"积分"，而积分比求导更"宽容"（连续函数就可积，积分结果更光滑）。

  **几何理解**：
  高阶导数公式意味着解析函数的"全部信息"都编码在边界值上——边界上的连续函数 f(z) 决定了内部所有阶导数的值。
  这是"边界决定内部"的又一体现（与平均值原理、最大值原理一致）。
  实变函数没有这种"边界决定内部"的性质——区间端点的值不能决定内部的导数（更不用说高阶导数）。
  二维复平面的拓扑（有内部和边界的闭曲线）使得积分表示成为可能——这是一维实直线没有的结构。
- **一句话点评**：f^{(n)}(z₀)=n!/(2πi)∮f(z)/(z-z₀)^{n+1}dz。Cauchy公式积分号下求导⟹高阶导数公式。被积函数作为z₀的函数光滑⟹积分保持光滑⟹任意阶导数存在。实变无闭路积分(一维无闭曲线),x|x|一阶可导二阶不可导。关键:积分表示把求导转化为积分(积分比求导宽容,连续就可积,结果更光滑)。边界值决定内部所有阶导数=边界决定内部(二维拓扑有内部/边界,一维没有)。

**【D8-1-CROSS-029】**（D8 × D5 级数 × D7 三角学）**讨论 Taylor 级数与 Laurent 级数的区别：解析函数在收敛圆内展开为 Taylor 级数（只有非负幂次），在圆环内解析但有奇点时展开为 Laurent 级数（含负幂次）。用 1/(1-z) 在 |z|&lt;1 展开为 Σzⁿ（Taylor），在 |z|>1 展开为 -Σ1/z^{n+1}（Laurent）说明。负幂次项对应奇点的影响。**

- **难度**：★★
- **对应知识点**：Taylor vs Laurent级数、圆环展开、负幂次=奇点、1/(1-z)例子
- **解答**：
  **Taylor 级数**：
  f 在 |z-z₀|&lt;R 内解析（无奇点），则 f(z)=Σ_{n=0}^∞ a_n(z-z₀)^n（只有非负幂次）。
  a_n=f^{(n)}(z₀)/n!。

  **Laurent 级数**：
  f 在圆环 r&lt;|z-z₀|&lt;R 内解析（内圆内可能有奇点），则 f(z)=Σ_{n=-∞}^∞ a_n(z-z₀)^n（含负幂次）。
  a_n=(1/2πi)∮f(z)/(z-z₀)^{n+1}dz。

  **例子：f(z)=1/(1-z)**

  **|z|&lt;1（Taylor）**：
  1/(1-z)=Σ_{n=0}^∞ zⁿ（几何级数，|z|&lt;1 收敛）。
  只有非负幂次——因为在 |z|&lt;1 内 f 解析（z=1 在收敛圆外）。∎

  **|z|>1（Laurent）**：
  1/(1-z)=1/[z(1/z-1)]=-1/z·1/(1-1/z)=-1/z·Σ_{n=0}^∞ (1/z)^n=-Σ_{n=0}^∞ 1/z^{n+1}=-Σ_{n=1}^∞ z^{-n}。
  只有负幂次——因为在 |z|>1 的区域（无穷远点附近），z=1 是"内部奇点"，Laurent 展开的负幂次反映了这个奇点的影响。∎

  **负幂次的意义**：
  Laurent 级数的负幂次部分 Σ_{n=-∞}^{-1} a_n(z-z₀)^n 称为"主要部分"，它反映了内圆内奇点的性质。
  - 如果主要部分只有有限项（到 -m），则 z₀ 是 m 阶极点。
  - 如果主要部分有无穷多项，则 z₀ 是本性奇点。
  - 如果没有主要部分（只有非负幂次），则 z₀ 是可去奇点。

  **几何理解**：
  Taylor 级数是"从内部看"——在奇点外面的圆盘内展开，看不到奇点，只有非负幂次（多项式-like）。
  Laurent 级数是"从外面看"——在奇点外面的圆环内展开，奇点的影响表现为负幂次（1/z 的幂次，在无穷远处衰减）。
  同一个函数在不同区域有不同的展开——这是解析延拓的级数表现。
  1/(1-z) 在 |z|&lt;1 是"增长型"（zⁿ），在 |z|>1 是"衰减型"（z^{-n}）——两个区域的行为完全不同。
- **一句话点评**：Taylor:|z-z₀|&lt;R内解析⟹Σa_n(z-z₀)^n(非负幂)。Laurent:圆环r&lt;|z-z₀|&lt;R内解析⟹Σ_{-∞}^∞a_n(z-z₀)^n(含负幂)。1/(1-z):|z|&lt;1⟹Σzⁿ(Taylor,z=1在圆外);|z|>1⟹-Σz^{-n}(Laurent,z=1是内部奇点)。负幂次=主要部分=奇点性质:有限项=极点,无穷项=本性奇点,无负幂=可去奇点。Taylor=从内部看(看不到奇点),Laurent=从外面看(奇点影响=负幂)。同一函数不同区域不同展开=解析延拓的级数表现。

**【D8-1-CROSS-030】**（D8 × D6 完备性 × D3 微分）**讨论 Morera 定理：若 f 在区域 D 内连续，且沿 D 内任意闭曲线积分为零，则 f 在 D 内解析。这是 Cauchy 积分定理的逆定理。说明它给出了解析函数的"积分定义"——不需要假设可导，只需要连续+闭路积分为零，就自动推出可导（甚至解析）。这是"弱条件推出强结论"的典范。**

- **难度**：★★
- **对应知识点**：Morera定理、Cauchy定理逆定理、积分定义解析、弱条件强结论
- **解答**：
  **Morera 定理**：
  若 f 在区域 D 内连续，且对 D 内任意闭曲线 C 有 ∮_C f(z)dz=0，则 f 在 D 内解析。

  **证明思路**：
  闭路积分为零意味着积分与路径无关。
  固定 z₀∈D，定义 F(z)=∫_{z₀}^z f(ζ)dζ（与路径无关）。
  可以证明 F 是解析的，且 F'(z)=f(z)（类似实变中的"变上限积分求导"）。
  因为 F 解析，所以 F'=f 也解析（解析函数的导数仍解析）。
  所以 f 解析。∎

  **弱条件推出强结论**：
  假设只有：(1) f 连续；(2) 闭路积分为零。
  结论：f 解析（无穷可导、幂级数展开、零点孤立...）。
  连续是很弱的条件（很多病态函数连续），闭路积分为零是一个积分条件——两者结合推出了极强的正则性。
  这在实变中不可能：连续函数 + 一维"闭路积分"（没有意义）不能推出可导。

  **三种等价定义的闭环**：
  Cauchy 定理：解析 ⟹ 闭路积分为零。
  Morera 定理：连续 + 闭路积分为零 ⟹ 解析。
  两者结合：在连续函数类中，解析 ⟺ 闭路积分为零。
  这就是解析函数的"积分定义"（定义三）。

  **与变上限积分的类比**：
  实变中：若 f 连续，则 F(x)=∫ₐˣf(t)dt 可导，F'=f（微积分基本定理）。
  复变中：若 f 连续+闭路积分为零，则 F(z)=∫_{z₀}^z f(ζ)dζ 解析，F'=f（Morera 定理）。
  复变多了"闭路积分为零"的条件——因为复平面上积分可以沿不同路径，需要路径无关才能定义 F。
  而"闭路积分为零"恰好等价于"积分与路径无关"。

  **几何理解**：
  Morera 定理说明：解析函数可以完全由"积分行为"刻画——不需要知道函数是否可导，只需要知道它的闭路积分是否为零。
  这是"整体条件（积分）决定局部性质（可导）"的典范——与"局部条件（可导）决定整体性质（唯一性、最大值原理）"形成对偶。
  解析函数的定义可以从三个等价角度：局部（可导）、代数（幂级数）、整体（积分）——Morera 定理是整体角度的核心。
- **一句话点评**：Morera:f连续+任意闭路积分=0⟹f解析。证明:积分与路径无关⟹定义F(z)=∫_{z₀}^z f,F解析且F'=f⟹f=F'解析。弱条件(连续+积分)⟹强结论(解析=无穷可导),实变不可能。Cauchy定理(解析⟹闭路积分=0)+Morera(连续+闭路积分=0⟹解析)=连续函数类中解析⟺闭路积分=0=积分定义。类比实变微积分基本定理,复变多了"闭路积分=0"(路径无关)条件。整体条件(积分)决定局部性质(可导),与局部决定整体对偶。

## 本模块易错点总结

1. **复可导要求所有方向差商极限相同**：实变只有2个方向（左右），复变有无穷多方向。这是复可导比实可导强得多的根本原因。|z|²只在原点可导（只有原点各向同性）是经典反例。

2. **一点可导 ≠ 在一点解析**：解析要求在 z₀ 的某个邻域内处处可导，而不仅仅是在 z₀ 处可导。|z|²、zRe(z)、x²+iy² 都只在孤立点/曲线上可导但不解析。

3. **C-R 方程是必要条件不是充分条件**：C-R + 偏导数连续才是充分条件。e^{-1/z⁴} 在原点 C-R 成立（偏导都为0）但不连续（沿45°方向发散），所以不解析。Goursat 定理后来证明了"区域内处处可导"已经足够（不需要导数连续）。

4. **C-R 方程的几何意义是雅可比矩阵为旋转缩放矩阵**：J=[[a,-b],[b,a]]=|f'|·R(φ)。缩放因子=|f'|，旋转角=arg f'。这意味着解析函数（f'≠0时）是保角映射。

5. **复可导自动蕴含无穷可导和幂级数展开**：实变中可导≠C^∞≠解析（e^{-1/x²}是C^∞但不解析）。复变中可导=解析=C^∞=幂级数展开=闭路积分为零——一次可导自动蕴含所有好性质。

6. **实解析 vs 复解析**：实变中 C^∞ 函数不一定解析（e^{-1/x²}），复变中可导函数一定解析。根源是方向自由度——复可导约束了二维整体行为，实可导只约束一维局部行为。

7. **共轭调和函数**：解析函数的实部虚部满足 Laplace 方程（调和），且等值线正交（∇u·∇v=0）。已知调和函数 u 可以通过 C-R 方程积分求共轭调和函数 v。

8. **零点孤立性**：非零解析函数的零点是孤立的。实变中可导函数零点可以有聚点（x²sin(1/x)）。零点孤立性是唯一性定理的基础——两个解析函数在有聚点的集合上相等则恒等。

9. **三种等价定义**：幂级数定义、复可导定义、Cauchy闭路积分定义是等价的。证明链条：幂级数→可导（逐项求导）→Cauchy（Goursat定理）→幂级数（Cauchy公式+几何级数）。

10. **开映射定理**：非常数解析函数将开集映射为开集。实变中可导函数不一定是开映射（x²将(-1,1)映为[0,1)）。最大值原理是开映射定理的推论。

11. **整函数与 Liouville 定理**：整函数（全平面解析）如果有界则必为常数。所以非常数整函数（eᶻ, sin z, cos z, 多项式）都无界。

12. **收敛半径=到最近奇点距离**：幂级数的收敛圆边界上至少有一个奇点。1/(1+x²)在实轴上光滑但收敛半径只有1，因为复奇点 z=±i 限制了半径。

13. **z̄ 处处不可导**：差商 Δz̄/Δz 沿实轴=1，沿虚轴=-1。z̄ 是反共形映射（保角度但反转定向），雅可比行列式=-1。

14. **高阶导数用积分表示**：f^{(n)}(z₀)=n!/(2πi)∮f(z)/(z-z₀)^{n+1}dz。只要 f 连续，所有阶导数都存在——积分号下可以自由求导。这是复可导自动蕴含无穷可导的关键机制。

15. **Morera 定理**：连续+闭路积分为零⟹解析。这是 Cauchy 定理的逆，给出了解析函数的"积分定义"——弱条件（连续+积分）推出强结论（解析）。
