## 第一章 引言：数列极限——分析学的第一个严格理论

### 1.1 为什么数列极限是分析学的第一个严格理论

在 D1-1 中，我们建立了极限语言的逻辑结构——ε-N/ε-δ 定义。数列极限是这个语言的第一个完整应用，原因有三：

1. **最简单**：数列是定义在自然数集 ℕ 上的函数，只有一个"趋向方向"（n→∞），不需要处理 x→x₀ 的双侧/单侧问题
2. **最基础**：函数极限可以通过 Heine 定理转化为数列极限，级数收敛是部分和数列的收敛，积分存在性可以用数列逼近
3. **最丰富**：数列极限的理论包含了分析学的核心思想——逼近、收敛、完备性、子列、上下极限等

数列极限理论是分析学的"训练基地"——在这里，学生第一次学会用 ε-N 语言做严格证明，第一次理解"收敛"的本质，第一次接触完备性（Cauchy 收敛准则）。

**📐 几何锚定**：数列极限的几何本质是"数轴上的点列向目标点凝聚"。把数列 {aₙ} 的每一项画在数轴上，收敛意味着这些点从某一项开始全部聚集在目标点 a 附近的任意小邻域内。数列的"尾巴"（n>N 的项）是一个"凝聚的点云"，而"头部"（n≤N 的项）可以任意分散。四则运算在几何上是"点云的运算"——两个凝聚的点云相加/相乘/相除后仍然凝聚。子列定理是"点云的任意子集仍然凝聚到同一点"。上下极限是"点云的最高凝聚点和最低凝聚点"——即使点云不收敛（在两个值之间振荡），它的"上边界"和"下边界"仍然有极限。Cauchy 列是"点云自身越来越紧密"——不需要知道目标点，只要点云内部的距离趋于零，就一定凝聚到某个点（在完备空间中）。

## 第二章 数列极限的定义与基本性质

### 2.1 数列极限的 ε-N 定义（回顾与深化）

**定义**：设 {aₙ} 是实数数列，a∈ℝ。若 ∀ε>0, ∃N∈ℕ, ∀n>N, |aₙ-a|&lt;ε，则称 {aₙ} 收敛于 a，记作 limₙ→∞ aₙ = a。

**定义的深化理解**：

1. **ε 的任意性**：ε 是任意正数，关键是"任意小"。如果只对某个特定的 ε（如 ε=1）成立，那不叫收敛——收敛要求对所有 ε>0 都成立。

2. **N 的存在性**：N 只需要存在，不需要是最小的。如果 N 满足条件，那么任何 N'>N 也满足条件。N 通常依赖于 ε——ε 越小，N 越大。

3. **n>N 的全称性**：N 之后的**所有**项都要满足条件，不能有例外。这是"最终性"的体现——数列的尾巴全部满足条件。

4. **严格不等式 |aₙ-a|&lt;ε**：严格的 &lt; 不是 ≤。但实际上 &lt; 和 ≤ 在极限定义中是等价的——如果定义用 ≤，可以通过取 ε' = ε/2 来转换为 &lt;。

5. **有限项不影响收敛性**：改变数列的前有限项，不改变数列的收敛性和极限值。因为 N 可以选得足够大，使得改变的项都在 N 之前。

### 2.2 唯一性

**定理**：若数列 {aₙ} 收敛，则其极限唯一。

**证明**：假设 {aₙ} 有两个极限 a 和 b，a≠b。取 ε = |a-b|/2 > 0。

由 aₙ→a，存在 N₁，使得 n>N₁ 时 |aₙ-a|&lt;ε。
由 aₙ→b，存在 N₂，使得 n>N₂ 时 |aₙ-b|&lt;ε。

取 N = max(N₁, N₂)，则 n>N 时：
|a-b| = |(a-aₙ)+(aₙ-b)| ≤ |a-aₙ| + |aₙ-b| &lt; ε + ε = 2ε = |a-b|

矛盾！故 a=b。∎

**几何理解**：如果数列收敛到两个不同的点 a 和 b，那么取足够小的 ε（小于 |a-b|/2），a 的 ε-邻域和 b 的 ε-邻域不相交。但数列的尾巴必须同时落在两个不相交的邻域内，这不可能。

### 2.3 有界性

**定理**：若数列 {aₙ} 收敛，则 {aₙ} 有界（即存在 M>0，使得 |aₙ|≤M 对所有 n 成立）。

**证明**：设 aₙ→a。取 ε=1，则存在 N，使得 n>N 时 |aₙ-a|&lt;1，故 |aₙ| &lt; |a|+1。

取 M = max(|a₁|, |a₂|, ..., |a_N|, |a|+1)，则对所有 n，|aₙ|≤M。∎

**逆命题不成立**：有界数列不一定收敛。反例：aₙ=(-1)ⁿ 有界但不收敛。

**几何理解**：收敛数列的尾巴凝聚在 a 附近的有界区域内，头部只有有限项，自然有界。所以整个数列有界。

### 2.4 保号性

**定理**：若 limₙ→∞ aₙ = a > 0（或 a &lt; 0），则存在 N，使得 n>N 时 aₙ > 0（或 aₙ &lt; 0）。

**证明**：设 a>0，取 ε=a/2>0。由收敛定义，存在 N，使得 n>N 时 |aₙ-a|&lt;a/2，故 aₙ > a - a/2 = a/2 > 0。∎

**推论（保不等式性）**：若 aₙ→a, bₙ→b，且存在 N₀ 使得 n>N₀ 时 aₙ≤bₙ，则 a≤b。

**证明**：反证。假设 a>b，取 ε=(a-b)/2>0。存在 N₁ 使得 n>N₁ 时 aₙ>a-ε=(a+b)/2；存在 N₂ 使得 n>N₂ 时 bₙ&lt;b+ε=(a+b)/2。取 N=max(N₀,N₁,N₂)，则 n>N 时 aₙ>(a+b)/2>bₙ，与 aₙ≤bₙ 矛盾。∎

**注意**：保不等式性中，即使 aₙ&lt;bₙ（严格小于），也只能推出 a≤b（非严格）。反例：aₙ=1/n, bₙ=2/n，aₙ&lt;bₙ 但极限都是 0。

### 2.5 迫敛性（夹逼定理）

**定理**：若存在 N₀，使得 n>N₀ 时 aₙ≤bₙ≤cₙ，且 lim aₙ = lim cₙ = a，则 lim bₙ = a。

**证明**：∀ε>0，由 aₙ→a，存在 N₁ 使得 n>N₁ 时 |aₙ-a|&lt;ε，即 a-ε&lt;aₙ&lt;a+ε。
由 cₙ→a，存在 N₂ 使得 n>N₂ 时 |cₙ-a|&lt;ε，即 a-ε&lt;cₙ&lt;a+ε。

取 N=max(N₀,N₁,N₂)，则 n>N 时：
a-ε &lt; aₙ ≤ bₙ ≤ cₙ &lt; a+ε
故 |bₙ-a|&lt;ε。∎

**几何理解**：bₙ 被夹在 aₙ 和 cₙ 之间，而 aₙ 和 cₙ 都凝聚到 a，所以 bₙ 也被"挤"到 a。

**应用**：夹逼定理是计算极限的重要工具——把复杂数列夹在两个简单数列之间。

### 2.6 基本性质的统一视角

收敛数列的五个基本性质（唯一性、有界性、保号性、保不等式性、迫敛性）可以统一理解为：

**"收敛数列的尾巴凝聚在极限值附近，因此具有极限值的所有'局部性质'。"**

- 唯一性：尾巴只能凝聚在一个点附近
- 有界性：尾巴在有限区域内，头部有限，整体有界
- 保号性：尾巴在正数附近，所以尾巴都是正数
- 保不等式性：两条尾巴保持大小关系，极限也保持
- 迫敛性：被夹在两条凝聚到同一点的尾巴之间，也凝聚到该点

## 第三章 收敛数列的四则运算

### 3.1 加法与减法

**定理**：若 aₙ→a, bₙ→b，则 aₙ±bₙ→a±b。

**证明（加法）**：∀ε>0，由 aₙ→a，存在 N₁ 使得 n>N₁ 时 |aₙ-a|&lt;ε/2。
由 bₙ→b，存在 N₂ 使得 n>N₂ 时 |bₙ-b|&lt;ε/2。
取 N=max(N₁,N₂)，则 n>N 时：
|(aₙ+bₙ)-(a+b)| = |(aₙ-a)+(bₙ-b)| ≤ |aₙ-a|+|bₙ-b| &lt; ε/2+ε/2 = ε。∎

**几何理解**：两个凝聚的点云相加，仍然凝聚——因为每个点云的偏差都很小，加起来的偏差也很小（三角不等式）。

### 3.2 乘法

**定理**：若 aₙ→a, bₙ→b，则 aₙbₙ→ab。

**证明**：
|aₙbₙ-ab| = |aₙbₙ-aₙb+aₙb-ab| = |aₙ(bₙ-b)+b(aₙ-a)| ≤ |aₙ||bₙ-b|+|b||aₙ-a|

由收敛数列有界性，存在 M>0 使得 |aₙ|≤M。
∀ε>0，由 bₙ→b，存在 N₁ 使得 n>N₁ 时 |bₙ-b|&lt;ε/(2M)（若 M=0 则 aₙ=0，结论平凡）。
由 aₙ→a，存在 N₂ 使得 n>N₂ 时 |aₙ-a|&lt;ε/(2(|b|+1))。
取 N=max(N₁,N₂)，则 n>N 时：
|aₙbₙ-ab| ≤ M·ε/(2M)+|b|·ε/(2(|b|+1)) &lt; ε/2+ε/2 = ε。∎

**几何理解**：乘法比加法复杂——需要同时控制 |aₙ|（有界性）和两个偏差。但核心思想一样：两个偏差都很小，乘积的偏差也很小。

### 3.3 除法

**定理**：若 aₙ→a, bₙ→b，且 b≠0, bₙ≠0，则 aₙ/bₙ→a/b。

**证明**：先证明 1/bₙ→1/b。
|1/bₙ-1/b| = |b-bₙ|/(|bₙ||b|)

由 bₙ→b≠0，取 ε=|b|/2，存在 N₀ 使得 n>N₀ 时 |bₙ-b|&lt;|b|/2，故 |bₙ|>|b|/2。
∀ε>0，由 bₙ→b，存在 N₁ 使得 n>N₁ 时 |bₙ-b|&lt;ε·b²/2。
取 N=max(N₀,N₁)，则 n>N 时：
|1/bₙ-1/b| = |b-bₙ|/(|bₙ||b|) &lt; (ε·b²/2)/((b/2)·b) = ε。

再由乘法法则，aₙ/bₙ = aₙ·(1/bₙ)→a·(1/b)=a/b。∎

**注意**：除法要求 b≠0 且 bₙ≠0（至少从某项起）。如果 b=0，除法可能发散或不收敛。

### 3.4 四则运算的应用

**例 1**：limₙ→∞ (3n²+2n+1)/(n²-5n+2)
= lim (3+2/n+1/n²)/(1-5/n+2/n²) = (3+0+0)/(1-0+0) = 3

**例 2**：limₙ→∞ (√(n+1)-√n)
= lim [(√(n+1)-√n)(√(n+1)+√n)]/(√(n+1)+√n)
= lim 1/(√(n+1)+√n) = 0

**例 3**：limₙ→∞ (1+1/2+1/3+...+1/n)/n
分子是调和级数 Hₙ ~ ln n，分母是 n，所以极限 = 0。
（严格证明可以用 Stolz 定理，见第五章）

### 3.5 四则运算的条件与局限

**四则运算成立的条件**：两个数列都收敛（除法还要求分母极限非零）。

**不成立的情况**：
1. 两个数列都发散，其和/积可能收敛也可能发散
   - aₙ=(-1)ⁿ, bₙ=(-1)ⁿ⁺¹，aₙ+bₙ=0 收敛
   - aₙ=(-1)ⁿ, bₙ=(-1)ⁿ，aₙbₙ=1 收敛
   - aₙ=n, bₙ=-n，aₙ+bₙ=0 收敛
   - aₙ=n, bₙ=n，aₙ+bₙ=2n 发散

2. 一个收敛一个发散，其和/差一定发散（反证：若和收敛，则差=和-收敛也收敛，矛盾）
3. 一个收敛（非零极限）一个发散，其积一定发散
4. 一个收敛到零一个发散，其积可能收敛也可能发散（不定式 0·∞）

**不定式**：四则运算不能直接处理的极限类型，包括 0/0、∞/∞、0·∞、∞-∞、1^∞、0⁰、∞⁰。这些需要特殊方法（Stolz 定理、洛必达法则、取对数等）。

## 第四章 子列定理与收敛判据

### 4.1 子列的定义

**定义**：设 {aₙ} 是数列，{n_k} 是严格递增的正整数列（n₁&lt;n₂&lt;n₃&lt;...），则 {a_{n_k}} 称为 {aₙ} 的一个子列。

**注意**：
1. n_k 严格递增：n₁&lt;n₂&lt;n₃&lt;...
2. n_k ≥ k（因为 n₁≥1, n₂≥2, ...）
3. 子列保持原数列的顺序
4. 原数列本身也是自己的子列（取 n_k=k）

**常见子列**：
- 奇数项子列 {a_{2k-1}}
- 偶数项子列 {a_{2k}}
- 任意选取的子列 {a_{n_k}}

### 4.2 子列定理

**定理**：若 aₙ→a，则 {aₙ} 的任意子列 {a_{n_k}} 也收敛于 a。

**证明**：∀ε>0，由 aₙ→a，存在 N 使得 n>N 时 |aₙ-a|&lt;ε。
因为 n_k 严格递增，所以 n_k≥k。取 K=N，则当 k>K 时 n_k>k>N，故 |a_{n_k}-a|&lt;ε。∎

**逆定理**：若 {aₙ} 的任意子列都收敛于 a，则 aₙ→a。
（这是显然的，因为原数列本身是自己的子列）

**部分逆定理**：若 {aₙ} 的奇数项子列和偶数项子列都收敛于 a，则 aₙ→a。

**证明**：∀ε>0，存在 K₁ 使得 k>K₁ 时 |a_{2k-1}-a|&lt;ε；存在 K₂ 使得 k>K₂ 时 |a_{2k}-a|&lt;ε。
取 N=max(2K₁-1, 2K₂)，则 n>N 时：
- 若 n 为奇数，n=2k-1>N≥2K₁-1，故 k>K₁，|aₙ-a|&lt;ε
- 若 n 为偶数，n=2k>N≥2K₂，故 k>K₂，|aₙ-a|&lt;ε
因此 aₙ→a。∎

**更一般的结论**：若 {aₙ} 可以分成有限个子列，每个子列都收敛于 a，则 aₙ→a。

### 4.3 子列定理的应用——证明不收敛

子列定理最常用的应用是**证明数列不收敛**：

**方法**：找到两个子列，它们收敛到不同的极限（或一个收敛一个发散），则原数列不收敛。

**例 1**：aₙ=(-1)ⁿ
- 奇数项子列 a_{2k-1}=-1→-1
- 偶数项子列 a_{2k}=1→1
- 两个子列收敛到不同极限，故 {(-1)ⁿ} 不收敛

**例 2**：aₙ=sin(nπ/2)
- a_{4k}=sin(2kπ)=0→0
- a_{4k+1}=sin(2kπ+π/2)=1→1
- 两个子列收敛到不同极限，故不收敛

**例 3**：aₙ=n(1+(-1)ⁿ)
- 奇数项 a_{2k-1}=0→0
- 偶数项 a_{2k}=4k→∞（发散）
- 一个子列收敛一个发散，故原数列不收敛

### 4.4 Bolzano-Weierstrass 定理

**定理**：有界数列必有收敛子列。

**证明（区间套法）**：
设 {aₙ} 有界，即存在 [c₁,d₁] 包含所有 aₙ。
将 [c₁,d₁] 等分为两个子区间 [c₁,(c₁+d₁)/2] 和 [(c₁+d₁)/2,d₁]。至少有一个子区间包含 {aₙ} 的无穷多项，记为 [c₂,d₂]。
继续等分，得到区间套 [c_k,d_k]，满足：
1. [c₁,d₁]⊃[c₂,d₂]⊃...
2. d_k-c_k=(d₁-c₁)/2^{k-1}→0
3. 每个 [c_k,d_k] 包含 {aₙ} 的无穷多项

由区间套定理，存在唯一的 a∈⋂[c_k,d_k]。
现在构造子列：在 [c₁,d₁] 中取 a_{n₁}，在 [c₂,d₂] 中取 a_{n₂}（n₂>n₁），...，在 [c_k,d_k] 中取 a_{n_k}（n_k>n_{k-1}）。
因为 a_{n_k}∈[c_k,d_k] 且 a∈[c_k,d_k]，所以 |a_{n_k}-a|≤d_k-c_k→0，故 a_{n_k}→a。∎

**几何理解**：有界数列被限制在一个有限区间内，无穷多个点塞进有限区间，必然有"拥挤"的地方——某个子区间包含无穷多个点。不断缩小这个拥挤的子区间，最终凝聚到一个点，对应的子列收敛到该点。

**Bolzano-Weierstrass 的意义**：它是分析学中最重要的定理之一——它保证了有界数列"不会完全失控"，至少有一个子列是收敛的。在紧性理论中，Bolzano-Weierstrass 是序列紧的等价表述（见 D6-2）。

### 4.5 收敛的子列判据

**定理**：数列 {aₙ} 收敛于 a ⟺ {aₙ} 的任意子列都收敛于 a。

**证明**：
- ⇒：子列定理（已证）
- ⇐：原数列本身是自己的子列，所以如果任意子列收敛于 a，原数列也收敛于 a

**更实用的判据**：
1. 若奇数项子列和偶数项子列都收敛于 a，则原数列收敛于 a
2. 若数列可以分成有限个子列，每个都收敛于 a，则原数列收敛于 a
3. 若存在一个子列发散，或两个子列收敛到不同极限，则原数列不收敛

## 第五章 Stolz 定理

### 5.1 Stolz 定理的 ∞/∞ 型

**定理（∞/∞ 型）**：设 {bₙ} 严格递增且 lim bₙ=+∞。若 lim (aₙ₊₁-aₙ)/(bₙ₊₁-bₙ) = L（L 可以是有限数、+∞ 或 -∞），则 lim aₙ/bₙ = L。

**证明（有限 L 的情形）**：
设 lim (aₙ₊₁-aₙ)/(bₙ₊₁-bₙ) = L（有限）。
∀ε>0，存在 N 使得 n>N 时：
L-ε &lt; (aₙ₊₁-aₙ)/(bₙ₊₁-bₙ) &lt; L+ε

因为 bₙ₊₁-bₙ>0（严格递增），所以：
(L-ε)(bₙ₊₁-bₙ) &lt; aₙ₊₁-aₙ &lt; (L+ε)(bₙ₊₁-bₙ)

对 n=N, N+1, ..., m-1 求和：
(L-ε)(b_m-b_N) &lt; a_m-a_N &lt; (L+ε)(b_m-b_N)

除以 b_m（b_m>0 当 m 足够大）：
(L-ε)(1-b_N/b_m) + a_N/b_m &lt; a_m/b_m &lt; (L+ε)(1-b_N/b_m) + a_N/b_m

令 m→∞，由 b_m→∞，b_N/b_m→0, a_N/b_m→0，故：
L-ε ≤ liminf a_m/b_m ≤ limsup a_m/b_m ≤ L+ε

由 ε 的任意性，lim a_m/b_m = L。∎

### 5.2 Stolz 定理的 0/0 型

**定理（0/0 型）**：设 {bₙ} 严格递减且 lim bₙ=0，lim aₙ=0。若 lim (aₙ₊₁-aₙ)/(bₙ₊₁-bₙ) = L，则 lim aₙ/bₙ = L。

**证明思路**：与 ∞/∞ 型类似，但需要处理 bₙ→0 的情形。可以通过令 cₙ=1/bₙ 转化为 ∞/∞ 型，或者直接用类似的不等式方法证明。

### 5.3 Stolz 定理的应用

**例 1**：limₙ→∞ (1+1/2+...+1/n)/n
令 aₙ=Hₙ=1+1/2+...+1/n, bₙ=n。
bₙ 严格递增且→∞，满足 ∞/∞ 型条件。
(aₙ₊₁-aₙ)/(bₙ₊₁-bₙ) = (1/(n+1))/1 = 1/(n+1)→0
故 lim Hₙ/n = 0。

**例 2**：limₙ→∞ (1^k+2^k+...+n^k)/n^{k+1}
令 aₙ=Σ_{i=1}^n i^k, bₙ=n^{k+1}。
(aₙ₊₁-aₙ)/(bₙ₊₁-bₙ) = (n+1)^k/[(n+1)^{k+1}-n^{k+1}]
分母 = (k+1)n^k + o(n^k)（二项式展开）
分子 = n^k + o(n^k)
比值 → 1/(k+1)
故 lim = 1/(k+1)。

**例 3**：limₙ→∞ ⁿ√(n!) / n
先取对数：ln(ⁿ√(n!)/n) = (ln 1+ln 2+...+ln n)/n - ln n = (Σ ln k - n ln n)/n
令 aₙ=Σ_{k=1}^n ln k - n ln n, bₙ=n。
(aₙ₊₁-aₙ)/(bₙ₊₁-bₙ) = ln(n+1) - (n+1)ln(n+1) + n ln n
= ln(n+1) - n[ln(n+1)-ln n] - ln(n+1)
= -n ln(1+1/n) → -1
故 lim ln(ⁿ√(n!)/n) = -1，即 lim ⁿ√(n!)/n = e^{-1} = 1/e。

### 5.4 Stolz 定理的条件与注意事项

**条件**：
1. ∞/∞ 型：bₙ 严格递增且→∞
2. 0/0 型：bₙ 严格递减且→0，aₙ→0
3. 差商极限存在（可以是 ±∞）

**注意事项**：
1. **bₙ 必须严格单调**：如果 bₙ 不严格单调，Stolz 定理不适用
2. **差商极限不存在时，原极限可能仍然存在**：Stolz 定理是充分条件，不是必要条件。差商极限不存在不代表原极限不存在
3. **L=±∞ 的情形**：Stolz 定理对 L=+∞ 或 -∞ 也成立，但证明需要调整
4. **不能反向使用**：lim aₙ/bₙ = L 不蕴含 lim (aₙ₊₁-aₙ)/(bₙ₊₁-bₙ) = L

**反例（差商极限不存在但原极限存在）**：
aₙ=n+(-1)ⁿ, bₙ=n。lim aₙ/bₙ=1。
但 (aₙ₊₁-aₙ)/(bₙ₊₁-bₙ) = 1+(-1)ⁿ⁺¹-(-1)ⁿ = 1+2(-1)ⁿ⁺¹，在 -1 和 3 之间振荡，极限不存在。

## 第六章 上下极限

### 6.1 上极限和下极限的定义

**定义（确界定义）**：设 {aₙ} 是有界数列。
- 上极限：limsupₙ→∞ aₙ = limₙ→∞ sup_{k≥n} a_k = infₙ sup_{k≥n} a_k
- 下极限：liminfₙ→∞ aₙ = limₙ→∞ inf_{k≥n} a_k = supₙ inf_{k≥n} a_k

**定义（子列极限定义）**：
- 上极限 = {aₙ} 的所有收敛子列的极限的上确界
- 下极限 = {aₙ} 的所有收敛子列的极限的下确界

**两种定义等价**（需要证明，通常用 Bolzano-Weierstrass 定理）。

### 6.2 上下极限的基本性质

1. **总是存在**：对于有界数列，上下极限总是存在（有限数）。对于无界数列，可以扩展到 ±∞。

2. **不等式**：liminf aₙ ≤ limsup aₙ

3. **收敛判据**：lim aₙ = a ⟺ liminf aₙ = limsup aₙ = a

4. **子列性质**：
   - 存在子列收敛到 limsup aₙ
   - 存在子列收敛到 liminf aₙ
   - 任何收敛子列的极限都在 [liminf, limsup] 内

5. **运算性质**：
   - limsup(aₙ+bₙ) ≤ limsup aₙ + limsup bₙ
   - liminf(aₙ+bₙ) ≥ liminf aₙ + liminf bₙ
   - 若 aₙ≥0, bₙ≥0，则 limsup(aₙbₙ) ≤ (limsup aₙ)(limsup bₙ)

6. **与极限的关系**：
   - 若 lim aₙ = a，则 limsup aₙ = liminf aₙ = a
   - 若 limsup aₙ = liminf aₙ = a（有限），则 lim aₙ = a

### 6.3 上下极限的几何理解

**📐 几何图像**：上下极限的几何图像是"点云的上边界和下边界的极限"。把数列 {aₙ} 画在数轴上（或 n-aₙ 平面上），上极限是"点云的最高凝聚点"——不管数列怎么振荡，它的"上边界"（从第 n 项起的最大值）随着 n 增大而下降，最终趋于一个值，这个值就是上极限。下极限是"点云的最低凝聚点"——下边界（从第 n 项起的最小值）随着 n 增大而上升，最终趋于一个值，这个值就是下极限。

如果上极限=下极限，说明点云的上边界和下边界趋于同一个点，点云凝聚到该点——数列收敛。如果上极限>下极限，说明点云在两个值之间振荡，没有凝聚到一个点——数列不收敛。

**另一种几何图像**：在 n-aₙ 平面上，上极限是"所有子列极限的最高点"，下极限是"最低点"。数列的所有收敛子列的极限都落在 [liminf, limsup] 这个区间内。

### 6.4 上下极限的应用

**应用 1：判断收敛性**
若能证明 limsup aₙ = liminf aₙ，则数列收敛。

**应用 2：处理不收敛的数列**
对于不收敛的有界数列，上下极限给出了"最好的上界和下界"——任何子列极限都在这个范围内。

**应用 3：证明不等式**
利用 limsup 和 liminf 的运算性质，可以证明一些极限不等式。

**例**：证明若 aₙ≥0 且 lim aₙ=a，则 lim ⁿ√(a₁a₂...aₙ)=a。
证明：取对数，令 bₙ=ln aₙ，则 lim bₙ=ln a。
需要证明 lim (b₁+...+bₙ)/n = ln a。
由 Stolz 定理（∞/∞ 型），lim (b₁+...+bₙ)/n = lim bₙ = ln a。
故 lim ⁿ√(a₁...aₙ) = e^{ln a} = a。

### 6.5 上下极限的例子

**例 1**：aₙ=(-1)ⁿ
- sup_{k≥n} a_k = 1（总是有偶数项=1）
- inf_{k≥n} a_k = -1（总是有奇数项=-1）
- limsup = 1, liminf = -1
- 不收敛

**例 2**：aₙ=1+(-1)ⁿ/n
- sup_{k≥n} a_k → 1（上界趋于 1）
- inf_{k≥n} a_k → 1（下界趋于 1）
- limsup = liminf = 1
- 收敛到 1

**例 3**：aₙ=sin(n)
- limsup = 1, liminf = -1（因为 {sin(n)} 在 [-1,1] 中稠密）
- 不收敛

## 第七章 Cauchy 列与实数完备性

### 7.1 Cauchy 列的定义

**定义**：若 ∀ε>0, ∃N∈ℕ, ∀m,n>N, |aₘ-aₙ|&lt;ε，则称 {aₙ} 是 Cauchy 列（基本列）。

**理解**：Cauchy 列是"数列自身的项之间最终任意接近"——不需要知道极限值，只要数列的尾巴内部足够紧密。

**与收敛的关系**：
- 收敛数列一定是 Cauchy 列（显然：|aₘ-aₙ|≤|aₘ-a|+|a-aₙ|&lt;ε/2+ε/2=ε）
- Cauchy 列不一定收敛（在不完备空间中，如 ℚ）
- 在实数系中，Cauchy 列一定收敛（Cauchy 收敛准则，即实数完备性）

### 7.2 Cauchy 收敛准则

**定理**：在实数系 ℝ 中，数列 {aₙ} 收敛 ⟺ {aₙ} 是 Cauchy 列。

**证明**：
- ⇒：已证（收敛⇒Cauchy）
- ⇐：设 {aₙ} 是 Cauchy 列。
  第一步：证明 {aₙ} 有界。取 ε=1，存在 N 使得 m,n>N 时 |aₘ-aₙ|&lt;1。特别地，n>N 时 |aₙ-a_{N+1}|&lt;1，故 |aₙ|&lt;|a_{N+1}|+1。取 M=max(|a₁|,...,|a_N|,|a_{N+1}|+1)，则 {aₙ} 有界。
  第二步：由 Bolzano-Weierstrass 定理，{aₙ} 有收敛子列 {a_{n_k}}，设 a_{n_k}→a。
  第三步：证明 aₙ→a。∀ε>0，由 Cauchy 性，存在 N₁ 使得 m,n>N₁ 时 |aₘ-aₙ|&lt;ε/2。由 a_{n_k}→a，存在 K 使得 k>K 时 |a_{n_k}-a|&lt;ε/2。取 N=max(N₁, n_K)，则 n>N 时，取 k>K 使得 n_k>N（因为 n_k→∞），有 |aₙ-a|≤|aₙ-a_{n_k}|+|a_{n_k}-a|&lt;ε/2+ε/2=ε。∎

**Cauchy 收敛准则的意义**：
1. **不需要知道极限值**：判断收敛性不需要先猜出极限值，只需要验证数列自身的"紧密性"
2. **等价于完备性**：Cauchy 收敛准则在 ℝ 中成立，本质上是因为 ℝ 是完备的。在不完备空间（如 ℚ）中，Cauchy 列不一定收敛
3. **是完备性的六种等价表述之一**：Cauchy 收敛准则 ⟺ 确界原理 ⟺ 单调有界定理 ⟺ 区间套定理 ⟺ 有限覆盖定理 ⟺ 聚点定理（见 D6-1）

### 7.3 Cauchy 列的几何理解

**📐 几何图像**：Cauchy 列的几何图像是"点云自身越来越紧密"。收敛数列的点云凝聚到目标点 a 附近——点云与 a 的距离趋于零。Cauchy 列的点云不需要参考外部目标点——它只要求点云内部的任意两点之间的距离趋于零。几何上，这意味着点云的"直径"（尾巴中任意两点的最大距离）趋于零。

在完备空间中，"自身越来越紧密"的点云一定凝聚到空间内的某个点——因为空间没有"针孔"，点云不会挤向一个不存在的点。在不完备空间（如 ℚ）中，Cauchy 列可以挤向一个"针孔"（如 √2），极限不在空间内，所以不收敛。

**另一种几何图像**：把数列看作一个人在数轴上"跳跃"——a₁→a₂→a₃→...。收敛意味着这个人最终停在 a 附近。Cauchy 意味着这个人的跳跃幅度最终任意小——不管他停在哪里，他的跳跃越来越小。在完备的数轴上，"跳跃越来越小"的人一定停在某个地方；在有"针孔"的数轴（如 ℚ）上，他可能挤向一个针孔而停不下来。

### 7.4 Cauchy 列的应用

**应用 1：判断收敛性（不需要极限值）**
例：证明 aₙ = 1 + 1/2² + 1/3² + ... + 1/n² 收敛。
证明：对 m>n，
|aₘ-aₙ| = 1/(n+1)² + ... + 1/m² &lt; 1/[n(n+1)] + ... + 1/[(m-1)m] = 1/n - 1/m &lt; 1/n
∀ε>0，取 N=⌈1/ε⌉，则 m,n>N 时 |aₘ-aₙ|&lt;1/n&lt;ε。故 {aₙ} 是 Cauchy 列，收敛。

**应用 2：证明实数完备性的等价定理**
Cauchy 收敛准则是实数完备性的等价表述之一，可以用来证明其他等价定理（如确界原理、区间套定理等）。

**应用 3：构造实数**
Cantor 用有理数 Cauchy 列的等价类来构造实数（见 D6-1）——每个实数对应一个有理数 Cauchy 列的等价类。

### 7.5 Cauchy 列与收敛的关系总结

| 空间 | 收敛⇒Cauchy | Cauchy⇒收敛 |
|---|---|---|
| ℝ（完备） | ✓ | ✓ |
| ℂ（完备） | ✓ | ✓ |
| ℚ（不完备） | ✓ | ✗（如 √2 的有理逼近数列是 Cauchy 但不收敛于 ℚ） |
| C[a,b] sup（完备） | ✓ | ✓ |
| C[a,b] Lp（不完备） | ✓ | ✗ |
| Lp（完备） | ✓ | ✓ |
| 任意完备度量空间 | ✓ | ✓ |
| 任意不完备度量空间 | ✓ | ✗ |

**核心结论**：收敛⇒Cauchy 在任何度量空间中都成立；Cauchy⇒收敛当且仅当空间完备。

## 第八章 递推数列的收敛性

### 8.1 递推数列的定义

**定义**：由递推关系 aₙ₊₁ = f(aₙ)（或更一般的 aₙ₊₁ = f(aₙ, aₙ₋₁, ...)）和初值 a₁ 定义的数列称为递推数列。

递推数列是分析学中最常见的数列类型之一——它出现在迭代法、动力系统、数值分析、概率模型等领域。

### 8.2 单调有界定理

**定理**：单调递增有上界的数列必收敛；单调递减有下界的数列必收敛。

**证明**：设 {aₙ} 单调递增有上界。由确界原理，{aₙ} 有上确界 a=sup{aₙ}。
∀ε>0，由上确界定义，存在 N 使得 a_N > a-ε（否则 a-ε 是上界，与 a 是上确界矛盾）。
由单调性，n>N 时 aₙ≥a_N>a-ε，又 aₙ≤a（上界），故 a-ε&lt;aₙ≤a&lt;a+ε，即 |aₙ-a|&lt;ε。∎

**几何理解**：单调递增的点在数轴上"向右移动"，但被上界"挡住"，所以只能越来越靠近某个点——上确界。

### 8.3 递推数列收敛性的分析方法

**方法一：单调有界定理**

步骤：
1. 证明数列单调（数学归纳法）
2. 证明数列有界（数学归纳法或不等式估计）
3. 由单调有界定理，数列收敛
4. 对递推式两边取极限，解方程求极限值

**例**：a₁=√2, aₙ₊₁=√(2+aₙ)
1. 单调性：a₂=√(2+√2)>√2=a₁。假设 aₙ>aₙ₋₁，则 aₙ₊₁=√(2+aₙ)>√(2+aₙ₋₁)=aₙ。故单调递增。
2. 有界性：a₁=√2&lt;2。假设 aₙ&lt;2，则 aₙ₊₁=√(2+aₙ)&lt;√(2+2)=2。故有上界 2。
3. 收敛，设极限为 a。对 aₙ₊₁=√(2+aₙ) 取极限：a=√(2+a)，解得 a=2（a=-1 舍去）。
故 lim aₙ=2。

**方法二：压缩映射原理（Banach 不动点定理）**

若递推函数 f 满足 Lipschitz 条件 |f(x)-f(y)|≤q|x-y|（0≤q&lt;1），则递推数列 aₙ₊₁=f(aₙ) 收敛到 f 的不动点。

**证明**：|aₙ₊₁-aₙ|=|f(aₙ)-f(aₙ₋₁)|≤q|aₙ-aₙ₋₁|≤...≤q^{n-1}|a₂-a₁|。
对 m>n，|aₘ-aₙ|≤Σ_{k=n}^{m-1}|a_{k+1}-a_k|≤|a₂-a₁|Σ_{k=n}^{m-1}q^{k-1}≤|a₂-a₁|q^{n-1}/(1-q)→0。
故 {aₙ} 是 Cauchy 列，收敛。∎

**例**：a₁=1, aₙ₊₁=(aₙ+2/aₙ)/2（求 √2 的迭代法）
f(x)=(x+2/x)/2，f'(x)=(1-2/x²)/2。在 x≥1 时，|f'(x)|≤1/2&lt;1，故压缩。
收敛到不动点 x=(x+2/x)/2，解得 x=√2。

**方法三：先猜后证**

1. 假设数列收敛，对递推式取极限，猜出极限值 a
2. 证明 aₙ→a（用 ε-N 定义或估计 |aₙ-a|）

**例**：a₁=1, aₙ₊₁=1+1/aₙ
假设收敛到 a，则 a=1+1/a，解得 a=(1+√5)/2（黄金分割比）。
证明 |aₙ-a|→0：|aₙ₊₁-a|=|1+1/aₙ-1-1/a|=|a-aₙ|/(aₙa)≤|aₙ-a|/a（因为 aₙ≥1），所以是压缩的，收敛。

### 8.4 递推数列的反例

**反例 1：单调但无界**
aₙ=n，单调递增但无上界，发散到 +∞。

**反例 2：有界但不单调**
aₙ=(-1)ⁿ，有界但不单调，不收敛。

**反例 3：递推数列不收敛**
a₁=2, aₙ₊₁=aₙ²-2
- a₁=2, a₂=2, a₃=2, ... 收敛到 2（初值敏感）
- a₁=0, a₂=-2, a₃=2, a₄=2, ... 收敛到 2
- a₁=1, a₂=-1, a₃=-1, ... 收敛到 -1
- 但对于某些初值（如 a₁=2.1），数列无界发散

**反例 4：周期递推**
a₁=1, aₙ₊₁=1/aₙ
- a₁=1, a₂=1, a₃=1, ... 收敛
- a₁=2, a₂=1/2, a₃=2, a₄=1/2, ... 周期为 2，不收敛

### 8.5 递推数列的几何理解

**📐 几何图像**：递推数列 aₙ₊₁=f(aₙ) 的几何图像是"蛛网图"（cobweb plot）。在 x-y 平面上画出 y=f(x) 和 y=x 两条曲线。从初值 a₁ 开始：
1. 从 (a₁, 0) 垂直到 (a₁, f(a₁))=(a₁, a₂)
2. 水平到 (a₂, a₂)（在 y=x 上）
3. 垂直到 (a₂, f(a₂))=(a₂, a₃)
4. 水平到 (a₃, a₃)
5. 重复...

这样形成的"蛛网"如果向 f(x) 与 y=x 的交点（不动点）螺旋收敛，则递推数列收敛；如果蛛网向外螺旋，则发散；如果蛛网在两个点之间循环，则周期振荡。

压缩映射原理在几何上是"f(x) 的图像比 y=x 平缓"——|f'(x)|&lt;1 意味着 f 的斜率小于 1，蛛网向内螺旋收敛。如果 |f'(x)|>1，f 的斜率大于 1，蛛网向外螺旋发散。

## 第九章 平均数列与特殊数列

### 9.1 算术平均数列

**定理（Cesàro 平均）**：若 aₙ→a，则 (a₁+a₂+...+aₙ)/n→a。

**证明**：∀ε>0，由 aₙ→a，存在 N₁ 使得 n>N₁ 时 |aₙ-a|&lt;ε/2。
令 Sₙ=Σ_{k=1}^n a_k。则 |Sₙ/n-a| = |Σ_{k=1}^n (a_k-a)|/n ≤ Σ_{k=1}^{N₁}|a_k-a|/n + Σ_{k=N₁+1}^n |a_k-a|/n
≤ C/n + (n-N₁)/n · ε/2 &lt; C/n + ε/2，其中 C=Σ_{k=1}^{N₁}|a_k-a| 是常数。
取 N=max(N₁, ⌈2C/ε⌉)，则 n>N 时 |Sₙ/n-a|&lt;ε/2+ε/2=ε。∎

**逆命题不成立**：算术平均收敛不蕴含原数列收敛。
反例：aₙ=(-1)ⁿ，算术平均 = [(-1)+1+...+(-1)ⁿ]/n → 0，但 aₙ 不收敛。

**几何理解**：算术平均是"平滑化"操作——它把数列的振荡"平均掉"。即使原数列在两个值之间振荡，算术平均也会趋于两个值的平均。收敛数列的算术平均趋于同一极限——因为尾巴都在 a 附近，平均后也在 a 附近。

### 9.2 几何平均数列

**定理**：若 aₙ>0 且 aₙ→a>0，则 ⁿ√(a₁a₂...aₙ)→a。

**证明**：取对数，令 bₙ=ln aₙ，则 bₙ→ln a。
由算术平均定理，(b₁+...+bₙ)/n→ln a。
即 ln(ⁿ√(a₁...aₙ))→ln a，故 ⁿ√(a₁...aₙ)→a。∎

**应用**：
- 若 aₙ→a>0，则 ⁿ√(aₙ)→1（取 a₁=...=aₙ=aₙ？不对，应该用几何平均定理的推论）
- 实际上，ⁿ√(aₙ)→1 可以直接证明：ln(ⁿ√aₙ)=ln aₙ/n→0

**例**：lim ⁿ√n = 1
证明：ln(ⁿ√n)=ln n/n→0（由 Stolz 或洛必达），故 ⁿ√n→1。

### 9.3 调和平均数列

**定理**：若 aₙ>0 且 aₙ→a>0，则 n/(1/a₁+...+1/aₙ)→a。

**证明**：令 bₙ=1/aₙ，则 bₙ→1/a。由算术平均定理，(b₁+...+bₙ)/n→1/a，故 n/(b₁+...+bₙ)→a。∎

### 9.4 三种平均的关系

对于正数列 {aₙ}，有：
调和平均 ≤ 几何平均 ≤ 算术平均

即：
n/(Σ1/a_k) ≤ ⁿ√(Πa_k) ≤ (Σa_k)/n

如果 aₙ→a>0，则三种平均都→a。

### 9.5 其他特殊数列

**斐波那契数列**：F₁=F₂=1, Fₙ₊₂=Fₙ₊₁+Fₙ
- Fₙ ~ φⁿ/√5，其中 φ=(1+√5)/2（黄金分割比）
- lim Fₙ₊₁/Fₙ = φ
- 证明：令 rₙ=Fₙ₊₁/Fₙ，则 rₙ=1+1/rₙ₋₁，递推收敛到 φ

**阶乘数列**：n!
- n! 增长极快，比任何指数函数都快
- Stirling 公式：n! ~ √(2πn)(n/e)ⁿ
- lim ⁿ√(n!)/n = 1/e（已在 Stolz 定理部分证明）

**指数数列**：aⁿ
- |a|&lt;1 时 aⁿ→0
- a=1 时 aⁿ→1
- |a|>1 时 |aⁿ|→∞
- a=-1 时不收敛（振荡）

**幂数列**：n^α
- α>0 时 n^α→∞
- α=0 时 n^α=1
- α&lt;0 时 n^α→0

**对数数列**：ln n
- ln n→∞，但比任何 n^α（α>0）都慢
- lim ln n/n^α = 0（α>0）

### 9.6 数列增长速度的比较

| 增长速度 | 数列类型 | 例子 |
|---|---|---|
| 极慢 | 迭代对数 | ln ln n |
| 慢 | 对数 | ln n, (ln n)^k |
| 中等 | 幂函数 | n^α (α>0) |
| 快 | 指数 | aⁿ (a>1) |
| 极快 | 阶乘 | n! |
| 极极快 | 迭代指数 | nⁿ, a^{aⁿ} |

**比较规则**：
- ln n = o(n^α)（α>0）
- n^α = o(aⁿ)（α>0, a>1）
- aⁿ = o(n!)（a>1）
- n! = o(nⁿ)

这些比较可以用 Stolz 定理或取对数后比较来证明。

## 第十章 数列极限的计算方法

### 10.1 方法总结

| 方法 | 适用场景 | 关键思想 |
|---|---|---|
| 定义法（ε-N） | 简单数列、证明题 | 直接验证定义 |
| 四则运算法 | 可分解为简单数列的四则运算 | 极限的四则运算 |
| 夹逼定理 | 数列被夹在两个简单数列之间 | 估计上下界 |
| 单调有界定理 | 递推数列、单调数列 | 证明单调+有界 |
| Stolz 定理 | ∞/∞ 型、0/0 型 | 差商的极限 |
| 变量替换 | 复杂递推可简化为简单递推 | 换元 |
| 取对数 | 乘积、幂、指数形式 | 对数化乘为加 |
| 递推求极限 | 递推数列 | 假设收敛+解方程+证明 |
| 压缩映射 | 递推函数 Lipschitz | 估计 |aₙ₊₁-aₙ|≤q|aₙ-aₙ₋₁| |
| 子列法 | 证明不收敛 | 找两个子列收敛到不同极限 |
| Cauchy 准则 | 不需要知道极限值 | 证明数列是 Cauchy 列 |
| 上下极限 | 有界不收敛数列 | 分析 limsup 和 liminf |
| 已知极限 | 标准极限的组合 | 利用已知结果 |

### 10.2 标准极限

以下是需要牢记的标准极限：

1. lim 1/n = 0
2. lim C = C（常数数列）
3. lim qⁿ = 0（|q|&lt;1）
4. lim ⁿ√a = 1（a>0）
5. lim ⁿ√n = 1
6. lim (1+1/n)ⁿ = e
7. lim (1+a/n)ⁿ = e^a
8. lim n^α/qⁿ = 0（α>0, q>1）
9. lim ln n/n = 0
10. lim (a₁+...+aₙ)/n = a（若 aₙ→a）
11. lim ⁿ√(a₁...aₙ) = a（若 aₙ→a>0）
12. lim Hₙ/n = 0（Hₙ 调和级数）
13. lim Hₙ/ln n = 1
14. lim ⁿ√(n!)/n = 1/e
15. lim Fₙ₊₁/Fₙ = φ（黄金分割比）

### 10.3 综合例题

**例 1**：limₙ→∞ (1+1/n)^{n²} / e^n
取对数：n² ln(1+1/n) - n = n²(1/n - 1/(2n²) + o(1/n²)) - n = n - 1/2 + o(1) - n = -1/2 + o(1)
故极限 = e^{-1/2}

**例 2**：limₙ→∞ Σ_{k=1}^n 1/√(n²+k)
夹逼：n/√(n²+n) ≤ Σ1/√(n²+k) ≤ n/√(n²+1)
左边 = 1/√(1+1/n)→1，右边 = 1/√(1+1/n²)→1
故极限 = 1

**例 3**：limₙ→∞ (1·3·5·...·(2n-1))/(2·4·6·...·2n)
令 aₙ = (2n-1)!!/(2n)!!
则 aₙ² = (1·3·...·(2n-1))²/(2·4·...·2n)²
由 Wallis 公式，aₙ ~ 1/√(πn)，故极限 = 0
（也可以用夹逼：aₙ &lt; 1/√(2n+1)，因为 (2k-1)/(2k) &lt; √((2k-1)/(2k+1))，乘积后 aₙ &lt; 1/√(2n+1)）

## 第十一章 反例库

### 11.1 收敛性质的反例

**反例 1：有界但不收敛**
aₙ=(-1)ⁿ。有界（|aₙ|=1）但不收敛（奇数项→-1，偶数项→1）。

**反例 2：单调但不收敛**
aₙ=n。单调递增但无上界，发散到 +∞。

**反例 3：收敛但不单调**
aₙ=(-1)ⁿ/n。收敛到 0，但不单调（在正负之间振荡）。

**反例 4：保号性的逆不成立**
aₙ=1/n>0 对所有 n，但极限=0（不是正数）。
说明：数列的项都是正数，极限可以是 0。

**反例 5：保不等式性的严格性**
aₙ=1/n &lt; 2/n=bₙ 对所有 n，但极限都是 0（a=b，不是 a&lt;b）。
说明：严格不等式的极限只能推出非严格不等式。

### 11.2 四则运算的反例

**反例 6：两个发散数列的和收敛**
aₙ=n, bₙ=-n。都发散，但 aₙ+bₙ=0 收敛。

**反例 7：两个发散数列的积收敛**
aₙ=(-1)ⁿ, bₙ=(-1)ⁿ。都发散，但 aₙbₙ=1 收敛。

**反例 8：0·∞ 不定式**
aₙ=1/n→0, bₙ=n→∞。aₙbₙ=1→1。
但 aₙ=1/n²→0, bₙ=n→∞ 时，aₙbₙ=1/n→0。
说明 0·∞ 型的极限不确定。

**反例 9：∞-∞ 不定式**
aₙ=n²+n→∞, bₙ=n²→∞。aₙ-bₙ=n→∞。
但 aₙ=n+1→∞, bₙ=n→∞ 时，aₙ-bₙ=1→1。
说明 ∞-∞ 型的极限不确定。

### 11.3 子列的反例

**反例 10：有收敛子列但原列不收敛**
aₙ=(-1)ⁿ。偶数项子列→1（收敛），但原列不收敛。

**反例 11：所有子列都有收敛子列但原列不收敛**
aₙ=(-1)ⁿ。任何子列要么全是奇数项（→-1），要么全是偶数项（→1），要么混合（有收敛子列）。但原列不收敛。
注意：这不是"所有子列都收敛"，而是"所有子列都有收敛子列"。

**反例 12：无界数列没有收敛子列**
aₙ=n。无界，任何子列也→∞，没有收敛子列。
（对比 Bolzano-Weierstrass：有界数列必有收敛子列）

### 11.4 Stolz 定理的反例

**反例 13：差商极限不存在但原极限存在**
aₙ=n+(-1)ⁿ, bₙ=n。lim aₙ/bₙ=1。
但 (aₙ₊₁-aₙ)/(bₙ₊₁-bₙ)=1+2(-1)ⁿ⁺¹ 振荡，极限不存在。
说明 Stolz 定理是充分条件，不是必要条件。

**反例 14：bₙ 不严格单调**
aₙ=n, bₙ=n+(-1)ⁿ。bₙ 不严格单调（b₂=3>b₁=0, b₃=2&lt;b₂=3）。
lim aₙ/bₙ=1，但 Stolz 定理不适用（bₙ 不严格单调）。

### 11.5 上下极限的反例

**反例 15：limsup+liminf 不等式的严格性**
aₙ=(-1)ⁿ, bₙ=(-1)ⁿ⁺¹。
limsup(aₙ+bₙ)=limsup 0=0。
limsup aₙ + limsup bₙ = 1+1=2。
0 ≤ 2，不等式成立但严格不等。

**反例 16：上下极限相等但数列不收敛（无界情形）**
在扩展实数系中，如果 limsup=liminf=+∞，则数列发散到 +∞（不收敛到有限数）。
所以"上下极限相等"只在有限值时等价于收敛。

### 11.6 Cauchy 列的反例

**反例 17：ℚ 中的 Cauchy 列不收敛**
aₙ = √2 的前 n 位小数近似（如 a₁=1.4, a₂=1.41, a₃=1.414, ...）。
{aₙ} 是 ℚ 中的 Cauchy 列，但极限 √2∉ℚ，所以在 ℚ 中不收敛。
说明 Cauchy⇒收敛依赖于空间的完备性。

**反例 18：不是 Cauchy 列但有收敛子列**
aₙ=(-1)ⁿ。不是 Cauchy 列（|aₘ-aₙ|=2 对奇偶不同的 m,n），但有收敛子列（偶数项→1）。
说明"有收敛子列"比"Cauchy 列"弱。

### 11.7 递推数列的反例

**反例 19：递推数列周期振荡**
a₁=2, aₙ₊₁=1/aₙ。a₁=2, a₂=1/2, a₃=2, a₄=1/2, ... 周期为 2，不收敛。

**反例 20：递推数列对初值敏感**
aₙ₊₁=aₙ²-2。
- a₁=2 → 恒为 2，收敛
- a₁=0 → -2, 2, 2, ... 收敛到 2
- a₁=2.1 → 无界发散
说明递推数列的收敛性对初值极其敏感（混沌现象的雏形）。

### 12.3 历史发展的主线

数列极限理论的历史发展有三条主线：

**主线一：严格化**
从无穷小（不严格）→ 柯西动态定义（半严格）→ 魏尔斯特拉斯 ε-N（严格）→ 实数构造（完全严格）。

**主线二：工具丰富化**
从基本性质（唯一性、有界性、保号性）→ 四则运算 → 子列定理 → Stolz 定理 → 上下极限 → Cauchy 准则 → 压缩映射原理。每一个新工具都扩展了我们能处理的数列类型。

**主线三：空间一般化**
从实数数列 → 复数数列 → 度量空间中的点列 → 函数空间中的点列（函数列）。Cauchy 收敛准则从实数的特殊性质变成了完备性的定义，Bolzano-Weierstrass 从实数定理变成了紧性的等价表述。

### 13.3 反例演化链

```

  ↓ 升维到函数空间

      └── 从"数值发散"变成"函数发散"

  ↓ 升维到函数空间
  └── C[a,b] Lp 中的 Cauchy 列（在 C[a,b] 中不收敛，完备化得到 Lp）
      └── 从"有理数的针孔"变成"不连续函数的针孔"
```

### 13.4 关键蜕变问题

**问题一：为什么数列极限是分析学的第一个严格理论？**

回答：因为数列最简单（只有一个趋向方向 n→∞）、最基础（函数极限通过 Heine 定理转化为数列极限，级数收敛是部分和数列的收敛）、最丰富（包含了分析学的核心思想：逼近、收敛、完备性、子列、上下极限）。数列极限理论是分析学的"训练基地"——在这里学会 ε-N 语言，理解收敛的本质，接触完备性。

**问题二：Cauchy 收敛准则为什么等价于完备性？**

回答：Cauchy 收敛准则说的是"自身越来越紧密的数列一定收敛"。在完备空间中，空间没有"针孔"，所以"自身越来越紧密"的点云一定凝聚到空间内的某个点。在不完备空间中，点云可以挤向一个"针孔"（不在空间内的点），所以不收敛。因此，"Cauchy 列都收敛"等价于"空间没有针孔"，即完备性。

**问题三：上下极限为什么总是存在？**

回答：上极限 = infₙ sup_{k≥n} a_k。sup_{k≥n} a_k 是单调递减的（n 增大时，取上确界的集合变小，上确界不增），有下界（因为数列有界），由单调有界定理，sup_{k≥n} a_k 收敛，其极限就是上极限。下极限类似。所以上下极限总是存在（对有界数列），不需要数列收敛。

**问题四：Stolz 定理的本质是什么？**

回答：Stolz 定理的本质是"离散版本的洛必达法则"——对于 ∞/∞ 型，aₙ/bₙ 的极限等于差商 (aₙ₊₁-aₙ)/(bₙ₊₁-bₙ) 的极限。这类似于连续情形下的洛必达法则 f(x)/g(x) ~ f'(x)/g'(x)。Stolz 定理的证明核心是"望远镜求和"——把 aₙ-a_N 表示为差商的加权平均，然后利用差商收敛到 L 来证明加权平均也收敛到 L。

### 14.3 常见误区清单

1. **有界数列收敛** → 错。有界不一定收敛（如 (-1)ⁿ），但有界数列有收敛子列。
2. **单调数列收敛** → 错。单调还需要有界（递增有上界或递减有下界）。
3. **aₙ>0 ⟹ lim aₙ>0** → 错。极限可以是 0（如 1/n>0 但极限=0）。
4. **aₙ&lt;bₙ ⟹ lim aₙ&lt;lim bₙ** → 错。只能推出 lim aₙ≤lim bₙ（如 1/n&lt;2/n 但极限都是 0）。
5. **两个发散数列的和发散** → 错。可以收敛（如 n + (-n)=0）。
6. **Stolz 定理是必要条件** → 错。是充分条件，差商极限不存在不代表原极限不存在。
7. **上下极限相等 ⟹ 收敛** → 只在有限值时成立。如果 limsup=liminf=±∞，则发散到 ±∞。
8. **Cauchy 列一定收敛** → 只在完备空间中成立。在不完备空间（如 ℚ）中，Cauchy 列不一定收敛。
9. **递推数列假设收敛后取极限就证明了收敛** → 错。假设收敛后取极限只能得到"如果收敛，极限是多少"，还需要单独证明收敛性。
10. **算术平均收敛 ⟹ 原数列收敛** → 错。如 (-1)ⁿ 的算术平均→0，但原数列不收敛。
11. **N 必须是最小的** → 错。N 只需要存在，不需要最小。
12. **ε 必须很小** → 错。ε 是任意正数，关键是"任意小"也要满足，但大的 ε 自然满足。

- 上下极限与函数的上下极限：前者是数列的，后者是函数的

- 单调有界定理与压缩映射原理：前者是递推数列收敛的充分条件，后者是更一般的不动点定理
- 算术平均定理与 Cesàro 求和：前者是数列的平均，后者是级数的求和

> **模块结语 · D1 极限领域核心理论**：
>
> 数列极限是分析学的第一个严格理论——它建立在 D1-1 的 ε-N 语言之上，包含了分析学的核心思想：逼近、收敛、完备性、子列、上下极限。
>
> 本模块从六个维度建立了数列极限的完整理论：
>
> **基本性质**：唯一性、有界性、保号性、保不等式性、迫敛性——收敛数列的尾巴凝聚在极限值附近，因此具有极限值的所有"局部性质"。
>
> **四则运算**：加、减、乘、除——两个凝聚的点云进行运算后仍然凝聚，但需要注意不定式（0/0、∞/∞、0·∞、∞-∞）不能直接用四则运算。
>
> **子列理论**：子列定理、Bolzano-Weierstrass 定理、收敛的子列判据——子列是分析数列收敛性的重要工具，找到两个收敛到不同极限的子列就能证明不收敛。
>
> **Stolz 定理**：∞/∞ 型和 0/0 型——离散版本的洛必达法则，通过差商的极限来求商的极限，是处理不定式的有力工具。
>
> **上下极限**：limsup 和 liminf——有界数列的"最高凝聚点"和"最低凝聚点"，总是存在，是分析不收敛数列的重要工具。
>
> **Cauchy 列与完备性**：Cauchy 收敛准则——不需要知道极限值就能判断收敛性，等价于空间的完备性。在 ℝ 中成立，在不完备空间（如 ℚ）中不成立。
>
> **递推数列**：单调有界定理、压缩映射原理、先猜后证——递推数列是最常见的数列类型，收敛性分析需要结合单调性、有界性、压缩性等多种方法。
>
> 数列极限理论的核心洞察是：**收敛的本质是"尾巴凝聚"，而判断收敛性有多种工具——基本性质、四则运算、子列、Stolz、上下极限、Cauchy 准则、单调有界、压缩映射**。每一种工具都有自己的适用场景，熟练掌握这些工具是学好分析学的基础。
>
> 下一步，D1-3 将深入研究函数极限与 Heine 定理——从离散的数列极限到连续的函数极限，Heine 定理建立了两者之间的桥梁。
