## L0 初等直觉层

> **引导语**：复数域上的极限从实轴扩展到复平面。复数列极限可以分解为实部和虚部两个实数列极限，但复平面的拓扑（开集、闭集、紧集、单连通）带来了全新的概念。这一层只有两道直觉题，关键是建立对复平面拓扑的直观感觉。

**【D1-5-001】** 用自己的话解释复数列极限的直觉含义。它和实数列极限有什么相同和不同？

- **难度**：★
- **对应知识点**：复数列极限的直觉理解
- **解答**：
  **相同点**：
  - 定义形式完全一样：∀ε>0, ∃N, ∀n>N, |zₙ-z₀|&lt;ε
  - 基本性质完全平行：唯一性、有界性、四则运算、Cauchy 准则
  - 收敛的直觉都是"点列向目标点凝聚"
  
  **不同点**：
  - 实数列在数轴上（一维），复数列在复平面上（二维）
  - 复数列收敛等价于实部和虚部分别收敛（两个实数列收敛）
  - 复数列有极坐标表示（模和辐角），收敛意味着模和辐角都收敛
  
  **几何图像**：实数列收敛是"数轴上的点向一个点靠近"；复数列收敛是"复平面上的点向一个点凝聚"——像一群鸟向同一个目标飞近。∎
- **一句话点评**：复数列极限就是"复平面上的点向目标点凝聚"——和实数列的直觉一样，只是从一维升级到二维。

**【D1-5-002】** 写出复数列极限的 ε-N 定义。为什么说复数列极限可以"完全转化为两个实数列极限"？

- **难度**：★
- **对应知识点**：复数列极限的定义
- **解答**：
  **定义**：设 {zₙ} 是复数列，z₀ 是复数。如果 ∀ε>0, ∃N∈ℕ, ∀n>N, |zₙ-z₀|&lt;ε，则称 {zₙ} 收敛于 z₀。
  
  **为什么可以转化为两个实数列极限**：
  设 zₙ=xₙ+iyₙ，z₀=x₀+iy₀。则
  |zₙ-z₀| = √[(xₙ-x₀)²+(yₙ-y₀)²]
  
  所以 zₙ→z₀ 等价于 √[(xₙ-x₀)²+(yₙ-y₀)²]→0，这又等价于 xₙ→x₀ 且 yₙ→y₀。
  
  **证明**：
  - ⇒：|xₙ-x₀|≤|zₙ-z₀|&lt;ε，|yₙ-y₀|≤|zₙ-z₀|&lt;ε，所以 xₙ→x₀, yₙ→y₀
  - ⇐：∀ε>0，存在 N₁ 使得 |xₙ-x₀|&lt;ε/√2，存在 N₂ 使得 |yₙ-y₀|&lt;ε/√2。取 N=max(N₁,N₂)，则 |zₙ-z₀|&lt;√[(ε/√2)²+(ε/√2)²]=ε。∎
- **一句话点评**：复数列收敛 = 实部收敛 + 虚部收敛——把一个二维问题拆成两个一维问题。

## L1 数学分析层

> **引导语**：从直觉到严格。这一层涵盖复数列极限计算、Cauchy列与完备性、复平面拓扑、复函数极限与Heine定理、内闭一致收敛。按计算、拓扑、定理的线索推进。

### 组A：复数列极限与完备性

**【D1-5-003】** 计算复数列 zₙ=(1/2+i/3)ⁿ 的极限。

- **难度**：★
- **对应知识点**：复数列极限的计算
- **解答**：
  先算模：|zₙ| = |1/2+i/3|ⁿ = (√(1/4+1/9))ⁿ = (√(13/36))ⁿ = (√13/6)ⁿ
  
  因为 √13/6 ≈ 3.606/6 ≈ 0.601 &lt; 1，所以 |zₙ|→0。
  
  模趋于 0 意味着复数列趋于 0（不管辐角怎么变）。
  
  所以 zₙ→0。∎
- **一句话点评**：模小于 1 的复数列，n 次方趋于 0——和实数列一样。

**【D1-5-004】** 判断复数列 zₙ=iⁿ 是否收敛。

- **难度**：★
- **对应知识点**：复数列的收敛性判断
- **解答**：
  zₙ=iⁿ 的值在四个值之间循环：
  - n=1: i
  - n=2: -1
  - n=3: -i
  - n=4: 1
  - n=5: i
  - ...
  
  实部 xₙ=cos(nπ/2) 在 1, 0, -1, 0 之间振荡，不收敛。
  虚部 yₙ=sin(nπ/2) 在 0, 1, 0, -1 之间振荡，不收敛。
  
  实部和虚部都不收敛，所以复数列不收敛。∎
- **一句话点评**：iⁿ 在四个方向上循环——实部和虚部都振荡，不收敛。

**【D1-5-006】** 计算复数列 zₙ=(1+i/n)ⁿ 的极限。

- **难度**：★★
- **对应知识点**：复数列极限的计算（极坐标法）
- **解答**：
  **方法一：极坐标法**
  模：|zₙ| = |1+i/n|ⁿ = (1+1/n²)^{n/2}
  ln|zₙ| = (n/2)·ln(1+1/n²) ≈ (n/2)·(1/n²) = 1/(2n) → 0
  所以 |zₙ|→e⁰=1。
  
  辐角：arg zₙ = n·arg(1+i/n) = n·arctan(1/n)
  当 n→∞ 时，arctan(1/n)≈1/n，所以 arg zₙ≈n·(1/n)=1。
  
  所以 zₙ→e^{i}=cos1+i sin1。
  
  **方法二：重要极限**
  (1+i/n)ⁿ → e^{i}（因为 (1+x/n)ⁿ→e^x 对复数 x 也成立）。∎
- **一句话点评**：(1+i/n)ⁿ → e^i——重要极限从实数推广到复数。

**【D1-5-007】** 证明：复数列 {zₙ} 收敛当且仅当它是 Cauchy 列。（复平面的完备性）

- **难度**：★★
- **对应知识点**：复平面的完备性
- **解答**：
  zₙ=xₙ+iyₙ。
  
  **必要性**（收敛 ⇒ Cauchy 列）：
  若 zₙ→z₀，则 xₙ→x₀, yₙ→y₀。因为实数列收敛 ⇒ 是 Cauchy 列，所以 {xₙ} 和 {yₙ} 都是 Cauchy 列。
  于是 |zₘ-zₙ| = √[(xₘ-xₙ)²+(yₘ-yₙ)²] ≤ |xₘ-xₙ|+|yₘ-yₙ| → 0。
  所以 {zₙ} 是 Cauchy 列。
  
  **充分性**（Cauchy 列 ⇒ 收敛）：
  若 {zₙ} 是 Cauchy 列，则 |xₘ-xₙ|≤|zₘ-zₙ|→0，|yₘ-yₙ|≤|zₘ-zₙ|→0。
  所以 {xₙ} 和 {yₙ} 都是实 Cauchy 列。由实数完备性，{xₙ} 和 {yₙ} 都收敛。
  设 xₙ→x₀, yₙ→y₀，则 zₙ=xₙ+iyₙ→x₀+iy₀=z₀。∎
- **一句话点评**：复平面是完备的——复数列收敛 ⟺ 是 Cauchy 列。完备性来自实数的完备性。

### 组B：复平面拓扑

**【D1-5-005】** 用自己的话解释什么是"复平面的拓扑"。为什么要在复分析中研究拓扑？

- **难度**：★
- **对应知识点**：复平面拓扑的直觉理解
- **解答**：
  **复平面的拓扑**：研究复平面上的"开集、闭集、紧集、连通性"等概念。这些概念描述的是复平面的"结构"——哪些点组成一个"整体"，哪些集合是"有限大小的"，等等。
  
  **为什么要在复分析中研究拓扑**：
  1. **定义域**：解析函数通常定义在"区域"（连通开集）上——这是拓扑概念
  2. **紧集上的性质**：紧集上的连续函数有很多好性质（有界、一致连续、取到最值）
  3. **单连通性**：很多重要定理（Cauchy 积分定理、原函数存在定理）只在单连通区域上成立
  
  **几何图像**：拓扑就是"橡皮膜上的几何学"——不关心距离和角度，只关心"哪些点连在一起"、"有没有洞"。∎
- **一句话点评**：复平面的拓扑就是"研究复平面的结构"——哪些点组成一个整体，哪些集合是有限大小的。

### ★★ 进阶应用

**【D1-5-008】** 解释什么是"紧集"。为什么说"复平面上的紧集 = 有界闭集"？

- **难度**：★★
- **对应知识点**：紧集的定义与性质
- **解答**：
  **紧集的定义**：设 K⊂ℂ。如果 K 的任意开覆盖都有有限子覆盖，则称 K 是紧集。
  - 开覆盖：一组开集，它们的并包含 K
  - 有限子覆盖：从这组开集中选出有限个，仍然覆盖 K
  
  **为什么紧集 = 有界闭集（Heine-Borel 定理）**：
  - **紧集 ⇒ 有界**：如果 K 无界，那么用一组越来越大的开圆盘覆盖 K，就没有有限子覆盖
  - **紧集 ⇒ 闭集**：如果 K 不闭，那么 K 有极限点不在 K 中，可以构造一个开覆盖没有有限子覆盖
  - **有界闭集 ⇒ 紧集**：这是 Heine-Borel 定理的核心结论，证明比较复杂
  
  **几何图像**：紧集就是"有限大小且边缘属于集合"的集合——闭圆盘就是紧集，开圆盘不是紧集（不闭），全平面不是紧集（无界）。∎
- **一句话点评**：紧集 = 有界闭集——"有限大小且边缘属于集合"。这是复分析中最重要的拓扑概念之一。

**【D1-5-009】** 判断以下集合是开集、闭集、还是都不是：
1. 开圆盘 {z : |z|&lt;1}
2. 闭圆盘 {z : |z|≤1}
3. 单位圆周 {z : |z|=1}
4. 半平面 {z : Re z>0}

- **难度**：★★
- **对应知识点**：开集与闭集的判断
- **解答**：
  1. **开圆盘 {|z|&lt;1}**：开集。每个点都有一个小圆盘完全包含在集合内。不是闭集（边界点 |z|=1 不在集合内）。
  
  2. **闭圆盘 {|z|≤1}**：闭集。包含所有极限点。不是开集（边界点没有小圆盘完全包含在集合内）。
  
  3. **单位圆周 {|z|=1}**：闭集。包含所有极限点。不是开集（每个点的任何小圆盘都有不在圆周上的点）。
  
  4. **半平面 {Re z>0}**：开集。每个点都有一个小圆盘完全在右半平面内。不是闭集（边界点 Re z=0 不在集合内）。∎
- **一句话点评**：开集 = 每个点都是内点；闭集 = 包含所有极限点。大多数集合既不是开集也不是闭集。

**【D1-5-010】** 解释什么是"单连通区域"。为什么说"圆环不是单连通的"？

- **难度**：★★
- **对应知识点**：单连通与多连通
- **解答**：
  **单连通区域的定义**：设 D 是区域（连通开集）。如果 D 中的任意简单闭曲线的内部都完全包含在 D 中，则称 D 是单连通的。
  - 直观理解：单连通区域没有"洞"——任意闭曲线都可以在区域内收缩到一个点
  
  **为什么圆环不是单连通的**：
  圆环 {z : r&lt;|z|&lt;R} 中间有一个"洞"（|z|≤r 的部分）。
  绕洞画一个闭曲线 |z|=(r+R)/2，这个闭曲线的内部包含了洞（|z|&lt;r 的部分不在 D 中）。
  所以圆环不是单连通的——它是"多连通"的（有一个洞）。
  
  **几何图像**：单连通就是"橡皮膜上没有洞"——任意画一个圈，都可以把圈缩小到一个点而不离开橡皮膜。如果有洞，绕洞画的圈就缩不小。∎
- **一句话点评**：单连通 = 没有洞；多连通 = 有洞。圆环有一个洞，所以不是单连通的。

### 组C：复函数极限与一致收敛

**【D1-5-011】** 证明：复函数极限的 Heine 定理。lim_{z→z₀} f(z)=A ⟺ 对任意满足 zₙ→z₀ 且 zₙ≠z₀ 的复数列 {zₙ}，都有 f(zₙ)→A。

- **难度**：★★★
- **对应知识点**：复函数极限的 Heine 定理
- **解答**：
  **必要性**（极限存在 ⇒ 任意数列极限存在）：
  设 lim_{z→z₀} f(z)=A。∀ε>0，存在 δ>0，使得 0&lt;|z-z₀|&lt;δ 时 |f(z)-A|&lt;ε。
  
  对任意 zₙ→z₀, zₙ≠z₀，存在 N，使得 n>N 时 0&lt;|zₙ-z₀|&lt;δ。
  于是 |f(zₙ)-A|&lt;ε。所以 f(zₙ)→A。
  
  **充分性**（任意数列极限存在 ⇒ 函数极限存在）：
  反证法。假设 lim_{z→z₀} f(z)≠A。则存在 ε₀>0，对任意 δ>0，存在 z 使得 0&lt;|z-z₀|&lt;δ 但 |f(z)-A|≥ε₀。
  
  取 δ=1/n，得到 zₙ 使得 0&lt;|zₙ-z₀|&lt;1/n 但 |f(zₙ)-A|≥ε₀。
  于是 zₙ→z₀ 但 f(zₙ)↛A，矛盾。∎
- **一句话点评**：复函数极限的 Heine 定理——和一元函数的 Heine 定理完全平行。

**【D1-5-012】** 证明：f(z)=z̄/z 在 z→0 时极限不存在。

- **难度**：★★★
- **对应知识点**：复函数极限的路径依赖性
- **解答**：
  **沿实轴 z=x→0**：
  f(x) = x̄/x = x/x = 1 → 1
  
  **沿虚轴 z=iy→0**：
  f(iy) = (iy)̄/(iy) = (-iy)/(iy) = -1 → -1
  
  沿两条路径趋近得到不同极限（1 vs -1），由路径判据，重极限不存在。∎
- **一句话点评**：z̄/z 在原点处沿实轴→1，沿虚轴→-1——路径依赖性的经典例子。

**【D1-5-013】** 解释什么是"内闭一致收敛"。它和"一致收敛"有什么区别？为什么复分析中常用"内闭一致收敛"？

- **难度**：★★★
- **对应知识点**：内闭一致收敛
- **解答**：
  **一致收敛**：∀ε>0, ∃N, ∀n>N, ∀z∈D, |fₙ(z)-f(z)|&lt;ε
  - 收敛速度在整个区域 D 上是均匀的
  
  **内闭一致收敛**：对任意紧子集 K⊂D，{fₙ} 在 K 上一致收敛
  - 收敛速度在每个紧子集上是均匀的
  
  **区别**：
  - 一致收敛要求在整个 D 上收敛速度均匀
  - 内闭一致收敛只要求在 D 的每个紧子集上收敛速度均匀
  - 一致收敛 ⇒ 内闭一致收敛，但反过来不成立
  
  **为什么复分析中常用内闭一致收敛**：
  复分析中的解析函数列通常在区域上内闭一致收敛，而不是一致收敛。这是因为区域是开集，边界附近函数可能发散（如幂级数在收敛圆内闭一致收敛，但在边界上可能发散）。
  
  **几何图像**：一致收敛是"整个画布上颜色均匀地变"；内闭一致收敛是"画布的每一个局部区域颜色均匀地变"——边缘可能不均匀，但中间每个小区域都是均匀的。∎
- **一句话点评**：一致收敛 = 整个区域均匀收敛；内闭一致收敛 = 每个紧子集均匀收敛。复分析中常用后者，因为开集边界附近可能不均匀。

**【D1-5-014】** 写出复函数连续性的 ε-δ 定义。它和二元实函数连续性有什么不同？

- **难度**：★
- **对应知识点**：复函数的连续性
- **解答**：
  **定义**：f(z) 在 z₀ 处连续，当且仅当 lim_{z→z₀} f(z) = f(z₀)。
  用 ε-δ 语言：∀ε>0, ∃δ>0, ∀z(|z-z₀|&lt;δ ⇒ |f(z)-f(z₀)|&lt;ε)。
  
  **与二元实函数连续性的不同**：
  形式上完全一样——都是把"距离"换成模。
  - 二元实函数：√[(x-x₀)²+(y-y₀)²]
  - 复函数：|z-z₀|
  
  实际上，复函数连续 ⟺ 它的实部和虚部作为二元实函数都连续。这和 D1-4 中讲的完全一样。
  
  **独特之处**：如果 f 是解析函数（满足 C-R 方程），那么 f 在定义域内处处连续。这是复分析特有的——"解析 ⇒ 连续"。∎
- **一句话点评**：复函数连续——和二元实函数连续形式完全一样。但解析函数自动连续，这是复分析特有的。

**【D1-5-015】** 解释什么是"解析函数列的一致收敛"。为什么说"Weierstrass 定理是复分析独有的强大定理"？

- **难度**：★
- **对应知识点**：Weierstrass 定理
- **解答**：
  **Weierstrass 定理**：设 {fₙ(z)} 是区域 D 上的解析函数列。如果 {fₙ} 在 D 上内闭一致收敛于 f(z)，则：
  1. f(z) 在 D 上解析
  2. {fₙ'}（导函数列）在 D 上内闭一致收敛于 f'(z)
  3. 更一般地，对任意 k，{fₙ^{(k)}} 内闭一致收敛于 f^{(k)}(z)
  
  **为什么是复分析独有的强大定理**：
  在实分析中，可导函数列的一致收敛极限不一定可导（如 fₙ(x)=sin(nx)/n 一致收敛到 0，但导函数列 cos(nx) 不收敛）。
  
  但在复分析中，解析函数列的内闭一致收敛极限不仅解析，而且各阶导数都收敛！这就是"解析刚性"。
  
  **几何图像**：解析函数是"保角映射"——它保持角度。一系列保角映射整体凝聚到一个极限映射，因为每个映射都保角，极限映射也必须保角，所以极限也是解析的。∎
- **一句话点评**：Weierstrass 定理是复分析独有的——解析函数列的内闭一致收敛极限仍然解析，且各阶导数都收敛。这就是"解析刚性"。

### ★★ 进阶应用

**【D1-5-016】** 证明：若 f(z)=u(x,y)+iv(x,y) 在 z₀ 处连续，则 u(x,y) 和 v(x,y) 都在 (x₀,y₀) 处连续。

- **难度**：★★
- **对应知识点**：复函数连续性的实部虚部分解
- **解答**：
  因为 |u(x,y)-u(x₀,y₀)| ≤ |f(z)-f(z₀)|，|v(x,y)-v(x₀,y₀)| ≤ |f(z)-f(z₀)|。
  
  对于任意 ε>0，存在 δ>0，使得 |z-z₀|&lt;δ 时 |f(z)-f(z₀)|&lt;ε。
  
  于是 |u-u₀| ≤ |f-f₀| &lt; ε，|v-v₀| ≤ |f-f₀| &lt; ε。
  
  所以 u 和 v 都在 (x₀,y₀) 处连续。∎
- **一句话点评**：复函数连续 ⇒ 实部和虚部分别连续——把二维问题拆成两个一维问题。

**【D1-5-017】** 计算 lim_{z→0} (e^z-1-z)/z²。

- **难度**：★★
- **对应知识点**：复极限的计算（幂级数展开）
- **解答**：
  e^z = 1 + z + z²/2! + z³/3! + ...
  
  (e^z-1-z)/z² = (z²/2 + z³/6 + ...)/z² = 1/2 + z/6 + ... → 1/2。
  
  所以极限=1/2。∎
- **一句话点评**：用幂级数展开计算复极限——解析函数的 Taylor 展开是最有力的工具。

**【D1-5-018】** 判断 lim_{z→0} e^{1/z} 是否存在。

- **难度**：★★
- **对应知识点**：复函数极限的路径依赖性
- **解答**：
  **沿正实轴 z=x→0⁺**：e^{1/x}→+∞。
  **沿负实轴 z=x→0⁻**：e^{1/x}=e^{-1/|x|}→0。
  
  两条路径趋势不同（无穷 vs 0），极限不存在。
  
  实际上，z=0 是 e^{1/z} 的本性奇点——在任意邻域内，e^{1/z} 可以取到任意复数值（Casorati-Weierstrass 定理）。∎
- **一句话点评**：e^{1/z} 在原点处沿正实轴→∞，沿负实轴→0——本性奇点的典型表现。

**【D1-5-019】** 解释为什么"解析函数列的内闭一致收敛极限仍然解析"在实分析中没有对应物。

- **难度**：★★
- **对应知识点**：解析刚性的理解
- **解答**：
  **实分析中的反例**：fₙ(x)=sin(nx)/n。
  - 每个 fₙ 都是可导的（甚至无穷可导）
  - fₙ 一致收敛到 0（因为 |sin(nx)/n|≤1/n→0）
  - 但导函数列 fₙ'(x)=cos(nx) 不收敛（在实轴上振荡）
  
  **为什么复分析中有 Weierstrass 定理而实分析中没有**：
  解析函数比实可导函数"刚性"得多——解析函数满足 C-R 方程，它的实部和虚部不是独立的，而是"耦合"在一起的。
  
  这种耦合使得解析函数的极限也必须满足 C-R 方程——所以极限也是解析的。
  
  实可导函数没有这种耦合——实函数的导数和函数值之间没有像 C-R 方程那样的强约束。所以实可导函数列的极限不一定可导。
  
  **几何图像**：解析函数是"保角映射"——它保持所有角度。一系列保角映射凝聚到一个极限，极限也必须保角，所以也是解析的。实可导函数只是"局部有切线"，不要求保持角度——所以极限可以"失去切线"。∎
- **一句话点评**：解析函数有 C-R 方程的强约束（实部和虚部耦合），所以极限也必须解析。实可导函数没有这种强约束，所以极限不一定可导。

### ★★★ 研究探索

**【D1-5-020】** 证明：复平面上的有界闭集是紧集。（Heine-Borel 定理的复平面版本）

- **难度**：★★★
- **对应知识点**：Heine-Borel 定理
- **解答**：
  这个证明比较复杂，我们给出思路。
  
  **思路**：
  1. 有界闭集 K 可以包含在一个大闭矩形 R 中
  2. 把 R 分成四个小矩形
  3. 如果 K 不是紧集，那么至少有一个小矩形中的 K 部分不是紧集（否则有限个小矩形就给出有限子覆盖）
  4. 继续分下去，得到一个矩形套，直径趋于 0
  5. 矩形套的交点 z₀∈K（因为 K 闭）
  6. 开覆盖中有一个开集 U 包含 z₀
  7. 因为 U 是开集，存在一个小圆盘包含在 U 中
  8. 当矩形套的直径足够小时，整个矩形都包含在这个小圆盘内，所以包含在 U 中
  9. 这说明 K 被有限个开集覆盖，矛盾。
  
  这个证明是 Bolzano-Weierstrass 定理和矩形套原理的应用。∎
- **一句话点评**：Heine-Borel 定理——有界闭集是紧集。证明思路是"二分法 + 矩形套原理"。

**【D1-5-021】** 解释为什么"单连通性"在复分析中如此重要。列出三个只在单连通区域上成立的重要定理。

- **难度**：★★★
- **对应知识点**：单连通性的重要性
- **解答**：
  **三个只在单连通区域上成立的重要定理**：
  
  1. **Cauchy 积分定理**：若 f 在单连通区域 D 内解析，则对 D 内任意闭曲线 γ，∮_γ f(z)dz=0。
     - 在多连通区域上，需要考虑"洞"周围的积分——绕洞一周的积分不一定为零。
  
  2. **原函数存在定理**：若 f 在单连通区域 D 内解析，则 f 在 D 内有原函数（即存在解析函数 F 使得 F'=f）。
     - 在多连通区域上，f 可能没有全局原函数（如 f(z)=1/z 在 ℂ\{0} 上没有全局原函数）。
  
  3. **对数函数的定义**：在单连通区域上，可以定义连续的对数分支。
     - 在多连通区域上，绕"洞"一周后对数会增加 2πi，无法定义全局单值对数。
  
  **为什么单连通性如此重要**：
  单连通意味着"没有洞"——任意两条连接相同端点的路径之间的区域完全在 D 内。所以积分与路径无关——这是 Cauchy 定理、原函数存在定理等的基础。∎
- **一句话点评**：单连通性 = 没有洞。没有洞 ⇒ 积分与路径无关 ⇒ Cauchy 定理、原函数存在定理等成立。

**【D1-5-022】** 证明：fₙ(z)=zⁿ 在单位圆盘 |z|&lt;1 内逐点收敛到 0，但不一致收敛。但它在内闭一致收敛。

- **难度**：★★★
- **对应知识点**：逐点收敛 vs 一致收敛 vs 内闭一致收敛
- **解答**：
  **逐点收敛**：对任意 |z|&lt;1，|z|ⁿ→0，所以 fₙ(z)→0。逐点收敛到 0。
  
  **不一致收敛**：
  取 zₙ=1-1/n（|zₙ|&lt;1）。
  fₙ(zₙ) = (1-1/n)ⁿ → e⁻¹ ≈ 0.368 ≠ 0。
  
  所以存在 z 使得 |fₙ(z)-0| 不趋于 0——不一致收敛。
  
  **内闭一致收敛**：
  对任意紧子集 K⊂{ |z|&lt;1 }，因为 K 是紧集且在开圆盘内，所以存在 r&lt;1 使得 K⊂{ |z|≤r }。
  
  在 { |z|≤r } 上，|fₙ(z)-0| = |z|ⁿ ≤ rⁿ→0。
  
  所以 fₙ 在 K 上一致收敛到 0。由 K 的任意性，fₙ 在单位圆盘内内闭一致收敛到 0。∎
- **一句话点评**：zⁿ 在单位圆盘内逐点收敛、内闭一致收敛，但不一致收敛——因为接近边界 z=1 时收敛很慢。

## L2 复变函数层

> **引导语**：复变函数的极限理论是复分析的基础。复函数的连续性可以分解为实部和虚部的连续性，解析函数列的一致收敛保持解析性，这是复分析独有的强大结果。

### ★ 基础巩固

**【D1-5-023】** 解释为什么复函数极限比二元实函数极限"更强"。这种"强"体现在哪里？

- **难度**：★
- **对应知识点**：复极限的方向自由度
- **解答**：
  **复函数极限"更强"的体现**：
  
  1. **复可导（解析）比二元实可微强得多**：
     - 二元实可微：沿任意方向的方向导数都存在，且可以用偏导数线性表示
     - 复可导：差商极限沿所有方向都相等——这蕴含了 C-R 方程
     - C-R 方程给函数施加了极强的约束：实部和虚部不是独立的，而是"耦合"在一起的
  
  2. **解析函数具有"刚性"**：
     - 解析 ⇒ 无穷可导（实可导不保证）
     - 解析 ⇒ 幂级数展开（实光滑不保证）
     - 唯一性定理：一小片信息确定整个函数
     - 最大值原理：非常数解析函数不在内部取最大值
  
  **几何图像**：复函数是"保角映射"——它保持角度。这种保角性非常强，使得解析函数的行为是"全局同步"的。∎
- **一句话点评**：复极限比二元实极限"更强"——因为复结构带来了 C-R 方程的强约束，导致解析函数的"刚性"。

### ★★ 进阶应用

**【D1-5-024】** 证明：若 f(z) 在区域 D 内解析，则 f(z) 在 D 内连续。

- **难度**：★★
- **对应知识点**：解析 ⇒ 连续
- **解答**：
  解析的定义：f 在 D 内每一点都可导。
  
  可导的定义：f'(z₀)=lim_{z→z₀} [f(z)-f(z₀)]/(z-z₀) 存在。
  
  令 g(z)=[f(z)-f(z₀)]/(z-z₀)。则 g(z)→f'(z₀)（当 z→z₀）。
  
  于是 f(z)-f(z₀) = g(z)·(z-z₀) → f'(z₀)·0 = 0（当 z→z₀）。
  
  所以 lim_{z→z₀} f(z) = f(z₀)。f 在 z₀ 处连续。
  
  由 z₀ 的任意性，f 在 D 内连续。∎
- **一句话点评**：解析 ⇒ 连续——和实函数中"可导 ⇒ 连续"类似，但复分析中"解析"比"可导"强得多。

### ★★★ 研究探索

**【D1-5-025】** 解释什么是"解析刚性"。列出至少四个体现解析刚性的性质。

- **难度**：★★★
- **对应知识点**：解析刚性
- **解答**：
  **解析刚性**：解析函数具有极强的性质——局部的行为决定全局的行为。这种"局部决定全局"的特性称为"解析刚性"。
  
  **体现解析刚性的性质**：
  
  1. **解析 ⇒ 无穷可导**：复可导一次就蕴含无穷次可导。这和实函数完全不同——实函数可导一次不保证可导两次。
  
  2. **解析 ⇒ 幂级数展开**：解析函数在定义域内每一点都有 Taylor 展开。这意味着解析函数的行为完全由它在某一点附近的各阶导数决定。
  
  3. **唯一性定理**：如果两个解析函数在区域 D 内的一个有聚点的集合上相等，那么它们在整个 D 上相等。一小片信息决定整个函数！
  
  4. **最大值原理**：非常数解析函数在区域内部不取最大值——最大值只能在边界上取到。这意味着解析函数的"最大高度"完全由边界决定。
  
  5. **Weierstrass 定理**：解析函数列的内闭一致收敛极限仍然解析，且各阶导数都收敛。
  
  **解析刚性的根源**：方向自由度。复可导要求差商极限沿所有方向都相等，这给函数施加了极强的约束（C-R 方程）。∎
- **一句话点评**：解析刚性 = 局部决定全局。解析函数的"一小片"信息就能决定整个函数的行为——这是复分析最独特的性质。

## L3 实变函数层

> **引导语**：从复平面到一般拓扑空间。极限概念在拓扑空间中通过开集和邻域来定义，完备性和紧性是拓扑空间的核心性质。

### ★ 基础巩固

**【D1-5-026】** 解释为什么复平面 ℂ 是完备的度量空间。它和实数轴 ℝ 的完备性有什么关系？

- **难度**：★
- **对应知识点**：复平面的完备性
- **解答**：
  **复平面的完备性**：复数列 {zₙ} 收敛 ⟺ {zₙ} 是 Cauchy 列。
  
  **与实数完备性的关系**：
  zₙ=xₙ+iyₙ。{zₙ} 是 Cauchy 列 ⟺ {xₙ} 和 {yₙ} 都是实 Cauchy 列 ⟺ {xₙ} 和 {yₙ} 都收敛（实数完备性）⟺ {zₙ} 收敛。
  
  所以复平面的完备性直接来自实数的完备性——ℂ≅ℝ²，有限个完备空间的乘积仍然完备。
  
  **几何图像**：完备性就是"空间没有缝隙"。ℝ 没有缝隙，所以 ℝ² 也没有缝隙——任何 Cauchy 列都凝聚到空间内的某个点。∎
- **一句话点评**：复平面是完备的——因为 ℝ 是完备的。有限个完备空间的乘积仍然完备。

### ★★ 进阶应用

**【D1-5-027】** 解释什么是"道路连通"。为什么说"复平面上的开集连通 ⟺ 道路连通"？

- **难度**：★★
- **对应知识点**：连通性与道路连通
- **解答**：
  **道路连通的定义**：如果对集合 S 中任意两点 z₁,z₂，都存在连续曲线 γ:[0,1]→S 使得 γ(0)=z₁, γ(1)=z₂，则称 S 是道路连通的。
  
  **为什么复平面上的开集连通 ⟺ 道路连通**：
  这是 ℝⁿ（n≥2）中开集的特殊性质。证明思路：
  
  设 D 是开集且连通。取 z₀∈D，令 A 为 D 中所有可以用 D 内的连续曲线连接到 z₀ 的点的集合。
  
  - A 是开集：因为 D 是开集，对任意 z∈A，存在一个小圆盘包含在 D 中。小圆盘内的点都可以用直线连接到 z，所以也可以连接到 z₀。
  - D\A 也是开集：同理。
  
  因为 D 连通，所以 A 和 D\A 不能同时非空（否则 D 分成两个不相交的开集）。所以 D\A=∅，即 D=A。
  
  所以 D 中任意点都可以用 D 内的连续曲线连接到 z₀——D 是道路连通的。∎
- **一句话点评**：复平面上的开集连通 ⟺ 道路连通——这是 ℝⁿ 中开集的特殊性质。

### ★★★ 研究探索

**【D1-5-028】** 解释什么是"正规族"。它和复平面的紧性有什么关系？

- **难度**：★★★
- **对应知识点**：正规族与 Montel 定理
- **解答**：
  **正规族的定义**：设 F 是区域 D 上的解析函数族。如果 F 中的任意函数列都有内闭一致收敛的子列，则称 F 是正规族。
  
  **Montel 定理**：如果解析函数族 F 在 D 上内闭一致有界（即对任意紧子集 K⊂D，存在 M_K 使得 |f(z)|≤M_K 对所有 f∈F, z∈K 成立），则 F 是正规族。
  
  **与复平面紧性的关系**：
  正规族是"函数空间中的紧性"——函数族 F 中的任意序列都有收敛子列，这和紧集中的任意序列都有收敛子列（Bolzano-Weierstrass）是类似的。
  
  由 Weierstrass 定理，正规族的极限也是解析函数。
  
  **几何图像**：正规族就是"函数空间中的紧集"——函数族中的函数不会"跑散"，它们凝聚在一个"紧"的范围内。∎
- **一句话点评**：正规族 = 函数空间中的紧集。Montel 定理说：内闭一致有界 ⇒ 正规族。这是复分析中紧性理论的核心。

## 补充基础题（L1 数学分析 / L2 复变函数 / L3 实变函数）

> **引导语**：针对三个阶段补充基础题。L1 侧重复数列极限和拓扑，L2 侧重复函数连续性，L3 侧重拓扑空间和紧性。

### L1 数学分析基础

**【D1-5-036】** 证明：复数列 $z_n=\left(1+\frac{i}{n}\right)^n$ 收敛，并求其极限。

- **难度**：★★
- **解答**：$|z_n|=\left(1+\frac{1}{n^2}\right)^{n/2}\to e^0=1$。辐角 $\arg z_n=n\arctan\frac{1}{n}\to n\cdot\frac{1}{n}=1$。
故 $z_n\to e^{i}=\cos1+i\sin1$。
严格证明：$z_n=e^{n\log(1+i/n)}=e^{n(i/n+O(1/n^2))}=e^{i+O(1/n)}\to e^i$。∎
- **点评**：复数版的 $(1+1/n)^n\to e$——模和辐角分别取极限，再组合成复数。

**【D1-5-037】** 证明：若 $\sum|z_n|$ 收敛，则 $\sum z_n$ 收敛（复数级数的绝对收敛蕴含收敛）。

- **难度**：★
- **解答**：设 $z_n=x_n+iy_n$。$|x_n|\leq|z_n|$，$|y_n|\leq|z_n|$，故 $\sum|x_n|$ 和 $\sum|y_n|$ 都收敛。
由实数级数绝对收敛蕴含收敛，$\sum x_n$ 和 $\sum y_n$ 都收敛。
故 $\sum z_n=\sum x_n+i\sum y_n$ 收敛。∎
- **点评**：复数级数绝对收敛→收敛，证明通过分解为实部虚部两个实数级数。

**【D1-5-038】** 求极限：$\lim_{n\to\infty}\sqrt[n]{|i^n+2^n|}$。

- **难度**：★★
- **解答**：$|i^n+2^n|=|2^n(1+(i/2)^n)|=2^n|1+(i/2)^n|$。
$\sqrt[n]{|i^n+2^n|}=2\cdot|1+(i/2)^n|^{1/n}$。
$|1+(i/2)^n|\to1$（因为 $|i/2|=1/2<1$），故 $|1+(i/2)^n|^{1/n}\to1^0=1$。
极限为 2。∎
- **点评**：这是根值判别法的典型计算——主导项 $2^n$ 决定了根值极限。

**【D1-5-039】** 证明：复数域 $\mathbb{C}$ 是完备的——每个 Cauchy 复数列都收敛。

- **难度**：★★
- **解答**：设 $\{z_n\}$ 是 Cauchy 复数列，$z_n=x_n+iy_n$。
$|x_m-x_n|\leq|z_m-z_n|$，$|y_m-y_n|\leq|z_m-z_n|$，故 $\{x_n\}$ 和 $\{y_n\}$ 都是实数 Cauchy 列。
由实数完备性，$x_n\to x$，$y_n\to y$。故 $z_n\to x+iy\in\mathbb{C}$。∎
- **点评**：复数域的完备性来自实数域的完备性——实部虚部分别是实 Cauchy 列，分别收敛后组合成复极限。

### L2 复变函数基础

**【D1-5-040】** 证明：开圆盘 $D(a,r)=\{z:|z-a|<r\}$ 是开集。

- **难度**：★
- **解答**：任取 $z_0\in D(a,r)$，则 $|z_0-a|=r_0<r$。取 $\delta=r-r_0>0$。
对任意 $z$ 满足 $|z-z_0|<\delta$，有 $|z-a|\leq|z-z_0|+|z_0-a|<\delta+r_0=r$，故 $z\in D(a,r)$。
所以 $D(z_0,\delta)\subset D(a,r)$，$z_0$ 是内点。由 $z_0$ 任意，$D(a,r)$ 是开集。∎
- **点评**：开集的定义——每个点都是内点（存在一个完全包含在集合内的开圆盘）。

**【D1-5-041】** 证明：集合 $E=\{z:|z|\leq1\}$ 是紧集（用 Heine-Borel 定理）。

- **难度**：★★
- **解答**：Heine-Borel 定理：$\mathbb{C}$（同胚于 $\mathbb{R}^2$）中集合紧 ⟺ 闭且有界。
有界：$|z|\leq1$ 对所有 $z\in E$，故有界。
闭：$E$ 的补集 $\{z:|z|>1\}$ 是开集（类似 D1-5-040 的证明），故 $E$ 是闭集。
由 Heine-Borel，$E$ 是紧集。∎
- **点评**：复平面上的紧集 = 闭且有界（Heine-Borel）。闭单位圆盘是最基本的紧集例子。

**【D1-5-042】** 证明：若 $K\subset\mathbb{C}$ 是紧集，$f:K\to\mathbb{C}$ 连续，则 $f$ 在 $K$ 上一致连续。

- **难度**：★★
- **解答**：反证。若不一致连续，则 $\exists\varepsilon_0>0$，$\forall n$，$\exists z_n,w_n\in K$ 使 $|z_n-w_n|<1/n$ 但 $|f(z_n)-f(w_n)|\geq\varepsilon_0$。
由 $K$ 紧，$\{z_n\}$ 有收敛子列 $z_{n_k}\to z\in K$。则 $w_{n_k}\to z$ 也（因为 $|z_{n_k}-w_{n_k}|<1/n_k\to0$）。
由 $f$ 连续，$f(z_{n_k})\to f(z)$，$f(w_{n_k})\to f(z)$，故 $|f(z_{n_k})-f(w_{n_k})|\to0$，矛盾。∎
- **点评**：紧集上的连续函数一致连续——这是复分析中的基本定理，证明用紧性提取收敛子列。

### L3 实变函数基础

**【D1-5-043】** 证明：复值函数 $f=u+iv$ 可测当且仅当 $u,v$ 都可测。

- **难度**：★
- **解答**：若 $f$ 可测，则对任意开集 $U\subset\mathbb{C}$，$f^{-1}(U)$ 可测。
取 $U=\{x+iy:x>a\}$（右半平面平移），则 $f^{-1}(U)=\{x:u(x)>a\}$ 可测，故 $u$ 可测。同理 $v$ 可测。
反之若 $u,v$ 可测，则 $f=(u,v):X\to\mathbb{R}^2$ 可测（可测函数的笛卡尔积可测），而 $\mathbb{C}$ 与 $\mathbb{R}^2$ 同胚，故 $f$ 可测。∎
- **点评**：复可测函数 = 实部虚部都可测——这是复值函数可测性的基本判据。

**【D1-5-044】** 设 $f=u+iv\in L^1(\mu)$（复值可积函数）。定义 $\int f d\mu=\int u d\mu+i\int v d\mu$。证明 $|\int f d\mu|\leq\int|f|d\mu$。

- **难度**：★★
- **解答**：设 $\int f d\mu=re^{i\theta}$（极坐标），则 $e^{-i\theta}\int f d\mu=r=|\int f d\mu|$ 是实数。
$|\int f d\mu|=e^{-i\theta}\int f d\mu=\int e^{-i\theta}f d\mu=\int\text{Re}(e^{-i\theta}f)d\mu$（因为左边是实数，虚部积分为0）。
$\text{Re}(e^{-i\theta}f)\leq|e^{-i\theta}f|=|f|$，故 $\int\text{Re}(e^{-i\theta}f)d\mu\leq\int|f|d\mu$。∎
- **点评**：复值积分的三角不等式——证明技巧是乘以 $e^{-i\theta}$ 把积分旋转到正实轴上。

**【D1-5-045】** 叙述复值函数的控制收敛定理（DCT），并说明它与实值 DCT 的关系。

- **难度**：★
- **解答**：复值 DCT：若 $f_n\to f$ a.e.，$|f_n|\leq g$ a.e.，$g\in L^1$，则 $\int f_n d\mu\to\int f d\mu$。
证明：设 $f_n=u_n+iv_n$，$f=u+iv$。$|u_n|\leq|f_n|\leq g$，$|v_n|\leq g$。由实值 DCT，$\int u_n\to\int u$，$\int v_n\to\int v$。故 $\int f_n=\int u_n+i\int v_n\to\int u+i\int v=\int f$。∎
- **点评**：复值 DCT 是实值 DCT 的直接推论——分解为实部虚部分别应用实值 DCT。

## 跨领域综合题

> **引导语**：复数域上的极限是连接实分析和复分析的桥梁。Heine 定理在复平面依然成立，Weierstrass 定理是复分析独有的强大结果，单连通性是许多复分析定理的前提。

> 定位：串联多个概念领域的综合题，培养全局视野和数学思考的"爽感"。

### 一、经典名题（做一遍爽一遍）

**【D1-5-CROSS-029】**（D1 × D8 解析 × D6 完备性）**Weierstrass 定理的深层意义**：为什么说 Weierstrass 定理是"解析刚性"的最强体现？它如何体现了"局部决定全局"？

- **难度**：★★★
- **对应知识点**：Weierstrass 定理（D8）、解析刚性（D8）、完备性（D6）
- **来源**：复分析最深刻的定理之一
- **解答**：
  **Weierstrass 定理如何体现解析刚性**：
  
  1. **极限保持解析性**：解析函数列的内闭一致收敛极限仍然解析。这意味着"解析性"这个性质在极限运算下是封闭的——这是实分析中没有的。
  
  2. **导数收敛**：不仅极限解析，而且各阶导数都内闭一致收敛到极限函数的对应阶导数。这意味着"所有阶的变化率"也一起收敛——这是"刚性"的最强体现。
  
  3. **局部决定全局**：Weierstrass 定理的证明用到了 Cauchy 积分公式——而 Cauchy 积分公式说的是"函数在圆盘内的值完全由边界上的值决定"。这本身就是"局部决定全局"的体现。
  
  **与完备性的联系**：
  Weierstrass 定理的证明依赖于复平面的完备性——Cauchy 积分公式的推导需要完备性。所以 Weierstrass 定理的"刚性"，根源在于复平面的完备性。
  
  **几何图像**：解析函数是"保角映射"。一系列保角映射整体凝聚到一个极限映射——因为每个映射都保角，极限也必须保角，所以极限也是解析的。而且，保角映射的"变形率"（导数）也必须凝聚——因为保角性不仅要求保持角度，还要求局部的缩放和旋转是连续的。∎
- **一句话点评**：Weierstrass 定理 = 解析刚性的最强体现。极限保持解析性 + 各阶导数收敛 = 局部决定全局的最深刻体现。

**【D1-5-CROSS-030】**（D1 × D6 完备性 × D7 三角学）**复数列收敛与模和辐角**：为什么说"模收敛 + 辐角收敛 = 复数列收敛"？这和极坐标变换有什么关系？

- **难度**：★★★
- **对应知识点**：复数列收敛（D1）、极坐标表示（D7）
- **来源**：复数的极坐标表示
- **解答**：
  **模收敛 + 辐角收敛 = 复数列收敛**：
  设 zₙ=rₙe^{iθₙ}, z=re^{iθ}（r>0）。则 zₙ→z ⟺ rₙ→r 且 θₙ→θ（mod 2π）。
  
  **证明思路**：
  |zₙ-z| = |rₙe^{iθₙ}-re^{iθ}|
  由三角不等式：||zₙ|-|z|| ≤ |zₙ-z|，所以模收敛是必要的。
  
  模收敛保证了"径向"的收敛，辐角收敛保证了"角向"的收敛。两者结合，点就凝聚到目标点。
  
  **与极坐标变换的关系**：
  极坐标变换 x=r cosθ, y=r sinθ 把直角坐标转化为极坐标。复数列收敛在极坐标下就是"径向距离收敛 + 角度收敛"。
  
  **几何图像**：复平面上的点用极坐标表示就是"到原点的距离 r"和"与 x 轴的夹角 θ"。复数列收敛就是"距离趋于固定值"且"角度趋于固定值"——像一群鸟既靠近目标的距离，又对准目标的方向。∎
- **一句话点评**：复数列收敛 = 模收敛 + 辐角收敛。径向和角向都收敛，点才真正凝聚到目标。

### 二、定理串联型（多领域协同的爽感）

**【D1-5-CROSS-031】**（D1 × D6 完备性 × D8 解析）**复平面的完备性与 Cauchy 积分定理**：为什么说复平面的完备性是 Cauchy 积分定理的基础？

- **难度**：★★★
- **对应知识点**：复平面完备性（D6）、Cauchy 积分定理（D8）
- **来源**：复分析的基础定理
- **解答**：
  **复平面完备性与 Cauchy 积分定理的关系**：
  
  1. **Cauchy 积分定理的证明需要完备性**：
     Cauchy 积分定理的证明通常用到"多边形逼近"或"矩形套"等方法——这些方法都依赖于复平面的完备性。
  
  2. **完备性保证了极限的存在性**：
     Cauchy 积分定理的各种证明中，都需要取极限（如把闭曲线分成很多小弧段，然后取极限）。完备性保证了这些极限存在。
  
  3. **解析刚性依赖于完备性**：
     Weierstrass 定理、唯一性定理等"解析刚性"的性质，根源在于复平面的完备性。而 Cauchy 积分定理是解析刚性的基础。
  
  **几何图像**：完备性就是"空间没有缝隙"。复平面没有缝隙，所以我们可以放心地取极限——任何"无限细分"的过程都会凝聚到一个确定的结果。如果复平面有缝隙，Cauchy 积分定理就可能不成立——因为某些极限"掉到缝隙里"去了。∎
- **一句话点评**：复平面的完备性是 Cauchy 积分定理的基础——没有"没有缝隙的空间"，就没有可靠的极限运算。

**【D1-5-CROSS-032】**（D1 × D8 解析 × D3 微分）**从方向自由度到解析刚性**：为什么说"方向自由度"是解析刚性的根源？

- **难度**：★★★
- **对应知识点**：方向自由度（D1）、C-R 方程（D3）、解析刚性（D8）
- **来源**：复分析最深刻的洞察之一
- **解答**：
  **方向自由度如何导致解析刚性**：
  
  1. **复可导要求所有方向的差商极限都相等**：
     复可导的定义是 f'(z₀)=lim_{z→z₀} [f(z)-f(z₀)]/(z-z₀) 存在——这里 z 可以沿任意方向趋近 z₀。
  
  2. **所有方向差商相等 ⇒ C-R 方程**：
     沿实轴方向趋近，差商极限 = u_x + i v_x。
     沿虚轴方向趋近，差商极限 = (1/i)(u_y + i v_y) = v_y - i u_y。
     两者相等 ⇒ u_x = v_y, v_x = -u_y（C-R 方程）。
  
  3. **C-R 方程 ⇒ 极强的约束**：
     C-R 方程把实部和虚部"耦合"在一起——u 和 v 不是独立的，而是满足微分方程组。
     这种耦合使得解析函数具有极强的性质：无穷可导、幂级数展开、唯一性定理、最大值原理等。
  
  **几何图像**：方向自由度就是"所有方向都必须一致"。复可导要求沿所有方向的"变化率"都相同——这给函数施加了极强的约束。就像一个军队，所有方向的行军速度都必须一致——这种严格的一致性，使得整个军队的行为非常"刚性"。∎
- **一句话点评**：方向自由度 ⇒ C-R 方程 ⇒ 解析刚性。所有方向的变化率都必须一致——这就是复分析"刚性"的根源。

**【D1-5-CROSS-033】**（D1 × D2 连续 × D6 完备性）**紧集上的连续函数**：为什么说"紧集上的连续函数有很多好性质"？列出至少三个这样的性质。

- **难度**：★★★
- **对应知识点**：紧集（D6）、连续函数（D2）
- **来源**：分析学的基本定理
- **解答**：
  **紧集上连续函数的好性质**：
  
  1. **有界性**：紧集 K 上的连续函数 f 有界（即存在 M 使得 |f(z)|≤M 对所有 z∈K 成立）。
     - 证明思路：如果 f 无界，则存在点列 zₙ∈K 使得 |f(zₙ)|→∞。但 K 是紧集，{zₙ} 有收敛子列 z_{n_k}→z₀∈K。由连续性，f(z_{n_k})→f(z₀)，矛盾。
  
  2. **取到最大值和最小值**：紧集 K 上的连续函数 f 取到最大值和最小值。
     - 证明思路：由有界性，f 有上确界 M。取点列 zₙ 使得 f(zₙ)→M。由紧性，{zₙ} 有收敛子列 z_{n_k}→z₀∈K。由连续性，f(z₀)=M。
  
  3. **一致连续性**：紧集 K 上的连续函数 f 一致连续。
     - 证明思路：用反证法 + 紧性。如果 f 不一致连续，存在 ε₀>0 和点列 zₙ,wₙ∈K 使得 |zₙ-wₙ|→0 但 |f(zₙ)-f(wₙ)|≥ε₀。由紧性，{zₙ} 有收敛子列 z_{n_k}→z₀∈K。于是 w_{n_k}→z₀。由连续性，f(z_{n_k})→f(z₀), f(w_{n_k})→f(z₀)，矛盾。
  
  **几何图像**：紧集就是"有限大小且边缘属于集合"的集合。在这样的集合上，连续函数的行为是"受控"的——不会突然变得很大或很小，不会突然"跳变"。∎
- **一句话点评**：紧集上的连续函数 = 有界 + 取到最值 + 一致连续。紧性保证了连续函数的行为是"受控"的。

### 三、基础综合（保留）

**【D1-5-CROSS-034】**（D1 × D7 三角学）设 zₙ=rₙe^{iθₙ}，证明：若 rₙ→r 且 θₙ→θ，则 zₙ→re^{iθ}。

- **难度**：★★
- **对应知识点**：复数列收敛的极坐标判据（D7 联动）
- **来源**：概念综合题
- **解答**：
  |zₙ-z| = |rₙe^{iθₙ}-re^{iθ}|
  
  由三角不等式：|rₙe^{iθₙ}-re^{iθ}| ≤ |rₙe^{iθₙ}-re^{iθₙ}| + |re^{iθₙ}-re^{iθ}|
  = |rₙ-r|·|e^{iθₙ}| + r·|e^{iθₙ}-e^{iθ}|
  = |rₙ-r| + r·|e^{iθₙ}-e^{iθ}|
  
  第一项 |rₙ-r|→0（因为 rₙ→r）。
  
  第二项：|e^{iθₙ}-e^{iθ}| = √[(cosθₙ-cosθ)²+(sinθₙ-sinθ)²] → 0（因为 θₙ→θ，余弦和正弦都是连续函数）。
  
  所以 |zₙ-z|→0，即 zₙ→z。∎
- **一句话点评**：模收敛 + 辐角收敛 = 复数列收敛。径向和角向都收敛，点就凝聚到目标。

**【D1-5-CROSS-035】**（D1 × D8 解析）设 f(z) 在区域 D 内解析，且 f'(z)=0 对所有 z∈D 成立。证明 f(z) 在 D 内是常数。

- **难度**：★★
- **对应知识点**：解析函数的导数（D8 联动）
- **来源**：概念综合题
- **解答**：
  因为 f 解析，所以 u 和 v 满足 C-R 方程：
  u_x = v_y, v_x = -u_y
  
  又 f'(z)=u_x + i v_x = 0，所以 u_x=0, v_x=0。
  
  由 C-R 方程，u_y = -v_x = 0，v_y = u_x = 0。
  
  所以 u 和 v 的所有偏导数都为零——u 和 v 都是常数。
  
  所以 f=u+iv 是常数。∎
- **一句话点评**：解析函数的导数处处为零 ⇒ 函数是常数。这是 C-R 方程的直接推论。

## 本模块易错点总结

1. **复数列收敛 ⟺ 实部虚部分别收敛**：这是复数列极限的核心定理——把二维问题拆成两个一维问题。

2. **模收敛 ≠ 复数列收敛**：模收敛只是必要条件，不是充分条件。还需要辐角收敛。

3. **复函数极限 = 二元实函数极限**：形式上完全一样，只是把距离换成模。路径依赖性、累次极限等概念都可以直接应用。

4. **紧集 = 有界闭集**：这是 Heine-Borel 定理的复平面版本。开圆盘不是紧集（不闭），全平面不是紧集（无界）。

5. **单连通 = 没有洞**：圆环不是单连通的（有一个洞）。复平面去掉一个点也不是单连通的（有一个"点洞"）。

6. **一致收敛 vs 内闭一致收敛**：一致收敛要求整个区域上收敛均匀；内闭一致收敛只要求每个紧子集上收敛均匀。复分析中常用内闭一致收敛。

7. **Weierstrass 定理是复分析独有的**：解析函数列的内闭一致收敛极限仍然解析，且各阶导数都收敛。这是"解析刚性"的体现。

8. **解析 ⇒ 无穷可导**：这和实函数完全不同——实函数可导一次不保证可导两次。

9. **唯一性定理**：两个解析函数在一个有聚点的集合上相等 ⇒ 它们在整个连通区域上相等。一小片信息决定整个函数！

10. **方向自由度是解析刚性的根源**：复可导要求所有方向的差商极限都相等——这给函数施加了极强的约束。

1. **《复分析》（Ahlfors）**：复平面的拓扑、解析函数的极限理论
2. **《复变函数论》（钟玉泉）**：复数列极限、复函数极限、Weierstrass 定理
3. **《数学分析原理》（Rudin）**：度量空间的完备性、紧性
4. **《复分析》（Stein & Shakarchi）**：解析函数的刚性、Weierstrass 定理
5. **《陶哲轩实分析》**：完备性与极限的关系
