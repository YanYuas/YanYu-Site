## L0 初等直觉层

> **引导语**：函数极限的直觉从运动开始。x 越来越靠近 x0 时，f(x) 往哪里走？为什么需要去心，x0 本身是个洞？这一层只有两道直觉题，关键是建立对函数极限的直观感觉，严格证明从 L1 开始。

**【D1-3-001】** 用自己的话解释"函数极限"的直觉含义。它和数列极限有什么不同？

- **难度**：★
- **对应知识点**：函数极限的直觉理解
- **解答**：
  函数极限的直觉含义是：当自变量 x 连续地趋近于 x₀ 时，函数值 f(x) 趋近于某个确定的数 A。
  
  与数列极限的不同：
  1. **自变量是连续的**：数列的自变量 n 只能取正整数（离散），函数的自变量 x 可以连续地取实数值
  2. **趋近方向更多**：x 可以从左侧、右侧、或任意方向趋近 x₀；x 也可以趋近 +∞、-∞
  3. **局部性质**：函数极限是"局部"的——只描述 x₀ 附近的行为，不关心远处的行为
  
  几何上，函数极限就是"函数图像在 x₀ 附近被夹在两条水平线之间"。∎
- **一句话点评**：数列极限是"点列凝聚"，函数极限是"图像局部收敛"——一个是离散的，一个是连续的。

**【D1-3-002】** 为什么函数极限需要"去心邻域"（0&lt;|x-x₀|）？如果不去心会怎样？

- **难度**：★
- **对应知识点**：去心邻域的意义
- **解答**：
  去心的原因有三个：
  1. **函数在 x₀ 处可能没有定义**：例如 f(x)=(x²-1)/(x-1) 在 x=1 处没有定义，但 limₓ→1 f(x)=2
  2. **函数在 x₀ 处的值与极限无关**：例如 f(x)={x², x≠0; 100, x=0}，limₓ→0 f(x)=0，尽管 f(0)=100
  3. **导数的定义需要去心**：导数 f'(x₀)=limₕ→0 [f(x₀+h)-f(x₀)]/h，这里 h≠0（否则分母为零）
  
  极限描述的是"x₀ 附近的趋势"，不是"f(x₀) 的值"——x₀ 本身是个"洞"。∎
- **一句话点评**：极限关心的是"x 靠近 x₀ 时 f(x) 往哪里走"，而不是"f(x₀) 是什么"。

## L1 数学分析层

> **引导语**：从直觉到严格。这一层涵盖 ε-δ 定义证明、两个重要极限、极限的性质与运算、复合函数极限、Heine 定理、无穷小与等价替换。内容较多，按定义、计算、性质、定理、应用的线索推进。

### 组A：ε-δ 定义与基本证明

**【D1-3-003】** 用 ε-δ 定义证明：limₓ→2 (3x+1) = 7。

- **难度**：★
- **对应知识点**：ε-δ 定义的直接应用
- **解答**：
  计算 |f(x) - 7| = |3x+1 - 7| = |3x - 6| = 3|x - 2|。
  
  对于任意 ε>0，取 δ = ε/3。当 0&lt;|x-2|&lt;δ 时，|f(x)-7| = 3|x-2| &lt; 3δ = ε。∎
- **一句话点评**：线性函数的极限——δ 就是 ε 除以斜率。

**【D1-3-004】** 写出"双侧极限存在"的充要条件。为什么分段函数在分段点处需要分别计算左右极限？

- **难度**：★
- **对应知识点**：单侧极限与双侧极限
- **解答**：
  双侧极限存在的充要条件：左右极限都存在且相等。
  limₓ→x₀ f(x) = A ⟺ limₓ→x₀⁺ f(x) = limₓ→x₀⁻ f(x) = A
  
  分段函数在分段点处需要分别计算左右极限，因为：
  - 分段函数在分段点的左侧和右侧可能有不同的表达式
  - 左右极限可能不同——如果不同，双侧极限就不存在
  
  例如 f(x) = {x+1, x≥0; x-1, x&lt;0}：
  - 右极限 limₓ→0⁺ f(x) = 1
  - 左极限 limₓ→0⁻ f(x) = -1
  - 左右极限不等，故 limₓ→0 f(x) 不存在。∎
- **一句话点评**：双侧极限存在 ⟺ 左右极限都存在且相等——这是分段函数极限存在性的判据。

**【D1-3-005】** 用 ε-δ 定义证明：limₓ→0 √(x+1) = 1。

- **难度**：★
- **对应知识点**：有理化法
- **解答**：
  计算 |√(x+1) - 1| = |(√(x+1)-1)(√(x+1)+1)/(√(x+1)+1)| = |x|/(√(x+1)+1)。
  
  当 |x|&lt;1 时，√(x+1)>0，所以 √(x+1)+1>1，因此 |√(x+1)-1| &lt; |x|。
  
  对于任意 ε>0，取 δ = min(1, ε)。当 0&lt;|x|&lt;δ 时，|√(x+1)-1| &lt; |x| &lt; ε。∎
- **一句话点评**：含根式的极限——先有理化，再放缩。

**【D1-3-006】** 解释什么是"无穷小"。为什么说"无穷小是极限为零的量"？

- **难度**：★
- **对应知识点**：无穷小的定义
- **解答**：
  若 limₓ→x₀ f(x) = 0，则称 f(x) 当 x→x₀ 时为无穷小量（简称无穷小）。
  
  无穷小的理解：
  1. **无穷小不是"很小的数"**：无穷小是一个"极限为零的变量"，不是一个固定的很小的数
  2. **无穷小依赖于极限过程**：同一个函数在不同的极限过程中可能是无穷小也可能不是。例如 f(x)=x 在 x→0 时是无穷小，但在 x→1 时不是
  3. **零是唯一的常数无穷小**：f(x)=0 是唯一的常数函数，它在任何极限过程中都是无穷小（因为 lim 0=0）
  
  几何上，无穷小就是"图像趋近于 x 轴"——当 x→x₀ 时，f(x) 的图像越来越贴近 x 轴。∎
- **一句话点评**：无穷小不是"很小的数"，而是"极限为零的变量"——它是一个过程，不是一个数。

### ★★ 进阶应用

**【D1-3-007】** 用 ε-δ 定义证明：limₓ→1 x² = 1。

- **难度**：★★
- **对应知识点**：放缩法
- **解答**：
  计算 |x² - 1| = |x-1|·|x+1|。
  
  需要控制 |x+1|。先限制 |x-1|&lt;1，则 x∈(0,2)，所以 |x+1|&lt;3。
  
  对于任意 ε>0，取 δ = min(1, ε/3)。当 0&lt;|x-1|&lt;δ 时，|x²-1| = |x-1|·|x+1| &lt; (ε/3)·3 = ε。∎
- **一句话点评**：非线性函数的极限——先"局部限制"控制其他因子，再"放缩"找 δ。

**【D1-3-008】** 用 ε-δ 定义证明：limₓ→∞ (3x²+2x+1)/(x²-5x+2) = 3。

- **难度**：★★
- **对应知识点**：x→∞ 时的极限
- **解答**：
  计算 |f(x) - 3| = |(3x²+2x+1)/(x²-5x+2) - 3| = |(3x²+2x+1 - 3x²+15x-6)/(x²-5x+2)| = |(17x-5)/(x²-5x+2)|。
  
  当 x>10 时，|17x-5| &lt; 17x，x²-5x+2 > x² - 0.5x² = 0.5x²（因为 x>10 时 5x&lt;0.5x²）。
  
  所以 |f(x)-3| &lt; 17x/(0.5x²) = 34/x。
  
  对于任意 ε>0，取 X = max(10, 34/ε)。当 x>X 时，|f(x)-3| &lt; 34/x &lt; 34/X ≤ ε。∎
- **一句话点评**：x→∞ 时的极限——分子分母同除以最高次项，比较系数。

### 组B：重要极限与计算技巧

**【D1-3-009】** 证明：limₓ→₀ (sin x)/x = 1。（第一个重要极限）

- **难度**：★★
- **对应知识点**：第一个重要极限
- **解答**：
  考虑单位圆中的扇形，设 0&lt;x&lt;π/2（x 为弧度）。
  比较三个区域的面积：
  - 三角形 OAB 的面积 = (1/2)sin x
  - 扇形 OAB 的面积 = (1/2)x
  - 三角形 OAC 的面积 = (1/2)tan x
  
  由面积大小关系：(1/2)sin x &lt; (1/2)x &lt; (1/2)tan x
  即 sin x &lt; x &lt; tan x
  
  除以 sin x（正数）：1 &lt; x/sin x &lt; 1/cos x
  取倒数：cos x &lt; sin x/x &lt; 1
  
  由 limₓ→0⁺ cos x = 1 和夹逼定理，limₓ→0⁺ sin x/x = 1。
  
  对于 x→0⁻，令 t=-x→0⁺，则 sin x/x = sin(-t)/(-t) = (-sin t)/(-t) = sin t/t→1。
  
  故 limₓ→0 sin x/x = 1。∎
- **一句话点评**：第一个重要极限的几何意义——小角度下，弦近似于弧（以直代曲）。

**【D1-3-010】** 计算：limₓ→₀ (tan x - sin x)/x³。

- **难度**：★★
- **对应知识点**：等价无穷小替换的条件
- **解答**：
  注意：等价无穷小替换只能用于乘除因子，不能用于加减项！
  
  错误做法：tan x~x, sin x~x，所以 (tan x - sin x)/x³ ~ (x-x)/x³=0。
  
  正确做法：
  tan x - sin x = sin x(1/cos x - 1) = sin x(1-cos x)/cos x
  
  利用等价无穷小：
  - sin x ~ x（x→0）
  - 1-cos x ~ x²/2（x→0）
  - cos x → 1
  
  所以 tan x - sin x ~ x·(x²/2)/1 = x³/2。
  
  因此 limₓ→₀ (tan x - sin x)/x³ = limₓ→₀ (x³/2)/x³ = 1/2。∎
- **一句话点评**：等价无穷小替换不能用于加减项——直接替换会丢失高阶信息。

**【D1-3-011】** 计算：limₓ→∞ (1 + 2/x)^x。

- **难度**：★★
- **对应知识点**：第二个重要极限
- **解答**：
  利用第二个重要极限的变形：limₓ→∞ (1 + k/x)^x = e^k。
  
  令 t = x/2，则 x→∞ 时 t→∞。
  (1 + 2/x)^x = (1 + 1/t)^{2t} = [(1 + 1/t)^t]^2。
  
  由 limₜ→∞ (1 + 1/t)^t = e，所以 [(1 + 1/t)^t]^2 → e²。
  
  因此 limₓ→∞ (1 + 2/x)^x = e²。∎
- **一句话点评**：第二个重要极限的变形——底数是 1+k/x，指数是 x，极限就是 e^k。

**【D1-3-016】** 证明：limₓ→∞ (1 + 1/x)^x = e。（第二个重要极限）

- **难度**：★★★
- **对应知识点**：第二个重要极限
- **解答**：
  **第一步：证明数列极限 limₙ→∞ (1+1/n)^n 存在。**
  - 单调递增（二项式展开比较）
  - 有上界（aₙ&lt;3）
  - 由单调有界定理，极限存在，记为 e
  
  **第二步：证明函数极限 limₓ→+∞ (1+1/x)^x = e。**
  对任意 x>0，取 n=[x]（不超过 x 的最大整数），则 n≤x&lt;n+1。
  由单调性：(1+1/(n+1))^n &lt; (1+1/x)^x &lt; (1+1/n)^{n+1}
  两边都趋于 e，由夹逼定理，limₓ→+∞ (1+1/x)^x = e
  
  **第三步：x→-∞ 的情况。**
  令 t=-x→+∞，则 (1+1/x)^x = (1-1/t)^{-t} = [t/(t-1)]^t = [1+1/(t-1)]^t → e
  
  因此 limₓ→∞ (1+1/x)^x = e。∎
- **一句话点评**：第二个重要极限的几何意义——连续复利的极限：每年复利 n 次，本利和趋于 e。

**【D1-3-024】** 计算：limₓ→₀ (1 - cos x)/x²。

- **难度**：★★
- **对应知识点**：等价无穷小
- **解答**：
  利用三角恒等式：1 - cos x = 2sin²(x/2)。
  
  所以 (1 - cos x)/x² = 2sin²(x/2)/x² = (1/2)·[sin(x/2)/(x/2)]²。
  
  由第一个重要极限：limₜ→₀ sin t/t = 1。令 t=x/2，则 limₓ→₀ sin(x/2)/(x/2) = 1。
  
  因此 limₓ→₀ (1 - cos x)/x² = (1/2)·1² = 1/2。∎
- **一句话点评**：1-cos x ~ x²/2——这是最常用的等价无穷小之一。

**【D1-3-025】** 计算：limₓ→∞ (√(x²+x) - x)。

- **难度**：★★
- **对应知识点**：有理化法
- **解答**：
  这是 ∞-∞ 型不定式。先有理化：
  
  √(x²+x) - x = [√(x²+x) - x]·[√(x²+x) + x]/[√(x²+x) + x]
  = (x²+x - x²)/[√(x²+x) + x]
  = x/[√(x²+x) + x]
  
  分子分母同除以 x：
  = 1/[√(1+1/x) + 1]
  
  当 x→∞ 时，1/x→0，√(1+1/x)→1。所以：
  limₓ→∞ (√(x²+x) - x) = 1/(1+1) = 1/2。∎
- **一句话点评**：∞-∞ 型不定式——先有理化，再求极限。

### 组C：极限的性质与运算

**【D1-3-012】** 证明：若 limₓ→x₀ f(x) = A > 0，则存在 δ>0，使得 0&lt;|x-x₀|&lt;δ 时 f(x) > 0。（局部保号性）

- **难度**：★★
- **对应知识点**：局部保号性
- **解答**：
  取 ε = A/2 > 0。因为 limₓ→x₀ f(x) = A，存在 δ>0，使得 0&lt;|x-x₀|&lt;δ 时 |f(x)-A|&lt;ε=A/2。
  
  即 f(x) > A - A/2 = A/2 > 0。∎
- **一句话点评**：局部保号性——极限为正，函数在附近也为正（局部的，不是全局的）。

### ★★★ 研究探索

**【D1-3-013】** 证明：函数极限的唯一性。若 limₓ→x₀ f(x) 存在，则唯一。

- **难度**：★★★
- **对应知识点**：极限的唯一性
- **解答**：
  反证法。假设 limₓ→x₀ f(x) = A 且 limₓ→x₀ f(x) = B，A≠B。取 ε = |A-B|/2 > 0。
  
  因为 lim f(x)=A，存在 δ₁，使得 0&lt;|x-x₀|&lt;δ₁ 时 |f(x)-A|&lt;ε。
  因为 lim f(x)=B，存在 δ₂，使得 0&lt;|x-x₀|&lt;δ₂ 时 |f(x)-B|&lt;ε。
  
  取 δ = min(δ₁, δ₂)。则 0&lt;|x-x₀|&lt;δ 时：
  |A-B| = |(A-f(x))+(f(x)-B)| ≤ |A-f(x)| + |f(x)-B| &lt; ε + ε = 2ε = |A-B|
  
  这与 |A-B|>0 矛盾。因此 A=B。∎
- **一句话点评**：极限的唯一性——如果极限不唯一，收敛就没有意义了。

**【D1-3-014】** 证明：若 limₓ→x₀ f(x) = A（有限），则存在 δ>0，使得 f(x) 在去心邻域 {x: 0&lt;|x-x₀|&lt;δ} 内有界。（局部有界性）

- **难度**：★★★
- **对应知识点**：局部有界性
- **解答**：
  取 ε=1，由极限定义，存在 δ>0，使得 0&lt;|x-x₀|&lt;δ 时 |f(x)-A|&lt;1。
  
  即 |f(x)| &lt; |A| + 1。所以 f(x) 在去心邻域 {x: 0&lt;|x-x₀|&lt;δ} 内有界（界为 |A|+1）。∎
- **一句话点评**：局部有界性——极限存在，函数在附近有界（局部的，不是全局的）。

**【D1-3-015】** 证明：若 f(x) ≤ g(x) ≤ h(x) 在 x₀ 附近成立，且 limₓ→x₀ f(x) = limₓ→x₀ h(x) = A，则 limₓ→x₀ g(x) = A。（夹逼定理）

- **难度**：★★★
- **对应知识点**：夹逼定理
- **解答**：
  对于任意 ε>0：
  - 因为 lim f(x)=A，存在 δ₁，使得 0&lt;|x-x₀|&lt;δ₁ 时 |f(x)-A|&lt;ε，即 A-ε &lt; f(x) &lt; A+ε
  - 因为 lim h(x)=A，存在 δ₂，使得 0&lt;|x-x₀|&lt;δ₂ 时 |h(x)-A|&lt;ε，即 A-ε &lt; h(x) &lt; A+ε
  
  取 δ = min(δ₀, δ₁, δ₂)（δ₀ 是 f≤g≤h 成立的邻域半径）。则 0&lt;|x-x₀|&lt;δ 时：
  A-ε &lt; f(x) ≤ g(x) ≤ h(x) &lt; A+ε
  即 |g(x)-A| &lt; ε。
  
  因此 lim g(x) = A。∎
- **一句话点评**：夹逼定理——上下界都"挤进"目标带，中间的函数也被"挤"进去。

**【D1-3-029】** 证明：若 limₓ→x₀ f(x) = A, limₓ→x₀ g(x) = B，则 limₓ→x₀ [f(x)·g(x)] = A·B。

- **难度**：★★★
- **对应知识点**：极限的乘法法则
- **解答**：
  计算 |fg - AB| = |f(g-B) + B(f-A)| ≤ |f|·|g-B| + |B|·|f-A|。
  
  第一步：f 局部有界（由 lim f=A 存在），即存在 M>0 和 δ₀>0，使得 0&lt;|x-x₀|&lt;δ₀ 时 |f|≤M。
  
  对于任意 ε>0：
  - 因为 lim g=B，存在 δ₁，使得 0&lt;|x-x₀|&lt;δ₁ 时 |g-B|&lt;ε/(2M)
  - 因为 lim f=A，存在 δ₂，使得 0&lt;|x-x₀|&lt;δ₂ 时 |f-A|&lt;ε/(2|B|)（如果 B≠0）
  
  取 δ = min(δ₀, δ₁, δ₂)。则 0&lt;|x-x₀|&lt;δ 时：
  |fg - AB| ≤ |f|·|g-B| + |B|·|f-A| &lt; M·ε/(2M) + |B|·ε/(2|B|) = ε/2 + ε/2 = ε。∎
- **一句话点评**：乘法法则——利用局部有界性控制 f，再分别控制两项。

**【D1-3-030】** 证明：若 limₓ→x₀ f(x) = A, limₓ→x₀ g(x) = B，且 B≠0，g(x)≠0，则 limₓ→x₀ [f(x)/g(x)] = A/B。

- **难度**：★★★
- **对应知识点**：极限的除法法则
- **解答**：
  第一步：先证 1/g→1/B。
  |1/g - 1/B| = |g-B|/(|g|·|B|)。
  
  因为 lim g=B≠0，由局部保号性，存在 δ₀>0，使得 0&lt;|x-x₀|&lt;δ₀ 时 |g|≥|B|/2。
  
  对于任意 ε>0，存在 δ₁，使得 0&lt;|x-x₀|&lt;δ₁ 时 |g-B|&lt;ε·B²/2。
  
  取 δ = min(δ₀, δ₁)。则 0&lt;|x-x₀|&lt;δ 时：
  |1/g - 1/B| = |g-B|/(|g|·|B|) &lt; (ε·B²/2)/[(|B|/2)·|B|] = ε。
  
  所以 1/g→1/B。
  
  第二步：f/g = f·(1/g)，由乘法法则，lim f/g = lim f · lim(1/g) = A·(1/B) = A/B。∎
- **一句话点评**：除法法则——先证倒数的极限，再用乘法法则。

### 组D：复合函数极限与 Heine 定理

**【D1-3-017】** 证明：复合函数极限定理。设 limₓ→x₀ g(x) = u₀，limᵤ→u₀ f(u) = A，且在 x₀ 附近 g(x)≠u₀（或 f 在 u₀ 处连续），则 limₓ→x₀ f(g(x)) = A。

- **难度**：★★★
- **对应知识点**：复合函数极限
- **解答**：
  对于任意 ε>0：
  - 因为 limᵤ→u₀ f(u) = A，存在 η>0，使得 0&lt;|u-u₀|&lt;η 时 |f(u)-A|&lt;ε
  - 因为 limₓ→x₀ g(x) = u₀，存在 δ>0，使得 0&lt;|x-x₀|&lt;δ 时 |g(x)-u₀|&lt;η
  
  如果在 x₀ 附近 g(x)≠u₀，则 0&lt;|g(x)-u₀|&lt;η，故 |f(g(x))-A|&lt;ε。
  
  如果 f 在 u₀ 处连续，则即使 g(x)=u₀，也有 |f(g(x))-A| = |f(u₀)-A| = 0 &lt; ε。∎
- **一句话点评**：复合函数极限——"两步趋近"：先 x→x₀ 使 u→u₀，再 u→u₀ 使 y→A。

**【D1-3-018】** 解释为什么复合函数极限定理需要条件 3（g(x)≠u₀ 或 f 连续）。给出一个反例说明条件 3 是必要的。

- **难度**：★★★
- **对应知识点**：复合函数极限的条件
- **解答**：
  **反例**：设 g(x)=0（常数函数），f(u)={1, u≠0; 0, u=0}。
  
  则 limₓ→0 g(x) = 0，limᵤ→0 f(u) = 1。
  
  但 f(g(x)) = f(0) = 0，所以 limₓ→0 f(g(x)) = 0 ≠ 1。
  
  **原因**：g(x)=0=u₀，不满足条件 3（g(x)≠u₀），而 f 在 u₀=0 处不连续。
  
  **几何解释**：g(x) 在趋近 u₀ 的过程中"停在"u₀ 上（常数函数），而 f 在 u₀ 处不连续——f(u₀) 不等于 f 的极限。所以复合后的极限由 f(u₀) 决定，而不是由 f 的极限决定。
  
  条件 3 的几何意义：g(x) 在趋近 u₀ 的过程中"不踩在"u₀ 上——它只是经过 u₀ 附近，不会停在 u₀。∎
- **一句话点评**：复合函数极限的条件 3——g(x) 不能"停在"u₀ 上，否则 f(u₀) 会"污染"极限。

**【D1-3-019】** 写出 Heine 定理的内容。它为什么被称为"归结原则"？

- **难度**：★
- **对应知识点**：Heine 定理
- **解答**：
  Heine 定理：limₓ→x₀ f(x) = A ⟺ 对任意满足 xₙ→x₀ 且 xₙ≠x₀ 的数列 {xₙ}，都有 limₙ→∞ f(xₙ) = A。
  
  **为什么叫"归结原则"**：Heine 定理将函数极限"归结"为数列极限——函数极限的问题可以转化为数列极限的问题来解决。它是函数极限与数列极限之间的"桥梁"。
  
  Heine 定理的意义：
  1. 将函数极限转化为数列极限——利用数列极限的理论来解决函数极限的问题
  2. 证明函数极限不存在——找到两个数列趋于不同极限即可
  3. 将数列极限的性质推广到函数极限∎
- **一句话点评**：Heine 定理是函数极限与数列极限之间的"桥梁"——把连续的问题归结为离散的问题。

**【D1-3-020】** 用 Heine 定理证明：limₓ→0 sin(1/x) 不存在。

- **难度**：★
- **对应知识点**：Heine 定理的应用
- **解答**：
  取两个数列：
  - xₙ = 1/(2nπ) → 0，则 sin(1/xₙ) = sin(2nπ) = 0 → 0
  - yₙ = 1/(2nπ + π/2) → 0，则 sin(1/yₙ) = sin(2nπ + π/2) = 1 → 1
  
  两个数列都趋于 0，但函数值趋于不同极限（0 和 1）。由 Heine 定理，limₓ→0 sin(1/x) 不存在。∎
- **一句话点评**：sin(1/x) 在 x→0 时无限振荡——沿不同路径趋于不同极限，极限不存在。

**【D1-3-022】** 用 Heine 定理证明：f(x) 在 x₀ 处连续当且仅当对于任意序列 xₙ→x₀，都有 f(xₙ)→f(x₀)。

- **难度**：★★
- **对应知识点**：连续性的 Heine 刻画
- **解答**：
  **必要性**（连续 ⇒ 序列刻画）：
  设 f 在 x₀ 连续。对于任意 ε>0，存在 δ>0，使得 |x-x₀|&lt;δ 时 |f(x)-f(x₀)|&lt;ε。
  因为 xₙ→x₀，存在 N，使得 n>N 时 |xₙ-x₀|&lt;δ。于是 n>N 时 |f(xₙ)-f(x₀)|&lt;ε。
  所以 f(xₙ)→f(x₀)。
  
  **充分性**（序列刻画 ⇒ 连续）：
  反证法。假设 f 在 x₀ 不连续。则存在 ε₀>0，使得对于任意 δ>0，都存在 x 满足 |x-x₀|&lt;δ 但 |f(x)-f(x₀)|≥ε₀。
  取 δ=1/n，构造序列 xₙ：|xₙ-x₀|&lt;1/n 但 |f(xₙ)-f(x₀)|≥ε₀。
  显然 xₙ→x₀，但 f(xₙ)↛f(x₀)，与条件矛盾。∎
- **一句话点评**：连续性的"序列刻画"和"ε-δ 刻画"是等价的——Heine 定理的威力。

**【D1-3-023】** 证明：Dirichlet 函数 D(x) 在任何点都不连续。

- **难度**：★★
- **对应知识点**：Heine 定理的应用
- **解答**：
  Dirichlet 函数：D(x) = {1, x 为有理数; 0, x 为无理数}。
  
  对于任意 x₀：
  - 取有理数列 xₙ→x₀（xₙ≠x₀），则 D(xₙ) = 1 → 1
  - 取无理数列 yₙ→x₀（yₙ≠x₀），则 D(yₙ) = 0 → 0
  
  两个数列都趋于 x₀，但 D(xₙ)→1，D(yₙ)→0。由 Heine 定理，limₓ→x₀ D(x) 不存在。
  
  因此 D(x) 在任何点都不连续。∎
- **一句话点评**：Dirichlet 函数处处不连续——有理数和无理数在任何点附近都稠密，沿不同路径趋于不同极限。

**【D1-3-031】** 证明：f(x) 在 x₀ 处连续当且仅当 limₓ→x₀ f(x) = f(x₀)。解释为什么"去心"在连续定义中不需要。

- **难度**：★★★
- **对应知识点**：连续性的定义
- **解答**：
  **连续的定义**：f 在 x₀ 处连续，当且仅当 limₓ→x₀ f(x) = f(x₀)。
  
  **为什么连续定义不需要去心**：
  在函数极限定义中，我们需要去心（0&lt;|x-x₀|），因为极限描述的是"x₀ 附近的趋势"，与 f(x₀) 无关。
  
  但在连续定义中，我们要求 lim f(x) = f(x₀)——极限值等于函数值。这时 x=x₀ 是允许的（因为 |f(x₀)-f(x₀)|=0&lt;ε 自动成立）。所以连续定义中不需要去心。
  
  **ε-δ 形式**：f 在 x₀ 连续 ⟺ ∀ε>0, ∃δ>0, ∀x(|x-x₀|&lt;δ ⇒ |f(x)-f(x₀)|&lt;ε)。
  
  注意：这里是 |x-x₀|&lt;δ，不是 0&lt;|x-x₀|&lt;δ——x=x₀ 是允许的。∎
- **一句话点评**：连续就是"极限值等于函数值"——这时 x=x₀ 是允许的，所以不需要去心。

### 组E：无穷小与等价替换

**【D1-3-006】** 解释什么是"无穷小"。为什么说"无穷小是极限为零的量"？

- **难度**：★
- **对应知识点**：无穷小的定义
- **解答**：
  若 limₓ→x₀ f(x) = 0，则称 f(x) 当 x→x₀ 时为无穷小量（简称无穷小）。
  
  无穷小的理解：
  1. **无穷小不是"很小的数"**：无穷小是一个"极限为零的变量"，不是一个固定的很小的数
  2. **无穷小依赖于极限过程**：同一个函数在不同的极限过程中可能是无穷小也可能不是。例如 f(x)=x 在 x→0 时是无穷小，但在 x→1 时不是
  3. **零是唯一的常数无穷小**：f(x)=0 是唯一的常数函数，它在任何极限过程中都是无穷小（因为 lim 0=0）
  
  几何上，无穷小就是"图像趋近于 x 轴"——当 x→x₀ 时，f(x) 的图像越来越贴近 x 轴。∎
- **一句话点评**：无穷小不是"很小的数"，而是"极限为零的变量"——它是一个过程，不是一个数。

### ★★ 进阶应用

**【D1-3-026】** 证明：等价无穷小替换定理。设 f(x)~f₁(x), g(x)~g₁(x)（x→x₀），且 lim f₁(x)/g₁(x) 存在，则 lim f(x)/g(x) = lim f₁(x)/g₁(x)。

- **难度**：★★
- **对应知识点**：等价无穷小替换
- **解答**：
  lim f/g = lim (f/f₁)·(f₁/g₁)·(g₁/g)
  
  因为 f~f₁，所以 lim f/f₁ = 1。
  因为 g~g₁，所以 lim g₁/g = 1。
  
  因此 lim f/g = 1 · lim(f₁/g₁) · 1 = lim f₁/g₁。∎
- **一句话点评**：等价无穷小替换——在乘除因子中可以"替换"为等价无穷小，简化计算。

### ★★★ 研究探索

**【D1-3-027】** 解释为什么"等价无穷小替换只能用于乘除因子，不能用于加减项"。用 (tan x - sin x)/x³ 的例子说明。

- **难度**：★★★
- **对应知识点**：等价无穷小替换的条件
- **解答**：
  **反例**：limₓ→₀ (tan x - sin x)/x³。
  
  **错误做法**：tan x~x, sin x~x，所以 (tan x - sin x)/x³ ~ (x-x)/x³ = 0，极限=0。
  
  **正确做法**：tan x - sin x = sin x(1/cos x - 1) = sin x(1-cos x)/cos x ~ x·(x²/2)/1 = x³/2，极限=1/2。
  
  **原因**：tan x 和 sin x 都是 x 的等价无穷小，但它们的差 tan x - sin x 是 x³ 的同阶无穷小——直接替换会丢失高阶信息。
  
  **本质**：等价无穷小替换只保证"比值趋于 1"，但不保证"差值趋于零的速度"。在加减项中，两个等价无穷小的差可能是更高阶的无穷小——直接替换会把这个"高阶差"丢掉。∎
- **一句话点评**：等价无穷小替换不能用于加减项——两个等价无穷小的差可能是更高阶的无穷小，直接替换会丢失这个信息。

**【D1-3-028】** 证明：f(x)=O(g(x))（x→x₀）的含义是"f(x)/g(x) 在 x₀ 附近有界"。解释大 O 和小 o 的区别。

- **难度**：★★★
- **对应知识点**：大O与小o记号
- **解答**：
  **大O记号**：f(x)=O(g(x))（x→x₀）表示存在常数 C>0 和 δ>0，使得 0&lt;|x-x₀|&lt;δ 时 |f(x)|≤C|g(x)|。即 f(x)/g(x) 在 x₀ 附近有界。
  
  **小o记号**：f(x)=o(g(x))（x→x₀）表示 limₓ→x₀ f(x)/g(x)=0。即 f(x)/g(x)→0。
  
  **大O与小o的区别**：
  - 小o蕴含大O：f=o(g) ⟹ f=O(g)
  - 大O不蕴含小o：f=O(g) 不蕴含 f=o(g)
  
  **几何理解**：
  - 大O：f 的图像被 g 的图像的某个倍数"压住"——f 不会比 g 增长得更快
  - 小o：f/g→0——f 的图像相对于 g 的图像来说"可以忽略"，g 是"主导项"∎
- **一句话点评**：大O是"有界"，小o是"趋于零"——小o比大O强得多。

## L2 复变函数层

> **引导语**：函数极限从实轴扩展到复平面。复函数极限的 ε-δ 定义形式不变，但四面八方趋近使其比实函数极限强得多。复函数的连续性可以分解为实部和虚部的连续性。

### ★ 基础巩固

**【D1-3-032】** 写出复函数极限的 ε-δ 定义。与实函数极限有什么不同？

- **难度**：★
- **对应知识点**：复函数极限
- **解答**：
  复函数极限的定义：lim_z→z₀ f(z) = w₀ ⟺ ∀ε>0, ∃δ>0, ∀z(0&lt;|z-z₀|&lt;δ ⇒ |f(z)-w₀|&lt;ε)。
  
  与实函数极限的区别：
  1. **距离的含义**：|z-z₀| 是复数的模，即二维欧氏距离 √[(Re(z-z₀))²+(Im(z-z₀))²]，而不是绝对值
  2. **方向自由度**：z 可以从复平面上的任意方向趋近 z₀（无穷多个方向），而实函数中 x 只能从左或右趋近（两个方向）
  3. **几何图像**：复函数极限就是"圆盘收敛"——z 最终落在以 z₀ 为中心、δ 为半径的圆盘内，f(z) 落在以 w₀ 为中心、ε 为半径的圆盘内
  
  形式上，复函数极限与实函数极限的 ε-δ 结构完全相同，只是"距离"从一维绝对值变成了二维模长。∎
- **一句话点评**：复函数极限就是"圆盘收敛"——形式上和实函数一样，只是距离从"线段"变成了"圆盘"。

### ★★ 进阶应用

**【D1-3-033】** 解释为什么复函数极限比实函数极限"更强"。这种"强"体现在哪里？

- **难度**：★★
- **对应知识点**：复极限的方向自由度
- **解答**：
  在一维实数轴上，x 只能从左或右趋近 x₀——只有两个方向。所以实函数极限存在 ⟺ 左右极限都存在且相等。
  
  在二维复平面上，z 可以从无穷多个方向趋近 z₀——沿直线、沿曲线、沿螺旋线……所有方向的极限都必须存在且相等，复函数极限才存在。
  
  这种"强"体现在：
  1. **复可导（解析）比实可导强得多**：复可导要求沿所有方向的差商极限都存在且相等，而实可导只要求沿一个方向的极限存在
  2. **复函数的极限理论更"漂亮"**：由于方向自由度，复函数的极限理论比实函数更简洁、更优雅
  
  几何上，复极限的"方向自由度"就像"从所有方向逼近一个点"——只有当所有方向的趋势都一致时，极限才存在。这比"只从左右两个方向逼近"严格得多。∎
- **一句话点评**：复极限的"强"就是"方向多"——实极限只有左右两个方向，复极限有无穷多个方向。

### ★★★ 研究探索

**【D1-3-034】** 证明：复函数 f(z) 在 z₀ 处连续当且仅当 Re(f(z)) 和 Im(f(z)) 在 z₀ 处连续。

- **难度**：★★★
- **对应知识点**：复函数的连续性
- **解答**：
  设 f(z) = u(x,y) + iv(x,y)，其中 z = x+iy。
  
  **必要性**（f 连续 ⇒ u, v 连续）：
  因为 |Re(f(z)) - Re(f(z₀))| ≤ |f(z) - f(z₀)|，|Im(f(z)) - Im(f(z₀))| ≤ |f(z) - f(z₀)|。
  
  对于任意 ε>0，存在 δ>0，使得 |z-z₀|&lt;δ 时 |f(z)-f(z₀)|&lt;ε。
  
  于是 |u(x,y)-u(x₀,y₀)| ≤ |f(z)-f(z₀)| &lt; ε，|v(x,y)-v(x₀,y₀)| ≤ |f(z)-f(z₀)| &lt; ε。
  
  所以 u 和 v 都在 (x₀,y₀) 处连续。
  
  **充分性**（u, v 连续 ⇒ f 连续）：
  对于任意 ε>0：
  - 存在 δ₁，使得 |(x,y)-(x₀,y₀)|&lt;δ₁ 时 |u(x,y)-u(x₀,y₀)|&lt;ε/√2
  - 存在 δ₂，使得 |(x,y)-(x₀,y₀)|&lt;δ₂ 时 |v(x,y)-v(x₀,y₀)|&lt;ε/√2
  
  取 δ = min(δ₁, δ₂)。则 |z-z₀|&lt;δ 时：
  |f(z)-f(z₀)| = √[|u-u₀|² + |v-v₀|²] &lt; √[(ε/√2)² + (ε/√2)²] = ε。
  
  所以 f 在 z₀ 处连续。∎
- **一句话点评**：复函数连续 ⟺ 实部和虚部分别连续——把二维问题拆成两个一维问题。

## L3 实变函数层

> **引导语**：函数极限的思想延伸到积分理论。Riemann 积分是分割越来越细时黎曼和的极限；Dirichlet 函数揭示了 Riemann 积分的局限；Lebesgue 积分从另一个角度解决了可积性问题。

### ★ 基础巩固

**【D1-3-035】** 解释为什么 Riemann 积分需要"分割越来越细"。用函数极限的语言解释黎曼和的极限。

- **难度**：★
- **对应知识点**：Riemann 积分的极限本质
- **解答**：
  Riemann 积分的定义：f(x) 在 [a,b] 上 Riemann 可积，积分值为 I，当且仅当：
  ∀ε>0, ∃δ>0, 对于任意分割 λ（分割的最大小区间长度 &lt;δ），任意取点 ξᵢ∈[xᵢ₋₁,xᵢ]，都有 |Σᵢ f(ξᵢ)Δxᵢ - I| &lt; ε。
  
  **为什么需要"分割越来越细"**：
  - 黎曼和 Σ f(ξᵢ)Δxᵢ 是"小矩形面积之和"
  - 积分 I 是"曲线下的精确面积"
  - 随着分割越来越细（δ 越来越小），小矩形越来越窄，矩形面积之和越来越接近曲线下的精确面积
  
  这就是"面积逼近"的极限本质——从"折线逼近曲线"到"面积逼近"，本质上就是 ε-δ 语言的几何应用。∎
- **一句话点评**：Riemann 积分就是"黎曼和的极限"——分割越来越细，小矩形面积之和"凝聚"到精确的曲线下面积。

### ★★ 进阶应用

**【D1-3-036】** 解释为什么 Dirichlet 函数 D(x) 不是 Riemann 可积的。用函数极限的语言解释。

- **难度**：★★
- **对应知识点**：Riemann 可积性
- **解答**：
  Dirichlet 函数：D(x) = {1, x 为有理数; 0, x 为无理数}。
  
  **上和与下和**：
  - 上和（每个区间取有理点）：U(λ) = Σ 1·Δxᵢ = b-a
  - 下和（每个区间取无理点）：L(λ) = Σ 0·Δxᵢ = 0
  
  无论分割多么细，上和始终是 b-a，下和始终是 0。上和减下和 = b-a ≠ 0。
  
  **为什么不是 Riemann 可积**：
  Riemann 可积的条件是：当分割越来越细时，上和与下和的差趋于零。但 Dirichlet 函数的上和减下和始终是 b-a，不趋于零。
  
  **函数极限的语言**：黎曼和的极限不存在——因为沿不同的取点方式（有理点或无理点），黎曼和趋于不同的值（b-a 或 0）。由 Heine 定理，黎曼和的极限不存在。∎
- **一句话点评**：Dirichlet 函数不是 Riemann 可积——沿不同取点方式，黎曼和趋于不同极限。

### ★★★ 研究探索

**【D1-3-037】** 解释为什么 Lebesgue 积分"解决"了 Dirichlet 函数的可积性问题。用函数极限的语言解释 Lebesgue 积分的定义。

- **难度**：★★★
- **对应知识点**：Lebesgue 积分的思想
- **解答**：
  **Riemann 积分的问题**：Riemann 积分按"x 轴分割"——把定义域分成小区间，计算每个区间上的函数值。对于 Dirichlet 函数，无论怎么分割 x 轴，每个小区间内都既有有理数也有无理数，所以上和与下和的差始终是 b-a。
  
  **Lebesgue 积分的思想**：Lebesgue 积分按"y 轴分割"——把函数值分成小层，计算每个层的"测度"（面积/长度）。对于 Dirichlet 函数：
  - 函数值为 1 的集合（有理数集）的测度是 0
  - 函数值为 0 的集合（无理数集）的测度是 b-a
  - 所以 Lebesgue 积分 = 1·0 + 0·(b-a) = 0
  
  **函数极限的语言**：Lebesgue 积分是"函数值层的测度加权和的极限"——随着分割越来越细，加权和趋于积分值。这个极限总是存在的（对于有界可测函数），因为 Lebesgue 测度具有可数可加性。
  
  **为什么 Lebesgue 积分"解决"了问题**：Lebesgue 积分不关心函数在 x 轴上的局部行为，只关心函数值的分布（测度）。Dirichlet 函数在 Lebesgue 意义下是可积的（积分值为 0），因为它的"高值集合"（有理数集）的测度为 0。∎
- **一句话点评**：Lebesgue 积分按"y 轴分割"——不关心 x 轴上的局部行为，只关心函数值的分布。Dirichlet 函数在 Lebesgue 意义下可积，因为它的"高值集合"测度为 0。

## 补充基础题（L1 数学分析 / L2 复变函数 / L3 实变函数）

> **引导语**：针对三个阶段补充基础题。L1 侧重 ε-δ 证明和 Heine 定理应用，L2 侧重复函数极限的存在性判断，L3 侧重一致收敛与函数列极限。

### L1 数学分析基础

**【D1-3-046】** 用 ε-δ 定义证明：$\lim_{x\to 1}\frac{x^2-1}{x-1}=2$。

- **难度**：★
- **对应知识点**：ε-δ 定义、去心邻域
- **解答**：
  对任意 ε>0，要使 $\left|\frac{x^2-1}{x-1}-2\right|<\varepsilon$（x≠1）。
  化简：$\left|\frac{(x-1)(x+1)}{x-1}-2\right|=|x+1-2|=|x-1|$。
  取 δ=ε，则 0&lt;|x-1|&lt;δ 时，$|x-1|<\varepsilon$。∎
- **一句话点评**：去心邻域让我们可以约掉为零的因子，这是 ε-δ 证明中最常用的技巧。
**【D1-3-047】** 求下列左右极限并判断极限是否存在：
(a) $\lim_{x\to0}\frac{|x|}{x}$　(b) $\lim_{x\to1}\frac{x^2-1}{|x-1|}$

- **难度**：★
- **解答**：(a) $x>0$ 时 $\frac{|x|}{x}=1$，右极限=1；$x<0$ 时 $\frac{|x|}{x}=-1$，左极限=-1。左右不等，极限不存在。
(b) $x>1$ 时 $\frac{x^2-1}{|x-1|}=\frac{(x-1)(x+1)}{x-1}=x+1\to2$；$x<1$ 时 $=\frac{(x-1)(x+1)}{1-x}=-(x+1)\to-2$。左右不等，极限不存在。∎
- **点评**：含绝对值的函数在分界点必须分别计算左右极限——左右极限相等是极限存在的充要条件。

**【D1-3-048】** 用 Heine 定理证明：$\lim_{x\to 0}\cos\frac{1}{x}$ 不存在。

- **难度**：★★
- **对应知识点**：Heine 定理、函数极限不存在的证明
- **解答**：
  取两个数列 $x_n=\frac{1}{2n\pi}$ 和 $y_n=\frac{1}{(2n+1)\pi}$，都满足 $x_n\to 0$，$y_n\to 0$。
  但 $\cos\frac{1}{x_n}=\cos(2n\pi)=1$，$\cos\frac{1}{y_n}=\cos((2n+1)\pi)=-1$。
  两个子列的极限不同（1 和 -1），由 Heine 定理，极限不存在。∎
- **一句话点评**：Heine 定理把函数极限翻译成数列极限，找到两个趋向同一点但函数值不同的数列，就证明了极限不存在。
**【D1-3-049】** 设 $\lim_{x\to x_0}f(x)=A\neq0$，$\lim_{x\to x_0}g(x)=B$。证明 $\lim_{x\to x_0}\frac{f(x)}{g(x)}=\frac{A}{B}$（$B\neq0$）。

- **难度**：★★
- **解答**：先证 $\lim\frac{1}{g(x)}=\frac{1}{B}$。由 $g(x)\to B\neq0$，存在 $\delta_1$ 使 $|g(x)|>|B|/2$。则 $\left|\frac{1}{g(x)}-\frac{1}{B}\right|=\frac{|g(x)-B|}{|g(x)||B|}\leq\frac{2|g(x)-B|}{B^2}$，可任意小。
再由乘积法则 $\lim f\cdot\frac{1}{g}=A\cdot\frac{1}{B}=\frac{A}{B}$。∎
- **点评**：商的极限法则证明分两步——先证倒数极限，再用乘积法则。关键是利用极限非零保证分母有正下界。

### L2 复变函数基础

**【D1-3-050】** 证明：$\lim_{z\to0}\frac{\text{Re}(z)}{z}$ 不存在。

- **难度**：★★
- **解答**：沿实轴 $z=x\to0$，$\frac{\text{Re}(z)}{z}=\frac{x}{x}=1\to1$。
沿虚轴 $z=iy\to0$，$\frac{\text{Re}(z)}{z}=\frac{0}{iy}=0\to0$。
沿不同路径极限不同，故复极限不存在。∎
- **点评**：复函数极限要求"沿所有路径趋于同一点"——这比实函数极限强得多，因为复平面是二维的。

**【D1-3-051】** 设 $f(z)=z^2$。用 ε-δ 定义证明 $\lim_{z\to z_0}f(z)=z_0^2$。

- **难度**：★
- **解答**：$|z^2-z_0^2|=|z-z_0||z+z_0|$。当 $|z-z_0|<1$ 时，$|z+z_0|\leq|z-z_0|+2|z_0|<1+2|z_0|$。
取 $\delta=\min(1,\frac{\varepsilon}{1+2|z_0|})$，则 $|z-z_0|<\delta$ 时 $|z^2-z_0^2|<\varepsilon$。∎
- **点评**：复多项式函数的连续性证明与实函数类似——因式分解 + 有界性放缩。

**【D1-3-052】** 证明：若 $\lim_{z\to z_0}f(z)=w_0$，则 $\lim_{z\to z_0}|f(z)|=|w_0|$。反之是否成立？

- **难度**：★★
- **解答**：由三角不等式 $||f(z)|-|w_0||\leq|f(z)-w_0|$，直接得必要性。
反之不成立。反例 $f(z)=e^{i/z}$，$|f(z)|=1\to1$，但 $f(z)$ 在 $z\to0$ 时不收敛（沿不同辐角方向极限不同）。∎
- **点评**：模的收敛是复函数收敛的必要条件但不充分——模只记录"大小"，丢失了"方向"（辐角）信息。

### L3 实变函数基础

**【D1-3-053】** 设 $f_n(x)=\frac{nx}{1+n^2x^2}$ 在 $[0,1]$ 上。证明 $f_n\to0$ 逐点收敛，但不一致收敛。

- **难度**：★★
- **解答**：对每个固定 $x>0$，$f_n(x)=\frac{nx}{1+n^2x^2}\sim\frac{1}{nx}\to0$；$x=0$ 时 $f_n(0)=0$。故逐点收敛到 0。
但 $\sup_{[0,1]}|f_n|=f_n(1/n)=\frac{n\cdot(1/n)}{1+n^2\cdot(1/n^2)}=\frac{1}{2}$，不趋于 0，故不一致收敛。∎
- **点评**：这是经典的"滑动峰"反例——峰值高度不变但位置趋于 0，导致逐点收敛但不一致收敛。

**【D1-3-054】** 叙述 Egorov 定理，并说明为什么它要求测度有限。

- **难度**：★★
- **解答**：Egorov 定理：在有限测度空间上，若 $f_n\to f$ a.e.，则 $\forall\delta>0$，存在可测集 $E$ 使 $\mu(E^c)<\delta$ 且 $f_n$ 在 $E$ 上一致收敛到 $f$。
要求测度有限的原因：在无限测度空间上反例 $f_n=\chi_{[n,n+1]}$，a.e. 收敛到 0，但在任何测度有限补集的集合上都不一致收敛（因为峰可以移到无穷远）。∎
- **点评**：Egorov 定理是"逐点收敛几乎等于一致收敛"——但只在有限测度空间上成立，无限测度上质量可以逃逸到无穷远。

**【D1-3-055】** 设 $f_n\to f$ 一致收敛且每个 $f_n$ 连续。证明 $f$ 连续。

- **难度**：★
- **解答**：$\forall\varepsilon>0$，取 $N$ 使 $n>N$ 时 $\|f_n-f\|_\infty<\varepsilon/3$。固定 $n>N$，由 $f_n$ 连续，$\exists\delta>0$ 使 $|x-y|<\delta$ 时 $|f_n(x)-f_n(y)|<\varepsilon/3$。
则 $|f(x)-f(y)|\leq|f(x)-f_n(x)|+|f_n(x)-f_n(y)|+|f_n(y)-f(y)|<\varepsilon/3+\varepsilon/3+\varepsilon/3=\varepsilon$。∎
- **点评**：一致收敛保持连续性——这是一致收敛最重要的性质之一。证明用"ε/3 技巧"。

## 跨领域综合题

> **引导语**：函数极限是分析学的通用语言。两个重要极限串联了三角学、级数和解析函数；Heine 定理是连接数列极限与函数极限的桥梁；等价无穷小是 Taylor 展开的前奏。每道综合题都展示了函数极限的全局意义。

> 定位：串联多个概念领域的综合题，培养全局视野和数学思考的"爽感"。

### 一、经典名题（做一遍爽一遍）

**【D1-3-CROSS-038】**（D1 × D7 三角学 × D4 积分）**第一个重要极限的几何本质**：limₓ→0 sin x/x = 1。为什么这个极限是"以直代曲"的数学表达？它和圆的几何有什么关系？

- **难度**：★★★
- **对应知识点**：第一个重要极限（D1）、三角函数（D7）、面积（D4）
- **来源**：分析学最经典的极限之一
- **解答**：
  **几何本质**：在单位圆中，当角度 x 很小时：
  - 弧长 = x（弧度制）
  - 弦长 = 2sin(x/2) ≈ sin x（小角度近似）
  
  所以 sin x/x → 1 意味着：小角度下，弦长 ≈ 弧长。这就是"以直代曲"——用直线（弦）近似代替曲线（弧）。
  
  **与圆的几何的关系**：
  这个极限的证明依赖于单位圆中的面积比较：
  - 三角形面积 &lt; 扇形面积 &lt; 外切三角形面积
  - (1/2)sin x &lt; (1/2)x &lt; (1/2)tan x
  - 由夹逼定理，sin x/x → 1
  
  **为什么重要**：
  这个极限是所有三角函数导数公式的基础——(sin x)' = cos x 的证明依赖于 lim sin x/x = 1。它也是 Taylor 展开 sin x = x - x³/6 + ... 的基础。
  
  **几何图像**：小角度下，圆弧和切线几乎重合——弦近似于弧，切线近似于弧。这就是"局部线性化"的几何基础——在很小的尺度上，曲线近似于直线。∎
- **一句话点评**：lim sin x/x = 1 是"以直代曲"的数学表达——小角度下，弦近似于弧。这是所有三角函数导数公式的基础。

**【D1-3-CROSS-039】**（D1 × D8 解析 × D5 级数）**第二个重要极限与 e 的定义**：limₓ→∞ (1+1/x)^x = e。为什么自然常数 e 是用极限定义的？它和指数函数的解析延拓有什么关系？

- **难度**：★★★
- **对应知识点**：第二个重要极限（D1）、指数函数（D8）、级数（D5）
- **来源**：欧拉数 e 的定义
- **解答**：
  **e 的极限定义**：e = limₙ→∞ (1+1/n)^n。这是欧拉在 1748 年给出的定义。
  
  **为什么用极限定义**：e 不是一个"简单的常数"——它不能用有限的代数运算从整数构造出来。它是一个"超越数"——不是任何整系数多项式的根。所以 e 只能用极限（或级数）来定义。
  
  **与指数函数的关系**：
  指数函数 e^x 的定义：e^x = limₙ→∞ (1+x/n)^n。
  这是第二个重要极限的推广——当 x=1 时就是 e 的定义。
  
  **与解析延拓的关系**：
  指数函数 e^z 可以通过幂级数 e^z = Σ_{n=0}^∞ z^n/n! 定义到整个复平面。这个级数在整个复平面上收敛，定义了一个全纯函数。
  
  从极限定义到级数定义：
  (1+x/n)^n = [1 + x/n]^n → e^x（n→∞）
  展开 [1+x/n]^n = Σ_{k=0}^n C(n,k)(x/n)^k → Σ_{k=0}^∞ x^k/k! = e^x
  
  **几何图像**：第二个重要极限的几何意义是"连续复利"——如果年利率为 100%，每年复利 n 次，本利和为 (1+1/n)^n；当 n→∞（连续复利）时，本利和趋于 e≈2.718。这是"离散复利"到"连续复利"的极限。∎
- **一句话点评**：e 是用极限定义的——它不是"简单的常数"，而是"连续复利的极限"。从这个极限出发，我们定义了整个复平面上的指数函数。

### 二、定理串联型（多领域协同的爽感）

**【D1-3-CROSS-040】**（D1 × D2 连续 × D3 微分 × D4 积分）**Heine 定理的全局意义**：Heine 定理为什么是分析学的核心定理之一？它如何连接数列极限、函数极限、连续性和导数？

- **难度**：★★★
- **对应知识点**：Heine 定理（D1）、连续性（D2）、导数（D3）、积分（D4）
- **来源**：分析学的核心桥梁
- **解答**：
  **Heine 定理的表述**：limₓ→x₀ f(x) = A ⟺ 对任意满足 xₙ→x₀ 的数列 {xₙ}，都有 f(xₙ)→A。
  
  **为什么是核心定理**：
  1. **连接数列极限和函数极限**：Heine 定理把"连续的函数极限"归结为"离散的数列极限"——函数极限的问题可以转化为数列极限的问题。
  
  2. **连续性的刻画**：f 在 x₀ 连续 ⟺ 对任意 xₙ→x₀，f(xₙ)→f(x₀)。这是连续性的"序列刻画"，与 ε-δ 刻画等价。
  
  3. **导数的定义**：f'(x₀) = limₕ→₀ [f(x₀+h)-f(x₀)]/h。由 Heine 定理，f'(x₀) 存在 ⟺ 对任意 hₙ→0，[f(x₀+hₙ)-f(x₀)]/hₙ 收敛到同一个极限。
  
  4. **积分的定义**：Riemann 积分是黎曼和的极限。由 Heine 定理，黎曼和的极限存在 ⟺ 对任意分割序列（分割越来越细），黎曼和趋于同一个极限。
  
  **全局意义**：Heine 定理是分析学的"统一语言"——它把所有"极限过程"都归结为"数列的极限过程"。无论是函数极限、连续性、导数还是积分，本质上都是 Heine 定理的不同应用。
  
  **几何图像**：Heine 定理的几何本质是"所有路径都到达同一个终点"——在 x₀ 附近，无论你沿着哪条路径（数列）趋近 x₀，对应的函数值都趋于同一个极限 A。这就是函数极限的几何本质——"所有路径的统一终点"。∎
- **一句话点评**：Heine 定理是分析学的"统一语言"——它把所有极限过程都归结为数列的极限过程。函数极限、连续性、导数、积分，本质上都是 Heine 定理的不同应用。

**【D1-3-CROSS-041】**（D1 × D3 微分 × D6 完备性）**等价无穷小与 Taylor 展开**：为什么说等价无穷小替换是 Taylor 展开的"一阶近似"？Taylor 展开比等价无穷小替换"多"了什么？

- **难度**：★★★
- **对应知识点**：等价无穷小（D1）、Taylor 展开（D3）、完备性（D6）
- **来源**：渐近分析的本质
- **解答**：
  **等价无穷小替换的本质**：
  等价无穷小 f~g 意味着 f/g→1，即 f = g + o(g)。这是 Taylor 展开的"一阶近似"——只保留主导项，忽略高阶项。
  
  例如 sin x ~ x 意味着 sin x = x + o(x)。
  
  **Taylor 展开比等价无穷小替换"多"了什么**：
  Taylor 展开：f(x) = f(x₀) + f'(x₀)(x-x₀) + f''(x₀)/2!·(x-x₀)² + ... + f⁽ⁿ⁾(x₀)/n!·(x-x₀)ⁿ + o((x-x₀)ⁿ)
  
  Taylor 展开不仅给出"主导项"（一阶近似），还给出了"高阶修正项"——二阶、三阶……直到 n 阶。这些高阶项在更精确的计算中是必要的。
  
  例如 sin x = x - x³/6 + x⁵/120 - ...
  - 一阶近似：sin x ~ x（等价无穷小）
  - 三阶近似：sin x ~ x - x³/6（更精确）
  
  **为什么等价无穷小替换不能用于加减项**：
  在加减项中，主导项可能"抵消"，高阶项就变成了"主导项"。例如：
  tan x - sin x = x + x³/3 + ... - (x - x³/6 + ...) = x³/2 + ...
  
  一阶项 x 抵消了，三阶项 x³/2 变成了主导项。如果直接用一阶近似（tan x~x, sin x~x），就会丢失三阶项的信息。
  
  **几何图像**：等价无穷小替换是"只看图像的主要趋势"，Taylor 展开是"精确描述图像的形状"——一阶是"斜率"，二阶是"曲率"，三阶是"挠率"……阶数越高，描述越精确。∎
- **一句话点评**：等价无穷小替换是 Taylor 展开的"一阶近似"——只保留主导项，忽略高阶项。在加减项中，主导项可能抵消，高阶项就变成了主导项——这就是为什么等价无穷小替换不能用于加减项。

**【D1-3-CROSS-042】**（D1 × D6 完备性 × D8 解析）**函数极限的存在性与完备性**：为什么说"Cauchy 列收敛"依赖于实数的完备性？函数极限的存在性是否也依赖于完备性？

- **难度**：★★★
- **对应知识点**：函数极限（D1）、完备性（D6）、复平面的完备性（D8）
- **解答**：
  **数列极限的存在性与完备性**：
  Cauchy 列本身不蕴含收敛——在有理数系中，存在 Cauchy 列不收敛（如 √2 的有理数逼近）。只有在完备空间（实数系）中，Cauchy 列才收敛。
  
  **函数极限的存在性与完备性**：
  函数极限的"存在性"也依赖于完备性。考虑函数 f(x) = x·sin(1/x) 在 x→0 时的极限。这个极限存在且等于 0——但这个结论依赖于实数系的完备性。
  
  更深刻地说：函数极限的"Cauchy 准则"（lim f(x) 存在 ⟺ f(x) 是"函数 Cauchy 列"）也依赖于完备性。在不完备空间中，函数 Cauchy 列可能不收敛。
  
  **复平面的完备性**：
  复平面 ℂ 也是完备的（因为 ℝ² 完备）。所以复函数极限的存在性也依赖于 ℂ 的完备性。
  
  **几何图像**：完备性就是"空间没有缝隙"——实数系就像一条"填满"的数轴，所有 Cauchy 列的极限都在这条数轴上。函数极限的存在性，本质上就是"函数值的 Cauchy 列收敛"——这需要空间是完备的。∎
- **一句话点评**：函数极限的存在性也依赖于完备性——Cauchy 准则的有效性，建立在"空间没有缝隙"的基础上。

**【D1-3-CROSS-043】**（D1 × D7 三角学 × D5 级数）**两个重要极限的统一视角**：lim sin x/x = 1 和 lim (1+1/x)^x = e——这两个极限看似无关，但它们都是"0/0"和"1^∞"型不定式的标准结果。它们有什么共同的本质？

- **难度**：★★★
- **对应知识点**：两个重要极限（D1）、三角函数（D7）、级数（D5）
- **来源**：分析学的基础极限
- **解答**：
  **形式上的不同**：
  - 第一个重要极限：limₓ→0 sin x/x = 1——"0/0"型
  - 第二个重要极限：limₓ→∞ (1+1/x)^x = e——"1^∞"型
  
  **共同的本质**：
  1. **都是"逼近"的极限**：
     - 第一个：小角度下，sin x 逼近于 x（弦逼近于弧）
     - 第二个：连续复利下，(1+1/n)^n 逼近于 e
  
  2. **都是 Taylor 展开的"一阶近似"**：
     - sin x = x - x³/6 + ...，所以 sin x/x = 1 - x²/6 + ... → 1
     - ln(1+1/x)·x = x·(1/x - 1/(2x²) + ...) = 1 - 1/(2x) + ... → 1，所以 (1+1/x)^x = e^{x·ln(1+1/x)} → e
  
  3. **都是"以直代曲"的极限**：
     - 第一个：用直线（弦）近似代替曲线（弧）
     - 第二个：用离散的复利近似代替连续的复利
  
  **与级数的关系**：
  两个重要极限都可以通过 Taylor 展开（或幂级数）来理解：
  - sin x 的 Taylor 展开：sin x = Σ_{n=0}^∞ (-1)^n x^{2n+1}/(2n+1)!
  - e^x 的 Taylor 展开：e^x = Σ_{n=0}^∞ x^n/n!
  
  两个重要极限本质上就是这些幂级数在 x=0（或 x→∞）时的"首项行为"。
  
  **几何图像**：两个重要极限都是"局部线性化"的结果——在很小的尺度上，函数图像近似于直线（或常数）。这就是"以直代曲"的数学本质——在局部，曲线近似于直线。∎
- **一句话点评**：两个重要极限都是"以直代曲"的结果——在局部，曲线近似于直线。第一个是"弦近似于弧"，第二个是"离散复利近似于连续复利"。

**【D1-3-CROSS-044】**（D1 × D3 微分）设函数 f 在 x₀ 处可导，定义数列 aₙ = [f(x₀+1/n) - f(x₀)]/(1/n)。证明：lim aₙ = f'(x₀)。并思考：如果 lim aₙ 存在，能否推出 f 在 x₀ 处可导？

- **难度**：★★
- **对应知识点**：导数定义与数列极限的关系（D3-1 联动）
- **来源**：概念综合题
- **解答**：
  由导数定义，f'(x₀) = limₕ→₀ [f(x₀+h)-f(x₀)]/h。取 h = 1/n → 0，由 Heine 定理，limₙ→∞ [f(x₀+1/n)-f(x₀)]/(1/n) = f'(x₀)。
  
  反过来不成立：即使沿 h=1/n 的极限存在，也不能保证沿所有 h→0 的极限都存在。反例：f(x) = sin(π/x)（x≠0），f(0)=0。取 x₀=0，aₙ = [f(1/n)-f(0)]/(1/n) = n·sin(nπ) = 0，所以 lim aₙ = 0。但 f 在 0 处不可导（沿 h=2/(4n+1) 时极限不同）。∎
- **一句话点评**：可导要求"沿所有路径"的差商极限都存在且相等，只沿一条路径（如 1/n）存在是不够的。

**【D1-3-CROSS-045】**（D1 × D2 连续）证明：若 f(x) 在 [a,b] 上连续，则 f(x) 在 [a,b] 上有界。用函数极限的语言解释为什么连续函数在闭区间上有界。

- **难度**：★★
- **对应知识点**：连续函数的有界性（D2 联动）
- **来源**：概念综合题
- **解答**：
  闭区间上连续函数的有界性定理：若 f 在 [a,b] 上连续，则 f 在 [a,b] 上有界。
  
  **为什么需要"闭区间"**：
  开区间上的连续函数不一定有界。例如 f(x)=1/x 在 (0,1) 上连续，但无界（x→0⁺ 时 f(x)→∞）。
  
  **为什么"闭区间"就有界**：
  闭区间 [a,b] 是"紧集"——任何无穷序列都有收敛子列（Bolzano-Weierstrass 定理）。如果 f 无界，则存在序列 xₙ∈[a,b] 使得 |f(xₙ)|→∞。但 xₙ 有收敛子列 x_{n_k}→x₀∈[a,b]。由连续性，f(x_{n_k})→f(x₀)，矛盾（因为 |f(x_{n_k})|→∞）。
  
  **函数极限的语言**：
  连续性意味着 f(x) 在每个点 x₀ 附近"局部有界"。闭区间上的紧性保证了"局部有界"可以"拼接"成"全局有界"——有限个局部有界的区间拼接起来，就是全局有界。∎
- **一句话点评**：闭区间上连续函数有界——因为闭区间是紧集，局部有界可以拼接成全局有界。

## 本模块易错点总结

1. **极限定义需要去心**：0&lt;|x-x₀| 是关键——x 不等于 x₀。函数在 x₀ 处的值与极限无关。

2. **δ 不需要最大**：ε-δ 定义只要求"存在 δ"，不要求"最大的 δ"。找到更小的 δ 也可以。

3. **单侧极限与双侧极限**：双侧极限存在 ⟺ 左右极限都存在且相等。分段函数在分段点处需要分别计算左右极限。

4. **Heine 定理的逆否命题**：如果找到两个数列趋于不同极限，则函数极限不存在——这是证明极限不存在的最常用方法。

5. **等价无穷小替换的条件**：只能用于乘除因子，不能用于加减项！两个等价无穷小的差可能是更高阶的无穷小。

6. **局部性质 vs 全局性质**：函数极限的性质是"局部"的——局部有界、局部保号。数列极限的性质是"整体"的。

7. **无穷小不是数**：无穷小是"极限为零的变量"，不是"很小的数"。零是唯一的常数无穷小。

8. **复合函数极限的条件 3**：g(x)≠u₀ 或 f 连续——否则 f(u₀) 会"污染"极限。

9. **大O与小o的区别**：大O是"有界"，小o是"趋于零"。小o蕴含大O，大O不蕴含小o。

10. **两个重要极限的几何意义**：
    - lim sin x/x = 1：小角度下，弦近似于弧（以直代曲）
    - lim (1+1/x)^x = e：连续复利的极限
