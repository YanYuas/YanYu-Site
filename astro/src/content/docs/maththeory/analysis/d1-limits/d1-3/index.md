## 第一章 引言：从离散到连续——函数极限的本质

### 1.1 为什么需要函数极限

在 D1-2 中，我们建立了数列极限的完整理论。数列是定义在自然数集 ℕ 上的函数——它的"自变量"n 只能取正整数，是离散的。但分析学中更常见的是定义在实数区间上的函数——自变量 x 可以连续地取实数值。

函数极限描述的是"当自变量 x 连续地趋近于某个值 x₀（或无穷大）时，函数值 f(x) 的变化趋势"。这比数列极限更丰富，因为：

1. **趋近方向更多**：x 可以从左侧、右侧、或任意方向趋近 x₀；x 也可以趋近 +∞、-∞ 或 ∞
2. **函数在 x₀ 处的值与极限无关**：极限描述的是 x₀ 附近的趋势，不是 f(x₀) 的值
3. **与连续性的关系**：函数在 x₀ 处连续 ⟺ limₓ→x₀ f(x) = f(x₀)——函数极限是连续性的基础
4. **与导数的关系**：导数 f'(x₀) = limₕ→0 [f(x₀+h)-f(x₀)]/h——函数极限是导数的基础
5. **与积分的关系**：定积分是黎曼和的极限，而黎曼和是函数值的加权和——函数极限是积分的基础

**📐 几何锚定**：函数极限的几何本质是"函数图像在 x₀ 附近被夹在两条水平线之间"。在 x-y 平面上画出函数 y=f(x) 的图像，limₓ→x₀ f(x)=A 意味着：对于任意小的"目标带" (A-ε, A+ε)，总能找到一个足够窄的"输入带" (x₀-δ, x₀+δ)，使得输入带内（除 x=x₀ 外）的函数图像全部落在目标带内。注意 x=x₀ 处有一个"洞"——函数在 x₀ 处的值可以不在目标带内，甚至可以没有定义。几何上，函数极限描述的是"图像在 x₀ 附近的局部行为"，而不是"图像在 x₀ 处的点"。

## 第二章 函数极限的定义

### 2.1 双侧极限的 ε-δ 定义（回顾与深化）

**定义**：设函数 f(x) 在 x₀ 的某个去心邻域内有定义，A∈ℝ。若 ∀ε>0, ∃δ>0, ∀x(0&lt;|x-x₀|&lt;δ ⇒ |f(x)-A|&lt;ε)，则称 f(x) 当 x→x₀ 时收敛于 A，记作 limₓ→x₀ f(x) = A。

**定义的深化理解**：

1. **去心邻域 0&lt;|x-x₀|**：这是函数极限最关键的特征——x 不等于 x₀。函数在 x₀ 处的值 f(x₀) 与极限无关，f(x₀) 甚至可以没有定义。这是因为极限描述的是"x₀ 附近的趋势"，而不是"x₀ 处的值"。

2. **δ 依赖于 ε**：通常 ε 越小，δ 也越小——需要 x 更接近 x₀ 才能达到更高的精度。但 δ 不要求是"最大的"，只要存在一个就行。

3. **δ 不依赖于 x**：同一个 δ 对去心邻域内的所有 x 都适用——这是"一致"的要求（与一致连续的思想类似，但这里是极限定义的内在要求）。

4. **f(x) 在去心邻域内有定义**：这是前提条件。如果 f(x) 在 x₀ 附近的某些点没有定义，极限可能无法定义（或者需要限制定义域）。

### 2.2 单侧极限

**右极限**：设 f(x) 在 x₀ 的右侧邻域 (x₀, x₀+η) 内有定义。若 ∀ε>0, ∃δ>0, ∀x(0&lt;x-x₀&lt;δ ⇒ |f(x)-A|&lt;ε)，则称 f(x) 当 x→x₀⁺ 时的右极限为 A，记作 limₓ→x₀⁺ f(x) = A 或 f(x₀⁺)=A。

**左极限**：设 f(x) 在 x₀ 的左侧邻域 (x₀-η, x₀) 内有定义。若 ∀ε>0, ∃δ>0, ∀x(0&lt;x₀-x&lt;δ ⇒ |f(x)-A|&lt;ε)，则称 f(x) 当 x→x₀⁻ 时的左极限为 A，记作 limₓ→x₀⁻ f(x) = A 或 f(x₀⁻)=A。

**双侧极限与单侧极限的关系**：

**定理**：limₓ→x₀ f(x) = A ⟺ limₓ→x₀⁺ f(x) = limₓ→x₀⁻ f(x) = A。

**证明**：
- ⇒：若双侧极限存在，则对任意 ε>0，存在 δ>0 使得 0&lt;|x-x₀|&lt;δ 时 |f(x)-A|&lt;ε。特别地，当 0&lt;x-x₀&lt;δ（右侧）或 0&lt;x₀-x&lt;δ（左侧）时也成立，故左右极限都等于 A。
- ⇐：若左右极限都等于 A，则 ∀ε>0，存在 δ₁>0 使得 0&lt;x-x₀&lt;δ₁ 时 |f(x)-A|&lt;ε；存在 δ₂>0 使得 0&lt;x₀-x&lt;δ₂ 时 |f(x)-A|&lt;ε。取 δ=min(δ₁,δ₂)，则 0&lt;|x-x₀|&lt;δ 时 |f(x)-A|&lt;ε，故双侧极限等于 A。∎

**几何理解**：双侧极限要求函数图像从左侧和右侧趋近 x₀ 时都"进入"目标带。如果左侧趋近和右侧趋近进入不同的目标带（左右极限不同），则双侧极限不存在。

**应用**：单侧极限常用于分段函数——在分段点处，需要分别计算左右极限，判断双侧极限是否存在。

**例**：f(x) = {x+1, x≥0; x-1, x&lt;0}
- 右极限：limₓ→0⁺ f(x) = limₓ→0⁺ (x+1) = 1
- 左极限：limₓ→0⁻ f(x) = limₓ→0⁻ (x-1) = -1
- 左右极限不等，故 limₓ→0 f(x) 不存在

### 2.3 无穷极限

**x→+∞ 时的极限**：设 f(x) 在 (a, +∞) 上有定义。若 ∀ε>0, ∃X>0, ∀x>X, |f(x)-A|&lt;ε，则称 limₓ→+∞ f(x) = A。

**x→-∞ 时的极限**：设 f(x) 在 (-∞, a) 上有定义。若 ∀ε>0, ∃X>0, ∀x&lt;-X, |f(x)-A|&lt;ε，则称 limₓ→-∞ f(x) = A。

**x→∞ 时的极限**：limₓ→∞ f(x) = A ⟺ limₓ→+∞ f(x) = limₓ→-∞ f(x) = A。

**几何理解**：x→+∞ 时的极限描述的是"函数图像在 x 轴正方向的远端的趋势"——当 x 足够大时，f(x) 落在 A 附近的任意小邻域内。这类似于数列极限（n→∞），但 x 是连续的实数而不是离散的自然数。

**函数极限与数列极限的联系**：limₓ→+∞ f(x) = A ⟺ 对任意满足 xₙ→+∞ 的数列 {xₙ}，都有 f(xₙ)→A（这是 Heine 定理的一种形式，见第五章）。

### 2.4 无穷大极限（发散到无穷）

**定义**：若 ∀M>0, ∃δ>0, ∀x(0&lt;|x-x₀|&lt;δ ⇒ f(x)>M)，则称 f(x) 当 x→x₀ 时发散到 +∞，记作 limₓ→x₀ f(x) = +∞。

类似地可以定义 limₓ→x₀ f(x) = -∞ 和 limₓ→x₀ f(x) = ∞（绝对值发散到无穷大）。

**注意**：无穷大极限不是"收敛到无穷大"，而是"发散到无穷大"——极限不存在，但有明确的趋势。在扩展实数系 ℝ∪{±∞} 中，可以说"收敛到 ±∞"，但在标准实数系中，这是发散的一种特殊情况。

**几何理解**：发散到 +∞ 意味着函数图像在 x₀ 附近"向上冲到无穷高"——无论你画多高的水平线 y=M，总能找到一个足够窄的输入带，使得输入带内的函数图像全部在水平线之上。

### 2.5 各种极限类型的统一视角

函数极限有多种类型，可以按"自变量的趋近方式"和"函数值的趋势"分类：

| 自变量趋近 | 函数值趋势 | 记号 |
|---|---|---|
| x→x₀（双侧） | →A（有限） | limₓ→x₀ f(x)=A |
| x→x₀⁺（右侧） | →A | limₓ→x₀⁺ f(x)=A |
| x→x₀⁻（左侧） | →A | limₓ→x₀⁻ f(x)=A |
| x→+∞ | →A | limₓ→+∞ f(x)=A |
| x→-∞ | →A | limₓ→-∞ f(x)=A |
| x→x₀ | →+∞ | limₓ→x₀ f(x)=+∞ |
| x→x₀ | →-∞ | limₓ→x₀ f(x)=-∞ |
| x→+∞ | →+∞ | limₓ→+∞ f(x)=+∞ |

所有这些类型都有类似的 ε-δ（或 ε-X、M-δ 等）定义，核心思想都是"对于任意的目标要求，存在足够的输入范围使得条件成立"。

## 第三章 函数极限的基本性质

### 3.1 唯一性

**定理**：若 limₓ→x₀ f(x) 存在，则唯一。

**证明**：与数列极限唯一性的证明类似。假设 lim f(x)=A 和 lim f(x)=B，A≠B。取 ε=|A-B|/2>0，存在 δ₁ 使得 0&lt;|x-x₀|&lt;δ₁ 时 |f(x)-A|&lt;ε；存在 δ₂ 使得 0&lt;|x-x₀|&lt;δ₂ 时 |f(x)-B|&lt;ε。取 δ=min(δ₁,δ₂)，则 0&lt;|x-x₀|&lt;δ 时 |A-B|≤|A-f(x)|+|f(x)-B|&lt;2ε=|A-B|，矛盾。∎

### 3.2 局部有界性

**定理**：若 limₓ→x₀ f(x)=A（有限），则存在 δ>0，使得 f(x) 在去心邻域 {x: 0&lt;|x-x₀|&lt;δ} 内有界。

**证明**：取 ε=1，由极限定义，存在 δ>0 使得 0&lt;|x-x₀|&lt;δ 时 |f(x)-A|&lt;1，故 |f(x)|&lt;|A|+1。∎

**注意**：是"局部"有界——只在 x₀ 附近的一个小邻域内有界，不要求在整个定义域上有界。这与数列极限的"整体有界"不同（数列的有界性是对所有项成立的）。

### 3.3 局部保号性

**定理**：若 limₓ→x₀ f(x)=A>0（或 A&lt;0），则存在 δ>0，使得 0&lt;|x-x₀|&lt;δ 时 f(x)>0（或 f(x)&lt;0）。

**证明**：设 A>0，取 ε=A/2>0，存在 δ>0 使得 0&lt;|x-x₀|&lt;δ 时 |f(x)-A|&lt;A/2，故 f(x)>A-A/2=A/2>0。∎

**推论（局部保不等式性）**：若 limₓ→x₀ f(x)=A, limₓ→x₀ g(x)=B，且存在 δ₀>0 使得 0&lt;|x-x₀|&lt;δ₀ 时 f(x)≤g(x)，则 A≤B。

**注意**：与数列类似，即使 f(x)&lt;g(x)（严格小于），也只能推出 A≤B（非严格）。

### 3.4 迫敛性（夹逼定理）

**定理**：若存在 δ₀>0，使得 0&lt;|x-x₀|&lt;δ₀ 时 f(x)≤g(x)≤h(x)，且 limₓ→x₀ f(x)=limₓ→x₀ h(x)=A，则 limₓ→x₀ g(x)=A。

**证明**：与数列夹逼定理类似。∀ε>0，存在 δ₁ 使得 0&lt;|x-x₀|&lt;δ₁ 时 |f(x)-A|&lt;ε，即 A-ε&lt;f(x)&lt;A+ε；存在 δ₂ 使得 0&lt;|x-x₀|&lt;δ₂ 时 |h(x)-A|&lt;ε，即 A-ε&lt;h(x)&lt;A+ε。取 δ=min(δ₀,δ₁,δ₂)，则 0&lt;|x-x₀|&lt;δ 时 A-ε&lt;f(x)≤g(x)≤h(x)&lt;A+ε，故 |g(x)-A|&lt;ε。∎

### 3.5 基本性质的统一视角

函数极限的基本性质（唯一性、局部有界性、局部保号性、迫敛性）与数列极限的基本性质类似，但有一个关键区别：

- **数列极限**：性质是"整体"的——有界性对所有项成立，保号性对所有充分大的项成立
- **函数极限**：性质是"局部"的——有界性只在 x₀ 附近的小邻域内成立，保号性只在 x₀ 附近的小邻域内成立

这个区别的根源是：数列的"自变量"n 只有一个方向（n→∞），而函数的"自变量"x 可以在整个定义域上变化，极限只描述 x₀ 附近的局部行为。

**📐 几何图像**：函数极限的局部性质在几何上是"x₀ 附近的小窗口"。局部有界性意味着在 x₀ 附近的一个小窗口内，函数图像不会跑到无穷远——它被限制在一个有限的水平范围内。局部保号性意味着在 x₀ 附近的一个小窗口内，函数图像全部在 x 轴上方（如果极限为正）或下方（如果极限为负）。迫敛性意味着如果 g(x) 的图像在 x₀ 附近被夹在 f(x) 和 h(x) 之间，而 f(x) 和 h(x) 都"挤进"目标带，那么 g(x) 也被"挤"进目标带。这些性质都是"局部"的——它们只描述 x₀ 附近的小窗口内的行为，不关心窗口外的函数图像。

## 第四章 函数极限的四则运算

### 4.1 加减乘除

**定理**：若 limₓ→x₀ f(x)=A, limₓ→x₀ g(x)=B，则：
1. limₓ→x₀ [f(x)±g(x)] = A±B
2. limₓ→x₀ [f(x)·g(x)] = A·B
3. limₓ→x₀ [f(x)/g(x)] = A/B（若 B≠0 且 g(x)≠0 在 x₀ 附近）

**证明思路**：与数列极限的四则运算证明完全类似，利用三角不等式和局部有界性。

**加法证明**：|(f+g)-(A+B)| ≤ |f-A|+|g-B| &lt; ε/2+ε/2 = ε。

**乘法证明**：|fg-AB| = |f(g-B)+B(f-A)| ≤ |f||g-B|+|B||f-A|。利用 f 的局部有界性（|f|≤M），控制两项都小于 ε/2。

**除法证明**：先证 1/g→1/B（利用 |1/g-1/B|=|g-B|/(|g||B|)，再利用 g 的局部保号性控制 |g|≥|B|/2），再用乘法法则 f/g = f·(1/g)。

### 4.2 四则运算的条件与局限

**条件**：两个函数的极限都存在（有限），除法还要求分母极限非零。

**不定式**：当四则运算的条件不满足时（如 0/0、∞/∞、0·∞、∞-∞），不能直接用四则运算法则，需要特殊方法（如因式分解、有理化、等价无穷小、洛必达法则等）。

**常见不定式类型**：
1. **0/0 型**：分子分母都趋于 0。方法：因式分解、有理化、等价无穷小、洛必达法则
2. **∞/∞ 型**：分子分母都趋于无穷。方法：除以最高次、洛必达法则
3. **0·∞ 型**：一个因子趋于 0，另一个趋于无穷。方法：转化为 0/0 或 ∞/∞（取倒数）
4. **∞-∞ 型**：两个无穷大相减。方法：通分、有理化、提取公因子
5. **1^∞ 型**：底数趋于 1，指数趋于无穷。方法：取对数转化为 0·∞，或利用重要极限 lim(1+1/x)^x=e
6. **0⁰ 型**：底数和指数都趋于 0。方法：取对数转化为 0·∞
7. **∞⁰ 型**：底数趋于无穷，指数趋于 0。方法：取对数转化为 0·∞

### 4.3 四则运算的应用

**例 1（0/0 型，因式分解）**：
limₓ→1 (x²-1)/(x-1) = limₓ→1 (x-1)(x+1)/(x-1) = limₓ→1 (x+1) = 2

**例 2（0/0 型，有理化）**：
limₓ→0 (√(1+x)-1)/x = limₓ→0 [(√(1+x)-1)(√(1+x)+1)]/[x(√(1+x)+1)] = limₓ→0 x/[x(√(1+x)+1)] = limₓ→0 1/(√(1+x)+1) = 1/2

**例 3（∞/∞ 型，除以最高次）**：
limₓ→∞ (3x²+2x+1)/(x²-5x+2) = limₓ→∞ (3+2/x+1/x²)/(1-5/x+2/x²) = 3

**例 4（∞-∞ 型，通分）**：
limₓ→1 [1/(x-1) - 2/(x²-1)] = limₓ→1 [(x+1)-2]/(x²-1) = limₓ→1 (x-1)/[(x-1)(x+1)] = limₓ→1 1/(x+1) = 1/2

## 第五章 Heine 定理

### 5.1 Heine 定理的表述

**定理（Heine 定理 / 归结原则）**：limₓ→x₀ f(x)=A ⟺ 对任意满足 xₙ→x₀ 且 xₙ≠x₀ 的数列 {xₙ}，都有 limₙ→∞ f(xₙ)=A。

**证明**：
- ⇒（函数极限⇒数列极限）：设 limₓ→x₀ f(x)=A。∀ε>0，存在 δ>0 使得 0&lt;|x-x₀|&lt;δ 时 |f(x)-A|&lt;ε。由 xₙ→x₀ 且 xₙ≠x₀，存在 N 使得 n>N 时 0&lt;|xₙ-x₀|&lt;δ，故 |f(xₙ)-A|&lt;ε。因此 f(xₙ)→A。
- ⇐（数列极限⇒函数极限）：反证。假设 limₓ→x₀ f(x)≠A，则存在 ε₀>0，使得对任意 δ>0，都存在 x 满足 0&lt;|x-x₀|&lt;δ 但 |f(x)-A|≥ε₀。取 δ=1/n，则存在 xₙ 满足 0&lt;|xₙ-x₀|&lt;1/n 但 |f(xₙ)-A|≥ε₀。显然 xₙ→x₀ 且 xₙ≠x₀，但 f(xₙ)↛A，与条件矛盾。故 limₓ→x₀ f(x)=A。∎

### 5.2 Heine 定理的意义

Heine 定理是函数极限与数列极限之间的桥梁，它的重要性体现在：

1. **将函数极限转化为数列极限**：函数极限的问题可以转化为数列极限的问题，利用数列极限的理论来解决。

2. **证明函数极限不存在**：这是 Heine 定理最常用的应用——找到两个数列 xₙ→x₀, yₙ→x₀（xₙ,yₙ≠x₀），使得 f(xₙ) 和 f(yₙ) 收敛到不同极限（或一个收敛一个发散），则 limₓ→x₀ f(x) 不存在。

3. **将数列极限的性质推广到函数极限**：函数极限的唯一性、有界性、保号性、四则运算等都可以通过 Heine 定理转化为数列极限的对应性质来证明。

4. **理解函数极限的本质**：函数极限描述的是"所有趋近于 x₀ 的路径上的函数值都趋于 A"——Heine 定理将"所有路径"严格表述为"所有满足 xₙ→x₀ 的数列"。

### 5.3 Heine 定理的应用——证明极限不存在

**例 1**：证明 limₓ→0 sin(1/x) 不存在。

证明：取 xₙ=1/(2nπ)→0，则 sin(1/xₙ)=sin(2nπ)=0→0。
取 yₙ=1/(2nπ+π/2)→0，则 sin(1/yₙ)=sin(2nπ+π/2)=1→1。
两个数列都趋于 0，但函数值趋于不同极限（0 和 1），由 Heine 定理，limₓ→0 sin(1/x) 不存在。∎

**例 2**：证明 limₓ→0 D(x) 不存在（D(x) 为 Dirichlet 函数）。

证明：取有理数列 xₙ→0（xₙ≠0），则 D(xₙ)=1→1。
取无理数列 yₙ→0（yₙ≠0），则 D(yₙ)=0→0。
由 Heine 定理，limₓ→0 D(x) 不存在。∎

**例 3**：证明 limₓ→+∞ sin x 不存在。

证明：取 xₙ=2nπ→+∞，则 sin xₙ=0→0。
取 yₙ=2nπ+π/2→+∞，则 sin yₙ=1→1。
由 Heine 定理（x→+∞ 的版本），limₓ→+∞ sin x 不存在。∎

### 5.4 Heine 定理的推广

Heine 定理可以推广到其他类型的函数极限：

1. **x→x₀⁺（右极限）**：limₓ→x₀⁺ f(x)=A ⟺ 对任意满足 xₙ→x₀⁺（即 xₙ>x₀ 且 xₙ→x₀）的数列 {xₙ}，都有 f(xₙ)→A。

2. **x→+∞**：limₓ→+∞ f(x)=A ⟺ 对任意满足 xₙ→+∞ 的数列 {xₙ}，都有 f(xₙ)→A。

3. **无穷大极限**：limₓ→x₀ f(x)=+∞ ⟺ 对任意满足 xₙ→x₀ 且 xₙ≠x₀ 的数列 {xₙ}，都有 f(xₙ)→+∞。

### 5.5 Heine 定理的几何理解

**📐 几何图像**：Heine 定理的几何图像是"所有通向 x₀ 的路径都到达 A"。在 x-y 平面上，函数极限 limₓ→x₀ f(x)=A 意味着：不管你沿着 x 轴上的哪条路径（数列）趋近 x₀，对应的函数值（y 坐标）都趋近 A。Heine 定理将"所有路径"严格表述为"所有满足 xₙ→x₀ 的数列"——每一个数列代表一条"离散的路径"，所有路径上的函数值都趋于 A，等价于函数极限存在且等于 A。

如果存在两条路径（两个数列）通向 x₀，但函数值趋于不同的极限，那么函数极限不存在——几何上，函数图像在 x₀ 附近"分裂"成两个不同的趋势，沿着不同路径趋近 x₀ 会到达不同的高度。这就是 sin(1/x) 在 x→0 时极限不存在的几何原因——函数图像在 x=0 附近无限振荡，沿着不同路径趋近 0 会到达不同的高度。

## 第六章 复合函数的极限

### 6.1 复合函数极限定理

**定理**：设函数 y=f(u) 和 u=g(x) 构成复合函数 y=f(g(x))。若：
1. limₓ→x₀ g(x) = u₀
2. limᵤ→u₀ f(u) = A
3. 在 x₀ 的某去心邻域内 g(x)≠u₀（或 f 在 u₀ 处连续）

则 limₓ→x₀ f(g(x)) = A。

**证明**：∀ε>0，由 limᵤ→u₀ f(u)=A，存在 η>0 使得 0&lt;|u-u₀|&lt;η 时 |f(u)-A|&lt;ε。
由 limₓ→x₀ g(x)=u₀，存在 δ>0 使得 0&lt;|x-x₀|&lt;δ 时 |g(x)-u₀|&lt;η。
如果在 x₀ 附近 g(x)≠u₀，则 0&lt;|g(x)-u₀|&lt;η，故 |f(g(x))-A|&lt;ε。
如果 f 在 u₀ 处连续，则即使 g(x)=u₀，也有 |f(g(x))-A|=|f(u₀)-A|=0&lt;ε。∎

### 6.2 条件 3 的重要性

条件 3（g(x)≠u₀ 或 f 连续）是必要的，否则定理可能不成立。

**反例**：设 g(x)=0（常数函数），f(u)={1, u≠0; 0, u=0}。
则 limₓ→0 g(x)=0，limᵤ→0 f(u)=1。
但 f(g(x))=f(0)=0，所以 limₓ→0 f(g(x))=0≠1。

原因：g(x)=0=u₀，不满足条件 3（g(x)≠u₀），而 f 在 u₀=0 处不连续。

### 6.3 变量替换法

复合函数极限定理是"变量替换法"的理论基础。

**变量替换法**：在计算 limₓ→x₀ f(g(x)) 时，令 u=g(x)，如果 limₓ→x₀ g(x)=u₀ 且满足条件 3，则 limₓ→x₀ f(g(x))=limᵤ→u₀ f(u)。

**例 1**：limₓ→0 sin(2x)/x
令 u=2x，则 x→0 时 u→0，且 u≠0（x≠0 时）。
limₓ→0 sin(2x)/x = limₓ→0 2·sin(2x)/(2x) = 2·limᵤ→0 sin u/u = 2·1 = 2

**例 2**：limₓ→∞ (1+1/x)^x
令 u=1/x，则 x→∞ 时 u→0⁺，且 u≠0。
limₓ→∞ (1+1/x)^x = limᵤ→0⁺ (1+u)^{1/u} = e

### 6.4 复合函数极限的几何理解

**📐 几何图像**：复合函数的极限在几何上是"两步趋近"——先让 x 趋近 x₀，对应的 u=g(x) 趋近 u₀；再让 u 趋近 u₀，对应的 y=f(u) 趋近 A。复合函数极限定理说的是：如果两步趋近都"正常"（g(x) 不"停在"u₀，或者 f 在 u₀ 处连续），那么复合后的趋近也正常——x→x₀ 时 f(g(x))→A。

条件 3 的几何意义是：g(x) 在趋近 u₀ 的过程中"不踩在"u₀ 上——它只是经过 u₀ 附近，不会停在 u₀。如果 g(x) 停在 u₀（如常数函数 g(x)=u₀），那么 f(g(x))=f(u₀)，而 f(u₀) 可能不等于 limᵤ→u₀ f(u)（如果 f 在 u₀ 处不连续）。这就是为什么需要条件 3——确保复合函数的极限由 f 的极限决定，而不是由 f(u₀) 的值决定。

## 第七章 未定式与渐近分析

### 7.1 无穷小与无穷大

**定义（无穷小）**：若 limₓ→x₀ f(x)=0，则称 f(x) 当 x→x₀ 时为无穷小量（简称无穷小）。

**定义（无穷大）**：若 limₓ→x₀ f(x)=∞（绝对值发散到无穷），则称 f(x) 当 x→x₀ 时为无穷大量（简称无穷大）。

**无穷小与无穷大的关系**：若 f(x) 为无穷大，则 1/f(x) 为无穷小；若 f(x) 为无穷小且 f(x)≠0，则 1/f(x) 为无穷大。

**无穷小的运算性质**：
1. 有限个无穷小的和仍是无穷小
2. 有界函数与无穷小的乘积仍是无穷小
3. 常数与无穷小的乘积仍是无穷小
4. 有限个无穷小的乘积仍是无穷小
5. 无穷小除以极限非零的函数仍是无穷小

**注意**：无穷小除以无穷小不一定是无穷小（0/0 型不定式）；两个无穷小的商可以是任何值，取决于它们"趋近 0 的速度"。

### 7.2 无穷小的比较

设 f(x) 和 g(x) 都是 x→x₀ 时的无穷小，且 g(x)≠0。

**高阶无穷小**：若 lim f(x)/g(x)=0，则称 f(x) 是比 g(x) 高阶的无穷小，记作 f(x)=o(g(x))（x→x₀）。

**低阶无穷小**：若 lim f(x)/g(x)=∞，则称 f(x) 是比 g(x) 低阶的无穷小。

**同阶无穷小**：若 lim f(x)/g(x)=c≠0，则称 f(x) 与 g(x) 是同阶无穷小。

**等价无穷小**：若 lim f(x)/g(x)=1，则称 f(x) 与 g(x) 是等价无穷小，记作 f(x)~g(x)（x→x₀）。

**k 阶无穷小**：若 lim f(x)/[g(x)]^k=c≠0，则称 f(x) 是关于 g(x) 的 k 阶无穷小。

**常见等价无穷小（x→0）**：
1. sin x ~ x
2. tan x ~ x
3. arcsin x ~ x
4. arctan x ~ x
5. 1-cos x ~ x²/2
6. e^x - 1 ~ x
7. ln(1+x) ~ x
8. (1+x)^α - 1 ~ αx
9. a^x - 1 ~ x ln a
10. log_a(1+x) ~ x/ln a

### 7.3 等价无穷小替换定理

**定理**：设 f(x)~f₁(x), g(x)~g₁(x)（x→x₀），且 lim f₁(x)/g₁(x) 存在，则 lim f(x)/g(x) = lim f₁(x)/g₁(x)。

**证明**：lim f/g = lim (f/f₁)·(f₁/g₁)·(g₁/g) = 1·lim(f₁/g₁)·1 = lim f₁/g₁。∎

**应用**：在计算 0/0 型极限时，可以将分子分母中的无穷小因子替换为等价无穷小，简化计算。

**例**：limₓ→0 sin(3x)·ln(1+2x)/(1-cos x)
= limₓ→0 (3x)·(2x)/(x²/2) = limₓ→0 6x²/(x²/2) = 12

**注意**：等价无穷小替换只能用于乘除因子，不能用于加减项！

**反例**：limₓ→0 (tan x - sin x)/x³
错误做法：tan x~x, sin x~x，所以 (tan x - sin x)/x³ ~ (x-x)/x³=0，极限=0。
正确做法：tan x - sin x = sin x(1/cos x - 1) = sin x(1-cos x)/cos x ~ x·(x²/2)/1 = x³/2，所以极限=1/2。

原因：tan x 和 sin x 都是 x 的等价无穷小，但它们的差 tan x - sin x 是 x³ 的同阶无穷小——直接替换会丢失高阶信息。

### 7.4 大O与小o记号

**小o记号**：f(x)=o(g(x))（x→x₀）表示 limₓ→x₀ f(x)/g(x)=0。即 f(x) 是比 g(x) 高阶的无穷小（如果 g(x) 是无穷小），或 f(x)/g(x)→0。

**大O记号**：f(x)=O(g(x))（x→x₀）表示存在常数 C>0 和 δ>0，使得 0&lt;|x-x₀|&lt;δ 时 |f(x)|≤C|g(x)|。即 f(x)/g(x) 在 x₀ 附近有界。

**大O与小o的关系**：
- f(x)=o(g(x)) ⟹ f(x)=O(g(x))（小o蕴含大O）
- f(x)=O(g(x)) 不蕴含 f(x)=o(g(x))（大O不蕴含小o）

**常见用法**：
- Taylor 展开的余项：f(x)=f(x₀)+f'(x₀)(x-x₀)+o(x-x₀)（Peano 余项）
- 渐近估计：f(x)=O(g(x)) 表示 f 和 g 同阶或更低阶
- 误差分析：误差=o(1) 表示误差趋于 0

**运算规则**：
1. o(f) ± o(f) = o(f)
2. O(f) ± O(f) = O(f)
3. o(f) · O(g) = o(f·g)
4. O(f) · O(g) = O(f·g)
5. f · o(g) = o(f·g)
6. o(f) = O(f)

### 7.5 渐近分析的几何理解

**📐 几何图像**：无穷小的比较在几何上是"趋近 0 的速度"。在 x-y 平面上，两个无穷小函数 f(x) 和 g(x) 都随着 x→x₀ 而趋近 0（图像趋近 x 轴），但它们"下降的速度"不同。高阶无穷小下降得更快——图像更"陡峭"地贴近 x 轴。等价无穷小下降的速度相同——图像在 x₀ 附近"几乎重合"（比值趋于 1）。

大O和小o记号在几何上是"增长速度的比较"。f=O(g) 表示 f 的图像被 g 的图像的某个倍数"压住"——f 不会比 g 增长得更快。f=o(g) 表示 f/g→0——f 的图像相对于 g 的图像来说"可以忽略"，g 是"主导项"。

渐近分析的核心思想是"抓住主导项，忽略高阶小项"——在计算极限时，只需要知道函数的"主要部分"（等价无穷小或主导项），高阶小项可以忽略。这在几何上就是"只看图像的主要趋势，忽略微小的波动"。

## 第八章 两个重要极限

### 8.1 第一个重要极限：limₓ→0 sin x/x = 1

**定理**：limₓ→0 sin x/x = 1。

**证明（几何方法）**：
考虑单位圆中的扇形，设 0&lt;x&lt;π/2（x 为弧度）。
比较三个区域的面积：
- 三角形 OAB 的面积 = (1/2)sin x
- 扇形 OAB 的面积 = (1/2)x
- 三角形 OAC 的面积 = (1/2)tan x

由面积大小关系：(1/2)sin x &lt; (1/2)x &lt; (1/2)tan x
即 sin x &lt; x &lt; tan x
除以 sin x（正数）：1 &lt; x/sin x &lt; 1/cos x
取倒数：cos x &lt; sin x/x &lt; 1

由 limₓ→0⁺ cos x = 1 和夹逼定理，limₓ→0⁺ sin x/x = 1。

对于 x→0⁻，令 t=-x→0⁺，则 sin x/x = sin(-t)/(-t) = (-sin t)/(-t) = sin t/t→1。
故 limₓ→0 sin x/x = 1。∎

**几何理解**：这个极限的几何意义是"当弧长 x 很小时，弦长 sin x 与弧长 x 的比值趋于 1"——在很小的尺度上，圆弧近似于直线（弦近似于弧）。这是"以直代曲"思想的数学表达。

**应用**：
- limₓ→0 tan x/x = 1（tan x = sin x/cos x，cos x→1）
- limₓ→0 arcsin x/x = 1（令 t=arcsin x，则 x=sin t，t→0）
- limₓ→0 (1-cos x)/x² = 1/2（1-cos x=2sin²(x/2)，sin(x/2)/(x/2)→1）

### 8.2 第二个重要极限：limₓ→∞ (1+1/x)^x = e

**定理**：limₓ→∞ (1+1/x)^x = e，其中 e 是自然对数的底（欧拉数）。

**证明思路**：
第一步：证明数列极限 limₙ→∞ (1+1/n)^n 存在。
- 证明数列 aₙ=(1+1/n)^n 单调递增（二项式展开比较）
- 证明数列有上界（aₙ&lt;3，由二项式展开估计）
- 由单调有界定理，极限存在，记为 e

第二步：证明函数极限 limₓ→∞ (1+1/x)^x = e。
- 对任意 x>0，取 n=[x]（不超过 x 的最大整数），则 n≤x&lt;n+1
- 由单调性：(1+1/(n+1))^n &lt; (1+1/x)^x &lt; (1+1/n)^{n+1}
- 两边都趋于 e，由夹逼定理，limₓ→+∞ (1+1/x)^x = e
- 对于 x→-∞，令 t=-x→+∞，则 (1+1/x)^x=(1-1/t)^{-t}=[t/(t-1)]^t=[1+1/(t-1)]^t→e

**e 的性质**：
- e ≈ 2.718281828459045...
- e 是无理数（欧拉证明），实际上是超越数（埃尔米特证明）
- e = Σ_{n=0}^∞ 1/n! = 1 + 1 + 1/2! + 1/3! + ...
- e = limₙ→∞ (1+1/n)^n

**等价形式**：
- limₓ→0 (1+x)^{1/x} = e（令 t=1/x）
- limₓ→0 (1+kx)^{1/x} = e^k
- limₓ→∞ (1+k/x)^x = e^k

**几何理解**：第二个重要极限的几何意义是"复利的连续化"——如果年利率为 100%，每年复利一次，本利和为 2；每年复利 n 次，本利和为 (1+1/n)^n；当 n→∞（连续复利）时，本利和趋于 e≈2.718。这是"离散复利"到"连续复利"的极限。

**应用**：
- 1^∞ 型极限的计算：lim f(x)^{g(x)}，其中 f(x)→1, g(x)→∞
  方法：取对数 ln(f^{g})=g·ln f = g·ln[1+(f-1)] ~ g(f-1)，然后计算 exp(lim g(f-1))
- 例：limₓ→∞ (1+2/x)^x = e^2
- 例：limₓ→0 (cos x)^{1/x²} = exp(limₓ→0 ln(cos x)/x²) = exp(limₓ→0 (cos x-1)/x²) = exp(limₓ→0 (-x²/2)/x²) = e^{-1/2}

### 8.3 两个重要极限的统一视角

两个重要极限虽然形式不同，但有共同的本质：

1. **第一个重要极限**：limₓ→0 sin x/x = 1——"小角度下，弧近似于弦"，是三角函数在 0 附近的线性近似（sin x ≈ x）
2. **第二个重要极限**：limₓ→∞ (1+1/x)^x = e——"连续复利的极限"，是指数函数的定义基础（e^x = lim(1+x/n)^n）

两个重要极限都是"0/0"或"1^∞"型不定式的标准结果，它们是计算更复杂极限的基础。

### 9.2 综合例题

**例 1（0/0 型，等价无穷小+重要极限）**：
limₓ→0 (e^{sin x}-1)/ln(1+tan x)
= limₓ→0 sin x / tan x （e^{sin x}-1~sin x, ln(1+tan x)~tan x）
= limₓ→0 sin x / (sin x/cos x) = limₓ→0 cos x = 1

**例 2（1^∞ 型，取对数）**：
limₓ→0 (1+sin x)^{1/x}
= exp(limₓ→0 ln(1+sin x)/x)
= exp(limₓ→0 sin x/x) （ln(1+sin x)~sin x）
= exp(1) = e

**例 3（∞-∞ 型，有理化）**：
limₓ→+∞ (√(x²+x)-√(x²-x))
= limₓ→+∞ [(√(x²+x)-√(x²-x))(√(x²+x)+√(x²-x))]/(√(x²+x)+√(x²-x))
= limₓ→+∞ (2x)/(√(x²+x)+√(x²-x))
= limₓ→+∞ 2/(√(1+1/x)+√(1-1/x)) = 2/(1+1) = 1

**例 4（∞/∞ 型，除以最高次）**：
limₓ→∞ (2x³+3x²+1)/(5x³-4x+2)
= limₓ→∞ (2+3/x+1/x³)/(5-4/x²+2/x³) = 2/5

## 第十章 反例库

### 10.1 极限不存在的反例

**反例 1：左右极限不等**
f(x)={x+1, x≥0; x-1, x&lt;0}，在 x=0 处左极限=-1，右极限=1，双侧极限不存在。

**反例 2：振荡函数**
f(x)=sin(1/x)，x→0 时极限不存在（无限振荡）。

**反例 3：Dirichlet 函数**
D(x)={1, x∈ℚ; 0, x∉ℚ}，在任何点处极限都不存在。

**反例 4：无界振荡**
f(x)=(1/x)sin(1/x)，x→0 时无界且不趋于无穷（振荡幅度越来越大）。

### 10.2 四则运算的反例

**反例 5：两个极限不存在的函数的和极限存在**
f(x)=sin(1/x), g(x)=-sin(1/x)，都不存在极限，但 f+g=0 极限存在。

**反例 6：0/0 型不定式结果不确定**
- limₓ→0 x²/x = 0
- limₓ→0 x/x = 1
- limₓ→0 x/x² = ∞
同样是 0/0 型，结果可以是 0、1、∞。

**反例 7：∞-∞ 型不定式结果不确定**
- limₓ→∞ (x+1)-x = 1
- limₓ→∞ (x²+x)-x² = ∞
- limₓ→∞ (x+1/x)-x = 0

### 10.3 Heine 定理的反例

**反例 8：存在一个数列收敛但函数极限不存在**
f(x)=sin(1/x)，取 xₙ=1/(2nπ)→0，则 f(xₙ)=0→0。但函数极限不存在（取另一个数列 yₙ=1/(2nπ+π/2)→0，f(yₙ)=1→1）。
说明：存在一个收敛数列不代表函数极限存在，需要"所有"数列都收敛到同一极限。

**反例 9：所有有理数列收敛但函数极限不存在**
f(x)=D(x)（Dirichlet 函数），对所有有理数列 xₙ→x₀，f(xₙ)=1→1。但函数极限不存在（无理数列给出 0）。
说明：Heine 定理要求"所有"数列，包括有理数列和无理数列。

### 10.4 复合函数极限的反例

**反例 10：条件 3 不满足时复合函数极限定理不成立**
g(x)=0（常数），f(u)={1, u≠0; 0, u=0}。
limₓ→0 g(x)=0, limᵤ→0 f(u)=1，但 limₓ→0 f(g(x))=f(0)=0≠1。

### 10.5 等价无穷小替换的反例

**反例 11：加减项不能用等价无穷小替换**
limₓ→0 (tan x - sin x)/x³
错误：tan x~x, sin x~x ⇒ (x-x)/x³=0
正确：tan x - sin x = sin x(1-cos x)/cos x ~ x·(x²/2) = x³/2 ⇒ 极限=1/2

**反例 12：等价无穷小替换的阶数不够**
limₓ→0 (x - sin x)/x³
sin x~x 替换后得到 0，但正确结果是 1/6（需要 sin x=x-x³/6+o(x³) 的展开）。
说明：等价无穷小替换只给出"一阶近似"，当一阶项抵消时，需要更高阶的展开。

### 10.6 局部性质的反例

**反例 13：极限存在但函数在整个定义域上无界**
f(x)=1/x，limₓ→1 f(x)=1（存在），但 f(x) 在 (0,∞) 上无界（x→0⁺ 时 f(x)→∞）。
说明：函数极限的有界性是"局部"的——只在 x₀ 附近有界，不要求在整个定义域上有界。

**反例 14：极限为正但函数在某些点为负**
f(x)=x，limₓ→1 f(x)=1>0，但 f(x) 在 x&lt;0 时为负。
说明：局部保号性只保证在 x₀ 附近的小邻域内保号，不保证在整个定义域上保号。

### 11.3 历史发展的主线

函数极限理论的历史发展有三条主线：

**主线一：严格化**
从无穷小（不严格）→ 柯西动态定义（半严格）→ 魏尔斯特拉斯 ε-δ（严格）→ 实数构造（完全严格）。

**主线二：函数概念的演化**
从"解析表达式"（欧拉）→ "任意对应关系"（狄利克雷）→ "集合间的映射"（康托尔/豪斯多夫）。函数概念的扩展使得函数极限理论能处理更广泛的函数（包括病态函数如 Dirichlet 函数）。

**主线三：一般化**
从实数函数的极限 → 度量空间中的极限 → 拓扑空间中的极限（邻域定义）。每一次一般化都扩展了极限理论的适用范围。

### 12.4 关键蜕变问题

**问题一：函数极限与数列极限的本质区别是什么？**

回答：数列极限的自变量 n 是离散的（只有 n→∞ 一个方向），函数极限的自变量 x 是连续的（可以从任意方向趋近 x₀，也可以趋近 ±∞）。函数极限比数列极限更丰富——它有单侧极限、无穷极限等多种类型，而且函数在 x₀ 处的值与极限无关（去心邻域）。但 Heine 定理建立了两者的等价性——函数极限存在当且仅当所有趋近路径上的数列极限都存在且相等。

**问题二：Heine 定理为什么重要？**

回答：Heine 定理是函数极限与数列极限之间的桥梁。它的重要性体现在三个方面：(1) 将函数极限转化为数列极限，利用数列极限的理论来解决函数极限的问题；(2) 证明函数极限不存在——找到两个数列趋于不同极限即可；(3) 理解函数极限的本质——"所有趋近路径上的函数值都趋于 A"。Heine 定理是分析学中最重要的定理之一，它将离散与连续统一起来。

**问题三：为什么等价无穷小替换不能用于加减项？**

回答：等价无穷小替换的理论基础是"乘除因子的极限等于等价无穷小的极限"——证明中利用了 f/f₁→1 和 g₁/g→1，所以 f/g=(f/f₁)(f₁/g₁)(g₁/g)→1·(f₁/g₁)·1。但对于加减项 f-g，替换为 f₁-g₁ 后，(f-g)/(f₁-g₁) 不一定趋于 1——因为 f 和 g 的一阶项可能抵消，此时差的阶数高于一阶，等价无穷小（一阶近似）无法捕捉高阶信息。因此加减项需要更高阶的展开（如 Taylor 展开），不能直接用一阶等价无穷小替换。

**问题四：两个重要极限为什么重要？**

回答：第一个重要极限 lim sin x/x=1 是三角函数在 0 附近的线性近似（sin x≈x），它是"以直代曲"思想的数学表达，也是导数公式 (sin x)'=cos x 的基础。第二个重要极限 lim(1+1/x)^x=e 是指数函数的定义基础，它描述了"连续复利"的极限，也是导数公式 (e^x)'=e^x 的基础。两个重要极限分别是三角函数和指数函数的"基石"，而三角函数和指数函数是分析学中最重要的两类初等函数，因此两个重要极限在极限理论中占据核心地位。

### 13.3 常见误区清单

1. **函数极限与 f(x₀) 有关** → 错。极限描述的是 x₀ 附近的趋势，与 f(x₀) 无关，f(x₀) 甚至可以没有定义。
2. **δ 必须是最大的** → 错。δ 只需要存在，不需要最大。
3. **左右极限存在则双侧极限存在** → 错。还需要左右极限相等。
4. **两个极限不存在的函数的和极限不存在** → 错。可以存在（如 sin(1/x)+(-sin(1/x))=0）。
5. **等价无穷小可以用于加减项** → 错。只能用于乘除因子，加减项需要更高阶展开。
6. **0/0 型极限等于 0** → 错。0/0 是不定式，结果可以是任何值（包括 0、有限非零、无穷）。
7. **1^∞ 型极限等于 1** → 错。1^∞ 是不定式，结果通常不是 1（如 (1+1/x)^x→e）。
8. **Heine 定理只需要一个数列收敛** → 错。需要"所有"满足 xₙ→x₀ 的数列都收敛到同一极限。
9. **复合函数极限定理不需要条件 3** → 错。需要 g(x)≠u₀ 或 f 连续，否则定理可能不成立。
10. **无穷小是一个很小的数** → 错（在标准实数系中）。无穷小是"极限为 0 的变量"，不是一个固定的很小的数。
11. **大O和小o是一样的** → 错。小o蕴含大O，但大O不蕴含小o。f=O(g) 表示 f/g 有界，f=o(g) 表示 f/g→0。
12. **局部有界性意味着函数在整个定义域上有界** → 错。只在 x₀ 附近的小邻域内有界。

- D1-3 → D1-7 极限蜕变图谱（本领域收束）

### 15.2 类比

- 函数极限与数列极限：都是"最终接近"，前者连续（x→x₀），后者离散（n→∞）
- 双侧极限与数列极限：双侧极限要求左右两侧都趋于 A，数列极限只有一个方向
- Heine 定理与子列定理：都是"通过子序列/子路径判断收敛"
- 函数极限的局部有界性与数列极限的整体有界性：前者局部，后者整体
- 等价无穷小替换与数列极限的 Stolz 定理：都是处理不定式的工具
- 两个重要极限与数列极限的标准极限：都是计算更复杂极限的基础
- 大O/小o记号与数列的增长速度比较：都是"阶"的比较
- 复合函数极限与复合数列极限：都是"两步趋近"

### 15.3 推广

- 从一元函数极限到多元函数极限（n 维欧氏空间）
- 从实函数极限到复函数极限（模长度量，方向自由度）
- 从函数极限到函数列极限（多种收敛模式）
- 从 ε-δ 定义到拓扑空间中的邻域定义
- 从双侧极限到单侧极限、无穷极限、无穷大极限
- 从有限极限到扩展实数系中的极限（±∞）
- 从等价无穷小到渐近展开（Taylor 展开、大O/小o）
- 从 Heine 定理到更一般的"网收敛"（拓扑空间中的推广）
- 从两个重要极限到更一般的标准极限（如 lim(1+x/n)^n=e^x）

### 15.4 特例

- 数列极限是函数极限的特例（定义域为 ℕ，x→∞）
- 单侧极限是双侧极限的特例（限制趋近方向）
- 右极限/左极限是单侧极限的特例
- x→+∞ 是函数极限的特例（自变量趋于无穷）
- 无穷大极限是极限不存在的特例（有明确趋势的发散）
- 连续函数的极限是函数极限的特例（极限值=函数值）
- 多项式函数的极限是函数极限的特例（直接代入）
- 0/0 型是不定式的特例（最常见的类型）
- 等价无穷小是同阶无穷小的特例（比值=1）
- 第一个重要极限是 0/0 型的特例
- 第二个重要极限是 1^∞ 型的特例

### 15.5 反例簇

- 极限不存在簇：左右极限不等、振荡函数（sin(1/x)）、Dirichlet 函数、无界振荡
- 四则运算反例簇：两个发散的和收敛、0/0 型结果不确定、∞-∞ 型结果不确定
- Heine 定理反例簇：一个数列收敛但函数极限不存在、有理数列收敛但函数极限不存在
- 复合函数反例簇：条件 3 不满足时定理不成立（常数函数 g+不连续 f）
- 等价无穷小反例簇：加减项不能替换（tan x - sin x）、阶数不够（x - sin x）
- 局部性质反例簇：极限存在但整体无界、极限为正但某些点为负
- 不定式簇：0/0、∞/∞、0·∞、∞-∞、1^∞、0⁰、∞⁰
- 无穷小比较反例簇：两个无穷小不可比较（比值振荡）、高阶无穷小的和仍为高阶

> **模块结语 · D1 极限领域核心理论（续）**：
>
> 函数极限是分析学从离散到连续的关键一步——它将 D1-2 的数列极限理论推广到连续的函数，建立了函数极限的完整理论体系。
>
> 本模块从六个维度建立了函数极限的完整理论：
>
> **定义体系**：双侧极限、单侧极限、无穷极限、无穷大极限——函数极限比数列极限更丰富，因为自变量 x 可以从任意方向趋近 x₀，也可以趋近 ±∞。去心邻域 0&lt;|x-x₀| 是函数极限最关键的特征——函数在 x₀ 处的值与极限无关。
>
> **基本性质**：唯一性、局部有界性、局部保号性、迫敛性——与数列极限的性质类似，但函数极限的性质是"局部"的（只在 x₀ 附近成立），而数列极限的性质是"整体"的（对所有充分大的项成立）。
>
> **Heine 定理**：函数极限与数列极限的桥梁——limₓ→x₀ f(x)=A 当且仅当所有满足 xₙ→x₀ 的数列都有 f(xₙ)→A。Heine 定理是证明函数极限不存在的最有力工具——找到两个数列趋于不同极限即可。
>
> **四则运算与复合**：加减乘除的极限法则，复合函数极限定理（需要条件 3：g(x)≠u₀ 或 f 连续）。不定式（0/0、∞/∞ 等）不能直接用四则运算，需要特殊方法。
>
> **渐近分析**：无穷小的比较（高阶/低阶/同阶/等价）、等价无穷小替换定理（只能用于乘除因子）、大O/小o记号。渐近分析的核心思想是"抓住主导项，忽略高阶小项"。
>
> **两个重要极限**：lim sin x/x=1（以直代曲）和 lim(1+1/x)^x=e（连续复利）。它们分别是三角函数和指数函数的基石，是计算更复杂极限的基础。
>
> 函数极限理论的核心洞察是：**函数极限的本质是"所有趋近路径上的函数值都趋于 A"（Heine 定理），而去心邻域使得极限与函数值无关——极限描述的是"趋势"，不是"值"**。渐近分析和两个重要极限是计算极限的有力工具，而等价无穷小替换需要注意"只能用于乘除，不能用于加减"。
>
> 下一步，D1-4 将深入研究多元函数极限与路径依赖性——从一维到 n 维，极限的存在性变得更加复杂，因为趋近路径从 2 个（左右）变成无穷多个。
