## 本模块核心考点

1. **重极限的 ε-δ 定义**：多元函数极限的严格表述
2. **路径依赖性**：沿不同路径趋近得到不同极限
3. **累次极限与重极限**：两者的关系与区别
4. **极坐标变换**：应用与陷阱
5. **多元极限的计算方法**：夹逼、变量替换、不等式估计
6. **证明极限不存在**：找两条路径得到不同极限

## L0 初等直觉层

> **引导语**：多元函数极限的直觉从维度升级开始。从一元到二元，x 趋近 x0 变成了 (x,y) 趋近 (x0,y0)，路径从两个方向变成了无穷多条。这一层只有两道直觉题，关键是理解路径依赖性，严格证明从 L1 开始。

**【D1-4-001】** 用自己的话解释"多元函数极限"的直觉含义。它和一元函数极限有什么不同？

- **难度**：★
- **对应知识点**：多元极限的直觉理解
- **解答**：
  多元函数极限的直觉含义是：当自变量 (x,y) 以任意方式趋近 (x₀,y₀) 时，函数值 f(x,y) 趋近于某个确定的数 A。
  
  与一元函数极限的不同：
  1. **趋近方向更多**：一元函数中 x 只能从左右两个方向趋近 x₀；多元函数中 (x,y) 可以从无穷多个方向、沿无穷多条路径趋近 (x₀,y₀)
  2. **路径依赖性**：多元函数极限的存在性比一元复杂得多——沿不同路径可能得到不同极限
  3. **几何图像**：一元函数图像是平面曲线，多元函数图像是三维曲面。极限描述的是曲面在某点上方的"高度趋势"
  
  几何上，多元极限就是"曲面在 (x₀,y₀) 上方没有裂缝——从任何方向靠近，高度都趋于同一个值"。∎
- **一句话点评**：一元极限是"从左右两条路看高度"，多元极限是"从所有方向、所有路径看高度"——后者严格得多。

**【D1-4-002】** 写出二元函数重极限的 ε-δ 定义。为什么需要"去心邻域"？

- **难度**：★
- **对应知识点**：重极限的定义
- **解答**：
  **定义**：设二元函数 f(x,y) 在点 P₀(x₀,y₀) 的某去心邻域内有定义，A 是常数。如果对于任意 ε>0，存在 δ>0，使得当 0&lt;√[(x-x₀)²+(y-y₀)²]&lt;δ 时，有 |f(x,y)-A|&lt;ε，那么称 f(x,y) 当 (x,y)→(x₀,y₀) 时以 A 为极限。
  
  **为什么需要去心邻域**：和一元函数一样，f 在 P₀ 处的值与极限无关——f(P₀) 甚至可以没有定义。极限描述的是"P₀ 附近的趋势"，不是"f(P₀) 的值"。∎
- **一句话点评**：去心邻域就是"排除中心点"——极限关心的是附近的趋势，不是中心点的值。

## L1 数学分析层

> **引导语**：从直觉到严格。这一层涵盖 ε-δ 定义证明、路径依赖性、累次极限、极坐标变换、连续性与可微性。按定义、计算、路径、定理的线索推进。

### 组A：ε-δ 定义与基本证明

**【D1-4-003】** 用 ε-δ 定义证明：lim_{(x,y)→(0,0)} (x²+y²) = 0。

- **难度**：★
- **对应知识点**：定义法证明
- **解答**：
  对于任意 ε>0，取 δ=√ε。当 0&lt;√(x²+y²)&lt;δ 时，|x²+y²-0| = x²+y² &lt; δ² = ε。∎
- **一句话点评**：最基本的多元极限——距离平方就是函数本身。

**【D1-4-006】** 证明：lim_{(x,y)→(0,0)} (x+y) sin(1/x) sin(1/y) = 0。

- **难度**：★★
- **对应知识点**：夹逼定理
- **解答**：
  因为 |sin(1/x)|≤1, |sin(1/y)|≤1，所以
  |f(x,y)-0| = |x+y|·|sin(1/x)|·|sin(1/y)| ≤ |x+y| ≤ |x|+|y|
  
  当 √(x²+y²)&lt;δ 时，|x|≤√(x²+y²)&lt;δ，|y|&lt;δ，所以 |x|+|y|&lt;2δ。
  
  对于任意 ε>0，取 δ=ε/2，则 |f|&lt;2δ=ε。∎
- **一句话点评**：有界函数乘无穷小——极限为零。这是最常用的夹逼技巧。

**【D1-4-007】** 证明：lim_{(x,y)→(0,0)} (x³-xy²)/(x²+y²) = 0。

- **难度**：★★
- **对应知识点**：不等式估计
- **解答**：
  |f| = |x(x²-y²)|/(x²+y²) ≤ |x|·(x²+y²)/(x²+y²) = |x| ≤ √(x²+y²)
  
  对于任意 ε>0，取 δ=ε，则 |f|&lt;δ=ε。∎
- **一句话点评**：分子提取公因子，分母约掉，剩下的就是 |x|——直接估计。

**【D1-4-008】** 计算：lim_{(x,y)→(0,0)} (e^{x²+y²}-1)/(x²+y²)。

- **难度**：★★
- **对应知识点**：变量替换法
- **解答**：
  令 u = x²+y²→0，则
  极限 = lim_{u→0} (e^u-1)/u = 1（一元重要极限）。∎
- **一句话点评**：多元极限可以通过变量替换转化为一元极限——这是最常用的技巧之一。

**【D1-4-016】** 用极坐标变换证明：lim_{(x,y)→(0,0)} x³/(x²+y²) = 0。

- **难度**：★★★
- **对应知识点**：极坐标变换
- **解答**：
  令 x=r cosθ, y=r sinθ，则
  f = r³ cos³θ / r² = r cos³θ。
  
  |f| = r|cos³θ| ≤ r → 0（r→0）。
  
  这个估计与 θ 无关——无论 θ 取什么值，|f|≤r→0。
  
  由夹逼定理，重极限=0。∎
- **一句话点评**：极坐标变换后，|f|≤g(r)，g(r)→0 且与 θ 无关——这是用极坐标证明极限存在的标准方法。

### 组B：路径依赖性与累次极限

**【D1-4-004】** 解释什么是"路径依赖性"。为什么多元函数极限会有路径依赖性，而一元函数没有？

- **难度**：★
- **对应知识点**：路径依赖性
- **解答**：
  **路径依赖性**：沿不同路径趋近 (x₀,y₀) 时，函数值可能趋于不同的极限。如果存在两条路径得到不同极限，重极限就不存在。
  
  **为什么一元函数没有路径依赖性**：一元函数中，x 趋近 x₀ 只有两条路——左边来、右边来。只要左右极限相等，双侧极限就存在。
  
  **为什么多元函数有路径依赖性**：多元函数中，(x,y) 趋近 (x₀,y₀) 有无穷多条路——沿直线、沿抛物线、沿螺旋线……所有路径的极限都必须存在且相等，重极限才存在。
  
  几何上，路径依赖性就是"曲面在某点上方的各向异性"——不同方向的高度趋于不同的值。∎
- **一句话点评**：一元函数只有左右两条路，多元函数有无穷多条路——所有路都通向同一个终点，极限才存在。

**【D1-4-005】** 写出"累次极限"的定义。它和重极限有什么不同？

- **难度**：★
- **对应知识点**：累次极限
- **解答**：
  **累次极限的定义**：
  - 先 x 后 y：lim_{y→y₀} lim_{x→x₀} f(x,y)
  - 先 y 后 x：lim_{x→x₀} lim_{y→y₀} f(x,y)
  
  **与重极限的不同**：
  - 重极限：(x,y) 同时、以任意方式趋近 (x₀,y₀)
  - 累次极限：每次只让一个变量变化，另一个固定——是两次一元极限
  
  累次极限是"分步走"——先固定 y 让 x→x₀，得到关于 y 的函数，再让 y→y₀。∎
- **一句话点评**：重极限是"同时趋近"，累次极限是"分步趋近"——一个是二维的，一个是一维的两次叠加。

### ★★ 进阶应用

**【D1-4-009】** 证明：f(x,y)=xy/(x²+y²) 在 (0,0) 处的重极限不存在。

- **难度**：★★
- **对应知识点**：路径判据
- **解答**：
  沿直线 y=kx 趋近 (0,0)：
  f(x,kx) = x·kx/(x²+k²x²) = k/(1+k²)
  
  - k=0（沿 x 轴）：极限=0
  - k=1（沿 y=x）：极限=1/2
  
  不同路径得到不同极限（0 vs 1/2），由路径判据，重极限不存在。∎
- **一句话点评**：最经典的路径依赖反例——沿直线 y=kx，极限依赖于 k。

**【D1-4-010】** 计算 f(x,y)=xy/(x²+y²) 在 (0,0) 处的两个累次极限。

- **难度**：★★
- **对应知识点**：累次极限的计算
- **解答**：
  **先 x 后 y**：固定 y≠0，lim_{x→0} xy/(x²+y²) = 0/(0+y²) = 0。再 y→0，得 0。
  
  **先 y 后 x**：固定 x≠0，lim_{y→0} xy/(x²+y²) = 0/(x²+0) = 0。再 x→0，得 0。
  
  两个累次极限都等于 0。
  
  但注意：这个函数的重极限不存在！这说明——两个累次极限都存在且相等，也不能保证重极限存在。∎
- **一句话点评**：累次极限存在且相等，重极限不一定存在——这是多元极限最反直觉的结论之一。

**【D1-4-011】** 计算 f(x,y)=(x-y)/(x+y) 在 (0,0) 处的两个累次极限。它们相等吗？

- **难度**：★★
- **对应知识点**：累次极限不相等
- **解答**：
  **先 x 后 y**：固定 y≠0，lim_{x→0} (x-y)/(x+y) = (-y)/y = -1。再 y→0，得 -1。
  
  **先 y 后 x**：固定 x≠0，lim_{y→0} (x-y)/(x+y) = x/x = 1。再 x→0，得 1。
  
  两个累次极限不相等（-1≠1）。此时重极限一定不存在（因为如果重极限存在，两个累次极限应该相等）。∎
- **一句话点评**：两个累次极限不相等——重极限一定不存在。这是证明重极限不存在的另一种方法。

### ★★★ 研究探索

**【D1-4-012】** 证明：f(x,y)=x²y/(x⁴+y²) 在 (0,0) 处沿所有直线方向的极限都是 0，但重极限不存在。

- **难度**：★★★
- **对应知识点**：抛物线路径
- **解答**：
  **沿直线 y=kx**：
  f(x,kx) = x²·kx/(x⁴+k²x²) = kx/(x²+k²) → 0（x→0）
  
  所有直线方向的极限都是 0！
  
  **沿抛物线 y=kx²**：
  f(x,kx²) = x²·kx²/(x⁴+k²x⁴) = k/(1+k²)
  
  - k=1：极限=1/2
  - k=2：极限=2/5
  
  沿不同抛物线趋近得到不同极限，重极限不存在。
  
  **教训**：即使沿所有直线趋近都得到同一个极限，也不能保证重极限存在！必须检查所有路径，包括曲线路径。∎
- **一句话点评**：直线方向都收敛，不代表所有路径都收敛——抛物线方向可能"藏着"不同的极限。

**【D1-4-017】** 解释极坐标变换的"陷阱"。为什么说"固定 θ 令 r→0"不能证明重极限存在？

- **难度**：★★★
- **对应知识点**：极坐标变换的陷阱
- **解答**：
  **陷阱一：固定 θ**
  错误做法：令 x=r cosθ, y=r sinθ，固定 θ，令 r→0，得到极限。这只检查了沿射线 y=(tanθ)x 的极限，不能代表所有路径。
  
  **反例**：f(x,y)=xy/(x²+y²)，极坐标 f=cosθ sinθ=(sin2θ)/2。
  如果固定 θ，r→0 时 f=(sin2θ)/2，是一个常数。但这个常数依赖于 θ——不同 θ 得到不同值。所以不能说"极限等于 (sin2θ)/2"，而应该说"极限不存在，因为依赖于 θ"。
  
  **陷阱二：r→0 时 θ 也在变**
  有些路径在极坐标下不是 θ 固定，而是 θ 随 r 变化。比如沿抛物线 y=x²：r sinθ=r² cos²θ ⇒ sinθ=r cos²θ ⇒ θ≈r（当 r→0 时，θ→0）。
  
  如果只检查 θ 固定的情形，会漏掉这些路径。
  
  **正确做法**：极坐标变换后，必须证明 |f(r,θ)-A|≤g(r)，其中 g(r)→0 且 g(r) 与 θ 无关。∎
- **一句话点评**：极坐标变换的陷阱——固定 θ 只检查了一条射线，不是所有路径。必须证明 |f|≤g(r) 且与 θ 无关。

### 组C：极限的性质

**【D1-4-013】** 证明：若重极限 lim_{(x,y)→(x₀,y₀)} f(x,y)=A 存在，且内层极限 lim_{x→x₀} f(x,y) 存在（对 y≠y₀），则累次极限 lim_{y→y₀} lim_{x→x₀} f(x,y) 存在且等于 A。

- **难度**：★★★
- **对应知识点**：重极限与累次极限的关系
- **解答**：
  由重极限存在，∀ε>0，存在 δ>0，当 0&lt;√[(x-x₀)²+(y-y₀)²]&lt;δ 时 |f-A|&lt;ε。
  
  固定 y 满足 0&lt;|y-y₀|&lt;δ，令 x→x₀。由内层极限存在，得 |lim_{x→x₀} f(x,y)-A|≤ε。
  
  这说明 φ(y)=lim_{x→x₀} f(x,y) 当 y→y₀ 时趋于 A。
  
  因此累次极限 lim_{y→y₀} lim_{x→x₀} f(x,y) 存在且等于 A。∎
- **一句话点评**：重极限存在 ⇒ 累次极限存在且相等——但反过来不成立。

**【D1-4-014】** 证明：多元函数极限的唯一性。若重极限存在，则唯一。

- **难度**：★★★
- **对应知识点**：极限的唯一性
- **解答**：
  反证法。假设 lim f(x,y)=A 且 lim f(x,y)=B，A≠B。取 ε=|A-B|/2>0。
  
  因为 lim f=A，存在 δ₁，使得 0&lt;√[(x-x₀)²+(y-y₀)²]&lt;δ₁ 时 |f-A|&lt;ε。
  因为 lim f=B，存在 δ₂，使得 0&lt;√[(x-x₀)²+(y-y₀)²]&lt;δ₂ 时 |f-B|&lt;ε。
  
  取 δ=min(δ₁,δ₂)。则 0&lt;√[...] &lt;δ 时：
  |A-B| = |(A-f)+(f-B)| ≤ |A-f|+|f-B| &lt; ε+ε = 2ε = |A-B|
  
  矛盾。因此 A=B。∎
- **一句话点评**：极限的唯一性——和一元函数完全一样。

**【D1-4-015】** 证明：若重极限存在（有限值），则 f 在 P₀ 的某去心邻域内有界。（局部有界性）

- **难度**：★★★
- **对应知识点**：局部有界性
- **解答**：
  取 ε=1，由极限定义，存在 δ>0，使得 0&lt;√[(x-x₀)²+(y-y₀)²]&lt;δ 时 |f-A|&lt;1。
  
  即 |f| &lt; |A|+1。所以 f 在去心邻域 {0&lt;√(...)&lt;δ} 内有界（界为 |A|+1）。∎
- **一句话点评**：局部有界性——和一元函数完全一样。

### 组D：连续性与可微性

**【D1-4-018】** 写出二元函数连续性的 ε-δ 定义。它和一元函数连续性有什么不同？

- **难度**：★
- **对应知识点**：多元函数的连续性
- **解答**：
  **定义**：f(x,y) 在 P₀(x₀,y₀) 处连续，当且仅当 lim_{(x,y)→(x₀,y₀)} f(x,y) = f(x₀,y₀)。
  
  用 ε-δ 语言：∀ε>0, ∃δ>0, ∀(x,y)(√[(x-x₀)²+(y-y₀)²]&lt;δ ⇒ |f(x,y)-f(x₀,y₀)|&lt;ε)。
  
  **与一元函数的不同**：
  - 距离不同：一元是 |x-x₀|，二元是 √[(x-x₀)²+(y-y₀)²]
  - 路径更多：二元函数连续要求沿所有路径趋近都连续，而一元只需要左右极限相等
  
  注意：多元函数连续 ⟺ 沿所有路径连续——这比一元函数严格得多。∎
- **一句话点评**：多元函数连续——沿所有路径趋近，函数值都趋于函数值。

**【D1-4-019】** 解释什么是"偏导数"。它和一元函数的导数有什么不同？

- **难度**：★
- **对应知识点**：偏导数的定义
- **解答**：
  **偏导数的定义**：
  f 对 x 的偏导数：f_x(x₀,y₀) = lim_{h→0} [f(x₀+h,y₀)-f(x₀,y₀)]/h
  f 对 y 的偏导数：f_y(x₀,y₀) = lim_{k→0} [f(x₀,y₀+k)-f(x₀,y₀)]/k
  
  **与一元函数导数的不同**：
  - 偏导数只描述沿一个方向的变化率——x 方向或 y 方向
  - 一元导数描述沿唯一方向的变化率
  - 偏导数存在不代表函数可微——这是多元函数特有的现象
  
  几何上，偏导数就是"沿着坐标轴方向的斜率"——f_x 是沿 x 轴方向的切线斜率，f_y 是沿 y 轴方向的切线斜率。∎
- **一句话点评**：偏导数就是"沿坐标轴方向的斜率"——只看一个方向，不看所有方向。

### ★★ 进阶应用

**【D1-4-020】** 证明：若 f(x,y) 在 P₀ 处连续，则它在 P₀ 处有定义，且沿任意路径趋近 P₀ 时 f(x,y)→f(P₀)。

- **难度**：★★
- **对应知识点**：连续性的路径刻画
- **解答**：
  连续性的定义就是 lim_{(x,y)→(x₀,y₀)} f(x,y) = f(x₀,y₀)。
  
  由路径判据（Heine 定理的多元版本），这等价于：对于任意满足 P(t)→P₀ 的路径 P(t)，都有 lim_{t→t₀} f(P(t)) = f(P₀)。
  
  所以 f 在 P₀ 处连续 ⟺ 沿任意路径趋近 P₀ 时 f(x,y)→f(P₀)。∎
- **一句话点评**：连续就是"沿所有路径趋近，函数值都趋于函数值"——这是路径判据的直接应用。

**【D1-4-021】** 证明：f(x,y)=xy/(x²+y²)（f(0,0)=0）在 (0,0) 处不连续。

- **难度**：★★
- **对应知识点**：连续性的反例
- **解答**：
  沿直线 y=kx 趋近 (0,0)：
  f(x,kx) = k/(1+k²)
  
  - k=1：极限=1/2≠f(0,0)=0
  - k=0：极限=0=f(0,0)
  
  沿不同路径趋近 (0,0) 时，函数值趋于不同极限。由路径判据，重极限不存在。
  
  因此 f 在 (0,0) 处不连续（即使 f(0,0)=0 有定义）。∎
- **一句话点评**：函数在某点有定义，不代表连续——极限可能不存在，或者极限不等于函数值。

**【D1-4-022】** 计算：lim_{(x,y)→(0,0)} (x²y+xy²)/(x²+y²)。

- **难度**：★★
- **对应知识点**：不等式估计
- **解答**：
  |f| = |xy(x+y)|/(x²+y²) ≤ |xy|·(|x|+|y|)/(x²+y²)
  
  因为 |xy| ≤ (x²+y²)/2（由 2|xy|≤x²+y²），|x|+|y|≤√2·√(x²+y²)（由柯西不等式），
  
  所以 |f| ≤ (x²+y²)/2 · √2·√(x²+y²)/(x²+y²) = (√2/2)·√(x²+y²) → 0。
  
  极限=0。∎
- **一句话点评**：利用不等式估计——把分子拆成 |xy| 和 |x|+|y|，分别用不等式放缩。

**【D1-4-023】** 计算：lim_{(x,y)→(0,0)} (x²+y²)^{x²+y²}。

- **难度**：★★
- **对应知识点**：取对数法
- **解答**：
  令 u=x²+y²→0⁺，则极限=lim_{u→0⁺} u^u。
  
  取对数：ln(u^u) = u·ln u。当 u→0⁺ 时，u·ln u→0（这是一元函数的标准极限）。
  
  所以 lim_{u→0⁺} u^u = exp(0) = 1。∎
- **一句话点评**：幂指函数的极限——取对数转化为乘积的极限。

### ★★★ 研究探索

**【D1-4-024】** 证明：若 f(x,y) 在 P₀ 处不连续，则存在一条路径 P(t)→P₀，使得 f(P(t))↛f(P₀)。

- **难度**：★★★
- **对应知识点**：不连续的路径刻画
- **解答**：
  反证法。假设对于任意满足 P(t)→P₀ 的路径 P(t)，都有 f(P(t))→f(P₀)。
  
  取一条特殊路径：x 固定，y→y₀；然后 y 固定，x→x₀。这说明两个累次极限都等于 f(P₀)。
  
  但这还不够——需要证明重极限存在。由路径判据的逆否命题：如果存在一条路径使得 f(P(t))↛f(P₀)，则重极限不存在。
  
  反证法：假设重极限存在且等于 f(P₀)，则 f 在 P₀ 处连续。与 f 不连续矛盾。
  
  因此存在一条路径 P(t)→P₀，使得 f(P(t))↛f(P₀)。∎
- **一句话点评**：不连续就是"存在某条路径，沿它趋近时函数值不趋于函数值"。

**【D1-4-025】** 证明：f(x,y)={xy/(x²+y²), (x,y)≠(0,0); 0, (x,y)=(0,0)} 在 (0,0) 处的两个偏导数都存在，但函数不连续。

- **难度**：★★★
- **对应知识点**：偏导数存在与连续性的关系
- **解答**：
  **偏导数存在性**：
  f_x(0,0) = lim_{h→0} [f(h,0)-f(0,0)]/h = lim_{h→0} [0-0]/h = 0。
  f_y(0,0) = lim_{k→0} [f(0,k)-f(0,0)]/k = lim_{k→0} [0-0]/k = 0。
  
  两个偏导数都存在且等于 0。
  
  **不连续性**：沿直线 y=kx 趋近 (0,0)，f(x,kx)=k/(1+k²)，依赖于 k。重极限不存在。
  
  所以 f 在 (0,0) 处不连续。
  
  **结论**：偏导数存在不代表函数连续——这是多元函数特有的现象。一元函数中，可导一定连续；但多元函数中，偏导数存在不一定连续。∎
- **一句话点评**：偏导数存在 ≠ 连续——这是多元函数最反直觉的结论之一。偏导数只看坐标轴方向，不看所有方向。

**【D1-4-026】** 证明：若 f(x,y) 在 P₀ 处可微，则 f 在 P₀ 处连续，且两个偏导数都存在。

- **难度**：★★★
- **对应知识点**：可微与连续的关系
- **解答**：
  **可微的定义**：f 在 P₀ 处可微，当且仅当
  Δf = f(x₀+h,y₀+k) - f(x₀,y₀) = A·h + B·k + o(√(h²+k²))
  
  其中 A, B 是常数（即偏导数 f_x, f_y）。
  
  **连续性**：令 h→0, k→0，则 √(h²+k²)→0，所以 o(√(h²+k²))→0。
  Δf = A·h + B·k + o(√(h²+k²)) → 0。
  所以 f 在 P₀ 处连续。
  
  **偏导数存在**：令 k=0，令 h→0：
  Δf/h = A + o(|h|)/h → A。
  所以 f_x(0,0) = A 存在。同理 f_y(0,0) = B 存在。∎
- **一句话点评**：可微 ⇒ 连续 + 偏导数存在——但反过来不成立。

**【D1-4-027】** 解释为什么多元函数中"偏导数存在不代表可微"。给出一个反例。

- **难度**：★★★
- **对应知识点**：可微的充分条件
- **解答**：
  **反例**：f(x,y)={xy/(x²+y²), (x,y)≠(0,0); 0, (x,y)=(0,0)}。
  
  前面已经证明：两个偏导数都存在（都等于 0），但 f 在 (0,0) 处不连续。
  
  因为可微 ⇒ 连续，而 f 不连续，所以 f 不可微。
  
  **为什么偏导数存在不代表可微**：
  偏导数只描述沿 x 轴和 y 轴方向的变化率，不描述沿其他方向（如对角线 y=x）的变化率。
  
  可微要求"沿所有方向的变化率都可以用偏导数线性表示"——这比"沿两个坐标轴方向存在偏导数"强得多。
  
  几何上，可微意味着"曲面在该点有切平面"——所有方向的切线都在同一个平面上。偏导数存在只说明"沿 x 轴和 y 轴方向有切线"，不代表所有方向的切线共面。∎
- **一句话点评**：偏导数存在 ≠ 可微——偏导数只看两个方向，可微要求看所有方向。

## L2 复变函数层

> **引导语**：复函数极限是二元实函数极限的加强版。复平面上的极限要求四面八方都收敛，这比二元实函数更强，也更漂亮。复函数的连续性可以分解为实部和虚部的连续性。

### ★ 基础巩固

**【D1-4-028】** 解释为什么复函数极限比二元实函数极限"更强"。这种"强"体现在哪里？

- **难度**：★
- **对应知识点**：复极限的方向自由度
- **解答**：
  **二元实函数极限**：(x,y) 在 ℝ² 中趋近 (x₀,y₀)，可以沿任意路径趋近。
  
  **复函数极限**：z 在 ℂ 中趋近 z₀ = x₀+iy₀。ℂ 在拓扑上和 ℝ² 是一样的——都是二维空间。
  
  **为什么复极限"更强"**：
  复函数极限不仅要求"沿所有路径极限存在且相等"，还要求"极限与路径的选择无关"——这就是"解析性"的雏形。
  
  更深刻地说：复可导（解析）比二元实可导强得多。复可导要求沿所有方向的差商极限都存在且相等，而二元实可微只要求"线性逼近"。
  
  几何上，复极限的"强"体现在：复函数图像是"黎曼面"——它在所有方向上的行为都是"同步"的，这导致了解析函数的"刚性"（唯一性定理等）。∎
- **一句话点评**：复极限比二元实极限"更强"——因为复结构带来了额外的约束，导致解析函数的"刚性"。

### ★★ 进阶应用

**【D1-4-029】** 证明：复函数 f(z)=u(x,y)+iv(x,y) 在 z₀ 处连续，当且仅当 u(x,y) 和 v(x,y) 都在 (x₀,y₀) 处连续。

- **难度**：★★
- **对应知识点**：复函数的连续性
- **解答**：
  设 f(z) = u(x,y) + iv(x,y)，z = x+iy。
  
  **必要性**（f 连续 ⇒ u, v 连续）：
  因为 |u(x,y)-u(x₀,y₀)| ≤ |f(z)-f(z₀)|，|v(x,y)-v(x₀,y₀)| ≤ |f(z)-f(z₀)|。
  
  对于任意 ε>0，存在 δ>0，使得 |z-z₀|&lt;δ 时 |f(z)-f(z₀)|&lt;ε。
  
  于是 |u-u₀| ≤ |f-f₀| &lt; ε，|v-v₀| ≤ |f-f₀| &lt; ε。
  
  所以 u 和 v 都在 (x₀,y₀) 处连续。
  
  **充分性**（u, v 连续 ⇒ f 连续）：
  对于任意 ε>0：
  - 存在 δ₁，使得 √[(x-x₀)²+(y-y₀)²]&lt;δ₁ 时 |u-u₀|&lt;ε/√2
  - 存在 δ₂，使得 √[...] &lt;δ₂ 时 |v-v₀|&lt;ε/√2
  
  取 δ=min(δ₁,δ₂)。则 |z-z₀|&lt;δ 时：
  |f-f₀| = √[|u-u₀|²+|v-v₀|²] &lt; √[(ε/√2)²+(ε/√2)²] = ε。
  
  所以 f 在 z₀ 处连续。∎
- **一句话点评**：复函数连续 ⟺ 实部和虚部分别连续——把二维问题拆成两个一维问题。

### ★★★ 研究探索

**【D1-4-030】** 解释为什么复函数的极限理论比二元实函数极限理论"更漂亮"。这种"漂亮"体现在哪里？

- **难度**：★★★
- **对应知识点**：复极限的"刚性"
- **解答**：
  **复极限理论的"漂亮"体现在**：
  1. **唯一性定理**：如果两个解析函数在一个有聚点的集合上相等，那么它们在整个定义域上相等。这在二元实函数中是没有的——两个光滑函数可以在一条曲线上相等，但在其他地方不同。
  
  2. **Cauchy-Riemann 方程**：复可导的条件非常严格——偏导数必须满足 Cauchy-Riemann 方程。这导致复可导函数具有极强的性质（无穷可导、解析延拓等）。
  
  3. **全局性质**：复函数的局部性质决定全局性质——局部可导 ⇒ 全局解析。这在二元实函数中是没有的。
  
  **为什么会这样**：
  复结构带来了额外的约束——复函数不仅是"两个二元实函数的叠加"，它还有"乘法结构"（复数乘法）。这个乘法结构使得复函数的极限理论具有"刚性"。
  
  几何上，复极限的"漂亮"就是"刚性"——解析函数的行为是"全局同步"的，局部的一点点信息就能决定整个函数的行为。∎
- **一句话点评**：复极限理论比二元实极限"更漂亮"——因为复结构带来了"刚性"，局部决定全局。

## L3 实变函数层

> **引导语**：多元函数的收敛模式从逐点收敛扩展到一致收敛。一致收敛保持连续性，是连接极限和连续的重要桥梁。

### ★ 基础巩固

**【D1-4-031】** 解释为什么在多元函数中，"逐点收敛"不够，需要引入"一致收敛"等新概念。

- **难度**：★
- **对应知识点**：多元函数的收敛模式
- **解答**：
  在多元函数中，逐点收敛的问题和一元函数一样：
  1. **极限函数不一定连续**：即使每个 fₙ 连续，逐点收敛的极限函数可能不连续
  2. **不能交换极限和积分**：∫lim fₙ ≠ lim∫fₙ
  3. **不能交换极限和微分**：逐点收敛的可导函数列的极限不一定可导
  
  在多元函数中，问题更复杂——因为函数定义在高维空间上，逐点收敛的"不均匀性"更严重。不同区域的收敛速度可能差异很大。
  
  为了解决这些问题，需要引入"一致收敛"、"几乎处处收敛"、"依测度收敛"等新的收敛模式。∎
- **一句话点评**：多元函数的逐点收敛更"不均匀"——不同区域收敛速度差异更大，所以更需要一致收敛等新概念。

### ★★ 进阶应用

**【D1-4-032】** 解释什么是"一致收敛"。它和逐点收敛有什么不同？

- **难度**：★★
- **对应知识点**：一致收敛的定义
- **解答**：
  **逐点收敛**：∀(x,y), ∀ε>0, ∃N(x,y,ε), ∀n>N, |fₙ(x,y)-f(x,y)|&lt;ε
  - N 依赖于 (x,y) 和 ε——不同的点可能需要不同的 N
  
  **一致收敛**：∀ε>0, ∃N(ε), ∀(x,y), ∀n>N, |fₙ(x,y)-f(x,y)|&lt;ε
  - N 只依赖于 ε，不依赖于 (x,y)——同一个 N 对所有点都适用
  
  **关键区别**：∀(x,y) 和 ∃N 的顺序。逐点收敛中 ∀(x,y) 在 ∃N 之前（N 可以依赖于 (x,y)）；一致收敛中 ∃N 在 ∀(x,y) 之前（N 不依赖于 (x,y)）。
  
  几何上，逐点收敛是"每个点各自收敛"，一致收敛是"整个函数图像同步收敛"——像一块布整体向下平移，而不是每个点各自慢慢靠近。∎
- **一句话点评**：逐点收敛是"每个点各自收敛"，一致收敛是"整个函数图像同步收敛"——量词顺序的差异。

### ★★★ 研究探索

**【D1-4-033】** 证明：若 fₙ(x,y) 在 E 上一致收敛于 f(x,y)，且每个 fₙ 连续，则 f 也连续。

- **难度**：★★★
- **对应知识点**：一致收敛保持连续性
- **解答**：
  取 P₀∈E。对于任意 ε>0：
  1. 由一致收敛，存在 N，使得 ∀P∈E, ∀n>N, |fₙ(P)-f(P)|&lt;ε/3
  2. 固定 n>N，fₙ 连续，所以存在 δ>0，使得 |P-P₀|&lt;δ 时 |fₙ(P)-fₙ(P₀)|&lt;ε/3
  
  则 |f(P)-f(P₀)| ≤ |f(P)-fₙ(P)| + |fₙ(P)-fₙ(P₀)| + |fₙ(P₀)-f(P₀)| &lt; ε/3 + ε/3 + ε/3 = ε。
  
  所以 f 在 P₀ 处连续。由 P₀ 的任意性，f 在 E 上连续。∎
- **一句话点评**：一致收敛保持连续性——这是一致收敛最重要的性质之一。

## 补充基础题（L1 数学分析 / L2 复变函数 / L3 实变函数）

> **引导语**：针对三个阶段补充基础题。L1 侧重 ε-δ 证明和路径依赖性，L2 侧重复函数连续性，L3 侧重一致收敛与可测性。

### L1 数学分析基础

**【D1-4-041】** 用 ε-δ 定义证明：$\lim_{(x,y)\to(0,0)}\frac{x^2y}{x^2+y^2}=0$。

- **难度**：★
- **解答**：$\left|\frac{x^2y}{x^2+y^2}\right|\leq\frac{x^2|y|}{x^2+y^2}\leq\frac{(x^2+y^2)\cdot\sqrt{x^2+y^2}}{x^2+y^2}=\sqrt{x^2+y^2}$。
$\forall\varepsilon>0$，取 $\delta=\varepsilon$，当 $0<\sqrt{x^2+y^2}<\delta$ 时，$|f(x,y)|<\varepsilon$。∎
- **点评**：多元极限的 ε-δ 证明——用 $x^2\leq x^2+y^2$ 和 $|y|\leq\sqrt{x^2+y^2}$ 放缩。

**【D1-4-042】** 证明：$f(x,y)=\frac{x^2-y^2}{x^2+y^2}$ 在 $(0,0)$ 处的重极限不存在。

- **难度**：★
- **对应知识点**：路径依赖性、重极限不存在的证明
- **解答**：
  沿路径 y=0 趋近：$\lim_{x\to 0}\frac{x^2-0}{x^2+0}=1$。
  沿路径 x=0 趋近：$\lim_{y\to 0}\frac{0-y^2}{0+y^2}=-1$。
  两条路径的极限不同（1 和 -1），故重极限不存在。∎
- **一句话点评**：路径依赖性是多元极限的核心特征，找到两条极限不同的路径就证明了极限不存在。
**【D1-4-043】** 讨论 $f(x,y)=\frac{x^2y}{x^4+y^2}$ 在 $(0,0)$ 处沿抛物线 $y=kx^2$ 的极限，并说明这对重极限存在性的影响。

- **难度**：★★
- **对应知识点**：路径依赖性、抛物线路径
- **解答**：
  沿路径 $y=kx^2$ 趋近：$\lim_{x\to 0}\frac{x^2\cdot kx^2}{x^4+k^2x^4}=\lim_{x\to 0}\frac{kx^4}{(1+k^2)x^4}=\frac{k}{1+k^2}$。
  这个极限依赖于 k：k=0 时为 0，k=1 时为 1/2。
  因此沿不同抛物线趋近的极限不同，重极限不存在。∎
- **一句话点评**：这是经典反例，沿所有直线方向极限都是 0，但沿抛物线方向极限不同，说明直线方向不够，必须考虑所有路径。
**【D1-4-044】** 用极坐标变换求：$\lim_{(x,y)\to(0,0)}\frac{x^3+y^3}{x^2+y^2}$。

- **难度**：★★
- **解答**：令 $x=r\cos\theta, y=r\sin\theta$，则 $\frac{x^3+y^3}{x^2+y^2}=\frac{r^3(\cos^3\theta+\sin^3\theta)}{r^2}=r(\cos^3\theta+\sin^3\theta)$。
$|f|\leq r(|\cos^3\theta|+|\sin^3\theta|)\leq2r\to0$（$r\to0$），与 $\theta$ 无关。故极限为 0。∎
- **点评**：极坐标变换后，若表达式可写为 $r^k\cdot g(\theta)$ 且 $g$ 有界，则极限为 0（$k>0$）。

### L2 复变函数基础

**【D1-4-045】** 证明：复函数 $f(z)=z^2+2z$ 在任意点 $z_0$ 处连续。

- **难度**：★
- **解答**：$|f(z)-f(z_0)|=|z^2-z_0^2+2(z-z_0)|=|z-z_0||z+z_0+2|$。
当 $|z-z_0|<1$ 时，$|z+z_0+2|\leq|z-z_0|+2|z_0|+2<1+2|z_0|+2=3+2|z_0|$。
取 $\delta=\min(1,\frac{\varepsilon}{3+2|z_0|})$，则 $|z-z_0|<\delta$ 时 $|f(z)-f(z_0)|<\varepsilon$。∎
- **点评**：复多项式函数处处连续——证明与实函数类似，关键是因式分解后有界性放缩。

**【D1-4-046】** 证明：$f(z)=\frac{\text{Re}(z)\cdot\text{Im}(z)}{|z|^2}$ 在 $z\to0$ 时极限不存在。

- **难度**：★★
- **解答**：令 $z=x+iy$，则 $f(z)=\frac{xy}{x^2+y^2}$。
沿实轴 $y=0$：$f=0\to0$。沿直线 $y=x$：$f=\frac{x^2}{2x^2}=\frac{1}{2}\to\frac{1}{2}$。
沿不同路径极限不同，故极限不存在。∎
- **点评**：这与 D1-4-042 是同一个函数——复函数极限本质上就是二元实函数极限，路径依赖性完全相同。

**【D1-4-047】** 设 $f(z)=u(x,y)+iv(x,y)$。证明：$\lim_{z\to z_0}f(z)=a+ib$ 当且仅当 $\lim_{(x,y)\to(x_0,y_0)}u(x,y)=a$ 且 $\lim v(x,y)=b$。

- **难度**：★★
- **解答**：由 $|u-a|\leq|f-(a+ib)|$ 和 $|v-b|\leq|f-(a+ib)|$ 得必要性。
充分性由 $|f-(a+ib)|\leq|u-a|+|v-b|$ 得。∎
- **点评**：复函数极限 = 实部极限 + i·虚部极限。这是复极限与二元实函数极限的基本对应关系。

### L3 实变函数基础

**【D1-4-048】** 设 $f_n(x,y)=\frac{nxy}{1+n^2x^2y^2}$ 在 $[0,1]^2$ 上。证明 $f_n\to0$ 逐点收敛，但不一致收敛。

- **难度**：★★
- **解答**：对固定 $(x,y)\neq(0,0)$，$f_n\sim\frac{1}{nxy}\to0$；$(0,0)$ 处 $f_n=0$。故逐点收敛到 0。
但沿 $y=1/n$（随 $n$ 变化的路径），$f_n(x,1/n)=\frac{x}{1+x^2}$，在 $x=1$ 处为 $1/2$。$\sup|f_n|\geq1/2$，不一致收敛。∎
- **点评**：二元函数列的不一致收敛——"峰值"可以沿随 n 变化的曲线移动，与一元的滑动峰类似。

**【D1-4-049】** 叙述 Fubini 定理，并说明为什么需要"绝对可积"条件。

- **难度**：★★
- **解答**：Fubini 定理：若 $\int_{X\times Y}|f(x,y)|d(\mu\times\nu)<\infty$，则 $\int_X\int_Y f\,d\nu\,d\mu=\int_Y\int_X f\,d\mu\,d\nu=\int_{X\times Y}f\,d(\mu\times\nu)$。
需要绝对可积的原因：反例 $f(x,y)=\frac{x^2-y^2}{(x^2+y^2)^2}$ 在 $[0,1]^2$ 上，$\int_0^1\int_0^1 f\,dx\,dy=\pi/4$，但 $\int_0^1\int_0^1 f\,dy\,dx=-\pi/4$，两个累次积分不等。原因是 $f$ 不是绝对可积的。∎
- **点评**：Fubini 定理是多元积分的核心——绝对可积保证积分次序可交换，否则可能得到不同结果。

**【D1-4-050】** 证明：在 $\mathbb{R}^n$ 上，连续函数的紧支撑集是可测的，且连续函数是 Borel 可测函数。

- **难度**：★
- **解答**：连续函数的紧支撑是闭集（连续函数在闭集外为 0，支撑是闭集的闭包），闭集是 Borel 集，故可测。
连续函数可测：对任意开集 $U$，$f^{-1}(U)$ 是开集（连续的定义），开集是 Borel 集，故 $f$ 是 Borel 可测的。∎
- **点评**：连续函数是可测函数——这是实变函数的基本事实，意味着所有连续函数都可以进行 Lebesgue 积分。

## 跨领域综合题

> **引导语**：多元函数极限是维度升级的典型案例。路径依赖性连接了几何和微分；极坐标变换连接了三角学和积分；Heine 定理在多元情形下依然成立。每道综合题都展示了从一元到多元的概念跃迁。

> 定位：串联多个概念领域的综合题，培养全局视野和数学思考的"爽感"。

### 一、经典名题（做一遍爽一遍）

**【D1-4-CROSS-034】**（D1 × D7 几何 × D3 微分）**多元极限的路径依赖性与切平面**：为什么说"偏导数存在不代表可微"等价于"曲面在该点没有切平面"？用几何图像解释。

- **难度**：★★★
- **对应知识点**：偏导数存在（D1）、切平面（D3）、曲面几何（D7）
- **来源**：多元微积分的核心概念
- **解答**：
  **偏导数存在的几何意义**：
  - f_x 存在：曲面沿 x 轴方向的切线存在
  - f_y 存在：曲面沿 y 轴方向的切线存在
  
  **可微的几何意义**：
  可微意味着曲面在该点有切平面——所有方向的切线都在同一个平面上。
  
  **为什么偏导数存在不代表可微**：
  偏导数只说明"沿 x 轴和 y 轴方向的切线存在"，不代表"所有方向的切线共面"。
  
  **反例的几何图像**：
  f(x,y)=xy/(x²+y²) 在 (0,0) 处：
  - 沿 x 轴方向：切线斜率=0（偏导数 f_x=0）
  - 沿 y 轴方向：切线斜率=0（偏导数 f_y=0）
  - 沿对角线 y=x 方向：函数值=1/2，不趋于 0
  
  曲面在 (0,0) 上方"旋转"——不同方向的高度不同。沿 x 轴和 y 轴方向高度为 0，沿对角线方向高度为 1/2。曲面在该点没有切平面——因为不同方向的"切线斜率"不一致。
  
  **几何本质**：可微 = 曲面在该点"平坦"（所有方向的切线共面）。偏导数存在只说明"两个坐标轴方向的切线存在"，不代表"平坦"。∎
- **一句话点评**：偏导数存在 = 两条线有切线；可微 = 整个面有切平面。两条线有切线，不代表整个面是平的。

**【D1-4-CROSS-035】**（D1 × D6 完备性 × D8 解析）**多元极限的存在性与完备性**：为什么说"多元函数极限的存在性"也依赖于空间的完备性？

- **难度**：★★★
- **对应知识点**：多元极限（D1）、完备性（D6）、复平面的完备性（D8）
- **来源**：分析学基础的深层问题
- **解答**：
  **一元情况**：Cauchy 列在实数系中收敛，但在有理数系中不收敛——这说明极限的存在性依赖于完备性。
  
  **多元情况**：n 维欧氏空间 ℝⁿ 也是完备的（因为 ℝ 完备）。所以多元函数极限的存在性也依赖于 ℝⁿ 的完备性。
  
  **为什么多元极限也依赖于完备性**：
  多元函数极限的"Cauchy 准则"（lim f(P) 存在 ⟺ f(P) 是"函数 Cauchy 列"）也依赖于完备性。在不完备空间中，函数 Cauchy 列可能不收敛。
  
  **复平面的完备性**：
  复平面 ℂ 也是完备的（因为 ℝ² 完备）。所以复函数极限的存在性也依赖于 ℂ 的完备性。
  
  **几何图像**：完备性就是"空间没有缝隙"——ℝⁿ 就像一个"填满"的空间，所有 Cauchy 列的极限都在这个空间中。多元函数极限的存在性，本质上就是"函数值的 Cauchy 列收敛"——这需要空间是完备的。∎
- **一句话点评**：多元极限的存在性也依赖于完备性——Cauchy 准则的有效性，建立在"空间没有缝隙"的基础上。

### 二、定理串联型（多领域协同的爽感）

**【D1-4-CROSS-036】**（D1 × D3 微分 × D7 几何）**从一元到多元：极限概念的"维度升级"**：为什么说从一元函数极限到多元函数极限，是一次"维度升级"？这次升级带来了什么新现象？

- **难度**：★★★
- **对应知识点**：多元极限（D1）、偏导数与可微（D3）、曲面几何（D7）
- **来源**：分析学的维度跃迁
- **解答**：
  **一元到多元的"维度升级"**：
  1. **路径更多**：一元函数只有左右两条路；多元函数有无穷多条路
  2. **偏导数存在 ≠ 可微**：一元函数中，可导 ⇒ 连续；多元函数中，偏导数存在 ≠ 连续
  3. **累次极限 ≠ 重极限**：一元函数没有"累次极限"的概念，多元函数中累次极限和重极限可能不同
  4. **方向导数**：多元函数可以沿任意方向求导数，而一元函数只有"一个方向"
  
  **这次升级带来的新现象**：
  - **路径依赖性**：沿不同路径可能得到不同极限
  - **偏导数存在不代表连续**：这是多元函数最反直觉的现象之一
  - **可微的充分条件**：偏导数连续 ⇒ 可微（这是多元函数特有的充分条件）
  
  **几何图像**：从一元到多元，就是从"曲线"到"曲面"的升级。曲线只有左右两个方向，曲面有无穷多个方向。所有方向的行为必须"同步"，曲面才是"光滑"的——这就是可微的几何意义。∎
- **一句话点评**：从一元到多元是"维度升级"——从曲线到曲面，从两个方向到无穷多个方向。所有方向必须"同步"，曲面才是光滑的。

**【D1-4-CROSS-037】**（D1 × D6 完备性 × D8 解析）**多元极限与 Heine 定理**：Heine 定理在多元函数中是什么形式？它如何描述"路径依赖性"？

- **难度**：★★★
- **对应知识点**：Heine 定理（D1）、路径依赖性（D1）、完备性（D6）
- **来源**：分析学的核心桥梁
- **解答**：
  **多元 Heine 定理**：
  lim_{(x,y)→(x₀,y₀)} f(x,y) = A ⟺ 对于任意满足 Pₙ=(xₙ,yₙ)→(x₀,y₀) 且 Pₙ≠P₀ 的序列 {Pₙ}，都有 f(Pₙ)→A。
  
  **与一元 Heine 定理的区别**：
  - 一元：任意数列 xₙ→x₀
  - 多元：任意点列 Pₙ→P₀（二维空间中的点列）
  
  **如何描述路径依赖性**：
  多元 Heine 定理的逆否命题：如果存在两个点列 Pₙ→P₀, Qₙ→P₀，使得 f(Pₙ)→A, f(Qₙ)→B 且 A≠B，则重极限不存在。
  
  每个点列 Pₙ→P₀ 代表一条"离散的路径"。找到两个不同的点列（两条路径），极限不同——重极限不存在。
  
  **几何意义**：多元 Heine 定理说的就是"所有路径都通向同一个终点"——沿任何离散的路径趋近 P₀，函数值都趋于同一个极限 A。∎
- **一句话点评**：多元 Heine 定理就是"所有路径都通向同一个终点"——找到两条路径极限不同，重极限就不存在。

**【D1-4-CROSS-038】**（D1 × D7 三角学 × D4 积分）**极坐标变换的几何本质**：为什么说极坐标变换是"从直角坐标到极坐标的坐标系变换"？它在多元极限计算中为什么这么有用？

- **难度**：★★★
- **对应知识点**：极坐标变换（D1）、三角学（D7）、积分变换（D4）
- **来源**：坐标系变换的威力
- **解答**：
  **极坐标变换的几何本质**：
  极坐标变换 x=r cosθ, y=r sinθ 是"从直角坐标到极坐标的坐标系变换"。
  - r 是"到原点的距离"
  - θ 是"与 x 轴的夹角"
  
  **为什么在多元极限计算中这么有用**：
  1. **简化 x²+y²**：在极坐标下，x²+y²=r²——很多复杂的表达式会简化
  2. **分离 r 和 θ**：很多函数在极坐标下可以写成 f(r,θ)=r^k·g(θ)——"径向部分"和"角向部分"分离
  3. **判断极限是否与方向有关**：如果 |f(r,θ)|≤g(r) 且 g(r)→0，则极限与方向无关——重极限存在
  
  **几何意义**：
  极坐标变换就是"以原点为中心的极坐标网格"——圆心是原点，半径是 r，角度是 θ。在这个网格下，很多具有"旋转对称性"的函数会变得非常简单。
  
  **与积分变换的联系**：
  极坐标变换不仅用于极限计算，也用于二重积分的计算——把直角坐标下的二重积分转化为极坐标下的二重积分。这是"坐标系变换"思想的统一应用。∎
- **一句话点评**：极坐标变换就是"以原点为中心的坐标系变换"——它把"旋转对称"的函数变得简单，让我们能判断极限是否与方向有关。

### 三、基础综合（保留）

**【D1-4-CROSS-039】**（D1 × D3 微分）设 f(x,y) 在 (x₀,y₀) 处可微，证明：f 沿任意方向的方向导数都存在，且等于梯度在该方向的投影。

- **难度**：★★
- **对应知识点**：方向导数与梯度（D3 联动）
- **来源**：概念综合题
- **解答**：
  **方向导数的定义**：f 在 P₀ 处沿方向 v=(cosα, sinα) 的方向导数：
  D_v f(P₀) = lim_{t→0} [f(P₀+t·v) - f(P₀)]/t
  
  **可微的条件**：
  Δf = f(P₀+t·v) - f(P₀) = f_x·t·cosα + f_y·t·sinα + o(t)
  
  所以 [f(P₀+t·v) - f(P₀)]/t = f_x·cosα + f_y·sinα + o(t)/t → f_x·cosα + f_y·sinα。
  
  **梯度**：∇f = (f_x, f_y)。方向 v=(cosα, sinα)。
  
  所以 D_v f(P₀) = ∇f · v（梯度在 v 方向的投影）。∎
- **一句话点评**：可微 ⇒ 所有方向的方向导数都存在，且等于梯度在该方向的投影。

**【D1-4-CROSS-040】**（D1 × D2 连续）证明：若 f(x,y) 在有界闭区域 D 上连续，则 f 在 D 上有界。用多元函数极限的语言解释为什么连续函数在有界闭区域上有界。

- **难度**：★★
- **对应知识点**：连续函数的有界性（D2 联动）
- **来源**：概念综合题
- **解答**：
  **有界闭区域上连续函数的有界性定理**：若 f 在有界闭区域 D 上连续，则 f 在 D 上有界。
  
  **为什么需要"有界闭区域"**：
  开区域上的连续函数不一定有界。例如 f(x,y)=1/(x²+y²) 在 (0,0) 附近无界。
  
  **为什么"有界闭区域"就有界**：
  有界闭区域是"紧集"——任何无穷序列都有收敛子列（Bolzano-Weierstrass 定理的多元版本）。如果 f 无界，则存在点列 Pₙ∈D 使得 |f(Pₙ)|→∞。但 Pₙ 有收敛子列 P_{n_k}→P₀∈D。由连续性，f(P_{n_k})→f(P₀)，矛盾。
  
  **多元极限的语言**：
  连续性意味着 f 在每个点 P₀ 附近"局部有界"。有界闭区域上的紧性保证了"局部有界"可以"拼接"成"全局有界"——有限个局部有界的区域拼接起来，就是全局有界。∎
- **一句话点评**：有界闭区域上连续函数有界——因为有界闭区域是紧集，局部有界可以拼接成全局有界。

## 本模块易错点总结

1. **重极限 ≠ 累次极限**：重极限是"同时趋近"，累次极限是"分步趋近"。两个累次极限都存在且相等，也不能保证重极限存在。

2. **路径依赖性**：沿不同路径趋近可能得到不同极限。找到两条路径极限不同，重极限就不存在。

3. **直线方向都收敛 ≠ 所有路径都收敛**：即使沿所有直线方向极限都相同，也不能保证重极限存在——抛物线方向可能"藏着"不同的极限。

4. **极坐标变换的陷阱**：固定 θ 令 r→0 只检查了一条射线，不能证明重极限存在。必须证明 |f(r,θ)|≤g(r) 且 g(r) 与 θ 无关。

5. **偏导数存在 ≠ 连续**：多元函数中，偏导数存在不代表函数连续——这是与一元函数最根本的区别。

6. **偏导数存在 ≠ 可微**：偏导数只看两个坐标轴方向，可微要求看所有方向。

7. **可微 ⇒ 连续 + 偏导数存在**：但反过来不成立。

8. **去心邻域**：和一元函数一样，多元函数极限也需要去心邻域——f(P₀) 与极限无关。

9. **累次极限不能交换顺序**：一般来说，lim_y lim_x f ≠ lim_x lim_y f。交换极限顺序需要附加条件（如一致收敛）。

10. **局部性质 vs 全局性质**：多元函数极限的性质也是"局部"的——局部有界、局部保号。
