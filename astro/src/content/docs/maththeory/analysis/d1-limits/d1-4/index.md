## 第一章 引言：从一条线到一个平面

### 1.1 为什么多元极限更难

在一元函数中，x 趋近 x₀ 只有两个方向：从左边来，或者从右边来。只要左右极限相等，双侧极限就存在。

但在二元函数中，(x,y) 趋近 (x₀,y₀) 的方式无穷多：
- 可以沿直线 y=kx 趋近
- 可以沿抛物线 y=kx² 趋近
- 可以沿任意曲线 y=f(x) 趋近
- 可以先让 x→x₀ 再让 y→y₀（累次极限）
- 可以沿螺旋线、折线等复杂路径趋近

**重极限存在**要求：不管沿哪条路径趋近 (x₀,y₀)，函数值都趋于同一个数 A。

这比一元函数严格得多——一元函数只需要检查两个方向，多元函数需要检查无穷多条路径。

**📐 几何锚定**：一元函数的图像是平面上的一条曲线，极限描述的是曲线在某点附近的"高度趋势"——从左边和右边靠近时，高度趋于同一个值。二元函数的图像是三维空间中的一个曲面，极限描述的是曲面在某点上方的"高度趋势"——在 xy 平面上，不管从哪个方向、沿哪条曲线靠近 (x₀,y₀)，曲面的高度都趋于同一个值。几何上，这意味着曲面在 (x₀,y₀) 上方没有"裂缝"或"尖刺"——从任何方向靠近，高度都平滑地趋于 A。如果沿不同路径靠近得到不同高度，说明曲面在该点有"裂缝"——极限不存在。

## 第二章 多元函数的重极限定义

### 2.1 二元函数重极限的 ε-δ 定义

**定义**：设二元函数 f(x,y) 在点 P₀(x₀,y₀) 的某去心邻域内有定义，A 是常数。如果对于任意 ε>0，存在 δ>0，使得当 0&lt;√[(x-x₀)²+(y-y₀)²]&lt;δ 时，有 |f(x,y)-A|&lt;ε，那么称 f(x,y) 当 (x,y)→(x₀,y₀) 时以 A 为极限，记作：

lim_{(x,y)→(x₀,y₀)} f(x,y) = A

这个极限称为**重极限**（或全面极限），强调 (x,y) 同时、以任意方式趋近 (x₀,y₀)。

### 2.2 定义的逐点理解

**去心邻域**：0&lt;√[(x-x₀)²+(y-y₀)²]&lt;δ 表示以 P₀ 为圆心、δ 为半径的去心圆盘——不包括圆心 P₀ 本身。和一元函数一样，f 在 P₀ 处的值与极限无关，f(P₀) 甚至可以没有定义。

**距离**：√[(x-x₀)²+(y-y₀)²] 是平面上两点之间的欧氏距离。也可以用其他距离，比如 |x-x₀|+|y-y₀|（曼哈顿距离）或 max(|x-x₀|,|y-y₀|)（切比雪夫距离）。在有限维空间中，这些距离是等价的——用哪种距离定义极限，结果都一样。

**δ 依赖于 ε**：和一元函数一样，ε 越小，通常 δ 也越小。但 δ 不要求是最大的，只要存在一个就行。

### 2.3 用定义证明重极限

**例 1**：证明 lim_{(x,y)→(0,0)} (x²+y²) = 0

证明：∀ε>0，取 δ=√ε。当 0&lt;√(x²+y²)&lt;δ 时，|x²+y²-0|=x²+y²&lt;δ²=ε。∎

**例 2**：证明 lim_{(x,y)→(1,2)} (x²+xy+y²) = 7

证明：先计算 |f(x,y)-7| = |x²+xy+y²-7|。
令 u=x-1, v=y-2，则 x=1+u, y=2+v，(u,v)→(0,0)。
f-7 = (1+u)²+(1+u)(2+v)+(2+v)²-7
= (1+2u+u²)+(2+v+2u+uv)+(4+4v+v²)-7
= 4u+5v+u²+uv+v²
|f-7| ≤ 4|u|+5|v|+u²+|uv|+v²

当 √(u²+v²)&lt;δ 时，|u|≤√(u²+v²)&lt;δ，|v|&lt;δ，u²&lt;δ²，|uv|&lt;δ²，v²&lt;δ²。
所以 |f-7| &lt; 4δ+5δ+δ²+δ²+δ² = 9δ+3δ²。

取 δ&lt;1，则 δ²&lt;δ，所以 |f-7|&lt;9δ+3δ=12δ。
∀ε>0，取 δ=min(1, ε/12)，则 |f-7|&lt;ε。∎

**方法总结**：证明多元极限常用"平移法"——令 u=x-x₀, v=y-y₀，把问题转化为 (u,v)→(0,0) 的情形，然后用 |u|,|v|≤√(u²+v²) 来估计。

### 2.4 更多证明例题

**例 3**：证明 lim_{(x,y)→(0,0)} (x+y) sin(1/x) sin(1/y) = 0

证明：因为 |sin(1/x)|≤1, |sin(1/y)|≤1，所以
|f(x,y)-0| = |x+y|·|sin(1/x)|·|sin(1/y)| ≤ |x+y| ≤ |x|+|y|
当 √(x²+y²)&lt;δ 时，|x|≤√(x²+y²)&lt;δ，|y|&lt;δ，所以 |x|+|y|&lt;2δ。
∀ε>0，取 δ=ε/2，则 |f|&lt;2δ=ε。∎

**例 4**：证明 lim_{(x,y)→(0,0)} (x³-xy²)/(x²+y²) = 0

证明：|f| = |x(x²-y²)|/(x²+y²) ≤ |x|(x²+y²)/(x²+y²) = |x| ≤ √(x²+y²)
∀ε>0，取 δ=ε，则 |f|&lt;δ=ε。∎

**例 5**：证明 lim_{(x,y)→(0,0)} √(x²+y²) sin(1/√(x²+y²)) = 0

证明：|f| = √(x²+y²)·|sin(1/√(x²+y²))| ≤ √(x²+y²)
∀ε>0，取 δ=ε，则 |f|&lt;δ=ε。∎

这是一元函数 x sin(1/x)→0（x→0）的二元推广。

**例 6**：证明 lim_{(x,y)→(2,3)} (x²+xy-10) = 2

证明：令 u=x-2, v=y-3，则 x=2+u, y=3+v，(u,v)→(0,0)。
f-2 = (2+u)²+(2+u)(3+v)-10-2
= (4+4u+u²)+(6+2v+3u+uv)-12
= 7u+2v+u²+uv
|f-2| ≤ 7|u|+2|v|+u²+|uv|
当 √(u²+v²)&lt;δ&lt;1 时，|u|&lt;δ, |v|&lt;δ, u²&lt;δ, |uv|&lt;δ
所以 |f-2| &lt; 7δ+2δ+δ+δ = 11δ
∀ε>0，取 δ=min(1, ε/11)，则 |f-2|&lt;ε。∎

## 第三章 重极限的基本性质与运算法则

### 3.1 基本性质

和一元函数极限类似，重极限有以下基本性质：

1. **唯一性**：若重极限存在，则唯一。
2. **局部有界性**：若重极限存在（有限值），则 f 在 P₀ 的某去心邻域内有界。
3. **局部保号性**：若 lim f=A>0，则在 P₀ 的某去心邻域内 f>0。
4. **迫敛性（夹逼定理）**：若在 P₀ 附近 f≤g≤h，且 lim f=lim h=A，则 lim g=A。

这些性质的证明和一元函数完全类似，只是把 |x-x₀| 换成 √[(x-x₀)²+(y-y₀)²]。

### 3.2 四则运算法则

若 lim_{(x,y)→(x₀,y₀)} f(x,y)=A，lim g(x,y)=B，则：
1. lim (f±g) = A±B
2. lim (f·g) = A·B
3. lim (f/g) = A/B（当 B≠0 时）

证明和一元函数类似，利用三角不等式和局部有界性。

### 3.3 复合函数的极限

若 lim_{(x,y)→(x₀,y₀)} g(x,y)=u₀，lim_{u→u₀} f(u)=A，且在 P₀ 附近 g(x,y)≠u₀（或 f 在 u₀ 处连续），则 lim_{(x,y)→(x₀,y₀)} f(g(x,y))=A。

这是一元复合函数极限定理的直接推广。

## 第四章 累次极限

### 4.1 累次极限的定义

**定义**：先固定 y，让 x→x₀，得到一个关于 y 的函数 φ(y)=lim_{x→x₀} f(x,y)；再让 y→y₀，得到 lim_{y→y₀} φ(y)。这个极限称为**先 x 后 y 的累次极限**，记作：

lim_{y→y₀} lim_{x→x₀} f(x,y)

类似地，可以定义先 y 后 x 的累次极限：

lim_{x→x₀} lim_{y→y₀} f(x,y)

### 4.2 累次极限的计算

**例**：f(x,y)=xy/(x²+y²)，求 (0,0) 处的两个累次极限。

先 x 后 y：固定 y≠0，lim_{x→0} xy/(x²+y²) = 0/(0+y²) = 0。
再 y→0：lim_{y→0} 0 = 0。
所以 lim_{y→0} lim_{x→0} f(x,y) = 0。

先 y 后 x：同理，lim_{x→0} lim_{y→0} f(x,y) = 0。

两个累次极限都等于 0。但后面会看到，这个函数的重极限不存在！

### 4.3 累次极限的注意事项

1. **累次极限是两次一元极限**：每次只让一个变量变化，另一个固定。这和重极限不同——重极限要求两个变量同时变化。

2. **内层极限必须存在**：计算累次极限时，内层极限（如 lim_{x→x₀} f(x,y)）必须对 y≠y₀ 存在。如果内层极限不存在，累次极限就无法定义。

3. **两个累次极限可能不相等**：后面会看到反例。

4. **累次极限不能交换顺序**：一般来说，lim_{y→y₀} lim_{x→x₀} f ≠ lim_{x→x₀} lim_{y→y₀} f。交换极限顺序需要附加条件（如一致收敛）。

## 第五章 重极限与累次极限的关系

### 5.1 重极限存在 ⇒ 累次极限存在且相等

**定理**：若重极限 lim_{(x,y)→(x₀,y₀)} f(x,y)=A 存在，且内层极限 lim_{x→x₀} f(x,y) 存在（对 y≠y₀），则累次极限 lim_{y→y₀} lim_{x→x₀} f(x,y) 存在且等于 A。

**证明思路**：由重极限存在，∀ε>0，存在 δ>0，当 0&lt;√[(x-x₀)²+(y-y₀)²]&lt;δ 时 |f-A|&lt;ε。固定 y 满足 0&lt;|y-y₀|&lt;δ，令 x→x₀，由内层极限存在，得 |lim_{x→x₀} f(x,y)-A|≤ε。这说明 φ(y)=lim_{x→x₀} f(x,y) 当 y→y₀ 时趋于 A。∎

**推论**：若重极限存在，且两个内层极限都存在，则两个累次极限都存在且相等，都等于重极限的值。

### 5.2 累次极限存在 ⇏ 重极限存在

这是多元极限中最重要的结论之一。两个累次极限都存在且相等，也不能保证重极限存在。

**经典反例**：f(x,y)=xy/(x²+y²)

两个累次极限都等于 0（见第四章），但重极限不存在。

证明重极限不存在：沿直线 y=kx 趋近 (0,0)，
f(x,kx) = x·kx/(x²+k²x²) = k/(1+k²)
这个值依赖于 k——沿不同斜率的直线趋近，得到不同的极限。由路径依赖性（第六章），重极限不存在。

### 5.3 两个累次极限可能不相等

**反例**：f(x,y)=(x-y)/(x+y)，在 (0,0) 处。

先 x 后 y：固定 y≠0，lim_{x→0} (x-y)/(x+y) = (-y)/y = -1。再 y→0，得 -1。
先 y 后 x：固定 x≠0，lim_{y→0} (x-y)/(x+y) = x/x = 1。再 x→0，得 1。

两个累次极限不相等（-1≠1）。此时重极限一定不存在（因为如果重极限存在，两个累次极限应该相等）。

### 5.4 关系总结

| 情形 | 重极限 | 累次极限1 | 累次极限2 |
|---|---|---|---|
| 1 | 存在=A | 存在=A | 存在=A |
| 2 | 不存在 | 存在=0 | 存在=0 |
| 3 | 不存在 | 存在=-1 | 存在=1 |
| 4 | 不存在 | 不存在 | 存在 |
| 5 | 存在=A | 不存在 | 存在=A |

- 重极限存在 + 内层极限存在 ⇒ 累次极限存在且相等
- 两个累次极限都存在且相等 ⇏ 重极限存在
- 两个累次极限不相等 ⇒ 重极限不存在
- 重极限存在 ⇏ 内层极限存在（情形5）

## 第六章 路径依赖性与典型反例

### 6.1 路径依赖性的本质

**定理（路径判据）**：重极限 lim_{(x,y)→(x₀,y₀)} f(x,y)=A 存在，当且仅当对于任意满足 P(t)→P₀（t→t₀）且 P(t)≠P₀ 的连续路径 P(t)，都有 lim_{t→t₀} f(P(t))=A。

换句话说：**重极限存在 ⟺ 沿所有路径趋近都得到同一个极限**。

**推论（证明重极限不存在的方法）**：如果能找到两条路径，沿它们趋近 P₀ 时 f 趋于不同的极限，那么重极限不存在。

这是证明多元极限不存在最常用、最有效的方法。

### 6.2 经典反例一：f(x,y)=xy/(x²+y²)

沿直线 y=kx 趋近 (0,0)：
f(x,kx) = k/(1+k²)

- k=0（沿 x 轴）：极限=0
- k=1（沿 y=x）：极限=1/2
- k→∞（沿 y 轴）：极限→0

不同路径得到不同极限，重极限不存在。

**📐 几何图像**：这个函数的曲面 z=xy/(x²+y²) 在原点上方有一个"马鞍形"的扭曲——沿 x 轴和 y 轴，高度为 0；沿 y=x，高度为 1/2；沿 y=-x，高度为 -1/2。曲面在原点上方"旋转"，不同方向的高度不同，所以没有统一的极限。

### 6.3 经典反例二：f(x,y)=x²y/(x⁴+y²)

沿直线 y=kx 趋近 (0,0)：
f(x,kx) = x²·kx/(x⁴+k²x²) = kx/(x²+k²) → 0（x→0）

所有直线方向的极限都是 0！但重极限仍然不存在。

沿抛物线 y=kx² 趋近 (0,0)：
f(x,kx²) = x²·kx²/(x⁴+k²x⁴) = k/(1+k²)

- k=1：极限=1/2
- k=2：极限=2/5

沿不同抛物线趋近得到不同极限，重极限不存在。

**这个反例的教训**：即使沿所有直线趋近都得到同一个极限，也不能保证重极限存在！必须检查所有路径，包括曲线路径。

### 6.4 经典反例三：f(x,y)=x²y²/(x²y²+(x-y)²)

沿 y=kx：f→0（所有直线方向）
沿 y=x²：f = x²·x⁴/(x²·x⁴+(x-x²)²) = x⁶/(x⁶+x²(1-x)²) → 0
沿 y=x：f = x⁴/(x⁴+0) = 1

沿 y=x 得到极限 1，沿其他路径得到 0，重极限不存在。

### 6.5 构造反例的方法

构造"沿不同路径极限不同"的反例，常用以下技巧：

1. **齐次函数法**：f(x,y)=P_m(x,y)/Q_n(x,y)，其中 P_m 是 m 次齐次多项式，Q_n 是 n 次齐次多项式。当 m=n 时，沿 y=kx 的极限依赖于 k。
   - 例：xy/(x²+y²)（都是 2 次）

2. **抛物线法**：当沿所有直线极限相同时，尝试沿抛物线 y=kx²。如果分子分母的"次数"在抛物线下变得相同，极限可能依赖于 k。
   - 例：x²y/(x⁴+y²)（沿 y=kx²，分子分母都是 4 次）

3. **特殊路径法**：选择能让分母中某项为零的路径，使函数值突变。
   - 例：x²y²/(x²y²+(x-y)²)，沿 y=x 时分母第二项为零

### 6.6 更多路径依赖反例

**反例六**：f(x,y)=xy²/(x²+y⁴)

沿 y=kx：f=x·k²x²/(x²+k⁴x⁴)=k²x/(1+k⁴x²)→0。
沿 x=ky²：f=ky²·y²/(k²y⁴+y⁴)=k/(k²+1)。
- k=1：极限=1/2
- k=2：极限=2/5
沿不同抛物线 x=ky² 得到不同极限，重极限不存在。

**反例七**：f(x,y)=xy/(x²+y²)·sin(1/(x²+y²))

沿 y=kx：f=k/(1+k²)·sin(1/((1+k²)x²))。
当 x→0 时，sin(1/((1+k²)x²)) 在 [-1,1] 之间振荡，不趋于固定值。
所以沿任何直线 y=kx（k≠0），极限都不存在（振荡）。
沿 y=0：f=0，极限=0。
重极限不存在。

**反例八**：f(x,y)=e^{-1/(x²+y²)}·cos(1/(x²+y²))

这个函数沿所有路径都趋于 0（因为 e^{-1/r²}→0 比任何多项式都快，cos 有界），所以重极限=0。
但它的偏导数在原点不存在（偏导数在原点附近无限振荡）。
这个例子说明：重极限存在（甚至函数连续）不代表偏导数存在。

### 6.7 路径依赖性的几何理解

**📐 几何深化**：路径依赖性在几何上是"曲面在某点上方的各向异性"。如果曲面在 P₀ 上方是"各向同性"的——不管从哪个方向靠近，高度都趋于同一个值——那么重极限存在。如果曲面是"各向异性"的——不同方向的高度趋于不同的值——那么重极限不存在。

更微妙的是"直线方向各向同性但曲线方向各向异性"的情形（如反例二）——曲面在所有直线方向上看起来"平滑"，但沿抛物线靠近时会"凸起"或"凹陷"。这就像一座山，从所有大路（直线）看过去山顶高度一样，但沿一条小路（抛物线）爬上去会发现一个不同的高度。几何上，这意味着曲面在该点的"平坦性"不够——它在高阶方向上有"褶皱"。

## 第七章 极坐标变换的应用与陷阱

### 7.1 极坐标变换的基本思想

令 x=r cosθ, y=r sinθ，则 (x,y)→(0,0) 等价于 r→0（θ 可以任意变化）。

重极限 lim_{(x,y)→(0,0)} f(x,y)=A 等价于：
∀ε>0, ∃δ>0, 当 0&lt;r&lt;δ 时，对所有 θ，都有 |f(r cosθ, r sinθ)-A|&lt;ε。

**关键**：极坐标变换后，r→0 时 θ 必须是任意的——不能固定 θ。如果固定 θ=θ₀，那只是沿一条射线趋近，不能代表所有路径。

### 7.2 极坐标变换的正确应用

**例 1**：证明 lim_{(x,y)→(0,0)} (x²+y²) ln(x²+y²) = 0

极坐标：f = r² ln r² = 2r² ln r。
当 r→0 时，2r² ln r→0（因为 r^α ln r→0 对任意 α>0）。
这个极限与 θ 无关，所以重极限=0。∎

**例 2**：证明 lim_{(x,y)→(0,0)} x³/(x²+y²) = 0

极坐标：f = r³ cos³θ / r² = r cos³θ。
|f| = r|cos³θ| ≤ r → 0（r→0）。
与 θ 无关，重极限=0。∎

**方法**：如果极坐标变换后 |f(r,θ)| ≤ g(r)，其中 g(r)→0 且与 θ 无关，那么可以用夹逼定理证明重极限=0。

### 7.3 极坐标变换的陷阱

**陷阱一：固定 θ**

错误做法：令 x=r cosθ, y=r sinθ，固定 θ，令 r→0，得到极限。这只检查了沿射线 y=(tanθ)x 的极限，不能代表所有路径。

**反例**：f(x,y)=xy/(x²+y²)，极坐标 f=cosθ sinθ=(sin2θ)/2。
如果固定 θ，r→0 时 f=(sin2θ)/2，是一个常数。但这个常数依赖于 θ——不同 θ 得到不同值。所以不能说"极限等于 (sin2θ)/2"，而应该说"极限不存在，因为依赖于 θ"。

**陷阱二：r→0 时 θ 也在变**

有些路径在极坐标下不是 θ 固定，而是 θ 随 r 变化。比如：
- 沿抛物线 y=x²：r sinθ = r² cos²θ ⇒ sinθ = r cos²θ ⇒ θ≈r（当 r→0 时，θ→0）
- 沿螺旋线 r=θ：r→0 时 θ→0

如果只检查 θ 固定的情形，会漏掉这些路径。

**正确做法**：极坐标变换后，必须证明 |f(r,θ)-A|≤g(r)，其中 g(r)→0 且 g(r) 与 θ 无关。如果做不到这一点（即 f 的极限依赖于 θ 或 θ 的变化方式），就不能用极坐标变换证明重极限存在。

### 7.4 极坐标变换的适用范围

**适用**：
1. 函数含有 x²+y²（极坐标下变为 r²，简化计算）
2. 函数是齐次函数（极坐标下 f=r^k·g(θ)，容易判断）
3. 能证明 |f|≤g(r) 且 g(r)→0（夹逼定理）

**不适用**：
1. 函数含有 x-y 或其他非齐次项（极坐标下可能变复杂）
2. 函数在某些特殊路径（如抛物线）上有不同行为（极坐标下 θ 随 r 变化，容易忽略）
3. 极限点不在原点（需要先平移）

## 第八章 多元极限的计算方法

### 8.1 方法总结

| 方法 | 适用场景 | 关键思想 |
|---|---|---|
| 定义法（ε-δ） | 简单函数、证明题 | 直接验证定义 |
| 四则运算法 | 可分解为简单函数 | 极限的四则运算 |
| 夹逼定理 | 函数被夹在两个简单函数之间 | 估计上下界，与 θ 无关 |
| 变量替换 | 复合函数，可简化 | 令 u=g(x,y)，转化为一元极限 |
| 极坐标变换 | 含 x²+y² 或齐次函数 | x=r cosθ, y=r sinθ，证明与 θ 无关 |
| 平移法 | 极限点不在原点 | 令 u=x-x₀, v=y-y₀ |
| 路径判据 | 证明极限不存在 | 找两条路径得到不同极限 |
| 不等式估计 | 含绝对值、根式 | 用 |x|,|y|≤√(x²+y²) 估计 |
| 取对数 | 幂指函数 f(x,y)^{g(x,y)} | 对数化幂为乘 |

### 8.2 综合例题

**例 1（夹逼定理）**：lim_{(x,y)→(0,0)} (x²+y²) sin(1/(x²+y²))

因为 |sin(1/(x²+y²))|≤1，所以 |f|≤x²+y²→0。由夹逼定理，极限=0。

**例 2（变量替换）**：lim_{(x,y)→(0,0)} (e^{x²+y²}-1)/(x²+y²)

令 u=x²+y²→0，则极限=lim_{u→0} (e^u-1)/u = 1（一元重要极限）。

**例 3（极坐标+夹逼）**：lim_{(x,y)→(0,0)} (x³+y³)/(x²+y²)

极坐标：f = r³(cos³θ+sin³θ)/r² = r(cos³θ+sin³θ)。
|f| ≤ r(|cos³θ|+|sin³θ|) ≤ 2r → 0。
极限=0。

**例 4（路径判据，证明不存在）**：lim_{(x,y)→(0,0)} x²y/(x⁴+y²)

沿 y=kx：f=kx³/(x⁴+k²x²)=kx/(x²+k²)→0。
沿 y=x²：f=x²·x²/(x⁴+x⁴)=x⁴/(2x⁴)=1/2。
两条路径极限不同（0 vs 1/2），重极限不存在。

**例 5（不等式估计）**：lim_{(x,y)→(0,0)} (x²y+xy²)/(x²+y²)

|f| = |xy(x+y)|/(x²+y²) ≤ |xy|(|x|+|y|)/(x²+y²)
因为 |xy|≤(x²+y²)/2，|x|+|y|≤√2·√(x²+y²)，
所以 |f| ≤ (x²+y²)/2 · √2·√(x²+y²)/(x²+y²) = (√2/2)√(x²+y²) → 0。
极限=0。

**例 6（取对数）**：lim_{(x,y)→(0,0)} (x²+y²)^{x²+y²}

令 u=x²+y²→0⁺，则极限=lim_{u→0⁺} u^u = exp(lim_{u→0⁺} u ln u) = exp(0) = 1。
（因为 u ln u→0，这是一元函数的标准极限。）

**例 7（证明不存在）**：lim_{(x,y)→(0,0)} (x²-y²)/(x²+y²)

沿 y=0：f=x²/x²=1，极限=1。
沿 x=0：f=-y²/y²=-1，极限=-1。
两条路径极限不同，重极限不存在。

**例 8（证明不存在）**：lim_{(x,y)→(0,0)} cos((x+y)/(x-y))

沿 y=0：f=cos(1)，极限=cos(1)。
沿 y=kx（k≠1）：f=cos((1+k)/(1-k))，极限=cos((1+k)/(1-k))，依赖于 k。
沿不同直线得到不同极限，重极限不存在。

### 8.3 判断多元极限存在性的一般策略

**第一步：先猜极限值**
- 如果函数看起来"光滑"，尝试直接代入（如果函数在该点连续）
- 如果是 0/0 型，尝试估计阶数，猜测极限值

**第二步：尝试证明极限存在**
- 用夹逼定理：找到上下界都趋于同一个值
- 用极坐标变换：证明 |f(r,θ)|≤g(r)，g(r)→0 且与 θ 无关
- 用变量替换：转化为一元极限
- 用不等式估计：|x|,|y|≤√(x²+y²)

**第三步：如果证明困难，尝试证明不存在**
- 沿直线 y=kx 趋近，看极限是否依赖 k
- 如果沿所有直线极限相同，尝试沿抛物线 y=kx² 或 x=ky²
- 如果还不行，尝试更复杂的路径（如 y=x^α，螺旋线等）

**第四步：总结**
- 如果找到了两条路径极限不同，极限不存在
- 如果用夹逼/极坐标/变量替换证明了极限存在，给出严格证明

## 第九章 n 元函数的极限

### 9.1 n 元函数重极限的定义

**定义**：设 n 元函数 f(x₁,x₂,...,xₙ) 在点 P₀(x₁⁰,x₂⁰,...,xₙ⁰) 的某去心邻域内有定义。如果 ∀ε>0, ∃δ>0，当 0&lt;√[Σ_{i=1}^n (x_i-x_i⁰)²]&lt;δ 时，|f-A|&lt;ε，则称 f 在 P₀ 处的重极限为 A。

和二元函数完全类似，只是距离从二维推广到 n 维。

### 9.2 n 元函数极限的特点

1. **路径更多**：n 维空间中的路径比二维更丰富，路径依赖性更复杂。
2. **距离等价**：n 维欧氏空间中，各种距离（欧氏、曼哈顿、切比雪夫）仍然等价。
3. **极坐标推广**：可以用球坐标（n 维球面坐标），但角度参数更多，更复杂。
4. **理论一致**：重极限与累次极限的关系、路径判据、四则运算等理论都可以直接推广到 n 元。

### 9.3 常见的 n 元极限

**例 1**：lim_{P→P₀} ||P-P₀||² = 0（显然）

**例 2**：lim_{(x₁,...,xₙ)→0} (Σ x_i²) ln(Σ x_i²) = 0（令 r²=Σx_i²，r² ln r²→0）

**例 3**：lim_{(x₁,...,xₙ)→0} (Σ x_i³)/(Σ x_i²) = 0（因为 |Σx_i³|≤Σ|x_i|³≤(max|x_i|)·Σx_i²≤||P||·Σx_i²，所以 |f|≤||P||→0）

### 9.4 三元函数极限举例

**例**：lim_{(x,y,z)→(0,0,0)} (x+y+z)/(x²+y²+z²)

沿 x=y=z=t→0：f=3t/(3t²)=1/t→∞，极限不存在（发散到无穷）。

实际上，沿任何过原点的直线 (x,y,z)=t(a,b,c)→0，f=t(a+b+c)/(t²(a²+b²+c²))=(a+b+c)/(t(a²+b²+c²))→±∞（除非 a+b+c=0）。
所以重极限不存在。

**例**：lim_{(x,y,z)→(0,0,0)} (x²+y²+z²) ln(x²+y²+z²) = 0

令 r²=x²+y²+z²→0⁺，则极限=lim_{r→0⁺} r² ln r² = 2 lim r² ln r = 0。
与方向无关，重极限=0。

### 9.5 多元极限与连续性的关系

**定义**：f(x,y) 在 (x₀,y₀) 处连续 ⟺ lim_{(x,y)→(x₀,y₀)} f(x,y) = f(x₀,y₀)。

这意味着：
1. f 在 (x₀,y₀) 处有定义
2. 重极限存在
3. 重极限等于函数值

**多元连续函数的性质**：
- 连续函数的和、差、积、商（分母非零）连续
- 连续函数的复合连续
- 有界闭集（紧集）上的连续函数有最大值和最小值
- 有界闭集上的连续函数一致连续
- 连通集上的连续函数满足介值定理

**不连续的类型**：
- 重极限不存在（路径依赖）→ 不连续
- 重极限存在但不等于函数值 → 可去间断
- 重极限为无穷大 → 无穷间断

## 第十章 反例库

### 10.1 重极限不存在的反例

**反例 1**：f(x,y)=xy/(x²+y²)，沿 y=kx 极限=k/(1+k²)，依赖 k。

**反例 2**：f(x,y)=x²y/(x⁴+y²)，沿 y=kx 极限=0，沿 y=x² 极限=1/2。

**反例 3**：f(x,y)=(x-y)/(x+y)，两个累次极限分别为 -1 和 1，不相等。

**反例 4**：f(x,y)=x²y²/(x²y²+(x-y)²)，沿 y=x 极限=1，沿其他路径极限=0。

**反例 5**：f(x,y)=sin(xy)/(x²+y²)，沿 y=x 极限=sin(x²)/(2x²)→1/2，沿 y=0 极限=0。

### 10.2 累次极限的反例

**反例 6**：两个累次极限都存在且相等，但重极限不存在——反例 1、2、4。

**反例 7**：两个累次极限不相等——反例 3。

**反例 8**：一个累次极限存在，另一个不存在。
f(x,y)=x sin(1/y)+y sin(1/x)
先 x 后 y：固定 y≠0，lim_{x→0} [x sin(1/y)+y sin(1/x)] 不存在（因为 y sin(1/x) 振荡）。
先 y 后 x：同理不存在。
但重极限存在：|f|≤|x|+|y|→0，所以重极限=0。

**反例 9**：重极限存在，但累次极限不存在——反例 8。

### 10.3 极坐标变换的反例

**反例 10**：极坐标变换后 f 与 θ 有关，不能直接令 r→0。
f(x,y)=xy/(x²+y²)，极坐标 f=(sin2θ)/2，与 θ 有关，极限不存在。

**反例 11**：极坐标变换后 f 与 θ 无关，但 θ 随 r 变化时可能有不同行为。
f(x,y)=e^{-1/(x²+y²)} / [e^{-1/(x²+y²)} + (y-x²)²]
沿 y=x²：f=e^{-1/x²}/[e^{-1/x²}+0]=1。
沿 y=0：f=e^{-1/x²}/[e^{-1/x²}+x⁴]→0（因为 e^{-1/x²} 比 x⁴ 更快趋于 0）。
极坐标下 f 看起来与 θ 无关（因为 x²+y²=r²），但沿 y=x² 时 θ≈r，r→0 时 (y-x²)=0，导致 f=1。这说明极坐标变换后即使 f 表面上与 θ 无关，也不能忽略 θ 随 r 变化的路径。

### 10.4 四则运算的反例

**反例 12**：两个重极限都不存在，但它们的和的重极限存在。
f(x,y)=xy/(x²+y²)，g(x,y)=-xy/(x²+y²)，都不存在极限，但 f+g=0 极限存在。

**反例 13**：0/0 型不定式结果不确定。
- lim x²/(x²+y²)：沿 y=kx 极限=1/(1+k²)，不存在
- lim x³/(x²+y²)=0（存在）
同样是 0/0 型，结果不同。

## 第十一章 历史演进

### 11.1 多元函数极限理论的历史分期

**第一期：多元微积分的创立（1748 - 1821）**
- 欧拉（1748）：《无穷分析引论》，多元函数概念的萌芽
- 拉格朗日（1760s）：多元函数的微分学
- 蒙日（1780s）：曲面的微分几何

**第二期：严格化运动（1821 - 1900）**
- 柯西（1821）：多元函数极限的初步处理
- 魏尔斯特拉斯（1850s-1870s）：ε-δ 定义推广到多元
- 迪尼（Dini, 1878）：累次极限与重极限的区别
- 皮亚诺（Peano, 1884）：路径依赖性的反例
- 若尔当（Jordan, 1893）：多元函数极限的系统处理

**第三期：现代发展（1900 - 至今）**
- 勒贝格（1902）：Lebesgue 积分，多元积分理论
- 豪斯多夫（1914）：拓扑空间，极限的一般化
- 穆尔-史密斯（Moore-Smith, 1922）：网收敛（一般拓扑空间中的极限）
- 泛函分析的发展：无限维空间中的极限

### 11.3 历史发展的主线

1. **严格化**：从直观的"趋近"到 ε-δ 严格定义，从一元到多元。
2. **路径依赖性的发现**：皮亚诺等人发现多元极限的路径依赖性，这是多元极限区别于一元极限的核心特征。
3. **一般化**：从欧氏空间到度量空间到拓扑空间，极限概念不断一般化。

### 11.4 多元极限严格化的关键突破

多元极限理论的严格化经历了几个关键突破：

1. **魏尔斯特拉斯的 ε-δ 定义**：将一元函数的 ε-δ 定义推广到多元，用 n 维欧氏距离代替一维绝对值。这是多元极限严格化的基础。

2. **路径依赖性的发现**：皮亚诺（Peano）在 1884 年的《无穷小分析几何应用》中系统研究了多元函数的极限，发现了"沿不同路径极限不同"的现象。这是多元极限区别于一元极限的核心特征。

3. **累次极限与重极限的区分**：迪尼（Dini）在 1878 年的《变量函数论基础》中明确区分了累次极限和重极限，给出了重极限存在但累次极限不存在的反例，以及两个累次极限不相等的反例。

4. **一致收敛概念的引入**：多元函数项级数的一致收敛概念是由魏尔斯特拉斯引入的，它解决了"极限交换顺序"的问题——什么时候可以交换两个极限的顺序？这是累次极限理论的核心问题。

5. **拓扑学的一般化**：豪斯多夫（Hausdorff）在 1914 年的《集合论基础》中建立了拓扑空间的概念，将极限从欧氏空间推广到一般拓扑空间。穆尔-史密斯（Moore-Smith）在 1922 年引入了"网收敛"（net convergence），将序列极限推广到一般拓扑空间中的极限。

```
  ↓ 升维到复变
  └── z̄/z（复变：沿不同方向极限不同，z→0 时极限不存在）
      └── 从"实路径依赖"变成"复方向依赖"

x²y/(x⁴+y²)（多元：沿直线极限=0，沿抛物线极限=1/2）
  ↓ 升维到复变
  └── 类似的复变函数（沿不同曲线极限不同）
      └── 复变函数的"本性奇点"概念

(x-y)/(x+y)（多元：两个累次极限不等）
  ↓ 复变中
  └── 复变函数没有累次极限（复变量不可分实部虚部）
      └── 但有类似的"沿不同射线极限不同"
```

### 12.4 关键蜕变问题

**问题一：为什么多元极限有路径依赖性，一元极限没有？**

回答：因为一元函数中 x 趋近 x₀ 只有两个方向（左和右），只要左右极限相等就够了。但多元函数中，(x,y) 趋近 (x₀,y₀) 有无穷多条路径——直线、抛物线、螺旋线、任意曲线。重极限要求沿所有路径趋近都得到同一个极限，这比一元严格得多。路径依赖性是多元极限区别于一元极限的核心特征。

**问题二：极坐标变换能用来判断多元极限吗？有什么陷阱？**

回答：极坐标变换可以用来**证明**多元极限存在（如果能证明 |f(r,θ)|≤g(r)，g(r)→0 且与 θ 无关），也可以用来**证明**极限不存在（如果 f(r,θ) 的极限依赖于 θ）。但陷阱是：(1) 不能固定 θ 令 r→0——这只检查了沿射线的极限；(2) 不能忽略 θ 随 r 变化的路径（如抛物线 y=x² 在极坐标下 θ≈r）；(3) 即使 f 表面上与 θ 无关，也可能在特殊路径上有不同行为。

**问题三：重极限和累次极限是什么关系？**

回答：重极限存在 + 内层极限存在 ⇒ 累次极限存在且等于重极限。但反过来不成立——两个累次极限都存在且相等，也不能保证重极限存在（如 xy/(x²+y²)）。如果两个累次极限不相等，那么重极限一定不存在。累次极限是两次一元极限，每次只让一个变量变化；重极限要求两个变量同时变化，且沿所有路径都得到同一个极限。

**问题四：为什么要研究多元极限？它有什么用？**

回答：多元极限是多元微积分的基础——多元函数的连续性、偏导数、全微分、重积分等概念都建立在多元极限之上。路径依赖性的研究帮助我们理解多元函数的"病态"行为——为什么有些函数在某点不连续、不可微。在实际应用中（物理、工程、经济学），大多数函数是多元的，多元极限理论是处理这些函数的基础工具。

### 12.5 从一元到多元的概念升维总结

| 概念 | 一元函数 | 多元函数 | 升维的本质 |
|---|---|---|---|
| 趋近方向 | 2个（左、右） | 无穷多个（任意路径） | 从"方向"到"路径" |
| 极限存在条件 | 左右极限相等 | 沿所有路径极限相等 | 从"检查2个方向"到"检查无穷路径" |
| 极限定义 | ε-δ（一维距离） | ε-δ（n维距离） | 距离公式推广 |
| 累次极限 | 无 | 有（先x后y等） | 多元特有的"分步取极限" |
| 极坐标变换 | 不适用 | 适用（二维） | 利用旋转对称性简化 |
| 路径判据 | 不适用（只有2方向） | 核心方法 | 证明不存在的最有力工具 |
| 连续性 | 极限=函数值 | 极限=函数值 | 定义相同，但验证更难 |
| 可导性 | 可导⟺左右导数相等 | 偏导存在⇏可微 | 从"可导"到"可微"的概念变化 |

升维的核心变化是：**从"方向"到"路径"**。一元函数只有两个方向，多元函数有无穷多条路径，这使得多元极限的存在性判断比一元复杂得多。路径依赖性是多元极限的核心难点，也是多元微积分区别于一元微积分的根本特征之一。

### 13.3 常见误区清单

1. **两个累次极限相等⇒重极限存在** → 错。如 xy/(x²+y²)，两个累次极限都是 0，但重极限不存在。
2. **沿所有直线极限相等⇒重极限存在** → 错。如 x²y/(x⁴+y²)，沿所有直线极限都是 0，但沿抛物线 y=x² 极限=1/2。
3. **极坐标变换后令 r→0 就得到重极限** → 错。必须检查与 θ 是否有关，以及 θ 随 r 变化的路径。
4. **多元极限和一元极限一样简单** → 错。路径依赖性使得多元极限的存在性判断比一元复杂得多。
5. **重极限存在⇒累次极限存在** → 错。还需要内层极限存在。如 x sin(1/y)+y sin(1/x)，重极限=0，但累次极限不存在。
6. **固定 θ 令 r→0 就是极坐标法** → 错。这只检查了沿射线的极限，不是所有路径。
7. **f(x,y) 在 (x₀,y₀) 处有定义⇒重极限等于 f(x₀,y₀)** → 错。重极限与函数值无关，f 在该点可以不连续。
8. **n 越大，极限越难** → 不一定。很多 n 元极限的处理方法和二元一样，只是距离公式不同。

### 13.4 实用技巧与口诀

**技巧一：先猜后证**
拿到一个多元极限，先猜极限值。怎么猜？
- 如果函数在该点连续，直接代入
- 如果是 0/0 型，先看分子分母的"次数"，猜测极限值
- 沿几条特殊路径（x轴、y轴、y=x）算一下，如果都一样，可能极限存在

**技巧二：证明不存在优先于证明存在**
如果猜测极限可能不存在，先尝试找两条路径得到不同极限。这比证明极限存在容易得多——只需要找到反例。

**技巧三：极坐标变换的检查清单**
使用极坐标变换后，检查以下几点：
1. f(r,θ) 是否与 θ 有关？如果有关，极限很可能不存在
2. 如果 f(r,θ) 与 θ 无关，令 r→0 得到极限值
3. 检查是否有 θ 随 r 变化的特殊路径（如抛物线）被忽略
4. 最好用夹逼定理 |f|≤g(r) 来严格证明

**技巧四：常见的"危险信号"**
以下情况通常意味着极限不存在：
- 分子分母都是同次齐次多项式（如 xy/(x²+y²)）
- 含有 x-y 或 x+y 的项（沿 y=x 或 y=-x 可能突变）
- 含有 sin(1/r) 或 cos(1/r) 的振荡项
- 函数在某些路径上分母为零

**口诀**：
- "多元极限看路径，两条不同就不存在"
- "极坐标变换要小心，固定 θ 只看射线"
- "累次极限两回事，相等也不保证重极限"
- "先猜后证找反例，证明不存在更容易"

### 13.5 与后续课程的联系

多元函数极限是以下课程的基础：

1. **多元函数微分学**：偏导数、全微分、方向导数、梯度、隐函数定理、多元极值——都建立在多元极限之上
2. **重积分**：二重积分、三重积分、曲线积分、曲面积分——积分定义是黎曼和的多元极限

>
> 多元函数极限是分析学从一维到高维的关键一步——它将 D1-3 的一元函数极限理论推广到 n 维空间，揭示了多元极限区别于一元极限的核心特征：路径依赖性。
>
> 本模块从五个维度建立了多元函数极限的完整理论：
>
> **定义体系**：重极限的 ε-δ 定义（n 维欧氏距离）、去心邻域、基本性质（唯一性、局部有界性、局部保号性、迫敛性）、四则运算法则。
>
> **累次极限**：先 x 后 y 和先 y 后 x 两种累次极限的定义和计算。累次极限是两次一元极限，每次只让一个变量变化。
>
> **重极限与累次极限的关系**：重极限存在 + 内层极限存在 ⇒ 累次极限存在且相等；但反过来不成立——两个累次极限都存在且相等也不能保证重极限存在。两个累次极限不相等 ⇒ 重极限不存在。
>
> **路径依赖性**：重极限存在 ⟺ 沿所有路径趋近都得到同一个极限。这是多元极限的核心难点——证明重极限不存在只需要找到两条路径得到不同极限。经典反例 xy/(x²+y²)（沿不同直线极限不同）和 x²y/(x⁴+y²)（沿直线极限=0，沿抛物线极限=1/2）展示了路径依赖性的微妙之处。
>
> **极坐标变换**：x=r cosθ, y=r sinθ 是计算多元极限的有力工具，但有重要陷阱——不能固定 θ 令 r→0（这只检查了沿射线的极限），必须证明与 θ 无关，且不能忽略 θ 随 r 变化的路径（如抛物线）。
>
> 多元函数极限的核心洞察是：**多元极限的本质是"各向同性"——沿所有路径趋近都得到同一个极限，而路径依赖性是多元极限区别于一元极限的根本特征**。在一元函数中，只需要检查两个方向；在多元函数中，需要检查无穷多条路径，这使得多元极限的存在性判断比一元复杂得多。
>
