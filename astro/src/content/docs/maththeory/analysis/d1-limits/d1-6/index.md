## 第一章 引言：从逐点收敛到整体收敛

### 1.1 为什么需要多种收敛模式

在数学分析中，我们主要研究"逐点收敛"——函数列 fₙ(x) 在每个点 x 处都收敛到 f(x)。但在实变函数中，逐点收敛有两个严重的问题：

**问题一：逐点收敛太"严格"了**

在实变函数中，我们经常在"零测集"上不关心函数的值——两个在零测集上不同的函数被认为是"同一个"函数（等价类）。如果要求逐点收敛，那么即使 fₙ 在除了一个零测集之外的所有点都收敛到 f，我们也不能说 fₙ→f。这太严格了——我们应该允许在零测集上不收敛。

**问题二：逐点收敛不保持积分**

即使 fₙ 逐点收敛到 f，积分也不一定收敛：∫fₙ 不一定→∫f。经典反例：fₙ(x)=n·χ_{(0,1/n)}(x)，在 (0,1) 上逐点收敛到 0，但 ∫fₙ=1 不趋于 0。

为了解决这两个问题，实变函数引入了多种收敛模式：
- **几乎处处收敛（a.e.）**：允许在零测集上不收敛
- **依测度收敛**：不收敛的集合的测度趋于 0
- **Lp 收敛**：函数差的 p 次幂积分趋于 0（"平均收敛"）
- **几乎一致收敛（a.u.）**：除了一个测度任意小的集合外，一致收敛

## 第二章 几乎处处收敛

### 2.1 定义

**定义**：设 (X,𝓜,μ) 是测度空间，fₙ, f 是可测函数。如果存在零测集 N（μ(N)=0），使得对所有 x∉N，都有 fₙ(x)→f(x)，则称 fₙ 几乎处处收敛于 f，记作 fₙ→f a.e.（almost everywhere）。

**和逐点收敛的区别**：逐点收敛要求在所有点收敛，几乎处处收敛允许在零测集上不收敛。在实变函数中，零测集被认为是"可以忽略"的，所以几乎处处收敛是逐点收敛的"合理放宽"。

### 2.2 几乎处处收敛的基本性质

1. **极限唯一性（a.e.）**：若 fₙ→f a.e. 且 fₙ→g a.e.，则 f=g a.e.
2. **线性性**：若 fₙ→f a.e., gₙ→g a.e.，则 fₙ+gₙ→f+g a.e., c fₙ→c f a.e.
3. **乘积**：若 fₙ→f a.e., gₙ→g a.e.，则 fₙ·gₙ→f·g a.e.
4. **最大值/最小值**：若 fₙ→f a.e., gₙ→g a.e.，则 max(fₙ,gₙ)→max(f,g) a.e.
5. **绝对值**：若 fₙ→f a.e.，则 |fₙ|→|f| a.e.

这些性质的证明都很直接——不收敛的集合是各个 fₙ 不收敛集合的并，有限个或可数个零测集的并仍是零测集。

### 2.3 几乎处处收敛的几何理解

**📐 几何图像**：几乎处处收敛可以想象为"函数图像在几乎所有位置都向目标图像靠拢"。在 x-y 平面上，fₙ(x) 的图像在绝大多数 x 处都向 f(x) 的图像靠拢，只有在一个"长度为零"的集合上（如一些离散的点、Cantor 集等），图像可能不靠拢甚至发散。这些"不靠拢"的点集在几何上是"可以忽略的"——它们没有长度（测度为零）。

对比逐点收敛：逐点收敛要求图像在**所有** x 处都靠拢，包括那些"长度为零"的点集。几乎处处收敛放宽了这个要求——只要在"有长度"的地方靠拢就行。

### 2.4 几乎处处收敛的例题

**例 1**：fₙ(x)=xⁿ，在 [0,1] 上。
- 当 x∈[0,1) 时，xⁿ→0
- 当 x=1 时，xⁿ→1
所以 fₙ→f a.e.，其中 f(x)=0（x∈[0,1)）, f(1)=1。
不收敛的集合是空集（实际上在所有点都收敛，只是极限函数在 x=1 处为 1）。
如果定义 f(x)=0 对所有 x∈[0,1]，则 fₙ→f a.e.（因为只在 x=1 这一个零测集上不收敛到 0）。

**例 2**：fₙ(x)=n·χ_{(0,1/n)}(x)，在 (0,1) 上。
- 对任意固定的 x∈(0,1)，当 n>1/x 时，x∉(0,1/n)，所以 fₙ(x)=0。
因此 fₙ→0 a.e.（实际上逐点收敛到 0）。
但 ∫fₙ = n·(1/n)=1 不趋于 0。
这说明：几乎处处收敛不保证积分收敛。

**例 3**：fₙ(x)=χ_{(k/2^m,(k+1)/2^m]}(x)，其中 n=2^m+k，0≤k&lt;2^m。
这是"滑动区间"函数列——fₙ 在一个长度为 1/2^m 的区间上为 1，其余为 0，区间在 [0,1] 上滑动。
- 对任意固定的 x∈[0,1]，x 属于无穷多个这样的区间（因为区间越来越小但覆盖整个 [0,1]），也不属于无穷多个区间。
所以 fₙ(x) 在 0 和 1 之间振荡，不收敛。
因此 fₙ 不几乎处处收敛到任何函数。
但 fₙ 依测度收敛到 0（见第三章）。

## 第三章 依测度收敛

### 3.1 定义

**定义**：设 (X,𝓜,μ) 是测度空间，fₙ, f 是可测函数。如果对任意 ε>0，都有
lim_{n→∞} μ({x : |fₙ(x)-f(x)|≥ε}) = 0
则称 fₙ 依测度收敛于 f，记作 fₙ→^μ f 或 fₙ⇒f。

**直观理解**：依测度收敛意味着"fₙ 和 f 差别大的地方越来越少"——对于任意给定的误差 ε，fₙ 和 f 差别超过 ε 的集合的测度趋于 0。不要求在每个点收敛，只要求"不收敛（差别大）的地方的面积趋于 0"。

### 3.2 依测度收敛的基本性质

1. **极限唯一性（a.e.）**：若 fₙ→^μ f 且 fₙ→^μ g，则 f=g a.e.
2. **线性性**：若 fₙ→^μ f, gₙ→^μ g，则 fₙ+gₙ→^μ f+g, c fₙ→^μ c f
3. **乘积（有限测度空间）**：若 fₙ→^μ f, gₙ→^μ g，且测度空间有限，则 fₙ·gₙ→^μ f·g
4. **绝对值**：若 fₙ→^μ f，则 |fₙ|→^μ |f|
5. **子列性质**：若 fₙ→^μ f，则存在子列 fₙₖ→f a.e.（Riesz 定理，见第九章）

### 3.3 依测度收敛的几何理解

**📐 几何图像**：依测度收敛可以想象为"函数图像和目标图像之间的'差异区域'的面积越来越小"。在 x-y 平面上，画出 fₙ(x) 和 f(x) 的图像，它们之间的"垂直距离"超过 ε 的 x 的集合的"长度"（测度）趋于 0。这意味着 fₙ 和 f 在"大部分地方"都很接近，只有在"面积很小"的地方差别大。

对比几乎处处收敛：几乎处处收敛要求在"除了零测集之外的所有点"都收敛——不收敛的集合测度为 0。依测度收敛更弱——不收敛的集合测度可以不为 0，只要趋于 0 就行。所以几乎处处收敛比依测度收敛强（在有限测度空间上）。

### 3.4 依测度收敛的例题

**例 1**：fₙ(x)=n·χ_{(0,1/n)}(x)，在 (0,1) 上。
对任意 ε>0：
- 如果 ε&lt;n（即 n>ε），则 {x : |fₙ(x)|≥ε} = (0,1/n)，测度=1/n→0
- 如果 ε≥n，则 {x : |fₙ(x)|≥ε} = ∅，测度=0
所以 fₙ→^μ 0。
（同时 fₙ→0 a.e.，但 ∫fₙ=1 不趋于 0。）

**例 2**：滑动区间函数列 fₙ=χ_{(k/2^m,(k+1)/2^m]}（n=2^m+k）。
对任意 ε∈(0,1)，{x : |fₙ(x)|≥ε} = 那个区间，测度=1/2^m→0（因为 n→∞ 时 m→∞）。
所以 fₙ→^μ 0。
但 fₙ 不几乎处处收敛（见第二章例 3）。
这说明：依测度收敛不蕴含几乎处处收敛。

**例 3**：fₙ(x)=χ_{(n,n+1)}(x)，在 ℝ 上（无限测度空间）。
对任意 ε∈(0,1)，{x : |fₙ(x)|≥ε}=(n,n+1)，测度=1，不趋于 0。
所以 fₙ 不依测度收敛到 0。
但 fₙ→0 a.e.（对任意固定的 x，当 n>x 时 fₙ(x)=0）。
这说明：在无限测度空间上，几乎处处收敛不蕴含依测度收敛。

## 第四章 Lp 收敛

### 4.1 定义

**定义**：设 1≤p&lt;∞，fₙ, f∈Lp(X,𝓜,μ)。如果
lim_{n→∞} ∫|fₙ-f|^p dμ = 0
则称 fₙ 在 Lp 中收敛于 f，记作 fₙ→^Lp f 或 ||fₙ-f||_p→0。

**p=∞ 的情况**：L∞ 收敛即本质一致收敛：lim_{n→∞} ess sup |fₙ-f| = 0。

**直观理解**：Lp 收敛是"平均收敛"——fₙ 和 f 的差的 p 次幂的积分（"平均误差"）趋于 0。它不要求在每个点收敛，只要求"整体平均误差"趋于 0。

### 4.2 Lp 收敛的基本性质

1. **极限唯一性（a.e.）**：若 fₙ→^Lp f 且 fₙ→^Lp g，则 f=g a.e.
2. **线性性**：Lp 收敛保持线性运算
3. **范数收敛**：若 fₙ→^Lp f，则 ||fₙ||_p→||f||_p（由三角不等式 |||fₙ||_p-||f||_p|≤||fₙ-f||_p）
4. **蕴含依测度收敛**：若 fₙ→^Lp f，则 fₙ→^μ f（由 Chebyshev 不等式：μ({|fₙ-f|≥ε})≤(1/ε^p)∫|fₙ-f|^p→0）
5. **不蕴含几乎处处收敛**：Lp 收敛不蕴含几乎处处收敛（滑动区间反例）
6. **几乎处处收敛+控制⇒Lp 收敛**：若 fₙ→f a.e. 且 |fₙ|≤g∈Lp，则 fₙ→^Lp f（Lebesgue 控制收敛定理的 Lp 版本）

### 4.3 Lp 收敛的几何理解

**📐 几何图像**：Lp 收敛可以想象为"函数图像和目标图像之间的'面积'趋于 0"。在 x-y 平面上，|fₙ(x)-f(x)|^p 的图像下方的面积（积分）趋于 0。这意味着 fₙ 和 f 在"整体上"很接近——它们的图像之间的"区域面积"趋于 0。

不同的 p 对应不同的"几何度量"：
- p=1：面积（L1 距离）
- p=2：欧氏距离的平方（L2 距离，Hilbert 空间）
- p→∞：最大垂直距离（L∞ 距离，本质一致收敛）

Lp 收敛和依测度收敛的区别：Lp 收敛要求"整体面积"趋于 0，依测度收敛只要求"差别大的区域面积"趋于 0。Lp 收敛更强——它不仅要求差别大的区域小，还要求差别本身不能太大（因为差的 p 次幂积分要趋于 0）。

### 4.4 Lp 收敛的例题

**例 1**：fₙ(x)=n·χ_{(0,1/n)}(x)，在 (0,1) 上，p=1。
∫|fₙ-0| dx = ∫fₙ dx = n·(1/n)=1，不趋于 0。
所以 fₙ 不 L1 收敛到 0。
（但 fₙ→0 a.e. 且 fₙ→^μ 0。）

**例 2**：fₙ(x)=√n·χ_{(0,1/n)}(x)，在 (0,1) 上，p=2。
∫|fₙ|² dx = ∫n·χ_{(0,1/n)} dx = n·(1/n)=1，不趋于 0。
所以 fₙ 不 L2 收敛到 0。
但 fₙ→0 a.e. 且 fₙ→^μ 0。

**例 3**：fₙ(x)=n^α·χ_{(0,1/n)}(x)，在 (0,1) 上，p=1。
∫|fₙ| dx = n^α·(1/n)=n^{α-1}。
- 若 α&lt;1：n^{α-1}→0，L1 收敛到 0
- 若 α=1：n^{α-1}=1，不 L1 收敛
- 若 α>1：n^{α-1}→∞，不 L1 收敛
这说明：函数的"高度"和"宽度"的乘积决定了 L1 收敛性。高度增长太快（α≥1）就不 L1 收敛。

## 第五章 几乎一致收敛

### 5.1 定义

**定义**：设 (X,𝓜,μ) 是测度空间，fₙ, f 是可测函数。如果对任意 δ>0，存在可测集 E 使得 μ(E)&lt;δ，且 fₙ 在 E^c 上一致收敛于 f，则称 fₙ 几乎一致收敛于 f，记作 fₙ→f a.u.（almost uniformly）。

**直观理解**：几乎一致收敛意味着"除了一个测度任意小的集合外，一致收敛"。可以先去掉一个很小的集合，在剩下的集合上 fₙ 一致收敛到 f。

### 5.2 几乎一致收敛的基本性质

1. **蕴含几乎处处收敛**：若 fₙ→f a.u.，则 fₙ→f a.e.
   证明：对每个 k，取 E_k 使得 μ(E_k)&lt;1/k 且 fₙ 在 E_k^c 上一致收敛。令 N=∩_k E_k，则 μ(N)≤μ(E_k)&lt;1/k 对所有 k，所以 μ(N)=0。对 x∉N，存在 k 使得 x∉E_k，所以 fₙ(x)→f(x)。∎

2. **蕴含依测度收敛**：若 fₙ→f a.u.，则 fₙ→^μ f。
   证明：对任意 ε>0 和 δ>0，取 E 使得 μ(E)&lt;δ 且 fₙ 在 E^c 上一致收敛。则存在 N 使得 n>N 时 |fₙ-f|&lt;ε 在 E^c 上。所以 {|fₙ-f|≥ε}⊂E，μ({|fₙ-f|≥ε})≤μ(E)&lt;δ。由 δ 任意性，μ({|fₙ-f|≥ε})→0。∎

3. **极限唯一性（a.e.）**：几乎一致收敛的极限在 a.e. 意义下唯一。

### 5.3 几乎一致收敛的几何理解

**📐 几何图像**：几乎一致收敛可以想象为"去掉一小块区域后，函数图像整体向目标图像靠拢"。在 x-y 平面上，可以先去掉 x 轴上一个"长度任意小"的集合 E，在剩下的 x 集合上，fₙ(x) 的图像**一致**地向 f(x) 的图像靠拢——收敛速度不依赖于 x。

对比一致收敛：一致收敛要求在**所有** x 处收敛速度均匀。几乎一致收敛放宽了这个要求——可以先去掉一个任意小的集合，在剩下的集合上一致收敛。

对比几乎处处收敛：几乎处处收敛只要求在除了零测集之外的点收敛，但收敛速度可以不均匀。几乎一致收敛更强——除了小集合外，不仅收敛，而且一致收敛。

### 5.4 几乎一致收敛的例题

**例 1**：fₙ(x)=xⁿ，在 [0,1] 上。
对任意 δ>0，取 E=[1-δ/2,1]（测度=δ/2&lt;δ）。在 E^c=[0,1-δ/2) 上，|xⁿ-0|≤(1-δ/2)ⁿ→0，一致收敛。
所以 fₙ→0 a.u.
（同时 fₙ→0 a.e.）

**例 2**：fₙ(x)=n·χ_{(0,1/n)}(x)，在 (0,1) 上。
对任意 δ>0，取 E=(0,δ)（测度=δ）。在 E^c=[δ,1) 上，当 n>1/δ 时，(0,1/n)⊂(0,δ)，所以 fₙ=0 在 E^c 上，一致收敛到 0。
所以 fₙ→0 a.u.
（同时 fₙ→0 a.e. 且 fₙ→^μ 0，但不 L1 收敛。）

**例 3**：滑动区间函数列 fₙ=χ_{(k/2^m,(k+1)/2^m]}。
fₙ 不几乎一致收敛到 0。
证明：假设 fₙ→0 a.u.，则 fₙ→0 a.e.（因为 a.u.⇒a.e.）。但我们已经知道 fₙ 不 a.e. 收敛（第二章例 3）。矛盾。
所以 fₙ 不几乎一致收敛。
（但 fₙ→^μ 0。）

## 第六章 四种收敛模式的关系网

### 6.1 关系总览

在**有限测度空间**（如 [0,1] 上的 Lebesgue 测度）上，四种收敛模式的关系如下：

```
                    Lp 收敛
                       │
                       ▼
            几乎一致收敛 ──► 依测度收敛
                       │              │
                       ▼              ▼
                 几乎处处收敛      （子列 a.e.）
```

详细关系：
1. **Lp 收敛 ⇒ 依测度收敛**（Chebyshev 不等式）
2. **几乎一致收敛 ⇒ 几乎处处收敛**
3. **几乎一致收敛 ⇒ 依测度收敛**
4. **几乎处处收敛 + 有限测度 ⇒ 依测度收敛**（Lebesgue 定理）
5. **几乎处处收敛 + 有限测度 ⇒ 几乎一致收敛**（Egorov 定理）
6. **依测度收敛 ⇒ 存在子列几乎处处收敛**（Riesz 定理）
7. **依测度收敛 ⇒ 存在子列几乎一致收敛**（Riesz 定理的加强版）
8. **Lp 收敛 ⇏ 几乎处处收敛**（滑动区间反例）
9. **几乎处处收敛 ⇏ Lp 收敛**（fₙ=nχ_{(0,1/n)} 反例）
10. **依测度收敛 ⇏ 几乎处处收敛**（滑动区间反例）
11. **几乎处处收敛 ⇏ 几乎一致收敛**（在无限测度空间上；有限测度上由 Egorov 定理成立）

### 6.2 有限测度 vs 无限测度

在**无限测度空间**（如 ℝ 上的 Lebesgue 测度）上，关系有所不同：

1. **几乎处处收敛 ⇏ 依测度收敛**（fₙ=χ_{(n,n+1)} 反例）
2. **几乎处处收敛 ⇏ 几乎一致收敛**（fₙ=χ_{(n,n+1)} 反例）
3. **Egorov 定理不成立**（需要有限测度条件）
4. **Lp 收敛 ⇒ 依测度收敛**仍然成立（Chebyshev 不等式不需要有限测度）
5. **几乎一致收敛 ⇒ 几乎处处收敛**仍然成立
6. **几乎一致收敛 ⇒ 依测度收敛**仍然成立

### 6.3 关系表

| 从 \ 到 | a.e. | 依测度 | Lp | a.u. |
|---|---|---|---|---|
| **a.e.** | — | 有限测度⇒ | ⇏（需控制） | 有限测度⇒（Egorov） |
| **依测度** | ⇏（子列⇒） | — | ⇏ | ⇏（子列⇒） |
| **Lp** | ⇏（子列⇒） | ⇒ | — | ⇏（子列⇒） |
| **a.u.** | ⇒ | ⇒ | ⇏ | — |

### 6.4 关系网的几何理解

**📐 几何图像**：四种收敛模式可以按"强度"排序：

**最强**：L∞ 收敛（本质一致收敛）——函数图像在几乎所有地方都以均匀速度靠拢
**强**：几乎一致收敛——去掉一小块后均匀靠拢
**中**：Lp 收敛——图像之间的"面积"趋于 0
**中弱**：几乎处处收敛——在几乎所有点都靠拢（速度可不均匀）
**最弱**：依测度收敛——差别大的地方"面积"趋于 0

但这个排序不是线性的——Lp 收敛和几乎处处收敛之间没有蕴含关系（互相都不蕴含），它们是"不同维度"的收敛：Lp 收敛衡量"整体平均误差"，几乎处处收敛衡量"逐点收敛性"。依测度收敛是两者的"公共弱化"——Lp 收敛和几乎处处收敛（有限测度）都蕴含依测度收敛。

## 第七章 Egorov 定理

### 7.1 定理陈述

**Egorov 定理**：设 (X,𝓜,μ) 是有限测度空间（μ(X)&lt;∞），fₙ, f 是可测函数。如果 fₙ→f a.e.，则对任意 δ>0，存在可测集 E 使得 μ(E)&lt;δ，且 fₙ 在 E^c 上一致收敛于 f。即：**有限测度空间上，几乎处处收敛 ⇒ 几乎一致收敛**。

### 7.2 证明思路

1. 对每个 k，定义 E_{n,k} = ∪_{m≥n} {x : |fₘ(x)-f(x)|≥1/k}
2. 因为 fₙ→f a.e.，所以对每个 k，∩_n E_{n,k} 是零测集（不收敛的点集）
3. 因为 μ(X)&lt;∞，由测度的上连续性，μ(E_{n,k})→0（n→∞）
4. 对每个 k，取 n_k 使得 μ(E_{n_k,k})&lt;δ/2^k
5. 令 E=∪_k E_{n_k,k}，则 μ(E)≤Σ δ/2^k=δ
6. 在 E^c 上，对每个 k，当 n≥n_k 时 |fₙ-f|&lt;1/k，所以一致收敛

### 7.3 Egorov 定理的意义

Egorov 定理是实变函数中最重要的定理之一。它说：在有限测度空间上，几乎处处收敛和几乎一致收敛"差不多"——只差一个测度任意小的集合。这使得我们可以把几乎处处收敛的问题转化为几乎一致收敛的问题，而几乎一致收敛更容易处理（因为一致收敛有很多好的性质）。

**典型应用**：
- 证明 Lebesgue 控制收敛定理（先用 Egorov 把 a.e. 收敛转化为 a.u. 收敛，再处理小集合上的积分）
- 证明可测函数可以用简单函数逼近（Lusin 定理的证明中用到 Egorov）
- 研究函数列的收敛性

### 7.4 Egorov 定理的几何理解

**📐 几何图像**：Egorov 定理在几何上是"收敛速度的均匀化"。几乎处处收敛意味着在几乎所有点都收敛，但收敛速度可能不均匀——有些点收敛快，有些点收敛慢。Egorov 定理说：可以把那些"收敛特别慢"的点去掉（它们的集合测度任意小），在剩下的点上，收敛速度就均匀了。

想象一群人向终点跑——几乎所有人都能跑到终点（a.e. 收敛），但有些人跑得特别慢。Egorov 定理说：可以把那些最慢的人去掉（人数任意少），剩下的人到达终点的时间就有一个统一的上界（一致收敛）。

### 7.5 Egorov 定理的条件讨论

**有限测度条件必要吗？** 必要。在无限测度空间上，Egorov 定理不成立。
反例：fₙ(x)=χ_{(n,n+1)}(x) 在 ℝ 上，fₙ→0 a.e.，但不几乎一致收敛（对任意有限测度集合 E，在 E^c 上 fₙ 不趋于 0，因为 E^c 包含 (n,n+1) 对充分大的 n）。

**可测函数条件必要吗？** 是的，fₙ 和 f 都需要可测，否则 {|fₙ-f|≥ε} 可能不可测。

## 第八章 Lebesgue 控制收敛定理

### 8.1 定理陈述

**Lebesgue 控制收敛定理（DCT）**：设 (X,𝓜,μ) 是测度空间，fₙ, f 是可测函数。如果：
1. fₙ→f a.e.（或依测度收敛）
2. 存在可积函数 g∈L¹ 使得 |fₙ(x)|≤g(x) 对所有 n 和 a.e. x 成立
则 f∈L¹ 且 lim_{n→∞} ∫fₙ dμ = ∫f dμ。

### 8.2 证明思路（用 Egorov 定理）

1. 由 |fₙ|≤g 和 fₙ→f a.e.，得 |f|≤g a.e.，所以 f∈L¹
2. 对任意 ε>0，因为 g∈L¹，由积分的绝对连续性，存在 δ>0 使得 μ(E)&lt;δ 时 ∫_E |g| dμ&lt;ε/3
3. 由 Egorov 定理（有限测度子集上），存在 E 使得 μ(E)&lt;δ 且 fₙ 在 E^c 上一致收敛到 f
4. 在 E^c 上，由一致收敛，存在 N 使得 n>N 时 |fₙ-f|&lt;ε/(3μ(X))（如果 μ(X)&lt;∞；一般情况用 g 的积分控制）
5. 估计 |∫fₙ-∫f|≤∫|fₙ-f|=∫_E |fₙ-f|+∫_{E^c}|fₙ-f|≤2∫_E g+∫_{E^c}|fₙ-f|&lt;2ε/3+ε/3=ε

### 8.3 控制收敛定理的意义

DCT 是实变函数中最常用的定理之一。它解决了"什么时候积分和极限可以交换顺序"的问题——只要函数列被一个可积函数控制，且几乎处处收敛（或依测度收敛），就可以交换积分和极限。

**对比 Riemann 积分**：在 Riemann 积分理论中，交换积分和极限需要一致收敛条件（非常强）。DCT 把条件从"一致收敛"放宽到"几乎处处收敛+可积控制"，这是 Lebesgue 积分比 Riemann 积分优越的核心原因之一。

**典型应用**：
- 证明积分号下求导（Leibniz 法则）
- 证明 Fubini 定理
- 证明 Fourier 变换的连续性
- 证明 Lp 空间的完备性（Riesz-Fischer 定理）

### 8.4 控制收敛定理的几何理解

**📐 几何图像**：DCT 在几何上是"面积的收敛"。fₙ(x) 的图像下方的面积（积分）收敛到 f(x) 图像下方的面积。控制条件 |fₙ|≤g 意味着 fₙ 的图像都在 g 的图像下方——g 的图像下方的面积有限（g∈L¹），所以 fₙ 的图像下方的面积不会"跑掉"。在这个"天花板"g 的控制下，fₙ 的图像向 f 的图像靠拢（a.e. 收敛），面积也跟着靠拢。

对比没有控制条件的情况：fₙ=nχ_{(0,1/n)} 的图像是一个"又高又瘦"的矩形——高度 n 趋于无穷，宽度 1/n 趋于 0，面积始终为 1。虽然 fₙ→0 a.e.，但面积不趋于 0，因为"高度"跑掉了。控制条件 |fₙ|≤g 就是防止"高度跑掉"——g 给了一个统一的上界。

### 8.5 相关定理

**Fatou 引理**：若 fₙ≥0 且 fₙ→f a.e.，则 ∫f ≤ lim inf ∫fₙ。
（Fatou 引理不需要控制条件，但只能得到不等式，不是等式。）

**单调收敛定理（MCT）**：若 0≤f₁≤f₂≤... 且 fₙ→f a.e.，则 ∫fₙ→∫f。
（单调收敛定理不需要控制条件，但需要单调性。）

**三个定理的关系**：
- MCT ⇒ Fatou 引理（对 fₙ 取下确界构造单调列）
- Fatou 引理 ⇒ DCT（对 g+fₙ 和 g-fₙ 分别用 Fatou）
- DCT ⇒ MCT（如果 fₙ 单调递增且 f₁∈L¹，则 fₙ 被 f 控制，用 DCT）

## 第九章 Riesz 定理与子列收敛

### 9.1 Riesz 定理

**Riesz 定理**：若 fₙ→^μ f（依测度收敛），则存在子列 {fₙₖ} 使得 fₙₖ→f a.e.（几乎处处收敛）。

**加强版**：实际上，这个子列还可以做到几乎一致收敛。

### 9.2 证明思路

1. 因为 fₙ→^μ f，对每个 k，存在 n_k 使得 μ({|fₙₖ-f|≥1/k})&lt;1/2^k
2. 令 E_k={|fₙₖ-f|≥1/k}，则 μ(E_k)&lt;1/2^k
3. 令 E=lim sup E_k=∩_m ∪_{k≥m} E_k
4. 由 Borel-Cantelli 引理（Σ μ(E_k)&lt;∞），μ(E)=0
5. 对 x∉E，存在 m 使得 x∉∪_{k≥m} E_k，即对所有 k≥m，|fₙₖ(x)-f(x)|&lt;1/k→0
6. 所以 fₙₖ(x)→f(x) 对 x∉E，即 fₙₖ→f a.e.

### 9.3 Riesz 定理的意义

Riesz 定理建立了依测度收敛和几乎处处收敛之间的桥梁——依测度收敛虽然不蕴含几乎处处收敛，但总能找到一个子列几乎处处收敛。这使得我们可以用"子列技巧"来处理依测度收敛的问题：先取子列转化为几乎处处收敛，用几乎处处收敛的性质处理，再回到原序列。

**典型应用**：
- 证明 Lp 收敛的完备性（Riesz-Fischer 定理）中用到 Riesz 定理
- 证明依测度收敛的某些性质时，先取子列
- 证明 Vitali 收敛定理

### 9.4 Riesz 定理的几何理解

**📐 几何图像**：Riesz 定理在几何上是"从依测度收敛中提取逐点收敛子列"。依测度收敛意味着"差别大的地方面积趋于 0"——但这些"差别大的地方"可能在不同的 n 出现在不同的位置（如滑动区间），所以没有一个固定的点能保证收敛。Riesz 定理说：可以选一个子列，使得"差别大的地方"出现得足够稀疏（Borel-Cantelli 条件），以至于几乎每个点只在有限个子列项中属于"差别大的地方"——从而在这个子列下，几乎每个点都收敛。

想象滑动区间函数列——区间在 [0,1] 上滑动，每个点都在无穷多个区间内（所以不逐点收敛）。但如果选一个子列，使得区间的长度下降得足够快（如 1/2^k），那么由 Borel-Cantelli，几乎每个点只在有限个区间内——从而在这个子列下，几乎每个点最终都离开区间，函数值趋于 0。

## 第十章 反例库

### 10.1 几乎处处收敛但不依测度收敛（无限测度）

**反例 1**：fₙ(x)=χ_{(n,n+1)}(x)，在 ℝ 上。
- fₙ→0 a.e.（对任意固定 x，n>x 时 fₙ(x)=0）
- 但 fₙ 不依测度收敛到 0（μ({|fₙ|≥1/2})=1 不趋于 0）
- 也不几乎一致收敛（在任意有限测度集合外，fₙ 不趋于 0）
- 也不 Lp 收敛（∫|fₙ|^p=1 不趋于 0）

### 10.2 依测度收敛但不几乎处处收敛

**反例 2**：滑动区间函数列 fₙ=χ_{(k/2^m,(k+1)/2^m]}（n=2^m+k, 0≤k&lt;2^m），在 [0,1] 上。
- fₙ→^μ 0（区间测度 1/2^m→0）
- 但 fₙ 不 a.e. 收敛（每个点属于无穷多个区间，函数值在 0 和 1 之间振荡）
- 也不几乎一致收敛（a.u.⇒a.e.，矛盾）
- 也不 Lp 收敛（∫|fₙ|^p=1/2^m→0？等等，∫|fₙ|^p=区间长度=1/2^m→0，所以 Lp 收敛到 0！）

让我重新检查：fₙ=χ_{区间}，区间长度=1/2^m。∫|fₙ|^p=1/2^m→0。所以滑动区间函数列**Lp 收敛到 0**！

那 Lp 收敛但不 a.e. 收敛的反例就是滑动区间函数列。这验证了"Lp 收敛⇏a.e. 收敛"。

### 10.3 几乎处处收敛但不 Lp 收敛

**反例 3**：fₙ(x)=n·χ_{(0,1/n)}(x)，在 (0,1) 上，p=1。
- fₙ→0 a.e.
- fₙ→^μ 0
- fₙ→0 a.u.
- 但 ∫|fₙ|=1 不趋于 0，不 L1 收敛

**反例 4**：fₙ(x)=√n·χ_{(0,1/n)}(x)，在 (0,1) 上，p=2。
- fₙ→0 a.e.
- fₙ→^μ 0
- 但 ∫|fₙ|²=1 不趋于 0，不 L2 收敛

### 10.4 Lp 收敛但不几乎处处收敛

**反例 5**：滑动区间函数列（见反例 2）。
- Lp 收敛到 0（∫|fₙ|^p=1/2^m→0）
- 但不 a.e. 收敛
- 存在子列 a.e. 收敛（Riesz 定理）

### 10.5 依测度收敛但不 Lp 收敛

**反例 6**：fₙ(x)=n·χ_{(0,1/n)}(x)，在 (0,1) 上，p=1。
- fₙ→^μ 0
- 但不 L1 收敛（∫|fₙ|=1）

### 10.6 几乎处处收敛但不几乎一致收敛（无限测度）

**反例 7**：fₙ(x)=χ_{(n,n+1)}(x)，在 ℝ 上。
- fₙ→0 a.e.
- 但不 a.u.（Egorov 定理需要有限测度）

### 10.7 控制收敛定理中控制条件不可去

**反例 8**：fₙ(x)=n·χ_{(0,1/n)}(x)，在 (0,1) 上。
- fₙ→0 a.e.
- 但不存在可积函数 g 使得 |fₙ|≤g（因为 sup_n fₙ(x)~1/x，不可积）
- ∫fₙ=1 不趋于 ∫0=0
- 这说明控制条件是必要的

### 10.8 Egorov 定理中有限测度条件不可去

**反例 9**：fₙ(x)=χ_{(n,n+1)}(x)，在 ℝ 上。
- fₙ→0 a.e.
- 但不 a.u.（有限测度条件不满足）
- 这说明有限测度条件是必要的

## 第十一章 历史演进

### 11.1 收敛模式理论的历史分期

**第一期：逐点收敛与一致收敛（1821 - 1902）**
- 柯西（1821）：引入逐点收敛和一致收敛的概念（虽然最初混淆了两者）
- 阿贝尔（1826）：指出柯西"连续函数列的极限连续"的错误，需要一致收敛
- 魏尔斯特拉斯（1840s-1870s）：严格区分逐点收敛和一致收敛，给出一致收敛的 ε-N 定义
- 狄利克雷（1829）：研究函数项级数的收敛性

**第二期：Lebesgue 积分与新收敛模式（1902 - 1930）**
- 勒贝格（1902）：创立 Lebesgue 积分，引入几乎处处收敛的概念
- 勒贝格（1904-1910）：证明控制收敛定理、Egorov 定理（Egorov 1911 年独立发表）
- Egorov（1911）：发表 Egorov 定理
- Riesz（1909-1910）：引入依测度收敛，证明 Riesz 定理
- Fischer（1907）：证明 L² 空间的完备性（Riesz-Fischer 定理）
- Fatou（1906）：证明 Fatou 引理

**第三期：系统化与公理化（1930 - 1950）**
- 巴拿赫（1932）：Banach 空间理论，Lp 空间作为 Banach 空间的例子
- 维纳（1930s）：调和分析中的收敛模式
- Khintchine（1930s）：概率论中的依概率收敛（依测度收敛在概率论中的版本）
- 科尔莫戈罗夫（1933）：概率论公理化，将依概率收敛、几乎必然收敛、Lp 收敛纳入公理框架

**第四期：现代发展（1950 - 至今）**
- 弱收敛、弱*收敛（Banach 空间中的收敛模式）
- 分布收敛（Schwartz 分布理论）
- 模糊收敛（测度的收敛）
- 各种函数空间中的收敛（Sobolev 空间、Besov 空间等）

### 11.2 关键人物与贡献

| 人物 | 年代 | 贡献 |
|---|---|---|
| 柯西 | 1821 | 逐点收敛与一致收敛（初期混淆） |
| 阿贝尔 | 1826 | 指出一致收敛的必要性 |
| 魏尔斯特拉斯 | 1840s-1870s | 严格区分逐点和一致收敛 |
| 勒贝格 | 1902 | Lebesgue 积分，几乎处处收敛，DCT |
| Fatou | 1906 | Fatou 引理 |
| Riesz | 1909 | 依测度收敛，Riesz 定理 |
| Fischer | 1907 | L² 完备性 |
| Egorov | 1911 | Egorov 定理 |
| 巴拿赫 | 1932 | Banach 空间，Lp 空间理论 |

### 11.3 历史发展的主线

1. **从逐点到几乎处处**：Lebesgue 积分的创立使得"零测集上不收敛"可以被忽略，几乎处处收敛成为自然的收敛概念。
2. **从逐点到整体**：依测度收敛和 Lp 收敛不再关注每个点的收敛性，而是关注"整体"的收敛——差别大的集合测度趋于 0，或平均误差趋于 0。
3. **积分和极限的交换**：DCT、MCT、Fatou 引理解决了"什么时候可以交换积分和极限"的问题，这是 Lebesgue 积分理论的核心。
4. **函数空间的完备性**：Lp 空间的完备性（Riesz-Fischer 定理）使得 Lp 空间成为 Banach 空间，为泛函分析奠定基础。

## 第十二章 跨层蜕变图谱

### 12.1 极限概念在各层的演化

| 维度 | L1 数学分析 | L2 复变函数 | L3 实变函数 |
|---|---|---|---|
| 收敛模式 | 逐点收敛、一致收敛 | 逐点收敛、内闭一致收敛 | a.e.、依测度、Lp、a.u. |
| 收敛定义 | ε-N/ε-δ | ε-δ（模长） | 测度/积分 |
| 不收敛的容忍度 | 不容忍（逐点） | 不容忍（逐点） | 容忍零测集（a.e.）或小测度集（依测度/a.u.） |
| 积分交换条件 | 一致收敛 | 内闭一致收敛 | a.e.+控制（DCT） |
| 函数空间 | C[a,b]（sup 范数） | 解析函数空间 | Lp 空间（Banach/Hilbert） |
| 完备性 | C[a,b] sup 完备 | 解析函数空间内闭一致收敛完备 | Lp 完备（Riesz-Fischer） |
| 子列收敛 | 有界数列有收敛子列（BW） | 正规族（Montel） | 依测度收敛有 a.e. 子列（Riesz） |
| 代表定理 | 一致收敛极限连续 | Weierstrass 定理（极限仍解析） | DCT、Egorov、Riesz |

### 12.2 定理强度演化表

| 定理 | 数学分析 | 复变函数 | 实变函数 |
|---|---|---|---|
| 极限唯一性 | 成立 | 成立 | a.e. 成立 |
| 极限保持连续性 | 一致收敛⇒连续 | 内闭一致收敛⇒解析 | a.e.收敛⇒可测（不保证连续） |

### 12.3 反例演化链

```
fₙ=nχ_{(0,1/n)}（实变：a.e.→0，依测度→0，a.u.→0，但不 L1 收敛，积分不收敛）
  ↓ 对应数学分析
  └── fₙ(x)=n x(1-x²)^n（数分：逐点→0，但不一致收敛，积分不收敛）
      └── 都是"高度跑掉"的反例——函数值在小区间上很大，导致积分不收敛

滑动区间 fₙ=χ_{(k/2^m,(k+1)/2^m]}（实变：依测度→0，Lp→0，但不 a.e. 收敛）
  ↓ 对应数学分析
  └── 无直接对应（数分中主要研究逐点收敛和一致收敛，不研究依测度收敛）
      └── 这是实变函数独有的反例类型——"移动的不收敛点集"

fₙ=χ_{(n,n+1)}（实变无限测度：a.e.→0，但不依测度、不 a.u.、不 Lp）
  ↓ 对应有限测度
  └── 在有限测度空间上，a.e.⇒依测度（Lebesgue 定理）和 a.u.（Egorov）
      └── 无限测度空间上这些蕴含关系失效
```

### 12.4 关键蜕变问题

**问题一：为什么实变函数需要这么多种收敛模式？**

回答：因为逐点收敛在实变函数中有两个严重缺陷——(1) 太严格（不允许零测集上不收敛），(2) 不保持积分。为了解决这两个问题，需要引入新的收敛模式：几乎处处收敛放宽了"每个点都收敛"的要求；依测度收敛和 Lp 收敛从"整体"角度衡量收敛，和积分有更好的兼容性；几乎一致收敛是"去掉小集合后的一致收敛"，兼具逐点性和一致性。这些收敛模式各有用途，共同构成了实变函数的收敛理论。

**问题二：四种收敛模式之间最核心的关系是什么？**

回答：在有限测度空间上，核心关系是：
1. **几乎处处收敛 ⟺ 几乎一致收敛**（Egorov 定理给出 ⇒，反向是平凡的）
2. **Lp 收敛 ⇒ 依测度收敛**（Chebyshev 不等式）
3. **几乎处处收敛 ⇒ 依测度收敛**（Lebesgue 定理）
4. **依测度收敛 ⇒ 存在子列几乎处处收敛**（Riesz 定理）

其中 Egorov 定理和 Riesz 定理是两座桥梁——Egorov 连接 a.e. 和 a.u.，Riesz 连接依测度和 a.e.（通过子列）。Lp 收敛和 a.e. 收敛之间没有直接蕴含关系，它们是"不同维度"的收敛，但都蕴含依测度收敛。

**问题三：控制收敛定理为什么重要？**

回答：DCT 解决了"积分和极限交换顺序"的问题——这是分析学中最基本的操作之一。在 Riemann 积分中，交换积分和极限需要一致收敛（非常强的条件）。DCT 把条件放宽到"几乎处处收敛+可积控制"，这使得大量以前无法处理的极限问题变得可以处理。DCT 是 Lebesgue 积分比 Riemann 积分优越的核心原因之一，也是现代分析学（概率论、偏微分方程、调和分析等）的基础工具。

**问题四：从几何上如何理解四种收敛模式的区别？**

回答：四种收敛模式衡量"函数图像向目标图像靠拢"的不同方式：
- **几乎处处收敛**：在几乎所有 x 处，图像的 y 坐标靠拢（速度可不均匀）
- **依测度收敛**：图像 y 坐标差别大的 x 集合的"长度"趋于 0
- **Lp 收敛**：图像之间的"面积"（差的 p 次幂积分）趋于 0
- **几乎一致收敛**：去掉一小块 x 集合后，图像以均匀速度靠拢

可以用"人群向终点跑"来类比：a.e. 是几乎所有人都跑到终点（时间可不同）；依测度是"没跑到终点的人数比例"趋于 0；Lp 是"所有人离终点的平均距离"趋于 0；a.u. 是去掉少数最慢的人后，所有人到达终点的时间有统一上界。

### 13.3 常见误区清单

1. **几乎处处收敛就是逐点收敛** → 错。a.e. 允许在零测集上不收敛。
2. **依测度收敛蕴含几乎处处收敛** → 错。滑动区间反例。
3. **Lp 收敛蕴含几乎处处收敛** → 错。滑动区间反例（Lp 收敛但不 a.e.）。
4. **几乎处处收敛蕴含 Lp 收敛** → 错。fₙ=nχ_{(0,1/n)} 反例。
5. **几乎处处收敛蕴含依测度收敛** → 在有限测度上对，无限测度上错。
6. **Egorov 定理在无限测度上成立** → 错。需要有限测度。
7. **DCT 不需要控制条件** → 错。控制条件必要（fₙ=nχ_{(0,1/n)} 反例）。
8. **依测度收敛的极限唯一** → a.e. 意义下唯一，不是逐点唯一。
9. **一致收敛和几乎一致收敛一样** → 错。a.u. 允许去掉小集合。
10. **Lp 收敛对所有 p 都一样** → 错。不同 p 的 Lp 收敛不等价（有限测度上 p 越大越强）。

### 15.2 类比

- 几乎处处收敛与逐点收敛：前者允许零测集上不收敛
- 依测度收敛与几乎处处收敛：前者衡量"差别大的集合大小"，后者衡量"逐点收敛性"

- L∞ 收敛是 Lp 收敛的特例（p→∞）
- 数列收敛是函数列收敛的特例（定义域为单点）
- 连续函数列是可测函数列的特例
- 概率空间是有限测度空间的特例（测度=1）

> **模块结语 · D1 极限领域核心理论（续四）**：
>
> 实变函数中的收敛模式是从"逐点"到"整体"的范式转变——它不再要求每个点都收敛，而是允许在"小集合"上不收敛，或用"平均"的方式衡量收敛。
>
> 本模块从五个维度建立了实变函数收敛模式的完整理论：
>
> **四种收敛模式**：几乎处处收敛（允许零测集上不收敛）、依测度收敛（差别大的集合测度趋于 0）、Lp 收敛（平均误差趋于 0）、几乎一致收敛（去掉小集合后一致收敛）。
>
> **关系网**：在有限测度空间上，a.e.⟺a.u.（Egorov），Lp⇒依测度（Chebyshev），a.e.⇒依测度（Lebesgue），依测度⇒子列 a.e.（Riesz）。Lp 和 a.e. 之间没有直接蕴含关系。
>
> **三大定理**：Egorov 定理（a.e.⇒a.u.，有限测度）、Riesz 定理（依测度⇒子列 a.e.）、Lebesgue 控制收敛定理（a.e.+控制⇒积分收敛）。这三大定理是实变函数的基石。
>
> **积分和极限的交换**：DCT、MCT、Fatou 引理解决了"什么时候可以交换积分和极限"的问题——这是 Lebesgue 积分比 Riemann 积分优越的核心原因。
>
> **几何视角**：四种收敛模式衡量"函数图像向目标图像靠拢"的不同方式——a.e. 是几乎所有点靠拢（速度可不均），依测度是差别大的地方面积趋于 0，Lp 是图像之间的面积趋于 0，a.u. 是去掉一小块后均匀靠拢。
>
> 实变函数收敛模式的核心洞察是：**逐点收敛太严格且不保持积分，需要引入多种"整体"收敛模式来弥补——这些收敛模式各有用途，通过 Egorov、Riesz、DCT 三大定理相互联系，共同构成了现代分析学的收敛理论基础**。
>
